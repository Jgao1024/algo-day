### 041: [704. 二分查找 (Binary Search)](https://leetcode.cn/problems/binary-search)

**题目描述:**
给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target` ，写一个函数搜索 `nums` 中的 `target`，如果目标值存在返回下标，否则返回 `-1`。

**解题思路 (标准二分查找):**
1.  初始化两个指针，`left = 0` 和 `right = nums.length - 1`。
2.  当 `left <= right` 时，执行循环：
    a.  计算中间索引 `mid = left + (right - left) // 2` (这种写法可以防止 `left + right` 溢出，尽管在 Python 中不那么关键，但在 Java 等语言中很重要)。
    b.  比较 `nums[mid]` 和 `target`:
    i.  如果 `nums[mid] == target`，则找到了目标值，返回 `mid`。
    ii. 如果 `nums[mid] < target`，说明目标值在右半部分 (如果存在)，所以 `left = mid + 1`。
    iii.如果 `nums[mid] > target`，说明目标值在左半部分 (如果存在)，所以 `right = mid - 1`。
3.  如果循环结束 (`left > right`) 仍未找到目标值，则返回 `-1`。

**Python 实现:**
```python
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2 # Prevents potential overflow
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else: # nums[mid] > target
                right = mid - 1
                
        return -1 # Target not found
```

**Java 实现:**
```java

        int left = 0;
        int right = nums.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2; // Prevents potential overflow
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {

            } else { // nums[mid] > target

        }

    }
}
```

**复杂度分析:**
*   时间复杂度: O(log N)，其中 N 是数组 `nums` 的长度。每次迭代都将搜索空间减半。
*   空间复杂度: O(1)，只使用了常数个额外变量。

### 042: [232. 用栈实现队列 (Implement Queue using Stacks)](https://leetcode.cn/problems/implement-queue-using-stacks)

**题目描述:**
请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（`push`、`pop`、`peek`、`empty`）。

**解题思路 (双栈法):**
使用两个栈，`input_stack` 和 `output_stack`。
*   **`push(x)` 操作 (入队):**
    *   始终将新元素压入 `input_stack`。这是 O(1) 操作。
*   **`pop()` 操作 (出队):**
    *   如果 `output_stack` 为空，则将 `input_stack` 中的所有元素逐个弹出并压入 `output_stack`。这个过程会反转元素的顺序，使得最早进入 `input_stack` 的元素现在位于 `output_stack` 的顶部。
    *   然后，从 `output_stack` 顶部弹出一个元素并返回。
    *   如果 `output_stack` 和 `input_stack` 都为空，则队列为空，无法弹出。
*   **`peek()` 操作 (查看队首元素):**
    *   与 `pop()` 类似，如果 `output_stack` 为空，先将 `input_stack` 的元素倒入 `output_stack`。
    *   然后，返回 `output_stack` 顶部的元素，但不弹出。
*   **`empty()` 操作 (判空):**
    *   当且仅当 `input_stack` 和 `output_stack` 都为空时，队列才为空。

**摊还分析:**
虽然 `pop` 和 `peek` 操作在某些情况下（当 `output_stack` 为空时）需要 O(N) 的时间来转移元素，但每个元素最多只会被从 `input_stack` 移到 `output_stack` 一次。因此，对于一系列操作，平均下来每个操作的时间复杂度是 O(1)。

**Python 实现:**
```python
class MyQueue:
    def __init__(self):
        self.input_stack = []
        self.output_stack = []

    def push(self, x: int) -> None:
        self.input_stack.append(x)

    def _transfer_if_needed(self):
        # If output_stack is empty, transfer elements from input_stack
        if not self.output_stack:
            while self.input_stack:
                self.output_stack.append(self.input_stack.pop())

    def pop(self) -> int:
        self._transfer_if_needed()
        if not self.output_stack:
            return None # Or raise an error for empty queue
        return self.output_stack.pop()

    def peek(self) -> int:
        self._transfer_if_needed()
        if not self.output_stack:
            return None # Or raise an error
        return self.output_stack[-1] # Peek at the top element

    def empty(self) -> bool:
        return not self.input_stack and not self.output_stack

```

**Java 实现:**
```java
import java.util.Stack;

class MyQueue {
    private Stack<Integer> inputStack;
    private Stack<Integer> outputStack;

    public MyQueue() {
        inputStack = new Stack<>();
        outputStack = new Stack<>();
    }
    
    public void push(int x) {
        inputStack.push(x);
    }
    
    private void transferIfNeeded() {
        // If outputStack is empty, transfer elements from inputStack
        if (outputStack.isEmpty()) {
            while (!inputStack.isEmpty()) {
                outputStack.push(inputStack.pop());
            }
        }
    }
    
    public int pop() {
        transferIfNeeded();
        if (outputStack.isEmpty()) {
            throw new RuntimeException("Queue is empty"); // Or return a specific value if allowed
        }
        return outputStack.pop();
    }
    
    public int peek() {
        transferIfNeeded();
        if (outputStack.isEmpty()) {
            throw new RuntimeException("Queue is empty"); // Or return a specific value
        }
        return outputStack.peek();
    }
    
    public boolean empty() {
        return inputStack.isEmpty() && outputStack.isEmpty();
    }
}
```

**复杂度分析:**
*   `push`: O(1)
*   `pop`: 摊还 O(1) (最坏情况 O(N) 当需要转移时，但平均为 O(1))
*   `peek`: 摊还 O(1) (最坏情况 O(N) 当需要转移时，但平均为 O(1))
*   `empty`: O(1)
*   空间复杂度: O(N) (N 是队列中元素的数量，存储在两个栈中)。

### 043: [148. 排序链表 (Sort List)](https://leetcode.cn/problems/sort-list)

**题目描述:**
给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。
**进阶：** 你可以在 O(n log n) 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

**解题思路 (归并排序):**
链表排序的常用高效方法是归并排序，因为它天然适合链表操作，并且可以达到 O(N log N) 的时间复杂度。原地归并排序对链表来说实现 O(1) 空间复杂度比较困难 (通常递归版本是 O(log N) 栈空间，迭代版本用技巧可实现 O(1) 额外空间但较复杂)。LeetCode 这个问题一般用递归的归并排序就能通过。

1.  **分割 (Split):**
    *   **基准情况**: 如果链表为空或只有一个节点，它已经排序，直接返回。
    *   使用快慢指针法找到链表的中点。慢指针 `slow` 走一步，快指针 `fast` 走两步。
    *   当 `fast` 到达末尾 (或 `fast.next` 到末尾) 时，`slow` 所在的位置就是中点 (或中点前的节点，如果希望 `slow` 是第一部分的尾巴)。
    *   找到中点后，将链表从中间断开，形成两个子链表。设 `mid_node = slow.next`，然后 `slow.next = null`。
2.  **递归排序 (Conquer):**
    *   递归地对两个子链表进行排序：
        *   `sorted_left_half = sortList(head)` (原始的 `head` 到 `slow` 之前的子链表)
        *   `sorted_right_half = sortList(mid_node)` (从中点开始的子链表)
3.  **合并 (Merge):**
    *   将两个已排序的子链表 `sorted_left_half` 和 `sorted_right_half` 合并成一个有序链表。使用标准的合并两个有序链表的算法 (类似题目 21)。
    *   返回合并后的链表头。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        # Base case for recursion
        if not head or not head.next:
            return head

        # 1. Split the list into two halves
        # Find middle using slow and fast pointers
        slow, fast = head, head.next # Start fast one step ahead to get mid or left-mid
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        # 'slow' is now at the middle (or left-middle if even nodes).
        # The second half starts at 'slow.next'.
        second_half_head = slow.next
        slow.next = None # Disconnect the first half from the second half

        # 2. Recursively sort each half
        sorted_left_half = self.sortList(head)
        sorted_right_half = self.sortList(second_half_head)

        # 3. Merge the two sorted halves
        return self.merge_two_sorted_lists(sorted_left_half, sorted_right_half)

    def merge_two_sorted_lists(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        current = dummy

        while l1 and l2:
            if l1.val < l2.val:
                current.next = l1
                l1 = l1.next
            else:
                current.next = l2
                l2 = l2.next
            current = current.next
        
        if l1:
            current.next = l1
        elif l2:
            current.next = l2
            
        return dummy.next
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode sortList(ListNode head) {
        // Base case for recursion
        if (head == null || head.next == null) {
            return head;
        }

        // 1. Split the list into two halves
        // Find middle using slow and fast pointers
        ListNode slow = head;
        ListNode fast = head.next; // Start fast one step ahead for correct middle
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // 'slow' is now at the middle (or left-middle for even nodes).
        // The second half starts at 'slow.next'.
        ListNode secondHalfHead = slow.next;
        slow.next = null; // Disconnect the first half from the second half

        // 2. Recursively sort each half
        ListNode sortedLeftHalf = sortList(head);
        ListNode sortedRightHalf = sortList(secondHalfHead);

        // 3. Merge the two sorted halves
        return mergeTwoSortedLists(sortedLeftHalf, sortedRightHalf);
    }

    private ListNode mergeTwoSortedLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }
        
        if (l1 != null) {
            current.next = l1;
        } else if (l2 != null) {
            current.next = l2;
        }
            
        return dummy.next;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N log N)。分割链表 (快慢指针) O(N)，合并链表 O(N)。递归深度是 log N。所以是 N * log N。
*   空间复杂度: O(log N)。主要是递归调用栈的深度。对于迭代版本的归并排序（自底向上），可以实现 O(1) 空间，但实现起来更复杂。

### 044: [22. 括号生成 (Generate Parentheses)](https://leetcode.cn/problems/generate-parentheses)

**题目描述:**
数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

**解题思路 (回溯法 Backtracking):**
我们可以通过构建字符串，在每一步决定是添加一个左括号 `'('`还是一个右括号 `')'`。为了确保生成的括号组合是有效的，我们需要遵循以下规则：
1.  **左括号数量约束**: 任何时候，已放置的左括号数量不能超过 `n`。
2.  **右括号数量约束**: 任何时候，已放置的右括号数量不能超过已放置的左括号数量。
3.  **最终数量约束**: 最终生成的字符串中，左括号和右括号的数量都必须等于 `n`。

**回溯函数 `backtrack(current_string, open_count, close_count)`:**
*   `current_string`: 当前构建的括号字符串。
*   `open_count`: 当前已使用的左括号数量。
*   `close_count`: 当前已使用的右括号数量。
*   `n`: 需要的括号对数。

**递归步骤:**
1.  **基准情况 (Base Case)**:
    *   如果 `len(current_string) == 2 * n` (即字符串长度达到 `n` 对括号的总长度)，说明已生成一个完整的组合。将其加入结果列表 `result`，并返回。
2.  **添加左括号**:
    *   如果 `open_count < n` (还可以添加左括号)，则：
        *   `current_string += '('`
        *   `backtrack(current_string, open_count + 1, close_count)`
        *   `current_string.pop_back()` (撤销选择)
3.  **添加右括号**:
    *   如果 `close_count < open_count` (已有的左括号比右括号多，可以添加右括号来匹配)，则：
        *   `current_string += ')'`
        *   `backtrack(current_string, open_count, close_count + 1)`
        *   `current_string.pop_back()` (撤销选择)

**Python 实现:**
```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        result = []
        current_string = [] # Use a list of chars for easier append/pop

        def backtrack(open_count, close_count):
            # Base case: string is complete
            if len(current_string) == 2 * n:
                result.append("".join(current_string))
                return

            # Option 1: Add an opening parenthesis
            if open_count < n:
                current_string.append("(")
                backtrack(open_count + 1, close_count)
                current_string.pop() # Backtrack

            # Option 2: Add a closing parenthesis
            if close_count < open_count:
                current_string.append(")")
                backtrack(open_count, close_count + 1)
                current_string.pop() # Backtrack

        backtrack(0, 0)
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(result, new StringBuilder(), 0, 0, n);
        return result;
    }

    private void backtrack(List<String> result, StringBuilder currentString, int openCount, int closeCount, int n) {
        // Base case: string is complete
        if (currentString.length() == 2 * n) {
            result.add(currentString.toString());
            return;
        }

        // Option 1: Add an opening parenthesis
        if (openCount < n) {
            currentString.append('(');
            backtrack(result, currentString, openCount + 1, closeCount, n);
            currentString.deleteCharAt(currentString.length() - 1); // Backtrack
        }

        // Option 2: Add a closing parenthesis
        if (closeCount < openCount) {
            currentString.append(')');
            backtrack(result, currentString, openCount, closeCount + 1, n);
            currentString.deleteCharAt(currentString.length() - 1); // Backtrack
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(4<sup>n</sup> / √n)。结果的数量是卡特兰数 C<sub>n</sub>，大约是这个量级。每个结果长度为 2n。
*   空间复杂度: O(N) (递归栈深度最大为 2N，`current_string` 长度最大 2N)。

### 045: [165. 比较版本号 (Compare Version Numbers)](https://leetcode.cn/problems/compare-version-numbers)

**题目描述:**
给你两个版本号 `version1` 和 `version2` ，请你比较它们。
版本号由一个或多个修订号组成，各修订号由一个 `.` 连接。每个修订号由 **多位数字** 组成，可能包含 **前导零** 。

**解题思路:**
1.  **分割版本号**: 将 `version1` 和 `version2` 字符串按 `'.'` 分割成修订号列表 (e.g., `"1.0.1"` -> `["1", "0", "1"]`)。
2.  **逐个比较**: 确定两个版本号列表的最大长度 `max_len`。然后从 `i = 0` 到 `max_len - 1` 遍历：
    a.  获取第 `i` 个修订号：
    *   对于 `version1`: 如果 `i` 小于 `v1_parts` 的长度，则取 `v1_parts[i]` 并转换为整数。否则，视为 `0` (例如 `1.0` 与 `1.0.0` 比较时，前者第三段是 `0`)。
    *   对于 `version2`: 同理。
    b.  比较这两个整数修订号 `rev1` 和 `rev2`：
    *   如果 `rev1 > rev2`，则 `version1 > version2`，返回 `1`。
    *   如果 `rev1 < rev2`，则 `version1 < version2`，返回 `-1`。
3.  如果遍历完所有修订号都相等，则 `version1 == version2`，返回 `0`。

**Python 实现:**
```python
class Solution:
    def compareVersion(self, version1: str, version2: str) -> int:
        v1_parts = version1.split('.')
        v2_parts = version2.split('.')
        
        len1 = len(v1_parts)
        len2 = len(v2_parts)
        max_len = max(len1, len2)
        
        for i in range(max_len):
            # Get revision number, defaulting to 0 if part doesn't exist
            rev1 = int(v1_parts[i]) if i < len1 else 0
            rev2 = int(v2_parts[i]) if i < len2 else 0
            
            if rev1 > rev2:
                return 1
            elif rev1 < rev2:
                return -1
                
        return 0 # Versions are equal
```

```python
        """
        n = len(nums)
        if n <= 1:
            return

        # 1. Find the first element from the right that is smaller than its next element
        i = n - 2
        while i >= 0 and nums[i] >= nums[i+1]:
            i -= 1

        if i >= 0: # Found such an element nums[i]
            # 2. Find the smallest element to the right of nums[i] that is greater than nums[i]
            j = n - 1
            while j > i and nums[j] <= nums[i]:
                j -= 1
            # 3. Swap nums[i] and nums[j]
            nums[i], nums[j] = nums[j], nums[i]
        
        # 4. Reverse the sub-array to the right of index i
        # If i < 0 (array was in descending order), this reverses the whole array
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
```

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        if (n <= 1) {
            return;
        }

        // 1. Find the first element from the right that is smaller than its next element
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i+1]) {
            i--;
        }

        if (i >= 0) { // Found such an element nums[i]
            // 2. Find the smallest element to the right of nums[i] that is greater than nums[i]
            int j = n - 1;
            while (j > i && nums[j] <= nums[i]) {
                j--;
            }
            // 3. Swap nums[i] and nums[j]
            swap(nums, i, j);
        }
        
        // 4. Reverse the sub-array to the right of index i
        // If i < 0 (array was in descending order), this reverses the whole array
        reverse(nums, i + 1, n - 1);
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}
```

*   空间复杂度: O(1)，因为是原地修改。

### 047: [69. x 的平方根 (Sqrt(x))](https://leetcode.cn/problems/sqrtx)

**题目描述:**
给你一个非负整数 `x` ，计算并返回 `x` 的 **算术平方根** 。
由于返回类型是整数，结果只保留 **整数部分** ，小数部分将被 **舍去** 。
**注意：** 不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5` 。

**解题思路:**
**1. 二分查找法:**
* 我们要找一个整数 `ans` 使得 `ans * ans <= x` 并且 `(ans + 1) * (ans + 1) > x`。
* 搜索范围是 `[0, x]` (或者更紧一点，比如 `[0, x/2 + 1]` 如果 x >= 2)。
* 初始化 `left = 0`, `right = x`。
* `ans = 0` (用来记录满足 `mid*mid <= x` 的最大 `mid`)。
* 当 `left <= right` 时循环：
    * `mid = left + (right - left) // 2`。
    * 如果 `mid * mid == x`，则 `mid` 就是精确的平方根，返回 `mid`。
    * 如果 `mid * mid < x`：
        * `mid` 可能就是答案，或者答案在 `mid` 的右边。记录 `ans = mid`，然后 `left = mid + 1` (尝试更大的值)。
    * 如果 `mid * mid > x`：
        * `mid` 太大了，答案在 `mid` 的左边。`right = mid - 1`。
* 循环结束后，`ans` (或者最后一次满足 `mid*mid < x` 的`mid`，也就是当前的`right` 指针可能的位置）即为所求。实际上，循环结束时，`right` 指向的就是结果。

**2. 牛顿迭代法 (更高级):**
* 求 `f(ans) = ans^2 - x = 0` 的根。
* 迭代公式: `ans_new = ans_old - f(ans_old) / f'(ans_old)`
* `f'(ans) = 2 * ans`
* `ans_new = ans_old - (ans_old^2 - x) / (2 * ans_old)`
* `ans_new = (2 * ans_old^2 - ans_old^2 + x) / (2 * ans_old)`
* `ans_new = (ans_old^2 + x) / (2 * ans_old)`
* `ans_new = 0.5 * (ans_old + x / ans_old)`
* 初始猜测值 `ans_0 = x`。迭代直到 `ans` 收敛。返回整数部分。
* 注意浮点数精度问题，以及 `x=0` 的情况。

对于整数平方根，二分查找更直接简单。

**Python 实现 (二分查找):**
```python
class Solution:
    def mySqrt(self, x: int) -> int:
        if x == 0:
            return 0
        if x == 1:
            return 1
        
        left, right = 1, x // 2 + 1 # Search space for the root can be up to x/2 for x >= 4
                                    # More simply, up to x works too.
        ans = 0
        while left <= right:
            mid = left + (right - left) // 2
            # Need to be careful about mid * mid overflow if x is very large,
            # but for typical integer limits (e.g., 2^31-1), mid * mid fits in a 64-bit integer.
            # Python handles large integers automatically.
            # For other languages, could use: if mid > x / mid:
            
            square = mid * mid 
            if square == x:
                return mid
            elif square < x:
                ans = mid # mid is a potential answer, try larger
                left = mid + 1
            else: # square > x
                right = mid - 1
        
        # When loop terminates, 'ans' holds the largest 'mid' such that mid*mid <= x.
        # Or, alternatively, 'right' will be the answer because left crosses right.
        return ans # or return right, if initialized carefully
```

### 048: [239. 滑动窗口最大值 (Sliding Window Maximum)](https://leetcode.cn/problems/sliding-window-maximum)

**题目描述:**
给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。
返回 *滑动窗口中的最大值* 。

**解题思路 (使用双端队列 Deque):**
我们可以使用一个双端队列 `deque` 来存储当前窗口中元素的**索引**，并且保持队列中的索引对应的 `nums` 值是**单调递减**的。
1.  初始化一个结果列表 `result` 和一个双端队列 `dq`。
2.  遍历数组 `nums` (索引 `i` 从 `0` 到 `n-1`):
    a.  **移除队首的越界元素**: 如果 `dq` 不为空，并且队首元素的索引 `dq` 小于 `i - k + 1` (即队首元素已不在当前窗口内)，则从队首弹出 `dq.popleft()`。
    b.  **维护单调递减**: 当 `dq` 不为空，并且 `nums[dq[-1]] <= nums[i]` (当前元素 `nums[i]` 大于或等于队尾元素对应的值)，则从队尾弹出 `dq.pop()`。这样做是为了确保新加入的 `i` 成为可能的新的最大值（或保持递减性）。
    c.  **添加当前元素索引**: 将当前元素的索引 `i` 加入 `dq` 的队尾 `dq.append(i)`。
    d.  **记录窗口最大值**: 如果当前窗口已形成 (即 `i >= k - 1`)，那么当前窗口的最大值就是 `nums[dq]` (因为 `dq` 的队首存储的是当前窗口最大值的索引)。将其加入 `result`。
3.  返回 `result`。

**Python 实现:**
```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        if not nums or k == 0:
            return []
        if k == 1:
            return nums

        n = len(nums)
        result = []
        dq = deque() # Stores indices of elements in nums

        for i in range(n):
            # 1. Remove elements from the front of the deque that are out of the current window
            if dq and dq[0] < i - k + 1:
                dq.popleft()
            
            # 2. Maintain monotonically decreasing property in the deque
            # Remove elements from the back of the deque that are smaller than or equal to current element
            while dq and nums[dq[-1]] <= nums[i]:
                dq.pop()
            
            # 3. Add current element's index to the deque
            dq.append(i)
            
            # 4. If window is fully formed, the front of the deque is the max for this window
            if i >= k - 1:
                result.append(nums[dq[0]])
                
        return result
```

**Java 实现:**
```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k == 0) {
            return new int[0];
        }
        if (k == 1) {
            return nums;
        }

        int n = nums.length;
        int[] result = new int[n - k + 1];
        int resultIdx = 0;
        Deque<Integer> dq = new ArrayDeque<>(); // Stores indices of elements in nums

        for (int i = 0; i < n; i++) {
            // 1. Remove elements from the front of the deque that are out of the current window
            if (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
                dq.pollFirst();
            }
            
            // 2. Maintain monotonically decreasing property in the deque
            // Remove elements from the back of the deque that are smaller than or equal to current element
            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) {
                dq.pollLast();
            }
            
            // 3. Add current element's index to the deque
            dq.offerLast(i);
            
            // 4. If window is fully formed, the front of the deque is the max for this window
            if (i >= k - 1) {
                result[resultIdx++] = nums[dq.peekFirst()];
            }
        }
        
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)。虽然有嵌套的 `while` 循环，但每个元素 `nums[i]` 最多入队一次、出队一次。所以所有双端队列操作的总和是 O(N)。
*   空间复杂度: O(K)。双端队列中最多存储 `k` 个元素的索引。

```python
            # This is equivalent to: num > INT_MAX / 10 OR (num == INT_MAX / 10 AND digit > INT_MAX % 10)
            if sign == 1:
                if num > INT_MAX // 10 or (num == INT_MAX // 10 and digit > INT_MAX % 10):
                    return INT_MAX
            # For negative: sign * (num * 10 + digit) < INT_MIN => num * 10 + digit > abs(INT_MIN) (if num is kept positive)
            # abs(INT_MIN) = 2**31.
            # So check: num > (2**31) // 10 OR (num == (2**31) // 10 AND digit > (2**31) % 10)
            # Note: (2**31) % 10 = 8
            # Note: (2**31) // 10 = INT_MAX // 10 (214748364)
            # So if num > INT_MAX // 10 (which is 214748364), it overflows
            # If num == INT_MAX // 10 (214748364), digit must be <= 8 for negative.
            else: # sign == -1
                 if num > INT_MAX // 10 or (num == INT_MAX // 10 and digit > (INT_MAX % 10) + 1): # Checking against 2^31
                    return INT_MIN

            num = num * 10 + digit
            i += 1
            
        return sign * num
```

```java
class Solution {
    public int myAtoi(String s) {
        int i = 0, n = s.length();
        // 1. Skip whitespace
        while (i < n && s.charAt(i) == ' ') i++;

        // 2. Handle sign
        int sign = 1;
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            sign = (s.charAt(i) == '+') ? 1 : -1;
            i++;
        }

        int num = 0;
        // 3. Convert digits and handle overflow
        while (i < n && Character.isDigit(s.charAt(i))) {
            int digit = s.charAt(i) - '0';

            // Check for overflow
            // Integer.MAX_VALUE = 2147483647
            // Integer.MIN_VALUE = -2147483648
            if (num > Integer.MAX_VALUE / 10 || 
                (num == Integer.MAX_VALUE / 10 && digit > Integer.MAX_VALUE % 10)) {
                return (sign == 1) ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
             // This check above doesn't fully handle MIN_VALUE for sign = -1
             // because 2147483648 when * -1 becomes MIN_VALUE.
             // For digit = 8, when num = 214748364, it should be allowed for sign = -1.
             // MAX_VALUE % 10 is 7. digit > 7 is the issue.

            // Revised check (standard way):
            if (sign == 1) {
                 if (num > Integer.MAX_VALUE / 10 || (num == Integer.MAX_VALUE / 10 && digit > 7) ) {
                    return Integer.MAX_VALUE;
                 }
            } else { // sign == -1
                 // Check if -num will underflow: current positive num * 10 + digit > abs(MIN_VALUE)
                 // abs(MIN_VALUE) = 2147483648
                 if (num > Integer.MAX_VALUE / 10 || (num == Integer.MAX_VALUE / 10 && digit > 8) ) { // Compare digit with 8
                    return Integer.MIN_VALUE;
                 }
            }
            
            num = num * 10 + digit;
            i++;
        }
        return sign * num;
    }
}
```

### 050: [2. 两数相加 (Add Two Numbers)](https://leetcode.cn/problems/add-two-numbers)

**题目描述:**
给你两个 **非空** 的链表，表示两个非负整数。它们每位数字都是按照 **逆序** 方式存储的，并且每个节点只能存储 **一位** 数字。
请你将两个数相加，并以相同形式返回一个表示和的链表。
你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**解题思路 (模拟手动加法):**
1.  由于数字是逆序存储的，链表的头部对应数字的最低位，这非常适合从低位到高位逐位相加。
2.  初始化一个哑节点 `dummy_head` 作为结果链表的头指针的前一个节点，一个 `current` 指针指向 `dummy_head`，用于构建结果链表。
3.  初始化 `carry = 0` (进位)。
4.  遍历两个输入链表 `l1` 和 `l2`，只要 `l1` 或 `l2` 不为空，或者 `carry > 0`，就继续循环：
    a.  获取当前位的数字：
    *   `val1 = l1.val` 如果 `l1` 不为空，否则为 `0`。
    *   `val2 = l2.val` 如果 `l2` 不为空，否则为 `0`。
    b.  计算当前位的和：`current_sum = val1 + val2 + carry`。
    c.  新节点的值是 `current_sum % 10`。
    d.  新的进位是 `carry = current_sum // 10`。
    e.  创建一个新节点，值为 `current_sum % 10`，将其连接到 `current.next`。然后 `current = current.next`。
    f.  移动 `l1` 和 `l2` 指针 (如果它们不为空)：`l1 = l1.next`，`l2 = l2.next`。
5.  返回 `dummy_head.next`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy_head = ListNode(0)
        current = dummy_head
        carry = 0

        p1, p2 = l1, l2

        while p1 or p2 or carry:
            val1 = p1.val if p1 else 0
            val2 = p2.val if p2 else 0
            
            current_sum = val1 + val2 + carry
            
            digit = current_sum % 10
            carry = current_sum // 10
            
            current.next = ListNode(digit)
            current = current.next
            
            if p1:
                p1 = p1.next
            if p2:
                p2 = p2.next
                
        return dummy_head.next
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummyHead = new ListNode(0);
        ListNode current = dummyHead;
        int carry = 0;

        ListNode p1 = l1;
        ListNode p2 = l2;

        while (p1 != null || p2 != null || carry != 0) {
            int val1 = (p1 != null) ? p1.val : 0;
            int val2 = (p2 != null) ? p2.val : 0;
            
            int currentSum = val1 + val2 + carry;
            
            int digit = currentSum % 10;
            carry = currentSum / 10;
            
            current.next = new ListNode(digit);
            current = current.next;
            
            if (p1 != null) {
                p1 = p1.next;
            }
            if (p2 != null) {
                p2 = p2.next;
            }
        }
        
        return dummyHead.next;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(max(M, N))，其中 M 和 N 分别是链表 `l1` 和 `l2` 的长度。需要遍历较长的链表一次。
*   空间复杂度: O(max(M, N))，结果链表的长度最多是 `max(M, N) + 1`。
