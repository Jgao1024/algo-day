### 141: [329. 矩阵中的最长递增路径 (Longest Increasing Path in a Matrix)](https://leetcode.cn/problems/longest-increasing-path-in-a-matrix)

**题目描述:**
给定一个整数矩阵，找出最长递增路径的长度。对于每个单元格，你可以往上，下，左，右四个方向移动。 你不能在对角线方向上移动或移动到边界外。

**解题思路 (DFS + 记忆化):**
1.  对矩阵中的每个单元格 `(r, c)`，使用深度优先搜索 (DFS) 来找出从该单元格出发的最长递增路径。
2.  为了避免重复计算，使用一个记忆化数组 `memo[r][c]` 来存储从单元格 `(r,c)` 出发的最长递增路径的长度。
3.  DFS 函数 `dfs(r, c)` 的逻辑：
    a.  如果 `memo[r][c]` 已经被计算过，则直接返回其值。
    b.  初始化当前单元格出发的最长路径为 1（至少包含自身）。
    c.  对于 `(r,c)` 的四个邻居 `(nr, nc)`：
    i.  如果邻居在边界内，并且 `matrix[nr][nc] > matrix[r][c]` (满足递增条件)，则可以从 `(r,c)` 移动到 `(nr,nc)`。
    ii. 当前路径长度可以更新为 `1 + dfs(nr, nc)`。
    iii. 更新从 `(r,c)` 出发的最长路径：`max_len_from_rc = max(max_len_from_rc, 1 + dfs(nr, nc))`。
    d.  将计算结果存入 `memo[r][c]` 并返回。
4.  遍历矩阵中所有单元格，对每个单元格调用 DFS，并取所有结果中的最大值作为最终答案。

**Python 实现:**
```python
class Solution:
    def longestIncreasingPath(self, matrix: list[list[int]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        
        rows = len(matrix)
        cols = len(matrix[0])
        memo = {} # Using a dictionary for memoization: (r, c) -> length

        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)] # Right, Left, Down, Up

        def dfs(r, c):
            if (r, c) in memo:
                return memo[(r, c)]
            
            max_path_from_here = 1 # Path includes the cell itself
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                
                if 0 <= nr < rows and 0 <= nc < cols and matrix[nr][nc] > matrix[r][c]:
                    max_path_from_here = max(max_path_from_here, 1 + dfs(nr, nc))
            
            memo[(r, c)] = max_path_from_here
            return max_path_from_here

        max_overall_path = 0
        for r in range(rows):
            for c in range(cols):
                max_overall_path = max(max_overall_path, dfs(r, c))
                
        return max_overall_path
```

**Java 实现:**
```java
class Solution {
    private int rows;
    private int cols;
    private int[][] matrix;
    private int[][] memo;
    private int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}}; // Right, Left, Down, Up

    public int longestIncreasingPath(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return 0;
        }
        this.rows = matrix.length;
        this.cols = matrix[0].length;
        this.matrix = matrix;
        this.memo = new int[rows][cols]; // Stores the length of LIP starting from (r,c)
                                         // 0 means not computed yet (as path length is >=1)
        int maxOverallPath = 0;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                maxOverallPath = Math.max(maxOverallPath, dfs(r, c));
            }
        }
        return maxOverallPath;
    }

    private int dfs(int r, int c) {
        if (memo[r][c] != 0) { // Already computed
            return memo[r][c];
        }

        int maxPathFromHere = 1; // Path includes the cell itself

        for (int[] dir : directions) {
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && matrix[nr][nc] > matrix[r][c]) {
                maxPathFromHere = Math.max(maxPathFromHere, 1 + dfs(nr, nc));
            }
        }
        
        memo[r][c] = maxPathFromHere;
        return maxPathFromHere;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，每个单元格的 DFS 计算结果被记忆化，因此每个单元格相关的计算（其四个方向的探索）只进行一次。
*   空间复杂度: O(M * N)，用于记忆化数组 `memo` 和递归栈空间（最坏情况下，路径可能覆盖所有单元格）。

### 142: [91. 解码方法 (Decode Ways)](https://leetcode.cn/problems/decode-ways)

**题目描述:**
一条包含字母 `A-Z` 的消息通过以下映射进行了 **编码** ：'A' -> "1", 'B' -> "2", ..., 'Z' -> "26"。
要 **解码** 已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。例如，"11106" 可以映射为 "AAJF" 和 "KJF" 。
注意，像 "06" 这种 ग्रुपिंग 无效。
给你一个只含数字的 **非空** 字符串 `s` ，请计算并返回 **解码 方法的数目** 。题目数据保证答案肯定是 managable (32-bit int).

**解题思路 (动态规划):**
设 `dp[i]` 为字符串 `s` 的前 `i` 个字符 (即 `s[0...i-1]`) 的解码方法数。

1.  **初始化**:
    *   `dp = 1` (空字符串有一种解码方法：什么都不做)。
    *   `dp`:
        *   如果 `s` 是 '0'，则 `dp = 0` (无法解码)。
        *   否则，`dp = 1`。
2.  **状态转移**: 对于 `i` 从 2 到 `len(s)`：
    a.  **单字符解码**: 考虑 `s[i-1]` (当前字符)。
    *   如果 `s[i-1]` 不是 '0' (即 '1' 到 '9')，则它可以独立解码。这部分贡献 `dp[i-1]` 种方法。
    b.  **双字符解码**: 考虑 `s[i-2]s[i-1]` (当前字符和前一个字符组成的两位数)。
    *   取出这两位字符组成的子串 `two_digits = s[i-2:i]`。
    *   如果 `two_digits` 表示的数字在 10 到 26 之间 (即 "10" <= `two_digits` <= "26")，则它可以解码为一个字母。这部分贡献 `dp[i-2]` 种方法。
    c.  `dp[i]` 是上述两种情况贡献的总和。
3.  最终结果是 `dp[len(s)]`。

**空间优化**: `dp[i]` 只依赖于 `dp[i-1]` 和 `dp[i-2]`，可以用两个变量优化空间至 O(1)。

**Python 实现 (空间优化):**
```python
class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0
        
        # dp_i_minus_2 represents dp[i-2], dp_i_minus_1 represents dp[i-1]
        # dp[0] = 1 (empty string)
        dp_i_minus_2 = 1 
        
        # dp[1] (for s[0])
        if s[0] == '0':
            dp_i_minus_1 = 0
        else:
            dp_i_minus_1 = 1
            
        if n == 1:
            return dp_i_minus_1

        for i in range(2, n + 1):
            current_dp_i = 0
            
            # One-digit decode (s[i-1])
            one_digit_val = int(s[i-1:i])
            if one_digit_val >= 1 and one_digit_val <= 9: # Same as s[i-1] != '0'
                current_dp_i += dp_i_minus_1
            
            # Two-digit decode (s[i-2]s[i-1])
            two_digit_val = int(s[i-2:i])
            if two_digit_val >= 10 and two_digit_val <= 26:
                current_dp_i += dp_i_minus_2
            
            dp_i_minus_2 = dp_i_minus_1
            dp_i_minus_1 = current_dp_i
            
        return dp_i_minus_1 # This now holds dp[n]
```

### 143: [450. 删除二叉搜索树中的节点 (Delete Node in a BST)](https://leetcode.cn/problems/delete-node-in-a-bst)

**题目描述:**
给定一个二叉搜索树的根节点 `root` 和一个值 `key`，删除二叉搜索树中的 `key` 对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。

**解题思路 (递归):**
1.  **基准情况**: 如果 `root` 为空，说明未找到 `key`，直接返回 `null`。
2.  **查找节点**:
    *   如果 `key < root.val`，则 `key` 在左子树中，递归调用 `deleteNode(root.left, key)`，并将返回结果赋给 `root.left`。
    *   如果 `key > root.val`，则 `key` 在右子树中，递归调用 `deleteNode(root.right, key)`，并将返回结果赋给 `root.right`。
    *   如果 `key == root.val`，则当前 `root` 就是要删除的节点。执行删除操作：
        a.  **情况1: 节点是叶子节点 (没有子节点)**: 直接删除该节点，即返回 `null` (其父节点会将对应的子指针设为 `null`)。
        b.  **情况2: 节点只有一个子节点**: 用其子节点替换该节点。
            *   如果只有左子节点，返回 `root.left`。
            *   如果只有右子节点，返回 `root.right`。
        c.  **情况3: 节点有两个子节点**:
            *   找到该节点的**中序后继** (即其右子树中的最小节点) 或者 **中序前驱** (其左子树中的最大节点)。
            *   假设我们用中序后继：在 `root.right` 中找到最小值 `successor_val`。
            *   将 `root.val` 替换为 `successor_val`。
            *   现在问题转化为删除原右子树中的 `successor_val`。递归调用 `deleteNode(root.right, successor_val)`，并将返回结果赋给 `root.right`。
3.  在每一步修改后，函数都应返回当前子树（可能已修改）的根。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findMin(self, node: TreeNode) -> TreeNode:
        # Find the minimum node in a BST subtree (leftmost node)
        current = node
        while current and current.left:
            current = current.left
        return current

    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        if not root:
            return None # Key not found, or tree is empty

        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        else: # key == root.val, this is the node to be deleted
            # Case 1 & 2: Node with 0 or 1 child
            if not root.left:
                return root.right # If left is null, return right child (could be null too)
            elif not root.right:
                return root.left  # If right is null, return left child
            
            # Case 3: Node with two children
            # Find inorder successor (smallest in the right subtree)
            successor = self.findMin(root.right)
            # Copy successor's value to this node
            root.val = successor.val
            # Delete the inorder successor from the right subtree
            root.right = self.deleteNode(root.right, successor.val)
            
        return root
```

    TreeNode left;
    TreeNode right;
    TreeNode() {}

        // Find the minimum node in a BST subtree (leftmost node)
        while (node != null && node.left != null) {
            node = node.left;
        }
        return node;
    }

    public TreeNode deleteNode(TreeNode root, int key) {

            return null; // Key not found, or tree is empty
        }

        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else { // key == root.val, this is the node to be deleted
            // Case 1 & 2: Node with 0 or 1 child
            if (root.left == null) {
                return root.right; // If left is null, return right child (could be null too)
            } else if (root.right == null) {
                return root.left;  // If right is null, return left child
            }
            
            // Case 3: Node with two children
            // Find inorder successor (smallest in the right subtree)
            TreeNode successor = findMin(root.right);
            // Copy successor's value to this node
            root.val = successor.val;
            // Delete the inorder successor from the right subtree
            root.right = deleteNode(root.right, successor.val);
        }
        return root;
    }
}

*   空间复杂度: O(H)，用于递归调用栈。

### 144: [135. 分发糖果 (Candy)](https://leetcode.cn/problems/candy)

**题目描述:**
`n` 个孩子站成一排。给你一个整数数组 `ratings` 表示每个孩子的评分。
你需要按照以下要求，给这些孩子分发糖果：
*   每个孩子至少分配到 1 个糖果。
*   相邻两个孩子评分更高的孩子会获得更多的糖果。
    返回最小需要准备的糖果数目。

**解题思路 (两遍扫描/贪心):**
1.  **初始化**: 给每个孩子先分配 1 个糖果。创建一个 `candies` 数组，所有元素初始化为 1。
2.  **第一遍 (从左到右)**:
    *   遍历 `ratings` 数组从左到右 (从 `i = 1` 到 `n-1`)。
    *   如果 `ratings[i] > ratings[i-1]`，说明第 `i` 个孩子评分比左边的高，那么第 `i` 个孩子应该比第 `i-1` 个孩子多至少一个糖果。更新 `candies[i] = candies[i-1] + 1`。
    *   这一遍保证了所有孩子相对于其左边评分较低的邻居，糖果数是正确的。
3.  **第二遍 (从右到左)**:
    *   遍历 `ratings` 数组从右到左 (从 `i = n-2` 到 `0`)。
    *   如果 `ratings[i] > ratings[i+1]`，说明第 `i` 个孩子评分比右边的高。
    *   此时第 `i` 个孩子需要 `candies[i+1] + 1` 个糖果。
    *   但是，`candies[i]` 可能已经在第一遍中因为其左邻居而被设置了一个值。我们需要满足两个条件（比左边高，比右边高）。所以，`candies[i]` 应该是 `max(candies[i], candies[i+1] + 1)`。
    *   这一遍保证了所有孩子相对于其右边评分较低的邻居，糖果数是正确的，同时不会破坏第一遍建立的条件。
4.  **计算总和**: 对 `candies` 数组求和，即为最少需要的糖果数。

**Python 实现:**
```python
class Solution:
    def candy(self, ratings: list[int]) -> int:
        n = len(ratings)
        if n == 0:
            return 0
        
        candies = [1] * n # Each child gets at least 1 candy

        # Pass 1: Left to Right
        for i in range(1, n):
            if ratings[i] > ratings[i-1]:
                candies[i] = candies[i-1] + 1
        
        # Pass 2: Right to Left
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i+1]:
                # Child i needs more than child i+1, but also respect previous assignment
                candies[i] = max(candies[i], candies[i+1] + 1)
                
        return sum(candies)
```

**Java 实现:**
```java
import java.util.Arrays;

class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        if (n == 0) {
            return 0;
        }

        int[] candies = new int[n];
        Arrays.fill(candies, 1); // Each child gets at least 1 candy

        // Pass 1: Left to Right
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i-1]) {
                candies[i] = candies[i-1] + 1;
            }
        }
        
        // Pass 2: Right to Left
        // Sum can be computed during this pass too, or after
        int totalCandies = 0; 
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i+1]) {
                candies[i] = Math.max(candies[i], candies[i+1] + 1);
            }
        }
        
        for (int count : candies) {
            totalCandies += count;
        }
        return totalCandies;
    }
}
```

*   时间复杂度: O(N)，两次遍历数组。
*   空间复杂度: O(N)，用于 `candies` 数组。

### 146: [442. 数组中重复的数据 (Find All Duplicates in an Array)](https://leetcode.cn/problems/find-all-duplicates-in-an-array)

**题目描述:**
给你一个长度为 `n` 的整数数组 `nums` ，其中 `nums` 的所有整数都在范围 `[1, n]` 内，且每个整数出现 **一次** 或 **两次** 。请你找出所有出现 **两次** 的整数，并以数组形式返回。
你必须设计并实现一个时间复杂度为 `O(n)` 且仅使用常量额外空间的算法来解决此问题。

**解题思路 (原地标记/哈希):**
利用数组本身作为哈希表。因为数字范围是 `[1, n]`，它们可以映射到数组索引 `[0, n-1]`。
1.  遍历数组 `nums`。对于每个数字 `num = nums[i]`：
    a.  获取其绝对值 `abs_num = abs(num)`。
    b.  计算对应的索引 `idx = abs_num - 1`。
    c.  检查 `nums[idx]` 的符号：
    i.  如果 `nums[idx]` 是正数，说明数字 `abs_num` 是第一次遇到。将其标记为已遇到，方法是将 `nums[idx]` 变为负数 (`nums[idx] = -nums[idx]`)。
    ii. 如果 `nums[idx]` 是负数，说明数字 `abs_num` 之前已经遇到过（其对应位置的数已被标记为负），因此 `abs_num` 是一个重复的数字。将其加入结果列表。
2.  返回结果列表。
    (注意：这个方法会修改输入数组。如果不能修改，则需要 O(N) 额外空间，例如使用哈希集合。)

**Python 实现:**
```python
class Solution:
    def findDuplicates(self, nums: list[int]) -> list[int]:
        duplicates = []
        for num in nums:
            abs_num = abs(num)
            idx = abs_num - 1 # Convert value to 0-based index
            
            if nums[idx] < 0: # This number (abs_num) has been seen before
                duplicates.append(abs_num)
            else:
                nums[idx] = -nums[idx] # Mark as seen
                
        # Optional: Restore the array if needed by problem (not usually for this type)
        # for i in range(len(nums)):
        #     if nums[i] < 0:
        #         nums[i] = -nums[i]
                
        return duplicates
```

### 147: [125. 验证回文串 (Valid Palindrome)](https://leetcode.cn/problems/valid-palindrome)

**题目描述:**
如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样，则可以认为该短语是一个 **回文串** 。
字母和数字都属于字母数字字符。
给你一个字符串 `s`，如果它是 **回文串** ，返回 `true` ；否则，返回 `false` 。

**解题思路 (双指针):**
1.  初始化两个指针：`left` 指向字符串开头，`right` 指向字符串末尾。
2.  当 `left < right` 时，循环：
    a.  **移动 `left` 指针**: 如果 `s[left]` 不是字母数字字符，则 `left++`，继续。
    b.  **移动 `right` 指针**: 如果 `s[right]` 不是字母数字字符，则 `right--`，继续。
    c.  如果 `left < right` (确保指针未交错) 并且 `s[left]` 和 `s[right]` 都是字母数字字符：
    i.  将 `s[left]` 和 `s[right]` 都转换为小写。
    ii. 如果转换后的字符不相等，则不是回文串，返回 `false`。
    iii. 如果相等，则 `left++`，`right--`。
3.  如果循环完成（`left >= right`），说明所有检查都通过，返回 `true`。

**Python 实现:**
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        
        while left < right:
            # Move left pointer to the next alphanumeric character
            while left < right and not s[left].isalnum():
                left += 1
            
            # Move right pointer to the previous alphanumeric character
            while left < right and not s[right].isalnum():
                right -= 1
            
            if left < right: # Ensure pointers haven't crossed
                if s[left].lower() != s[right].lower():
                    return False
                left += 1
                right -= 1
                
        return True
```

**Java 实现:**
```java
class Solution {
    public boolean isPalindrome(String s) {
        if (s == null || s.isEmpty()) {
            return true;
        }

        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            char charLeft = s.charAt(left);
            char charRight = s.charAt(right);

            // Move left pointer if not alphanumeric
            if (!Character.isLetterOrDigit(charLeft)) {
                left++;
                continue;
            }
            // Move right pointer if not alphanumeric
            if (!Character.isLetterOrDigit(charRight)) {
                right--;
                continue;
            }

            // Compare characters (case-insensitive)
            if (Character.toLowerCase(charLeft) != Character.toLowerCase(charRight)) {
                return false;
            }
            
            left++;
            right--;
        }
        return true;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是字符串长度。每个字符最多被访问一到两次。
*   空间复杂度: O(1)。

### 148: [剑指 Offer 10- II. 青蛙跳台阶问题 (qing-wa-tiao-tai-jie-wen-ti-lcof)](https://leetcode.cn/problems/qing-wa-tiao-tai-jie-wen-ti-lcof)

**题目描述:**
一只青蛙一次可以跳上1级台阶，也可以跳上2级台阶。求该青蛙跳上一个 `n` 级的台阶总共有多少种跳法。
答案需要取模 1e9+7（1000000007），如计算初始结果为：1000000008，请返回 1。
`0 <= n <= 100`

**解题思路 (斐波那契数列):**
设 `dp[i]` 为跳上 `i` 级台阶的方法数。
*   要跳上第 `i` 级台阶，青蛙可以从第 `i-1` 级跳1步上来，或者从第 `i-2` 级跳2步上来。
*   所以，`dp[i] = dp[i-1] + dp[i-2]`。
*   **基准情况**:
    *   `dp = 1` (跳上0级台阶有1种方法：不跳。这是为了让 `dp = dp + dp` 正确)。
    *   `dp = 1` (跳上1级台阶有1种方法：跳1步)。
    *   `dp = dp + dp = 1 + 1 = 2` (跳法: 1+1, 2)。
*   这正是斐波那契数列的递推关系（可能有一个偏移或起始值不同）。
*   需要对每一步加法取模。

**Python 实现:**
```python
class Solution:
    def numWays(self, n: int) -> int:
        MOD = 1000000007
        
        if n == 0:
            return 1
        if n == 1:
            return 1
        
        # dp[i] means number of ways to reach step i
        # Using O(1) space
        # dp_i_minus_2 corresponds to dp[i-2] (or ways to reach step i-2)
        # dp_i_minus_1 corresponds to dp[i-1] (or ways to reach step i-1)
        
        dp_i_minus_2 = 1 # Corresponds to ways for n=0
        dp_i_minus_1 = 1 # Corresponds to ways for n=1
        
        for i in range(2, n + 1):
            current_dp_i = (dp_i_minus_1 + dp_i_minus_2) % MOD
            dp_i_minus_2 = dp_i_minus_1
            dp_i_minus_1 = current_dp_i
            
        return dp_i_minus_1
```

**Java 实现:**
```java

        final int MOD = 1000000007;

        if (n == 0) {
            return 1;
        }

            return 1;
        }

        // dp_i_minus_2 represents ways for step i-2
        // dp_i_minus_1 represents ways for step i-1

*   空间复杂度: O(1)。

### 149: [445. 两数相加 II (Add Two Numbers II)](https://leetcode.cn/problems/add-two-numbers-ii)

**题目描述:**
给你两个 **非空** 链表来代表两个非负整数。数字最高位位于链表开始位置。它们的每个节点只存储一位数字。将这两数相加会返回一个新的链表。
你可以假设除了数字 0 之外，这两个数字都不会以零开头。
**进阶：** 如果输入链表不能修改该如何处理？换句话说，不能对列表中的节点进行翻转。

**解题思路 (使用栈):**
由于最高位在头部，而加法从最低位开始，所以不能直接遍历。也不能反转链表（根据进阶要求）。
1.  **入栈**:
    *   将链表 `l1` 的所有数字压入栈 `stack1`。
    *   将链表 `l2` 的所有数字压入栈 `stack2`。
2.  **逐位相加**:
    *   初始化 `carry = 0`。
    *   初始化结果链表的头 `result_head = null`。
    *   当 `stack1` 不空、或 `stack2` 不空、或 `carry > 0` 时，循环：
        a.  从 `stack1` 弹出一个数字 `d1` (如果栈空则为0)。
        b.  从 `stack2` 弹出一个数字 `d2` (如果栈空则为0)。
        c.  计算 `sum = d1 + d2 + carry`。
        d.  当前位的值是 `sum % 10`。
        e.  新的进位是 `carry = sum / 10`。
        f.  创建一个新节点，值为 `sum % 10`。
        g.  将该新节点插入到 `result_head` 的**前面** (因为我们是从低位向高位构建的)。
3.  返回 `result_head`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        stack1 = []
        stack2 = []

        # Push digits of l1 onto stack1
        curr = l1
        while curr:
            stack1.append(curr.val)
            curr = curr.next
        
        # Push digits of l2 onto stack2
        curr = l2
        while curr:
            stack2.append(curr.val)
            curr = curr.next
            
        carry = 0
        result_head = None # This will be the head of the resulting list

        while stack1 or stack2 or carry:
            d1 = stack1.pop() if stack1 else 0
            d2 = stack2.pop() if stack2 else 0
            
            current_sum = d1 + d2 + carry
            digit = current_sum % 10
            carry = current_sum // 10
            
            # Create a new node for the current digit and prepend it to the result list
            new_node = ListNode(digit)
            new_node.next = result_head
            result_head = new_node
            
        return result_head if result_head else ListNode(0) # Handles sum 0 if input was [0],[0] (though constraints say non-empty)
                                                           # problem states "non-empty" lists. result_head will be valid.
```

**Java 实现:**
```java
import java.util.Stack;

class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        Stack<Integer> stack1 = new Stack<>();
        Stack<Integer> stack2 = new Stack<>();

        // Push digits of l1 onto stack1
        ListNode curr = l1;
        while (curr != null) {
            stack1.push(curr.val);
            curr = curr.next;
        }
        
        // Push digits of l2 onto stack2
        curr = l2;
        while (curr != null) {
            stack2.push(curr.val);
            curr = curr.next;
        }
            
        int carry = 0;
        ListNode resultHead = null; // This will be the head of the resulting list

        while (!stack1.isEmpty() || !stack2.isEmpty() || carry > 0) {
            int d1 = stack1.isEmpty() ? 0 : stack1.pop();
            int d2 = stack2.isEmpty() ? 0 : stack2.pop();
            
            int currentSum = d1 + d2 + carry;
            int digit = currentSum % 10;
            carry = currentSum / 10;
            
            // Create a new node for the current digit and prepend it
            ListNode newNode = new ListNode(digit);
            newNode.next = resultHead;
            resultHead = newNode;
        }
        
        return resultHead; // If sum is 0, e.g. l1=[0], l2=[0], resultHead will be ListNode(0)
    }
}
```

**复杂度分析:**
*   时间复杂度: O(max(N1, N2))，其中 N1, N2 是两个链表的长度。遍历链表入栈 + 弹栈相加。
*   空间复杂度: O(N1 + N2)，用于两个栈。

### 150: [45. 跳跃游戏 II (Jump Game II)](https://leetcode.cn/problems/jump-game-ii)

**题目描述:**
给定一个长度为 `n` 的整数数组 `nums` 。你初始在 `nums` 处。
数组中的每个元素 `nums[i]` 都表示你可以从下标 `i` 向后执行的最大跳跃长度。也就是说，如果你在 `nums[i]` 处，你可以跳到任意 `nums[i + j]` 处，其中 `0 <= j <= nums[i]` 且 `i + j < n`。
返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

**解题思路 (贪心 / BFS-like Layer):**
1.  如果数组长度为 1 (或0)，则不需要跳跃，返回 0。
2.  `jumps = 0`: 记录跳跃次数。
3.  `current_reach_end = 0`: 当前这一跳能够到达的最远位置。
4.  `next_max_reach = 0`: 从当前这一跳覆盖的范围内，下一跳能够到达的最远位置。
5.  遍历数组 `nums` (从 `i = 0` 到 `n-2`，因为到达 `n-1` 后就不需要再跳了)：
    a.  更新 `next_max_reach = max(next_max_reach, i + nums[i])`。这是为了找出在当前 `[0...current_reach_end]` 范围内所有点出发，能跳到的最远点。
    b.  如果当前位置 `i` 达到了 `current_reach_end`：
    i.  说明我们必须进行下一次跳跃才能继续前进。
    ii. `jumps++`。
    iii. 更新 `current_reach_end = next_max_reach`。
    iv. 如果 `current_reach_end >= n - 1`，说明已经可以到达或越过终点，可以直接返回 `jumps`。
6.  返回 `jumps` (理论上，循环会因为 `current_reach_end >= n-1` 而提前结束，但若遍历到 `n-2` 仍未触发，则最终 `jumps` 值也正确)。

**Python 实现:**
```python
class Solution:
    def jump(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 1: # Already at the end or only one element
            return 0

        jumps = 0
        current_reach_end = 0 # The farthest index reachable with the current number of jumps
        next_max_reach = 0    # The farthest index reachable with (jumps + 1)

        for i in range(n):
            # If we have reached the end of the array or can reach it from current position
            if current_reach_end >= n - 1:
                break
            
            # Update the farthest we can reach from the current jump's range
            next_max_reach = max(next_max_reach, i + nums[i])
            
            # If we have reached the end of the current jump's capability
            if i == current_reach_end:
                jumps += 1 # Take another jump
                current_reach_end = next_max_reach # Update the new reach
        
        return jumps
```

**Java 实现:**

class Solution {
    public int jump(int[] nums) {
        int n = nums.length;
        if (n <= 1) { // Already at the end or only one element
            return 0;
        }

        int jumps = 0;
        int currentReachEnd = 0; // The farthest index reachable with the current number of jumps
        int nextMaxReach = 0;    // The farthest index reachable with (jumps + 1)

        // We iterate up to n-1 because if i reaches n-1, we are at the destination.
        // The loop condition i < n -1 effectively handles that we don't process from last element.
        for (int i = 0; i < n - 1; i++) { 
            // Update the farthest we can reach from the current jump's range
            nextMaxReach = Math.max(nextMaxReach, i + nums[i]);
            
            // If we can reach the end with the current nextMaxReach
            if (nextMaxReach >= n - 1) {
                jumps++; // One more jump to reach the end
                return jumps;
            }
            
            // If we have reached the end of the current jump's capability
            if (i == currentReachEnd) {
                jumps++; // Take another jump
                currentReachEnd = nextMaxReach; // Update the new reach
            }
        }

        // and the above logic correctly identifies the last jump.
        // However, if n=1 and for loop i<n-1 -> i<0, loop is skipped, returns initial jumps=0, which is correct.
        return jumps; 
    }
}
