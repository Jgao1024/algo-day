### 131: [59. 螺旋矩阵 II (Spiral Matrix II)](https://leetcode.cn/problems/spiral-matrix-ii)

**题目描述:**
给你一个正整数 `n` ，生成一个包含 `1` 到 `n^2` 所有元素，且元素按顺时针顺序螺旋排列的 `n x n` 正方形矩阵 `matrix` 。

**解题思路 (模拟边界):**
与 "螺旋矩阵 I" 非常相似，只是这里是填充数字而不是读取数字。
1.  初始化一个 `n x n` 的矩阵，所有元素可以预设为 0。
2.  定义四个边界：`top = 0`, `bottom = n - 1`, `left = 0`, `right = n - 1`。
3.  初始化当前要填充的数字 `num = 1`。
4.  在一个循环中，只要 `num <= n*n` (或 `top <= bottom` 且 `left <= right`)：
    a.  **从左到右 (填充上边界)**:
    *   从 `left` 到 `right`，为 `matrix[top][c]` 填充 `num`，然后 `num++`。
    *   `top++` (上边界下移)。
    b.  **从上到下 (填充右边界)**:
    *   从 `top` 到 `bottom`，为 `matrix[r][right]` 填充 `num`，然后 `num++`。
    *   `right--` (右边界左移)。
    c.  **从右到左 (填充下边界)**:
    *   （确保 `top <= bottom`）从 `right` 到 `left` (倒序)，为 `matrix[bottom][c]` 填充 `num`，然后 `num++`。
    *   `bottom--` (下边界上移)。
    d.  **从下到上 (填充左边界)**:
    *   （确保 `left <= right`）从 `bottom` 到 `top` (倒序)，为 `matrix[r][left]` 填充 `num`，然后 `num++`。
    *   `left++` (左边界右移)。
5.  返回填充好的 `matrix`。

**Python 实现:**
```python
class Solution:
    def generateMatrix(self, n: int) -> list[list[int]]:
        if n == 0:
            return []
        
        matrix = [[0] * n for _ in range(n)]
        num = 1
        top, bottom, left, right = 0, n - 1, 0, n - 1
        
        while num <= n * n:
            # Fill top row
            for c in range(left, right + 1):
                matrix[top][c] = num
                num += 1
            top += 1
            if top > bottom: break

            # Fill right column
            for r in range(top, bottom + 1):
                matrix[r][right] = num
                num += 1
            right -= 1
            if left > right: break

            # Fill bottom row (if it's a valid row)
            if top <= bottom:
                for c in range(right, left - 1, -1):
                    matrix[bottom][c] = num
                    num += 1
                bottom -= 1
            if top > bottom: break
            
            # Fill left column (if it's a valid column)
            if left <= right:
                for r in range(bottom, top - 1, -1):
                    matrix[r][left] = num
                    num += 1
                left += 1
            if left > right: break
                
        return matrix
```

### 132: [518. 零钱兑换 II (Coin Change II)](https://leetcode.cn/problems/coin-change-ii)

**题目描述:**
给你一个整数数组 `coins` 表示不同面额的硬币，另给一个整数 `amount` 表示总金额。
请你计算并返回可以凑成总金额的硬币组合数。如果任何硬币组合都无法凑出总金额，返回 `0` 。
你可以预设每种面额的硬币有无限个。
题目数据保证结果符合 32 位带符号整数。

**解题思路 (完全背包问题 - 动态规划):**
这是经典的完全背包问题，目标是求组合数。
1.  定义 `dp[i]` 表示凑成金额 `i` 的组合数。
2.  **初始化**:
    *   `dp = 1` (凑成金额 0 的方法只有一种：不使用任何硬币)。
    *   其余 `dp[j]` (j > 0) 初始化为 0。
3.  **状态转移 (遍历硬币，再遍历金额)**:
    *   对于 `wordDict` 中的每一种硬币 `coin`：
        *   对于金额 `j` 从 `coin` 到 `amount`： (确保 `j >= coin`)
            *   `dp[j] = dp[j] + dp[j - coin]`
            *   解释：要凑成金额 `j`，可以考虑是否使用当前的 `coin`。
                *   如果不使用 `coin`，组合数就是之前用其他硬币凑成 `j` 的组合数 (即 `dp[j]` 的旧值)。
                *   如果使用 `coin` (至少一个)，那么剩下的金额是 `j - coin`，其组合数是 `dp[j - coin]`。由于 `coin` 可以无限使用，这些组合都是新的。
                *   所以，`dp[j]` 更新为包含当前 `coin` 和不包含当前 `coin` 的总和。
    *   **重要**: 必须先遍历硬币，再遍历金额。如果内外循环顺序反过来，会计算出排列数而不是组合数。(例如，用 `` 凑 3，会把 `(1,2)` 和 `(2,1)` 当作不同，如果先遍历金额再遍历硬币)
4.  **结果**: `dp[amount]` 是最终答案。

**Python 实现:**
```python
class Solution:
    def change(self, amount: int, coins: list[int]) -> int:
        # dp[i] will be storing the number of combinations to make up amount i
        dp = [0] * (amount + 1)
        dp[0] = 1 # Base case: one way to make amount 0 (using no coins)
        
        # Iterate over coins first to ensure combinations, not permutations
        for coin in coins:
            for i in range(coin, amount + 1):
                # For amount i, we can form it by:
                # 1. Not using the current coin (dp[i] already accounts for this from previous coins)
                # 2. Using the current coin, then the number of ways to make up the remaining amount (i - coin)
                #    is dp[i - coin].
                dp[i] += dp[i - coin]
                
        return dp[amount]
```

### 133: [剑指 Offer 26. 树的子结构 (Shu De Zi Jie Gou Lcof / Substructure of a Tree)](https://leetcode.cn/problems/shu-de-zi-jie-gou-lcof)

**题目描述:**
输入两棵二叉树A和B，判断B是不是A的子结构。(约定空树不是任意一个树的子结构)
B是A的子结构， 即 A中有出现和B相同的结构和节点值。
例如:
给定的树 A: `` (`3` / `4` 5 / `1` 2 N N`)
给定的树 B: `` (`4` / `1` N`)
返回 `true`，因为 B 与 A 的一个子树拥有相同的结构和节点值。

**解题思路 (递归):**
分两步：
1.  **主函数 `isSubStructure(A, B)`:**
    *   如果 A 或 B 为空，直接返回 `false` (根据约定)。
    *   调用一个辅助函数 `doesTreeAHaveTreeB(A, B)` 来检查以 A 为根的树是否包含 B。
    *   如果 `doesTreeAHaveTreeB(A, B)` 为 `true`，则返回 `true`。
    *   否则，递归地在 A 的左子树和右子树中寻找 B：
        `return isSubStructure(A.left, B) or isSubStructure(A.right, B)`。
2.  **辅助函数 `doesTreeAHaveTreeB(A_node, B_node)`:**
    *   此函数判断从 `A_node` 开始的子树是否与 `B_node` 代表的树结构和值都匹配。
    *   **B 遍历完了**: 如果 `B_node` 为 `null`，说明 B 的所有部分都已成功匹配，返回 `true`。
    *   **A 遍历完了但 B 没完**: 如果 `A_node` 为 `null` (但 `B_node` 不为 `null`，上一步已处理)，说明 A 提前结束，无法匹配 B，返回 `false`。
    *   **值不匹配**: 如果 `A_node.val != B_node.val`，根节点值不同，返回 `false`。
    *   **递归检查左右子树**: 返回 `doesTreeAHaveTreeB(A_node.left, B_node.left) and doesTreeAHaveTreeB(A_node.right, B_node.right)`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Solution:
    def isSubStructure(self, A: TreeNode, B: TreeNode) -> bool:
        if not A or not B: # Empty tree cannot be a substructure, nor can contain one
            return False
        
        # Check if B is a substructure starting from A, or from A.left, or from A.right
        return self._does_A_have_B(A, B) or \
               self.isSubStructure(A.left, B) or \
               self.isSubStructure(A.right, B)

    def _does_A_have_B(self, node_A: TreeNode, node_B: TreeNode) -> bool:
        # Base cases for the recursive helper
        if not node_B: # B part has been successfully matched
            return True
        if not node_A: # A part exhausted, but B still needs matching
            return False
        if node_A.val != node_B.val: # Values don't match
            return False
        
        # Values match, check left and right subtrees
        return self._does_A_have_B(node_A.left, node_B.left) and \
               self._does_A_have_B(node_A.right, node_B.right)

```

**Java 实现:**
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

class Solution {
    public boolean isSubStructure(TreeNode A, TreeNode B) {
        if (A == null || B == null) { // Per problem: empty tree is not substructure of any tree
            return false;
        }
        // Check if B is a substructure starting from A, or from A.left, or from A.right
        return doesAHaveB(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B);
    }

    private boolean doesAHaveB(TreeNode nodeA, TreeNode nodeB) {
        // Base cases for the recursive helper
        if (nodeB == null) { // B part has been successfully matched
            return true;
        }
        if (nodeA == null) { // A part exhausted, but B still needs matching
            return false;
        }
        if (nodeA.val != nodeB.val) { // Values don't match
            return false;
        }
        
        // Values match, check left and right subtrees
        return doesAHaveB(nodeA.left, nodeB.left) && doesAHaveB(nodeA.right, nodeB.right);
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M*N)，其中 M 是树 A 的节点数，N 是树 B 的节点数。在最坏情况下 (例如，树 A 和 B 都是链状，且每次匹配都失败在最后一层)，`isSubStructure` 可能对 A 的每个节点调用一次 `doesAHaveB`，而 `doesAHaveB` 的复杂度是 O(N)。
*   空间复杂度: O(M) or O(H_A) for recursion stack of `isSubStructure`. O(H_B) for recursion stack of `doesAHaveB`. If H_A is M, then O(M).

### 134: [50. Pow(x, n) (Pow(x, n))](https://leetcode.cn/problems/powx-n)

**题目描述:**
实现 `pow(x, n)` ，即计算 `x` 的整数 `n` 次幂函数（即，`x^n`）。

**解题思路 (快速幂 / Exponentiation by Squaring):**
递归或迭代实现。
1.  **处理特殊情况**:
    *   如果 `x = 0`, 结果是 0 (除非 `n=0`)。
    *   如果 `n = 0`, 结果是 1。
    *   如果 `n < 0`，则问题转换为计算 `(1/x)^(-n)`。
2.  **递归 (正数 n)**:
    *   基准情况： `myPow(x, 0) = 1`。
    *   如果 `n` 是偶数: `x^n = (x^{n/2})^2 = myPow(x, n/2) * myPow(x, n/2)`。
    *   如果 `n` 是奇数: `x^n = x * (x^{(n-1)/2})^2 = x * myPow(x, (n-1)/2) * myPow(x, (n-1)/2)`。
        可以优化为: `x^n = x * myPow(x, n-1)`，或者 `half = myPow(x, n/2); return x * half * half` if n is odd; `half = myPow(x, n/2); return half * half` if n is even.
3.  **迭代 (正数 n)**:
    *   `result = 1.0`
    *   `current_product = x`
    *   当 `n > 0`:
        *   如果 `n` 的最后一位是 1 (即 `n % 2 == 1` 或 `n & 1`)，则 `result *= current_product`。
        *   `current_product *= current_product` (平方)。
        *   `n //= 2` (右移一位)。
    *   返回 `result`。

### 135: [145. 二叉树的后序遍历 (Binary Tree Postorder Traversal)](https://leetcode.cn/problems/binary-tree-postorder-traversal)

**题目描述:**
给你一棵二叉树的根节点 `root` ，返回其节点值的 **后序遍历** 。(左 -> 右 -> 根)

**解题思路:**
**1. 递归法:**
* 基准情况: 如果 `root` 为 `null`，返回。
* 递归遍历左子树: `postorderTraversal(root.left)`。
* 递归遍历右子树: `postorderTraversal(root.right)`。
* 访问根节点: 将 `root.val` 加入结果列表。

**2. 迭代法 (使用两个栈 或 修改先序遍历):**
**修改先序遍历思路 (根-右-左 -> reverse -> 左-右-根):**
* 进行一种修改版的先序遍历：根 -> 右子树 -> 左子树。
* 将遍历结果存入一个列表。
* 最后将该列表反转，即得到后序遍历的结果。
* 实现修改版先序：
    * 使用一个栈。将 `root` 压栈。
    * 当栈不为空：
        * 弹出节点 `node`，将其值加入结果列表 `temp_result`。
        * 先将 `node.left` 压栈 (如果存在)。
        * 再将 `node.right` 压栈 (如果存在)。 (这样弹出时就是先右后左)
    * `temp_result.reverse()`
      **一个栈的真正迭代后序:**
      *   这个比较复杂。需要跟踪节点最后一次访问的状态（是刚访问完左子树，还是刚访问完右子树）。
      *   栈中元素可以是 `(node, state)` 或通过一个 `prev_visited_node` 指针来判断。
      *   Loop while `curr` is not null or stack is not empty:
        *   While `curr` is not null: push `curr` to stack, `curr = curr.left` (go as left as possible)
        *   `curr = stack.peek()`
        *   If `curr.right` is null OR `curr.right == prev_visited_node`:
            *   `curr = stack.pop()`, add `curr.val` to result.
            *   `prev_visited_node = curr`.
            *   Set `curr = null` (to force pop from stack on next iteration if stack isn't empty).
        *   Else:
            *   `curr = curr.right` (go to right subtree)


**Python 实现 (递归和迭代-修改先序):**

```python
    def postorderTraversalRecursive(self, root: TreeNode) -> list[int]:
        result = []
        def _traverse(node):
            if not node:
                return
            _traverse(node.left)
            _traverse(node.right)
            result.append(node.val)
        _traverse(root)
        return result

            node = stack.pop()

                stack.append(node.left)
            if node.right:
                stack.append(node.right)
                
        return temp_result[::-1] # Reverse to get Left-Right-Root
```

```java
        return result;

    private void traverse(TreeNode node, List<Integer> result) {

            return;
        }
        traverse(node.left, result);
        traverse(node.right, result);
        result.add(node.val);
    }

    // Iterative solution (modified preorder: Root-Right-Left, then reverse)
    public List<Integer> postorderTraversal(TreeNode root) { // Defaulting to this for main func
        LinkedList<Integer> result = new LinkedList<>(); // LinkedList allows addFirst
        if (root == null) {
            return result;
        }
        
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.addFirst(node.val); // Add to front, effectively reversing on the fly
            
            // Push left child first, then right. So right is popped (and added to front of result)
            // before left. This achieves Root-Left-Right for adding to front,
            // which becomes Left-Right-Root after all processing.
            // Example: process 1, R, L. res: [1]. process R. res: [R, 1]. process L. res: [L, R, 1]. OK.
            // If Root-Right-Left is desired for temp list:
            //  res.add(node.val) -> Collections.reverse(res) later.
            //  Current logic of addFirst is more direct for postorder.

            if (node.left != null) { // Left child is pushed first
                stack.push(node.left);
            }
            if (node.right != null) { // Right child is pushed second
                stack.push(node.right);
            }
        }
        // The addFirst effectively results in [Left, Right, Root] directly.
        return result;
    }
}
```

### 136: [75. 颜色分类 (Sort Colors)](https://leetcode.cn/problems/sort-colors)

**题目描述:**
给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums` ，**原地**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色的顺序排列。
我们使用整数 `0`、 `1` 和 `2` 分别表示红色、白色和蓝色。
你必须在不使用库的sort函数的情况下解决这个问题。你能想出一个仅使用常数空间的一趟扫描算法吗？

**解题思路 (荷兰国旗问题 / 三指针法):**
1.  使用三个指针：
    *   `p0`: 指向0区域的末尾 (即下一个0应该放置的位置)。初始为0。
    *   `curr`: 当前正在扫描的元素。初始为0。
    *   `p2`: 指向2区域的开头 (即下一个2应该放置的位置的前一个位置)。初始为 `n-1`。
2.  当 `curr <= p2` 时，循环：
    a.  如果 `nums[curr] == 0` (红色):
    *   交换 `nums[curr]` 和 `nums[p0]`。
    *   `p0++`。
    *   `curr++` (因为从 `p0` 换过来的元素可能是0或1，需要继续处理)。
    b.  如果 `nums[curr] == 1` (白色):
    *   `curr++` (1在正确的位置，继续扫描)。
    c.  如果 `nums[curr] == 2` (蓝色):
    *   交换 `nums[curr]` 和 `nums[p2]`。
    *   `p2--`。
    *   `curr` 不增加，因为从 `p2` 换过来的元素未知，需要重新检查 `nums[curr]`。
3.  循环结束后，数组即按0, 1, 2的顺序排好。

**Python 实现:**
```python
class Solution:
    def sortColors(self, nums: list[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        p0 = 0       # Points to the end of the 0s region
        curr = 0     # Current element being considered
        p2 = n - 1   # Points to the start of the 2s region
        
        while curr <= p2:
            if nums[curr] == 0:
                nums[curr], nums[p0] = nums[p0], nums[curr]
                p0 += 1
                curr += 1 # The element swapped from p0 to curr could be 0 or 1, handled correctly
            elif nums[curr] == 1:
                curr += 1
            else: # nums[curr] == 2
                nums[curr], nums[p2] = nums[p2], nums[curr]
                p2 -= 1
                # curr does not increment because the swapped element from p2 needs to be processed
```

**Java 实现:**
```java
class Solution {
    public void sortColors(int[] nums) {
        int n = nums.length;
        int p0 = 0;       // Points to the end of the 0s region (next 0 goes here)
        int curr = 0;     // Current element being considered
        int p2 = n - 1;   // Points to the start of the 2s region (next 2 from here, move to end)

        while (curr <= p2) {
            if (nums[curr] == 0) {
                swap(nums, curr, p0);
                p0++;
                curr++; // Element from p0 could be 0 or 1. If 0, p0 moves again. If 1, curr moves over it.
            } else if (nums[curr] == 1) {
                curr++;
            } else { // nums[curr] == 2
                swap(nums, curr, p2);
                p2--;
                // curr does not increment here, because the element swapped from nums[p2]
                // has not been processed yet and needs to be checked.
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 137: [572. 另一个树的子树 (Subtree of Another Tree)](https://leetcode.cn/problems/subtree-of-another-tree)

**题目描述:**
给你两棵二叉树 `root` 和 `subRoot` 。检验 `root` 中是否包含和 `subRoot` 具有相同结构和节点值的子树。如果存在，返回 `true` ；否则，返回 `false` 。
一棵树 `t` 是树 `s` 的子树的前提是：`s` 中的某个节点 `n` 的子树与 `t` 完全相同，并且节点 `n` 本身与 `t` 的根节点的值也相同。

**解题思路 (递归):**
与 "树的子结构" (剑指 Offer 26) 类似，但这里的定义更严格，要求完全相同 (包括 null 叶子)。
1.  **主函数 `isSubtree(root, subRoot)`:**
    *   如果 `subRoot` 为 `null`，任何树都包含一个空子树，返回 `true` (按定义，如果题目说空树不是子树则为false)。LeetCode对`subRoot`为空的情况判定比较宽松，这里假设空`subRoot`应该返回true（空树是任何树的子树），或如果`root`也为空，`subRoot`为空则为true。
    *   如果 `root` 为 `null` (但 `subRoot` 不为 `null`)，则 `root` 无法包含 `subRoot`，返回 `false`。
    *   调用一个辅助函数 `isSameTree(root, subRoot)` 来检查以 `root` 为根的树是否与 `subRoot` 完全相同。
    *   如果 `isSameTree(root, subRoot)` 为 `true`，则返回 `true`。
    *   否则，递归地在 `root` 的左子树和右子树中寻找 `subRoot`：
        `return isSubtree(root.left, subRoot) or isSubtree(root.right, subRoot)`。

2.  **辅助函数 `isSameTree(p, q)`:**
    *   此函数判断两棵树 `p` 和 `q` 是否完全相同。
    *   如果 `p` 和 `q` 都为 `null`，它们相同，返回 `true`。
    *   如果 `p` 或 `q` 中只有一个为 `null`，它们不同，返回 `false`。
    *   如果 `p.val != q.val`，它们不同，返回 `false`。
    *   递归检查左右子树: 返回 `isSameTree(p.left, q.left) and isSameTree(p.right, q.right)`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSubtree(self, root: TreeNode, subRoot: TreeNode) -> bool:
        if not root: # If the main tree is empty, it cannot contain a non-empty subRoot
            return not subRoot # True if subRoot is also empty, False otherwise
        if not subRoot: # An empty subRoot is considered a subtree of any tree (usually)
            return True

        # Check if current root matches subRoot's structure, 
        # or if subRoot is a subtree of root's left or right children.
        if self.isSameTree(root, subRoot):
            return True
        
        return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)

    def isSameTree(self, p: TreeNode, q: TreeNode) -> bool:
        # Both are None, considered same
        if not p and not q:
            return True
        # One is None, the other is not, considered different
        if not p or not q:
            return False
        # Values are different
        if p.val != q.val:
            return False
        
        # Recursively check left and right subtrees
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

### 138: [440. 字典序的第K小数字 (K-th Smallest in Lexicographical Order)](https://leetcode.cn/problems/k-th-smallest-in-lexicographical-order)

**题目描述:**
给定整数 `n` 和 `k`，返回 `[1, n]` 中字典序第 `k` 小的数字。

**解题思路 (按前缀枚举 / 十叉树Denary Tree Traversal):**
这是一个较难的问题，核心思想是在一个概念上的十叉树（每个节点的孩子是当前数字后面追加0-9）中进行搜索。
1.  `current_num`: 当前考虑的数字，初始为 1。
2.  `k` : 还需要跳过的数字个数，初始时，因为 `current_num = 1` 是第一个，所以 `k` 减 1。
3.  当 `k > 0` 时循环：
    a.  计算以 `current_num` 为前缀的数字在 `[1, n]` 范围内的总个数 `steps`。
    *   这个计算函数 `count_steps(n, prefix_start, prefix_end)`:
    *   `prefix_start` 是当前前缀 (e.g., 1, 10, 100 for prefix "1")。
    *   `prefix_end` 是当前前缀后面加一位的最大可能值 (e.g., 2, 11, 101 for prefix "1")。
    *   `steps_count = 0`。
    *   当 `prefix_start <= n` 时：
    *   当前这一层 (同样位数的数字)，以 `prefix_start` 到 `min(n, prefix_end - 1)` 开头的数字都算。
    *   `steps_count += min(n + 1, prefix_end) - prefix_start`。(e.g., n=13, prefix_start=1, prefix_end=2 => min(14,2)-1=1. n=13, p_s=10, p_e=20 => min(14,20)-10 = 4 (10,11,12,13)).
    *   `prefix_start *= 10` (下一层前缀，如 1 -> 10)
    *   `prefix_end *= 10` (下一层前缀，如 2 -> 20)
    *   返回 `steps_count`。
    b.  比较 `steps` 和 `k`:
    i.  如果 `steps <= k`:
    *   说明第 `k` 小的数字不在以 `current_num` 为前缀的这批数字中。
    *   跳过这 `steps` 个数字: `k -= steps`。
    *   `current_num` 增加 1 (移动到下一个兄弟前缀，如从 1xxxx 跳到 2xxxx)。
    ii. 如果 `steps > k`:
    *   说明第 `k` 小的数字在以 `current_num` 为前缀的这批数字中。
    *   `current_num` 乘以 10 (深入到下一层，如从前缀 1 深入到前缀 10)。
    *   `k` 减 1 (因为 `current_num` 本身被选中，跳过它，进入它的子树)。
4.  循环结束后，`current_num` 就是第 `k` (原始的) 小的数字。

**Python 实现:**
```python
class Solution:
    def findKthNumber(self, n: int, k: int) -> int:
        
        def count_steps(prefix_val, total_n):
            """Counts how many numbers in [1, total_n] start with prefix_val."""
            steps = 0
            curr_prefix = prefix_val
            next_prefix = prefix_val + 1
            
            while curr_prefix <= total_n:
                steps += min(total_n + 1, next_prefix) - curr_prefix
                curr_prefix *= 10
                next_prefix *= 10
            return steps

        current_num = 1
        k -= 1  # current_num (1) is the 1st smallest, so we need to find k-1 more steps
        
        while k > 0:
            steps = count_steps(current_num, n)
            
            if steps <= k:
                # The k-th number is not in the subtree of current_num
                k -= steps
                current_num += 1 # Move to the next sibling
            else:
                # The k-th number is in the subtree of current_num
                k -= 1 # current_num itself is one step, then go into its children
                current_num *= 10 # Move to the first child
                
        return current_num
```

**Java 实现:**
```java
class Solution {
    public int findKthNumber(int n, int k) {
        long currentNum = 1;
        k = k - 1; // currentNum (1) is the 1st smallest, we need to find k-1 more steps

        while (k > 0) {
            long steps = countSteps(currentNum, n);
            
            if (steps <= k) {
                // The k-th number is not in the "denary tree" subtree of currentNum.
                // Skip this subtree.
                k -= steps;
                currentNum++; // Move to the next sibling in the denary tree.
            } else {
                // The k-th number is in the "denary tree" subtree of currentNum.
                // currentNum itself is one step, so decrease k by 1.
                k--;
                currentNum *= 10; // Move to the first child of currentNum.
            }
        }
        return (int) currentNum;
    }

    // Calculates how many numbers in the range [1, totalN] start with the given prefixVal.
    private long countSteps(long prefixVal, long totalN) {
        long steps = 0;
        long currentLevelStart = prefixVal;
        long nextLevelStart = prefixVal + 1; // Prefix for the next sibling at the same "conceptual level"

        while (currentLevelStart <= totalN) {
            // Numbers at the current level of the "denary tree" that fall under totalN.
            // e.g., if totalN = 13, prefixVal = 1:
            //   currentLevelStart=1, nextLevelStart=2 -> min(13+1, 2) - 1 = 2-1=1 (number "1")
            //   currentLevelStart=10, nextLevelStart=20 -> min(13+1, 20) - 10 = 14-10=4 (numbers "10,11,12,13")
            steps += Math.min(totalN + 1, nextLevelStart) - currentLevelStart;
            
            currentLevelStart *= 10;
            nextLevelStart *= 10;
        }
        return steps;
    }
}
```

*   空间复杂度: O(1)。

### 139: [剑指 Offer 40. 最小的k个数 (Zui Xiao De Kge Shu Lcof / Get Least K Numbers)](https://leetcode.cn/problems/zui-xiao-de-kge-shu-lcof)

**题目描述:**
输入整数数组 `arr` ，找出其中最小的 `k` 个数。例如，输入4、5、1、6、2、7、3、8这8个数字，则最小的4个数字是1、2、3、4。

**解题思路:**
**1. 排序法 (O(N log N)):**
* 对整个数组排序，然后取前 `k` 个元素。
* 简单直接，但不是最优。

**2. 最大堆 (O(N log K)):**
* 维护一个大小为 `k` 的最大堆。
* 遍历数组 `arr`:
    * 如果堆的大小小于 `k`，将当前元素加入堆。
    * 否则，如果当前元素小于堆顶元素 (最大元素)，则弹出堆顶，并将当前元素加入堆。
* 遍历结束后，堆中的 `k` 个元素即为最小的 `k` 个数。
* 时间复杂度: O(N log K)，空间复杂度: O(K)。

**3. 快速选择 (基于快速排序的分区思想) (平均 O(N), 最坏 O(N^2)):**
* 目标是找到第 `k` 小的元素 (如果数组排序后，它会在索引 `k-1` 的位置)。
* 使用快速排序的分区 (partition) 函数，将数组分为两部分：小于枢轴的元素，和大于枢轴的元素。枢轴元素会处在它最终排序后的位置 `pivot_idx`。
* 比较 `pivot_idx` 和 `k-1`:
    * 如果 `pivot_idx == k-1`，则前 `k` 个元素 (`arr[0...k-1]`) 就是最小的 `k` 个数 (它们可能未完全排序，但都是小于等于第k小的数)。
    * 如果 `pivot_idx < k-1`，说明第 `k` 小的元素在枢轴的右边，递归搜索右子数组。
    * 如果 `pivot_idx > k-1`，说明第 `k` 小的元素在枢轴的左边，递归搜索左子数组。
* 一旦找到 `pivot_idx == k-1`，返回数组的前 `k` 个元素。
* 时间复杂度: 平均 O(N)，最坏 O(N^2) (可以通过随机化枢轴优化)。空间复杂度: O(log N) 递归栈 (最坏 O(N))。

对于 "找到最小/最大的k个数"，最大堆/最小堆是常见且性能稳定的方法。快速选择平均更快。

**Python 实现 (最大堆):**
```python
import heapq

class Solution:
    def getLeastNumbers(self, arr: list[int], k: int) -> list[int]:
        if k == 0:
            return []
        if k >= len(arr):
            return arr
            
        # Create a max-heap of size k
        # In Python, heapq is a min-heap. To simulate a max-heap, store negative numbers.
        max_heap = []
        for num in arr:
            if len(max_heap) < k:
                heapq.heappush(max_heap, -num) # Push negative to simulate max-heap
            elif -num > max_heap[0]: # If current num is smaller than largest in heap (stored as smallest neg)
                heapq.heappop(max_heap)      # Pop largest (smallest negative)
                heapq.heappush(max_heap, -num) # Push current num (as negative)
                
        # Convert back from negative numbers
        return [-x for x in max_heap]
```

**Java 实现 (最大堆 / PriorityQueue):**
```java
import java.util.PriorityQueue;
import java.util.Comparator; // For max-heap

class Solution {
    public int[] getLeastNumbers(int[] arr, int k) {
        if (k == 0 || arr == null || arr.length == 0) {
            return new int[0];
        }
        if (k >= arr.length) {
            return arr; // Or a sorted version if the problem implies order among k
                        // LeetCode tests seem to accept any order for the k numbers.
        }

        // Max-heap of size k
        // PriorityQueue<Integer> maxHeap = new PriorityQueue<>(k, Comparator.reverseOrder());
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(k, (a, b) -> b - a);


        for (int num : arr) {
            if (maxHeap.size() < k) {
                maxHeap.offer(num);
            } else if (num < maxHeap.peek()) { // If current num is smaller than largest in heap
                maxHeap.poll(); // Remove largest
                maxHeap.offer(num); // Add current num
            }
        }
        
        // Convert heap to array
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = maxHeap.poll();
        }
        return result; // Note: order is not guaranteed here, just the k smallest elements
    }
}
```

**复杂度分析 (最大堆法):**
*   时间复杂度: O(N log K)。N 次遍历，每次堆操作 (offer/poll) 是 log K。

### 140: [剑指 Offer 54. 二叉搜索树的第k大节点 (Er Cha Sou Suo Shu De Di Kda Jie Dian Lcof / Kth Largest Node in BST)](https://leetcode.cn/problems/er-cha-sou-suo-shu-de-di-kda-jie-dian-lcof)

**题目描述:**
给定一棵二叉搜索树，请找出其中第 `k` 大的节点的值。

**解题思路 (中序遍历的逆序):**
二叉搜索树 (BST) 的中序遍历 (左-根-右) 会得到一个升序序列。
要找第 `k` 大的节点，我们可以进行中序遍历的“逆序”：**右-根-左**。这样会得到一个降序序列。遍历到的第 `k` 个节点就是第 `k` 大的节点。

1.  定义一个计数器 `count` (或 `k` 本身递减) 和一个结果变量 `result_node_val`。
2.  实现一个递归函数 `traverse(node)`:
    a.  基准情况: 如果 `node` 为 `null`，返回。
    b.  **先遍历右子树**: `traverse(node.right)`。
    c.  **处理根节点**:
    *   `count` (或 `k`) 减 1。
    *   如果 `count` (或 `k`) 变为 0，说明当前 `node` 就是我们要找的第 `k` 大节点。记录 `node.val` 到 `result_node_val`，并可以提前结束遍历 (例如通过设置一个标志或抛出异常)。
    d.  **再遍历左子树** (如果尚未找到结果): `traverse(node.left)`。
3.  初始调用 `traverse(root)`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Solution:
    def kthLargest(self, root: TreeNode, k: int) -> int:
        self.k = k
        self.result_val = -1 # Placeholder

        def inorder_reversed(node):
            if not node or self.k == 0: # Stop if node is null or result found
                return

            # 1. Traverse right subtree
            inorder_reversed(node.right)
            
            # 2. Process current node (count down k)
            if self.k > 0: # Ensure we only decrement and check if not already found
                self.k -= 1
                if self.k == 0:
                    self.result_val = node.val
                    return # Result found, stop further traversal
            
            # 3. Traverse left subtree (only if result not yet found)
            if self.k > 0: # Important to check self.k again, might have been found in right tree for current node
                inorder_reversed(node.left)

        inorder_reversed(root)
        return self.result_val
```

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

class Solution {
    private int currentK;
    private int resultVal;

    public int kthLargest(TreeNode root, int k) {
        this.currentK = k;
        // this.resultVal will be set by the traversal
        inorderReversed(root);
        return this.resultVal;
    }

    private void inorderReversed(TreeNode node) {
        if (node == null || this.currentK == 0) { // Stop if node is null or result already found
            return;
        }

        // 1. Traverse right subtree
        inorderReversed(node.right);
        
        // 2. Process current node (count down k)
        // Check if result already found by deeper right recursion for current node's right child
        if (this.currentK == 0) { 
            return;
        }

        this.currentK--; // Decrement k for the current node
        if (this.currentK == 0) {
            this.resultVal = node.val;
            return; // Result found, stop further traversal
        }
        
        // 3. Traverse left subtree (only if result not yet found)
        // Check currentK again as it might have become 0 after processing the current node
        if (this.currentK > 0) {
            inorderReversed(node.left);
        }
    }
}
```
