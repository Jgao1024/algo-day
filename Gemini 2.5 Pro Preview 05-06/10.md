### 001: [3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)](https://leetcode.cn/problems/longest-substring-without-repeating-characters)

**题目描述:**
给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

**解题思路:**
使用滑动窗口的方法。维护一个窗口 `[left, right)`，窗口内的字符不重复。
1.  初始化 `left = 0`, `right = 0`，一个哈希集合 `seen_chars` 来存储窗口中的字符，`max_length = 0`。
2.  不断向右扩展窗口 (`right++`)：
    *   将 `s[right]` 加入窗口。
    *   如果 `s[right]` 不在 `seen_chars` 中，将其加入 `seen_chars`，更新 `max_length = max(max_length, right - left)`。
    *   如果 `s[right]` 已经存在于 `seen_chars` 中，说明窗口内出现了重复字符。此时需要收缩窗口左边界：不断从 `seen_chars` 中移除 `s[left]` 并 `left++`，直到 `s[right]`不再是重复字符。然后再将新的`s[right]`（即导致冲突的那个字符）加入`seen_chars`。
3.  当 `right` 到达字符串末尾时，`max_length` 即为所求。

**Python 实现:**
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        seen_chars = set()
        left = 0
        max_length = 0
        for right in range(len(s)):
            while s[right] in seen_chars:
                seen_chars.remove(s[left])
                left += 1
            seen_chars.add(s[right])
            max_length = max(max_length, right - left + 1)
        return max_length

```

**Java 实现:**
```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> seenChars = new HashSet<>();
        int left = 0;
        int maxLength = 0;
        for (int right = 0; right < s.length(); right++) {
            while (seenChars.contains(s.charAt(right))) {
                seenChars.remove(s.charAt(left));
                left++;
            }
            seenChars.add(s.charAt(right));
            maxLength = Math.max(maxLength, right - left + 1);
        }
        return maxLength;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是字符串的长度。尽管有嵌套循环，但 `left` 和 `right` 指针都只会向前移动，每个字符最多被访问两次（一次被 `right` 指针扫描，一次被 `left` 指针扫描）。
*   空间复杂度: O(min(M, N))，其中 N 是字符串长度，M 是字符集的大小 (例如 ASCII 是128，扩展 ASCII 是 256)。存储 `seen_chars` 需要的空间。

### 002: [146. LRU缓存机制 (LRU Cache)](https://leetcode.cn/problems/lru-cache)

**题目描述:**
请你设计并实现一个满足 LRU (最近最少使用) 缓存 约束的数据结构。
实现 `LRUCache` 类：
*   `LRUCache(int capacity)` 以 正整数 作为容量 `capacity` 初始化 LRU 缓存
*   `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 -1 。
*   `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 逐出 最久未使用的关键字。
    函数 `get` 和 `put` 必须以 O(1) 的平均时间复杂度运行。

**解题思路:**
使用一个哈希表 (HashMap) 和一个双向链表 (Doubly Linked List)。
1.  **哈希表**: 存储 `key` 到链表节点的映射，实现 O(1) 的查找。
2.  **双向链表**: 存储 `(key, value)` 对，并维护节点的访问顺序。链表头部表示最近使用的，链表尾部表示最久未使用的。
    *   节点结构: `key, value, prev_pointer, next_pointer`。
    *   需要 `head` 和 `tail` 伪节点来简化边界操作。

**操作:**
*   `get(key)`:
    1.  通过哈希表查找节点。
    2.  如果找到，将该节点移动到链表头部 (表示最近使用)，返回值。
    3.  如果未找到，返回 -1。
*   `put(key, value)`:
    1.  通过哈希表查找节点。
    2.  如果找到：更新节点的值，将该节点移动到链表头部。
    3.  如果未找到：
        *   创建一个新节点。
        *   将新节点插入链表头部。
        *   在哈希表中添加 `key` 和新节点的映射。
        *   如果缓存大小超过 `capacity`：移除链表尾部节点 (最久未使用)，并从哈希表中移除对应的 `key`。

**Python 实现:**
```python
import collections

class DLinkedNode:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}  # key -> DLinkedNode
        # Dummy head and tail
        self.head = DLinkedNode()
        self.tail = DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def _move_to_head(self, node):
        # Remove node from its current position
        node.prev.next = node.next
        node.next.prev = node.prev
        # Add node to head
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _remove_tail(self):
        node_to_remove = self.tail.prev
        # Remove from list
        node_to_remove.prev.next = self.tail
        self.tail.prev = node_to_remove.prev
        return node_to_remove

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._move_to_head(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._move_to_head(node)
        else:
            new_node = DLinkedNode(key, value)
            self.cache[key] = new_node
            self._add_to_head(new_node)
            self.size += 1
            if self.size > self.capacity:
                tail_node = self._remove_tail()
                del self.cache[tail_node.key]
                self.size -= 1
```

```java
import java.util.HashMap;
import java.util.Map;

class DLinkedNode {
    int key;
    int value;
    DLinkedNode prev;
    DLinkedNode next;

    public DLinkedNode() {}
    public DLinkedNode(int key, int value) {
        this.key = key;
        this.value = value;
    }
}

class LRUCache {
    private Map<Integer, DLinkedNode> cache;
    private int capacity;
    private int size;
    private DLinkedNode head, tail; // Dummy head and tail

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.size = 0;
        this.cache = new HashMap<>();
        
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
    }

    private void moveToHead(DLinkedNode node) {
        // Remove node from its current position
        node.prev.next = node.next;
        node.next.prev = node.prev;
        // Add node to head
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private void addToHead(DLinkedNode node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private DLinkedNode removeTail() {
        DLinkedNode nodeToRemove = tail.prev;
        // Remove from list
        nodeToRemove.prev.next = tail;
        tail.prev = nodeToRemove.prev;
        return nodeToRemove;
    }
    
    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            return -1;
        }
        moveToHead(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
        } else {
            DLinkedNode newNode = new DLinkedNode(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            size++;
            if (size > capacity) {
                DLinkedNode tailNode = removeTail();
                cache.remove(tailNode.key);
                size--;
            }
        }
    }
}
```

### 003: [206. 反转链表 (Reverse Linked List)](https://leetcode.cn/problems/reverse-linked-list)

**题目描述:**
给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表头节点。

**解题思路:**
**迭代法:**
1.  初始化三个指针：`prev = null`，`curr = head`，`next_temp = null`。
2.  遍历链表，当 `curr` 不为 `null` 时：
    a.  保存 `curr` 的下一个节点: `next_temp = curr.next`。
    b.  将 `curr` 的 `next` 指针指向 `prev`：`curr.next = prev`。
    c.  移动 `prev` 和 `curr` 指针向前：`prev = curr`，`curr = next_temp`。
3.  循环结束后，`prev` 指向新的头节点。

**递归法:**
1.  基本情况：如果 `head` 为空或 `head.next` 为空（链表为空或只有一个节点），直接返回 `head`。
2.  递归步骤：
    a.  递归调用 `reverseList(head.next)`，这将反转 `head` 之后的子链表，并返回新的子链表头节点 `new_head`。
    b.  此时，`head.next` 仍然指向原来的下一个节点 (在反转后的子链表中，它是尾节点)。让 `head.next.next = head`，即将原 `head` 的下一个节点的 `next` 指针指向 `head`。
    c.  将 `head.next = null`，断开原 `head` 与下一节点的连接，避免循环。
    d.  返回 `new_head`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    # Iterative Solution
    def reverseListIterative(self, head: ListNode) -> ListNode:
        prev = None
        curr = head
        while curr:
            next_temp = curr.next  # Store next node
            curr.next = prev      # Reverse current node's pointer
            prev = curr           # Move prev one step forward
            curr = next_temp      # Move curr one step forward
        return prev

    # Recursive Solution
    def reverseList(self, head: ListNode) -> ListNode: # Defaulting to recursive for the main function name
        if not head or not head.next:
            return head
        
        new_head = self.reverseList(head.next)
        
        head.next.next = head # head's original next node now points to head
        head.next = None      # head becomes the new tail
        
        return new_head
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    // Iterative Solution
    public ListNode reverseListIterative(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next; // Store next node
            curr.next = prev;             // Reverse current node's pointer
            prev = curr;                  // Move prev one step forward
            curr = nextTemp;              // Move curr one step forward
        }
        return prev;
    }

    // Recursive Solution
    public ListNode reverseList(ListNode head) { // Defaulting to recursive for the main function name
        if (head == null || head.next == null) {
            return head;
        }
        ListNode newHead = reverseList(head.next);
        
        head.next.next = head; // head's original next node now points to head
        head.next = null;      // head becomes the new tail
        
        return newHead;
    }
}
```

*   **迭代法:**
    *   时间复杂度: O(N)，其中 N 是链表的节点数。每个节点访问一次。
    *   空间复杂度: O(1)。
*   **递归法:**
    *   时间复杂度: O(N)。每个节点访问一次。
    *   空间复杂度: O(N)，因为递归调用会产生 N 层调用栈。

### 004: [215. 数组中的第K个最大元素 (Kth Largest Element in an Array)](https://leetcode.cn/problems/kth-largest-element-in-an-array)

**题目描述:**
给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。
请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

**解题思路:**
1.  **排序法:**
    *   将数组 `nums` 排序 (例如，升序)。
    *   第 `k` 大的元素即为 `nums[nums.length - k]`。
    *   时间复杂度: O(N log N)，空间复杂度: O(1) or O(N) (取决于排序算法实现)。

2.  **最小堆 (Min-Heap):**
    *   维护一个大小为 `k` 的最小堆。
    *   遍历数组：
        *   如果堆的大小小于 `k`，将当前元素加入堆。
        *   否则，如果当前元素大于堆顶元素，则弹出堆顶元素，并将当前元素加入堆。
    *   遍历结束后，堆顶元素即为第 `k` 大的元素。
    *   时间复杂度: O(N log K)，空间复杂度: O(K)。

3.  **快速选择 (Quickselect Algorithm):**
    *   这是快速排序的变种。目标是找到第 `k` 大的元素，等价于找到排序后索引为 `n - k` 的元素 (0-indexed)。
    *   选择一个枢轴 (pivot)，将数组分区，使得小于枢轴的元素在左边，大于枢轴的在右边。枢轴元素放置在正确排序后的位置 `p_idx`。
    *   比较 `p_idx` 和 `target_idx = n - k`：
        *   如果 `p_idx == target_idx`，枢轴元素就是所求。
        *   如果 `p_idx < target_idx`，则第 `k` 大元素在枢轴右侧，递归搜索右子数组。
        *   如果 `p_idx > target_idx`，则第 `k` 大元素在枢轴左侧，递归搜索左子数组。
    *   时间复杂度: 平均 O(N)，最坏 O(N^2) (如果枢轴选择不当)。可以通过随机化枢轴选择来降低最坏情况概率。
    *   空间复杂度: 平均 O(log N) (递归栈)，最坏 O(N)。可以优化为 O(1) 通过尾递归或迭代实现。

对于面试，最小堆和快速选择通常是更受期待的解法。

    *   最坏情况: O(N^2) (如果枢轴选择总是导致不平衡的分割)。随机化枢轴可以大大降低这种情况。
*   空间复杂度:
    *   平均情况 (递归): O(log N) for recursion stack.
    *   最坏情况 (递归): O(N) for recursion stack.
    *   迭代实现 (或尾递归优化) 可以做到 O(1) 空间。

### 005: [25. K 个一组翻转链表 (Reverse Nodes in k-Group)](https://leetcode.cn/problems/reverse-nodes-in-k-group)

**题目描述:**
给你一个链表，每 `k` 个节点一组进行翻转，请你返回修改后的链表。
`k` 是一个正整数，它的值小于或等于链表的长度。
如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。
你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**解题思路:**
这是一个相对复杂的链表操作题。
1.  **分组处理**:
    *   首先，我们需要一个方法来统计从当前节点开始，后面是否有足够的 `k` 个节点。
    *   如果不足 `k` 个，则不翻转，直接返回当前头节点。
2.  **翻转 k 个节点**:
    *   如果足够 `k` 个，我们需要翻转这 `k` 个节点。可以写一个辅助函数 `reverseK(head, k)`。
    *   这个翻转操作类似于标准的链表翻转，但只翻转前 `k` 个。
    *   重要的是记录这 `k` 个节点中的第一个节点 (在翻转后会变成该组的尾部) 和第 `k+1` 个节点 (下一组的头部)。
3.  **连接各组**:
    *   原始的头节点 (本组的第一个节点) 在翻转后会成为这 `k` 个节点的尾节点。这个尾节点的 `next` 指针需要指向下一组（递归处理后的）的头部。
    *   `reverseK` 函数应该返回翻转后的这 `k` 个节点的头部。
4.  **递归/迭代**:
    *   **递归法**:
        *   `new_head = reverseK(current_head, k)`
        *   `current_head.next = solve(kth_plus_one_node, k)` (current_head 是翻转前的本组第一个，翻转后是本组最后一个)
        *   返回 `new_head`
    *   **迭代法**:
        *   使用一个 `dummy` 节点来简化头节点的处理。`prev_group_tail` 指向上一组的尾部 (初始为 `dummy`)。
        *   `curr_group_head` 指向当前准备处理的组的头。
        *   循环处理：
            a.  检查 `curr_group_head` 后面是否有 `k` 个节点。
            b.  如果有，记录下本组的第 `k` 个节点 `group_kth_node` 和第 `k+1` 个节点 `next_group_head = group_kth_node.next`。
            c.  断开 `group_kth_node.next = null` 以便翻转。
            d.  翻转从 `curr_group_head` 开始的这 `k` 个节点。翻转后 `new_group_head` 是新头，`curr_group_head` (原来的头) 变成尾。
            e.  `prev_group_tail.next = new_group_head`。
            f.  `curr_group_head.next = next_group_head` (原来的头，现在的尾，指向下一组的头)。
            g.  更新 `prev_group_tail = curr_group_head` (现在的尾巴)
            h.  `curr_group_head = next_group_head` (移动到下一组)。
        *   如果没有足够的 `k` 个节点，则 `prev_group_tail.next = curr_group_head` (如果还有剩余节点)，然后结束。
        *   返回 `dummy.next`。

迭代法通常在链表操作中对空间更友好。

**Python 实现 (迭代法):**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseKGroup(self, head: ListNode, k: int) -> ListNode:
        if not head or k == 1:
            return head

        # Helper to reverse a segment of the list from `start_node` to `end_node` (inclusive)
        # Returns the new head and new tail of the reversed segment
        def reverse_segment(start_node: ListNode, end_node: ListNode):
            prev = None
            curr = start_node
            original_next_after_end = end_node.next # Save for later connection
            
            while curr != original_next_after_end: # Reverse until just after end_node
                next_temp = curr.next
                curr.next = prev
                prev = curr
                curr = next_temp
            # After loop, prev is the new head of the reversed segment (original end_node)
            # start_node is the new tail of the reversed segment
            return prev, start_node # new_head, new_tail

        dummy = ListNode(0, head)
        prev_group_tail = dummy
        curr_group_start = head

        while curr_group_start:
            # 1. Check if there are k nodes left
            group_end_node = curr_group_start
            count = 1
            while count < k and group_end_node:
                group_end_node = group_end_node.next
                count += 1
            
            if not group_end_node: # Not enough nodes to reverse
                prev_group_tail.next = curr_group_start # Attach remaining part
                break

            # 2. Identify the next group's start
            next_group_start_node = group_end_node.next

            # 3. Reverse the current k-group
            # We pass group_end_node itself to the reversal function
            # The reversal helper will handle connections up to group_end_node.next
            
            # Disconnect the group to reverse it
            # group_end_node.next = None # No, let helper use original next_after_end

            reversed_group_head, reversed_group_tail = reverse_segment(curr_group_start, group_end_node)

            # 4. Connect with the previous part
            prev_group_tail.next = reversed_group_head
            
            # 5. Connect the current reversed group's tail to the start of the next group
            reversed_group_tail.next = next_group_start_node # Original curr_group_start is now tail

            # 6. Move pointers for the next iteration
            prev_group_tail = reversed_group_tail # This is the tail of the just-reversed group
            curr_group_start = next_group_start_node
            
        return dummy.next
```

```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }

class Solution {
    // Helper function to reverse 'k' nodes starting from 'head'.
    // Returns the new head of the reversed k-group.
    // The original 'head' becomes the tail of the reversed k-group.
    // The 'next' pointer of this new tail should point to the (k+1)th node.
    private ListNode[] reverse(ListNode head, int k) {
        // head: start of the sublist to reverse
        // end: end of the sublist to reverse (kth node)
        ListNode prev = null;
        ListNode curr = head;
        ListNode originalHead = head; // To be the tail after reversal

        int count = 0;
        while (count < k && curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
            count++;
        }
        // prev is new head, originalHead is new tail, curr is the (k+1)th node
        return new ListNode[]{prev, originalHead, curr}; 
    }

    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) {
            return head;
        }

        ListNode dummy = new ListNode(0);
        dummy.next = head;
        
        ListNode prevGroupTail = dummy; // Tail of the previous (already processed) group
        ListNode currGroupStart = head; // Start of the current group to process

        while (currGroupStart != null) {
            // 1. Check if there are at least k nodes left
            ListNode checkNode = currGroupStart;
            int count = 0;
            while (count < k && checkNode != null) {
                checkNode = checkNode.next;
                count++;
            }

            if (count == k) { // Enough nodes to reverse
                // `checkNode` is now the (k+1)th node (start of the next segment)
                
                // Reverse k nodes starting from currGroupStart
                ListNode[] reversedSegment = reverseSubList(currGroupStart, k);
                ListNode groupNewHead = reversedSegment[0];
                ListNode groupNewTail = reversedSegment[1]; // This was original currGroupStart
                ListNode nextSegmentStart = reversedSegment[2]; // This was the (k+1)th node

                // Connect previous group's tail to current group's new head
                prevGroupTail.next = groupNewHead;
                
                // Connect current group's new tail to the start of the next segment
                groupNewTail.next = nextSegmentStart;

                // Move pointers for the next iteration
                prevGroupTail = groupNewTail;       // The tail of the group just reversed
                currGroupStart = nextSegmentStart;  // Start of the next group
            } else {
                // Not enough nodes, current group remains as is.
                // prevGroupTail.next is already pointing to currGroupStart.
                break; 
            }
        }
        return dummy.next;
    }

    // Helper function: reverses 'count' nodes starting from 'node'
    // Returns an array: {newHead, newTail, nextNodeAfterSegment}
    private ListNode[] reverseSubList(ListNode node, int count) {
        ListNode prev = null;
        ListNode curr = node;
        ListNode originalStart = node; // This will be the new tail
        ListNode nextNodeAfterSegment = null;

        for (int i = 0; i < count && curr != null; i++) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        nextNodeAfterSegment = curr; // Node after the reversed segment
        // prev is the new head of this segment
        // originalStart is the new tail of this segment
        return new ListNode[]{prev, originalStart, nextNodeAfterSegment};
    }
}
```

```java
class SolutionRevKGroupJavaClean {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) return head;

        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode curr = head;
        ListNode prevGroupTail = dummy; // Points to the tail of the previous k-group (or dummy)
        ListNode nextGroupHead;         // Points to the head of the next k-group

        while (curr != null) {
            // 1. Find the k-th node of the current group
            ListNode kthNode = curr;
            int count = 1;
            while (count < k && kthNode != null) {
                kthNode = kthNode.next;
                count++;
            }

            // If not enough nodes, break (the rest remains as is)
            if (kthNode == null) {
                prevGroupTail.next = curr; // Connect remaining list
                break;
            }

            // 2. Store the head of the next group
            nextGroupHead = kthNode.next;

            // 3. Reverse the current k-group (from curr to kthNode)
            // Temporarily disconnect the k-group for reversal
            kthNode.next = null;
            ListNode reversedGroupHead = reverseLinkedList(curr);

            // 4. Connect the reversed k-group
            prevGroupTail.next = reversedGroupHead; // Previous group tail to new head of current group
            curr.next = nextGroupHead; // `curr` is now the tail of the reversed group

            // 5. Move pointers for the next iteration
            prevGroupTail = curr; // Current group's original head is now its tail
            curr = nextGroupHead; // Move to the start of the next group
        }
        return dummy.next;
    }

    // Helper function to reverse a simple linked list (ends when head becomes null)
    private ListNode reverseLinkedList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev; // New head of the reversed list
    }
}
```

### 006: [15. 三数之和 (3Sum)](https://leetcode.cn/problems/3sum)

**题目描述:**
给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。
注意：答案中不可以包含重复的三元组。

**解题思路:**
1.  **排序**: 首先对数组 `nums`进行排序。这有助于后续使用双指针法，并且更容易处理重复元素。
2.  **主循环 (固定第一个数)**:
    *   遍历排序后的数组，用 `nums[i]` 作为第一个数。
    *   为了避免重复三元组，如果当前的 `nums[i]` 与前一个元素 `nums[i-1]` 相同，则跳过 (因为以 `nums[i-1]` 开头的所有组合都已找到)。
    *   如果 `nums[i] > 0`，由于数组已排序，后续的数也都会大于0，不可能三数之和为0，可以直接中断循环。
3.  **双指针 (寻找另外两个数)**:
    *   对于每个 `nums[i]`，我们想在 `nums[i+1 ... n-1]` 这个子数组中找到两个数 `nums[left]` 和 `nums[right]` 使得 `nums[left] + nums[right] == -nums[i]`。
    *   初始化 `left = i + 1` 和 `right = nums.length - 1`。
    *   当 `left < right` 时：
        *   计算 `sum = nums[i] + nums[left] + nums[right]`。
        *   如果 `sum == 0`：
            *   找到了一个三元组 `(nums[i], nums[left], nums[right])`，将其加入结果列表。
            *   **处理重复**:
                *   移动 `left` 指针向右，直到 `nums[left]` 不等于前一个 `nums[left]`。
                *   移动 `right` 指针向左，直到 `nums[right]` 不等于前一个 `nums[right]`。
                *   然后 `left++` 和 `right--` 继续寻找下一对。
        *   如果 `sum < 0`：说明和太小，需要增大，`left++`。
        *   如果 `sum > 0`：说明和太大，需要减小，`right--`。
4.  返回结果列表。

**Python 实现:**
```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        result = []
        n = len(nums)

        for i in range(n - 2):
            # Optimization: if current number is positive, sum cannot be zero
            if nums[i] > 0:
                break
            
            # Skip duplicate for the first element
            if i > 0 and nums[i] == nums[i-1]:
                continue

            left, right = i + 1, n - 1
            target = -nums[i]

            while left < right:
                current_sum = nums[left] + nums[right]
                if current_sum == target:
                    result.append([nums[i], nums[left], nums[right]])
                    # Skip duplicates for the second element
                    while left < right and nums[left] == nums[left+1]:
                        left += 1
                    # Skip duplicates for the third element
                    while left < right and nums[right] == nums[right-1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif current_sum < target:
                    left += 1
                else: # current_sum > target
                    right -= 1
        return result
```

```java
import java.util.List;

        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            // Optimization: if current number is positive, sum cannot be zero
            if (nums[i] > 0) {
                break;
            }

            if (i > 0 && nums[i] == nums[i-1]) {
                continue;
            }

            int right = n - 1;
            int target = -nums[i];

            while (left < right) {
                int currentSum = nums[left] + nums[right];
                if (currentSum == target) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    // Skip duplicates for the second element
                    while (left < right && nums[left] == nums[left+1]) {
                        left++;
                    }
                    // Skip duplicates for the third element
                    while (left < right && nums[right] == nums[right-1]) {
                        right--;
                    }
                    left++;
                    right--;
                } else if (currentSum < target) {
                    left++;
                } else { // currentSum > target
                    right--;
                }
            }
        }

    }
```

### 007: [53. 最大子数组和 (Maximum Subarray)](https://leetcode.cn/problems/maximum-subarray)

**题目描述:**
给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。
子数组是数组中的一个连续部分。

**解题思路 (Kadane's Algorithm):**
1.  初始化两个变量:
    *   `current_max_sum`: 到当前位置为止，包含当前元素的最大子数组和。
    *   `global_max_sum`: 到目前为止找到的全局最大子数组和。将两者都初始化为数组的第一个元素 `nums`。
2.  从数组的第二个元素开始遍历 (`i = 1 to n-1`):
    *   对于当前元素 `nums[i]`, `current_max_sum` 可以是：
        *   `nums[i]` 本身 (即开始一个新的子数组)。
        *   `current_max_sum + nums[i]` (即将 `nums[i]` 加入到之前的最大子数组中)。
        *   所以，`current_max_sum = max(nums[i], current_max_sum + nums[i])`。
    *   更新 `global_max_sum = max(global_max_sum, current_max_sum)`。
3.  遍历结束后，`global_max_sum` 即为所求。

**Python 实现:**
```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        if not nums:
            return 0
        
        current_max_sum = nums[0]
        global_max_sum = nums[0]
        
        for i in range(1, len(nums)):
            current_max_sum = max(nums[i], current_max_sum + nums[i])
            global_max_sum = max(global_max_sum, current_max_sum)
            
        return global_max_sum
```

*   空间复杂度: O(1)，因为我们只使用了几个额外的变量。

### 008: 补充题4. 手撕快速排序 (Sort an Array - LeetCode 912)

**题目描述:**
给你一个整数数组 `nums`，请你将该数组升序排列。
这里特指使用**快速排序 (Quick Sort)** 来实现。

**解题思路 (快速排序):**
1.  **基准情况 (Base Case)**: 如果子数组的 `low >= high` (即子数组为空或只有一个元素)，则它已经排序，直接返回。
2.  **选择枢轴 (Pivot)**: 从子数组中选择一个元素作为枢轴。常见的选择有第一个元素、最后一个元素、中间元素或随机选择。随机选择或三数取中法可以帮助避免最坏情况。
3.  **分区 (Partition)**: 重新排列子数组，使得所有小于枢轴的元素都移动到枢轴的左边，所有大于枢轴的元素都移动到枢轴的右边。等于枢轴的元素可以放在任何一边或中间。分区后，枢轴元素处于其最终排序位置。
    *   **Lomuto 分区方案**: 通常选择最后一个元素为枢轴。维护一个指针 `i` 指向小于枢轴区域的末尾。遍历数组，若元素小于枢轴，则交换 `nums[j]` 与 `nums[i+1]`，并递增 `i`。最后将枢轴与 `nums[i+1]` 交换。返回 `i+1` 作为枢轴的新索引。
    *   **Hoare 分区方案**: 通常选择第一个元素或中间元素为枢轴。使用两个指针，一个从左向右 (`left_ptr`)，一个从右向左 (`right_ptr`)。`left_ptr` 找大于等于枢轴的元素，`right_ptr` 找小于等于枢轴的元素。如果 `left_ptr < right_ptr`，则交换它们。当 `left_ptr >= right_ptr` 时，分区完成，返回 `right_ptr`。
4.  **递归排序**: 递归地对枢轴左边的子数组和右边的子数组进行快速排序。
    *   `quickSort(array, low, pivot_index - 1)`
    *   `quickSort(array, pivot_index + 1, high)`

**Python 实现 (Lomuto Partition):**
```python
import random

class Solution:
    def sortArray(self, nums: list[int]) -> list[int]: # Matches LeetCode 912
        self.quick_sort(nums, 0, len(nums) - 1)
        return nums

    def quick_sort(self, nums: list[int], low: int, high: int):
        if low < high:
            pivot_index = self.partition(nums, low, high)
            self.quick_sort(nums, low, pivot_index - 1)
            self.quick_sort(nums, pivot_index + 1, high)

    def partition(self, nums: list[int], low: int, high: int) -> int:
        # Randomize pivot choice to improve average-case performance
        # and avoid worst-case on already sorted/reverse-sorted arrays.
        rand_pivot_idx = random.randint(low, high)
        nums[rand_pivot_idx], nums[high] = nums[high], nums[rand_pivot_idx] # Move pivot to end
        
        pivot = nums[high] # Pivot is now the last element
        i = low - 1        # Pointer for the element smaller than pivot

        for j in range(low, high):
            if nums[j] <= pivot: # If current element is smaller than or equal to pivot
                i += 1
                nums[i], nums[j] = nums[j], nums[i] # Swap
        
        nums[i + 1], nums[high] = nums[high], nums[i + 1] # Place pivot in correct spot
        return i + 1 # Return partitioning index
```

**Java 实现 (Lomuto Partition):**
```java
import java.util.Random;

class Solution {
    public int[] sortArray(int[] nums) { // Matches LeetCode 912
        quickSort(nums, 0, nums.length - 1);
        return nums;
    }

    private void quickSort(int[] nums, int low, int high) {
        if (low < high) {
            int pivotIndex = partition(nums, low, high);
            quickSort(nums, low, pivotIndex - 1);
            quickSort(nums, pivotIndex + 1, high);
        }
    }

    private int partition(int[] nums, int low, int high) {
        // Randomize pivot choice
        Random rand = new Random();
        int randPivotIdx = low + rand.nextInt(high - low + 1);
        swap(nums, randPivotIdx, high); // Move pivot to end

        int pivot = nums[high]; // Pivot is now the last element
        int i = low - 1;        // Index of smaller element

        for (int j = low; j < high; j++) {
            // If current element is smaller than or equal to pivot
            if (nums[j] <= pivot) {
                i++;
                swap(nums, i, j);
            }
        }
        swap(nums, i + 1, high); // Place pivot in correct spot
        return i + 1; // Return partitioning index
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

**复杂度分析:**
*   时间复杂度:
    *   平均情况: O(N log N)。每次分区大致将问题规模减半。
    *   最坏情况: O(N^2)。如果枢轴选择不当 (例如，在已排序数组中总是选第一个或最后一个)，导致每次分区都极不平衡。随机化枢轴选择可以使最坏情况的发生概率极低。
*   空间复杂度:
    *   平均情况: O(log N)，用于递归调用栈。
    *   最坏情况: O(N)，递归栈深度可能达到 N。可以通过尾递归优化（某些语言支持）或迭代化版本（如使用显式栈）来改进最坏情况空间复杂度。

### 009: [21. 合并两个有序链表 (Merge Two Sorted Lists)](https://leetcode.cn/problems/merge-two-sorted-lists)

**题目描述:**
将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的节点组成的。

**解题思路:**
1.  **迭代法:**
    *   创建一个哑节点 `dummy` 作为新链表的头指针的前一个节点，这有助于简化头节点的处理。
    *   创建一个 `current` 指针，初始化为 `dummy`，用于构建新链表。
    *   比较 `list1` 和 `list2` 的当前节点的值：
        *   如果 `list1.val <= list2.val`，则将 `list1` 的当前节点连接到 `current.next`，然后 `list1` 指针后移。
        *   否则 (如果 `list2.val < list1.val`)，则将 `list2` 的当前节点连接到 `current.next`，然后 `list2` 指针后移。
        *   移动 `current` 指针到新添加的节点 (`current = current.next`)。
    *   重复上述过程，直到 `list1` 或 `list2` 中有一个变为空。
    *   将未耗尽的那个链表的剩余部分直接连接到 `current.next`。
    *   返回 `dummy.next` 作为合并后链表的头节点。

2.  **递归法:**
    *   **基准情况:**
        *   如果 `list1` 为空，返回 `list2`。
        *   如果 `list2` 为空，返回 `list1`。
    *   **递归步骤:**
        *   比较 `list1.val` 和 `list2.val`。
        *   如果 `list1.val <= list2.val`：
            *   `list1.next` 应指向 `list1` 的其余部分与 `list2` 合并的结果。
            *   即 `list1.next = mergeTwoLists(list1.next, list2)`。
            *   返回 `list1`。
        *   否则 (`list2.val < list1.val`):
            *   `list2.next` 应指向 `list1` 与 `list2` 的其余部分合并的结果。
            *   即 `list2.next = mergeTwoLists(list1, list2.next)`。
            *   返回 `list2`。

**Python 实现 (迭代法):**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(self, list1: ListNode, list2: ListNode) -> ListNode:
        dummy = ListNode(-1) # Dummy head
        current = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                current.next = list1
                list1 = list1.next
            else:
                current.next = list2
                list2 = list2.next
            current = current.next
        
        # Append remaining nodes of list1 or list2
        if list1:
            current.next = list1
        elif list2:
            current.next = list2
            
        return dummy.next

    # Recursive solution
```

### 010: [5. 最长回文子串 (Longest Palindromic Substring)](https://leetcode.cn/problems/longest-palindromic-substring)

**题目描述:**
给你一个字符串 `s`，找到 `s` 中最长的回文子串。
如果字符串的反序与原始字符串相同，则该字符串称为回文字符串。

**解题思路:**
1.  **动态规划 (DP):**
    *   定义 `dp[i][j]` 为布尔值，表示子串 `s[i...j]` (包含 `i` 和 `j`) 是否为回文串。
    *   **状态转移方程:** `dp[i][j] = (s[i] == s[j]) and dp[i+1][j-1]`。
    *   **基本情况:**
        *   单个字符 `dp[i][i]` 总是 `true` (长度为 1 的子串)。
        *   两个相同字符 `dp[i][i+1]` 若 `s[i] == s[i+1]` 则为 `true` (长度为 2 的子串)。
    *   遍历方向：需要 `dp[i+1][j-1]` 的值，所以 `i` 应从大到小遍历，`j` 应从小到大遍历，或者按子串长度 `L` 遍历。
    *   在填充 `dp` 表的过程中，记录最长回文子串的起始位置和长度。
    *   时间复杂度: O(N^2)，空间复杂度: O(N^2)。

2.  **中心扩展法 (Expand Around Center):**
    *   回文串的特性是它关于其中心对称。中心可以是单个字符（奇数长度回文串，如 "aba"，中心是 'b'）或两个字符之间（偶数长度回文串，如 "abba"，中心在两个 'b' 之间）。
    *   总共有 `2N - 1` 个可能的中心点 (N 个单字符中心，N-1 个双字符间中心)。
    *   遍历这 `2N - 1` 个中心点：
        *   从每个中心点向两边扩展 ( `left--`, `right++` )，只要 `s[left] == s[right]` 且未越界。
        *   记录下遇到的最长回文子串。
    *   时间复杂度: O(N^2) (每个中心最多扩展 N/2 次)。
    *   空间复杂度: O(1) (如果我们只存储最长回文子串的起始和长度)。

中心扩展法通常是面试中更受欢迎的解法，因为它空间复杂度更优。

**Python 实现 (中心扩展法):**
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s or len(s) < 1:
            return ""
        
        start = 0
        end = 0 # Stores indices of the longest palindrome found s[start:end+1]

        for i in range(len(s)):
            # Odd length palindromes (center is s[i])
            len1 = self.expand_around_center(s, i, i)
            # Even length palindromes (center is between s[i] and s[i+1])
            len2 = self.expand_around_center(s, i, i + 1)
            
            max_len = max(len1, len2)
            
            if max_len > (end - start + 1):
                # Update start and end for the new longest palindrome
                # The center of the palindrome is 'i'
                # The length is max_len
                # For odd length: s[i - (max_len-1)//2 ... i + (max_len-1)//2]
                # For even length: s[i - max_len//2 + 1 ... i + max_len//2]
                # General formula for start: i - (max_len - 1) // 2
                start = i - (max_len - 1) // 2
                end = i + max_len // 2 # For python slice this would be `s[start : end+1]`
                                        # so end should be i + max_len // 2.

        return s[start : end + 1]

    def expand_around_center(self, s: str, left: int, right: int) -> int:
        # Expand while characters match and pointers are within bounds
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        # The palindrome is s[left+1 ... right-1]
        # Length = (right - 1) - (left + 1) + 1 = right - left - 1
        return right - left - 1
```

**Java 实现 (中心扩展法):**
```java
class Solution {
    private int startIdx;
    private int maxLength;

    public String longestPalindrome(String s) {
        if (s == null || s.length() < 1) {
            return "";
        }
        
        startIdx = 0;
        maxLength = 0;

        for (int i = 0; i < s.length(); i++) {
            // Odd length palindromes (center is s.charAt(i))
            expandAroundCenter(s, i, i);
            // Even length palindromes (center is between s.charAt(i) and s.charAt(i+1))
            expandAroundCenter(s, i, i + 1);
        }
        
        return s.substring(startIdx, startIdx + maxLength);
    }

    private void expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        // The actual palindrome is from s[left+1] to s[right-1]
        // currentLength = (right - 1) - (left + 1) + 1 = right - left - 1;
        int currentLength = right - left - 1;
        if (currentLength > maxLength) {
            maxLength = currentLength;
            startIdx = left + 1; // The start of this palindrome
        }
    }
}
```

**复杂度分析 (中心扩展法):**
*   时间复杂度: O(N^2)。有 `2N-1` 个中心，每个中心扩展最多 O(N) 次。
*   空间复杂度: O(1)。
