### 031: [72. 编辑距离 (Edit Distance)](https://leetcode.cn/problems/edit-distance)

**题目描述:**
给你两个单词 `word1` 和 `word2`， 请返回将 `word1` 转换成 `word2` 所使用的最少操作数 。
你可以对一个单词进行如下三种操作：
1.  插入一个字符
2.  删除一个字符
3.  替换一个字符

**解题思路 (动态规划):**
设 `dp[i][j]` 表示将 `word1` 的前 `i` 个字符 (`word1[0...i-1]`) 转换成 `word2` 的前 `j` 个字符 (`word2[0...j-1]`) 所需的最少操作数。

1.  **初始化:**
    *   `dp = 0` (空串到空串不需要操作)。
    *   `dp[i] = i` (将 `word1` 的前 `i` 个字符转换成空串需要 `i` 次删除操作)。
    *   `dp[j] = j` (将空串转换成 `word2` 的前 `j` 个字符需要 `j` 次插入操作)。

2.  **状态转移方程:**
    对于 `dp[i][j]`，考虑 `word1[i-1]` 和 `word2[j-1]`：
    *   **如果 `word1[i-1] == word2[j-1]`**: 最后一个字符相同，不需要操作，问题规模缩小。
        `dp[i][j] = dp[i-1][j-1]`
    *   **如果 `word1[i-1] != word2[j-1]`**: 需要操作，考虑三种可能：
        a.  **替换**: 将 `word1[i-1]` 替换成 `word2[j-1]`。操作数 = `dp[i-1][j-1] + 1`。
        b.  **删除 (从 word1)**: 将 `word1[i-1]` 删除，然后将 `word1` 的前 `i-1` 个字符转换成 `word2` 的前 `j` 个字符。操作数 = `dp[i-1][j] + 1`。
        c.  **插入 (到 word1 以匹配 word2)**: 在 `word1` 的前 `i` 个字符后插入 `word2[j-1]`，然后将 `word1` 的前 `i` 个字符转换成 `word2` 的前 `j-1` 个字符。操作数 = `dp[i][j-1] + 1`。
        `dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])`

3.  **结果:** 最终答案是 `dp[len(word1)][len(word2)]`。

**Python 实现:**
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word1)
        n = len(word2)

        # dp[i][j] will be the edit distance between word1[:i] and word2[:j]
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # Initialize base cases
        # Cost to convert word1[:i] to empty string is i deletions
        for i in range(m + 1):
            dp[i][0] = i
        # Cost to convert empty string to word2[:j] is j insertions
        for j in range(n + 1):
            dp[0][j] = j

        # Fill dp table
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1] # No operation needed for this char
                else:
                    replace_cost = dp[i-1][j-1]
                    delete_cost = dp[i-1][j]   # Delete from word1
                    insert_cost = dp[i][j-1]   # Insert into word1
                    dp[i][j] = 1 + min(replace_cost, delete_cost, insert_cost)
        
        return dp[m][n]
```

**Java 实现:**```java
class Solution {
public int minDistance(String word1, String word2) {
int m = word1.length();
int n = word2.length();

        // dp[i][j] will be the edit distance between word1.substring(0, i) and word2.substring(0, j)
        int[][] dp = new int[m + 1][n + 1];

        // Initialize base cases
        // Cost to convert word1.substring(0, i) to empty string is i deletions
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        // Cost to convert empty string to word2.substring(0, j) is j insertions
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // Fill dp table
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i-1][j-1]; // No operation needed for this char
                } else {
                    int replaceCost = dp[i-1][j-1];
                    int deleteCost = dp[i-1][j];   // Delete from word1
                    int insertCost = dp[i][j-1];   // Insert into word1
                    dp[i][j] = 1 + Math.min(replaceCost, Math.min(deleteCost, insertCost));
                }
            }
        }
        return dp[m][n];
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 和 N 分别是 `word1` 和 `word2` 的长度。需要填充一个 M*N 大小的 DP 表。
*   空间复杂度: O(M * N)，用于存储 DP 表。可以优化到 O(min(M,N))，因为 `dp[i][j]` 只依赖于 `dp[i-1]` 和 `dp[i]` (或 `dp[j-1]` 和 `dp[j]`)。

### 032: [124. 二叉树中的最大路径和 (Binary Tree Maximum Path Sum)](https://leetcode.cn/problems/binary-tree-maximum-path-sum)

**题目描述:**
**路径** 被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。
**路径和** 是路径中各节点值的总和。
给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

**解题思路 (深度优先搜索/递归):**
对于任何一个节点 `node`，它可以是最大路径的一部分，具体来说：
1.  路径可以穿过 `node`：`node.val + max_gain(node.left) + max_gain(node.right)`。
2.  路径可以在 `node` 的左子树中，且不经过 `node`。
3.  路径可以在 `node` 的右子树中，且不经过 `node`。

为了实现这一点，我们定义一个递归函数 `max_gain(node)`，它返回从 `node` 向下延伸到其子树中能获得的最大单边路径和（即这条路径必须以 `node` 为一个端点，并且只能向下走）。

*   **`max_gain(node)` 的计算:**
    1.  基本情况：如果 `node` 为空，返回 0 (不贡献任何增益)。
    2.  递归计算左子树能提供的最大单边增益：`left_gain = max(0, max_gain(node.left))` (如果子树增益为负，则不取)。
    3.  递归计算右子树能提供的最大单边增益：`right_gain = max(0, max_gain(node.right))`。
    4.  **更新全局最大路径和**:
        *   以当前 `node` 为 "拐点" (最高点) 的路径和是 `node.val + left_gain + right_gain`。
        *   将这个值与全局 `max_path_sum` 比较并更新。
    5.  **返回值**: 当前节点 `node` 能向其父节点提供的最大单边路径和是 `node.val + max(left_gain, right_gain)`。父节点只能选择从当前节点向下的一条路径。

全局 `max_path_sum` 初始化为一个非常小的值 (比如负无穷，或者树中节点的最小值，如果已知范围)。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def __init__(self):
        self.max_path_sum = float('-inf') # Initialize with negative infinity

    def maxPathSum(self, root: TreeNode) -> int:
        self._max_gain(root)
        return self.max_path_sum

    def _max_gain(self, node: TreeNode) -> int:
        """
        Returns the maximum path sum starting from this node and going downwards.
        Also updates the global max_path_sum if a path through this node is larger.
        """
        if not node:
            return 0

        # Recursively get max gain from left and right subtrees
        # If a subtree's gain is negative, we don't include it (hence max(0, ...))
        left_gain = max(0, self._max_gain(node.left))
        right_gain = max(0, self._max_gain(node.right))

        # Calculate the price of the path passing through the current node as the "highest" point
        # This path could be node.val alone, or node.val + left, or node.val + right, 
        # or node.val + left + right
        current_path_through_node = node.val + left_gain + right_gain
        
        # Update global maximum path sum if necessary
        self.max_path_sum = max(self.max_path_sum, current_path_through_node)

        # For recursion upwards: the node can only contribute one branch (left or right) to its parent
        # Or just itself if both children gains are negative.
        return node.val + max(left_gain, right_gain)
```

    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    private int maxPathSumGlobal;

    public int maxPathSum(TreeNode root) {
        maxPathSumGlobal = Integer.MIN_VALUE; // Initialize with a very small number
        maxGain(root);
        return maxPathSumGlobal;
    }

    /**
     * Returns the maximum path sum starting from this node and going downwards.
     * Also updates the global maxPathSumGlobal if a path through this node is larger.
     */
    private int maxGain(TreeNode node) {
        if (node == null) {
            return 0;
        }

        // Recursively get max gain from left and right subtrees
        // If a subtree's gain is negative, we don't include it (hence Math.max(0, ...))
        int leftGain = Math.max(0, maxGain(node.left));
        int rightGain = Math.max(0, maxGain(node.right));

        // Calculate the price of the path passing through the current node as the "highest" point
        int currentPathThroughNode = node.val + leftGain + rightGain;
        
        // Update global maximum path sum if necessary
        maxPathSumGlobal = Math.max(maxPathSumGlobal, currentPathThroughNode);

        // For recursion upwards: the node can only contribute one branch (left or right) to its parent
        // Or just itself if both children gains are negative (already handled by max(0, gain)).
        return node.val + Math.max(leftGain, rightGain);
    }

*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点被访问一次。
*   空间复杂度: O(H)，其中 H 是树的高度。这是递归调用栈的空间。最坏情况下 (链状树) 为 O(N)，最好情况 (完全平衡树) 为 O(log N)。

### 033: [93. 复原IP地址 (Restore IP Addresses)](https://leetcode.cn/problems/restore-ip-addresses)

**题目描述:**
**有效 IP 地址** 正好由四个整数（每个整数位于 `0` 到 `255` 之间组成，且不能含有前导 `0`），整数之间用 `'.'` 分隔。
例如：`"0.1.2.201"` 和 `"192.168.1.1"` 是 **有效** IP 地址，但是 `"0.011.255.245"`、`"192.168.1.312"` 和 `"192.168@1.1"` 是 **无效** IP 地址。
给定一个只包含数字的字符串 `s` ，用以表示一个 IP 地址，返回所有可能的**有效 IP 地址**，这些地址可以通过在 `s` 中插入 `'.'` 来形成。你 **不能** 重新排序或删除 `s` 中的任何数字。你可以按 **任何** 顺序返回答案。

**解题思路 (回溯法):**
我们需要将字符串 `s` 分割成 4 段，每段代表一个 0-255 之间的整数，并且没有多余的前导零 (除非数字本身是 0)。

1.  **定义回溯函数 `backtrack(start_index, num_dots, current_ip_path)`**:
    *   `start_index`: 当前考虑在 `s` 中开始取下一段 IP 的起始索引。
    *   `num_dots`: 已经放置的小数点数量 (也即已形成的 IP 段数 - 1)。
    *   `current_ip_path`: 一个列表，存储当前已经形成的 IP 段。
2.  **基准情况 (Base Case)**:
    *   如果 `num_dots == 3` (已经形成了 3 个点，即 4 段 IP):
        *   取出剩余的字符串作为第四段: `segment = s[start_index:]`。
        *   验证 `segment` 是否有效 (0-255，无非法前导零)。
        *   如果有效，则将 `current_ip_path + [segment]` 拼接成字符串，加入结果列表 `result`。
        *   返回。
    *   如果 `start_index >= len(s)`，说明字符串用完了但 IP 段还没凑够，或者已经凑够了，提前返回。
3.  **递归步骤 (尝试分割)**:
    *   从 `start_index` 开始，尝试取长度为 1、2、3 的子串作为当前 IP 段 `segment`：
        *   循环 `length` from 1 to 3 (或者 `end_index` from `start_index` to `min(start_index + 2, len(s) - 1)`):
            *   `segment = s[start_index : end_index + 1]`
            *   **验证 `segment`**:
                *   长度不能超过3。
                *   不能有非法前导零 (如 "01", "001"，但 "0" 是允许的)。
                *   值必须在 0 到 255 之间。
            *   如果 `segment` 有效：
                a.  **选择**: 将 `segment` 加入 `current_ip_path`。
                b.  **探索**: 递归调用 `backtrack(end_index + 1, num_dots + 1, current_ip_path)`。
                c.  **撤销选择 (回溯)**: 将 `segment` 从 `current_ip_path` 中移除。
    *   注意 `end_index + 1` 不能超过字符串 `s` 的长度。

**Python 实现:**
```python
class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:
        result = []
        n = len(s)

        def is_valid_segment(segment: str) -> bool:
            if not segment:
                return False
            # Check for leading zeros: "0" is ok, "01" is not.
            if len(segment) > 1 and segment[0] == '0':
                return False
            # Check if segment is within 0-255 range
            if not (0 <= int(segment) <= 255):
                return False
            return True

        def backtrack(start_index: int, dots: int, current_path: list[str]):
            # Base case: if we have placed 3 dots (meaning 4 segments)
            # and we have used up the entire string
            if dots == 3:
                segment = s[start_index:]
                if is_valid_segment(segment):
                    result.append(".".join(current_path + [segment]))
                return
            
            # Try segments of length 1, 2, or 3
            # Ensure we don't go out of bounds for segments and leave enough chars for remaining segments
            for length in range(1, 4):
                if start_index + length > n: # Current segment goes out of bounds
                    break
                
                segment = s[start_index : start_index + length]
                
                # Pruning: check if remaining string length is plausible for remaining segments
                remaining_chars = n - (start_index + length)
                remaining_segments = 3 - dots # (4 segments total) - (dots+1 already formed segments)
                
                # Each remaining segment needs at least 1 char, at most 3 chars
                if remaining_chars < remaining_segments * 1 or remaining_chars > remaining_segments * 3:
                    continue

                if is_valid_segment(segment):
                    current_path.append(segment)
                    backtrack(start_index + length, dots + 1, current_path)
                    current_path.pop() # Backtrack

        if n < 4 or n > 12: # IP addresses must be between 4 ("1.1.1.1") and 12 ("255.255.255.255") chars
            return []
            
        backtrack(0, 0, [])
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    List<String> result;
    String sGlobal;
    int nGlobal;

    private boolean isValidSegment(String segment) {
        if (segment.isEmpty() || segment.length() > 3) {
            return false;
        }
        // Check for leading zeros: "0" is ok, "01" is not.
        if (segment.length() > 1 && segment.charAt(0) == '0') {
            return false;
        }
        try {
            int val = Integer.parseInt(segment);
            return val >= 0 && val <= 255;
        } catch (NumberFormatException e) {
            return false; // Should not happen if length <= 3 and only digits
        }
    }

    private void backtrack(int startIndex, int dots, List<String> currentPath) {
        if (dots == 3) { // Placed 3 dots, now form the 4th segment
            String segment = sGlobal.substring(startIndex);
            if (isValidSegment(segment)) {
                currentPath.add(segment);
                result.add(String.join(".", currentPath));
                currentPath.remove(currentPath.size() - 1); // Backtrack for this segment
            }
            return;
        }

        // Try segments of length 1, 2, or 3
        for (int length = 1; length <= 3; length++) {
            if (startIndex + length > nGlobal) { // Current segment goes out of bounds
                break;
            }
            
            String segment = sGlobal.substring(startIndex, startIndex + length);
            
            // Pruning: check if remaining string length is plausible for remaining segments
            int remainingChars = nGlobal - (startIndex + length);
            int remainingSegments = 3 - dots; 
            
            if (remainingChars < remainingSegments * 1 || remainingChars > remainingSegments * 3) {
                continue;
            }

            if (isValidSegment(segment)) {
                currentPath.add(segment);
                backtrack(startIndex + length, dots + 1, currentPath);
                currentPath.remove(currentPath.size() - 1); // Backtrack
            }
        }
    }

    public List<String> restoreIpAddresses(String s) {
        result = new ArrayList<>();
        sGlobal = s;
        nGlobal = s.length();

        if (nGlobal < 4 || nGlobal > 12) {
            return result;
        }
        
        backtrack(0, 0, new ArrayList<>());
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: 虽然有三层循环（外层决定段数，内层决定段长），但由于段长和段数限制，不是简单的 O(N^4)。具体分析比较复杂，但由于 N 最大为 12，段长最大为 3，可能的组合是有限的。对于每个组合，`isValidSegment` 和 `join` 操作也花费少量时间。大致上是一个较小的常数乘以 `N`。可以认为回溯树的节点数是有限的。
*   空间复杂度: O(N) 或 O(1) （因为 N 最大为 12）。主要是递归栈深度（最多4层）和存储 `current_path`（最多4个字符串，总长N）。结果列表不算在内。

### 034: [142. 环形链表 II (Linked List Cycle II)](https://leetcode.cn/problems/linked-list-cycle-ii)

**题目描述:**
给定一个链表的头节点 `head` ，返回链表开始入环的第一个节点。 如果链表无环，则返回 `null`。
如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。
**不允许修改** 链表。

**解题思路 (Floyd's Tortoise and Hare / 双指针):**
此问题分两步：
1.  **检测环是否存在，并找到相遇点**:
    *   使用两个指针，`slow` 和 `fast`，都从 `head` 开始。
    *   `slow` 每次移动一步，`fast` 每次移动两步。
    *   如果链表无环，`fast` 或 `fast.next` 会先到达 `null`。
    *   如果链表有环，`slow` 和 `fast` 最终会在环内相遇。设相遇点为 `meet_node`。

2.  **找到环的入口点**:
    *   当 `slow` 和 `fast` 在 `meet_node` 相遇后：
    *   将一个新指针 `ptr1` 置于 `head`。
    *   将另一个指针 `ptr2` 置于 `meet_node`。
    *   同时以相同的速度 (每次一步) 移动 `ptr1` 和 `ptr2`。
    *   它们相遇的节点就是环的入口点。

**数学证明 (第二步的原理):**
设链表头到环入口的距离为 `a`。
环的长度为 `c`。
`slow` 和 `fast` 在环内相遇，设相遇点距离环入口的距离为 `b`。
当它们相遇时：
`slow` 走过的距离 = `a + b`
`fast` 走过的距离 = `a + b + k*c` (k >= 1, fast 比 slow 多走了 k 圈)
并且，`fast` 走过的距离是 `slow` 的两倍: `2 * (a + b) = a + b + k*c`
简化得: `a + b = k*c`
这意味着 `a = k*c - b`。
`k*c - b` 可以看作：从相遇点 `meet_node` (它在环入口后 b 步) 开始，向前走 `k*c` (回到相遇点)，再后退 `b` 步，就回到了环入口。
或者更直观地：
从相遇点 `meet_node` 走到环入口的距离是 `c - b`。
我们有 `a = k*c - b = (k-1)*c + c - b`。
这表明，从头节点 `head` 走 `a` 步到达环入口，和从相遇点 `meet_node` 开始走 `a` 步 (即 `(k-1)*c + (c-b)` 步，意味着先走 `k-1` 圈回到相遇点，再走 `c-b` 步到环入口) 会在环入口相遇。

**Python 实现:**
```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def detectCycle(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return None

        slow = head
        fast = head
        has_cycle = False

        # Step 1: Detect cycle and find meeting point
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                has_cycle = True
                break
        
        if not has_cycle:
            return None

        # Step 2: Find the entrance of the cycle
        ptr1 = head
        ptr2 = slow # or fast, they are at the same meeting point
        while ptr1 != ptr2:
            ptr1 = ptr1.next
            ptr2 = ptr2.next
            
        return ptr1
```

        boolean hasCycle = false;

        // Step 1: Detect cycle and find meeting point
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                hasCycle = true;
                break;
            }
        }

        if (!hasCycle) {
            return null;
        }

        // Step 2: Find the entrance of the cycle
        ListNode ptr1 = head;
        ListNode ptr2 = slow; // or fast, they are at the same meeting point
        while (ptr1 != ptr2) {
            ptr1 = ptr1.next;
            ptr2 = ptr2.next;
        }
        
        return ptr1;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是链表的节点数。
    *   第一步，`slow` 和 `fast` 最多遍历链表一次 (实际上 `slow` 在环内不会超过一圈，`fast` 不会超过两圈)。
    *   第二步，`ptr1` 和 `ptr2` 最多遍历链表一次 (具体是 `a` 步)。
*   空间复杂度: O(1)，只使用了常数个额外指针。

### 035: [1143. 最长公共子序列 (Longest Common Subsequence)](https://leetcode.cn/problems/longest-common-subsequence)

**题目描述:**
给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在公共子序列，返回 `0` 。
一个字符串的 **子序列** 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。
例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。
两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

**解题思路 (动态规划):**
设 `dp[i][j]` 表示 `text1` 的前 `i` 个字符 (`text1[0...i-1]`) 与 `text2` 的前 `j` 个字符 (`text2[0...j-1]`) 的最长公共子序列的长度。

1.  **初始化:**
    *   DP 表大小为 `(len(text1) + 1) x (len(text2) + 1)`。
    *   `dp[j] = 0` for all `j` (空串与任何串的 LCS 为 0)。
    *   `dp[i] = 0` for all `i` (任何串与空串的 LCS 为 0)。

2.  **状态转移方程:**
    对于 `dp[i][j]`，考虑 `text1[i-1]` 和 `text2[j-1]`：
    *   **如果 `text1[i-1] == text2[j-1]`**: 这两个字符可以作为 LCS 的一部分。
        `dp[i][j] = 1 + dp[i-1][j-1]`
    *   **如果 `text1[i-1] != text2[j-1]`**: 这两个字符至少有一个不能作为当前 LCS 的结尾。
        *   可能 LCS 是 `text1` 的前 `i-1` 个字符与 `text2` 的前 `j` 个字符的 LCS。
        *   或者，LCS 是 `text1` 的前 `i` 个字符与 `text2` 的前 `j-1` 个字符的 LCS。
            `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

3.  **结果:** 最终答案是 `dp[len(text1)][len(text2)]`。

**Python 实现:**
```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)

        # dp[i][j] will be the LCS of text1[:i] and text2[:j]
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # Fill dp table
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = 1 + dp[i-1][j-1]
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        return dp[m][n]
```

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        // dp[i][j] will be the LCS of text1.substring(0,i) and text2.substring(0,j)
        int[][] dp = new int[m + 1][n + 1];

        // Fill dp table (base cases dp[0][j] and dp[i][0] are already 0 by default)
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {

                } else {
                    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
                }
            }
        }
        return dp[m][n];
    }

*   空间复杂度: O(M * N)，用于存储 DP 表。可以优化到 O(min(M,N))。

### 036: [19. 删除链表的倒数第N个节点 (Remove Nth Node From End of List)](https://leetcode.cn/problems/remove-nth-node-from-end-of-list)

**题目描述:**
给你一个链表的头节点 `head` 和一个整数 `n` ，请你将链表的倒数第 `n` 个节点删除，并返回链表的头节点。

**解题思路 (双指针 + 哑节点):**
1.  **哑节点 (Dummy Head)**: 创建一个哑节点 `dummy`，使其 `next` 指向 `head`。这有助于处理删除头节点的情况 (当 `n` 等于链表长度时)。
2.  **快慢指针**:
    *   初始化 `fast` 指针和 `slow` 指针都指向 `dummy`。
    *   首先，让 `fast` 指针向前移动 `n + 1` 步。这样，`fast` 和 `slow` 之间就相隔了 `n` 个节点（如果 `fast` 走了 `n` 步，slow 和 fast 之间有 `n-1` 个节点。我们希望 slow 停在被删除节点的前一个，所以 fast 比 slow 多走 n+1 步，这样 slow.next 就是目标）。
    *   然后，同时移动 `fast` 和 `slow` 指针，每次都移动一步，直到 `fast` 到达链表的末尾 (`fast` 为 `null`)。
    *   此时，`slow` 指针指向的是待删除节点的**前一个**节点。
3.  **删除节点**:
    *   `slow.next = slow.next.next`
4.  返回 `dummy.next` 作为新的头节点。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        dummy = ListNode(0, head)
        slow = dummy
        fast = dummy

        # Move fast pointer n+1 steps ahead
        # The +1 is because we want slow to be at the node *before* the one to be deleted
        for _ in range(n + 1):
            if fast is None: # Should not happen if n is valid and list has at least n nodes
                             # However, if n can be > list length, fast could become None.
                             # LeetCode constraints usually ensure n <= length.
                return head # Or handle error, depends on strict problem constraints.
                           # For typical LeetCode usage, this check might not be strictly necessary for n itself,
                           # but useful for robustness if head can be empty or n too large.
                           # If loop is n+1, we check fast here.
            fast = fast.next

        # Move both pointers until fast reaches the end
        while fast is not None:
            slow = slow.next
            fast = fast.next
        
        # Now slow is pointing to the node just before the Nth node from the end
        # Delete the Nth node from the end
        if slow.next: # Ensure slow.next is not None (e.g. if trying to delete the node after the tail, though problem constraints should prevent this logic)
            slow.next = slow.next.next
            
        return dummy.next

### 037: [82. 删除排序链表中的重复元素 II (Remove Duplicates from Sorted List II)](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii)

**题目描述:**
给定一个已排序的链表的头 `head` ， **删除原始链表中所有重复数字的节点**，只留下不同的数字。返回 已排序的链表 。

**解题思路 (迭代 + 哨兵节点):**
由于可能删除头节点，使用一个哨兵节点 `dummy` 会使代码更简洁。
1.  创建一个 `dummy` 节点，`dummy.next = head`。
2.  使用一个 `current` 指针，初始指向 `dummy`。这个 `current` 指针将始终指向结果链表中最后一个不重复的节点。
3.  遍历链表 (通过 `current.next` 和 `current.next.next` 来判断重复):
    *   当 `current.next` 和 `current.next.next` 都存在时：
        *   **如果 `current.next.val == current.next.next.val`** (发现重复):
            *   记录下重复值 `duplicate_val = current.next.val`。
            *   用一个内部循环跳过所有等于 `duplicate_val` 的节点：
                *   `while current.next and current.next.val == duplicate_val:`
                    *   `current.next = current.next.next`
        *   **如果 `current.next.val != current.next.next.val`** (没有重复，`current.next` 是一个独特的数字):
            *   `current` 指针可以安全地前进到 `current.next`: `current = current.next`。
    *   当 `current.next` 存在但 `current.next.next` 不存在时 (只剩一个节点或者到链表尾部了)，说明没有更多重复项可以比较了，`current.next` 如果存在就是唯一的，直接将 `current` 前进 `current = current.next` 并结束循环，或者如果不再需要处理（`current.next` 是最后一个节点），则 `current` 保持不变。
    *   更简洁的逻辑是：在循环的每一步，检查 `current.next` 后面的节点是否与 `current.next` 重复。

**改进的迭代逻辑:**
1.  `dummy = ListNode(0, head)`
2.  `prev = dummy` (`prev` 始终是已处理好不重复部分的尾巴)
3.  `curr = head`
4.  `while curr:`
    *   `if curr.next and curr.val == curr.next.val:` (发现重复的开始)
        *   `while curr.next and curr.val == curr.next.val:`
            *   `curr = curr.next` (跳过所有重复的)
        *   `// curr 现在是重复序列的最后一个节点`
        *   `prev.next = curr.next` (将 `prev` 连接到重复序列之后的第一个不同节点)
        *   `curr = curr.next` (移动 `curr` 到下一个待检查的节点)
    *   `else:` (当前 `curr` 不重复)
        *   `prev = curr`
        *   `curr = curr.next`
5.  `return dummy.next`

                current = current.next

    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) return null;

        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy; // `prev` tracks the tail of the non-duplicate list.
        ListNode current = head;

        while (current != null) {
            // Check if current node is part of a duplicate sequence
            if (current.next != null && current.val == current.next.val) {
                // Advance current until it's the last node of the duplicate sequence
                while (current.next != null && current.val == current.next.val) {
                    current = current.next;
                }
                // `current` is now the last node of the duplicate sequence.
                // `prev` should skip all these duplicates.
                prev.next = current.next; 
                // Advance `current` to the next distinct node (or null)
                current = current.next;
            } else {
                // `current` node is not a duplicate.
                // Link `prev` to `current` and then advance `prev`.
                // Note: If prev is dummy and current is head (first unique node), prev.next=current happens.
                // If prev was nodeX and current is nodeY (unique), prev.next=current happens.
                prev.next = current; // This might be redundant if it's already linked, but ensures correctness
                prev = current;      // Advance prev to the current unique node
                current = current.next; // Advance current

        }

### 038: [4. 寻找两个正序数组的中位数 (Median of Two Sorted Arrays)](https://leetcode.cn/problems/median-of-two-sorted-arrays)

**题目描述:**
给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。
算法的时间复杂度应该为 O(log (m+n)) 。

**解题思路 (二分查找法):**
这个问题等价于寻找两个排序数组合并后的第 `k` 小的元素。
中位数是第 `(m+n+1)/2` 个元素 (对于奇数总长度) 或第 `(m+n)/2` 和第 `(m+n)/2 + 1` 个元素的平均值 (对于偶数总长度)。

核心是设计一个函数 `findKth(nums1, start1, nums2, start2, k)`，它返回 `nums1` 从 `start1` 开始和 `nums2` 从 `start2` 开始的子数组中合并后的第 `k` 小元素。

1.  **`findKth(arr1, s1, arr2, s2, k)` 逻辑:**
    a.  **确保 arr1 是较短的那个数组** (如果不是，交换它们) 来简化边界。如果 `arr1` 用尽，则第 `k` 小在 `arr2` 中 (`arr2[s2 + k - 1]`)。
    b.  **如果 `k == 1`**: 返回 `min(arr1[s1], arr2[s2])`。
    c.  **二分思想**:
    *   比较 `arr1` 的第 `k/2` 个元素 (`arr1[s1 + k/2 - 1]`) 和 `arr2` 的第 `k/2` 个元素 (`arr2[s2 + k/2 - 1]`)。
    *   取 `p1 = min(k/2, len(arr1)-s1)` 个元素从 `arr1`，索引是 `idx1 = s1 + p1 - 1`。
    *   取 `p2 = k - p1` (或者 `min(k/2, len(arr2)-s2)` and adjust `k`) 个元素从 `arr2`，索引是 `idx2 = s2 + p2 - 1`。
    *   (实际上，通常比较 `arr1[s1 + k/2 - 1]` 和 `arr2[s2 + k/2 - 1]`)
    *   设比较的两个元素为 `pivot1 = arr1[s1 + k/2 - 1]` 和 `pivot2 = arr2[s2 + k/2 - 1]` (注意边界，如果 `k/2` 超出某个数组的剩余长度，则取该数组剩余所有元素中的最后一个)。
    *   **如果 `pivot1 <= pivot2`**: 这意味着 `arr1` 中 `s1` 到 `s1 + k/2 - 1` 之间的所有元素 (共 `k/2` 个) 都不可能是第 `k` 小的元素。因为即使 `pivot2` 是第 `k` 小的，`arr1` 的这些元素也都小于等于它。所以可以安全地排除 `arr1` 的这前 `k/2` 个元素。
    *   递归调用 `findKth(arr1, s1 + k/2, arr2, s2, k - k/2)`。
    *   **如果 `pivot1 > pivot2`**: 同理，排除 `arr2` 的前 `k/2` 个元素。
    *   递归调用 `findKth(arr1, s1, arr2, s2 + k/2, k - k/2)`。

2.  **计算中位数:**
    *   `total_length = m + n`
    *   `if total_length is odd`: `median = findKth(nums1, 0, nums2, 0, total_length/2 + 1)`
    *   `if total_length is even`:
        *   `left_median = findKth(nums1, 0, nums2, 0, total_length/2)`
        *   `right_median = findKth(nums1, 0, nums2, 0, total_length/2 + 1)`
        *   `median = (left_median + right_median) / 2.0`

**Python 实现:**
```python
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        m, n = len(nums1), len(nums2)
        total_length = m + n

        def findKth(arr1, start1, len1, arr2, start2, len2, k):
            # Make arr1 the shorter array to handle base cases easier
            if len1 > len2:
                return findKth(arr2, start2, len2, arr1, start1, len1, k)
            
            # Base cases for findKth
            if len1 == 0: # arr1 is exhausted
                return arr2[start2 + k - 1]
            if k == 1: # The smallest element from the current view of arr1 and arr2
                return min(arr1[start1], arr2[start2])

            # Partition k into two parts for arr1 and arr2
            # i is number of elements to take from arr1 (1-based for k/2 concept)
            # j is number of elements to take from arr2
            i = min(k // 2, len1) 
            j = k - i 
            # Using (k//2) may lead to issues if j becomes > len2. 
            # Better to define i and j carefully, for example, 
            # i = min(k//2, len1) and j = min(k-i, len2) BUT k must then be updated using elements *discarded*.

            # A common way: compare elements at k/2 - 1 from respective starts.
            # Careful with indices: we compare arr1[start1 + i -1] and arr2[start2 + j - 1]
            # where i and j are *counts* of elements being considered.
            
            # Elements to compare (potential pivots)
            # Index is start + num_elements_before_it_in_current_segment
            idx1_comp = start1 + i - 1
            idx2_comp = start2 + j - 1
            
            pivot1 = arr1[idx1_comp]
            pivot2 = arr2[idx2_comp]

            if pivot1 <= pivot2:
                # arr1[start1 ... idx1_comp] are all <= pivot2.
                # These 'i' elements from arr1 can be discarded.
                # New k = k - i
                return findKth(arr1, start1 + i, len1 - i, arr2, start2, len2, k - i)
            else: # pivot1 > pivot2
                # arr2[start2 ... idx2_comp] are all < pivot1.
                # These 'j' elements from arr2 can be discarded.
                # New k = k - j
                return findKth(arr1, start1, len1, arr2, start2 + j, len2 - j, k - j)

        if total_length % 2 == 1:
            # Odd total length, median is the middle element
            return float(findKth(nums1, 0, m, nums2, 0, n, total_length // 2 + 1))
        else:
            # Even total length, median is avg of two middle elements
            k1 = total_length // 2
            k2 = total_length // 2 + 1
            median1 = findKth(nums1, 0, m, nums2, 0, n, k1)
            median2 = findKth(nums1, 0, m, nums2, 0, n, k2)
            return (median1 + median2) / 2.0

```

**Java 实现:**
```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length;
        int n = nums2.length;
        int totalLength = m + n;

        if (totalLength % 2 == 1) {
            // Odd total length
            return findKth(nums1, 0, m, nums2, 0, n, totalLength / 2 + 1);
        } else {
            // Even total length
            double median1 = findKth(nums1, 0, m, nums2, 0, n, totalLength / 2);
            double median2 = findKth(nums1, 0, m, nums2, 0, n, totalLength / 2 + 1);
            return (median1 + median2) / 2.0;
        }
    }

    // Finds the k-th smallest element (1-indexed k) in the combined sorted arrays
    // considering nums1 from index start1 with len1 elements, and nums2 from start2 with len2 elements.
    private double findKth(int[] nums1, int start1, int len1, int[] nums2, int start2, int len2, int k) {
        // Ensure nums1 is the shorter array (or remaining part of it)
        if (len1 > len2) {
            return findKth(nums2, start2, len2, nums1, start1, len1, k);
        }

        // Base cases
        if (len1 == 0) { // nums1 is exhausted
            return nums2[start2 + k - 1];
        }
        if (k == 1) { // The smallest element from the current view of nums1 and nums2
            return Math.min(nums1[start1], nums2[start2]);
        }

        // Number of elements to consider from nums1.
        // This is effectively k/2 elements, but capped by len1.
        int i = Math.min(k / 2, len1); 
        // Number of elements to consider from nums2.
        // This takes the rest of k, capped by len2. Note k must be sum of these.
        int j = k - i; // Since k must be found, and we commit 'i' from nums1.
                       // This 'j' is number of elements that *would* be considered from nums2
                       // to fulfill the `k/2` partitioning idea alongside `i` from nums1.
                       // The actual number of elements considered from nums2 for comparison is Math.min(j, len2) if `j` was `k/2`.
                       // The `k-i` for `j` is crucial for correct k update.

        // Indices of elements to compare (0-based for array access)
        // pivot1 is the (i)-th element from nums1[start1...]
        // pivot2 is the (j)-th element from nums2[start2...]
        int pivot1 = nums1[start1 + i - 1];
        int pivot2 = nums2[start2 + j - 1]; // Note: If j > len2, this fails. Ensure j is capped by len2 too initially?
                                          // No, the current formulation ensures i + j = k.
                                          // If i=len1 (nums1 shorter), then j = k - len1.
                                          // If k-len1 > len2 means k > len1+len2, impossible if k is valid.

        if (pivot1 <= pivot2) {
            // nums1[start1 ... start1 + i - 1] are all <= pivot2.
            // These 'i' elements from nums1 can be discarded.
            // New k = k - i (we are looking for the (k-i)-th element in the rest)
            return findKth(nums1, start1 + i, len1 - i, nums2, start2, len2, k - i);
        } else { // pivot1 > pivot2
            // nums2[start2 ... start2 + j - 1] are all < pivot1.
            // These 'j' elements from nums2 can be discarded.
            // New k = k - j
            return findKth(nums1, start1, len1, nums2, start2 + j, len2 - j, k - j);
        }
    }
}
```
There's a slight nuance in partition choice `i` and `j` to ensure they are valid and `j` isn't too large. A standard choice is: `i = min(len1, k/2)` and `j = min(len2, k/2)`. Then if `arr1[s1+i-1] < arr2[s2+j-1]`, we discard `i` elements from `arr1` and update `k` to `k-i`. This ensures `j` isn't larger than remaining length of `arr2`.
My current formulation with `i = min(k/2, len1)` and `j = k-i` should also be correct for `k` update. The key is that `k` gets reduced by the number of elements *actually discarded*.

**Complexity Analysis:**
*   时间复杂度: O(log(M+N)) or O(log(min(M,N))) depending on partition strategy. In each step of `findKth`, we reduce `k` by roughly `k/2`, leading to a logarithmic number of calls.
*   空间复杂度: O(log(M+N)) or O(log(min(M,N))) due to recursion stack. Can be made O(1) with iterative binary search.

This specific `findKth` approach might be O(log K) where K is initially M+N, which is O(log(M+N)).
The partitioning strategy by picking fixed proportion (like k/2) of k elements and discarding one part usually leads to log(k) which becomes log(m+n).

A different popular binary search directly tries to find the partition point in one array (say `nums1`) such that it splits the combined `m+n` elements into two equal halves.
The `i`-th partition in `nums1` and `j`-th in `nums2` are such that `i+j = (m+n)/2`. Binary search for `i`. This gives O(log(min(M,N))).

### 039: [94. 二叉树的中序遍历 (Binary Tree Inorder Traversal)](https://leetcode.cn/problems/binary-tree-inorder-traversal)

**题目描述:**
给定一个二叉树的根节点 `root` ，返回 **中序遍历** 结果。

**解题思路:**
**中序遍历顺序: 左子树 -> 根节点 -> 右子树**

1.  **递归法 (很简单):**
    *   定义 `inorder(node, result_list)`:
        *   如果 `node` 为空，返回。
        *   递归调用 `inorder(node.left, result_list)`。
        *   将 `node.val` 加入 `result_list`。
        *   递归调用 `inorder(node.right, result_list)`。

2.  **迭代法 (使用栈):**
    *   初始化一个空栈 `stack` 和一个空的结果列表 `result_list`。
    *   设置 `current_node = root`。
    *   循环条件: `while current_node or stack:` (当当前节点不为空或栈不为空时)
        *   **第一阶段 (向左下走，并入栈):**
            *   `while current_node:`
                *   将 `current_node` 压入栈中。
                *   `current_node = current_node.left` (继续向左)。
        *   **第二阶段 (节点出栈，访问，转向右子树):**
            *   `current_node = stack.pop()` (栈顶元素是当前子树中最左的、尚未访问的节点)。
            *   将 `current_node.val` 加入 `result_list`。
            *   `current_node = current_node.right` (转向该节点的右子树，开始下一轮的向左下)。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    # Recursive solution
    def inorderTraversalRecursive(self, root: TreeNode) -> list[int]:
        result = []
        self._inorder_helper(root, result)
        return result

    def _inorder_helper(self, node: TreeNode, result: list[int]):
        if not node:
            return
        self._inorder_helper(node.left, result)
        result.append(node.val)
        self._inorder_helper(node.right, result)

    # Iterative solution (default for the method name)
    def inorderTraversal(self, root: TreeNode) -> list[int]:
        result = []
        stack = []
        current_node = root

        while current_node or stack:
            # Traverse to the leftmost node of the current subtree
            while current_node:
                stack.append(current_node)
                current_node = current_node.left
            
            # current_node is None here, pop from stack
            # This is the node to be "visited"
            current_node = stack.pop()
            result.append(current_node.val)
            
            # Move to the right subtree
            current_node = current_node.right
            
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Stack;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    // Recursive solution
    public List<Integer> inorderTraversalRecursive(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        inorderHelper(root, result);
        return result;
    }

    private void inorderHelper(TreeNode node, List<Integer> result) {
        if (node == null) {
            return;
        }
        inorderHelper(node.left, result);
        result.add(node.val);
        inorderHelper(node.right, result);
    }
    
    // Iterative solution (default for the method name)
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        TreeNode currentNode = root;

        while (currentNode != null || !stack.isEmpty()) {
            // Traverse to the leftmost node of the current subtree
            while (currentNode != null) {
                stack.push(currentNode);
                currentNode = currentNode.left;
            }
            
            // currentNode is null here, pop from stack
            // This is the node to be "visited"
            currentNode = stack.pop();
            result.add(currentNode.val);
            
            // Move to the right subtree
            currentNode = currentNode.right;
        }
        return result;
    }
}
```

*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点被访问一次。
*   空间复杂度:
    *   递归法: O(H)，其中 H 是树的高度，用于递归调用栈。最坏 O(N)，平均 O(log N)。
    *   迭代法: O(H)，用于栈。最坏 O(N)，平均 O(log N)。

### 040: [199. 二叉树的右视图 (Binary Tree Right Side View)](https://leetcode.cn/problems/binary-tree-right-side-view)

**题目描述:**
给定一个二叉树的 **根节点** `root`，想象自己站在它的 **右侧** ，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**解题思路:**
1.  **广度优先搜索 (BFS) / 层序遍历:**
    *   进行层序遍历。
    *   对于每一层，该层最右边的节点就是从右侧能看到的节点。
    *   在层序遍历中，每一层最后一个被访问 (出队) 的节点就是该层的最右节点。
    *   将每层最右节点的 `val` 加入结果列表。

2.  **深度优先搜索 (DFS) / 改变遍历顺序 (根 -> 右 -> 左):**
    *   定义 `dfs(node, level, result_list)`:
    *   **巧妙之处:** 如果我们保证先访问右子树，那么对于每一层 (level)，我们遇到的第一个节点就是该层的最右节点。
    *   **逻辑:**
        *   如果 `node` 为空，返回。
        *   **检查是否是该层第一个访问的节点**: 如果 `level == len(result_list)`，说明这是第一次到达 `level` 这一层，当前 `node` 是该层的最右节点 (因为我们先访问右边)。将其 `node.val` 加入 `result_list`。
        *   递归调用 `dfs(node.right, level + 1, result_list)` (先右)。
        *   递归调用 `dfs(node.left, level + 1, result_list)` (后左)。

    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            TreeNode rightmostNodeThisLevel = null;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                // The current node is the rightmost for this iteration
                rightmostNodeThisLevel = node; 
                
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            // After iterating through all nodes of the level,
            // rightmostNodeThisLevel holds the last node processed, which is the rightmost.
            if (rightmostNodeThisLevel != null) { // Should always be true if levelSize > 0
                 result.add(rightmostNodeThisLevel.val);
            }
        }
        return result;
    }

**复杂度分析:**
*   **BFS:**
    *   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点访问一次。
    *   空间复杂度: O(W)，其中 W 是树的最大宽度 (用于队列)。
*   **DFS (根-右-左):**
    *   时间复杂度: O(N)。
    *   空间复杂度: O(H)，其中 H 是树的高度 (用于递归栈)。最坏 O(N)，平均 O(log N)。
