### 061: [155. 最小栈 (Min Stack)](https://leetcode.cn/problems/min-stack)

**题目描述:**
设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。
实现 `MinStack` 类:
*   `MinStack()` 初始化堆栈对象。
*   `void push(int val)` 将元素 `val` 推入堆栈。
*   `void pop()` 删除堆栈顶部的元素。
*   `int top()` 获取堆栈顶部的元素。
*   `int getMin()` 获取堆栈中的最小元素。
    每个函数操作的时间复杂度应该为 O(1)。

**解题思路:**
**方法1: 使用两个栈**
1.  一个主栈 `data_stack`，用于存储所有元素，执行常规的栈操作。
2.  一个辅助栈 `min_stack`，其栈顶始终存储 `data_stack` 中当前所有元素的最小值。
    *   `push(val)`: 将 `val` 压入 `data_stack`。如果 `min_stack` 为空，或 `val <= min_stack.peek()`，则也将 `val` 压入 `min_stack`。
    *   `pop()`: 从 `data_stack` 弹出元素 `popped_val`。如果 `popped_val` 等于 `min_stack.peek()`，则也从 `min_stack` 弹出。
    *   `top()`: 返回 `data_stack.peek()`。
    *   `getMin()`: 返回 `min_stack.peek()`。

**方法2: 在主栈中存储 (值, 当前最小值) 对 (Pythonic tuple approach)**
* 栈中每个元素是一个元组 `(value, current_minimum_when_this_value_was_pushed)`。
* `push(val)`: 如果栈为空，`current_min = val`。否则，`current_min = min(val, stack.top().current_minimum)`。压入 `(val, current_min)`。
* `pop()`: 弹出栈顶元组。
* `top()`: 返回栈顶元组的 `value` 部分。
* `getMin()`: 返回栈顶元组的 `current_minimum` 部分。

方法1 (two stacks) is generally preferred in Java for clarity with separate stack objects. Method 2 (or a variation) is also good. Let's use method 1, modified slightly for push.

**Modified Method 1 Logic for `push` on `min_stack`:**
When pushing `val` to `data_stack`:
*   If `min_stack` is empty, push `val` to `min_stack`.
*   Else, push `min(val, min_stack.peek())` to `min_stack`.
    This ensures `min_stack` always has the same number of elements as `data_stack`, and `min_stack.peek()` is the minimum up to that point in `data_stack`.
    When `pop()`: always pop from both `data_stack` and `min_stack`.

Let's go with the initially described "two stacks" Method 1 as it's more space efficient if min doesn't change often.

**Python 实现 (Method 1):**
```python
class MinStack:
    def __init__(self):
        self.data_stack = []
        self.min_stack = [] # Stores the minimums

    def push(self, val: int) -> None:
        self.data_stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        if self.data_stack:
            popped_val = self.data_stack.pop()
            if self.min_stack and popped_val == self.min_stack[-1]:
                self.min_stack.pop()

    def top(self) -> int:
        if self.data_stack:
            return self.data_stack[-1]
        return None # Or raise error

    def getMin(self) -> int:
        if self.min_stack:
            return self.min_stack[-1]
        return None # Or raise error
```

**Java 实现 (Method 1):**
```java
import java.util.Stack;

class MinStack {
    private Stack<Integer> dataStack;
    private Stack<Integer> minStack; // Stores the minimums

    public MinStack() {
        dataStack = new Stack<>();
        minStack = new Stack<>();
    }
    
    public void push(int val) {
        dataStack.push(val);
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }
    
    public void pop() {
        if (!dataStack.isEmpty()) {
            int poppedVal = dataStack.pop();
            // If the popped value is the current minimum, pop from minStack as well
            if (!minStack.isEmpty() && poppedVal == minStack.peek()) {
                minStack.pop();
            }
        }
    }
    
    public int top() {
        if (!dataStack.isEmpty()) {
            return dataStack.peek();
        }
        throw new RuntimeException("Stack is empty"); // Or return a specific value / handle as per problem spec
    }
    
    public int getMin() {
        if (!minStack.isEmpty()) {
            return minStack.peek();
        }
        throw new RuntimeException("Stack is empty"); // Or return a specific value
    }
}
```

**复杂度分析:**
*   时间复杂度: `push`, `pop`, `top`, `getMin` 都是 O(1)。
*   空间复杂度: O(N) in the worst case (e.g., pushing decreasing numbers means `min_stack` stores N elements).

**题目描述:**
给你一个二叉树的根节点 `root` ，树中每个节点都存放有一个 0 到 9 之间的数字。
每条从根节点到叶节点的路径都代表一个数字：例如，从根到叶节点路径 `1 -> 2 -> 3` 表示数字 `123` 。

    b.  计算到达当前节点 `node` 所形成的数字: `num_so_far = current_path_sum * 10 + node.val`。

    *   如果 `node.left` 不为空，调用 `dfs(node.left, num_so_far)`。
    *   如果 `node.right` 不为空，调用 `dfs(node.right, num_so_far)`。

### 063: [101. 对称二叉树 (Symmetric Tree)](https://leetcode.cn/problems/symmetric-tree)

**题目描述:**
给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

**解题思路:**
**递归法:**
1.  如果 `root` 为空，它是对称的。
2.  否则，检查 `root.left` 和 `root.right` 是否是彼此的镜像。
3.  定义一个辅助函数 `isMirror(tree1_node, tree2_node)`：
    a.  **基准情况:**
    *   如果 `tree1_node` 和 `tree2_node`都为空，它们是镜像，返回 `true`。
    *   如果其中一个为空而另一个不为空，它们不是镜像，返回 `false`。
    *   如果 `tree1_node.val != tree2_node.val`，它们不是镜像，返回 `false`。
    b.  **递归步骤:**
    *   检查 `tree1_node.left` 与 `tree2_node.right` 是否是镜像。
    *   检查 `tree1_node.right` 与 `tree2_node.left` 是否是镜像。
    *   只有当以上两者都为镜像时，`tree1_node` 和 `tree2_node` 才互为镜像。
    `return isMirror(tree1_node.left, tree2_node.right) && isMirror(tree1_node.right, tree2_node.left)`

**迭代法 (使用队列/BFS):**
1.  如果 `root` 为空，返回 `true`。
2.  创建一个队列，并将 `root.left` 和 `root.right` 成对加入。
3.  当队列不为空时：
    a.  从队列中弹出两个节点 `node1` 和 `node2`。
    b.  如果 `node1` 和 `node2` 都为空，继续。
    c.  如果一个为空而另一个不为空，或者 `node1.val != node2.val`，返回 `false`。
    d.  将子节点按镜像顺序成对加入队列: `node1.left`, `node2.right`, `node1.right`, `node2.left`。
4.  如果队列为空且未返回 `false`，则树是对称的，返回 `true`。

**Python 实现 (递归法):**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSymmetric(self, root: TreeNode) -> bool:
        if not root:
            return True
        
        return self.isMirror(root.left, root.right)

    def isMirror(self, node1: TreeNode, node2: TreeNode) -> bool:
        # Both are None, considered mirror images
        if not node1 and not node2:
            return True
        # One is None, the other is not, not mirror images
        if not node1 or not node2:
            return False
        # Values are different, not mirror images
        if node1.val != node2.val:
            return False
        
        # Check if (node1.left is mirror of node2.right) AND 
        # (node1.right is mirror of node2.left)
        return self.isMirror(node1.left, node2.right) and \
               self.isMirror(node1.right, node2.left)
```

```java
        }
```

### 064: [104. 二叉树的最大深度 (Maximum Depth of Binary Tree)](https://leetcode.cn/problems/maximum-depth-of-binary-tree)

**题目描述:**
给定一个二叉树，找出其最大深度。
二叉树的深度为根节点到最远叶子节点的最长路径上的节点数。
**说明:** 叶子节点是指没有子节点的节点。

**解题思路 (DFS / 递归):**
1.  **基准情况:** 如果 `root` 为空，则其深度为 0。
2.  **递归步骤:** 如果 `root` 不为空，则其深度为 `1` (当前节点) 加上其左右子树中较大的那个深度。
    `maxDepth(root) = 1 + max(maxDepth(root.left), maxDepth(root.right))`

**迭代法 (BFS):**
1.  使用队列进行层序遍历。
2.  记录遍历的层数 `depth`。每处理完一层，`depth++`。
3.  最终的 `depth` 即为最大深度。

**Python 实现 (递归法):**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0
        
        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)
        
        return 1 + max(left_depth, right_depth)
```

### 065: [34. 在排序数组中查找元素的第一个和最后一个位置 (Find First and Last Position of Element in Sorted Array)](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array)

**题目描述:**
给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。
如果数组中不存在目标值 `target`，返回 `[-1, -1]`。
你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**解题思路:**
使用两次二分查找。
1.  **查找第一个位置 (Leftmost Boundary):**
    *   编写一个二分查找函数，当 `nums[mid] == target` 时，我们尝试在左半部分 (`high = mid - 1`) 继续查找，同时记录 `mid` 为一个潜在的起始位置。
    *   如果 `nums[mid] < target`，则 `low = mid + 1`。
    *   如果 `nums[mid] > target`，则 `high = mid - 1`。
2.  **查找最后一个位置 (Rightmost Boundary):**
    *   编写另一个二分查找函数，当 `nums[mid] == target` 时，我们尝试在右半部分 (`low = mid + 1`) 继续查找，同时记录 `mid` 为一个潜在的结束位置。
    *   如果 `nums[mid] < target`，则 `low = mid + 1`。
    *   如果 `nums[mid] > target`，则 `high = mid - 1`。
3.  如果第一次查找没有找到 `target` (起始位置为 -1)，则可以直接返回 `[-1, -1]`。否则，进行第二次查找。

**Python 实现:**
```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        
        def find_boundary(is_first: bool) -> int:
            low, high = 0, len(nums) - 1
            ans = -1
            while low <= high:
                mid = low + (high - low) // 2
                if nums[mid] == target:
                    ans = mid # Found a potential answer
                    if is_first:
                        high = mid - 1 # Try to find an earlier one
                    else:
                        low = mid + 1  # Try to find a later one
                elif nums[mid] < target:
                    low = mid + 1
                else: # nums[mid] > target
                    high = mid - 1
            return ans

        first_pos = find_boundary(True)
        
        if first_pos == -1: # Target not found at all
            return [-1, -1]
            
        last_pos = find_boundary(False)
        
        return [first_pos, last_pos]

```

```java
        }
```

### 066: [144. 二叉树的前序遍历 (Binary Tree Preorder Traversal)](https://leetcode.cn/problems/binary-tree-preorder-traversal)

**题目描述:**
给你二叉树的根节点 `root` ，返回它节点值的 **前序** 遍历。 (顺序：根节点 -> 左子树 -> 右子树)

**解题思路:**
**递归法:**
1.  如果 `root` 为空，返回。
2.  将 `root.val` 添加到结果列表中。
3.  递归调用前序遍历函数处理 `root.left`。
4.  递归调用前序遍历函数处理 `root.right`。

**迭代法 (使用栈):**
1.  初始化一个空栈和一个空的结果列表 `result`。
2.  如果 `root` 为空，直接返回 `result`。
3.  将 `root` 压入栈中。
4.  当栈不为空时，循环：
    a.  从栈中弹出一个节点 `node`。
    b.  将 `node.val` 加入 `result`。
    c.  如果 `node.right` 不为空，将其压入栈中 (先压右子节点)。
    d.  如果 `node.left` 不为空，将其压入栈中 (后压左子节点，这样左子节点会先被处理)。
5.  返回 `result`。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        result = []
        stack = [root]
        
        while stack:
            node = stack.pop()
            result.append(node.val)
            
            # Push right child first so that left child is processed first (LIFO)
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
                
        return result
```

```java
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            
            // Push right child first so that left child is processed first (LIFO)
            if (node.right != null) {
                stack.push(node.right);
            }
            if (node.left != null) {
                stack.push(node.left);
            }
        }
        return result;
    }
}
```

### 067: [39. 组合总和 (Combination Sum)](https://leetcode.cn/problems/combination-sum)

**题目描述:**
给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 **不同组合** 。解集不能包含重复的组合。你可以按任意顺序返回组合。
`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。
对于给定的输入，保证和为 `target` 的不同组合数少于 150 个。

**解题思路 (回溯法):**
1.  对 `candidates` 数组进行排序（可选，但有助于剪枝和生成有序组合，如果需要）。
2.  定义一个递归回溯函数 `backtrack(current_combination, remaining_target, start_index)`:
    *   `current_combination`: 当前已选择的数字列表。
    *   `remaining_target`: 还需要凑足的目标和。
    *   `start_index`: 为了避免重复组合 (如 `` 和 `` 算作一种) 并且允许元素重复使用，本次迭代从 `candidates[start_index]` 开始选择。
3.  **基准情况:**
    *   如果 `remaining_target == 0`: 找到了一个有效组合，将 `current_combination` 的一个副本加入结果列表。
    *   如果 `remaining_target < 0`: 当前路径无效，返回。
4.  **递归步骤:**
    *   从 `i = start_index` 到 `len(candidates) - 1` 遍历 `candidates`:
        a.  **选择**: 将 `candidates[i]` 加入 `current_combination`。
        b.  **探索**: 递归调用 `backtrack(current_combination, remaining_target - candidates[i], i)`。注意，第三个参数仍然是 `i`，因为同一个数字可以重复使用。
        c.  **撤销选择 (回溯)**: 将 `candidates[i]` 从 `current_combination` 中移除。
5.  主函数初始化结果列表，调用 `backtrack([], target, 0)`。

**Python 实现:**
```python
from typing import List

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        result = []
        current_combination = []
        # candidates.sort() # Optional: useful if need to prune (e.g., if candidate > remaining_target after sorting)

        def backtrack(remaining_target: int, start_index: int):
            if remaining_target == 0:
                result.append(list(current_combination)) # Add a copy
                return
            if remaining_target < 0:
                return

            for i in range(start_index, len(candidates)):
                candidate = candidates[i]
                
                # Choose
                current_combination.append(candidate)
                # Explore (pass 'i' to allow reuse of the same element)
                backtrack(remaining_target - candidate, i) 
                # Unchoose (backtrack)
                current_combination.pop()
        
        backtrack(target, 0)
        return result
```

**Java 实现:**

```java
                           int remainingTarget, 
                           int startIndex, 
                           List<Integer> currentCombination, 
                           List<List<Integer>> result) {

            result.add(new ArrayList<>(currentCombination)); // Add a copy
            return;

            return;
        }

        for (int i = startIndex; i < candidates.length; i++) {
```

*   时间复杂度: O(N^(T/M + 1)), where N is number of candidates, T is target, M is minimum value in candidates. This is a loose upper bound. The number of recursive calls can be large. Given "guarantee ...组合数少于 150 个", specific performance depends heavily on constraints not fully captured by a simple formula. The number of nodes in the recursion tree can be very large. For each combination of length k, it takes O(k) to copy.
*   空间复杂度: O(T/M) for the recursion stack depth in the worst case, and O(k_max) for `current_combination` storage where k_max is max length of a combination. The result storage itself is separate.

### 068: [394. 字符串解码 (Decode String)](https://leetcode.cn/problems/decode-string)

**题目描述:**
给定一个经过编码的字符串，返回它解码后的字符串。
编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。
你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。
此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2` 的输入。

**解题思路 (使用双栈):**
1.  初始化两个栈：`count_stack` (用于存储重复次数 `k`) 和 `string_stack` (用于存储在遇到 `[` 前已经解码的字符串部分)。
2.  初始化 `current_string_builder` (用于构建当前 `[` 和 `]` 之间的字符串) 和 `current_num = 0` (用于解析多位数的 `k`)。
3.  遍历输入字符串 `s` 中的每个字符 `char`:
    *   如果 `char` 是数字: `current_num = current_num * 10 + int(char)`。
    *   如果 `char == '['`:
        *   将 `current_num` 压入 `count_stack`。
        *   重置 `current_num = 0`。
        *   将 `current_string_builder` 的内容压入 `string_stack`。
        *   重置 `current_string_builder` 为空。
    *   如果 `char == ']`:
        *   从 `count_stack` 弹出重复次数 `repeat_count`。
        *   从 `string_stack` 弹出上一层的字符串 `prev_string`。
        *   将 `current_string_builder` 的内容重复 `repeat_count` 次，然后将其拼接到 `prev_string` 后面，更新 `current_string_builder` 为这个新的拼接结果。
            `decoded_segment = current_string_builder.toString()`
            `repeated_segment = decoded_segment repeated repeat_count times`
            `current_string_builder = new StringBuilder(prev_string).append(repeated_segment)`
    *   如果 `char` 是字母: 将 `char` 追加到 `current_string_builder`。
4.  最终 `current_string_builder` 中的内容即为解码后的完整字符串。

**Python 实现:**
```python
class Solution:
    def decodeString(self, s: str) -> str:
        count_stack = []    # Stack for numbers (k)
        string_stack = []   # Stack for string segments before a '['
        current_string = "" # Current segment being built
        current_num = 0     # Current number k being parsed

        for char in s:
            if char.isdigit():
                current_num = current_num * 10 + int(char)
            elif char == '[':
                # Push the current number and string segment onto stacks
                count_stack.append(current_num)
                string_stack.append(current_string)
                # Reset for the new segment
                current_num = 0
                current_string = ""
            elif char == ']':
                # Pop the count and the previous string segment
                repeat_count = count_stack.pop()
                prev_string = string_stack.pop()
                # Decode: prev_string + current_string * repeat_count
                current_string = prev_string + current_string * repeat_count
            else: # char is a letter
                current_string += char
                
        return current_string
```

**Java 实现:**
```java
import java.util.Stack;

class Solution {
    public String decodeString(String s) {
        Stack<Integer> countStack = new Stack<>();    // Stack for numbers (k)
        Stack<StringBuilder> stringStack = new Stack<>(); // Stack for string segments
        
        StringBuilder currentString = new StringBuilder();
        int currentNum = 0;

        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                currentNum = currentNum * 10 + (ch - '0');
            } else if (ch == '[') {
                // Push current number and current string onto stacks
                countStack.push(currentNum);
                stringStack.push(currentString);
                // Reset for the new segment
                currentNum = 0;
                currentString = new StringBuilder();
            } else if (ch == ']') {
                // Pop the count and the previous string builder
                int repeatCount = countStack.pop();
                StringBuilder prevString = stringStack.pop(); // This is the string builder from outer scope
                
                // Repeat currentString 'repeatCount' times
                StringBuilder temp = new StringBuilder();
                for (int i = 0; i < repeatCount; i++) {
                    temp.append(currentString);
                }
                // Append the repeated segment to the previous string
                currentString = prevString.append(temp);
            } else { // ch is a letter
                currentString.append(ch);
            }
        }
        return currentString.toString();
    }
}
```

**复杂度分析:**
*   时间复杂度: O(L_max * K_max + S_len), where S_len is the length of the input string. The decoded string can be very long. L_max is the maximum length of a decoded segment inside brackets, K_max is the maximum repeat count. Each character of input is processed. String concatenations/building can be dominant if decoded string is large. Roughly, proportional to the length of the output string.
*   空间复杂度: O(D + L_out_at_max_depth), where D is maximum nesting depth of brackets (for stacks), L_out_at_max_depth is max length of string accumulated on stack at deepest level. Roughly, proportional to maximum nesting depth times average string length stored, plus the output string itself.

### 069: [110. 平衡二叉树 (Balanced Binary Tree)](https://leetcode.cn/problems/balanced-binary-tree)

**题目描述:**
给定一个二叉树，判断它是否是高度平衡的。
对于此问题，一棵高度平衡二叉树定义为：一个二叉树**每个节点** 的左右两个子树的高度差的绝对值不超过 1 。

**解题思路 (DFS / 递归 - 后序遍历优化):**
可以采用“自底向上”的递归方法。
1.  定义一个辅助函数 `getHeight(node)`，该函数返回节点 `node` 的高度。
    *   如果 `node` 使得树不平衡，则 `getHeight` 可以返回一个特殊值 (例如 -1) 来表示不平衡。
2.  `getHeight(node)` 逻辑:
    a.  **基准情况:** 如果 `node` 为空，其高度为 0 (代表平衡)。
    b.  **递归调用:**
    *   `left_height = getHeight(node.left)`
    *   如果 `left_height == -1` (左子树已不平衡)，则当前子树也不平衡，直接返回 -1。
    *   `right_height = getHeight(node.right)`
    *   如果 `right_height == -1` (右子树已不平衡)，则当前子树也不平衡，直接返回 -1。
    c.  **检查当前节点平衡性:**
    *   如果 `abs(left_height - right_height) > 1`，则以 `node` 为根的子树不平衡，返回 -1。
    d.  **返回高度:** 如果平衡，返回 `1 + max(left_height, right_height)`。
3.  主函数调用 `getHeight(root)`。如果返回 -1，则树不平衡；否则，树平衡。

这种方法在计算高度的同时检查平衡性，避免了对每个节点重复计算高度 (与朴素的 `isBalanced(node) && isBalanced(node.left) && isBalanced(node.right)` 结合 `height(node)` 相比)。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isBalanced(self, root: TreeNode) -> bool:
        
        def get_height_and_check_balance(node: TreeNode) -> int:
            # Returns height if balanced, -1 if not.
            if not node:
                return 0 # Height of an empty tree is 0 and it's balanced.

            left_height = get_height_and_check_balance(node.left)
            if left_height == -1: # Left subtree is not balanced
                return -1 
            
            right_height = get_height_and_check_balance(node.right)
            if right_height == -1: # Right subtree is not balanced
                return -1
            
            # Check balance at the current node
            if abs(left_height - right_height) > 1:
                return -1
            
            # If balanced, return its height
            return 1 + max(left_height, right_height)

        return get_height_and_check_balance(root) != -1
```

### 070: [64. 最小路径和 (Minimum Path Sum)](https://leetcode.cn/problems/minimum-path-sum)

**题目描述:**
给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。
**说明：** 每次只能向下或者向右移动一步。

**解题思路 (动态规划):**
1.  定义 `dp[i][j]` 为到达网格单元格 `(i, j)` 的最小路径和。
2.  **状态转移方程:**
    *   要到达 `(i, j)`，只能从 `(i-1, j)` (向下移动) 或 `(i, j-1)` (向右移动) 到达。
    *   因此，`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。
3.  **基本情况 (初始化):**
    *   `dp = grid` (起点)。
    *   第一行: `dp[j] = grid[j] + dp[j-1]` for `j > 0`。 (只能从左边来)
    *   第一列: `dp[i] = grid[i] + dp[i-1]` for `i > 0`。 (只能从上边来)
4.  遍历填充 `dp` 数组。
5.  最终结果是 `dp[m-1][n-1]`。

**空间优化:**
由于 `dp[i][j]` 只依赖于上一行和当前行的前一列的值，我们可以将空间复杂度优化到 O(N) (使用一维数组) 或 O(1) (直接修改输入 `grid` 数组)。

**Python 实现 (空间 O(1) - 修改原grid):**
```python
from typing import List

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m = len(grid)
        n = len(grid[0])

        # Initialize first row
        for j in range(1, n):
            grid[0][j] += grid[0][j-1]
            
        # Initialize first column
        for i in range(1, m):
            grid[i][0] += grid[i-1][0]
            
        # Fill the rest of the grid
        for i in range(1, m):
            for j in range(1, n):
                grid[i][j] += min(grid[i-1][j], grid[i][j-1])
                
        return grid[m-1][n-1]
```
