### 011: [102. 二叉树的层序遍历 (Binary Tree Level Order Traversal)](https://leetcode.cn/problems/binary-tree-level-order-traversal)

**题目描述:**
给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。 (即逐层地，从左到右访问所有节点)。

**解题思路:**
使用广度优先搜索 (BFS)。
1.  如果根节点 `root` 为空，返回空列表。
2.  初始化一个队列，并将根节点 `root` 加入队列。
3.  初始化一个结果列表 `result_levels` 来存储每一层的节点值。
4.  当队列不为空时，循环执行：
    a.  获取当前层的节点数量 `level_size = queue.size()`。
    b.  创建一个列表 `current_level_values` 来存储当前层所有节点的值。
    c.  循环 `level_size` 次 (处理当前层的所有节点)：
    i.  从队列中取出一个节点 `node`。
    ii. 将 `node.val` 加入 `current_level_values`。
    iii.如果 `node` 的左子节点不为空，将其加入队列。
    iv. 如果 `node` 的右子节点不为空，将其加入队列。
    d.  将 `current_level_values` 加入 `result_levels`。
5.  返回 `result_levels`。

**Python 实现:**
```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def levelOrder(self, root: TreeNode) -> list[list[int]]:
        if not root:
            return []

        result_levels = []
        queue = deque([root])

        while queue:
            level_size = len(queue)
            current_level_values = []
            for _ in range(level_size):
                node = queue.popleft()
                current_level_values.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            result_levels.append(current_level_values)
            
        return result_levels
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> resultLevels = new ArrayList<>();
        if (root == null) {
            return resultLevels;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> currentLevelValues = new ArrayList<>();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                currentLevelValues.add(node.val);
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            resultLevels.add(currentLevelValues);
        }
        return resultLevels;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点只会被访问和处理一次。
*   空间复杂度: O(W)，其中 W 是树的最大宽度。在最坏的情况下（例如完全二叉树），队列中可能存储 W 个节点。

### 012: [1. 两数之和 (Two Sum)](https://leetcode.cn/problems/two-sum)

**题目描述:**
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。
你可以按任意顺序返回答案。

**解题思路:**
使用哈希表 (HashMap)。
1.  初始化一个哈希表 `num_to_index_map` 来存储数字及其在数组中的索引。
2.  遍历数组 `nums` 中的每个元素 `num` 及其索引 `i`：
    a.  计算需要的另一个数 `complement = target - num`。
    b.  检查 `complement` 是否在 `num_to_index_map` 中：
    i.  如果存在，并且 `num_to_index_map[complement]` 不是当前索引 `i`（确保不是同一个元素），则找到了两个数，返回 `[num_to_index_map[complement], i]`。
    c.  如果 `complement` 不在哈希表中，或者找到了但索引相同（这意味着如果允许重复，会找到自己，但题目不允许），则将当前数字和索引存入哈希表：`num_to_index_map[num] = i`。
3.  如果遍历完成仍未找到，说明没有符合条件的两个数（根据题目假设，总有答案，所以这步理论上不会到）。

**更优化的单遍哈希表:**
1.  初始化一个哈希表 `num_to_index_map`。
2.  遍历数组 `nums` 中的每个元素 `num` 及其索引 `i`：
    a.  计算需要的另一个数 `complement = target - num`。
    b.  检查 `complement` 是否在 `num_to_index_map` 中：
    i.  如果存在，说明之前已经遍历过 `complement`，其索引存储在 `num_to_index_map[complement]`。直接返回 `[num_to_index_map[complement], i]`。
    c.  如果 `complement` 不在哈希表中，将当前数字 `num` 和其索引 `i` 存入哈希表: `num_to_index_map[num] = i`。这样可以确保我们不会使用同一个元素两次。

**Python 实现:**
```python
class Solution:

        num_to_index_map = {}  # Stores number -> index
        for index, num in enumerate(nums):
            complement = target - num
            if complement in num_to_index_map:
                return [num_to_index_map[complement], index]
            num_to_index_map[num] = index
        return [] # Should not be reached based on problem description
```

### 013: [33. 搜索旋转排序数组 (Search in Rotated Sorted Array)](https://leetcode.cn/problems/search-in-rotated-sorted-array)

**题目描述:**
整数数组 `nums` 原先按升序排列，后经由 `1` 到 `n`（未知）个导致旋转的点进行了旋转，使得数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums, nums, ..., nums[k-1]]`（`0 <= k < n`）。例如，`` 可能旋转为 ``。
给你旋转后的数组 `nums` 和一个整数 `target`，如果 `target` 在 `nums` 中存在，则返回其下标，否则返回 `-1`。
你必须设计一个时间复杂度为 O(log n) 的算法来解决此问题。

**解题思路:**
使用 модифицированный二分查找。
关键在于，旋转后的数组至少有一半是保持有序的。
1.  初始化 `left = 0`, `right = nums.length - 1`。
2.  当 `left <= right` 时循环：
    a.  计算中间点 `mid = left + (right - left) / 2`。
    b.  如果 `nums[mid] == target`，返回 `mid`。
    c.  **判断哪一半是有序的:**
    i.  **如果左半部分 `nums[left...mid]` 是有序的** (即 `nums[left] <= nums[mid]`):
    *   判断 `target` 是否在左半部分有序区间内 (即 `nums[left] <= target < nums[mid]`)。
    *   如果是，则在左半部分搜索：`right = mid - 1`。
    *   否则，在右半部分搜索：`left = mid + 1`。
    ii. **如果右半部分 `nums[mid...right]` 是有序的** (即 `nums[mid] < nums[right]`，注意这里是严格小于，因为左半边不有序则 `nums[left] > nums[mid]`)
    *   判断 `target` 是否在右半部分有序区间内 (即 `nums[mid] < target <= nums[right]`)。
    *   如果是，则在右半部分搜索：`left = mid + 1`。
    *   否则，在左半部分搜索：`right = mid - 1`。
3.  如果循环结束仍未找到，返回 `-1`。

**Python 实现:**
```python
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1

        while left <= right:
            mid = left + (right - left) // 2

            if nums[mid] == target:
                return mid

            # Case 1: Left part is sorted (nums[left] to nums[mid])
            if nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]: # Target is in the sorted left part
                    right = mid - 1
                else: # Target is in the right (possibly unsorted) part
                    left = mid + 1
            # Case 2: Right part is sorted (nums[mid] to nums[right])
            else: # nums[left] > nums[mid] means pivot is in left part
                if nums[mid] < target <= nums[right]: # Target is in the sorted right part
                    left = mid + 1
                else: # Target is in the left (possibly unsorted) part
                    right = mid - 1
                    
        return -1
```

### 014: [200. 岛屿数量 (Number of Islands)](https://leetcode.cn/problems/number-of-islands)

**题目描述:**
给你一个由 `'1'` (陆地) 和 `'0'` (水) 组成的二维网格 `grid`，请你计算网格中岛屿的数量。
岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。
此外，你可以假设该网格的四条边均被水包围。

**解题思路:**
遍历整个网格。当遇到一个 `'1'`（陆地）并且这个陆地没有被访问过时，就找到了一个新的岛屿。然后，从这个点开始，使用深度优先搜索 (DFS) 或广度优先搜索 (BFS) 将与该点相连的所有陆地标记为已访问（例如，可以将 `'1'` 变成 `'0'` 或另一个标记字符），以避免重复计数。

1.  初始化 `num_islands = 0`。
2.  获取网格的行数 `rows` 和列数 `cols`。
3.  遍历网格中的每个单元格 `grid[r][c]`：
    a.  如果 `grid[r][c] == '1'`:
        i.  `num_islands++`。
        ii. 调用 DFS 或 BFS 函数，从 `(r, c)` 开始，将所有相连的 `'1'` 标记为已访问 (例如，修改为 `'0'` 或使用一个 `visited` 数组)。
4.  返回 `num_islands`。

**DFS 辅助函数 `dfs(grid, r, c)`:**
1.  边界检查和条件检查：如果 `(r, c)` 超出边界，或者 `grid[r][c]` 不是 `'1'`，则返回。
2.  标记当前单元格为已访问：`grid[r][c] = '0'`。
3.  递归地访问四个相邻方向：
    *   `dfs(grid, r + 1, c)` (下)
    *   `dfs(grid, r - 1, c)` (上)
    *   `dfs(grid, r, c + 1)` (右)
    *   `dfs(grid, r, c - 1)` (左)

**Python 实现 (DFS):**
```python
class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        if not grid or not grid[0]:
            return 0

        rows = len(grid)
        cols = len(grid[0])
        num_islands = 0

        def dfs(r, c):
            # Boundary checks and if it's water or already visited (marked as '0')
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == '0':
                return
            
            grid[r][c] = '0' # Mark as visited (sink the island part)
            
            # Explore neighbors
            dfs(r + 1, c) # Down
            dfs(r - 1, c) # Up
            dfs(r, c + 1) # Right
            dfs(r, c - 1) # Left

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == '1':
                    num_islands += 1
                    dfs(r, c)
        
        return num_islands
```

**Java 实现 (DFS):**
```java
class Solution {
    private int rows;
    private int cols;

    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }

        rows = grid.length;
        cols = grid[0].length;
        int numIslands = 0;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == '1') {
                    numIslands++;
                    dfs(grid, r, c);
                }
            }
        }
        return numIslands;
    }

    private void dfs(char[][] grid, int r, int c) {
        // Boundary checks and if it's water or already visited (marked as '0')
        if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == '0') {
            return;
        }

        grid[r][c] = '0'; // Mark as visited (sink the island part)

        // Explore neighbors
        dfs(grid, r + 1, c); // Down
        dfs(grid, r - 1, c); // Up
        dfs(grid, r, c + 1); // Right
        dfs(grid, r, c - 1); // Left
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 是行数，N 是列数。每个单元格最多被访问两次 (一次在主循环中，一次在 DFS/BFS 中)。
*   空间复杂度:
    *   如果修改原网格: O(1) (忽略递归栈空间)。
    *   递归栈空间: 最坏情况下，如果整个网格都是一个岛屿，递归深度可能达到 O(M * N)。
    *   如果使用 `visited` 数组 (不修改原网格): O(M * N) for the `visited` array.
    *   BFS 队列空间: 最坏情况下 O(min(M, N)) (对于细长的岛屿) 或 O(M*N) (如果使用 BFS 并需要存储大量节点). 但对于 DFS 来说，递归栈是主要空间因素。

### 015: [46. 全排列 (Permutations)](https://leetcode.cn/problems/permutations)

**题目描述:**
给定一个不含重复数字的数组 `nums` ，返回其 **所有可能的全排列** 。你可以 **按任意顺序** 返回答案。

**解题思路 (回溯法 Backtracking):**
1.  **定义回溯函数 `backtrack(current_permutation, remaining_elements)`**:
    *   `current_permutation`: 当前已经构建的部分排列。
    *   `remaining_elements`: 尚未被加入排列的元素。
2.  **基准情况 (Base Case)**:
    *   如果 `remaining_elements` 为空 (或者 `current_permutation` 的长度等于原始数组 `nums` 的长度)，说明已经构建了一个完整的排列。将其加入结果列表 `result`。
3.  **递归步骤 (选择 - 探索 - 撤销选择)**:
    *   遍历 `remaining_elements` 中的每一个元素 `num`:
        a.  **选择**: 将 `num` 加入 `current_permutation`。
        b.  **探索**: 递归调用 `backtrack`，传入新的 `current_permutation` 和从 `remaining_elements` 中移除了 `num` 之后的新 `remaining_elements`。
        c.  **撤销选择 (回溯)**: 将 `num` 从 `current_permutation` 中移除，并将其加回到 `remaining_elements` 的相应位置（如果 `remaining_elements` 是通过传递副本或切片来处理的，这一步可能是隐式的，或者需要维护一个 `used` 数组）。

**使用 `used` 数组优化 (更常见的回溯模式):**
回溯函数 `backtrack(current_permutation)`，辅助数据：`used` 布尔数组标记元素是否已使用。
1.  **定义 `backtrack(current_permutation)`**
2.  **基准情况**: 如果 `len(current_permutation) == len(nums)`，将 `current_permutation` 的一个副本加入结果列表。
3.  **递归步骤**:
    *   遍历 `nums` 中的每一个元素 `nums[i]` (通过索引 `i`)。
    *   如果 `nums[i]` 未被使用 (`used[i]` 为 `false`):
        a.  **选择**: `current_permutation.add(nums[i])`，`used[i] = true`。
        b.  **探索**: `backtrack(current_permutation)`。
        c.  **撤销选择**: `current_permutation.removeLast()`，`used[i] = false`。

**Python 实现 (使用 `used` 数组):**
```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        result = []
        n = len(nums)
        used = [False] * n
        current_permutation = []

        def backtrack():
            if len(current_permutation) == n:
                result.append(list(current_permutation)) # Add a copy
                return

            for i in range(n):
                if not used[i]:
                    # Choose
                    used[i] = True
                    current_permutation.append(nums[i])
                    
                    # Explore
                    backtrack()
                    
                    # Unchoose (Backtrack)
                    current_permutation.pop()
                    used[i] = False
        
        backtrack()
        return result
```

**Java 实现 (使用 `used` 数组):**
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        List<Integer> currentPermutation = new ArrayList<>();
        
        backtrack(nums, currentPermutation, used, result);
        
        return result;
    }

    private void backtrack(int[] nums, List<Integer> currentPermutation, boolean[] used, List<List<Integer>> result) {
        if (currentPermutation.size() == nums.length) {
            result.add(new ArrayList<>(currentPermutation)); // Add a copy
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            if (!used[i]) {
                // Choose
                used[i] = true;
                currentPermutation.add(nums[i]);
                
                // Explore
                backtrack(nums, currentPermutation, used, result);
                
                // Unchoose (Backtrack)
                currentPermutation.remove(currentPermutation.size() - 1); // Remove last added
                used[i] = false;
            }
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N * N!)。
    *   有 N! 个排列。
    *   对于每个排列，需要 O(N) 的时间来构造它 (例如，将其复制到结果列表中)。
    *   回溯树的节点总数约为 N! * N (叶子节点N!，每个叶子节点路径长N)。每个节点的操作是常数时间（除了复制到结果）。
*   空间复杂度: O(N)。
    *   `used` 数组和 `current_permutation` 列表都需要 O(N) 空间。
    *   递归栈的深度也是 O(N)。
    *   结果列表本身会存储 N! 个长度为 N 的列表，但这通常不计入辅助空间复杂度，或单独说明为 O(N * N!)。

### 016: [20. 有效的括号 (Valid Parentheses)](https://leetcode.cn/problems/valid-parentheses)

**题目描述:**
给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。
有效字符串需满足：
1.  左括号必须用相同类型的右括号闭合。
2.  左括号必须以正确的顺序闭合。
3.  每个右括号都有一个对应的相同类型的左括号。

**解题思路:**
使用栈。
1.  创建一个空栈。
2.  创建一个哈希表 `mapping` 来存储右括号到对应左括号的映射 (e.g., `')' -> '('`, `']' -> '['`, `'}' -> '{'`）。
3.  遍历输入字符串 `s` 中的每个字符 `char`:
    a.  如果 `char` 是一个左括号 (`'('`, `'['`, `'{'`)：将其压入栈中。
    b.  如果 `char` 是一个右括号 (`')'`, `']'`, `'}'`)：
    i.  检查栈是否为空。如果为空，说明没有对应的左括号，返回 `false`。
    ii. 从栈顶弹出一个元素 `top_element`。
    iii. 检查 `top_element` 是否是 `char` 对应的左括号 (即 `mapping[char] == top_element`)。如果不是，说明括号类型不匹配，返回 `false`。
    c.  如果 `char` 不是括号字符 (题目说明只包括括号，但以防万一)，可以忽略或报错。
4.  遍历完字符串后，检查栈是否为空：
    *   如果栈为空，说明所有左括号都已正确闭合，返回 `true`。
    *   如果栈不为空，说明有未闭合的左括号，返回 `false`。

**Python 实现:**
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        mapping = {")": "(", "]": "[", "}": "{"}

        for char in s:
            if char in mapping: # It's a closing bracket
                if not stack: # Stack is empty, no matching opening bracket
                    return False
                top_element = stack.pop()
                if mapping[char] != top_element:
                    return False # Mismatched brackets
            else: # It's an opening bracket
                stack.append(char)
        
        return not stack # If stack is empty, all brackets were matched
```

**Java 实现:**
```java

        Stack<Character> stack = new Stack<>();
        Map<Character, Character> mapping = new HashMap<>();

        }

    }

### 017: [88. 合并两个有序数组 (Merge Sorted Array)](https://leetcode.cn/problems/merge-sorted-array)

**题目描述:**
给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` ，分别表示 `nums1` 和 `nums2` 中的元素数目。
请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。
**注意：** 最终合并后的数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0` ，应忽略。`nums2` 的长度为 `n` 。

**解题思路:**
**从后向前双指针法:**
由于 `nums1` 有足够的空间容纳 `nums2` 中的所有元素，并且我们需要将结果直接放在 `nums1` 中，从后向前填充可以避免覆盖 `nums1` 中尚未处理的元素。
1.  初始化三个指针：
    *   `p1`: 指向 `nums1` 中有效元素的末尾，初始为 `m - 1`。
    *   `p2`: 指向 `nums2` 中有效元素的末尾，初始为 `n - 1`。
    *   `p_merge`: 指向 `nums1` 合并后数组的末尾，初始为 `m + n - 1`。
2.  当 `p1 >= 0` 且 `p2 >= 0` 时，比较 `nums1[p1]` 和 `nums2[p2]`：
    *   如果 `nums1[p1] > nums2[p2]`，则将 `nums1[p1]` 放入 `nums1[p_merge]`，然后 `p1--`。
    *   否则 ( `nums1[p1] <= nums2[p2]` )，将 `nums2[p2]` 放入 `nums1[p_merge]`，然后 `p2--`。
    *   在每种情况下，都 `p_merge--`。
3.  循环结束后，可能有一个数组还有剩余元素 (因为另一个数组的指针已经小于 0)。
    *   如果 `nums1` 还有剩余 (即 `p1 >= 0`)，这些元素已经在 `nums1` 的正确位置了，不需要处理（因为我们是从后往前填充的，它们没被动过）。
    *   如果 `nums2` 还有剩余 (即 `p2 >= 0`)，将 `nums2` 中剩余的元素依次拷贝到 `nums1` 的前面空余位置 (`nums1[p_merge] = nums2[p2]`, `p2--`, `p_merge--`)。
4.  最终 `nums1` 即为合并后的排序数组。

**Python 实现:**
```python
class Solution:
    def merge(self, nums1: list[int], m: int, nums2: list[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        p1 = m - 1       # Pointer for last element of actual nums1 part
        p2 = n - 1       # Pointer for last element of nums2
        p_merge = m + n - 1 # Pointer for last position in nums1 (merged array)

        # Merge from the end
        while p1 >= 0 and p2 >= 0:
            if nums1[p1] > nums2[p2]:
                nums1[p_merge] = nums1[p1]
                p1 -= 1
            else:
                nums1[p_merge] = nums2[p2]
                p2 -= 1
            p_merge -= 1
        
        # If there are remaining elements in nums2, copy them over
        # (nums1 elements are already in place if p1 >= 0)
        while p2 >= 0:
            nums1[p_merge] = nums2[p2]
            p2 -= 1
            p_merge -= 1
```

**Java 实现:**

class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;       // Pointer for last element of actual nums1 part
        int p2 = n - 1;       // Pointer for last element of nums2
        int pMerge = m + n - 1; // Pointer for last position in nums1 (merged array)

        // Merge from the end
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] > nums2[p2]) {
                nums1[pMerge] = nums1[p1];
                p1--;
            } else {
                nums1[pMerge] = nums2[p2];
                p2--;
            }
            pMerge--;
        }

        // If there are remaining elements in nums2, copy them over
        // (nums1 elements are already in place if p1 >= 0)

            nums1[pMerge] = nums2[p2];
            p2--;
            pMerge--;
        }
    }
}
```

*   时间复杂度: O(M + N)。每个元素最多被比较和移动一次。
*   空间复杂度: O(1)，因为是原地修改 `nums1`，只使用了常数个额外指针。

### 018: [121. 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock)

**题目描述:**
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。
你只能选择 **某一天** 买入这只股票，并选择在 **未来的某个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。
返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**解题思路 (单遍扫描):**
1.  初始化两个变量：
    *   `min_price`: 记录到目前为止遇到的最低股票价格，初始为 `prices` (或者一个非常大的数，如果数组可能为空，则需要处理)。
    *   `max_profit`: 记录到目前为止能获得的最大利润，初始为 `0`。
2.  从第二天开始遍历价格数组 `prices` (索引 `i = 1` 到 `n-1`):
    a.  对于当前价格 `prices[i]`：
    i.  更新 `min_price = min(min_price, prices[i])`。找到到今天为止的最低买入价。
    ii. 计算如果在今天卖出，并且以之前的 `min_price` 买入，能获得的利润 `current_profit = prices[i] - min_price`。
    iii. 更新 `max_profit = max(max_profit, current_profit)`。
3.  遍历结束后，`max_profit` 即为所求。

**Python 实现:**
```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices or len(prices) < 2:
            return 0

        min_price = prices[0]
        max_profit = 0

        for i in range(1, len(prices)):
            # Update the minimum price seen so far
            min_price = min(min_price, prices[i])
            # Calculate profit if sold today at prices[i] having bought at min_price
            current_profit = prices[i] - min_price
            # Update the maximum profit
            max_profit = max(max_profit, current_profit)
            
        return max_profit
```

### 019: [103. 二叉树的锯齿形层次遍历 (Binary Tree Zigzag Level Order Traversal)](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal)

**题目描述:**
给你二叉树的根节点 `root` ，返回其节点值的 **锯齿形层序遍历** 。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

**解题思路:**
与普通的层序遍历 (BFS) 类似，但需要根据层级的奇偶性来决定节点值的添加顺序。
1.  如果根节点 `root` 为空，返回空列表。
2.  初始化一个队列 (通常用 `Deque` 实现，以便双端操作，虽然此题单端队列配合标志位也可)，并将根节点 `root` 加入队列。
3.  初始化一个结果列表 `result_levels`。
4.  用一个布尔变量 `left_to_right = true` 来标记当前层的遍历方向，初始为从左到右。
5.  当队列不为空时，循环执行：
    a.  获取当前层的节点数量 `level_size = queue.size()`。
    b.  创建一个双端队列 `current_level_values_deque` 来存储当前层所有节点的值，这样可以方便地按需从头或尾添加。
    c.  循环 `level_size` 次 (处理当前层的所有节点)：
    i.  从队列中取出一个节点 `node`。
    ii. 根据 `left_to_right` 的值决定如何添加 `node.val`到 `current_level_values_deque`：
    *   如果 `left_to_right` 为 `true` (从左到右)，则 `current_level_values_deque.addLast(node.val)`。
    *   如果 `left_to_right` 为 `false` (从右到左)，则 `current_level_values_deque.addFirst(node.val)`。
    iii. 将子节点加入主队列（用于下一层的处理，顺序是常规的从左到右入队）：
    *   如果 `node.left` 不为空，将其加入主队列。
    *   如果 `node.right` 不为空，将其加入主队列。
    d.  将 `current_level_values_deque` 转换为列表，并加入 `result_levels`。
    e.  切换遍历方向：`left_to_right = not left_to_right`。
6.  返回 `result_levels`。

**Python 实现:**
```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def zigzagLevelOrder(self, root: TreeNode) -> list[list[int]]:
        if not root:
            return []

        result_levels = []
        queue = deque([root]) # Main queue for BFS processing
        left_to_right = True # Flag for direction

        while queue:
            level_size = len(queue)
            # Use a deque for current level values to easily add front or back
            current_level_values_deque = deque() 
            
            for _ in range(level_size):
                node = queue.popleft() # Always process from left for BFS structure
                
                if left_to_right:
                    current_level_values_deque.append(node.val)
                else: # right_to_left
                    current_level_values_deque.appendleft(node.val) # Add to the front
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            result_levels.append(list(current_level_values_deque))
            left_to_right = not left_to_right # Flip direction for next level
            
        return result_levels
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue; // For the main BFS queue
import java.util.Deque; // For current level values

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> resultLevels = new ArrayList<>();
        if (root == null) {
            return resultLevels;
        }

        Queue<TreeNode> queue = new LinkedList<>(); // Main queue for BFS
        queue.offer(root);
        boolean leftToRight = true; // Flag for direction

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            // Use a Deque (LinkedList implements Deque) for current level values
            Deque<Integer> currentLevelValuesDeque = new LinkedList<>(); 
            
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll(); // Always process from left for BFS structure
                
                if (leftToRight) {
                    currentLevelValuesDeque.offerLast(node.val);
                } else { // rightToLeft
                    currentLevelValuesDeque.offerFirst(node.val); // Add to the front
                }
                
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            resultLevels.add(new ArrayList<>(currentLevelValuesDeque));
            leftToRight = !leftToRight; // Flip direction for next level
        }
        return resultLevels;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点只会被访问和处理一次。`Deque` 操作 (`append`, `appendleft`, `offerFirst`, `offerLast`) 都是 O(1)。
*   空间复杂度: O(W)，其中 W 是树的最大宽度。主队列和当前层值双端队列在最坏情况下可能存储 W 个节点。

### 020: [236. 二叉树的最近公共祖先 (Lowest Common Ancestor of a Binary Tree)](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree)

**题目描述:**
给定一个二叉树, 找到该树中两个指定节点的最近公共祖先（LCA）。
最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

**解题思路 (递归法):**
这是一种经典的递归解法。对于当前节点 `root`：
1.  **基准情况:**
    *   如果 `root` 为空 (`null`)，则 p 和 q 肯定不在此子树中，返回 `null`。
    *   如果 `root` 等于 `p` 或 `root` 等于 `q`，则 `root` 自身就是 p 或 q，并且它可能是 p 和 q 的 LCA (如果另一个节点在其子树中)，或者它只是 p 或 q 中的一个，LCA 在其父节点。总之，当前子树的搜索到此为止，返回 `root`。
2.  **递归搜索左右子树:**
    *   递归调用 `lowestCommonAncestor(root.left, p, q)` 得到 `left_lca`。
    *   递归调用 `lowestCommonAncestor(root.right, p, q)` 得到 `right_lca`。
3.  **根据左右子树的返回结果判断 LCA:**
    *   如果 `left_lca` 不为空且 `right_lca` 不为空：这意味着 `p` 和 `q` 分别位于 `root` 的左子树和右子树中，因此 `root` 就是它们的 LCA。返回 `root`。
    *   如果 `left_lca` 不为空但 `right_lca` 为空：这意味着 `p` 和 `q` 都在左子树中 (或者 p/q 其中一个是 `left_lca`，另一个在 `left_lca` 的子树中)。因此，LCA 就是 `left_lca`。返回 `left_lca`。
    *   如果 `left_lca` 为空但 `right_lca` 不为空：类似地，LCA 就是 `right_lca`。返回 `right_lca`。
    *   如果 `left_lca` 和 `right_lca` 都为空：这意味着 `p` 和 `q` 都不在 `root` 的左右子树中 (或者说 `root` 的子树中找不到它们)，返回 `null`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # Base cases
        if not root:
            return None
        if root == p or root == q: # If root is p or q, then root is a candidate for LCA
            return root

        # Recursively search in left and right subtrees
        left_lca = self.lowestCommonAncestor(root.left, p, q)
        right_lca = self.lowestCommonAncestor(root.right, p, q)

        # Process results from children
        if left_lca and right_lca:
            # p and q are found in different subtrees, so root is the LCA
            return root
        elif left_lca:
            # Both p and q are in the left subtree (or one is left_lca and other is below)
            return left_lca
        elif right_lca:
            # Both p and q are in the right subtree (or one is right_lca and other is below)
            return right_lca
        else:
            # Neither p nor q found in subtrees of root
            return None
```
