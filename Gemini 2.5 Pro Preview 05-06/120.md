### 111: [47. 全排列 II (Permutations II)](https://leetcode.cn/problems/permutations-ii)

**题目描述:**
给定一个可包含重复数字的序列 `nums` ，按任意顺序 返回所有不重复的全排列。

**解题思路 (回溯法 + 剪枝处理重复):**
与全排列 I 类似，但需要处理重复元素以避免生成重复的排列。
1.  **排序**: 首先对数组 `nums` 进行排序。这使得相同的元素相邻，方便后续的剪枝操作。
2.  **回溯函数 `backtrack(current_permutation, used_mask)`**:
    *   `current_permutation`: 当前已经构建的部分排列。
    *   `used_mask`: 一个布尔数组，标记 `nums` 中的元素是否已被使用。
3.  **基准情况**: 如果 `len(current_permutation) == len(nums)`，将 `current_permutation` 的一个副本加入结果列表。
4.  **递归步骤 (选择 - 探索 - 撤销选择)**:
    *   遍历 `nums` 中的每一个元素 `nums[i]` (通过索引 `i`)。
    *   **剪枝条件 (重要)**:
        *   如果 `nums[i]` 已被使用 (`used[i]` 为 `true`)，跳过。
        *   **如果 `i > 0` 且 `nums[i] == nums[i-1]` 且 `used[i-1]` 为 `false`** (即前一个相同的元素没有被使用)，则跳过 `nums[i]`。
            *   这个条件确保对于一组相同的数字，我们总是按它们在排序后数组中出现的顺序来使用它们。如果前一个相同的数字 `nums[i-1]` 还没被用 (它在这一轮的更早的 `for` 循环迭代中本可以被选，但如果它没被选而现在要选 `nums[i]`，就会导致重复的排列，比如 `[1, 2a, 2b]` vs `[1, 2b, 2a]` where `2a` and `2b` are identical values but from different original indices before sort. After sort they are adjacent. If we consider `nums[i-1]` which is same as `nums[i]`, if `nums[i-1]` was NOT used in this current path/permutation building, it implies it has been considered and backtracked from already, OR we are ensuring a fixed order for picking identical values. So if `used[i-1]` is false, means the permutation starting with picking `nums[i-1]` at this depth has been/will be explored. To avoid duplicate permutations generated by picking `nums[i]` now when `nums[i-1]` (identical) was available but not chosen FOR THIS LEVEL OF RECURSION (i.e. `used[i-1]` is false for the path leading *to* the current `backtrack` call at this specific position in the permutation), we skip.  Essentially, for identical elements, they must be picked in their sorted order in a permutation to avoid duplicates arising from swapping identical elements that are effectively in different "slots" in the original list before sorting.
    *   **选择**: `current_permutation.add(nums[i])`，`used[i] = true`。
    *   **探索**: `backtrack(current_permutation, used)`。
    *   **撤销选择**: `current_permutation.removeLast()`，`used[i] = false`。

**Python 实现:**
```python
class Solution:
    def permuteUnique(self, nums: list[int]) -> list[list[int]]:
        result = []
        n = len(nums)
        used = [False] * n
        current_permutation = []
        
        nums.sort() # Sort to handle duplicates

        def backtrack():
            if len(current_permutation) == n:
                result.append(list(current_permutation)) # Add a copy
                return

            for i in range(n):
                if used[i]:
                    continue
                # Pruning condition:
                # If the current number is the same as the previous one,
                # and the previous one has not been used in this path yet, skip.
                # This ensures that for a set of identical numbers, we pick them
                # in the order they appear in the sorted 'nums' array for a given "slot"
                # in the permutation. If nums[i-1] was available but not picked
                # for the current slot, and nums[i] is same, picking nums[i] now would be
                # redundant to a path where nums[i-1] *was* picked.
                if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
                    continue
                
                # Choose
                used[i] = True
                current_permutation.append(nums[i])
                
                # Explore
                backtrack()
                
                # Unchoose (Backtrack)
                current_permutation.pop()
                used[i] = False
        
        backtrack()
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        List<Integer> currentPermutation = new ArrayList<>();
        
        Arrays.sort(nums); // Sort to handle duplicates
        
        backtrack(nums, currentPermutation, used, result);
        
        return result;
    }

    private void backtrack(int[] nums, List<Integer> currentPermutation, boolean[] used, List<List<Integer>> result) {
        if (currentPermutation.size() == nums.length) {
            result.add(new ArrayList<>(currentPermutation)); // Add a copy
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            if (used[i]) {
                continue;
            }
            // Pruning condition (important for duplicates):
            // If the current element is the same as the previous element,
            // AND the previous element has not been used (in the current path leading to this choice),
            // then skip the current element. This prevents duplicate permutations.
            // Example: nums = [1, 2, 2']. Sort gives [1, 2, 2'].
            // If we build [1, _, _]:
            //  - Option 1: Pick nums[1] (value 2). Path: [1, 2]. used = [T, T, F]
            //  - Option 2: (Backtrack from above, now consider alternatives for the second slot)
            //             If we are now trying to pick nums[2] (value 2') for the second slot,
            //             and nums[1] (value 2) was not used *for this second slot*, i.e., !used[1],
            //             then we skip picking nums[2].
            //             This condition (not used[i-1]) means: if we have identical choices
            //             (e.g., 'a', 'b' both with value X), and we are filling a position,
            //             if 'a' was not picked (and we considered it or skipped it at current recursion level),
            //             don't pick 'b' for this same position if 'a' leads to a state we could have gotten.
            //             Basically, for identical numbers, force picking them in their sorted order for this level of recursion.
            if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) {
                continue;
            }
            
            // Choose
            used[i] = true;
            currentPermutation.add(nums[i]);
            
            // Explore
            backtrack(nums, currentPermutation, used, result);
            
            // Unchoose (Backtrack)
            currentPermutation.remove(currentPermutation.size() - 1);
            used[i] = false;
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N * N!) in the worst case if all elements are unique (like permutation I), because sorting takes O(N log N) and backtracking will dominate. Generating N! permutations, each of length N. If there are many duplicates, the number of unique permutations will be less than N!, but the branching factor reduction is complex to analyze simply. The number of distinct permutations is `N! / (n1! * n2! * ... * nk!)` where `ni` is the count of each distinct number. Each permutation still takes O(N) to build/copy. The sorting step helps in pruning. The overall complexity is bounded by N * (number of unique permutations).
*   空间复杂度: O(N) (for `used` array, `current_permutation`, and recursion stack depth). Result storage is separate.

### 112: [136. 只出现一次的数字 (Single Number)](https://leetcode.cn/problems/single-number)

**题目描述:**
给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。
你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**解题思路 (位运算 XOR):**
利用异或 (XOR) 运算的性质：
1.  `a ^ a = 0` (任何数与自身异或结果为 0)。
2.  `a ^ 0 = a` (任何数与 0 异或结果为自身)。
3.  XOR 运算满足交换律和结合律 (e.g., `a ^ b ^ a = a ^ a ^ b = 0 ^ b = b`)。

遍历数组，将所有元素进行异或操作。成对出现的元素异或后会抵消为 0。最终剩下的就是那个只出现一次的元素。

**Python 实现:**
```python
class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        result = 0
        for num in nums:
            result ^= num
        return result
```

**Java 实现:**
```java

    public int singleNumber(int[] nums) {
        int result = 0;
        for (int num : nums) {
            result ^= num;
        }
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，遍历数组一次。
*   空间复杂度: O(1)，只使用了一个额外变量。

### 113: [11. 盛最多水的容器 (Container With Most Water)](https://leetcode.cn/problems/container-with-most-water)

**题目描述:**
给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。
找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。
返回容器可以储存的最大水量。
说明：你不能倾斜容器。

**解题思路 (双指针法):**
1.  初始化两个指针：`left = 0` 指向数组开头，`right = len(height) - 1` 指向数组末尾。
2.  初始化 `max_area = 0`。
3.  当 `left < right` 时循环：
    a.  计算当前两条线构成的容器的宽度：`width = right - left`。
    b.  容器的高度由较短的那条线决定：`h = min(height[left], height[right])`。
    c.  计算当前面积：`current_area = width * h`。
    d.  更新 `max_area = max(max_area, current_area)`。
    e.  **移动指针的策略 (关键)**:
    *   为了尝试找到更大的面积，我们应该移动指向较短线段的那个指针。
    *   如果 `height[left] < height[right]`，则 `left++`。因为如果移动 `right` (较长的线)，宽度减小，高度不可能增加 (最多保持 `height[left]`)，所以面积肯定不会变大。移动 `left` 才有可能找到更高的 `height[left]` 从而可能得到更大面积。
    *   否则 (`height[left] >= height[right]`)，则 `right--`。
4.  返回 `max_area`。

**Python 实现:**
```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0

        while left < right:
            h = min(height[left], height[right])
            width = right - left
            current_area = h * width
            max_area = max(max_area, current_area)

            if height[left] < height[right]:
                left += 1
            else: # height[left] >= height[right]
                right -= 1
        
        return max_area
```

**Java 实现:**
```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int h = Math.min(height[left], height[right]);
            int width = right - left;
            int currentArea = h * width;
            maxArea = Math.max(maxArea, currentArea);

            if (height[left] < height[right]) {
                left++;
            } else { // height[left] >= height[right]
                right--;
            }
        }
        return maxArea;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，两个指针总共扫描数组一次。
*   空间复杂度: O(1)。

### 114: [补充题5. 手撕归并排序 (Sort an Array - LeetCode 912, using Merge Sort)](https://leetcode.cn/problems/sort-an-array)

**题目描述:**
给你一个整数数组 `nums`，请你将该数组升序排列。这里特指使用**归并排序 (Merge Sort)** 来实现。

**解题思路 (归并排序):**
归并排序是一种分治算法。
1.  **分解 (Divide)**:
    *   如果数组长度为 0 或 1，则它已经排序，直接返回。
    *   否则，将数组从中间分成两个大致相等的子数组。
2.  **解决 (Conquer)**:
    *   递归地对两个子数组进行归并排序。
3.  **合并 (Merge)**:
    *   将两个已排序的子数组合并成一个单一的、排序的数组。
    *   合并操作：创建临时空间，使用双指针分别指向两个子数组的开头，比较元素，将较小的元素放入结果数组，并移动相应指针，直到一个子数组耗尽，然后将另一个子数组的剩余部分复制到结果数组。

**Python 实现:**
```python
class Solution:
    def sortArray(self, nums: list[int]) -> list[int]: # For LeetCode 912
        if len(nums) <= 1:
            return nums
        
        mid = len(nums) // 2
        left_half = self.sortArray(nums[:mid])
        right_half = self.sortArray(nums[mid:])
        
        return self.merge(left_half, right_half)

    def merge(self, left: list[int], right: list[int]) -> list[int]:
        merged = []
        p1, p2 = 0, 0 # Pointers for left and right halves

        while p1 < len(left) and p2 < len(right):
            if left[p1] <= right[p2]:
                merged.append(left[p1])
                p1 += 1
            else:
                merged.append(right[p2])
                p2 += 1
        
        # Append remaining elements from left (if any)
        while p1 < len(left):
            merged.append(left[p1])
            p1 += 1
        
        # Append remaining elements from right (if any)
        while p2 < len(right):
            merged.append(right[p2])
            p2 += 1
            
        return merged
```

```java
import java.util.Arrays; // For creating subarrays if needed, or use indices

class Solution {
    public int[] sortArray(int[] nums) { // For LeetCode 912
        if (nums == null || nums.length <= 1) {
            return nums;
        }
        mergeSort(nums, 0, nums.length - 1);
        return nums;
    }

    private void mergeSort(int[] nums, int left, int right) {
        if (left >= right) {
            return;
        }
        int mid = left + (right - left) / 2;
        mergeSort(nums, left, mid);
        mergeSort(nums, mid + 1, right);
        merge(nums, left, mid, right);
    }

    private void merge(int[] nums, int left, int mid, int right) {
        // Create temporary arrays for left and right subarrays
        int n1 = mid - left + 1;
        int n2 = right - mid;

        int[] L = new int[n1];
        int[] R = new int[n2];

        // Copy data to temp arrays L[] and R[]
        for (int i = 0; i < n1; ++i)
            L[i] = nums[left + i];
        for (int j = 0; j < n2; ++j)
            R[j] = nums[mid + 1 + j];

        // Merge the temp arrays back into nums[left...right]
        int i = 0; // Initial index of first subarray
        int j = 0; // Initial index of second subarray
        int k = left; // Initial index of merged subarray

        while (i < n1 && j < n2) {
            if (L[i] <= R[j]) {
                nums[k] = L[i];
                i++;
            } else {
                nums[k] = R[j];
                j++;
            }
            k++;
        }

        // Copy remaining elements of L[] if any
        while (i < n1) {
            nums[k] = L[i];
            i++;
            k++;
        }

        // Copy remaining elements of R[] if any
        while (j < n2) {
            nums[k] = R[j];
            j++;
            k++;
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N log N)。分解是 log N 层，每层合并操作总共是 O(N)。
*   空间复杂度: O(N)。递归调用栈空间是 O(log N)。`merge` 操作通常需要 O(N) 的额外空间来存储临时合并的子数组 (如 Java 实现中的 `L` 和 `R` 数组，或者 Python 中创建的 `merged` 列表和切片)。可以进行原地归并，但实现复杂且效率较低。

### 115: [剑指 Offer 09. 用两个栈实现队列 (Implement Queue using Stacks LCOF)](https://leetcode.cn/problems/yong-liang-ge-zhan-shi-xian-dui-lie-lcof)

**题目描述:**
用两个栈实现一个队列。队列的声明如下，请实现它的两个函数 `appendTail` 和 `deleteHead` ，分别完成在队列尾部插入整数和在队列头部删除整数的功能。(若队列中没有元素，`deleteHead` 操作返回 -1)

**解题思路:**
使用两个栈：`stack_in` (用于入队) 和 `stack_out` (用于出队)。
1.  **`appendTail(value)` (入队):**
    *   直接将 `value` 压入 `stack_in`。
2.  **`deleteHead()` (出队):**
    *   **检查 `stack_out`**:
        *   如果 `stack_out` 不为空，直接从 `stack_out` 弹出一个元素并返回。
        *   如果 `stack_out` 为空：
            *   **检查 `stack_in`**:
                *   如果 `stack_in` 也为空，说明队列为空，返回 -1。
                *   如果 `stack_in` 不为空，将 `stack_in` 中的所有元素依次弹出并压入 `stack_out` (这样元素的顺序就反过来了，符合队列的先进先出)。
                *   然后，从 `stack_out` 弹出一个元素并返回。

**Python 实现:**
```python
class CQueue:
    def __init__(self):
        self.stack_in = []
        self.stack_out = []

    def appendTail(self, value: int) -> None:
        self.stack_in.append(value)

    def deleteHead(self) -> int:
        if not self.stack_out: # If stack_out is empty
            if not self.stack_in: # And stack_in is also empty, queue is empty
                return -1
            # Transfer elements from stack_in to stack_out
            while self.stack_in:
                self.stack_out.append(self.stack_in.pop())
        
        # stack_out now has elements in correct order (or was already non-empty)
        if not self.stack_out: # Should not happen if stack_in had elements
            return -1 # Re-check, though logic above should handle it.
                      # This case would only occur if after transfer, stack_out is still empty.
                      # This means stack_in was empty to begin with and initial check `if not self.stack_in:` handled it.
                      # So, if we reach here, stack_out should have elements from stack_in.
        
        return self.stack_out.pop()

# Your CQueue object will be instantiated and called as such:
# obj = CQueue()
# obj.appendTail(value)
# param_2 = obj.deleteHead()
```

**Java 实现:**
```java
import java.util.Stack; // or java.util.Deque with addLast/removeLast

class CQueue {
    private Stack<Integer> stackIn;
    private Stack<Integer> stackOut;

    public CQueue() {
        stackIn = new Stack<>();
        stackOut = new Stack<>();
    }
    
    public void appendTail(int value) {
        stackIn.push(value);
    }
    
    public int deleteHead() {
        if (stackOut.isEmpty()) { // If stackOut is empty
            if (stackIn.isEmpty()) { // And stackIn is also empty, queue is empty
                return -1;
            }
            // Transfer elements from stackIn to stackOut
            while (!stackIn.isEmpty()) {
                stackOut.push(stackIn.pop());
            }
        }
        
        // stackOut now has elements in correct order (or was already non-empty)
        // If after attempting to populate stackOut, it's still empty, then the queue was truly empty.
        if (stackOut.isEmpty()) { 
             return -1;
        }
        
        return stackOut.pop();
    }
}

 * Your CQueue object will be instantiated and called as such:
 * CQueue obj = new CQueue();
 * obj.appendTail(value);
 * int param_2 = obj.deleteHead();
 */
```

**复杂度分析 (摊销 Amortized):**
*   `appendTail`: O(1)。
*   `deleteHead`:
    *   最坏情况: O(N)，当 `stack_out` 为空且 `stack_in` 中有 N 个元素时，需要 N 次 `pop` 和 N 次 `push`。
    *   **摊销分析**: 每个元素最多被压入 `stack_in` 一次，从 `stack_in` 弹出一次，压入 `stack_out` 一次，从 `stack_out` 弹出一次。总共 4 次操作。所以，对于 M 次 `deleteHead` 操作，总时间是 O(M + N_total_elements)。平均下来，每次 `deleteHead` 是 O(1) (摊销)。
*   空间复杂度: O(N)，最坏情况下所有元素都在一个栈中。

### 116: [61. 旋转链表 (Rotate List)](https://leetcode.cn/problems/rotate-list)

**题目描述:**
给你一个链表的头节点 `head` ，旋转链表，将链表每个节点向右移动 `k` 个位置。

**解题思路:**
1.  **处理边界情况**: 如果 `head` 为空，或 `head.next` 为空 (链表少于2个节点)，或 `k` 为 0，则无需旋转，直接返回 `head`。
2.  **计算链表长度 `n` 并找到尾节点**: 遍历链表得到长度 `n`，同时找到尾节点 `tail`。
3.  **处理 `k`**: 实际需要移动的步数是 `k % n` (因为移动 `n` 步等于没有移动)。如果 `k % n == 0`，也无需旋转。
4.  **形成环**: 将尾节点 `tail` 的 `next` 指针指向头节点 `head`，形成一个环形链表。
5.  **找到新的尾节点和新的头节点**:
    *   新的尾节点是原链表中从头开始数的第 `(n - (k % n) - 1)` 个节点 (0-indexed)。或者说，新的头节点是第 `(n - k % n)` 个节点。
    *   从 `head` 开始，向前走 `n - (k % n) - 1` 步，到达新的尾节点 `new_tail`。
6.  **断开环**:
    *   新的头节点是 `new_head = new_tail.next`。
    *   将 `new_tail.next` 设置为 `null`，断开环。
7.  返回 `new_head`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def rotateRight(self, head: ListNode, k: int) -> ListNode:
        if not head or not head.next or k == 0:
            return head

        # 1. Calculate length and find the tail
        n = 1
        current = head
        while current.next:
            current = current.next
            n += 1
        tail = current # tail is the last node

        # 2. Adjust k
        k = k % n
        if k == 0:
            return head # No rotation needed

        # 3. Form a cycle
        tail.next = head
        
        # 4. Find the new tail (which is (n - k - 1)th node from original head)
        # The new head will be (n - k)th node from original head.
        # We need to travel (n - k) steps from original tail to find new head in the cycle,
        # or (n - k -1) steps from original head to find new tail.
        steps_to_new_tail = n - k - 1
        new_tail = head
        for _ in range(steps_to_new_tail):
            new_tail = new_tail.next
            
        # 5. Break the cycle
        new_head = new_tail.next
        new_tail.next = None
        
        return new_head
```

```java
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }

            return head;

        int n = 1;
        ListNode current = head;
        while (current.next != null) {
            current = current.next;
            n++;
        }
        ListNode tail = current; // tail is the last node

        // 2. Adjust k
        k = k % n;
        if (k == 0) {
            return head; // No rotation needed
        }

        // 3. Form a cycle
        tail.next = head;
        
        // 4. Find the new tail (which is (n - k - 1)th node from original head)
        // The new head will be (n - k)th node from original head.
        int stepsToNewTail = n - k - 1; // Number of steps from current head to the new tail
        ListNode newTail = head;
        for (int i = 0; i < stepsToNewTail; i++) {
            newTail = newTail.next;
        }
            
        // 5. Break the cycle
        ListNode newHead = newTail.next;
        newTail.next = null;
        
        return newHead;
    }
}
```

*   空间复杂度: O(1)。

### 117: [123. 买卖股票的最佳时机 III (Best Time to Buy and Sell Stock III)](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii)

**题目描述:**
给定一个数组，它的第 `i` 个元素是一支给定的股票在第 `i` 天的价格。
设计一个算法来计算你所能获取的最大利润。你最多可以完成 **两笔** 交易。
注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**解题思路 (动态规划):**
定义状态：
*   `buy1`: 到目前为止，进行第一次买入后，手上的最大利润 (通常是负数，表示花费)。
*   `sell1`: 到目前为止，进行第一次卖出后，手上的最大利润。
*   `buy2`: 到目前为止，进行第二次买入后 (要求在第一次卖出之后)，手上的最大利润。
*   `sell2`: 到目前为止，进行第二次卖出后，手上的最大利润。

**状态转移方程 (遍历每一天的价格 `price`):**
1.  `buy1 = max(buy1, -price)`
    *   保持之前的 `buy1`，或者在今天以 `price` 买入 (利润变为 `-price`)。
2.  `sell1 = max(sell1, buy1 + price)`
    *   保持之前的 `sell1`，或者在今天以 `price` 卖出 (基于之前的 `buy1` 状态)。
3.  `buy2 = max(buy2, sell1 - price)`
    *   保持之前的 `buy2`，或者在今天以 `price` 进行第二次买入 (利润是 `sell1 - price`，因为 `sell1` 是第一次交易的净利润)。
4.  `sell2 = max(sell2, buy2 + price)`
    *   保持之前的 `sell2`，或者在今天以 `price` 进行第二次卖出 (基于之前的 `buy2` 状态)。

**初始化:**
*   `buy1 = -infinity` (或 `-prices`)
*   `sell1 = 0`
*   `buy2 = -infinity` (或 `-prices`)
*   `sell2 = 0`
    为了简化，通常将 `buy1` 和 `buy2` 初始化为非常小的负数 (如 `-prices` 或 `Integer.MIN_VALUE`)。`sell1` 和 `sell2` 初始化为 0。

**最终结果:** `sell2`

**Python 实现:**
```python
class Solution:

        if not prices or len(prices) < 2:
            return 0

        buy1 = -float('inf')
        sell1 = 0
        buy2 = -float('inf')
        sell2 = 0

        for price in prices:
            # For the first transaction
            # Max profit after buying the first stock
            buy1 = max(buy1, -price) 
            # Max profit after selling the first stock
            sell1 = max(sell1, buy1 + price)
            
            # For the second transaction
            # Max profit after buying the second stock (must be after first sell)
            buy2 = max(buy2, sell1 - price)
            # Max profit after selling the second stock
            sell2 = max(sell2, buy2 + price)
            
        return sell2
```

### 118: [498. 对角线遍历 (Diagonal Traverse)](https://leetcode.cn/problems/diagonal-traverse)

**题目描述:**
给你一个大小为 `m x n` 的矩阵 `mat` ，按对角线遍历并返回矩阵中的所有元素。

**解题思路 (模拟):**
1.  获取矩阵的行数 `rows` 和列数 `cols`。
2.  初始化结果列表 `result` 和当前位置 `(r, c) = (0, 0)`.
3.  总共需要遍历 `rows * cols` 个元素。
4.  **方向**: 用一个变量 `direction` 标记当前遍历方向：`1` 表示右上 (`up-right`)，`-1` 表示左下 (`down-left`)。初始为右上。
5.  在循环中（`rows * cols` 次）：
    a.  将 `mat[r][c]` 加入 `result`。
    b.  根据 `direction` 计算下一个位置 `(next_r, next_c)`:
    *   如果 `direction == 1` (右上): `next_r = r - 1`, `next_c = c + 1`.
    *   如果 `direction == -1` (左下): `next_r = r + 1`, `next_c = c - 1`.
    c.  **处理边界和转向**:
    *   **如果当前是右上方向 (`direction == 1`)**:
    *   如果 `next_c >= cols` (超出右边界)：转向，新位置 `(r, c+1)` 改为 `(r+1, c)`。 `direction = -1`。`r++`。
    *   Else if `next_r < 0` (超出上边界)：转向，新位置 `(r-1,c)` 改为 `(r, c+1)`。`direction = -1`。 `c++`。
    *   Else (未越界)：`r = next_r`, `c = next_c`。
    *   **如果当前是左下方向 (`direction == -1`)**:
    *   如果 `next_r >= rows` (超出下边界)：转向，新位置 `(r+1,c)` 改为 `(r, c+1)`。`direction = 1`。 `c++`。
    *   Else if `next_c < 0` (超出左边界)：转向，新位置 `(r,c-1)` 改为 `(r+1,c)`。`direction = 1`。 `r++`。
    *   Else (未越界)：`r = next_r`, `c = next_c`。
    *  **注意处理边界条件的顺序**: 优先检查会同时触碰两个角的条件 (例如，右上移动时同时出右边界和上边界)，不过一般设计是如果出右边界，就向下调整，如果出上边界就向右调整。
    *   A more structured way for changing direction and finding the next head of a diagonal:
        When going up-right:
        If `c == cols - 1` (hit right wall): `r++`, change direction.
        Else if `r == 0` (hit top wall): `c++`, change direction.
        Else: `r--`, `c++`.
        When going down-left:
        If `r == rows - 1` (hit bottom wall): `c++`, change direction.
        Else if `c == 0` (hit left wall): `r++`, change direction.
        Else: `r++`, `c--`.

**Python 实现:**
```python
class Solution:
    def findDiagonalOrder(self, mat: list[list[int]]) -> list[int]:
        if not mat or not mat[0]:
            return []

        rows, cols = len(mat), len(mat[0])
        result = [0] * (rows * cols)
        r, c = 0, 0
        direction_up_right = True # True for up-right, False for down-left

        for i in range(rows * cols):
            result[i] = mat[r][c]

            if direction_up_right:
                # Try to move up-right
                if c == cols - 1: # Hit right wall
                    r += 1
                    direction_up_right = False
                elif r == 0:    # Hit top wall
                    c += 1
                    direction_up_right = False
                else: # Normal up-right move
                    r -= 1
                    c += 1
            else: # direction_down_left
                # Try to move down-left
                if r == rows - 1: # Hit bottom wall
                    c += 1
                    direction_up_right = True
                elif c == 0:    # Hit left wall
                    r += 1
                    direction_up_right = True
                else: # Normal down-left move
                    r += 1
                    c -= 1
        return result
```

### 119: [958. 二叉树的完全性检验 (Check Completeness of a Binary Tree)](https://leetcode.cn/problems/check-completeness-of-a-binary-tree)

**题目描述:**
给你一棵二叉树的根节点 `root` ，请你判断这棵树是否是一棵 **完全二叉树** 。
在一棵 完全二叉树 中，除了最后一层外，所有层都被完全填满，并且最后一层中的所有节点都尽可能靠左排列。最后一层（第 `h` 层）中可以包含 `1` 到 `2^h` 个节点。

**解题思路 (层序遍历 / BFS):**
1.  使用队列进行层序遍历。
2.  在遍历过程中，一旦遇到一个 `null` 节点，就设置一个标志 `found_null = true`。
3.  如果在 `found_null` 为 `true` 的情况下，又遇到了一个非 `null` 节点，则该树不是完全二叉树，返回 `false`。
4.  如果遍历完成都没有违反上述条件，则该树是完全二叉树，返回 `true`。
    *   基本思想：在层序遍历中，所有非空节点应该连续出现。一旦出现空节点，之后所有节点都必须是空节点。

**Python 实现:**
```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        if not root:
            return True
        
        queue = deque([root])
        found_null = False # Flag to indicate if a null node has been encountered
        
        while queue:
            node = queue.popleft()
            
            if node is None:
                found_null = True
            else: # node is not None
                if found_null: # If we previously found a null, but now found a non-null
                    return False 
                
                queue.append(node.left)
                queue.append(node.right)
                
        return True
```

**Java 实现:**
```java
import java.util.LinkedList;
import java.util.Queue;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public boolean isCompleteTree(TreeNode root) {
        if (root == null) {
            return true;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        boolean foundNull = false; // Flag to indicate if a null node has been encountered

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();

            if (node == null) {
                foundNull = true;
            } else { // node is not null
                if (foundNull) { // If we previously found a null, but now found a non-null
                    return false;
                }
                // Add children to queue regardless of whether they are null or not initially,
                // The check for `node == null` handles it.
                queue.offer(node.left);
                queue.offer(node.right);
            }
        }
        return true;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点入队出队一次。
*   空间复杂度: O(W)，其中 W 是树的最大宽度 (队列大小)。

### 120: [55. 跳跃游戏 (Jump Game)](https://leetcode.cn/problems/jump-game)

**题目描述:**
给你一个非负整数数组 `nums` ，你最初位于数组的 **第一个下标** 。数组中的每个元素代表你在该位置可以跳跃的最大长度。
判断你是否能够到达最后一个下标。

**解题思路 (贪心):**
1.  维护一个变量 `max_reachable_index`，表示从当前位置以及之前所有位置出发，能够到达的最远下标。初始时，`max_reachable_index = 0` (因为我们从下标 0 开始)。
2.  遍历数组 `nums` (用索引 `i` 从 0 到 `len(nums) - 1`):
    a.  **检查是否可达当前位置**: 如果 `i > max_reachable_index`，说明当前位置 `i` 无法从之前的任何位置到达，因此也无法到达最后一个下标。返回 `false`。
    b.  **更新最远可达距离**: 从当前位置 `i` 出发，可以跳到 `i + nums[i]`。更新 `max_reachable_index = max(max_reachable_index, i + nums[i])`。
    c.  **提前成功判断**: 如果 `max_reachable_index >= len(nums) - 1` (最后一个下标)，说明已经可以到达最后一个下标，返回 `true`。
3.  如果循环完成，说明可以逐步到达最后一个位置（或者在循环中已返回 true）。在循环结束后，`max_reachable_index >= len(nums) - 1` 也是一种判断方法，但通常在循环内判断更直接。如果循环结束都没能使 `max_reachable_index` 覆盖末尾，且没有提前因为不可达而返回 `false`，那应该意味着所有位置都可达，并且末尾也被覆盖了。
    A simpler loop structure for greedy is: iterate `i` from `0` to `n-1`. `max_reachable = max(max_reachable, i + nums[i])`. If at any point `i > max_reachable_so_far_from_previous_steps`, return `false`. This means `max_reachable` for index `i` must be updated based on its value *before* checking `i` against it if we modify it in place.
    Better approach for loop `for i in range(n)`:
    If `i <= max_reachable_index`: `max_reachable_index = max(max_reachable_index, i + nums[i])`
    Else (current `i` is not reachable): `return False`
    Final check: `return max_reachable_index >= n - 1` (although it usually returns true inside loop if condition met).
    No, actually:
    Loop `i` from `0` to `n-1`. If `i > max_reachable` return `False`. `max_reachable = max(max_reachable, i + nums[i])`.
    After the loop, if we haven't returned `False`, it means we could reach every `i` up to potentially the last one. If the loop finishes, it implies we could reach `n-1`. Return `True`.

**Python 实现:**
```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        n = len(nums)
        if n == 0:
            return False # Or True if empty array means "trivially can reach end (which doesn't exist)" - problem states "non-negative", implies not empty. Assume non-empty if needed.
                        # LeetCode generally: if n=1, [0], True. if n=1, [X], True.
        if n == 1:
            return True

        max_reachable_index = 0
        for i in range(n):
            # If the current index i is beyond the furthest we could have reached so far
            if i > max_reachable_index:
                return False
            
            # Update the furthest reachable index from current or previous positions
            max_reachable_index = max(max_reachable_index, i + nums[i])
            
            # Optimization: If we can already reach or pass the last index
            if max_reachable_index >= n - 1:
                return True
                
        # If the loop completes, it means we've processed all elements up to a point.
        # The return True inside the loop should cover all successful cases.
        # If loop finishes and not returned True, it implies it might not have reached.
        # However, the first `if i > max_reachable_index:` catches all impossible scenarios.
        # So if loop completes, it means all i were <= max_reachable_index and
        # the last value of max_reachable_index covers or passes n-1.
        # The current structure will return true within loop.
        # If last index isn't reachable, 'i > max_reachable_index' would hit.
        # What if last nums[n-1] makes max_reachable_index >= n-1 only at i = n-1?
        # e.g. [2,0,0] n=3.
        # i=0: max_r = max(0,0+2)=2. max_r >= 2 (3-1), return True.
        # e.g. [0,1] n=2.
        # i=0: max_r=max(0,0+0)=0.
        # i=1: 1 > max_r(0) is True. return False. Correct.
        
        # This final return false would be for cases where loop finishes
        # but the final max_reachable_index does not cover n-1,
        # yet the `if i > max_reachable_index` was never triggered.
        # Example: [1,0,0] n=3
        # i=0: max_r = max(0, 0+1)=1. Not >=2.
        # i=1: 1 <= max_r(1). max_r = max(1, 1+0)=1. Not >=2.
        # i=2: 2 > max_r(1) is True. Return False.
        
        # The structure looks correct. The last return in current form is essentially unreachable
        # because either we reach the end (return True) or get stuck (return False earlier).
        # However, let's be safe: the condition is simply whether max_reachable_index >= n-1 at the end of considering all *reachable* points.
        # The Pythonic loop range(n) will cover up to n-1. If `i` becomes `n-1`, we update `max_reachable_index`. If this value is `>=n-1`, it means it's reachable.
        
        # Simpler structure for loop:
        # max_reach = 0
        # for i, num in enumerate(nums):
        #     if i > max_reach:
        #         return False
        #     max_reach = max(max_reach, i + num)
        # return True # If loop completes, we could reach every point `i`
        
        # The `return True` inside the loop (optimization) is fine. If loop finishes and
        # this didn't trigger, then `max_reachable_index` must have been less than `n-1`.
        # If this is the case, then we never returned `False` earlier means that every `i` was reachable,
        # but the final `max_reachable_index` didn't cross the line.
        # This seems contradictory if the loop truly finishes all N iterations without returning `False` for `i > max_r`.
        # Ah, the crucial part is: we only need to ensure `max_reachable_index` *eventually* covers `n-1`.

        return False # This line means: loop finished, but max_reachable_index never reached n-1

                     # If n=0, we already handled (assume this case gives error based on constraints "non-negative integers", usually means array exists)
                     # if n=1 (e.g., [0]), `max_reachable_index = 0`, which is `n-1`, so returns true.

    def canJump_canonical(self, nums: list[int]) -> bool:

        n = len(nums)

                return False

                     # Or if n=0 then depends. Assume n >= 1. If n=1, first iter: i=0, max_reach=nums[0].
```

```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        n = len(nums)
        if n == 0: # Typically constraints imply n>=1
            return False 
        
        max_reachable_index = 0
        for i in range(n):
            if i > max_reachable_index: # Current position i is not reachable
                return False
            
            max_reachable_index = max(max_reachable_index, i + nums[i])
            
            # Optimization: if the end is already reachable
            if max_reachable_index >= n - 1:
                return True
                
        # This return is effectively unreachable if n > 0 because either:
        # 1. `max_reachable_index >= n - 1` becomes true -> `return True`
        # 2. `i > max_reachable_index` becomes true -> `return False`
        # If the loop finishes for all `i` up to `n-1` without returning False for condition 2,
        # it means that `n-1 <= max_reachable_index` must have held at the start of iteration `i=n-1`.
        # Then in that iteration, `max_reachable_index` would be updated and then the condition `max_reachable_index >= n - 1` would surely be true.
        # Exception: what if `nums = [0]` and `n=1`?
        # i=0. `0 > 0` is false. `max_r = max(0, 0+0) = 0`. `0 >= 1-1 (0)` is true. Returns true. Correct.
        return False # Logically, if n > 0, this is hard to reach. But let it stand for default case.
                     # More correct logic for after loop is usually based on max_reach value IF no optimization used.
                     # With optimization `if max_reachable_index >= n-1: return True`, this implies failure.
```

```java
class Solution {
    public boolean canJump(int[] nums) {
        int n = nums.length;
        if (n == 0) { // As per typical LeetCode handling, 0-length array is problem-specific.
            return false; // Or true if "no jumps needed for no target". Given problem: can reach *last index*.
        }
        
        int maxReachableIndex = 0;
        for (int i = 0; i < n; i++) {
            if (i > maxReachableIndex) { // Current position i is not reachable
                return false;
            }
            
            maxReachableIndex = Math.max(maxReachableIndex, i + nums[i]);
            
            // Optimization: if the end is already reachable
            if (maxReachableIndex >= n - 1) {
                return true;
            }
        }
        
        // If loop completes without returning true (optimized path),
        // it means n-1 was never covered.
        // And if it never returned false, implies all i up to a point were reachable.
        // This should generally be covered by the two returns inside the loop for n > 0.
        return false; // Fallback for any edge cases, implies n-1 not reached.
                      // E.g. n=1, [0] -> i=0, maxReach=0. 0 >= 0, return true.
                      // For a single-element array [X], it always returns true by this logic.
    }
}
```
