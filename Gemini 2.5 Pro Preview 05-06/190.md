### 181: [补充题9. 36进制加法](https://mp.weixin.qq.com/s/XcKQwnwCh5nZsz-DLHJwzQ)

**题目描述 (根据常见 N 进制加法推断):**
给定两个以字符串形式表示的 36 进制非负整数，返回它们的和，同样以 36 进制字符串形式表示。
36 进制数码包括 `0-9` 和 `a-z` (小写，表示 10-35)。

**解题思路 (模拟手动加法):**
这与二进制加法或十进制字符串相加 (如 LeetCode 415. 字符串相加) 的逻辑非常相似，只是基数为 36。

1.  **字符与值的映射**:
    *   创建一个函数或映射，将字符 `'0'-'9'` 转换为整数 `0-9`。
    *   创建一个函数或映射，将字符 `'a'-'z'` 转换为整数 `10-35`。
    *   同样，需要一个反向映射，将整数 `0-35` 转换回对应的字符。
2.  **模拟加法**:
    *   从两个输入字符串的末尾开始，逐位进行相加。
    *   使用一个 `carry` (进位) 变量，初始为 0。
    *   初始化指针 `p1` 指向 `num1` 末尾，`p2` 指向 `num2` 末尾。
    *   初始化一个结果字符串构建器 `result_builder`。
    *   当 `p1 >= 0` 或 `p2 >= 0` 或 `carry > 0` 时，循环：
        a.  获取当前位的数值：
        *   `val1 = charToValue(num1[p1])` 如果 `p1 >= 0`，否则为 0。
        *   `val2 = charToValue(num2[p2])` 如果 `p2 >= 0`，否则为 0。
        b.  计算当前位的和：`current_sum = val1 + val2 + carry`。
        c.  当前位的结果字符是 `valueToChar(current_sum % 36)`。
        d.  新的进位是 `carry = current_sum // 36` (或 `current_sum / 36` 取整)。
        e.  将当前位结果字符添加到 `result_builder` 的**前端**。
        f.  移动指针：`p1--`，`p2--`。
3.  如果 `result_builder` 为空（例如输入 "0", "0"），则结果应为 "0"。
4.  将 `result_builder` 转换为字符串并返回。

**Python 实现:**
```python
class Solution:
    def add36Strings(self, num1: str, num2: str) -> str:
        
        def char_to_value(c: str) -> int:
            if '0' <= c <= '9':
                return int(c)
            else: # 'a' to 'z'
                return ord(c) - ord('a') + 10

        def value_to_char(v: int) -> str:
            if 0 <= v <= 9:
                return str(v)
            else: # 10 to 35
                return chr(ord('a') + v - 10)

        p1 = len(num1) - 1
        p2 = len(num2) - 1
        carry = 0
        result_chars = []

        while p1 >= 0 or p2 >= 0 or carry > 0:
            val1 = char_to_value(num1[p1]) if p1 >= 0 else 0
            val2 = char_to_value(num2[p2]) if p2 >= 0 else 0
            
            current_sum = val1 + val2 + carry
            
            digit_to_add_val = current_sum % 36
            carry = current_sum // 36
            
            result_chars.append(value_to_char(digit_to_add_val))
            
            if p1 >= 0:
                p1 -= 1
            if p2 >= 0:
                p2 -= 1
        
        if not result_chars: # Should happen only if both inputs are empty, problem implies non-negative.
                             # If inputs are "0", "0", result_chars will be ['0']
            return "0"

        return "".join(result_chars[::-1])

```

**Java 实现:**
```java
class Solution {
    private int charToValue(char c) {
        if (c >= '0' && c <= '9') {
            return c - '0';
        } else { // 'a' to 'z'
            return c - 'a' + 10;
        }
    }

    private char valueToChar(int v) {
        if (v >= 0 && v <= 9) {
            return (char) (v + '0');
        } else { // 10 to 35
            return (char) (v - 10 + 'a');
        }
    }

    public String add36Strings(String num1, String num2) {
        if (num1 == null || num1.isEmpty()) return num2;
        if (num2 == null || num2.isEmpty()) return num1;

        int p1 = num1.length() - 1;
        int p2 = num2.length() - 1;
        int carry = 0;
        StringBuilder resultBuilder = new StringBuilder();

        while (p1 >= 0 || p2 >= 0 || carry > 0) {
            int val1 = (p1 >= 0) ? charToValue(num1.charAt(p1)) : 0;
            int val2 = (p2 >= 0) ? charToValue(num2.charAt(p2)) : 0;

            int currentSum = val1 + val2 + carry;
            
            int digitToAddVal = currentSum % 36;
            carry = currentSum / 36;
            
            resultBuilder.append(valueToChar(digitToAddVal));
            
            if (p1 >= 0) p1--;
            if (p2 >= 0) p2--;
        }
        
        if (resultBuilder.length() == 0) return "0"; // Should not happen for valid non-empty inputs unless both are "0"
        return resultBuilder.reverse().toString();
    }
}
```

*   时间复杂度: O(max(L1, L2))，其中 L1 和 L2 是两个输入字符串的长度。
*   空间复杂度: O(max(L1, L2))，用于存储结果字符串。

### 182: [剑指 Offer 29. 顺时针打印矩阵](https://leetcode.cn/problems/shun-shi-zhen-da-yin-ju-zhen-lcof)
(此题与 LeetCode 54. 螺旋矩阵 为同一题目，题号 #023 已解答)

**题目描述:**
输入一个矩阵，按照从外向里以顺时针的顺序依次打印出每一个数字。

**解题思路 (模拟边界):**
此题与之前解答的 #023 LeetCode 54. 螺旋矩阵完全相同。
1.  定义四个边界：`top`, `bottom`, `left`, `right`。
2.  循环遍历并收缩边界：
    *   从左到右 (上边界)。
    *   从上到下 (右边界)。
    *   从右到左 (下边界) - 需检查 `top <= bottom`。
    *   从下到上 (左边界) - 需检查 `left <= right`。

**Python 实现 (同 #023):**
```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]: # Function name matches LeetCode 54
        if not matrix or not matrix[0]:
            return []

        rows = len(matrix)
        cols = len(matrix[0])
        result = []
        
        top, bottom, left, right = 0, rows - 1, 0, cols - 1

        while top <= bottom and left <= right:
            for c in range(left, right + 1):
                result.append(matrix[top][c])
            top += 1
            if top > bottom: break

            for r in range(top, bottom + 1):
                result.append(matrix[r][right])
            right -= 1
            if left > right: break

            if top <= bottom:
                for c in range(right, left - 1, -1):
                    result.append(matrix[bottom][c])
                bottom -= 1
            if top > bottom: break # Added after solution 023 to make it more robust for single row/col

            if left <= right:
                for r in range(bottom, top - 1, -1):
                    result.append(matrix[r][left])
                left += 1
            # No need for: if left > right: break here, while condition will catch it.
            
        return result
```

```java
            right--;
            if (left > right) break;

            if (top <= bottom) {
                for (int c = right; c >= left; c--) resultList.add(matrix[bottom][c]);
                bottom--;
            }
             if (top > bottom) break;


            if (left <= right) {
                for (int r = bottom; r >= top; r--) resultList.add(matrix[r][left]);
                left++;
            }
        }
        
        int[] resArray = new int[resultList.size()];
        for (int i = 0; i < resultList.size(); i++) {
            resArray[i] = resultList.get(i);
        }

    }
```

### 183: [剑指 Offer 27. 二叉树的镜像 (Invert Binary Tree)](https://leetcode.cn/problems/er-cha-shu-de-jing-xiang-lcof)
(此题与 LeetCode 226. Invert Binary Tree 为同一题目)

**题目描述:**
请完成一个函数，输入一个二叉树，该函数输出它的镜像。

**解题思路 (递归/DFS):**
1.  **基准情况**: 如果当前节点 `node` 为空，则返回 `null` (或直接返回)。
2.  **交换左右子节点**: 交换当前节点的左子节点和右子节点。
    *   `temp = node.left`
    *   `node.left = node.right`
    *   `node.right = temp`
3.  **递归处理**: 对（新的）左子树和（新的）右子树分别递归调用镜像函数。
    *   `mirrorTree(node.left)`
    *   `mirrorTree(node.right)`
4.  返回处理后的根节点 `node`。

**也可以先递归后交换。**

**Python 实现:**
```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Solution:
    def mirrorTree(self, root: TreeNode) -> TreeNode: # Function name matches Jianzhi Offer
        if not root:
            return None
        
        # Swap children
        # temp = root.left
        # root.left = root.right
        # root.right = temp
        
        # Recursively call for children BEFORE swap is also fine (more common for invert)
        left_mirror = self.mirrorTree(root.left)
        right_mirror = self.mirrorTree(root.right)
        
        # Swap the (mirrored) children
        root.left = right_mirror
        root.right = left_mirror
        
        return root
```

**Java 实现:**
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

class Solution {
    public TreeNode mirrorTree(TreeNode root) { // Function name matches Jianzhi Offer
        if (root == null) {
            return null;
        }

        // Recursively mirror the left and right subtrees
        TreeNode leftMirror = mirrorTree(root.left);
        TreeNode rightMirror = mirrorTree(root.right);

        // Swap the (mirrored) children of the current node
        root.left = rightMirror;
        root.right = leftMirror;
        
        return root;
    }
}
```
**Iterative (BFS) approach is also possible:**
Use a queue. For each node dequeued, swap its children, then enqueue its (original) children.

**复杂度分析:**
*   时间复杂度: O(N)，N 是树中的节点数，每个节点访问一次。
*   空间复杂度: O(H)，H 是树的高度，用于递归调用栈。最坏情况 O(N)。

### 184: [剑指 Offer 39. 数组中出现次数超过一半的数字 (Majority Element)](https://leetcode.cn/problems/shu-zu-zhong-chu-xian-ci-shu-chao-guo-yi-ban-de-shu-zi-lcof)
(此题与 LeetCode 169. Majority Element 为同一题目)

**题目描述:**
数组中有一个数字出现的次数超过数组长度的一半，请找出这个数字。
你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**解题思路:**
**1. 哈希表计数 (O(N) time, O(N) space):**
* 遍历数组，用哈希表记录每个数字的出现次数。
* 再次遍历哈希表或在计数过程中检查，找出次数超过 `n/2` 的数字。

**2. 排序 (O(N log N) time, O(1) or O(N) space):**
* 对数组排序。
* 出现次数超过一半的数字，排序后必然位于数组的中间位置 `nums[n/2]`。

**3. Boyer-Moore 投票算法 (O(N) time, O(1) space):** (最优解)
* 初始化 `candidate = null` (或任一元素), `count = 0`。
* 遍历数组 `nums`:
    *   如果 `count == 0`，将 `candidate` 设为当前元素 `num`，`count = 1`。
    *   如果 `num == candidate`，则 `count++`。
    *   如果 `num != candidate`，则 `count--`。
* 遍历结束后，`candidate` 中存储的即为多数元素。
* (如果题目不保证多数元素一定存在，则需要第二遍遍历来验证 `candidate` 的次数是否真的超过一半。)

**Python 实现 (Boyer-Moore):**
```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        candidate = 0 # Can be any initial value if count starts at 0
        count = 0
        
        for num in nums:
            if count == 0:
                candidate = num
                count = 1
            elif num == candidate:
                count += 1
            else: # num != candidate
                count -= 1
        
        # According to problem statement, majority element always exists.
        # No need for a second pass to verify.
        return candidate
```

### 185: [1004. 最大连续1的个数 III (Max Consecutive Ones III)](https://leetcode.cn/problems/max-consecutive-ones-iii)

**题目描述:**
给定一个二进制数组 `nums` 和一个整数 `k`，如果我们可以将 `k` 个 `0` 翻转成 `1` ，返回数组中访问到的最长连续 `1` 的子数组的长度。

**解题思路 (滑动窗口):**
1.  使用滑动窗口 `[left, right]` 来表示当前考虑的子数组。
2.  维护窗口内 `0` 的数量 `zeros_count`。
3.  不断向右扩展窗口 (`right++`):
    *   如果 `nums[right]` 是 `0`，则 `zeros_count++`。
4.  **调整窗口**: 当 `zeros_count > k` 时，说明窗口内的 `0` 太多，无法全部翻转。需要收缩窗口左边界 (`left++`):
    *   如果 `nums[left]` 是 `0`，则 `zeros_count--`。
5.  在每次调整后 (或者说，在每次 `right` 移动后，只要 `zeros_count <= k`)，当前的窗口长度 `right - left + 1` 是一个有效的连续 `1` (加上翻转) 的子数组长度。更新最大长度 `max_len = max(max_len, right - left + 1)`。
6.  `right` 遍历完整个数组后，`max_len` 即为所求。

**Python 实现:**
```python
class Solution:
    def longestOnes(self, nums: list[int], k: int) -> int:
        left = 0
        max_len = 0
        zeros_count = 0
        
        for right in range(len(nums)):
            if nums[right] == 0:
                zeros_count += 1
            
            # While the number of zeros in the window exceeds k, shrink the window from the left
            while zeros_count > k:
                if nums[left] == 0:
                    zeros_count -= 1
                left += 1
            
            # At this point, the window [left, right] is valid
            # (i.e., number of zeros <= k)
            max_len = max(max_len, right - left + 1)
            
        return max_len
```

**Java 实现:**
```java
class Solution {
    public int longestOnes(int[] nums, int k) {
        int left = 0;
        int maxLen = 0;
        int zerosCount = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                zerosCount++;
            }

            // While the number of zeros in the window exceeds k, shrink the window from the left
            while (zerosCount > k) {
                if (nums[left] == 0) {
                    zerosCount--;
                }
                left++;
            }

            // At this point, the window [left, right] is valid
            // (i.e., number of zeros <= k)
            maxLen = Math.max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)。`left` 和 `right` 指针都只向前移动，每个元素最多被访问两次。
*   空间复杂度: O(1).

### 186: [补充题14. 阿拉伯数字转中文数字](https://leetcode.cn/problems/None)

**题目描述 (推断):**
将一个非负整数（阿拉伯数字）转换为其对应的中文数字字符串表示。
例如：123 -> "一百二十三", 105 -> "一百零五", 10000 -> "一万", 100000000 -> "一亿"。

**解题思路:**
这是一个分段处理的问题，中文数字系统有“万”和“亿”这样的大单位。
基本思路是每四位一组进行处理，因为中文数字有“万”，“亿”，“万亿”等单位。

1.  **基础数字和单位**:
    *   `digits = ["零", "一", "二", "三", "四", "五", "六", "七", "八", "九"]`
    *   `units_section = ["", "十", "百", "千"]` (节内单位)
    *   `units_large = ["", "万", "亿", "万亿"]` (大单位)

2.  **处理四位一组 (section_to_chinese)**:
    *   输入一个小于10000的整数。
    *   例如，`1234`: "一千二百三十四"。 `0105`: "一百零五"。`0012`: "一十二" 或 "十二"。`0000`: "零" (但在整体转换中可能不输出)。
    *   特殊处理 "零"：
        *   连续的零只读一个 "零"。
        *   末尾的零不读 (如 1200 -> "一千二百")。
        *   如果数字是 `10`，通常读 "十" 而不是 "一十"。
    *   函数 `section_to_chinese(n)` 返回 n (0-9999) 的中文表示。
        *   如果 n = 0, return "零" (or handle by caller).
        *   Iterate digits from千, 百, 十, 个.
        *   Append `digits[digit] + units_section[pos]` if digit > 0.
        *   Handle '零' carefully: if current digit is 0 but previous was not 0 and we are not at the end of section, append '零'. Avoid "零零".

3.  **主转换函数**:
    *   如果输入是0，返回 "零"。
    *   从低位到高位，每四位取一组。
    *   对每一组调用 `section_to_chinese`。
    *   将该组的结果与对应的大单位 `units_large` 拼接。
    *   组合所有组的结果。注意 "零" 的处理，例如 "一亿零二百万零五十"。如果一个四位组是0 (e.g., 100000000, 中间四位是0)，则可能需要加一个 "零"，但要避免 "万零亿"。

**Python 实现 (简化的示例，可能不完全覆盖所有精细规则):**
```python
class Solution:
    def numberToChinese(self, num: int) -> str:
        if num == 0:
            return "零"

        digits_map = ["零", "一", "二", "三", "四", "五", "六", "七", "八", "九"]
        section_units = ["", "十", "百", "千"] # Units within a 4-digit section
        large_units = ["", "万", "亿", "万亿"] # Units for sections

        def section_to_chinese_str(section_num): # Process a number < 10000
            if section_num == 0:
                return "" # Let caller decide if "零" is needed
            
            s = ""
            # Example: 1023 -> "一千零二十三" ; 1200 -> "一千二百"; 20 -> "二十"; 5 -> "五"
            
            temp_num_str = str(section_num)
            n = len(temp_num_str)
            zero_pending = False

            for i in range(n):
                digit_val = int(temp_num_str[i])
                unit_pos = n - 1 - i # 0 for个, 1 for十, 2 for百, 3 for千
                
                if digit_val != 0:
                    if zero_pending: # Previous was zero, now non-zero
                        s += digits_map[0]
                        zero_pending = False
                    # Special case for "一十" -> "十"
                    if not (digit_val == 1 and unit_pos == 1 and (n == 2 or (n > 2 and temp_num_str[i-1] == '0' )) and s == "" ) : # crude first '十' e.g., 10, 12, not 112
                         if not(digit_val == 1 and unit_pos == 1 and n == 2 and section_num >=10 and section_num <=19):
                            s += digits_map[digit_val]
                    s += section_units[unit_pos]
                else: # digit_val == 0
                    if i < n -1 and int(temp_num_str[i+1]) != 0 : # Only add zero if it's not trailing and next isn't zero
                       zero_pending = True
            return s

        parts = []
        large_unit_idx = 0
        if num == 0: return digits_map[0]
        
        while num > 0:
            section = num % 10000
            if section > 0 :
                section_str = section_to_chinese_str(section)
                current_part = section_str + large_units[large_unit_idx]
                parts.insert(0, current_part)
            elif parts and parts[0][0] != '零' and large_unit_idx > 0: # Avoid "万零亿", add '零' if section is 0 but prev was not.
                # Check if a "零" is needed because this entire section is 0
                # but it's not the least significant section being processed (large_unit_idx > 0)
                # and the previous part was not ending in zero.
                # This logic can be complex to get perfect "零" placement.
                 if parts and not any(p.startswith("零") for p in parts): # if previous significant parts exist
                    # Add '零' if necessary, only if there are more significant parts.
                    # A full zero section might need a "零" if it's between non-zero sections.
                    # E.g., 100000001 -> "一亿零一"
                    # This heuristic may not be perfect for all "零" rules.
```

### 187: [349. 两个数组的交集 (Intersection of Two Arrays)](https://leetcode.cn/problems/intersection-of-two-arrays)

**题目描述:**
给定两个数组 `nums1` 和 `nums2` ，返回它们的 **交集** 。输出结果中的每个元素一定是 **唯一** 的。我们可以 **不考虑输出结果的顺序** 。

**解题思路:**
**1. 使用哈希集合:**
*   将 `nums1` 中的所有元素添加到一个哈希集合 `set1` (处理唯一性)。
*   创建一个结果哈希集合 `resultSet`。
*   遍历 `nums2`，对于 `nums2` 中的每个元素 `num`：
    *   如果 `num` 存在于 `set1` 中，将其加入 `resultSet` (确保结果也唯一)。
*   将 `resultSet` 转换为列表/数组返回。
*   时间复杂度: O(N + M)，空间复杂度: O(N + M) in worst case.

**2. 双指针 (如果数组可以排序):**
*   对 `nums1` 和 `nums2` 进行排序。
*   使用两个指针 `p1` 和 `p2` 分别指向两个数组的开头。
*   创建一个结果集合 (以处理唯一性) `resultSet`。
*   当 `p1 < len(nums1)` 且 `p2 < len(nums2)`:
    *   如果 `nums1[p1] == nums2[p2]`，将此元素加入 `resultSet`，`p1++`, `p2++`。
    *   如果 `nums1[p1] < nums2[p2]`，则 `p1++`。
    *   如果 `nums1[p1] > nums2[p2]`，则 `p2++`。
*   时间复杂度: O(N log N + M log M) for sorting, O(N+M) for scan. Total dominated by sort.
*   空间复杂度: O(K) for result (K intersection size) + sort space (O(log N) or O(N)).

**Python 实现 (哈希集合):**
```python
class Solution:
    def intersection(self, nums1: list[int], nums2: list[int]) -> list[int]:
        set1 = set(nums1)
        result_set = set()
        
        for num in nums2:
            if num in set1:
                result_set.add(num)
        
        return list(result_set)
```

### 188: [97. 交错字符串 (Interleaving String)](https://leetcode.cn/problems/interleaving-string)

**题目描述:**
给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错** 组成的。
两个字符串 `s` 和 `t` **交错** 的定义与过程如下，其中每个字符串都会被分割成若干 **非空** 子字符串：
`s = s1 + s2 + ... + sn`
`t = t1 + t2 + ... + tm`
`|n - m| <= 1`
交错是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`
**注意：** `a + b` 意味着字符串 `a` 和 `b` 连接。
(LeetCode's actual problem is simpler: check if s3 can be formed by interleaving all characters of s1 and s2 while maintaining their relative order.)

**Actual LeetCode Problem Reframing:**
Is `s3` formed by an interleaving of `s1` and `s2`? This means `s3` should contain all characters from `s1` and `s2`, and the relative order of characters within `s1` and `s2` must be preserved. Total length of `s1` and `s2` must be length of `s3`.

**解题思路 (动态规划):**
`dp[i][j]` 表示 `s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符能否交错组成 `s3` 的前 `i+j` 个字符。

1.  长度检查: 如果 `len(s1) + len(s2) != len(s3)`，返回 `false`。
2.  `dp` 表大小: `(len(s1) + 1) x (len(s2) + 1)`.
3.  **初始化**:
    *   `dp = true` (空 `s1` 和空 `s2` 可以组成空 `s3`)。
    *   `dp[i]`: `s1` 的前 `i` 个字符能否组成 `s3` 的前 `i` 个字符。 `dp[i] = dp[i-1] and s1[i-1] == s3[i-1]`.
    *   `dp[j]`: `s2` 的前 `j` 个字符能否组成 `s3` 的前 `j` 个字符。 `dp[j] = dp[j-1] and s2[j-1] == s3[j-1]`.
4.  **状态转移**:
    For `dp[i][j]` (representing `s1[0...i-1]` and `s2[0...j-1]` forming `s3[0...i+j-1]`):
    *   Consider `s3[i+j-1]` (the (i+j)-th character of `s3`):
        *   **Option 1: `s3[i+j-1]` 来自 `s1[i-1]`**
            If `s1[i-1] == s3[i+j-1]`, then we check if `s1`的前 `i-1` 个和 `s2`的前 `j` 个能组成 `s3` 的前 `i+j-1` 个 (i.e., `dp[i-1][j]`).
            If so, `dp[i][j]` can be `true`.
        *   **Option 2: `s3[i+j-1]` 来自 `s2[j-1]`**
            If `s2[j-1] == s3[i+j-1]`, then we check if `s1`的前 `i` 个和 `s2`的前 `j-1` 个能组成 `s3` 的前 `i+j-1` 个 (i.e., `dp[i][j-1]`).
            If so, `dp[i][j]` can be `true`.
    *   `dp[i][j] = (dp[i-1][j] and s1[i-1] == s3[i+j-1]) OR (dp[i][j-1] and s2[j-1] == s3[i+j-1])`.
    *   Need `i > 0` for first part, `j > 0` for second part.
5.  结果是 `dp[len(s1)][len(s2)]`.

**Python 实现:**
```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        l1, l2, l3 = len(s1), len(s2), len(s3)
        if l1 + l2 != l3:
            return False

        # dp[i][j] means s1[:i] and s2[:j] can form s3[:i+j]
        dp = [[False for _ in range(l2 + 1)] for _ in range(l1 + 1)]

        dp[0][0] = True # Empty s1 and empty s2 form empty s3

        # Initialize first row (s1 is empty)
        for j in range(1, l2 + 1):
            dp[0][j] = dp[0][j-1] and s2[j-1] == s3[j-1]
        
        # Initialize first column (s2 is empty)
        for i in range(1, l1 + 1):
            dp[i][0] = dp[i-1][0] and s1[i-1] == s3[i-1]

        # Fill the rest of the dp table
        for i in range(1, l1 + 1):
            for j in range(1, l2 + 1):
                # Current char in s3 is s3[i+j-1]
                # Option 1: current char of s3 comes from s1
                option1 = dp[i-1][j] and s1[i-1] == s3[i+j-1]
                # Option 2: current char of s3 comes from s2
                option2 = dp[i][j-1] and s2[j-1] == s3[i+j-1]
                dp[i][j] = option1 or option2
                
        return dp[l1][l2]

# Space optimized solution O(min(l1,l2)) using 1D dp array is also possible.
```

```java
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int l1 = s1.length();
        int l2 = s2.length();
        int l3 = s3.length();

        if (l1 + l2 != l3) {
            return false;
        }

        // dp[i][j] indicates if s1's first i chars and s2's first j chars
        // can interleave to form s3's first i+j chars.
        boolean[][] dp = new boolean[l1 + 1][l2 + 1];

        dp[0][0] = true; // Empty s1 and empty s2 form empty s3

        // Initialize first row (s1 is empty, using only s2)
        for (int j = 1; j <= l2; j++) {
            dp[0][j] = dp[0][j-1] && (s2.charAt(j-1) == s3.charAt(j-1));
        }
        
        // Initialize first column (s2 is empty, using only s1)
        for (int i = 1; i <= l1; i++) {
            dp[i][0] = dp[i-1][0] && (s1.charAt(i-1) == s3.charAt(i-1));
        }

        // Fill the rest of the dp table
        for (int i = 1; i <= l1; i++) {
            for (int j = 1; j <= l2; j++) {
                // Current char in s3 is s3.charAt(i+j-1)
                // Option 1: s3 char matches s1 char, and previous part was valid
                boolean option1 = dp[i-1][j] && (s1.charAt(i-1) == s3.charAt(i+j-1));
                // Option 2: s3 char matches s2 char, and previous part was valid
                boolean option2 = dp[i][j-1] && (s2.charAt(j-1) == s3.charAt(i+j-1));
                
                dp[i][j] = option1 || option2;
            }
        }
        return dp[l1][l2];
    }
}
```

### 189: [264. 丑数 II (Ugly Number II)](https://leetcode.cn/problems/ugly-number-ii)

**题目描述:**
给你一个整数 `n` ，请你找出并返回第 `n` 个 **丑数** 。
**丑数** 就是只包含质因数 `2`、`3` 和 `5` 的正整数。

**解题思路 (动态规划 + 三指针):**
丑数序列可以认为是这样生成的：
1.  第一个丑数是 1。
2.  后续的丑数都是由已知的丑数分别乘以 2, 3, 或 5 得到的。
3.  我们希望按升序生成丑数。

维护三个指针 `p2`, `p3`, `p5`，分别指向丑数序列中，下一个可以用来乘以 2, 3, 5 以生成新丑数的最小丑数。
`dp[i]` 表示第 `i` 个丑数 (1-indexed)。
`dp = 1`. (or `dp=1` if 1-indexed array for dp).

1.  初始化 `dp` 数组 (大小 `n`)，`dp = 1`.
2.  初始化三个指针 `p2 = 0`, `p3 = 0`, `p5 = 0`.
3.  对于 `i` 从 1 到 `n-1` (生成第 `i+1` 个丑数):
    a.  下一个丑数候选：
    *   `next_ugly_by_2 = dp[p2] * 2`
    *   `next_ugly_by_3 = dp[p3] * 3`
    *   `next_ugly_by_5 = dp[p5] * 5`
    b.  `dp[i] = min(next_ugly_by_2, next_ugly_by_3, next_ugly_by_5)`。
    c.  更新指针：如果 `dp[i]` 是由 `dp[px] * x` 产生的，则 `px++`。
    *   如果 `dp[i] == next_ugly_by_2`, `p2++`.
    *   如果 `dp[i] == next_ugly_by_3`, `p3++`.
    *   如果 `dp[i] == next_ugly_by_5`, `p5++`.
    (注意：这里可能是 `if`, `if`, `if` 而不是 `if/else if`，因为可能一个数可以通过多种方式得到，例如 6 = 2\*3 = 3\*2。我们都需要推进相应的指针以避免重复生成或跳过。)
4.  返回 `dp[n-1]`.

**Python 实现:**
```python
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        if n <= 0:
            return 0 # Or raise error
        if n == 1:
            return 1
            
        ugly_numbers = [0] * n
        ugly_numbers[0] = 1
        
        p2, p3, p5 = 0, 0, 0 # Pointers for 2, 3, 5 multipliers for the ugly_numbers array
        
        for i in range(1, n):
            next_ugly_by_2 = ugly_numbers[p2] * 2
            next_ugly_by_3 = ugly_numbers[p3] * 3
            next_ugly_by_5 = ugly_numbers[p5] * 5
            
            next_ugly = min(next_ugly_by_2, next_ugly_by_3, next_ugly_by_5)
            ugly_numbers[i] = next_ugly
            
            # Increment pointers for numbers that produced this next_ugly
            if next_ugly == next_ugly_by_2:
                p2 += 1
            if next_ugly == next_ugly_by_3: # Note: use 'if', not 'elif', because multiple paths might yield same ugly number (e.g., 6)
                p3 += 1
            if next_ugly == next_ugly_by_5:
                p5 += 1
                
        return ugly_numbers[n-1]
```

        *   对于每个分割后的子字符串，递归调用本函数，找到其中满足条件的最长子串长度。
        *   返回这些递归调用结果中的最大值。

```java
        }
        if (k <= 1) { // Any non-empty substring is fine, as each char appears >= 1 times
            return n;
        }

        // Count character frequencies in the current string s
        Map<Character, Integer> counts = new HashMap<>();
        for (char c : s.toCharArray()) {
            counts.put(c, counts.getOrDefault(c, 0) + 1);
        }

        // Check if all characters in s meet the k-frequency requirement
        boolean allCharsValid = true;
        for (char c : counts.keySet()) {
            if (counts.get(c) < k) {
                allCharsValid = false;
                break;
            }
        }

        if (allCharsValid) {
            return n; // The entire string s is a valid candidate
        }

        // If not, at least one character (a splitter) has frequency < k.
        // We need to split the string by such characters.
        // The result is the max of longestSubstring on the substrings.
        int maxLen = 0;
        int currentStart = 0;
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (counts.get(c) < k) { // This character is a splitter
                // Process substring s[currentStart...i-1]
                if (i > currentStart) {
                     maxLen = Math.max(maxLen, longestSubstring(s.substring(currentStart, i), k));
                }
                currentStart = i + 1; // Next substring starts after this splitter
            }
        }
        
        // Process the last segment (if any)
        if (currentStart < n) {
            maxLen = Math.max(maxLen, longestSubstring(s.substring(currentStart, n), k));
        } else if (currentStart == n && n > 0 && counts.get(s.charAt(n-1)) >= k) {
            //This check handles cases like "a", k=1 (single char string),
            //or "aa", k=2 for last segment after a split like "baac", k=2 split by 'b'
            //currentStart might be equal to n if the last char was a splitter.
            //Actually the s.substring(currentStart, n) will be "" if currentStart==n, this case fine.
        }


        return maxLen;
    }
}
```
The Java splitting logic iterates through the string. If char `s[i]` is invalid, all valid substrings must lie entirely to the left or right of `s[i]`. So we process the segment `s[currentStart...i-1]`, then update `currentStart = i + 1`. After the loop, the final segment `s[currentStart...n-1]` is processed.

**复杂度分析 (分治法):**
*   时间复杂度: Worst case O(N^2) (e.g., "ababc", k=2, splits are small). Average case is better. At each level of recursion (max 26 levels, one for each char), we do O(N) work for counting and splitting. So it is roughly O(26*N) = O(N).
*   空间复杂度: O(H_recursion) for recursion stack, where H_recursion can be up to 26 (or N in weird split cases). Counts map O(1) as alphabet size is fixed.

Alternative using sliding window: Iterate for `numUniqueTarget` from 1 to 26. For each `numUniqueTarget`, find the longest substring with exactly `numUniqueTarget` unique characters, where each appears at least `k` times. This has O(26 * N) time.
