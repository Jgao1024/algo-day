### 121: [剑指 Offer 36. 二叉搜索树与双向链表 (Convert Binary Search Tree to Sorted Doubly Linked List)](https://leetcode.cn/problems/er-cha-sou-suo-shu-yu-shuang-xiang-lian-biao-lcof)

**题目描述:**
输入一棵二叉搜索树，将该二叉搜索树转换成一个排序的循环双向链表。要求不能创建任何新的节点，只能调整树中节点指针的指向。

**解题思路 (中序遍历):**
二叉搜索树的中序遍历结果是按节点值升序排列的。我们可以利用这个特性，在遍历过程中修改节点的 `left` 和 `right` 指针，将它们变成双向链表的 `prev` 和 `next` 指针。
1.  使用两个全局（或类成员）指针：`head` (指向双向链表的头节点) 和 `prev` (指向上一个在中序遍历中访问过的节点)。
2.  定义一个递归函数 `dfs(current_node)` (中序遍历):
    a.  如果 `current_node` 为空，返回。
    b.  递归调用 `dfs(current_node.left)` 处理左子树。
    c.  **处理当前节点**:
    i.  如果 `prev` 为空 (说明 `current_node` 是第一个被访问的节点，即链表的头):
    *   将 `head` 指向 `current_node`。
    ii. 否则 (`prev` 不为空):
    *   将 `prev.right` (next) 指向 `current_node`。
    *   将 `current_node.left` (prev) 指向 `prev`。
    iii.将 `prev` 更新为 `current_node` (为下一个节点做准备)。
    d.  递归调用 `dfs(current_node.right)` 处理右子树。
3.  主函数调用 `dfs(root)`。
4.  **处理循环**: 遍历结束后，`head` 指向链表头，`prev` 指向链表尾。将它们连接起来形成循环：`head.left = prev`，`prev.right = head`。

**Python 实现:**
```python
class Node: # LeetCode problem uses 'Node'
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def __init__(self):
        self.head = None
        self.prev = None

    def treeToDoublyList(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        self.dfs(root)
        
        # Connect head and tail to make it circular
        if self.head and self.prev:
            self.head.left = self.prev
            self.prev.right = self.head
            
        return self.head

    def dfs(self, current_node: 'Node'):
        if not current_node:
            return

        # In-order: Left
        self.dfs(current_node.left)

        # In-order: Process current node
        if self.prev: # If prev exists, link it with current_node
            self.prev.right = current_node
            current_node.left = self.prev
        else: # This is the first node (head of the list)
            self.head = current_node
        
        self.prev = current_node # Update prev to current_node

        # In-order: Right
        self.dfs(current_node.right)
```

            return null;

        if (head != null && prev != null) {
            head.left = prev;
            prev.right = head;
        }
        
        return head;

    private void dfs(Node currentNode) {

            return;
        }

        // In-order: Left
        dfs(currentNode.left);

        // In-order: Process current node
        if (prev != null) { // If prev exists, link it with currentNode
            prev.right = currentNode;
            currentNode.left = prev;
        } else { // This is the first node (head of the list)
            head = currentNode;
        }
        prev = currentNode; // Update prev to currentNode

        // In-order: Right
        dfs(currentNode.right);
    }

### 122: [40. 组合总和 II (Combination Sum II)](https://leetcode.cn/problems/combination-sum-ii)

**题目描述:**
给定一个候选人编号的集合 `candidates` 和一个目标数 `target` ，找出 `candidates` 中所有可以使数字和为 `target` 的组合。
`candidates` 中的每个数字在每个组合中只能使用 **一次** 。
**注意：** 解集不能包含重复的组合。

**解题思路 (回溯法 + 剪枝):**
1.  **排序**: 首先对 `candidates` 数组进行排序。这有助于后续处理重复元素，确保生成的组合是唯一的，并且可以进行剪枝。
2.  **定义回溯函数 `backtrack(current_combination, remaining_target, start_index)`**:
    *   `current_combination`: 当前已选数字的组合。
    *   `remaining_target`: 还需要凑齐的目标和。
    *   `start_index`: 当前可以开始选择的 `candidates` 数组的起始索引 (避免重复使用元素和生成重复的组合顺序)。
3.  **基准情况**:
    *   如果 `remaining_target == 0`：找到了一个有效组合，将其加入结果列表。
    *   如果 `remaining_target < 0`：当前路径无效，返回。
4.  **递归步骤 (选择 - 探索 - 撤销选择)**:
    *   从 `start_index` 遍历到 `candidates.length - 1`：
        a.  **剪枝 (处理重复)**: 如果 `i > start_index` 且 `candidates[i] == candidates[i-1]`，说明当前数字与上一个在同一层级中处理过的数字相同 (并且上一个没有被选入当前组合，否则 `start_index`会不同)，为避免重复组合，跳过当前数字。
        b.  **选择**: 将 `candidates[i]` 加入 `current_combination`。
        c.  **探索**: 递归调用 `backtrack(current_combination, remaining_target - candidates[i], i + 1)`。(注意是 `i + 1` 因为每个数字只能用一次)。
        d.  **撤销选择**: 将 `candidates[i]` 从 `current_combination` 中移除。
5.  主函数初始化结果列表，调用 `backtrack([], target, 0)`。

**Python 实现:**
```python
class Solution:
    def combinationSum2(self, candidates: list[int], target: int) -> list[list[int]]:
        result = []
        candidates.sort() # Sort to handle duplicates and for ordered combinations
        
        current_combination = []

        def backtrack(remaining_target, start_index):
            if remaining_target == 0:
                result.append(list(current_combination)) # Add a copy
                return
            if remaining_target < 0:
                return

            for i in range(start_index, len(candidates)):
                # Skip duplicates: if current num is same as previous one,
                # and we are not at the very first element of this level's choices
                if i > start_index and candidates[i] == candidates[i-1]:
                    continue
                
                # Optimization: if current candidate is > remaining_target,
                # no need to check further since candidates are sorted.
                if candidates[i] > remaining_target:
                    break

                # Choose
                current_combination.append(candidates[i])
                # Explore (use i + 1 since each number can be used only once)
                backtrack(remaining_target - candidates[i], i + 1)
                # Unchoose (Backtrack)
                current_combination.pop()

        backtrack(target, 0)
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(candidates); // Sort to handle duplicates
        
        List<Integer> currentCombination = new ArrayList<>();
        backtrack(candidates, target, 0, currentCombination, result);
        
        return result;
    }

    private void backtrack(int[] candidates, int remainingTarget, int startIndex, 
                           List<Integer> currentCombination, List<List<Integer>> result) {
        if (remainingTarget == 0) {
            result.add(new ArrayList<>(currentCombination)); // Add a copy
            return;
        }
        if (remainingTarget < 0) {
            return;
        }

        for (int i = startIndex; i < candidates.length; i++) {
            // Skip duplicates: if current num is same as previous one,
            // and we are not at the very first element of this level's choices.
            if (i > startIndex && candidates[i] == candidates[i-1]) {
                continue;
            }

            // Optimization: if current candidate is > remaining_target,
            // no need to check further since candidates are sorted.
            if (candidates[i] > remainingTarget) {
                break;
            }

            // Choose
            currentCombination.add(candidates[i]);
            // Explore (use i + 1 since each number can be used only once)
            backtrack(candidates, remainingTarget - candidates[i], i + 1, currentCombination, result);
            // Unchoose (Backtrack)
            currentCombination.remove(currentCombination.size() - 1);
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(2^N * N) in worst-case due to combination generation (where N is the number of candidates). Sorting is O(N log N). Copying combination to result is O(K) where K is avg length. The precise analysis is complex, depending on how many valid combinations exist.
*   空间复杂度: O(N) (or O(target) in some scenarios) for the recursion stack depth and storing `current_combination`.

### 123: [16. 最接近的三数之和 (3Sum Closest)](https://leetcode.cn/problems/3sum-closest)

**题目描述:**
给你一个长度为 `n` 的整数数组 `nums` 和一个目标值 `target` 。请你从 `nums` 中选出三个整数，使它们的和与 `target` 最接近。
返回这三个数的和。
假定每组输入只存在唯一答案。

**解题思路 (排序 + 双指针):**
1.  **排序**: 对数组 `nums` 进行排序。
2.  初始化 `closest_sum = nums + nums + nums` (或一个基于 `target` 和 `nums` 范围的合理初始值，比如一个极大值对应的差值)。
3.  **主循环 (固定第一个数)**:
    *   遍历排序后的数组，用 `nums[i]` 作为第一个数 (`i` from `0` to `n-3`).
    *   **双指针 (寻找另外两个数)**:
        *   初始化 `left = i + 1` 和 `right = nums.length - 1`。
        *   当 `left < right` 时：
            a.  计算 `current_sum = nums[i] + nums[left] + nums[right]`。
            b.  **比较接近程度**:
            *   如果 `abs(current_sum - target) < abs(closest_sum - target)`，更新 `closest_sum = current_sum`。
            c.  **移动指针以更接近 target**:
            *   如果 `current_sum < target`，则 `left++` (尝试增大和)。
            *   如果 `current_sum > target`，则 `right--` (尝试减小和)。
            *   如果 `current_sum == target`，直接返回 `target` (因为这是最接近的)。
            d.  处理重复（可选，但可以提高效率）：如果 `left` 或 `right` 移动后与之前的值相同，可以继续移动直到不同，但这主要用于3Sum的去重，对3Sum Closest影响不大。
4.  返回 `closest_sum`。

**Python 实现:**
```python
class Solution:
    def threeSumClosest(self, nums: list[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        closest_sum = float('inf') # Initialize with a value that guarantees first sum is closer

        for i in range(n - 2):
            # Optional: Skip duplicate for the first element if it helps avoid redundant checks
            # though for "closest" it's not strictly for correctness.
            if i > 0 and nums[i] == nums[i-1]:
                continue

            left, right = i + 1, n - 1
            while left < right:
                current_sum = nums[i] + nums[left] + nums[right]

                if abs(current_sum - target) < abs(closest_sum - target):
                    closest_sum = current_sum
                
                if current_sum < target:
                    left += 1
                    # Optional: Skip duplicates for left pointer
                    # while left < right and nums[left] == nums[left - 1]:
                    #     left += 1
                elif current_sum > target:
                    right -= 1
                    # Optional: Skip duplicates for right pointer
                    # while left < right and nums[right] == nums[right + 1]:
                    #     right -= 1
                else: # current_sum == target
                    return target # Found the exact sum, which is the closest
        
        return closest_sum

### 124: [74. 搜索二维矩阵 (Search a 2D Matrix)](https://leetcode.cn/problems/search-a-2d-matrix)

**题目描述:**
给你一个满足下述两条属性的 `m x n` 整数矩阵：
*   每行中的整数从左到右按非严格递增顺序排列。
*   每行的第一个整数大于前一行的最后一个整数。
    给定一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

**解题思路 (将二维视为一维 / 两次二分):**
由于矩阵的特殊属性 (每行递增，且下一行的开头大于上一行的末尾)，整个矩阵可以看作是一个扁平化后的一维有序数组。

**方法1: 视为一维有序数组进行二分查找**
1.  获取行数 `rows` 和列数 `cols`。
2.  对索引 `0` 到 `rows * cols - 1` 进行二分查找。
3.  对于二分查找的中间索引 `mid_1d`，将其转换为二维坐标 `(r, c)`：
    *   `r = mid_1d / cols` (整数除法)
    *   `c = mid_1d % cols`
4.  比较 `matrix[r][c]` 与 `target`，并相应调整二分查找的 `low` 和 `high`。

**方法2: 先定位行，再定位列 (两次二分查找)** (不如此题更优的方法1简洁，但也可行)
1.  对第一列的所有元素进行二分查找，找到 `target` 可能所在的行 `r` (即 `matrix[r] <= target` 且 ( `r`是最后一行 或 `matrix[r+1] > target`) )。
2.  如果找不到这样的行 (例如 `target` 小于 `matrix` 或大于 `matrix[rows-1][cols-1]`)，则返回 `false`。
3.  在找到的行 `r` 中，对该行 `matrix[r]` 进行二分查找 `target`。

方法1更直接且符合本题特性。

**Python 实现 (方法1):**
```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        
        rows = len(matrix)
        cols = len(matrix[0])
        
        low = 0
        high = rows * cols - 1 # Total number of elements - 1
        
        while low <= high:
            mid_1d = low + (high - low) // 2
            r = mid_1d // cols
            c = mid_1d % cols
            
            if matrix[r][c] == target:
                return True
            elif matrix[r][c] < target:
                low = mid_1d + 1
            else: # matrix[r][c] > target
                high = mid_1d - 1
                
        return False
```

### 125: [剑指 Offer 51. 数组中的逆序对 (Shu Zu Zhong De Ni Xu Dui LCOF)](https://leetcode.cn/problems/shu-zu-zhong-de-ni-xu-dui-lcof)

**题目描述:**
在数组中的两个数字，如果前面一个数字大于后面的数字，则这两个数字组成一个逆序对。输入一个数组，求出这个数组中的逆序对的总数。

**解题思路 (归并排序):**
1.  逆序对的定义：对于数组 `nums` 中的 `i < j`，如果 `nums[i] > nums[j]`，则 `(nums[i], nums[j])` 是一个逆序对。
2.  **归并排序的思想**: 在归并排序的合并过程中，当我们将两个已排序的子数组 `L` 和 `R` 合并成一个大的有序数组时，可以有效地计算跨越这两个子数组的逆序对。
    *   假设 `L` 和 `R` 都是升序的。
    *   使用两个指针 `p1` (指向 `L`) 和 `p2` (指向 `R`)。
    *   如果要将 `L[p1]` 放入合并后的数组：说明 `L[p1]` 小于等于 `R` 中所有尚未处理的元素。与 `L[p1]` 相关的跨子数组逆序对已处理完毕。
    *   如果要将 `R[p2]` 放入合并后的数组：说明 `R[p2]` 小于 `L` 中所有尚未处理的元素 (`L[p1]` 到 `L` 的末尾)。这些尚未处理的 `L` 中的元素 (`len(L) - p1` 个) 都比 `R[p2]` 大，并且它们在原数组中的索引都小于 `R[p2]` 的索引。因此，这 `len(L) - p1` 个元素与 `R[p2]` 各自形成一个逆序对。将这个数量累加到总逆序对数。
3.  **递归结构**:
    *   `countReversePairs(array, start, end)`:
        a.  如果 `start >= end`，返回 0 (没有逆序对)。
        b.  `mid = start + (end - start) / 2`。
        c.  `count_left = countReversePairs(array, start, mid)`。
        d.  `count_right = countReversePairs(array, mid + 1, end)`。
        e.  `count_merge = mergeAndCount(array, start, mid, end)` (合并子数组并计算跨子数组的逆序对)。
        f.  返回 `count_left + count_right + count_merge`。
4.  `mergeAndCount` 函数中进行合并，并如上所述计算 `count_merge`。

**Python 实现:**```python
class Solution:
def reversePairs(self, nums: list[int]) -> int:
if not nums:
return 0

        self.count = 0
        self.merge_sort(nums, 0, len(nums) - 1)
        return self.count

    def merge_sort(self, nums: list[int], left: int, right: int) -> list[int]:
        if left == right:
            return [nums[left]] # Base case: single element array is sorted
        
        mid = left + (right - left) // 2
        
        sorted_left_half = self.merge_sort(nums, left, mid)
        sorted_right_half = self.merge_sort(nums, mid + 1, right)
        
        return self.merge_and_count(sorted_left_half, sorted_right_half)

    def merge_and_count(self, left_arr: list[int], right_arr: list[int]) -> list[int]:
        merged_arr = []
        p1, p2 = 0, 0 # Pointers for left_arr and right_arr
        
        while p1 < len(left_arr) and p2 < len(right_arr):
            if left_arr[p1] <= right_arr[p2]:
                merged_arr.append(left_arr[p1])
                p1 += 1
            else: # left_arr[p1] > right_arr[p2]
                  # This means right_arr[p2] forms reverse pairs with all remaining elements in left_arr
                merged_arr.append(right_arr[p2])
                self.count += (len(left_arr) - p1) # All remaining in left_arr are greater
                p2 += 1
        
        # Append remaining elements
        merged_arr.extend(left_arr[p1:])
        merged_arr.extend(right_arr[p2:])
        
        return merged_arr

```

**Java 实现:**
```java
class Solution {
    int count = 0;

    public int reversePairs(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        mergeSort(nums, 0, nums.length - 1);
        return count;
    }

    private int[] mergeSort(int[] nums, int left, int right) {
        if (left == right) {
            return new int[]{nums[left]}; // Base case: single element array
        }

        int mid = left + (right - left) / 2;

        int[] sortedLeftHalf = mergeSort(nums, left, mid);
        int[] sortedRightHalf = mergeSort(nums, mid + 1, right);
        
        return mergeAndCount(sortedLeftHalf, sortedRightHalf);
    }

    private int[] mergeAndCount(int[] leftArr, int[] rightArr) {
        int[] mergedArr = new int[leftArr.length + rightArr.length];
        int p1 = 0, p2 = 0, pMerged = 0;

        while (p1 < leftArr.length && p2 < rightArr.length) {
            if (leftArr[p1] <= rightArr[p2]) {
                mergedArr[pMerged++] = leftArr[p1++];
            } else { // leftArr[p1] > rightArr[p2]
                // This means rightArr[p2] forms reverse pairs with all remaining elements in leftArr
                mergedArr[pMerged++] = rightArr[p2++];
                count += (leftArr.length - p1); // All remaining in leftArr are greater
            }
        }

        // Append remaining elements
        while (p1 < leftArr.length) {
            mergedArr[pMerged++] = leftArr[p1++];
        }
        while (p2 < rightArr.length) {
            mergedArr[pMerged++] = rightArr[p2++];
        }
        
        // Note: LeetCode might expect modification of the original 'nums' array.
        // The provided solution returns new sorted arrays. 
        // For in-place modification and counting, a helper array and direct modification of 'nums' indices are needed.
        // Let's refine Java to be closer to typical in-place merge sort structure:
        return mergedArr; //This merge_and_count correctly counts, but returns a new array.
                           //For LC '剑指 Offer 51', they usually pass `nums` to `mergeAndCount` and modify `nums` within merge logic using a temp array
    }

    public int reversePairs(int[] nums) {
        if (nums == null || nums.length < 2) {
            return 0;
        }
        int[] temp = new int[nums.length];
        mergeSortRecursive(nums, 0, nums.length - 1, temp);

    private void mergeSortRecursive(int[] nums, int left, int right, int[] temp) {
        if (left >= right) {
            return;
        }
        int mid = left + (right - left) / 2;
        mergeSortRecursive(nums, left, mid, temp);
        mergeSortRecursive(nums, mid + 1, right, temp);
        mergeAndCountInPlace(nums, left, mid, right, temp);
    }

    private void mergeAndCountInPlace(int[] nums, int left, int mid, int right, int[] temp) {
        // Copy relevant part to temp array
        for (int k = left; k <= right; k++) {
            temp[k] = nums[k];
        }

        int i = left;     // Pointer for left half (in temp)
        int j = mid + 1;  // Pointer for right half (in temp)
        int k = left;     // Pointer for merged array (in nums)

        while (i <= mid && j <= right) {
            if (temp[i] <= temp[j]) {
                nums[k++] = temp[i++];
            } else { // temp[i] > temp[j]
                nums[k++] = temp[j++];
                // All elements from temp[i] to temp[mid] are greater than temp[j]
                // and form reverse pairs with temp[j]
                count += (mid - i + 1); 
            }
        }

        // Copy remaining elements from left half, if any
        while (i <= mid) {
            nums[k++] = temp[i++];
        }
        // Copy remaining elements from right half, if any (no reverse pairs here)
        while (j <= right) {
            nums[k++] = temp[j++];
        }
    }

**解题思路:**
1.  初始化 `reversed_x = 0`。
2.  循环当 `x != 0`:

    b.  `x /= 10` (移除最后一位数字)。
    c.  **溢出检查 (在追加 `pop` 之前)**:
    *   如果 `reversed_x > Integer.MAX_VALUE / 10` 或者 (`reversed_x == Integer.MAX_VALUE / 10` 且 `pop > 7`)，则 `reversed_x * 10 + pop` 会正向溢出。

    *   如果发生溢出，返回 0。
    d.  `reversed_x = reversed_x * 10 + pop`。
3.  返回 `reversed_x`。

### 127: 补充题23. 检测循环依赖

**Context:** This is typically a graph problem: given a set of tasks or modules and their dependencies, detect if there's a circular dependency (e.g., A depends on B, B depends on C, and C depends on A). This is equivalent to finding a cycle in a directed graph.
Since no specific input format is given by the "supplementary question" link (which I cannot access), I will assume a general directed graph represented by an adjacency list.

**解题思路 (DFS with state tracking):**
1.  **States**: For each node, maintain one of three states:
    *   `0` (UNVISITED): Node has not been visited yet.
    *   `1` (VISITING): Node is currently in the recursion stack of the DFS (i.e., we started visiting it, but haven't finished visiting all its descendants).
    *   `2` (VISITED): Node and all its descendants have been visited and processed (no cycle involving it as a forward path from its ancestors was found).
2.  **Graph Representation**: Use an adjacency list `adj` where `adj[u]` is a list of nodes `v` such that there's an edge `u -> v`.
3.  **Main Loop**: Iterate through all nodes `u` from `0` to `numNodes - 1`.
    *   If node `u` is `UNVISITED`, call `dfs_has_cycle(u, adj, states)`. If it returns `true`, then a cycle is found.
4.  **`dfs_has_cycle(node, adj, states)` function**:
    a.  Mark `states[node] = VISITING`.
    b.  For each `neighbor` in `adj[node]`:
    i.  If `states[neighbor] == VISITING`: A cycle is detected (back edge to a node in the current recursion path). Return `true`.
    ii. If `states[neighbor] == UNVISITED`: Recursively call `dfs_has_cycle(neighbor, adj, states)`. If this call returns `true`, propagate `true`.
    iii.If `states[neighbor] == VISITED`: This neighbor and its subtree have been processed and no cycle was found through it from previous paths. Do nothing for this neighbor.
    c.  Mark `states[node] = VISITED` (finished processing this node and its subtree from this path).
    d.  Return `false` (no cycle found starting from this `node` in this DFS traversal path).

**Python 实现 (assuming number of nodes `numCourses` and prerequisites `[[to, from], ...]` like LeetCode 207/210):**
```python
from collections import defaultdict

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool: # This finds if possible, inverse of hasCycle
        adj = defaultdict(list)
        for dest, src in prerequisites:
            adj[src].append(dest) # src -> dest

        # States: 0 = UNVISITED, 1 = VISITING, 2 = VISITED
        states = [0] * numCourses

        for i in range(numCourses):
            if states[i] == 0: # UNVISITED
                if self.dfs_has_cycle(i, adj, states):
                    return False # Cycle detected, cannot finish
        return True # No cycle detected, can finish

    def dfs_has_cycle(self, node: int, adj: defaultdict, states: list[int]) -> bool:
        states[node] = 1 # Mark as VISITING

        for neighbor in adj[node]:
            if states[neighbor] == 1: # Cycle detected (VISITING -> VISITING)
                return True
            if states[neighbor] == 0: # UNVISITED
                if self.dfs_has_cycle(neighbor, adj, states):
                    return True # Cycle found in deeper DFS call
        
        states[node] = 2 # Mark as VISITED
        return False # No cycle found from this node

import java.util.ArrayList;
import java.util.List;

class Solution {
    // Returns true if a cycle is detected, false otherwise.
    public boolean hasCircularDependency(int numItems, int[][] dependencies) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numItems; i++) {
            adj.add(new ArrayList<>());
        }
        // Assuming dependencies[i] = {item, item_it_depends_on}
        // So, edge is item_it_depends_on -> item
        for (int[] dep : dependencies) {
            int item = dep[0];
            int dependsOn = dep[1];
            adj.get(dependsOn).add(item);
        }

        // States: 0 = UNVISITED, 1 = VISITING, 2 = VISITED
        int[] states = new int[numItems];

        for (int i = 0; i < numItems; i++) {
            if (states[i] == 0) { // UNVISITED
                if (dfsHasCycle(i, adj, states)) {
                    return true; // Cycle detected
                }
            }
        }
        return false; // No cycle
    }

    private boolean dfsHasCycle(int node, List<List<Integer>> adj, int[] states) {
        states[node] = 1; // Mark as VISITING

        for (int neighbor : adj.get(node)) {
            if (states[neighbor] == 1) { // Cycle detected (VISITING -> VISITING)
                return true;
            }
            if (states[neighbor] == 0) { // UNVISITED
                if (dfsHasCycle(neighbor, adj, states)) {
                    return true; // Cycle found in deeper DFS call
                }
            }
            // If states[neighbor] == 2 (VISITED), do nothing, already processed.
        }
        
        states[node] = 2; // Mark as VISITED
        return false; // No cycle found from this node on this path
    }
}

### 128: [26. 删除排序数组中的重复项 (Remove Duplicates from Sorted Array)](https://leetcode.cn/problems/remove-duplicates-from-sorted-array)

**题目描述:**
给你一个 **非严格递增排列** 的数组 `nums` ，请你 **原地** 删除重复出现的元素，使每个元素 **只出现一次** ，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致** 。然后返回 `nums` 中唯一元素的个数。
考虑 `nums` 的唯一元素的数量为 `k` ，你需要做以下事情确保你的题解可以被通过：
更改数组 `nums` ，使 `nums` 的前 `k` 个元素包含唯一元素，并按照它们最初在 `nums` 中出现的顺序排列。`nums` 的其余元素与 `nums` 的大小不重要。
返回 `k` 。

**解题思路 (双指针):**
1.  如果数组为空，返回 0。
2.  使用一个 "慢" 指针 `insert_index` (或 `write_ptr`)，它指向下一个唯一元素应该被写入的位置。初始 `insert_index = 1` (因为 `nums` 总是唯一的，或者说如果数组非空，第一个位置将存放一个唯一元素)。
3.  使用一个 "快" 指针 `read_ptr` 从数组的第二个元素 (`index = 1`) 开始遍历到末尾。
4.  比较 `nums[read_ptr]` 和 `nums[insert_index - 1]` (即已记录的最后一个唯一元素):
    a.  如果 `nums[read_ptr]` **不等于** `nums[insert_index - 1]`，说明找到了一个新的唯一元素：
    *   将 `nums[read_ptr]` 复制到 `nums[insert_index]`。
    *   `insert_index++`。
    b.  如果相等，则跳过，`read_ptr` 继续前进。
5.  `insert_index` 的最终值就是唯一元素的数量 `k`。

**Python 实现:**
```python
class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        if not nums:
            return 0
        
        # insert_index points to where the next unique element should be placed.
        # nums[0] is always considered unique for the purpose of starting.
        insert_index = 1 
        
        for read_ptr in range(1, len(nums)):
            # If the current element is different from the previous unique element placed
            if nums[read_ptr] != nums[insert_index - 1]:
                nums[insert_index] = nums[read_ptr]
                insert_index += 1
                
        return insert_index
```

    *   `odd_list` will already be sorted in ascending order.
    *   `even_list` will be sorted in descending order.
2.  **Reverse Even List**: Reverse the `even_list` so it becomes sorted in ascending order.
3.  **Merge**: Merge the `odd_list` and the (now reversed) `even_list` using the standard algorithm for merging two sorted linked lists.

**Python 实现:**```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class SolutionSortOddEvenList:
    def sortOddEvenList(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head

        # 1. Split into odd and even lists
        odd_head = ListNode(0); odd_tail = odd_head
        even_head = ListNode(0); even_tail = even_head
        
        current = head
        is_odd_pos = True
        while current:
            if is_odd_pos:
                odd_tail.next = current
                odd_tail = odd_tail.next
            else:
                even_tail.next = current
                even_tail = even_tail.next
            
            current = current.next
            is_odd_pos = not is_odd_pos
            
        odd_tail.next = None  # Terminate odd list
        even_tail.next = None # Terminate even list
        
        # Actual heads of odd and even lists
        actual_odd_head = odd_head.next
        actual_even_head = even_head.next

        # 2. Reverse the even list
        reversed_even_head = self._reverse_list(actual_even_head)
        
        # 3. Merge the two sorted lists
        return self._merge_two_sorted_lists(actual_odd_head, reversed_even_head)

    def _reverse_list(self, head: ListNode) -> ListNode:
        prev = None
        curr = head
        while curr:
            next_temp = curr.next
            curr.next = prev
            prev = curr
            curr = next_temp
        return prev

    def _merge_two_sorted_lists(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        tail = dummy
        while l1 and l2:
            if l1.val <= l2.val:
                tail.next = l1
                l1 = l1.next
            else:
                tail.next = l2
                l2 = l2.next
            tail = tail.next
        
        if l1:
            tail.next = l1
        if l2:
            tail.next = l2
        return dummy.next

```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class SolutionSortOddEvenList {
    public ListNode sortOddEvenList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        // 1. Split into odd and even lists
        ListNode oddHeadDummy = new ListNode(0); 
        ListNode oddTail = oddHeadDummy;
        ListNode evenHeadDummy = new ListNode(0); 
        ListNode evenTail = evenHeadDummy;
        
        ListNode current = head;
        boolean isOddPos = true;
        while (current != null) {
            if (isOddPos) {
                oddTail.next = current;
                oddTail = oddTail.next;
            } else {
                evenTail.next = current;
                evenTail = evenTail.next;
            }
            current = current.next;
            isOddPos = !isOddPos;
        }
        oddTail.next = null;  // Terminate odd list
        evenTail.next = null; // Terminate even list
        
        ListNode actualOddHead = oddHeadDummy.next;
        ListNode actualEvenHead = evenHeadDummy.next;

        // 2. Reverse the even list
        ListNode reversedEvenHead = reverseList(actualEvenHead);
        
        // 3. Merge the two sorted lists
        return mergeTwoSortedLists(actualOddHead, reversedEvenHead);
    }

    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }

    private ListNode mergeTwoSortedLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                tail.next = l1;
                l1 = l1.next;
            } else {
                tail.next = l2;
                l2 = l2.next;
            }
            tail = tail.next;
        }
        
        if (l1 != null) {
            tail.next = l1;
        }
        if (l2 != null) {
            tail.next = l2;
        }
        return dummy.next;
    }
}
```

*   时间复杂度: O(N). Splitting is O(N), reversing the even list is O(N/2) = O(N), merging is O(N).
*   空间复杂度: O(1) (if dummy nodes are not counted significantly, the list nodes are reused).

### 130: [114. 二叉树展开为链表 (Flatten Binary Tree to Linked List)](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list)

**题目描述:**
给你二叉树的根结点 `root` ，请你将它展开为一个单链表：
*   展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而 `left` 子指针始终为 `null` 。
*   展开后的单链表应该与二叉树 先序遍历 顺序相同。

**解题思路:**
**方法1: 递归 (Post-order like traversal idea)**
1.  **基准情况**: 如果 `root` 为 `null`，返回。
2.  **递归处理子树**:
    *   递归调用 `flatten(root.left)`。
    *   递归调用 `flatten(root.right)`。
3.  **重新连接**: (After left and right subtrees are themselves flattened)
    a.  保存 `root` 原来的右子树 (现在是已展开的右链表头): `flattened_right = root.right`。
    b.  将 `root` 的右指针指向其左子树 (现在是已展开的左链表头): `root.right = root.left`。
    c.  将 `root` 的左指针设为 `null`: `root.left = null`。
    d.  找到当前 `root.right` (即原左子树展开后的链表) 的末尾节点。
    e.  将该末尾节点的 `right` 指针指向 `flattened_right`。

**方法2: 更高效的递归 (Pre-order "reversed" or using a global/member `prev` pointer)**
Traverse in a "Root, Right, Left" order (reversed pre-order). Maintain a `prev` pointer to the previously visited node in this reversed order. When visiting the current `root`:
1.  `root.right = prev` (The previously visited node `prev` is what should come after `root` in the final pre-order flattened list).
2.  `root.left = null`.
3.  `prev = root`.
    After this modified traversal, `prev` will be the head. This might need slight adjustment to get the correct head if `prev` is a global or class member. A common way is to make `prev` a class member and initialize it to `null`. The last node processed by this (Right, Left, Root) sequence becomes the overall list's head that this `prev` pointer will be referring to at the start of the next relevant `root` call up the stack.

Let's refine method 1 for simpler direct recursion, and ensure O(N) if possible.
**Refined Method 1 Recursive O(N):**
The key insight is that `flatten(node)` returns the tail of the flattened list starting at `node`.
   ```
   TreeNode flatten_return_tail(TreeNode node) {
       if (node == null) return null;
       if (node.left == null && node.right == null) return node; // Leaf is its own tail

       TreeNode left_tail = flatten_return_tail(node.left);
       TreeNode right_tail = flatten_return_tail(node.right);

       TreeNode original_right_subtree_head = node.right; // Save this

       if (left_tail != null) { // If there was a left subtree
           node.right = node.left; // Attach flattened left to node's right
           node.left = null;
           left_tail.right = original_right_subtree_head; // Attach original right to left's tail
       }
       // If right_tail exists, it's the new tail of the combined list.
       // If no right subtree, left_tail is the tail.
       // If no left subtree, original right_tail is the tail (or node if no right).
       return right_tail != null ? right_tail : (left_tail != null ? left_tail : node);
   }
   ```
This makes it O(N). Or even simpler using void recursive (standard):

**Python 实现 (Recursive - standard post-order like rearrangement):**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flatten(self, root: TreeNode) -> None:
        """
        Do not return anything, modify root in-place instead.
        """
        if not root:
            return

        # Flatten left and right subtrees first
        self.flatten(root.left)
        self.flatten(root.right)

        # Save the original right child (which is now a flattened list)
        original_right = root.right 

        # If there's a flattened left subtree, move it to the right
        if root.left:
            root.right = root.left
            root.left = None # Set left child to null

            # Find the tail of the new right subtree (which was the original left subtree)
            current_tail = root.right
            while current_tail.right:
                current_tail = current_tail.right
            
            # Append the original right subtree to this tail
            current_tail.right = original_right
```

**Java 实现 (Recursive - standard post-order like rearrangement):**
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public void flatten(TreeNode root) {
        if (root == null) {
            return;
        }

        // Flatten left and right subtrees first
        flatten(root.left);
        flatten(root.right);

        // Store the original right child (which is now a flattened list)
        TreeNode originalRight = root.right;

        // If there's a flattened left subtree
        if (root.left != null) {
            // Move flattened left subtree to the right
            root.right = root.left;
            root.left = null; // Set left child to null

            // Find the tail of the new right subtree (which was the original left subtree)
            TreeNode currentTail = root.right;
            while (currentTail.right != null) {
                currentTail = currentTail.right;
            }
            
            // Append the original (flattened) right subtree to this tail
            currentTail.right = originalRight;
        }
        // If root.left was null, root.right remains originalRight, no action needed for root itself.
    }
}
```

**复杂度分析 (Recursive Post-order like rearrangement):**
*   时间复杂度: O(N). While there's a `while` loop to find the tail, each node's `right` pointer is traversed at most once across all recursive calls in total when summing up the work (amortized). This means this common recursive solution is indeed O(N).
*   空间复杂度: O(H)，where H is the height of the tree, for the recursion stack. Worst case O(N).
