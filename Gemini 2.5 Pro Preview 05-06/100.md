### 091: [169. 多数元素 (Majority Element)](https://leetcode.cn/problems/majority-element)

**题目描述:**
给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。
你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**解题思路 (Boyer-Moore 投票算法):**
这是解决此问题的最优方法之一，时间复杂度为 O(N)，空间复杂度为 O(1)。
1.  初始化两个变量：`candidate` (候选多数元素) 和 `count` (计数器)。
2.  遍历数组 `nums` 中的每个元素 `num`：
    a.  如果 `count` 为 0，将 `candidate` 设置为 `num`，并将 `count` 设置为 1。
    b.  如果 `num` 等于 `candidate`，则 `count` 增加 1。
    c.  如果 `num` 不等于 `candidate`，则 `count` 减少 1。
3.  遍历结束后，`candidate` 中存储的就是多数元素。
    (由于题目保证多数元素总是存在，所以最后 `candidate` 一定是答案，无需第二遍验证)。

**Python 实现:**
```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        candidate = None
        count = 0
        for num in nums:
            if count == 0:
                candidate = num
                count = 1
            elif num == candidate:
                count += 1
            else:
                count -= 1
        return candidate
```

**Java 实现:**
```java
class Solution {
    public int majorityElement(int[] nums) {
        Integer candidate = null; // Or int candidate = 0; if nums cannot be empty and type allows
        int count = 0;
        for (int num : nums) {
            if (count == 0) {
                candidate = num;
                count = 1;
            } else if (num == candidate) {
                count++;
            } else {
                count--;
            }
        }
        // Since the problem guarantees a majority element always exists,
        // candidate will hold the majority element.
        return candidate;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，因为我们只遍历数组一次。
*   空间复杂度: O(1)，只使用了常数个额外变量。

### 092: [227. 基本计算器 II (Basic Calculator II)](https://leetcode.cn/problems/basic-calculator-ii)

**题目描述:**
给你一个字符串表达式 `s` ，请你实现一个基本计算器来计算并返回它的值。
整数除法仅保留整数部分。
你可以假设给定的表达式总是有效的。所有中间结果将在 `[-2^31, 2^31 - 1]` 的范围内。
**注意：**不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()` 。

**解题思路 (使用栈):**
这个思路的要点是处理运算符的优先级，乘除优先于加减。
1.  初始化一个栈 `stack` 用于存储待计算的数字（或中间结果）。
2.  初始化 `current_number = 0`，`last_operator = '+'` (默认第一个数是正数)。
3.  遍历字符串 `s` (可以在末尾加一个无关紧要的非数字、非空格的符号如 '+' 来触发最后一次运算)：
    a.  如果当前字符是数字，更新 `current_number`。
    b.  如果当前字符是运算符 (`+`, `-`, `*`, `/`)，或者到达字符串末尾：
    i.  根据 `last_operator` 执行操作：
    *   如果 `last_operator == '+'`：将 `current_number` 压入栈。
    *   如果 `last_operator == '-'`：将 `-current_number` 压入栈。
    *   如果 `last_operator == '*'`：弹出栈顶元素，与 `current_number` 相乘，结果压回栈。
    *   如果 `last_operator == '/'`：弹出栈顶元素，除以 `current_number` (整数除法)，结果压回栈。
    ii. 更新 `last_operator = current_char` (当前遇到的运算符)。
    iii.重置 `current_number = 0`。
4.  遍历结束后，栈中所有元素的和即为最终结果。

**Python 实现:**
```python
class Solution:
    def calculate(self, s: str) -> int:
        if not s:
            return 0
        
        stack = []
        current_number = 0
        last_operator = '+' 
        
        # Append a dummy operator to process the last number
        s_plus = s + "+" 

        for i, char in enumerate(s_plus):
            if char.isdigit():
                current_number = current_number * 10 + int(char)
            elif char == ' ':
                continue
            else: # Operator or end (due to dummy char)
                if last_operator == '+':
                    stack.append(current_number)
                elif last_operator == '-':
                    stack.append(-current_number)
                elif last_operator == '*':
                    stack.append(stack.pop() * current_number)
                elif last_operator == '/':
                    # Integer division truncates toward zero
                    top = stack.pop()
                    if top * current_number < 0 and top % current_number != 0:
                        stack.append(top // current_number +1) # for python's negative division to match truncate
                    else:
                        stack.append(top // current_number)

                last_operator = char
                current_number = 0
                
        return sum(stack)

```

**Java 实现:**
```java
import java.util.Stack;

class Solution {
    public int calculate(String s) {
        if (s == null || s.isEmpty()) {
            return 0;
        }

        Stack<Integer> stack = new Stack<>();
        int currentNumber = 0;
        char lastOperator = '+';

        for (int i = 0; i < s.length(); i++) {
            char currentChar = s.charAt(i);

            if (Character.isDigit(currentChar)) {
                currentNumber = currentNumber * 10 + (currentChar - '0');
            }
            
            // An operator is found or it's the last character
            if (!Character.isDigit(currentChar) && currentChar != ' ' || i == s.length() - 1) {
                if (lastOperator == '+') {
                    stack.push(currentNumber);
                } else if (lastOperator == '-') {
                    stack.push(-currentNumber);
                } else if (lastOperator == '*') {
                    stack.push(stack.pop() * currentNumber);
                } else if (lastOperator == '/') {
                    stack.push(stack.pop() / currentNumber); // Java's / on int truncates towards zero
                }
                
                lastOperator = currentChar; // Update operator
                currentNumber = 0;        // Reset number
            }
        }
        
        int result = 0;
        while (!stack.isEmpty()) {
            result += stack.pop();
        }
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是字符串 `s` 的长度。我们只遍历字符串一次。
*   空间复杂度: O(N) 或 O(W) (W 为数字个数)，在最坏情况下（例如全是加减法），栈中可能存储多个数字。

### 093: [83. 删除排序链表中的重复元素 (Remove Duplicates from Sorted List)](https://leetcode.cn/problems/remove-duplicates-from-sorted-list)

**题目描述:**
给定一个已排序的链表的头 `head` ， 删除所有重复的元素，使每个元素只出现一次 。返回 已排序的链表 。

**解题思路:**
1.  如果链表为空或只有一个节点，则没有重复项，直接返回 `head`。
2.  初始化一个指针 `current` 指向 `head`。
3.  当 `current` 不为空且 `current.next` 不为空时，循环：
    a.  如果 `current.val == current.next.val` (发现重复)：
    *   将 `current.next` 指向 `current.next.next`，从而跳过 (删除) 重复的节点。
    b.  否则 ( `current.val != current.next.val`，没有重复)：
    *   将 `current` 移动到下一个节点 (`current = current.next`)。
4.  返回 `head`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteDuplicates(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
        
        current = head
        while current and current.next:
            if current.val == current.next.val:
                current.next = current.next.next # Skip duplicate
            else:
                current = current.next # Move to next distinct node
        return head
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode deleteDuplicates(ListNode head) {

            return head;
        }

        while (current != null && current.next != null) {
            if (current.val == current.next.val) {
                current.next = current.next.next; // Skip duplicate
            } else {

            }
        }
        return head;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是链表的节点数。每个节点最多被访问一次。
*   空间复杂度: O(1)，原地修改。

### 094: [718. 最长重复子数组 (Maximum Length of Repeated Subarray)](https://leetcode.cn/problems/maximum-length-of-repeated-subarray)

**题目描述:**
给两个整数数组 `nums1` 和 `nums2` ，返回 **两个数组中 公共的 、长度最长的子数组的长度** 。
(注意：这是“最长公共子数组”，不是“最长公共子序列”)

**解题思路 (动态规划):**
1.  定义 `dp[i][j]` 表示以 `nums1[i-1]` 结尾的子数组 和以 `nums2[j-1]` 结尾的子数组 它们的最长公共**后缀**的长度。
    *   这里的“后缀”指的是，如果 `nums1[i-1]` 和 `nums2[j-1]` 相等，那么这个公共后缀就又增长了。如果它们不相等，那么以它们为结尾的公共子数组长度为0。
2.  **状态转移方程:**
    *   如果 `nums1[i-1] == nums2[j-1]`： `dp[i][j] = dp[i-1][j-1] + 1`。
    *   如果 `nums1[i-1] != nums2[j-1]`： `dp[i][j] = 0` (因为子数组必须是连续的，一旦不匹配，以当前元素结尾的公共长度就断了)。
3.  **初始化**: `dp` 表大小为 `(len(nums1)+1) x (len(nums2)+1)`，所有值为 0。
4.  **结果**: 遍历 `dp` 表，其中的最大值就是所求的最长公共子数组的长度。
5.  迭代填充 `dp` 表，`i` 从 1 到 `len(nums1)`，`j` 从 1 到 `len(nums2)`。

**Python 实现:**
```python
class Solution:
    def findLength(self, nums1: list[int], nums2: list[int]) -> int:
        m = len(nums1)
        n = len(nums2)
        
        # dp[i][j] will be the length of the common subarray ending at nums1[i-1] and nums2[j-1]
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        max_length = 0
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if nums1[i-1] == nums2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                    max_length = max(max_length, dp[i][j])
                else:
                    dp[i][j] = 0 # Not necessary due to initialization, but explicit
        
        return max_length
```

**Java 实现:**
```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length;
        int n = nums2.length;

        // dp[i][j] will be the length of the common subarray ending at nums1[i-1] and nums2[j-1]
        int[][] dp = new int[m + 1][n + 1]; // Initialized to 0 by default
        int maxLength = 0;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (nums1[i-1] == nums2[j-1]) {
                    dp[i][j] = dp[i-1][j-1] + 1;
                    maxLength = Math.max(maxLength, dp[i][j]);
                } else {
                    dp[i][j] = 0; // Not strictly necessary, default is 0
                }
            }
        }
        return maxLength;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 和 N 分别是 `nums1` 和 `nums2` 的长度。需要填充整个 `dp` 表。
*   空间复杂度: O(M * N)，用于 `dp` 表。可以优化到 O(min(M,N))，因为 `dp[i][j]` 只依赖于 `dp[i-1][j-1]`，所以只需要前一行(或前一列)的信息。

### 095: [139. 单词拆分 (Word Break)](https://leetcode.cn/problems/word-break)

**题目描述:**
给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。请你判断是否可以利用字典中出现的单词拼接出 `s` 。
注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**解题思路 (动态规划):**
1.  定义 `dp[i]` 为布尔值，表示字符串 `s` 的前 `i` 个字符 (即子串 `s[0...i-1]`) 是否可以被字典中的单词成功拆分。
2.  **初始化**: `dp = true` (空字符串可以被认为是成功拆分)。
3.  **状态转移**:
    *   对于 `i` 从 1 到 `len(s)`： (我们要判断 `s[0...i-1]` 能否拆分)
        *   对于 `j` 从 0 到 `i-1`： ( `j` 是一个可能的分割点)
            *   如果 `dp[j]` 为 `true` (即 `s[0...j-1]` 可以被拆分)
            *   并且 子串 `s[j...i-1]` (从索引 `j` 到 `i-1`) 存在于 `wordDict` 中：
                *   那么 `dp[i]` 就为 `true`。一旦找到一个这样的 `j`，就可以 `break` 内层循环，因为 `dp[i]` 已经确定为 `true`。
4.  **结果**: `dp[len(s)]` 就是最终答案。
5.  为了快速查找 `wordDict`，最好将其转换为哈希集合 (Set)。

**Python 实现:**
```python
class Solution:
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        n = len(s)
        word_set = set(wordDict) # For O(1) average lookup
        
        # dp[i] is true if s[0...i-1] can be segmented
        dp = [False] * (n + 1)
        dp[0] = True # Empty string can be segmented
        
        for i in range(1, n + 1): # Iterate through all possible end points of prefixes
            for j in range(i):    # Iterate through all possible split points before i
                # If s[0...j-1] can be segmented AND s[j...i-1] is in wordDict
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break # Found a way to segment s[0...i-1], move to next i
        
        return dp[n]
```

**Java 实现:**
```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        Set<String> wordSet = new HashSet<>(wordDict); // For O(1) average lookup

        // dp[i] is true if s.substring(0, i) can be segmented
        boolean[] dp = new boolean[n + 1];
        dp[0] = true; // Empty string can be segmented

        for (int i = 1; i <= n; i++) { // Iterate through all possible end points of prefixes
            for (int j = 0; j < i; j++) {    // Iterate through all possible split points before i
                // If s.substring(0, j) can be segmented AND s.substring(j, i) is in wordSet
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break; // Found a way to segment s.substring(0, i), move to next i
                }
            }
        }
        return dp[n];
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N^2 * L) 或 O(N^3) (如果子串提取是 O(L) 的话)。 外层循环 N 次，内层循环 N 次。在内层循环中，`s.substring(j, i)` 的操作可能需要 O(L) 时间，其中 L 是子串长度 (最长 N)。 `wordSet.contains` 平均 O(L) (哈希计算和比较)。
    *   更准确地说是 Σ (i * L_avg_word) from i=1 to N,  大致是 O(N^2 * L_avg_word_in_dict_check_ + N * L_substring_op)  which could be O(N^3) if average L is N. Many sources cite O(N^2) if assuming substring and set lookups are efficient, but string operations are key. Often written as O(N*M) where M is average word length. For LeetCode, a tighter bound might be  `N * sum(length of words checked for each prefix)`.  If word lengths are bounded and hash operations efficient, substring creation can be the N^2 part and sum over it can be O(N^3) for worst case.  A common DP time complexity is `O(length of s * length of s * average length of a word in dictionary)` for this setup.  With better state representation / transitions (e.g. Trie-based solutions) optimizations exist. For standard DP with string slicing it's safer to assume an O(N^3)-ish behavior in worst case. Let's denote as O(N^2 * MaxWordLength) if hashing+comparison of word dominates, or O(N^3) if substring is dominating factor of inner loop. Simpler view: outer loop N, inner loop N. Inside: substring is up to O(N), set lookup is average O(length of substring). Total O(N^3).
*   空间复杂度: O(N) for the `dp` array, and O(Sum of lengths of words in `wordDict`) for the `wordSet`.

### 096: [209. 长度最小的子数组 (Minimum Size Subarray Sum)](https://leetcode.cn/problems/minimum-size-subarray-sum)

**题目描述:**
给定一个含有 `n` 个正整数的数组和一个正整数 `target` 。
找出该数组中满足其总和大于等于 `target` 的长度最小的 **连续子数组** `[nums_l, nums_{l+1}, ..., nums_{r-1}, nums_r]` ，并返回其长度。如果不存在符合条件的子数组，返回 `0` 。

**解题思路 (滑动窗口):**
1.  初始化 `min_length = infinity` (或 `n + 1` 作为不可能的值)。
2.  初始化 `left = 0` (窗口左边界)。
3.  初始化 `current_sum = 0`。
4.  使用 `right` 指针遍历数组 (作为窗口右边界)：
    a.  将 `nums[right]` 加入 `current_sum`。
    b.  **当 `current_sum >= target` 时** (窗口满足条件)：
    i.  更新 `min_length = min(min_length, right - left + 1)`。
    ii. 尝试缩小窗口：从 `current_sum` 中减去 `nums[left]`。
    iii.移动左边界：`left++`。
    (持续缩小直到 `current_sum < target` 为止)。
5.  遍历结束后，如果 `min_length` 仍为初始的 `infinity` (或 `n + 1`)，说明未找到满足条件的子数组，返回 0。否则返回 `min_length`。

**Python 实现:**
```python
class Solution:
    def minSubArrayLen(self, target: int, nums: list[int]) -> int:
        if not nums:
            return 0
        
        n = len(nums)
        min_length = float('inf')
        current_sum = 0
        left = 0
        
        for right in range(n):
            current_sum += nums[right]
            
            while current_sum >= target:
                min_length = min(min_length, right - left + 1)
                current_sum -= nums[left]
                left += 1
                
        return min_length if min_length != float('inf') else 0
```

**Java 实现:**
```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int n = nums.length;
        int minLength = Integer.MAX_VALUE;
        int currentSum = 0;
        int left = 0;

        for (int right = 0; right < n; right++) {
            currentSum += nums[right];

            while (currentSum >= target) {
                minLength = Math.min(minLength, right - left + 1);
                currentSum -= nums[left];
                left++;
            }
        }
        
        return (minLength == Integer.MAX_VALUE) ? 0 : minLength;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)。虽然有嵌套 `while` 循环，但 `left` 和 `right` 指针都只向前移动，每个元素最多被访问两次（一次被 `right` 指针加入，一次被 `left` 指针移除）。
*   空间复杂度: O(1)。

### 097: [226. 翻转二叉树 (Invert Binary Tree)](https://leetcode.cn/problems/invert-binary-tree)

**题目描述:**
给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

**解题思路 (递归 / DFS):**
1.  **基准情况**: 如果 `root` 为 `null`，则无需翻转，直接返回 `null`。
2.  **递归翻转子树**:
    *   递归调用 `invertTree` 翻转左子树：`inverted_left_child = invertTree(root.left)`。
    *   递归调用 `invertTree` 翻转右子树：`inverted_right_child = invertTree(root.right)`。
3.  **交换当前节点的左右子节点**:
    *   将 `root.left` 设置为 `inverted_right_child`。
    *   将 `root.right` 设置为 `inverted_left_child`。
4.  返回 `root`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def invertTree(self, root: TreeNode) -> TreeNode:
        if not root:
            return None
        
        # Recursively invert children
        inverted_left_child = self.invertTree(root.left)
        inverted_right_child = self.invertTree(root.right)
        
        # Swap the children of the current node
        root.left = inverted_right_child
        root.right = inverted_left_child
        
        return root
```

```java
        this.val = val;
        this.left = left;
        this.right = right;
    }

    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;
        }

        // Recursively invert children
        TreeNode invertedLeftChild = invertTree(root.left);
        TreeNode invertedRightChild = invertTree(root.right);

        // Swap the children of the current node
        root.left = invertedRightChild;
        root.right = invertedLeftChild;
        
        return root;
    }
}
```

### 098: [24. 两两交换链表中的节点 (Swap Nodes in Pairs)](https://leetcode.cn/problems/swap-nodes-in-pairs)

**题目描述:**
给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**解题思路 (迭代法):**
1.  创建一个哑节点 `dummy`，使其 `dummy.next = head`。这能简化对头两个节点的处理。
2.  使用一个指针 `prev_node`，初始指向 `dummy`。`prev_node` 总是指向待交换的两个节点的前一个节点。
3.  循环条件：只要 `prev_node.next` (第一个待交换节点) 不为空，且 `prev_node.next.next` (第二个待交换节点) 不为空。
    a.  定义 `node1 = prev_node.next` (第一个待交换节点)。
    b.  定义 `node2 = prev_node.next.next` (第二个待交换节点)。
    c.  **执行交换**:
    i.  `prev_node.next = node2` (将前驱节点指向 `node2`)。
    ii. `node1.next = node2.next` (将 `node1` 指向 `node2` 原来的下一个节点)。
    iii. `node2.next = node1` (将 `node2` 指向 `node1`)。
    d.  **更新 `prev_node`**: 将 `prev_node` 移动到 `node1` (因为 `node1` 现在是已交换对的第二个节点，即下一对的前驱)。`prev_node = node1`。
4.  返回 `dummy.next`。

**Python 实现 (迭代法):**

    def __init__(self, val=0, next=None):

            node1.next = node2.next
            node2.next = node1

### 099: [补充题6. 手撕堆排序 (Sort an Array - LeetCode 912, using Heap Sort)](https://leetcode.cn/problems/sort-an-array)

**题目描述:**
给你一个整数数组 `nums`，请你将该数组升序排列。这里特指使用**堆排序 (Heap Sort)** 来实现。

**解题思路 (堆排序):**
堆排序分为两个主要步骤：
1.  **建堆 (Build Heap)**: 将输入数组原地转换成一个最大堆 (Max-Heap)。最大堆的性质是父节点的值总是大于或等于其子节点的值，所以堆顶元素（数组的第一个元素）是最大的。
    *   从最后一个非叶子节点开始，向上到根节点，对每个节点执行 "下沉 (siftDown / heapify)" 操作。最后一个非叶子节点的索引是 `(n/2) - 1` (0-indexed)。
2.  **排序阶段**:
    *   重复 `n-1` 次：
        a.  将堆顶元素 (当前最大元素 `nums`) 与堆的最后一个元素 `nums[heap_size - 1]` 交换。
        b.  将交换到末尾的最大元素从堆中移除 (逻辑上，通过减小 `heap_size`)。
        c.  对新的堆顶元素 `nums` 执行 "下沉 (siftDown / heapify)" 操作，以维护最大堆的性质，堆的大小为 `current_heap_size`。

**`heapify(arr, n, i)` 函数 (下沉操作，维护以 `i` 为根的子树的最大堆性质):**
   * `i`: 当前需要调整的子树的根节点索引。
   * `n`: 当前堆的大小。
   * `largest = i`
   * `left_child = 2 * i + 1`
   * `right_child = 2 * i + 2`
   * 如果 `left_child < n` 且 `arr[left_child] > arr[largest]`，则 `largest = left_child`。
   * 如果 `right_child < n` 且 `arr[right_child] > arr[largest]`，则 `largest = right_child`。
   * 如果 `largest != i` (说明需要调整)：
     *   交换 `arr[i]` 和 `arr[largest]`。
     *   递归调用 `heapify(arr, n, largest)` 继续调整受影响的子树。

**Python 实现:**
```python
class Solution:
    def sortArray(self, nums: list[int]) -> list[int]: # For LeetCode 912
        n = len(nums)

        # 1. Build Max-Heap
        # Start from the last non-leaf node and heapify down to the root
        for i in range(n // 2 - 1, -1, -1):
            self.heapify(nums, n, i)

        # 2. Sorting phase
        # Extract elements one by one from the heap
        for i in range(n - 1, 0, -1):
            # Move current root (max element) to the end
            nums[0], nums[i] = nums[i], nums[0]
            
            # Call heapify on the reduced heap (size i)
            self.heapify(nums, i, 0)
            
        return nums

    def heapify(self, arr: list[int], n: int, i: int):
        """
        To heapify a subtree rooted with node i which is an index in arr[].
        n is size of heap.
        """
        largest = i        # Initialize largest as root
        left_child = 2 * i + 1
        right_child = 2 * i + 2

        # See if left child of root exists and is greater than root
        if left_child < n and arr[left_child] > arr[largest]:
            largest = left_child

        # See if right child of root exists and is greater than the largest so far
        if right_child < n and arr[right_child] > arr[largest]:
            largest = right_child

        # Change root, if needed
        if largest != i:
            arr[i], arr[largest] = arr[largest], arr[i] # Swap
            
            # Recursively heapify the affected sub-tree
            self.heapify(arr, n, largest)

```

**Java 实现:**
```java
class Solution {
    public int[] sortArray(int[] nums) { // For LeetCode 912
        int n = nums.length;

        // 1. Build Max-Heap
        // Start from the last non-leaf node (n/2 - 1) and heapify down to the root (index 0)
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(nums, n, i);
        }

        // 2. Sorting phase
        // Extract elements one by one from the heap
        for (int i = n - 1; i > 0; i--) {
            // Move current root (max element) to the end
            int temp = nums[0];
            nums[0] = nums[i];
            nums[i] = temp;
            
            // Call heapify on the reduced heap (size i)
            // The root of the heap is always at index 0
            heapify(nums, i, 0);
        }
        return nums;
    }

    // To heapify a subtree rooted with node i which is an index in arr[].
    // n is size of heap.
    private void heapify(int[] arr, int n, int i) {
        int largest = i;        // Initialize largest as root
        int leftChild = 2 * i + 1;
        int rightChild = 2 * i + 2;

        // If left child is larger than root
        if (leftChild < n && arr[leftChild] > arr[largest]) {
            largest = leftChild;
        }

        // If right child is larger than largest so far
        if (rightChild < n && arr[rightChild] > arr[largest]) {
            largest = rightChild;
        }

        // If largest is not root
        if (largest != i) {
            int swap = arr[i];
            arr[i] = arr[largest];
            arr[largest] = swap;
            
            // Recursively heapify the affected sub-tree
            heapify(arr, n, largest);
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N log N)。
    *   建堆: O(N) (虽然看起来是 N/2 次 heapify调用，每次logN，但更精确的分析表明是线性的)。
    *   排序阶段: N-1 次交换和 heapify 调用。每次 heapify 是 O(log N)。总共 O(N log N)。
    *   所以总体是 O(N log N)。
*   空间复杂度: O(1) (原地排序，递归版heapify会用O(logN)栈空间，但可以改成迭代版)。

### 100: [297. 二叉树的序列化与反序列化 (Serialize and Deserialize Binary Tree)](https://leetcode.cn/problems/serialize-and-deserialize-binary-tree)

**题目描述:**
序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。
请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串，并且可以将该字符串反序列化为原始的树结构。

**解题思路 (先序遍历 DFS):**
**序列化 (serialize):**
1.  使用先序遍历 (根-左-右)。
2.  如果当前节点为 `null`，则在序列化结果中添加一个特殊标记 (如 "null" 或 "#")。
3.  如果当前节点不为 `null`，则添加节点的值 (转换为字符串)，然后递归序列化其左子节点和右子节点。
4.  节点值和标记之间用分隔符 (如 ",") 分隔。

**反序列化 (deserialize):**
1.  将序列化字符串按分隔符分割成节点值/标记的列表（或队列）。
2.  定义一个递归辅助函数，它从列表中取出一个元素来构建当前节点：
    a.  取出列表的下一个元素。
    b.  如果该元素是 `null` 标记，则当前子树为空，返回 `null`。
    c.  否则，该元素是节点的值。创建一个新的 `TreeNode`，其值为该元素（转换回整数）。
    d.  递归调用辅助函数，构建该节点的左子树：`node.left = helper()`。
    e.  递归调用辅助函数，构建该节点的右子树：`node.right = helper()`。
    f.  返回当前构建的 `node`。
3.  初始调用该辅助函数即可得到根节点。

**Python 实现:**
```python
class TreeNode(object):
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Codec:
    NULL_MARKER = "#"
    SEPARATOR = ","

    def serialize(self, root: TreeNode) -> str:
        """Encodes a tree to a single string."""
        if not root:
            return self.NULL_MARKER
        
        # Pre-order traversal: root, left, right
        # Using a list to join later for efficiency over string concatenation
        parts = []
        
        def build_string(node):
            if not node:
                parts.append(self.NULL_MARKER)
                return
            parts.append(str(node.val))
            build_string(node.left)
            build_string(node.right)
            
        build_string(root)
        return self.SEPARATOR.join(parts)
        

    def deserialize(self, data: str) -> TreeNode:
        """Decodes your encoded data to tree."""
        if not data:
            return None
        
        nodes_str_list = data.split(self.SEPARATOR)
        # Use a list as a queue by popping from the front (or an actual deque)
        # For simple list pop(0) is O(N), so better to pass an index or use iterator
        self.nodes_iter = iter(nodes_str_list) # Or use a class member index

        def build_tree():
            val_str = next(self.nodes_iter)
            if val_str == self.NULL_MARKER:
                return None
            
            node = TreeNode(int(val_str))
            node.left = build_tree()
            node.right = build_tree()
            return node
            
        return build_tree()
```

**Java 实现:**
```java
import java.util.Arrays;
import java.util.LinkedList;
import java.util.Queue; // Or Deque for popFirst behavior

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

class Codec {
    private static final String NULL_MARKER = "null"; // Or "#"
    private static final String SEPARATOR = ",";

    // Encodes a tree to a single string.
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        buildString(root, sb);
        // Remove trailing separator if any (might not be needed if handled in buildString)
        if (sb.length() > 0 && sb.charAt(sb.length() -1) == SEPARATOR.charAt(0)) {
            sb.deleteCharAt(sb.length() - 1);
        }
        return sb.toString();
    }

    private void buildString(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append(NULL_MARKER).append(SEPARATOR);
        } else {
            sb.append(node.val).append(SEPARATOR);
            buildString(node.left, sb);
            buildString(node.right, sb);
        }
    }

    // Decodes your encoded data to tree.
    public TreeNode deserialize(String data) {
        if (data == null || data.isEmpty() || data.equals(NULL_MARKER)) {
            return null;
        }
        // Use LinkedList as a Queue for efficient pollFirst/removeFirst
        Queue<String> nodesQueue = new LinkedList<>(Arrays.asList(data.split(SEPARATOR)));
        return buildTree(nodesQueue);
    }

    private TreeNode buildTree(Queue<String> nodesQueue) {
        String valStr = nodesQueue.poll();
        if (valStr == null || valStr.equals(NULL_MARKER)) {
            return null;
        }
        
        TreeNode node = new TreeNode(Integer.parseInt(valStr));
        node.left = buildTree(nodesQueue);
        node.right = buildTree(nodesQueue);
        return node;
    }
}
```
