### 021: [141. 环形链表 (Linked List Cycle)](https://leetcode.cn/problems/linked-list-cycle)

**题目描述:**
给你一个链表的头节点 `head` ，判断链表中是否有环。
如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**。仅仅是为了标识链表的实际情况。
如果链表中存在环，则返回 `true` 。否则，返回 `false` 。

**解题思路 (快慢指针法 / Floyd's Tortoise and Hare):**
1.  初始化两个指针，`slow` (慢指针) 和 `fast` (快指针)，都指向链表的头节点 `head`。
2.  在一个循环中移动指针：
    *   `slow` 每次向前移动一步 (`slow = slow.next`)。
    *   `fast` 每次向前移动两步 (`fast = fast.next.next`)。
3.  **检查条件:**
    *   如果在移动过程中，`fast` 指针或者 `fast.next` 指针变为空 (`null`)，说明快指针到达了链表的末尾，链表中没有环。返回 `false`。
    *   如果在移动过程中，`slow` 指针和 `fast` 指针相遇 (即 `slow == fast`)，说明链表中存在环。返回 `true`。
4.  如果链表为空或只有一个节点，不可能有环，直接返回 `false`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        if not head or not head.next:
            return False
        
        slow = head
        fast = head.next # Start fast one step ahead, or ensure fast.next.next is checked carefully

        while slow != fast:
            if not fast or not fast.next: # Fast pointer reached the end
                return False
            slow = slow.next
            fast = fast.next.next
            
        return True # If slow == fast, a cycle is detected
```
**Alternative Python starting both at head:**
```python

                return True

```

### 022: [92. 反转链表 II (Reverse Linked List II)](https://leetcode.cn/problems/reverse-linked-list-ii)

**题目描述:**
给你单链表的头指针 `head` 和两个整数 `left` 和 `right` ，其中 `left <= right` 。请你反转从位置 `left` 到位置 `right` 的链表节点，返回 **反转后的链表** 。

**解题思路:**
1.  **定位**:
    *   找到 `left` 位置的前一个节点 `prev_left_node`（如果 `left > 1`）。
    *   找到 `left` 位置的节点 `left_node` (即待反转子链表的头节点)。
    *   找到 `right` 位置的节点 `right_node` (即待反转子链表的尾节点)。
    *   找到 `right` 位置的后一个节点 `next_right_node` (子链表反转后，原 `left_node` 将指向它)。
2.  **处理哑节点**: 为了统一处理 `left = 1` 的情况，创建一个哑节点 `dummy`，使其 `dummy.next = head`。这样 `prev_left_node` 就总能找到。
3.  **反转子链表**:
    *   断开 `left_node` 和 `next_right_node` 之间的连接 (将 `right_node.next` 设为 `null`，虽然严格来说这一步不必须如果反转函数处理得当，但可以帮助理解)。
    *   反转从 `left_node` 到 `right_node` 的子链表。标准的链表反转逻辑。反转后，原来的 `left_node` 变成新子链表的尾，原来的 `right_node` 变成新子链表的头。
4.  **重新连接**:
    *   将 `prev_left_node.next` 指向反转后的子链表头 (即原来的 `right_node`)。
    *   将反转后的子链表尾 (即原来的 `left_node`) 的 `next` 指向 `next_right_node`。
5.  返回 `dummy.next`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        if not head or left == right:
            return head

        dummy = ListNode(0, head)
        prev_left_node = dummy

        # 1. Move prev_left_node to the node just before the 'left'th node
        for _ in range(left - 1):
            prev_left_node = prev_left_node.next
        
        # prev_left_node is now at (left - 1)th position
        # left_node is the starting node of the sublist to be reversed
        left_node = prev_left_node.next 
        
        # Standard reversal of 'right - left + 1' nodes
        # curr points to the first node to reverse (left_node)
        # prev is initially None (within the context of the sub-reversal)
        curr = left_node
        prev = None 
        
        for _ in range(right - left + 1):
            next_temp = curr.next
            curr.next = prev
            prev = curr
            curr = next_temp
            
        # After reversal:
        # 'prev' is the new head of the reversed sublist (original right_node)
        # 'left_node' (original start of sublist) is now the tail of the reversed sublist
        # 'curr' is the node that was originally after the right_node (next_right_node)

        # 2. Reconnect
        prev_left_node.next = prev   # Connect (left-1)th node to the new head of reversed part
        left_node.next = curr      # Connect the new tail of reversed part to (right+1)th node
        
        return dummy.next
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        if (head == null || left == right) {
            return head;
        }

        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prevLeftNode = dummy;

        // 1. Move prevLeftNode to the node just before the 'left'th node
        for (int i = 0; i < left - 1; i++) {
            prevLeftNode = prevLeftNode.next;
        }
        
        // prevLeftNode is at (left - 1)th position
        // leftNode is the starting node of the sublist to be reversed
        ListNode leftNode = prevLeftNode.next; 
        
        // Standard reversal of 'right - left + 1' nodes
        ListNode curr = leftNode;
        ListNode prev = null; 
        
        for (int i = 0; i < right - left + 1; i++) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        
        // After reversal:
        // 'prev' is the new head of the reversed sublist (original right_node)
        // 'leftNode' (original start of sublist) is now the tail of the reversed sublist
        // 'curr' is the node that was originally after the right_node (next_right_node)

        // 2. Reconnect
        prevLeftNode.next = prev;   // Connect (left-1)th node to new head of reversed part
        leftNode.next = curr;       // Connect new tail of reversed part to (right+1)th node
        
        return dummy.next;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是链表的长度。最坏情况下需要遍历整个链表。
*   空间复杂度: O(1)，只使用了常数个额外指针。

### 023: [54. 螺旋矩阵 (Spiral Matrix)](https://leetcode.cn/problems/spiral-matrix)

**题目描述:**
给你一个 `m` 行 `n` 列的矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素。

**解题思路 (模拟边界):**
1.  定义四个边界：`top`, `bottom`, `left`, `right`。
    *   `top = 0`
    *   `bottom = rows - 1`
    *   `left = 0`
    *   `right = cols - 1`
2.  初始化一个结果列表 `result`。
3.  在一个循环中，只要 `top <= bottom` 且 `left <= right`，就按顺时针顺序遍历当前边界的元素，并收缩边界：
    a.  **从左到右 (遍历上边界)**:
    *   从 `left` 到 `right` 遍历 `matrix[top][c]`，将元素加入 `result`。
    *   `top++` (上边界下移)。如果此时 `top > bottom`，说明已遍历完，跳出循环。
    b.  **从上到下 (遍历右边界)**:
    *   从 `top` 到 `bottom` 遍历 `matrix[r][right]`，将元素加入 `result`。
    *   `right--` (右边界左移)。如果此时 `left > right`，说明已遍历完，跳出循环。
    c.  **从右到左 (遍历下边界)**:
    *   从 `right` 到 `left` (倒序) 遍历 `matrix[bottom][c]`，将元素加入 `result`。
    *   `bottom--` (下边界上移)。如果此时 `top > bottom`，说明已遍历完，跳出循环。
    d.  **从下到上 (遍历左边界)**:
    *   从 `bottom` 到 `top` (倒序) 遍历 `matrix[r][left]`，将元素加入 `result`。
    *   `left++` (左边界右移)。如果此时 `left > right`，说明已遍历完，跳出循环。
4.  返回 `result`。

**Python 实现:**
```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]:
        if not matrix or not matrix[0]:
            return []

        rows = len(matrix)
        cols = len(matrix[0])
        result = []
        
        top, bottom, left, right = 0, rows - 1, 0, cols - 1

        while top <= bottom and left <= right:
            # 1. Traverse Right (top row)
            for c in range(left, right + 1):
                result.append(matrix[top][c])
            top += 1
            if top > bottom: break # Check if all rows are processed

            # 2. Traverse Down (rightmost column)
            for r in range(top, bottom + 1):
                result.append(matrix[r][right])
            right -= 1
            if left > right: break # Check if all columns are processed

            # 3. Traverse Left (bottom row) - needs check top <= bottom
            if top <= bottom: # Ensure there's still a valid row to traverse
                for c in range(right, left - 1, -1):
                    result.append(matrix[bottom][c])
                bottom -= 1
            if top > bottom: break

            # 4. Traverse Up (leftmost column) - needs check left <= right
            if left <= right: # Ensure there's still a valid column to traverse
                for r in range(bottom, top - 1, -1):
                    result.append(matrix[r][left])
                left += 1
            if left > right: break
            
        return result
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return result;
        }

        int rows = matrix.length;
        int cols = matrix[0].length;
        int top = 0, bottom = rows - 1, left = 0, right = cols - 1;

        while (top <= bottom && left <= right) {
            // 1. Traverse Right (top row)
            for (int c = left; c <= right; c++) {
                result.add(matrix[top][c]);
            }
            top++;
            if (top > bottom) break;

            // 2. Traverse Down (rightmost column)
            for (int r = top; r <= bottom; r++) {
                result.add(matrix[r][right]);
            }
            right--;
            if (left > right) break;

            // 3. Traverse Left (bottom row) - check needed if rows are exhausted
            if (top <= bottom) { // Important check after top++ and bottom may change
                for (int c = right; c >= left; c--) {
                    result.add(matrix[bottom][c]);
                }
                bottom--;
            }
            if (top > bottom) break;


            // 4. Traverse Up (leftmost column) - check needed if cols are exhausted
            if (left <= right) { // Important check after right-- and left may change
                for (int r = bottom; r >= top; r--) {
                    result.add(matrix[r][left]);
                }
                left++;
            }
            if (left > right) break;
        }
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 是行数，N 是列数。每个元素只被访问一次。
*   空间复杂度: O(1) (如果结果列表不计入额外空间)。结果列表本身是 O(M * N)。

### 024: [300. 最长递增子序列 (Longest Increasing Subsequence)](https://leetcode.cn/problems/longest-increasing-subsequence)

**题目描述:**
给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。
子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`` 是数组 `` 的子序列。

**解题思路:**
**1. 动态规划 O(N^2):**
* 定义 `dp[i]` 为以 `nums[i]` 结尾的最长递增子序列的长度。
* 初始化 `dp` 数组所有元素为 1 (每个元素自身构成长度为1的递增子序列)。
* 状态转移：对于每个 `nums[i]`，遍历它之前的所有元素 `nums[j]` (where `j < i`)：
    * 如果 `nums[i] > nums[j]`，则 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面。
    * `dp[i] = max(dp[i], dp[j] + 1)`。
* 最终结果是 `dp` 数组中的最大值。
* 时间复杂度: O(N^2)，空间复杂度: O(N)。

**2. 贪心 + 二分查找 O(N log N):** (通常是面试官期望的更优解)
* 维护一个数组 `tails` (或称为 `piles` 或 `min_end_of_length_k`)，其中 `tails[k]` 存储长度为 `k+1` 的所有递增子序列中，末尾元素的最小值。
* `tails` 数组一定是递增的。 (证明：如果 `tails[k] >= tails[k+1]`，则长度为 `k+2` 的递增子序列其末尾元素是 `tails[k+1]`，它的前 `k+1` 个元素构成的子序列的末尾元素肯定 `< tails[k+1]`，从而也 `< tails[k]`。这与 `tails[k]` 是长度为 `k+1` 的递增子序列的最小末尾元素矛盾)。
* 遍历 `nums` 数组中的每个元素 `num`:
    *  **二分查找**: 在 `tails` 数组中找到第一个大于或等于 `num` 的元素的位置 `idx`。
        *   如果 `num` 大于 `tails` 中的所有元素 (即 `idx == len(tails)`)：将 `num` 追加到 `tails` 的末尾。这表示我们找到了一个更长的递增子序列。
        *   如果找到了这样一个 `tails[idx] >= num`：用 `num` 替换 `tails[idx]`。这表示我们找到了一个长度为 `idx+1` 的递增子序列，且其末尾元素更小 (`num`)，这为后续构建更长的递增子序列提供了更好的机会。
*  最终，`tails` 数组的长度就是最长递增子序列的长度。
* 时间复杂度: O(N log N) (N 次遍历，每次二分查找 log N)。
* 空间复杂度: O(N) (用于 `tails` 数组，最坏情况是整个数组递增)。

**Python 实现 (O(N log N)):**
```python
import bisect

class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        if not nums:
            return 0
        
        tails = [] # tails[k] stores the smallest tail of all increasing subsequences of length k+1
        
        for num in nums:
            # Find the first index idx such that tails[idx] >= num
            # If num is greater than all elements in tails, idx will be len(tails)
            idx = bisect.bisect_left(tails, num)
            
            if idx == len(tails):
                tails.append(num) # Extends the LIS found so far
            else:
                tails[idx] = num # Replace with a smaller tail for the same length
                                 # This potentially allows for longer subsequences later
        
        return len(tails)

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        // 'tails' will store the smallest tail of all increasing subsequences of a certain length.
        // tails.get(k) is the smallest tail of an increasing subsequence of length k+1.
        List<Integer> tails = new ArrayList<>();
        
        for (int num : nums) {
            // Binary search for the first element in 'tails' that is >= num
            // If all elements are smaller, Collections.binarySearch returns -(insertion_point) - 1
            // insertion_point is where 'num' would be inserted to maintain order.
            int idx = Collections.binarySearch(tails, num);
            
            if (idx < 0) {
                // If num is not found, idx = -(insertion_point) - 1.
                // So, insertion_point = -(idx + 1).
                idx = -(idx + 1);
            }
            
            if (idx == tails.size()) {
                tails.add(num); // Extends the LIS found so far
            } else {
                tails.set(idx, num); // Replace with a smaller tail for the same length
                                     // This potentially allows for longer subsequences later
            }
        }
        
        return tails.size();
    }
}

### 025: [23. 合并K个排序链表 (Merge K Sorted Lists)](https://leetcode.cn/problems/merge-k-sorted-lists)

**题目描述:**
给你一个链表数组 `lists` ，每个链表都已经按升序排列。
请你将所有链表合并到一个升序排列的链表中，返回合并后的链表。

**解题思路:**
**1. 逐一合并 (O(NK), K是链表数量, N是总节点数):**
* 初始化一个空链表 `merged_list = null`。
* 遍历 `lists` 数组，将每个链表逐一与 `merged_list` 合并。合并两个有序链表的操作是 O(L1 + L2)。
* 如果 K 个链表平均长度为 N/K，则总复杂度约为 (N/K) + (2N/K) + ... + ((K-1)N/K + N/K) = O(K * N).

**2. 使用最小堆 (优先队列) (O(N log K)):**
* 创建一个最小堆 (Min-Heap / PriorityQueue)。
* 将 `lists` 数组中所有非空链表的头节点加入最小堆。堆中存储节点本身，比较规则是节点的 `val`。
* 创建一个哑节点 `dummy` 和一个 `current` 指针用于构建合并后的链表。
* 当堆不为空时，循环：
  a. 从堆中弹出（`extractMin`）值最小的节点 `min_node`。
  b. 将 `min_node` 连接到 `current.next`。
  c. 移动 `current` 到 `min_node`。
  d. 如果 `min_node` 的下一个节点 `min_node.next` 不为空，将其加入堆中。
* 返回 `dummy.next`。
* 时间复杂度: O(N log K)。总共有 N 个节点，每个节点入堆和出堆一次，操作复杂度为 O(log K)。
* 空间复杂度: O(K)，堆中最多存储 K 个节点 (每个链表的当前头节点)。

**3. 分治法 (归并排序思想) (O(N log K)):**
* 将 K 个链表的合并问题，看作是 K 个元素的归并排序。
* 两两合并链表：`lists` 与 `lists` 合并，`lists` 与 `lists` 合并，依此类推。
* 这样 K 个链表变成 K/2 个链表。
* 重复这个过程，直到只剩下一个链表。
* 合并两个有序链表的复杂度是 O(length1 + length2)。
* 过程类似于归并排序的合并步骤，总共 log K 轮，每轮所有合并操作的总节点数是 N。
* 时间复杂度: O(N log K)。
* 空间复杂度:
    * 递归实现: O(log K) 递归栈空间。
    * 迭代实现 (使用队列或修改原数组): O(K) 或 O(1) (如果允许修改输入数组并复用空间)。

**Python 实现 (最小堆):**
```python
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
    
    # Need to implement __lt__ for heapq if storing ListNode objects directly and they have same val
    def __lt__(self, other):
        return self.val < other.val

class Solution:
    def mergeKLists(self, lists: list[ListNode]) -> ListNode:
        min_heap = []
        # Add a unique tie-breaker (index i) if values can be the same,
        # or implement __lt__ in ListNode if directly storing nodes.
        # Here, (node.val, index_of_list, node) ensures unique elements for heap if vals are same.
        # Simpler: if storing only nodes and node has __lt__ based on val.
        for i, l_head in enumerate(lists):
            if l_head:
                heapq.heappush(min_heap, l_head) # ListNode must have __lt__

        dummy = ListNode(0)
        current = dummy

        while min_heap:
            smallest_node = heapq.heappop(min_heap)
            current.next = smallest_node
            current = current.next
            
            if smallest_node.next:
                heapq.heappush(min_heap, smallest_node.next)
                
        return dummy.next

# Python's heapq with tuples as (value, unique_id, node) to handle duplicate values correctly if ListNode itself doesn't define __lt__ or if strict ordering for same values matters.
# Often for LeetCode, __lt__ on ListNode is sufficient or not strictly needed if only value is used.
# Let's assume ListNode is made comparable (e.g., __lt__ is defined).
```

**Java 实现 (最小堆 / PriorityQueue):**
```java

import java.util.Comparator; // If ListNode is not Comparable or need custom comparison

class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }

        // Min-heap stores ListNodes, compared by their 'val'
        // PriorityQueue<ListNode> minHeap = new PriorityQueue<>( (a, b) -> a.val - b.val );
        PriorityQueue<ListNode> minHeap = new PriorityQueue<>(Comparator.comparingInt(node -> node.val));


        for (ListNode head : lists) {
            if (head != null) {
                minHeap.offer(head);
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        while (!minHeap.isEmpty()) {
            ListNode smallestNode = minHeap.poll();
            current.next = smallestNode;
            current = current.next;

            if (smallestNode.next != null) {
                minHeap.offer(smallestNode.next);
            }
        }
        
        return dummy.next;
    }
}
```

### 026: [143. 重排链表 (Reorder List)](https://leetcode.cn/problems/reorder-list)

**题目描述:**
给定一个单链表 `L` 的头节点 `head` ，请将其重新排列后变为：
L<sub>0</sub> → L<sub>n</sub> → L<sub>1</sub> → L<sub>n-1</sub> → L<sub>2</sub> → L<sub>n-2</sub> → …
不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

**解题思路:**
分三步解决：
1.  **找到链表中点**: 使用快慢指针法找到链表的中间节点。如果链表长度为奇数，慢指针恰好在中间；如果为偶数，慢指针在中间两个节点的前一个。我们将链表从中间断开，形成两个子链表。
2.  **反转后半部分链表**: 将找到中点后的第二部分链表进行反转。
3.  **合并两个链表**: 将前半部分链表和反转后的后半部分链表，按照题目要求的 L<sub>0</sub> → L<sub>n</sub> → L<sub>1</sub> → L<sub>n-1</sub> → … 的顺序交替合并。

**详细步骤:**
1.  **找中点**: `slow` 走一步, `fast` 走两步。当 `fast` 到达末尾 (或 `fast.next` 到末尾) 时, `slow` 就在中点 (或中点前一个)。
    *   得到第一部分链表头 `head1 = head`。
    *   得到第二部分链表头 `head2 = slow.next`。
    *   断开第一部分和第二部分: `slow.next = null`。
2.  **反转后半段**: 对 `head2` 调用标准的链表反转函数，得到 `reversed_head2`。
3.  **合并**:
    *   初始化两个指针，`p1 = head1`，`p2 = reversed_head2`。
    *   交替连接：
        ```
        while p1 != null && p2 != null:
            next_p1 = p1.next
            next_p2 = p2.next
            
            p1.next = p2
            p2.next = next_p1 // if next_p1 is null, then p2 is the last node.
            
            p1 = next_p1
            p2 = next_p2
        ```
    *   由于修改的是 `head` 指向的链表，不需要返回新的头，操作是原地的。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reorderList(self, head: ListNode) -> None:
        """
        Do not return anything, modify head in-place instead.
        """
        if not head or not head.next or not head.next.next: # 0, 1, or 2 nodes
            return

        # 1. Find the middle of the list
        slow, fast = head, head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        # slow is now at the middle node (or left-middle for even length)
        # The second half starts from slow.next
        head_second_half = slow.next
        slow.next = None # Split the list into two halves

        # 2. Reverse the second half of the list
        prev = None
        curr = head_second_half
        while curr:
            next_temp = curr.next
            curr.next = prev
            prev = curr
            curr = next_temp
        reversed_second_half_head = prev # 'prev' is now the head of the reversed second half

        # 3. Merge the two halves
        p1 = head               # Head of the first half
        p2 = reversed_second_half_head # Head of the reversed second half

        while p1 and p2:
            next_p1 = p1.next
            next_p2 = p2.next
            
            p1.next = p2
            # If p1 was the original tail of the first half (next_p1 is None), 
            # and p2 still has elements, we don't need to connect p2.next further back to first half
            if next_p1 is None: 
                break # First half ended, p2 might have one more node if lengths differ by 1
                      # and it's already linked.

            p2.next = next_p1
            
            p1 = next_p1
            p2 = next_p2
```

### 027: [415. 字符串相加 (Add Strings)](https://leetcode.cn/problems/add-strings)

**题目描述:**
给定两个字符串形式的非负整数 `num1` 和 `num2` ，计算它们的和并同样以字符串形式返回。
你不能使用任何內建的用于处理大整数的库（比如 `BigInteger`）， 也不能直接将输入的字符串转换为整数形式。

**解题思路 (模拟手动加法):**
1.  从两个字符串的末尾开始，逐位相加。
2.  使用一个 `carry` (进位) 变量，初始为 0。
3.  初始化指针 `p1` 指向 `num1` 末尾，`p2` 指向 `num2` 末尾。
4.  初始化一个结果字符串构建器 `result_builder` (或列表)。
5.  当 `p1 >= 0` 或 `p2 >= 0` 或 `carry > 0` 时，循环：
    a.  获取当前位的数字：
    *   `digit1 = int(num1[p1])` 如果 `p1 >= 0`，否则为 0。
    *   `digit2 = int(num2[p2])` 如果 `p2 >= 0`，否则为 0。
    b.  计算当前位的和：`current_sum = digit1 + digit2 + carry`。
    c.  当前位的结果是 `current_sum % 10`。
    d.  新的进位是 `carry = current_sum // 10`。
    e.  将当前位结果（`current_sum % 10`）转换回字符，并添加到 `result_builder` 的**前端** (因为是从低位开始计算的)。
    f.  移动指针：`p1--`，`p2--`。
6.  如果 `result_builder` 为空（例如输入 "0", "0"），确保返回 "0"。
7.  将 `result_builder` 转换为字符串并返回。

**Python 实现:**
```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        p1 = len(num1) - 1
        p2 = len(num2) - 1
        carry = 0
        result_chars = []

        while p1 >= 0 or p2 >= 0 or carry > 0:
            digit1 = int(num1[p1]) if p1 >= 0 else 0
            digit2 = int(num2[p2]) if p2 >= 0 else 0
            
            current_sum = digit1 + digit2 + carry
            
            digit_to_add = current_sum % 10
            carry = current_sum // 10
            
            result_chars.append(str(digit_to_add))
            
            if p1 >= 0:
                p1 -= 1
            if p2 >= 0:
                p2 -= 1
        
        # The result_chars are in reverse order, so join and reverse
        return "".join(result_chars[::-1])
```

**Java 实现:**
```java

        int p2 = num2.length() - 1;

        StringBuilder resultBuilder = new StringBuilder();

            }
            if (p2 >= 0) {
                p2--;
            }
        }

        return resultBuilder.reverse().toString();
    }
}

*   空间复杂度: O(max(L1, L2))，用于存储结果字符串。

### 028: [56. 合并区间 (Merge Intervals)](https://leetcode.cn/problems/merge-intervals)

**题目描述:**
以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start_i, end_i]` 。请你合并所有重叠的区间，并返回 *一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间* 。

**解题思路:**
1.  **排序**: 首先，将所有区间按照起始点 `start_i` 升序排序。如果起始点相同，可以按结束点排序，但仅按起始点排序已足够。
2.  **合并**:
    *   初始化一个结果列表 `merged_intervals`。
    *   将第一个排序后的区间加入 `merged_intervals`。
    *   遍历排序后的其余区间 `current_interval`:
        *   获取 `merged_intervals` 中的最后一个区间 `last_merged_interval`。
        *   **检查重叠**: 如果 `current_interval.start <= last_merged_interval.end`，说明当前区间与上一个合并后的区间有重叠。
            *   **合并操作**: 更新 `last_merged_interval.end = max(last_merged_interval.end, current_interval.end)`。
        *   **不重叠**: 如果 `current_interval.start > last_merged_interval.end`，说明没有重叠，将 `current_interval` 直接加入 `merged_intervals`。
3.  返回 `merged_intervals`。

**Python 实现:**
```python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        if not intervals:
            return []

        # Sort intervals based on the start point
        intervals.sort(key=lambda x: x[0])
        
        merged_intervals = []
        
        for interval in intervals:
            # If merged_intervals is empty or the current interval does not overlap with the previous one
            if not merged_intervals or interval[0] > merged_intervals[-1][1]:
                merged_intervals.append(interval)
            else:
                # There is an overlap, so merge the current interval with the last one in merged_intervals
                # by updating the end point of the last interval
                merged_intervals[-1][1] = max(merged_intervals[-1][1], interval[1])
                
        return merged_intervals
```

### 029: [160. 相交链表 (Intersection of Two Linked Lists)](https://leetcode.cn/problems/intersection-of-two-linked-lists)

**题目描述:**
给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null` 。
题目数据 **保证** 整个链式结构中不存在环。
**注意**，函数返回结果后，链表必须 **保持其原始结构** 。

**解题思路:**
**1. 哈希集合法:**
   * 遍历链表 A，将所有节点存入一个哈希集合。
   * 遍历链表 B，对于每个节点，检查它是否存在于哈希集合中。
   * 第一个在集合中找到的 B 的节点就是相交节点。如果没有，则不相交。
   * 时间复杂度: O(M + N)，空间复杂度: O(M) 或 O(N)。

**2. 双指针法 (巧妙利用长度差):**
   * 两个指针 `pA` 指向 `headA`，`pB` 指向 `headB`。
   * 同时向前移动 `pA` 和 `pB`。
   * 如果 `pA` 到达链表 A 的末尾，则将其重定向到 `headB`。
   * 如果 `pB` 到达链表 B 的末尾，则将其重定向到 `headA`。
   * **原理**:
     * 假设链表 A 长度为 `LA`，链表 B 长度为 `LB`。
     * 不相交部分分别为 `prefixA` 和 `prefixB`，相交部分为 `common`。
     * `LA = len(prefixA) + len(common)`
     * `LB = len(prefixB) + len(common)`
     * 指针 `pA` 走过的路径：`prefixA + common + prefixB` (当第一次到达B的末尾并跳到A的头部时，如果 `prefixA`比`prefixB`长)
     * 指针 `pB` 走过的路径：`prefixB + common + prefixA`
     * 这样，两个指针都走了 `len(prefixA) + len(prefixB) + len(common)` 的距离后，如果它们相遇，相遇点就是交点。
     * 如果没有交点 (`len(common) = 0`)，则 `LA = len(prefixA)`, `LB = len(prefixB)`。
       `pA` 走 `LA + LB`，`pB` 走 `LB + LA`。它们会同时到达 `null` (各自链表的末尾，再跳到对方链表的末尾)，此时 `pA == pB == null`。
   * 循环直到 `pA == pB`。此时的 `pA` (或 `pB`) 就是交点，或者都是 `null` (不相交)。

**Python 实现 (双指针法):**
```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        if not headA or not headB:
            return None

        pA = headA
        pB = headB

        # Loop until pA and pB meet or both reach null (if no intersection)
        while pA != pB:
            # If pA reaches the end of list A, redirect it to the head of list B
            pA = pA.next if pA else headB
            # If pB reaches the end of list B, redirect it to the head of list A
            pB = pB.next if pB else headA
            
        return pA # pA will be the intersection node or null
```

*   空间复杂度: O(1)。

### 030: [42. 接雨水 (Trapping Rain Water)](https://leetcode.cn/problems/trapping-rain-water)

**题目描述:**
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**解题思路:**
**1. 按列计算 (O(N^2)):**
* 对于每一列 `i` (除了最左和最右)，它能接的雨水取决于它左边的最高柱子 `left_max` 和右边的最高柱子 `right_max`。
* 水位高度是 `min(left_max, right_max)`。
* 该列能接的雨水量是 `max(0, min(left_max, right_max) - height[i])`。
* 遍历每一列，对每列计算其 `left_max` 和 `right_max` (这需要两次内层遍历)，累加雨水。
* 时间复杂度 O(N^2)。

**2. 动态规划优化 (O(N)):**
* `left_max[i]`: 从左到 `i` (包含`i`) 的最高柱子。可以从左到右一次遍历计算。
* `right_max[i]`: 从右到 `i` (包含`i`) 的最高柱子。可以从右到左一次遍历计算。
* 对于列 `i`，能接的雨水是 `max(0, min(left_max[i], right_max[i]) - height[i])`。
* 累加所有列的雨水。
* 时间复杂度 O(N)，空间复杂度 O(N) (用于存储 `left_max` 和 `right_max` 数组)。

**3. 双指针法 (O(N), 空间 O(1)):** (最优雅的解法)
* 维护两个指针 `left` 和 `right`，分别指向数组的开头和末尾。
* 维护 `left_max_height` (从左到 `left` 的最高柱) 和 `right_max_height` (从右到 `right` 的最高柱)。
* `total_water = 0`。
* 当 `left < right` 时循环：
    *   如果 `height[left] < height[right]` (瓶颈在于左边较矮的柱子)：
        *   如果 `height[left] >= left_max_height`，更新 `left_max_height = height[left]` (当前左柱是新的左边最高，不能存水)。
        *   否则 (`height[left] < left_max_height`)，说明 `height[left]` 可以存水，存水量是 `left_max_height - height[left]`。将其加到 `total_water`。
        *   `left++` (向右移动左指针)。
    *   否则 (`height[left] >= height[right]`) (瓶颈在于右边较矮的柱子)：
        *   如果 `height[right] >= right_max_height`，更新 `right_max_height = height[right]`。
        *   否则，`height[right]` 可以存水，存水量是 `right_max_height - height[right]`。将其加到 `total_water`。
        *   `right--` (向左移动右指针)。
* **原理**: 当 `height[left] < height[right]` 时，我们知道 `left_max_height` 肯定小于或等于 `right_max_height` (因为 `height[right]` 本身就比 `height[left]` 大，而 `right_max_height` 至少是 `height[right]`)。所以，对于 `left` 位置，其右边的实际最高墙至少是 `height[right]`，因此 `min(left_max_height, 右边的某个实际最高墙)` 实际上由 `left_max_height` 决定。反之亦然。

**Python 实现 (双指针法):**
```python
class Solution:
    def trap(self, height: list[int]) -> int:
        if not height or len(height) < 3:
            return 0

        left, right = 0, len(height) - 1
        left_max_height = 0
        right_max_height = 0
        total_water = 0

        while left < right:
            if height[left] < height[right]:
                if height[left] >= left_max_height:
                    left_max_height = height[left]
                else:
                    total_water += left_max_height - height[left]
                left += 1
            else: # height[left] >= height[right]
                if height[right] >= right_max_height:
                    right_max_height = height[right]
                else:
                    total_water += right_max_height - height[right]
                right -= 1
        
        return total_water

**Java 实现 (双指针法):**
```java
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length < 3) {
            return 0;
        }

        int left = 0;
        int right = height.length - 1;
        int leftMaxHeight = 0;
        int rightMaxHeight = 0;
        int totalWater = 0;

        while (left < right) {
            if (height[left] < height[right]) {
                if (height[left] >= leftMaxHeight) {
                    leftMaxHeight = height[left];
                } else {
                    totalWater += leftMaxHeight - height[left];
                }
                left++;
            } else { // height[left] >= height[right]
                if (height[right] >= rightMaxHeight) {
                    rightMaxHeight = height[right];
                } else {
                    totalWater += rightMaxHeight - height[right];
                }
                right--;
            }
        }
        return totalWater;
    }
}
