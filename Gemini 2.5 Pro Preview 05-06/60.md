### 051: [32. 最长有效括号 (Longest Valid Parentheses)](https://leetcode.cn/problems/longest-valid-parentheses)

**题目描述:**
给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

**解题思路:**
**1. 动态规划 (DP):**
* `dp[i]` 表示以 `s[i]` 结尾的最长有效括号子串的长度。
* 初始化 `dp` 数组为 0。 `max_len = 0`。
* 遍历字符串 `s` 从 `i = 1` 到 `n-1` (因为单个字符不可能是有效括号对):
    *   如果 `s[i] == ')'`:
        *   如果 `s[i-1] == '('`: 说明找到了一个 `()` 对。`dp[i] = (dp[i-2] if i >= 2 else 0) + 2`。
        *   如果 `s[i-1] == ')'`: 说明 `s[i]` 可能与更早的某个 `'('` 匹配。
            *   检查 `s[i - dp[i-1] - 1]` 是否是 `'('` (即 `...((...)) )` 结构中的外层匹配)。
            *   `j = i - dp[i-1] - 1`
            *   如果 `j >= 0` 且 `s[j] == '('`:
                *   `dp[i] = dp[i-1] + 2 + (dp[j-1] if j >= 1 else 0)`。(`dp[i-1]` 是内层有效长度，`+2` 是当前匹配的 `()`, `dp[j-1]` 是 `(` 左边可能连接的有效长度)。
    *   更新 `max_len = max(max_len, dp[i])`。
* 返回 `max_len`。
* 时间复杂度: O(N)，空间复杂度: O(N)。

**2. 使用栈 (Stack):**
* 栈中存储的是**未匹配的左括号的索引**。
* 初始化栈，放入一个 `-1` 作为哨兵，方便计算长度（表示一个有效的子串开始之前的索引）。
* `max_len = 0`。
* 遍历字符串 `s` 中的每个字符 `s[i]` 及其索引 `i`:
    *   如果 `s[i] == '('`: 将索引 `i` 压入栈。
    *   如果 `s[i] == ')'`:
        *   弹出栈顶元素。
        *   如果弹出后栈为空：说明当前的 `')'` 没有匹配的 `'('`，将当前 `')'` 的索引 `i` 压入栈作为新的“有效子串开始之前的索引”（类似于哨兵）。
        *   如果弹出后栈不为空：当前的 `')'` 与栈顶弹出的 `'('` 形成了有效括号。当前有效括号子串的长度是 `i - stack.top()`。更新 `max_len = max(max_len, i - stack.top())`。
* 返回 `max_len`。
* 时间复杂度: O(N)，空间复杂度: O(N)。

**3. 双向遍历 (空间 O(1)):**
* **从左到右遍历:**
    * 维护 `left_count` 和 `right_count`。
    * 遇到 `'('`，`left_count++`。遇到 `')'`，`right_count++`。
    * 如果 `left_count == right_count`，则当前形成了一个有效括号串，长度为 `2 * right_count`。更新 `max_len`。
    * 如果 `right_count > left_count`，说明右括号过多，从这里开始无法构成有效串，重置 `left_count = 0`, `right_count = 0`。
* **从右到左遍历 (处理 `((()` 这种情况):**
    * 逻辑类似，维护 `left_count` 和 `right_count`。
    * 遇到 `'('`，`left_count++`。遇到 `')'`，`right_count++`。
    * 如果 `left_count == right_count`，则当前形成了一个有效括号串，长度为 `2 * left_count`。更新 `max_len`。
    * 如果 `left_count > right_count` (从右往左看，左括号先于右括号多了)，重置 `left_count = 0`, `right_count = 0`。
* 返回 `max_len`。
* 时间复杂度: O(N)，空间复杂度: O(1)。 (这种方法巧妙，但不如栈直接)

**Python 实现 (Stack):**
```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]  # Stack stores indices of '(' that haven't been matched. 
                      # -1 acts as a base for length calculation.
        max_len = 0

        for i, char in enumerate(s):
            if char == '(':
                stack.append(i)
            elif char == ')':
                stack.pop() # Try to match with the last '('.
                if not stack: # Current ')' has no matching '('.
                    stack.append(i) # This ')' becomes the new base.
                else:
                    # Matched '('. The length is current index minus the index
                    # of the character just before the start of this valid segment.
                    max_len = max(max_len, i - stack[-1])
        return max_len
```

**Java 实现 (Stack):**
```java
import java.util.Stack;

class Solution {
    public int longestValidParentheses(String s) {
        Stack<Integer> stack = new Stack<>();
        stack.push(-1); // Base for calculating length
        int maxLen = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);
            } else { // c == ')'
                stack.pop(); // Try to match
                if (stack.isEmpty()) { // No matching '(' found for this ')'
                    stack.push(i); // This ')' becomes the new base
                } else {
                    // Matched. Length = current_index - index_before_valid_segment_starts
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}
```

**复杂度分析 (Stack):**
*   时间复杂度: O(N)。每个字符被处理一次。
*   空间复杂度: O(N)，栈最多存储 N 个索引。

### 052: [70. 爬楼梯 (Climbing Stairs)](https://leetcode.cn/problems/climbing-stairs)

**题目描述:**
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。
每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以到达楼顶？

**解题思路 (动态规划):**
这道题是经典的斐波那契数列问题。
*   `dp[i]` 表示爬到第 `i` 阶楼梯的不同方法数。
*   **状态转移方程**: 要到达第 `i` 阶，可以从第 `i-1` 阶爬 1 步上来，也可以从第 `i-2` 阶爬 2 步上来。
    所以，`dp[i] = dp[i-1] + dp[i-2]`。
*   **基本情况**:
    *   `dp = 1` (可以认为爬到第0阶有一种方法，即不爬) - 如果n从1开始，dp=1, dp=2。
    *   `dp = 1` (爬到第1阶只有一种方法：1步)
    *   `dp = 2` (爬到第2阶有两种方法：1+1 或 2)
*   最终结果是 `dp[n]`。

**空间优化**: 由于 `dp[i]` 只依赖于 `dp[i-1]` 和 `dp[i-2]`，可以使用两个变量来优化空间复杂度到 O(1)。

**Python 实现 (空间优化DP):**
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 0:
            return 0
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        # dp_i_minus_2 corresponds to dp[i-2], dp_i_minus_1 to dp[i-1]
        dp_i_minus_2 = 1 # ways to reach step 1
        dp_i_minus_1 = 2 # ways to reach step 2
        
        current_dp = 0
        for i in range(3, n + 1):
            current_dp = dp_i_minus_1 + dp_i_minus_2
            dp_i_minus_2 = dp_i_minus_1
            dp_i_minus_1 = current_dp
            
        return dp_i_minus_1 # This now holds ways to reach step n
```

**Java 实现 (空间优化DP):**
```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 0) {
            return 0;
        }
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }

        // dpIMinus2 corresponds to dp[i-2], dpIMinus1 to dp[i-1]
        int dpIMinus2 = 1; // Ways to reach step 1
        int dpIMinus1 = 2; // Ways to reach step 2
        
        int currentDp = 0;
        for (int i = 3; i <= n; i++) {
            currentDp = dpIMinus1 + dpIMinus2;
            dpIMinus2 = dpIMinus1;
            dpIMinus1 = currentDp;
        }
        return dpIMinus1; // This now holds ways to reach step n
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，因为我们迭代 N 次。
*   空间复杂度: O(1)，使用了常数个额外变量。

### 053: [322. 零钱兑换 (Coin Change)](https://leetcode.cn/problems/coin-change)

**题目描述:**
给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。
计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。
你可以认为每种硬币的数量是无限的。（完全背包问题）

**解题思路 (动态规划 - 完全背包):**
*   `dp[i]` 表示凑成金额 `i` 所需的最少硬币数量。
*   初始化 `dp` 数组：`dp = 0` (凑成金额0需要0个硬币)。其他 `dp[j]` (for `j > 0`) 初始化为一个大数 (例如 `amount + 1`，表示当前不可达)。
*   **状态转移**:
    *   遍历金额 `i` 从 1 到 `amount`。
    *   对于每个金额 `i`，遍历 `coins` 数组中的每种硬币 `coin`：
        *   如果 `i >= coin` (当前金额 `i` 大于等于硬币面值 `coin`)：
            *   我们可以尝试使用一个 `coin`。那么凑成 `i` 的硬币数，可以是凑成 `i - coin` 的硬币数加 1。
            *   `dp[i] = min(dp[i], dp[i - coin] + 1)`。
            *   注意，`dp[i-coin]` 必须是可达的（即不是初始的大数值）。
*   最终结果是 `dp[amount]`。如果 `dp[amount]` 仍然是初始的大数值，则说明无法凑成总金额，返回 `-1`。

**Python 实现:**
```python
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        if amount == 0:
            return 0
        
        # dp[i] will be storing the minimum number of coins required for amount i
        # Initialize with a value larger than any possible number of coins (amount + 1)
        dp = [float('inf')] * (amount + 1)
        dp[0] = 0 # Base case: 0 coins are needed to make amount 0
        
        for i in range(1, amount + 1): # For each amount from 1 to 'amount'
            for coin in coins:          # For each coin denomination
                if i - coin >= 0 and dp[i - coin] != float('inf'):
                    # If coin can be used and previous state is reachable
                    dp[i] = min(dp[i], dp[i - coin] + 1)
                    
        return dp[amount] if dp[amount] != float('inf') else -1
```

**Java 实现:**
```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        if (amount == 0) {
            return 0;
        }

        // dp[i] will store the minimum number of coins for amount i
        // Initialize with a value larger than any possible number of coins (amount + 1)
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1); // Using amount + 1 as "infinity"
        
        dp[0] = 0; // Base case: 0 coins for amount 0

        for (int i = 1; i <= amount; i++) { // For each amount from 1 to 'amount'
            for (int coin : coins) {        // For each coin denomination
                if (i - coin >= 0 && dp[i - coin] != (amount + 1)) {
                    // If coin can be used and previous state (dp[i-coin]) is reachable
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }
        
        return (dp[amount] == (amount + 1)) ? -1 : dp[amount];
    }
}
```

**复杂度分析:**
*   时间复杂度: O(S * N)，其中 S 是总金额 `amount`，N 是硬币种类数 `len(coins)`。
*   空间复杂度: O(S)，用于 `dp` 数组。

### 054: [76. 最小覆盖子串 (Minimum Window Substring)](https://leetcode.cn/problems/minimum-window-substring)

**题目描述:**
给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。
注意：
*   对于 `t` 中重复字符，我们寻找的子串中该字符数量必须不少于 `t` 中该字符数量。
*   如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

**解题思路 (滑动窗口):**
1.  **统计目标字符**: 使用哈希表 `target_counts` 统计字符串 `t` 中每个字符的出现频率。
2.  **滑动窗口**:
    *   初始化 `left = 0`, `right = 0`。
    *   `window_counts` 哈希表用于记录当前窗口 `s[left...right)` 中字符的频率。
    *   `formed_chars` 计数器记录当前窗口中满足 `t` 要求的字符种类数。当 `formed_chars == len(target_counts)` 时，表示窗口已覆盖 `t`。
    *   `min_len = infinity`, `min_window_start = 0` 用于记录最小覆盖子串的长度和起始位置。
3.  **扩展窗口 (移动 `right` 指针)**:
    *   将 `s[right]` 加入窗口，更新 `window_counts[s[right]]`。
    *   如果 `s[right]` 在 `target_counts` 中，并且 `window_counts[s[right]] == target_counts[s[right]]`，则 `formed_chars++`。
    *   `right++`。
4.  **收缩窗口 (当 `formed_chars == len(target_counts)` 时，移动 `left` 指针)**:
    *   此时窗口 `s[left...right-1]` 是一个有效的覆盖子串。
    *   更新 `min_len` 和 `min_window_start` 如果当前窗口更短。
    *   将 `s[left]` 移出窗口，更新 `window_counts[s[left]]--`。
    *   如果 `s[left]` 在 `target_counts` 中，并且在移出前 `window_counts[s[left]] == target_counts[s[left]]`，则 `formed_chars--` (因为这个字符不再满足数量要求了)。
    *   `left++`。
5.  重复扩展和收缩，直到 `right` 到达 `s` 的末尾。
6.  如果 `min_len` 仍为 `infinity`，返回 `""`，否则返回 `s[min_window_start : min_window_start + min_len]`。

**Python 实现:**
```python
import collections

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not t or not s or len(s) < len(t):
            return ""

        target_counts = collections.Counter(t)
        required_unique_chars = len(target_counts) # Number of unique characters in t we need to match count for
        
        left = 0
        formed_chars = 0 # Number of unique characters in t whose counts are satisfied in window
        window_counts = collections.defaultdict(int)
        
        min_len = float('inf')
        ans_left, ans_right = 0, 0 # To store the boundaries of the min window

        for right in range(len(s)):
            char_right = s[right]
            window_counts[char_right] += 1

            if char_right in target_counts and window_counts[char_right] == target_counts[char_right]:
                formed_chars += 1
            
            # Try and contract the window while it's still valid
            while left <= right and formed_chars == required_unique_chars:
                current_len = right - left + 1
                if current_len < min_len:
                    min_len = current_len
                    ans_left = left
                    ans_right = right + 1 # s[ans_left:ans_right]
                
                char_left = s[left]
                window_counts[char_left] -= 1
                
                if char_left in target_counts and window_counts[char_left] < target_counts[char_left]:
                    formed_chars -= 1
                
                left += 1
                
        return s[ans_left:ans_right] if min_len != float('inf') else ""

```

**Java 实现:**
```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String minWindow(String s, String t) {
        if (s == null || t == null || s.length() == 0 || t.length() == 0 || s.length() < t.length()) {
            return "";
        }

        Map<Character, Integer> targetCounts = new HashMap<>();
        for (char c : t.toCharArray()) {
            targetCounts.put(c, targetCounts.getOrDefault(c, 0) + 1);
        }

        int left = 0;
        Map<Character, Integer> windowCounts = new HashMap<>();
        int formedChars = 0; // How many unique characters in t are satisfied in the window
        int requiredUniqueChars = targetCounts.size();

        int minLen = Integer.MAX_VALUE;
        int ansLeft = 0, ansRight = 0; // s.substring(ansLeft, ansRight)

        for (int right = 0; right < s.length(); right++) {
            char charRight = s.charAt(right);
            windowCounts.put(charRight, windowCounts.getOrDefault(charRight, 0) + 1);

            if (targetCounts.containsKey(charRight) && 
                windowCounts.get(charRight).intValue() == targetCounts.get(charRight).intValue()) {
                formedChars++;
            }

            // Try and contract the window
            while (left <= right && formedChars == requiredUniqueChars) {
                int currentLen = right - left + 1;
                if (currentLen < minLen) {
                    minLen = currentLen;
                    ansLeft = left;
                    ansRight = right + 1;
                }

                char charLeft = s.charAt(left);
                windowCounts.put(charLeft, windowCounts.get(charLeft) - 1);

                if (targetCounts.containsKey(charLeft) && 
                    windowCounts.get(charLeft).intValue() < targetCounts.get(charLeft).intValue()) {
                    formedChars--;
                }
                left++;
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(ansLeft, ansRight);
    }
}
```

**复杂度分析:**
*   时间复杂度: O(|S| + |T|)。|S| 是字符串 `s` 的长度，|T| 是字符串 `t` 的长度。`left` 和 `right` 指针都最多遍历 `s` 一次。预处理 `t` 需要 O(|T|)。
*   空间复杂度: O(K_s + K_t)，其中 K_s 是 `s` 中不同字符数，K_t 是 `t` 中不同字符数（取决于字符集大小）。用于存储 `target_counts` 和 `window_counts`。

### 055: [41. 缺失的第一个正数 (First Missing Positive)](https://leetcode.cn/problems/first-missing-positive)

**题目描述:**
给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。
请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的算法。

**解题思路 (原地哈希 / 循环排序变体):**
核心思想：我们期望数字 `1` 出现在索引 `0`，数字 `2` 出现在索引 `1`，以此类推，数字 `k` 出现在索引 `k-1`。
1.  遍历数组 `nums`。对于每个数字 `nums[i]`：
    *   如果 `nums[i]` 是正数，且 `nums[i] <= n` (n 是数组长度)，并且 `nums[i]` 没有在它应该在的位置上 (即 `nums[i] != nums[nums[i]-1]`)：
        *   则交换 `nums[i]` 和 `nums[nums[i]-1]`，直到 `nums[i]` 在正确的位置，或者它不再满足上述条件（变为非正数、大于n、或已在正确位置）。
        *   需要用 `while` 循环来处理一个位置上的数被换过来后，可能还需要继续调整的情况。
2.  完成上述交换操作后，再次遍历数组：
    *   找到第一个 `nums[i] != i + 1` 的位置。那么 `i + 1` 就是缺失的第一个正数。
3.  如果遍历完发现所有 `nums[i] == i + 1` (即数组是 `[1, 2, ..., n]`)，那么缺失的第一个正数是 `n + 1`。

**Python 实现:**
```python
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)
        
        # Step 1: Place each number in its correct "hash" position if possible
        # nums[i] should ideally be i+1
        # So number k should be at index k-1
        i = 0
        while i < n:
            # j is the target index for nums[i]
            j = nums[i] - 1 
            if 0 <= j < n and nums[i] != nums[j]: # nums[i] is in range 1..n and not in place
                nums[i], nums[j] = nums[j], nums[i] # Swap
            else:
                i += 1 # Move to next element if current one is correct or out of range
        
        # Step 2: Find the first position where nums[i] != i + 1
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        
        # If all numbers from 1 to n are present, the missing one is n + 1
        return n + 1
```

**Java 实现:**
```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        // Step 1: Place each number in its correct "hash" position
        // Number k should be at index k-1
        for (int i = 0; i < n; ) {
            int targetVal = nums[i];
            if (targetVal > 0 && targetVal <= n && nums[targetVal - 1] != targetVal) {
                // Swap nums[i] with nums[targetVal - 1]
                int temp = nums[targetVal - 1];
                nums[targetVal - 1] = targetVal;
                nums[i] = temp;
                // Don't increment i, check the new nums[i]
            } else {
                i++; // Move to next element if nums[i] is correct or out of range
            }
        }

        // Step 2: Find the first position where nums[i] != i + 1
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }

        // If all numbers from 1 to n are present
        return n + 1;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)。虽然第一步有 `while` 循环嵌套在 `for` 循环里（或外层是`while`），但每个数字最多被交换到正确位置一次。所以总的交换次数不会超过 N。第二步遍历也是 O(N)。

### 056: [43. 字符串相乘 (Multiply Strings)](https://leetcode.cn/problems/multiply-strings)

**题目描述:**
给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积，它们的乘积也表示为字符串形式。
**注意：** 不能使用任何内置的 BigInteger 库或直接将输入转换为整数。

**解题思路 (模拟手动乘法):**
1.  如果 `num1` 或 `num2` 是 "0"，结果是 "0"。
2.  创建一个长度为 `len(num1) + len(num2)` 的数组 `result_digits` (或列表)，初始化为0。这个数组用来存放乘积的每一位。
3.  从右到左遍历 `num1` (索引 `i`) 和 `num2` (索引 `j`)：
    *   取 `digit1 = int(num1[i])` 和 `digit2 = int(num2[j])`.
    *   乘积 `product = digit1 * digit2`。
    *   `product` 影响 `result_digits` 中的两位：`result_digits[i + j + 1]` (低位) 和 `result_digits[i + j]` (高位)。
    *   计算 `sum_val = product + result_digits[i + j + 1]` (加上之前可能存在的进位)。
    *   `result_digits[i + j + 1] = sum_val % 10` (当前位的数字)。
    *   `result_digits[i + j] += sum_val // 10` (高位累加上新的进位)。
4.  将 `result_digits` 数组转换为字符串。注意处理前导零 (如果 `result_digits` 是0，则不包括它，除非结果本身是0)。

**Python 实现:**
```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"

        m, n = len(num1), len(num2)
        # result_digits[i+j+1] stores product of num1[i] and num2[j]'s unit digit contribution
        # result_digits[i+j] stores the carry.
        result_digits = [0] * (m + n)

        for i in range(m - 1, -1, -1):
            digit1 = int(num1[i])
            for j in range(n - 1, -1, -1):
                digit2 = int(num2[j])
                
                product = digit1 * digit2
                
                # Position in result_digits for current product:
                # p1 for carry (e.g., tens place), p2 for unit place
                p1, p2 = i + j, i + j + 1 
                
                # Add current product to the existing value at result_digits[p2]
                current_sum = product + result_digits[p2]
                
                result_digits[p2] = current_sum % 10
                result_digits[p1] += current_sum // 10 # Add carry to higher position

        # Convert result_digits list to string
        # Find the first non-zero digit
        first_digit_idx = 0
        while first_digit_idx < len(result_digits) and result_digits[first_digit_idx] == 0:
            first_digit_idx += 1
        
        if first_digit_idx == len(result_digits): # Should not happen if not "0"*"0"
             return "0" 

        return "".join(map(str, result_digits[first_digit_idx:]))
```

**Java 实现:**
```java
class Solution {
    public String multiply(String num1, String num2) {
        if ("0".equals(num1) || "0".equals(num2)) {
            return "0";
        }

        int m = num1.length();
        int n = num2.length();
        int[] resultDigits = new int[m + n]; // Stores digits of the result

        // Multiply from right to left
        for (int i = m - 1; i >= 0; i--) {
            int digit1 = num1.charAt(i) - '0';
            for (int j = n - 1; j >= 0; j--) {
                int digit2 = num2.charAt(j) - '0';
                
                int product = digit1 * digit2;
                
                // p1 is for the more significant digit (carry), p2 is for the less significant
                int p1 = i + j;     // Index for potential carry
                int p2 = i + j + 1; // Index for the unit part of product

                // Add current product to the existing value at resultDigits[p2]
                int currentSum = product + resultDigits[p2];
                
                resultDigits[p2] = currentSum % 10;    // Set unit digit
                resultDigits[p1] += currentSum / 10;   // Add carry to higher position
            }
        }

        // Convert resultDigits array to string
        StringBuilder sb = new StringBuilder();
        int firstDigitIdx = 0;
        // Skip leading zeros (unless the result is just "0", handled at start)
        while (firstDigitIdx < resultDigits.length && resultDigits[firstDigitIdx] == 0) {
            firstDigitIdx++;
        }
        
        if (firstDigitIdx == resultDigits.length) return "0"; // Should be caught by initial check

        for (int k = firstDigitIdx; k < resultDigits.length; k++) {
            sb.append(resultDigits[k]);
        }
        
        return sb.toString();
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 和 N 分别是 `num1` 和 `num2` 的长度。两层嵌套循环。
*   空间复杂度: O(M + N)，用于存储结果 `result_digits`。

### 057: [剑指 Offer 22. 链表中倒数第k个节点 (Lian Biao Zhong Dao Shu Di Kge Jie Dian Lcof)](https://leetcode.cn/problems/lian-biao-zhong-dao-shu-di-kge-jie-dian-lcof)
(LeetCode 主站也有对应题目: 19. Remove Nth Node From End of List，但这题是找到节点，不是删除)

**题目描述:**
输入一个链表，输出该链表中倒数第k个节点。为了符合大多数人的习惯，本题从1开始计数，即链表的尾节点是倒数第1个节点。例如，一个链表有 6 个节点，从头节点开始，它们的值依次是 1、2、3、4、5、6。这个链表的倒数第 3 个节点是值为 4 的节点。

**解题思路 (双指针法):**
1.  创建两个指针，`fast` 和 `slow`，都初始化为链表的头节点 `head`。
2.  让 `fast` 指针先向前移动 `k` 步。
    *   如果在移动过程中 `fast` 变为 `null`，说明链表长度小于 `k`，则题目要求无效（根据 LeetCode 此题上下文，`k` 保证有效）。
3.  然后，同时向前移动 `fast` 和 `slow` 指针，一步一步地移动。
4.  当 `fast` 指针到达链表的末尾 (`fast == null`，如果 `fast` 先走了 `k` 步，那它到 `null` 时，`slow` 就在倒数第 `k` 个。或者更稳妥是，`fast` 到达最后一个节点时，`slow` 的位置，然后 `slow` 再根据 `k` 的定义调整)

Let's refine step 2 & 3 for finding the node:
1.  `fast` and `slow` start at `head`.
2.  Move `fast` forward `k` steps.
3.  Now, move both `fast` and `slow` forward one step at a time until `fast` reaches the end of the list (`fast == null`).
4.  When `fast` is `null`, `slow` will be pointing to the倒数第 `k` 个节点。

Consider example: 1->2->3->4->5, k=2.
slow=1, fast=1
fast moves k steps: fast becomes 3 (1->2->3).
Now move both:
slow=2, fast=4
slow=3, fast=5
slow=4, fast=null -> slow (node 4) is the answer.

**Python 实现:**
```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def getKthFromEnd(self, head: ListNode, k: int) -> ListNode:
        if not head or k <= 0:
            return None
        
        fast = head
        slow = head
        
        # Move fast pointer k steps ahead
        for _ in range(k):
            if not fast: # k is larger than the length of the list
                return None
            fast = fast.next
            
        # Move both pointers until fast reaches the end
        while fast:
            slow = slow.next
            fast = fast.next
            
        return slow
```

**Java 实现:**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

class Solution {
    public ListNode getKthFromEnd(ListNode head, int k) {
        if (head == null || k <= 0) {
            return null;
        }

        ListNode fast = head;
        ListNode slow = head;

        // Move fast pointer k steps ahead
        for (int i = 0; i < k; i++) {
            if (fast == null) { // k is larger than the length of the list
                return null; 
            }
            fast = fast.next;
        }

            fast = fast.next;
        }
        
        return slow;
    }
}
```

*   时间复杂度: O(N)，其中 N 是链表的长度。`fast` 指针遍历链表一次。
*   空间复杂度: O(1)，只使用了常数个额外指针。

### 058: [105. 从前序与中序遍历序列构造二叉树 (Construct Binary Tree from Preorder and Inorder Traversal)](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal)

**题目描述:**
给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**解题思路 (递归):**
1.  **基本特性:**
    *   **先序遍历 (`preorder`):** 第一个元素是当前子树的根节点。
    *   **中序遍历 (`inorder`):** 根节点左边的元素是左子树的所有节点，右边的元素是右子树的所有节点。
2.  **递归函数 `build(preorder_left, preorder_right, inorder_left, inorder_right)`:**
    *   参数表示当前处理的 `preorder` 和 `inorder` 子数组的边界。
3.  **基准情况:**
    *   如果 `preorder_left > preorder_right` (或 `inorder_left > inorder_right`)，说明子数组为空，返回 `None`。
4.  **递归步骤:**
    a.  **找到根节点**: `preorder[preorder_left]` 是当前子树的根节点值 `root_val`。
    b.  **创建根节点**: `root = TreeNode(root_val)`。
    c.  **在中序遍历中定位根节点**: 遍历 `inorder` (从 `inorder_left` 到 `inorder_right`)，找到 `root_val` 的索引 `inorder_root_idx`。
    (优化: 可以预先将 `inorder` 值与其索引存入哈希表，O(1)查找)。
    d.  **计算左子树的大小**: `left_subtree_size = inorder_root_idx - inorder_left`。
    e.  **递归构建左子树**:
    *   `root.left = build(preorder_left + 1, preorder_left + left_subtree_size, inorder_left, inorder_root_idx - 1)`
    f.  **递归构建右子树**:
    *   `root.right = build(preorder_left + left_subtree_size + 1, preorder_right, inorder_root_idx + 1, inorder_right)`
    g.  返回 `root`。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> TreeNode:
        if not preorder or not inorder:
            return None
            
        # Optimization: Create a map for inorder values to their indices
        inorder_map = {val: idx for idx, val in enumerate(inorder)}
        
        # Keep track of the current root index in preorder traversal
        # This avoids slicing preorder array repeatedly.
        self.preorder_idx = 0 

        def build_helper(in_left, in_right):
            # Base case: if the current inorder segment is empty
            if in_left > in_right:
                return None
            
            # The current root value is the next element in preorder
            root_val = preorder[self.preorder_idx]
            self.preorder_idx += 1
            
            root = TreeNode(root_val)
            
            # Find the root's index in the current inorder segment
            inorder_root_idx = inorder_map[root_val]
            
            # Recursively build the left and right subtrees
            # Important: Build left subtree first because preorder_idx advances.
            root.left = build_helper(in_left, inorder_root_idx - 1)
            root.right = build_helper(inorder_root_idx + 1, in_right)
            
            return root

        return build_helper(0, len(inorder) - 1)

```

**Java 实现:**
```java
import java.util.HashMap;
import java.util.Map;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    private int preorderIdx; // Tracks current root in preorder traversal
    private Map<Integer, Integer> inorderMap; // To quickly find root in inorder

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        if (preorder == null || inorder == null || preorder.length == 0 || inorder.length == 0) {
            return null;
        }

        preorderIdx = 0;
        inorderMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            inorderMap.put(inorder[i], i);
        }

        return buildHelper(preorder, 0, inorder.length - 1);
    }

    private TreeNode buildHelper(int[] preorder, int inLeft, int inRight) {
        // Base case: if the current inorder segment is empty
        if (inLeft > inRight) {
            return null;
        }

        // The current root value is from preorder traversal
        int rootVal = preorder[preorderIdx];
        preorderIdx++; // Move to the next root for subsequent calls

        TreeNode root = new TreeNode(rootVal);

        // Find the root's index in the current inorder segment using the map
        int inorderRootIdx = inorderMap.get(rootVal);

        // Recursively build left and right subtrees
        // Note: Left subtree must be built first because preorderIdx is advanced.
        root.left = buildHelper(preorder, inLeft, inorderRootIdx - 1);
        root.right = buildHelper(preorder, inorderRootIdx + 1, inRight);

        return root;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是节点数。每个节点被访问和处理一次。哈希表查找 `inorder_root_idx` 是 O(1)。
*   空间复杂度: O(N) (用于哈希表 `inorder_map` 和递归调用栈)。在最坏情况下（链状树），递归栈深度可达 N。平衡树时为 O(log N) for stack.

### 059: [78. 子集 (Subsets)](https://leetcode.cn/problems/subsets)

**题目描述:**
给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。
解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

**解题思路:**
**1. 回溯法 (Backtracking):**
* 定义 `backtrack(start_index, current_subset)`。
* `start_index`: 当前选择可以从 `nums[start_index]` 开始，避免重复子集 (如 `` 和 `` 如果不限制起始，会重复)。
* `current_subset`: 当前构建的子集。
* **递归步骤**:
  a.  首先将 `current_subset` (的副本) 加入结果列表 `result` (因为空集也是子集，且每个中间状态也是子集)。
  b.  从 `start_index` 到 `len(nums)-1` 遍历 `nums[i]`:
  i.  **选择**: `current_subset.add(nums[i])`。
  ii. **探索**: `backtrack(i + 1, current_subset)` (注意是 `i + 1`，不是 `start_index + 1`，因为下一元素必须在当前元素之后选)。
  iii. **撤销选择**: `current_subset.removeLast()` (或 `pop()`)。
* 初始调用: `backtrack(0, [])`。

**2. 迭代法 (构建):**
* 从一个空集 `[[]]` 开始。
* 遍历 `nums` 中的每个元素 `num`:
    * 对于 `result` 中已有的每个子集 `subset`，创建一个新的子集 `subset + [num]`，并将其加入 `result`。
* (这个迭代法直接对 `result` 操作，需要注意迭代时修改集合的问题，通常是先复制 `result` 当前状态的子集，再添加新元素。)
  ```python
  result = [[]]
  for num in nums:
      new_subsets = []
      for subset in result:
          new_subsets.append(subset + [num])
      result.extend(new_subsets)
  return result
  ```

**3. 位运算 (Binary Mask):**
* 如果有 `n` 个元素，那么有 `2^n` 个子集。
* 每个数字从 `0` 到 `2^n - 1` 可以看作是一个二进制掩码。
* 如果掩码的第 `j`-th 位是 1，则表示 `nums[j]` 在当前子集中。
* 遍历 `i` 从 `0` 到 `2^n - 1`:
*   构建子集：检查 `i` 的每一位。如果第 `j` 位是1, 加入 `nums[j]`。

**Python 实现 (Backtracking):**
```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        result = []
        current_subset = []
        n = len(nums)

        def backtrack(start_index):
            result.append(list(current_subset)) # Add a copy of the current subset

            for i in range(start_index, n):
                # Choose
                current_subset.append(nums[i])
                # Explore
                backtrack(i + 1)
                # Unchoose (Backtrack)
                current_subset.pop()
        
        backtrack(0)
        return result
```

**Java 实现 (Backtracking):**
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> currentSubset = new ArrayList<>();
        
        backtrack(nums, 0, currentSubset, result);
        
        return result;
    }

    private void backtrack(int[] nums, int startIndex, List<Integer> currentSubset, List<List<Integer>> result) {
        result.add(new ArrayList<>(currentSubset)); // Add a copy

        for (int i = startIndex; i < nums.length; i++) {
            // Choose
            currentSubset.add(nums[i]);
            // Explore
            backtrack(nums, i + 1, currentSubset, result);
            // Unchoose (Backtrack)
            currentSubset.remove(currentSubset.size() - 1);
        }
    }
}
```

**复杂度分析 (Backtracking):**
*   时间复杂度: O(N * 2^N)。有 2^N 个子集，每个子集平均长度 N/2，复制一个子集需要 O(N)。
*   空间复杂度: O(N) (用于 `current_subset` 和递归调用栈深度)。结果列表本身存储 2^N 个子集。

### 060: [151. 翻转字符串里的单词 (Reverse Words in a String)](https://leetcode.cn/problems/reverse-words-in-a-string)

**题目描述:**
给你一个字符串 `s` ，请你翻转字符串中 **单词** 的顺序。

```java
class SolutionManualJava {
    public String reverseWords(String s) {
        if (s == null) return null;

        // 1. Clean spaces: remove leading/trailing and reduce multiple to single
        StringBuilder sb = new StringBuilder();
        int i = 0, n = s.length();
        while (i < n && s.charAt(i) == ' ') i++; // skip leading spaces
        
        while (i < n) {
            while (i < n && s.charAt(i) != ' ') {
                sb.append(s.charAt(i));
                i++;
            }
            // At this point, i is at a space or end of string
            while (i < n && s.charAt(i) == ' ') { // skip multiple spaces
                i++;
            }
            if (i < n) { // If not end of string, it means next char is start of new word
                sb.append(' '); // Add a single space
            }
        }
        
        String cleanedString = sb.toString();
        if (cleanedString.isEmpty()) return "";

        // 2. Split into words (now guaranteed single space separated)
        String[] words = cleanedString.split(" ");
        
        // 3. Reverse the array of words
        StringBuilder reversedSb = new StringBuilder();
        for (int j = words.length - 1; j >= 0; j--) {
            reversedSb.append(words[j]);
            if (j > 0) {
                reversedSb.append(" ");
            }
        }
        return reversedSb.toString();
    }
}
```

**复杂度分析 (Python Built-in):**
*   时间复杂度: O(N)，其中 N 是字符串长度。`split` 是 O(N)，`reverse` 是 O(W) (W 单词数)，`join` 是 O(N)。
*   空间复杂度: O(N)，用于存储单词列表和结果字符串。

**复杂度分析 (Java with regex split/join):**
*   时间复杂度: O(N). `trim` O(N), `split` with regex can be O(N), `reverse` O(W), `join` O(N).
*   空间复杂度: O(N) for the `wordsList` and the final string.

**复杂度分析 (Java Manual approach for O(1) space (if done in char array in place), but here it's O(N)):**
The provided manual Java creates new StringBuilders, so it's O(N) space. True in-place for O(1) space involves:
1. Reverse entire char array.
2. Reverse each word in the reversed char array.
3. Clean up spaces (hardest part for O(1) space).
   The LeetCode problem constraints usually allow O(N) space for string manipulations. The `SolutionManualJava` as written is still O(N) space for `sb` and `words` array.
