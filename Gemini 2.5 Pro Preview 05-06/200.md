### 191: [84. 柱状图中最大的矩形 (Largest Rectangle in Histogram)](https://leetcode.cn/problems/largest-rectangle-in-histogram)

**题目描述:**
给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。
求在该柱状图中，能够勾勒出来的矩形的最大面积。

**解题思路 (单调栈):**
这个问题是单调栈的经典应用。
核心思想是：对于每个柱子 `i`，如果我们想以它为高度 `h = heights[i]` 来构建一个矩形，那么这个矩形的宽度就是向左和向右延伸，直到遇到第一个高度小于 `h` 的柱子为止。

1.  维护一个单调递增栈，栈中存储柱子的**索引**。栈底到栈顶的柱子高度是递增的。
2.  遍历柱子高度数组 `heights`:
    a.  对于当前柱子 `heights[i]`：
    i.  **当栈不为空，且当前柱子高度 `heights[i]` 小于栈顶柱子 `heights[stack.top()]` 时**:
    *   这说明栈顶柱子找到了它的“右边界”（即当前柱子 `i`）。它的“左边界”是栈中再下一个元素对应的柱子 (如果栈中只有一个元素，左边界就是-1，或者说数组的开始)。
    *   弹出栈顶元素 `top_idx`。令 `h = heights[top_idx]`。
    *   计算宽度 `w`。如果栈为空，宽度是 `i`；否则，宽度是 `i - stack.top() - 1`。
    *   计算面积 `area = h * w`，并更新最大面积 `max_area`。
    *   **持续弹出**，直到当前柱子不再小于新的栈顶，或者栈为空。
    ii. **将当前柱子索引 `i` 压入栈中**。
3.  遍历完所有柱子后，栈中可能还剩下一些柱子。这些柱子的“右边界”可以认为是整个数组的末尾 (索引 `n`)。
    *   依次弹出栈中剩余的元素，按上述方法计算以它们为高度的矩形面积。
    *   此时，对于弹出的 `top_idx`，`h = heights[top_idx]`。宽度 `w`：如果栈为空，宽度是 `n` (总长度)；否则，宽度是 `n - stack.top() - 1`。

**优化技巧**: 为了统一处理第3步（遍历完后的栈中剩余元素），可以在 `heights` 数组的末尾添加一个高度为0的柱子。这样，所有栈中的元素都会在遇到这个0高度柱子时被正确处理弹出。

**Python 实现 (单调栈):**
```python
class Solution:
    def largestRectangleArea(self, heights: list[int]) -> int:
        stack = [-1] # Store indices, -1 as a sentinel for boundary calculation
        max_area = 0
        
        # Add a sentinel 0 at the end to ensure all bars are processed
        extended_heights = heights + [0] 
        
        for i, h_curr in enumerate(extended_heights):
            # While stack is not empty (beyond sentinel) and current height is less than stack top height
            while stack[-1] != -1 and extended_heights[stack[-1]] >= h_curr:
                # Pop the bar from stack, this bar's height is h
                h_popped = extended_heights[stack.pop()]
                # The width is from current index i to the index of the bar just before popped one in stack
                w = i - stack[-1] - 1
                max_area = max(max_area, h_popped * w)
            
            stack.append(i)
            
        return max_area
```

    public int largestRectangleArea(int[] heights) {

            return 0;
        }

        // Stack stores indices of bars
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;

        // Create a new array with an extra 0 at the end to pop all remaining bars
        int[] extendedHeights = new int[heights.length + 1];
        for (int i = 0; i < heights.length; i++) {
            extendedHeights[i] = heights[i];
        }
        extendedHeights[heights.length] = 0; // Sentinel bar

        for (int i = 0; i < extendedHeights.length; i++) {
            // While stack is not empty and current height is less than stack top's height
            while (!stack.isEmpty() && extendedHeights[stack.peek()] >= extendedHeights[i]) {
                int hPopped = extendedHeights[stack.pop()];
                // Calculate width
                // If stack is empty, it means the popped bar extended to the beginning
                int w = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, hPopped * w);
            }
            stack.push(i); // Push current bar's index
        }
        return maxArea;
    }
}

### 192: [51. N皇后 (N-Queens)](https://leetcode.cn/problems/n-queens)

**题目描述:**
n 皇后问题 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。
给你一个整数 `n` ，返回所有不同的 n 皇后问题 的解决方案。
每一种解法包含一个不同的 n 皇后 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。
皇后可以攻击同一行、同一列、以及两条主副对角线上的单位。

**解题思路 (回溯法 Backtracking):**
1.  **棋盘表示**: 通常使用一个一维数组 `placement[row] = col` 来表示第 `row` 行的皇后放在了第 `col` 列。
2.  **回溯函数 `backtrack(row, current_board_state)`**:
    *   `row`: 当前尝试放置皇后的行号 (从0到n-1)。
    *   `current_board_state`: 可以是上述的 `placement` 数组，或者是一个二维字符数组表示整个棋盘。
3.  **基准情况**:
    *   如果 `row == n`，说明已经成功放置了n个皇后（0到n-1行都放了）。将当前棋盘状态 `current_board_state` 格式化后加入结果列表。
4.  **递归步骤 (对于当前行 `row`)**:
    *   遍历当前行的每一列 `col` (从0到n-1)。
    *   **检查合法性 `is_valid(row, col, placement)`**: 检查在 `(row, col)` 位置放置皇后是否会与之前已放置的皇后 (在 `0` 到 `row-1` 行) 发生冲突。
        *   **列冲突**: 检查 `placement[prev_row] == col`。
        *   **对角线冲突**:
            *   主对角线: `abs(row - prev_row) == abs(col - placement[prev_row])`，并且 `(row - prev_row)` 和 `(col - placement[prev_row])` 同号。 (Actually `abs(row-prev_row) == abs(col-col_of_prev_row)`)
            *   或者，更简单地： `prev_row - placement[prev_row] == row - col` (同一副对角线，行列差相同)。
            *   `prev_row + placement[prev_row] == row + col` (同一主对角线，行列和相同)。
    *   如果 `is_valid` 为 `true`:
        a.  **选择**: `placement[row] = col` (或者在棋盘上标记 `'Q'`)。
        b.  **探索**: 递归调用 `backtrack(row + 1, placement)`。
        c.  **撤销选择 (回溯)**: `placement[row]` 恢复 (或者棋盘上标记回 `'.'`)，以便尝试该行其他列。

**优化合法性检查**:
可以使用三个布尔数组/集合来O(1)检查冲突：
*   `used_cols[c]`: 标记第 `c` 列是否已被占用。
*   `used_diag1[r - c + (n-1)]`: 标记从左上到右下的对角线 (`r-c` 为常数) 是否被占用。`+(n-1)` 是为了让索引非负。
*   `used_diag2[r + c]`: 标记从右上到左下的对角线 (`r+c` 为常数) 是否被占用。

**Python 实现:**```python
class Solution:
def solveNQueens(self, n: int) -> list[list[str]]:
solutions = []
# board[row] = col means queen at (row, col)
# More efficient: placement array where index is row, value is col.

        # To make board state easily: char_board = [['.' for _ in range(n)] for _ in range(n)]
        
        # Using boolean arrays for O(1) conflict checking
        used_cols = [False] * n
        # For diagonals: row - col = const (main diagonals)
        # Add (n-1) to shift index to be non-negative. Min value of r-c is 0-(n-1) = -(n-1). Max is (n-1)-0 = n-1.
        # Range is -(n-1) to n-1. Size 2n-1. Shifted index: 0 to 2n-2.
        used_diag1 = [False] * (2 * n - 1) # For r - c + (n-1)
        # For diagonals: row + col = const (anti-diagonals)
        # Min value of r+c is 0. Max is (n-1)+(n-1) = 2n-2. Size 2n-1.
        used_diag2 = [False] * (2 * n - 1) # For r + c

        current_placement = [-1] * n # stores col for each row

        def backtrack(row):
            if row == n:
                # Found a solution, format it and add to solutions
                board_str_format = []
                for r_idx in range(n):
                    line = ['.'] * n
                    line[current_placement[r_idx]] = 'Q'
                    board_str_format.append("".join(line))
                solutions.append(board_str_format)
                return

            for col in range(n):
                diag1_idx = row - col + (n - 1)
                diag2_idx = row + col
                
                if not used_cols[col] and \
                   not used_diag1[diag1_idx] and \
                   not used_diag2[diag2_idx]:
                    
                    # Place queen
                    current_placement[row] = col
                    used_cols[col] = True
                    used_diag1[diag1_idx] = True
                    used_diag2[diag2_idx] = True
                    
                    # Recurse for next row
                    backtrack(row + 1)
                    
                    # Backtrack (un-place queen)
                    used_cols[col] = False
                    used_diag1[diag1_idx] = False
                    used_diag2[diag2_idx] = False
                    # current_placement[row] = -1 (optional if always overwritten)
        
        backtrack(0)
        return solutions

```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Arrays;

class Solution {
    private List<List<String>> solutions;
    private int n;
    private boolean[] usedCols;
    private boolean[] usedDiag1; // r - c + (n-1)
    private boolean[] usedDiag2; // r + c
    private int[] currentPlacement; // currentPlacement[row] = col

    public List<List<String>> solveNQueens(int n) {
        this.solutions = new ArrayList<>();
        this.n = n;
        this.usedCols = new boolean[n];
        this.usedDiag1 = new boolean[2 * n - 1];
        this.usedDiag2 = new boolean[2 * n - 1];
        this.currentPlacement = new int[n]; // Stores column for each row

        backtrack(0);
        return solutions;
    }

    private void backtrack(int row) {
        if (row == n) {
            // Found a solution, format it
            List<String> boardStrFormat = new ArrayList<>();
            char[] lineChars = new char[n];
            for (int r_idx = 0; r_idx < n; r_idx++) {
                Arrays.fill(lineChars, '.');
                lineChars[currentPlacement[r_idx]] = 'Q';
                boardStrFormat.add(new String(lineChars));
            }
            solutions.add(boardStrFormat);
            return;
        }

        for (int col = 0; col < n; col++) {
            int diag1Idx = row - col + (n - 1);
            int diag2Idx = row + col;

            if (!usedCols[col] && !usedDiag1[diag1Idx] && !usedDiag2[diag2Idx]) {
                // Place queen
                currentPlacement[row] = col;
                usedCols[col] = true;
                usedDiag1[diag1Idx] = true;
                usedDiag2[diag2Idx] = true;

                // Recurse for next row
                backtrack(row + 1);

                // Backtrack (un-place queen)
                usedCols[col] = false;
                usedDiag1[diag1Idx] = false;
                usedDiag2[diag2Idx] = false;
            }
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N!). There are N! possible placements if one queen per row and column. Checking each takes O(1) with boolean arrays. Generating solution board takes O(N^2). The number of solutions is much less than N!, but the search space explored is roughly N!. A tighter upper bound is difficult, often stated as O(N * N!) or related to number of solutions B(N) as O(N^2 * B(N)). Pruning significantly reduces paths compared to N!. Roughly O(N!) dominates.
*   空间复杂度: O(N) for recursion stack and tracking arrays (`usedCols`, `usedDiags`, `currentPlacement`). The output list can be O(B(N) * N^2) where B(N) is the number of solutions.

### 193: [673. 最长递增子序列的个数 (Number of Longest Increasing Subsequence)](https://leetcode.cn/problems/number-of-longest-increasing-subsequence)

**题目描述:**
给定一个未排序的整数数组 `nums` ， 返回最长递增子序列的个数 。
**注意** 这个数列必须是 **严格** 递增的。

**解题思路 (动态规划):**
与找到最长递增子序列 (LIS) 的长度类似，但还需要统计其个数。
1.  定义两个DP数组：
    *   `length[i]`: 以 `nums[i]` 结尾的最长递增子序列的长度。
    *   `count[i]`: 以 `nums[i]` 结尾的最长递增子序列的个数。
2.  **初始化**: `length[i] = 1` 和 `count[i] = 1` for all `i` (每个元素自身构成长度为1，个数为1的LIS)。
3.  **状态转移**: 对于每个 `nums[i]` (outer loop, `i` from 0 to n-1):
    *   遍历其之前的所有元素 `nums[j]` (inner loop, `j` from 0 to `i-1`):
        *   如果 `nums[i] > nums[j]` (可以构成递增):
            *   **如果 `length[j] + 1 > length[i]`**:
                *   我们找到了一个更长的以 `nums[i]` 结尾的 LIS。
                *   更新 `length[i] = length[j] + 1`。
                *   这种更长的 LIS 的个数直接继承自以 `nums[j]` 结尾的 LIS 的个数：`count[i] = count[j]`。
            *   **如果 `length[j] + 1 == length[i]`**:
                *   我们找到了另一个相同长度的以 `nums[i]` 结尾的 LIS。
                *   累加以 `nums[j]` 结尾的 LIS 的个数：`count[i] += count[j]`。
4.  **计算结果**:
    *   遍历完后，找到 `length` 数组中的最大值 `max_lis_length`。
    *   遍历 `length` 数组，将所有 `length[k] == max_lis_length` 对应的 `count[k]` 相加，即为最终结果。

**Python 实现:**
```python
class Solution:
    def findNumberOfLIS(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        
        # length[i]: length of LIS ending at nums[i]
        # count[i]: number of LIS ending at nums[i]
        length = [1] * n
        count = [1] * n
        
        for i in range(n):
            for j in range(i):
                if nums[i] > nums[j]:
                    if length[j] + 1 > length[i]:
                        length[i] = length[j] + 1
                        count[i] = count[j]  # Reset count
                    elif length[j] + 1 == length[i]:
                        count[i] += count[j] # Add to count
                        
        max_lis_length = 0
        for l in length:
            max_lis_length = max(max_lis_length, l)
        
        if max_lis_length == 0: # Should not happen if n > 0 as min length is 1
             return 0

        total_count_of_max_lis = 0
        for i in range(n):
            if length[i] == max_lis_length:
                total_count_of_max_lis += count[i]
                
        return total_count_of_max_lis
```

**Java 实现:**
```java
import java.util.Arrays;

class Solution {
    public int findNumberOfLIS(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }

        // length[i]: length of LIS ending at nums[i]
        // count[i]: number of LIS ending at nums[i]
        int[] length = new int[n];
        int[] count = new int[n];
        Arrays.fill(length, 1);
        Arrays.fill(count, 1);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) {
                    if (length[j] + 1 > length[i]) {
                        length[i] = length[j] + 1;
                        count[i] = count[j]; // Reset count
                    } else if (length[j] + 1 == length[i]) {
                        count[i] += count[j]; // Add to count
                    }
                }
            }
        }

        int maxLisLength = 0;
        for (int l : length) {
            maxLisLength = Math.max(maxLisLength, l);
        }
        
        if (maxLisLength == 0) { // Should not happen if n > 0
            return 0;
        }

        int totalCountOfMaxLIS = 0;
        for (int i = 0; i < n; i++) {
            if (length[i] == maxLisLength) {
                totalCountOfMaxLIS += count[i];
            }
        }
        return totalCountOfMaxLIS;
    }
}
```

*   时间复杂度: O(N^2)，两层嵌套循环。
*   空间复杂度: O(N)，用于 `length` 和 `count` 数组。

### 194: [253. 会议室 II (Meeting Rooms II)](https://leetcode.cn/problems/meeting-rooms-ii)

**题目描述:**
给你一个会议时间安排的数组 `intervals` ，每个会议时间都会包括开始和结束的时间 `intervals[i] = [start_i, end_i]` ，返回 所需会议室的最小数量 。

**解题思路:**
**1. 排序 + 最小堆 (优先队列):**
* **排序**: 将所有会议按照**开始时间**升序排序。
* **最小堆**: 维护一个最小堆，堆中存储的是当前正在进行的所有会议的**结束时间**。
* **遍历会议**:
    * 对于每个会议 `[start_i, end_i]`：
        *   **检查堆顶**: 查看堆顶的会议结束时间 `min_end_time`。如果 `start_i >= min_end_time`，说明当前会议可以在堆顶会议结束后使用同一个会议室。因此，将堆顶元素弹出 (表示该会议室空出来了)。
        *   **将当前会议加入**: 无论如何，当前会议都需要一个会议室。将其结束时间 `end_i` 加入堆中。
    * **堆的大小**: 遍历过程中，堆的最大大小就是所需要的最小会议室数量。因为堆里存放的是所有当前并发进行的会议的结束时间，其数量代表了某一时刻同时进行的会议数。
* 最终，遍历完所有会议后，堆在整个过程中的最大size即为答案。（Actually, no, the number of rooms required is just `heap.size()` after processing current interval. Maximize this overall values `max_rooms_needed = max(max_rooms_needed, heap.size())`.) Or simpler: The total number of rooms needed is the maximum size the heap ever reaches. The question just asks for the peak number of concurrent meetings. The heap's final size might not be the maximum. We just track its size along the way or return its final size (if interpreted correctly, which means at any point the elements in the heap are currently ongoing meetings). Let's check the most common understanding: `heap.size()` at each step indicates active rooms.

Let's trace with min-heap storing end times:
Intervals: `[,,]` -> Sort by start time -> same.
Rooms needed: 0. Min-heap `H = []`.

1. Meeting `M1=`: `H` is empty. Push `30`. `H =`. `rooms = max(0,1) = 1`.
2. Meeting `M2=`: `start=5`. `H.top()=30`. `5 < 30` (cannot reuse). Push `10`. `H =`. `rooms = max(1,2) = 2`.
3. Meeting `M3=`: `start=15`. `H.top()=10`. `15 >= 10` (can reuse room that ended at 10). Pop `10`. `H =`. Push `20`. `H =`. `rooms = max(2,2) = 2`.

Final rooms = 2. The heap's final size `len(H)` can represent the number of rooms needed IF we do not track max size dynamically. If we do, then `max(rooms_needed_so_far, heap.size())`. Most solutions state heap size during processing reflects needed rooms. At the end of all meetings, the size of heap itself would be how many rooms are still occupied by meetings that haven't finished when last meeting was scheduled, this isn't what we want. We need the maximum number of rooms that were *ever simultaneously occupied*. So track `max_rooms = max(max_rooms, heap.size())` after *each* `heap.push()`.


**2. 扫描线 / 差分数组思想 (Chronological Ordering):**
* 创建一个事件列表。每个会议产生两个事件：`(start_time, +1)` (需要一个房间) 和 `(end_time, -1)` (释放一个房间)。
* 将所有事件按照时间排序。如果时间相同，将 `+1` (开始) 事件排在 `-1` (结束) 事件前面 (这样可以正确处理 `,` 这种情况，一个结束，一个开始，可以复用房间)。
* 遍历排序后的事件：
    *   `current_rooms_needed = 0`
    *   `max_rooms_needed = 0`
    *   For each event `(time, type)`:
        *   `current_rooms_needed += type`
        *   `max_rooms_needed = max(max_rooms_needed, current_rooms_needed)`
*   返回 `max_rooms_needed`。
* 时间复杂度: O(N log N) for sorting events. O(N) for traversal.
* 空间复杂度: O(N) for storing events.

**Python 实现 (最小堆):**
```python
import heapq

class Solution:
    def minMeetingRooms(self, intervals: list[list[int]]) -> int:
        if not intervals:
            return 0
        
        # Sort intervals by start time
        intervals.sort(key=lambda x: x[0])
        
        # Min-heap to store end times of meetings currently in progress
        # The size of the heap at any point indicates the number of rooms being used
        active_meetings_end_times = []
        max_rooms_needed = 0

        for interval in intervals:
            start_time, end_time = interval[0], interval[1]
            
            # Remove meetings from heap that have already ended before current meeting starts
            while active_meetings_end_times and active_meetings_end_times[0] <= start_time:
                heapq.heappop(active_meetings_end_times) # Free up a room
            
            # Add current meeting's end time to the heap
            heapq.heappush(active_meetings_end_times, end_time)
            
            # Update max rooms needed (the current size of heap is rooms in use now)
            max_rooms_needed = max(max_rooms_needed, len(active_meetings_end_times))
            
        return max_rooms_needed
```

**Java 实现 (最小堆):**
```java
import java.util.Arrays;
import java.util.PriorityQueue;
import java.util.Comparator;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals == null || intervals.length == 0) {
            return 0;
        }

        // Sort intervals by start time
        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
        // Or: Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        // Min-heap to store end times of meetings currently in progress
        PriorityQueue<Integer> activeMeetingsEndTimes = new PriorityQueue<>();
        int maxRoomsNeeded = 0;

        for (int[] interval : intervals) {
            int startTime = interval[0];
            int endTime = interval[1];

            // Remove meetings from heap that have already ended
            while (!activeMeetingsEndTimes.isEmpty() && activeMeetingsEndTimes.peek() <= startTime) {
                activeMeetingsEndTimes.poll(); // Free up a room
            }

            // Add current meeting's end time to the heap
            activeMeetingsEndTimes.offer(endTime);

            // Update max rooms needed
            maxRoomsNeeded = Math.max(maxRoomsNeeded, activeMeetingsEndTimes.size());
        }
        return maxRoomsNeeded;
    }
}
```

*   空间复杂度: O(N) or O(K)。堆最多存储 N 个会议的结束时间 (如果所有会议都重叠)。

### 195: [面试题 02.05. 链表求和 (Sum Lists LCCI)](https://leetcode.cn/problems/sum-lists-lcci)

**题目描述:**
给定两个用链表表示的整数，每个节点包含一个数位。
这些数位是反向存放的，也就是个位排在链表首部。
编写函数对这两个整数求和，并用链表形式返回结果。

例如：输入：(7 -> 1 -> 6) + (5 -> 9 -> 2)，即 617 + 295.
输出：2 -> 1 -> 9，即 912.

**进阶：** 假设这些数位是正向存放的，又该如何解决呢？(如 (6 -> 1 -> 7) + (2 -> 9 -> 5) = 9 -> 1 -> 2) - *This problem part only specifies reverse order*. The typical follow-up would be this forward order sum.

**解题思路 (模拟手动加法，反向存储):**
这与第27题“字符串相加”非常类似，但操作对象是链表，并且数字是反向存储的，这更简单，因为我们自然地从个位开始处理。
1.  创建一个哑节点 `dummy` 和一个 `current` 指针，用于构建结果链表。
2.  初始化 `carry = 0`。
3.  使用两个指针 `p1` 指向 `l1`，`p2` 指向 `l2`。
4.  当 `p1 != null` 或 `p2 != null` 或 `carry > 0` 时，循环：
    a.  获取当前节点的值：
    *   `val1 = p1.val` 如果 `p1 != null`，否则为 0。
    *   `val2 = p2.val` 如果 `p2 != null`，否则为 0。
    b.  计算当前位的和：`current_sum = val1 + val2 + carry`。
    c.  当前位的结果是 `digit_to_add = current_sum % 10`。
    d.  新的进位是 `carry = current_sum / 10`。
    e.  创建一个新节点，值为 `digit_to_add`，将其连接到 `current.next`。然后移动 `current`。
    f.  移动指针：`p1 = p1.next` (if `p1 != null`)，`p2 = p2.next` (if `p2 != null`)。
5.  返回 `dummy.next`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy_head = ListNode(0)
        current_node = dummy_head
        carry = 0
        
        p1, p2 = l1, l2
        
        while p1 is not None or p2 is not None or carry != 0:
            val1 = p1.val if p1 else 0
            val2 = p2.val if p2 else 0
            
            current_sum = val1 + val2 + carry
            
            digit = current_sum % 10
            carry = current_sum // 10
            
            current_node.next = ListNode(digit)
            current_node = current_node.next
            
            if p1:
                p1 = p1.next
            if p2:
                p2 = p2.next
                
        return dummy_head.next
```

### 196: [71. 简化路径 (Simplify Path)](https://leetcode.cn/problems/simplify-path)

**题目描述:**
给你一个字符串 `path` ，表示文件系统中的一个文件的绝对路径，请你将其转化为规范路径。
在 Unix 风格的文件系统中，一个点（`.`）表示当前目录本身；此外，两个点 （`..`） 表示将目录切换到上一级（指向父目录）；两者都可以是复杂相对路径的组成部分。任意多个连续斜杠（即，`'//'`）都被视为单个斜杠 `'/'` 。 对于此问题，任何其他格式的点（例如，`'...'`）均被视为文件/目录名称。
规范路径应当满足下述格式：
*   始终以斜杠 `'/'` 开头。
*   两个目录名之间必须只有一个斜杠 `'/'`。
*   最后一个目录名（如果存在）**不能** 以 `'/'` 结尾。
*   如果路径仅包含根目录，则路径为 `'/'` 。

**解题思路 (使用栈):**
1.  **分割路径**: 首先，使用 `'/'` 作为分隔符将路径字符串 `path` 分割成多个部分 (目录名或特殊符号)。
2.  **处理各部分**:
    *   初始化一个栈 (或列表模拟栈) 来存储有效的目录名。
    *   遍历分割后的各个部分 `part`:
        *   如果 `part` 为空 (多个连续斜杠产生) 或 `part == "."` (当前目录)，则忽略。
        *   如果 `part == ".."` (上一级目录):
            *   如果栈不为空，则弹出栈顶元素 (表示返回上一级)。
            *   如果栈为空 (已经在根目录)，则无操作。
        *   如果 `part` 是其他字符串 (有效目录名):
            *   将其压入栈中。
3.  **构建规范路径**:
    *   用 `'/'` 将栈中所有元素连接起来，并在最前面加上一个 `'/'`。
    *   如果栈为空 (结果是根目录 `'/'`)，则直接返回 `'/'`。

**Python 实现:**
```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        # Split the path by '/'
        parts = path.split('/')
        
        stack = []
        
        for part in parts:
            if not part or part == ".":
                # Empty string (from multiple slashes or trailing slash) or current dir
                continue
            elif part == "..":
                # Go up one level
                if stack:
                    stack.pop()
            else:
                # Valid directory name
                stack.append(part)
                
        # Construct the canonical path
        if not stack:
            return "/"
        
        return "/" + "/".join(stack)
```

**题目描述:**
编写一个函数，其功能是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。
不要给另外的数组分配额外的空间，你必须**原地修改输入数组**、使用 O(1) 的额外空间解决这一问题。

**解题思路 (双指针):**
1.  初始化两个指针：`left` 指向数组开头 (索引 0)，`right` 指向数组末尾 (索引 `len(s) - 1`)。
2.  当 `left < right` 时，循环执行：
    a.  交换 `s[left]` 和 `s[right]`。
    b.  `left++`
    c.  `right--`
3.  数组 `s` 即被原地反转。

**Python 实现:**
```python
class Solution:
    def reverseString(self, s: list[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```

**Java 实现:**
```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0;
        int right = s.length - 1;
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++;
            right--;
        }
    }
}
```

*   时间复杂度: O(N)，N/2 次交换。
*   空间复杂度: O(1)。

### 198: [494. 目标和 (Target Sum)](https://leetcode.cn/problems/target-sum)

**题目描述:**
给你一个整数数组 `nums` 和一个整数 `target` 。
向数组中的每个整数前添加 `'+'` 或 `'-'` ，然后串联起所有整数，可以构造一个 **表达式** 。
返回可以通过上述方法构造的、运算结果等于 `target` 的不同 **表达式** 的数目。

**解题思路:**
**1. 回溯 (DFS):**
* 定义 `dfs(index, current_sum)`:
    * `index`: 当前处理到 `nums` 数组的哪个元素。
    * `current_sum`: 到目前为止通过 `+` or `-` 组合得到的和。
* **基准情况**:
    * 如果 `index == len(nums)`:
        * 如果 `current_sum == target`，返回 1 (找到一种方法)。
        * 否则，返回 0。
* **递归步骤**:
    * `count = 0`
    * 考虑将 `nums[index]` 加到 `current_sum`: `count += dfs(index + 1, current_sum + nums[index])`
    * 考虑将 `nums[index]` 从 `current_sum` 减去: `count += dfs(index + 1, current_sum - nums[index])`
    * 返回 `count`。
* 初始调用 `dfs(0, 0)`.
* **记忆化**: 上述 DFS 会有很多重复子问题 (相同的 `index` 和 `current_sum`)。可以使用哈希表 (或二维数组，如果 `current_sum` 范围可控) `memo[index][sum]` 来存储结果。

**2. 转换为 0-1 背包问题:**
* 假设数组 `nums` 的总和为 `total_sum`。
* 设 P 为选择 `+` 号的子集的和，N 为选择 `-` 号的子集的和。
* 我们有 `P - N = target`。
* 并且 `P + N = total_sum`。
* 两式相加：`2 * P = target + total_sum` => `P = (target + total_sum) / 2`。
* 问题转化为：从 `nums` 数组中找到一个子集，其和等于 `P = (target + total_sum) / 2`。
* **约束**:
    * `target + total_sum` 必须是非负偶数 (因为P是整数和，`nums`中的元素非负整数的情况下P也是非负，`total_sum >= 0`)。
    * `P` 必须非负。
* 如果上述约束不满足，则没有解，返回 0。
* **0-1 背包 DP**:
    * `dp[j]` 表示和为 `j` 的子集的个数。
    * 初始化 `dp = 1` (和为0的子集有一个：空集)。
    * 遍历 `nums` 中的每个数 `num`:
        * 从后向前遍历 `dp` 数组 (`j` from `P` down to `num`):
            * `dp[j] += dp[j - num]` (选择 `num` 或不选择 `num`)
    * 最终结果是 `dp[P]`。
    * (注意：题目中的 `nums` 元素可以为0，这会影响组合数，但背包公式依然有效)。

**Python 实现 (0-1 背包转换):**
```python
class Solution:
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        total_sum = sum(nums)

        # Constraints for P = (target + total_sum) / 2
        if (target + total_sum) < 0 or (target + total_sum) % 2 != 0:
            return 0 # P must be a non-negative integer sum of elements
        
        # Target sum for the subset P
        subset_sum_p = (target + total_sum) // 2

        # DP: dp[j] = number of ways to get sum j
        # Initialize dp array for sums from 0 to P
        dp = [0] * (subset_sum_p + 1)
        dp[0] = 1 # There's one way to get sum 0 (empty set)

        for num in nums:
            # Iterate downwards to use dp values from previous iteration (before considering current num)
            for j in range(subset_sum_p, num - 1, -1):
                dp[j] += dp[j - num]
                
        return dp[subset_sum_p]

class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int totalSum = 0;
        for (int num : nums) {
            totalSum += num;
        }

        // Constraints for P = (target + totalSum) / 2
        // (target + totalSum) must be non-negative and even.
        if ((target + totalSum) < 0 || (target + totalSum) % 2 != 0) {
            return 0; 
        }

        int subsetSumP = (target + totalSum) / 2;

        // dp[j] = number of ways to get sum j
        int[] dp = new int[subsetSumP + 1];
        dp[0] = 1; // One way to get sum 0 (empty set)

        for (int num : nums) {
            // Iterate downwards
            for (int j = subsetSumP; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        return dp[subsetSumP];
    }
}

### 199: [670. 最大交换 (Maximum Swap)](https://leetcode.cn/problems/maximum-swap)

**题目描述:**
给定一个非负整数，你 **至多** 可以交换一次数字中的任意两位。返回你能得到的最大整数。

**解题思路 (贪心):**
要使交换后的数字最大，我们应该尝试将一个较大的数字放到更高位（更左边）。
1.  将整数转换为字符数组 (或数字列表)。
2.  从左到右遍历数字 (高位到低位)，对于当前位置 `i`：
    a.  找到从 `i+1` 到末尾的所有数字中，值最大且位置最靠右的那个数字 `max_digit_suffix` 及其索引 `max_idx_suffix`。
    b.  如果 `max_digit_suffix > s[i]` (当前数字 `s[i]` 不是它应该在的最佳位置):
    *   我们就找到了可以进行一次交换来增益的地方。将 `s[i]` 与 `s[max_idx_suffix]` 交换。
    *   交换后，直接返回构造的新数字 (因为我们是从最高位开始找，第一次找到的能增大的交换就是最优的)。
3.  如果遍历完所有位都没有发生交换，说明原数字已经是最大，直接返回原数字。

*   `i = 0` (`s = '2'`). Suffix `['7','3','6']`. `max_digit_suffix = '7'`, `max_idx_suffix = 1`.
    `'7' > '2'`. Swap `s` and `s`. `s` becomes `['7','2','3','6']`. Return "7236".

**Example:** `num = 9973` -> `s = ['9','9','7','3']`
*   `i = 0` (`s = '9'`). Suffix `['9','7','3']`. `max_digit_suffix = '9'`, `max_idx_suffix = 1`.
    `'9'` is not `> '9'`. (If we want strictly larger, use `>`. If allow same, `max_idx_suffix` has to be *strictly after* i. Here `max_idx_suffix=1` means finding largest in `s[i+1:]`).
    This part needs careful thought for max digit. We need to find the largest digit `d_max` in `s[i+1 ... n-1]`.
    If `d_max > s[i]`, we should swap `s[i]` with the *rightmost occurrence* of `d_max` in the suffix to maximize the change at `s[i]` and keep smaller numbers towards the end.

Corrected algorithm:
1.  Convert number to char array `s`.
2.  Iterate `i` from `0` to `n-2`:
    a. Find `max_val_in_suffix = s[i+1]` and `idx_of_max_val = i+1`.
    b. For `j` from `i+2` to `n-1`:
    If `s[j] >= max_val_in_suffix` (note: `>=` to get rightmost):
    `max_val_in_suffix = s[j]`
    `idx_of_max_val = j`
    c. If `max_val_in_suffix > s[i]`:
    Swap `s[i]` and `s[idx_of_max_val]`.
    Return `"".join(s)`.
3. If loop finishes, no swap made value larger, return original number.

Alternative, slightly more robust logic (O(N)):
1. `char[] A = String.valueOf(num).toCharArray();`
2. `int[] last_occurrence = new int;` // `last_occurrence[d]` is the last index of digit `d`
3. For `i` from `0` to `A.length - 1`: `last_occurrence[A[i] - '0'] = i;`
4. For `i` from `0` to `A.length - 1` (current digit to potentially swap out):
   For `d` from `9` down to `(A[i] - '0' + 1)` (larger digits to potentially swap in):
   If `last_occurrence[d] > i`:  // Found a larger digit `d` that is to the right of `i`
   Swap `A[i]` and `A[last_occurrence[d]]`.
   Return `String.valueOf(A)`.
5. Return `String.valueOf(num)` (no swap needed).

**Python 实现 (Using last_occurrence logic):**
```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        s_num = list(str(num)) # Convert to list of chars
        n = len(s_num)
        
        # last_occurrence[digit_val] = index
        last_occurrence = [-1] * 10 
        for i in range(n):
            last_occurrence[int(s_num[i])] = i
            
        for i in range(n): # Current position to potentially swap out s_num[i]
            current_digit = int(s_num[i])
            # Try to find a larger digit 'd' to swap in from its rightmost position
            for d in range(9, current_digit, -1): # d from 9 down to current_digit + 1
                if last_occurrence[d] > i: # If digit d exists to the right of current position i
                    # Swap s_num[i] with s_num[last_occurrence[d]]
                    s_num[i], s_num[last_occurrence[d]] = s_num[last_occurrence[d]], s_num[i]
                    return int("".join(s_num))
                    
        return num # No swap improved the number
```

**Java 实现 (Using last_occurrence logic):**
```java
class Solution {
    public int maximumSwap(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        int n = digits.length;

        // lastOccurrence[digit_val] = index
        int[] lastOccurrence = new int[10];
        for (int i = 0; i < n; i++) {
            lastOccurrence[digits[i] - '0'] = i;
        }

        for (int i = 0; i < n; i++) { // Current position to potentially swap out digits[i]
            int currentDigitVal = digits[i] - '0';
            // Try to find a larger digit 'd' to swap in from its rightmost position
            for (int d = 9; d > currentDigitVal; d--) { // d from 9 down to currentDigitVal + 1
                if (lastOccurrence[d] > i) { // If digit d exists to the right of current position i
                    // Swap digits[i] with digits[lastOccurrence[d]]
                    char temp = digits[i];
                    digits[i] = digits[lastOccurrence[d]];
                    digits[lastOccurrence[d]] = temp;
                    return Integer.parseInt(new String(digits));
                }
            }
        }
        return num; // No swap improved the number
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N), where N is the number of digits in `num`. `last_occurrence` takes O(N). The nested loops: outer O(N), inner O(10) (constant). So, O(N).
*   空间复杂度: O(N) for char array. O(1) for `last_occurrence` array (size 10).

### 200: [279. 完全平方数 (Perfect Squares)](https://leetcode.cn/problems/perfect-squares)

**题目描述:**
给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。
**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**解题思路:**
**1. 动态规划:**
* `dp[i]` 表示和为 `i` 的最少完全平方数的数量。
* **目标**: `dp[n]`。
* **初始化**: `dp = 0` (和为0不需要数)。`dp[i] = infinity` for `i > 0`.
* **状态转移**:
    * `dp[i] = min(dp[i - j*j] + 1)` for all `j*j <= i`.
    * This means to get `i`, we can take any perfect square `j*j`, and add it to a sum that forms `i - j*j`. We want the minimum count.
    * Iterate `i` from `1` to `n`.
    * For each `i`, iterate `j` from `1` such that `j*j <= i`.
        * `dp[i] = min(dp[i], dp[i - j*j] + 1)`.

**2. BFS (广度优先搜索):**
*  将问题看作图搜索。节点是数字 (从0到n)。边是从 `x` 到 `x + square` (如果 `x + square <= n`)。我们想找到从 `0` 到 `n` 的最短路径，路径长度就是平方数的个数。
*  Queue stores `(number, steps)` or just `number`, and level itself represents steps.
*  Level 0: `0` (0 steps)
*  Level 1: `1, 4, 9, ...` (1 step) from `0 + square`
*  Level 2: `x + square` where `x` is from Level 1.
*  Use a `visited` set to avoid re-processing numbers. The first time we reach `n`, it's via the minimum number of steps.

**Python 实现 (Dynamic Programming):**
```python
import math

class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] will store the minimum number of perfect squares that sum up to i
        dp = [float('inf')] * (n + 1)
        dp[0] = 0 # Base case: 0 needs 0 perfect squares

        # Pre-calculate perfect squares up to n
        # Not strictly necessary, can calculate inside loop
        
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                square = j * j
                dp[i] = min(dp[i], dp[i - square] + 1)
                j += 1
        
        return dp[n]

**Java 实现 (Dynamic Programming):**
```java
import java.util.Arrays;

class Solution {
    public int numSquares(int n) {
        // dp[i] stores the minimum number of perfect squares summing to i
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE); // Initialize with a large value
        dp[0] = 0; // Base case: 0 needs 0 perfect squares

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                int square = j * j;
                if (dp[i - square] != Integer.MAX_VALUE) { // Check if i-square is reachable
                    dp[i] = Math.min(dp[i], dp[i - square] + 1);
                }
            }
        }
        return dp[n];
    }
}
```
**Lagrange's Four-Square Theorem**: Any natural number can be represented as the sum of four integer squares. So the answer is at most 4. This theorem can be used to optimize further (e.g. if Legendre's three-square theorem conditions aren't met, then 4). Check if it's 1 (n is perfect square), then 2 (n = a^2+b^2), then 3 (by Legendre's). If none, then 4. This is a number theory approach, usually DP or BFS is expected in interviews unless specified.

**复杂度分析 (Dynamic Programming):**
*   时间复杂度: O(N * sqrt(N)). Outer loop N times, inner loop sqrt(N) times.
*   空间复杂度: O(N) for DP array.

**复杂度分析 (BFS):**
*   时间复杂度: O(N * sqrt(N)) in worst case as it explores states similar to DP. Number of nodes is N, each node may have up to sqrt(N) edges.
*   空间复杂度: O(N) for queue and visited set.
