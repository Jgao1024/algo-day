### 101: [283. 移动零 (Move Zeroes)](https://leetcode.cn/problems/move-zeroes)

**题目描述:**
给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。
**注意**：必须在不复制数组的情况下原地对数组进行操作。

**解题思路 (双指针):**
1.  使用一个 `insert_pos` 指针（或称 `slow` 指针），表示下一个非零元素应该被放置的位置。初始 `insert_pos = 0`。
2.  遍历数组 (使用 `fast` 指针，或者直接用循环索引 `i`):
    a.  如果 `nums[i]` 不为零：
    i.  将 `nums[i]` 放到 `nums[insert_pos]`。
    ii. 如果 `i != insert_pos` (即当前非零元素不在它最终应该在的位置)，则可以将 `nums[i]`（原位置）设为 0。但更简洁的方法是，先用非零元素填满前面部分，然后将 `insert_pos` 之后的所有位置填充为 0。
    iii. `insert_pos++`。
3.  **第二种填充方式 (更推荐)**:
    a.  如果 `nums[i]` 不为零，将其与 `nums[insert_pos]` 交换 (如果 `i != insert_pos`) 或者直接 `nums[insert_pos] = nums[i]`.
    b. `insert_pos++`.
    c.  完成上述遍历后，`insert_pos` 指向第一个零应该开始的位置。从 `insert_pos` 到数组末尾的所有元素填充为 0 (这一步只有在第一种 `nums[insert_pos] = nums[i]` 赋值方式时才需要单独做，如果采用交换方式，则不需要这个后缀填充步骤)。

**推荐的单遍扫描双指针（`snowball` 或 `write_ptr`）:**
1.  `write_ptr = 0`。
2.  遍历数组 `nums` with `read_ptr` from `0` to `n-1`:
    a.  If `nums[read_ptr] != 0`:
    i.  `nums[write_ptr] = nums[read_ptr]`.
    ii. `write_ptr++`.
3.  After the loop, all non-zero elements are in `nums[0...write_ptr-1]`.
4.  Fill `nums[write_ptr...n-1]` with zeros.

**Python 实现:**
```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        write_ptr = 0 # Points to the position where the next non-zero element should be placed
        
        # First pass: move all non-zero elements to the front
        for read_ptr in range(len(nums)):
            if nums[read_ptr] != 0:
                nums[write_ptr] = nums[read_ptr]
                write_ptr += 1
        
        # Second pass: fill the remaining part of the array with zeros
        for i in range(write_ptr, len(nums)):
            nums[i] = 0
```

### 102: [739. 每日温度 (Daily Temperatures)](https://leetcode.cn/problems/daily-temperatures)

**题目描述:**
给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

**解题思路 (单调递减栈):**
1.  初始化一个结果数组 `answer`，所有元素为 0。
2.  初始化一个空栈 `stack`，用于存储之前日期的**索引**，这些日期对应的温度是单调递减的。
3.  遍历 `temperatures` 数组，对于每个日期 `i` 和其温度 `temp = temperatures[i]`:
    a.  **当栈不为空且 `temp > temperatures[stack.top()]`** (当前温度比栈顶索引对应的温度高)：
    i.  说明找到了栈顶日期的一个“下一个更高温度日”。
    ii. 弹出栈顶索引 `prev_day_index = stack.pop()`。
    iii.计算天数差：`answer[prev_day_index] = i - prev_day_index`。
    iv. 继续检查新的栈顶 (因为当前温度可能也比新的栈顶温度高)。
    b.  **处理完所有比当前温度低的栈顶元素后**，将当前日期的索引 `i` 压入栈。
4.  返回 `answer`。

**Python 实现:**
```python
class Solution:
    def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
        n = len(temperatures)
        answer = [0] * n
        stack = [] # Stores indices of days with decreasing temperatures

        for i, temp in enumerate(temperatures):
            # While stack is not empty and current temperature is warmer than stack top's temperature
            while stack and temp > temperatures[stack[-1]]:
                prev_day_index = stack.pop()
                answer[prev_day_index] = i - prev_day_index
            stack.append(i) # Push current day's index
            
        return answer
```

**Java 实现:**
```java
import java.util.Stack;

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n]; // Initialized to 0 by default
        Stack<Integer> stack = new Stack<>(); // Stores indices

        for (int i = 0; i < n; i++) {
            int currentTemp = temperatures[i];
            // While stack is not empty and current temperature is warmer than stack top's temperature
            while (!stack.isEmpty() && currentTemp > temperatures[stack.peek()]) {
                int prevDayIndex = stack.pop();
                answer[prevDayIndex] = i - prevDayIndex;
            }
            stack.push(i); // Push current day's index
        }
        return answer;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是 `temperatures` 的长度。虽然有嵌套 `while` 循环，但每个索引最多被压入栈和弹出栈一次。
*   空间复杂度: O(N)，在最坏情况下（例如，温度持续下降），栈中可能存储所有 N 个索引。

### 103: [224. 基本计算器 (Basic Calculator)](https://leetcode.cn/problems/basic-calculator)

**题目描述:**
给你一个字符串表达式 `s` ，请你实现一个基本计算器来计算并返回它的值。
注意:不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()`。
表达式中可能包含 `(`，`)`，`+`，`-`，非负整数和空格。

**解题思路 (栈模拟):**
1.  初始化 `result = 0` (当前括号层级的累积结果)，`sign = 1` (当前数字的符号，+1 或 -1)，`number = 0` (当前解析的数字)。
2.  使用一个栈 `stack` 来处理括号。当遇到 `(` 时，将之前的 `result` 和 `sign` 压入栈，然后重置 `result` 和 `sign` 以计算括号内的表达式。当遇到 `)` 时，计算完括号内的 `result` 后，与栈顶的 `sign` 和 `result` 合并。
3.  遍历字符串 `s` 中的每个字符 `char`:
    a.  如果 `char` 是数字：更新 `number = number * 10 + int(char)`。
    b.  如果 `char` 是 `'+'` 或 `'-'`：
    i.  将 `number` 乘以 `sign` 后加到 `result`: `result += sign * number`。
    ii. 重置 `number = 0`。
    iii.更新 `sign`: 如果 `char == '+'`, `sign = 1`; 如果 `char == '-'`, `sign = -1`。
    c.  如果 `char` 是 `'('`：
    i.  将当前的 `result` 和 `sign` 压入栈。
    ii. 重置 `result = 0` 和 `sign = 1` (为括号内的计算做准备)。
    d.  如果 `char` 是 `')'`：
    i.  将当前 `number` 计算进当前括号层级的 `result`: `result += sign * number`。
    ii. 重置 `number = 0`。
    iii.从栈中弹出之前的符号 `prev_sign = stack.pop()`。
    iv. 从栈中弹出之前的累积结果 `prev_result = stack.pop()`。
    v.  合并：`result = prev_result + prev_sign * result`。
4.  遍历结束后，如果还有未处理的 `number`，将其加入 `result` ( `result += sign * number`)。
5.  返回 `result`。

**Python 实现:**
```python
class Solution:
    def calculate(self, s: str) -> int:
        stack = []  # To store (result_so_far, sign_before_parenthesis)
        result = 0
        number = 0
        sign = 1  # 1 for positive, -1 for negative

        for char in s:
            if char.isdigit():
                number = number * 10 + int(char)
            elif char == '+':
                result += sign * number
                number = 0
                sign = 1
            elif char == '-':
                result += sign * number
                number = 0
                sign = -1
            elif char == '(':
                # Push current result and sign onto stack
                stack.append(result)
                stack.append(sign)
                # Reset for the expression inside parenthesis
                result = 0
                sign = 1
                # number is already 0 or will be reset by next '+' or '-'
            elif char == ')':
                result += sign * number # Calculate for the last number in parenthesis
                number = 0
                
                # Pop sign before this parenthesis
                prev_sign = stack.pop()
                # Pop result accumulated before this parenthesis
                prev_result = stack.pop()
                
                result = prev_result + prev_sign * result
            # Ignore spaces
        
        # Add the last number if any
        result += sign * number
        return result
```

**Java 实现:**
```java
import java.util.Stack;

class Solution {
    public int calculate(String s) {
        Stack<Integer> stack = new Stack<>(); // Stores results and signs for parentheses
        int result = 0;
        int number = 0;
        int sign = 1; // 1 for positive, -1 for negative

        for (int i = 0; i < s.length(); i++) {
            char currentChar = s.charAt(i);

            if (Character.isDigit(currentChar)) {
                number = number * 10 + (currentChar - '0');
            } else if (currentChar == '+') {
                result += sign * number;
                number = 0;
                sign = 1;
            } else if (currentChar == '-') {
                result += sign * number;
                number = 0;
                sign = -1;
            } else if (currentChar == '(') {
                // Push current result and sign onto stack
                stack.push(result);
                stack.push(sign);
                // Reset for the expression inside parenthesis
                result = 0;
                sign = 1;
                // number will be reset or is 0
            } else if (currentChar == ')') {
                result += sign * number; // Calculate for the last number in parenthesis
                number = 0;
                
                // result is now the value of the expression inside the parenthesis
                // Pop sign before this parenthesis
                int prevSign = stack.pop();
                // Pop result accumulated before this parenthesis
                int prevResult = stack.pop();
                
                result = prevResult + prevSign * result;
            }
            // Ignore spaces
        }
        
        // Add the last number if any
        if (number != 0) {
            result += sign * number;
        }
        return result;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是字符串 `s` 的长度。每个字符只被处理一次。
*   空间复杂度: O(N)，在最坏情况下 (例如，深层嵌套的括号 `((((...))))`)，栈的大小可能达到 N。

### 104: [138. 复制带随机指针的链表 (Copy List with Random Pointer)](https://leetcode.cn/problems/copy-list-with-random-pointer)

**题目描述:**
给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random` ，该指针可以指向链表中的任何节点或 `null`。
构造这个链表的 **深拷贝**。深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点** 。

**解题思路 (哈希表映射):**
1.  **第一遍遍历 (复制节点和next指针, 建立映射):**
    *   创建一个哈希表 `map`，用于存储 `original_node -> copied_node` 的映射。
    *   遍历原链表，对于每个节点 `curr_original`:
        a.  创建一个新节点 `copied_node`，其值为 `curr_original.val`。
        b.  将映射 `(curr_original, copied_node)` 存入 `map`。
        c.  将前一个复制的节点 (如果存在) 的 `next` 指向当前 `copied_node`。
2.  **第二遍遍历 (设置random指针):**
    *   再次遍历原链表，对于每个节点 `curr_original`:
        a.  获取其对应的复制节点 `copied_node = map.get(curr_original)`。
        b.  获取原节点的随机指针 `original_random_node = curr_original.random`。
        c.  如果 `original_random_node` 不为 `null`，则其对应的复制节点是 `map.get(original_random_node)`。
        d.  设置 `copied_node.random = map.get(original_random_node)` (如果 `original_random_node` 非空)。
3.  返回复制链表的头节点 (即 `map.get(head_original)`)。

```python
        self.next = next

class Solution:
```

### 105: [468. 验证IP地址 (Validate IP Address)](https://leetcode.cn/problems/validate-ip-address)

**题目描述:**
给定一个字符串 `queryIP`。如果是有效的 IPv4 地址，返回 `"IPv4"` ；如果是有效的 IPv6 地址，返回 `"IPv6"` ；如果不是上述类型的 IP 地址，返回 `"Neither"` 。

**IPv4 规则:**
`x1.x2.x3.x4`
1.  `0 <= xi <= 255`
2.  `xi` 不能有前导零，除非 `xi` 本身是 "0"。

**IPv6 规则:**
`x1:x2:x3:x4:x5:x6:x7:x8`
1.  每段 `xi` 是 1 到 4 个十六进制字符。
2.  十六进制字符包括 `0-9`, `a-f`, `A-F`。
3.  允许前导零 (e.g. "0012" is valid).

**解题思路:**
1.  **尝试按 '.' 分割**。如果能分割成 4 段，则可能是 IPv4。
2.  **尝试按 ':' 分割**。如果能分割成 8 段，则可能是 IPv6。
3.  如果以上都不满足，返回 "Neither"。

**IPv4 验证 `validateIPv4(String ip)`:**
a. 按 `.` 分割字符串成 `segments`。
b. 如果 `segments.length != 4`，返回 "Neither"。
c. 遍历 `segments` 中的每一段 `s`:
i.  检查长度是否为 0 或大于 3 (`1 <= len(s) <= 3`)。
ii. 检查是否有非数字字符。
iii.检查是否有前导零 (如果 `len(s) > 1` 且 `s.charAt(0) == '0'`, 则无效)。
iv. 将 `s` 转换为整数 `val`，检查 `0 <= val <= 255`。
v.  如果任一检查失败，返回 "Neither"。
d. 如果所有段都有效，返回 "IPv4"。

**IPv6 验证 `validateIPv6(String ip)`:**
a. 按 `:` 分割字符串成 `segments`。
b. 如果 `segments.length != 8`，返回 "Neither"。
c. 遍历 `segments` 中的每一段 `s`:
i.  检查长度是否为 0 或大于 4 (`1 <= len(s) <= 4`)。
ii. 检查每个字符是否是有效的十六进制字符 (`0-9`, `a-f`, `A-F`)。
iii.如果任一检查失败，返回 "Neither"。
d. 如果所有段都有效，返回 "IPv6"。

**主函数 `validIPAddress(String queryIP)`:**
1. 如果 `queryIP` 包含 `.`，调用 `validateIPv4(queryIP)`。
2. 否则如果 `queryIP` 包含 `:`，调用 `validateIPv6(queryIP)`。
3. 否则返回 "Neither"。

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        
        def is_ipv4(s):
            parts = s.split('.')
            if len(parts) != 4:
                return False
            for part in parts:
                if not part.isdigit(): # Must be all digits
                    return False
                if len(part) == 0 or len(part) > 3: # Length check
                    return False
                if len(part) > 1 and part[0] == '0': # Leading zero check
                    return False
                if not (0 <= int(part) <= 255): # Range check
                    return False
            return True

        def is_ipv6(s):
            parts = s.split(':')
            if len(parts) != 8:
                return False
            hex_chars = "0123456789abcdefABCDEF"
            for part in parts:
                if not (1 <= len(part) <= 4): # Length check
                    return False
                for char in part:
                    if char not in hex_chars: # Hex char check
                        return False
            return True

        if '.' in queryIP and ':' in queryIP: # Cannot contain both
             return "Neither"
        if '.' in queryIP:
            # Ensure split correctly handles cases like "1.1.1.1." -> ends with dot
            if queryIP.count('.') != 3 : return "Neither" # More robust split check
            if is_ipv4(queryIP):
                return "IPv4"
        elif ':' in queryIP:
            if queryIP.count(':') != 7: return "Neither"
            if is_ipv6(queryIP):
                return "IPv6"
        
        return "Neither"
```

```java
        if (queryIP.indexOf('.') >= 0) { // Potential IPv4
             // Ensure correct number of parts for split. split(delimiter, limit) if limit is -1, no trailing empty string removed.
            if (countChars(queryIP, '.') != 3) return "Neither";
            String[] parts = queryIP.split("\\.", -1); // Use -1 to ensure all parts are kept, even if trailing
            if (parts.length != 4) {
                return "Neither";
            }
            for (String part : parts) {
                if (part.isEmpty() || part.length() > 3) return "Neither";
                if (part.length() > 1 && part.charAt(0) == '0') return "Neither"; // Leading zero
                for (char ch : part.toCharArray()) {
                    if (!Character.isDigit(ch)) return "Neither";
                }
                try {
                    int val = Integer.parseInt(part);
                    if (val < 0 || val > 255) return "Neither";
                } catch (NumberFormatException e) {
                    return "Neither"; // Should have been caught by isDigit, but good practice
                }
            }
            return "IPv4";
        } else if (queryIP.indexOf(':') >= 0) { // Potential IPv6
            if (countChars(queryIP, ':') != 7) return "Neither";
            String[] parts = queryIP.split(":", -1);
            if (parts.length != 8) {
                return "Neither";
            }
            String hexChars = "0123456789abcdefABCDEF";
            for (String part : parts) {
                if (part.isEmpty() || part.length() > 4) return "Neither";
                for (char ch : part.toCharArray()) {
                    if (hexChars.indexOf(ch) == -1) return "Neither";
                }
            }
            return "IPv6";
        }
        
        return "Neither";
    }

    private int countChars(String s, char c) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == c) {
                count++;
            }
        }
        return count;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(L)，其中 L 是 `queryIP` 的长度。分割字符串和遍历各段都是线性的。
*   空间复杂度: O(L)，用于存储分割后的字符串片段。

### 106: [460. LFU缓存 (LFU Cache)](https://leetcode.cn/problems/lfu-cache)

**题目描述:**
请你为 最不经常使用（LFU）缓存算法设计并实现数据结构。
实现 `LFUCache` 类：
*   `LFUCache(int capacity)` 初始化对象。
*   `int get(int key)` 如果键 `key` 存在于缓存中，则获取键的值，否则返回 -1。
*   `void put(int key, int value)` 如果键 `key` 已存在，则变更其值；如果键不存在，请插入键值对。当缓存达到其容量 `capacity` 时，则应该在插入新项之前，移除最不经常使用的项。在此问题中，当存在平局（即两个或更多个键具有相同使用频率）时，应该去除 **最近最久未使用** 的键。
    对一个键 कार्यकारिणी `get` 和 `put` 操作都包含一种 **使用** 操作。
    `get` 和 `put` 函数的时间复杂度都应该是 `O(1)` (平均)。

**解题思路 (双哈希表 + 双向链表):**
这是 LFU 缓存的一种经典实现。
1.  `Node` 结构: 存储 `key, value, freq, prev, next`。
2.  `keyToNodeMap (HashMap<Integer, Node>)`: 存储 `key` 到其对应 `Node` 的映射。
3.  `freqToDllMap (HashMap<Integer, DoublyLinkedList>)`: 存储频率 `freq` 到一个双向链表的映射。该双向链表 (DLL) 中存储了所有使用频率为 `freq` 的节点，并且链表本身按 LRU 顺序维护 (表头是最近使用的，表尾是最近最久使用的)。
4.  `minFreq (int)`: 记录当前缓存中最小的使用频率。
5.  `capacity (int)` 和 `size (int)`。

**`DoublyLinkedList` (DLL) 内部类:**
*   `head` 和 `tail` 伪节点。
*   `addNodeToHead(Node node)`: 将节点添加到头部 (表示最近使用)。
*   `removeNode(Node node)`: 从链表中移除节点。
*   `removeTailNode()`: 移除尾部节点 (LFU+LRU 平局时的牺牲者)。
*   `isEmpty()`: 判断链表是否为空。

**`get(key)` 操作:**
1. 如果 `key` 不在 `keyToNodeMap` 中，返回 -1。
2. 获取 `node`。
3. 调用 `incrementFrequency(node)`。
4. 返回 `node.value`。

**`put(key, value)` 操作:**
1. 如果 `capacity == 0`，直接返回。
2. 如果 `key` 已存在于 `keyToNodeMap`:
   a.  获取 `node`，更新 `node.value = value`。
   b.  调用 `incrementFrequency(node)`。
3. 如果 `key` 不存在:
   a.  如果 `size == capacity`:
   i.  获取 `minFreq` 对应的 DLL (`freqToDllMap.get(minFreq)`)。
   ii. 从该 DLL 中移除尾部节点 (最不常用且最久未用的) `evictedNode`。
   iii.从 `keyToNodeMap` 中移除 `evictedNode.key`。
   iv. `size--`。
   b.  创建新节点 `newNode` (`key, value, freq=1`)。
   c.  将其加入 `keyToNodeMap`。
   d.  将其加入频率为 1 的 DLL (`freqToDllMap.computeIfAbsent(1, k -> new DoublyLinkedList()).addNodeToHead(newNode)`)。
   e.  设置 `minFreq = 1`。
   f.  `size++`。

**`incrementFrequency(node)` 辅助函数:**
1. 获取 `node` 的当前频率 `oldFreq = node.freq`。
2. 从 `freqToDllMap.get(oldFreq)` 中移除 `node`。
3. 如果移除后，`oldFreq` 对应的 DLL 为空，且 `oldFreq == minFreq`，则 `minFreq++` (或更准确地说，如果DLL为空就从`freqToDllMap`中移除，且如果`oldFreq == minFreq`，`minFreq`变为`node.freq+1`)。
4. 增加 `node.freq++`。
5. 将 `node` 加入新的频率 `newFreq = node.freq` 对应的 DLL (`freqToDllMap.computeIfAbsent(newFreq, k -> new DoublyLinkedList()).addNodeToHead(node)`).
6. 如果 `oldFreq` 的 DLL 为空并且 `minFreq` 等于 `oldFreq`，则将 `minFreq` 更新为 `node.freq`。 (Correct handling for minFreq: if the list for `minFreq` becomes empty and `oldFreq == minFreq`, then `minFreq` becomes `node.freq`. If `node.freq` was `oldFreq+1`, and `freqToDllMap` didn't have an entry for `node.freq` previously, this new list becomes the `minFreq` if `minFreq` had no other smaller non-empty frequency lists.) Generally, if the DLL at `minFreq` becomes empty due to node removal, `minFreq` updates to `node.freq`. If `node.freq` becomes 1 (on new insert), then `minFreq` is 1.

**Python 实现:**
```python
import collections

class DLinkedNode:
    def __init__(self, key=0, value=0, freq=0):
        self.key = key
        self.value = value
        self.freq = freq
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        self.head = DLinkedNode() # Dummy head
        self.tail = DLinkedNode() # Dummy tail
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node
        self.size += 1

    def remove_node(self, node):
        if self.size == 0: return # Or raise error
        node.prev.next = node.next
        node.next.prev = node.prev
        self.size -= 1
        # Optional: Nullify node's pointers if it's fully removed from structure
        # node.prev = None
        # node.next = None


    def remove_tail(self):
        if self.size == 0: return None # Or raise error
        tail_node = self.tail.prev
        self.remove_node(tail_node)
        return tail_node
    
    def is_empty(self):
        return self.size == 0


class LFUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.size = 0
        self.key_to_node = {}  # key -> Node
        self.freq_to_dll = collections.defaultdict(DoublyLinkedList) # freq -> DLL of Nodes
        self.min_freq = 0


    def _update_node_freq(self, node: DLinkedNode):
        old_freq = node.freq
        self.freq_to_dll[old_freq].remove_node(node)

        if self.freq_to_dll[old_freq].is_empty():
            del self.freq_to_dll[old_freq]
            if self.min_freq == old_freq:
                self.min_freq += 1 # This might need careful adjustment if self.min_freq was not this old_freq
                                   # Actually, if this list becomes empty and it was the min_freq list,
                                   # min_freq must be updated to the next smallest frequency.
                                   # Here, we just increment. If we're promoting, the new freq is old_freq + 1.

        node.freq += 1
        new_freq = node.freq
        self.freq_to_dll[new_freq].add_to_head(node)
        # If we promoted the ONLY item from min_freq list, then min_freq should be new_freq.
        # Or, if we deleted old_freq and it was min_freq, and now node.freq list exists,
        # min_freq could be node.freq IF it is the new minimum. Simpler: min_freq can remain, or become 1 for new nodes.
        # When old_freq list becomes empty and it was min_freq, the new min_freq becomes node.freq if it's indeed the minimum.
        # The general way is if old_freq_dll is empty and old_freq was min_freq, min_freq = node.freq
        # But if there are OTHER nodes at old_freq, min_freq doesn't change necessarily.
        # Let's re-evaluate min_freq update logic: min_freq must be lowest freq with items.
        # After removing from old_freq list, if old_freq_dll becomes empty and old_freq == self.min_freq,
        # then self.min_freq becomes new_freq (which is old_freq + 1). This covers one case.

    def get(self, key: int) -> int:
        if key not in self.key_to_node:
            return -1
        
        node = self.key_to_node[key]
        self._update_node_freq(node) # Moves node to higher freq DLL, and to its head
        return node.value

    def put(self, key: int, value: int) -> None:
        if self.capacity == 0:
            return

        if key in self.key_to_node:
            node = self.key_to_node[key]
            node.value = value
            self._update_node_freq(node)
        else:
            if self.size == self.capacity:
                min_freq_dll = self.freq_to_dll[self.min_freq]
                node_to_evict = min_freq_dll.remove_tail()
                del self.key_to_node[node_to_evict.key]
                self.size -= 1
                # if min_freq_dll.is_empty() after removal and min_freq_dll was from self.freq_to_dll:
                # (it will be empty here only if it had 1 element)
                # we don't need to del self.freq_to_dll[self.min_freq] here if _update handles it
                # self.min_freq logic gets tricky here. The simplest for min_freq is:
                # After eviction, if the self.freq_to_dll[self.min_freq] became empty, we don't touch min_freq.
                # It's fine because new element will have freq 1 making min_freq=1.

            new_node = DLinkedNode(key, value, 1) # New nodes have freq 1
            self.key_to_node[key] = new_node
            self.freq_to_dll[1].add_to_head(new_node)
            self.min_freq = 1 # Newest element always has freq 1, making it potentially the new min_freq
            self.size += 1

```

**Java 实现:**
```java
import java.util.HashMap;
import java.util.Map;

// Node for DLL
class Node {
    int key, value, freq;
    Node prev, next;

    public Node(int key, int value) {
        this.key = key;
        this.value = value;
        this.freq = 1; // New nodes start with frequency 1
    }
}

// DoublyLinkedList to store nodes with the same frequency
class DoublyLinkedList {
    Node head, tail; // Dummy head and tail
    int size;

    public DoublyLinkedList() {
        head = new Node(-1, -1); // Dummy value
        tail = new Node(-1, -1);
        head.next = tail;
        tail.prev = head;
        size = 0;
    }

    // Add node right after head (MRU position for this frequency)
    public void addNode(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
        size++;
    }

    // Remove a given node
    public void removeNode(Node node) {
        if (size == 0) return;
        node.prev.next = node.next;
        node.next.prev = node.prev;
        size--;
    }

    // Remove node right before tail (LRU node for this frequency)
    public Node removeTail() {
        if (size == 0) return null;
        Node nodeToRemove = tail.prev;
        removeNode(nodeToRemove);
        return nodeToRemove;
    }
    
    public boolean isEmpty() {
        return size == 0;
    }
}


class LFUCache {
    private Map<Integer, Node> keyToNodeMap;          // key -> Node
    private Map<Integer, DoublyLinkedList> freqToDllMap; // freq -> DLL of Nodes
    private int capacity;
    private int size;
    private int minFreq; // Tracks the minimum frequency currently in the cache

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.size = 0;
        this.minFreq = 0; // Or 1, if capacity > 0; 0 is fine initially.
        this.keyToNodeMap = new HashMap<>();
        this.freqToDllMap = new HashMap<>();
    }
    
    // Helper to update node's frequency and move it accordingly
    private void updateNodeFrequency(Node node) {
        int oldFreq = node.freq;
        DoublyLinkedList oldList = freqToDllMap.get(oldFreq);
        oldList.removeNode(node);

        if (oldList.isEmpty()) {
            freqToDllMap.remove(oldFreq);
            if (oldFreq == this.minFreq) {
                this.minFreq++; // Or minFreq = node.freq + 1 after incrementing node.freq
            }
        }

        node.freq++;
        DoublyLinkedList newList = freqToDllMap.computeIfAbsent(node.freq, k -> new DoublyLinkedList());
        newList.addNode(node); // Add to head (MRU) of new frequency list
    }

    public int get(int key) {
        if (!keyToNodeMap.containsKey(key)) {
            return -1;
        }
        Node node = keyToNodeMap.get(key);
        updateNodeFrequency(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        if (capacity == 0) return;

        if (keyToNodeMap.containsKey(key)) {
            Node node = keyToNodeMap.get(key);
            node.value = value;
            updateNodeFrequency(node);
        } else {
            if (size == capacity) {
                DoublyLinkedList minFreqList = freqToDllMap.get(this.minFreq);
                Node nodeToEvict = minFreqList.removeTail(); // LRU node from minFreq list
                keyToNodeMap.remove(nodeToEvict.key);
                size--;
                if (minFreqList.isEmpty()) { // If this list became empty
                    freqToDllMap.remove(this.minFreq);
                    // minFreq might need update if all items of this freq are gone,
                    // but usually the newly added item with freq 1 resets minFreq or an update increments it.
                    // No need to explicitly update minFreq here, next new node will set it to 1 or an existing access will handle.
                }
            }
            
            Node newNode = new Node(key, value); // Default freq is 1
            keyToNodeMap.put(key, newNode);
            DoublyLinkedList newList = freqToDllMap.computeIfAbsent(1, k -> new DoublyLinkedList());
            newList.addNode(newNode);
            this.minFreq = 1; // New node's frequency is 1, which is the new min frequency
            size++;
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: `get` 和 `put` 都是 O(1) 平均时间复杂度。哈希表操作是 O(1) 平均，DLL 操作是 O(1)。
*   空间复杂度: O(Capacity)，因为我们存储 `capacity` 数量的节点信息在 `keyToNodeMap` 和 `freqToDllMap` 中。

### 107: [153. 寻找旋转排序数组中的最小值 (Find Minimum in Rotated Sorted Array)](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array)

**题目描述:**
已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums =` 在变化后可能得到：
*   若旋转 `4` 次，则可以得到 ``
*   若旋转 `7` 次，则可以得到 ``
    给你一个元素值 **互不相同** 的数组 `nums` ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素** 。
    你必须设计一个时间复杂度为 O(log n) 的算法来解决此问题。

**解题思路 (二分查找):**
1.  如果数组未旋转 (即 `nums[left] < nums[right]`) 或者只有一个元素，则最小元素是 `nums[left]`。
2.  初始化 `left = 0`, `right = nums.length - 1`。
3.  当 `left < right` 时循环：
    a.  计算中间点 `mid = left + (right - left) / 2`。
    b.  **比较 `nums[mid]` 和 `nums[right]`**:
    i.  如果 `nums[mid] < nums[right]`：说明 `mid` 到 `right` 这一段是升序的，并且 `mid` 可能是最小值，或者最小值在 `mid` 的左边。所以，将搜索范围缩小到左半部分（包括 `mid`）：`right = mid`。
    ii. 如果 `nums[mid] > nums[right]`：说明最小值在 `mid` 的右边 (旋转点在 `mid` 和 `right` 之间)。所以，将搜索范围缩小到右半部分（不包括 `mid`，因为 `mid` 肯定不是最小的）：`left = mid + 1`。
4.  循环结束后，`left` (或 `right`) 指向的就是最小元素。返回 `nums[left]`。

**Python 实现:**
```python
class Solution:
    def findMin(self, nums: list[int]) -> int:
        left, right = 0, len(nums) - 1
        
        # If the array is not rotated (or rotated n times),
        # the first element is the minimum.
        # This also handles the case of a single element array.
        if nums[left] <= nums[right]: # Handles sorted or single element
            return nums[left]
            
        while left < right:
            mid = left + (right - left) // 2
            
            # If nums[mid] > nums[mid+1], then mid+1 is the smallest. This check useful for 154 with duplicates
            # if mid + 1 < len(nums) and nums[mid] > nums[mid+1]: 
            #     return nums[mid+1]
            # If nums[mid-1] > nums[mid], then mid is the smallest. This check is more direct for finding minimum value
            # if mid > 0 and nums[mid-1] > nums[mid]:
            #     return nums[mid]

            if nums[mid] > nums[right]:
                # Minimum is in the right part (mid+1 to right)
                left = mid + 1
            else: # nums[mid] <= nums[right]
                # Minimum is in the left part (left to mid), or mid itself
                right = mid
        
        # After the loop, left == right and points to the minimum element
        return nums[left]
```

### 108: [207. 课程表 (Course Schedule)](https://leetcode.cn/problems/course-schedule)

**题目描述:**
你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。
在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi` 。
例如，先修课程对 `` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。
请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。

**解题思路 (拓扑排序 / Kahn's Algorithm - BFS based):**
1.  **构建图和入度数组**:
    *   `adjList`: 一个邻接表，`adjList[i]` 存储课程 `i` 的所有后续课程。
    *   `inDegree`: 一个数组，`inDegree[i]` 存储课程 `i` 的入度 (即先修课程数量)。
    *   遍历 `prerequisites`: 对于每个 `[ai, bi]` (要学 `ai` 先学 `bi`):
        *   `adjList[bi].add(ai)` ( `bi` 指向 `ai`)
        *   `inDegree[ai]++`
2.  **初始化队列**:
    *   创建一个队列 `queue`。
    *   将所有入度为 0 的课程加入队列。这些是可以立即开始学习的课程。
3.  **BFS 拓扑排序**:
    *   初始化 `courses_taken_count = 0`。
    *   当队列不为空时：
        a.  从队列中取出一个课程 `course`。
        b.  `courses_taken_count++`。
        c.  遍历 `course` 的所有后续课程 `next_course` (在 `adjList[course]` 中):
        i.  将 `next_course` 的入度 `inDegree[next_course]--`。
        ii. 如果 `inDegree[next_course]` 变为 0，说明其所有先修课程都已完成，将其加入队列。
4.  **结果**:
    *   如果 `courses_taken_count == numCourses`，说明所有课程都可以完成，返回 `true`。
    *   否则，图中存在环，无法完成所有课程，返回 `false`。

**Python 实现:**
```python
from collections import defaultdict, deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        adj_list = defaultdict(list)
        in_degree = [0] * numCourses

        for course, prereq in prerequisites: # [course, prereq] means prereq -> course
            adj_list[prereq].append(course)
            in_degree[course] += 1
            
        queue = deque()
        for i in range(numCourses):
            if in_degree[i] == 0:
                queue.append(i)
        
        courses_taken_count = 0
        while queue:
            course = queue.popleft()
            courses_taken_count += 1
            
            for next_course in adj_list[course]:
                in_degree[next_course] -= 1
                if in_degree[next_course] == 0:
                    queue.append(next_course)
                    
        return courses_taken_count == numCourses
```

**Java 实现:**
```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> adjList = new ArrayList<>(numCourses);
        for (int i = 0; i < numCourses; i++) {
            adjList.add(new ArrayList<>());
        }
        int[] inDegree = new int[numCourses];

        // prerequisites[i] = [ai, bi] means bi is a prerequisite for ai (bi -> ai)
        for (int[] prerequisite : prerequisites) {
            int course = prerequisite[0];
            int prereq = prerequisite[1];
            adjList.get(prereq).add(course); // Edge from prereq to course
            inDegree[course]++;
        }

        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        int coursesTakenCount = 0;
        while (!queue.isEmpty()) {
            int course = queue.poll();
            coursesTakenCount++;

            for (int nextCourse : adjList.get(course)) {
                inDegree[nextCourse]--;
                if (inDegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }
        
        return coursesTakenCount == numCourses;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(V + E)，其中 V 是课程数 (`numCourses`)，E 是先修关系数 (`prerequisites.length`)。构建图 O(E)，初始化队列 O(V)，BFS 过程访问每个节点和边一次 O(V+E)。
*   空间复杂度: O(V + E)，用于存储邻接表和入度数组/队列。

### 109: [79. 单词搜索 (Word Search)](https://leetcode.cn/problems/word-search)

**题目描述:**
给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。
单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**解题思路 (回溯法 / DFS):**
1.  遍历网格 `board` 中的每个单元格 `(r, c)`。
2.  如果 `board[r][c]` 等于 `word` 的第一个字符 `word`，则从该单元格开始进行 DFS 搜索。
3.  **DFS 辅助函数 `dfs(row, col, k)`**:
    *   `k`: 当前正在匹配 `word` 中的第 `k` 个字符 (`word[k]`)。
    *   **基准情况**:
        *   如果 `k == len(word)`，说明整个单词都已成功匹配，返回 `true`。
        *   如果 `(row, col)` 超出网格边界，或者 `board[row][col]` 不等于 `word[k]`，或者该单元格已被访问过 (在当前路径中)，则此路不通，返回 `false`。
    *   **递归步骤 (选择 - 探索 - 撤销选择)**:
        a.  **标记**: 将 `board[row][col]` 标记为已访问 (例如，将其临时修改为一个特殊字符，或者使用一个 `visited` 数组)。
        b.  **探索**: 递归地向四个相邻方向 (上, 下, 左, 右) 进行 DFS 搜索：`dfs(next_row, next_col, k + 1)`。
        *   `found = dfs(row+1, col, k+1) or dfs(row-1, col, k+1) or dfs(row, col+1, k+1) or dfs(row, col-1, k+1)`
        c.  **撤销标记 (回溯)**: 恢复 `board[row][col]` 的原始字符 (或将 `visited[row][col]` 设回 `false`)，以便其他路径可以使用该单元格。
        d.  返回 `found`。
4.  如果在任何一次从网格单元格开始的 DFS 中返回了 `true`，则整个函数返回 `true`。
5.  如果遍历完所有可能的起始点且 DFS 均未成功，返回 `false`。

**Python 实现:**
```python
class Solution:
    def exist(self, board: list[list[str]], word: str) -> bool:
        if not board or not board[0]:
            return False
        
        rows, cols = len(board), len(board[0])
        
        def dfs(r, c, k): # k is the index in word
            # Base cases
            if k == len(word): # Word found
                return True
            if not (0 <= r < rows and 0 <= c < cols): # Out of bounds
                return False
            if board[r][c] != word[k]: # Character doesn't match
                return False
            # If board[r][c] == '#' (visited in current path) - already handled by temp modification

            # Mark as visited
            temp_char = board[r][c]
            board[r][c] = '#' # Temporarily mark
            
            # Explore neighbors
            found = (dfs(r + 1, c, k + 1) or
                     dfs(r - 1, c, k + 1) or
                     dfs(r, c + 1, k + 1) or
                     dfs(r, c - 1, k + 1))
            
            # Unmark (backtrack)
            board[r][c] = temp_char
            
            return found

        for r in range(rows):
            for c in range(cols):
                if dfs(r, c, 0):
                    return True
        return False
```

**Java 实现:**
```java
class Solution {
    private int rows;
    private int cols;
    private char[][] board;
    private String word;

    public boolean exist(char[][] board, String word) {
        if (board == null || board.length == 0 || board[0].length == 0) {
            return false;
        }
        if (word == null || word.isEmpty()) {
            return true; // Or false based on definition, typically true if empty word matches empty prefix.
                         // LeetCode test cases likely involve non-empty words for true returns.
        }

        this.rows = board.length;
        this.cols = board[0].length;
        this.board = board;
        this.word = word;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (dfs(r, c, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean dfs(int r, int c, int k) { // k is the index in word
        // Base cases
        if (k == word.length()) { // Word found
            return true;
        }
        if (r < 0 || r >= rows || c < 0 || c >= cols) { // Out of bounds
            return false;
        }
        if (board[r][c] != word.charAt(k)) { // Character doesn't match or already visited in current path
            return false;
        }
        // If board[r][c] was marked with '#' it would be caught above

        // Mark as visited
        char tempChar = board[r][c];
        board[r][c] = '#'; // Temporarily mark

        // Explore neighbors
        boolean found = dfs(r + 1, c, k + 1) ||
                        dfs(r - 1, c, k + 1) ||
                        dfs(r, c + 1, k + 1) ||
                        dfs(r, c - 1, k + 1);
        
        // Unmark (backtrack)
        board[r][c] = tempChar;
        
        return found;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N * 3^L) 或 O(M * N * 4^L)，其中 M, N 是网格维度，L 是单词长度。
    *   从每个单元格开始，最坏情况下需要探索 3 (不是4，因为不能回头) 个方向，深度为 L。
    *   实际上，由于不能重复使用单元格，路径会受限，但上界是指数级的。
*   空间复杂度: O(L)，用于递归调用栈的深度。

### 110: [402. 移掉K位数字 (Remove K Digits)](https://leetcode.cn/problems/remove-k-digits)

**题目描述:**
给你一个以字符串表示的非负整数 `num` 和一个整数 `k` ，移除这个数中的 `k` 位数字，使得剩下的数字最小。请注意，如果最终结果是 `"0"`，那么应该直接返回 `"0"` 。

**解题思路 (贪心 + 单调栈):**
要使得剩下的数字最小，我们应该尽可能地从左到右移除那些 “峰值” 数字。也就是说，如果一个数字比它右边的数字大，那么移除它通常会得到更小的结果。
1.  使用一个栈 `stack` 来构建结果数字。
2.  遍历 `num` 中的每个数字 `digit`：
    a.  **当 `k > 0` 且栈不为空且 `digit < stack.top()`**：
    i.  说明栈顶元素是一个“峰值” (比当前数字大)，移除它 (`stack.pop()`) 会使结果更小。
    ii. `k--` (表示用掉了一次移除机会)。
    b.  将 `digit` 压入栈 (`stack.push(digit)`)。
3.  遍历结束后，如果 `k > 0` 仍然成立（意味着原数字本身是递增的，或者移除次数没用完）：
    *   从栈顶移除 `k` 个元素 (这些是最大的数字)。
4.  **处理结果**:
    a.  将栈中的数字连接成字符串。
    b.  移除前导零 (除非结果就是 "0")。
    c.  如果结果字符串为空 (例如 `num = "10", k = 2`)，返回 "0"。

**Python 实现:**
```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        stack = [] # Will store digits of the result
        
        for digit in num:
            # While k > 0, stack is not empty, and current digit is smaller than stack top
            while k > 0 and stack and digit < stack[-1]:
                stack.pop()
                k -= 1
            stack.append(digit)
            
        # If k is still > 0 after iterating through all digits (e.g., num="12345", k=2)
        # This means remaining k digits must be removed from the end of the stack
        while k > 0 and stack:
            stack.pop()
            k -= 1 # Not strictly necessary here as loop condition handles it
            
        # Construct the result string
        if not stack:
            return "0"
        
        result = "".join(stack)
        
        # Remove leading zeros
        # Find first non-zero digit
        first_non_zero = 0
        while first_non_zero < len(result) -1 and result[first_non_zero] == '0':
            first_non_zero +=1
            
        return result[first_non_zero:]

```

**Java 实现:**
```java
import java.util.Stack; // Or Deque<Character> as Stack (LinkedList)

class Solution {
    public String removeKdigits(String num, int k) {
        if (k == num.length()) {
            return "0";
        }

        Stack<Character> stack = new Stack<>();

        for (char digit : num.toCharArray()) {
            // While k > 0, stack is not empty, and current digit is smaller than stack top
            while (k > 0 && !stack.isEmpty() && digit < stack.peek()) {
                stack.pop();
                k--;
            }
            stack.push(digit);
        }

        // If k is still > 0 (e.g., num="12345", k=2)
        // Remove remaining k digits from the end of the stack
        while (k > 0 && !stack.isEmpty()) {
            stack.pop();
            k--;
        }

        // Construct the result string
        StringBuilder sb = new StringBuilder();
        for (char c : stack) { // Iterating stack gives bottom-to-top, correct order for number
            sb.append(c);
        }

        if (sb.length() == 0) {
            return "0";
        }
        
        // Remove leading zeros
        int firstNonZero = 0;
        while (firstNonZero < sb.length() -1 && sb.charAt(firstNonZero) == '0') {
            firstNonZero++;
        }
        
        return sb.substring(firstNonZero);
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，其中 N 是 `num` 的长度。每个数字最多被压入栈和弹出栈一次。
*   空间复杂度: O(N)，用于存储栈。
