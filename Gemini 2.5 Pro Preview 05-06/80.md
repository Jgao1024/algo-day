### 071: [48. 旋转图像 (Rotate Image)](https://leetcode.cn/problems/rotate-image)

**题目描述:**
给定一个 *n* × *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。
你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**解题思路 (原地旋转):**
原地顺时针旋转 90 度可以通过两步实现：
1.  **沿主对角线翻转 (Transpose)**: 交换 `matrix[i][j]` 和 `matrix[j][i]`。
2.  **沿垂直中轴线翻转 (Reverse each row)**: 对于每一行，翻转其元素。

或者，另一种顺序也可以（更常见）：
1.  **沿水平中轴线翻转 (Reverse rows up-down)**: 交换 `matrix[i][j]` 和 `matrix[n-1-i][j]`（对于 `j` from `0` to `n-1`, `i` from `0` to `n/2 - 1`）。或者简单地，先将整个矩阵的行上下翻转。
2.  **沿主对角线翻转 (Transpose)**: 交换 `matrix[i][j]` 和 `matrix[j][i]`。

我们将使用更常见的方法：先转置，后翻转行。
1.  **转置矩阵 (Transpose)**:
    *   遍历矩阵的上半角 (或下半角)，即 `i` 从 `0` 到 `n-1`，`j` 从 `i+1` 到 `n-1` (避免重复交换和对角线元素自我交换)。
    *   交换 `matrix[i][j]` 和 `matrix[j][i]`。
2.  **翻转每一行 (Reverse each row)**:
    *   遍历每一行 `i` 从 `0` 到 `n-1`。
    *   使用双指针法 (或者直接用切片反转) 翻转 `matrix[i]` 这一行。

**Python 实现:**
```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        # 1. Transpose the matrix
        # Iterate only through the upper triangle (or lower) to avoid double swaps
        for i in range(n):
            for j in range(i + 1, n): # j starts from i+1 to avoid self-swap of diagonal and processing twice
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        
        # 2. Reverse each row
        for i in range(n):
            matrix[i].reverse() # Python's list.reverse() is in-place

        # Alternatively, manually reverse each row:
        # for i in range(n):
        #     left, right = 0, n - 1
        #     while left < right:
        #         matrix[i][left], matrix[i][right] = matrix[i][right], matrix[i][left]
        #         left += 1
        #         right -= 1
```

**Java 实现:**
```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // 1. Transpose the matrix
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) { // j starts from i+1
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // 2. Reverse each row
        for (int i = 0; i < n; i++) {
            int left = 0;
            int right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N^2)，其中 N 是矩阵的边长。需要遍历矩阵元素进行转置和翻转。
*   空间复杂度: O(1)，因为是原地修改。

### 073: [240. 搜索二维矩阵 II (Search a 2D Matrix II)](https://leetcode.cn/problems/search-a-2d-matrix-ii)

**题目描述:**
编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：
*   每行中的整数从左到右按升序排列。
*   每列中的整数从上到下按升序排列。

**解题思路 (从角落开始搜索):**
1.  选择一个合适的起始角落。最优的起始点是**左下角** (`matrix[rows-1]`) 或 **右上角** (`matrix[cols-1]`)。
    *   以**右上角** (`matrix[cols-1]`) 为例 (row = 0, col = cols - 1):
        *   当前元素 `current = matrix[row][col]`。
        *   如果 `current == target`，找到了，返回 `true`。
        *   如果 `current > target`，说明 `target` 不可能在当前列（因为当前列的下方元素都更大），所以向左移动，减小列索引: `col--`。
        *   如果 `current < target`，说明 `target` 不可能在当前行（因为当前行的左方元素都更小），所以向下移动，增大行索引: `row++`。
2.  重复上述步骤，直到找到 `target` 或指针超出矩阵边界。
    *   如果 `row >= rows` 或 `col < 0`，说明没找到，返回 `false`。

**Python 实现:**
```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        rows = len(matrix)
        cols = len(matrix[0])

        # Start from the top-right corner
        row = 0
        col = cols - 1

        while row < rows and col >= 0:
            current_val = matrix[row][col]
            if current_val == target:
                return True
            elif current_val > target:
                col -= 1  # Move left (target must be smaller)
            else: # current_val < target
                row += 1  # Move down (target must be larger)
        
        return False # Target not found
```

**Java 实现:**
```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int rows = matrix.length;
        int cols = matrix[0].length;

        // Start from the top-right corner
        int row = 0;
        int col = cols - 1;

        while (row < rows && col >= 0) {
            int currentVal = matrix[row][col];
            if (currentVal == target) {
                return true;
            } else if (currentVal > target) {
                col--; // Move left
            } else { // currentVal < target
                row++; // Move down
            }
        }
        
        return false; // Target not found
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M + N)，其中 M 是行数，N 是列数。在每一步，要么行索引增加，要么列索引减少。行索引最多增加 M 次，列索引最多减少 N 次。
*   空间复杂度: O(1)。

### 074: [98. 验证二叉搜索树 (Validate Binary Search Tree)](https://leetcode.cn/problems/validate-binary-search-tree)

**题目描述:**
给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。
有效 二叉搜索树定义如下：
*   节点的左子树只包含 **小于** 当前节点的数。
*   节点的右子树只包含 **大于** 当前节点的数。
*   所有左子树和右子树自身必须也是二叉搜索树。

**解题思路:**
**1. 递归 (带范围限制):**
* 定义一个辅助递归函数 `isValidBSTHelper(node, lower_bound, upper_bound)`。
* `lower_bound`: 当前节点值必须大于的下界。
* `upper_bound`: 当前节点值必须小于的上界。
* **基准情况**:
    * 如果 `node` 为空，它是有效的 BST (空树是 BST)，返回 `true`。
* **检查当前节点**:
    * 如果 `node.val <= lower_bound` 或 `node.val >= upper_bound`，则当前节点不满足 BST 条件，返回 `false`。
* **递归检查子树**:
    * 对左子树: `isValidBSTHelper(node.left, lower_bound, node.val)` (左子节点的值必须小于 `node.val`)。
    * 对右子树: `isValidBSTHelper(node.right, node.val, upper_bound)` (右子节点的值必须大于 `node.val`)。
    * 只有当左右子树都有效时，当前子树才有效。
* 初始调用: `isValidBSTHelper(root, -infinity, +infinity)`。

**2. 中序遍历法:**
* 对二叉搜索树进行中序遍历，得到的序列一定是严格递增的。
* 执行中序遍历，将节点值存入列表。
* 检查列表是否严格递增。
* 优化：可以在中序遍历时，直接比较当前节点与上一个遍历到的节点，而无需存储整个列表。维护一个 `prev_val` 变量。

### 075: [543. 二叉树的直径 (Diameter of Binary Tree)](https://leetcode.cn/problems/diameter-of-binary-tree)

**题目描述:**
给定一棵二叉树，你需要计算它的直径长度。一棵二叉树的直径长度是任意两个节点路径长度中的最大值。这条路径可能穿过也可能不穿过根节点。
**注意**：两节点之间的路径长度是以它们之间边的数目表示。

**解题思路:**
对于每个节点，通过它的最长路径可以是：`左子树的最大深度 + 右子树的最大深度`。
我们需要遍历所有节点，计算以每个节点为“拐点”（路径的最高点）的直径，并取最大值。

1.  **定义递归函数 `maxDepth(node)`**:
    *   这个函数不仅计算以 `node` 为根的子树的最大深度，同时在计算过程中更新全局的 `diameter`。
    *   **基准情况**: 如果 `node` 为空，返回深度 0。
    *   **递归计算**:
        *   `left_depth = maxDepth(node.left)`
        *   `right_depth = maxDepth(node.right)`
    *   **更新直径**:
        *   通过当前 `node` 的直径是 `left_depth + right_depth`。
        *   用这个值更新全局的 `max_diameter = max(max_diameter, left_depth + right_depth)`。
    *   **返回深度**: `maxDepth` 函数本身应该返回当前 `node` 的深度，即 `1 + max(left_depth, right_depth)`。
2.  初始化 `max_diameter = 0`。
3.  调用 `maxDepth(root)`。最终的 `max_diameter` 就是答案。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def __init__(self):
        self.max_diameter = 0

    def diameterOfBinaryTree(self, root: TreeNode) -> int:
        self.max_diameter = 0 # Reset if called multiple times (LeetCode test cases)
        self._max_depth(root)
        return self.max_diameter

    def _max_depth(self, node: TreeNode) -> int:
        # This helper function returns the depth of the tree rooted at 'node'
        # and updates self.max_diameter along the way.
        if not node:
            return 0 # Depth of an empty tree is 0

        left_depth = self._max_depth(node.left)
        right_depth = self._max_depth(node.right)

        # The diameter through the current 'node' is the sum of depths of its left and right subtrees.
        # This is the number of nodes. Number of edges = number of nodes - 1.
        # The depth returned by _max_depth is "number of nodes in longest path from root to leaf".
        # So, left_depth + right_depth directly represents the number of edges for the path passing through node.
        current_diameter = left_depth + right_depth
        self.max_diameter = max(self.max_diameter, current_diameter)

        # Return the depth of the tree rooted at 'node'
        # Depth = 1 (for current node) + max depth of its children
        return 1 + max(left_depth, right_depth)
```

**Java 实现:**
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    private int maxDiameter;

    public int diameterOfBinaryTree(TreeNode root) {
        maxDiameter = 0; // Initialize diameter
        maxDepth(root);
        return maxDiameter;
    }

    private int maxDepth(TreeNode node) {
        // This helper function returns the depth of the tree rooted at 'node'
        // and updates maxDiameter along the way.
        if (node == null) {
            return 0; // Depth of an empty tree is 0
        }

        int leftDepth = maxDepth(node.left);
        int rightDepth = maxDepth(node.right);

        // The diameter that passes through the current 'node' is the sum of
        // the depths of its left and right subtrees.
        // (Number of edges in the longest path from node.left down +
        //  Number of edges in the longest path from node.right down)
        // Our definition of depth here (height) means leftDepth is number of edges.
        int currentDiameter = leftDepth + rightDepth;
        maxDiameter = Math.max(maxDiameter, currentDiameter);

        // Return the depth of the tree rooted at 'node' for the parent call
        // Depth = 1 (for edge to parent) + max depth of its children
        // If depth definition is number of nodes, then 1 (current node) + ...
        // Here, depth is essentially height (number of edges).
        return 1 + Math.max(leftDepth, rightDepth);
    }
}
```

*   时间复杂度: O(N)，其中 N 是树中节点的数量。每个节点被访问一次。
*   空间复杂度: O(H)，其中 H 是树的高度，用于递归调用栈。最坏情况下 O(N)，平均情况下 O(log N)。

### 076: [221. 最大正方形 (Maximal Square)](https://leetcode.cn/problems/maximal-square)

**题目描述:**
在一个由 `'0'` 和 `'1'` 组成的二维矩阵内，找到只包含 `'1'` 的最大正方形，并返回其面积。

**解题思路 (动态规划):**
1.  定义 `dp[i][j]` 为以 `matrix[i-1][j-1]` (或者 `matrix[i][j]` 如果 `dp` 表与 `matrix` 索引对应) 为右下角的最大正方形的**边长**。
2.  **初始化**:
    *   `dp` 表大小为 `(rows+1) x (cols+1)`，并用 0 初始化。第一行和第一列的 `dp` 值将帮助处理边界。
3.  **状态转移方程**:
    *   遍历矩阵 `matrix` (从 `i=1` 到 `rows`，`j=1` 到 `cols`，对应 `dp` 表)。
    *   如果 `matrix[i-1][j-1] == '1'`:
        *   `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`。
        *   这个公式的含义是：如果当前单元格 `matrix[i-1][j-1]` 是 '1'，那么以它为右下角能构成的最大正方形的边长，取决于它左边、上边、左上角三个位置能构成的正方形。它只能取这三者中的最小值，并加 1（因为当前单元格 `matrix[i-1][j-1]` 本身贡献了 1 的边长）。
    *   如果 `matrix[i-1][j-1] == '0'`:
        *   `dp[i][j] = 0` (以 '0' 为右下角不能构成任何正方形)。
4.  在填充 `dp` 表的过程中，记录 `max_side_length = max(max_side_length, dp[i][j])`。
5.  最终结果是 `max_side_length * max_side_length`。

**Python 实现:**
```python
class Solution:
    def maximalSquare(self, matrix: list[list[str]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        
        rows = len(matrix)
        cols = len(matrix[0])
        
        # dp[i][j] will store the side length of the largest square 
        # whose bottom-right corner is at matrix[i-1][j-1]
        dp = [[0 for _ in range(cols + 1)] for _ in range(rows + 1)]
        max_side_length = 0
        
        for r in range(1, rows + 1):
            for c in range(1, cols + 1):
                if matrix[r-1][c-1] == '1':
                    # The side length is determined by the minimum of the square ending at:
                    # 1. Directly above (dp[r-1][c])
                    # 2. Directly to the left (dp[r][c-1])
                    # 3. Diagonally top-left (dp[r-1][c-1])
                    # plus 1 (for the current cell matrix[r-1][c-1])
                    dp[r][c] = min(dp[r-1][c], dp[r][c-1], dp[r-1][c-1]) + 1
                    max_side_length = max(max_side_length, dp[r][c])
                # If matrix[r-1][c-1] == '0', dp[r][c] remains 0 (by initialization)
                
        return max_side_length * max_side_length
```

**Java 实现:**
```java
class Solution {
    public int maximalSquare(char[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return 0;
        }

        int rows = matrix.length;
        int cols = matrix[0].length;

        // dp[i][j] stores the side length of the largest square
        // whose bottom-right corner is at matrix[i-1][j-1]
        int[][] dp = new int[rows + 1][cols + 1]; // Default initialized to 0
        int maxSideLength = 0;

        for (int r = 1; r <= rows; r++) {
            for (int c = 1; c <= cols; c++) {
                if (matrix[r-1][c-1] == '1') {
                    dp[r][c] = Math.min(Math.min(dp[r-1][c], dp[r][c-1]), dp[r-1][c-1]) + 1;
                    maxSideLength = Math.max(maxSideLength, dp[r][c]);
                }
                // If matrix[r-1][c-1] == '0', dp[r][c] remains 0
            }
        }
        
        return maxSideLength * maxSideLength;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M * N)，其中 M 是行数，N 是列数。需要填充整个 DP 表。
*   空间复杂度: O(M * N)，用于 DP 表。可以优化到 O(N) 因为 `dp[i][j]` 只依赖于 `dp[i-1]` 行和 `dp[i]` 行的左边部分。

### 077: [128. 最长连续序列 (Longest Consecutive Sequence)](https://leetcode.cn/problems/longest-consecutive-sequence)

**题目描述:**
给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。
请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

**解题思路 (使用哈希集合):**
1.  将所有数字存入一个哈希集合 `num_set`，方便 O(1) 查找。
2.  初始化 `max_length = 0`。
3.  遍历 `nums` 数组中的每个数字 `num`:
    *   **检查是否是序列的起点**: 如果 `num - 1` 不在 `num_set` 中，则 `num` 可能是一个连续序列的开始。
    *   如果是序列的起点：
        *   初始化 `current_num = num`，`current_length = 1`。
        *   不断检查 `current_num + 1` 是否在 `num_set` 中：
            *   如果在，则 `current_num++`，`current_length++`。
            *   直到 `current_num + 1` 不在 `num_set` 中。
        *   更新 `max_length = max(max_length, current_length)`。
4.  返回 `max_length`。

**为什么是 O(N)?**
虽然看起来有嵌套循环，但内层 `while` 循环对于每个数字最多只执行一次。考虑一个连续序列 `x, x+1, ..., x+k`。当外层循环处理到 `x` 时，内层循环会执行 `k` 次。当外层循环处理到 `x+1, ..., x+k` 时，条件 `num - 1 not in num_set` 不会满足，所以内层循环不会执行。因此，每个数字作为内层循环的一部分最多被访问一次。

**Python 实现:**
```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        if not nums:
            return 0
            
        num_set = set(nums)
        max_length = 0
        
        for num in nums: # Iterate through original nums to process each number
            # Check if 'num' is the start of a sequence
            # If num-1 is present, then 'num' is not the start, 
            # it will be covered when num-1 (or an earlier element) is processed.
            if (num - 1) not in num_set:
                current_num = num
                current_length = 1
                
                # Count how long the sequence starting from 'num' is
                while (current_num + 1) in num_set:
                    current_num += 1
                    current_length += 1
                
                max_length = max(max_length, current_length)
                
        return max_length
```

**Java 实现:**
```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) {
            numSet.add(num);
        }
        
        int maxLength = 0;
        
        for (int num : numSet) { // Iterate through unique numbers in the set
            // Check if 'num' is the start of a sequence
            // If num-1 is present, then 'num' is not the start.
            if (!numSet.contains(num - 1)) {
                int currentNum = num;
                int currentLength = 1;
                
                // Count how long the sequence starting from 'num' is
                while (numSet.contains(currentNum + 1)) {
                    currentNum++;
                    currentLength++;
                }
                
                maxLength = Math.max(maxLength, currentLength);
            }
        }
        return maxLength;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)。将 N 个数加入哈希集合需要 O(N)。外层循环遍历 N 个数 (或唯一的数)，内层 `while` 循环的总执行次数在所有外层循环迭代中加起来也是 O(N)。
*   空间复杂度: O(N)，用于存储哈希集合。

### 078: [122. 买卖股票的最佳时机 II (Best Time to Buy and Sell Stock II)](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii)

**题目描述:**
给你一个整数数组 `prices` ，其中 `prices[i]` 表示某支股票第 `i` 天的价格。
在每一天，你可以决定是否购买和/或出售股票。你在任何时候 **最多** 只能持有 **一股** 股票。你也可以先购买，然后在 **同一天** 出售。
返回 你能获得的 **最大利润** 。

**解题思路 (贪心算法):**
只要今天的价格比昨天的价格高，我们就在昨天买入，今天卖出，并累加这个利润。
这等价于：如果价格序列是 `p1, p2, p3, ..., pk`，并且 `p1 < p2 < ... < pk`，那么最大利润是 `(p2-p1) + (p3-p2) + ... + (pk - p(k-1))`，这简化为 `pk - p1`。
所以，策略是只要能赚钱就交易。
1.  初始化 `max_profit = 0`。
2.  从第二天开始遍历价格数组 (`i = 1` 到 `n-1`):
    *   如果 `prices[i] > prices[i-1]` (今天的价格比昨天高):
        *   累加利润: `max_profit += prices[i] - prices[i-1]`。
3.  返回 `max_profit`。

**Python 实现:**
```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices or len(prices) < 2:
            return 0
        
        max_profit = 0
        for i in range(1, len(prices)):
            if prices[i] > prices[i-1]:
                max_profit += prices[i] - prices[i-1]
                
        return max_profit
```

### 080: [14. 最长公共前缀 (Longest Common Prefix)](https://leetcode.cn/problems/longest-common-prefix)

**题目描述:**
编写一个函数来查找字符串数组中的最长公共前缀。

**解题思路:**
**1. 水平扫描 (逐个比较):**
* 取第一个字符串作为初始的 `prefix`。

    * 不断缩短 `prefix`，直到 `str` 以 `prefix` 开头 (`str.startsWith(prefix)`)。
    * 如果 `prefix` 缩短到空字符串 `""`，说明没有公共前缀，直接返回 `""`。

* 遍历第一个字符串的每个字符 (作为潜在前缀的字符)。设当前字符索引为 `i`。
* 对于每个字符 `char = strs[i]`:
    * 检查数组中所有其他字符串 `strs[j]` (从 `j=1` 开始)：
        * 如果 `i` 超出 `strs[j]` 的长度，或者 `strs[j][i]` 不等于 `char`，则说明当前 `char` 及其之前的字符构成的子串 `strs[0...i-1]` 就是最长公共前缀。返回它。
* 如果第一个字符串的所有字符都成功匹配了所有其他字符串的对应位置，则整个第一个字符串就是最长公共前缀。

    *   时间复杂度: O(S)，其中 S 是所有字符串中字符的总数。在最坏情况下（例如，所有字符串都相同，或只有一个字符串，或前缀很长然后不匹配），`prefix` 会被反复缩短和比较。`String.startsWith()` 或 `indexOf()` 可能需要 O(len(prefix) * len(current_str)) 或 O(len(prefix)) 或 O(len(current_str)) 的时间，取决于实现，但总的字符比较次数不会超过 S。更准确地说，是 `m * n` 其中 `m` 是最短字符串的长度，`n` 是字符串数量。
*   **垂直扫描:**
    *   时间复杂度: O(S)。在最坏情况下 (所有字符串相同)，将比较第一个字符串的每个字符与所有其他字符串的对应字符。总比较次数也是 O(S)。或者可以看作是 O(N * L)，其中 N 是字符串数量，L 是最短字符串的长度。

*   空间复杂度: O(1) (不计输入字符串占用的空间)。
