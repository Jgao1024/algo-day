### 161: [剑指 Offer 62. 圆圈中最后剩下的数字 (LCOF - Josephus Problem)](https://leetcode.cn/problems/yuan-quan-zhong-zui-hou-sheng-xia-de-shu-zi-lcof)

**题目描述:**
0,1,···,n-1 这 n 个数字排成一个圆圈，从数字 0 开始，每次从这个圆圈里删除第 m 个数字（删除后从下一个数字开始重新计数）。求出这个圆圈里剩下的最后一个数字。
例如，0、1、2、3、4 这 5 个数字组成一个圆圈，从数字 0 开始每次删除第 3 个数字，则删除的前 4 个数字依次是 2、0、4、1，因此最后剩下的数字是 3。
限制：`1 <= n <= 10^5`, `1 <= m <= 10^6`。

**解题思路 (数学/动态规划 - 反推法):**
这是一个经典的约瑟夫环问题。
设 `f(n, m)` 表示 n 个数字（0 到 n-1），每次删除第 m 个，最后剩下的数字。

考虑第一轮删除：第 `(m-1) % n` 个数字被删除（0-indexed）。
删除后，剩下 `n-1` 个数字。可以将这 `n-1` 个数字重新映射为 0 到 `n-2` 来解决子问题 `f(n-1, m)`。
假设在 `n-1` 规模下，最后剩下的是数字 `x_prime = f(n-1, m)`。
我们需要找到这个 `x_prime` 在原始 `n` 个数字序列中的编号 `x`。

被删除的数字是 `k = (m-1) % n`。
删除 `k` 后，序列从 `k+1` 开始重新编号。
原来的 `k+1` 变成新序列的 0。
原来的 `k+2` 变成新序列的 1。
...
原来的 `(k + x_prime) % n` 对应于子问题中的 `x_prime`（在长度为 n-1 的序列中的位置）。
所以，`x = ( (m-1)%n + 1 + f(n-1,m) ) % n` is not quite right.

正确的递推公式（0-indexed Josephus problem）：
`f(n, m) = (f(n-1, m) + m) % n`
其中 `f(1, m) = 0` (当只有1个人时，这个人（编号0）留下)。

我们想要求 `f(n,m)`.
`f(1, m) = 0` (1个人，从0开始报数，他自己留下，下标0)
`f(2, m) = (f(1, m) + m) % 2 = (0 + m) % 2`
`f(3, m) = (f(2, m) + m) % 3`
...
`f(i, m) = (f(i-1, m) + m) % i`

我们可以从 `i = 2` 迭代到 `n` 来计算 `f(n, m)`。
令 `ans = 0` for `f(1, m)`.
For `i` from 2 to `n`:
`ans = (ans + m) % i`

**Python 实现:**
```python
class Solution:
    def lastRemaining(self, n: int, m: int) -> int:
        # f(n, m) = (f(n-1, m) + m) % n
        # Base case: f(1, m) = 0 (when only 1 person, index 0 remains)
        
        # Let's use 'ans' to store f(i, m)
        # Initialize ans for i = 1
        ans = 0 
        
        # Iterate from i = 2 to n
        for i in range(2, n + 1):
            ans = (ans + m) % i
            
        return ans
```

**Java 实现:**
```java

        // Initialize ans for i = 1

*   时间复杂度: O(N)，循环 N 次。
*   空间复杂度: O(1)。

### 162: [96. 不同的二叉搜索树 (Unique Binary Search Trees)](https://leetcode.cn/problems/unique-binary-search-trees)

**题目描述:**
给你一个整数 `n` ，求恰由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的 **二叉搜索树** 有多少种？返回满足题意的二叉搜索树的种数。

**解题思路 (动态规划 - Catalan Numbers):**
设 `G[n]` 为由 `n` 个节点（1 到 `n`）构成的不同二叉搜索树的数量。
设 `F[i][n]` 为以 `i` 为根节点，且序列长度为 `n` (即从 1 到 n 的节点) 构成的不同二叉搜索树的数量。
由于节点值从 1到 n 是固定的，我们只需考虑节点个数。
`G[n] = sum over i from 1 to n (F[i][n])`
`F[i][n]` (以 `i` 为根)：
左子树的节点个数为 `i-1` (节点值从 1 到 `i-1`)。左子树的种类有 `G[i-1]` 种。
右子树的节点个数为 `n-i` (节点值从 `i+1` 到 `n`)。右子树的种类有 `G[n-i]` 种。
所以 `F[i][n] = G[i-1] * G[n-i]`。

因此，`G[n] = sum over i from 1 to n (G[i-1] * G[n-i])`。

**基准情况:**
*   `G = 1` (空树也是一种 BST，这有助于递推)。
*   `G = 1` (单个节点只有一种 BST)。
    Calculation for G[n]:
    `G = 1`
    `G = G*G = 1*1 = 1`
    `G = G*G + G*G = 1*1 + 1*1 = 2` (root 1 or root 2)
    `G = G*G + G*G + G*G = 1*2 + 1*1 + 2*1 = 2 + 1 + 2 = 5`

这正是卡特兰数的定义。

**Python 实现:**
```python
class Solution:
    def numTrees(self, n: int) -> int:
        if n == 0:
            return 1 # By convention, or problem constraints n >= 1. Let's check. (n >= 1)
        if n == 1:
            return 1
            
        # G[i] will store the number of unique BSTs for i nodes
        G = [0] * (n + 1)
        G[0] = 1
        G[1] = 1
        
        # Fill G for nodes from 2 to n
        for num_nodes in range(2, n + 1):
            for root_val_idx_minus_1 in range(num_nodes): # Iterate through possible number of left nodes (0 to num_nodes-1)
                                                       # which means root_val_idx from 0 to num_nodes-1 (0-indexed roots)
                                                       # or if thinking as root value i from 1 to num_nodes:
                                                       # num_left_nodes = i-1
                                                       # num_right_nodes = num_nodes - i
                num_left_nodes = root_val_idx_minus_1
                num_right_nodes = num_nodes - 1 - root_val_idx_minus_1 # (num_nodes - 1) total other nodes
                
                G[num_nodes] += G[num_left_nodes] * G[num_right_nodes]
                
        return G[n]
```

**Java 实现:**
```java
class Solution {
    public int numTrees(int n) {
        // G[i] stores the number of unique BSTs for i nodes
        int[] G = new int[n + 1];
        
        // Base cases
        G[0] = 1; // Empty tree
        if (n >= 1) {
            G[1] = 1; // Single node tree
        }
        
        // Fill G for number of nodes from 2 to n
        for (int numNodes = 2; numNodes <= n; numNodes++) {
            // Iterate through all possible root nodes (1-indexed conceptual root value, means number of nodes on left)
            // If 'i' is the root (1 to numNodes), then i-1 nodes are on the left, numNodes-i nodes on the right.
            for (int numLeftNodes = 0; numLeftNodes < numNodes; numLeftNodes++) {
                int numRightNodes = numNodes - 1 - numLeftNodes;
                G[numNodes] += G[numLeftNodes] * G[numRightNodes];
            }
        }
        
        return G[n];
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N^2)，外层循环 N 次，内层循环也 N 次。
*   空间复杂度: O(N)，用于存储 DP 数组 `G`。

### 163: [516. 最长回文子序列 (Longest Palindromic Subsequence)](https://leetcode.cn/problems/longest-palindromic-subsequence)

**题目描述:**
给你一个字符串 `s` ，找出其中最长的回文子序列，并返回该序列的长度。
子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

**解题思路 (动态规划):**
设 `dp[i][j]` 为字符串 `s` 从索引 `i` 到 `j` (包含 `i` 和 `j`) 的子串 `s[i...j]` 中最长回文子序列的长度。

**状态转移方程:**
1.  如果 `s[i] == s[j]`:
    *   那么 `s[i]` 和 `s[j]` 可以作为回文子序列的两端。
    *   `dp[i][j] = dp[i+1][j-1] + 2`。 (这两个字符贡献长度2，再加上中间部分 `s[i+1...j-1]` 的最长回文子序列)
    *   特殊情况: 如果 `i == j` (单个字符)，`dp[i][i] = 1`。
    *   特殊情况: 如果 `i + 1 == j` (两个字符 `s[i]s[i+1]`) 且 `s[i]==s[i+1]`, `dp[i][i+1] = 2`. (based on `dp[i+1][j-1]` where `i+1 > j-1` which for DP table will mean 0). `dp[i+1][j-1]` (i.e. `dp[i+1][i]`) represents an empty or invalid substring, length 0.

2.  如果 `s[i] != s[j]`:
    *   那么 `s[i]` 和 `s[j]` 不能同时作为当前最长回文子序列的两端。
    *   我们有两种选择：
        *   不考虑 `s[j]`，在 `s[i...j-1]` 中找最长回文子序列: `dp[i][j-1]`。
        *   不考虑 `s[i]`，在 `s[i+1...j]` 中找最长回文子序列: `dp[i+1][j]`。
    *   `dp[i][j] = max(dp[i][j-1], dp[i+1][j])`。

**遍历顺序:**
`dp[i][j]` 的计算依赖于 `dp[i+1][j-1]`, `dp[i][j-1]`, `dp[i+1][j]`。
这意味着我们需要先计算长度较短的子串的 LPS。
所以，`i` 应该从 `n-1` 向下遍历到 `0`。
`j` 应该从 `i` (或 `i+1`) 向上遍历到 `n-1`。
(Or iterate by length `L` from 1 to `n`).

**基准情况 (对角线):**
*   `dp[i][i] = 1` for all `i` (单个字符是长度为 1 的回文子序列)。

**Python 实现:**
```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0
        
        # dp[i][j] = length of the longest palindromic subsequence in s[i...j]
        dp = [[0 for _ in range(n)] for _ in range(n)]

        # Base case: single character is a palindrome of length 1
        for i in range(n):
            dp[i][i] = 1
            
        # Fill the table. Iterate by length of substring 'L'
        # Or iterate i from n-1 down to 0, and j from i+1 up to n-1
        for i in range(n - 1, -1, -1): # Iterate i from n-1 down to 0
            for j in range(i + 1, n):   # Iterate j from i+1 up to n-1
                if s[i] == s[j]:
                    # dp[i+1][j-1] can be 0 if i+1 > j-1 (e.g. adjacent chars i, j=i+1)
                    # In this case, it would be just s[i] and s[j], length 2.
                    # The term dp[i+1][j-1] for an "empty" or invalid range (start > end) is 0.
                    dp[i][j] = dp[i+1][j-1] + 2 
                else:
                    dp[i][j] = max(dp[i+1][j], dp[i][j-1])
                    
        return dp[0][n-1] # Result for the whole string s[0...n-1]
```

**Java 实现:**
```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        if (n == 0) {
            return 0;
        }

        // dp[i][j] = length of the longest palindromic subsequence in s.substring(i, j+1)
        int[][] dp = new int[n][n];

        // Base case: single character is a palindrome of length 1
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }

        // Fill the table. Iterate i from n-1 down to 0
        for (int i = n - 1; i >= 0; i--) {
            // Iterate j from i+1 up to n-1
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    // For adjacent characters s[i]s[i+1] where i+1=j:
                    // i+1 > j-1 is true (e.g. i=0,j=1 -> i+1=1, j-1=0). dp[1][0] would be 0.
                    // So dp[i][j] = 0 + 2 = 2, which is correct.
                    dp[i][j] = dp[i+1][j-1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);
                }
            }
        }
        
        return dp[0][n-1]; // Result for the whole string s[0...n-1]
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N^2)，两层嵌套循环。
*   空间复杂度: O(N^2)，用于 DP 表。 (可以优化到 O(N) 因为 `dp[i]` 只依赖 `dp[i+1]` 和 `dp[i]` 的前一列).

### 164: [189. 轮转数组 (Rotate Array)](https://leetcode.cn/problems/rotate-array)

**题目描述:**
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**解题思路:**
1.  **使用额外数组 (O(N) space, O(N) time):**
    *   创建一个新数组 `new_nums`。
    *   对于每个元素 `nums[i]`，它在新数组中的位置是 `(i + k) % n` (n是数组长度)。
    *   将 `new_nums` 的元素复制回 `nums`。

2.  **多次反转 (O(1) space, O(N) time):**
    *   `k = k % n` (处理 k 大于 n 的情况)。
    *   反转整个数组 `nums`。
    *   反转前 `k` 个元素 `nums[0...k-1]`。
    *   反转后 `n-k` 个元素 `nums[k...n-1]`。
    *   例: nums = ``, k = 3
        1. `k = 3 % 7 = 3`
        2. Reverse all: `` -> ``
        3. Reverse `nums[0...k-1]` (``): `` -> ``
        4. Reverse `nums[k...n-1]` (``): `` -> ``. Correct.

3.  **环状替换 / Juggling Algorithm (O(1) space, O(N) time):**
    *   `k = k % n`。
    *   从索引 `start = 0` 开始，将 `nums[start]` 移动到 `(start + k) % n`，`nums[(start + k) % n]` 移动到 `(start + 2k) % n`，以此类推，形成一个环。
    *   总共需要进行 `gcd(n, k)` 个这样的环状替换。`gcd` 是最大公约数。
    *   对每个环的起始点 `start` 从 `0` 到 `gcd(n, k) - 1` 进行操作。
    *   在一个环内，`count` 元素会被移动。当下一个目标位置回到 `start` 时，一个环完成。
    *   这个方法实现起来稍复杂。

**Python 实现 (多次反转):**
```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        if n == 0 or k == 0:
            return
        
        k = k % n # Effective rotations
        if k == 0:
            return

        def reverse(arr, start, end):
            while start < end:
                arr[start], arr[end] = arr[end], arr[start]
                start += 1
                end -= 1

        # 1. Reverse the entire array
        reverse(nums, 0, n - 1)
        # 2. Reverse the first k elements
        reverse(nums, 0, k - 1)
        # 3. Reverse the remaining n-k elements
        reverse(nums, k, n - 1)
```

**Java 实现 (多次反转):**
```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        if (n == 0 || k == 0) {
            return;
        }
        
        k = k % n; // Effective rotations
        if (k == 0) {
            return;
        }

        // 1. Reverse the entire array
        reverse(nums, 0, n - 1);
        // 2. Reverse the first k elements
        reverse(nums, 0, k - 1);
        // 3. Reverse the remaining n-k elements
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] arr, int start, int end) {
        while (start < end) {
            int temp = arr[start];
            arr[start] = arr[end];
            arr[end] = temp;
            start++;
            end--;
        }
    }
}
```

**复杂度分析 (多次反转):**
*   时间复杂度: O(N)，三次反转，每次反转操作是 O(N)。
*   空间复杂度: O(1)。

### 165: [225. 用队列实现栈 (Implement Stack using Queues)](https://leetcode.cn/problems/implement-stack-using-queues)

**题目描述:**
请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（`push`、`top`、`pop` 和 `empty`）。
你可以使用 `list` 或 `deque`（双端队列）来模拟一个队列，只要是标准的队列操作即可。

**解题思路:**
**使用两个队列 (`q1`, `q2`):**
*   **`push(x)`:** 将元素 `x` 加入 `q1`。 O(1)
*   **`pop()`:** (使 `q1` 的队尾元素模拟栈顶)
    *   将 `q1` 中除最后一个元素外的所有元素依次出队并入队到 `q2`。
    *   `q1` 中剩下的最后一个元素就是栈顶元素，将其出队作为 `pop` 的结果。
    *   交换 `q1` 和 `q2` 的引用 (使 `q1` 始终是主队列，`q2` 是辅助队列)。
    *   O(N)
*   **`top()`:** 类似于 `pop()`，但不删除元素。将 `q1` 中除最后一个元素外的所有元素移到 `q2`，记录最后一个元素的值，然后将这个元素也移到 `q2`。最后交换 `q1` 和 `q2`。 O(N)
*   **`empty()`:** 检查 `q1` 是否为空。O(1)

**使用一个队列 (`q`):**
*   **`push(x)`:**
    *   获取当前队列大小 `size = q.size()`。
    *   将 `x` 入队。
    *   将队列中原有的 `size` 个元素（在 `x` 前面的元素）依次出队，再重新入队。这样新元素 `x` 就到了队首。
    *   O(N)
*   **`pop()`:** 直接从队列 `q` 的队首出队。 O(1)
*   **`top()`:** 返回队列 `q` 的队首元素。 O(1)
*   **`empty()`:** 检查 `q` 是否为空。 O(1)

通常单队列法在 `push` 上耗时，双队列法在 `pop/top` 上耗时。题目一般不限制哪种，选择一种实现即可。我们选单队列法，因为它pop/top为O(1)。

**Python 实现 (单队列):**
```python
from collections import deque

class MyStack:
    def __init__(self):
        self.q = deque() # Using one queue

    def push(self, x: int) -> None:
        # Add the new element to the queue
        self.q.append(x)
        # Rotate the queue so that the new element becomes the front
        # All previous elements are moved from front to back, after x
        size = len(self.q)
        for _ in range(size - 1): # Rotate size-1 times
            self.q.append(self.q.popleft())

    def pop(self) -> int:
        # The front of the queue is the top of the stack
        if not self.empty():
            return self.q.popleft()
        return -1 # Or raise error, problem usually defines behavior

    def top(self) -> int:
        # The front of the queue is the top of the stack
        if not self.empty():
            return self.q[0]
        return -1 # Or raise error

    def empty(self) -> bool:
        return not self.q
```

**Java 实现 (单队列):**
```java
import java.util.LinkedList;
import java.util.Queue;

class MyStack {
    private Queue<Integer> q;

    public MyStack() {
        q = new LinkedList<>(); // Using one queue
    }
    
    // Push element x onto stack.
    public void push(int x) {
        // Add the new element to the queue
        q.offer(x);
        // Rotate the queue so that the new element becomes the front
        // All previous elements are moved from front to back, after x
        int size = q.size();
        for (int i = 0; i < size - 1; i++) { // Rotate size-1 times
            q.offer(q.poll());
        }
    }
    
    // Removes the element on top of the stack and returns that element.
    public int pop() {
        // The front of the queue is the top of the stack
        if (!empty()) {
            return q.poll();
        }
        throw new RuntimeException("Stack is empty"); // Or handle as per problem spec
    }
    
    // Get the top element.
    public int top() {
        // The front of the queue is the top of the stack
        if (!empty()) {
            return q.peek();
        }
        throw new RuntimeException("Stack is empty"); // Or handle
    }
    
    // Returns whether the stack is empty.
    public boolean empty() {
        return q.isEmpty();
    }
}
```

**复杂度分析 (单队列法):**
*   `push`: O(N)，N 是栈中元素数量，因为需要旋转队列。
*   `pop`: O(1)。
*   `top`: O(1)。
*   `empty`: O(1)。

**题目描述:**
给定一个包含 `n + 1` 个整数的数组 `nums` ，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。
假设 `nums` 中 **只存在一个重复的整数** ，返回 **这个重复的数** 。
你设计的解决方案必须 **不修改** 数组 `nums` 且只用常量级 O(1) 的额外空间。
进阶：时间复杂度小于 O(n^2)。

**解题思路 (快慢指针 - 类比链表环检测):**
可以将数组 `nums` 视为一个链表（或函数映射）。每个索引 `i` 指向 `nums[i]`。
由于数字范围是 `[1, n]` 且数组长度是 `n+1`，而索引范围是 `[0, n]`。
如果我们把 `nums[i]` 的值看作是下一个节点的 "索引" (需要映射到有效索引，例如 `value -> value` if indices allow, or some other transformation like `index -> nums[index]`).
Consider the sequence `x, nums[x], nums[nums[x]], ...`. Since all values are within `[1, n]` and there are `n+1` numbers, by pigeonhole principle, there must be a duplicate.
This also means the sequence must eventually form a cycle. The duplicate number is part of (or leads into) this cycle.

Floyd's Tortoise and Hare Algorithm:

class Solution {
    public int findDuplicate(int[] nums) {
        // Phase 1: Find the intersection point in the "cycle"
        // The "list" is formed by: index -> value -> value at that index ...
        // E.g., nums[0] is the "head", then nums[nums[0]] is next, etc.
        
        int tortoise = nums[0];
        int hare = nums[0]; // Initialize hare to the same start for loop structure
        
        // First step (do-while equivalent)
        // tortoise = nums[tortoise];
        // hare = nums[nums[hare]];
        // No, loop starts and then advances:
        
        do {
            tortoise = nums[tortoise]; // Tortoise moves one step
            hare = nums[nums[hare]];   // Hare moves two steps
        } while (tortoise != hare);
        
        // Phase 2: Find the entrance to the cycle
        // One pointer starts from the beginning of the "list" (nums[0])
        // The other starts from the intersection point (tortoise/hare)
        int ptr1 = nums[0];
        int ptr2 = tortoise; // or hare, as they are same here
        
        while (ptr1 != ptr2) {
            ptr1 = nums[ptr1];
            ptr2 = nums[ptr2];
        }
        
        return ptr1; // This value is the duplicate number
    }
}
```

### 167: [剑指 Offer 21. 调整数组顺序使奇数位于偶数前面 (LCOF)](https://leetcode.cn/problems/diao-zheng-shu-zu-shun-xu-shi-qi-shu-wei-yu-ou-shu-qian-mian-lcof)

**题目描述:**
输入一个整数数组，实现一个函数来调整该数组中数字的顺序，使得所有奇数在数组的前半部分，所有偶数在数组的后半部分。

**解题思路 (双指针):**
1.  初始化两个指针: `left = 0` (从头开始)，`right = nums.length - 1` (从尾开始)。
2.  当 `left < right` 时循环：
    a.  移动 `left` 指针向右，直到找到一个偶数 (`nums[left] % 2 == 0`).
    b.  移动 `right` 指针向左，直到找到一个奇数 (`nums[right] % 2 != 0`).
    c.  如果 `left < right` (确保指针未交叉)：
    *   交换 `nums[left]` 和 `nums[right]`。
    *   `left++`, `right--` (或者不移动，让下轮循环重新检查 `left` 和 `right` 指向的，交换后的新值). It's common to advance them after swap to avoid reprocessing the same (now correct) positions in next sub-iterations immediately.
3.  返回调整后的数组 `nums`。

**Python 实现:**
```python
class Solution:
    def exchange(self, nums: list[int]) -> list[int]:
        left, right = 0, len(nums) - 1
        
        while left < right:
            # Move left pointer to find an even number
            while left < right and nums[left] % 2 != 0: # nums[left] is odd
                left += 1
            
            # Move right pointer to find an odd number
            while left < right and nums[right] % 2 == 0: # nums[right] is even
                right -= 1
            
            # If pointers haven't crossed, swap
            if left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1
                
        return nums
```

**Java 实现:**
```java
class Solution {
    public int[] exchange(int[] nums) {
        int left = 0;
        int right = nums.length - 1;
        
        while (left < right) {
            // Move left pointer to find an even number
            while (left < right && nums[left] % 2 != 0) { // nums[left] is odd
                left++;
            }
            
            // Move right pointer to find an odd number
            while (left < right && nums[right] % 2 == 0) { // nums[right] is even
                right--;
            }
            
            // If pointers haven't crossed, swap
            if (left < right) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                left++;
                right--;
            }
        }
        return nums;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，每个指针最多遍历数组一次。
*   空间复杂度: O(1)。

### 168: [213. 打家劫舍 II (House Robber II)](https://leetcode.cn/problems/house-robber-ii)

**题目描述:**
你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都 **围成一圈** ，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警** 。
给定一个代表每个房屋存放金额的非负整数数组 `nums` ，计算你在不触动警报装置的情况下 ，今晚能够偷窃到的最高金额。

**解题思路:**
由于房屋围成一圈，第 0 间房和第 `n-1` 间房是相邻的，不能同时被偷。
这个问题可以分解为两个标准的“打家劫舍 I”问题：
1.  **情况 1: 不偷最后一间房 (`nums[n-1]`)**:
    那么可以在 `nums[0...n-2]` 范围内的房屋中进行偷窃（这里第 0 间和第 `n-2` 间不相邻）。
    应用“打家劫舍 I”算法到子数组 `nums[0...n-2]`。
2.  **情况 2: 不偷第一间房 (`nums`)**:
    那么可以在 `nums[1...n-1]` 范围内的房屋中进行偷窃（这里第 1 间和第 `n-1` 间不相邻）。
    应用“打家劫舍 I”算法到子数组 `nums[1...n-1]`。

最终的结果是这两种情况中能偷到的最大金额。

**特殊情况:**
*   如果 `n == 0`，返回 0。
*   如果 `n == 1`，返回 `nums`。 (没有相邻的房子，可以偷这间)。
    The two cases logic above naturally handles `n=1` if range is empty result is 0, `robRange([nums])` might be handled in helper.
    A good helper for House Robber I on a subarray `rob_linear(arr)`:
    If `len(nums) == 1`, `return nums`.
    Else, `max(rob_linear(nums[0...n-2]), rob_linear(nums[1...n-1]))`.

**Python 实现:**
```python
class Solution:
    def _rob_linear(self, sub_nums: list[int]) -> int:
        """Helper for House Robber I problem on a linear array."""
        n_sub = len(sub_nums)
        if n_sub == 0:
            return 0
        
        rob_prev2 = 0 # Max money robbing up to i-2 houses
        rob_prev1 = 0 # Max money robbing up to i-1 houses

        for current_money_in_house in sub_nums:
            temp_current_max = max(current_money_in_house + rob_prev2, rob_prev1)
            rob_prev2 = rob_prev1
            rob_prev1 = temp_current_max
        return rob_prev1

    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0] # Only one house, no circle constraint effectively
        
        # Case 1: Rob from houses 0 to n-2 (don't rob house n-1)
        max_if_not_rob_last = self._rob_linear(nums[:-1]) # nums[0...n-2]
        
        # Case 2: Rob from houses 1 to n-1 (don't rob house 0)
        max_if_not_rob_first = self._rob_linear(nums[1:]) # nums[1...n-1]
        
        return max(max_if_not_rob_last, max_if_not_rob_first)

```

**Java 实现:**
```java
class Solution {
    private int robLinear(int[] nums, int start, int end) {
        /** Helper for House Robber I on a linear subarray nums[start...end] inclusive. */
        if (start > end) { // Empty range
            return 0;
        }
        
        int robPrev2 = 0; // Max money robbing up to i-2 houses in the sub-array
        int robPrev1 = 0; // Max money robbing up to i-1 houses in the sub-array

        for (int i = start; i <= end; i++) {
            int currentMoneyInHouse = nums[i];
            int tempCurrentMax = Math.max(currentMoneyInHouse + robPrev2, robPrev1);
            robPrev2 = robPrev1;
            robPrev1 = tempCurrentMax;
        }
        return robPrev1;
    }

    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }
        if (n == 1) {
            return nums[0]; // Only one house
        }
        
        // Case 1: Rob from houses 0 to n-2 (don't rob house n-1)
        int maxIfNotRobLast = robLinear(nums, 0, n - 2);
        
        // Case 2: Rob from houses 1 to n-1 (don't rob house 0)
        int maxIfNotRobFirst = robLinear(nums, 1, n - 1);
        
        return Math.max(maxIfNotRobLast, maxIfNotRobFirst);
    }
}
```

*   时间复杂度: O(N)，调用两次 House Robber I 的辅助函数，每次 O(N)。
*   空间复杂度: O(1) (如果辅助函数也是空间优化的)。

### 169: [120. 三角形最小路径和 (Triangle)](https://leetcode.cn/problems/triangle)

**题目描述:**
给定一个三角形 `triangle` ，找出自顶向下的最小路径和。
每一步只能移动到下一行中相邻的结点上。**相邻的结点** 在这里指的是 **下标** 与 **上一层结点下标** 相同或者等于 **上一层结点下标 + 1** 的两个结点。也就是说，如果正位于当前行的下标 `i` ，那么下一步可以移动到下一行的下标 `i` 或 `i + 1` 。

**解题思路 (动态规划 - 自底向上):**
`dp[j]` (在一维DP中) 表示到达当前行第 `j` 个元素的最小路径和。
自底向上计算会更简单：`dp[j]` 表示从三角形底部到达第 `i` 行第 `j` 个元素的最小路径和。
但这题是自顶向下，所以从顶层到底层的某个点。
Let `dp[i][j]` be the minimum path sum to reach `triangle[i][j]`.
`dp[i][j] = triangle[i][j] + min(dp[i-1][j], dp[i-1][j-1])` (with boundary checks).

**自底向上优化 (原地修改/O(N)空间):**
Let `dp[j]` represent the minimum path sum ending at `triangle[row][j]` if we only consider rows up to current `row`. Or, even better, `dp[j]` means min path sum from `triangle[current_row][j]` *to the bottom*.
Let `dp` be an array representing the minimum path sums for the *last processed row*.
Initialize `dp` with the values of the last row of the triangle.
Then, iterate upwards from the second to last row (`row = n-2` down to `0`):
For each element `triangle[row][j]`:
`dp[j] = triangle[row][j] + min(dp[j], dp[j+1])` (where current `dp[j]` and `dp[j+1]` are from the row below).
The final result will be `dp`.

Let's stick to standard DP definition (min sum from top to `(i,j)`) with O(N) space.
`dp[j]` stores the minimum sum to reach column `j` of the *current* row.
When computing for `row i` (from `row i-1`'s `dp_prev` values):
`current_dp[j] = triangle[i][j] + min(dp_prev[j], dp_prev[j-1])`
The calculation must be done carefully if `dp_prev` is updated in place for current row.
E.g., if iterating `j` from left to right, `dp[j-1]` would be `current_dp[j-1]`. Need to iterate `j` from right to left.
`dp[j] = triangle[i][j] + min(dp_old_j, dp_old_j_minus_1)`
For `current_row[j]`:
`dp[j] = min(dp[j], dp[j-1]) + current_row[j]`. This update order needs care.
`dp[j]` needs previous `dp[j]` and `dp[j-1]`.
`dp` updated first. `dp[j]` update needs `old_dp[j]` and `old_dp[j-1]`.
So, if `j` loop is from `num_elements_in_row - 1` down to `1`:
`dp[j] = min(dp[j], dp[j-1]) + triangle[row][j]`
And `dp = dp + triangle[row]`

**Python 实现 (O(N) space, N = num rows):**
```python
class Solution:
    def minimumTotal(self, triangle: list[list[int]]) -> int:
        num_rows = len(triangle)
        if num_rows == 0:
            return 0
        
        # dp array to store min path sums for the current row being processed.
        # Its size is the number of elements in the last row.
        # Initialize with a copy of the first row (or just use it and start from second row)
        # More robust: dp size max_cols = num_rows
        dp = [0] * num_rows 

        # Base case: first row
        if num_rows > 0:
            dp[0] = triangle[0][0]

        # Iterate from the second row
        for r in range(1, num_rows):
            # Iterate from right to left for columns in current row
            # This is to use dp[j] and dp[j-1] from the *previous* row calculation correctly.
            num_cols_curr_row = len(triangle[r]) # which is r + 1
            for c in range(num_cols_curr_row - 1, -1, -1):
                val_curr_cell = triangle[r][c]
                if c == num_cols_curr_row - 1: # Rightmost element in current row
                    # Can only come from the rightmost element of previous row (index c-1)
                    dp[c] = dp[c-1] + val_curr_cell
                elif c == 0: # Leftmost element in current row
                    # Can only come from the leftmost element of previous row (index c)
                    dp[c] = dp[c] + val_curr_cell
                else:
                    # Can come from dp[c-1] or dp[c] of previous row
                    dp[c] = min(dp[c-1], dp[c]) + val_curr_cell
        
        # The result is the minimum value in the dp array (last row's path sums)
        min_sum_in_last_row = float('inf')
        for c in range(num_rows): # Iterate through all possible end points in the last row
             min_sum_in_last_row = min(min_sum_in_last_row, dp[c])
        
        return min_sum_in_last_row

class SolutionBottomUp:
    def minimumTotal(self, triangle: list[list[int]]) -> int:
        num_rows = len(triangle)
        if num_rows == 0:
            return 0
        
        # dp array representing min sums from bottom starting at current row
        # Initialize with the last row of the triangle
        dp = list(triangle[num_rows - 1]) # Make a copy
        
        # Iterate upwards from the second to last row
        for r in range(num_rows - 2, -1, -1):
            for c in range(len(triangle[r])):
                # Min path sum from triangle[r][c] is its value + min of paths from children in row r+1
                # Children are at dp[c] and dp[c+1] from the row below (which is currently stored in dp)
                dp[c] = triangle[r][c] + min(dp[c], dp[c+1])
        
        # The top element dp[0] will contain the overall minimum path sum
        return dp[0]
```
The bottom-up approach (`SolutionBottomUp`) is generally simpler to implement and understand for this problem using O(N_last_row_cols) space.

**Java 实现 (Bottom-up O(N_last_row_cols) space):**
```java
import java.util.List;
import java.util.ArrayList; // if needed
import java.util.Arrays; // if needed for initialization

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int numRows = triangle.size();
        if (numRows == 0) {
            return 0;
        }

        // dp array to store min path sums from bottom.
        // Size is number of elements in the last row, or numRows.
        int[] dp = new int[numRows];

        // Initialize dp with the values of the last row
        List<Integer> lastRow = triangle.get(numRows - 1);
        for (int c = 0; c < lastRow.size(); c++) {
            dp[c] = lastRow.get(c);
        }

        // Iterate upwards from the second to last row
        for (int r = numRows - 2; r >= 0; r--) {
            List<Integer> currentRow = triangle.get(r);
            for (int c = 0; c < currentRow.size(); c++) {
                // Min path sum from triangle[r][c] is its value + min of paths from its children in row r+1
                // Children's min sums (from their pos to bottom) are currently in dp[c] and dp[c+1]
                dp[c] = currentRow.get(c) + Math.min(dp[c], dp[c+1]);
            }
        }
        
        // The top element dp[0] will contain the overall minimum path sum from top to bottom
        return dp[0];
    }
}
```

**复杂度分析 (Bottom-up):**
*   时间复杂度: O(N^2) (where N is total number of rows, number of elements is ~N^2/2). Each element visited once.
*   空间复杂度: O(N) (where N is number of rows, for `dp` array of size of last row).

### 170: [887. 鸡蛋掉落 (Super Egg Drop)](https://leetcode.cn/problems/super-egg-drop)

**题目描述:**
给你 `k` 枚相同的鸡蛋，并可以使用一栋从 `1` 到 `n` 共有 `n` 层楼的建筑。
如果一枚鸡蛋从高楼的第 `x` 层扔下，满足 `0 <= f <= n` 的楼层 `f` 会导致 яйцо碎掉。已知存在楼层 `f` ，满足 `0 <= f <= n`：
*   在 `f` 层以下的楼层扔鸡蛋，鸡蛋 **不会碎** 。
*   在 `f` 层以及 `f` 层以上的楼层扔鸡蛋，鸡蛋 **会碎** 。
    每次操作，你可以取一枚鸡蛋，并在楼层 `x` 扔下。如果鸡蛋碎了，你不能再次使用它。如果没碎，你可以继续使用这枚鸡蛋。
    你需要确定这个 `f` 值。返回你确定 `f` 值所需的 **最小操作次数（也就是最少扔的次数）** 。

**解题思路 (动态规划):**
This is a notoriously hard DP problem.
Let `dp[m][k]` be the maximum number of floors `N` we can check with `k` eggs and `m` moves (drops).
Our goal is to find the smallest `m` such that `dp[m][k] >= n`.

**State transition for `dp[m][k]`**:
If we drop an egg from some floor `x` with `m` moves and `k` eggs:
1.  **Egg breaks**: We have `k-1` eggs left and `m-1` moves left. We need to check floors below `x`. The number of floors we can check below is `dp[m-1][k-1]`. So these are floors `1` to `dp[m-1][k-1]` relative to the subproblem.
2.  **Egg doesn't break**: We have `k` eggs left and `m-1` moves left. We need to check floors above `x`. The number of floors we can check above is `dp[m-1][k]`. So these are floors `1` to `dp[m-1][k]` relative to the subproblem.
    So, from floor `x`, we can identify the status of `dp[m-1][k-1]` (below x) + `1` (floor x itself) + `dp[m-1][k]` (above x) floors.
    `dp[m][k] = dp[m-1][k-1] + 1 + dp[m-1][k]`

**Base Cases:**
*   `dp[m] = m` (If only 1 egg, we must drop linearly from floor 1 up to m, can check m floors).
*   `dp[k] = 1` (If only 1 move, can only check 1 floor regardless of eggs > 0).

Iterate `m` from 1 upwards. For each `m`, compute `dp[m][j]` for `j` from 1 to `k`.
Stop when `dp[m][k] >= n`. That `m` is the answer.

**Python 实现:**
```python
class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        # dp[m][eggs] = max floors we can check with 'm' moves and 'eggs' eggs.
        # We want to find min 'm' such that dp[m][k] >= n.
        
        # dp array will actually store dp[eggs_count] for the current number of moves 'm'.
        # So, dp_current[eggs_count] = max floors checkable with 'm' moves & 'eggs_count' eggs.
        # dp_prev[eggs_count] = max floors checkable with 'm-1' moves & 'eggs_count' eggs.
        
        # dp[eggs_count] after 'm' moves. Size k+1.
        dp = [0] * (k + 1) 
        moves = 0
        
        # dp[moves][j] value for 'j' eggs.
        # When moves = 0, dp[0][any_egg_count] = 0 floors. This is implicit.
        
        while dp[k] < n: # While max floors checkable with 'k' eggs and 'moves' moves is less than 'n'
            moves += 1
            # Calculate for current 'moves' using values from 'moves-1'
            # Need to iterate backwards for eggs to use dp[j-1] from 'moves-1' state.
            # dp_new[j] = dp_old[j-1] (egg breaks) + 1 + dp_old[j] (egg survives)
            for eggs_count in range(k, 0, -1): # From k eggs down to 1 egg
                # dp[eggs_count] here refers to 'm-1' moves result before update.
                # dp[eggs_count-1] here refers to 'm-1' moves result for one less egg.
                dp[eggs_count] = dp[eggs_count] + dp[eggs_count - 1] + 1
                # If dp[eggs_count-1] hasn't been updated for this 'moves' iteration, this is fine.
                # Iterating eggs_count from k down to 1 ensures that when calculating dp[eggs_count],
                # dp[eggs_count-1] is still the value from the (moves-1)th iteration.
                
        return moves
```

**Java 实现:**```java
class Solution {
public int superEggDrop(int k, int n) {
// dp[eggs] will store the maximum number of floors we can check
// with the current number of moves ('moves') and 'eggs' eggs.
// dp[j] = max floors for 'moves' moves and 'j' eggs.
int[] dp = new int[k + 1]; // dp[0] is implicitly 0 (0 eggs, 0 floors)

        int moves = 0;
        
        // Loop until dp[k] (max floors checkable with k eggs and 'moves' moves) >= n
        while (dp[k] < n) {
            moves++;
            // Iterate from k eggs down to 1 egg.
            // This is important because dp[eggsCount] for the current 'moves' calculation
            // needs dp[eggsCount-1] from the *previous* 'moves' iteration (or for fewer eggs in current iter).
            // And dp[eggsCount] itself from previous 'moves' iteration.
            // dp_new[j] = dp_old[j] (egg survives) + dp_old[j-1] (egg breaks) + 1 (current floor tested)
            for (int eggsCount = k; eggsCount >= 1; eggsCount--) {
                // dp[eggsCount] before this line is from 'moves-1' using 'eggsCount' eggs.
                // dp[eggsCount-1] before this line is from 'moves-1' using 'eggsCount-1' eggs
                // (or already updated for current 'moves' if eggsCount-1 was > current loop iter's start for eggsCount.
                // But since loop goes k down to 1, dp[eggsCount-1] means 'm' moves and 'eggs-1' if we're thinking that way.
                // Let's clarify: dp[j] will be dp for `moves` for `j` eggs
                // it uses dp[j] for `moves-1` with `j` eggs, and dp[j-1] for `moves-1` with `j-1` eggs.
                // The array update logic `dp[j] = ... dp[j] + dp[j-1]` when iterating `j` downwards
                // uses `dp[j]` (value from `moves-1, j eggs`) and `dp[j-1]` (value from `moves-1, j-1 eggs`).
                dp[eggsCount] = dp[eggsCount] + dp[eggsCount - 1] + 1;
            }
        }
        
        return moves;
    }
}
```
The `dp` state definition here (`dp[j]` stores max floors for `j` eggs with current `moves`) works.
When calculating for `moves`:
`dp[j]` at the start of the inner loop = value from `(moves-1)` using `j` eggs.
`dp[j-1]` = value from `(moves-1)` using `j-1` eggs.
The update correctly reflects `dp_curr_moves[j_eggs] = dp_prev_moves[j_eggs] + dp_prev_moves[j_eggs-1] + 1`.
This iteration order is crucial for O(K) space.

**Alternative DP (Harder to optimize space for):**
`dp[i][j]` = min moves for `i` eggs and `j` floors.
`dp[i][j] = 1 + min over x from 1 to j ( max(dp[i-1][x-1], dp[i][j-x]) )`
This leads to O(K * N^2) or O(K * N log N) with binary search on `x`.
The `dp[m][k] = N` formulation is better.

**Complexity Analysis (for `dp[m][k]=N` formulation with O(K) space):**
*   时间复杂度: O(K * M)，where M is the answer (number of moves). In the worst case, M can be N (if K=1). So, it can be up to O(K*N). But for larger K, M is roughly O(log N). Maximum value for `k` is about 100. `n` up to 10000. Max moves for `k=1, n=10000` is `10000`. `k=2, n=10000`, moves around `sqrt(2n)` ~ 141. For larger `k`, moves is like `log_2(n)`. So it's efficient. Max moves M is `N`. `sum_{m=1 to M} K = K*M`.
*   空间复杂度: O(K).
