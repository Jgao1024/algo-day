### 151: [剑指 Offer 04. 二维数组中的查找 (Search a 2D Matrix II - LeetCode 240)](https://leetcode.cn/problems/er-wei-shu-zu-zhong-de-cha-zhao-lcof)

**题目描述:**
在一个 n x m 的二维数组中，每一行都按照从左到右递增的顺序排序，每一列都按照从上到下递增的顺序排序。请完成一个高效的函数，输入这样的一个二维数组和一个整数，判断数组中是否含有该整数。

**解题思路:**
利用矩阵的行列单调性。
1.  选择矩阵的右上角元素 `matrix[row][col]` (或者左下角)作为起始点。
    *   当前行 `row = 0`，当前列 `col = m - 1`。
2.  当 `row < n` 且 `col >= 0` 时，循环比较当前元素 `matrix[row][col]` 与 `target`：
    *   如果 `matrix[row][col] == target`，则找到目标，返回 `true`。
    *   如果 `matrix[row][col] > target`，说明当前元素偏大。由于当前列下方的元素都更大，当前行左边的元素都更小，所以目标值不可能在当前列，应向左移动：`col--`。
    *   如果 `matrix[row][col] < target`，说明当前元素偏小。由于当前行左边的元素都更小，当前列上方的元素都更小，所以目标值不可能在当前行，应向下移动：`row++`。
3.  如果循环结束仍未找到，说明目标不存在，返回 `false`。

**Python 实现:**
```python
class Solution:
    def findNumberIn2DArray(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        
        rows = len(matrix)
        cols = len(matrix[0])
        
        row, col = 0, cols - 1 # Start from top-right corner
        
        while row < rows and col >= 0:
            current_val = matrix[row][col]
            if current_val == target:
                return True
            elif current_val > target:
                col -= 1 # Target is smaller, move left
            else: # current_val < target
                row += 1 # Target is larger, move down
                
        return False
```

**Java 实现:**
```java
class Solution {
    public boolean findNumberIn2DArray(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }
        
        int rows = matrix.length;
        int cols = matrix[0].length;
        
        int row = 0;
        int col = cols - 1; // Start from top-right corner
        
        while (row < rows && col >= 0) {
            int currentVal = matrix[row][col];
            if (currentVal == target) {
                return true;
            } else if (currentVal > target) {
                col--; // Target is smaller, move left
            } else { // currentVal < target
                row++; // Target is larger, move down
            }
        }
        return false;
    }
}
```

**复杂度分析:**
*   时间复杂度: O(M + N)，其中 M 是行数，N 是列数。每次比较，行指针或列指针都会移动，最多移动 M+N 次。
*   空间复杂度: O(1)。

### 152: [10. 正则表达式匹配 (Regular Expression Matching)](https://leetcode.cn/problems/regular-expression-matching)

**题目描述:**
给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配。
*   `'.'` 匹配任意单个字符
*   `'*'` 匹配零个或多个前面的那一个元素
    所谓匹配，是要涵盖 **整个** 字符串 `s` 的，而不是部分字符串。

**解题思路 (动态规划):**
定义 `dp[i][j]` 表示字符串 `s` 的前 `i` 个字符 (`s[0...i-1]`) 是否能被模式 `p` 的前 `j` 个字符 (`p[0...j-1]`) 匹配。

1.  **DP Table Size**: `dp` table 的大小为 `(len(s) + 1) x (len(p) + 1)`.
2.  **Base Case**:
    *   `dp = true` (空字符串匹配空模式)。
    *   `dp[j]` (空字符串 `s` 匹配模式 `p` 的前 `j` 个字符)：
        *   如果 `p[j-1]` 是 `'*'`，则它可以匹配零个前面的元素 `p[j-2]`。此时 `dp[j] = dp[j-2]`。
        *   否则 (非 `'*'` 或 `p[j-2]*` 无法匹配空串)，`dp[j] = false`。

3.  **Transitions** for `i > 0, j > 0`:
    *   **If `p[j-1]` is NOT `'*'`**:
        *   `dp[i][j] = dp[i-1][j-1]` IF `s[i-1]` matches `p[j-1]` (i.e., `s[i-1] == p[j-1]` or `p[j-1] == '.'`).
        *   Else `dp[i][j] = false`.
    *   **If `p[j-1]` IS `'*'`**:
        Let `prev_char_in_p = p[j-2]`. The `*` applies to `prev_char_in_p`.
        `p[j-2]*` can match:
        *   **Zero occurrences of `prev_char_in_p`**: In this case, `p[j-2]*` is effectively ignored. `dp[i][j] = dp[i][j-2]`.
        *   **One or more occurrences of `prev_char_in_p`**: In this case, `s[i-1]` must match `prev_char_in_p`. If it does, then `p[j-2]*` matches `s[i-1]` and potentially previous characters. We look at `dp[i-1][j]` (meaning `p[0...j-1]` matches `s[0...i-2]`).
            So, if `s[i-1]` matches `p[j-2]` (i.e., `s[i-1] == p[j-2]` or `p[j-2] == '.'`), then `dp[i][j]` can also be `dp[i-1][j]`.
        *   Combine these: `dp[i][j] = dp[i][j-2]` (zero occurrences) `OR` ( `matches(s[i-1], p[j-2]) AND dp[i-1][j]` (one or more occurrences)).

4.  The final answer is `dp[len(s)][len(p)]`.

**Python 实现:**
```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        # dp[i][j] will be true if s[0..i-1] matches p[0..j-1]
        dp = [[False] * (n + 1) for _ in range(m + 1)]

        # Base cases
        dp[0][0] = True  # Empty s and empty p match

        # dp[0][j]: s is empty, p is not.
        # Only p like a*, a*b*, a*b*c* can match empty s
        for j in range(1, n + 1):
            if p[j-1] == '*':
                # '*' can match zero preceding elements
                dp[0][j] = dp[0][j-2] 

        # Fill the dp table
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                s_char = s[i-1]
                p_char = p[j-1]

                if p_char != '*':
                    # Current p_char is a literal or '.'
                    if s_char == p_char or p_char == '.':
                        dp[i][j] = dp[i-1][j-1]
                else: # p_char is '*'
                    # '*' applies to p[j-2]
                    p_prev_char = p[j-2] 
                    
                    # Option 1: '*' matches zero of p_prev_char
                    # In this case, p[0...j-1] matches s[0...i-1] if p[0...j-3] matches s[0...i-1]
                    if dp[i][j-2]:
                        dp[i][j] = True
                    # Option 2: '*' matches one or more of p_prev_char
                    # If s_char matches p_prev_char, and p[0...j-1] (with '*' acting on p_prev_char)
                    # matches s[0...i-2] (i.e. s up to its previous char)
                    elif s_char == p_prev_char or p_prev_char == '.':
                        dp[i][j] = dp[i-1][j]
        
        return dp[m][n]

```

**Java 实现:**
```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length();
        int n = p.length();
        // dp[i][j] will be true if s.substring(0, i) matches p.substring(0, j)
        boolean[][] dp = new boolean[m + 1][n + 1];

        // Base cases
        dp[0][0] = true; // Empty s and empty p match

        // dp[0][j]: s is empty, p is not.
        // Only p like a*, a*b*, a*b*c* can match empty s
        for (int j = 1; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                // '*' can match zero preceding elements (if j >= 2 for p.charAt(j-2))
                if (j >= 2) { // Make sure there is a char before '*'
                     dp[0][j] = dp[0][j - 2];
                }
            }
        }

        // Fill the dp table
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char sChar = s.charAt(i - 1);
                char pChar = p.charAt(j - 1);

                if (pChar != '*') {
                    // Current pChar is a literal or '.'
                    if (sChar == pChar || pChar == '.') {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                } else { // pChar is '*'
                    // '*' applies to p.charAt(j - 2)
                    // Make sure there is a char before '*'
                    if (j < 2) continue; // '*' cannot be the first char of pattern or not preceded by char

                    char pPrevChar = p.charAt(j - 2);
                    
                    // Option 1: '*' matches zero of pPrevChar
                    // e.g., s="a", p="ab*c" -> "ac". dp[i][j] depends on dp[i][j-2]
                    if (dp[i][j - 2]) {
                        dp[i][j] = true;
                    }
                    // Option 2: '*' matches one or more of pPrevChar
                    // e.g., s="aa", p="a*". sChar must match pPrevChar.
                    // And dp[i-1][j] means s up to prev char matches p up to current including *
                    else if (sChar == pPrevChar || pPrevChar == '.') {
                        dp[i][j] = dp[i - 1][j];
                    }
                }
            }
        }
        return dp[m][n];
    }
}
```

**复杂度分析:**
*   时间复杂度: O(S * P)，其中 S是字符串s的长度, P是模式p的长度。
*   空间复杂度: O(S * P)，用于DP表。

### 153: [剑指 Offer 10- I. 斐波那契数列 (Fibonacci Number)](https://leetcode.cn/problems/fei-bo-na-qi-shu-lie-lcof)

**题目描述:**
写一个函数，输入 n ，求斐波那契（Fibonacci）数列的第 n 项（即 F(N)）。斐波那契数列的定义如下：
F(0) = 0, F(1) = 1
F(N) = F(N-1) + F(N-2), 其中 N > 1.
斐波那契数列由 0 和 1 开始，之后的斐波那契数就是由之前的两数相加而得出。
答案需要取模 1e9+7（1000000007），如计算初始结果为：1000000008，请返回 1。

**解题思路 (迭代DP):**
1.  处理边界情况：
    *   If `n == 0`, return 0.
    *   If `n == 1`, return 1.
2.  初始化 `a = 0` (F(0)), `b = 1` (F(1)).
3.  从 `i = 2` 循环到 `n`:
    *   `current_fib = (a + b) % 1000000007`
    *   `a = b`
    *   `b = current_fib`
4.  返回 `b` (如果n>1) or the base case results. The loop structure should naturally lead to `b` storing F(n).
    A better loop state would be: `a` stores F(i-2), `b` stores F(i-1). Compute F(i).

**Python 实现:**
```python
class Solution:
    def fib(self, n: int) -> int:
        if n == 0:
            return 0
        if n == 1:
            return 1
        
        MOD = 1000000007
        
        # F(0) F(1)
        a, b = 0, 1 
        
        for _ in range(2, n + 1): # Iterate to calculate F(2) up to F(n)
            current_fib = (a + b) % MOD
            a = b
            b = current_fib
            
        return b
```

**Java 实现:**
```java
class Solution {
    public int fib(int n) {
        if (n == 0) {
            return 0;
        }
        if (n == 1) {
            return 1;
        }
        
        final int MOD = 1000000007;
        
        int a = 0; // Represents F(i-2)
        int b = 1; // Represents F(i-1)
        int currentFib = 0;
        
        for (int i = 2; i <= n; i++) {
            currentFib = (a + b) % MOD;
            a = b;
            b = currentFib;
        }
        
        return b; // b now holds F(n)
    }
}
```

**复杂度分析:**
*   时间复杂度: O(N)，线性扫描。
*   空间复杂度: O(1)。

### 154: 补充题2. 圆环回原点问题

**题目描述 (来自分析):**
圆环上有 `n` 个点，编号从 `0` 到 `n-1`。一个指针最初在 `0` 点。每一步，指针可以顺时针或逆时针移动一个单位。问 `k` 步后，指针回到 `0` 点的方案数有多少种？(结果可能需要取模，假设MOD=1e9+7 if not specified otherwise).

**解题思路 (动态规划):**
Let `dp[i][j]` be the number of ways to reach point `j` on the circle in exactly `i` steps.
Points are `0, 1, ..., n-1`.
`dp` table size: `(k+1) x n`.

1.  **Base Case**:
    *   `dp = 1` (at 0 steps, 1 way to be at position 0).
    *   `dp[j] = 0` for `j > 0`.
2.  **Transitions** for `steps` from `1` to `k`, and for each `position` from `0` to `n-1`:
    To reach `position` in `steps` steps, one must have been at `(position - 1 + n) % n` (left neighbor) or `(position + 1) % n` (right neighbor) in `steps - 1` steps.
    *   `dp[steps][position] = (dp[steps-1][(position - 1 + n) % n] + dp[steps-1][(position + 1) % n]) % MOD`
3.  The final answer is `dp[k]`.

**Space Optimization:**
Since `dp[steps]` only depends on `dp[steps-1]`, we can optimize space to O(N) using two arrays (current and previous step's DP states) or by updating in place carefully.

**Python 实现 (O(N) space):**
```python
class SolutionCircleSteps: # Placeholder class name
    def countWaysToOrigin(self, n_points: int, k_steps: int, MOD: int = 1000000007) -> int:
        if n_points <= 0 or k_steps < 0:
            return 0
        if n_points == 1: # If only one point, always at origin
            return 1 
        
        # dp[j] will store the number of ways to reach point j in the current number of steps
        dp_current = [0] * n_points
        dp_current[0] = 1 # Base case: 0 steps, at point 0 in 1 way

        for step in range(1, k_steps + 1):
            dp_prev = list(dp_current) # Copy previous state
            for pos in range(n_points):
                left_neighbor = (pos - 1 + n_points) % n_points
                right_neighbor = (pos + 1) % n_points
                
                dp_current[pos] = (dp_prev[left_neighbor] + dp_prev[right_neighbor]) % MOD
        
        return dp_current[0]

```

### 155: [328. 奇偶链表 (Odd Even Linked List)](https://leetcode.cn/problems/odd-even-linked-list)

**题目描述:**
给定单链表的头节点 `head` ，将所有索引为奇数的节点和索引为偶数的节点分别组合在一起，然后重新连接起来，使得奇数节点位于偶数节点之前。第一个节点的索引视为奇数，第二个节点的索引视为偶数，以此类推。
请注意，链表节点的顺序应保持不变。即：在奇数节点组内和偶数节点组内，它们的相对顺序应与输入中的相对顺序相同。
你需要 O(1) 的额外空间复杂度和 O(n) 的时间复杂度。

**解题思路:**
1.  处理边界：如果链表为空、只有一个节点或只有两个节点，无需操作，直接返回 `head`。
2.  创建指针：
    *   `odd_ptr`: 指向当前奇数链表的尾部，初始为 `head`。
    *   `even_head`: 指向偶数链表的头部，初始为 `head.next`。
    *   `even_ptr`: 指向当前偶数链表的尾部，初始为 `head.next`。
3.  迭代处理节点：
    当 `even_ptr` 和 `even_ptr.next` 都不为空时 (确保有奇数节点可以连接到 `odd_ptr`，并且有下一个偶数节点可以连接到 `even_ptr`)：
    *   `odd_ptr.next = even_ptr.next` (连接奇数链表尾到下一个奇数节点)。
    *   `odd_ptr = odd_ptr.next` (移动奇数链表尾指针)。
    *   `even_ptr.next = odd_ptr.next` (连接偶数链表尾到下一个偶数节点)。
    *   `even_ptr = even_ptr.next` (移动偶数链表尾指针)。
4.  连接奇数链表和偶数链表：
    *   `odd_ptr.next = even_head`。
5.  返回 `head`。

**Python 实现:**
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def oddEvenList(self, head: ListNode) -> ListNode:
        if not head or not head.next or not head.next.next:
            return head
        
        odd_ptr = head
        even_head = head.next
        even_ptr = head.next
        
        while even_ptr and even_ptr.next:
            # Link next odd node
            odd_ptr.next = even_ptr.next
            odd_ptr = odd_ptr.next
            
            # Link next even node
            even_ptr.next = odd_ptr.next # which is the node after the newly linked odd_ptr
            even_ptr = even_ptr.next
            
        # Connect the tail of the odd list to the head of the even list
        odd_ptr.next = even_head
        
        return head
```

### 156: [347. 前 K 个高频元素 (Top K Frequent Elements)](https://leetcode.cn/problems/top-k-frequent-elements)

**题目描述:**
给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按任意顺序返回答案。

**解题思路:**
1.  **统计频率**: 使用哈希表 (HashMap) 统计数组中每个元素的出现频率。
2.  **找出前 K 个高频元素**:
    *   **方法 A: 最小堆 (Min-Heap)**
        *   创建一个大小为 K 的最小堆，堆中存储 `(frequency, element)` 对，按 `frequency` 比较。
        *   遍历哈希表中的频率项：
            *   如果堆的大小小于 K，直接将当前项加入堆。
            *   如果堆的大小等于 K，比较当前项的频率与堆顶元素的频率。如果当前项频率更高，则弹出堆顶，加入当前项。
        *   最终堆中剩下的 K 个元素就是所求。
        *   时间复杂度: O(N + M log K)，其中 N 是 `nums` 长度，M 是不同元素的数量。构建频率表 O(N)。遍历M个不同元素，堆操作O(log K)。
    *   **方法 B: 桶排序 (Bucket Sort)**
        *   频率的范围是 `[1, len(nums)]`。创建一个桶数组，`buckets[freq]` 存储所有频率为 `freq` 的元素列表。
        *   遍历哈希表中的频率项，将元素放入对应的频率桶中。
        *   从后向前 (高频到低频) 遍历桶数组，收集元素，直到收集满 K 个。
        *   时间复杂度: O(N)，构建频率表 O(N)。将M个不同元素放入桶 O(M)。遍历桶收集 O(N) (桶数组最大长度N+1, 遍历一遍)。
        *   空间复杂度: O(N)，频率表和桶数组。

**Python 实现 (最小堆):**
```python
import collections
import heapq

class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        # 1. Count frequencies
        if not nums:
            return []
        counts = collections.Counter(nums) # O(N)
        
        # 2. Use a min-heap to find top k frequent elements
        # Heap stores (frequency, element)
        min_heap = []
        for element, freq in counts.items(): # O(M) unique elements
            if len(min_heap) < k:
                heapq.heappush(min_heap, (freq, element)) # O(log K)
            elif freq > min_heap[0][0]: # If current element's freq is higher than smallest in heap
                heapq.heapreplace(min_heap, (freq, element)) # O(log K)
                
        # Extract elements from the heap
        top_k_elements = [item[1] for item in min_heap] # O(K)
        return top_k_elements
```

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.List;
import java.util.ArrayList;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. Count frequencies
        if (nums == null || nums.length == 0) {
            return new int[0];
        }
        Map<Integer, Integer> counts = new HashMap<>();
        for (int num : nums) {
            counts.put(num, counts.getOrDefault(num, 0) + 1);
        }
        
        // 2. Use a min-heap to find top k frequent elements
        // Heap stores (element, frequency) but compares by frequency.
        // For min-heap based on frequency: (freq, element)
        PriorityQueue<Map.Entry<Integer, Integer>> minHeap = 
            new PriorityQueue<>((a, b) -> a.getValue() - b.getValue()); // Compare by frequency

        for (Map.Entry<Integer, Integer> entry : counts.entrySet()) {
            if (minHeap.size() < k) {
                minHeap.offer(entry);
            } else if (entry.getValue() > minHeap.peek().getValue()) {
                minHeap.poll();
                minHeap.offer(entry);
            }
        }
        
        // Extract elements from the heap
        int[] result = new int[k];
        int i = 0;
        while (!minHeap.isEmpty()) {
            result[i++] = minHeap.poll().getKey();
        }
        // The result array might be in ascending order of frequency; the problem allows any order.
        // If strict descending order is needed, additional sort or careful extraction required.
        return result;
    }
}
```

*   空间复杂度: O(M + K) (HashMap M, Heap K).

**题目描述:**
**Trie**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补完和拼写检查。

*   `Trie()` 初始化前缀树对象。
*   `void insert(String word)` 向前缀树中插入字符串 `word` 。
*   `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false` 。

**解题思路:**
1.  **TrieNode 类**:
    *   `children`: 一个字典 (或大小为26的数组，如果只考虑小写字母) 映射字符到子 `TrieNode`。
    *   `isEndOfWord`: 一个布尔值，标记当前节点是否代表一个完整单词的结束。
2.  **Trie 类**:
    *   `root`: 一个 `TrieNode` 对象，作为树的根。
    *   **`insert(word)`**:
        *   从 `root` 开始，遍历 `word` 中的每个字符。
        *   对于每个字符，如果当前节点的 `children` 中不存在该字符对应的子节点，则创建一个新的 `TrieNode` 并添加。
        *   移动到该子节点。
        *   单词遍历结束后，将最后一个节点的 `isEndOfWord` 标记为 `true`。
    *   **`search(word)`**:
        *   从 `root` 开始，遍历 `word` 中的每个字符。
        *   对于每个字符，如果当前节点的 `children` 中不存在该字符对应的子节点，说明单词不存在，返回 `false`。
        *   移动到该子节点。
        *   单词遍历结束后，检查最后一个节点的 `isEndOfWord` 是否为 `true`。
    *   **`startsWith(prefix)`**:
        *   与 `search` 类似，从 `root` 开始遍历 `prefix` 中的每个字符。
        *   如果中途找不到对应子节点，返回 `false`。
        *   如果 `prefix` 遍历完成，说明存在以此为前缀的单词，返回 `true`。

**Python 实现:**
```python
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_end_of_word = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for char in word:
            if char not in curr.children:
                curr.children[char] = TrieNode()
            curr = curr.children[char]
        curr.is_end_of_word = True
        
    def search(self, word: str) -> bool:
        curr = self.root
        for char in word:
            if char not in curr.children:
                return False
            curr = curr.children[char]
        return curr.is_end_of_word

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for char in prefix:
            if char not in curr.children:
                return False
            curr = curr.children[char]
        return True

```

### 158: [230. 二叉搜索树中第K小的元素 (Kth Smallest Element in a BST)](https://leetcode.cn/problems/kth-smallest-element-in-a-bst)

**题目描述:**
给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**解题思路:**
**方法1: 中序遍历 (In-order Traversal)**
1.  BST的中序遍历结果是一个递增序列。
2.  执行中序遍历，并将节点值存储在一个列表中。
3.  返回列表中的第 `k-1` 个元素 (0-indexed)。
    *   时间: O(N) to traverse all nodes. 空间: O(N) for list + O(H) for recursion stack (H is height).

**方法2: 迭代式中序遍历 + 提前终止**
1.  使用栈进行迭代式中序遍历。
2.  在访问（从栈中弹出并处理）一个节点时，递减 `k`。
3.  当 `k` 变为 0 时，当前访问的节点就是第 K 小的元素，返回其值。
    *   时间: O(H + K) on average (H to reach first smallest, K to find Kth). Worst case O(N).
    *   空间: O(H) for stack.

**Python 实现 (迭代式中序遍历):**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def kthSmallest(self, root: TreeNode, k: int) -> int:
        stack = []
        curr = root
        count = 0 # How many elements visited so far

        while curr or stack:
            # Go left as much as possible
            while curr:
                stack.append(curr)
                curr = curr.left
            
            # Current curr is None, pop from stack (this is the next smallest)
            node_to_visit = stack.pop()
            count += 1
            
            if count == k:
                return node_to_visit.val
            
            # Move to the right subtree
            curr = node_to_visit.right
            
        return -1 # Should not happen if k is valid and tree is not empty
```

**Java 实现 (迭代式中序遍历):**

```java
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

    public int kthSmallest(TreeNode root, int k) {
        Stack<TreeNode> stack = new Stack<>();
        TreeNode curr = root;
        int count = 0;

        while (curr != null || !stack.isEmpty()) {
            // Go left as much as possible
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            
            // Current curr is null, pop from stack (this is the next smallest)
            TreeNode nodeToVisit = stack.pop();
            count++;
            
            if (count == k) {
                return nodeToVisit.val;
            }
            
            // Move to the right subtree
            curr = nodeToVisit.right;
        }
        return -1; // Should not be reached if k is valid
    }
}
```

*   时间复杂度: 平均 O(H + K)，最坏 O(N)。H 是树的高度。
*   空间复杂度: O(H) for the stack.

### 159: [295. 数据流的中位数 (Find Median from Data Stream)](https://leetcode.cn/problems/find-median-from-data-stream)

**题目描述:**
中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。
例如，`` 的中位数是 `3` 。`` 的中位数是 `(2 + 3) / 2 = 2.5` 。
实现 MedianFinder 类:
*   `MedianFinder()` 初始化 `MedianFinder` 对象。
*   `void addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中。
*   `double findMedian()` 返回到目前为止所有元素的中位数。

**解题思路 (双堆法):**
维护两个堆：
1.  **小顶堆 (min_heap or `hi_half`)**: 存储数据流中较大的那一半数字。
2.  **大顶堆 (max_heap or `lo_half`)**: 存储数据流中较小的那一半数字。

**保持平衡**:
*   `max_heap` 的大小等于 `min_heap` 的大小，或者比 `min_heap` 多一个元素。
    (`max_heap.size() == min_heap.size()` or `max_heap.size() == min_heap.size() + 1`).
*   `max_heap` 中的所有元素都小于或等于 `min_heap` 中的所有元素 (`max_heap.top() <= min_heap.top()`).

**`addNum(num)` 操作**:
1.  将 `num` 加入 `max_heap` (Python的heapq是min-heap, so store `-num`).
2.  为了维持堆的性质 (max_heap < min_heap), 将 `max_heap` 的堆顶元素（最大的小元素）移动到 `min_heap`。
    `min_heap.push(max_heap.pop())`.
3.  **平衡调整**: 如果 `max_heap` 的大小小于 `min_heap` 的大小，则从 `min_heap` 拿出一个元素（最小的大元素）放回 `max_heap`。
    `max_heap.push(min_heap.pop())`.

**`findMedian()` 操作**:
1.  如果 `max_heap` 的大小比 `min_heap` 大 (即总元素个数为奇数)，中位数是 `max_heap` 的堆顶元素。
2.  如果两个堆大小相等 (即总元素个数为偶数)，中位数是 `(max_heap.top() + min_heap.top()) / 2.0`。

**Python 实现:**
```python
import heapq

class MedianFinder:
    def __init__(self):
        self.lo_half = []  # Max-heap (stores negative numbers for min-heap implementation)
        self.hi_half = []  # Min-heap

    def addNum(self, num: int) -> None:
        # Add to max-heap (lo_half)
        heapq.heappush(self.lo_half, -num)
        
        # Balance by moving largest of lo_half to hi_half
        largest_in_lo = -heapq.heappop(self.lo_half)
        heapq.heappush(self.hi_half, largest_in_lo)
        
        # Ensure lo_half is equal or one larger than hi_half
        if len(self.lo_half) < len(self.hi_half):
            smallest_in_hi = heapq.heappop(self.hi_half)
            heapq.heappush(self.lo_half, -smallest_in_hi)

    def findMedian(self) -> float:
        if len(self.lo_half) > len(self.hi_half): # Odd number of elements
            return float(-self.lo_half[0])
        else: # Even number of elements
            return (-self.lo_half[0] + self.hi_half[0]) / 2.0

```

**Java 实现:**
```java
import java.util.PriorityQueue;
import java.util.Collections; // For max-heap

class MedianFinder {
    private PriorityQueue<Integer> loHalf; // Max-heap for the lower half
    private PriorityQueue<Integer> hiHalf; // Min-heap for the upper half

    public MedianFinder() {
        loHalf = new PriorityQueue<>(Collections.reverseOrder()); // Max-heap
        hiHalf = new PriorityQueue<>();                          // Min-heap (default)
    }
    
    public void addNum(int num) {
        loHalf.offer(num); // Add to max-heap
        
        // Balance by moving largest of loHalf to hiHalf
        hiHalf.offer(loHalf.poll());
        
        // Ensure loHalf is equal or one larger than hiHalf
        if (loHalf.size() < hiHalf.size()) {
            loHalf.offer(hiHalf.poll());
        }
    }
    
    public double findMedian() {
        if (loHalf.size() > hiHalf.size()) { // Odd number of elements
            return (double) loHalf.peek();
        } else { // Even number of elements (or initially empty, but findMedian usually called after adds)
            if (loHalf.isEmpty()) return 0.0; // Or throw exception if not allowed
            return (loHalf.peek() + hiHalf.peek()) / 2.0;
        }
    }
}
```

*   `addNum`: O(log N) (heap operations).
*   `findMedian`: O(1) (peeking heap tops).
*   空间复杂度: O(N) (to store all numbers in heaps).

### 160: [106. 从中序与后序遍历序列构造二叉树 (Construct Binary Tree from Inorder and Postorder Traversal)](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal)

**题目描述:**
给定两个整数数组 `inorder` 和 `postorder` ，其中 `inorder` 是二叉树的中序遍历， `postorder` 是同一棵树的后序遍历，请你构造并返回这颗 二叉树 。

**解题思路 (递归):**
1.  **后序遍历特性**: `postorder` 数组的最后一个元素是当前 (子)树的根节点。
2.  **中序遍历特性**: 在 `inorder` 数组中找到该根节点的值。该值左边的所有元素属于根节点的左子树，右边的所有元素属于根节点的右子树。
3.  **递归构建**:
    a.  创建一个 `TreeNode` 以 `postorder` 的最后一个元素为根。
    b.  在 `inorder` 中找到根的值，得到其索引 `root_idx_inorder`。
    c.  `inorder` 中 `root_idx_inorder` 左边的元素构成左子树的中序遍历。左子树的元素数量是 `root_idx_inorder - inorder_start_idx`。
    d.  `inorder` 中 `root_idx_inorder` 右边的元素构成右子树的中序遍历。
    e.  根据左子树的元素数量，可以在 `postorder` 中确定左子树的后序遍历部分和右子树的后序遍历部分。
    *   左子树的后序遍历是 `postorder` 从 `postorder_start_idx` 开始，长度为左子树元素数量。
    *   右子树的后序遍历是 `postorder` 在左子树后序遍历之后，直到根节点（即`postorder`末尾元素）之前。
    f.  递归调用构建函数，分别传入对应的 `inorder` 和 `postorder` 子段来构建左子树和右子树。
4.  **优化**: 为了快速在 `inorder` 中查找根节点值的索引，可以预先将 `inorder` 元素及其索引存入哈希表。

**Python 实现:**
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, inorder: list[int], postorder: list[int]) -> TreeNode:
        if not inorder or not postorder:
            return None
        
        # For quick lookup of root index in inorder traversal
        inorder_map = {val: i for i, val in enumerate(inorder)}
        
        # Keep track of the current root index in postorder (which moves from right to left)
        self.postorder_idx = len(postorder) - 1

        def build_recursive(in_start, in_end):
            # Base case: if the segment is empty
            if in_start > in_end:
                return None
            
            # The last element in postorder is the current root
            root_val = postorder[self.postorder_idx]
            self.postorder_idx -= 1 # Move to the root of the next subtree (right then left)
            
            root = TreeNode(root_val)
            
            # Find root_val's index in the current inorder segment
            root_idx_inorder = inorder_map[root_val]
            
            # Recursively build right subtree first (because postorder is L-R-Root, so when processing
            # postorder from right to left, we encounter Root, then Right-subtree-root, then Left-subtree-root)
            root.right = build_recursive(root_idx_inorder + 1, in_end)
            root.left = build_recursive(in_start, root_idx_inorder - 1)
            
            return root

        return build_recursive(0, len(inorder) - 1)
```

```java
import java.util.HashMap;
import java.util.Map;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    private int postorderIdx;
    private Map<Integer, Integer> inorderMap;

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        if (inorder == null || postorder == null || inorder.length == 0 || inorder.length != postorder.length) {
            return null;
        }
        
        inorderMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            inorderMap.put(inorder[i], i);
        }
        
        postorderIdx = postorder.length - 1; // Start from the last element of postorder
        
        return buildRecursive(postorder, 0, inorder.length - 1);
    }

    private TreeNode buildRecursive(int[] postorder, int inStart, int inEnd) {
        // Base case: if the inorder segment is empty
        if (inStart > inEnd) {
            return null;
        }
        
        // The current root value is postorder[postorderIdx]
        int rootVal = postorder[postorderIdx];
        postorderIdx--; // Move to the root of the next subtree (right then left for postorder from end)
        
        TreeNode root = new TreeNode(rootVal);
        
        // Find rootVal's index in the inorder traversal
        int rootIdxInorder = inorderMap.get(rootVal);
        
        // Recursively build right subtree first
        // (because we process postorder from right to left: Root, then Right-subtree-root, then Left-subtree-root)
        root.right = buildRecursive(postorder, rootIdxInorder + 1, inEnd);
        // Then build left subtree
        root.left = buildRecursive(postorder, inStart, rootIdxInorder - 1);
        
        return root;
    }
}
```
