# 最长回文子串

## 题目描述
给定一个字符串s，找到s中最长的回文子串。你可以假设s的最大长度为1000。

示例：
```
输入：s = "babad"
输出："bab" 或 "aba"
解释：最长的回文子串是 "bab" 或 "aba"。

输入：s = "cbbd"
输出："bb"
解释：最长的回文子串是 "bb"。
```

## 解题思路
1. 中心扩展法：
   - 遍历每个字符作为中心点
   - 向两边扩展，判断是否为回文串
   - 需要考虑奇数和偶数长度的回文串
   - 时间复杂度：O(n²)，空间复杂度：O(1)

2. 动态规划法：
   - 定义dp[i][j]表示s[i...j]是否为回文串
   - 状态转移方程：
     - 如果s[i] == s[j]且dp[i+1][j-1]为true，则dp[i][j]为true
     - 否则dp[i][j]为false
   - 时间复杂度：O(n²)，空间复杂度：O(n²)

3. Manacher算法：
   - 预处理字符串，在每个字符间插入特殊字符
   - 利用回文串的对称性，减少重复计算
   - 时间复杂度：O(n)，空间复杂度：O(n)

## Java实现
```java
class Solution {
    // 中心扩展法
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 1) {
            return "";
        }
        
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expandAroundCenter(s, i, i);
            int len2 = expandAroundCenter(s, i, i + 1);
            int len = Math.max(len1, len2);
            if (len > end - start) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        
        return s.substring(start, end + 1);
    }
    
    private int expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
    
    // 动态规划法
    public String longestPalindromeDP(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        String result = "";
        
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                dp[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 3 || dp[i + 1][j - 1]);
                if (dp[i][j] && j - i + 1 > result.length()) {
                    result = s.substring(i, j + 1);
                }
            }
        }
        
        return result;
    }
    
    // Manacher算法
    public String longestPalindromeManacher(String s) {
        String t = preprocess(s);
        int n = t.length();
        int[] p = new int[n];
        int center = 0, maxRight = 0;
        int maxLen = 0, start = 0;
        
        for (int i = 0; i < n; i++) {
            if (i < maxRight) {
                p[i] = Math.min(maxRight - i, p[2 * center - i]);
            }
            
            int left = i - (p[i] + 1);
            int right = i + (p[i] + 1);
            while (left >= 0 && right < n && t.charAt(left) == t.charAt(right)) {
                p[i]++;
                left--;
                right++;
            }
            
            if (i + p[i] > maxRight) {
                center = i;
                maxRight = i + p[i];
            }
            
            if (p[i] > maxLen) {
                maxLen = p[i];
                start = (i - maxLen) / 2;
            }
        }
        
        return s.substring(start, start + maxLen);
    }
    
    private String preprocess(String s) {
        StringBuilder sb = new StringBuilder();
        sb.append("^");
        for (char c : s.toCharArray()) {
            sb.append("#").append(c);
        }
        sb.append("#$");
        return sb.toString();
    }
}
```

## Python实现
```python
class Solution:
    # 中心扩展法
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""
        
        start = end = 0
        for i in range(len(s)):
            len1 = self.expand_around_center(s, i, i)
            len2 = self.expand_around_center(s, i, i + 1)
            length = max(len1, len2)
            if length > end - start:
                start = i - (length - 1) // 2
                end = i + length // 2
        
        return s[start:end + 1]
    
    def expand_around_center(self, s: str, left: int, right: int) -> int:
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1
    
    # 动态规划法
    def longestPalindromeDP(self, s: str) -> str:
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        result = ""
        
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                dp[i][j] = s[i] == s[j] and (j - i < 3 or dp[i + 1][j - 1])
                if dp[i][j] and j - i + 1 > len(result):
                    result = s[i:j + 1]
        
        return result
    
    # Manacher算法
    def longestPalindromeManacher(self, s: str) -> str:
        t = self.preprocess(s)
        n = len(t)
        p = [0] * n
        center = max_right = 0
        max_len = start = 0
        
        for i in range(n):
            if i < max_right:
                p[i] = min(max_right - i, p[2 * center - i])
            
            left = i - (p[i] + 1)
            right = i + (p[i] + 1)
            while left >= 0 and right < n and t[left] == t[right]:
                p[i] += 1
                left -= 1
                right += 1
            
            if i + p[i] > max_right:
                center = i
                max_right = i + p[i]
            
            if p[i] > max_len:
                max_len = p[i]
                start = (i - max_len) // 2
        
        return s[start:start + max_len]
    
    def preprocess(self, s: str) -> str:
        return "^#" + "#".join(s) + "#$"
```

## 复杂度分析
- 中心扩展法：
  - 时间复杂度：O(n²)
  - 空间复杂度：O(1)
- 动态规划法：
  - 时间复杂度：O(n²)
  - 空间复杂度：O(n²)
- Manacher算法：
  - 时间复杂度：O(n)
  - 空间复杂度：O(n)
