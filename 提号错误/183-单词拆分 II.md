# 140. 单词拆分 II

## 题目描述
给定一个非空字符串 s 和一个包含非空单词的列表 wordDict，在字符串中增加空格来构建一个句子，使得句子中所有的单词都在词典中。返回所有这些可能的句子。

说明：
- 拆分时可以重复使用字典中的单词。
- 你可以假设字典中没有重复的单词。

示例 1:
```
输入：s = "catsanddog", wordDict = ["cat", "cats", "and", "sand", "dog"]
输出：[
  "cats and dog",
  "cat sand dog"
]
```

示例 2:
```
输入：s = "pineapplepenapple", wordDict = ["apple", "pen", "applepen", "pine", "pineapple"]
输出：[
  "pine apple pen apple",
  "pineapple pen apple",
  "pine applepen apple"
]
```

## 解题思路
1. 动态规划+DFS方法：
   - 使用动态规划判断是否可拆分
   - 使用DFS生成所有可能的拆分结果
   - 使用记忆化搜索优化
   - 时间复杂度：O(n²)，空间复杂度：O(n)

2. 关键点：
   - 理解动态规划的过程
   - 理解DFS的过程
   - 处理边界情况
   - 优化搜索过程

## Java实现
```java
class Solution {
    public List<String> wordBreak(String s, List<String> wordDict) {
        if (s == null || s.length() == 0 || wordDict == null || wordDict.isEmpty()) {
            return new ArrayList<>();
        }
        
        Set<String> wordSet = new HashSet<>(wordDict);
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        
        // 动态规划判断是否可拆分
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        
        if (!dp[n]) {
            return new ArrayList<>();
        }
        
        // DFS生成所有可能的拆分结果
        List<String> result = new ArrayList<>();
        dfs(s, wordSet, dp, 0, new ArrayList<>(), result);
        return result;
    }
    
    private void dfs(String s, Set<String> wordSet, boolean[] dp, int start, List<String> path, List<String> result) {
        if (start == s.length()) {
            result.add(String.join(" ", path));
            return;
        }
        
        for (int i = start + 1; i <= s.length(); i++) {
            if (dp[i] && wordSet.contains(s.substring(start, i))) {
                path.add(s.substring(start, i));
                dfs(s, wordSet, dp, i, path, result);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

## Python实现
```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        if not s or not wordDict:
            return []
            
        word_set = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        
        # 动态规划判断是否可拆分
        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break
        
        if not dp[n]:
            return []
        
        # DFS生成所有可能的拆分结果
        result = []
        
        def dfs(start: int, path: List[str]):
            if start == n:
                result.append(" ".join(path))
                return
                
            for i in range(start + 1, n + 1):
                if dp[i] and s[start:i] in word_set:
                    path.append(s[start:i])
                    dfs(i, path)
                    path.pop()
        
        dfs(0, [])
        return result
```

## 复杂度分析
- 时间复杂度：O(n²)，需要两层循环
- 空间复杂度：O(n)，需要存储dp数组和递归调用栈
