# 最长公共子串

## 题目描述
给定两个字符串，求它们的最长公共子串的长度。

子串是字符串中连续的字符序列。例如，"bcd" 是 "abcde" 的子串，但 "ace" 不是 "abcde" 的子串。

示例：
```
输入：str1 = "abcde", str2 = "cdef"
输出：2
解释：最长公共子串是 "cd"，它的长度为 2。

输入：str1 = "abc", str2 = "def"
输出：0
解释：两个字符串没有公共子串，返回 0。
```

## 解题思路
1. 动态规划方法：
   - 定义dp[i][j]表示以str1[i-1]和str2[j-1]结尾的最长公共子串长度
   - 状态转移方程：
     - 如果str1[i-1] == str2[j-1]，则dp[i][j] = dp[i-1][j-1] + 1
     - 否则，dp[i][j] = 0
   - 时间复杂度：O(mn)，空间复杂度：O(mn)

2. 空间优化：
   - 使用滚动数组优化空间
   - 时间复杂度：O(mn)，空间复杂度：O(min(m,n))

3. 后缀数组方法：
   - 将两个字符串连接起来，构建后缀数组
   - 使用后缀数组求解最长公共子串
   - 时间复杂度：O(nlogn)，空间复杂度：O(n)

## Java实现
```java
class Solution {
    // 动态规划方法
    public int longestCommonSubstring(String str1, String str2) {
        int m = str1.length();
        int n = str2.length();
        int[][] dp = new int[m + 1][n + 1];
        int maxLen = 0;
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (str1.charAt(i - 1) == str2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    maxLen = Math.max(maxLen, dp[i][j]);
                }
            }
        }
        
        return maxLen;
    }
    
    // 空间优化方法
    public int longestCommonSubstringOptimized(String str1, String str2) {
        int m = str1.length();
        int n = str2.length();
        
        // 确保str1是较短的字符串
        if (m > n) {
            return longestCommonSubstringOptimized(str2, str1);
        }
        
        int[] dp = new int[m + 1];
        int maxLen = 0;
        
        for (int j = 1; j <= n; j++) {
            int prev = 0;
            for (int i = 1; i <= m; i++) {
                int temp = dp[i];
                if (str1.charAt(i - 1) == str2.charAt(j - 1)) {
                    dp[i] = prev + 1;
                    maxLen = Math.max(maxLen, dp[i]);
                } else {
                    dp[i] = 0;
                }
                prev = temp;
            }
        }
        
        return maxLen;
    }
}
```

```python
class Solution:
    # 动态规划方法
    def longestCommonSubstring(self, str1: str, str2: str) -> int:
        m, n = len(str1), len(str2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        max_len = 0
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if str1[i - 1] == str2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                    max_len = max(max_len, dp[i][j])
        
        return max_len
    
    # 空间优化方法
    def longestCommonSubstringOptimized(self, str1: str, str2: str) -> int:
        m, n = len(str1), len(str2)
        
        # 确保str1是较短的字符串
        if m > n:
            return self.longestCommonSubstringOptimized(str2, str1)
        
        dp = [0] * (m + 1)
        max_len = 0
        
        for j in range(1, n + 1):
            prev = 0
            for i in range(1, m + 1):
                temp = dp[i]
                if str1[i - 1] == str2[j - 1]:
                    dp[i] = prev + 1
                    max_len = max(max_len, dp[i])
                else:
                    dp[i] = 0
                prev = temp
        
        return max_len
```

## 复杂度分析
- 动态规划方法：
  - 时间复杂度：O(mn)
  - 空间复杂度：O(mn)
- 空间优化方法：
