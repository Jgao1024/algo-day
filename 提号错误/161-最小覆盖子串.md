# 76. 最小覆盖子串

## 题目描述
给你一个字符串 s 和一个字符串 t 。返回 s 中涵盖 t 所有字符的最小子串。如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串 "" 。

注意：
- 如果 s 中存在这样的子串，我们保证它是唯一的答案。
- 对于 t 中重复字符，我们要寻找的子串中该字符数量必须不少于 t 中该字符数量。

示例：
```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

## 解题思路
1. 滑动窗口方法：
   - 使用双指针维护一个滑动窗口
   - 使用哈希表记录目标字符串中每个字符的出现次数
   - 使用计数器记录窗口中已匹配的字符数
   - 时间复杂度：O(n)，空间复杂度：O(k)

2. 关键点：
   - 窗口扩展和收缩
   - 字符匹配判断
   - 最小子串更新
   - 边界条件处理

## Java实现
```java
class Solution {
    public String minWindow(String s, String t) {
        if (s == null || t == null || s.length() < t.length()) {
            return "";
        }
        
        // 记录目标字符串中每个字符的出现次数
        Map<Character, Integer> target = new HashMap<>();
        for (char c : t.toCharArray()) {
            target.put(c, target.getOrDefault(c, 0) + 1);
        }
        
        int left = 0, right = 0;
        int count = 0;  // 记录窗口中已匹配的字符数
        int minLen = Integer.MAX_VALUE;
        int start = 0;
        
        // 记录窗口中每个字符的出现次数
        Map<Character, Integer> window = new HashMap<>();
        
        while (right < s.length()) {
            char c = s.charAt(right);
            window.put(c, window.getOrDefault(c, 0) + 1);
            
            // 如果当前字符是目标字符，且窗口中的数量不超过目标数量
            if (target.containsKey(c) && window.get(c).equals(target.get(c))) {
                count++;
            }
            
            // 当窗口包含所有目标字符时，尝试收缩窗口
            while (count == target.size()) {
                // 更新最小子串
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    start = left;
                }
                
                // 收缩窗口
                char leftChar = s.charAt(left);
                window.put(leftChar, window.get(leftChar) - 1);
                
                // 如果移除的是目标字符，且窗口中的数量小于目标数量
                if (target.containsKey(leftChar) && window.get(leftChar) < target.get(leftChar)) {
                    count--;
                }
                
                left++;
            }
            
            right++;
        }
        
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

## Python实现
```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not s or not t or len(s) < len(t):
            return ""
        
        # 记录目标字符串中每个字符的出现次数
        target = collections.Counter(t)
        
        left = right = 0
        count = 0  # 记录窗口中已匹配的字符数
        min_len = float('inf')
        start = 0
        
        # 记录窗口中每个字符的出现次数
        window = collections.defaultdict(int)
        
        while right < len(s):
            c = s[right]
            window[c] += 1
            
            # 如果当前字符是目标字符，且窗口中的数量不超过目标数量
            if c in target and window[c] == target[c]:
                count += 1
            
            # 当窗口包含所有目标字符时，尝试收缩窗口
            while count == len(target):
                # 更新最小子串
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    start = left
                
                # 收缩窗口
                left_char = s[left]
                window[left_char] -= 1
                
                # 如果移除的是目标字符，且窗口中的数量小于目标数量
                if left_char in target and window[left_char] < target[left_char]:
                    count -= 1
                
                left += 1
            
            right += 1
        
        return s[start:start + min_len] if min_len != float('inf') else ""
```

## 复杂度分析
- 时间复杂度：O(n)，其中n是字符串s的长度
- 空间复杂度：O(k)，其中k是字符集的大小
