# 3. 最长无重复字符子串

## 题目描述
给定一个字符串 s ，请你找出其中不含有重复字符的最长子串的长度。

示例：
```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
```

## 解题思路
1. 滑动窗口方法：
   - 使用双指针维护一个滑动窗口
   - 使用哈希表记录字符最后出现的位置
   - 当遇到重复字符时，更新窗口的起始位置
   - 时间复杂度：O(n)，空间复杂度：O(k)

2. 关键点：
   - 窗口维护
   - 重复字符处理
   - 最大长度更新
   - 边界条件

## Java实现
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }
        
        Map<Character, Integer> map = new HashMap<>();
        int maxLen = 0;
        int start = 0;
        
        for (int end = 0; end < s.length(); end++) {
            char c = s.charAt(end);
            
            // 如果字符已存在，更新窗口起始位置
            if (map.containsKey(c)) {
                start = Math.max(start, map.get(c) + 1);
            }
            
            // 更新字符最后出现的位置
            map.put(c, end);
            
            // 更新最大长度
            maxLen = Math.max(maxLen, end - start + 1);
        }
        
        return maxLen;
    }
    
    // 使用数组优化空间
    public int lengthOfLongestSubstringArray(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }
        
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);
        
        int maxLen = 0;
        int start = 0;
        
        for (int end = 0; end < s.length(); end++) {
            char c = s.charAt(end);
            
            // 如果字符已存在，更新窗口起始位置
            if (lastIndex[c] >= start) {
                start = lastIndex[c] + 1;
            }
            
            // 更新字符最后出现的位置
            lastIndex[c] = end;
            
            // 更新最大长度
            maxLen = Math.max(maxLen, end - start + 1);
        }
        
        return maxLen;
    }
}
```

## Python实现
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        if not s:
            return 0
        
        char_map = {}
        max_len = 0
        start = 0
        
        for end, char in enumerate(s):
            # 如果字符已存在，更新窗口起始位置
            if char in char_map and char_map[char] >= start:
                start = char_map[char] + 1
            
            # 更新字符最后出现的位置
            char_map[char] = end
            
            # 更新最大长度
            max_len = max(max_len, end - start + 1)
        
        return max_len
    
    # 使用数组优化空间
    def lengthOfLongestSubstringArray(self, s: str) -> int:
        if not s:
            return 0
        
        last_index = [-1] * 128
        max_len = 0
        start = 0
        
        for end, char in enumerate(s):
            # 如果字符已存在，更新窗口起始位置
            if last_index[ord(char)] >= start:
                start = last_index[ord(char)] + 1
            
            # 更新字符最后出现的位置
            last_index[ord(char)] = end
            
            # 更新最大长度
            max_len = max(max_len, end - start + 1)
        
        return max_len
```

## 复杂度分析
- 哈希表方法：
  - 时间复杂度：O(n)
  - 空间复杂度：O(k)，其中k是字符集的大小
- 数组方法：
  - 时间复杂度：O(n)
  - 空间复杂度：O(1)，因为字符集大小固定
