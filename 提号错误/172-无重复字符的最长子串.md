# 3. 无重复字符的最长子串

## 题目描述
给定一个字符串 s ，请你找出其中不含有重复字符的 最长子串 的长度。

示例：
```
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。

输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1。

输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。
```

## 解题思路
1. 滑动窗口方法：
   - 使用可变大小的滑动窗口
   - 使用哈希表记录字符最后出现的位置
   - 维护窗口内字符的唯一性
   - 时间复杂度：O(n)，空间复杂度：O(k)

2. 关键点：
   - 窗口大小可变
   - 字符位置记录
   - 重复字符处理
   - 最大长度更新

## Java实现
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }
        
        Map<Character, Integer> map = new HashMap<>();
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果字符已存在，更新左边界
            if (map.containsKey(c)) {
                left = Math.max(left, map.get(c) + 1);
            }
            
            // 更新字符位置
            map.put(c, right);
            
            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
    
    // 使用数组的实现方式
    public int lengthOfLongestSubstringArray(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }
        
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);
        
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果字符已存在，更新左边界
            if (lastIndex[c] >= left) {
                left = lastIndex[c] + 1;
            }
            
            // 更新字符位置
            lastIndex[c] = right;
            
            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
}
```

## Python实现
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        if not s:
            return 0
        
        char_map = {}
        max_len = 0
        left = 0
        
        for right, char in enumerate(s):
            # 如果字符已存在，更新左边界
            if char in char_map and char_map[char] >= left:
                left = char_map[char] + 1
            
            # 更新字符位置
            char_map[char] = right
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
    
    # 使用数组的实现方式
    def lengthOfLongestSubstringArray(self, s: str) -> int:
        if not s:
            return 0
        
        last_index = [-1] * 128
        max_len = 0
        left = 0
        
        for right, char in enumerate(s):
            # 如果字符已存在，更新左边界
            if last_index[ord(char)] >= left:
                left = last_index[ord(char)] + 1
            
            # 更新字符位置
            last_index[ord(char)] = right
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

## 复杂度分析
- 基本方法：
  - 时间复杂度：O(n)，其中n是字符串长度
  - 空间复杂度：O(k)，其中k是字符集大小
- 数组方法：
  - 时间复杂度：O(n)
  - 空间复杂度：O(1)，因为字符集大小固定
