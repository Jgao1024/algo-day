# 567. 字符串的排列

## 题目描述
给你两个字符串 s1 和 s2 ，写一个函数来判断 s2 是否包含 s1 的排列。如果是，返回 true ；否则，返回 false 。

换句话说，s1 的排列之一是 s2 的子串。

示例：
```
输入：s1 = "ab" s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列之一 ("ba").

输入：s1 = "ab" s2 = "eidboaoo"
输出：false
```

## 解题思路
1. 滑动窗口方法：
   - 使用固定大小的滑动窗口
   - 使用哈希表记录字符出现次数
   - 比较窗口内字符频率是否匹配
   - 时间复杂度：O(n)，空间复杂度：O(k)

2. 关键点：
   - 窗口大小固定
   - 字符频率统计
   - 匹配判断
   - 边界条件

## Java实现
```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) {
            return false;
        }
        
        int[] count1 = new int[26];
        int[] count2 = new int[26];
        
        // 初始化第一个窗口
        for (int i = 0; i < s1.length(); i++) {
            count1[s1.charAt(i) - 'a']++;
            count2[s2.charAt(i) - 'a']++;
        }
        
        // 检查第一个窗口
        if (matches(count1, count2)) {
            return true;
        }
        
        // 滑动窗口
        for (int i = s1.length(); i < s2.length(); i++) {
            // 添加新字符
            count2[s2.charAt(i) - 'a']++;
            // 移除旧字符
            count2[s2.charAt(i - s1.length()) - 'a']--;
            
            if (matches(count1, count2)) {
                return true;
            }
        }
        
        return false;
    }
    
    private boolean matches(int[] count1, int[] count2) {
        for (int i = 0; i < 26; i++) {
            if (count1[i] != count2[i]) {
                return false;
            }
        }
        return true;
    }
    
    // 优化版本：使用单个变量记录匹配的字符数
    public boolean checkInclusionOptimized(String s1, String s2) {
        if (s1.length() > s2.length()) {
            return false;
        }
        
        int[] count = new int[26];
        for (char c : s1.toCharArray()) {
            count[c - 'a']++;
        }
        
        int left = 0, right = 0;
        int matches = 0;
        
        while (right < s2.length()) {
            char c = s2.charAt(right);
            count[c - 'a']--;
            
            if (count[c - 'a'] >= 0) {
                matches++;
            }
            
            if (right - left + 1 == s1.length()) {
                if (matches == s1.length()) {
                    return true;
                }
                
                char leftChar = s2.charAt(left);
                count[leftChar - 'a']++;
                
                if (count[leftChar - 'a'] > 0) {
                    matches--;
                }
                
                left++;
            }
            
            right++;
        }
        
        return false;
    }
}
```

## Python实现
```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        if len(s1) > len(s2):
            return False
        
        count1 = [0] * 26
        count2 = [0] * 26
        
        # 初始化第一个窗口
        for i in range(len(s1)):
            count1[ord(s1[i]) - ord('a')] += 1
            count2[ord(s2[i]) - ord('a')] += 1
        
        # 检查第一个窗口
        if self.matches(count1, count2):
            return True
        
        # 滑动窗口
        for i in range(len(s1), len(s2)):
            # 添加新字符
            count2[ord(s2[i]) - ord('a')] += 1
            # 移除旧字符
            count2[ord(s2[i - len(s1)]) - ord('a')] -= 1
            
            if self.matches(count1, count2):
                return True
        
        return False
    
    def matches(self, count1: List[int], count2: List[int]) -> bool:
        for i in range(26):
            if count1[i] != count2[i]:
                return False
        return True
    
    # 优化版本：使用单个变量记录匹配的字符数
    def checkInclusionOptimized(self, s1: str, s2: str) -> bool:
        if len(s1) > len(s2):
            return False
        
        count = [0] * 26
        for c in s1:
            count[ord(c) - ord('a')] += 1
        
        left = right = matches = 0
        
        while right < len(s2):
            c = s2[right]
            count[ord(c) - ord('a')] -= 1
            
            if count[ord(c) - ord('a')] >= 0:
                matches += 1
            
            if right - left + 1 == len(s1):
                if matches == len(s1):
                    return True
                
                left_char = s2[left]
                count[ord(left_char) - ord('a')] += 1
                
                if count[ord(left_char) - ord('a')] > 0:
                    matches -= 1
                
                left += 1
            
            right += 1
        
        return False
```

## 复杂度分析
- 基本方法：
  - 时间复杂度：O(n)，其中n是s2的长度
  - 空间复杂度：O(1)，因为字符集大小固定
- 优化方法：
  - 时间复杂度：O(n)
  - 空间复杂度：O(1)
