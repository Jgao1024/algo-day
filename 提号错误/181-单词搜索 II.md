# 212. 单词搜索 II

## 题目描述
给定一个二维网格 board 和一个字典中的单词列表 words，找出所有同时在二维网格和字典中出现的单词。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母在一个单词中不允许被重复使用。

示例 1:
```
输入：board = [
  ["o","a","a","n"],
  ["e","t","a","e"],
  ["i","h","k","r"],
  ["i","f","l","v"]
], words = ["oath","pea","eat","rain"]
输出：["eat","oath"]
```

## 解题思路
1. Trie树+DFS方法：
   - 构建Trie树存储所有单词
   - 遍历网格，对每个位置进行DFS
   - 使用visited数组标记已访问的位置
   - 时间复杂度：O(m*n*4^L)，空间复杂度：O(L)

2. 关键点：
   - 理解Trie树的结构
   - 理解DFS的过程
   - 处理边界情况
   - 优化搜索过程

## Java实现
```java
class Solution {
    class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word;
    }
    
    public List<String> findWords(char[][] board, String[] words) {
        List<String> result = new ArrayList<>();
        if (board == null || board.length == 0 || words == null || words.length == 0) {
            return result;
        }
        
        // 构建Trie树
        TrieNode root = buildTrie(words);
        
        int m = board.length;
        int n = board[0].length;
        boolean[][] visited = new boolean[m][n];
        
        // 遍历网格
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dfs(board, root, visited, i, j, result);
            }
        }
        
        return result;
    }
    
    private TrieNode buildTrie(String[] words) {
        TrieNode root = new TrieNode();
        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                int index = c - 'a';
                if (node.children[index] == null) {
                    node.children[index] = new TrieNode();
                }
                node = node.children[index];
            }
            node.word = word;
        }
        return root;
    }
    
    private void dfs(char[][] board, TrieNode node, boolean[][] visited, int i, int j, List<String> result) {
        int m = board.length;
        int n = board[0].length;
        
        if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j]) {
            return;
        }
        
        char c = board[i][j];
        node = node.children[c - 'a'];
        if (node == null) {
            return;
        }
        
        if (node.word != null) {
            result.add(node.word);
            node.word = null; // 避免重复添加
        }
        
        visited[i][j] = true;
        dfs(board, node, visited, i + 1, j, result);
        dfs(board, node, visited, i - 1, j, result);
        dfs(board, node, visited, i, j + 1, result);
        dfs(board, node, visited, i, j - 1, result);
        visited[i][j] = false;
    }
}
```

## Python实现
```python
class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        if not board or not board[0] or not words:
            return []
            
        # 构建Trie树
        trie = {}
        for word in words:
            node = trie
            for char in word:
                node = node.setdefault(char, {})
            node['#'] = word
            
        m, n = len(board), len(board[0])
        result = []
        
        def dfs(i: int, j: int, node: dict):
            if '#' in node:
                result.append(node['#'])
                del node['#']  # 避免重复添加
                
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] not in node:
                return
                
            char = board[i][j]
            board[i][j] = '#'  # 标记已访问
            dfs(i + 1, j, node[char])
            dfs(i - 1, j, node[char])
            dfs(i, j + 1, node[char])
            dfs(i, j - 1, node[char])
            board[i][j] = char  # 恢复
            
        for i in range(m):
            for j in range(n):
                dfs(i, j, trie)
                
        return result
```

## 复杂度分析
- 时间复杂度：O(m*n*4^L)，其中L是单词长度
- 空间复杂度：O(L)，递归调用栈的深度
