# 516. 最长回文子序列

## 题目描述
给你一个字符串 s ，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

示例：
```
输入：s = "bbbab"
输出：4
解释：一个可能的最长回文子序列为 "bbbb"。

输入：s = "cbbd"
输出：2
解释：一个可能的最长回文子序列为 "bb"。
```

## 解题思路
1. 动态规划方法：
   - 定义dp[i][j]表示s[i...j]的最长回文子序列长度
   - 状态转移方程：
     - 如果s[i] == s[j]，dp[i][j] = dp[i+1][j-1] + 2
     - 否则，dp[i][j] = max(dp[i+1][j], dp[i][j-1])
   - 时间复杂度：O(n²)，空间复杂度：O(n²)

2. 空间优化方法：
   - 使用滚动数组优化空间
   - 时间复杂度：O(n²)，空间复杂度：O(n)

## Java实现
```java
class Solution {
    // 动态规划方法
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        
        // 单个字符都是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }
        
        // 从长度2开始
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        
        return dp[0][n - 1];
    }
    
    // 空间优化方法
    public int longestPalindromeSubseqOptimized(String s) {
        int n = s.length();
        int[] dp = new int[n];
        
        // 初始化对角线
        for (int i = 0; i < n; i++) {
            dp[i] = 1;
        }
        
        // 从长度2开始
        for (int len = 2; len <= n; len++) {
            int prev = 0;
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                int temp = dp[i];
                
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i] = prev + 2;
                } else {
                    dp[i] = Math.max(dp[i + 1], dp[i]);
                }
                
                prev = temp;
            }
        }
        
        return dp[0];
    }
}
```

## Python实现
```python
class Solution:
    # 动态规划方法
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        
        # 单个字符都是回文
        for i in range(n):
            dp[i][i] = 1
        
        # 从长度2开始
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        
        return dp[0][n - 1]
    
    # 空间优化方法
    def longestPalindromeSubseqOptimized(self, s: str) -> int:
        n = len(s)
        dp = [1] * n
        
        # 从长度2开始
        for length in range(2, n + 1):
            prev = 0
            for i in range(n - length + 1):
                j = i + length - 1
                temp = dp[i]
                
                if s[i] == s[j]:
                    dp[i] = prev + 2
                else:
                    dp[i] = max(dp[i + 1], dp[i])
                
                prev = temp
        
        return dp[0]
```

## 复杂度分析
- 动态规划方法：
  - 时间复杂度：O(n²)
  - 空间复杂度：O(n²)
- 空间优化方法：
  - 时间复杂度：O(n²)
  - 空间复杂度：O(n)
