## 最佳解法思路
- 迭代模拟规律：维护当前序列的“头元素 head”、步长 step、剩余数量 remain、方向 leftToRight。
- 每轮都会删掉一半：`remain/=2`，`step*=2`。当从左往右删，或从右往左删且 `remain` 为奇数时，`head += step`。

## Java 最佳实现

```java
class Solution {
    public int lastRemaining(int n) {
        int head = 1;
        int step = 1;
        int remain = n;
        boolean leftToRight = true;

        while (remain > 1) {
            if (leftToRight || (remain & 1) == 1) {
                head += step;
            }
            remain >>= 1;
            step <<= 1;
            leftToRight = !leftToRight;
        }
        return head;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
