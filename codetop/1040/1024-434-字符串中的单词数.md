## 最佳解法思路
- 统计“从空格到非空格”的转折：当 `s[i] != ' '` 且 `i==0` 或 `s[i-1]==' '` 时计数 +1。

## Java 最佳实现

```java
class Solution {
    public int countSegments(String s) {
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != ' ' && (i == 0 || s.charAt(i - 1) == ' ')) {
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
