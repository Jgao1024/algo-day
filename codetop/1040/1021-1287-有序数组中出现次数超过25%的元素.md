## 最佳解法思路
- 有序数组里出现次数 \(>25\%\) 的元素一定会出现在下标 `n/4、n/2、3n/4` 这几个位置的值中。
- 取这几个候选值，对每个值用二分查找其 `lowerBound/upperBound` 得到次数，返回次数满足的那个。

## Java 最佳实现

```java
class Solution {
    public int findSpecialInteger(int[] arr) {
        int n = arr.length;
        int[] candIdx = {n / 4, n / 2, (3 * n) / 4};
        for (int idx : candIdx) {
            int x = arr[idx];
            int l = lowerBound(arr, x);
            int r = upperBound(arr, x);
            if (r - l > n / 4) return x;
        }
        return arr[0];
    }

    private int lowerBound(int[] a, int x) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = l + ((r - l) >>> 1);
            if (a[m] >= x) r = m;
            else l = m + 1;
        }
        return l;
    }

    private int upperBound(int[] a, int x) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = l + ((r - l) >>> 1);
            if (a[m] > x) r = m;
            else l = m + 1;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
