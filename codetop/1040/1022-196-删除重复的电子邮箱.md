## 最佳解法思路
- 题目本质是去重：同一个 `email` 只保留最小 `id` 的那条记录。
- 用 HashMap 统计每个邮箱的最小 id，再过滤出保留记录即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class Person {
        int id;
        String email;
        Person(int id, String email) { this.id = id; this.email = email; }
    }

    public List<Person> deleteDuplicateEmails(List<Person> persons) {
        Map<String, Integer> minId = new HashMap<>();
        for (Person p : persons) {
            Integer cur = minId.get(p.email);
            if (cur == null || p.id < cur) minId.put(p.email, p.id);
        }

        List<Person> res = new ArrayList<>();
        for (Person p : persons) {
            if (p.id == minId.get(p.email)) res.add(p);
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
