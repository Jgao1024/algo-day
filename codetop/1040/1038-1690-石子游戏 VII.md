## 最佳解法思路
- 区间 DP（分差）：`dp[i][j]` 表示在区间 `[i..j]` 里先手相对后手能多拿的最大分差。
- 先手可以拿走左端或右端：  
  - 拿左端：得分是剩余和 `sum(i+1..j)`，之后对手能反超 `dp[i+1][j]`  
  - 拿右端：得分是 `sum(i..j-1)`，之后对手反超 `dp[i][j-1]`
- `dp[i][j] = max(sum(i+1..j) - dp[i+1][j], sum(i..j-1) - dp[i][j-1])`。

## Java 最佳实现

```java
class Solution {
    public int stoneGameVII(int[] stones) {
        int n = stones.length;
        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stones[i];

        int[][] dp = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                int sumLeft = pre[j + 1] - pre[i + 1]; // sum(i+1..j)
                int sumRight = pre[j] - pre[i];       // sum(i..j-1)
                dp[i][j] = Math.max(sumLeft - dp[i + 1][j], sumRight - dp[i][j - 1]);
            }
        }
        return dp[0][n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
