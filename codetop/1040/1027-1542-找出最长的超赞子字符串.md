## 最佳解法思路
- 状态压缩：用 10 位 bitmask 表示数字 `0..9` 出现次数的奇偶性。
- 子串是“超赞”当且仅当：mask 为 0（全部偶数），或 mask 只有 1 位为 1（只有一个数字出现奇数次）。
- 维护每个 mask 最早出现位置 `first[mask]`：遍历到位置 `i` 的前缀 mask，答案尝试  
  - `i - first[mask]`  
  - `i - first[mask ^ (1<<d)]`（枚举 d=0..9）

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int longestAwesome(String s) {
        int[] first = new int[1 << 10];
        Arrays.fill(first, -2);
        first[0] = -1;

        int mask = 0;
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            int d = s.charAt(i) - '0';
            mask ^= 1 << d;

            if (first[mask] != -2) {
                ans = Math.max(ans, i - first[mask]);
            } else {
                first[mask] = i;
            }

            for (int b = 0; b < 10; b++) {
                int m2 = mask ^ (1 << b);
                if (first[m2] != -2) {
                    ans = Math.max(ans, i - first[m2]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(10n)\)
- 空间：\(O(1)\)（1024 个状态）
