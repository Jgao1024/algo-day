## 最佳解法思路
- 用 `id -> salary` 映射先记录每个员工薪水。
- 再遍历员工：若存在 `managerId` 且 `salary > managerSalary`，则该员工满足条件。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class Employee {
        int id;
        String name;
        int salary;
        Integer managerId;
        Employee(int id, String name, int salary, Integer managerId) {
            this.id = id;
            this.name = name;
            this.salary = salary;
            this.managerId = managerId;
        }
    }

    public List<String> employeesEarningMoreThanManagers(List<Employee> employees) {
        Map<Integer, Integer> salary = new HashMap<>();
        for (Employee e : employees) salary.put(e.id, e.salary);

        List<String> res = new ArrayList<>();
        for (Employee e : employees) {
            if (e.managerId == null) continue;
            Integer ms = salary.get(e.managerId);
            if (ms != null && e.salary > ms) res.add(e.name);
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
