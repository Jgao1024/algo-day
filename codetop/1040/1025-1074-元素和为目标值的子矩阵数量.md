## 最佳解法思路
- 二维压一维：枚举上边界 `top` 和下边界 `bottom`，把 `top..bottom` 之间每列的和压成一维数组 `colSum`。
- 问题变成：`colSum` 中“子数组和等于 target”的数量，用前缀和 + HashMap 计数即可。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numSubmatrixSumTarget(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int ans = 0;

        for (int top = 0; top < m; top++) {
            int[] colSum = new int[n];
            for (int bottom = top; bottom < m; bottom++) {
                for (int c = 0; c < n; c++) {
                    colSum[c] += matrix[bottom][c];
                }
                ans += subarraySum(colSum, target);
            }
        }
        return ans;
    }

    private int subarraySum(int[] a, int target) {
        Map<Integer, Integer> cnt = new HashMap<>();
        cnt.put(0, 1);
        int pre = 0;
        int ans = 0;
        for (int v : a) {
            pre += v;
            ans += cnt.getOrDefault(pre - target, 0);
            cnt.put(pre, cnt.getOrDefault(pre, 0) + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m^2 \cdot n)\)
- 空间：\(O(n)\)
