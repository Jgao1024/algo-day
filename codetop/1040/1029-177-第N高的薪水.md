## 最佳解法思路
- 去重后取第 N 大：先把所有薪水放入集合去重，再按降序取第 N 个；不存在则返回空。

## Java 最佳实现

```java
import java.util.TreeSet;

class Solution {
    // 不存在返回 null
    public Integer nthHighestSalary(int[] salary, int n) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int x : salary) set.add(x);
        if (set.size() < n) return null;
        int k = 0;
        for (int x : set.descendingSet()) {
            k++;
            if (k == n) return x;
        }
        return null;
    }
}
```

## 复杂度分析
- 时间：\(O(m\log m)\)
- 空间：\(O(m)\)
