## 最佳解法思路
- 递归下降解析：表达式包含两种运算：  
  - 并集：`{a,b}` 中逗号分隔  
  - 连接：相邻部分做笛卡尔积拼接
- 语法：`expr = term (',' term)*`，`term = factor factor*`，`factor = 字母串 | '{' expr '}'`，用 Set 去重，最后排序输出。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    private String s;
    private int i;

    public List<String> braceExpansionII(String expression) {
        s = expression;
        i = 0;
        Set<String> set = parseExpr();
        List<String> res = new ArrayList<>(set);
        Collections.sort(res);
        return res;
    }

    private Set<String> parseExpr() {
        Set<String> res = parseTerm();
        while (i < s.length() && s.charAt(i) == ',') {
            i++;
            res.addAll(parseTerm());
        }
        return res;
    }

    private Set<String> parseTerm() {
        Set<String> res = new HashSet<>();
        res.add("");
        while (i < s.length() && s.charAt(i) != '}' && s.charAt(i) != ',') {
            Set<String> part = parseFactor();
            res = concat(res, part);
        }
        return res;
    }

    private Set<String> parseFactor() {
        if (s.charAt(i) == '{') {
            i++;
            Set<String> inside = parseExpr();
            i++; // skip '}'
            return inside;
        }
        int start = i;
        while (i < s.length() && Character.isLetter(s.charAt(i))) i++;
        Set<String> res = new HashSet<>();
        res.add(s.substring(start, i));
        return res;
    }

    private Set<String> concat(Set<String> a, Set<String> b) {
        Set<String> res = new HashSet<>();
        for (String x : a) {
            for (String y : b) {
                res.add(x + y);
            }
        }
        return res;
    }
}
```
