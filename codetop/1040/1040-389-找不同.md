## 最佳解法思路
- 异或：把 `s` 和 `t` 的所有字符异或起来，剩下的就是多出来的那个字符。

## Java 最佳实现

```java
class Solution {
    public char findTheDifference(String s, String t) {
        int x = 0;
        for (int i = 0; i < s.length(); i++) x ^= s.charAt(i);
        for (int i = 0; i < t.length(); i++) x ^= t.charAt(i);
        return (char) x;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
