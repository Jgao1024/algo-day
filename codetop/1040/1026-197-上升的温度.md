## 最佳解法思路
- 题目本质是“同一城市按日期比较昨日与今日温度”。一般数据假设每天最多一条记录。
- 用 `date -> record` 映射；遍历每条记录，看 `date-1` 是否存在且 `temp` 更低。

## Java 最佳实现

```java
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class Weather {
        int id;
        LocalDate date;
        int temperature;
        Weather(int id, String date, int temperature) {
            this.id = id;
            this.date = LocalDate.parse(date);
            this.temperature = temperature;
        }
    }

    public List<Integer> risingTemperatureIds(List<Weather> list) {
        Map<LocalDate, Weather> map = new HashMap<>();
        for (Weather w : list) map.put(w.date, w);

        List<Integer> res = new ArrayList<>();
        for (Weather w : list) {
            Weather prev = map.get(w.date.minusDays(1));
            if (prev != null && w.temperature > prev.temperature) {
                res.add(w.id);
            }
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
