## 最佳解法思路
- 先按单词长度排序，用 HashSet 保存已处理过的短单词。
- 对当前单词做 DP：`dp[i]` 表示前 `i` 个字符能否由字典拼出；枚举切分点 `j<i`，若 `dp[j]` 且 `word[j..i)` 在字典中，则 `dp[i]=true`。
- 能拼出且至少用到 2 个词时，该单词就是连接词。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<String> findAllConcatenatedWordsInADict(String[] words) {
        Arrays.sort(words, (a, b) -> Integer.compare(a.length(), b.length()));
        Set<String> dict = new HashSet<>();
        List<String> res = new ArrayList<>();

        for (String w : words) {
            if (w.length() == 0) continue;
            if (canForm(w, dict)) res.add(w);
            dict.add(w);
        }
        return res;
    }

    private boolean canForm(String w, Set<String> dict) {
        if (dict.isEmpty()) return false;
        int n = w.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (!dp[j]) continue;
                if (dict.contains(w.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：与总字符数及切分次数相关（最坏 \(O(L^2)\) / 单词）
- 空间：\(O(L)\)
