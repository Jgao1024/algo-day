## 最佳解法思路
- 题目本质是“稠密排名（dense rank）”：分数相同排名相同，下一名紧跟（无空档）。
- 先取所有分数去重并按降序排序，建立 `score -> rank` 映射，再为每条记录输出排名。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] denseRank(int[] scores) {
        int n = scores.length;
        int[] sorted = Arrays.copyOf(scores, n);
        Arrays.sort(sorted);

        Map<Integer, Integer> rank = new HashMap<>();
        int r = 0;
        for (int i = n - 1; i >= 0; i--) {
            int s = sorted[i];
            if (!rank.containsKey(s)) {
                rank.put(s, ++r);
            }
        }

        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            res[i] = rank.get(scores[i]);
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
