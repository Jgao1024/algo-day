# 583. 两个字符串的删除操作

- 题号：583
- 难度：中等
- LeetCode：[两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)

## 题目描述
每次只能删除一个字符，使两个字符串相同，求最少删除次数。

## 示例
- 示例  
输入：`word1 = "sea", word2 = "eat"`  
输出：`2`（删掉 's' 和 't'）

## 最佳解法思路
- 思路1（推荐）：转化为 LCS  
要让两串相同，保留它们的最长公共子序列（LCS）即可。  
最少删除次数 = `m + n - 2 * LCS(word1, word2)`。  
用 DP 求 LCS：`dp[i][j]` 表示前 i、前 j 的 LCS 长度。

## Java 最佳实现

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            char a = word1.charAt(i - 1);
            for (int j = 1; j <= n; j++) {
                char b = word2.charAt(j - 1);
                if (a == b) dp[i][j] = dp[i - 1][j - 1] + 1;
                else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        int lcs = dp[m][n];
        return m + n - 2 * lcs;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)

- 只删字符 => 保留 LCS；答案 `m+n-2*lcs`。
