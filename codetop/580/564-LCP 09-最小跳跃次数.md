# LCP 09. 最小跳跃次数

- 题号：LCP 09
- 难度：困难
- LeetCode：[最小跳跃次数](https://leetcode.cn/problems/zui-xiao-tiao-yue-ci-shu/)

## 题目描述
给定数组 `jump`，初始在下标 0：  
- 从 i 可以跳到 `i + jump[i]`  
- 或者跳到任意 `j < i`  
求最少跳跃次数使得位置 `>= n`（跳出数组）。

## 示例
- 示例  
输入：`jump = [2,5,1,1,1,1]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：BFS + 指针优化左跳  
这是一个最短路问题，用 BFS。  
右跳：从 i 到 `i+jump[i]`。  
左跳：从 i 到任意 `j<i`，若直接建边会 \(O(n^2)\)。  
优化：维护一个指针 `left`，表示“还没有通过左跳入队的最小下标”。当处理到某个 i 时，把 `[left, i-1]` 全部入队，并把 `left` 推进到 i。每个下标只会被左跳入队一次，总复杂度 \(O(n)\)。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int minJump(int[] jump) {
        int n = jump.length;
        boolean[] vis = new boolean[n];
        Deque<Integer> q = new ArrayDeque<>();
        q.offer(0);
        vis[0] = true;
        int left = 0;
        int step = 0;

        while (!q.isEmpty()) {
            int size = q.size();
            for (int s = 0; s < size; s++) {
                int i = q.poll();
                int r = i + jump[i];
                if (r >= n) return step + 1;
                if (!vis[r]) {
                    vis[r] = true;
                    q.offer(r);
                }
                while (left < i) {
                    if (!vis[left]) {
                        vis[left] = true;
                        q.offer(left);
                    }
                    left++;
                }
            }
            step++;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

- BFS 做最短步数；左跳用 `left` 指针把区间一次性入队，避免重复扫描。
