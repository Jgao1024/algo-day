# 216. 组合总和 III

- 题号：216
- 难度：中等
- LeetCode：[组合总和 III](https://leetcode.cn/problems/combination-sum-iii/)

## 题目描述
从 1~9 中选出 `k` 个不同数字，使其和为 `n`，返回所有可能组合。

## 示例
- 示例  
输入：`k = 3, n = 7`  
输出：`[[1,2,4]]`

## 最佳解法思路
- 思路1（推荐）：回溯（组合）  
从 `start` 开始枚举下一个数字，维护剩余和 `remain` 和当前路径。  
当选了 `k` 个数且 `remain==0` 记录答案。  
剪枝：若 `remain < 0` 或已选数超过 `k` 直接返回。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> ans = new ArrayList<>();
        dfs(1, k, n, new ArrayList<>(), ans);
        return ans;
    }

    private void dfs(int start, int k, int remain, List<Integer> path, List<List<Integer>> ans) {
        if (path.size() == k) {
            if (remain == 0) ans.add(new ArrayList<>(path));
            return;
        }
        for (int x = start; x <= 9; x++) {
            if (remain - x < 0) break;
            path.add(x);
            dfs(x + 1, k, remain - x, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(C(9,k))\)
- 空间：\(O(k)\)（递归栈）

## 总结（速记）
- 组合类题：从 `start` 往后选，递归时 `start=x+1` 保证不重复。
