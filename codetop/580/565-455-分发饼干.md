# 455. 分发饼干

- 题号：455
- 难度：简单
- LeetCode：[分发饼干](https://leetcode.cn/problems/assign-cookies/)

## 题目描述
每个孩子有一个胃口值 `g[i]`，每块饼干有大小 `s[j]`，若 `s[j] >= g[i]` 则可以满足该孩子。每块饼干最多给一个孩子，求最多能满足多少孩子。

## 示例
- 示例  
输入：`g = [1,2,3]`, `s = [1,1]`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：排序 + 双指针贪心  
优先用最小的饼干去满足胃口最小的孩子。  
排序后，用指针遍历：若当前饼干能满足当前孩子，就计数并移动到下一个孩子；否则换更大的饼干。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);
        int i = 0, j = 0;
        int ans = 0;
        while (i < g.length && j < s.length) {
            if (s[j] >= g[i]) {
                ans++;
                i++;
                j++;
            } else {
                j++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)
