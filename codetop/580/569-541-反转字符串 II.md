# 541. 反转字符串 II

- 题号：541
- 难度：简单
- LeetCode：[反转字符串 II](https://leetcode.cn/problems/reverse-string-ii/)

## 题目描述
给定字符串 `s` 和整数 `k`，从左到右每 `2k` 个字符为一组：反转前 `k` 个字符；若剩余不足 `k` 全部反转；若在 `[k,2k)` 仅反转前 `k` 个。

## 示例
- 示例  
输入：`s = "abcdefg", k = 2`  
输出：`"bacdfeg"`

## 最佳解法思路
- 思路1（推荐）：按块处理  
把字符串转成数组。每次从 `i` 开始，反转 `[i, min(i+k-1, n-1)]`，然后 `i += 2k`。

## Java 最佳实现

```java
class Solution {
    public String reverseStr(String s, int k) {
        char[] a = s.toCharArray();
        int n = a.length;
        for (int i = 0; i < n; i += 2 * k) {
            int l = i;
            int r = Math.min(i + k - 1, n - 1);
            while (l < r) {
                char t = a[l];
                a[l] = a[r];
                a[r] = t;
                l++;
                r--;
            }
        }
        return new String(a);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（字符数组）

## 总结（速记）
- 每 `2k` 一段，只反转前 `k`：`i += 2k` 循环即可。
