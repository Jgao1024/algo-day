# 314. 二叉树的垂直遍历

- 题号：314
- 难度：中等
- LeetCode：[二叉树的垂直遍历](https://leetcode.cn/problems/binary-tree-vertical-order-traversal/)

## 题目描述
按“列”从左到右输出二叉树：根节点列为 0，左孩子列 -1，右孩子列 +1。每列中从上到下、同层从左到右。

## 示例
- 示例  
输入：`root = [3,9,20,null,null,15,7]`  
输出：`[[9],[3,15],[20],[7]]`

## 最佳解法思路
- 思路1（推荐）：BFS + 列号映射  
用队列做层序遍历，并给每个节点带上列号 `col`。  
用 `Map<col, List<val>>` 收集每列的节点值；BFS 能保证“从上到下、同层从左到右”。  
同时维护 `minCol/maxCol`，最后从 `minCol` 到 `maxCol` 依次输出。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) return ans;

        Map<Integer, List<Integer>> map = new HashMap<>();
        Deque<TreeNode> nq = new ArrayDeque<>();
        Deque<Integer> cq = new ArrayDeque<>();
        nq.offer(root);
        cq.offer(0);
        int min = 0, max = 0;

        while (!nq.isEmpty()) {
            TreeNode node = nq.poll();
            int col = cq.poll();
            map.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);
            if (col < min) min = col;
            if (col > max) max = col;

            if (node.left != null) {
                nq.offer(node.left);
                cq.offer(col - 1);
            }
            if (node.right != null) {
                nq.offer(node.right);
                cq.offer(col + 1);
            }
        }

        for (int c = min; c <= max; c++) ans.add(map.get(c));
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 垂直遍历想要“同层从左到右”，用 BFS 收集列即可，不要用 DFS。
