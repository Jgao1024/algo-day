# 1669. 合并两个链表

- 题号：1669
- 难度：中等
- LeetCode：[合并两个链表](https://leetcode.cn/problems/merge-in-between-linked-lists/)

## 题目描述
给定链表 `list1`、`list2` 和下标 `a`、`b`，把 `list1` 中 `[a,b]` 这一段替换为 `list2`，返回合并后的链表。

## 示例
- 示例  
输入：`list1 = [0,1,2,3,4,5]`, `a = 3`, `b = 4`, `list2 = [1000000,1000001,1000002]`  
输出：`[0,1,2,1000000,1000001,1000002,5]`

## 最佳解法思路
- 思路1（推荐）：定位两端 + 拼接  
找到 `a-1` 位置的节点 `preA`，以及 `b` 位置的节点 `nodeB`，记录 `afterB = nodeB.next`。  
再找到 `list2` 的尾节点 `tail2`。  
拼接：`preA.next = list2`，`tail2.next = afterB`。

## Java 最佳实现

```java
class Solution {
    public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
        ListNode preA = list1;
        for (int i = 0; i < a - 1; i++) preA = preA.next;

        ListNode nodeB = preA;
        for (int i = 0; i < b - a + 2; i++) nodeB = nodeB.next;
        ListNode afterB = nodeB;

        ListNode tail2 = list2;
        while (tail2.next != null) tail2 = tail2.next;

        preA.next = list2;
        tail2.next = afterB;
        return list1;
    }
}
```

## 复杂度分析
- 时间：\(O(n+m)\)
- 空间：\(O(1)\)

## 总结（速记）
- 三个关键点：`preA`、`afterB`、`tail2`，把它们两次 next 指向连起来即可。
