# 剑指 Offer 49. 丑数

- 题号：剑指 Offer 49
- 难度：中等
- LeetCode：[丑数](https://leetcode.cn/problems/chou-shu-lcof/)

## 题目描述
求第 `n` 个丑数（只包含质因子 2、3、5 的正整数，1 为第一个丑数）。

## 示例
- 示例  
输入：`n = 10`  
输出：`12`

## 最佳解法思路
- 思路1（推荐）：DP + 三指针  
丑数序列是递增的。设 `dp[i]` 为第 i 个丑数。  
用三个指针 `p2/p3/p5` 指向下一次乘 2/3/5 的位置：  
`dp[i] = min(dp[p2]*2, dp[p3]*3, dp[p5]*5)`，谁命中就把对应指针前移（可能多个同时命中）。

## Java 最佳实现

```java
class Solution {
    public int nthUglyNumber(int n) {
        int[] dp = new int[n + 1];
        dp[1] = 1;
        int p2 = 1, p3 = 1, p5 = 1;
        for (int i = 2; i <= n; i++) {
            int a = dp[p2] * 2;
            int b = dp[p3] * 3;
            int c = dp[p5] * 5;
            int x = Math.min(a, Math.min(b, c));
            dp[i] = x;
            if (x == a) p2++;
            if (x == b) p3++;
            if (x == c) p5++;
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 三指针分别管 2/3/5，下一个丑数取三者最小，命中谁就移动谁。
