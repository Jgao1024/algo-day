# 705. 设计哈希集合

- 题号：705
- 难度：简单
- LeetCode：[设计哈希集合](https://leetcode.cn/problems/design-hashset/)

## 题目描述
设计一个哈希集合，支持 `add/remove/contains`。

## 示例
- 示例  
`add(1)`  
`add(2)`  
`contains(1)` -> `true`  
`contains(3)` -> `false`  
`remove(2)`  
`contains(2)` -> `false`

## 最佳解法思路
- 思路1（推荐）：布尔数组（按题目值域）  
题目 key 范围是 `0..10^6`，用 `boolean[1000001]` 直接标记即可，所有操作都是 \(O(1)\)。

## Java 最佳实现

```java
class MyHashSet {
    private final boolean[] seen = new boolean[1000001];

    public MyHashSet() {
    }

    public void add(int key) {
        seen[key] = true;
    }

    public void remove(int key) {
        seen[key] = false;
    }

    public boolean contains(int key) {
        return seen[key];
    }
}
```

## 复杂度分析
- 时间：所有操作 \(O(1)\)
- 空间：\(O(10^6)\)
