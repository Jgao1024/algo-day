# 653. 两数之和 IV - 输入 BST

- 题号：653
- 难度：简单
- LeetCode：[两数之和 IV - 输入 BST](https://leetcode.cn/problems/two-sum-iv-input-is-a-bst/)

## 题目描述
给定 BST 根节点 `root` 和目标值 `k`，判断是否存在两个不同节点的值之和等于 `k`。

## 示例
- 示例  
输入：`root = [5,3,6,2,4,null,7]`, `k = 9`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：DFS + HashSet  
遍历节点值 `x`：若集合中存在 `k-x`，说明找到一对；否则把 `x` 加入集合继续遍历。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean findTarget(TreeNode root, int k) {
        return dfs(root, k, new HashSet<>());
    }

    private boolean dfs(TreeNode node, int k, Set<Integer> seen) {
        if (node == null) return false;
        if (seen.contains(k - node.val)) return true;
        seen.add(node.val);
        return dfs(node.left, k, seen) || dfs(node.right, k, seen);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 一边遍历一边存值，遇到 `k-x` 就返回 true。
