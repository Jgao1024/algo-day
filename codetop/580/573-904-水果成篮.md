# 904. 水果成篮

- 题号：904
- 难度：中等
- LeetCode：[水果成篮](https://leetcode.cn/problems/fruit-into-baskets/)

## 题目描述
给定数组 `fruits`，从某个位置开始向右连续采摘，篮子最多装两种水果，求能采摘的最大数量（即最长子数组长度，至多 2 种不同值）。

## 示例
- 示例  
输入：`fruits = [1,2,1]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：滑动窗口（至多两种）  
用哈希表统计窗口内每种水果数量，维护 `distinct`。  
右扩展加入元素；当 `distinct > 2` 时移动左边界缩窗直到 `distinct <= 2`，过程中更新最大长度。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> cnt = new HashMap<>();
        int l = 0, ans = 0;
        for (int r = 0; r < fruits.length; r++) {
            cnt.put(fruits[r], cnt.getOrDefault(fruits[r], 0) + 1);
            while (cnt.size() > 2) {
                int x = fruits[l++];
                int c = cnt.get(x) - 1;
                if (c == 0) cnt.remove(x);
                else cnt.put(x, c);
            }
            ans = Math.max(ans, r - l + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（最多 2 种水果）
