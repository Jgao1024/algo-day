# 1151. 最少交换次数来组合所有的 1

- 题号：1151
- 难度：中等
- LeetCode：[最少交换次数来组合所有的 1](https://leetcode.cn/problems/minimum-swaps-to-group-all-1s-together/)

## 题目描述
给定只包含 0/1 的数组 `data`，通过交换任意两个元素，使所有的 1 变成连续一段，返回最少交换次数。

## 示例
- 示例  
输入：`data = [1,0,1,0,1]`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：固定窗口滑动  
设数组中 1 的总数为 `ones`，最终连续段长度必须为 `ones`。  
在数组上滑动一个长度为 `ones` 的窗口，统计窗口内 1 的最大数量 `maxOnes`。  
需要交换的最少次数就是把窗口内的 0 换出去：`ones - maxOnes`。

## Java 最佳实现

```java
class Solution {
    public int minSwaps(int[] data) {
        int ones = 0;
        for (int x : data) ones += x;
        if (ones <= 1) return 0;

        int cur = 0;
        for (int i = 0; i < ones; i++) cur += data[i];
        int max = cur;

        for (int r = ones; r < data.length; r++) {
            cur += data[r] - data[r - ones];
            if (cur > max) max = cur;
        }
        return ones - max;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 把“所有 1 连在一起”转成“找长度为 ones 的窗口里 1 最多”，答案是窗口里 0 的个数。
