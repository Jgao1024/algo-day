# 813. 最大平均值和的分组

- 题号：813
- 难度：中等
- LeetCode：[最大平均值和的分组](https://leetcode.cn/problems/largest-sum-of-averages/)

## 题目描述
给定数组 `nums`，把它分成最多 `k` 个非空相邻子数组，最大化各子数组平均值之和。

## 示例
- 示例  
输入：`nums = [9,1,2,3,9]`, `k = 3`  
输出：`20.0`（[9],[1,2,3],[9]）

## 最佳解法思路
- 思路1（推荐）：DP 划分 + 前缀和  
设前缀和 `pre[i]` 表示前 i 个数的和。区间平均值：`avg(j,i)= (pre[i]-pre[j])/(i-j)`。  
`dp[t][i]`：把前 i 个数分成 t 组的最大得分。  
转移：`dp[t][i] = max_{j<t..i-1}(dp[t-1][j] + avg(j,i))`。  
答案为 `dp[k][n]`（k 组用不满也可，因为多分组不会更差）。

## Java 最佳实现

```java
class Solution {
    public double largestSumOfAverages(int[] nums, int k) {
        int n = nums.length;
        double[] pre = new double[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];

        double[][] dp = new double[k + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            dp[1][i] = (pre[i] - pre[0]) / i;
        }

        for (int t = 2; t <= k; t++) {
            for (int i = t; i <= n; i++) {
                double best = 0;
                for (int j = t - 1; j < i; j++) {
                    double avg = (pre[i] - pre[j]) / (i - j);
                    best = Math.max(best, dp[t - 1][j] + avg);
                }
                dp[t][i] = best;
            }
        }
        return dp[k][n];
    }
}
```

## 复杂度分析
- 时间：\(O(k\cdot n^2)\)
- 空间：\(O(k\cdot n)\)

- 切分 DP：前缀和算平均值，枚举最后一刀位置 `j` 做转移。
