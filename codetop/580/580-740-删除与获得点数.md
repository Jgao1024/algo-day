# 740. 删除与获得点数

- 题号：740
- 难度：中等
- LeetCode：[删除与获得点数](https://leetcode.cn/problems/delete-and-earn/)

## 题目描述
给定数组 `nums`。你可以选择一个数 `x` 并获得 `x` 点数（每个 `x` 计入点数），然后数组中所有 `x-1` 和 `x+1` 都会被删除。可重复选择，求能获得的最大点数。

## 示例
- 示例  
输入：`nums = [3,4,2]`  
输出：`6`（选 4 得 4，选 2 得 2）

## 最佳解法思路
- 思路1（推荐）：转化为打家劫舍  
把相同数字合并：`points[v] = v * count(v)`。  
选择 v 会禁用 v-1 和 v+1，等价于在一条线性数组上“相邻不能同时选”。  
用打家劫舍 DP：`dp[i] = max(dp[i-1], dp[i-2] + points[i])`。

## Java 最佳实现

```java
class Solution {
    public int deleteAndEarn(int[] nums) {
        int max = 0;
        for (int x : nums) if (x > max) max = x;
        int[] points = new int[max + 1];
        for (int x : nums) points[x] += x;

        int pre2 = 0, pre1 = 0;
        for (int i = 0; i <= max; i++) {
            int cur = Math.max(pre1, pre2 + points[i]);
            pre2 = pre1;
            pre1 = cur;
        }
        return pre1;
    }
}
```

## 复杂度分析
- 时间：\(O(n + \max(nums))\)
- 空间：\(O(\max(nums))\)

## 总结（速记）
- 先把同值累加成 `points[v]`，问题就变成“相邻不能选”的打家劫舍。
