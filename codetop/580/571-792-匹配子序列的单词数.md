# 792. 匹配子序列的单词数

- 题号：792
- 难度：中等
- LeetCode：[匹配子序列的单词数](https://leetcode.cn/problems/number-of-matching-subsequences/)

## 题目描述
给定字符串 `s` 和单词数组 `words`，返回 `words` 中是 `s` 子序列的单词数量。

## 示例
- 示例  
输入：`s = "abcde"`, `words = ["a","bb","acd","ace"]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：按“下一个需要匹配的字符”分桶  
把每个单词看成一个指针（当前匹配到第几位）。  
用 26 个队列 `bucket[c]` 存放“下一位要匹配字符为 c 的指针”。  
遍历 `s` 的每个字符 `ch`：取出 `bucket[ch]` 中所有指针，让它们指针前进一位：  
若单词匹配完就计数；否则按新的“下一位字符”放回对应桶。  
每个字符指针最多移动一次，总复杂度线性。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private static class Node {
        char[] w;
        int i;
        Node(char[] w, int i) { this.w = w; this.i = i; }
    }

    public int numMatchingSubseq(String s, String[] words) {
        @SuppressWarnings("unchecked")
        Deque<Node>[] buckets = new Deque[26];
        for (int i = 0; i < 26; i++) buckets[i] = new ArrayDeque<>();

        for (String w : words) {
            char[] a = w.toCharArray();
            buckets[a[0] - 'a'].offer(new Node(a, 0));
        }

        int ans = 0;
        for (int idx = 0; idx < s.length(); idx++) {
            int b = s.charAt(idx) - 'a';
            int size = buckets[b].size();
            for (int t = 0; t < size; t++) {
                Node node = buckets[b].poll();
                node.i++;
                if (node.i == node.w.length) {
                    ans++;
                } else {
                    buckets[node.w[node.i] - 'a'].offer(node);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(|s| + \sum|word|)\)
- 空间：\(O(\sum|word|)\)

## 总结（速记）
- 多个子序列别逐个扫：把“等待某个字符”的单词指针分桶，扫一遍 `s` 就能推进。
