# 773. 滑动谜题

- 题号：773
- 难度：困难
- LeetCode：[滑动谜题](https://leetcode.cn/problems/sliding-puzzle/)

## 题目描述
给定 2x3 的滑动谜题，0 表示空位。每次可把 0 与上下左右相邻数字交换，求到达目标 `[[1,2,3],[4,5,0]]` 的最少步数，不可达返回 -1。

## 示例
- 示例  
输入：`board = [[1,2,3],[4,0,5]]`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：BFS 最短路  
把棋盘编码成字符串（长度 6），状态数量最多 720。  
预先写好 0 在每个位置可交换的位置列表，BFS 层序扩展，第一次到达目标即最短步数。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class Solution {
    private static final int[][] NEXT = {
            {1, 3},
            {0, 2, 4},
            {1, 5},
            {0, 4},
            {1, 3, 5},
            {2, 4}
    };

    public int slidingPuzzle(int[][] board) {
        StringBuilder sb = new StringBuilder();
        for (int[] row : board) {
            for (int x : row) sb.append((char) ('0' + x));
        }
        String start = sb.toString();
        String target = "123450";
        if (start.equals(target)) return 0;

        Deque<String> q = new ArrayDeque<>();
        Set<String> vis = new HashSet<>();
        q.offer(start);
        vis.add(start);
        int step = 0;

        while (!q.isEmpty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                String cur = q.poll();
                if (cur.equals(target)) return step;
                int z = cur.indexOf('0');
                for (int to : NEXT[z]) {
                    String next = swap(cur, z, to);
                    if (vis.add(next)) q.offer(next);
                }
            }
            step++;
        }
        return -1;
    }

    private String swap(String s, int i, int j) {
        char[] a = s.toCharArray();
        char t = a[i];
        a[i] = a[j];
        a[j] = t;
        return new String(a);
    }
}
```

## 复杂度分析
- 时间：\(O(\text{状态数})\)（最多 720）
- 空间：\(O(\text{状态数})\)
