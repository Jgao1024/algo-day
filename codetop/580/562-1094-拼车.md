# 1094. 拼车

- 题号：1094
- 难度：中等
- LeetCode：[拼车](https://leetcode.cn/problems/car-pooling/)

## 题目描述
给定若干行程 `trips[i] = [numPassengers, from, to]`，表示从 `from` 上车、到 `to` 下车（不包含 `to`）。问容量 `capacity` 是否足够承载全程。

## 示例
- 示例  
输入：`trips = [[2,1,5],[3,3,7]]`, `capacity = 4`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：差分数组 + 前缀和  
在 `from` 位置 +num，在 `to` 位置 -num。对差分做前缀和就是每个位置车上人数，过程中若超过容量返回 false。  
题目位置范围固定（0..1000），用数组即可。

## Java 最佳实现

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int[] diff = new int[1001];
        for (int[] t : trips) {
            int num = t[0], from = t[1], to = t[2];
            diff[from] += num;
            if (to <= 1000) diff[to] -= num;
        }
        int cur = 0;
        for (int i = 0; i <= 1000; i++) {
            cur += diff[i];
            if (cur > capacity) return false;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(1000 + \text{trips})\)
- 空间：\(O(1000)\)
