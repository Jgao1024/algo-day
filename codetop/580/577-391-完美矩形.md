# 391. 完美矩形

- 题号：391
- 难度：困难
- LeetCode：[完美矩形](https://leetcode.cn/problems/perfect-rectangle/)

## 题目描述
给定多个小矩形 `rectangles[i]=[x1,y1,x2,y2]`，判断它们是否能无重叠、无空隙地拼成一个完美大矩形。

## 示例
- 示例  
输入：`[[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：面积校验 + 四角奇偶性  
必要且充分条件：  
1) 所有小矩形面积之和 == 外接大矩形面积  
2) 除了大矩形四个角外，其他所有角点都应出现偶数次（被抵消）  
做法：  
- 维护外接矩形的 `minX/minY/maxX/maxY`，累计面积 `sum`  
- 用集合 `set` 对每个小矩形的四个角做“异或”效果：出现一次加入，出现第二次移除  
最后判断：`sum == (maxX-minX)*(maxY-minY)` 且 `set` 只剩 4 个角，并且正好是外接矩形四角。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isRectangleCover(int[][] rectangles) {
        int minX = Integer.MAX_VALUE, minY = Integer.MAX_VALUE;
        int maxX = Integer.MIN_VALUE, maxY = Integer.MIN_VALUE;
        long area = 0;
        Set<String> set = new HashSet<>();

        for (int[] r : rectangles) {
            int x1 = r[0], y1 = r[1], x2 = r[2], y2 = r[3];
            minX = Math.min(minX, x1);
            minY = Math.min(minY, y1);
            maxX = Math.max(maxX, x2);
            maxY = Math.max(maxY, y2);
            area += (long) (x2 - x1) * (y2 - y1);

            toggle(set, x1, y1);
            toggle(set, x1, y2);
            toggle(set, x2, y1);
            toggle(set, x2, y2);
        }

        long bound = (long) (maxX - minX) * (maxY - minY);
        if (area != bound) return false;

        if (set.size() != 4) return false;
        return set.contains(key(minX, minY))
                && set.contains(key(minX, maxY))
                && set.contains(key(maxX, minY))
                && set.contains(key(maxX, maxY));
    }

    private void toggle(Set<String> set, int x, int y) {
        String k = key(x, y);
        if (!set.add(k)) set.remove(k);
    }

    private String key(int x, int y) {
        return x + "," + y;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 完美矩形=面积对上 + 角点只剩四个外角（其余角必须成对抵消）。
