# 474. 一和零

- 题号：474
- 难度：中等
- LeetCode：[一和零](https://leetcode.cn/problems/ones-and-zeroes/)

## 题目描述
给定二进制字符串数组 `strs`，以及 `m` 个 0、`n` 个 1 的容量，求最多能选多少个字符串，使得选中字符串中 0 的总数不超过 m、1 的总数不超过 n。

## 示例
- 示例  
输入：`strs = ["10","0001","111001","1","0"]`, `m = 5`, `n = 3`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：二维 0/1 背包  
每个字符串是一个物品，消耗 `(zeros, ones)`，价值为 1。  
`dp[i][j]` 表示在 0 容量 i、1 容量 j 下能选的最多数量。  
对每个字符串倒序更新：`dp[i][j] = max(dp[i][j], dp[i-z][j-o] + 1)`。

## Java 最佳实现

```java
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        int[][] dp = new int[m + 1][n + 1];
        for (String s : strs) {
            int z = 0, o = 0;
            for (int i = 0; i < s.length(); i++) {
                if (s.charAt(i) == '0') z++;
                else o++;
            }
            for (int i = m; i >= z; i--) {
                for (int j = n; j >= o; j--) {
                    dp[i][j] = Math.max(dp[i][j], dp[i - z][j - o] + 1);
                }
            }
        }
        return dp[m][n];
    }
}
```

## 复杂度分析
- 时间：\(O(|strs|\cdot m \cdot n)\)
- 空间：\(O(mn)\)

## 总结（速记）
- “两种容量限制 + 选最多个”就是二维 0/1 背包，注意倒序更新避免重复选。
