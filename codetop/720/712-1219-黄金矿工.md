## 最佳解法思路
- 回溯：从每个有金子的格子出发 DFS，走过的格子暂时置 0 表示已访问，四方向探索，取最大路径和。

## Java 最佳实现

```java
class Solution {
    private int m;
    private int n;
    private int[][] g;
    private final int[] dr = {1, -1, 0, 0};
    private final int[] dc = {0, 0, 1, -1};

    public int getMaximumGold(int[][] grid) {
        g = grid;
        m = grid.length;
        n = grid[0].length;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (g[i][j] > 0) ans = Math.max(ans, dfs(i, j));
            }
        }
        return ans;
    }

    private int dfs(int r, int c) {
        int val = g[r][c];
        g[r][c] = 0;
        int best = 0;
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            if (g[nr][nc] == 0) continue;
            best = Math.max(best, dfs(nr, nc));
        }
        g[r][c] = val;
        return val + best;
    }
}
```

## 复杂度分析
- 时间：最坏指数级（路径枚举）
- 空间：递归深度 \(O(mn)\)
