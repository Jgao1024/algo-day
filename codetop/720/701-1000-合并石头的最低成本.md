## 最佳解法思路
- 区间 DP：每次必须合并 `K` 堆，所以只有当 `(n - 1) % (K - 1) == 0` 时才能最终合成 1 堆，否则返回 `-1`。
- `dp[i][j]` 表示把区间 `[i..j]` 合并到“尽可能少的堆”（按规则合并）的最小成本。  
  转移只在分割点按步长 `K-1` 枚举：`dp[i][j] = min(dp[i][m] + dp[m+1][j])`。  
  当 `(len - 1) % (K - 1) == 0` 时，说明这段能合成 1 堆，再额外加上区间和。
- 用前缀和算区间和。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int mergeStones(int[] stones, int K) {
        int n = stones.length;
        if ((n - 1) % (K - 1) != 0) return -1;

        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stones[i];

        int[][] dp = new int[n][n];
        for (int i = 0; i < n; i++) Arrays.fill(dp[i], 1_000_000_000);
        for (int i = 0; i < n; i++) dp[i][i] = 0;

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                for (int m = i; m < j; m += (K - 1)) {
                    dp[i][j] = Math.min(dp[i][j], dp[i][m] + dp[m + 1][j]);
                }
                if ((len - 1) % (K - 1) == 0) {
                    dp[i][j] += pre[j + 1] - pre[i];
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n^3/(K-1))\)
- 空间：\(O(n^2)\)
