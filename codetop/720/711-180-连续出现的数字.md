## 最佳解法思路
- 题目原本是 SQL：按 `id` 顺序找 `num` 连续出现 3 次的值。
- 用 Java 表达：遍历按 `id` 排序的记录，维护当前 `num` 的连续长度，长度达到 3 就加入结果集合。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    static class Log {
        int id;
        int num;
        Log(int id, int num) { this.id = id; this.num = num; }
    }

    public List<Integer> consecutiveNumbers(List<Log> logs) {
        Set<Integer> res = new HashSet<>();
        Integer prevNum = null;
        int run = 0;
        for (Log log : logs) {
            if (prevNum != null && log.num == prevNum) {
                run++;
            } else {
                prevNum = log.num;
                run = 1;
            }
            if (run >= 3) res.add(log.num);
        }
        return new ArrayList<>(res);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(ans)\)
