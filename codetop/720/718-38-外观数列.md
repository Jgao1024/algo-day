## 最佳解法思路
- 迭代生成：从 `"1"` 开始，每次把上一项按“连续相同字符的个数 + 字符”描述出来。

## Java 最佳实现

```java
class Solution {
    public String countAndSay(int n) {
        String s = "1";
        for (int i = 2; i <= n; i++) {
            s = next(s);
        }
        return s;
    }

    private String next(String s) {
        StringBuilder sb = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            int j = i + 1;
            while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
            sb.append(j - i).append(s.charAt(i));
            i = j;
        }
        return sb.toString();
    }
}
```
