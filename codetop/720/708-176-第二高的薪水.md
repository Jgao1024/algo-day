## 最佳解法思路
- 题目原本是 SQL：找“去重后第 2 大”的薪水，没有就返回空。
- 用 Java 表达：遍历时维护最大值 `first` 和第二大 `second`（都按“不同值”处理）。

## Java 最佳实现

```java
class Solution {
    // 没有第二高返回 null
    public Integer secondHighest(int[] salary) {
        Long first = null;
        Long second = null;
        for (int x : salary) {
            long v = x;
            if (first != null && v == first) continue;
            if (second != null && v == second) continue;

            if (first == null || v > first) {
                second = first;
                first = v;
            } else if (second == null || (v < first && v > second)) {
                second = v;
            }
        }
        return second == null ? null : second.intValue();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
