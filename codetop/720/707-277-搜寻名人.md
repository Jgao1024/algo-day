## 最佳解法思路
- 先用“淘汰法”找候选人：从 0 开始，若 `cand` 认识 `i`，则 `cand` 不可能是名人，候选变成 `i`。
- 再验证候选：候选不认识任何人，且所有人都认识候选。

## Java 最佳实现

```java
/* The knows API is defined in the parent class Relation.
      boolean knows(int a, int b); */

class Solution extends Relation {
    public int findCelebrity(int n) {
        int cand = 0;
        for (int i = 1; i < n; i++) {
            if (knows(cand, i)) cand = i;
        }

        for (int i = 0; i < n; i++) {
            if (i == cand) continue;
            if (knows(cand, i)) return -1;
            if (!knows(i, cand)) return -1;
        }
        return cand;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
