## 最佳解法思路
- 原地反转：先整体反转，再逐个把每个单词反转回来。

## Java 最佳实现

```java
class Solution {
    public void reverseWords(char[] s) {
        reverse(s, 0, s.length - 1);
        int i = 0;
        while (i < s.length) {
            int j = i;
            while (j < s.length && s[j] != ' ') j++;
            reverse(s, i, j - 1);
            i = j + 1;
        }
    }

    private void reverse(char[] a, int l, int r) {
        while (l < r) {
            char t = a[l];
            a[l] = a[r];
            a[r] = t;
            l++;
            r--;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
