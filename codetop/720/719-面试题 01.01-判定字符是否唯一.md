## 最佳解法思路
- 用数组记录字符是否出现过；出现重复直接返回 `false`。

## Java 最佳实现

```java
class Solution {
    public boolean isUnique(String astr) {
        boolean[] seen = new boolean[128];
        for (int i = 0; i < astr.length(); i++) {
            int c = astr.charAt(i);
            if (c >= 128) {
                // 题目通常限定 ASCII，这里按 ASCII 处理即可
                continue;
            }
            if (seen[c]) return false;
            seen[c] = true;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
