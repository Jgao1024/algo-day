## 最佳解法思路
- 异或后统计 1 的个数：`bitCount(x ^ y)`。

## Java 最佳实现

```java
class Solution {
    public int hammingDistance(int x, int y) {
        return Integer.bitCount(x ^ y);
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
