## 最佳解法思路
- 把起始 IP 转成 32 位整数 `x`，每次尽量取最大的 CIDR 块：  
  - 块大小必须是 2 的幂，且对齐（`lowbit(x)`）  
  - 块大小不能超过剩余数量 `n`
- 取到块大小 `size` 后输出 `ip/mask`，并 `x += size`，`n -= size`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> ipToCIDR(String ip, int n) {
        long x = ipToLong(ip);
        List<String> res = new ArrayList<>();
        while (n > 0) {
            long lowbit = x & -x;
            long size = lowbit == 0 ? (1L << 32) : lowbit;
            while (size > n) size >>= 1;

            int mask = 32 - log2(size);
            res.add(longToIp(x) + "/" + mask);

            x += size;
            n -= (int) size;
        }
        return res;
    }

    private long ipToLong(String ip) {
        String[] p = ip.split("\\.");
        long x = 0;
        for (int i = 0; i < 4; i++) {
            x = (x << 8) + Integer.parseInt(p[i]);
        }
        return x;
    }

    private String longToIp(long x) {
        return ((x >> 24) & 255) + "." + ((x >> 16) & 255) + "." + ((x >> 8) & 255) + "." + (x & 255);
    }

    private int log2(long x) {
        int k = 0;
        while ((1L << k) < x) k++;
        return k;
    }
}
```

## 复杂度分析
- 时间：\(O(ans)\)（输出块的数量）
- 空间：\(O(ans)\)
