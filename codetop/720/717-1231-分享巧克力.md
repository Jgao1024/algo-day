## 最佳解法思路
- 二分答案：想让每个人拿到的最小甜度最大。
- 检查 `mid`：从左到右累加，和 \(\ge mid\) 就切一段，能切出段数 \(\ge k+1\) 则可行。

## Java 最佳实现

```java
class Solution {
    public int maximizeSweetness(int[] sweetness, int k) {
        int lo = 1;
        int hi = 0;
        for (int v : sweetness) hi += v;
        hi /= (k + 1);

        int ans = 0;
        while (lo <= hi) {
            int mid = lo + ((hi - lo) >>> 1);
            if (can(sweetness, k + 1, mid)) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return ans;
    }

    private boolean can(int[] a, int needParts, int minSum) {
        int parts = 0;
        int cur = 0;
        for (int v : a) {
            cur += v;
            if (cur >= minSum) {
                parts++;
                cur = 0;
            }
        }
        return parts >= needParts;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log S)\)，\(S\) 为总甜度
- 空间：\(O(1)\)
