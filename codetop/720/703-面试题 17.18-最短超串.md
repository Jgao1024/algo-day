## 最佳解法思路
- 滑动窗口：在 `big` 中找一个最短连续子数组，包含 `small` 的所有元素（一般 `small` 无重复）。
- 用 `need` 记录每个目标数需要次数（通常为 1），窗口内用 `cnt` 统计；当满足全部需求后收缩左边界更新答案。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] shortestSeq(int[] big, int[] small) {
        Map<Integer, Integer> need = new HashMap<>();
        for (int x : small) need.put(x, need.getOrDefault(x, 0) + 1);

        Map<Integer, Integer> cnt = new HashMap<>();
        int miss = small.length;

        int bestL = -1, bestR = -1;
        int left = 0;
        for (int right = 0; right < big.length; right++) {
            int x = big[right];
            if (need.containsKey(x)) {
                int c = cnt.getOrDefault(x, 0) + 1;
                cnt.put(x, c);
                if (c <= need.get(x)) miss--;
            }

            while (miss == 0 && left <= right) {
                if (bestL == -1 || right - left < bestR - bestL) {
                    bestL = left;
                    bestR = right;
                }

                int y = big[left++];
                if (need.containsKey(y)) {
                    int c = cnt.get(y) - 1;
                    cnt.put(y, c);
                    if (c < need.get(y)) miss++;
                }
            }
        }

        return bestL == -1 ? new int[0] : new int[]{bestL, bestR};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(|small|)\)
