## 最佳解法思路
- 排序后贪心：把每个数至少变成 `prev+1`。
- 累加需要增加的次数。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minIncrementForUnique(int[] nums) {
        Arrays.sort(nums);
        long ans = 0;
        int prev = Integer.MIN_VALUE;
        for (int x : nums) {
            if (x <= prev) {
                ans += (long) (prev + 1 - x);
                prev = prev + 1;
            } else {
                prev = x;
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（排序栈空间不计）
