## 最佳解法思路
- 异或：数组包含 `1..n` 缺两个数 `a,b`，先算 `xor = a ^ b`。
- 取 `lowbit = xor & -xor`，用这一位把所有数分两组分别异或，就能拆出 `a`、`b`。

## Java 最佳实现

```java
class Solution {
    public int[] missingTwo(int[] nums) {
        int n = nums.length + 2;
        int xor = 0;
        for (int i = 1; i <= n; i++) xor ^= i;
        for (int v : nums) xor ^= v;

        int lowbit = xor & -xor;
        int a = 0, b = 0;
        for (int i = 1; i <= n; i++) {
            if ((i & lowbit) == 0) a ^= i;
            else b ^= i;
        }
        for (int v : nums) {
            if ((v & lowbit) == 0) a ^= v;
            else b ^= v;
        }
        return new int[]{a, b};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
