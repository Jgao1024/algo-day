# 280. 摆动排序

- 题号：280
- 难度：中等
- LeetCode：[摆动排序](https://leetcode.cn/problems/wiggle-sort/)

## 题目描述
给定数组 `nums`，原地重排使得：
`nums[0] <= nums[1] >= nums[2] <= nums[3] >= ...`

## 示例
- `nums = [3,5,2,1,6,4]`  
一种输出：`[3,5,1,6,2,4]`

## 最佳解法思路
- 一次遍历：
  - i 为奇数时需要 `nums[i] >= nums[i-1]`
  - i 为偶数时需要 `nums[i] <= nums[i-1]`
- 不满足就交换相邻两个数。

## Java 最佳实现

```java
class Solution {
    public void wiggleSort(int[] nums) {
        for (int i = 1; i < nums.length; i++) {
            if ((i & 1) == 1) {
                if (nums[i] < nums[i - 1]) {
                    swap(nums, i, i - 1);
                }
            } else {
                if (nums[i] > nums[i - 1]) {
                    swap(nums, i, i - 1);
                }
            }
        }
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
