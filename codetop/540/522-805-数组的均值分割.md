# 805. 数组的均值分割

- 题号：805
- 难度：困难
- LeetCode：[数组的均值分割](https://leetcode.cn/problems/split-array-with-same-average/)

## 题目描述
给定数组 `nums`，判断能否把它分成两个非空子集 A、B，使得 `avg(A) == avg(B)`。

## 示例
- `nums = [1,2,3,4,5,6,7,8]`，输出 `true`
- `nums = [3,1]`，输出 `false`

## 最佳解法思路
- 设总和 `sum`，长度 `n`。若存在子集大小 `k`、子集和 `s` 满足 `s/k == sum/n`，等价于 `s*n == sum*k`。
- 转换：令 `a[i] = nums[i] * n - sum`，则目标变成：是否存在非空且不全选的子集，使其元素和为 0。
- 用 DP + HashSet：`dp[k]` 存“选 k 个数能得到的所有和”，逐个加入元素并倒序更新 k；若某个 `dp[k]` 包含 0（`1<=k<n`）则为真。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean splitArraySameAverage(int[] nums) {
        int n = nums.length;
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }

        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = nums[i] * n - sum;
        }

        @SuppressWarnings("unchecked")
        Set<Integer>[] dp = new Set[n + 1];
        for (int i = 0; i <= n; i++) {
            dp[i] = new HashSet<>();
        }
        dp[0].add(0);

        for (int x : a) {
            for (int k = n - 1; k >= 1; k--) {
                if (dp[k - 1].isEmpty()) {
                    continue;
                }
                for (int s : dp[k - 1]) {
                    dp[k].add(s + x);
                }
            }
        }

        for (int k = 1; k < n; k++) {
            if (dp[k].contains(0)) {
                return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：约 \(O(n^2 \cdot S)\)（S 为可达和的数量，依数据而定）
- 空间：\(O(n \cdot S)\)
