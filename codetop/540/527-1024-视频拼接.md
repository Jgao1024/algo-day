# 1024. 视频拼接

- 题号：1024
- 难度：中等
- LeetCode：[视频拼接](https://leetcode.cn/problems/video-stitching/)

## 题目描述
给定若干视频片段 `clips[i] = [start,end]`，把它们剪辑成覆盖区间 `[0, time]`，返回最少片段数；无法覆盖返回 -1。

## 示例
- `clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]], time = 10`，输出 `3`
- `clips = [[0,1],[1,2]], time = 5`，输出 `-1`

## 最佳解法思路
- 贪心（类似跳跃游戏）：
  - 用 `maxEnd[s]` 记录“起点为 s 的片段能到的最远 end”
  - 从 0 开始扫描到 `time-1`，维护当前能到的最远 `far`
  - 当扫描到当前覆盖边界 `end` 时，必须选一次片段让 `end = far`，计数 +1
  - 若 `far <= i` 说明断开，返回 -1

## Java 最佳实现

```java
class Solution {
    public int videoStitching(int[][] clips, int time) {
        int[] maxEnd = new int[time + 1];
        for (int[] c : clips) {
            int s = c[0];
            int e = c[1];
            if (s > time) {
                continue;
            }
            if (e > maxEnd[s]) {
                maxEnd[s] = e;
            }
        }

        int ans = 0;
        int end = 0;
        int far = 0;
        for (int i = 0; i < time; i++) {
            far = Math.max(far, maxEnd[i]);
            if (far <= i) {
                return -1;
            }
            if (i == end) {
                ans++;
                end = far;
                if (end >= time) {
                    return ans;
                }
            }
        }
        return end >= time ? ans : -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n + time)\)
- 空间：\(O(time)\)
