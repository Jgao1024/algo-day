# 538. 把二叉搜索树转换为累加树

- 题号：538
- 难度：简单
- LeetCode：[把二叉搜索树转换为累加树](https://leetcode.cn/problems/convert-bst-to-greater-tree/)

## 题目描述
给定二叉搜索树，把每个节点值更新为“原值 + 所有大于它的节点值之和”。

## 示例
输入：`root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]`

## 最佳解法思路
- 反向中序遍历（右-根-左），累加一个 `sum`：
  - 先访问大的节点累加到 `sum`
  - 再把当前节点改成 `sum`

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int sum = 0;

    public TreeNode convertBST(TreeNode root) {
        dfs(root);
        return root;
    }

    private void dfs(TreeNode node) {
        if (node == null) {
            return;
        }
        dfs(node.right);
        sum += node.val;
        node.val = sum;
        dfs(node.left);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）
