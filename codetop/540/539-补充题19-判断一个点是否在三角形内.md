# 补充题19. 判断一个点是否在三角形内

- 题号：补充题19
- 难度：中等
- LeetCode：[判断一个点是否在三角形内](https://mp.weixin.qq.com/s/UK7ilkFeEDQeVWvLDHbuKA)

## 题目描述
给定三角形三个顶点 A、B、C（二维坐标）和点 P，判断 P 是否在三角形内（含边界）。

## 示例
- A(0,0) B(4,0) C(0,4)，P(1,1) => `true`
- A(0,0) B(4,0) C(0,4)，P(4,4) => `false`

## 最佳解法思路
- 叉积同向法：计算
  - `cross(A,B,P)`、`cross(B,C,P)`、`cross(C,A,P)`
- 若三个叉积全都 >= 0，或全都 <= 0，则 P 在三角形内（含边界）。

## Java 最佳实现

```java
class Solution {
    public boolean isPointInTriangle(int ax, int ay, int bx, int by, int cx, int cy, int px, int py) {
        long c1 = cross(ax, ay, bx, by, px, py);
        long c2 = cross(bx, by, cx, cy, px, py);
        long c3 = cross(cx, cy, ax, ay, px, py);
        return (c1 >= 0 && c2 >= 0 && c3 >= 0) || (c1 <= 0 && c2 <= 0 && c3 <= 0);
    }

    private long cross(int ax, int ay, int bx, int by, int px, int py) {
        long x1 = bx - ax;
        long y1 = by - ay;
        long x2 = px - ax;
        long y2 = py - ay;
        return x1 * y2 - y1 * x2;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
