# 1156. 单字符重复子串的最大长度

- 题号：1156
- 难度：中等
- LeetCode：[单字符重复子串的最大长度](https://leetcode.cn/problems/swap-for-longest-repeated-character-substring/)

## 题目描述
给定字符串 `text`，你可以最多交换一次任意两个字符，返回交换后“只包含同一字符”的最长子串长度。

## 示例
- `text = "ababa"`，输出 `3`
- `text = "aaabaaa"`，输出 `6`
- `text = "aaaaa"`，输出 `5`

## 最佳解法思路
- 先统计每个字符总次数 `total[c]`。
- 把字符串压缩成连续段：`(char, len)`。
- 对每一段：
  - 基本：`len + 1`（若还有同字符在别处可换进来），上限是 `total[c]`
  - 合并：若出现 `aaa b aaa` 这种“中间只隔 1 个其它字符”的模式，可把两段合并，再看是否还能额外 +1
- 取最大值。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int maxRepOpt1(String text) {
        int n = text.length();
        int[] total = new int[26];
        for (int i = 0; i < n; i++) {
            total[text.charAt(i) - 'a']++;
        }

        List<Character> ch = new ArrayList<>();
        List<Integer> len = new ArrayList<>();
        for (int i = 0; i < n; ) {
            char c = text.charAt(i);
            int j = i + 1;
            while (j < n && text.charAt(j) == c) {
                j++;
            }
            ch.add(c);
            len.add(j - i);
            i = j;
        }

        int ans = 0;
        for (int i = 0; i < ch.size(); i++) {
            int c = ch.get(i) - 'a';
            int l1 = len.get(i);
            ans = Math.max(ans, Math.min(l1 + 1, total[c]));

            if (i + 2 < ch.size() && ch.get(i) == ch.get(i + 2) && len.get(i + 1) == 1) {
                int merged = len.get(i) + len.get(i + 2);
                if (total[c] > merged) {
                    merged++;
                }
                ans = Math.max(ans, merged);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（段数组）
