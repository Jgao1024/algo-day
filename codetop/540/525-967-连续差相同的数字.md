# 967. 连续差相同的数字

- 题号：967
- 难度：中等
- LeetCode：[连续差相同的数字](https://leetcode.cn/problems/numbers-with-same-consecutive-differences/)

## 题目描述
给定整数 `n` 和 `k`，返回所有长度为 `n` 的非负整数，使得任意相邻两位数字的差的绝对值为 `k`。数字不能有前导 0（除非 n=1）。

## 示例
- `n = 3, k = 7`，输出 `[181,292,707,818,929]`
- `n = 2, k = 1`，输出 `[10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]`

## 最佳解法思路
- DFS 生成：从首位 `1..9` 开始，每次根据末位 `d` 生成 `d+k` / `d-k`（在 0..9 之间）。
- `k == 0` 时要去重（只走一个分支）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] numsSameConsecDiff(int n, int k) {
        List<Integer> res = new ArrayList<>();
        if (n == 1) {
            for (int i = 0; i <= 9; i++) {
                res.add(i);
            }
        } else {
            for (int first = 1; first <= 9; first++) {
                dfs(n - 1, k, first, res);
            }
        }
        int[] ans = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            ans[i] = res.get(i);
        }
        return ans;
    }

    private void dfs(int left, int k, int num, List<Integer> res) {
        if (left == 0) {
            res.add(num);
            return;
        }

        int last = num % 10;
        int a = last + k;
        int b = last - k;

        if (a >= 0 && a <= 9) {
            dfs(left - 1, k, num * 10 + a, res);
        }
        if (k != 0 && b >= 0 && b <= 9) {
            dfs(left - 1, k, num * 10 + b, res);
        }
    }
}
```

## 复杂度分析
- 时间：结果规模级别（最多约 \(9 \cdot 2^{n-1}\)）
- 空间：递归栈 \(O(n)\)
