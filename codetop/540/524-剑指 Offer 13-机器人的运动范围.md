# 剑指 Offer 13. 机器人的运动范围

- 题号：剑指 Offer 13
- 难度：中等
- LeetCode：[机器人的运动范围](https://leetcode.cn/problems/ji-qi-ren-de-yun-dong-fan-wei-lcof/)

## 题目描述
地上有一个 `m x n` 方格，机器人从 `(0,0)` 出发，只能上下左右移动。坐标 `(i,j)` 只有在 `i` 的数位和 + `j` 的数位和 <= `k` 时才能进入。求机器人能到达的格子数。

## 示例
- `m = 2, n = 3, k = 1`，输出 `3`
- `m = 3, n = 1, k = 0`，输出 `1`

## 最佳解法思路
- BFS/DFS 遍历可达点，`visited` 防重复。
- 每次判断 `(i,j)` 是否越界、是否已访问、数位和是否 <= k。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int movingCount(int m, int n, int k) {
        boolean[][] vis = new boolean[m][n];
        Queue<int[]> q = new ArrayDeque<>();

        if (!ok(0, 0, k)) {
            return 0;
        }
        q.offer(new int[]{0, 0});
        vis[0][0] = true;

        int ans = 0;
        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            ans++;
            for (int t = 0; t < 4; t++) {
                int nr = cur[0] + dr[t];
                int nc = cur[1] + dc[t];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                    continue;
                }
                if (vis[nr][nc]) {
                    continue;
                }
                if (!ok(nr, nc, k)) {
                    continue;
                }
                vis[nr][nc] = true;
                q.offer(new int[]{nr, nc});
            }
        }
        return ans;
    }

    private boolean ok(int i, int j, int k) {
        return digitSum(i) + digitSum(j) <= k;
    }

    private int digitSum(int x) {
        int s = 0;
        while (x > 0) {
            s += x % 10;
            x /= 10;
        }
        return s;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
