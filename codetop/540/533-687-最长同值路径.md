# 687. 最长同值路径

- 题号：687
- 难度：中等
- LeetCode：[最长同值路径](https://leetcode.cn/problems/longest-univalue-path/)

## 题目描述
给定二叉树，返回最长路径长度，使得路径上所有节点值都相同。路径长度按边数计算。

## 示例
输入：`[5,4,5,1,1,null,5]`，输出 `2`

## 最佳解法思路
- 后序 DFS：
  - `dfs(node)` 返回“从 node 往下走、且值相同的最长单边长度”
  - 对左右子树分别取可接上的长度 `left/right`，更新答案 `left+right`

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int ans = 0;

    public int longestUnivaluePath(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) {
            return 0;
        }
        int l = dfs(node.left);
        int r = dfs(node.right);

        int left = 0;
        int right = 0;
        if (node.left != null && node.left.val == node.val) {
            left = l + 1;
        }
        if (node.right != null && node.right.val == node.val) {
            right = r + 1;
        }

        ans = Math.max(ans, left + right);
        return Math.max(left, right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
