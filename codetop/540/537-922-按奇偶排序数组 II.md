# 922. 按奇偶排序数组 II

- 题号：922
- 难度：简单
- LeetCode：[按奇偶排序数组 II](https://leetcode.cn/problems/sort-array-by-parity-ii/)

## 题目描述
给定数组 `nums`，一半为偶数一半为奇数。请重排使得偶数下标放偶数，奇数下标放奇数。

## 示例
- `nums = [4,2,5,7]`，输出 `[4,5,2,7]`（满足条件即可）

## 最佳解法思路
- 两个指针分别走偶数下标和奇数下标：
  - 遍历数组把偶数放到 `i`，奇数放到 `j`。
- 更直白：新建结果数组，分别填偶数位/奇数位。

## Java 最佳实现

```java
class Solution {
    public int[] sortArrayByParityII(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        int i = 0;
        int j = 1;
        for (int x : nums) {
            if ((x & 1) == 0) {
                ans[i] = x;
                i += 2;
            } else {
                ans[j] = x;
                j += 2;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
