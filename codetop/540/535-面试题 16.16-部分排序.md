# 面试题 16.16. 部分排序

- 题号：面试题 16.16
- 难度：中等
- LeetCode：[部分排序](https://leetcode.cn/problems/sub-sort-lcci/)

## 题目描述
给定整数数组，返回最短的子数组 `[m,n]`，只要将这段排序，整个数组就变成有序。若本身有序返回 `[-1,-1]`。

## 示例
- `array = [1,2,4,7,10,11,7,12,6,7,16,18,19]`  
输出 `[3,9]`

## 最佳解法思路
- 从左到右维护当前最大值 `max`：
  - 若 `a[i] < max`，说明 i 必须在待排序区间内，更新 `right = i`
- 从右到左维护当前最小值 `min`：
  - 若 `a[i] > min`，更新 `left = i`
- 若 `right` 没被更新，说明已整体有序。

## Java 最佳实现

```java
class Solution {
    public int[] subSort(int[] array) {
        int n = array.length;
        int right = -1;
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            max = Math.max(max, array[i]);
            if (array[i] < max) {
                right = i;
            }
        }
        if (right == -1) {
            return new int[]{-1, -1};
        }

        int left = -1;
        int min = Integer.MAX_VALUE;
        for (int i = n - 1; i >= 0; i--) {
            min = Math.min(min, array[i]);
            if (array[i] > min) {
                left = i;
            }
        }
        return new int[]{left, right};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
