# 面试题 08.11. 硬币

- 题号：面试题 08.11
- 难度：中等
- LeetCode：[硬币](https://leetcode.cn/problems/coin-lcci/)

## 题目描述
硬币面值为 25、10、5、1，给定 `n`，返回凑出 `n` 分的方案数（对 \(10^9+7\) 取模）。

## 示例
- `n = 5`，输出 `2`（5；1+1+1+1+1）

## 最佳解法思路
- 完全背包：`dp[i]` 表示凑出金额 i 的方案数。
- 依次遍历硬币面值，每个面值从小到大更新：`dp[j] += dp[j-coin]`。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int waysToChange(int n) {
        int[] coins = {1, 5, 10, 25};
        int[] dp = new int[n + 1];
        dp[0] = 1;
        for (int c : coins) {
            for (int j = c; j <= n; j++) {
                dp[j] = (dp[j] + dp[j - c]) % MOD;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
