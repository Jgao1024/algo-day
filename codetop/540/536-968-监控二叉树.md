# 968. 监控二叉树

- 题号：968
- 难度：困难
- LeetCode：[监控二叉树](https://leetcode.cn/problems/binary-tree-cameras/)

## 题目描述
给定二叉树，在节点上安装摄像头可监控：该节点、父节点、子节点。求监控整棵树的最少摄像头数量。

## 示例
输入：`[0,0,null,0,0]`，输出 `1`

## 最佳解法思路
- 后序贪心（3 状态）：
  - 0：该节点放了摄像头
  - 1：该节点已被覆盖（自己没摄像头）
  - 2：该节点未被覆盖，需要父节点放摄像头
- 规则：
  - 若任一子节点是 2，则当前节点放摄像头（返回 0）
  - 否则若任一子节点是 0，则当前节点被覆盖（返回 1）
  - 否则返回 2
- 最后如果根返回 2，再补一个摄像头。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int ans = 0;

    public int minCameraCover(TreeNode root) {
        if (dfs(root) == 2) {
            ans++;
        }
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) {
            return 1;
        }
        int l = dfs(node.left);
        int r = dfs(node.right);

        if (l == 2 || r == 2) {
            ans++;
            return 0;
        }
        if (l == 0 || r == 0) {
            return 1;
        }
        return 2;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
