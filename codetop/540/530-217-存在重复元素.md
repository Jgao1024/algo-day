# 217. 存在重复元素

- 题号：217
- 难度：简单
- LeetCode：[存在重复元素](https://leetcode.cn/problems/contains-duplicate/)

## 题目描述
给定整数数组 `nums`，如果任意值至少出现两次返回 `true`，否则返回 `false`。

## 示例
- `nums = [1,2,3,1]`，输出 `true`
- `nums = [1,2,3,4]`，输出 `false`

## 最佳解法思路
- 用 HashSet：遍历数组，若元素已存在则说明重复。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) {
            if (!set.add(x)) {
                return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
