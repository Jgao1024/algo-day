# 326. 3的幂

- 题号：326
- 难度：简单
- LeetCode：[3的幂](https://leetcode.cn/problems/power-of-three/)

## 题目描述
给定整数 `n`，判断它是否是 3 的幂。

## 示例
- `n = 27`，输出 `true`
- `n = 0`，输出 `false`
- `n = 9`，输出 `true`

## 最佳解法思路
- 不断除以 3：只要能整除就除，最后看是否等于 1。

## Java 最佳实现

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        if (n <= 0) {
            return false;
        }
        while (n % 3 == 0) {
            n /= 3;
        }
        return n == 1;
    }
}
```

## 复杂度分析
- 时间：\(O(\log_3 n)\)
- 空间：\(O(1)\)
