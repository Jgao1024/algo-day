# 582. 杀死进程

- 题号：582
- 难度：中等
- LeetCode：[杀死进程](https://leetcode.cn/problems/kill-process/)

## 题目描述
给定进程 `pid` 列表和对应父进程 `ppid` 列表。杀死一个进程会连带杀死所有子孙进程。给定 `kill`，返回被杀死的所有进程 id。

## 示例
- `pid = [1,3,10,5], ppid = [3,0,5,3], kill = 5`  
输出 `[5,10]`

## 最佳解法思路
- 建图：`ppid -> children`。
- 从 `kill` 出发 BFS/DFS，把所有可达的节点加入答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<Integer> killProcess(List<Integer> pid, List<Integer> ppid, int kill) {
        Map<Integer, List<Integer>> g = new HashMap<>();
        for (int i = 0; i < pid.size(); i++) {
            int p = ppid.get(i);
            int c = pid.get(i);
            g.computeIfAbsent(p, x -> new ArrayList<>()).add(c);
        }

        List<Integer> ans = new ArrayList<>();
        Deque<Integer> st = new ArrayDeque<>();
        st.push(kill);
        while (!st.isEmpty()) {
            int cur = st.pop();
            ans.add(cur);
            List<Integer> children = g.get(cur);
            if (children == null) {
                continue;
            }
            for (int child : children) {
                st.push(child);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
