# 807. 保持城市天际线

- 题号：807
- 难度：中等
- LeetCode：[保持城市天际线](https://leetcode.cn/problems/max-increase-to-keep-city-skyline/)

## 题目描述
给定 `n x n` 网格表示建筑高度。你可以增加任意建筑高度，但从四个方向看到的天际线（每行/每列最大值）不能改变。求最大总增加高度。

## 示例
输入：
`[[3,0,8,4],[2,4,5,7],[9,2,6,3],[0,3,1,0]]`
输出：`35`

## 最佳解法思路
- 先求每行最大 `rowMax[i]`、每列最大 `colMax[j]`。
- 每个格子最高能增到 `min(rowMax[i], colMax[j])`，累加增量。

## Java 最佳实现

```java
class Solution {
    public int maxIncreaseKeepingSkyline(int[][] grid) {
        int n = grid.length;
        int[] row = new int[n];
        int[] col = new int[n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                row[i] = Math.max(row[i], grid[i][j]);
                col[j] = Math.max(col[j], grid[i][j]);
            }
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                ans += Math.min(row[i], col[j]) - grid[i][j];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
