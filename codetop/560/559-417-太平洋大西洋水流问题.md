# 417. 太平洋大西洋水流问题

- 题号：417
- 难度：中等
- LeetCode：[太平洋大西洋水流问题](https://leetcode.cn/problems/pacific-atlantic-water-flow/)

## 题目描述
给定 `m x n` 的高度矩阵 `heights`。水可以从高处或等高处流向低处或等高处（上下左右）。  
太平洋接触上边界和左边界，大西洋接触下边界和右边界。  
返回所有既能流到太平洋又能流到大西洋的坐标。

## 示例
- 示例  
输入：`heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]`  
输出：`[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]`

## 最佳解法思路
- 反向 BFS（推荐）  
从海洋边界反向出发：如果能从海边“爬”到某个点（下一格高度 >= 当前格高度），就说明该点的水能流回海边。  
分别从太平洋边界和大西洋边界做一次 BFS，得到两个可达集合，交集即答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        boolean[][] pac = new boolean[m][n];
        boolean[][] atl = new boolean[m][n];
        Deque<int[]> qp = new ArrayDeque<>();
        Deque<int[]> qa = new ArrayDeque<>();

        for (int i = 0; i < m; i++) {
            qp.addLast(new int[]{i, 0});
            pac[i][0] = true;
            qa.addLast(new int[]{i, n - 1});
            atl[i][n - 1] = true;
        }
        for (int j = 0; j < n; j++) {
            qp.addLast(new int[]{0, j});
            pac[0][j] = true;
            qa.addLast(new int[]{m - 1, j});
            atl[m - 1][j] = true;
        }

        bfs(heights, pac, qp);
        bfs(heights, atl, qa);

        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (pac[i][j] && atl[i][j]) {
                    List<Integer> cell = new ArrayList<>(2);
                    cell.add(i);
                    cell.add(j);
                    res.add(cell);
                }
            }
        }
        return res;
    }

    private void bfs(int[][] h, boolean[][] vis, Deque<int[]> q) {
        int m = h.length, n = h[0].length;
        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        while (!q.isEmpty()) {
            int[] cur = q.pollFirst();
            int x = cur[0], y = cur[1];
            for (int k = 0; k < 4; k++) {
                int nx = x + dx[k], ny = y + dy[k];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (vis[nx][ny]) continue;
                if (h[nx][ny] < h[x][y]) continue;
                vis[nx][ny] = true;
                q.addLast(new int[]{nx, ny});
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)

## 总结（速记）
- **从海边反向爬坡做两次 BFS，取两次可达的交集**。
