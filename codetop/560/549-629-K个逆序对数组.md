# 629. K个逆序对数组

- 题号：629
- 难度：困难
- LeetCode：[K个逆序对数组](https://leetcode.cn/problems/k-inverse-pairs-array/)

## 题目描述
给定 `n` 和 `k`，求由 `1..n` 组成且恰好有 `k` 个逆序对的数组个数。答案对 \(10^9+7\) 取模。

## 示例
- 示例  
输入：`n = 3, k = 1`  
输出：`2`

## 最佳解法思路
- 动态规划 + 前缀和优化（推荐）  
设 `dp[i][j]` 表示用 `1..i` 组成、逆序对数为 `j` 的个数。  
把数字 `i` 插入到长度 `i-1` 的排列中，最多新增 `i-1` 个逆序对：  
`dp[i][j] = sum(dp[i-1][j-x])`，其中 `x=0..min(j,i-1)`。  
用前缀和把转移优化到 \(O(nk)\)：  
`dp[i][j] = dp[i][j-1] + dp[i-1][j] - (j-i>=0 ? dp[i-1][j-i] : 0)`。

## Java 最佳实现

```java
class Solution {
    public int kInversePairs(int n, int k) {
        int MOD = 1_000_000_007;
        int[] prev = new int[k + 1];
        prev[0] = 1;
        for (int i = 1; i <= n; i++) {
            int[] cur = new int[k + 1];
            cur[0] = 1;
            for (int j = 1; j <= k; j++) {
                long val = cur[j - 1] + prev[j];
                if (j - i >= 0) val -= prev[j - i];
                val %= MOD;
                if (val < 0) val += MOD;
                cur[j] = (int) val;
            }
            prev = cur;
        }
        return prev[k];
    }
}
```

## 复杂度分析
- 时间：\(O(nk)\)
- 空间：\(O(k)\)
