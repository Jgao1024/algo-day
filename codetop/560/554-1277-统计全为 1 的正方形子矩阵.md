# 1277. 统计全为 1 的正方形子矩阵

- 题号：1277
- 难度：中等
- LeetCode：[统计全为 1 的正方形子矩阵](https://leetcode.cn/problems/count-square-submatrices-with-all-ones/)

## 题目描述
给定只包含 0/1 的矩阵 `matrix`，返回全为 1 的正方形子矩阵的个数（不同位置/大小都算）。

## 示例
- 示例  
输入：`matrix = [[0,1,1,1],[1,1,1,1],[0,1,1,1]]`  
输出：`15`

## 最佳解法思路
- DP（推荐）  
`dp[i][j]` 表示以 `(i,j)` 作为右下角的、全 1 正方形的最大边长。  
若 `matrix[i][j]==1`，则：  
`dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`。  
把所有 `dp[i][j]` 累加就是答案。

## Java 最佳实现

```java
class Solution {
    public int countSquares(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] dp = new int[m][n];
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) continue;
                if (i == 0 || j == 0) dp[i][j] = 1;
                else dp[i][j] = 1 + Math.min(dp[i - 1][j], Math.min(dp[i][j - 1], dp[i - 1][j - 1]));
                ans += dp[i][j];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)

- **dp 记“以该点为右下角的最大边长”，累加 dp 就是总个数**。
