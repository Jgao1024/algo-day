# 229. 求众数 II

- 题号：229
- 难度：中等
- LeetCode：[求众数 II](https://leetcode.cn/problems/majority-element-ii/)

## 题目描述
给定整数数组 `nums`，返回所有出现次数超过 \(\lfloor n/3 \rfloor\) 的元素。

## 示例
- 示例  
输入：`nums = [3,2,3]`  
输出：`[3]`

## 最佳解法思路
- Boyer-Moore 投票（推荐）  
超过 `n/3` 的元素最多只有 2 个。  
第一遍找出两个候选值；第二遍计数验证是否真的超过 `n/3`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> majorityElement(int[] nums) {
        int cand1 = 0, cand2 = 1;
        int cnt1 = 0, cnt2 = 0;
        for (int x : nums) {
            if (x == cand1) cnt1++;
            else if (x == cand2) cnt2++;
            else if (cnt1 == 0) {
                cand1 = x;
                cnt1 = 1;
            } else if (cnt2 == 0) {
                cand2 = x;
                cnt2 = 1;
            } else {
                cnt1--;
                cnt2--;
            }
        }

        cnt1 = 0;
        cnt2 = 0;
        for (int x : nums) {
            if (x == cand1) cnt1++;
            else if (x == cand2) cnt2++;
        }

        List<Integer> res = new ArrayList<>();
        int n = nums.length;
        if (cnt1 > n / 3) res.add(cand1);
        if (cnt2 > n / 3) res.add(cand2);
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **超过 n/3 的最多两个：先投票选候选，再二次计数验证**。
