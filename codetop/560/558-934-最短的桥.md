# 934. 最短的桥

- 题号：934
- 难度：中等
- LeetCode：[最短的桥](https://leetcode.cn/problems/shortest-bridge/)

## 题目描述
给定一个只包含 0/1 的矩阵 `grid`，其中有两座岛（两块 1 连通块）。  
你可以把 0 变成 1 连接两座岛，返回最少需要翻转的 0 的数量。

## 示例
- 示例  
输入：`grid = [[0,1],[1,0]]`  
输出：`1`

## 最佳解法思路
- DFS 标记第一座岛 + BFS 扩展（推荐）  
先找到第一座岛，用 DFS 把它全部标记为 2，并把这些坐标加入队列。  
再从这些点做 BFS 按层向外扩展（只走 0），第一次碰到另一座岛（值为 1）时，当前层数就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private int n;
    private int[][] g;
    private final int[] dx = {1, -1, 0, 0};
    private final int[] dy = {0, 0, 1, -1};

    public int shortestBridge(int[][] grid) {
        this.g = grid;
        this.n = grid.length;
        Deque<int[]> q = new ArrayDeque<>();

        boolean found = false;
        for (int i = 0; i < n && !found; i++) {
            for (int j = 0; j < n && !found; j++) {
                if (grid[i][j] == 1) {
                    dfsMark(i, j, q);
                    found = true;
                }
            }
        }

        int step = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            for (int s = 0; s < size; s++) {
                int[] cur = q.pollFirst();
                int x = cur[0], y = cur[1];
                for (int k = 0; k < 4; k++) {
                    int nx = x + dx[k], ny = y + dy[k];
                    if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                    if (g[nx][ny] == 1) return step;
                    if (g[nx][ny] != 0) continue;
                    g[nx][ny] = 2;
                    q.addLast(new int[]{nx, ny});
                }
            }
            step++;
        }
        return -1;
    }

    private void dfsMark(int i, int j, Deque<int[]> q) {
        if (i < 0 || i >= n || j < 0 || j >= n) return;
        if (g[i][j] != 1) return;
        g[i][j] = 2;
        q.addLast(new int[]{i, j});
        for (int k = 0; k < 4; k++) dfsMark(i + dx[k], j + dy[k], q);
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)

## 总结（速记）
- **先 DFS 把一座岛标记并入队，再 BFS 向外扩展，首次碰到另一座岛的层数就是答案**。
