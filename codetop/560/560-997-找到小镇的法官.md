# 997. 找到小镇的法官

- 题号：997
- 难度：简单
- LeetCode：[找到小镇的法官](https://leetcode.cn/problems/find-the-town-judge/)

## 题目描述
小镇有 `n` 个人，信任关系 `trust[i] = [a,b]` 表示 `a` 信任 `b`。  
法官满足：法官不信任任何人，且除法官外所有人都信任法官。返回法官编号，不存在返回 `-1`。

## 示例
- 示例  
输入：`n = 2, trust = [[1,2]]`  
输出：`2`

## 最佳解法思路
- 统计入度/出度（推荐）  
`in[i]` 记录被多少人信任，`out[i]` 记录信任了多少人。  
法官满足 `in[i] == n-1` 且 `out[i] == 0`。

## Java 最佳实现

```java
class Solution {
    public int findJudge(int n, int[][] trust) {
        if (n == 1) return 1;
        int[] in = new int[n + 1];
        int[] out = new int[n + 1];
        for (int[] t : trust) {
            out[t[0]]++;
            in[t[1]]++;
        }
        for (int i = 1; i <= n; i++) {
            if (in[i] == n - 1 && out[i] == 0) return i;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n + |trust|)\)
- 空间：\(O(n)\)
