# 841. 钥匙和房间

- 题号：841
- 难度：中等
- LeetCode：[钥匙和房间](https://leetcode.cn/problems/keys-and-rooms/)

## 题目描述
有 `n` 个房间，房间 `0` 初始打开，其余房间上锁。每个房间里有一些钥匙（指向其他房间编号）。  
判断是否能从房间 0 出发，最终进入所有房间。

## 示例
- 示例  
输入：`rooms = [[1],[2],[3],[]]`  
输出：`true`

## 最佳解法思路
- 图遍历（推荐）  
把房间看成点，钥匙看成边。从 0 做 DFS/BFS 标记可达房间，最后看访问数量是否等于 `n`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] vis = new boolean[n];
        Deque<Integer> q = new ArrayDeque<>();
        q.addLast(0);
        vis[0] = true;
        int cnt = 1;

        while (!q.isEmpty()) {
            int u = q.pollFirst();
            for (int v : rooms.get(u)) {
                if (!vis[v]) {
                    vis[v] = true;
                    cnt++;
                    q.addLast(v);
                }
            }
        }
        return cnt == n;
    }
}
```

## 复杂度分析
- 时间：\(O(n+\text{keys})\)
- 空间：\(O(n)\)

- **从 0 做 BFS/DFS，最后看能否访问到所有房间**。
