# 700. 二叉搜索树中的搜索

- 题号：700
- 难度：简单
- LeetCode：[二叉搜索树中的搜索](https://leetcode.cn/problems/search-in-a-binary-search-tree/)

## 题目描述
给定二叉搜索树根节点 `root` 和值 `val`，返回以 `val` 为根的子树；若不存在则返回 `null`。

## 示例
- 示例  
输入：`root = [4,2,7,1,3], val = 2`  
输出：`[2,1,3]`

## 最佳解法思路
- 利用 BST 性质（推荐）  
若 `val < cur.val` 去左子树；若 `val > cur.val` 去右子树；相等则返回当前节点。

## Java 最佳实现

```java
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        TreeNode cur = root;
        while (cur != null) {
            if (cur.val == val) return cur;
            cur = (val < cur.val) ? cur.left : cur.right;
        }
        return null;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)
- 空间：\(O(1)\)
