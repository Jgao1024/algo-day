# 324. 摆动排序 II

- 题号：324
- 难度：中等
- LeetCode：[摆动排序 II](https://leetcode.cn/problems/wiggle-sort-ii/)

## 题目描述
给定无序数组 `nums`，重新排列使得：  
`nums[0] < nums[1] > nums[2] < nums[3] ...`（相邻不等号交替）。

## 示例
- 示例  
输入：`nums = [1,5,1,1,6,4]`  
输出：`[1,6,1,5,1,4]`（一种合法答案）

## 最佳解法思路
- 排序 + 交错填充（推荐，易写）  
先排序。把较小的一半（含中位数）倒序放到偶数位，把较大的一半倒序放到奇数位，可以避免相等元素挤在一起，从而满足摆动条件。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public void wiggleSort(int[] nums) {
        int n = nums.length;
        int[] a = nums.clone();
        Arrays.sort(a);

        int left = (n - 1) / 2;
        int right = n - 1;
        for (int i = 0; i < n; i++) {
            if ((i & 1) == 0) nums[i] = a[left--];
            else nums[i] = a[right--];
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **排序后：偶数位放“小半段倒序”，奇数位放“大半段倒序”**。
