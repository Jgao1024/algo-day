# 剑指 Offer 44. 数字序列中某一位的数字

- 题号：剑指 Offer 44
- 难度：中等
- LeetCode：[数字序列中某一位的数字](https://leetcode.cn/problems/shu-zi-xu-lie-zhong-mou-yi-wei-de-shu-zi-lcof/)

## 题目描述
数字序列 `0123456789101112...` 中，求下标为 `n`（从 0 开始）的数字。

## 示例
- 示例  
输入：`n = 3`  
输出：`3`

## 最佳解法思路
- 分段定位（推荐）  
把序列按“数字位数”分段：  
1 位数（0-9）占 10 位；2 位数（10-99）占 `90*2` 位；3 位数占 `900*3` 位...  
先确定 `n` 落在哪一段，再确定具体是哪个数字以及数字内的哪一位。

## Java 最佳实现

```java
class Solution {
    public int findNthDigit(int n) {
        if (n < 10) return n;
        n -= 10;

        long digit = 2;
        long start = 10;
        long count = 90;
        while (n >= digit * count) {
            n -= digit * count;
            digit++;
            start *= 10;
            count *= 10;
        }

        long num = start + n / digit;
        int idx = (int) (n % digit);
        return String.valueOf(num).charAt(idx) - '0';
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
