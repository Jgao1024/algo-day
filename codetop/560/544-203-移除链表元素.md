# 203. 移除链表元素

- 题号：203
- 难度：简单
- LeetCode：[移除链表元素](https://leetcode.cn/problems/remove-linked-list-elements/)

## 题目描述
给定链表头结点 `head` 和整数 `val`，删除链表中所有值等于 `val` 的节点，并返回新头结点。

## 示例
- 示例  
输入：`head = [1,2,6,3,4,5,6], val = 6`  
输出：`[1,2,3,4,5]`

## 最佳解法思路
- 哑节点（推荐）  
用 `dummy` 指向头结点，统一处理“删除头结点”的情况；遍历时如果 `cur.next.val == val` 就跳过该节点。

## Java 最佳实现

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode cur = dummy;
        while (cur.next != null) {
            if (cur.next.val == val) cur.next = cur.next.next;
            else cur = cur.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **删除链表节点先上 dummy，遍历看 `cur.next` 更稳**。
