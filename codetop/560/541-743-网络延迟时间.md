# 743. 网络延迟时间

- 题号：743
- 难度：中等
- LeetCode：[网络延迟时间](https://leetcode.cn/problems/network-delay-time/)

## 题目描述
有 `n` 个节点的网络，信号从节点 `k` 出发，边 `times[i] = (u,v,w)` 表示从 `u` 到 `v` 传输需要 `w` 时间。  
返回所有节点都收到信号的最短时间；如果无法到达所有节点，返回 `-1`。

## 示例
- 示例  
输入：`times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2`  
输出：`2`

## 最佳解法思路
- Dijkstra（推荐）  
图是带正权的单源最短路：用优先队列每次取当前距离最小的点进行松弛更新。  
最终取所有点最短距离的最大值，若有点不可达则返回 `-1`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.PriorityQueue;

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<int[]>[] g = new List[n + 1];
        for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
        for (int[] t : times) g[t[0]].add(new int[]{t[1], t[2]});

        int INF = Integer.MAX_VALUE / 2;
        int[] dist = new int[n + 1];
        Arrays.fill(dist, INF);
        dist[k] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.add(new int[]{0, k});
        boolean[] vis = new boolean[n + 1];

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (vis[u]) continue;
            vis[u] = true;
            for (int[] e : g[u]) {
                int v = e[0], w = e[1];
                if (dist[v] > d + w) {
                    dist[v] = d + w;
                    pq.add(new int[]{dist[v], v});
                }
            }
        }

        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == INF) return -1;
            ans = Math.max(ans, dist[i]);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O((n+m)\log n)\)（\(m\) 为边数）
- 空间：\(O(n+m)\)
