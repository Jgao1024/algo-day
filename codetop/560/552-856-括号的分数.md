# 856. 括号的分数

- 题号：856
- 难度：中等
- LeetCode：[括号的分数](https://leetcode.cn/problems/score-of-parentheses/)

## 题目描述
给定一个平衡括号字符串 `s`，按规则计算分数：  
- `"()"` 得 1 分  
- `AB` 得 `A+B`  
- `(A)` 得 `2*A`

## 示例
- 示例  
输入：`s = "(()(()))"`  
输出：`6`

## 最佳解法思路
- 统计深度（推荐）  
当遇到形如 `"()"` 的一对时，它贡献的分数为 `2^depth`（这里 depth 是这一对括号外层的嵌套深度）。  
扫描字符串维护 `depth`：遇 `(` depth++；遇 `)` depth--，并在 `s[i-1]=='('` 时加上 `1<<depth`。

## Java 最佳实现

```java
class Solution {
    public int scoreOfParentheses(String s) {
        int depth = 0;
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                depth++;
            } else {
                depth--;
                if (s.charAt(i - 1) == '(') ans += 1 << depth;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **只数 `"()"`：每个 `"()"` 贡献 `2^外层深度`**。
