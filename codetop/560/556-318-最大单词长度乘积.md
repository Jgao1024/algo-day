# 318. 最大单词长度乘积

- 题号：318
- 难度：中等
- LeetCode：[最大单词长度乘积](https://leetcode.cn/problems/maximum-product-of-word-lengths/)

## 题目描述
给定字符串数组 `words`，找出两个单词，使它们不包含相同字符，并返回长度乘积的最大值；若不存在返回 0。

## 示例
- 示例  
输入：`words = ["abcw","baz","foo","bar","xtfn","abcdef"]`  
输出：`16`

## 最佳解法思路
- 位掩码（推荐）  
用 26 位整数表示单词包含哪些字母（mask）。  
两单词无公共字符等价于 `(mask[i] & mask[j]) == 0`，遍历所有对更新最大乘积。

## Java 最佳实现

```java
class Solution {
    public int maxProduct(String[] words) {
        int n = words.length;
        int[] mask = new int[n];
        int[] len = new int[n];
        for (int i = 0; i < n; i++) {
            int m = 0;
            String w = words[i];
            for (int j = 0; j < w.length(); j++) {
                m |= 1 << (w.charAt(j) - 'a');
            }
            mask[i] = m;
            len[i] = w.length();
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if ((mask[i] & mask[j]) == 0) {
                    ans = Math.max(ans, len[i] * len[j]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 \cdot L)\) 预处理为 \(O(nL)\)，两两比较为 \(O(n^2)\)
- 空间：\(O(n)\)

- **把每个单词压成 26 位 mask；两两判断 `mask&mask==0`**。
