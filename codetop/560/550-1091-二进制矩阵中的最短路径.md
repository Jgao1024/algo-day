# 1091. 二进制矩阵中的最短路径

- 题号：1091
- 难度：中等
- LeetCode：[二进制矩阵中的最短路径](https://leetcode.cn/problems/shortest-path-in-binary-matrix/)

## 题目描述
给定 `n x n` 的二进制矩阵 `grid`（0 可走，1 障碍），从左上角 `(0,0)` 到右下角 `(n-1,n-1)` 的最短路径长度是多少。  
可在 8 个方向移动。不可达返回 `-1`。

## 示例
- 示例  
输入：`grid = [[0,1],[1,0]]`  
输出：`2`

## 最佳解法思路
- BFS（推荐）  
无权最短路直接 BFS。用 `dist` 记录到达每个格子的最短步数，起点为 1，扩展 8 个方向，首次到达终点即最短。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int shortestPathBinaryMatrix(int[][] grid) {
        int n = grid.length;
        if (grid[0][0] != 0 || grid[n - 1][n - 1] != 0) return -1;
        if (n == 1) return 1;

        int[][] dist = new int[n][n];
        Deque<int[]> q = new ArrayDeque<>();
        q.addLast(new int[]{0, 0});
        dist[0][0] = 1;

        int[] dx = {-1, -1, -1, 0, 0, 1, 1, 1};
        int[] dy = {-1, 0, 1, -1, 1, -1, 0, 1};

        while (!q.isEmpty()) {
            int[] cur = q.pollFirst();
            int x = cur[0], y = cur[1];
            int d = dist[x][y];
            for (int k = 0; k < 8; k++) {
                int nx = x + dx[k], ny = y + dy[k];
                if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                if (grid[nx][ny] != 0) continue;
                if (dist[nx][ny] != 0) continue;
                dist[nx][ny] = d + 1;
                if (nx == n - 1 && ny == n - 1) return dist[nx][ny];
                q.addLast(new int[]{nx, ny});
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
