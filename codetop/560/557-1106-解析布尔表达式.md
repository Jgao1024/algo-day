# 1106. 解析布尔表达式

- 题号：1106
- 难度：困难
- LeetCode：[解析布尔表达式](https://leetcode.cn/problems/parsing-a-boolean-expression/)

## 题目描述
给定一个布尔表达式字符串 `expression`，包含：  
`'t'/'f'`、`'!'`、`'&'`、`'|'`、括号与逗号（逗号仅作分隔）。  
返回表达式的计算结果。

## 示例
- 示例  
输入：`expression = "|(&(t,f,t),!(t))"`  
输出：`false`

## 最佳解法思路
- 栈模拟（推荐）  
用栈保存字符（跳过逗号）。  
遇到 `')'` 就弹出直到 `'('`，统计本括号内出现了多少 `t/f`；再弹出 `'('` 和运算符：  
`'!'`：对唯一值取反  
`'&'`：只要出现 `f` 就是 `f`  
`'|'`：只要出现 `t` 就是 `t`  
把结果再压回栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean parseBoolExpr(String expression) {
        Deque<Character> st = new ArrayDeque<>();
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            if (c == ',') continue;
            if (c != ')') {
                st.push(c);
                continue;
            }

            boolean hasT = false;
            boolean hasF = false;
            while (st.peek() != '(') {
                char v = st.pop();
                if (v == 't') hasT = true;
                else if (v == 'f') hasF = true;
            }
            st.pop();
            char op = st.pop();

            char res;
            if (op == '!') {
                res = hasT ? 'f' : 't';
            } else if (op == '&') {
                res = hasF ? 'f' : 't';
            } else {
                res = hasT ? 't' : 'f';
            }
            st.push(res);
        }
        return st.pop() == 't';
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **遇 ')' 就结算一段：弹到 '('，再用运算符合并成一个 t/f 压回栈**。
