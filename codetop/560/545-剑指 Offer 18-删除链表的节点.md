# 剑指 Offer 18. 删除链表的节点

- 题号：剑指 Offer 18
- 难度：简单
- LeetCode：[删除链表的节点](https://leetcode.cn/problems/shan-chu-lian-biao-de-jie-dian-lcof/)

## 题目描述
给定单链表头结点 `head` 和一个值 `val`，删除链表中第一个值为 `val` 的节点并返回新头结点。

## 示例
- 示例  
输入：`head = [4,5,1,9], val = 5`  
输出：`[4,1,9]`

## 最佳解法思路
- 遍历找前驱（推荐）  
用 `dummy` 统一头结点删除场景，找到第一个 `cur.next.val == val` 的位置直接跳过即可。

## Java 最佳实现

```java
class Solution {
    public ListNode deleteNode(ListNode head, int val) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode cur = dummy;
        while (cur.next != null) {
            if (cur.next.val == val) {
                cur.next = cur.next.next;
                break;
            }
            cur = cur.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
