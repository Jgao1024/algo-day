# 1019. 链表中的下一个更大节点

- 题号：1019
- 难度：中等
- LeetCode：[链表中的下一个更大节点](https://leetcode.cn/problems/next-greater-node-in-linked-list/)

## 题目描述
给定一个链表 `head`，返回一个数组 `ans`：`ans[i]` 是第 `i` 个节点右侧第一个更大节点的值；如果不存在则为 `0`。

## 示例
- 示例  
输入：`head = [2,1,5]`  
输出：`[5,5,0]`

## 最佳解法思路
- 单调栈（推荐）  
先把链表转成数组 `vals`，然后用单调递减栈存下标：  
遍历到 `i` 时，若 `vals[i]` 大于栈顶对应值，就弹栈并把答案设为 `vals[i]`，直到不能弹，再把 `i` 入栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public int[] nextLargerNodes(ListNode head) {
        List<Integer> vals = new ArrayList<>();
        for (ListNode cur = head; cur != null; cur = cur.next) vals.add(cur.val);
        int n = vals.size();
        int[] ans = new int[n];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            int v = vals.get(i);
            while (!st.isEmpty() && vals.get(st.peek()) < v) {
                ans[st.pop()] = v;
            }
            st.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
