# 1162. 地图分析

- 题号：1162
- 难度：中等
- LeetCode：[地图分析](https://leetcode.cn/problems/as-far-from-land-as-possible/)

## 题目描述
给定 `n x n` 的 0/1 矩阵 `grid`（1 为陆地，0 为海洋），返回一个海洋格到最近陆地格的最大距离（曼哈顿距离）。  
如果全是陆地或全是海洋，返回 `-1`。

## 示例
- 示例  
输入：`grid = [[1,0,1],[0,0,0],[1,0,1]]`  
输出：`2`

## 最佳解法思路
- 多源 BFS（推荐）  
把所有陆地同时入队作为起点（距离 0），向外层层扩展，第一次到达某个海洋时就是它到最近陆地的最短距离。  
最后一层扩展到的海洋距离最大，就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maxDistance(int[][] grid) {
        int n = grid.length;
        Deque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) q.addLast(new int[]{i, j});
            }
        }
        if (q.isEmpty() || q.size() == n * n) return -1;

        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        int dist = -1;
        while (!q.isEmpty()) {
            int size = q.size();
            dist++;
            for (int s = 0; s < size; s++) {
                int[] cur = q.pollFirst();
                int x = cur[0], y = cur[1];
                for (int k = 0; k < 4; k++) {
                    int nx = x + dx[k], ny = y + dy[k];
                    if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] != 0) continue;
                    grid[nx][ny] = 2;
                    q.addLast(new int[]{nx, ny});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)（队列最坏情况）

## 总结（速记）
- **所有陆地一起 BFS 扩散，最后一层的层数就是最大距离**。
