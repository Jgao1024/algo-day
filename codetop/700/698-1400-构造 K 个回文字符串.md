## 最佳解法思路
- 思路：统计奇数频次  
每个回文串最多只能有 1 个奇数频次字符。  
设字符串长度为 `n`，奇数频次个数为 `odd`：  
- 若 `k > n` 无解  
- 若 `odd > k` 无解  
否则有解。

## Java 最佳实现

```java
class Solution {
    public boolean canConstruct(String s, int k) {
        if (k > s.length()) {
            return false;
        }
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
        }
        int odd = 0;
        for (int c : cnt) {
            if ((c & 1) == 1) {
                odd++;
            }
        }
        return odd <= k;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
