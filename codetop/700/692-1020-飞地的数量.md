## 最佳解法思路
- 思路：从边界 DFS/BFS 淹掉可达陆地  
把边界上所有陆地（1）做 flood fill 标记为 0，表示这些都能走出边界，不算飞地。  
最后统计剩余 1 的数量。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int numEnclaves(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        Deque<int[]> q = new ArrayDeque<>();

        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 1) q.add(new int[]{i, 0});
            if (grid[i][n - 1] == 1) q.add(new int[]{i, n - 1});
        }
        for (int j = 0; j < n; j++) {
            if (grid[0][j] == 1) q.add(new int[]{0, j});
            if (grid[m - 1][j] == 1) q.add(new int[]{m - 1, j});
        }

        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int x = cur[0], y = cur[1];
            if (x < 0 || x >= m || y < 0 || y >= n || grid[x][y] == 0) {
                continue;
            }
            grid[x][y] = 0;
            for (int d = 0; d < 4; d++) {
                q.add(new int[]{x + dx[d], y + dy[d]});
            }
        }

        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)（队列最坏）
