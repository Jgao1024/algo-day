## 最佳解法思路
- 思路（推荐）：后序遍历返回子树信息  
对每个节点，后序拿到左右子树信息：是否 BST、最小值、最大值、子树和。  
若左右都是 BST 且 `left.max < root.val < right.min`，则当前也是 BST，更新最大和；否则标记为非 BST。

## Java 最佳实现

```java
class Solution {
    private int best = 0;

    public int maxSumBST(TreeNode root) {
        best = 0;
        dfs(root);
        return best;
    }

    private Info dfs(TreeNode node) {
        if (node == null) {
            return new Info(true, Integer.MAX_VALUE, Integer.MIN_VALUE, 0);
        }

        Info L = dfs(node.left);
        Info R = dfs(node.right);

        if (L.isBst && R.isBst && node.val > L.max && node.val < R.min) {
            int sum = L.sum + R.sum + node.val;
            best = Math.max(best, sum);
            int min = Math.min(L.min, node.val);
            int max = Math.max(R.max, node.val);
            return new Info(true, min, max, sum);
        }
        return new Info(false, 0, 0, 0);
    }

    private static class Info {
        boolean isBst;
        int min;
        int max;
        int sum;

        Info(boolean isBst, int min, int max, int sum) {
            this.isBst = isBst;
            this.min = min;
            this.max = max;
            this.sum = sum;
        }
    }
}
```
