## 最佳解法思路
- 思路：找最大和次大  
找出数组中最大的两个数 `a、b`，答案为 `(a-1)*(b-1)`。

## Java 最佳实现

```java
class Solution {
    public int maxProduct(int[] nums) {
        int a = 0;
        int b = 0;
        for (int x : nums) {
            if (x >= a) {
                b = a;
                a = x;
            } else if (x > b) {
                b = x;
            }
        }
        return (a - 1) * (b - 1);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
