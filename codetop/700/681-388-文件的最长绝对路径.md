## 最佳解法思路
- 思路：用数组记录每层路径长度  
按 `\n` 分行，行首的 `\t` 个数表示层级 `depth`。  
用 `len[depth]` 记录到该层为止的“路径总长度”（包含 `/`）。  
若当前是文件（包含 `.`），更新答案 `len[depth-1] + nameLen`；否则更新 `len[depth] = len[depth-1] + nameLen + 1`。

## Java 最佳实现

```java
class Solution {
    public int lengthLongestPath(String input) {
        String[] lines = input.split("\n");
        int[] len = new int[lines.length + 1];
        int ans = 0;

        for (String line : lines) {
            int depth = 0;
            while (depth < line.length() && line.charAt(depth) == '\t') {
                depth++;
            }
            String name = line.substring(depth);
            int nameLen = name.length();

            if (name.indexOf('.') >= 0) {
                ans = Math.max(ans, len[depth] + nameLen);
            } else {
                len[depth + 1] = len[depth] + nameLen + 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(d)\)
