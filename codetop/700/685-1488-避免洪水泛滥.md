## 最佳解法思路
- 思路（推荐）：哈希表记录上次下雨日 + TreeSet 选择抽水日  
`rains[i] = x > 0` 表示湖 x 下雨；若该湖之前已满且还没抽干，就必须在 `(lastRain[x], i)` 之间找一个晴天把它抽干。  
用 `TreeSet` 维护所有晴天下标（`rains[i]==0`），每次用 `higher(lastRain[x])` 找最早可用的晴天安排抽 x。  
晴天默认抽 1（任意），有需求时覆盖成对应湖编号。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;
import java.util.TreeSet;

class Solution {
    public int[] avoidFlood(int[] rains) {
        int n = rains.length;
        int[] ans = new int[n];

        Map<Integer, Integer> last = new HashMap<>();
        TreeSet<Integer> dryDays = new TreeSet<>();

        for (int i = 0; i < n; i++) {
            int x = rains[i];
            if (x == 0) {
                dryDays.add(i);
                ans[i] = 1;
                continue;
            }

            ans[i] = -1;
            Integer prev = last.get(x);
            if (prev != null) {
                Integer d = dryDays.higher(prev);
                if (d == null) {
                    return new int[0];
                }
                ans[d] = x;
                dryDays.remove(d);
            }
            last.put(x, i);
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
