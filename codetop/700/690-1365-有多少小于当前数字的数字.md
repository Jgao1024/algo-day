## 最佳解法思路
- 思路：计数排序  
题目范围 `0..100`，先统计频次，再做前缀和 `pre[v] = <v 的个数`，答案就是 `pre[nums[i]]`。

## Java 最佳实现

```java
class Solution {
    public int[] smallerNumbersThanCurrent(int[] nums) {
        int[] cnt = new int[101];
        for (int x : nums) {
            cnt[x]++;
        }

        int[] pre = new int[101];
        for (int i = 1; i <= 100; i++) {
            pre[i] = pre[i - 1] + cnt[i - 1];
        }

        int[] ans = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            ans[i] = pre[nums[i]];
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
