## 最佳解法思路
- 思路（推荐）：DP（保留/删除一次）  
`keep`：以当前位置结尾且未删除的最大和；`del`：以当前位置结尾且已删除一次的最大和。  
转移：  
`del = max(del + x, keepPrev)`（要么之前删过继续加，要么删除当前 x）  
`keep = max(keep + x, x)`  
答案取 `max(keep, del)`。

## Java 最佳实现

```java
class Solution {
    public int maximumSum(int[] arr) {
        int keep = arr[0];
        int del = Integer.MIN_VALUE / 2;
        int ans = arr[0];

        for (int i = 1; i < arr.length; i++) {
            int x = arr[i];
            int newDel = Math.max(del + x, keep);
            int newKeep = Math.max(keep + x, x);
            del = newDel;
            keep = newKeep;
            ans = Math.max(ans, Math.max(keep, del));
        }
        return ans;
    }
}
```
