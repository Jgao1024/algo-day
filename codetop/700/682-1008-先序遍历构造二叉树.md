## 最佳解法思路
- 思路（推荐）：递归 + 上界  
先序遍历序列构造 BST：递归建树时带一个“允许的最大值 bound”。  
若当前值 `> bound` 则不属于当前子树，返回空；否则创建节点，先构建左子树（上界为当前值），再构建右子树（上界为 bound）。

## Java 最佳实现

```java
class Solution {
    private int i = 0;

    public TreeNode bstFromPreorder(int[] preorder) {
        i = 0;
        return build(preorder, Integer.MAX_VALUE);
    }

    private TreeNode build(int[] pre, int bound) {
        if (i == pre.length || pre[i] > bound) {
            return null;
        }
        int val = pre[i++];
        TreeNode node = new TreeNode(val);
        node.left = build(pre, val);
        node.right = build(pre, bound);
        return node;
    }
}
```

- 空间：\(O(h)\)
