## 最佳解法思路
- 思路：保存公式依赖，按需递归求值  
每个单元格要么是“普通数值”，要么是“公式”（若干单元格/范围的加和）。  
`set` 时清掉公式并写入数值；`sum` 时把公式依赖表保存起来；`get` 时若是公式则递归求和（按依赖计数累加）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Excel {
    private final int h;
    private final int w;
    private final int[][] val;
    private final Map<Integer, Map<Integer, Integer>> formula = new HashMap<>();

    public Excel(int height, char width) {
        this.h = height;
        this.w = width - 'A' + 1;
        this.val = new int[height + 1][this.w];
    }

    public void set(int row, char column, int value) {
        int c = column - 'A';
        formula.remove(key(row, c));
        val[row][c] = value;
    }

    public int get(int row, char column) {
        int c = column - 'A';
        int k = key(row, c);
        Map<Integer, Integer> f = formula.get(k);
        if (f == null) {
            return val[row][c];
        }
        int sum = 0;
        for (Map.Entry<Integer, Integer> e : f.entrySet()) {
            int dep = e.getKey();
            int cnt = e.getValue();
            sum += cnt * get(r(dep), (char) ('A' + col(dep)));
        }
        return sum;
    }

    public int sum(int row, char column, String[] numbers) {
        int c = column - 'A';
        int k = key(row, c);

        Map<Integer, Integer> f = new HashMap<>();
        for (String s : numbers) {
            int idx = s.indexOf(':');
            if (idx < 0) {
                int[] p = parseCell(s);
                add(f, p[0], p[1], 1);
            } else {
                int[] a = parseCell(s.substring(0, idx));
                int[] b = parseCell(s.substring(idx + 1));
                int r1 = Math.min(a[0], b[0]);
                int r2 = Math.max(a[0], b[0]);
                int c1 = Math.min(a[1], b[1]);
                int c2 = Math.max(a[1], b[1]);
                for (int rr = r1; rr <= r2; rr++) {
                    for (int cc = c1; cc <= c2; cc++) {
                        add(f, rr, cc, 1);
                    }
                }
            }
        }

        formula.put(k, f);
        return get(row, column);
    }

    private void add(Map<Integer, Integer> f, int row, int col, int delta) {
        int k = key(row, col);
        f.put(k, f.getOrDefault(k, 0) + delta);
    }

    private int[] parseCell(String s) {
        int col = s.charAt(0) - 'A';
        int row = 0;
        for (int i = 1; i < s.length(); i++) {
            row = row * 10 + (s.charAt(i) - '0');
        }
        return new int[]{row, col};
    }

    private int key(int row, int col) {
        return (row << 8) | col;
    }

    private int r(int key) {
        return key >>> 8;
    }

    private int col(int key) {
        return key & 255;
    }
}
```

## 复杂度分析
- 时间：`sum` 取决于范围展开；`get` 取决于依赖规模（按需递归）
- 空间：\(O(\text{公式依赖总量})\)
