## 最佳解法思路
- 思路（推荐）：计数 atMost  
`count(max<=R) - count(max<=L-1)`。  
`count(max<=bound)`：扫描数组，若 `nums[i] <= bound`，则以 `i` 结尾的合法子数组个数增加当前连续长度；否则连续长度归零。

## Java 最佳实现

```java
class Solution {
    public int numSubarrayBoundedMax(int[] nums, int left, int right) {
        return countAtMost(nums, right) - countAtMost(nums, left - 1);
    }

    private int countAtMost(int[] nums, int bound) {
        int len = 0;
        int ans = 0;
        for (int x : nums) {
            if (x <= bound) {
                len++;
                ans += len;
            } else {
                len = 0;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
