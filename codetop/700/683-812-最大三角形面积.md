## 最佳解法思路
- 思路：暴力枚举三点  
三角形面积 \(=\frac{1}{2}|(x2-x1)(y3-y1)-(x3-x1)(y2-y1)|\)。  
枚举所有三元组取最大值。

## Java 最佳实现

```java
class Solution {
    public double largestTriangleArea(int[][] points) {
        int n = points.length;
        double ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    ans = Math.max(ans, area(points[i], points[j], points[k]));
                }
            }
        }
        return ans;
    }

    private double area(int[] a, int[] b, int[] c) {
        long x1 = a[0], y1 = a[1];
        long x2 = b[0], y2 = b[1];
        long x3 = c[0], y3 = c[1];
        long cross = (x2 - x1) * (y3 - y1) - (x3 - x1) * (y2 - y1);
        return Math.abs(cross) / 2.0;
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)
- 空间：\(O(1)\)
