# 面试题 04.02. 最小高度树

- 题号：面试题 04.02
- 难度：简单
- LeetCode：[最小高度树](https://leetcode.cn/problems/minimum-height-tree-lcci/)

## 题目描述
给定一个升序整数数组，构造一棵高度最小的二叉搜索树并返回根节点。

## 示例
`nums = [-10,-3,0,5,9]` -> `[0,-3,9,-10,null,5]`（一种答案）

## 最佳解法思路
- 递归取中点为根，左右两边分别递归构造左右子树。

## Java 最佳实现

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] a, int l, int r) {
        if (l > r) {
            return null;
        }
        int m = l + (r - l) / 2;
        TreeNode node = new TreeNode(a[m]);
        node.left = build(a, l, m - 1);
        node.right = build(a, m + 1, r);
        return node;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(\log n)\)（递归栈）
