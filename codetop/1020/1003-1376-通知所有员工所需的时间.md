# 1376. 通知所有员工所需的时间

- 题号：1376
- 难度：中等
- LeetCode：[通知所有员工所需的时间](https://leetcode.cn/problems/time-needed-to-inform-all-employees/)

## 题目描述
公司有 n 名员工，经理 `headID` 要把消息传到所有员工。`manager[i]` 是 i 的直接经理（`headID` 的经理为 -1），经理通知其直接下属需要 `informTime[i]` 分钟。
返回通知到所有员工所需的总时间（最长路径耗时）。

## 示例
- `n=6, headID=2`
`manager=[2,2,-1,2,2,2]`
`informTime=[0,0,1,0,0,0]`
输出 `1`

## 最佳解法思路
- 建树：`manager -> 下属列表`。
- 从 `headID` DFS/BFS，路径累加 `informTime[cur]`，取最大到达时间。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int numOfMinutes(int n, int headID, int[] manager, int[] informTime) {
        @SuppressWarnings("unchecked")
        List<Integer>[] g = new List[n];
        for (int i = 0; i < n; i++) {
            g[i] = new ArrayList<>();
        }
        for (int i = 0; i < n; i++) {
            int p = manager[i];
            if (p != -1) {
                g[p].add(i);
            }
        }
        return dfs(headID, g, informTime);
    }

    private int dfs(int u, List<Integer>[] g, int[] informTime) {
        int best = 0;
        for (int v : g[u]) {
            best = Math.max(best, dfs(v, g, informTime));
        }
        return informTime[u] + best;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
