# 775. 全局倒置与局部倒置

- 题号：775
- 难度：中等
- LeetCode：[全局倒置与局部倒置](https://leetcode.cn/problems/global-and-local-inversions/)

## 题目描述
给定一个 0..n-1 的排列 `nums`。
- 局部倒置：`i` 满足 `nums[i] > nums[i+1]`
- 全局倒置：`i<j` 且 `nums[i] > nums[j]`
判断是否“全局倒置数 == 局部倒置数”。

## 示例
- `[1,0,2]` -> `true`
- `[1,2,0]` -> `false`

## 最佳解法思路
- 若存在非局部倒置（`j >= i+2`），则不相等。
- 扫描 i，从左到右维护 `prefixMax`（0..i 的最大值），看是否 `prefixMax > nums[i+2]`。

## Java 最佳实现

```java
class Solution {
    public boolean isIdealPermutation(int[] nums) {
        int n = nums.length;
        int max = nums[0];
        for (int i = 0; i + 2 < n; i++) {
            max = Math.max(max, nums[i]);
            if (max > nums[i + 2]) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
