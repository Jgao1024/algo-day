# 1218. 最长定差子序列

- 题号：1218
- 难度：中等
- LeetCode：[最长定差子序列](https://leetcode.cn/problems/longest-arithmetic-subsequence-of-given-difference/)

## 题目描述
给定数组 `arr` 和整数 `difference`，返回最长子序列长度，要求相邻元素差都等于 `difference`。

## 示例
- `arr = [1,2,3,4], difference = 1` -> `4`
- `arr = [1,3,5,7], difference = 1` -> `1`
- `arr = [1,5,7,8,5,3,4,2,1], difference = -2` -> `4`

## 最佳解法思路
- DP + HashMap：
  - `dp[x]` 表示以值 x 结尾的最长长度
  - 遍历 x：`dp[x] = dp.get(x-diff, 0) + 1`

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int longestSubsequence(int[] arr, int difference) {
        Map<Integer, Integer> dp = new HashMap<>();
        int ans = 0;
        for (int x : arr) {
            int v = dp.getOrDefault(x - difference, 0) + 1;
            dp.put(x, v);
            ans = Math.max(ans, v);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
