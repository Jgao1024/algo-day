# 954. 二倍数对数组

- 题号：954
- 难度：中等
- LeetCode：[二倍数对数组](https://leetcode.cn/problems/array-of-doubled-pairs/)

## 题目描述
给定整数数组 `arr`，判断能否重新排序，使得可以把数组分成若干对 `(x, 2x)`。

## 示例
- `[3,1,3,6]` -> `false`
- `[2,1,2,6]` -> `false`
- `[4,-2,2,-4]` -> `true`

## 最佳解法思路
- 用计数表，按绝对值从小到大处理 x，优先匹配 `2x`：
  - 如果 `cnt[2x] < cnt[x]`，无法配对
  - 否则 `cnt[2x] -= cnt[x]`
- 这样负数也能正确处理（因为 -2 要配 -4）。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean canReorderDoubled(int[] arr) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : arr) {
            cnt.put(x, cnt.getOrDefault(x, 0) + 1);
        }

        Integer[] a = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) {
            a[i] = arr[i];
        }
        Arrays.sort(a, (x, y) -> Integer.compare(Math.abs(x), Math.abs(y)));

        for (int x : a) {
            int cx = cnt.getOrDefault(x, 0);
            if (cx == 0) {
                continue;
            }
            int y = x * 2;
            int cy = cnt.getOrDefault(y, 0);
            if (cy < cx) {
                return false;
            }
            cnt.put(x, 0);
            cnt.put(y, cy - cx);
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
