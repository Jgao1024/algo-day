# 441. 排列硬币

- 题号：441
- 难度：简单
- LeetCode：[排列硬币](https://leetcode.cn/problems/arranging-coins/)

## 题目描述
你有 `n` 枚硬币，要摆成阶梯形：第 1 行 1 枚，第 2 行 2 枚... 返回能摆满的完整行数。

## 示例
- `n = 5` -> `2`
- `n = 8` -> `3`

## 最佳解法思路
- 二分最大 k，使得 \(k(k+1)/2 \le n\)。

## Java 最佳实现

```java
class Solution {
    public int arrangeCoins(int n) {
        long l = 0;
        long r = n;
        while (l < r) {
            long m = (l + r + 1) / 2;
            long need = m * (m + 1) / 2;
            if (need <= n) {
                l = m;
            } else {
                r = m - 1;
            }
        }
        return (int) l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
