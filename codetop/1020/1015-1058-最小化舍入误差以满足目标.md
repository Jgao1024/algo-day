# 1058. 最小化舍入误差以满足目标

- 题号：1058
- 难度：中等
- LeetCode：[最小化舍入误差以满足目标](https://leetcode.cn/problems/minimize-rounding-error-to-meet-target/)

## 题目描述
给定价格数组 `prices`（字符串形式的小数）和整数 `target`。你可以把每个价格向下取整或向上取整，使得总和等于 target，并且“舍入误差”最小：
\(\sum |rounded_i - price_i|\)。
如果无法满足 target，返回 `"-1"`；否则返回误差，保留 3 位小数。

## 示例
- `prices = ["0.700","2.800","4.900"], target = 8` -> `"1.000"`
- `prices = ["1.500","2.500","3.500"], target = 10` -> `"-1"`

## 最佳解法思路
- 先算所有数向下取整的和 `floorSum`，以及每个数的小数部分 `frac`。
- 只有非整数项才有“向上”选择（多加 1），需要向上的数量 `need = target - floorSum`。
- 对每个非整数项：
  - 选 floor 的误差是 `frac`
  - 选 ceil 的误差是 `1 - frac`
  - 从 floor 切换到 ceil，误差变化 `delta = (1-frac) - frac = 1 - 2*frac`
- 选择 `need` 个最小的 delta（最划算向上），得到最小总误差。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public String minimizeError(String[] prices, int target) {
        int floorSum = 0;
        int ceilSum = 0;
        double base = 0.0;
        List<Double> delta = new ArrayList<>();

        for (String p : prices) {
            double v = Double.parseDouble(p);
            int f = (int) Math.floor(v);
            int c = (int) Math.ceil(v);
            floorSum += f;
            ceilSum += c;

            double frac = v - f;
            base += frac;
            if (c > f) {
                delta.add(1.0 - 2.0 * frac);
            }
        }

        if (target < floorSum || target > ceilSum) {
            return "-1";
        }
        int need = target - floorSum;
        Collections.sort(delta);

        double ans = base;
        for (int i = 0; i < need; i++) {
            ans += delta.get(i);
        }

        return String.format("%.3f", ans);
    }
}
```

- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
