# 360. 有序转化数组

- 题号：360
- 难度：中等
- LeetCode：[有序转化数组](https://leetcode.cn/problems/sort-transformed-array/)

## 题目描述
给定一个升序数组 `nums` 和系数 `a,b,c`，对每个 `x` 计算 `f(x)=ax^2+bx+c`，返回按升序排列的结果数组。

## 示例
- `nums = [-4,-2,2,4], a=1,b=3,c=5` -> `[3,9,15,33]`
- `nums = [-4,-2,2,4], a=-1,b=3,c=5` -> `[-23,-5,1,7]`

## 最佳解法思路
- 抛物线：若 `a >= 0`，两端值更大；若 `a < 0`，两端值更小。
- 双指针从两端选取较大/较小，填充结果数组（从末尾或从开头）。

## Java 最佳实现

```java
class Solution {
    public int[] sortTransformedArray(int[] nums, int a, int b, int c) {
        int n = nums.length;
        int[] ans = new int[n];
        int l = 0;
        int r = n - 1;
        int idx = a >= 0 ? n - 1 : 0;

        while (l <= r) {
            int lv = f(nums[l], a, b, c);
            int rv = f(nums[r], a, b, c);
            if (a >= 0) {
                if (lv >= rv) {
                    ans[idx--] = lv;
                    l++;
                } else {
                    ans[idx--] = rv;
                    r--;
                }
            } else {
                if (lv <= rv) {
                    ans[idx++] = lv;
                    l++;
                } else {
                    ans[idx++] = rv;
                    r--;
                }
            }
        }
        return ans;
    }

    private int f(int x, int a, int b, int c) {
        return a * x * x + b * x + c;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
