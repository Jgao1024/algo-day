# 955. 删列造序 II

- 题号：955
- 难度：中等
- LeetCode：[删列造序 II](https://leetcode.cn/problems/delete-columns-to-make-sorted-ii/)

## 题目描述
给定字符串数组 `strs`（等长），你可以删除若干列，使得删除后数组按字典序非递减。返回最少删除列数。

## 示例
- `strs = ["ca","bb","ac"]` -> `1`
- `strs = ["xc","yb","za"]` -> `0`

## 最佳解法思路
- 贪心按列扫描，维护相邻字符串对是否已确定有序 `sorted[i]`（表示 `strs[i] < strs[i+1]` 已被前面某列确定）。
- 扫描列 j：
  - 若存在某个未确定的对 `i` 使得 `strs[i][j] > strs[i+1][j]`，该列必须删除
  - 否则更新 `sorted[i] |= (strs[i][j] < strs[i+1][j])`

## Java 最佳实现

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int m = strs.length;
        int n = strs[0].length();
        boolean[] sorted = new boolean[m - 1];
        int ans = 0;

        for (int col = 0; col < n; col++) {
            boolean bad = false;
            for (int i = 0; i < m - 1; i++) {
                if (sorted[i]) {
                    continue;
                }
                if (strs[i].charAt(col) > strs[i + 1].charAt(col)) {
                    bad = true;
                    break;
                }
            }
            if (bad) {
                ans++;
                continue;
            }
            for (int i = 0; i < m - 1; i++) {
                if (!sorted[i] && strs[i].charAt(col) < strs[i + 1].charAt(col)) {
                    sorted[i] = true;
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(m)\)
