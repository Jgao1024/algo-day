# 1685. 有序数组中差绝对值之和

- 题号：1685
- 难度：中等
- LeetCode：[有序数组中差绝对值之和](https://leetcode.cn/problems/sum-of-absolute-differences-in-a-sorted-array/)

## 题目描述
给定一个非递减数组 `nums`，返回数组 `ans`，其中 `ans[i] = sum_{j} |nums[i] - nums[j]|`。

## 示例
- `nums = [2,3,5]` -> `[4,3,5]`
- `nums = [1,4,6,8,10]` -> `[24,15,13,15,21]`

## 最佳解法思路
- 前缀和：
  - 对每个 i，左边贡献：`i*nums[i] - preSum[i-1]`
  - 右边贡献：`(totalSum - preSum[i]) - (n-1-i)*nums[i]`

## Java 最佳实现

```java
class Solution {
    public int[] getSumAbsoluteDifferences(int[] nums) {
        int n = nums.length;
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }
        long total = pre[n];
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            long left = (long) i * nums[i] - pre[i];
            long right = (total - pre[i + 1]) - (long) (n - 1 - i) * nums[i];
            ans[i] = (int) (left + right);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
