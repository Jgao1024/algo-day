# 979. 在二叉树中分配硬币

- 题号：979
- 难度：中等
- LeetCode：[在二叉树中分配硬币](https://leetcode.cn/problems/distribute-coins-in-binary-tree/)

## 题目描述
给定一棵有 N 个节点的二叉树，节点值表示硬币数，总硬币数等于 N。每次可以把一枚硬币沿边移动到相邻节点，求让每个节点最终恰好 1 枚硬币的最少移动次数。

## 示例
`[3,0,0]` -> `2`

## 最佳解法思路
- 后序 DFS：
  - `dfs(node)` 返回该子树“多出来/缺少”的硬币数：`balance = left + right + node.val - 1`
  - 需要的移动次数加上 `|left| + |right|`（把子树余额通过边搬上来）

## Java 最佳实现

```java
class Solution {
    private int ans = 0;

    public int distributeCoins(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) {
            return 0;
        }
        int l = dfs(node.left);
        int r = dfs(node.right);
        ans += Math.abs(l) + Math.abs(r);
        return l + r + node.val - 1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
