# 993. 二叉树的堂兄弟节点

- 题号：993
- 难度：简单
- LeetCode：[二叉树的堂兄弟节点](https://leetcode.cn/problems/cousins-in-binary-tree/)

## 题目描述
给定二叉树根节点 `root` 和两个不同节点值 `x`、`y`，若它们深度相同但父节点不同，则它们是堂兄弟节点。返回是否为堂兄弟节点。

## 示例
- `[1,2,3,4], x=4, y=3` -> `false`
- `[1,2,3,null,4,null,5], x=5, y=4` -> `true`

## 最佳解法思路
- BFS 按层遍历：每层记录 x、y 是否出现及其父节点。
- 若同层同时找到，判断父节点是否不同；若只找到一个，直接返回 false。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    private static class NodeP {
        TreeNode node;
        TreeNode parent;
        NodeP(TreeNode node, TreeNode parent) {
            this.node = node;
            this.parent = parent;
        }
    }

    public boolean isCousins(TreeNode root, int x, int y) {
        Queue<NodeP> q = new ArrayDeque<>();
        q.offer(new NodeP(root, null));

        while (!q.isEmpty()) {
            int size = q.size();
            TreeNode px = null;
            TreeNode py = null;
            for (int i = 0; i < size; i++) {
                NodeP cur = q.poll();
                if (cur.node.val == x) {
                    px = cur.parent;
                } else if (cur.node.val == y) {
                    py = cur.parent;
                }
                if (cur.node.left != null) {
                    q.offer(new NodeP(cur.node.left, cur.node));
                }
                if (cur.node.right != null) {
                    q.offer(new NodeP(cur.node.right, cur.node));
                }
            }
            if (px != null || py != null) {
                return px != null && py != null && px != py;
            }
        }

        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
