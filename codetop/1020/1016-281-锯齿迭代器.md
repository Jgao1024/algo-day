# 281. 锯齿迭代器

- 题号：281
- 难度：中等
- LeetCode：[锯齿迭代器](https://leetcode.cn/problems/zigzag-iterator/)

## 题目描述
实现一个迭代器，交替输出两个列表 `v1`、`v2` 的元素（若某个列表用尽则跳过），直到两个都用尽。

## 示例
`v1=[1,2], v2=[3,4,5,6]` -> `[1,3,2,4,5,6]`

## 最佳解法思路
- 用队列存“还没遍历完的列表及其当前下标”：
  - 每次取队头输出一个元素
  - 若该列表还有剩余则放回队尾

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class ZigzagIterator {
    private static class State {
        List<Integer> list;
        int idx;
        State(List<Integer> list, int idx) {
            this.list = list;
            this.idx = idx;
        }
    }

    private final Deque<State> q = new ArrayDeque<>();

    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        if (v1 != null && !v1.isEmpty()) {
            q.offerLast(new State(v1, 0));
        }
        if (v2 != null && !v2.isEmpty()) {
            q.offerLast(new State(v2, 0));
        }
    }

    public int next() {
        State s = q.pollFirst();
        int val = s.list.get(s.idx++);
        if (s.idx < s.list.size()) {
            q.offerLast(s);
        }
        return val;
    }

    public boolean hasNext() {
        return !q.isEmpty();
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\) / next
- 空间：\(O(1)\)（仅两个状态）
