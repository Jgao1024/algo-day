# 507. 完美数

- 题号：507
- 难度：简单
- LeetCode：[完美数](https://leetcode.cn/problems/perfect-number/)

## 题目描述
给定正整数 `num`，判断它是否为完美数：等于其所有正因子（不包括自身）之和。

## 示例
- `num = 28` -> `true`
- `num = 7` -> `false`

## 最佳解法思路
- 枚举因子到 \(\sqrt{num}\)，成对加入（注意去重、排除自身）。

## Java 最佳实现

```java
class Solution {
    public boolean checkPerfectNumber(int num) {
        if (num <= 1) {
            return false;
        }
        int sum = 1;
        for (int d = 2; (long) d * d <= num; d++) {
            if (num % d != 0) {
                continue;
            }
            sum += d;
            int other = num / d;
            if (other != d) {
                sum += other;
            }
        }
        return sum == num;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{n})\)
- 空间：\(O(1)\)
