# 843. 猜猜这个单词

- 题号：843
- 难度：困难
- LeetCode：[猜猜这个单词](https://leetcode.cn/problems/guess-the-word/)

## 题目描述
这是交互题：给定候选单词列表 `wordlist`，你可以调用 `master.guess(word)` 得到与秘密单词相同位置字符个数（0..6）。最多 10 次，要求尽量找到秘密单词。

## 示例
见题面链接。

## 最佳解法思路
- 每次从候选集合里挑一个“最不偏”的单词去猜（minimax）：
  - 对每个候选 w，统计它与其它候选的 matchCount 分布，取最大桶大小作为 w 的代价
  - 选择代价最小的 w 去 guess
- 根据返回的匹配数，过滤候选集合（只保留 matchCount 相等的）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

/**
 * This is the Master's API interface.
 * You should not implement it, or speculate about its implementation.
 */
interface Master {
    int guess(String word);
}

class Solution {
    public void findSecretWord(String[] wordlist, Master master) {
        List<String> cand = new ArrayList<>();
        for (String w : wordlist) {
            cand.add(w);
        }

        for (int t = 0; t < 10 && !cand.isEmpty(); t++) {
            String pick = pickMinimax(cand);
            int x = master.guess(pick);
            if (x == 6) {
                return;
            }
            List<String> next = new ArrayList<>();
            for (String w : cand) {
                if (match(pick, w) == x) {
                    next.add(w);
                }
            }
            cand = next;
        }
    }

    private String pickMinimax(List<String> cand) {
        int n = cand.size();
        String best = cand.get(0);
        int bestScore = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            String a = cand.get(i);
            int[] bucket = new int[7];
            for (int j = 0; j < n; j++) {
                if (i == j) {
                    continue;
                }
                bucket[match(a, cand.get(j))]++;
            }
            int worst = 0;
            for (int v : bucket) {
                worst = Math.max(worst, v);
            }
            if (worst < bestScore) {
                bestScore = worst;
                best = a;
            }
        }
        return best;
    }

    private int match(String a, String b) {
        int cnt = 0;
        for (int i = 0; i < 6; i++) {
            if (a.charAt(i) == b.charAt(i)) {
                cnt++;
            }
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：每轮选点约 \(O(n^2)\)，共最多 10 轮
- 空间：\(O(n)\)
