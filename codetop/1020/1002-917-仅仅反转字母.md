# 917. 仅仅反转字母

- 题号：917
- 难度：简单
- LeetCode：[仅仅反转字母](https://leetcode.cn/problems/reverse-only-letters/)

## 题目描述
给定字符串 `s`，只反转其中的字母位置，非字母字符保持原位置不变。

## 示例
- `s = "ab-cd"` -> `"dc-ba"`
- `s = "a-bC-dEf-ghIj"` -> `"j-Ih-gfE-dCba"`

## 最佳解法思路
- 双指针：左指针找字母，右指针找字母，交换后同时移动；遇到非字母就跳过。

## Java 最佳实现

```java
class Solution {
    public String reverseOnlyLetters(String s) {
        char[] a = s.toCharArray();
        int l = 0;
        int r = a.length - 1;
        while (l < r) {
            while (l < r && !isLetter(a[l])) {
                l++;
            }
            while (l < r && !isLetter(a[r])) {
                r--;
            }
            if (l < r) {
                char t = a[l];
                a[l] = a[r];
                a[r] = t;
                l++;
                r--;
            }
        }
        return new String(a);
    }

    private boolean isLetter(char c) {
        return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z');
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（字符数组）
