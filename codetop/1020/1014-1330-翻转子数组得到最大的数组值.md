# 1330. 翻转子数组得到最大的数组值

- 题号：1330
- 难度：困难
- LeetCode：[翻转子数组得到最大的数组值](https://leetcode.cn/problems/reverse-subarray-to-maximize-array-value/)

## 题目描述
给定数组 `nums`，数组值定义为 \(\sum_{i=1}^{n-1} |nums[i]-nums[i-1]|\)。
你最多可以翻转一次连续子数组，求翻转后数组值的最大可能值。

## 示例
- `nums = [2,3,1,5,4]` -> `10`

## 最佳解法思路
- 先算原始 `base`。
- 计算翻转带来的最大增益：
  - 翻转包含头/尾：枚举边界 i，更新增益
  - 翻转内部：最佳增益可化成 `2 * (max(min(a[i],a[i-1])) - min(max(a[i],a[i-1])))`

## Java 最佳实现

```java
class Solution {
    public int maxValueAfterReverse(int[] nums) {
        int n = nums.length;
        int base = 0;
        for (int i = 1; i < n; i++) {
            base += Math.abs(nums[i] - nums[i - 1]);
        }

        int gain = 0;
        for (int i = 1; i < n; i++) {
            gain = Math.max(gain, Math.abs(nums[i] - nums[0]) - Math.abs(nums[i] - nums[i - 1]));
            gain = Math.max(gain, Math.abs(nums[n - 1] - nums[i - 1]) - Math.abs(nums[i] - nums[i - 1]));
        }

        int high = Integer.MIN_VALUE;
        int low = Integer.MAX_VALUE;
        for (int i = 1; i < n; i++) {
            int a = nums[i - 1];
            int b = nums[i];
            high = Math.max(high, Math.min(a, b));
            low = Math.min(low, Math.max(a, b));
        }
        gain = Math.max(gain, 2 * (high - low));

        return base + gain;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
