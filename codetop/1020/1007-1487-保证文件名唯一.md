# 1487. 保证文件名唯一

- 题号：1487
- 难度：中等
- LeetCode：[保证文件名唯一](https://leetcode.cn/problems/making-file-names-unique/)

## 题目描述
给定文件名数组 `names`。生成一个新数组，使得每个名字唯一：
- 若 `name` 未出现过，直接使用
- 否则在后面加 `(k)`（k 为最小正整数），使新名字未出现过

## 示例
- `["pes","fifa","gta","pes(2019)"]` -> `["pes","fifa","gta","pes(2019)"]`
- `["gta","gta(1)","gta","avalon"]` -> `["gta","gta(1)","gta(2)","avalon"]`

## 最佳解法思路
- HashMap 记录每个名字下一次尝试的 k（起步 k=1）。
- 遇到重复就从该 k 开始递增，直到找到没用过的名字，并更新映射。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String[] getFolderNames(String[] names) {
        Map<String, Integer> next = new HashMap<>();
        String[] ans = new String[names.length];

        for (int i = 0; i < names.length; i++) {
            String name = names[i];
            if (!next.containsKey(name)) {
                ans[i] = name;
                next.put(name, 1);
                continue;
            }

            int k = next.get(name);
            while (true) {
                String cand = name + "(" + k + ")";
                if (!next.containsKey(cand)) {
                    ans[i] = cand;
                    next.put(name, k + 1);
                    next.put(cand, 1);
                    break;
                }
                k++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(n)\)
- 空间：\(O(n)\)
