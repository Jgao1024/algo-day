## 最佳解法思路
- 逐次拼接 `word`，看是否仍是 `sequence` 的子串：
  - 用 `StringBuilder` 从空开始，不断追加 `word`
  - 只要 `sequence.contains(sb.toString())` 就计数 +1
  - 一旦不包含就停止

## Java 最佳实现

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int ans = 0;
        StringBuilder sb = new StringBuilder();
        while (true) {
            sb.append(word);
            if (sequence.contains(sb.toString())) ans++;
            else break;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：与 `contains` 实现有关，整体可认为较慢但可过
- 空间：\(O(ans * |word|)\)
