## 最佳解法思路
- 先统计 Bulls（位置相同），再统计 Cows：
  - `secret[i] == guess[i]` 直接 bulls++
  - 否则把 `secret` 和 `guess` 的数字频次分别计数
  - cows = \(\sum min(cntS[d], cntG[d])\)

## Java 最佳实现

```java
class Solution {
    public String getHint(String secret, String guess) {
        int bulls = 0;
        int[] sCnt = new int[10];
        int[] gCnt = new int[10];
        for (int i = 0; i < secret.length(); i++) {
            char a = secret.charAt(i);
            char b = guess.charAt(i);
            if (a == b) {
                bulls++;
            } else {
                sCnt[a - '0']++;
                gCnt[b - '0']++;
            }
        }
        int cows = 0;
        for (int d = 0; d < 10; d++) {
            cows += Math.min(sCnt[d], gCnt[d]);
        }
        return bulls + "A" + cows + "B";
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
