## 最佳解法思路
- 排序 + 二分：
  - 先把 `drinks` 排序
  - 对每个 `staple[i]`，可搭配的饮料数量是 `drinks` 中 `<= x - staple[i]` 的个数（上界二分）
  - 累加并对 \(10^9+7\) 取模

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    private static final int MOD = 1000000007;

    public int breakfastNumber(int[] staple, int[] drinks, int x) {
        Arrays.sort(drinks);
        long ans = 0;
        for (int s : staple) {
            int t = x - s;
            if (t < 0) continue;
            ans += upperBound(drinks, t);
            ans %= MOD;
        }
        return (int) ans;
    }

    // 返回 <= target 的元素个数
    private int upperBound(int[] a, int target) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = (l + r) >>> 1;
            if (a[m] <= target) l = m + 1;
            else r = m;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(m\log m + n\log m)\)
- 空间：\(O(1)\)（不算排序）
