## 最佳解法思路
- 直接用临时变量交换即可。

## Java 最佳实现

```java
class Solution {
    public int[] swapNumbers(int[] numbers) {
        int tmp = numbers[0];
        numbers[0] = numbers[1];
        numbers[1] = tmp;
        return numbers;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
