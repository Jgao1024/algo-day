## 最佳解法思路
- 排序 + 枚举分界点：
  - 把数组排序
  - 假设下标 `0..i` 加 `K`，`i+1..n-1` 减 `K`
  - 新最大值 `high = max(a[i] + K, a[n-1] - K)`
  - 新最小值 `low = min(a[0] + K, a[i+1] - K)`
  - 更新答案 `min(ans, high - low)`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int smallestRangeII(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        int ans = nums[n - 1] - nums[0];
        for (int i = 0; i < n - 1; i++) {
            int high = Math.max(nums[i] + k, nums[n - 1] - k);
            int low = Math.min(nums[0] + k, nums[i + 1] - k);
            ans = Math.min(ans, high - low);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不算排序）
