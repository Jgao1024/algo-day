## 最佳解法思路
- 两次遍历：
  - 从左到右，记录最近一次出现 `c` 的位置 `pos`，更新 `ans[i] = i - pos`
  - 从右到左，再做一次，`ans[i] = min(ans[i], pos - i)`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int[] shortestToChar(String s, char c) {
        int n = s.length();
        int[] ans = new int[n];
        Arrays.fill(ans, n);

        int pos = -n;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == c) pos = i;
            ans[i] = i - pos;
        }

        pos = 2 * n;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == c) pos = i;
            ans[i] = Math.min(ans[i], pos - i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不算输出数组）
