## 最佳解法思路
- DP 同时维护最大/最小乘积（因为有负数会翻转）：
  - `max[i][j]`：到达 `(i,j)` 的最大乘积
  - `min[i][j]`：到达 `(i,j)` 的最小乘积
  - 来自上/左两格的 `max/min` 都乘上当前值，取最大/最小
  - 最终看 `max[m-1][n-1]`，若为负返回 -1，否则对 \(10^9+7\) 取模

## Java 最佳实现

```java
class Solution {
    private static final long MOD = 1000000007L;

    public int maxProductPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        long[][] mx = new long[m][n];
        long[][] mn = new long[m][n];
        mx[0][0] = grid[0][0];
        mn[0][0] = grid[0][0];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                long v = grid[i][j];
                long maxVal = Long.MIN_VALUE;
                long minVal = Long.MAX_VALUE;

                if (i > 0) {
                    long a = mx[i - 1][j] * v;
                    long b = mn[i - 1][j] * v;
                    maxVal = Math.max(maxVal, Math.max(a, b));
                    minVal = Math.min(minVal, Math.min(a, b));
                }
                if (j > 0) {
                    long a = mx[i][j - 1] * v;
                    long b = mn[i][j - 1] * v;
                    maxVal = Math.max(maxVal, Math.max(a, b));
                    minVal = Math.min(minVal, Math.min(a, b));
                }

                mx[i][j] = maxVal;
                mn[i][j] = minVal;
            }
        }

        long best = mx[m - 1][n - 1];
        if (best < 0) return -1;
        return (int) (best % MOD);
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
