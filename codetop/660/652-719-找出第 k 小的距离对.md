## 最佳解法思路
- 排序 + 二分答案：
  - 距离的范围是 \([0, max-min]\)，二分 `d`
  - 统计数组中“距离 <= d”的数对数量 `cnt`
  - 若 `cnt >= k`，说明第 k 小距离不大于 `d`，收缩右边界
- 计数用双指针：
  - 固定右指针 `i`，移动左指针 `j` 使 `nums[i]-nums[j] <= d`
  - 此时以 `i` 结尾的合法数对有 `i-j` 个

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int smallestDistancePair(int[] nums, int k) {
        Arrays.sort(nums);
        int lo = 0;
        int hi = nums[nums.length - 1] - nums[0];
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countPairs(nums, mid) >= k) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private long countPairs(int[] a, int d) {
        long cnt = 0;
        int j = 0;
        for (int i = 0; i < a.length; i++) {
            while (a[i] - a[j] > d) j++;
            cnt += (i - j);
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：排序 \(O(n\log n)\)，二分 \(O(\log W)\) 次，每次计数 \(O(n)\)，总 \(O(n\log n + n\log W)\)
- 空间：\(O(1)\)（不算排序）
