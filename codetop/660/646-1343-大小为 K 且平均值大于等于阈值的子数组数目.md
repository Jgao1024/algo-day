## 最佳解法思路
- 固定长度滑动窗口：
  - 先算前 `k` 个数之和
  - 每次窗口右移：`sum += a[i] - a[i-k]`
  - 若 `sum >= threshold * k` 计数 +1

## Java 最佳实现

```java
class Solution {
    public int numOfSubarrays(int[] arr, int k, int threshold) {
        int target = threshold * k;
        int sum = 0;
        for (int i = 0; i < k; i++) sum += arr[i];

        int ans = (sum >= target) ? 1 : 0;
        for (int i = k; i < arr.length; i++) {
            sum += arr[i] - arr[i - k];
            if (sum >= target) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
