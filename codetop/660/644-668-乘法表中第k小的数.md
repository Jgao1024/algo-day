## 最佳解法思路
- 二分答案 `x`（范围 \([1, m*n]\)），统计乘法表中 `<= x` 的个数：
  - 第 `i` 行是 `i, 2i, 3i ... ni`，所以这一行 `<=x` 的个数是 `min(n, x / i)`
  - 总数 `cnt = sum(min(n, x/i))`
  - 若 `cnt >= k`，说明答案不大于 `x`，右边界收缩

## Java 最佳实现

```java
class Solution {
    public int findKthNumber(int m, int n, int k) {
        int lo = 1, hi = m * n;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countLE(m, n, mid) >= k) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private int countLE(int m, int n, int x) {
        long cnt = 0;
        for (int i = 1; i <= m; i++) {
            cnt += Math.min(n, x / i);
        }
        return (int) cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(m \log(mn))\)
- 空间：\(O(1)\)
