## 最佳解法思路
- 贪心（用 long 防溢出）：
  - 若 `n` 为偶数：`n = n/2`
  - 若 `n` 为奇数：优先让 `n` 变成能多除 2 的数
    - 特判 `n == 3`：`3 -> 2 -> 1` 更优
    - 其它奇数：若 `(n & 3) == 1` 选 `n-1`，否则选 `n+1`

## Java 最佳实现

```java
class Solution {
    public int integerReplacement(int n) {
        long x = n;
        int ans = 0;
        while (x != 1) {
            if ((x & 1) == 0) {
                x >>= 1;
            } else {
                if (x == 3) {
                    x--;
                } else if ((x & 3) == 1) {
                    x--;
                } else {
                    x++;
                }
            }
            ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
