## 最佳解法思路
- 前缀和 + 归并排序分治计数：
  - 令 `pre[i]` 为前 `i` 个数的和，则区间和 `sum(i..j) = pre[j+1] - pre[i]`
  - 对 `pre` 做分治：左右两半分别计数后，统计跨越左右的对数
  - 对于左边每个 `pre[i]`，在右边找到 `pre[k]-pre[i] >= lower` 的最小 `k`，以及 `pre[j]-pre[i] <= upper` 的最大边界 `j`
  - 右半段有序时可用双指针线性统计

## Java 最佳实现

```java
class Solution {
    public int countRangeSum(int[] nums, int lower, int upper) {
        int n = nums.length;
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];
        long[] tmp = new long[n + 1];
        long ans = sortCount(pre, tmp, 0, n + 1, lower, upper);
        return (int) ans;
    }

    private long sortCount(long[] a, long[] tmp, int l, int r, int lower, int upper) {
        if (r - l <= 1) return 0;
        int m = (l + r) >>> 1;
        long cnt = sortCount(a, tmp, l, m, lower, upper) + sortCount(a, tmp, m, r, lower, upper);

        int i = l, k = m, j = m;
        for (; i < m; i++) {
            while (k < r && a[k] - a[i] < lower) k++;
            while (j < r && a[j] - a[i] <= upper) j++;
            cnt += (j - k);
        }

        int p1 = l, p2 = m, t = l;
        while (p1 < m && p2 < r) {
            if (a[p1] <= a[p2]) tmp[t++] = a[p1++];
            else tmp[t++] = a[p2++];
        }
        while (p1 < m) tmp[t++] = a[p1++];
        while (p2 < r) tmp[t++] = a[p2++];
        for (int p = l; p < r; p++) a[p] = tmp[p];

        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
