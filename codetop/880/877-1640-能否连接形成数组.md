## 最佳解法思路
- **用首元素做映射**  
把每个 `piece` 的首元素映射到该数组。遍历 `arr`，遇到 `arr[i]` 就找到对应 `piece`，并检查 `piece` 是否与 `arr` 从 `i` 开始完全匹配，匹配后跳过该段。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean canFormArray(int[] arr, int[][] pieces) {
        Map<Integer, int[]> map = new HashMap<>();
        for (int[] p : pieces) {
            map.put(p[0], p);
        }

        int i = 0;
        while (i < arr.length) {
            int[] p = map.get(arr[i]);
            if (p == null) return false;
            for (int x : p) {
                if (i >= arr.length || arr[i] != x) return false;
                i++;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(\text{pieces})\)
