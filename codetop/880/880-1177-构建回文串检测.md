## 最佳解法思路
- **前缀异或（奇偶位掩码）**  
用 `mask` 的第 `i` 位表示字符 `i` 的出现次数奇偶性。前缀 `pre[t]` 表示 `s[0..t-1]` 的奇偶 mask。  
区间 `[l,r]` 的 mask 为 `pre[r+1] ^ pre[l]`，其中 1 的个数就是“出现奇数次的字符数” `odd`。  
要变成回文，最多允许 `odd/2` 次替换，因此判断 `odd/2 <= k`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Boolean> canMakePaliQueries(String s, int[][] queries) {
        int n = s.length();
        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) {
            int bit = 1 << (s.charAt(i) - 'a');
            pre[i + 1] = pre[i] ^ bit;
        }

        List<Boolean> ans = new ArrayList<>(queries.length);
        for (int[] q : queries) {
            int l = q[0];
            int r = q[1];
            int k = q[2];
            int mask = pre[r + 1] ^ pre[l];
            int odd = Integer.bitCount(mask);
            ans.add(odd / 2 <= k);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：预处理 \(O(n)\)，每次查询 \(O(1)\)
- 空间：\(O(n)\)
