## 最佳解法思路
- **前缀和按面积加权随机**  
每个矩形包含的整点数为 `(x2-x1+1)*(y2-y1+1)`，用前缀和做“加权轮盘”：  
先随机一个 `[0,total)` 的下标，二分找到落在哪个矩形；再在该矩形内按偏移量映射到 `(x,y)`。

## Java 最佳实现

```java
import java.util.concurrent.ThreadLocalRandom;

class Solution {
    private final int[][] rects;
    private final long[] pre;
    private final long total;

    public Solution(int[][] rects) {
        this.rects = rects;
        this.pre = new long[rects.length];
        long sum = 0;
        for (int i = 0; i < rects.length; i++) {
            int[] r = rects[i];
            long cnt = (long) (r[2] - r[0] + 1) * (r[3] - r[1] + 1);
            sum += cnt;
            pre[i] = sum;
        }
        this.total = sum;
    }

    public int[] pick() {
        long k = ThreadLocalRandom.current().nextLong(total);
        int idx = lowerBound(pre, k + 1);
        int[] r = rects[idx];
        long before = idx == 0 ? 0 : pre[idx - 1];
        long offset = k - before;

        int w = r[2] - r[0] + 1;
        int x = r[0] + (int) (offset % w);
        int y = r[1] + (int) (offset / w);
        return new int[]{x, y};
    }

    private int lowerBound(long[] a, long target) {
        int l = 0;
        int r = a.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (a[mid] >= target) r = mid;
            else l = mid + 1;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：构造 \(O(n)\)，每次 `pick` 为 \(O(\log n)\)
- 空间：\(O(n)\)
