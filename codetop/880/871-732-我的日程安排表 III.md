## 最佳解法思路
- **扫描线差分（TreeMap）**  
每次预订 `[start,end)`：`start` 处 +1，`end` 处 -1。  
用 `TreeMap` 存差分点，然后按时间升序累加得到当前时刻的并发数，取最大值返回。

## Java 最佳实现

```java
import java.util.Map;
import java.util.TreeMap;

class MyCalendarThree {
    private final TreeMap<Integer, Integer> diff = new TreeMap<>();

    public MyCalendarThree() {
    }

    public int book(int start, int end) {
        diff.put(start, diff.getOrDefault(start, 0) + 1);
        diff.put(end, diff.getOrDefault(end, 0) - 1);

        int cur = 0;
        int ans = 0;
        for (Map.Entry<Integer, Integer> e : diff.entrySet()) {
            cur += e.getValue();
            if (cur > ans) ans = cur;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：每次预订 \(O(M)\)，\(M\) 为差分点个数
- 空间：\(O(M)\)
