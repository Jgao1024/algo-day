## 最佳解法思路
- **裴蜀定理：gcd 为 1 即可**  
如果数组所有元素的最大公约数 `gcd(nums)` 为 1，则可以通过整数组合得到 1（因此是好数组）；否则不行。

## Java 最佳实现

```java
class Solution {
    public boolean isGoodArray(int[] nums) {
        int g = 0;
        for (int x : nums) g = gcd(g, x);
        return g == 1;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log V)\)
- 空间：\(O(1)\)
