## 最佳解法思路
- **滑动窗口：让窗口外满足平衡**  
设 `limit = n/4`。如果窗口外 `Q/W/E/R` 的计数都 `<= limit`，说明替换窗口内的子串就能补齐成平衡。  
初始统计总计数，右指针扩张时把字符从“外部计数”里减掉；当外部已满足条件时，尝试收缩左指针更新最小窗口。

## Java 最佳实现

```java
class Solution {
    public int balancedString(String s) {
        int n = s.length();
        int limit = n / 4;
        int[] cnt = new int[128];
        for (int i = 0; i < n; i++) cnt[s.charAt(i)]++;

        if (ok(cnt, limit)) return 0;

        int ans = n;
        int l = 0;
        for (int r = 0; r < n; r++) {
            cnt[s.charAt(r)]--;
            while (l <= r && ok(cnt, limit)) {
                ans = Math.min(ans, r - l + 1);
                cnt[s.charAt(l)]++;
                l++;
            }
        }
        return ans;
    }

    private boolean ok(int[] cnt, int limit) {
        return cnt['Q'] <= limit && cnt['W'] <= limit && cnt['E'] <= limit && cnt['R'] <= limit;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
