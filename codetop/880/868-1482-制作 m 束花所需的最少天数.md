## 最佳解法思路
- **二分答案 + 贪心校验**  
天数越大，能做出的花束越多（单调性）。对天数 `day` 做二分：  
扫描 `bloomDay`，统计连续 `<= day` 的花朵数，凑够 `k` 朵就做一束并清零，最后看能否做出 `m` 束。

## Java 最佳实现

```java
class Solution {
    public int minDays(int[] bloomDay, int m, int k) {
        long need = (long) m * k;
        if (need > bloomDay.length) return -1;

        int lo = Integer.MAX_VALUE;
        int hi = Integer.MIN_VALUE;
        for (int d : bloomDay) {
            if (d < lo) lo = d;
            if (d > hi) hi = d;
        }

        int l = lo;
        int r = hi;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (canMake(bloomDay, m, k, mid)) r = mid;
            else l = mid + 1;
        }
        return l;
    }

    private boolean canMake(int[] a, int m, int k, int day) {
        int bouquet = 0;
        int cnt = 0;
        for (int x : a) {
            if (x <= day) {
                cnt++;
                if (cnt == k) {
                    bouquet++;
                    if (bouquet >= m) return true;
                    cnt = 0;
                }
            } else {
                cnt = 0;
            }
        }
        return bouquet >= m;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log D)\)，\(D\) 为天数范围
- 空间：\(O(1)\)
