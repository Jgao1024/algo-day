## 最佳解法思路
- **枚举 a 的长度，推导 b 的长度**  
统计 `pattern` 中 `a/b` 个数。为了方便，先把 `pattern` 变成以 `a` 开头（如果开头是 `b` 就把 a/b 交换）。  
枚举 `a` 对应子串长度 `lenA`，则 `lenB` 可由总长度推导出来（必须是整数且 ≥0）。  
按 pattern 依次切片比对，首次出现时记录 `aStr/bStr`，之后必须一致，并且要求 `aStr` 与 `bStr` 不能相同。

## Java 最佳实现

```java
class Solution {
    public boolean patternMatching(String pattern, String value) {
        if (pattern.length() == 0) return value.length() == 0;

        boolean swapped = false;
        if (pattern.charAt(0) == 'b') {
            pattern = swap(pattern);
            swapped = true;
        }

        int aCnt = 0;
        int bCnt = 0;
        for (int i = 0; i < pattern.length(); i++) {
            if (pattern.charAt(i) == 'a') aCnt++;
            else bCnt++;
        }

        int n = value.length();
        int maxLenA = aCnt == 0 ? 0 : n / aCnt;
        for (int lenA = 0; lenA <= maxLenA; lenA++) {
            int rest = n - lenA * aCnt;
            if (bCnt == 0) {
                if (rest != 0) continue;
                if (match(pattern, value, lenA, 0, swapped)) return true;
            } else {
                if (rest < 0 || rest % bCnt != 0) continue;
                int lenB = rest / bCnt;
                if (match(pattern, value, lenA, lenB, swapped)) return true;
            }
        }
        return false;
    }

    private boolean match(String pattern, String value, int lenA, int lenB, boolean swapped) {
        String aStr = null;
        String bStr = null;
        int idx = 0;

        for (int i = 0; i < pattern.length(); i++) {
            char ch = pattern.charAt(i);
            int len = ch == 'a' ? lenA : lenB;
            if (idx + len > value.length()) return false;
            String sub = value.substring(idx, idx + len);
            idx += len;

            if (ch == 'a') {
                if (aStr == null) aStr = sub;
                else if (!aStr.equals(sub)) return false;
            } else {
                if (bStr == null) bStr = sub;
                else if (!bStr.equals(sub)) return false;
            }
        }

        if (idx != value.length()) return false;
        if (aStr == null) aStr = "";
        if (bStr == null) bStr = "";
        if (aStr.equals(bStr)) return false;
        return true;
    }

    private String swap(String pattern) {
        char[] cs = pattern.toCharArray();
        for (int i = 0; i < cs.length; i++) {
            cs[i] = cs[i] == 'a' ? 'b' : 'a';
        }
        return new String(cs);
    }
}
```

## 复杂度分析
- 时间：最坏约 \(O(n \cdot |pattern|)\)（枚举 `lenA`）
- 空间：\(O(1)\)（不计子串）
