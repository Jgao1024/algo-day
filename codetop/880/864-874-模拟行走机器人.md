## 最佳解法思路
- **方向模拟 + 障碍哈希**  
用方向数组表示北东南西，`-1/-2` 改方向，正数表示前进步数。  
把障碍坐标编码进 `HashSet`，每走一步就判断下一个格子是否是障碍，遇到障碍停下。过程中维护最大欧式距离平方。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    private static final int[] DX = {0, 1, 0, -1};
    private static final int[] DY = {1, 0, -1, 0};

    public int robotSim(int[] commands, int[][] obstacles) {
        Set<Long> set = new HashSet<>();
        for (int[] o : obstacles) {
            set.add(key(o[0], o[1]));
        }

        int x = 0;
        int y = 0;
        int dir = 0;
        int ans = 0;
        for (int cmd : commands) {
            if (cmd == -2) {
                dir = (dir + 3) % 4;
            } else if (cmd == -1) {
                dir = (dir + 1) % 4;
            } else {
                for (int s = 0; s < cmd; s++) {
                    int nx = x + DX[dir];
                    int ny = y + DY[dir];
                    if (set.contains(key(nx, ny))) break;
                    x = nx;
                    y = ny;
                    int d = x * x + y * y;
                    if (d > ans) ans = d;
                }
            }
        }
        return ans;
    }

    private long key(int x, int y) {
        return (((long) x) << 32) ^ (y & 0xffffffffL);
    }
}
```

## 复杂度分析
- 时间：\(O(\text{总步数})\)
- 空间：\(O(\text{障碍数量})\)
