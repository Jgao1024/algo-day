## 最佳解法思路
- **拼接一致性 + 长度 gcd**  
若 `str1 + str2 != str2 + str1`，说明不存在公共基串。  
否则答案长度是 `gcd(len1, len2)`，返回 `str1` 的前 `g` 个字符。

## Java 最佳实现

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        if (!(str1 + str2).equals(str2 + str1)) return "";
        int g = gcd(str1.length(), str2.length());
        return str1.substring(0, g);
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（拼接产生新字符串）
