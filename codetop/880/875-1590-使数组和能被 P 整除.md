## 最佳解法思路
- **前缀和取模 + 哈希表记录最近位置**  
设总和对 `p` 取模为 `need`，要删除的子数组和对 `p` 取模也必须是 `need`。  
扫描前缀模 `pre`，若存在某个历史前缀模 `preOld` 使得 `(pre - preOld + p) % p == need`，则可删除区间 `(old+1..i)`，取最短即可。  
为了最短，哈希表记录每个模值最新出现的位置。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int minSubarray(int[] nums, int p) {
        long sum = 0;
        for (int x : nums) sum += x;
        int need = (int) (sum % p);
        if (need == 0) return 0;

        Map<Integer, Integer> last = new HashMap<>();
        last.put(0, -1);
        int pre = 0;
        int ans = nums.length;

        for (int i = 0; i < nums.length; i++) {
            pre = (pre + nums[i]) % p;
            int want = (pre - need + p) % p;
            Integer j = last.get(want);
            if (j != null) {
                int len = i - j;
                if (len < ans) ans = len;
            }
            last.put(pre, i);
        }
        return ans == nums.length ? -1 : ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(p)\)（最坏 \(O(n)\)）
