## 最佳解法思路
- **贪心 + 大根堆**  
按课程截止时间 `lastDay` 升序排序，依次考虑每门课：  
把课程时长 `duration` 加进总时间 `time` 并入大根堆；若 `time > lastDay`，说明安排不下，就把堆里“最耗时”的课程踢掉（弹出最大 duration），这样能让后续尽可能放下更多课程。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int scheduleCourse(int[][] courses) {
        Arrays.sort(courses, (a, b) -> a[1] - b[1]);
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        int time = 0;
        for (int[] c : courses) {
            int d = c[0];
            int end = c[1];
            time += d;
            maxHeap.add(d);
            if (time > end) {
                time -= maxHeap.poll();
            }
        }
        return maxHeap.size();
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
