## 最佳解法思路
- **按 event_type 求均值，再筛业务**  
先按 `event_type` 计算平均 `occurences`，再找出每条记录是否大于该平均值；最后统计每个 `business_id` 满足条件的 `event_type` 个数，至少 2 个即为活跃业务。

## SQL 最佳实现

```sql
WITH avg_tbl AS (
  SELECT event_type, AVG(occurences) AS avg_occ
  FROM Events
  GROUP BY event_type
),
above AS (
  SELECT e.business_id, e.event_type
  FROM Events e
  JOIN avg_tbl a
    ON e.event_type = a.event_type
  WHERE e.occurences > a.avg_occ
)
SELECT business_id
FROM above
GROUP BY business_id
HAVING COUNT(*) >= 2;
```

## 复杂度分析
- 时间：\(O(n)\)（分组/连接）
- 空间：\(O(n)\)
