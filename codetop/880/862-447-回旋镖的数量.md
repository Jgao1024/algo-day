## 最佳解法思路
- **固定点 i，按距离分组计数**  
对每个点 `i`，计算它到其他点 `j` 的平方距离 `d`，同一距离的点数为 `cnt`，能组成的有序回旋镖数量是 `cnt*(cnt-1)`（选两个不同点作为 (j,k) 且有序）。  
把所有 `i` 的结果累加。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfBoomerangs(int[][] points) {
        int n = points.length;
        int ans = 0;
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < n; i++) {
            map.clear();
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                int dx = points[i][0] - points[j][0];
                int dy = points[i][1] - points[j][1];
                int d = dx * dx + dy * dy;
                map.put(d, map.getOrDefault(d, 0) + 1);
            }
            for (int cnt : map.values()) {
                ans += cnt * (cnt - 1);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
