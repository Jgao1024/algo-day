## 最佳解法思路
- 双指针：
  - `l = 0`，`r = floor(sqrt(c))`
  - 比较 `l^2 + r^2` 与 `c`：
    - 大了就 `r--`
    - 小了就 `l++`
    - 相等返回 true

## Java 最佳实现

```java
class Solution {
    public boolean judgeSquareSum(int c) {
        long l = 0;
        long r = (long) Math.sqrt(c);
        while (l <= r) {
            long sum = l * l + r * r;
            if (sum == c) return true;
            if (sum > c) r--;
            else l++;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{c})\)
- 空间：\(O(1)\)
