## 最佳解法思路
- 转化为“分成两堆尽量接近”的 0/1 背包：
  - 总和 `sum`，目标是找一个子集和 `j` 尽量接近 `sum/2`
  - 最小剩余重量 = `sum - 2*j`
  - 用一维布尔 `dp[j]` 表示是否能凑出和 `j`

## Java 最佳实现

```java
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int sum = 0;
        for (int x : stones) sum += x;
        int target = sum / 2;

        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int w : stones) {
            for (int j = target; j >= w; j--) {
                dp[j] = dp[j] || dp[j - w];
            }
        }

        for (int j = target; j >= 0; j--) {
            if (dp[j]) return sum - 2 * j;
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot sum)\)
- 空间：\(O(sum)\)
