## 最佳解法思路
- 多路归并 + 最小堆：
  - 每个列表取一个当前元素放入最小堆，堆顶是当前最小值，同时维护当前最大值 `max`
  - 现在窗口是 \([min, max]\)，更新最优答案
  - 弹出堆顶（最小值来自某个列表），把该列表的下一个元素加入堆，并更新 `max`
  - 某个列表耗尽时结束（无法再覆盖所有列表）

## Java 最佳实现

```java
import java.util.Comparator;
import java.util.List;
import java.util.PriorityQueue;

class Solution {
    public int[] smallestRange(List<List<Integer>> nums) {
        int k = nums.size();
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < k; i++) {
            int v = nums.get(i).get(0);
            pq.offer(new int[]{v, i, 0}); // value, listIndex, elemIndex
            max = Math.max(max, v);
        }

        int bestL = 0, bestR = Integer.MAX_VALUE;
        while (pq.size() == k) {
            int[] cur = pq.poll();
            int min = cur[0], li = cur[1], ei = cur[2];
            if (max - min < bestR - bestL) {
                bestL = min;
                bestR = max;
            }

            int nextIdx = ei + 1;
            if (nextIdx >= nums.get(li).size()) break;
            int nextVal = nums.get(li).get(nextIdx);
            pq.offer(new int[]{nextVal, li, nextIdx});
            if (nextVal > max) max = nextVal;
        }
        return new int[]{bestL, bestR};
    }
}
```

## 复杂度分析
- 时间：\(O(N\log k)\)，\(N\) 为所有元素总数
- 空间：\(O(k)\)
