## 最佳解法思路
- 栈模拟（字符 + 连续计数）：
  - 依次扫描字符
  - 若与栈顶字符相同，计数 +1；计数到 `k` 就弹栈（等价于删除）
  - 否则入栈新字符，计数为 1
  - 最后把栈内容拼回字符串

## Java 最佳实现

```java
class Solution {
    public String removeDuplicates(String s, int k) {
        int n = s.length();
        char[] cs = new char[n];
        int[] cnt = new int[n];
        int top = -1;

        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (top >= 0 && cs[top] == c) {
                cnt[top]++;
                if (cnt[top] == k) top--;
            } else {
                top++;
                cs[top] = c;
                cnt[top] = 1;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i <= top; i++) {
            for (int j = 0; j < cnt[i]; j++) sb.append(cs[i]);
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
