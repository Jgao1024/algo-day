## 最佳解法思路
- 以 `%20` 作为分隔符提取单词，倒序拼回：
  - 扫描字符串，遇到 `%20` 就截断一个单词
  - 忽略空单词（连续分隔符）
  - 反转单词列表，再用 `%20` 连接

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String reverseUrlWords(String s) {
        List<String> words = new ArrayList<>();
        int i = 0;
        int n = s.length();
        while (i < n) {
            int j = i;
            while (j + 2 < n && !(s.charAt(j) == '%' && s.charAt(j + 1) == '2' && s.charAt(j + 2) == '0')) {
                j++;
            }
            String w = s.substring(i, j);
            if (!w.isEmpty()) words.add(w);
            if (j + 2 < n) i = j + 3;
            else i = n;
        }

        StringBuilder sb = new StringBuilder();
        for (int k = words.size() - 1; k >= 0; k--) {
            if (sb.length() > 0) sb.append("%20");
            sb.append(words.get(k));
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
