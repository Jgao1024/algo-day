## 最佳解法思路
- 遍历每个陆地格子：
  - 先贡献 4 条边
  - 每有一个相邻陆地（上下左右），就少一条边
  - 累加得到周长

## Java 最佳实现

```java
class Solution {
    public int islandPerimeter(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 1) continue;
                ans += 4;
                if (i > 0 && grid[i - 1][j] == 1) ans--;
                if (i + 1 < m && grid[i + 1][j] == 1) ans--;
                if (j > 0 && grid[i][j - 1] == 1) ans--;
                if (j + 1 < n && grid[i][j + 1] == 1) ans--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)
