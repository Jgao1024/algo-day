## 最佳解法思路
- Trie + DFS：
  - 先把 `words` 建成前缀树
  - 从网格每个格子出发 DFS，沿着 Trie 走
  - 走到某个节点若 `word != null`，说明找到一个单词（加入答案并置空避免重复）
  - 用原地标记 `board[i][j] = '#'` 表示访问过

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    static class Node {
        Node[] next = new Node[26];
        String word;
    }

    public List<String> findWords(char[][] board, String[] words) {
        Node root = build(words);
        List<String> ans = new ArrayList<>();
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dfs(board, i, j, root, ans);
            }
        }
        return ans;
    }

    private Node build(String[] words) {
        Node root = new Node();
        for (String w : words) {
            Node cur = root;
            for (int i = 0; i < w.length(); i++) {
                int idx = w.charAt(i) - 'a';
                if (cur.next[idx] == null) cur.next[idx] = new Node();
                cur = cur.next[idx];
            }
            cur.word = w;
        }
        return root;
    }

    private void dfs(char[][] b, int i, int j, Node node, List<String> ans) {
        char ch = b[i][j];
        if (ch == '#') return;
        Node nxt = node.next[ch - 'a'];
        if (nxt == null) return;

        if (nxt.word != null) {
            ans.add(nxt.word);
            nxt.word = null;
        }

        b[i][j] = '#';
        if (i > 0) dfs(b, i - 1, j, nxt, ans);
        if (i + 1 < b.length) dfs(b, i + 1, j, nxt, ans);
        if (j > 0) dfs(b, i, j - 1, nxt, ans);
        if (j + 1 < b[0].length) dfs(b, i, j + 1, nxt, ans);
        b[i][j] = ch;
    }
}
```

## 复杂度分析
- 时间：建 Trie \(O(\sum L)\)，搜索与网格规模及剪枝有关
- 空间：\(O(\sum L)\)
