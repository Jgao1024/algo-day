## 最佳解法思路
- 计算 4 个点两两之间的平方距离（共 6 个），排序后：
  - 最小的 4 个相等且 > 0（四条边）
  - 最大的 2 个相等（两条对角线）
  - 且对角线 = 2 * 边（平方距离关系）

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public boolean validSquare(int[] p1, int[] p2, int[] p3, int[] p4) {
        long[] d = new long[6];
        int idx = 0;
        int[][] ps = new int[][]{p1, p2, p3, p4};
        for (int i = 0; i < 4; i++) {
            for (int j = i + 1; j < 4; j++) {
                d[idx++] = dist2(ps[i], ps[j]);
            }
        }
        Arrays.sort(d);
        return d[0] > 0
                && d[0] == d[1] && d[1] == d[2] && d[2] == d[3]
                && d[4] == d[5]
                && d[4] == 2 * d[0];
    }

    private long dist2(int[] a, int[] b) {
        long dx = (long) a[0] - b[0];
        long dy = (long) a[1] - b[1];
        return dx * dx + dy * dy;
    }
}
```

- 时间：\(O(1)\)
- 空间：\(O(1)\)
