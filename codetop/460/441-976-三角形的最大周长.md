## 最佳解法思路
- 排序 + 贪心：把数组升序排序后，从右往左取连续三个数 \(a \le b \le c\)。若 \(a + b > c\) 则能组成三角形，而且此时周长最大（因为 \(c\) 已经尽可能大）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int largestPerimeter(int[] nums) {
        Arrays.sort(nums);
        for (int i = nums.length - 1; i >= 2; i--) {
            int a = nums[i - 2], b = nums[i - 1], c = nums[i];
            if (a + b > c) {
                return a + b + c;
            }
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（排序额外空间看实现）
