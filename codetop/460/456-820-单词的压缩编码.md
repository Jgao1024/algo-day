## 最佳解法思路
- 用集合删除“后缀词”：
  - 把所有单词放进 `Set`
  - 对每个单词，把它所有真后缀（从位置 1 开始）从集合里删掉
  - 最后集合里剩下的词就是编码里必须出现的词，答案是 \(\sum (len(word)+1)\)

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumLengthEncoding(String[] words) {
        Set<String> set = new HashSet<>();
        for (String w : words) set.add(w);

        for (String w : words) {
            for (int i = 1; i < w.length(); i++) {
                set.remove(w.substring(i));
            }
        }

        int ans = 0;
        for (String w : set) {
            ans += w.length() + 1;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：与所有单词的后缀总数有关（最坏约 \(O(\sum L^2)\)）
- 空间：\(O(\sum L)\)
