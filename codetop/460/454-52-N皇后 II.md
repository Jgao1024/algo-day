## 最佳解法思路
- 回溯：
  - 逐行放皇后
  - 用 `col[]`、`diag1[]`、`diag2[]` 标记列/两条对角线是否被占用
  - 放到第 `n` 行时计数 +1

## Java 最佳实现

```java
class Solution {
    private int n;
    private boolean[] col;
    private boolean[] d1;
    private boolean[] d2;
    private int ans;

    public int totalNQueens(int n) {
        this.n = n;
        this.col = new boolean[n];
        this.d1 = new boolean[2 * n];
        this.d2 = new boolean[2 * n];
        this.ans = 0;
        dfs(0);
        return ans;
    }

    private void dfs(int r) {
        if (r == n) {
            ans++;
            return;
        }
        for (int c = 0; c < n; c++) {
            int a = r - c + n;
            int b = r + c;
            if (col[c] || d1[a] || d2[b]) continue;
            col[c] = true;
            d1[a] = true;
            d2[b] = true;
            dfs(r + 1);
            col[c] = false;
            d1[a] = false;
            d2[b] = false;
        }
    }
}
```

## 复杂度分析
- 时间：回溯（近似 \(O(n!)\)）
- 空间：\(O(n)\)
