## 最佳解法思路
- 预处理回文 + DP 最少切割：
  - `pal[i][j]` 表示 `s[i..j]` 是否回文（从后往前填）
  - `dp[i]` 表示 `s[0..i]` 的最少切割次数
    - 若 `pal[0][i]` 为真，`dp[i]=0`
    - 否则 `dp[i] = min(dp[j] + 1)`，其中 `0<=j<i` 且 `pal[j+1][i]` 为真

## Java 最佳实现

```java
class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i < 2 || pal[i + 1][j - 1])) {
                    pal[i][j] = true;
                }
            }
        }

        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            if (pal[0][i]) {
                dp[i] = 0;
                continue;
            }
            int best = Integer.MAX_VALUE;
            for (int j = 0; j < i; j++) {
                if (pal[j + 1][i]) {
                    best = Math.min(best, dp[j] + 1);
                }
            }
            dp[i] = best;
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
