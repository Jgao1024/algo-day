## 最佳解法思路
- 计数 + 公式：
  - 设最高频次为 `maxCnt`，有 `maxNum` 种任务达到该频次
  - 先把最高频任务排成 `maxCnt - 1` 个“桶”，每个桶长度 `n + 1`
  - 最少时间 = \((maxCnt - 1) * (n + 1) + maxNum\)
  - 但如果其它任务足够填满空位，则答案是 `tasks.length`
  - 最终：`max(tasks.length, (maxCnt - 1) * (n + 1) + maxNum)`

## Java 最佳实现

```java
class Solution {
    public int leastInterval(char[] tasks, int n) {
        int[] cnt = new int[26];
        for (char c : tasks) cnt[c - 'A']++;

        int maxCnt = 0;
        for (int x : cnt) maxCnt = Math.max(maxCnt, x);

        int maxNum = 0;
        for (int x : cnt) if (x == maxCnt) maxNum++;

        int part = (maxCnt - 1) * (n + 1) + maxNum;
        return Math.max(tasks.length, part);
    }
}
```

## 复杂度分析
- 时间：\(O(26)\)
- 空间：\(O(26)\)
