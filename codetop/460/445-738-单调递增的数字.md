## 最佳解法思路
- 贪心（从右往左修正）：
  - 把数字转成字符数组 `digits`
  - 从右向左找首次出现 `digits[i-1] > digits[i]` 的位置，把 `digits[i-1]--`，并记录从 `i` 开始的后缀都要变成 `'9'`
  - 继续向左检查可能产生的连锁（比如 332 -> 299）

## Java 最佳实现

```java
class Solution {
    public int monotoneIncreasingDigits(int n) {
        char[] a = String.valueOf(n).toCharArray();
        int mark = a.length;
        for (int i = a.length - 1; i > 0; i--) {
            if (a[i - 1] > a[i]) {
                a[i - 1]--;
                mark = i;
            }
        }
        for (int i = mark; i < a.length; i++) {
            a[i] = '9';
        }
        return Integer.parseInt(new String(a));
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(\log n)\)
