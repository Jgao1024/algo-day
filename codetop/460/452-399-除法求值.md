## 最佳解法思路
- 建图 + 搜索：
  - 对每个等式 `a / b = v`，建双向边：`a -> b (v)`，`b -> a (1/v)`
  - 对每个查询 `x / y`，从 `x` 开始 BFS/DFS，沿边累乘，找到 `y` 即得到结果；找不到返回 `-1`

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Queue;
import java.util.Set;

class Solution {
    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
        Map<String, Map<String, Double>> g = new HashMap<>();
        for (int i = 0; i < equations.size(); i++) {
            String a = equations.get(i).get(0);
            String b = equations.get(i).get(1);
            double v = values[i];
            g.computeIfAbsent(a, k -> new HashMap<>()).put(b, v);
            g.computeIfAbsent(b, k -> new HashMap<>()).put(a, 1.0 / v);
        }

        double[] ans = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            String s = queries.get(i).get(0);
            String t = queries.get(i).get(1);
            ans[i] = bfs(g, s, t);
        }
        return ans;
    }

    private double bfs(Map<String, Map<String, Double>> g, String s, String t) {
        if (!g.containsKey(s) || !g.containsKey(t)) return -1.0;
        if (s.equals(t)) return 1.0;

        Queue<String> q = new ArrayDeque<>();
        Queue<Double> valQ = new ArrayDeque<>();
        Set<String> vis = new HashSet<>();
        q.offer(s);
        valQ.offer(1.0);
        vis.add(s);

        while (!q.isEmpty()) {
            String cur = q.poll();
            double curVal = valQ.poll();
            Map<String, Double> nexts = g.get(cur);
            for (Map.Entry<String, Double> e : nexts.entrySet()) {
                String nxt = e.getKey();
                if (vis.contains(nxt)) continue;
                double nxtVal = curVal * e.getValue();
                if (nxt.equals(t)) return nxtVal;
                vis.add(nxt);
                q.offer(nxt);
                valQ.offer(nxtVal);
            }
        }
        return -1.0;
    }
}
```

## 复杂度分析
- 时间：建图 \(O(E)\)，每次查询最坏 \(O(V+E)\)
- 空间：\(O(V+E)\)
