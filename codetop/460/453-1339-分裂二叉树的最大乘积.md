## 最佳解法思路
- 两次后序遍历：
  - 第一次算整棵树总和 `total`
  - 第二次算每个子树和 `sub`，如果切断“子树与父节点”的边，则两部分和分别是 `sub` 和 `total - sub`，乘积取最大
  - 最后对 \(10^9+7\) 取模

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private static final long MOD = 1000000007L;
    private long total;
    private long best;

    public int maxProduct(TreeNode root) {
        total = sum(root);
        best = 0;
        sum2(root);
        return (int) (best % MOD);
    }

    private long sum(TreeNode node) {
        if (node == null) return 0;
        return node.val + sum(node.left) + sum(node.right);
    }

    private long sum2(TreeNode node) {
        if (node == null) return 0;
        long left = sum2(node.left);
        long right = sum2(node.right);
        long sub = node.val + left + right;
        long prod = sub * (total - sub);
        if (prod > best) best = prod;
        return sub;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）
