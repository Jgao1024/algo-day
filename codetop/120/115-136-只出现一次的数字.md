# 136. 只出现一次的数字

- 题号：136
- 难度：简单
- LeetCode：[只出现一次的数字](https://leetcode.cn/problems/single-number/)

## 题目描述
给定非空整数数组，除一个元素只出现一次外，其余元素都出现两次。找出只出现一次的元素。

## 示例
- 示例  
输入：`nums = [4,1,2,1,2]`  
输出：`4`

## 最佳解法思路
- 异或（推荐）  
利用性质：`a^a=0`，`a^0=a`，异或满足交换律/结合律。把所有数异或起来，成对的会抵消，剩下的就是答案。

## Java 最佳实现

```java
class Solution {
    public int singleNumber(int[] nums) {
        int x = 0;
        for (int n : nums) x ^= n;
        return x;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
