# 47. 全排列 II

- 题号：47
- 难度：中等
- LeetCode：[全排列 II](https://leetcode.cn/problems/permutations-ii/)

## 题目描述
给定可包含重复数字的数组 `nums`，返回所有不重复的全排列。

## 示例
- 示例  
输入：`nums = [1,1,2]`  
输出：`[[1,1,2],[1,2,1],[2,1,1]]`

## 最佳解法思路
- 回溯 + 去重（推荐）  
先排序。用 `used[i]` 表示该位置是否已选。  
在同一层里，如果 `nums[i] == nums[i-1]` 且 `nums[i-1]` 没被用过，跳过当前 `i`，避免产生重复排列。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        dfs(nums, used, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            path.add(nums[i]);
            dfs(nums, used, path, res);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(n \cdot n!)\)（去重后会更少）
- 空间：\(O(n)\)（递归栈与 `used`，不含输出）

## 总结（速记）
- **排序 + used；同层去重条件：`nums[i]==nums[i-1] && !used[i-1]` 就跳过**。
