# 40. 组合总和 II

- 题号：40
- 难度：中等
- LeetCode：[组合总和 II](https://leetcode.cn/problems/combination-sum-ii/)

## 题目描述
给定候选数组 `candidates`（可包含重复数字）和目标值 `target`，找出所有和为 `target` 的组合。每个数字只能使用一次，解集不能包含重复组合。

## 示例
- 示例  
输入：`candidates = [10,1,2,7,6,1,5], target = 8`  
输出：`[[1,1,6],[1,2,5],[1,7],[2,6]]`

## 最佳解法思路
- 回溯 + 排序去重（推荐）  
先排序，便于剪枝与去重。  
每层从 `start` 开始选数，选了 `i` 后递归 `i+1`（保证每个元素只用一次）。  
同一层遇到重复值跳过：`i > start && candidates[i] == candidates[i-1]`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, 0, target, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int[] a, int start, int remain, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < a.length; i++) {
            if (i > start && a[i] == a[i - 1]) continue;
            if (a[i] > remain) break;
            path.add(a[i]);
            dfs(a, i + 1, remain - a[i], path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：指数级（回溯），剪枝后通常较快
- 空间：\(O(n)\)（递归栈与路径，不含输出）

## 总结（速记）
- **排序；同层去重 `i>start && a[i]==a[i-1]`；下一层用 `i+1` 保证只用一次**。
