# 402. 移掉K位数字

- 题号：402
- 难度：中等
- LeetCode：[移掉K位数字](https://leetcode.cn/problems/remove-k-digits/)

## 题目描述
给定非负整数 `num`（字符串形式）和整数 `k`，移除 `k` 位数字，使得剩下的数字最小，返回结果字符串（不能有前导零，除非结果为 0）。

## 示例
- 示例  
输入：`num = "1432219", k = 3`  
输出：`"1219"`

## 最佳解法思路
- 单调栈（推荐）  
从左到右扫描数字，维护一个单调递增栈（用 `StringBuilder` 当栈）。  
遇到新数字 `c`，只要 `k>0` 且栈顶 > `c`，就弹栈（删除更大的高位），`k--`；然后把 `c` 入栈。  
扫描完若 `k` 仍 > 0，继续从栈尾删除。  
最后去掉前导 0，空则返回 `"0"`。

## Java 最佳实现

```java
class Solution {
    public String removeKdigits(String num, int k) {
        StringBuilder st = new StringBuilder();
        for (int i = 0; i < num.length(); i++) {
            char c = num.charAt(i);
            while (k > 0 && st.length() > 0 && st.charAt(st.length() - 1) > c) {
                st.deleteCharAt(st.length() - 1);
                k--;
            }
            st.append(c);
        }
        while (k > 0 && st.length() > 0) {
            st.deleteCharAt(st.length() - 1);
            k--;
        }

        int idx = 0;
        while (idx < st.length() && st.charAt(idx) == '0') idx++;
        String ans = st.substring(idx);
        return ans.length() == 0 ? "0" : ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **想变小就删“左边更大的数”：维护递增栈，遇到更小数字就一直弹**。
