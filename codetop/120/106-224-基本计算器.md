# 224. 基本计算器

- 题号：224
- 难度：困难
- LeetCode：[基本计算器](https://leetcode.cn/problems/basic-calculator/)

## 题目描述
给定字符串表达式 `s`（包含数字、`+`、`-`、括号和空格），计算并返回结果。

## 示例
- 示例  
输入：`s = "(1+(4+5+2)-3)+(6+8)"`  
输出：`23`

## 最佳解法思路
- 栈保存“外层状态”（推荐）  
从左到右扫描：  
`res` 表示当前括号层的累计结果，`sign` 表示当前数字前的符号（+1 / -1）。  
遇到数字就读完整数字并累加到 `res`；遇到 `+/-` 更新 `sign`；  
遇到 `(` 把当前 `res` 和 `sign` 入栈，并重置 `res=0, sign=1`；  
遇到 `)` 先把括号内 `res` 乘上栈顶的 `sign`，再加上栈里保存的外层 `res`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int calculate(String s) {
        int res = 0;
        int sign = 1;
        Deque<Integer> st = new ArrayDeque<>();

        int i = 0;
        while (i < s.length()) {
            char c = s.charAt(i);
            if (c == ' ') {
                i++;
            } else if (c == '+') {
                sign = 1;
                i++;
            } else if (c == '-') {
                sign = -1;
                i++;
            } else if (c == '(') {
                st.push(res);
                st.push(sign);
                res = 0;
                sign = 1;
                i++;
            } else if (c == ')') {
                int prevSign = st.pop();
                int prevRes = st.pop();
                res = prevRes + prevSign * res;
                i++;
            } else {
                int num = 0;
                while (i < s.length()) {
                    char ch = s.charAt(i);
                    if (ch < '0' || ch > '9') break;
                    num = num * 10 + (ch - '0');
                    i++;
                }
                res += sign * num;
            }
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **遇 '(' 把“当前 res 和 sign”压栈；遇 ')' 弹出 sign/res 合并回外层**。
