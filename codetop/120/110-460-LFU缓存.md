# 460. LFU缓存

- 题号：460
- 难度：困难
- LeetCode：[LFU缓存](https://leetcode.cn/problems/lfu-cache/)

## 题目描述
设计 LFU（Least Frequently Used）缓存：支持 `get(key)`、`put(key,value)`，当容量满时淘汰 **使用频率最低** 的键；若频率相同，淘汰 **最久未使用** 的键。

## 示例
- 示例  
输入：`capacity = 2`，操作序列见题面  
输出：按 LFU 规则返回/淘汰

## 最佳解法思路
- HashMap + “频次桶”双向链表（推荐）  
维护：  
1) `key -> Node`：O(1) 找节点  
2) `freq -> DoublyList`：同一频次的节点按 LRU 顺序存放（头新尾旧）  
3) `minFreq`：当前缓存的最小频次  
`get/put` 命中时：把节点从旧频次链表移除，频次 +1，加入新频次链表头；必要时更新 `minFreq`。  
`put` 需要淘汰时：从 `minFreq` 对应链表尾部删除一个节点（同频次下 LRU）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class LFUCache {
    private final int capacity;
    private int size = 0;
    private int minFreq = 0;
    private final Map<Integer, Node> keyToNode = new HashMap<>();
    private final Map<Integer, DoublyList> freqToList = new HashMap<>();

    public LFUCache(int capacity) {
        this.capacity = capacity;
    }

    public int get(int key) {
        Node node = keyToNode.get(key);
        if (node == null) return -1;
        touch(node);
        return node.value;
    }

    public void put(int key, int value) {
        if (capacity == 0) return;

        Node node = keyToNode.get(key);
        if (node != null) {
            node.value = value;
            touch(node);
            return;
        }

        if (size == capacity) {
            DoublyList list = freqToList.get(minFreq);
            Node removed = list.removeLast();
            keyToNode.remove(removed.key);
            size--;
        }

        Node newNode = new Node(key, value);
        keyToNode.put(key, newNode);
        minFreq = 1;
        freqToList.computeIfAbsent(1, k -> new DoublyList()).addFirst(newNode);
        size++;
    }

    private void touch(Node node) {
        int freq = node.freq;
        DoublyList oldList = freqToList.get(freq);
        oldList.remove(node);

        if (freq == minFreq && oldList.isEmpty()) {
            minFreq++;
        }

        node.freq++;
        freqToList.computeIfAbsent(node.freq, k -> new DoublyList()).addFirst(node);
    }

    private static class Node {
        int key;
        int value;
        int freq = 1;
        Node prev;
        Node next;

        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private static class DoublyList {
        private final Node head = new Node(0, 0);
        private final Node tail = new Node(0, 0);
        private int size = 0;

        DoublyList() {
            head.next = tail;
            tail.prev = head;
        }

        boolean isEmpty() {
            return size == 0;
        }

        void addFirst(Node node) {
            Node next = head.next;
            head.next = node;
            node.prev = head;
            node.next = next;
            next.prev = node;
            size++;
        }

        void remove(Node node) {
            Node p = node.prev;
            Node n = node.next;
            p.next = n;
            n.prev = p;
            node.prev = null;
            node.next = null;
            size--;
        }

        Node removeLast() {
            Node node = tail.prev;
            remove(node);
            return node;
        }
    }
}
```

## 复杂度分析
- 时间：`get/put` 均摊 \(O(1)\)
- 空间：\(O(capacity)\)

## 总结（速记）
- **key->node + freq->双向链表；淘汰 `minFreq` 链表尾（LRU）**。
