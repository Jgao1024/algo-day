# 739. 每日温度

- 题号：739
- 难度：中等
- LeetCode：[每日温度](https://leetcode.cn/problems/daily-temperatures/)

## 题目描述
给定每天的温度数组 `temperatures`，返回一个数组 `answer`：`answer[i]` 表示第 `i` 天之后需要等几天才会出现更高温度；若没有更高温度则为 `0`。

## 示例
输入：`temperatures = [73,74,75,71,69,72,76,73]`  
输出：`[1,1,4,2,1,1,0,0]`

## 最佳解法思路
- 思路1（推荐）：单调栈（递减栈，存下标）  
栈里下标对应的温度保持递减。遍历到第 `i` 天时，如果 `temperatures[i]` 大于栈顶下标对应温度，说明找到了栈顶那天的“下一个更高温度”，弹栈并更新答案为 `i - idx`，直到不能弹为止；最后把 `i` 入栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] ans = new int[n];
        Deque<Integer> st = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && temperatures[i] > temperatures[st.peek()]) {
                int idx = st.pop();
                ans[idx] = i - idx;
            }
            st.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 单调栈存“下标”，栈内温度递减；遇到更高温度就弹栈并写 `距离 = 当前下标 - 被弹下标`。
