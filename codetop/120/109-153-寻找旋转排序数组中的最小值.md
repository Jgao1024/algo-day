# 153. 寻找旋转排序数组中的最小值

- 题号：153
- 难度：中等
- LeetCode：[寻找旋转排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)

## 题目描述
给定一个经过旋转的升序数组 `nums`（无重复），返回其中的最小元素。

## 示例
- 示例  
输入：`nums = [3,4,5,1,2]`  
输出：`1`

## 最佳解法思路
- 二分查找（推荐）  
比较 `nums[mid]` 和 `nums[r]`：  
若 `nums[mid] > nums[r]`，最小值在右半段，`l = mid + 1`；  
否则最小值在左半段（含 mid），`r = mid`。  
最终 `l==r` 即最小值位置。

## Java 最佳实现

```java
class Solution {
    public int findMin(int[] nums) {
        int l = 0, r = nums.length - 1;
        while (l < r) {
            int mid = l + ((r - l) >> 1);
            if (nums[mid] > nums[r]) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return nums[l];
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
