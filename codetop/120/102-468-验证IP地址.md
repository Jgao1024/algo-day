# 468. 验证IP地址

- 题号：468
- 难度：中等
- LeetCode：[验证IP地址](https://leetcode.cn/problems/validate-ip-address/)

## 题目描述
给定字符串 `queryIP`，判断其是合法 IPv4、合法 IPv6，还是都不是。

## 示例
- 输入：`queryIP = "172.16.254.1"`  
输出：`"IPv4"`

- 输入：`queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"`  
输出：`"IPv6"`

## 最佳解法思路
- 思路1（推荐）：按分隔符拆分 + 逐段校验  
如果包含 `.`，按 IPv4 规则校验 4 段：每段只能是数字，长度 1~3，不能有前导 0（除非就是 "0"），数值范围 0~255。  
如果包含 `:`，按 IPv6 规则校验 8 段：每段长度 1~4，只能是十六进制字符（0-9a-fA-F）。  
注意用 `split(..., -1)` 保留空段，能正确判定诸如 `"1.1.1."` 这类非法情况。

## Java 最佳实现

```java
class Solution {
    public String validIPAddress(String queryIP) {
        if (queryIP.indexOf('.') >= 0) return isIPv4(queryIP) ? "IPv4" : "Neither";
        if (queryIP.indexOf(':') >= 0) return isIPv6(queryIP) ? "IPv6" : "Neither";
        return "Neither";
    }

    private boolean isIPv4(String s) {
        String[] parts = s.split("\\.", -1);
        if (parts.length != 4) return false;
        for (String p : parts) {
            if (p.length() == 0 || p.length() > 3) return false;
            if (p.length() > 1 && p.charAt(0) == '0') return false;
            int val = 0;
            for (int i = 0; i < p.length(); i++) {
                char c = p.charAt(i);
                if (c < '0' || c > '9') return false;
                val = val * 10 + (c - '0');
            }
            if (val > 255) return false;
        }
        return true;
    }

    private boolean isIPv6(String s) {
        String[] parts = s.split(":", -1);
        if (parts.length != 8) return false;
        for (String p : parts) {
            if (p.length() == 0 || p.length() > 4) return false;
            for (int i = 0; i < p.length(); i++) {
                if (Character.digit(p.charAt(i), 16) == -1) return false;
            }
        }
        return true;
    }
}
```

## 总结（速记）
- IPv4 看“4 段数字 + 不许前导 0 + 0~255”；IPv6 看“8 段十六进制 + 每段 1~4 位”；`split(..., -1)` 用来抓住空段。
