# 207. 课程表

- 题号：207
- 难度：中等
- LeetCode：[课程表](https://leetcode.cn/problems/course-schedule/)

## 题目描述
给定课程总数 `numCourses` 和先修关系 `prerequisites[i] = [a,b]`（学 a 前必须先学 b），判断是否能学完所有课程。

## 示例
- 示例  
输入：`numCourses = 2, prerequisites = [[1,0]]`  
输出：`true`

## 最佳解法思路
- 拓扑排序（推荐）  
把先修关系看成有向图：`b -> a`。统计每门课入度 `indeg`。  
把所有入度为 0 的点入队，不断出队并“删除”其出边（相邻点入度减 1，减到 0 继续入队）。  
最后看能否处理完所有点（计数是否等于 `numCourses`）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) g.add(new ArrayList<>());
        int[] indeg = new int[numCourses];

        for (int[] p : prerequisites) {
            int a = p[0], b = p[1];
            g.get(b).add(a);
            indeg[a]++;
        }

        Deque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (indeg[i] == 0) q.addLast(i);
        }

        int cnt = 0;
        while (!q.isEmpty()) {
            int u = q.pollFirst();
            cnt++;
            for (int v : g.get(u)) {
                if (--indeg[v] == 0) q.addLast(v);
            }
        }
        return cnt == numCourses;
    }
}
```

## 复杂度分析
- 时间：\(O(V+E)\)
- 空间：\(O(V+E)\)
