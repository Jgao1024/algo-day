# 123. 买卖股票的最佳时机 III

- 题号：123
- 难度：困难
- LeetCode：[买卖股票的最佳时机 III](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/)

## 题目描述
给定股票价格数组 `prices`，最多完成两笔交易（一次买入一次卖出），不能同时参与多笔交易，求最大利润。

## 示例
- 示例  
输入：`prices = [3,3,5,0,0,3,1,4]`  
输出：`6`

## 最佳解法思路
- 状态机 DP（推荐）  
用四个状态表示到当前天为止的最大收益：  
`buy1`：第一次买入后；`sell1`：第一次卖出后；  
`buy2`：第二次买入后；`sell2`：第二次卖出后。  
每天用当前价格更新四个状态即可。

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices) {
        int buy1 = Integer.MIN_VALUE, sell1 = 0;
        int buy2 = Integer.MIN_VALUE, sell2 = 0;
        for (int p : prices) {
            buy1 = Math.max(buy1, -p);
            sell1 = Math.max(sell1, buy1 + p);
            buy2 = Math.max(buy2, sell1 - p);
            sell2 = Math.max(sell2, buy2 + p);
        }
        return sell2;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 四状态：**buy1/sell1/buy2/sell2**，每天按顺序用 `max` 更新即可。
