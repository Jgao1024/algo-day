# 79. 单词搜索

- 题号：79
- 难度：中等
- LeetCode：[单词搜索](https://leetcode.cn/problems/word-search/)

## 题目描述
给定 `m x n` 字符矩阵 `board` 和字符串 `word`，判断 `word` 是否能由相邻格（上下左右）连续拼出，同一格不能重复使用。

## 示例
- 示例  
输入：`board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"`  
输出：`true`

## 最佳解法思路
- DFS 回溯（推荐）  
从每个格子作为起点尝试匹配 `word[idx]`。匹配成功后临时标记该格已用（比如改成 `'#'`），向四个方向继续；返回时恢复字符。

## Java 最佳实现

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] b, String w, int i, int j, int idx) {
        if (idx == w.length()) return true;
        if (i < 0 || i >= b.length || j < 0 || j >= b[0].length) return false;
        if (b[i][j] != w.charAt(idx)) return false;

        char old = b[i][j];
        b[i][j] = '#';
        boolean ok = dfs(b, w, i + 1, j, idx + 1)
                || dfs(b, w, i - 1, j, idx + 1)
                || dfs(b, w, i, j + 1, idx + 1)
                || dfs(b, w, i, j - 1, idx + 1);
        b[i][j] = old;
        return ok;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(mn \cdot 4^{L})\)（\(L\) 为 `word` 长度）
- 空间：\(O(L)\)（递归栈）

- **每格做起点 DFS；走过的格临时标记，回溯恢复**。
