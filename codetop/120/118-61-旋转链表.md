# 61. 旋转链表

- 题号：61
- 难度：中等
- LeetCode：[旋转链表](https://leetcode.cn/problems/rotate-list/)

## 题目描述
给定链表头结点 `head`，将链表向右旋转 `k` 个位置并返回新头结点。

## 示例
- 示例  
输入：`head = [1,2,3,4,5], k = 2`  
输出：`[4,5,1,2,3]`

## 最佳解法思路
- 成环再断开（推荐）  
先遍历得到链表长度 `n` 和尾节点 `tail`，把 `tail.next = head` 成环。  
实际右旋 `k` 等价于左移 `n - (k % n)` 步，从 `head` 走 `n - (k % n) - 1` 步找到新尾，断开环得到新头。

## Java 最佳实现

```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) return head;
        int n = 1;
        ListNode tail = head;
        while (tail.next != null) {
            tail = tail.next;
            n++;
        }

        int step = n - (k % n);
        if (step == n) return head;

        tail.next = head;
        ListNode newTail = head;
        for (int i = 1; i < step; i++) newTail = newTail.next;
        ListNode newHead = newTail.next;
        newTail.next = null;
        return newHead;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **先成环，再走到新尾断开；步数是 `n - (k % n)`**。
