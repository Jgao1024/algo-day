# 138. 复制带随机指针的链表

- 题号：138
- 难度：中等
- LeetCode：[复制带随机指针的链表](https://leetcode.cn/problems/copy-list-with-random-pointer/)

## 题目描述
给定一个链表，每个节点有 `next` 和 `random` 指针（`random` 可指向任意节点或 `null`），返回该链表的深拷贝。

## 示例
- 示例  
输入：`head = [[7,null],[13,0],[11,4],[10,2],[1,0]]`  
输出：`[[7,null],[13,0],[11,4],[10,2],[1,0]]`

## 最佳解法思路
- 哈希表映射（推荐）  
用 `map<旧节点, 新节点>` 记录映射关系。  
遍历原链表：先把每个旧节点对应的新节点创建出来；再第二次遍历把 `next/random` 指针按映射连起来。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;
        Map<Node, Node> map = new HashMap<>();

        Node cur = head;
        while (cur != null) {
            map.put(cur, new Node(cur.val));
            cur = cur.next;
        }

        cur = head;
        while (cur != null) {
            Node copy = map.get(cur);
            copy.next = map.get(cur.next);
            copy.random = map.get(cur.random);
            cur = cur.next;
        }

        return map.get(head);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **先建映射再连指针：`copy.next/random = map.get(old.next/random)`**。
