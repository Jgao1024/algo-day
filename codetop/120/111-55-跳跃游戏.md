# 55. 跳跃游戏

- 题号：55
- 难度：中等
- LeetCode：[跳跃游戏](https://leetcode.cn/problems/jump-game/)

## 题目描述
给定数组 `nums`，你在下标 0，每个位置的值表示最大跳跃长度。判断是否能到达最后一个下标。

## 示例
- 示例  
输入：`nums = [2,3,1,1,4]`  
输出：`true`

## 最佳解法思路
- 贪心（推荐）  
维护目前能到达的最远位置 `maxReach`。遍历到 `i` 时，如果 `i > maxReach` 说明断了走不到；否则用 `maxReach = max(maxReach, i + nums[i])` 更新。  
最后看 `maxReach` 是否覆盖到末尾。

## Java 最佳实现

```java
class Solution {
    public boolean canJump(int[] nums) {
        int maxReach = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > maxReach) return false;
            maxReach = Math.max(maxReach, i + nums[i]);
            if (maxReach >= nums.length - 1) return true;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **一路更新最远可达；出现 `i > maxReach` 就失败**。
