# 11. 盛最多水的容器

- 题号：11
- 难度：中等
- LeetCode：[盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)

## 题目描述
给定数组 `height`，选择两条竖线与 x 轴构成容器，求能装水的最大面积。

## 示例
- 示例  
输入：`height = [1,8,6,2,5,4,8,3,7]`  
输出：`49`

## 最佳解法思路
- 双指针（推荐）  
左右指针 `l/r` 表示容器边界，面积为 `(r-l) * min(height[l], height[r])`。  
要想变大，只能移动较短的一边（宽度变小，必须靠高度变大补偿），因此每次移动较短指针。

## Java 最佳实现

```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1;
        int ans = 0;
        while (l < r) {
            int h = Math.min(height[l], height[r]);
            ans = Math.max(ans, (r - l) * h);
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **宽度每次都会变小，所以永远移动短板**。
