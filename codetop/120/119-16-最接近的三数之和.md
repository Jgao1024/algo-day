# 16. 最接近的三数之和

- 题号：16
- 难度：中等
- LeetCode：[最接近的三数之和](https://leetcode.cn/problems/3sum-closest/)

## 题目描述
给定整数数组 `nums` 和目标值 `target`，找出三个整数之和最接近 `target` 的值，并返回该和（保证唯一答案）。

## 示例
- 示例  
输入：`nums = [-1,2,1,-4], target = 1`  
输出：`2`

## 最佳解法思路
- 排序 + 双指针（推荐）  
先排序，固定一个下标 `i`，剩下用 `l/r` 双指针夹逼。  
计算 `sum = nums[i] + nums[l] + nums[r]`，用 `|sum-target|` 更新最优；  
若 `sum < target` 左指针右移增大和，否则右指针左移减小和。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int best = nums[0] + nums[1] + nums[2];
        for (int i = 0; i < nums.length - 2; i++) {
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (Math.abs(sum - target) < Math.abs(best - target)) best = sum;
                if (sum == target) return sum;
                if (sum < target) l++;
                else r--;
            }
        }
        return best;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)（排序若不计入额外空间）

## 总结（速记）
- **固定一个数 + 双指针夹逼；用差值更新 best**。
