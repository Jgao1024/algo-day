# 297. 二叉树的序列化与反序列化

- 题号：297
- 难度：困难
- LeetCode：[二叉树的序列化与反序列化](https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/)

## 题目描述
设计一个算法，把二叉树序列化成字符串，并能从字符串反序列化回原树结构。

## 示例
- 示例  
输入：`root = [1,2,3,null,null,4,5]`  
输出：序列化后可再反序列化得到等价的树

## 最佳解法思路
- 前序 DFS + 空节点标记（推荐）  
序列化：前序遍历，空节点写成 `#`，节点值用逗号分隔。  
反序列化：按分隔后的数组顺序递归构造，读到 `#` 返回 `null`，否则创建节点并递归构造左右子树。

## Java 最佳实现

```java
class Codec {
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        dfsSer(root, sb);
        return sb.toString();
    }

    private void dfsSer(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("#,");
            return;
        }
        sb.append(node.val).append(',');
        dfsSer(node.left, sb);
        dfsSer(node.right, sb);
    }

    public TreeNode deserialize(String data) {
        String[] arr = data.split(",");
        int[] idx = new int[1];
        return dfsDe(arr, idx);
    }

    private TreeNode dfsDe(String[] arr, int[] idx) {
        String s = arr[idx[0]++];
        if (s.equals("#")) return null;
        TreeNode node = new TreeNode(Integer.parseInt(s));
        node.left = dfsDe(arr, idx);
        node.right = dfsDe(arr, idx);
        return node;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（序列化字符串/递归栈）

## 总结（速记）
- **用前序 + `#` 标记空节点；反序列化按相同顺序递归读回去**。
