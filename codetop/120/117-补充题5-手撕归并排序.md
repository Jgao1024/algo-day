# 补充题5. 手撕归并排序

- 题号：补充题5
- 难度：中等
- LeetCode：[手撕归并排序](https://leetcode.cn/problems/sort-an-array/)

## 题目描述
给定整数数组 `nums`，将数组按升序排序并返回（题面是 “Sort an Array”）。

## 示例
- 示例  
输入：`nums = [5,2,3,1]`  
输出：`[1,2,3,5]`

## 最佳解法思路
- 归并排序（推荐）  
分治：把区间一分为二分别排序，再把两个有序段合并。  
合并时用临时数组存结果，最后拷回原数组。

## Java 最佳实现

```java
class Solution {
    public int[] sortArray(int[] nums) {
        int[] tmp = new int[nums.length];
        mergeSort(nums, 0, nums.length - 1, tmp);
        return nums;
    }

    private void mergeSort(int[] a, int l, int r, int[] tmp) {
        if (l >= r) return;
        int mid = l + ((r - l) >> 1);
        mergeSort(a, l, mid, tmp);
        mergeSort(a, mid + 1, r, tmp);
        merge(a, l, mid, r, tmp);
    }

    private void merge(int[] a, int l, int mid, int r, int[] tmp) {
        int i = l, j = mid + 1, k = 0;
        while (i <= mid && j <= r) {
            if (a[i] <= a[j]) tmp[k++] = a[i++];
            else tmp[k++] = a[j++];
        }
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= r) tmp[k++] = a[j++];
        for (int t = 0; t < k; t++) a[l + t] = tmp[t];
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **分两半分别排，再合并两段有序数组**。
