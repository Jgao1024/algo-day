# 518. 零钱兑换 II

- 题号：518
- 难度：中等
- LeetCode：[零钱兑换 II](https://leetcode.cn/problems/coin-change-ii/)

## 题目描述
给定整数 `amount` 和硬币数组 `coins`，返回凑成 `amount` 的组合数。每种硬币数量无限，组合不考虑顺序。

## 示例
- 示例  
输入：`amount = 5, coins = [1,2,5]`  
输出：`4`

## 最佳解法思路
- 完全背包（组合数，推荐）  
`dp[i]` 表示凑成金额 `i` 的组合数。  
外层遍历硬币 `coin`，内层 `i` 从 `coin` 到 `amount`：`dp[i] += dp[i-coin]`。  
外层先硬币可以保证“组合不计顺序”。

## Java 最佳实现

```java
class Solution {
    public int change(int amount, int[] coins) {
        int[] dp = new int[amount + 1];
        dp[0] = 1;
        for (int coin : coins) {
            for (int i = coin; i <= amount; i++) {
                dp[i] += dp[i - coin];
            }
        }
        return dp[amount];
    }
}
```

## 复杂度分析
- 时间：\(O(amount \cdot |\text{coins}|)\)
- 空间：\(O(amount)\)
