## 最佳解法思路
- **统计 + 回溯生成半边**  
统计每个字符次数，若奇数次数超过 1，无法构成回文。  
把每个字符的一半数量放进数组，回溯生成所有不重复的“左半边”，右半边是其反转，中间可加唯一的奇数字符。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> generatePalindromes(String s) {
        int[] cnt = new int[128];
        for (int i = 0; i < s.length(); i++) cnt[s.charAt(i)]++;

        int odd = 0;
        char mid = 0;
        for (int c = 0; c < 128; c++) {
            if ((cnt[c] & 1) == 1) {
                odd++;
                mid = (char) c;
            }
        }
        if (odd > 1) return new ArrayList<>();

        char[] half = new char[s.length() / 2];
        int idx = 0;
        for (int c = 0; c < 128; c++) {
            for (int k = 0; k < cnt[c] / 2; k++) {
                half[idx++] = (char) c;
            }
        }
        Arrays.sort(half);

        List<String> ans = new ArrayList<>();
        boolean[] used = new boolean[half.length];
        StringBuilder path = new StringBuilder();
        dfs(half, used, path, mid == 0 ? "" : String.valueOf(mid), ans);
        return ans;
    }

    private void dfs(char[] half, boolean[] used, StringBuilder path, String mid, List<String> ans) {
        if (path.length() == half.length) {
            String left = path.toString();
            String right = new StringBuilder(left).reverse().toString();
            ans.add(left + mid + right);
            return;
        }
        for (int i = 0; i < half.length; i++) {
            if (used[i]) continue;
            if (i > 0 && half[i] == half[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            path.append(half[i]);
            dfs(half, used, path, mid, ans);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

- 时间：\(O((n/2)!)\) 级别（取决于重复字符）
- 空间：\(O(n)\)
