## 最佳解法思路
- **算两个指针的角度再取最小**  
分钟指针角度：`minute * 6`。  
时针角度：`(hour % 12) * 30 + minute * 0.5`。  
两者差值取绝对值 `d`，答案为 `min(d, 360-d)`。

## Java 最佳实现

```java
class Solution {
    public double angleClock(int hour, int minutes) {
        double m = minutes * 6.0;
        double h = (hour % 12) * 30.0 + minutes * 0.5;
        double d = Math.abs(h - m);
        return Math.min(d, 360.0 - d);
    }
}
```
