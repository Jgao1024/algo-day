## 最佳解法思路
- **单调栈（可删除数量）**  
要选长度为 `k` 的子序列，相当于从 `n` 个里删掉 `remove = n-k` 个。  
从左到右维护递增栈：遇到更小的数就尽量弹出栈顶（还要保证剩余可删次数 >0），最后取前 `k` 个即为字典序最小的子序列。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] mostCompetitive(int[] nums, int k) {
        int n = nums.length;
        int remove = n - k;
        Deque<Integer> st = new ArrayDeque<>();
        for (int x : nums) {
            while (remove > 0 && !st.isEmpty() && st.peekLast() > x) {
                st.removeLast();
                remove--;
            }
            st.addLast(x);
        }
        while (remove > 0) {
            st.removeLast();
            remove--;
        }
        int[] ans = new int[k];
        for (int i = 0; i < k; i++) {
            ans[i] = st.removeFirst();
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
