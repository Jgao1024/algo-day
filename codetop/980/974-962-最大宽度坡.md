## 最佳解法思路
- **单调栈 + 从右往左扫**  
先从左到右建“严格递减栈”（存下标），保证栈中对应值递减，这些位置是潜在的最左端。  
再从右往左扫描 `j`，当 `A[stackTop] <= A[j]` 时可以形成坡，更新宽度并弹栈（因为更左的才可能更宽）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maxWidthRamp(int[] nums) {
        int n = nums.length;
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (st.isEmpty() || nums[i] < nums[st.peek()]) {
                st.push(i);
            }
        }

        int ans = 0;
        for (int j = n - 1; j >= 0; j--) {
            while (!st.isEmpty() && nums[st.peek()] <= nums[j]) {
                ans = Math.max(ans, j - st.pop());
            }
            if (st.isEmpty()) break;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
