## 最佳解法思路
- **前缀计数**  
`[1..x]` 内奇数个数是 `(x+1)/2`。  
答案为 `odd(high) - odd(low-1)`。

## Java 最佳实现

```java
class Solution {
    public int countOdds(int low, int high) {
        return odd(high) - odd(low - 1);
    }

    private int odd(int x) {
        if (x <= 0) return 0;
        return (x + 1) / 2;
    }
}
```
