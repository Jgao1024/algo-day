## 最佳解法思路
- **拓扑序 + 传递闭包（可达性）**  
用 `reach[u][v]` 表示 `u` 是否是 `v` 的先修课。  
按拓扑序遍历边 `u -> v`：  
  - `reach[u][v] = true`  
  - 且 `reach[x][v] |= reach[x][u]`（所有能到 u 的课也能到 v）  
最后对每个查询直接查 `reach[a][b]`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public List<Boolean> checkIfPrerequisite(int numCourses, int[][] prerequisites, int[][] queries) {
        List<Integer>[] g = new List[numCourses];
        for (int i = 0; i < numCourses; i++) g[i] = new ArrayList<>();
        int[] indeg = new int[numCourses];

        for (int[] e : prerequisites) {
            g[e[0]].add(e[1]);
            indeg[e[1]]++;
        }

        boolean[][] reach = new boolean[numCourses][numCourses];
        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.add(i);

        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : g[u]) {
                reach[u][v] = true;
                for (int x = 0; x < numCourses; x++) {
                    if (reach[x][u]) reach[x][v] = true;
                }
                indeg[v]--;
                if (indeg[v] == 0) q.add(v);
            }
        }

        List<Boolean> ans = new ArrayList<>(queries.length);
        for (int[] qu : queries) {
            ans.add(reach[qu[0]][qu[1]]);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)（\(n\le 100\) 可接受）
- 空间：\(O(n^2)\)
