## 最佳解法思路
- **暴力对比相邻块**  
从 `i` 开始检查长度为 `m` 的块是否连续重复 `k` 次：  
比较 `arr[j]` 和 `arr[j+m]`，若连续相等次数达到 `(k-1)*m`，说明存在重复模式。

## Java 最佳实现

```java
class Solution {
    public boolean containsPattern(int[] arr, int m, int k) {
        int n = arr.length;
        int need = (k - 1) * m;
        for (int i = 0; i + k * m <= n; i++) {
            int same = 0;
            for (int j = i; j + m < n; j++) {
                if (arr[j] == arr[j + m]) {
                    same++;
                    if (same >= need) return true;
                } else {
                    same = 0;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(n^2)\)，但数据范围下可过
- 空间：\(O(1)\)
