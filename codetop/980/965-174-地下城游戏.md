## 最佳解法思路
- **DP 从终点反推最小血量**  
设 `dp[i][j]` 表示进入格子 `(i,j)` 时至少需要的血量，保证从这里走到终点全程血量始终 >0。  
从右下角开始反推：  
`need = min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j]`，再 `dp[i][j] = max(1, need)`。

## Java 最佳实现

```java
class Solution {
    public int calculateMinimumHP(int[][] dungeon) {
        int m = dungeon.length;
        int n = dungeon[0].length;
        int INF = 1_000_000_000;
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) {
            for (int j = 0; j <= n; j++) {
                dp[i][j] = INF;
            }
        }
        dp[m][n - 1] = 1;
        dp[m - 1][n] = 1;

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int next = Math.min(dp[i + 1][j], dp[i][j + 1]);
                int need = next - dungeon[i][j];
                dp[i][j] = need <= 1 ? 1 : need;
            }
        }
        return dp[0][0];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
