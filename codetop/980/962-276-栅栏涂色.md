## 最佳解法思路
- **DP：相同/不同两种状态**  
设 `same` 表示最后两根颜色相同的方案数，`diff` 表示最后两根颜色不同的方案数。  
转移：
  - 新的 `same = diff`（想让最后两根相同，上一根必须不同）
  - 新的 `diff = (same + diff) * (k-1)`（最后一根换成不同颜色）  
答案为 `same + diff`。

## Java 最佳实现

```java
class Solution {
    public int numWays(int n, int k) {
        if (n == 0) return 0;
        if (n == 1) return k;

        long same = 0;
        long diff = k;
        for (int i = 2; i <= n; i++) {
            long nsame = diff;
            long ndiff = (same + diff) * (k - 1);
            same = nsame;
            diff = ndiff;
        }
        return (int) (same + diff);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
