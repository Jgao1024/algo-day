## 最佳解法思路
- **DFS 累积二进制值**  
从根到当前节点的值 `cur`，每往下一层：`cur = (cur<<1) + node.val`。  
到叶子节点时把 `cur` 加到答案中。

## Java 最佳实现

```java
class Solution {
    public int sumRootToLeaf(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int cur) {
        if (node == null) return 0;
        int val = (cur << 1) + node.val;
        if (node.left == null && node.right == null) return val;
        return dfs(node.left, val) + dfs(node.right, val);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
