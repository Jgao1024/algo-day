## 最佳解法思路
- **计数/哈希 + 先放 arr2 再放剩余**  
统计 `arr1` 各值出现次数。先按 `arr2` 的顺序把对应数字输出 `count` 次；  
剩下未在 `arr2` 里的数字按升序输出。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Arrays;

class Solution {
    public int[] relativeSortArray(int[] arr1, int[] arr2) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : arr1) cnt.put(x, cnt.getOrDefault(x, 0) + 1);

        int[] ans = new int[arr1.length];
        int idx = 0;

        for (int x : arr2) {
            int c = cnt.getOrDefault(x, 0);
            for (int i = 0; i < c; i++) ans[idx++] = x;
            cnt.remove(x);
        }

        int[] rest = new int[cnt.size()];
        int p = 0;
        for (int key : cnt.keySet()) rest[p++] = key;
        Arrays.sort(rest);
        for (int x : rest) {
            int c = cnt.get(x);
            for (int i = 0; i < c; i++) ans[idx++] = x;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)（主要在剩余元素排序）
- 空间：\(O(n)\)
