## 最佳解法思路
- **DP 按轮次传递**  
`dp[i]` 表示当前轮到达节点 `i` 的方案数。每一轮根据边 `u->v` 更新 `ndp[v] += dp[u]`，做 `k` 轮后返回 `dp[n-1]`。

## Java 最佳实现

```java
class Solution {
    public int numWays(int n, int[][] relation, int k) {
        int[] dp = new int[n];
        dp[0] = 1;
        for (int step = 0; step < k; step++) {
            int[] ndp = new int[n];
            for (int[] e : relation) {
                ndp[e[1]] += dp[e[0]];
            }
            dp = ndp;
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(k \cdot m)\)，\(m\) 为边数
- 空间：\(O(n)\)
