## 最佳解法思路
- **DFS 维护路径，遇到叶子更新最小**  
从根 DFS 到叶子，用 `StringBuilder` 维护从根到当前的字符序列。  
到叶子时把路径反转得到“从叶到根”的字符串，与当前最小值比较更新即可。

## Java 最佳实现

```java
class Solution {
    private String best = null;

    public String smallestFromLeaf(TreeNode root) {
        dfs(root, new StringBuilder());
        return best == null ? "" : best;
    }

    private void dfs(TreeNode node, StringBuilder path) {
        if (node == null) return;
        path.append((char) ('a' + node.val));
        if (node.left == null && node.right == null) {
            String cur = path.reverse().toString();
            path.reverse();
            if (best == null || cur.compareTo(best) < 0) best = cur;
        } else {
            dfs(node.left, path);
            dfs(node.right, path);
        }
        path.deleteCharAt(path.length() - 1);
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(n^2)\)（每个叶子构造/比较字符串）
- 空间：\(O(h)\)
