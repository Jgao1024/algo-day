## 最佳解法思路
- **把“去一趟再回来”转成“两个人同时从起点走到终点”**  
两次路径本质上可以看成两个人同时从 `(0,0)` 出发，只能向右/向下走，走到 `(n-1,n-1)`，每一步两人走的总步数相同 `k`。  
当步数为 `k` 时：
  - 人1位置 `(x1, y1)` 且 `y1 = k - x1`
  - 人2位置 `(x2, y2)` 且 `y2 = k - x2`  
用 `dp[x1][x2]` 记录当前 `k` 下的最大樱桃数，转移来自上一步 `k-1` 的 4 种组合（两人各自来自上/左）。  
每步累加当前位置的樱桃：若两人落在同一格，只加一次。遇到荆棘 `-1` 的格子不可达。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int cherryPickup(int[][] grid) {
        int n = grid.length;
        int NEG = -1_000_000_000;
        int[][] dp = new int[n][n];
        for (int i = 0; i < n; i++) Arrays.fill(dp[i], NEG);
        if (grid[0][0] == -1) return 0;
        dp[0][0] = grid[0][0];

        for (int k = 1; k <= 2 * n - 2; k++) {
            int[][] ndp = new int[n][n];
            for (int i = 0; i < n; i++) Arrays.fill(ndp[i], NEG);

            for (int x1 = Math.max(0, k - (n - 1)); x1 <= Math.min(n - 1, k); x1++) {
                int y1 = k - x1;
                if (grid[x1][y1] == -1) continue;
                for (int x2 = Math.max(0, k - (n - 1)); x2 <= Math.min(n - 1, k); x2++) {
                    int y2 = k - x2;
                    if (grid[x2][y2] == -1) continue;

                    int best = dp[x1][x2];
                    if (x1 > 0) best = Math.max(best, dp[x1 - 1][x2]);
                    if (x2 > 0) best = Math.max(best, dp[x1][x2 - 1]);
                    if (x1 > 0 && x2 > 0) best = Math.max(best, dp[x1 - 1][x2 - 1]);
                    if (best <= NEG / 2) continue;

                    int add = grid[x1][y1];
                    if (x1 != x2 || y1 != y2) add += grid[x2][y2];
                    ndp[x1][x2] = Math.max(ndp[x1][x2], best + add);
                }
            }
            dp = ndp;
        }
        return Math.max(0, dp[n - 1][n - 1]);
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)
- 空间：\(O(n^2)\)
