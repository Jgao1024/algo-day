## 最佳解法思路
- **贪心：优先接到已有序列后面**  
维护两个哈希表：
  - `freq[x]`：数字 `x` 还剩多少个可用
  - `need[x]`：有多少个序列正等着用 `x` 作为下一个数  
遍历 `nums`：
  - 若 `need[x] > 0`：把 `x` 接到某个序列末尾（`need[x]--`，`need[x+1]++`）
  - 否则尝试新开长度至少 3 的序列：需要 `x,x+1,x+2` 都有剩余
  - 两者都不行则失败

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isPossible(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        Map<Integer, Integer> need = new HashMap<>();
        for (int x : nums) freq.put(x, freq.getOrDefault(x, 0) + 1);

        for (int x : nums) {
            int f = freq.getOrDefault(x, 0);
            if (f == 0) continue;

            int n = need.getOrDefault(x, 0);
            if (n > 0) {
                need.put(x, n - 1);
                need.put(x + 1, need.getOrDefault(x + 1, 0) + 1);
                freq.put(x, f - 1);
            } else {
                int f1 = freq.getOrDefault(x + 1, 0);
                int f2 = freq.getOrDefault(x + 2, 0);
                if (f1 > 0 && f2 > 0) {
                    freq.put(x, f - 1);
                    freq.put(x + 1, f1 - 1);
                    freq.put(x + 2, f2 - 1);
                    need.put(x + 3, need.getOrDefault(x + 3, 0) + 1);
                } else {
                    return false;
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
