## 最佳解法思路
- **模拟匹配 + 循环节加速**  
把 `S1 = s1` 重复 `n1` 次，`S2 = s2` 重复 `n2` 次。  
逐段扫描每一段 `s1`，用指针 `j` 表示当前匹配到 `s2[j]`，每当匹配完一整次 `s2` 就让 `cnt2++` 且 `j=0`。  
关键：`j` 的取值只有 `0..len2-1`，当某次扫描完一段 `s1` 后出现了“相同的 j”，说明进入循环节：  
用循环节直接计算能贡献多少个 `s2`，再把剩余的段数继续模拟即可。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        if (n1 == 0) return 0;
        int len2 = s2.length();
        int[] firstBlock = new int[len2];
        int[] firstCount = new int[len2];
        Arrays.fill(firstBlock, -1);

        int j = 0;
        int cnt2 = 0;

        for (int block = 1; block <= n1; block++) {
            for (int i = 0; i < s1.length(); i++) {
                if (s1.charAt(i) == s2.charAt(j)) {
                    j++;
                    if (j == len2) {
                        j = 0;
                        cnt2++;
                    }
                }
            }

            if (firstBlock[j] != -1) {
                int preBlock = firstBlock[j];
                int preCnt2 = firstCount[j];

                int loopBlock = block - preBlock;
                int loopCnt2 = cnt2 - preCnt2;

                int remain = n1 - preBlock;
                int loops = remain / loopBlock;

                int total = preCnt2 + loops * loopCnt2;

                int restBlocks = remain % loopBlock;
                int jj = j;
                int extra = 0;
                for (int t = 0; t < restBlocks; t++) {
                    for (int i = 0; i < s1.length(); i++) {
                        if (s1.charAt(i) == s2.charAt(jj)) {
                            jj++;
                            if (jj == len2) {
                                jj = 0;
                                extra++;
                            }
                        }
                    }
                }
                total += extra;
                return total / n2;
            } else {
                firstBlock[j] = block;
                firstCount[j] = cnt2;
            }
        }
        return cnt2 / n2;
    }
}
```

## 复杂度分析
- 时间：约 \(O(|s1| \cdot (len2 + \text{循环前段数}))\)
- 空间：\(O(len2)\)
