## 最佳解法思路
- 反向思考：从两端删掉的和为 `x`，等价于保留中间一个子数组，和为 `sum(nums) - x`，并且这个子数组尽量长。
- 因为 `nums[i] > 0`，用滑动窗口找“和为 target 的最长子数组”，答案是 `n - maxLen`，找不到返回 `-1`。

## Java 最佳实现

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int n = nums.length;
        long sum = 0;
        for (int v : nums) sum += v;
        long target = sum - x;
        if (target < 0) return -1;
        if (target == 0) return n;

        int left = 0;
        long cur = 0;
        int maxLen = -1;
        for (int right = 0; right < n; right++) {
            cur += nums[right];
            while (left <= right && cur > target) {
                cur -= nums[left++];
            }
            if (cur == target) {
                maxLen = Math.max(maxLen, right - left + 1);
            }
        }
        return maxLen == -1 ? -1 : n - maxLen;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
