## 最佳解法思路
- 排序 + 前缀判断：把所有路径按字典序排序。
- 维护最后保留的根文件夹 `prev`。若当前 `cur` 以 `prev + "/"` 开头，则它是子文件夹，跳过；否则保留并更新 `prev`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> removeSubfolders(String[] folder) {
        Arrays.sort(folder);
        List<String> res = new ArrayList<>();

        String prev = null;
        for (String cur : folder) {
            if (prev != null && cur.startsWith(prev) && cur.length() > prev.length()
                    && cur.charAt(prev.length()) == '/') {
                continue;
            }
            res.add(cur);
            prev = cur;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（不计输出）
