## 最佳解法思路
- 滑动窗口 + 单调队列：维护窗口内的最大值队列 `maxQ`（单调递减）和最小值队列 `minQ`（单调递增）。
- 扩张右端加入新数；当 `max - min > limit` 时移动左端，并在队首等于被移出元素时弹出。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestSubarray(int[] nums, int limit) {
        Deque<Integer> maxQ = new ArrayDeque<>();
        Deque<Integer> minQ = new ArrayDeque<>();

        int left = 0;
        int ans = 0;
        for (int right = 0; right < nums.length; right++) {
            int x = nums[right];
            while (!maxQ.isEmpty() && maxQ.peekLast() < x) maxQ.pollLast();
            while (!minQ.isEmpty() && minQ.peekLast() > x) minQ.pollLast();
            maxQ.addLast(x);
            minQ.addLast(x);

            while (!maxQ.isEmpty() && !minQ.isEmpty() && (long) maxQ.peekFirst() - (long) minQ.peekFirst() > limit) {
                int out = nums[left++];
                if (out == maxQ.peekFirst()) maxQ.pollFirst();
                if (out == minQ.peekFirst()) minQ.pollFirst();
            }

            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（最坏队列长度）
