## 最佳解法思路
- DP：`dp[i][d]` 表示以 `i` 结尾、公差为 `d` 的最长等差子序列长度。
- 枚举 `j < i`，设 `d = nums[i] - nums[j]`，则 `dp[i][d] = max(dp[i][d], dp[j][d] + 1)`。
- 本题 `nums[i]` 在 `0..500`，所以 `d` 在 `[-500,500]`，可以用二维数组代替 HashMap。

## Java 最佳实现

```java
class Solution {
    public int longestArithSeqLength(int[] nums) {
        int n = nums.length;
        if (n <= 1) return n;

        int[][] dp = new int[n][1001];
        int ans = 2;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int d = nums[i] - nums[j] + 500;
                int prev = dp[j][d];
                dp[i][d] = Math.max(dp[i][d], prev == 0 ? 2 : prev + 1);
                ans = Math.max(ans, dp[i][d]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n \cdot 1001)\)
