## 最佳解法思路
- 直接构造：最大值为 \(10^n - 1\)，答案就是 `1..max`。
- 注意：当 `n` 很大时结果数组会非常大，实际测试一般不会给到需要爆内存的规模。

## Java 最佳实现

```java
class Solution {
    public int[] printNumbers(int n) {
        if (n <= 0) return new int[0];
        int max = 1;
        for (int i = 0; i < n; i++) {
            max *= 10;
        }
        max -= 1;

        int[] res = new int[max];
        for (int i = 1; i <= max; i++) {
            res[i - 1] = i;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(10^n)\)
- 空间：\(O(10^n)\)
