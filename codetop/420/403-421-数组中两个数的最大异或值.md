## 最佳解法思路
- 按位贪心：从高位到低位逐位尝试把答案的该位设为 1。
- 固定当前位 `b`，把所有数的前缀 `num >> b` 放入集合；若存在 `p ^ q = candidate`，则这位可以为 1。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findMaximumXOR(int[] nums) {
        int ans = 0;
        for (int b = 30; b >= 0; b--) {
            Set<Integer> set = new HashSet<>();
            for (int x : nums) {
                set.add(x >> b);
            }

            int candidate = ans | (1 << b);
            boolean ok = false;
            for (int p : set) {
                if (set.contains(p ^ candidate)) {
                    ok = true;
                    break;
                }
            }
            if (ok) {
                ans = candidate;
            }
        }
        return ans;
    }
}
```
