## 最佳解法思路
- 二分答案：运载能力 `cap` 越大，需要的天数越少（单调）。
- `cap` 下界是 `max(weights)`，上界是 `sum(weights)`；用 `check(cap)` 计算需要多少天，二分最小可行 `cap`。

## Java 最佳实现

```java
class Solution {
    public int shipWithinDays(int[] weights, int days) {
        int lo = 0;
        int hi = 0;
        for (int w : weights) {
            lo = Math.max(lo, w);
            hi += w;
        }

        int ans = hi;
        while (lo <= hi) {
            int mid = lo + ((hi - lo) >>> 1);
            if (needDays(weights, mid) <= days) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }

    private int needDays(int[] weights, int cap) {
        int days = 1;
        int cur = 0;
        for (int w : weights) {
            if (cur + w > cap) {
                days++;
                cur = 0;
            }
            cur += w;
        }
        return days;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log(\sum weights))\)
- 空间：\(O(1)\)
