## 最佳解法思路
- 二分答案：长度越大，能切出的段数越少，满足单调性。
- 二分 `len`，统计 `sum(wood[i] / len)` 是否 \(\ge k\)。

## Java 最佳实现

```java
class Solution {
    public int woodCut(int[] wood, int k) {
        int max = 0;
        for (int w : wood) {
            max = Math.max(max, w);
        }
        if (max == 0) return 0;

        int l = 1, r = max, ans = 0;
        while (l <= r) {
            int mid = l + ((r - l) >>> 1);
            if (canCut(wood, k, mid)) {
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }

    private boolean canCut(int[] wood, int k, int len) {
        long pieces = 0;
        for (int w : wood) {
            pieces += w / len;
            if (pieces >= k) return true;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log M)\)，\(M\) 为最大木头长度
- 空间：\(O(1)\)
