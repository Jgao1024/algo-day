## 最佳解法思路
- 差分数组：对区间 `[l, r]` 加 `x`，在差分数组里做 `diff[l]+=x`、`diff[r+1]-=x`，最后前缀和还原每个航班的订座数。

## Java 最佳实现

```java
class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        long[] diff = new long[n + 2];
        for (int[] b : bookings) {
            int l = b[0];
            int r = b[1];
            int seats = b[2];
            diff[l] += seats;
            diff[r + 1] -= seats;
        }

        int[] res = new int[n];
        long cur = 0;
        for (int i = 1; i <= n; i++) {
            cur += diff[i];
            res[i - 1] = (int) cur;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n+m)\)
- 空间：\(O(n)\)
