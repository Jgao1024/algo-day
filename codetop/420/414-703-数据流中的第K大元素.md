## 最佳解法思路
- 维护一个大小为 `k` 的小根堆：堆里永远放当前最大的 `k` 个数，堆顶就是第 `k` 大。
- 每次 `add(val)`：入堆，若堆大小超过 `k` 就弹出堆顶。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class KthLargest {
    private final int k;
    private final PriorityQueue<Integer> pq = new PriorityQueue<>();

    public KthLargest(int k, int[] nums) {
        this.k = k;
        for (int x : nums) add(x);
    }

    public int add(int val) {
        pq.add(val);
        if (pq.size() > k) pq.poll();
        return pq.peek();
    }
}
```

## 复杂度分析
- 时间：初始化 \(O(n\log k)\)，单次 add \(O(\log k)\)
- 空间：\(O(k)\)
