## 最佳解法思路
- 这是“中序遍历的下一个节点”，节点通常有 `parent` 指针。
- 规则：  
  - 若 `p` 有右子树：下一个是“右子树最左节点”。  
  - 否则向上找第一个满足“当前节点在它的左子树里”的祖先，该祖先就是下一个；若找不到则为 `null`。

## Java 最佳实现

```java
class Solution {
    static class Node {
        int val;
        Node left;
        Node right;
        Node parent;
        Node(int val) { this.val = val; }
    }

    public Node next(Node p) {
        if (p == null) return null;
        if (p.right != null) {
            Node cur = p.right;
            while (cur.left != null) cur = cur.left;
            return cur;
        }

        Node cur = p;
        Node par = p.parent;
        while (par != null && par.right == cur) {
            cur = par;
            par = par.parent;
        }
        return par;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)
- 空间：\(O(1)\)
