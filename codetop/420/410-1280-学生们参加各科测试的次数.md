## 最佳解法思路
- 题面本质是 SQL：对所有学生与所有科目做笛卡尔积（全组合），再左连接考试表做计数。
- 用 Java 做：  
  - 用 `Map<studentId, name>` 保存学生  
  - 用 `List<String>` 保存科目并排序  
  - 用 `Map<String, Integer>` 统计 `(studentId, subjectName)` 的出现次数  
  - 枚举所有组合输出

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class Student {
        int id;
        String name;
        Student(int id, String name) { this.id = id; this.name = name; }
    }

    static class Examination {
        int studentId;
        String subjectName;
        Examination(int studentId, String subjectName) {
            this.studentId = studentId;
            this.subjectName = subjectName;
        }
    }

    static class Row {
        int studentId;
        String studentName;
        String subjectName;
        int attendedExams;
        Row(int studentId, String studentName, String subjectName, int attendedExams) {
            this.studentId = studentId;
            this.studentName = studentName;
            this.subjectName = subjectName;
            this.attendedExams = attendedExams;
        }
    }

    public List<Row> studentsAndExaminations(List<Student> students, List<String> subjects, List<Examination> exams) {
        Collections.sort(subjects);

        Collections.sort(students, (a, b) -> Integer.compare(a.id, b.id));

        Map<String, Integer> cnt = new HashMap<>();
        for (Examination e : exams) {
            String key = e.studentId + "#" + e.subjectName;
            cnt.put(key, cnt.getOrDefault(key, 0) + 1);
        }

        List<Row> res = new ArrayList<>();
        for (Student s : students) {
            for (String subject : subjects) {
                String key = s.id + "#" + subject;
                res.add(new Row(s.id, s.name, subject, cnt.getOrDefault(key, 0)));
            }
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(|students|\cdot|subjects| + |exams|)\)
- 空间：\(O(|exams|)\)
