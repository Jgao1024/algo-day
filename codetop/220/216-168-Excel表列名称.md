## 最佳解法思路
- 思路：26 进制（无 0）转换  
把 `n` 变成类似 A..Z 的进制表示：每次先 `n--`，再取 `n % 26` 映射到 `'A'..'Z'`，最后反转。

## Java 最佳实现

```java
class Solution {
    public String convertToTitle(int columnNumber) {
        StringBuilder sb = new StringBuilder();
        int n = columnNumber;
        while (n > 0) {
            n--;
            sb.append((char) ('A' + (n % 26)));
            n /= 26;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(\log_{26} n)\)
- 空间：\(O(\log_{26} n)\)
