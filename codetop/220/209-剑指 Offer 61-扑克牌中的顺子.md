## 最佳解法思路
- 思路：排序 + 统计 0  
把 0 当作癞子（可变成任意数）。排序后：  
- 统计 0 的个数 `joker`  
- 检查非 0 是否有重复（有重复必不可能）  
- 用最大值减最小值判断跨度：`max - min < 5` 即可组成顺子

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public boolean isStraight(int[] nums) {
        Arrays.sort(nums);

        int joker = 0;
        while (joker < nums.length && nums[joker] == 0) {
            joker++;
        }

        for (int i = joker + 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1]) {
                return false;
            }
        }

        int min = nums[joker];
        int max = nums[nums.length - 1];
        return max - min < 5;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（排序视实现）
