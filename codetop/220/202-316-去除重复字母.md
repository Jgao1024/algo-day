## 最佳解法思路
- 思路（推荐）：单调栈 + 计数  
先统计每个字符剩余出现次数 `cnt`。从左到右遍历字符 `c`：  
如果 `c` 已在栈中则跳过；否则在入栈前，若栈顶字符比 `c` 大且栈顶字符后面还会出现（`cnt[top] > 0`），就把栈顶弹出，这样能让字典序更小。最后栈内容就是答案。

## Java 最佳实现

```java
class Solution {
    public String removeDuplicateLetters(String s) {
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
        }

        boolean[] inStack = new boolean[26];
        char[] stack = new char[s.length()];
        int top = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int idx = c - 'a';
            cnt[idx]--;

            if (inStack[idx]) {
                continue;
            }

            while (top > 0) {
                char last = stack[top - 1];
                if (last <= c) {
                    break;
                }
                if (cnt[last - 'a'] == 0) {
                    break;
                }
                inStack[last - 'a'] = false;
                top--;
            }

            stack[top++] = c;
            inStack[idx] = true;
        }

        return new String(stack, 0, top);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
