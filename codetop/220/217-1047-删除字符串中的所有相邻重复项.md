## 最佳解法思路
- 思路：栈  
用数组当栈：遍历字符 `c`，若栈顶等于 `c` 就弹出，否则入栈。遍历结束栈中即为结果。

## Java 最佳实现

```java
class Solution {
    public String removeDuplicates(String s) {
        char[] stack = new char[s.length()];
        int top = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (top > 0 && stack[top - 1] == c) {
                top--;
            } else {
                stack[top++] = c;
            }
        }
        return new String(stack, 0, top);
    }
}
```

- 空间：\(O(n)\)
