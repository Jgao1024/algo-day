## 最佳解法思路
- 思路（推荐）：双指针切换  
指针 `a` 从 A 走到尾后切到 B，指针 `b` 从 B 走到尾后切到 A。  
两指针总路程相同，最终会在第一个公共节点相遇；若无交点则同时为 `null`。

## Java 最佳实现

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode a = headA;
        ListNode b = headB;
        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(m + n)\)
- 空间：\(O(1)\)
