## 最佳解法思路
- 思路：迭代 DP  
`f(0)=0, f(1)=1`，从 2 开始迭代累加即可。

## Java 最佳实现

```java
class Solution {
    public int fib(int n) {
        if (n < 2) {
            return n;
        }
        int a = 0;
        int b = 1;
        for (int i = 2; i <= n; i++) {
            int c = a + b;
            a = b;
            b = c;
        }
        return b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
