## 最佳解法思路
- 思路（推荐）：转成 0/1 背包计数  
把 `+` 的集合和记为 `P`，把 `-` 的集合和记为 `N`：  
`P - N = target`，且 `P + N = sum`，可得 `P = (sum + target) / 2`。  
若 `|target| > sum` 或 `sum + target` 为奇数则无解。  
问题转为：从数组里选一些数，使和为 `P` 的方案数（0/1 背包计数）。

## Java 最佳实现

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }
        if (Math.abs(target) > sum) {
            return 0;
        }
        if (((sum + target) & 1) == 1) {
            return 0;
        }

        int p = (sum + target) / 2;
        int[] dp = new int[p + 1];
        dp[0] = 1;

        for (int num : nums) {
            for (int j = p; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        return dp[p];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot P)\)
- 空间：\(O(P)\)
