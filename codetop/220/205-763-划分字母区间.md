## 最佳解法思路
- 思路（推荐）：贪心 + 记录每个字符最后出现位置  
先扫一遍得到 `last[26]`。再从左到右遍历，维护当前分段的最远右边界 `end = max(end, last[s[i]])`。  
当 `i == end`，说明这一段内所有字符都不会在后面再出现，可以切一刀并记录长度。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> ans = new ArrayList<>();
        int start = 0;
        int end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                ans.add(end - start + 1);
                start = i + 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
