## 最佳解法思路
- 思路（推荐）：二分答案长度 + Rolling Hash（哈希冲突用字符对比兜底）  
二分重复子串长度 `len`：  
- 对固定 `len`，用滚动哈希计算所有长度为 `len` 的子串哈希，若出现相同哈希则再做一次字符逐位对比确认，确认后说明存在重复子串。  
- 若存在则尝试更长，否则更短。  
最终得到最大 `len` 及其起点。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private char[] s;
    private long[] h;
    private long[] pow;
    private long base = 911382323L;

    public String longestDupSubstring(String str) {
        this.s = str.toCharArray();
        int n = s.length;
        if (n <= 1) {
            return "";
        }

        pow = new long[n + 1];
        h = new long[n + 1];
        pow[0] = 1;
        for (int i = 0; i < n; i++) {
            pow[i + 1] = pow[i] * base;
            h[i + 1] = h[i] * base + (s[i] - 'a' + 1);
        }

        int lo = 1;
        int hi = n - 1;
        int bestLen = 0;
        int bestStart = -1;

        while (lo <= hi) {
            int mid = (lo + hi) >>> 1;
            int idx = check(mid);
            if (idx != -1) {
                bestLen = mid;
                bestStart = idx;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }

        return bestStart == -1 ? "" : str.substring(bestStart, bestStart + bestLen);
    }

    private int check(int len) {
        int n = s.length;
        Map<Long, ArrayList<Integer>> map = new HashMap<>();
        for (int i = 0; i + len <= n; i++) {
            long key = getHash(i, i + len);
            ArrayList<Integer> list = map.get(key);
            if (list != null) {
                for (int j : list) {
                    if (equalsSub(i, j, len)) {
                        return i;
                    }
                }
                list.add(i);
            } else {
                ArrayList<Integer> nl = new ArrayList<>(1);
                nl.add(i);
                map.put(key, nl);
            }
        }
        return -1;
    }

    private long getHash(int l, int r) {
        return h[r] - h[l] * pow[r - l];
    }

    private boolean equalsSub(int i, int j, int len) {
        for (int k = 0; k < len; k++) {
            if (s[i + k] != s[j + k]) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：约 \(O(n \log n)\)（均摊，哈希命中后做少量对比）
- 空间：\(O(n)\)
