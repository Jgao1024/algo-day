## 最佳解法思路
- 思路（推荐）：中心扩展  
回文中心有 `2n-1` 个（单字符中心 + 双字符中心）。  
对每个中心向两侧扩展，能扩展一次就多一个回文子串，累加即可。

## Java 最佳实现

```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int ans = 0;
        for (int center = 0; center < 2 * n - 1; center++) {
            int l = center / 2;
            int r = l + (center % 2);
            while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
                ans++;
                l--;
                r++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)
