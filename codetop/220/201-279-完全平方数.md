## 最佳解法思路
- 思路（推荐）：动态规划  
设 `dp[i]` 表示凑出和为 `i` 的最少完全平方数个数，则  
`dp[i] = min(dp[i - j*j] + 1)`，其中 `j*j <= i`。  
初始化 `dp[0]=0`，其余为较大值，顺序计算到 `dp[n]`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n\sqrt{n})\)
- 空间：\(O(n)\)
