## 最佳解法思路
- 思路（推荐）：贪心（尽量拆成 3）  
当 `n <= 3` 时必须拆，答案是 `n - 1`。  
当 `n > 4` 时不断拆出 `3`，最后剩下 `2/3/4`，把剩余乘到结果里（避免出现 `1`）。

## Java 最佳实现

```java
class Solution {
    public int integerBreak(int n) {
        if (n <= 3) {
            return n - 1;
        }

        int res = 1;
        while (n > 4) {
            res *= 3;
            n -= 3;
        }
        return res * n;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（循环次数约为 \(n/3\)）
- 空间：\(O(1)\)
