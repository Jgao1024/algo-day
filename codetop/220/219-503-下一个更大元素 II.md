## 最佳解法思路
- 思路（推荐）：单调栈 + 循环数组  
维护一个“下标栈”，栈内对应值单调递减。遍历 `0..2n-1`（用 `i % n` 取值）模拟循环：  
当当前值大于栈顶下标对应值时，就为栈顶元素找到了下一个更大值并出栈。  
只在 `i < n` 时把下标入栈，避免重复入栈。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        Arrays.fill(ans, -1);

        int[] stack = new int[n];
        int top = 0;

        for (int i = 0; i < 2 * n; i++) {
            int idx = i % n;
            while (top > 0 && nums[stack[top - 1]] < nums[idx]) {
                ans[stack[--top]] = nums[idx];
            }
            if (i < n) {
                stack[top++] = idx;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
