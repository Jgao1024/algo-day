## 最佳解法思路
- 思路（推荐）：二维后缀和 + DP  
先预处理 `sum[i][j]` 表示从 `(i,j)` 到右下角子矩形内苹果数量。  
设 `dp[t][i][j]` 表示从 `(i,j)` 这块披萨切 `t` 份（切 `t-1` 刀），且每份至少 1 个苹果的方案数。  
转移：在 `(i,j)` 位置尝试水平切到 `x`（`i < x < m`），若上半部分有苹果（`sum[i][j] - sum[x][j] > 0`），则累加 `dp[t-1][x][j]`；  
同理尝试竖直切到 `y`，若左半部分有苹果（`sum[i][j] - sum[i][y] > 0`），累加 `dp[t-1][i][y]`。  
初始：`dp[1][i][j] = (sum[i][j] > 0 ? 1 : 0)`。答案是 `dp[k][0][0]`。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int ways(String[] pizza, int k) {
        int m = pizza.length;
        int n = pizza[0].length();

        int[][] sum = new int[m + 1][n + 1];
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                sum[i][j] = sum[i + 1][j] + sum[i][j + 1] - sum[i + 1][j + 1]
                        + (pizza[i].charAt(j) == 'A' ? 1 : 0);
            }
        }

        int[][][] dp = new int[k + 1][m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dp[1][i][j] = sum[i][j] > 0 ? 1 : 0;
            }
        }

        for (int t = 2; t <= k; t++) {
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (sum[i][j] == 0) {
                        continue;
                    }
                    long ways = 0;

                    for (int x = i + 1; x < m; x++) {
                        if (sum[i][j] - sum[x][j] > 0) {
                            ways += dp[t - 1][x][j];
                        }
                    }
                    for (int y = j + 1; y < n; y++) {
                        if (sum[i][j] - sum[i][y] > 0) {
                            ways += dp[t - 1][i][y];
                        }
                    }

                    dp[t][i][j] = (int) (ways % MOD);
                }
            }
        }

        return dp[k][0][0];
    }
}
```

## 复杂度分析
- 时间：\(O(kmn(m+n))\)
- 空间：\(O(kmn)\)
