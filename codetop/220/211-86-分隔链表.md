## 最佳解法思路
- 思路：双链表拼接  
维护两个链表：`small` 存 `< x`，`large` 存 `>= x`，遍历原链表按值接到对应链表尾部。  
最后 `small` 尾接 `large` 头，并把 `large` 尾置 `null`。

## Java 最佳实现

```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode smallDummy = new ListNode(0);
        ListNode largeDummy = new ListNode(0);
        ListNode small = smallDummy;
        ListNode large = largeDummy;

        while (head != null) {
            if (head.val < x) {
                small.next = head;
                small = small.next;
            } else {
                large.next = head;
                large = large.next;
            }
            head = head.next;
        }

        large.next = null;
        small.next = largeDummy.next;
        return smallDummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
