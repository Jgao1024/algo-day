## 最佳解法思路
- 思路（推荐）：先转置，再每行反转  
顺时针旋转 90° 等价于：
  1) 沿主对角线转置  
  2) 每一行左右反转  
全程原地操作。

## Java 最佳实现

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = tmp;
            }
        }

        for (int i = 0; i < n; i++) {
            int l = 0, r = n - 1;
            while (l < r) {
                int tmp = matrix[i][l];
                matrix[i][l] = matrix[i][r];
                matrix[i][r] = tmp;
                l++;
                r--;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)
