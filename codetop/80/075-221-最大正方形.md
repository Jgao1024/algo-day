## 最佳解法思路
- 思路（推荐）：DP（以 \((i,j)\) 为右下角的最大边长）  
若 `matrix[i][j] == '1'`，则：
`dp[i][j] = min(上, 左, 左上) + 1`。  
用一维滚动数组：`dp[j]` 表上方，`dp[j-1]` 表左侧，`prev` 表左上。

## Java 最佳实现

```java
class Solution {
    public int maximalSquare(char[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[] dp = new int[n + 1];
        int max = 0;

        for (int i = 1; i <= m; i++) {
            int prev = 0; // dp[j-1] from previous row (left-top)
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];
                if (matrix[i - 1][j - 1] == '1') {
                    dp[j] = Math.min(Math.min(dp[j], dp[j - 1]), prev) + 1;
                    max = Math.max(max, dp[j]);
                } else {
                    dp[j] = 0;
                }
                prev = temp;
            }
        }
        return max * max;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
