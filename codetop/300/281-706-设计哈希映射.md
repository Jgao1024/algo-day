# 706. 设计哈希映射

- 题号：706
- 难度：简单
- LeetCode：[设计哈希映射](https://leetcode.cn/problems/design-hashmap/)

## 题目描述
实现一个不使用内置哈希表的 `MyHashMap`，支持 `put/get/remove`。

## 示例
输入：
`["MyHashMap","put","put","get","get","put","get","remove","get"]`
`[[],[1,1],[2,2],[1],[3],[2,1],[2],[2],[2]]`
输出：`[null,null,null,1,-1,null,1,null,-1]`

## 最佳解法思路
- 用“数组 + 拉链法”（桶数组，每个桶挂一个链表/数组）存键值对。
- 取一个固定桶数 `N`，`idx = key % N`，在桶里线性找 key，存在就更新，不存在就新增；删除则从桶里移除。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class MyHashMap {
    private static class Pair {
        int key;
        int val;

        Pair(int key, int val) {
            this.key = key;
            this.val = val;
        }
    }

    private final int N = 769;
    private final List<Pair>[] buckets;

    public MyHashMap() {
        buckets = new List[N];
        for (int i = 0; i < N; i++) {
            buckets[i] = new ArrayList<>();
        }
    }

    public void put(int key, int value) {
        List<Pair> b = buckets[idx(key)];
        for (Pair p : b) {
            if (p.key == key) {
                p.val = value;
                return;
            }
        }
        b.add(new Pair(key, value));
    }

    public int get(int key) {
        List<Pair> b = buckets[idx(key)];
        for (Pair p : b) {
            if (p.key == key) {
                return p.val;
            }
        }
        return -1;
    }

    public void remove(int key) {
        List<Pair> b = buckets[idx(key)];
        for (int i = 0; i < b.size(); i++) {
            if (b.get(i).key == key) {
                b.remove(i);
                return;
            }
        }
    }

    private int idx(int key) {
        return key % N;
    }
}
```

## 复杂度分析
- 时间：平均 \(O(1)\)，最坏 \(O(n)\)（冲突极端时）
- 空间：\(O(n+N)\)
