# 340. 至多包含 K 个不同字符的最长子串

- 题号：340
- 难度：困难
- LeetCode：[至多包含 K 个不同字符的最长子串](https://leetcode.cn/problems/longest-substring-with-at-most-k-distinct-characters/)

## 题目描述
给定字符串 `s` 和整数 `k`，返回至多包含 `k` 个不同字符的最长子串长度。

## 示例
- `s = "eceba", k = 2`，输出 `3`（"ece"）
- `s = "aa", k = 1`，输出 `2`

## 最佳解法思路
- 滑动窗口：右指针扩张并计数；当窗口内不同字符数 `distinct > k` 时，左指针收缩并维护计数，直到满足条件。
- 每次满足条件时更新答案 `right - left + 1`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        if (s == null || s.length() == 0 || k <= 0) {
            return 0;
        }

        Map<Character, Integer> cnt = new HashMap<>();
        int left = 0;
        int ans = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            cnt.put(c, cnt.getOrDefault(c, 0) + 1);

            while (cnt.size() > k) {
                char d = s.charAt(left++);
                int v = cnt.get(d) - 1;
                if (v == 0) {
                    cnt.remove(d);
                } else {
                    cnt.put(d, v);
                }
            }

            ans = Math.max(ans, right - left + 1);
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(k)\)
