# 1095. 山脉数组中查找目标值

- 题号：1095
- 难度：困难
- LeetCode：[山脉数组中查找目标值](https://leetcode.cn/problems/find-in-mountain-array/)

## 题目描述
给定一个“山脉数组”（先严格递增后严格递减），通过接口 `MountainArray.get(i)` / `length()` 查找 `target` 的最小下标，不存在返回 -1。

## 示例
- `arr = [1,2,3,4,5,3,1], target = 3`，输出 `2`
- `arr = [0,1,2,4,2,1], target = 3`，输出 `-1`

## 最佳解法思路
- 先二分找峰值下标 `peak`（比较 `mid` 和 `mid+1`）。
- 再在 `[0, peak]` 做升序二分找 `target`；若没找到，再在 `[peak+1, n-1]` 做降序二分找 `target`。
- 题目限制 `get` 次数，二分是最省调用的写法。

## Java 最佳实现

```java
/**
 * // This is MountainArray's API interface.
 * // You should not implement it, or speculate about its implementation.
 * interface MountainArray {
 *     public int get(int index);
 *     public int length();
 * }
 */
class Solution {
    public int findInMountainArray(int target, MountainArray mountainArr) {
        int n = mountainArr.length();
        int peak = findPeak(mountainArr, n);

        int left = binaryAsc(mountainArr, 0, peak, target);
        if (left != -1) {
            return left;
        }
        return binaryDesc(mountainArr, peak + 1, n - 1, target);
    }

    private int findPeak(MountainArray a, int n) {
        int l = 0;
        int r = n - 1;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (a.get(m) < a.get(m + 1)) {
                l = m + 1;
            } else {
                r = m;
            }
        }
        return l;
    }

    private int binaryAsc(MountainArray a, int l, int r, int target) {
        while (l <= r) {
            int m = l + (r - l) / 2;
            int v = a.get(m);
            if (v == target) {
                return m;
            } else if (v < target) {
                l = m + 1;
            } else {
                r = m - 1;
            }
        }
        return -1;
    }

    private int binaryDesc(MountainArray a, int l, int r, int target) {
        while (l <= r) {
            int m = l + (r - l) / 2;
            int v = a.get(m);
            if (v == target) {
                return m;
            } else if (v > target) {
                l = m + 1;
            } else {
                r = m - 1;
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\) 次 `get` 调用
- 空间：\(O(1)\)
