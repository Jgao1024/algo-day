# 334. 递增的三元子序列

- 题号：334
- 难度：中等
- LeetCode：[递增的三元子序列](https://leetcode.cn/problems/increasing-triplet-subsequence/)

## 题目描述
给定整数数组 `nums`，判断是否存在下标 `i < j < k` 使得 `nums[i] < nums[j] < nums[k]`。

## 示例
- `nums = [1,2,3,4,5]`，输出 `true`
- `nums = [5,4,3,2,1]`，输出 `false`

## 最佳解法思路
- 贪心维护两个最小值：
  - `first`：目前最小的数
  - `second`：目前能接在 `first` 后面的最小数
- 遍历 `x`：
  - `x <= first`：更新 `first`
  - `x <= second`：更新 `second`
  - 否则 `x > second`：找到了 `first < second < x`，返回 `true`

## Java 最佳实现

```java
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int first = Integer.MAX_VALUE;
        int second = Integer.MAX_VALUE;
        for (int x : nums) {
            if (x <= first) {
                first = x;
            } else if (x <= second) {
                second = x;
            } else {
                return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
