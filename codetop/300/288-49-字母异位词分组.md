# 49. 字母异位词分组

- 题号：49
- 难度：中等
- LeetCode：[字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

## 题目描述
给定字符串数组，把字母异位词分到同一组并返回所有分组。

## 示例
- `strs = ["eat","tea","tan","ate","nat","bat"]`
输出：`[["eat","tea","ate"],["tan","nat"],["bat"]]`（顺序不限）

## 最佳解法思路
- 用计数作为 key：对每个字符串统计 26 个字母频次，拼成唯一 key（例如 `#1#0#0...`）。
- 相同 key 的放进同一个列表。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] cnt = new int[26];
            for (int i = 0; i < s.length(); i++) {
                cnt[s.charAt(i) - 'a']++;
            }
            String key = buildKey(cnt);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }

    private String buildKey(int[] cnt) {
        StringBuilder sb = new StringBuilder();
        for (int x : cnt) {
            sb.append('#').append(x);
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(\sum |s|)\)
- 空间：\(O(\sum |s|)\)
