# 994. 腐烂的橘子

- 题号：994
- 难度：中等
- LeetCode：[腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/)

## 题目描述
给定网格：0 空，1 新鲜，2 腐烂。每分钟腐烂橘子会让上下左右的新鲜橘子腐烂，问全部腐烂最少分钟数；如果不可能返回 -1。

## 示例
- `grid = [[2,1,1],[1,1,0],[0,1,1]]`，输出 `4`
- `grid = [[2,1,1],[0,1,1],[1,0,1]]`，输出 `-1`

## 最佳解法思路
- 多源 BFS：把所有腐烂橘子同时入队，统计新鲜橘子数量。
- 每一层表示 1 分钟，扩散腐烂；最后若新鲜数变成 0，返回分钟数，否则 -1。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;

        Queue<int[]> q = new ArrayDeque<>();
        int fresh = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    q.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        if (fresh == 0) {
            return 0;
        }

        int minutes = 0;
        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};

        while (!q.isEmpty()) {
            int size = q.size();
            boolean changed = false;

            for (int t = 0; t < size; t++) {
                int[] cur = q.poll();
                int r = cur[0];
                int c = cur[1];
                for (int k = 0; k < 4; k++) {
                    int nr = r + dr[k];
                    int nc = c + dc[k];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                        continue;
                    }
                    if (grid[nr][nc] != 1) {
                        continue;
                    }
                    grid[nr][nc] = 2;
                    fresh--;
                    q.offer(new int[]{nr, nc});
                    changed = true;
                }
            }

            if (changed) {
                minutes++;
            }
        }

        return fresh == 0 ? minutes : -1;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
