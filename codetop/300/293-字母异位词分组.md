# 49. 字母异位词分组

## 题目描述
给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。

字母异位词是由重新排列源单词的字母得到的一个新单词，所有源单词中的字母通常恰好只用一次。

示例 1:
```
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

示例 2:
```
输入：strs = [""]
输出：[[""]]
```

示例 3:
```
输入：strs = ["a"]
输出：[["a"]]
```

## 解题思路
1. 排序+哈希表法：
   - 将每个字符串排序后作为key
   - 将原字符串作为value存入哈希表
   - 时间复杂度：O(nklogk)，空间复杂度：O(nk)

2. 计数+哈希表法：
   - 统计每个字符串中字符出现的次数
   - 将计数结果作为key存入哈希表
   - 时间复杂度：O(nk)，空间复杂度：O(nk)

## Java实现
```java
// 排序+哈希表法
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        
        for (String str : strs) {
            char[] chars = str.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            
            if (!map.containsKey(key)) {
                map.put(key, new ArrayList<>());
            }
            map.get(key).add(str);
        }
        
        return new ArrayList<>(map.values());
    }
}

// 计数+哈希表法
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        
        for (String str : strs) {
            int[] count = new int[26];
            for (char c : str.toCharArray()) {
                count[c - 'a']++;
            }
            
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < 26; i++) {
                sb.append('#');
                sb.append(count[i]);
            }
            String key = sb.toString();
            
            if (!map.containsKey(key)) {
                map.put(key, new ArrayList<>());
            }
            map.get(key).add(str);
        }
        
        return new ArrayList<>(map.values());
    }
}
```

## Python实现
```python
# 排序+哈希表法
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        from collections import defaultdict
        
        map = defaultdict(list)
        for str in strs:
            key = ''.join(sorted(str))
            map[key].append(str)
            
        return list(map.values())

# 计数+哈希表法
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        from collections import defaultdict
        
        map = defaultdict(list)
        for str in strs:
            count = [0] * 26
            for c in str:
                count[ord(c) - ord('a')] += 1
                
            key = '#'.join(map(str, count))
            map[key].append(str)
            
        return list(map.values())
```

## 复杂度分析
- 排序+哈希表法：
  - 时间复杂度：O(nklogk)，其中n是字符串数组的长度，k是字符串的最大长度
  - 空间复杂度：O(nk)，需要存储所有字符串

- 计数+哈希表法：
  - 时间复杂度：O(nk)，其中n是字符串数组的长度，k是字符串的最大长度
  - 空间复杂度：O(nk)，需要存储所有字符串
