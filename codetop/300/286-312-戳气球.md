# 312. 戳气球

- 题号：312
- 难度：困难
- LeetCode：[戳气球](https://leetcode.cn/problems/burst-balloons/)

## 题目描述
有 `n` 个气球，每个有数字 `nums[i]`。戳破第 `i` 个气球可获得 `nums[left] * nums[i] * nums[right]`（left/right 为相邻未戳破气球），求最大金币数。

## 示例
- `nums = [3,1,5,8]`，输出 `167`

## 最佳解法思路
- 区间 DP：把两端补 1，变成 `arr[0]=arr[n+1]=1`。
- 设 `dp[l][r]` 表示只戳破开区间 `(l, r)` 内的气球（不含 l、r）能得到的最大金币。
- 枚举最后一个被戳破的气球 `k`（`l < k < r`）：
  `dp[l][r] = max(dp[l][k] + dp[k][r] + arr[l]*arr[k]*arr[r])`

## Java 最佳实现

```java
class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] a = new int[n + 2];
        a[0] = 1;
        a[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            a[i + 1] = nums[i];
        }

        int[][] dp = new int[n + 2][n + 2];
        for (int len = 2; len <= n + 1; len++) {
            for (int l = 0; l + len <= n + 1; l++) {
                int r = l + len;
                int best = 0;
                for (int k = l + 1; k < r; k++) {
                    int cur = dp[l][k] + dp[k][r] + a[l] * a[k] * a[r];
                    if (cur > best) {
                        best = cur;
                    }
                }
                dp[l][r] = best;
            }
        }
        return dp[0][n + 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)
- 空间：\(O(n^2)\)
