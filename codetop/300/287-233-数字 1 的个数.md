# 233. 数字 1 的个数

- 题号：233
- 难度：困难
- LeetCode：[数字 1 的个数](https://leetcode.cn/problems/number-of-digit-one/)

## 题目描述
给定整数 `n`，统计从 `1` 到 `n` 的所有整数中，数字字符 `'1'` 出现的次数。

## 示例
- `n = 13`，输出 `6`（1,10,11,12,13）

## 最佳解法思路
- 按位统计：考虑当前位置 `factor = 1,10,100...`，把 `n` 拆成 `high / cur / low`：
  - `high = n / (factor * 10)`
  - `cur = (n / factor) % 10`
  - `low = n % factor`
- 当前位贡献：
  - `cur == 0`：`high * factor`
  - `cur == 1`：`high * factor + low + 1`
  - `cur > 1`：`(high + 1) * factor`

## Java 最佳实现

```java
class Solution {
    public int countDigitOne(int n) {
        long ans = 0;
        long factor = 1;
        while (factor <= n) {
            long high = n / (factor * 10);
            long cur = (n / factor) % 10;
            long low = n % factor;

            if (cur == 0) {
                ans += high * factor;
            } else if (cur == 1) {
                ans += high * factor + low + 1;
            } else {
                ans += (high + 1) * factor;
            }

            factor *= 10;
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
