# 354. 俄罗斯套娃信封问题

- 题号：354
- 难度：困难
- LeetCode：[俄罗斯套娃信封问题](https://leetcode.cn/problems/russian-doll-envelopes/)

## 题目描述
给定若干信封 `envelopes[i] = [w, h]`，若 `w` 和 `h` 都严格大于另一个信封则可嵌套。求最多能嵌套多少个。

## 示例
- `envelopes = [[5,4],[6,4],[6,7],[2,3]]`，输出 `3`（[2,3] => [5,4] => [6,7]）

## 最佳解法思路
- 先排序：宽度升序；宽度相同则高度降序（避免同宽被同时选进 LIS）。
- 然后在“高度数组”上求严格递增的 LIS（耐心排序 + 二分）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        Arrays.sort(envelopes, (a, b) -> {
            if (a[0] != b[0]) {
                return a[0] - b[0];
            }
            return b[1] - a[1];
        });

        int n = envelopes.length;
        int[] d = new int[n];
        int len = 0;

        for (int[] e : envelopes) {
            int h = e[1];
            int i = lowerBound(d, 0, len, h);
            d[i] = h;
            if (i == len) {
                len++;
            }
        }

        return len;
    }

    private int lowerBound(int[] a, int l, int r, int x) {
        while (l < r) {
            int m = l + (r - l) / 2;
            if (a[m] >= x) {
                r = m;
            } else {
                l = m + 1;
            }
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
