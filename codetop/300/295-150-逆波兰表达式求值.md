# 150. 逆波兰表达式求值

- 题号：150
- 难度：中等
- LeetCode：[逆波兰表达式求值](https://leetcode.cn/problems/evaluate-reverse-polish-notation/)

## 题目描述
给定一个逆波兰表达式 tokens，返回表达式结果。运算符为 `+ - * /`，除法向 0 取整。

## 示例
- `tokens = ["2","1","+","3","*"]`，输出 `9`
- `tokens = ["4","13","5","/","+"]`，输出 `6`

## 最佳解法思路
- 栈：遇到数字入栈；遇到运算符弹出两个数 `b`、`a`，计算 `a op b` 再入栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> st = new ArrayDeque<>();
        for (String t : tokens) {
            if (isOp(t)) {
                int b = st.pop();
                int a = st.pop();
                st.push(calc(a, b, t));
            } else {
                st.push(Integer.parseInt(t));
            }
        }
        return st.pop();
    }

    private boolean isOp(String s) {
        return s.length() == 1 && (s.charAt(0) == '+' || s.charAt(0) == '-' || s.charAt(0) == '*' || s.charAt(0) == '/');
    }

    private int calc(int a, int b, String op) {
        char c = op.charAt(0);
        if (c == '+') {
            return a + b;
        }
        if (c == '-') {
            return a - b;
        }
        if (c == '*') {
            return a * b;
        }
        return a / b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
