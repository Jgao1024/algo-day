# 547. 省份数量（原朋友圈）

- 题号：547
- 难度：中等
- LeetCode：[省份数量（原朋友圈）](https://leetcode.cn/problems/number-of-provinces/)

## 题目描述
给定 `n x n` 邻接矩阵 `isConnected`，`isConnected[i][j]=1` 表示城市 i 和 j 直接相连。求省份数量（连通分量个数）。

## 示例
- `isConnected = [[1,1,0],[1,1,0],[0,0,1]]`，输出 `2`
- `isConnected = [[1,0,0],[0,1,0],[0,0,1]]`，输出 `3`

## 最佳解法思路
- 并查集：把相连的城市合并，最后统计不同根的数量。

## Java 最佳实现

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        UnionFind uf = new UnionFind(n);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) {
                    uf.union(i, j);
                }
            }
        }
        return uf.count();
    }

    private static class UnionFind {
        int[] p;
        int[] r;
        int cnt;

        UnionFind(int n) {
            p = new int[n];
            r = new int[n];
            cnt = n;
            for (int i = 0; i < n; i++) {
                p[i] = i;
            }
        }

        int find(int x) {
            while (p[x] != x) {
                p[x] = p[p[x]];
                x = p[x];
            }
            return x;
        }

        void union(int a, int b) {
            int ra = find(a);
            int rb = find(b);
            if (ra == rb) {
                return;
            }
            if (r[ra] < r[rb]) {
                p[ra] = rb;
            } else if (r[ra] > r[rb]) {
                p[rb] = ra;
            } else {
                p[rb] = ra;
                r[ra]++;
            }
            cnt--;
        }

        int count() {
            return cnt;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 \alpha(n))\)
- 空间：\(O(n)\)
