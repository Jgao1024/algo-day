# 1556. 千位分隔数

- 题号：1556
- 难度：简单
- LeetCode：[千位分隔数](https://leetcode.cn/problems/thousand-separator/)

## 题目描述
给定整数 `n`，把它格式化成字符串：每 3 位用 `'.'` 分隔（从右往左）。

## 示例
- `n = 987`，输出 `"987"`
- `n = 1234`，输出 `"1.234"`
- `n = 123456789`，输出 `"123.456.789"`

## 最佳解法思路
- 从右往左拼接：每放 3 个数字就放一个 `'.'`（注意首部不加分隔符），最后反转。

## Java 最佳实现

```java
class Solution {
    public String thousandSeparator(int n) {
        if (n == 0) {
            return "0";
        }

        StringBuilder sb = new StringBuilder();
        int cnt = 0;
        while (n > 0) {
            if (cnt == 3) {
                sb.append('.');
                cnt = 0;
            }
            sb.append(n % 10);
            n /= 10;
            cnt++;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(\log n)\)
