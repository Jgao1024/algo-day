# 752. 打开转盘锁

- 题号：752
- 难度：中等
- LeetCode：[打开转盘锁](https://leetcode.cn/problems/open-the-lock/)

## 题目描述
转盘锁 4 位数字，从 `"0000"` 出发，每次可把某一位 \(+1\) 或 \(-1\)（9 和 0 相邻）。给定死亡数字集合 `deadends` 和目标 `target`，求最少旋转次数，无法到达返回 -1。

## 示例
- `deadends = ["0201","0101","0102","1212","2002"], target = "0202"`，输出 `6`
- `deadends = ["8888"], target = "0009"`，输出 `1`

## 最佳解法思路
- BFS：状态是 4 位字符串，从 `"0000"` 开始按层扩展；遇到 `dead` 或已访问跳过；首次到达 `target` 时的层数就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int openLock(String[] deadends, String target) {
        Set<String> dead = new HashSet<>();
        for (String s : deadends) {
            dead.add(s);
        }
        if (dead.contains("0000")) {
            return -1;
        }
        if ("0000".equals(target)) {
            return 0;
        }

        Set<String> vis = new HashSet<>();
        Deque<String> q = new ArrayDeque<>();
        q.offer("0000");
        vis.add("0000");

        int steps = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            steps++;
            for (int i = 0; i < size; i++) {
                String cur = q.poll();
                for (int k = 0; k < 4; k++) {
                    String up = move(cur, k, 1);
                    if (up.equals(target)) {
                        return steps;
                    }
                    if (!dead.contains(up) && vis.add(up)) {
                        q.offer(up);
                    }

                    String down = move(cur, k, -1);
                    if (down.equals(target)) {
                        return steps;
                    }
                    if (!dead.contains(down) && vis.add(down)) {
                        q.offer(down);
                    }
                }
            }
        }
        return -1;
    }

    private String move(String s, int idx, int delta) {
        char[] a = s.toCharArray();
        int d = a[idx] - '0';
        d = (d + delta + 10) % 10;
        a[idx] = (char) ('0' + d);
        return new String(a);
    }
}
```

## 复杂度分析
- 时间：\(O(10^4)\)（状态总数上限）
- 空间：\(O(10^4)\)
