# 107. 二叉树的层次遍历 II

- 题号：107
- 难度：中等
- LeetCode：[二叉树的层次遍历 II](https://leetcode.cn/problems/binary-tree-level-order-traversal-ii/)

## 题目描述
给定二叉树根节点 `root`，按“自底向上”的层序遍历返回每一层节点值。

## 示例
输入：`[3,9,20,null,null,15,7]`  
输出：`[[15,7],[9,20],[3]]`

## 最佳解法思路
- BFS 正常按层遍历，但每一层结果用 `addFirst` 放到链表头部即可（避免最后整体反转）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        if (root == null) {
            return new ArrayList<>();
        }

        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        Deque<List<Integer>> res = new LinkedList<>();

        while (!q.isEmpty()) {
            int size = q.size();
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode cur = q.poll();
                level.add(cur.val);
                if (cur.left != null) {
                    q.offer(cur.left);
                }
                if (cur.right != null) {
                    q.offer(cur.right);
                }
            }
            res.addFirst(level);
        }

        return new ArrayList<>(res);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
