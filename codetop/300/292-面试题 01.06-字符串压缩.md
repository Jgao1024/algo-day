# 面试题 01.06. 字符串压缩

- 题号：面试题 01.06
- 难度：简单
- LeetCode：[字符串压缩](https://leetcode.cn/problems/compress-string-lcci/)

## 题目描述
对字符串做简单压缩：连续相同字符用“字符+次数”表示。若压缩后不更短，返回原字符串。

## 示例
- `s = "aabcccccaaa"`，输出 `"a2b1c5a3"`
- `s = "abbccd"`，输出 `"abbccd"`

## 最佳解法思路
- 双指针/计数：遍历字符串，统计每段连续字符的长度，追加到 `StringBuilder`。
- 最后比较长度，短则返回压缩串，否则返回原串。

## Java 最佳实现

```java
class Solution {
    public String compressString(String s) {
        if (s == null || s.length() == 0) {
            return s;
        }

        StringBuilder sb = new StringBuilder();
        int i = 0;
        int n = s.length();
        while (i < n) {
            char c = s.charAt(i);
            int j = i + 1;
            while (j < n && s.charAt(j) == c) {
                j++;
            }
            sb.append(c).append(j - i);
            i = j;
        }

        return sb.length() < n ? sb.toString() : s;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
