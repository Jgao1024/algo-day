# 172. 阶乘后的零

- 题号：172
- 难度：简单
- LeetCode：[阶乘后的零](https://leetcode.cn/problems/factorial-trailing-zeroes/)

## 题目描述
给定 `n`，返回 `n!` 末尾有多少个 0。

## 示例
- `n = 3`，输出 `0`
- `n = 5`，输出 `1`
- `n = 30`，输出 `7`

## 最佳解法思路
- 末尾 0 来自因子 `10 = 2 * 5`，2 的个数远多于 5，所以只需要统计 `1..n` 中 5 的因子个数：
  - `ans = n/5 + n/25 + n/125 + ...`

## Java 最佳实现

```java
class Solution {
    public int trailingZeroes(int n) {
        int ans = 0;
        while (n > 0) {
            n /= 5;
            ans += n;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log_5 n)\)
- 空间：\(O(1)\)
