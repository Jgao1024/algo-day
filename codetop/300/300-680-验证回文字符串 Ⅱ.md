# 680. 验证回文字符串 Ⅱ

- 题号：680
- 难度：简单
- LeetCode：[验证回文字符串 Ⅱ](https://leetcode.cn/problems/valid-palindrome-ii/)

## 题目描述
给定字符串 `s`，最多删除一个字符，判断是否能变成回文串。

## 示例
- `s = "aba"`，输出 `true`
- `s = "abca"`，输出 `true`（删 'b' 或 'c'）
- `s = "abc"`，输出 `false`

## 最佳解法思路
- 双指针从两端向中间：
  - 若相等继续；
  - 第一次不等时，尝试“跳过左边”或“跳过右边”两种情况，只要有一种能成回文就行。

## Java 最佳实现

```java
class Solution {
    public boolean validPalindrome(String s) {
        int l = 0;
        int r = s.length() - 1;
        while (l < r) {
            if (s.charAt(l) == s.charAt(r)) {
                l++;
                r--;
            } else {
                return isPal(s, l + 1, r) || isPal(s, l, r - 1);
            }
        }
        return true;
    }

    private boolean isPal(String s, int l, int r) {
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) {
                return false;
            }
            l++;
            r--;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
