# 7. 整数反转

## 题目描述
给你一个 32 位的有符号整数 x ，返回将 x 中的数字部分反转后的结果。如果反转后整数超过 32 位的有符号整数的范围 [−2^31, 2^31 − 1] ，就返回 0。

示例 1：
```
输入：x = 123
输出：321
```

示例 2：
```
输入：x = -123
输出：-321
```

示例 3：
```
输入：x = 120
输出：21
```

## 解题思路
1. 数学方法：
   - 通过取模和除法操作逐位反转
   - 在反转过程中判断是否溢出
   - 时间复杂度：O(log|x|)，空间复杂度：O(1)

2. 关键点：
   - 处理负数情况
   - 处理末尾为0的情况
   - 判断整数溢出
   - 边界条件处理

## Java实现
```java
class Solution {
    public int reverse(int x) {
        int result = 0;
        
        while (x != 0) {
            int digit = x % 10;
            x /= 10;
            
            // 判断是否溢出
            if (result > Integer.MAX_VALUE / 10 || 
                (result == Integer.MAX_VALUE / 10 && digit > 7)) {
                return 0;
            }
            if (result < Integer.MIN_VALUE / 10 || 
                (result == Integer.MIN_VALUE / 10 && digit < -8)) {
                return 0;
            }
            
            result = result * 10 + digit;
        }
        
        return result;
    }
}
```

## Python实现
```python
class Solution:
    def reverse(self, x: int) -> int:
        result = 0
        sign = 1 if x >= 0 else -1
        x = abs(x)
        
        while x != 0:
            digit = x % 10
            x //= 10
            
            // 判断是否溢出
            if result > (2**31 - 1) // 10 or \
               (result == (2**31 - 1) // 10 and digit > 7):
                return 0
                
            result = result * 10 + digit
            
        return sign * result
```

## 复杂度分析
- 时间复杂度：O(log|x|)，其中x为输入整数
- 空间复杂度：O(1)，只使用常数额外空间
