# 96. 不同的二叉搜索树

## 题目描述
给你一个整数 n，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的二叉搜索树有多少种？返回满足题意的二叉搜索树的种数。

示例 1:
```
输入：n = 3
输出：5
```

示例 2:
```
输入：n = 1
输出：1
```

## 解题思路
1. 动态规划方法：
   - 定义dp[i]表示i个节点能组成的二叉搜索树数量
   - 对于每个节点j作为根节点，左子树有j-1个节点，右子树有i-j个节点
   - dp[i] = Σ(dp[j-1] * dp[i-j])，其中j从1到i
   - 时间复杂度：O(n²)，空间复杂度：O(n)

2. 关键点：
   - 理解卡特兰数的应用
   - 使用动态规划避免重复计算
   - 注意边界条件

## Java实现
```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        
        return dp[n];
    }
}
```

## Python实现
```python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1
        
        for i in range(2, n + 1):
            for j in range(1, i + 1):
                dp[i] += dp[j - 1] * dp[i - j]
                
        return dp[n]
```

## 复杂度分析
- 时间复杂度：O(n²)，需要两层循环
- 空间复杂度：O(n)，需要存储dp数组
