# 剑指 Offer 27. 二叉树的镜像

- 题号：剑指 Offer 27
- 难度：简单
- LeetCode：[二叉树的镜像](https://leetcode.cn/problems/er-cha-shu-de-jing-xiang-lcof/)

## 题目描述
给定二叉树 `root`，把它变成镜像：对每个节点交换左右子树，返回根节点。

## 示例
- 示例  
输入：`root = [4,2,7,1,3,6,9]`  
输出：`[4,7,2,9,6,3,1]`

## 最佳解法思路
- 思路1（推荐）：递归  
递归处理子树，并在当前节点交换 `left/right`。

## Java 最佳实现

```java
class Solution {
    public TreeNode mirrorTree(TreeNode root) {
        if (root == null) return null;
        TreeNode left = mirrorTree(root.left);
        TreeNode right = mirrorTree(root.right);
        root.left = right;
        root.right = left;
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)

## 总结（速记）
- 每个节点做一次 swap，然后递归即可。
