# 673. 最长递增子序列的个数

- 题号：673
- 难度：中等
- LeetCode：[最长递增子序列的个数](https://leetcode.cn/problems/number-of-longest-increasing-subsequence/)

## 题目描述
给定整数数组 `nums`，返回最长递增子序列（LIS）的个数。

## 示例
- 示例  
输入：`nums = [1,3,5,4,7]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：DP（长度 + 计数）  
`len[i]`：以 `i` 结尾的 LIS 最长长度；`cnt[i]`：达到该长度的方案数。  
枚举 `j<i` 且 `nums[j] < nums[i]`：  
若 `len[j] + 1 > len[i]`，更新 `len[i]` 并让 `cnt[i]=cnt[j]`；  
若相等，累加 `cnt[i] += cnt[j]`。  
最后把所有 `len[i]==maxLen` 的 `cnt[i]` 求和。

## Java 最佳实现

```java
class Solution {
    public int findNumberOfLIS(int[] nums) {
        int n = nums.length;
        int[] len = new int[n];
        int[] cnt = new int[n];
        int maxLen = 0;

        for (int i = 0; i < n; i++) {
            len[i] = 1;
            cnt[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    if (len[j] + 1 > len[i]) {
                        len[i] = len[j] + 1;
                        cnt[i] = cnt[j];
                    } else if (len[j] + 1 == len[i]) {
                        cnt[i] += cnt[j];
                    }
                }
            }
            maxLen = Math.max(maxLen, len[i]);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (len[i] == maxLen) ans += cnt[i];
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
