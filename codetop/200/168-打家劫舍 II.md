# 213. 打家劫舍 II

## 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都围成一圈，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你在不触动警报装置的情况下，今晚能够偷窃到的最高金额。

示例 1:
```
输入：nums = [2,3,2]
输出：3
解释：你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2）, 因为他们是相邻的。
```

示例 2:
```
输入：nums = [1,2,3,1]
输出：4
解释：你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
```

## 解题思路
1. 动态规划方法：
   - 将问题分解为两个子问题：不偷第一个房子和不偷最后一个房子
   - 对每个子问题使用动态规划求解
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 处理环形房屋
   - 使用动态规划
   - 优化空间复杂度

## Java实现
```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) {
            return nums[0];
        }
        // 不偷第一个房子
        int max1 = robRange(nums, 1, nums.length - 1);
        // 不偷最后一个房子
        int max2 = robRange(nums, 0, nums.length - 2);
        return Math.max(max1, max2);
    }
    
    private int robRange(int[] nums, int start, int end) {
        int prev = 0;
        int curr = 0;
        
        for (int i = start; i <= end; i++) {
            int temp = curr;
            curr = Math.max(prev + nums[i], curr);
            prev = temp;
        }
        
        return curr;
    }
}
```

## Python实现
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) == 1:
            return nums[0]
            
        # 不偷第一个房子
        max1 = self.rob_range(nums, 1, len(nums) - 1)
        # 不偷最后一个房子
        max2 = self.rob_range(nums, 0, len(nums) - 2)
        
        return max(max1, max2)
    
    def rob_range(self, nums: List[int], start: int, end: int) -> int:
        prev = 0
        curr = 0
        
        for i in range(start, end + 1):
            temp = curr
            curr = max(prev + nums[i], curr)
            prev = temp
            
        return curr
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历数组两次
- 空间复杂度：O(1)，只使用常数额外空间
