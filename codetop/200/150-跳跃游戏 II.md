# 55. 跳跃游戏

## 题目描述
给定一个非负整数数组 nums，你最初位于数组的第一个位置。

数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个位置。

示例 1：
```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从位置 0 到达位置 1, 然后再从位置 1 跳 3 步到达最后一个位置。
```

示例 2：
```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达索引为 3 的位置。但该位置的最大跳跃长度是 0，所以永远不可能到达最后一个位置。
```

## 解题思路
1. 贪心法：
   - 维护一个变量maxReach表示能够到达的最远位置
   - 遍历数组，更新maxReach = max(maxReach, i + nums[i])
   - 如果maxReach >= n-1，说明可以到达最后一个位置
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 动态规划法：
   - 定义dp[i]表示从位置i是否能够到达最后一个位置
   - 状态转移方程：dp[i] = dp[i+1] || dp[i+2] || ... || dp[i+nums[i]]
   - 时间复杂度：O(n²)，空间复杂度：O(n)

## Java实现
```java
// 贪心法
class Solution {
    public boolean canJump(int[] nums) {
        if (nums == null || nums.length == 0) {
            return false;
        }
        
        int maxReach = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > maxReach) {
                return false;
            }
            maxReach = Math.max(maxReach, i + nums[i]);
            if (maxReach >= nums.length - 1) {
                return true;
            }
        }
        
        return false;
    }
}

// 动态规划法
class Solution {
    public boolean canJump(int[] nums) {
        if (nums == null || nums.length == 0) {
            return false;
        }
        
        int n = nums.length;
        boolean[] dp = new boolean[n];
        dp[n-1] = true;
        
        for (int i = n-2; i >= 0; i--) {
            int maxJump = Math.min(i + nums[i], n-1);
            for (int j = i + 1; j <= maxJump; j++) {
                if (dp[j]) {
                    dp[i] = true;
                    break;
                }
            }
        }
        
        return dp[0];
    }
}
```

## Python实现
```python
# 贪心法
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        if not nums:
            return False
            
        max_reach = 0
        for i in range(len(nums)):
            if i > max_reach:
                return False
            max_reach = max(max_reach, i + nums[i])
            if max_reach >= len(nums) - 1:
                return True
                
        return False

# 动态规划法
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        if not nums:
            return False
            
        n = len(nums)
        dp = [False] * n
        dp[n-1] = True
        
        for i in range(n-2, -1, -1):
            max_jump = min(i + nums[i], n-1)
            for j in range(i + 1, max_jump + 1):
                if dp[j]:
                    dp[i] = True
                    break
                    
        return dp[0]
```

## 复杂度分析
- 贪心法：
  - 时间复杂度：O(n)，只需要遍历一次数组
  - 空间复杂度：O(1)，只使用常数额外空间

- 动态规划法：
  - 时间复杂度：O(n²)，对于每个位置，最多需要检查n个位置
  - 空间复杂度：O(n)，需要存储dp数组
