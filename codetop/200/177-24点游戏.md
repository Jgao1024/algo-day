# 679. 24 点游戏

## 题目描述
给定一个长度为4的整数数组 cards，你有 4 张卡片，每张卡片上都对应一个数字（范围 1 到 9）。你被要求使用运算符 ['+', '-', '*', '/'] 和括号 '(' 和 ')' 将卡片上的数字连接起来，使得最终结果等于 24。

示例 1:
```
输入：cards = [4,1,8,7]
输出：true
解释：(8-4) * (7-1) = 24
```

示例 2:
```
输入：cards = [1,2,1,2]
输出：false
```

## 解题思路
1. 回溯法：
   - 每次选择两个数字进行运算
   - 将运算结果放回数组
   - 递归处理剩余数字
   - 时间复杂度：O(4! * 4^3)，空间复杂度：O(4)

2. 关键点：
   - 处理除法精度问题
   - 考虑所有可能的运算顺序
   - 处理边界情况

## Java实现
```java
class Solution {
    private static final double EPSILON = 1e-6;
    
    public boolean judgePoint24(int[] cards) {
        List<Double> nums = new ArrayList<>();
        for (int card : cards) {
            nums.add((double) card);
        }
        return solve(nums);
    }
    
    private boolean solve(List<Double> nums) {
        if (nums.size() == 1) {
            return Math.abs(nums.get(0) - 24) < EPSILON;
        }
        
        for (int i = 0; i < nums.size(); i++) {
            for (int j = i + 1; j < nums.size(); j++) {
                double a = nums.get(i);
                double b = nums.get(j);
                List<Double> nextNums = new ArrayList<>();
                
                for (int k = 0; k < nums.size(); k++) {
                    if (k != i && k != j) {
                        nextNums.add(nums.get(k));
                    }
                }
                
                // 尝试所有可能的运算
                for (double result : compute(a, b)) {
                    nextNums.add(result);
                    if (solve(nextNums)) {
                        return true;
                    }
                    nextNums.remove(nextNums.size() - 1);
                }
            }
        }
        return false;
    }
    
    private List<Double> compute(double a, double b) {
        List<Double> results = new ArrayList<>();
        results.add(a + b);
        results.add(a - b);
        results.add(b - a);
        results.add(a * b);
        if (Math.abs(b) > EPSILON) results.add(a / b);
        if (Math.abs(a) > EPSILON) results.add(b / a);
        return results;
    }
}
```

## Python实现
```python
class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        EPSILON = 1e-6
        
        def solve(nums):
            if len(nums) == 1:
                return abs(nums[0] - 24) < EPSILON
                
            for i in range(len(nums)):
                for j in range(i + 1, len(nums)):
                    a, b = nums[i], nums[j]
                    next_nums = [nums[k] for k in range(len(nums)) if k != i and k != j]
                    
                    # 尝试所有可能的运算
                    for result in compute(a, b):
                        next_nums.append(result)
                        if solve(next_nums):
                            return True
                        next_nums.pop()
            return False
            
        def compute(a, b):
            results = [a + b, a - b, b - a, a * b]
            if abs(b) > EPSILON:
                results.append(a / b)
            if abs(a) > EPSILON:
                results.append(b / a)
            return results
            
        return solve([float(x) for x in cards])
```

## 复杂度分析
- 时间复杂度：O(4! * 4^3)，需要尝试所有可能的数字组合和运算
- 空间复杂度：O(4)，递归调用栈的深度
