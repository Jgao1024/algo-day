# 补充题14. 阿拉伯数字转中文数字

- 题号：补充题14
- 难度：中等
- LeetCode：[阿拉伯数字转中文数字](https://leetcode.cn/problemset/all/?search=%E8%A1%A5%E5%85%85%E9%A2%9814)

## 题目描述
把阿拉伯数字转换成中文读法（不带货币单位）。  
例如：`12345 -> 一万二千三百四十五`，`10005 -> 一万零五`。

## 示例
- 示例  
输入：`10005`  
输出：`"一万零五"`

## 最佳解法思路
- 思路1（推荐）：按 4 位分段（万/亿）  
把数字按每 4 位切成一段：`xxxx`、`xxxx万`、`xxxx亿`...  
每段内部用 `千/百/十/个` 转换，并处理“零”的合并；段与段之间若出现断层或低段不足 4 位，需要补一个“零”。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private static final String[] DIG = {"零", "一", "二", "三", "四", "五", "六", "七", "八", "九"};
    private static final String[] UNIT = {"千", "百", "十", ""};
    private static final int[] DIV = {1000, 100, 10, 1};
    private static final String[] SEC_UNIT = {"", "万", "亿", "万亿"};

    public String numberToChinese(long num) {
        if (num == 0) return "零";
        if (num < 0) return "负" + numberToChinese(-num);

        List<Integer> sections = new ArrayList<>();
        while (num > 0) {
            sections.add((int) (num % 10000));
            num /= 10000;
        }

        StringBuilder sb = new StringBuilder();
        boolean zeroPending = false;
        for (int i = sections.size() - 1; i >= 0; i--) {
            int sec = sections.get(i);
            if (sec == 0) {
                zeroPending = sb.length() > 0;
                continue;
            }
            if (sb.length() > 0) {
                if (zeroPending || sec < 1000) sb.append("零");
            }
            sb.append(sectionToChinese(sec)).append(SEC_UNIT[i]);
            zeroPending = false;
        }

        String res = sb.toString();
        if (res.startsWith("一十")) res = res.substring(1);
        return res;
    }

    private String sectionToChinese(int sec) {
        StringBuilder sb = new StringBuilder();
        boolean zero = false;
        for (int i = 0; i < 4; i++) {
            int d = (sec / DIV[i]) % 10;
            if (d == 0) {
                if (sb.length() > 0) zero = true;
            } else {
                if (zero) {
                    sb.append("零");
                    zero = false;
                }
                sb.append(DIG[d]).append(UNIT[i]);
            }
        }
        return sb.toString();
    }
}
```

- 时间：\(O(\log_{10} n)\)
- 空间：\(O(\log_{10} n)\)

## 总结（速记）
- 先按 4 位切段（万/亿），段内按千百十个拼；“零”用标记合并，段之间缺位时补一个“零”。
