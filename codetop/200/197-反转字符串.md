# 344. 反转字符串

## 题目描述
编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 char[] 的形式给出。不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

示例 1:
```
输入：["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

示例 2:
```
输入：["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

## 解题思路
1. 双指针方法：
   - 使用左右两个指针从两端向中间移动
   - 交换左右指针指向的字符
   - 直到左右指针相遇
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 原地修改数组
   - 不需要额外空间
   - 注意指针移动条件

## Java实现
```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++;
            right--;
        }
    }
}
```

## Python实现
```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```

## 复杂度分析
- 时间复杂度：O(n)，其中n是字符串长度
- 空间复杂度：O(1)，只使用了常数额外空间
