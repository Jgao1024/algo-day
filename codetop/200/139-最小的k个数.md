# 剑指 Offer 40. 最小的k个数

## 题目描述
输入整数数组 arr，找出其中最小的 k 个数。例如，输入4、5、1、6、2、7、3、8这8个数字，则最小的4个数字是1、2、3、4。

示例 1：
```
输入：arr = [3,2,1], k = 2
输出：[1,2] 或者 [2,1]
```

示例 2：
```
输入：arr = [0,1,2,1], k = 1
输出：[0]
```

## 解题思路
1. 快速选择方法：
   - 使用快速排序的思想，每次选择一个基准值
   - 将数组分为两部分，左边小于基准值，右边大于基准值
   - 根据基准值的位置决定继续处理左半部分还是右半部分
   - 时间复杂度：平均O(n)，最坏O(n²)，空间复杂度：O(1)

2. 堆排序方法：
   - 维护一个大小为k的大顶堆
   - 遍历数组，当堆大小小于k时直接入堆
   - 当堆大小等于k时，比较当前元素与堆顶元素
   - 时间复杂度：O(nlogk)，空间复杂度：O(k)

## Java实现
```java
// 快速选择方法
class Solution {
    public int[] getLeastNumbers(int[] arr, int k) {
        if (k == 0 || arr.length == 0) {
            return new int[0];
        }
        return quickSearch(arr, 0, arr.length - 1, k - 1);
    }
    
    private int[] quickSearch(int[] arr, int left, int right, int k) {
        int j = partition(arr, left, right);
        if (j == k) {
            return Arrays.copyOf(arr, j + 1);
        }
        return j > k ? quickSearch(arr, left, j - 1, k) : quickSearch(arr, j + 1, right, k);
    }
    
    private int partition(int[] arr, int left, int right) {
        int pivot = arr[left];
        int i = left, j = right;
        while (i < j) {
            while (i < j && arr[j] >= pivot) j--;
            while (i < j && arr[i] <= pivot) i++;
            if (i < j) {
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
            }
        }
        arr[left] = arr[i];
        arr[i] = pivot;
        return i;
    }
}

// 堆排序方法
class Solution {
    public int[] getLeastNumbers(int[] arr, int k) {
        if (k == 0 || arr.length == 0) {
            return new int[0];
        }
        PriorityQueue<Integer> pq = new PriorityQueue<>((v1, v2) -> v2 - v1);
        for (int num : arr) {
            if (pq.size() < k) {
                pq.offer(num);
            } else if (num < pq.peek()) {
                pq.poll();
                pq.offer(num);
            }
        }
        return pq.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## Python实现
```python
# 快速选择方法
class Solution:
    def getLeastNumbers(self, arr: List[int], k: int) -> List[int]:
        if k == 0 or not arr:
            return []
        return self.quick_search(arr, 0, len(arr) - 1, k - 1)
    
    def quick_search(self, arr: List[int], left: int, right: int, k: int) -> List[int]:
        j = self.partition(arr, left, right)
        if j == k:
            return arr[:j + 1]
        return self.quick_search(arr, left, j - 1, k) if j > k else self.quick_search(arr, j + 1, right, k)
    
    def partition(self, arr: List[int], left: int, right: int) -> int:
        pivot = arr[left]
        i, j = left, right
        while i < j:
            while i < j and arr[j] >= pivot:
                j -= 1
            while i < j and arr[i] <= pivot:
                i += 1
            if i < j:
                arr[i], arr[j] = arr[j], arr[i]
        arr[left], arr[i] = arr[i], arr[left]
        return i

# 堆排序方法
class Solution:
    def getLeastNumbers(self, arr: List[int], k: int) -> List[int]:
        if k == 0 or not arr:
            return []
        heap = []
        for num in arr:
            if len(heap) < k:
                heapq.heappush(heap, -num)
            elif -num > heap[0]:
                heapq.heappop(heap)
                heapq.heappush(heap, -num)
        return [-x for x in heap]
```

## 复杂度分析
- 快速选择方法：
  - 时间复杂度：平均O(n)，最坏O(n²)
  - 空间复杂度：O(1)
- 堆排序方法：
  - 时间复杂度：O(nlogk)
  - 空间复杂度：O(k)
