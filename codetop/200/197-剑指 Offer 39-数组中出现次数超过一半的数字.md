# 剑指 Offer 39. 数组中出现次数超过一半的数字

- 题号：剑指 Offer 39
- 难度：简单
- LeetCode：[数组中出现次数超过一半的数字](https://leetcode.cn/problems/shu-zu-zhong-chu-xian-ci-shu-chao-guo-yi-ban-de-shu-zi-lcof/)

## 题目描述
给定数组 `nums`，返回出现次数超过数组长度一半的数字（保证存在）。

## 示例
- 示例  
输入：`nums = [1,2,3,2,2,2,5,4,2]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：Boyer-Moore 投票  
维护候选 `cand` 和计数 `count`：  
`count==0` 时更换候选；相等 `count++`，不等 `count--`。最后候选即答案。

## Java 最佳实现

```java
class Solution {
    public int majorityElement(int[] nums) {
        int cand = 0;
        int count = 0;
        for (int x : nums) {
            if (count == 0) {
                cand = x;
                count = 1;
            } else if (x == cand) {
                count++;
            } else {
                count--;
            }
        }
        return cand;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 投票法：多数元素能把其他元素抵消掉，最后留下它。
