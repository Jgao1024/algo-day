# 36进制加法

## 题目描述
实现36进制的加法，其中数字0-9和字母a-z分别表示0-35。

示例 1:
```
输入：num1 = "1b", num2 = "2x"
输出："48"
解释：1b(36) + 2x(36) = 48(36)
```

示例 2:
```
输入：num1 = "zz", num2 = "1"
输出："100"
解释：zz(36) + 1(36) = 100(36)
```

## 解题思路
1. 模拟加法：
   - 从右向左遍历两个字符串
   - 将字符转换为对应的数值
   - 处理进位
   - 时间复杂度：O(max(m,n))，空间复杂度：O(max(m,n))

2. 关键点：
   - 处理不同长度的字符串
   - 处理进位
   - 处理字符转换

## Java实现
```java
class Solution {
    public String add36(String num1, String num2) {
        StringBuilder result = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int carry = 0;
        
        while (i >= 0 || j >= 0 || carry > 0) {
            int x = i >= 0 ? getValue(num1.charAt(i)) : 0;
            int y = j >= 0 ? getValue(num2.charAt(j)) : 0;
            
            int sum = x + y + carry;
            carry = sum / 36;
            result.append(getChar(sum % 36));
            
            i--;
            j--;
        }
        
        return result.reverse().toString();
    }
    
    private int getValue(char c) {
        if (c >= '0' && c <= '9') {
            return c - '0';
        }
        return c - 'a' + 10;
    }
    
    private char getChar(int n) {
        if (n < 10) {
            return (char) (n + '0');
        }
        return (char) (n - 10 + 'a');
    }
}
```

## Python实现
```python
class Solution:
    def add36(self, num1: str, num2: str) -> str:
        def get_value(c):
            if c.isdigit():
                return int(c)
            return ord(c) - ord('a') + 10
            
        def get_char(n):
            if n < 10:
                return str(n)
            return chr(n - 10 + ord('a'))
            
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        result = []
        
        while i >= 0 or j >= 0 or carry > 0:
            x = get_value(num1[i]) if i >= 0 else 0
            y = get_value(num2[j]) if j >= 0 else 0
            
            sum_val = x + y + carry
            carry = sum_val // 36
            result.append(get_char(sum_val % 36))
            
            i -= 1
            j -= 1
            
        return ''.join(reversed(result))
```

## 复杂度分析
- 时间复杂度：O(max(m,n))，需要遍历较长的字符串
- 空间复杂度：O(max(m,n))，需要存储结果
