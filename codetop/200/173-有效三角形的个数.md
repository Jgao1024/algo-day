# 611. 有效三角形的个数

## 题目描述
给定一个包含非负整数的数组 nums，返回其中可以组成三角形三条边的三元组个数。

示例 1:
```
输入: nums = [2,2,3,4]
输出: 3
解释: 有效的组合是: 
2,3,4 (使用第一个 2)
2,3,4 (使用第二个 2)
2,2,3
```

示例 2:
```
输入: nums = [4,2,3,4]
输出: 4
```

## 解题思路
1. 排序+双指针法：
   - 先对数组排序
   - 固定最长边，使用双指针找其他两边
   - 时间复杂度：O(n²)，空间复杂度：O(1)

2. 关键点：
   - 三角形三边关系：a + b > c
   - 使用双指针优化
   - 处理重复元素

## Java实现
```java
class Solution {
    public int triangleNumber(int[] nums) {
        Arrays.sort(nums);
        int count = 0;
        
        for (int i = nums.length - 1; i >= 2; i--) {
            int left = 0;
            int right = i - 1;
            
            while (left < right) {
                if (nums[left] + nums[right] > nums[i]) {
                    count += right - left;
                    right--;
                } else {
                    left++;
                }
            }
        }
        
        return count;
    }
}
```

## Python实现
```python
class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        nums.sort()
        count = 0
        
        for i in range(len(nums) - 1, 1, -1):
            left = 0
            right = i - 1
            
            while left < right:
                if nums[left] + nums[right] > nums[i]:
                    count += right - left
                    right -= 1
                else:
                    left += 1
                    
        return count
```

## 复杂度分析
- 时间复杂度：O(n²)，需要两层循环
- 空间复杂度：O(1)，只使用常数额外空间
