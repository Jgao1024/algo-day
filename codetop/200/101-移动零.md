# 283. 移动零

## 题目描述
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

## 解题思路
1. 双指针法：
   - 使用一个指针指向当前要填入非零数的位置
   - 另一个指针遍历数组
   - 遇到非零数就交换到前面
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 优化点：
   - 避免不必要的交换
   - 处理全零数组的情况
   - 处理数组为空的情况

## Java实现
```java
class Solution {
    public void moveZeroes(int[] nums) {
        if (nums == null || nums.length == 0) {
            return;
        }
        
        int nonZeroIndex = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                if (i != nonZeroIndex) {
                    // 避免不必要的交换
                    int temp = nums[i];
                    nums[i] = nums[nonZeroIndex];
                    nums[nonZeroIndex] = temp;
                }
                nonZeroIndex++;
            }
        }
    }
}
```

## Python实现
```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        if not nums:
            return
            
        non_zero_index = 0
        for i in range(len(nums)):
            if nums[i] != 0:
                if i != non_zero_index:
                    # 避免不必要的交换
                    nums[i], nums[non_zero_index] = nums[non_zero_index], nums[i]
                non_zero_index += 1
```

## 复杂度分析
- 时间复杂度：O(n)，其中n是数组长度
- 空间复杂度：O(1)，只使用了常数额外空间
