# 670. 最大交换

## 题目描述
给定一个非负整数，你至多可以交换一次数字中的任意两位。返回你能得到的最大值。

示例 1:
```
输入: 2736
输出: 7236
解释: 交换数字2和数字7。
```

示例 2:
```
输入: 9973
输出: 9973
解释: 不需要交换。
```

## 解题思路
1. 贪心方法：
   - 从右向左遍历，记录每个位置右边最大数字的位置
   - 从左向右遍历，找到第一个可以交换的位置
   - 交换这两个位置的数字
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 只交换一次
   - 处理数字位数
   - 注意边界情况

## Java实现
```java
class Solution {
    public int maximumSwap(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        int n = digits.length;
        int[] last = new int[10];
        
        // 记录每个数字最后出现的位置
        for (int i = 0; i < n; i++) {
            last[digits[i] - '0'] = i;
        }
        
        // 从左向右遍历，找到第一个可以交换的位置
        for (int i = 0; i < n; i++) {
            // 从9开始向下找，找到第一个比当前数字大的数字
            for (int d = 9; d > digits[i] - '0'; d--) {
                if (last[d] > i) {
                    char temp = digits[i];
                    digits[i] = digits[last[d]];
                    digits[last[d]] = temp;
                    return Integer.parseInt(new String(digits));
                }
            }
        }
        
        return num;
    }
}
```

## Python实现
```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        digits = list(str(num))
        n = len(digits)
        last = {int(d): i for i, d in enumerate(digits)}
        
        for i in range(n):
            for d in range(9, int(digits[i]), -1):
                if d in last and last[d] > i:
                    digits[i], digits[last[d]] = digits[last[d]], digits[i]
                    return int(''.join(digits))
                    
        return num
```

## 复杂度分析
- 时间复杂度：O(n)，其中n是数字的位数
- 空间复杂度：O(1)，只使用了常数额外空间
