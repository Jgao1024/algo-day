# 51. N皇后

- 题号：51
- 难度：困难
- LeetCode：[N皇后](https://leetcode.cn/problems/n-queens/)

## 题目描述
在 `n x n` 棋盘上放置 `n` 个皇后，使得任意两个皇后都不在同一行、同一列、同一对角线。  
返回所有不同的摆放方案。

## 示例
- 示例  
输入：`n = 4`  
输出：`[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]`

## 最佳解法思路
- 思路1（推荐）：回溯  
一行行放皇后。用三个布尔数组快速判断冲突：  
`col[c]` 列是否占用；`diag1[row-col+n]` 主对角；`diag2[row+col]` 副对角。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> res = new ArrayList<>();
        char[][] board = new char[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) board[i][j] = '.';
        }
        boolean[] col = new boolean[n];
        boolean[] diag1 = new boolean[2 * n];
        boolean[] diag2 = new boolean[2 * n];
        dfs(0, n, board, col, diag1, diag2, res);
        return res;
    }

    private void dfs(int row, int n, char[][] board, boolean[] col, boolean[] diag1, boolean[] diag2, List<List<String>> res) {
        if (row == n) {
            List<String> one = new ArrayList<>();
            for (int i = 0; i < n; i++) one.add(new String(board[i]));
            res.add(one);
            return;
        }
        for (int c = 0; c < n; c++) {
            int d1 = row - c + n;
            int d2 = row + c;
            if (col[c] || diag1[d1] || diag2[d2]) continue;
            col[c] = diag1[d1] = diag2[d2] = true;
            board[row][c] = 'Q';
            dfs(row + 1, n, board, col, diag1, diag2, res);
            board[row][c] = '.';
            col[c] = diag1[d1] = diag2[d2] = false;
        }
    }
}
```

## 复杂度分析
- 时间：近似 \(O(n!)\)
- 空间：\(O(n)\)（标记数组 + 递归栈）

## 总结（速记）
- 回溯按行放；列/两条对角线用数组标记即可 \(O(1)\) 判冲突。
