# 395. 至少有K个重复字符的最长子串

## 题目描述
给你一个字符串 s 和一个整数 k，请你找出 s 中的最长子串，要求该子串中的每一字符出现次数都不少于 k。返回这一子串的长度。

示例 1:
```
输入：s = "aaabb", k = 3
输出：3
解释：最长子串为 "aaa" ，其中 'a' 重复了 3 次。
```

示例 2:
```
输入：s = "ababbc", k = 2
输出：5
解释：最长子串为 "ababb" ，其中 'a' 重复了 2 次， 'b' 重复了 3 次。
```

## 解题思路
1. 分治法：
   - 统计每个字符出现的次数
   - 找到第一个出现次数小于k的字符
   - 以该字符为分割点，递归处理左右两部分
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 滑动窗口法：
   - 枚举字符种类数
   - 对每种字符种类数使用滑动窗口
   - 时间复杂度：O(n)，空间复杂度：O(1)

## Java实现
```java
// 分治法
class Solution {
    public int longestSubstring(String s, int k) {
        if (s == null || s.length() < k) {
            return 0;
        }
        
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }
        
        for (int i = 0; i < s.length(); i++) {
            if (count[s.charAt(i) - 'a'] < k) {
                int left = longestSubstring(s.substring(0, i), k);
                int right = longestSubstring(s.substring(i + 1), k);
                return Math.max(left, right);
            }
        }
        
        return s.length();
    }
}

// 滑动窗口法
class Solution {
    public int longestSubstring(String s, int k) {
        int result = 0;
        int n = s.length();
        
        for (int t = 1; t <= 26; t++) {
            int[] count = new int[26];
            int total = 0;
            int less = 0;
            int left = 0;
            
            for (int right = 0; right < n; right++) {
                int c = s.charAt(right) - 'a';
                count[c]++;
                
                if (count[c] == 1) {
                    total++;
                    less++;
                }
                if (count[c] == k) {
                    less--;
                }
                
                while (total > t) {
                    int d = s.charAt(left) - 'a';
                    count[d]--;
                    if (count[d] == 0) {
                        total--;
                        less--;
                    }
                    if (count[d] == k - 1) {
                        less++;
                    }
                    left++;
                }
                
                if (less == 0) {
                    result = Math.max(result, right - left + 1);
                }
            }
        }
        
        return result;
    }
}
```

## Python实现
```python
# 分治法
class Solution:
    def longestSubstring(self, s: str, k: int) -> int:
        if not s or len(s) < k:
            return 0
            
        count = collections.Counter(s)
        
        for i, char in enumerate(s):
            if count[char] < k:
                left = self.longestSubstring(s[:i], k)
                right = self.longestSubstring(s[i+1:], k)
                return max(left, right)
                
        return len(s)

# 滑动窗口法
class Solution:
    def longestSubstring(self, s: str, k: int) -> int:
        result = 0
        n = len(s)
        
        for t in range(1, 27):
            count = [0] * 26
            total = less = 0
            left = 0
            
            for right in range(n):
                c = ord(s[right]) - ord('a')
                count[c] += 1
                
                if count[c] == 1:
                    total += 1
                    less += 1
                if count[c] == k:
                    less -= 1
                    
                while total > t:
                    d = ord(s[left]) - ord('a')
                    count[d] -= 1
                    if count[d] == 0:
                        total -= 1
                        less -= 1
                    if count[d] == k - 1:
                        less += 1
                    left += 1
                    
                if less == 0:
                    result = max(result, right - left + 1)
                    
        return result
```

## 复杂度分析
- 分治法：
  - 时间复杂度：O(n)，其中n为字符串长度
  - 空间复杂度：O(1)，使用常数额外空间
- 滑动窗口法：
  - 时间复杂度：O(n)，其中n为字符串长度
  - 空间复杂度：O(1)，使用常数额外空间
