# 面试题 02.05. 链表求和

- 题号：面试题 02.05
- 难度：中等
- LeetCode：[链表求和](https://leetcode.cn/problems/sum-lists-lcci/)

## 题目描述
两个链表分别表示两个整数（低位在前）。请把它们相加，并以同样的链表形式返回结果（低位在前）。

## 示例
- 示例  
输入：`(7 -> 1 -> 6) + (5 -> 9 -> 2)`  
输出：`2 -> 1 -> 9`

## 最佳解法思路
- 思路1（推荐）：模拟加法 + 进位  
双指针遍历两个链表，逐位相加并处理 `carry`，用哑节点构造新链表。

## Java 最佳实现

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int a = l1 != null ? l1.val : 0;
            int b = l2 != null ? l2.val : 0;
            int sum = a + b + carry;
            cur.next = new ListNode(sum % 10);
            cur = cur.next;
            carry = sum / 10;
            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(\max(m,n))\)
- 空间：\(O(\max(m,n))\)

## 总结（速记）
- 链表加法：`sum%10` 做当前位，`sum/10` 做进位，循环条件把 `carry` 也算上。
