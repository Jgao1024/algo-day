# 678. 有效的括号字符串

## 题目描述
给定一个只包含三种字符的字符串：（，）和 *，写一个函数来检验这个字符串是否为有效字符串。有效字符串具有如下规则：

1. 任何左括号 ( 必须有对应的右括号 )。
2. 任何右括号 ) 必须有对应的左括号 (。
3. 左括号 ( 必须在对应的右括号之前 )。
4. * 可以被视为单个右括号 )，或单个左括号 (，或一个空字符串。
5. 一个空字符串也被视为有效字符串。

示例 1:
```
输入: "()"
输出: True
```

示例 2:
```
输入: "(*)"
输出: True
```

## 解题思路
1. 贪心方法：
   - 使用两个变量记录左括号的最小和最大可能数量
   - 遇到左括号，最小和最大都加1
   - 遇到右括号，最小和最大都减1
   - 遇到星号，最小减1，最大加1
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 处理星号的多种可能性
   - 维护最小和最大左括号数量
   - 处理边界情况

## Java实现
```java
class Solution {
    public boolean checkValidString(String s) {
        int min = 0;  // 最小左括号数量
        int max = 0;  // 最大左括号数量
        
        for (char c : s.toCharArray()) {
            if (c == '(') {
                min++;
                max++;
            } else if (c == ')') {
                min = Math.max(0, min - 1);
                max--;
                if (max < 0) return false;
            } else {  // '*'
                min = Math.max(0, min - 1);
                max++;
            }
        }
        
        return min == 0;
    }
}
```

## Python实现
```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        min_count = 0  # 最小左括号数量
        max_count = 0  # 最大左括号数量
        
        for c in s:
            if c == '(':
                min_count += 1
                max_count += 1
            elif c == ')':
                min_count = max(0, min_count - 1)
                max_count -= 1
                if max_count < 0:
                    return False
            else:  # '*'
                min_count = max(0, min_count - 1)
                max_count += 1
                
        return min_count == 0
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历字符串一次
- 空间复杂度：O(1)，只使用常数额外空间
