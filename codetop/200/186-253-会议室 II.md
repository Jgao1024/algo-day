# 253. 会议室 II

- 题号：253
- 难度：中等
- LeetCode：[会议室 II](https://leetcode.cn/problems/meeting-rooms-ii/)

## 题目描述
给定会议时间区间数组 `intervals`，返回至少需要多少个会议室才能安排所有会议（区间可能重叠）。

## 示例
- 示例  
输入：`intervals = [[0,30],[5,10],[15,20]]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：起止时间分离 + 双指针  
分别取所有 `start`、`end` 排序。  
遍历每个开始时间：  
若 `start < end[endIdx]`，说明当前最早结束的会议还没结束，需要新房间；否则复用一个房间（`endIdx++`）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        int n = intervals.length;
        int[] starts = new int[n];
        int[] ends = new int[n];
        for (int i = 0; i < n; i++) {
            starts[i] = intervals[i][0];
            ends[i] = intervals[i][1];
        }
        Arrays.sort(starts);
        Arrays.sort(ends);

        int endIdx = 0;
        int rooms = 0;
        for (int i = 0; i < n; i++) {
            if (starts[i] < ends[endIdx]) {
                rooms++;
            } else {
                endIdx++;
            }
        }
        return rooms;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
