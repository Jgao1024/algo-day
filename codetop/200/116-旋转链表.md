# 61. 旋转链表

## 题目描述
给定一个链表的头节点 head，旋转链表，将链表每个节点向右移动 k 个位置。

示例 1:
```
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

示例 2:
```
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

## 解题思路
1. 快慢指针方法：
   - 计算链表长度
   - 将k对链表长度取模，避免重复旋转
   - 使用快慢指针找到旋转点
   - 重新连接链表
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 处理k大于链表长度的情况
   - 处理空链表和单节点链表
   - 找到正确的旋转点
   - 正确断开和重连链表

## Java实现
```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) {
            return head;
        }
        
        // 计算链表长度
        int len = 1;
        ListNode tail = head;
        while (tail.next != null) {
            tail = tail.next;
            len++;
        }
        
        // 计算实际需要旋转的次数
        k = k % len;
        if (k == 0) {
            return head;
        }
        
        // 找到旋转点
        ListNode slow = head;
        ListNode fast = head;
        for (int i = 0; i < k; i++) {
            fast = fast.next;
        }
        while (fast.next != null) {
            slow = slow.next;
            fast = fast.next;
        }
        
        // 重新连接链表
        ListNode newHead = slow.next;
        slow.next = null;
        tail.next = head;
        
        return newHead;
    }
}
```

## Python实现
```python
class Solution:
    def rotateRight(self, head: ListNode, k: int) -> ListNode:
        if not head or not head.next or k == 0:
            return head
            
        # 计算链表长度
        length = 1
        tail = head
        while tail.next:
            tail = tail.next
            length += 1
            
        # 计算实际需要旋转的次数
        k = k % length
        if k == 0:
            return head
            
        # 找到旋转点
        slow = fast = head
        for _ in range(k):
            fast = fast.next
        while fast.next:
            slow = slow.next
            fast = fast.next
            
        # 重新连接链表
        new_head = slow.next
        slow.next = None
        tail.next = head
        
        return new_head
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历链表两次
- 空间复杂度：O(1)，只使用常数额外空间
