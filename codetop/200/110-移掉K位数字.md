# 402. 移掉K位数字

## 题目描述
给定一个以字符串表示的非负整数 num 和一个整数 k，移除这个数中的 k 位数字，使得剩下的数字最小。

示例 1:
```
输入：num = "1432219", k = 3
输出："1219"
解释：移除掉三个数字 4, 3, 和 2 形成一个新的最小的数字 1219。
```

示例 2:
```
输入：num = "10200", k = 1
输出："200"
解释：移掉首位的 1 剩下的数字为 200。
```

## 解题思路
1. 贪心 + 单调栈方法：
   - 使用单调递增栈存储数字
   - 遍历字符串，对于每个数字，如果比栈顶数字小且还能删除数字，则弹出栈顶
   - 最后处理剩余需要删除的数字
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 关键点：
   - 处理前导零
   - 处理删除次数不足的情况
   - 处理结果为空的情况

## Java实现
```java
class Solution {
    public String removeKdigits(String num, int k) {
        if (num.length() == k) return "0";
        
        StringBuilder stack = new StringBuilder();
        for (char digit : num.toCharArray()) {
            while (k > 0 && stack.length() > 0 && stack.charAt(stack.length() - 1) > digit) {
                stack.deleteCharAt(stack.length() - 1);
                k--;
            }
            stack.append(digit);
        }
        
        // 处理剩余需要删除的数字
        while (k > 0) {
            stack.deleteCharAt(stack.length() - 1);
            k--;
        }
        
        // 处理前导零
        while (stack.length() > 1 && stack.charAt(0) == '0') {
            stack.deleteCharAt(0);
        }
        
        return stack.toString();
    }
}
```

## Python实现
```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        if len(num) == k:
            return "0"
            
        stack = []
        for digit in num:
            while k > 0 and stack and stack[-1] > digit:
                stack.pop()
                k -= 1
            stack.append(digit)
            
        # 处理剩余需要删除的数字
        while k > 0:
            stack.pop()
            k -= 1
            
        # 处理前导零
        while len(stack) > 1 and stack[0] == '0':
            stack.pop(0)
            
        return ''.join(stack)
```

## 复杂度分析
- 时间复杂度：O(n)，每个元素最多入栈和出栈一次
- 空间复杂度：O(n)，最坏情况下需要存储所有元素
