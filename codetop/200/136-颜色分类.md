# 75. 颜色分类

## 题目描述
给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色的顺序排列。我们使用整数 0、1 和 2 分别表示红色、白色和蓝色。

示例 1：
```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

示例 2：
```
输入：nums = [2,0,1]
输出：[0,1,2]
```

## 解题思路
1. 三指针：
   - 使用三个指针：left、right和curr
   - left指向0的右边界，right指向2的左边界
   - curr用于遍历数组
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 指针移动
   - 元素交换
   - 边界条件
   - 原地排序

## Java实现
```java
class Solution {
    public void sortColors(int[] nums) {
        int left = 0, right = nums.length - 1;
        int curr = 0;
        
        while (curr <= right) {
            if (nums[curr] == 0) {
                // 交换curr和left指向的元素
                swap(nums, curr, left);
                left++;
                curr++;
            } else if (nums[curr] == 2) {
                // 交换curr和right指向的元素
                swap(nums, curr, right);
                right--;
            } else {
                curr++;
            }
        }
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

## Python实现
```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        left, right = 0, len(nums) - 1
        curr = 0
        
        while curr <= right:
            if nums[curr] == 0:
                # 交换curr和left指向的元素
                nums[curr], nums[left] = nums[left], nums[curr]
                left += 1
                curr += 1
            elif nums[curr] == 2:
                # 交换curr和right指向的元素
                nums[curr], nums[right] = nums[right], nums[curr]
                right -= 1
            else:
                curr += 1
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为数组长度
- 空间复杂度：O(1)，只使用常数额外空间
