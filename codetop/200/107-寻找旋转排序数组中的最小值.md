# 153. 寻找旋转排序数组中的最小值

## 题目描述
已知一个长度为 n 的升序数组在预先未知的某个点上进行了旋转，找出其中最小的元素。

## 解题思路
1. 二分查找：
   - 比较中间元素和右端点
   - 若中间元素大于右端点，最小值在右半部分
   - 否则在左半部分
   - 时间复杂度：O(log n)

2. 关键点：
   - 处理无旋转的情况
   - 处理只有一个元素的情况

## Java实现
```java
class Solution {
    public int findMin(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[right]) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return nums[left];
    }
}
```

## Python实现
```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid
        return nums[left]
```

## 复杂度分析
- 时间复杂度：O(log n)
- 空间复杂度：O(1)
