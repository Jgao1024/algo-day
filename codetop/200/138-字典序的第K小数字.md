# 440. 字典序的第K小数字

## 题目描述
给定整数 n 和 k，找到 1 到 n 中字典序第 k 小的数字。

示例 1：
```
输入：n = 13, k = 2
输出：10
解释：字典序为 [1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]，所以第二小的数字是 10。
```

示例 2：
```
输入：n = 1, k = 1
输出：1
```

## 解题思路
1. 字典树：
   - 将数字看作字典树
   - 计算每个前缀下的数字个数
   - 根据k值确定目标数字
   - 时间复杂度：O(log²n)，空间复杂度：O(1)

2. 关键点：
   - 字典树遍历
   - 数字计数
   - 边界处理
   - 前缀计算

## Java实现
```java
class Solution {
    public int findKthNumber(int n, int k) {
        int curr = 1;
        k--;
        
        while (k > 0) {
            int steps = getSteps(curr, curr + 1, n);
            if (steps <= k) {
                curr++;
                k -= steps;
            } else {
                curr *= 10;
                k--;
            }
        }
        
        return curr;
    }
    
    private int getSteps(long curr, long next, int n) {
        int steps = 0;
        while (curr <= n) {
            steps += Math.min(next, n + 1) - curr;
            curr *= 10;
            next *= 10;
        }
        return steps;
    }
}
```

## Python实现
```python
class Solution:
    def findKthNumber(self, n: int, k: int) -> int:
        curr = 1
        k -= 1
        
        while k > 0:
            steps = self.getSteps(curr, curr + 1, n)
            if steps <= k:
                curr += 1
                k -= steps
            else:
                curr *= 10
                k -= 1
                
        return curr
        
    def getSteps(self, curr: int, next: int, n: int) -> int:
        steps = 0
        while curr <= n:
            steps += min(next, n + 1) - curr
            curr *= 10
            next *= 10
        return steps
```

- 时间复杂度：O(log²n)，其中n为数字范围
- 空间复杂度：O(1)，只使用常数额外空间
