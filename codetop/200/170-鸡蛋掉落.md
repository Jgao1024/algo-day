# 887. 鸡蛋掉落

## 题目描述
给你 k 枚相同的鸡蛋，并可以使用一栋从第 1 层到第 n 层共有 n 层楼的建筑。

已知存在楼层 f，满足 0 <= f <= n，任何从高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 x 扔下（满足 1 <= x <= n）。如果鸡蛋碎了，你就不能再次使用它。如果某枚鸡蛋扔下后没有摔碎，则可以在之后的操作中重复使用这枚鸡蛋。

请你计算并返回要确定 f 确切的值的最小操作次数是多少？

示例 1:
```
输入：k = 1, n = 2
输出：2
解释：
鸡蛋从 1 楼掉落。如果它碎了，肯定能确定 f = 0 。
否则，鸡蛋从 2 楼掉落。如果它碎了，肯定能确定 f = 1 。
如果它没碎，那么肯定能确定 f = 2 。
因此，在最坏的情况下我们需要移动 2 次以确定 f 是多少。
```

示例 2:
```
输入：k = 2, n = 6
输出：3
```

## 解题思路
1. 动态规划方法：
   - 定义dp[k][m]表示k个鸡蛋，m次操作最多可以确定的楼层数
   - dp[k][m] = dp[k-1][m-1] + dp[k][m-1] + 1
   - 时间复杂度：O(k*n)，空间复杂度：O(k*n)

2. 关键点：
   - 理解状态转移方程
   - 使用动态规划
   - 优化空间复杂度

## Java实现
```java
class Solution {
    public int superEggDrop(int k, int n) {
        int[][] dp = new int[k + 1][n + 1];
        int m = 0;
        
        while (dp[k][m] < n) {
            m++;
            for (int i = 1; i <= k; i++) {
                dp[i][m] = dp[i-1][m-1] + dp[i][m-1] + 1;
            }
        }
        
        return m;
    }
}
```

## Python实现
```python
class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        dp = [[0] * (n + 1) for _ in range(k + 1)]
        m = 0
        
        while dp[k][m] < n:
            m += 1
            for i in range(1, k + 1):
                dp[i][m] = dp[i-1][m-1] + dp[i][m-1] + 1
                
        return m
```

## 复杂度分析
- 时间复杂度：O(k*n)，需要填充dp表
- 空间复杂度：O(k*n)，需要存储dp表
