# 补充题9. 36进制加法

- 题号：补充题9
- 难度：中等
- LeetCode：[36进制加法](https://leetcode.cn/problems/https://mp.weixin.qq.com/s/XcKQwnwCh5nZsz-DLHJwzQ/)

## 题目描述
给定两个 36 进制的非负整数字符串（`0-9` + `a-z`/`A-Z`），返回它们的 36 进制和（小写输出）。

## 示例
- 示例  
输入：`"1z" + "2"`  
输出：`"21"`

## 最佳解法思路
- 思路1（推荐）：模拟竖式加法  
从末位开始逐位相加，`sum = a + b + carry`，当前位为 `sum % 36`，进位为 `sum / 36`。

## Java 最佳实现

```java
class Solution {
    public String add36(String a, String b) {
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;
        StringBuilder sb = new StringBuilder();
        while (i >= 0 || j >= 0 || carry != 0) {
            int x = i >= 0 ? val(a.charAt(i--)) : 0;
            int y = j >= 0 ? val(b.charAt(j--)) : 0;
            int sum = x + y + carry;
            sb.append(digit(sum % 36));
            carry = sum / 36;
        }
        return sb.reverse().toString();
    }

    private int val(char c) {
        if (c >= '0' && c <= '9') return c - '0';
        if (c >= 'a' && c <= 'z') return c - 'a' + 10;
        return c - 'A' + 10;
    }

    private char digit(int v) {
        if (v < 10) return (char) ('0' + v);
        return (char) ('a' + (v - 10));
    }
}
```

- 时间：\(O(\max(m,n))\)
- 空间：\(O(\max(m,n))\)
