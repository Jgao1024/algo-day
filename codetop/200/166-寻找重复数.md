# 287. 寻找重复数

## 题目描述
给定一个包含 n + 1 个整数的数组 nums，其数字都在 1 到 n 之间（包括 1 和 n），可知至少存在一个重复的整数。假设 nums 只有一个重复的整数，找出这个重复的数。

示例 1:
```
输入：nums = [1,3,4,2,2]
输出：2
```

示例 2:
```
输入：nums = [3,1,3,4,2]
输出：3
```

## 解题思路
1. 快慢指针法：
   - 将数组看作链表，数组下标作为节点，数组值作为下一个节点的索引
   - 使用快慢指针找到环的入口点
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 理解数组到链表的映射
   - 使用快慢指针找环
   - 处理边界情况

## Java实现
```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0];
        int fast = nums[0];
        
        // 找到相遇点
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);
        
        // 找到环的入口
        slow = nums[0];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        
        return slow;
    }
}
```

## Python实现
```python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[0]
        
        # 找到相遇点
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
                
        # 找到环的入口
        slow = nums[0]
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
            
        return slow
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历数组
- 空间复杂度：O(1)，只使用常数额外空间
