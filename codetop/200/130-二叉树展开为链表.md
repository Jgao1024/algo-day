# 114. 二叉树展开为链表

## 题目描述
给你二叉树的根结点 root，请你将它展开为一个单链表：
1. 展开后的单链表应该同样使用 TreeNode，其中 right 子指针指向链表中下一个结点，而 left 子指针始终为 null。
2. 展开后的单链表应该与二叉树先序遍历顺序相同。

示例：
```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

## 解题思路
1. 递归方法：
   - 使用后序遍历，先处理左右子树
   - 将左子树接到右子树位置
   - 将原右子树接到左子树最右节点
   - 时间复杂度：O(n)，空间复杂度：O(h)

2. 关键点：
   - 后序遍历
   - 保存右子树
   - 连接左子树
   - 边界条件处理

## Java实现
```java
class Solution {
    public void flatten(TreeNode root) {
        if (root == null) {
            return;
        }
        
        // 后序遍历
        flatten(root.left);
        flatten(root.right);
        
        // 保存右子树
        TreeNode right = root.right;
        
        // 将左子树接到右子树位置
        root.right = root.left;
        root.left = null;
        
        // 找到当前右子树的最右节点
        TreeNode curr = root;
        while (curr.right != null) {
            curr = curr.right;
        }
        
        // 将原右子树接到最右节点
        curr.right = right;
    }
}
```

## Python实现
```python
class Solution:
    def flatten(self, root: TreeNode) -> None:
        if not root:
            return
            
        # 后序遍历
        self.flatten(root.left)
        self.flatten(root.right)
        
        # 保存右子树
        right = root.right
        
        # 将左子树接到右子树位置
        root.right = root.left
        root.left = None
        
        # 找到当前右子树的最右节点
        curr = root
        while curr.right:
            curr = curr.right
            
        # 将原右子树接到最右节点
        curr.right = right
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为二叉树节点数
- 空间复杂度：O(h)，其中h为二叉树高度
