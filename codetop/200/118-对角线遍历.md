# 498. 对角线遍历

## 题目描述
给定一个含有 M x N 个元素的矩阵（M 行，N 列），请以对角线遍历的顺序返回这个矩阵中的所有元素。

示例 1:
```
输入：mat = [[1,2,3],
            [4,5,6],
            [7,8,9]]
输出：[1,2,4,7,5,3,6,8,9]
```

示例 2:
```
输入：mat = [[1,2],
            [3,4]]
输出：[1,2,3,4]
```

## 解题思路
1. 模拟方法：
   - 观察对角线遍历的规律
   - 偶数对角线向上遍历，奇数对角线向下遍历
   - 处理边界情况
   - 时间复杂度：O(m*n)，空间复杂度：O(1)

2. 关键点：
   - 对角线方向交替
   - 边界条件处理
   - 坐标变化规律
   - 结果数组的构建

## Java实现
```java
class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        if (mat == null || mat.length == 0) {
            return new int[0];
        }
        
        int m = mat.length;
        int n = mat[0].length;
        int[] result = new int[m * n];
        int row = 0, col = 0;
        
        for (int i = 0; i < result.length; i++) {
            result[i] = mat[row][col];
            
            // 偶数对角线向上遍历
            if ((row + col) % 2 == 0) {
                if (col == n - 1) {
                    row++;
                } else if (row == 0) {
                    col++;
                } else {
                    row--;
                    col++;
                }
            } 
            // 奇数对角线向下遍历
            else {
                if (row == m - 1) {
                    col++;
                } else if (col == 0) {
                    row++;
                } else {
                    row++;
                    col--;
                }
            }
        }
        
        return result;
    }
}
```

## Python实现
```python
class Solution:
    def findDiagonalOrder(self, mat: List[List[int]]) -> List[int]:
        if not mat or not mat[0]:
            return []
            
        m, n = len(mat), len(mat[0])
        result = []
        row = col = 0
        
        for i in range(m * n):
            result.append(mat[row][col])
            
            # 偶数对角线向上遍历
            if (row + col) % 2 == 0:
                if col == n - 1:
                    row += 1
                elif row == 0:
                    col += 1
                else:
                    row -= 1
                    col += 1
            # 奇数对角线向下遍历
            else:
                if row == m - 1:
                    col += 1
                elif col == 0:
                    row += 1
                else:
                    row += 1
                    col -= 1
                    
        return result
```

## 复杂度分析
- 时间复杂度：O(m*n)，需要遍历矩阵中的每个元素
- 空间复杂度：O(1)，不考虑输出数组的空间
