# 剑指 Offer 21. 调整数组顺序使奇数位于偶数前面

## 题目描述
输入一个整数数组，实现一个函数来调整该数组中数字的顺序，使得所有奇数位于数组的前半部分，所有偶数位于数组的后半部分。

示例 1:
```
输入：nums = [1,2,3,4]
输出：[1,3,2,4] 
注：[3,1,2,4] 也是正确的答案之一。
```

示例 2:
```
输入：nums = [2,4,6,8]
输出：[2,4,6,8]
```

## 解题思路
1. 双指针法：
   - 使用左右指针，左指针找偶数，右指针找奇数
   - 交换左右指针指向的元素
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 使用双指针
   - 处理边界情况
   - 保持相对顺序

## Java实现
```java
class Solution {
    public int[] exchange(int[] nums) {
        int left = 0;
        int right = nums.length - 1;
        
        while (left < right) {
            // 找到左边的偶数
            while (left < right && nums[left] % 2 == 1) {
                left++;
            }
            // 找到右边的奇数
            while (left < right && nums[right] % 2 == 0) {
                right--;
            }
            // 交换
            if (left < right) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
            }
        }
        
        return nums;
    }
}
```

## Python实现
```python
class Solution:
    def exchange(self, nums: List[int]) -> List[int]:
        left, right = 0, len(nums) - 1
        
        while left < right:
            # 找到左边的偶数
            while left < right and nums[left] % 2 == 1:
                left += 1
            # 找到右边的奇数
            while left < right and nums[right] % 2 == 0:
                right -= 1
            # 交换
            if left < right:
                nums[left], nums[right] = nums[right], nums[left]
                
        return nums
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历数组一次
- 空间复杂度：O(1)，只使用常数额外空间
