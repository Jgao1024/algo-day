# 264. 丑数 II

## 题目描述
给你一个整数 n，请你找出并返回第 n 个丑数。丑数就是只包含质因数 2、3 和/或 5 的正整数。

示例 1:
```
输入：n = 10
输出：12
解释：[1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是由前 10 个丑数组成的序列。
```

示例 2:
```
输入：n = 1
输出：1
解释：1 通常被视为丑数。
```

## 解题思路
1. 动态规划法：
   - 使用三个指针p2、p3、p5分别指向下一个要乘以2、3、5的数
   - 每次取三个指针指向的数乘以对应因子后的最小值
   - 更新对应的指针
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 关键点：
   - 使用三个指针避免重复计算
   - 处理重复数字的情况
   - 初始化第一个丑数为1

## Java实现
```java
class Solution {
    public int nthUglyNumber(int n) {
        int[] dp = new int[n];
        dp[0] = 1;
        
        int p2 = 0, p3 = 0, p5 = 0;
        
        for (int i = 1; i < n; i++) {
            int num2 = dp[p2] * 2;
            int num3 = dp[p3] * 3;
            int num5 = dp[p5] * 5;
            
            dp[i] = Math.min(Math.min(num2, num3), num5);
            
            if (dp[i] == num2) p2++;
            if (dp[i] == num3) p3++;
            if (dp[i] == num5) p5++;
        }
        
        return dp[n-1];
    }
}
```

## Python实现
```python
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        dp = [1] * n
        p2 = p3 = p5 = 0
        
        for i in range(1, n):
            num2 = dp[p2] * 2
            num3 = dp[p3] * 3
            num5 = dp[p5] * 5
            
            dp[i] = min(num2, num3, num5)
            
            if dp[i] == num2:
                p2 += 1
            if dp[i] == num3:
                p3 += 1
            if dp[i] == num5:
                p5 += 1
                
        return dp[-1]
```

## 复杂度分析
- 时间复杂度：O(n)，需要计算n个丑数
- 空间复杂度：O(n)，需要存储n个丑数
