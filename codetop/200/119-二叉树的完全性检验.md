# 958. 二叉树的完全性检验

## 题目描述
给定一个二叉树，确定它是否是一个完全二叉树。

示例 1:
```
输入：[1,2,3,4,5,6]
输出：true
解释：最后一层前的节点都是满的，且最后一层的节点都靠左。
```

示例 2:
```
输入：[1,2,3,4,5,null,7]
输出：false
解释：最后一层的节点没有靠左。
```

## 解题思路
1. 层序遍历方法：
   - 使用队列进行层序遍历
   - 记录是否遇到空节点
   - 如果遇到空节点后还有非空节点，则不是完全二叉树
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 关键点：
   - 层序遍历
   - 空节点的处理
   - 最后一层的判断
   - 队列的使用

## Java实现
```java
class Solution {
    public boolean isCompleteTree(TreeNode root) {
        if (root == null) {
            return true;
        }
        
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        boolean flag = false;
        
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            
            if (node == null) {
                flag = true;
            } else {
                if (flag) {
                    return false;
                }
                queue.offer(node.left);
                queue.offer(node.right);
            }
        }
        
        return true;
    }
}
```

## Python实现
```python
class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        if not root:
            return True
            
        queue = collections.deque([root])
        flag = False
        
        while queue:
            node = queue.popleft()
            
            if not node:
                flag = True
            else:
                if flag:
                    return False
                queue.append(node.left)
                queue.append(node.right)
                
        return True
```

## 复杂度分析
- 时间复杂度：O(n)，需要访问每个节点一次
- 空间复杂度：O(n)，队列中最多存储n个节点
