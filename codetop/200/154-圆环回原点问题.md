# 补充题2. 圆环回原点问题

## 题目描述
一个圆环上有10个点，编号为0~9。从0点出发，每次可以逆时针和顺时针走一步，问走n步回到0点共有多少种走法。

示例 1：
```
输入：n = 2
输出：2
解释：有两种走法：0->1->0 和 0->9->0
```

示例 2：
```
输入：n = 3
输出：0
解释：走3步无法回到原点
```

## 解题思路
1. 动态规划方法：
   - 定义dp[i][j]表示走i步到达j点的方案数
   - 状态转移方程：dp[i][j] = dp[i-1][(j-1+10)%10] + dp[i-1][(j+1)%10]
   - 初始条件：dp[0][0] = 1
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 状态转移方程
   - 取模运算
   - 空间优化
   - 边界条件

## Java实现
```java
class Solution {
    public int backToOrigin(int n) {
        if (n == 0) return 1;
        
        int[] dp = new int[10];
        dp[0] = 1;
        
        for (int i = 0; i < n; i++) {
            int[] next = new int[10];
            for (int j = 0; j < 10; j++) {
                next[j] = dp[(j - 1 + 10) % 10] + dp[(j + 1) % 10];
            }
            dp = next;
        }
        
        return dp[0];
    }
}
```

## Python实现
```python
class Solution:
    def backToOrigin(self, n: int) -> int:
        if n == 0:
            return 1
        
        dp = [0] * 10
        dp[0] = 1
        
        for _ in range(n):
            next_dp = [0] * 10
            for j in range(10):
                next_dp[j] = dp[(j - 1) % 10] + dp[(j + 1) % 10]
            dp = next_dp
        
        return dp[0]
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为步数
- 空间复杂度：O(1)，只使用常数额外空间
