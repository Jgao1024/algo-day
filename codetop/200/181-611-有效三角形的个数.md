# 611. 有效三角形的个数

- 题号：611
- 难度：中等
- LeetCode：[有效三角形的个数](https://leetcode.cn/problems/valid-triangle-number/)

## 题目描述
给定非负整数数组 `nums`，统计可以组成三角形的三元组数量。  
三角形判定：若三边为 \(a \le b \le c\)，需要满足 \(a + b > c\)。

## 示例
- 示例  
输入：`nums = [2,2,3,4]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：排序 + 双指针  
先排序。固定最大边 `c = nums[k]`，用双指针在 `[0..k-1]` 找满足 `nums[i] + nums[j] > nums[k]` 的组合：  
若成立，则 `i..j-1` 都能与 `j,k` 组成三角形，计数加 `j - i`，然后 `j--`；否则 `i++`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int triangleNumber(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int ans = 0;
        for (int k = n - 1; k >= 2; k--) {
            int i = 0, j = k - 1;
            while (i < j) {
                if (nums[i] + nums[j] > nums[k]) {
                    ans += (j - i);
                    j--;
                } else {
                    i++;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)（排序 \(O(n\log n)\) + 双指针）
- 空间：\(O(1)\)（不计排序栈）

## 总结（速记）
- 固定最大边 \(c\)，用 `i/j` 逼近：满足时一次性加 `j-i`。
