# 230. 二叉搜索树中第K小的元素

## 题目描述
给定一个二叉搜索树的根节点 root，和一个整数 k，请你设计一个算法查找其中第 k 个最小元素（从 1 开始计数）。

示例 1：
```
输入：root = [3,1,4,null,2], k = 1
   3
  / \
 1   4
  \
   2
输出：1
```

示例 2：
```
输入：root = [5,3,6,2,4,null,null,1], k = 3
       5
      / \
     3   6
    / \
   2   4
  /
 1
输出：3
```

## 解题思路
1. 中序遍历方法：
   - 二叉搜索树的中序遍历是升序的
   - 使用中序遍历找到第k个元素
   - 可以使用递归或迭代实现
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 关键点：
   - 中序遍历
   - 计数器的使用
   - 提前返回优化
   - 递归终止条件

## Java实现
```java
// 递归方法
class Solution {
    private int count = 0;
    private int result = 0;
    
    public int kthSmallest(TreeNode root, int k) {
        count = k;
        inorder(root);
        return result;
    }
    
    private void inorder(TreeNode root) {
        if (root == null || count == 0) return;
        
        inorder(root.left);
        if (--count == 0) {
            result = root.val;
            return;
        }
        inorder(root.right);
    }
}

// 迭代方法
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Stack<TreeNode> stack = new Stack<>();
        TreeNode curr = root;
        
        while (curr != null || !stack.isEmpty()) {
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            
            curr = stack.pop();
            if (--k == 0) {
                return curr.val;
            }
            curr = curr.right;
        }
        
        return -1;
    }
}
```

## Python实现
```python
# 递归方法
class Solution:
    def kthSmallest(self, root: TreeNode, k: int) -> int:
        self.count = k
        self.result = 0
        
        def inorder(root: TreeNode) -> None:
            if not root or self.count == 0:
                return
            
            inorder(root.left)
            self.count -= 1
            if self.count == 0:
                self.result = root.val
                return
            inorder(root.right)
        
        inorder(root)
        return self.result

# 迭代方法
class Solution:
    def kthSmallest(self, root: TreeNode, k: int) -> int:
        stack = []
        curr = root
        
        while curr or stack:
            while curr:
                stack.append(curr)
                curr = curr.left
            
            curr = stack.pop()
            k -= 1
            if k == 0:
                return curr.val
            curr = curr.right
        
        return -1
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为二叉搜索树的节点数
- 空间复杂度：O(n)，最坏情况下需要存储所有节点
