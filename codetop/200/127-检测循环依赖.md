# 补充题23. 检测循环依赖

## 题目描述
给定一个项目依赖关系图，判断是否存在循环依赖。每个项目都有一个唯一的标识符，依赖关系用有向图表示。

示例 1：
```
输入：dependencies = [[0,1],[1,2],[2,0]]
输出：true
解释：存在循环依赖 0->1->2->0
```

示例 2：
```
输入：dependencies = [[0,1],[1,2],[2,3]]
输出：false
解释：不存在循环依赖
```

## 解题思路
1. 拓扑排序：
   - 使用深度优先搜索(DFS)检测环
   - 维护访问状态：未访问、访问中、已访问
   - 时间复杂度：O(V+E)，空间复杂度：O(V)

2. 关键点：
   - 构建邻接表
   - 状态标记
   - 环的检测
   - 边界条件处理

## Java实现
```java
class Solution {
    public boolean hasCycle(int[][] dependencies) {
        // 构建邻接表
        Map<Integer, List<Integer>> graph = new HashMap<>();
        for (int[] dep : dependencies) {
            graph.computeIfAbsent(dep[0], k -> new ArrayList<>()).add(dep[1]);
        }
        
        // 状态数组：0-未访问，1-访问中，2-已访问
        int[] visited = new int[graph.size()];
        
        // 对每个节点进行DFS
        for (int node : graph.keySet()) {
            if (visited[node] == 0 && hasCycleDFS(node, graph, visited)) {
                return true;
            }
        }
        
        return false;
    }
    
    private boolean hasCycleDFS(int node, Map<Integer, List<Integer>> graph, int[] visited) {
        visited[node] = 1; // 标记为访问中
        
        for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
            if (visited[neighbor] == 1) {
                return true; // 发现环
            }
            if (visited[neighbor] == 0 && hasCycleDFS(neighbor, graph, visited)) {
                return true;
            }
        }
        
        visited[node] = 2; // 标记为已访问
        return false;
    }
}
```

## Python实现
```python
class Solution:
    def hasCycle(self, dependencies: List[List[int]]) -> bool:
        # 构建邻接表
        graph = defaultdict(list)
        for dep in dependencies:
            graph[dep[0]].append(dep[1])
            
        # 状态数组：0-未访问，1-访问中，2-已访问
        visited = [0] * len(graph)
        
        def dfs(node):
            visited[node] = 1  # 标记为访问中
            
            for neighbor in graph[node]:
                if visited[neighbor] == 1:
                    return True  # 发现环
                if visited[neighbor] == 0 and dfs(neighbor):
                    return True
                    
            visited[node] = 2  # 标记为已访问
            return False
            
        # 对每个节点进行DFS
        for node in graph:
            if visited[node] == 0 and dfs(node):
                return True
                
        return False
```

## 复杂度分析
- 时间复杂度：O(V+E)，其中V为节点数，E为边数
- 空间复杂度：O(V)，需要存储访问状态和递归调用栈
