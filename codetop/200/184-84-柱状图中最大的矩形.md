# 84. 柱状图中最大的矩形

- 题号：84
- 难度：困难
- LeetCode：[柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)

## 题目描述
给定柱状图高度数组 `heights`，每个柱宽为 1，求能勾勒出的最大矩形面积。

## 示例
- 示例  
输入：`heights = [2,1,5,6,2,3]`  
输出：`10`

## 最佳解法思路
- 思路1（推荐）：单调栈（递增栈）  
维护一个高度递增的下标栈。  
当遇到更小高度时，不断出栈，出栈高度作为矩形高，宽为“当前下标 i 与出栈后新的栈顶之间的距离 - 1”。  
末尾补一个 0 触发清栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        int[] h = new int[n + 1];
        System.arraycopy(heights, 0, h, 0, n);
        h[n] = 0;

        Deque<Integer> st = new ArrayDeque<>();
        st.push(-1);
        int ans = 0;
        for (int i = 0; i <= n; i++) {
            while (st.peek() != -1 && h[i] < h[st.peek()]) {
                int height = h[st.pop()];
                int width = i - st.peek() - 1;
                ans = Math.max(ans, height * width);
            }
            st.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 单调递增栈：弹栈时用“弹出高度”做高，用“当前 i 到新栈顶”算宽。
