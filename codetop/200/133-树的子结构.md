# 剑指 Offer 26. 树的子结构

## 题目描述
输入两棵二叉树A和B，判断B是不是A的子结构。(约定空树不是任意一个树的子结构)

示例 1：
```
输入：A = [1,2,3], B = [3,1]
输出：false
```

示例 2：
```
输入：A = [3,4,5,1,2], B = [4,1]
输出：true
```

## 解题思路
1. 递归方法：
   - 先序遍历A树，找到与B树根节点值相同的节点
   - 判断以该节点为根的子树是否包含B树
   - 时间复杂度：O(mn)，空间复杂度：O(m)

2. 关键点：
   - 先序遍历
   - 子树判断
   - 空树处理
   - 边界条件处理

## Java实现
```java
class Solution {
    public boolean isSubStructure(TreeNode A, TreeNode B) {
        if (A == null || B == null) {
            return false;
        }
        
        // 先序遍历A树，找到与B树根节点值相同的节点
        return isSubTree(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B);
    }
    
    private boolean isSubTree(TreeNode A, TreeNode B) {
        // B树为空，说明匹配成功
        if (B == null) {
            return true;
        }
        
        // A树为空或节点值不相等，说明匹配失败
        if (A == null || A.val != B.val) {
            return false;
        }
        
        // 递归判断左右子树
        return isSubTree(A.left, B.left) && isSubTree(A.right, B.right);
    }
}
```

## Python实现
```python
class Solution:
    def isSubStructure(self, A: TreeNode, B: TreeNode) -> bool:
        if not A or not B:
            return False
            
        # 先序遍历A树，找到与B树根节点值相同的节点
        return self.isSubTree(A, B) or \
               self.isSubStructure(A.left, B) or \
               self.isSubStructure(A.right, B)
               
    def isSubTree(self, A: TreeNode, B: TreeNode) -> bool:
        # B树为空，说明匹配成功
        if not B:
            return True
            
        # A树为空或节点值不相等，说明匹配失败
        if not A or A.val != B.val:
            return False
            
        # 递归判断左右子树
        return self.isSubTree(A.left, B.left) and \
               self.isSubTree(A.right, B.right)
```

## 复杂度分析
- 时间复杂度：O(mn)，其中m和n分别为A树和B树的节点数
- 空间复杂度：O(m)，递归调用栈的深度
