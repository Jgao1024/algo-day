# 670. 最大交换

- 题号：670
- 难度：中等
- LeetCode：[最大交换](https://leetcode.cn/problems/maximum-swap/)

## 题目描述
给定一个非负整数 `num`，你最多可以交换其中两位数字一次，使得结果数字最大，返回最大值。

## 示例
- 示例  
输入：`num = 2736`  
输出：`7236`

## 最佳解法思路
- 思路1（推荐）：记录每个数字最后出现位置 + 贪心  
从左到右遍历每一位 `digits[i]`：  
尝试找一个更大的数字 `d`（从 9 到当前位+1）在右侧最后出现的位置 `last[d]`，若 `last[d] > i`，就交换并直接返回。

## Java 最佳实现

```java
class Solution {
    public int maximumSwap(int num) {
        char[] s = String.valueOf(num).toCharArray();
        int n = s.length;
        int[] last = new int[10];
        for (int i = 0; i < n; i++) {
            last[s[i] - '0'] = i;
        }

        for (int i = 0; i < n; i++) {
            int cur = s[i] - '0';
            for (int d = 9; d > cur; d--) {
                if (last[d] > i) {
                    char tmp = s[i];
                    s[i] = s[last[d]];
                    s[last[d]] = tmp;
                    return Integer.parseInt(new String(s));
                }
            }
        }
        return num;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（常数 10 的内层循环）
- 空间：\(O(n)\)
