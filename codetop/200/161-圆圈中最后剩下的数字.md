# 剑指 Offer 62. 圆圈中最后剩下的数字

## 题目描述
0,1,···,n-1这n个数字排成一个圆圈，从数字0开始，每次从这个圆圈里删除第m个数字（删除后从下一个数字开始计数）。求出这个圆圈里剩下的最后一个数字。

示例 1:
```
输入: n = 5, m = 3
输出: 3
```

示例 2:
```
输入: n = 10, m = 17
输出: 2
```

## 解题思路
1. 约瑟夫环问题：
   - 使用数学公式：f(n,m) = (f(n-1,m) + m) % n
   - 当n=1时，f(1,m) = 0
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 理解约瑟夫环问题的数学推导
   - 使用递归或迭代实现
   - 注意取模运算

## Java实现
```java
class Solution {
    public int lastRemaining(int n, int m) {
        int ans = 0;
        for (int i = 2; i <= n; i++) {
            ans = (ans + m) % i;
        }
        return ans;
    }
}
```

## Python实现
```python
class Solution:
    def lastRemaining(self, n: int, m: int) -> int:
        ans = 0
        for i in range(2, n + 1):
            ans = (ans + m) % i
        return ans
```

## 复杂度分析
- 时间复杂度：O(n)，需要遍历n-1次
- 空间复杂度：O(1)，只使用常数额外空间
