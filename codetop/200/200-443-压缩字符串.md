# 443. 压缩字符串

- 题号：443
- 难度：中等
- LeetCode：[压缩字符串](https://leetcode.cn/problems/string-compression/)

## 题目描述
给定字符数组 `chars`，对其进行原地压缩：  
连续重复的字符写为 `字符 + 次数`（次数大于 1 才写），返回压缩后的长度。

## 示例
- 示例  
输入：`chars = ["a","a","b","b","c","c","c"]`  
输出：`返回 6，数组前 6 位为 ["a","2","b","2","c","3"]`

## 最佳解法思路
- 思路1（推荐）：双指针写入  
`read` 扫描每一段连续字符，统计 `count`；  
`write` 写入当前字符，若 `count>1` 再写入 `count` 的每一位数字。

## Java 最佳实现

```java
class Solution {
    public int compress(char[] chars) {
        int n = chars.length;
        int write = 0;
        int read = 0;
        while (read < n) {
            char c = chars[read];
            int start = read;
            while (read < n && chars[read] == c) read++;
            int count = read - start;

            chars[write++] = c;
            if (count > 1) {
                char[] digits = String.valueOf(count).toCharArray();
                for (char d : digits) chars[write++] = d;
            }
        }
        return write;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
