# 264. 丑数 II

- 题号：264
- 难度：中等
- LeetCode：[丑数 II](https://leetcode.cn/problems/ugly-number-ii/)

## 题目描述
丑数只包含质因子 `2、3、5`。给定整数 `n`，返回第 `n` 个丑数。

## 示例
- 示例  
输入：`n = 10`  
输出：`12`

## 最佳解法思路
- 思路1（推荐）：DP + 三指针  
用 `dp[i]` 表示第 `i+1` 个丑数（`dp[0]=1`）。  
维护三个指针 `p2/p3/p5`，表示下一个乘 `2/3/5` 的位置：  
`next = min(dp[p2]*2, dp[p3]*3, dp[p5]*5)`，相等的指针都要前进（去重）。

## Java 最佳实现

```java
class Solution {
    public int nthUglyNumber(int n) {
        int[] dp = new int[n];
        dp[0] = 1;
        int p2 = 0, p3 = 0, p5 = 0;
        for (int i = 1; i < n; i++) {
            int a = dp[p2] * 2;
            int b = dp[p3] * 3;
            int c = dp[p5] * 5;
            int next = Math.min(a, Math.min(b, c));
            dp[i] = next;
            if (next == a) p2++;
            if (next == b) p3++;
            if (next == c) p5++;
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 三指针去重：`next` 同时命中谁就推进谁。
