# 补充题14. 阿拉伯数字转中文数字

## 题目描述
将阿拉伯数字转换为中文数字表示。

示例 1:
```
输入：1234567
输出：一百二十三万四千五百六十七
```

示例 2:
```
输入：100000000
输出：一亿
```

## 解题思路
1. 分段处理法：
   - 将数字按每4位分成一段（个、万、亿）
   - 对每段进行转换，处理零的特殊情况
   - 添加单位（个、十、百、千）
   - 时间复杂度：O(log n)，空间复杂度：O(1)

2. 关键点：
   - 处理零的特殊情况
   - 处理单位的添加规则
   - 处理大数的分段

## Java实现
```java
class Solution {
    private static final String[] NUMBERS = {"零", "一", "二", "三", "四", "五", "六", "七", "八", "九"};
    private static final String[] UNITS = {"", "十", "百", "千"};
    private static final String[] SECTIONS = {"", "万", "亿"};
    
    public String numberToChinese(int num) {
        if (num == 0) return NUMBERS[0];
        
        StringBuilder result = new StringBuilder();
        int section = 0;
        
        while (num > 0) {
            int segment = num % 10000;
            if (segment != 0) {
                String segmentStr = convertSegment(segment);
                if (section > 0) {
                    segmentStr += SECTIONS[section];
                }
                result.insert(0, segmentStr);
            }
            num /= 10000;
            section++;
        }
        
        return result.toString();
    }
    
    private String convertSegment(int num) {
        if (num == 0) return "";
        
        StringBuilder result = new StringBuilder();
        boolean hasNonZero = false;
        
        for (int i = 3; i >= 0; i--) {
            int digit = (num / (int)Math.pow(10, i)) % 10;
            
            if (digit != 0) {
                if (hasNonZero) {
                    result.append(NUMBERS[0]);
                }
                result.append(NUMBERS[digit]);
                if (i > 0) {
                    result.append(UNITS[i]);
                }
                hasNonZero = true;
            }
        }
        
        return result.toString();
    }
}
```

## Python实现
```python
class Solution:
    NUMBERS = ["零", "一", "二", "三", "四", "五", "六", "七", "八", "九"]
    UNITS = ["", "十", "百", "千"]
    SECTIONS = ["", "万", "亿"]
    
    def numberToChinese(self, num: int) -> str:
        if num == 0:
            return self.NUMBERS[0]
            
        result = []
        section = 0
        
        while num > 0:
            segment = num % 10000
            if segment != 0:
                segment_str = self.convert_segment(segment)
                if section > 0:
                    segment_str += self.SECTIONS[section]
                result.insert(0, segment_str)
            num //= 10000
            section += 1
            
        return "".join(result)
    
    def convert_segment(self, num: int) -> str:
        if num == 0:
            return ""
            
        result = []
        has_non_zero = False
        
        for i in range(3, -1, -1):
            digit = (num // (10 ** i)) % 10
            
            if digit != 0:
                if has_non_zero:
                    result.append(self.NUMBERS[0])
                result.append(self.NUMBERS[digit])
                if i > 0:
                    result.append(self.UNITS[i])
                has_non_zero = True
                
        return "".join(result)
```

## 复杂度分析
- 时间复杂度：O(log n)，其中n为输入数字
- 空间复杂度：O(1)，使用常数额外空间
