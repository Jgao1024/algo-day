# 剑指 Offer 10- II. 青蛙跳台阶问题

## 题目描述
一只青蛙一次可以跳上1级台阶，也可以跳上2级台阶。求该青蛙跳上一个 n 级的台阶总共有多少种跳法。

答案需要取模 1e9+7（1000000007），如计算初始结果为：1000000008，请返回 1。

示例 1：
```
输入：n = 2
输出：2
```

示例 2：
```
输入：n = 7
输出：21
```

## 解题思路
1. 动态规划方法：
   - 定义dp[i]表示跳上第i级台阶的跳法数
   - 状态转移方程：dp[i] = dp[i-1] + dp[i-2]
   - 初始条件：dp[0] = 1, dp[1] = 1
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 关键点：
   - 状态转移方程
   - 空间优化
   - 取模运算
   - 边界条件

## Java实现
```java
class Solution {
    public int numWays(int n) {
        if (n == 0 || n == 1) return 1;
        
        int a = 1, b = 1;
        for (int i = 2; i <= n; i++) {
            int sum = (a + b) % 1000000007;
            a = b;
            b = sum;
        }
        
        return b;
    }
}
```

## Python实现
```python
class Solution:
    def numWays(self, n: int) -> int:
        if n == 0 or n == 1:
            return 1
        
        a, b = 1, 1
        for _ in range(2, n + 1):
            a, b = b, (a + b) % 1000000007
        
        return b
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为台阶数
- 空间复杂度：O(1)，只使用常数额外空间
