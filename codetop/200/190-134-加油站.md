# 134. 加油站

- 题号：134
- 难度：中等
- LeetCode：[加油站](https://leetcode.cn/problems/gas-station/)

## 题目描述
在一条环形路上有 `n` 个加油站，`gas[i]` 是第 `i` 站可加油量，`cost[i]` 是从 `i` 到 `i+1` 的耗油量。  
如果能绕行一周，返回起始站下标；否则返回 `-1`。

## 示例
- 示例  
输入：`gas = [1,2,3,4,5], cost = [3,4,5,1,2]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：贪心  
若总油量 `sum(gas) < sum(cost)`，一定无解。  
否则从左到右累加油箱 `tank += gas[i]-cost[i]`：  
若 `tank < 0`，说明当前起点到 i 走不到，把起点改成 `i+1`，并把 `tank` 清 0（这段区间内任何点都不可能作为起点）。

## Java 最佳实现

```java
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int total = 0;
        int tank = 0;
        int start = 0;
        for (int i = 0; i < gas.length; i++) {
            int diff = gas[i] - cost[i];
            total += diff;
            tank += diff;
            if (tank < 0) {
                start = i + 1;
                tank = 0;
            }
        }
        return total >= 0 ? start : -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
