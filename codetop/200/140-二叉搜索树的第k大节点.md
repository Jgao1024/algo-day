# 剑指 Offer 54. 二叉搜索树的第k大节点

## 题目描述
给定一棵二叉搜索树，请找出其中第k大的节点。

示例 1：
```
输入: root = [3,1,4,null,2], k = 1
   3
  / \
 1   4
  \
   2
输出: 4
```

示例 2：
```
输入: root = [5,3,6,2,4,null,null,1], k = 3
       5
      / \
     3   6
    / \
   2   4
  /
 1
输出: 4
```

## 解题思路
1. 中序遍历方法：
   - 二叉搜索树的中序遍历是升序的
   - 使用中序遍历的逆序（右-根-左）可以得到降序序列
   - 记录遍历顺序，找到第k个节点
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 关键点：
   - 中序遍历的逆序
   - 计数器的使用
   - 提前返回优化
   - 递归终止条件

## Java实现
```java
class Solution {
    private int count = 0;
    private int result = 0;
    
    public int kthLargest(TreeNode root, int k) {
        count = k;
        dfs(root);
        return result;
    }
    
    private void dfs(TreeNode root) {
        if (root == null || count == 0) return;
        
        dfs(root.right);
        if (--count == 0) {
            result = root.val;
            return;
        }
        dfs(root.left);
    }
}
```

## Python实现
```python
class Solution:
    def kthLargest(self, root: TreeNode, k: int) -> int:
        self.count = k
        self.result = 0
        
        def dfs(root: TreeNode) -> None:
            if not root or self.count == 0:
                return
            
            dfs(root.right)
            self.count -= 1
            if self.count == 0:
                self.result = root.val
                return
            dfs(root.left)
        
        dfs(root)
        return self.result
```

## 复杂度分析
- 时间复杂度：O(n)，其中n为二叉搜索树的节点数
- 空间复杂度：O(n)，最坏情况下需要存储所有节点
