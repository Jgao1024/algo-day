# 395. 至少有K个重复字符的最长子串

- 题号：395
- 难度：中等
- LeetCode：[至少有K个重复字符的最长子串](https://leetcode.cn/problems/longest-substring-with-at-least-k-repeating-characters/)

## 题目描述
给定字符串 `s`（仅小写字母）和整数 `k`，返回最长子串长度，使得子串中每个字符出现次数都不少于 `k`。

## 示例
- 示例  
输入：`s = "aaabb", k = 3`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：枚举不同字符种类数 + 滑动窗口  
枚举窗口内“不同字符数” `target`（1..26）。  
滑动窗口维护：`unique`（不同字符数）、`atLeastK`（出现次数 \(\ge k\) 的字符种类数）。  
当 `unique == target && unique == atLeastK` 时更新答案。

## Java 最佳实现

```java
class Solution {
    public int longestSubstring(String s, int k) {
        int n = s.length();
        int ans = 0;
        for (int target = 1; target <= 26; target++) {
            int[] cnt = new int[26];
            int left = 0, right = 0;
            int unique = 0, atLeastK = 0;
            while (right < n) {
                int r = s.charAt(right) - 'a';
                if (cnt[r] == 0) unique++;
                cnt[r]++;
                if (cnt[r] == k) atLeastK++;
                right++;

                while (unique > target) {
                    int l = s.charAt(left) - 'a';
                    if (cnt[l] == k) atLeastK--;
                    cnt[l]--;
                    if (cnt[l] == 0) unique--;
                    left++;
                }

                if (unique == target && unique == atLeastK) {
                    ans = Math.max(ans, right - left);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(26n)\)
- 空间：\(O(1)\)
