## 最佳解法思路
- 思路（推荐）：计数 + 按下标填充  
若某字符出现次数 `maxCnt > (n+1)/2` 则无解。  
先把出现最多的字符填到偶数下标 `0,2,4...`，再把剩余字符依次填充（偶数填满再填奇数），保证相邻不相等。

## Java 最佳实现

```java
class Solution {
    public String reorganizeString(String s) {
        int n = s.length();
        int[] cnt = new int[26];
        for (int i = 0; i < n; i++) {
            cnt[s.charAt(i) - 'a']++;
        }

        int maxIdx = 0;
        for (int i = 1; i < 26; i++) {
            if (cnt[i] > cnt[maxIdx]) {
                maxIdx = i;
            }
        }
        if (cnt[maxIdx] > (n + 1) / 2) {
            return "";
        }

        char[] res = new char[n];
        int idx = 0;
        while (cnt[maxIdx] > 0) {
            res[idx] = (char) ('a' + maxIdx);
            idx += 2;
            cnt[maxIdx]--;
        }

        for (int c = 0; c < 26; c++) {
            while (cnt[c] > 0) {
                if (idx >= n) {
                    idx = 1;
                }
                res[idx] = (char) ('a' + c);
                idx += 2;
                cnt[c]--;
            }
        }

        return new String(res);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
