## 最佳解法思路
- 思路：按 3 位一组处理  
把数字按 `Billion/Million/Thousand` 分组，每组（0~999）用固定规则转英文，再拼接组名即可。

## Java 最佳实现

```java
class Solution {
    private static final String[] LESS_20 = {
            "", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine",
            "Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"
    };
    private static final String[] TENS = {
            "", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"
    };

    public String numberToWords(int num) {
        if (num == 0) {
            return "Zero";
        }

        int n = num;
        StringBuilder sb = new StringBuilder();
        if (n >= 1_000_000_000) {
            sb.append(chunk(n / 1_000_000_000)).append(" Billion");
            n %= 1_000_000_000;
        }
        if (n >= 1_000_000) {
            appendSpace(sb);
            sb.append(chunk(n / 1_000_000)).append(" Million");
            n %= 1_000_000;
        }
        if (n >= 1000) {
            appendSpace(sb);
            sb.append(chunk(n / 1000)).append(" Thousand");
            n %= 1000;
        }
        if (n > 0) {
            appendSpace(sb);
            sb.append(chunk(n));
        }

        return sb.toString();
    }

    private void appendSpace(StringBuilder sb) {
        if (sb.length() > 0) {
            sb.append(' ');
        }
    }

    private String chunk(int n) {
        StringBuilder sb = new StringBuilder();
        if (n >= 100) {
            sb.append(LESS_20[n / 100]).append(" Hundred");
            n %= 100;
            if (n > 0) {
                sb.append(' ');
            }
        }
        if (n >= 20) {
            sb.append(TENS[n / 10]);
            n %= 10;
            if (n > 0) {
                sb.append(' ').append(LESS_20[n]);
            }
        } else if (n > 0) {
            sb.append(LESS_20[n]);
        }
        return sb.toString();
    }
}
```

- 时间：\(O(1)\)
- 空间：\(O(1)\)
