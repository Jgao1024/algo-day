## 最佳解法思路
- 思路：按“节”累加（万/亿分段）  
维护 `result`（最终）、`section`（万以内小节）、`number`（当前数字）。  
遇到数字字符更新 `number`；遇到十/百/千，把 `(number==0?1:number) * unit` 加到 `section`；  
遇到 万/亿，则把 `(section + number) * unit` 加到 `result`，并清空 `section/number`。最后返回 `result + section + number`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long chineseToNumber(String s) {
        Map<Character, Integer> digit = new HashMap<>();
        digit.put('零', 0);
        digit.put('一', 1);
        digit.put('二', 2);
        digit.put('两', 2);
        digit.put('三', 3);
        digit.put('四', 4);
        digit.put('五', 5);
        digit.put('六', 6);
        digit.put('七', 7);
        digit.put('八', 8);
        digit.put('九', 9);

        Map<Character, Integer> unit = new HashMap<>();
        unit.put('十', 10);
        unit.put('百', 100);
        unit.put('千', 1000);
        unit.put('万', 10000);
        unit.put('亿', 100000000);

        long result = 0;
        long section = 0;
        long number = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            Integer d = digit.get(c);
            if (d != null) {
                number = d;
                continue;
            }

            Integer u = unit.get(c);
            if (u == null) {
                continue;
            }

            if (u < 10000) {
                long base = (number == 0 ? 1 : number);
                section += base * u;
                number = 0;
            } else {
                section += number;
                result += section * u;
                section = 0;
                number = 0;
            }
        }

        return result + section + number;
    }
}
```
