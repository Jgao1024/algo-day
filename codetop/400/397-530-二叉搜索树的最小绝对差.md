## 最佳解法思路
- 思路：中序遍历（BST 有序）  
BST 中序遍历得到递增序列，最小差只可能出现在相邻元素之间。遍历时记录 `prev` 和当前答案即可。

## Java 最佳实现

```java
class Solution {
    private Integer prev = null;
    private int ans = Integer.MAX_VALUE;

    public int getMinimumDifference(TreeNode root) {
        inorder(root);
        return ans;
    }

    private void inorder(TreeNode node) {
        if (node == null) {
            return;
        }
        inorder(node.left);
        if (prev != null) {
            ans = Math.min(ans, node.val - prev);
        }
        prev = node.val;
        inorder(node.right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
