## 最佳解法思路
- 思路（推荐）：二分答案（吃香蕉速度）  
速度 `k` 越大，总耗时越小，满足单调性。二分 `k` 在 `[1, maxPile]`：  
计算每堆耗时 `ceil(p/k)` 累加，若总耗时 `<= h` 说明速度够快，向左收缩；否则向右。

## Java 最佳实现

```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int max = 0;
        for (int p : piles) {
            max = Math.max(max, p);
        }

        int l = 1;
        int r = max;
        while (l < r) {
            int m = (l + r) >>> 1;
            if (canFinish(piles, h, m)) {
                r = m;
            } else {
                l = m + 1;
            }
        }
        return l;
    }

    private boolean canFinish(int[] piles, int h, int k) {
        long hours = 0;
        for (int p : piles) {
            hours += (p + k - 1) / k;
            if (hours > h) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log M)\)，\(M\) 为最大堆大小
- 空间：\(O(1)\)
