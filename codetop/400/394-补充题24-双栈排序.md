## 最佳解法思路
- 思路：用一个辅助栈做插入排序  
把原栈元素逐个弹出，插入到辅助栈中，并保持辅助栈单调（比如从栈顶到栈底递增）。  
插入时如果辅助栈顶比当前值大，就把辅助栈顶弹回原栈，直到能插入。最后再把辅助栈倒回原栈即得到有序栈。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public void sortStack(Deque<Integer> stack) {
        Deque<Integer> help = new ArrayDeque<>();
        while (!stack.isEmpty()) {
            int cur = stack.pop();
            while (!help.isEmpty() && help.peek() > cur) {
                stack.push(help.pop());
            }
            help.push(cur);
        }
        while (!help.isEmpty()) {
            stack.push(help.pop());
        }
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(n^2)\)
- 空间：\(O(n)\)
