## 最佳解法思路
- 思路（推荐）：排序 + 双指针  
分别排序 `a、b`，用双指针从头扫：  
每次更新 `abs(a[i]-b[j])`，并移动较小的一侧指针，保证不漏解。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int smallestDifference(int[] a, int[] b) {
        Arrays.sort(a);
        Arrays.sort(b);

        int i = 0;
        int j = 0;
        long best = Long.MAX_VALUE;
        while (i < a.length && j < b.length) {
            long x = a[i];
            long y = b[j];
            best = Math.min(best, Math.abs(x - y));
            if (x < y) {
                i++;
            } else {
                j++;
            }
        }
        return (int) best;
    }
}
```

## 复杂度分析
- 时间：\(O((m+n)\log(m+n))\)
- 空间：\(O(1)\)（排序视实现）
