## 最佳解法思路
- 思路（推荐）：KMP 找最长回文前缀  
把 `s` 反转得 `rev`，构造 `t = s + "#" + rev`。  
对 `t` 求前缀函数 `lps`，`lps[last]` 就是 `s` 的最长回文前缀长度 `len`。  
答案 = `rev.substring(0, n-len) + s`。

## Java 最佳实现

```java
class Solution {
    public String shortestPalindrome(String s) {
        int n = s.length();
        String rev = new StringBuilder(s).reverse().toString();
        String t = s + "#" + rev;

        int[] lps = new int[t.length()];
        int j = 0;
        for (int i = 1; i < t.length(); i++) {
            while (j > 0 && t.charAt(i) != t.charAt(j)) {
                j = lps[j - 1];
            }
            if (t.charAt(i) == t.charAt(j)) {
                j++;
            }
            lps[i] = j;
        }

        int len = lps[t.length() - 1];
        return rev.substring(0, n - len) + s;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
