# 57. 插入区间

## 题目描述
给你一个无重叠的，按照区间起始端点排序的区间列表。

在列表中插入一个新的区间，你需要确保列表中的区间仍然有序且不重叠（如果有必要的话，可以合并区间）。

示例 1:
```
输入：intervals = [[1,3],[6,9]], newInterval = [2,5]
输出：[[1,5],[6,9]]
```

## 解题思路
1. 遍历法：
   - 遍历所有区间
   - 如果新区间的结束位置小于当前区间的起始位置，将新区间插入当前位置
   - 如果新区间的起始位置大于当前区间的结束位置，继续遍历
   - 否则，合并区间
   - 最后处理剩余区间

2. 二分查找法：
   - 使用二分查找找到新区间应该插入的位置
   - 合并重叠区间
   - 返回结果

## Java实现
```java
// 遍历法
class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        if (intervals == null || intervals.length == 0) {
            return new int[][]{newInterval};
        }
        
        List<int[]> result = new ArrayList<>();
        boolean inserted = false;
        
        for (int[] interval : intervals) {
            if (inserted || newInterval[1] < interval[0]) {
                // 新区间已经插入或新区间在当前区间之前
                result.add(interval);
            } else if (newInterval[0] > interval[1]) {
                // 新区间在当前区间之后
                result.add(interval);
            } else {
                // 合并区间
                newInterval[0] = Math.min(newInterval[0], interval[0]);
                newInterval[1] = Math.max(newInterval[1], interval[1]);
            }
        }
        
        if (!inserted) {
            result.add(newInterval);
        }
        
        return result.toArray(new int[result.size()][]);
    }
}

// 二分查找法
class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        if (intervals == null || intervals.length == 0) {
            return new int[][]{newInterval};
        }
        
        int left = 0;
        int right = intervals.length - 1;
        
        // 找到新区间应该插入的位置
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (intervals[mid][1] < newInterval[0]) {
                left = mid + 1;
            } else if (intervals[mid][0] > newInterval[1]) {
                right = mid - 1;
            } else {
                // 找到重叠区间
                break;
            }
        }
        
        List<int[]> result = new ArrayList<>();
        int i = 0;
        
        // 添加不重叠的区间
        while (i < left) {
            result.add(intervals[i++]);
        }
        
        // 合并重叠区间
        while (i < intervals.length && intervals[i][0] <= newInterval[1]) {
            newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
            newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
            i++;
        }
        
        result.add(newInterval);
        
        // 添加剩余区间
        while (i < intervals.length) {
            result.add(intervals[i++]);
        }
        
        return result.toArray(new int[result.size()][]);
    }
}
```

```python
# 遍历法
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        if not intervals:
            return [newInterval]
            
        result = []
        inserted = False
        
        for interval in intervals:
            if inserted or newInterval[1] < interval[0]:
                # 新区间已经插入或新区间在当前区间之前
                result.append(interval)
            elif newInterval[0] > interval[1]:
                # 新区间在当前区间之后
                result.append(interval)
            else:
                # 合并区间
                newInterval[0] = min(newInterval[0], interval[0])
                newInterval[1] = max(newInterval[1], interval[1])
                
        if not inserted:
            result.append(newInterval)

# 二分查找法
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        if not intervals:
            return [newInterval]
            
        left = 0
        right = len(intervals) - 1
        
        # 找到新区间应该插入的位置
        while left <= right:
            mid = left + (right - left) // 2
            if intervals[mid][1] < newInterval[0]:
                left = mid + 1
            elif intervals[mid][0] > newInterval[1]:
                right = mid - 1
            else:
                # 找到重叠区间
                break
                
        result = []
        i = 0
        
        # 添加不重叠的区间
        while i < left:
            result.append(intervals[i])
            i += 1
            
        # 合并重叠区间
        while i < len(intervals) and intervals[i][0] <= newInterval[1]:
            newInterval[0] = min(newInterval[0], intervals[i][0])
            newInterval[1] = max(newInterval[1], intervals[i][1])
            i += 1
            
        result.append(newInterval)
        
        # 添加剩余区间
        while i < len(intervals):
            result.append(intervals[i])
            i += 1
            
        return result
```
