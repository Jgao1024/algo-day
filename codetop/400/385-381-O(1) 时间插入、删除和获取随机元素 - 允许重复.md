## 最佳解法思路
- 思路（推荐）：动态数组 + 哈希表维护“值 -> 下标集合”  
用 `list` 存所有元素；用 `map[val]` 存该值在 `list` 里的所有下标。  
删除时从下标集合里取一个位置 `idx`，用 `list` 末尾元素覆盖到 `idx`，并同步更新两个值的下标集合，最后删掉末尾即可。`getRandom` 直接在 `list` 上随机取下标。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Random;
import java.util.Set;

class RandomizedCollection {
    private final ArrayList<Integer> list = new ArrayList<>();
    private final Map<Integer, Set<Integer>> idx = new HashMap<>();
    private final Random random = new Random();

    public boolean insert(int val) {
        Set<Integer> set = idx.get(val);
        boolean notExist = (set == null || set.isEmpty());
        if (set == null) {
            set = new HashSet<>();
            idx.put(val, set);
        }
        set.add(list.size());
        list.add(val);
        return notExist;
    }

    public boolean remove(int val) {
        Set<Integer> set = idx.get(val);
        if (set == null || set.isEmpty()) {
            return false;
        }

        int removeIdx = set.iterator().next();
        set.remove(removeIdx);

        int lastIdx = list.size() - 1;
        int lastVal = list.get(lastIdx);

        if (removeIdx != lastIdx) {
            list.set(removeIdx, lastVal);
            Set<Integer> lastSet = idx.get(lastVal);
            lastSet.remove(lastIdx);
            lastSet.add(removeIdx);
        }

        list.remove(lastIdx);
        return true;
    }

    public int getRandom() {
        return list.get(random.nextInt(list.size()));
    }
}
```

- 时间：插入/删除/随机 \(O(1)\) 均摊
- 空间：\(O(n)\)
