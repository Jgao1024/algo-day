## 最佳解法思路
- 思路（推荐）：DFS + 记忆化  
从下标 `start` 开始枚举下一段单词 `s[start..end)`，若在字典里就递归拼接后面的所有句子。  
用 `memo[start]` 缓存从 `start` 出发得到的所有结果，避免重复搜索。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    private String s;
    private Set<String> dict;
    private Map<Integer, List<String>> memo;
    private int maxLen;

    public List<String> wordBreak(String s, List<String> wordDict) {
        this.s = s;
        this.dict = new HashSet<>(wordDict);
        this.memo = new HashMap<>();

        maxLen = 0;
        for (String w : wordDict) {
            maxLen = Math.max(maxLen, w.length());
        }

        return dfs(0);
    }

    private List<String> dfs(int start) {
        List<String> cached = memo.get(start);
        if (cached != null) {
            return cached;
        }

        List<String> res = new ArrayList<>();
        if (start == s.length()) {
            res.add("");
            memo.put(start, res);
            return res;
        }

        int endLimit = Math.min(s.length(), start + maxLen);
        for (int end = start + 1; end <= endLimit; end++) {
            String word = s.substring(start, end);
            if (!dict.contains(word)) {
                continue;
            }
            List<String> tails = dfs(end);
            for (String tail : tails) {
                if (tail.length() == 0) {
                    res.add(word);
                } else {
                    res.add(word + " " + tail);
                }
            }
        }

        memo.put(start, res);
        return res;
    }
}
```
