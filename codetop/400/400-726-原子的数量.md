## 最佳解法思路
- 思路（推荐）：栈 + 计数映射  
用栈存每一层括号内的原子计数 `Map`：  
- 遇到 `(`：压入新空表  
- 遇到 `)`：弹出一层，读取后面的倍数 `k`，把该层所有原子计数乘 `k` 后合并到上一层  
- 遇到原子名：解析元素名（大写+若干小写）和后面的数字（默认 1），累加到当前层  
最后把最外层计数按字典序输出，数量为 1 不输出数字。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;
import java.util.TreeMap;

class Solution {
    public String countOfAtoms(String formula) {
        int n = formula.length();
        Deque<Map<String, Integer>> stack = new ArrayDeque<>();
        stack.push(new HashMap<>());

        int i = 0;
        while (i < n) {
            char c = formula.charAt(i);
            if (c == '(') {
                stack.push(new HashMap<>());
                i++;
            } else if (c == ')') {
                i++;
                int[] read = readNumber(formula, i);
                int mul = read[0];
                i = read[1];

                Map<String, Integer> top = stack.pop();
                Map<String, Integer> cur = stack.peek();
                for (Map.Entry<String, Integer> e : top.entrySet()) {
                    int add = e.getValue() * mul;
                    cur.put(e.getKey(), cur.getOrDefault(e.getKey(), 0) + add);
                }
            } else {
                String name = readName(formula, i);
                i += name.length();
                int[] read = readNumber(formula, i);
                int cnt = read[0];
                i = read[1];

                Map<String, Integer> cur = stack.peek();
                cur.put(name, cur.getOrDefault(name, 0) + cnt);
            }
        }

        TreeMap<String, Integer> sorted = new TreeMap<>(stack.pop());
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<String, Integer> e : sorted.entrySet()) {
            sb.append(e.getKey());
            if (e.getValue() > 1) {
                sb.append(e.getValue());
            }
        }
        return sb.toString();
    }

    private String readName(String s, int i) {
        StringBuilder sb = new StringBuilder();
        sb.append(s.charAt(i));
        i++;
        while (i < s.length()) {
            char c = s.charAt(i);
            if (c >= 'a' && c <= 'z') {
                sb.append(c);
                i++;
            } else {
                break;
            }
        }
        return sb.toString();
    }

    private int[] readNumber(String s, int i) {
        int n = s.length();
        if (i >= n || s.charAt(i) < '0' || s.charAt(i) > '9') {
            return new int[]{1, i};
        }
        int val = 0;
        while (i < n) {
            char c = s.charAt(i);
            if (c < '0' || c > '9') {
                break;
            }
            val = val * 10 + (c - '0');
            i++;
        }
        return new int[]{val, i};
    }
}
```

## 复杂度分析
- 时间：\(O(n \log m)\)，\(m\) 为不同原子种类数（最终排序）
- 空间：\(O(m)\)
