# 986. 区间列表的交集

## 题目描述
给定两个由一些闭区间组成的列表，每个区间列表都是成对不相交的，并且已经排序。

返回这两个区间列表的交集。

（形式上，闭区间 [a, b]（其中 a <= b）表示实数 x 的集合，而 a <= x <= b。两个闭区间的交集是一组实数，要么为空集，要么为闭区间。例如，[1, 3] 和 [2, 4] 的交集为 [2, 3]。）

示例 1:
```
输入：A = [[0,2],[5,10],[13,23],[24,25]], B = [[1,5],[8,12],[15,24],[25,26]]
输出：[[1,2],[5,5],[8,10],[15,23],[24,24],[25,25]]
```

## 解题思路
1. 双指针法：
   - 使用两个指针分别指向两个区间列表
   - 比较当前两个区间的起始和结束位置
   - 如果两个区间有交集，计算交集并加入结果集
   - 移动结束位置较小的区间的指针

2. 扫描线法：
   - 将所有区间的起始点和结束点分别排序
   - 使用两个指针分别指向起始点和结束点
   - 当起始点指针小于结束点指针时，说明有重叠区间
   - 记录重叠区间的起始和结束位置

## Java实现
```java
// 双指针法
class Solution {
    public int[][] intervalIntersection(int[][] A, int[][] B) {
        if (A == null || B == null || A.length == 0 || B.length == 0) {
            return new int[0][];
        }
        
        List<int[]> result = new ArrayList<>();
        int i = 0, j = 0;
        
        while (i < A.length && j < B.length) {
            // 计算两个区间的交集
            int start = Math.max(A[i][0], B[j][0]);
            int end = Math.min(A[i][1], B[j][1]);
            
            if (start <= end) {
                result.add(new int[]{start, end});
            }
            
            // 移动结束位置较小的区间的指针
            if (A[i][1] < B[j][1]) {
                i++;
            } else {
                j++;
            }
        }
        
        return result.toArray(new int[result.size()][]);
    }
}

// 扫描线法
class Solution {
    public int[][] intervalIntersection(int[][] A, int[][] B) {
        if (A == null || B == null || A.length == 0 || B.length == 0) {
            return new int[0][];
        }
        
        List<int[]> points = new ArrayList<>();
        
        // 添加所有区间的起始点和结束点
        for (int[] interval : A) {
            points.add(new int[]{interval[0], 1});  // 1表示起始点
            points.add(new int[]{interval[1], -1}); // -1表示结束点
        }
        
        for (int[] interval : B) {
            points.add(new int[]{interval[0], 1});
            points.add(new int[]{interval[1], -1});
        }
        
        // 按照位置排序，如果位置相同，起始点在前
        Collections.sort(points, (a, b) -> {
            if (a[0] != b[0]) {
                return a[0] - b[0];
            }
            return b[1] - a[1];
        });
        
        List<int[]> result = new ArrayList<>();
        int count = 0;
        int start = -1;
        
        for (int[] point : points) {
            count += point[1];
            
            if (count == 2) {
                start = point[0];
            } else if (start != -1) {
                result.add(new int[]{start, point[0]});
                start = -1;
            }
        }
        
        return result.toArray(new int[result.size()][]);
    }
}
```

## Python实现
```python
# 双指针法
class Solution:
    def intervalIntersection(self, A: List[List[int]], B: List[List[int]]) -> List[List[int]]:
        if not A or not B:
            return []
            
        result = []
        i = j = 0
        
        while i < len(A) and j < len(B):
            # 计算两个区间的交集
            start = max(A[i][0], B[j][0])
            end = min(A[i][1], B[j][1])
            
            if start <= end:
                result.append([start, end])
                
            # 移动结束位置较小的区间的指针
            if A[i][1] < B[j][1]:
                i += 1
            else:
                j += 1
                
        return result

# 扫描线法
class Solution:
    def intervalIntersection(self, A: List[List[int]], B: List[List[int]]) -> List[List[int]]:
        if not A or not B:
            return []
            
        points = []
        
        # 添加所有区间的起始点和结束点
        for interval in A:
            points.append((interval[0], 1))  # 1表示起始点
            points.append((interval[1], -1)) # -1表示结束点
            
        for interval in B:
            points.append((interval[0], 1))
            points.append((interval[1], -1))
            
        # 按照位置排序，如果位置相同，起始点在前
        points.sort(key=lambda x: (x[0], -x[1]))
        
        result = []
        count = 0
        start = -1
        
        for point in points:
            count += point[1]
            
            if count == 2:
                start = point[0]
            elif start != -1:
                result.append([start, point[0]])
                start = -1
                
        return result
```

## 复杂度分析
- 时间复杂度：O(n + m)，其中n和m分别是两个区间列表的长度
- 空间复杂度：O(n + m)
