## 最佳解法思路
- 思路：DFS  
深度 = `1 + max(childrenDepth)`；空节点返回 0。

## Java 最佳实现

```java
class Solution {
    public int maxDepth(Node root) {
        if (root == null) {
            return 0;
        }
        int best = 0;
        if (root.children != null) {
            for (Node child : root.children) {
                best = Math.max(best, maxDepth(child));
            }
        }
        return best + 1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
