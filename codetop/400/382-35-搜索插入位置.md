## 最佳解法思路
- 思路：二分查找  
找第一个 `>= target` 的下标；若都小于则返回 `n`。

## Java 最佳实现

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int l = 0;
        int r = nums.length;
        while (l < r) {
            int m = (l + r) >>> 1;
            if (nums[m] >= target) {
                r = m;
            } else {
                l = m + 1;
            }
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
