## 最佳解法思路
- 思路：位运算  
如果 `n` 是 2 的幂，则二进制只有一个 1，满足 `n & (n-1) == 0`，同时要保证 `n > 0`。

## Java 最佳实现

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
