# 30. 串联所有单词的子串

## 题目描述
给定一个字符串 s 和一些长度相同的单词 words。找出 s 中恰好可以由 words 中所有单词串联形成的子串的起始位置。注意子串要与 words 中的单词完全匹配，中间不能有其他字符，但不需要考虑 words 中单词串联的顺序。

示例 1:
```
输入：s = "barfoothefoobarman", words = ["foo","bar"]
输出：[0,9]
解释：
从索引 0 和 9 开始的子串分别是 "barfoo" 和 "foobar" 。
输出的顺序不重要, [9,0] 也是有效答案。
```

示例 2:
```
输入：s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
输出：[]
```

## 解题思路
1. 滑动窗口法：
   - 使用哈希表记录words中每个单词的出现次数
   - 遍历字符串s，对每个位置作为起始位置
   - 使用滑动窗口检查是否匹配
   - 使用另一个哈希表记录当前窗口中的单词出现次数
   - 比较两个哈希表是否相同

2. 优化滑动窗口法：
   - 使用哈希表记录words中每个单词的出现次数
   - 遍历字符串s，对每个位置作为起始位置
   - 使用滑动窗口检查是否匹配
   - 使用另一个哈希表记录当前窗口中的单词出现次数
   - 比较两个哈希表是否相同
   - 优化：当遇到不匹配的单词时，直接跳过

## Java实现
```java
// 滑动窗口法
class Solution {
    public List<Integer> findSubstring(String s, String[] words) {
        List<Integer> result = new ArrayList<>();
        if (s == null || s.length() == 0 || words == null || words.length == 0) {
            return result;
        }
        
        int wordLen = words[0].length();
        int wordCount = words.length;
        int totalLen = wordLen * wordCount;
        
        // 记录words中每个单词的出现次数
        Map<String, Integer> wordMap = new HashMap<>();
        for (String word : words) {
            wordMap.put(word, wordMap.getOrDefault(word, 0) + 1);
        }
        
        // 遍历字符串s
        for (int i = 0; i <= s.length() - totalLen; i++) {
            // 记录当前窗口中的单词出现次数
            Map<String, Integer> windowMap = new HashMap<>();
            boolean valid = true;
            
            // 检查当前窗口
            for (int j = 0; j < wordCount; j++) {
                String word = s.substring(i + j * wordLen, i + (j + 1) * wordLen);
                if (!wordMap.containsKey(word)) {
                    valid = false;
                    break;
                }
                windowMap.put(word, windowMap.getOrDefault(word, 0) + 1);
                if (windowMap.get(word) > wordMap.get(word)) {
                    valid = false;
                    break;
                }
            }
            
            if (valid) {
                result.add(i);
            }
        }
        
        return result;
    }
}
```

## Python实现
```python
# 滑动窗口法
class Solution:
    def findSubstring(self, s: str, words: List[str]) -> List[int]:
        if not s or not words:
            return []
            
        word_len = len(words[0])
        word_count = len(words)
        total_len = word_len * word_count
        
        # 记录words中每个单词的出现次数
        word_map = {}
        for word in words:
            word_map[word] = word_map.get(word, 0) + 1
            
        result = []
        
        # 遍历字符串s
        for i in range(len(s) - total_len + 1):
            # 记录当前窗口中的单词出现次数
            window_map = {}
            valid = True
            
            # 检查当前窗口
            for j in range(word_count):
                word = s[i + j * word_len:i + (j + 1) * word_len]
                if word not in word_map:
                    valid = False
                    break
                window_map[word] = window_map.get(word, 0) + 1
                if window_map[word] > word_map[word]:
                    valid = False
                    break
                    
            if valid:
                result.append(i)
                
        return result
```

## 复杂度分析
- 时间复杂度：O(n * m * k)，其中n是字符串s的长度，m是words的长度，k是每个单词的长度
- 空间复杂度：O(m)，其中m是words的长度
