## 最佳解法思路
- 思路：前缀扫描  
总和 `sum` 必须能被 3 整除，目标和 `target = sum/3`。  
从左到右累加，找到前两段和为 `target` 的位置（保证后面还剩元素），即可分成三段。

## Java 最佳实现

```java
class Solution {
    public boolean canThreePartsEqualSum(int[] arr) {
        int sum = 0;
        for (int x : arr) {
            sum += x;
        }
        if (sum % 3 != 0) {
            return false;
        }

        int target = sum / 3;
        int cur = 0;
        int count = 0;
        for (int i = 0; i < arr.length - 1; i++) {
            cur += arr[i];
            if (cur == target) {
                count++;
                cur = 0;
                if (count == 2) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
