## 最佳解法思路
- 思路：二分查找（求整数立方根的向下取整）  
在区间 `[0, max(|x|)]` 上二分 `mid`，比较 `mid^3` 与 `|x|`，最终得到最大满足 `mid^3 <= |x|` 的 `mid`。  
如果输入为负数，结果也取负。

## Java 最佳实现

```java
class Solution {
    public int cbrtFloor(int x) {
        long t = x;
        long abs = t >= 0 ? t : -t;

        long l = 0;
        long r = 1;
        while (r * r * r <= abs) {
            r <<= 1;
            if (r > 1_000_000) {
                break;
            }
        }
        if (r * r * r > abs) {
            // ok
        } else {
            r = 1_000_000;
        }

        long ans = 0;
        while (l <= r) {
            long m = (l + r) >>> 1;
            long cube = m * m * m;
            if (cube <= abs) {
                ans = m;
                l = m + 1;
            } else {
                r = m - 1;
            }
        }
        return x >= 0 ? (int) ans : (int) -ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log |x|)\)
- 空间：\(O(1)\)
