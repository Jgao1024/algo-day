# 36. 有效的数独

## 题目描述
判断一个 9x9 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可。

1. 数字 1-9 在每一行只能出现一次。
2. 数字 1-9 在每一列只能出现一次。
3. 数字 1-9 在每一个以粗实线分隔的 3x3 宫内只能出现一次。

示例 1:
```
输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

示例 2:
```
输入：board = 
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与 示例1 相同。但由于位于左上角的 3x3 宫内有两个 8 存在, 因此这个数独是无效的。
```

## 解题思路
1. 一次遍历法：
   - 使用三个数组分别记录行、列、3x3宫格中数字的出现情况
   - 遍历数独，检查每个数字是否在对应的行、列、宫格中重复出现
   - 时间复杂度：O(1)，因为数独大小固定为9x9

2. 位运算优化法：
   - 使用位运算来记录数字的出现情况
   - 使用一个整数表示一行、一列或一个宫格中数字的出现情况
   - 时间复杂度：O(1)

## Java实现
```java
// 一次遍历法
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // 记录每行数字出现情况
        boolean[][] row = new boolean[9][9];
        // 记录每列数字出现情况
        boolean[][] col = new boolean[9][9];
        // 记录每个3x3宫格数字出现情况
        boolean[][] box = new boolean[9][9];
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = board[i][j] - '1';
                    int boxIndex = (i / 3) * 3 + j / 3;
                    
                    if (row[i][num] || col[j][num] || box[boxIndex][num]) {
                        return false;
                    }
                    
                    row[i][num] = true;
                    col[j][num] = true;
                    box[boxIndex][num] = true;
                }
            }
        }
        
        return true;
    }
}

// 位运算优化法
class Solution {
    public boolean isValidSudoku(char[][] board) {
        int[] row = new int[9];
        int[] col = new int[9];
        int[] box = new int[9];
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = 1 << (board[i][j] - '1');
                    int boxIndex = (i / 3) * 3 + j / 3;
                    
                    if ((row[i] & num) != 0 || (col[j] & num) != 0 || (box[boxIndex] & num) != 0) {
                        return false;
                    }
                    
                    row[i] |= num;
                    col[j] |= num;
                    box[boxIndex] |= num;
                }
            }
        }
        
        return true;
    }
}
```

## Python实现
```python
# 一次遍历法
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        # 记录每行数字出现情况
        row = [[False] * 9 for _ in range(9)]
        # 记录每列数字出现情况
        col = [[False] * 9 for _ in range(9)]
        # 记录每个3x3宫格数字出现情况
        box = [[False] * 9 for _ in range(9)]
        
        for i in range(9):
            for j in range(9):
                if board[i][j] != '.':
                    num = int(board[i][j]) - 1
                    box_index = (i // 3) * 3 + j // 3
                    
                    if row[i][num] or col[j][num] or box[box_index][num]:
                        return False
                        
                    row[i][num] = True
                    col[j][num] = True
                    box[box_index][num] = True
                    
        return True
```
