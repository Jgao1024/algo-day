## 最佳解法思路
- 思路（推荐）：换根 DP（两次 DFS）  
先以 0 为根：  
- `cnt[u]`：u 子树节点数  
- `ans[0]`：从 0 到所有节点距离和（通过累加子树贡献）  
再进行第二次 DFS 换根：  
从父到子 `v` 的转移：`ans[v] = ans[u] - cnt[v] + (n - cnt[v])`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private int n;
    private List<Integer>[] g;
    private int[] cnt;
    private int[] ans;

    public int[] sumOfDistancesInTree(int n, int[][] edges) {
        this.n = n;
        g = new ArrayList[n];
        for (int i = 0; i < n; i++) {
            g[i] = new ArrayList<>();
        }
        for (int[] e : edges) {
            int a = e[0], b = e[1];
            g[a].add(b);
            g[b].add(a);
        }

        cnt = new int[n];
        ans = new int[n];

        dfs1(0, -1);
        dfs2(0, -1);

        return ans;
    }

    private void dfs1(int u, int p) {
        cnt[u] = 1;
        for (int v : g[u]) {
            if (v == p) {
                continue;
            }
            dfs1(v, u);
            cnt[u] += cnt[v];
            ans[u] += ans[v] + cnt[v];
        }
    }

    private void dfs2(int u, int p) {
        for (int v : g[u]) {
            if (v == p) {
                continue;
            }
            ans[v] = ans[u] - cnt[v] + (n - cnt[v]);
            dfs2(v, u);
        }
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(n)\)
