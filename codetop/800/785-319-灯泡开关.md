## 最佳解法思路
- 思路：平方数个数  
第 i 个灯泡会被切换“约数个数”次，只有完全平方数的约数个数是奇数，所以最终亮着的灯泡数量 = \(\lfloor \sqrt{n} \rfloor\)。

## Java 最佳实现

```java
class Solution {
    public int bulbSwitch(int n) {
        return (int) Math.sqrt(n);
    }
}
```
