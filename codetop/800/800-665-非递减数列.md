## 最佳解法思路
- 思路：一次遍历 + 贪心修改  
扫描发现 `nums[i] < nums[i-1]` 的“降序点”，只能出现一次。  
为尽量不影响后续：  
- 若 `i<2` 或 `nums[i] >= nums[i-2]`，把 `nums[i-1]` 降到 `nums[i]`  
- 否则把 `nums[i]` 升到 `nums[i-1]`

## Java 最佳实现

```java
class Solution {
    public boolean checkPossibility(int[] nums) {
        int cnt = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] >= nums[i - 1]) {
                continue;
            }
            cnt++;
            if (cnt > 1) {
                return false;
            }
            if (i < 2 || nums[i] >= nums[i - 2]) {
                nums[i - 1] = nums[i];
            } else {
                nums[i] = nums[i - 1];
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
