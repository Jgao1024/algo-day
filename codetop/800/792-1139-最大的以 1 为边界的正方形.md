## 最佳解法思路
- 思路：预处理右/下连续 1 的长度  
`right[i][j]`：从 `(i,j)` 往右连续 1 的个数；`down[i][j]`：往下连续 1 的个数。  
枚举左上角 `(i,j)` 和边长 `len`：若  
`right[i][j] >= len`、`down[i][j] >= len`、`right[i+len-1][j] >= len`、`down[i][j+len-1] >= len`  
则边界全为 1。取最大 `len^2`。

## Java 最佳实现

```java
class Solution {
    public int largest1BorderedSquare(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;

        int[][] right = new int[m][n];
        int[][] down = new int[m][n];

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (grid[i][j] == 1) {
                    right[i][j] = 1 + (j + 1 < n ? right[i][j + 1] : 0);
                    down[i][j] = 1 + (i + 1 < m ? down[i + 1][j] : 0);
                }
            }
        }

        int best = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int maxLen = Math.min(m - i, n - j);
                for (int len = maxLen; len > best; len--) {
                    if (right[i][j] < len || down[i][j] < len) {
                        continue;
                    }
                    if (right[i + len - 1][j] < len || down[i][j + len - 1] < len) {
                        continue;
                    }
                    best = len;
                    break;
                }
            }
        }
        return best * best;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(mn\min(m,n))\)
- 空间：\(O(mn)\)
