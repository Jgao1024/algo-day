## 最佳解法思路
- 思路：滑动窗口 + 计数  
维护长度为 `k` 的窗口和字符频次，窗口内如果所有字符频次都为 0/1（可用 `dup` 统计“出现次数 >=2 的字符数”），则该窗口合法。

## Java 最佳实现

```java
class Solution {
    public int numKLenSubstrNoRepeats(String s, int k) {
        if (k > s.length()) {
            return 0;
        }
        int[] cnt = new int[128];
        int dup = 0;
        int ans = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            cnt[c]++;
            if (cnt[c] == 2) {
                dup++;
            }

            if (i >= k) {
                char out = s.charAt(i - k);
                if (cnt[out] == 2) {
                    dup--;
                }
                cnt[out]--;
            }

            if (i >= k - 1 && dup == 0) {
                ans++;
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
