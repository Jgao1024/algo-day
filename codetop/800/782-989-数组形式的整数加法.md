## 最佳解法思路
- 思路：模拟加法  
从数组末尾开始与 `k` 的个位相加，维护进位；结果用列表反向收集后再反转。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public List<Integer> addToArrayForm(int[] num, int k) {
        List<Integer> res = new ArrayList<>();
        int i = num.length - 1;
        int carry = 0;

        while (i >= 0 || k > 0 || carry > 0) {
            int sum = carry;
            if (i >= 0) {
                sum += num[i--];
            }
            if (k > 0) {
                sum += (k % 10);
                k /= 10;
            }
            res.add(sum % 10);
            carry = sum / 10;
        }

        Collections.reverse(res);
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n + \log k)\)
- 空间：\(O(n)\)
