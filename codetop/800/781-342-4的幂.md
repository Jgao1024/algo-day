## 最佳解法思路
- 思路：位运算  
`n` 是 4 的幂需要满足：  
- `n > 0`  
- 只有一个 1（`n & (n-1) == 0`）  
- 这个 1 落在奇数位上（`n & 0x55555555 != 0`）

## Java 最佳实现

```java
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555) != 0;
    }
}
```
