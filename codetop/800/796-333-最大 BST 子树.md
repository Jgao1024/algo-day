## 最佳解法思路
- 思路（推荐）：后序遍历返回子树信息  
对每个节点后序拿到左右信息（是否 BST、最小/最大值、BST 大小）。  
若左右都是 BST 且 `left.max < root.val < right.min`，则当前也是 BST，大小为 `left.size + right.size + 1`；否则标记为非 BST。全局记录最大大小。

## Java 最佳实现

```java
class Solution {
    private int best = 0;

    public int largestBSTSubtree(TreeNode root) {
        best = 0;
        dfs(root);
        return best;
    }

    private Info dfs(TreeNode node) {
        if (node == null) {
            return new Info(true, Integer.MAX_VALUE, Integer.MIN_VALUE, 0);
        }

        Info L = dfs(node.left);
        Info R = dfs(node.right);

        if (L.isBst && R.isBst && node.val > L.max && node.val < R.min) {
            int size = L.size + R.size + 1;
            best = Math.max(best, size);
            int min = Math.min(L.min, node.val);
            int max = Math.max(R.max, node.val);
            return new Info(true, min, max, size);
        }

        return new Info(false, 0, 0, 0);
    }

    private static class Info {
        boolean isBst;
        int min;
        int max;
        int size;

        Info(boolean isBst, int min, int max, int size) {
            this.isBst = isBst;
            this.min = min;
            this.max = max;
            this.size = size;
        }
    }
}
```
