## 最佳解法思路
- 思路（推荐）：二维 DP（人数 + 利润）  
`dp[j][p]`：用 `j` 个成员、利润至少为 `p` 的方案数（把利润维度压到 `[0..minProfit]`，超过就截断到 `minProfit`）。  
对每个任务 `(group[i], profit[i])` 做 0/1 背包倒序更新。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int profitableSchemes(int n, int minProfit, int[] group, int[] profit) {
        int[][] dp = new int[n + 1][minProfit + 1];
        dp[0][0] = 1;

        for (int i = 0; i < group.length; i++) {
            int g = group[i];
            int p = profit[i];
            for (int j = n; j >= g; j--) {
                for (int k = minProfit; k >= 0; k--) {
                    int nk = Math.min(minProfit, k + p);
                    dp[j][nk] = (dp[j][nk] + dp[j - g][k]) % MOD;
                }
            }
        }

        long ans = 0;
        for (int j = 0; j <= n; j++) {
            ans += dp[j][minProfit];
        }
        return (int) (ans % MOD);
    }
}
```

## 复杂度分析
- 时间：\(O(m \cdot n \cdot P)\)，\(m\)=任务数，\(P\)=minProfit
- 空间：\(O(nP)\)
