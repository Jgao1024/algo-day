## 最佳解法思路
- 思路：递归 + 短路  
用 `&&` 的短路特性代替 `if`：当 `n==0` 时不再递归。

## Java 最佳实现

```java
class Solution {
    public int sumNums(int n) {
        int sum = n;
        boolean ok = (n > 0) && ((sum += sumNums(n - 1)) > 0);
        return sum;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（递归栈）
