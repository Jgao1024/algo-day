## 最佳解法思路
- 思路：BFS 求最短路径 + 父指针还原  
把字典词表建成“通配符模式”索引（例如 `hot` -> `*ot/h*t/ho*`）。  
从 `beginWord` 做 BFS，首次到达 `endWord` 时记录父节点并停止；最后从 `endWord` 沿父指针回溯得到路径。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Queue;
import java.util.Set;

class Solution {
    public List<String> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) {
            return new ArrayList<>();
        }
        dict.add(beginWord);

        Map<String, List<String>> pattern = new HashMap<>();
        int L = beginWord.length();
        for (String w : dict) {
            for (int i = 0; i < L; i++) {
                String p = w.substring(0, i) + "*" + w.substring(i + 1);
                pattern.computeIfAbsent(p, k -> new ArrayList<>()).add(w);
            }
        }

        Queue<String> q = new ArrayDeque<>();
        Set<String> vis = new HashSet<>();
        Map<String, String> parent = new HashMap<>();

        q.add(beginWord);
        vis.add(beginWord);

        boolean found = false;
        while (!q.isEmpty() && !found) {
            int size = q.size();
            Set<String> level = new HashSet<>();

            for (int s = 0; s < size; s++) {
                String cur = q.poll();
                for (int i = 0; i < L; i++) {
                    String p = cur.substring(0, i) + "*" + cur.substring(i + 1);
                    List<String> nexts = pattern.get(p);
                    if (nexts == null) {
                        continue;
                    }
                    for (String nxt : nexts) {
                        if (vis.contains(nxt)) {
                            continue;
                        }
                        if (!level.contains(nxt)) {
                            parent.put(nxt, cur);
                            level.add(nxt);
                            q.add(nxt);
                            if (nxt.equals(endWord)) {
                                found = true;
                            }
                        }
                    }
                }
            }

            vis.addAll(level);
        }

        if (!found) {
            return new ArrayList<>();
        }

        List<String> path = new ArrayList<>();
        String cur = endWord;
        while (cur != null) {
            path.add(cur);
            cur = parent.get(cur);
        }
        Collections.reverse(path);
        return path;
    }
}
```

## 复杂度分析
- 时间：构图 \(O(NL)\)，BFS 取决于扩展规模
- 空间：\(O(NL)\)
