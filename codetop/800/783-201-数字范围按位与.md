## 最佳解法思路
- 思路：找公共前缀  
区间内只要某一位出现过 0 和 1，该位按位与结果就是 0。  
做法是不断把 `left` 和 `right` 同时右移，直到两者相等，记录右移次数 `shift`，最后再左移回去。

## Java 最佳实现

```java
class Solution {
    public int rangeBitwiseAnd(int left, int right) {
        int shift = 0;
        while (left != right) {
            left >>= 1;
            right >>= 1;
            shift++;
        }
        return left << shift;
    }
}
```

## 复杂度分析
- 时间：\(O(\log M)\)
- 空间：\(O(1)\)
