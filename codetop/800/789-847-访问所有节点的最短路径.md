## 最佳解法思路
- 思路（推荐）：状态压缩 BFS  
状态为 `(node, mask)`，`mask` 表示已访问的节点集合。  
从每个节点作为起点做多源 BFS（初始 `mask = 1<<i`），每次走到邻居并更新 `mask`。首次到达 `mask == all` 的层数就是最短路。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int shortestPathLength(int[][] graph) {
        int n = graph.length;
        int all = (1 << n) - 1;

        int[][] dist = new int[n][1 << n];
        for (int i = 0; i < n; i++) {
            for (int m = 0; m < (1 << n); m++) {
                dist[i][m] = -1;
            }
        }

        Queue<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            int mask = 1 << i;
            dist[i][mask] = 0;
            q.add(new int[]{i, mask});
        }

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int u = cur[0];
            int mask = cur[1];
            int d = dist[u][mask];
            if (mask == all) {
                return d;
            }

            for (int v : graph[u]) {
                int nmask = mask | (1 << v);
                if (dist[v][nmask] == -1) {
                    dist[v][nmask] = d + 1;
                    q.add(new int[]{v, nmask});
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot 2^n + m \cdot 2^n)\)
- 空间：\(O(n \cdot 2^n)\)
