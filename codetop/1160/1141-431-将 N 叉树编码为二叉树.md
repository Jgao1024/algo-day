## 最佳解法思路
- 推荐：左孩子-右兄弟（Left-Child Right-Sibling）表示法  
把 N 叉树的“第一个孩子”挂到二叉树的 `left`，把“同层下一个兄弟”挂到二叉树的 `right`。

- 编码 `encode(Node root)`：
  - 当前 N 叉树节点 -> 新建二叉树节点 `TreeNode(root.val)`
  - 若有孩子：`left` 指向第一个孩子的编码结果
  - 其余孩子依次挂到前一个孩子编码节点的 `right`（形成兄弟链）
- 解码 `decode(TreeNode root)`：
  - 当前二叉树节点 -> 新建 N 叉树节点 `Node(root.val, children)`
  - 从 `root.left` 出发，沿着 `right` 链遍历，把每个节点解码后加入 `children`

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

/**
 * // Definition for a Node.
 * class Node {
 *     public int val;
 *     public List<Node> children;
 *
 *     public Node() {}
 *
 *     public Node(int _val) {
 *         val = _val;
 *     }
 *
 *     public Node(int _val, List<Node> _children) {
 *         val = _val;
 *         children = _children;
 *     }
 * };
 *
 * // Definition for a binary tree node.
 * class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Codec {
    // Encodes an n-ary tree to a binary tree.
    public TreeNode encode(Node root) {
        if (root == null) {
            return null;
        }
        TreeNode bRoot = new TreeNode(root.val);
        if (root.children == null || root.children.isEmpty()) {
            return bRoot;
        }

        TreeNode prev = null;
        for (int i = 0; i < root.children.size(); i++) {
            TreeNode cur = encode(root.children.get(i));
            if (i == 0) {
                bRoot.left = cur;
            } else {
                prev.right = cur;
            }
            prev = cur;
        }
        return bRoot;
    }

    // Decodes your binary tree to an n-ary tree.
    public Node decode(TreeNode root) {
        if (root == null) {
            return null;
        }
        List<Node> children = new ArrayList<Node>();
        TreeNode cur = root.left;
        while (cur != null) {
            children.add(decode(cur));
            cur = cur.right;
        }
        return new Node(root.val, children);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈，最坏 \(O(n)\)）
