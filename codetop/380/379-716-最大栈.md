# 716. 最大栈

- 题号：716
- 难度：简单
- LeetCode：[最大栈](https://leetcode.cn/problems/max-stack/)

## 题目描述
设计一个最大栈 `MaxStack`，支持：`push(x)`, `pop()`, `top()`, `peekMax()`, `popMax()`。  
`popMax()` 需要移除并返回当前栈中的最大值；若有多个最大值，移除最靠近栈顶的那个。

## 示例
- 示例  
`push(5), push(1), push(5)`  
`top()` -> `5`  
`popMax()` -> `5`  
`top()` -> `1`  
`peekMax()` -> `5`  
`pop()` -> `1`  
`top()` -> `5`

## 最佳解法思路
- 思路1（推荐）：双向链表 + TreeMap  
用双向链表维护栈的顺序（尾部为栈顶），实现 `pop/top` \(O(1)\)。  
用 `TreeMap<val, Deque<Node>>` 记录每个值在链表中的节点引用（按入栈顺序保存），`peekMax` 取 `lastKey`。  
`popMax`：从最大值对应的节点栈取出“最近入栈的最大值节点”，从链表中删除即可。整体 \(O(\log n)\)。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.TreeMap;

class MaxStack {
    private static class Node {
        int val;
        Node prev;
        Node next;
        Node(int v) { val = v; }
    }

    private final Node head = new Node(0);
    private final Node tail = new Node(0);
    private final TreeMap<Integer, Deque<Node>> map = new TreeMap<>();

    public MaxStack() {
        head.next = tail;
        tail.prev = head;
    }

    public void push(int x) {
        Node node = new Node(x);
        addLast(node);
        map.computeIfAbsent(x, k -> new ArrayDeque<>()).addLast(node);
    }

    public int pop() {
        Node node = tail.prev;
        remove(node);
        Deque<Node> st = map.get(node.val);
        st.removeLast();
        if (st.isEmpty()) map.remove(node.val);
        return node.val;
    }

    public int top() {
        return tail.prev.val;
    }

    public int peekMax() {
        return map.lastKey();
    }

    public int popMax() {
        int max = map.lastKey();
        Deque<Node> st = map.get(max);
        Node node = st.removeLast();
        if (st.isEmpty()) map.remove(max);
        remove(node);
        return max;
    }

    private void addLast(Node node) {
        Node p = tail.prev;
        p.next = node;
        node.prev = p;
        node.next = tail;
        tail.prev = node;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```

## 复杂度分析
- 时间：`push/top/peekMax` 为 \(O(1)\)，`pop/popMax` 为 \(O(\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 栈顺序用双向链表，最大值用 TreeMap；`popMax` 直接定位到“最近的最大值节点”并删掉。
