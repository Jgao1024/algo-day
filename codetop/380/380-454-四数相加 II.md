# 454. 四数相加 II

- 题号：454
- 难度：中等
- LeetCode：[四数相加 II](https://leetcode.cn/problems/4sum-ii/)

## 题目描述
给定四个整数数组 `A,B,C,D`，计算有多少个元组 `(i,j,k,l)` 使得 `A[i]+B[j]+C[k]+D[l] == 0`。

## 示例
- 示例  
输入：`A=[1,2], B=[-2,-1], C=[-1,2], D=[0,2]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：两两分组 + 哈希计数  
先枚举 `A+B` 的所有和，统计频次 `cnt[sum]`。  
再枚举 `C+D` 的所有和 `s2`，答案累加 `cnt[-s2]`。  
把四数问题降为两个两数和的匹配。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int fourSumCount(int[] A, int[] B, int[] C, int[] D) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int a : A) {
            for (int b : B) {
                int s = a + b;
                cnt.put(s, cnt.getOrDefault(s, 0) + 1);
            }
        }

        int ans = 0;
        for (int c : C) {
            for (int d : D) {
                ans += cnt.getOrDefault(-(c + d), 0);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)

## 相关题目

## 总结（速记）
- 四数=两两分组：先存 `A+B` 频次，再匹配 `-(C+D)`。
