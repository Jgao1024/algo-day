# 722. 删除注释

- 题号：722
- 难度：中等
- LeetCode：[删除注释](https://leetcode.cn/problems/remove-comments/)

## 题目描述
给定源码 `source`（每行一个字符串），移除 `//` 行注释和 `/* */` 块注释，返回去注释后的源码（空行不输出）。

## 示例
- 示例  
输入：`["/*test*/","int main()","{","// hello","}"]`  
输出：`["int main()","{","}"]`

## 最佳解法思路
- 思路1（推荐）：逐字符扫描 + 状态机  
维护 `inBlock` 表示是否在块注释中；`sb` 作为当前行输出缓存。  
遍历每行每个字符：  
- 若在块注释中：只寻找 `*/` 结束  
- 若不在块注释中：遇到 `//` 直接结束本行；遇到 `/*` 进入块注释；否则把字符加入 `sb`  
每行结束时，若不在块注释且 `sb` 非空，把 `sb.toString()` 加入结果并清空。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> removeComments(String[] source) {
        List<String> ans = new ArrayList<>();
        boolean inBlock = false;
        StringBuilder sb = new StringBuilder();

        for (String line : source) {
            int i = 0;
            if (!inBlock) sb.setLength(0);
            while (i < line.length()) {
                if (inBlock) {
                    if (i + 1 < line.length() && line.charAt(i) == '*' && line.charAt(i + 1) == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        i++;
                    }
                } else {
                    if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '/') {
                        break;
                    } else if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '*') {
                        inBlock = true;
                        i += 2;
                    } else {
                        sb.append(line.charAt(i++));
                    }
                }
            }
            if (!inBlock && sb.length() > 0) ans.add(sb.toString());
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\text{总字符数})\)
- 空间：\(O(\text{总字符数})\)（输出）

- 关键是 `inBlock` 状态：块注释跨行；行注释遇到 `//` 直接截断。
