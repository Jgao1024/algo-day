# 1171. 从链表中删去总和值为零的连续节点

- 题号：1171
- 难度：中等
- LeetCode：[从链表中删去总和值为零的连续节点](https://leetcode.cn/problems/remove-zero-sum-consecutive-nodes-from-linked-list/)

## 题目描述
删除链表中所有“连续节点和为 0”的子链表，返回删除后的链表头。

## 示例
- 示例  
输入：`head = [1,2,-3,3,1]`  
输出：`[3,1]`

## 最佳解法思路
- 思路1（推荐）：前缀和 + 哈希表（两遍）  
用虚拟头 `dummy`，把前缀和定义为从 `dummy` 到当前节点的累加和。  
若两个位置前缀和相同，说明它们之间的节点和为 0，应被删除。  
两遍做法：  
1) 第一遍遍历，记录“每个前缀和最后一次出现的节点”。  
2) 第二遍再走一遍，利用 map 把 `cur.next` 直接跳到 `map.get(sum).next`，一次性删掉中间 0 和段。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public ListNode removeZeroSumSublists(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        Map<Integer, ListNode> last = new HashMap<>();
        int sum = 0;
        for (ListNode cur = dummy; cur != null; cur = cur.next) {
            sum += cur.val;
            last.put(sum, cur);
        }

        sum = 0;
        for (ListNode cur = dummy; cur != null; cur = cur.next) {
            sum += cur.val;
            cur.next = last.get(sum).next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 前缀和相等 => 中间和为 0；用“记录最后一次出现”才能一次跳过最长可删段。
