# 57. 插入区间

- 题号：57
- 难度：困难
- LeetCode：[插入区间](https://leetcode.cn/problems/insert-interval/)

## 题目描述
给定一组不重叠且按起点排序的区间 `intervals`，插入新区间 `newInterval`，并合并重叠区间。

## 示例
- 示例  
输入：`intervals = [[1,3],[6,9]]`, `newInterval = [2,5]`  
输出：`[[1,5],[6,9]]`

## 最佳解法思路
- 思路1（推荐）：一次扫描  
分三段处理：  
- 完全在 `newInterval` 左侧的（`end < newStart`）直接加入答案  
- 与 `newInterval` 有交集的合并到 `newInterval`（更新 `start=min`、`end=max`）  
- 完全在右侧的（`start > newEnd`）先把合并后的 `newInterval` 加入，再把剩余区间全部加入

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> res = new ArrayList<>();
        int i = 0;
        int n = intervals.length;

        while (i < n && intervals[i][1] < newInterval[0]) {
            res.add(intervals[i++]);
        }

        while (i < n && intervals[i][0] <= newInterval[1]) {
            newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
            newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
            i++;
        }
        res.add(newInterval);

        while (i < n) res.add(intervals[i++]);

        return res.toArray(new int[res.size()][]);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（输出）

## 总结（速记）
- 扫描三段：左边直接放，中间合并，右边直接放（合并后的新区间只入一次）。
