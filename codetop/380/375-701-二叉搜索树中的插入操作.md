# 701. 二叉搜索树中的插入操作

- 题号：701
- 难度：中等
- LeetCode：[二叉搜索树中的插入操作](https://leetcode.cn/problems/insert-into-a-binary-search-tree/)

## 题目描述
在 BST 中插入值 `val`，返回插入后的根节点（保证 val 不存在）。

## 示例
- 示例  
输入：`root = [4,2,7,1,3]`, `val = 5`  
输出：`[4,2,7,1,3,5]`

## 最佳解法思路
- 思路1（推荐）：迭代查找插入位置  
从根开始：`val < cur.val` 走左，否则走右。  
走到空位置就把新节点挂上。

## Java 最佳实现

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) return new TreeNode(val);
        TreeNode cur = root;
        while (true) {
            if (val < cur.val) {
                if (cur.left == null) {
                    cur.left = new TreeNode(val);
                    break;
                }
                cur = cur.left;
            } else {
                if (cur.right == null) {
                    cur.right = new TreeNode(val);
                    break;
                }
                cur = cur.right;
            }
        }
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)（h 为树高）
- 空间：\(O(1)\)
