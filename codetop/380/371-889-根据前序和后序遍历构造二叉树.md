# 889. 根据前序和后序遍历构造二叉树

- 题号：889
- 难度：中等
- LeetCode：[根据前序和后序遍历构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-postorder-traversal/)

## 题目描述
给定一棵二叉树的前序遍历 `preorder` 和后序遍历 `postorder`（节点值互不相同），构造并返回这棵二叉树（答案不唯一，返回任意一种即可）。

## 示例
- 示例  
输入：`preorder = [1,2,4,5,3,6,7]`，`postorder = [4,5,2,6,7,3,1]`  
输出：`[1,2,3,4,5,6,7]`（一种可能）

## 最佳解法思路
- 思路1（推荐）：递归分治 + 后序位置哈希表  
前序的第一个是根 `root`。若子树不止一个节点，则 `pre[preIdx+1]` 是左子树根。  
在后序中找到左子树根的位置 `p`，则左子树大小 `leftSize = p - postL + 1`。  
据此划分左右子树区间递归构建即可。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int preIdx = 0;
    private int[] pre;
    private int[] post;
    private Map<Integer, Integer> pos = new HashMap<>();

    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        this.pre = preorder;
        this.post = postorder;
        for (int i = 0; i < post.length; i++) pos.put(post[i], i);
        return build(0, post.length - 1);
    }

    private TreeNode build(int postL, int postR) {
        TreeNode root = new TreeNode(pre[preIdx++]);
        if (postL == postR) return root;

        int leftRootVal = pre[preIdx];
        int p = pos.get(leftRootVal);
        int leftSize = p - postL + 1;

        root.left = build(postL, postL + leftSize - 1);
        if (postL + leftSize <= postR - 1) {
            root.right = build(postL + leftSize, postR - 1);
        }
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（哈希表 + 递归栈）

## 总结（速记）
- 前序定根；左子树根是 `pre[preIdx]`；在后序里定位左子树范围即可切分递归。
