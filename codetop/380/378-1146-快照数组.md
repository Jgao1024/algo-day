# 1146. 快照数组

- 题号：1146
- 难度：中等
- LeetCode：[快照数组](https://leetcode.cn/problems/snapshot-array/)

## 题目描述
实现一个可快照的数组：  
- `SnapshotArray(length)` 初始化长度为 `length` 的数组，初始全 0  
- `set(index, val)` 设置当前值  
- `snap()` 生成一个快照并返回快照 id  
- `get(index, snap_id)` 返回该下标在指定快照时的值

## 示例
- 示例  
`set(0,5)`  
`snap()` -> `0`  
`set(0,6)`  
`get(0,0)` -> `5`

## 最佳解法思路
- 思路1（推荐）：每个下标维护一条变更记录（snap_id -> val）  
对每个 index 维护一个按 `snap_id` 升序的列表 `[(snap,val)...]`，初始有 `(0,0)`。  
`set`：若最后一条记录的 `snap_id` 等于当前 `snapId`，直接覆盖；否则追加。  
`get`：在列表里二分找到 `snap_id` 对应的“最后一条 <= snap_id”的记录。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class SnapshotArray {
    private final List<int[]>[] hist;
    private int snapId = 0;

    @SuppressWarnings("unchecked")
    public SnapshotArray(int length) {
        hist = new List[length];
        for (int i = 0; i < length; i++) {
            hist[i] = new ArrayList<>();
            hist[i].add(new int[]{0, 0});
        }
    }

    public void set(int index, int val) {
        List<int[]> list = hist[index];
        int[] last = list.get(list.size() - 1);
        if (last[0] == snapId) {
            last[1] = val;
        } else {
            list.add(new int[]{snapId, val});
        }
    }

    public int snap() {
        return snapId++;
    }

    public int get(int index, int snap_id) {
        List<int[]> list = hist[index];
        int l = 0, r = list.size() - 1;
        while (l <= r) {
            int mid = (l + r) >>> 1;
            if (list.get(mid)[0] <= snap_id) l = mid + 1;
            else r = mid - 1;
        }
        return list.get(r)[1];
    }
}
```

## 复杂度分析
- 时间：`set` 均摊 \(O(1)\)，`snap` 为 \(O(1)\)，`get` 为 \(O(\log m)\)（m 为该下标的变更次数）
- 空间：\(O(\text{总变更次数})\)
