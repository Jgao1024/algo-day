# 895. 最大频率栈

- 题号：895
- 难度：困难
- LeetCode：[最大频率栈](https://leetcode.cn/problems/maximum-frequency-stack/)

## 题目描述
设计一个类似栈的数据结构 `FreqStack`：  
`push(x)` 把 x 入栈；`pop()` 弹出出现频率最高的元素；若频率相同，弹出离栈顶最近的那个。

## 示例
- 示例  
`push(5), push(7), push(5), push(7), push(4), push(5)`  
`pop()` -> `5`  
`pop()` -> `7`  
`pop()` -> `5`  
`pop()` -> `4`

## 最佳解法思路
- 思路1（推荐）：频次表 + 频次栈组  
`freq[x]` 记录每个值出现次数。  
`group[f]` 是一个栈，保存“频次为 f 的入栈顺序”（用 `Deque`）。  
每次 `push(x)`：频次 `f=++freq[x]`，把 x 压入 `group[f]`，更新 `maxFreq`。  
每次 `pop()`：从 `group[maxFreq]` 弹出栈顶元素 x，`freq[x]--`；若该组空了，`maxFreq--`。  
所有操作都是 \(O(1)\)。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

class FreqStack {
    private final Map<Integer, Integer> freq = new HashMap<>();
    private final Map<Integer, Deque<Integer>> group = new HashMap<>();
    private int maxFreq = 0;

    public FreqStack() {
    }

    public void push(int val) {
        int f = freq.getOrDefault(val, 0) + 1;
        freq.put(val, f);
        if (f > maxFreq) maxFreq = f;
        group.computeIfAbsent(f, k -> new ArrayDeque<>()).push(val);
    }

    public int pop() {
        Deque<Integer> st = group.get(maxFreq);
        int x = st.pop();
        freq.put(x, freq.get(x) - 1);
        if (st.isEmpty()) {
            group.remove(maxFreq);
            maxFreq--;
        }
        return x;
    }
}
```

## 复杂度分析
- 时间：`push/pop` 均为 \(O(1)\)
- 空间：\(O(n)\)

## 总结（速记）
- 频次最高且最近：按“频次分组的栈”，永远从 `maxFreq` 的栈顶弹。
