# 补充题8. 计算数组的小和

- 题号：补充题8
- 难度：中等
- 题面链接：[计算数组的小和](https://mp.weixin.qq.com/s/rMsbcUf9ZPhvfRoyZGW6HA)

## 题目描述
数组“小和”定义：对每个元素 `arr[i]`，它左边比它小的元素之和，所有 i 的该值累加起来。

## 示例
- 示例  
输入：`[1,3,4,2,5]`  
输出：`16`  
解释：  
1 左边小的和=0  
3 左边小的和=1  
4 左边小的和=1+3=4  
2 左边小的和=1  
5 左边小的和=1+3+4+2=10  
总计 0+1+4+1+10=16

## 最佳解法思路
- 思路1（推荐）：归并排序统计  
在归并的“合并两段有序数组”过程中：  
当 `left[i] < right[j]`，说明 `left[i]` 比右侧从 `j..end` 的所有元素都小，它会对这些元素贡献 `left[i] * (rightEnd - j + 1)` 的小和。  
用分治 + 合并即可在 \(O(n\log n)\) 内完成。

## Java 最佳实现

```java
class Solution {
    public long smallSum(int[] arr) {
        if (arr == null || arr.length < 2) return 0;
        int[] tmp = new int[arr.length];
        return sort(arr, 0, arr.length - 1, tmp);
    }

    private long sort(int[] a, int l, int r, int[] tmp) {
        if (l >= r) return 0;
        int mid = l + ((r - l) >>> 1);
        long ans = sort(a, l, mid, tmp) + sort(a, mid + 1, r, tmp);
        ans += merge(a, l, mid, r, tmp);
        return ans;
    }

    private long merge(int[] a, int l, int mid, int r, int[] tmp) {
        int i = l, j = mid + 1, k = l;
        long ans = 0;
        while (i <= mid && j <= r) {
            if (a[i] < a[j]) {
                ans += (long) a[i] * (r - j + 1);
                tmp[k++] = a[i++];
            } else {
                tmp[k++] = a[j++];
            }
        }
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= r) tmp[k++] = a[j++];
        for (int p = l; p <= r; p++) a[p] = tmp[p];
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 小和=“左边小于它的数之和”，归并时用 `a[i] < a[j]` 一次性贡献 `a[i] * (右边剩余个数)`。
