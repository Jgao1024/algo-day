# 405. 数字转换为十六进制数

- 题号：405
- 难度：简单
- LeetCode：[数字转换为十六进制数](https://leetcode.cn/problems/convert-a-number-to-hexadecimal/)

## 题目描述
给定一个 32 位有符号整数 `num`，返回其十六进制表示（小写），负数按补码处理。

## 示例
- 示例1  
输入：`num = 26`  
输出：`"1a"`

- 示例2  
输入：`num = -1`  
输出：`"ffffffff"`

## 最佳解法思路
- 思路1（推荐）：按 4 bit 取值（无符号右移）  
十六进制每位对应 4 bit：反复取 `num & 0xf` 得到低 4 位，然后 `num >>>= 4`（无符号右移）。  
循环最多 8 次（32/4）。`num==0` 特判返回 `"0"`。

## Java 最佳实现

```java
class Solution {
    public String toHex(int num) {
        if (num == 0) return "0";
        char[] map = "0123456789abcdef".toCharArray();
        StringBuilder sb = new StringBuilder();
        int x = num;
        while (x != 0) {
            sb.append(map[x & 0xf]);
            x >>>= 4;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（最多 8 次循环）
- 空间：\(O(1)\)

- 每次取低 4 位 `& 0xf`，再用 `>>> 4` 无符号右移，最多 8 位。
