# 剑指 Offer 65. 不用加减乘除做加法

- 题号：剑指 Offer 65
- 难度：简单
- LeetCode：[不用加减乘除做加法](https://leetcode.cn/problems/bu-yong-jia-jian-cheng-chu-zuo-jia-fa-lcof/)

## 题目描述
不用 `+ - * /` 计算两个整数 `a+b`。

## 示例
- 示例  
输入：`a = 1, b = 2`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：位运算模拟加法  
`sum = a ^ b` 表示“不带进位的和”；  
`carry = (a & b) << 1` 表示进位；  
不断用 `a=sum, b=carry` 迭代，直到 `carry==0`。

## Java 最佳实现

```java
class Solution {
    public int add(int a, int b) {
        while (b != 0) {
            int sum = a ^ b;
            int carry = (a & b) << 1;
            a = sum;
            b = carry;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（最多 32 次迭代）
- 空间：\(O(1)\)

- 异或管“和”，与再左移管“进位”，进位为 0 结束。
