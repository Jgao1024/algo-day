# 252. 会议室

- 题号：252
- 难度：简单
- LeetCode：[会议室](https://leetcode.cn/problems/meeting-rooms/)

## 题目描述
给定会议区间 `intervals[i]=[start,end]`，判断一个人是否能参加所有会议（即区间是否互不重叠）。

## 示例
- 示例1  
输入：`[[0,30],[5,10],[15,20]]`  
输出：`false`

- 示例2  
输入：`[[7,10],[2,4]]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：按开始时间排序后检查相邻重叠  
排序后只需检查：`intervals[i][0] < intervals[i-1][1]` 则重叠，返回 false；否则继续。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] < intervals[i - 1][1]) return false;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（排序可能使用额外栈空间）
