# 补充题17. 两个有序数组第k小的数

- 题号：补充题17
- 难度：困难
- LeetCode：[两个有序数组第k小的数](https://leetcode.cn/problemset/all/?search=%E8%A1%A5%E5%85%85%E9%A2%9817)

## 题目描述
给定两个升序数组 `a`、`b`，返回它们合并后的第 `k` 小元素（从 1 开始计数）。

## 示例
- 示例  
`a = [1,3,5]`，`b = [2,4,6]`，`k = 4`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：二分淘汰（每次丢掉 k/2 个元素）  
在 `a[i...]` 与 `b[j...]` 里找第 k 小：  
比较 `a[i + k/2 - 1]` 与 `b[j + k/2 - 1]`，较小的一侧不可能包含第 k 小（它及其前面最多只有 k/2 个），直接淘汰这 k/2 个元素，并让 `k -= k/2`。  
用边界处理（越界当作 +∞）即可迭代完成。

## Java 最佳实现

```java
class Solution {
    public int kth(int[] a, int[] b, int k) {
        int i = 0, j = 0;
        int m = a.length, n = b.length;

        while (true) {
            if (i >= m) return b[j + k - 1];
            if (j >= n) return a[i + k - 1];
            if (k == 1) return Math.min(a[i], b[j]);

            int half = k >>> 1;
            int ai = i + half - 1;
            int bj = j + half - 1;
            int aval = ai < m ? a[ai] : Integer.MAX_VALUE;
            int bval = bj < n ? b[bj] : Integer.MAX_VALUE;

            if (aval <= bval) {
                i += half;
                k -= half;
            } else {
                j += half;
                k -= half;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(\log k)\)
- 空间：\(O(1)\)

## 总结（速记）
- 第 k 小：每次比较两边第 `k/2` 个，丢掉更小的一边的 `k/2` 个元素。
