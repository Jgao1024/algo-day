# 852. 山脉数组的峰顶索引

- 题号：852
- 难度：简单
- LeetCode：[山脉数组的峰顶索引](https://leetcode.cn/problems/peak-index-in-a-mountain-array/)

## 题目描述
给定山脉数组（先严格递增后严格递减），返回峰顶下标。

## 示例
- 示例  
输入：`arr = [0,2,1,0]`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：二分查找峰值  
比较 `arr[mid]` 和 `arr[mid+1]`：  
- 若 `arr[mid] < arr[mid+1]`，峰在右侧（上坡）  
- 否则峰在左侧或 mid（下坡）  
最终 `l==r` 即峰顶。

## Java 最佳实现

```java
class Solution {
    public int peakIndexInMountainArray(int[] arr) {
        int l = 0, r = arr.length - 1;
        while (l < r) {
            int mid = l + ((r - l) >>> 1);
            if (arr[mid] < arr[mid + 1]) l = mid + 1;
            else r = mid;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
