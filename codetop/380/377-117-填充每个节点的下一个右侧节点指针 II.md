# 117. 填充每个节点的下一个右侧节点指针 II

- 题号：117
- 难度：中等
- LeetCode：[填充每个节点的下一个右侧节点指针 II](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node-ii/)

## 题目描述
给定二叉树（不一定完美），填充每个节点的 `next` 指针，指向其右侧下一个节点；若不存在则为 `null`。

## 示例
- 示例  
输入：`root = [1,2,3,4,5,null,7]`  
输出：`[1,#,2,3,#,4,5,7,#]`

## 最佳解法思路
- 思路1（推荐）：按层遍历，利用 next 串起下一层（\(O(1)\) 额外空间）  
用 `cur` 指向当前层的起点，遍历当前层时用一个 `dummy` 和 `tail` 把下一层的节点按从左到右串起来（通过 `next`）。  
当前层遍历完后，`cur = dummy.next` 进入下一层。

## Java 最佳实现

```java
class Solution {
    public Node connect(Node root) {
        Node cur = root;
        while (cur != null) {
            Node dummy = new Node(0);
            Node tail = dummy;
            for (Node p = cur; p != null; p = p.next) {
                if (p.left != null) {
                    tail.next = p.left;
                    tail = tail.next;
                }
                if (p.right != null) {
                    tail.next = p.right;
                    tail = tail.next;
                }
            }
            cur = dummy.next;
        }
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 每层用 `dummy/tail` 串下一层，靠 `next` 横向扫当前层，整体 \(O(1)\) 额外空间。
