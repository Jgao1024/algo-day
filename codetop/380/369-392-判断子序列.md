# 392. 判断子序列

- 题号：392
- 难度：简单
- LeetCode：[判断子序列](https://leetcode.cn/problems/is-subsequence/)

## 题目描述
判断字符串 `s` 是否为 `t` 的子序列。

## 示例
- 示例  
输入：`s = "abc"`, `t = "ahbgdc"`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：双指针  
用指针 i 扫 `s`，指针 j 扫 `t`：  
当 `s[i]==t[j]` 时 i++；j 每次都 ++。最终 i 到达 `s.length()` 则是子序列。

## Java 最佳实现

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) i++;
            j++;
        }
        return i == s.length();
    }
}
```

## 复杂度分析
- 时间：\(O(|t|)\)
- 空间：\(O(1)\)
