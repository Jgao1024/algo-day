# 159. 至多包含两个不同字符的最长子串

- 题号：159
- 难度：中等
- LeetCode：[至多包含两个不同字符的最长子串](https://leetcode.cn/problems/longest-substring-with-at-most-two-distinct-characters/)

## 题目描述
给定字符串 `s`，返回至多包含两个不同字符的最长子串长度。

## 示例
- 示例1  
输入：`s = "eceba"`  
输出：`3`（"ece"）

- 示例2  
输入：`s = "ccaabbb"`  
输出：`5`（"aabbb"）

## 最佳解法思路
- 思路1（推荐）：滑动窗口 + 计数  
用 `cnt[256]` 统计窗口内字符出现次数，维护 `distinct`。  
右指针扩展时若新字符出现次数从 0 变 1，则 `distinct++`；  
当 `distinct > 2` 时移动左指针收缩窗口，直到 `distinct <= 2`。  
每一步更新窗口最大长度。

## Java 最佳实现

```java
class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        int[] cnt = new int[256];
        int distinct = 0;
        int l = 0;
        int ans = 0;
        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            if (cnt[c]++ == 0) distinct++;
            while (distinct > 2) {
                char lc = s.charAt(l++);
                if (--cnt[lc] == 0) distinct--;
            }
            ans = Math.max(ans, r - l + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
