# 30. 串联所有单词的子串

- 题号：30
- 难度：困难
- LeetCode：[串联所有单词的子串](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/)

## 题目描述
给定字符串 `s` 和字符串数组 `words`（每个单词长度相同），找到所有起始下标，使得从该位置开始长度为 `words.length * wordLen` 的子串恰好由 `words` 的所有单词拼接而成（顺序不限，不允许额外字符）。

## 示例
- 示例  
输入：`s = "barfoothefoobarman"`, `words = ["foo","bar"]`  
输出：`[0,9]`

## 最佳解法思路
- 思路1（推荐）：按单词长度分组滑动窗口  
设单词长度 `L`，总单词数 `W`。  
对每个起点偏移 `offset=0..L-1`，以步长 `L` 在 `s` 上滑动：  
维护窗口内每个单词出现次数 `window`，当某个词次数超了就不断移动左边界（每次左移一个单词）。  
当窗口里恰好包含 `W` 个单词时记录左边界。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<Integer> findSubstring(String s, String[] words) {
        List<Integer> ans = new ArrayList<>();
        if (words == null || words.length == 0) return ans;

        int n = s.length();
        int L = words[0].length();
        int W = words.length;
        int total = L * W;
        if (n < total) return ans;

        Map<String, Integer> need = new HashMap<>();
        for (String w : words) need.put(w, need.getOrDefault(w, 0) + 1);

        for (int offset = 0; offset < L; offset++) {
            Map<String, Integer> win = new HashMap<>();
            int left = offset;
            int count = 0;

            for (int right = offset; right + L <= n; right += L) {
                String w = s.substring(right, right + L);
                if (!need.containsKey(w)) {
                    win.clear();
                    count = 0;
                    left = right + L;
                    continue;
                }

                win.put(w, win.getOrDefault(w, 0) + 1);
                count++;
                while (win.get(w) > need.get(w)) {
                    String lw = s.substring(left, left + L);
                    win.put(lw, win.get(lw) - 1);
                    left += L;
                    count--;
                }

                if (count == W) {
                    ans.add(left);
                    String lw = s.substring(left, left + L);
                    win.put(lw, win.get(lw) - 1);
                    left += L;
                    count--;
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（把 `substring` 视为 \(O(1)\) 的情况下；严格实现可用 rolling hash 优化）
- 空间：\(O(|words|)\)

## 总结（速记）
- 按单词长度分成 L 组窗口，窗口每次移动一个“单词块”，超频就缩左边界。
