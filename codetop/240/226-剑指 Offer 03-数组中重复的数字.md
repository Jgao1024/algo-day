## 最佳解法思路
- 思路（推荐）：原地交换，把数字放回它该在的位置  
数组长度为 n，数字范围通常是 `0..n-1`。遍历下标 i：  
只要 `nums[i] != i`，就把 `nums[i]` 交换到下标 `nums[i]` 上；如果发现 `nums[i] == nums[nums[i]]`，说明重复，直接返回。

## Java 最佳实现

```java
class Solution {
    public int findRepeatNumber(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            while (nums[i] != i) {
                int v = nums[i];
                if (nums[v] == v) {
                    return v;
                }
                nums[i] = nums[v];
                nums[v] = v;
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
