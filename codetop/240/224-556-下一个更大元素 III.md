## 最佳解法思路
- 思路（推荐）：下一个排列（next permutation）  
把数字转成字符数组：  
从右往左找第一个 `a[i] < a[i+1]` 的位置 i；再从右往左找第一个 `a[j] > a[i]` 的位置 j 交换；最后把 i+1 到末尾反转成最小。  
把结果转回 long，超过 32 位 int 就返回 -1。

## Java 最佳实现

```java
class Solution {
    public int nextGreaterElement(int n) {
        char[] a = String.valueOf(n).toCharArray();

        int i = a.length - 2;
        while (i >= 0 && a[i] >= a[i + 1]) {
            i--;
        }
        if (i < 0) {
            return -1;
        }

        int j = a.length - 1;
        while (a[j] <= a[i]) {
            j--;
        }
        swap(a, i, j);
        reverse(a, i + 1, a.length - 1);

        long v = Long.parseLong(new String(a));
        return v > Integer.MAX_VALUE ? -1 : (int) v;
    }

    private void swap(char[] a, int i, int j) {
        char t = a[i];
        a[i] = a[j];
        a[j] = t;
    }

    private void reverse(char[] a, int l, int r) {
        while (l < r) {
            swap(a, l++, r--);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(k)\)（k 为数字位数）
- 空间：\(O(k)\)
