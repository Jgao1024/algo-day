## 最佳解法思路
- 思路（推荐）：DP 计数（可压缩到一维）  
设 `dp[j]` 表示 `s` 扫描到当前为止，组成 `t[0..j)` 的方案数。  
初始化 `dp[0]=1`（空串只有 1 种）。遍历 `s` 的每个字符 `sc`，倒序遍历 `t`：  
若 `sc == t[j-1]`，则 `dp[j] += dp[j-1]`。

## Java 最佳实现

```java
class Solution {
    public int numDistinct(String s, String t) {
        int m = t.length();
        long[] dp = new long[m + 1];
        dp[0] = 1;

        for (int i = 0; i < s.length(); i++) {
            char sc = s.charAt(i);
            for (int j = m; j >= 1; j--) {
                if (sc == t.charAt(j - 1)) {
                    dp[j] += dp[j - 1];
                }
            }
        }
        return (int) dp[m];
    }
}
```

## 复杂度分析
- 时间：\(O(|s|\cdot|t|)\)
- 空间：\(O(|t|)\)
