## 最佳解法思路
- 思路（推荐）：异或分组  
所有数异或得到 `xor = a ^ b`（a、b 为只出现一次的两个数）。取 `lowbit = xor & -xor` 找到 a 和 b 在该位上不同的那一位。  
用 `lowbit` 把数组分成两组分别异或，就能得到 a、b。

## Java 最佳实现

```java
class Solution {
    public int[] singleNumber(int[] nums) {
        int xor = 0;
        for (int v : nums) {
            xor ^= v;
        }
        int lowbit = xor & -xor;

        int a = 0;
        int b = 0;
        for (int v : nums) {
            if ((v & lowbit) == 0) {
                a ^= v;
            } else {
                b ^= v;
            }
        }
        return new int[]{a, b};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
