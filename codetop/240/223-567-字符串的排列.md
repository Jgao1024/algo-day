## 最佳解法思路
- 思路（推荐）：固定滑动窗口 + 计数差  
窗口长度固定为 `s1.length()`，用 `cnt[26]` 维护“s1 需要的字符数 - 当前窗口字符数”。  
初始化 s1 计数为正、窗口计数为负；若所有位置都为 0，说明窗口是 s1 的一个排列。窗口右移时，右端字符 `--`，左端移出字符 `++`。

## Java 最佳实现

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int n = s1.length();
        if (n > s2.length()) {
            return false;
        }

        int[] cnt = new int[26];
        for (int i = 0; i < n; i++) {
            cnt[s1.charAt(i) - 'a']++;
            cnt[s2.charAt(i) - 'a']--;
        }
        if (allZero(cnt)) {
            return true;
        }

        for (int i = n; i < s2.length(); i++) {
            cnt[s2.charAt(i) - 'a']--;
            cnt[s2.charAt(i - n) - 'a']++;
            if (allZero(cnt)) {
                return true;
            }
        }
        return false;
    }

    private boolean allZero(int[] cnt) {
        for (int v : cnt) {
            if (v != 0) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（每步检查 26 个字符）
- 空间：\(O(1)\)
