## 最佳解法思路
- 思路（推荐）：答案二分 + 贪心验证  
最大分割和的最小值一定在 `[max(nums), sum(nums)]`。二分一个上限 `mid`，用贪心从左到右累加：  
若加入当前数会超过 `mid`，就切一刀开始新段。统计需要的段数 `parts`。  
若 `parts <= m` 说明 `mid` 可行，收缩右边界；否则增大 `mid`。

## Java 最佳实现

```java
class Solution {
    public int splitArray(int[] nums, int m) {
        int max = 0;
        long sum = 0;
        for (int v : nums) {
            max = Math.max(max, v);
            sum += v;
        }

        long low = max;
        long high = sum;
        while (low < high) {
            long mid = low + (high - low) / 2;
            if (canSplit(nums, m, mid)) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return (int) low;
    }

    private boolean canSplit(int[] nums, int m, long limit) {
        int parts = 1;
        long cur = 0;
        for (int v : nums) {
            if (cur + v > limit) {
                parts++;
                cur = v;
                if (parts > m) {
                    return false;
                }
            } else {
                cur += v;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log \sum)\)
- 空间：\(O(1)\)
