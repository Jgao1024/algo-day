## 最佳解法思路
- 思路（推荐）：二分（处理重复）  
和无重复版本类似，比较 `nums[mid]` 与 `nums[r]`：  
- 若 `nums[mid] < nums[r]`，最小值在左侧（含 mid），`r = mid`  
- 若 `nums[mid] > nums[r]`，最小值在右侧，`l = mid + 1`  
- 若相等无法判断，`r--` 缩小范围  
最后 `l==r` 即最小值位置。

## Java 最佳实现

```java
class Solution {
    public int findMin(int[] nums) {
        int l = 0;
        int r = nums.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] < nums[r]) {
                r = mid;
            } else if (nums[mid] > nums[r]) {
                l = mid + 1;
            } else {
                r--;
            }
        }
        return nums[l];
    }
}
```

## 复杂度分析
- 时间：平均 \(O(\log n)\)，最坏 \(O(n)\)
- 空间：\(O(1)\)
