## 最佳解法思路
- 思路（推荐）：按值二分 + 计数  
矩阵每行每列递增，答案在 `[min, max]`。二分一个值 `mid`，统计矩阵中 `<= mid` 的元素个数 `cnt`：  
从左下角出发，若 `matrix[r][c] <= mid`，则这一列上方 `r+1` 个都满足，`c++`；否则 `r--`。  
若 `cnt >= k`，答案在左边，否则在右边。

## Java 最佳实现

```java
class Solution {
    public int kthSmallest(int[][] matrix, int k) {
        int n = matrix.length;
        int low = matrix[0][0];
        int high = matrix[n - 1][n - 1];

        while (low < high) {
            int mid = low + (high - low) / 2;
            int cnt = countLE(matrix, mid);
            if (cnt >= k) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    }

    private int countLE(int[][] a, int x) {
        int n = a.length;
        int r = n - 1;
        int c = 0;
        int cnt = 0;
        while (r >= 0 && c < n) {
            if (a[r][c] <= x) {
                cnt += r + 1;
                c++;
            } else {
                r--;
            }
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log (max-min))\)
- 空间：\(O(1)\)
