## 最佳解法思路
- 思路（推荐）：数组 + 头指针 + 元素个数  
用固定数组存元素，`head` 指向队头，`size` 表示当前元素数量。  
入队位置 `tail = (head + size) % k`，出队让 `head = (head + 1) % k`。

## Java 最佳实现

```java
class MyCircularQueue {
    private final int[] a;
    private final int cap;
    private int head;
    private int size;

    public MyCircularQueue(int k) {
        this.a = new int[k];
        this.cap = k;
    }

    public boolean enQueue(int value) {
        if (isFull()) {
            return false;
        }
        int tail = (head + size) % cap;
        a[tail] = value;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) {
            return false;
        }
        head = (head + 1) % cap;
        size--;
        return true;
    }

    public int Front() {
        return isEmpty() ? -1 : a[head];
    }

    public int Rear() {
        if (isEmpty()) {
            return -1;
        }
        int tail = (head + size - 1) % cap;
        return a[tail];
    }

    public boolean isEmpty() {
        return size == 0;
    }

    public boolean isFull() {
        return size == cap;
    }
}
```

## 复杂度分析
- 时间：每个操作 \(O(1)\)
- 空间：\(O(k)\)
