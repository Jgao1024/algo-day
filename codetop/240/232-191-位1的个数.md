## 最佳解法思路
- 思路（推荐）：`n & (n - 1)` 消除最低位的 1  
每次 `n &= (n - 1)` 都会把二进制中最右侧的 1 变成 0，循环次数就是 1 的个数。

## Java 最佳实现

```java
public class Solution {
    public int hammingWeight(int n) {
        int ans = 0;
        while (n != 0) {
            n &= (n - 1);
            ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(k)\)（k 为 1 的个数，最坏 32 次）
- 空间：\(O(1)\)
