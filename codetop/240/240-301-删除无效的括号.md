## 最佳解法思路
- 思路（推荐）：BFS 按“删除次数”分层  
从原串开始，每次删除一个括号生成下一层字符串。第一次发现合法字符串的那一层，就是“最少删除次数”，把该层所有合法串收集即可。  
用 `visited` 去重；校验合法用计数法：遇到 `(` 加 1，遇到 `)` 若计数为 0 直接非法，否则减 1，最后计数为 0 才合法。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> res = new ArrayList<>();
        Set<String> visited = new HashSet<>();
        ArrayDeque<String> q = new ArrayDeque<>();

        q.add(s);
        visited.add(s);

        boolean found = false;
        while (!q.isEmpty()) {
            String cur = q.poll();
            if (isValid(cur)) {
                res.add(cur);
                found = true;
            }
            if (found) {
                continue;
            }

            for (int i = 0; i < cur.length(); i++) {
                char ch = cur.charAt(i);
                if (ch != '(' && ch != ')') {
                    continue;
                }
                if (i > 0 && cur.charAt(i) == cur.charAt(i - 1)) {
                    continue;
                }
                String next = cur.substring(0, i) + cur.substring(i + 1);
                if (visited.add(next)) {
                    q.add(next);
                }
            }
        }
        return res;
    }

    private boolean isValid(String s) {
        int bal = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                bal++;
            } else if (ch == ')') {
                if (bal == 0) {
                    return false;
                }
                bal--;
            }
        }
        return bal == 0;
    }
}
```

## 复杂度分析
- 时间：最坏指数级（BFS 状态数很多），每个状态校验 \(O(n)\)
- 空间：最坏指数级（队列 + visited）
