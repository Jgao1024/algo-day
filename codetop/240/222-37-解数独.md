## 最佳解法思路
- 思路（推荐）：回溯 + 位运算剪枝  
用 `row[i] / col[j] / box[b]` 三个掩码记录每行/列/宫已使用的数字（1~9 对应 bit0~bit8）。  
先收集所有空格位置，递归按顺序填数：可选集合为 `~(row|col|box) & FULL`，逐个尝试并回溯。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private static final int FULL = (1 << 9) - 1;

    public void solveSudoku(char[][] board) {
        int[] row = new int[9];
        int[] col = new int[9];
        int[] box = new int[9];
        List<int[]> empty = new ArrayList<>();

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char ch = board[i][j];
                if (ch == '.') {
                    empty.add(new int[]{i, j});
                } else {
                    int d = ch - '1';
                    int bit = 1 << d;
                    row[i] |= bit;
                    col[j] |= bit;
                    box[boxId(i, j)] |= bit;
                }
            }
        }

        dfs(board, 0, empty, row, col, box);
    }

    private boolean dfs(char[][] board, int idx, List<int[]> empty, int[] row, int[] col, int[] box) {
        if (idx == empty.size()) {
            return true;
        }
        int i = empty.get(idx)[0];
        int j = empty.get(idx)[1];
        int b = boxId(i, j);

        int used = row[i] | col[j] | box[b];
        int avail = (~used) & FULL;
        while (avail != 0) {
            int bit = avail & -avail;
            int d = Integer.numberOfTrailingZeros(bit);

            board[i][j] = (char) ('1' + d);
            row[i] |= bit;
            col[j] |= bit;
            box[b] |= bit;

            if (dfs(board, idx + 1, empty, row, col, box)) {
                return true;
            }

            row[i] ^= bit;
            col[j] ^= bit;
            box[b] ^= bit;
            board[i][j] = '.';

            avail -= bit;
        }
        return false;
    }

    private int boxId(int i, int j) {
        return (i / 3) * 3 + (j / 3);
    }
}
```

## 复杂度分析
- 时间：指数级（回溯，剪枝后通常很快）
- 空间：\(O(1)\)（固定 9x9 + 递归栈）
