## 最佳解法思路
- **DP 记录“以 i 结尾的最早起点”**  
用 `dp[j]` 表示：扫描到 `s1[i]` 时，匹配 `s2[0..j]` 的窗口起点下标（不存在则 -1）。  
遍历 `s1`，每次从 `s2` 的末尾往前更新：
  - 若 `s1[i] == s2[j]`：
    - `j==0`：`dp[0] = i`
    - `j>0`：`dp[j] = dp[j-1]`  
当 `dp[m-1] != -1`，说明在 `i` 处能匹配完整 `s2`，窗口为 `[dp[m-1], i]`，更新最短即可。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public String minWindow(String s1, String s2) {
        int n = s1.length();
        int m = s2.length();
        int[] dp = new int[m];
        Arrays.fill(dp, -1);

        int bestStart = -1;
        int bestLen = Integer.MAX_VALUE;

        for (int i = 0; i < n; i++) {
            char c1 = s1.charAt(i);
            for (int j = m - 1; j >= 0; j--) {
                if (c1 != s2.charAt(j)) continue;
                if (j == 0) dp[0] = i;
                else dp[j] = dp[j - 1];
            }
            if (dp[m - 1] != -1) {
                int start = dp[m - 1];
                int len = i - start + 1;
                if (len < bestLen) {
                    bestLen = len;
                    bestStart = start;
                }
            }
        }

        if (bestStart == -1) return "";
        return s1.substring(bestStart, bestStart + bestLen);
    }
}
```

## 复杂度分析
- 时间：\(O(nm)\)
- 空间：\(O(m)\)
