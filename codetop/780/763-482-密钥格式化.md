## 最佳解法思路
- **从后往前构造**  
先去掉 `-` 并统一转大写。然后从末尾开始每 `k` 个字符插入一个 `-`，最后反转得到结果（或直接用 `StringBuilder` 头插/倒序追加）。

## Java 最佳实现

```java
class Solution {
    public String licenseKeyFormatting(String s, int k) {
        StringBuilder sb = new StringBuilder();
        int cnt = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            char ch = s.charAt(i);
            if (ch == '-') continue;
            if (ch >= 'a' && ch <= 'z') ch = (char) (ch - 'a' + 'A');
            if (cnt == k) {
                sb.append('-');
                cnt = 0;
            }
            sb.append(ch);
            cnt++;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
