## 最佳解法思路
- **DP（走 K 步的概率）**  
`dp[r][c]` 表示当前步数下，马在 `(r,c)` 的概率。每一步从上一层 `dp` 转移到下一层 `ndp`：  
对每个格子，把 `dp[r][c]/8` 分给 8 个能走到且不出界的位置。做 `K` 次迭代后，把所有格子的概率加总就是仍在棋盘内的概率。

## Java 最佳实现

```java
class Solution {
    private static final int[] DR = {1, 1, 2, 2, -1, -1, -2, -2};
    private static final int[] DC = {2, -2, 1, -1, 2, -2, 1, -1};

    public double knightProbability(int n, int k, int row, int column) {
        double[][] dp = new double[n][n];
        dp[row][column] = 1.0;
        for (int step = 0; step < k; step++) {
            double[][] ndp = new double[n][n];
            for (int r = 0; r < n; r++) {
                for (int c = 0; c < n; c++) {
                    if (dp[r][c] == 0) continue;
                    double p = dp[r][c] / 8.0;
                    for (int d = 0; d < 8; d++) {
                        int nr = r + DR[d];
                        int nc = c + DC[d];
                        if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                            ndp[nr][nc] += p;
                        }
                    }
                }
            }
            dp = ndp;
        }
        double ans = 0.0;
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                ans += dp[r][c];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(K \cdot n^2)\)
- 空间：\(O(n^2)\)
