## 最佳解法思路
- **先算总长度，再从后往前反推**  
解码后的长度可能非常大，用 `long` 维护当前“解码长度” `size`：  
正向扫描：
  - 字母：`size++`
  - 数字 d：`size *= d`  
反向扫描时把 `K` 映射回前一步：
  - 数字 d：说明这一段被重复了 d 次，`size /= d`，`K %= size`
  - 字母：若 `K==0` 或 `K==size`，当前字母就是答案；否则 `size--`

## Java 最佳实现

```java
class Solution {
    public String decodeAtIndex(String s, int k) {
        long size = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') {
                size *= (c - '0');
            } else {
                size++;
            }
        }

        long K = k;
        for (int i = s.length() - 1; i >= 0; i--) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') {
                int d = c - '0';
                size /= d;
                K %= size;
            } else {
                if (K == 0 || K == size) return String.valueOf(c);
                size--;
            }
        }
        return "";
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
