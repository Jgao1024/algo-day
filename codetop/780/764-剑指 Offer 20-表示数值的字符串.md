## 最佳解法思路
- **有限状态判断（一次扫描）**  
一个合法数值可包含：可选符号位 `+/-`、整数/小数（`.` 前后至少一侧有数字）、可选指数部分 `e/E`（后面必须是整数且可带符号）。  
扫描时维护 4 个标记：
  - `numSeen`：是否出现过数字
  - `dotSeen`：是否出现过 `.`
  - `eSeen`：是否出现过 `e/E`
  - `numAfterE`：`e/E` 后是否出现过数字  
遇到空格只允许出现在首尾（先 trim 掉即可）。

## Java 最佳实现

```java
class Solution {
    public boolean isNumber(String s) {
        if (s == null) return false;
        s = s.trim();
        if (s.length() == 0) return false;

        boolean numSeen = false;
        boolean dotSeen = false;
        boolean eSeen = false;
        boolean numAfterE = true;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') {
                numSeen = true;
                if (eSeen) numAfterE = true;
            } else if (c == '.') {
                if (dotSeen || eSeen) return false;
                dotSeen = true;
            } else if (c == 'e' || c == 'E') {
                if (eSeen || !numSeen) return false;
                eSeen = true;
                numAfterE = false;
            } else if (c == '+' || c == '-') {
                if (i != 0) {
                    char prev = s.charAt(i - 1);
                    if (prev != 'e' && prev != 'E') return false;
                }
            } else {
                return false;
            }
        }
        return numSeen && numAfterE;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
