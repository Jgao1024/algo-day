## 最佳解法思路
- **一次扫描计数**  
遇到 `1` 连续计数加 1，遇到 `0` 清零，过程中更新最大值。

## Java 最佳实现

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int cur = 0;
        int ans = 0;
        for (int x : nums) {
            if (x == 1) {
                cur++;
                if (cur > ans) ans = cur;
            } else {
                cur = 0;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
