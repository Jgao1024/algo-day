## 最佳解法思路
- **DP 模拟溢出**  
`dp[r][c]` 表示倒入后第 `r` 行第 `c` 个杯子里的香槟量。超过 1 的部分会平均流向下一行的两个杯子：  
`overflow = max(0, (dp[r][c]-1)/2)`。

## Java 最佳实现

```java
class Solution {
    public double champagneTower(int poured, int query_row, int query_glass) {
        double[][] dp = new double[query_row + 2][query_row + 2];
        dp[0][0] = poured;
        for (int r = 0; r <= query_row; r++) {
            for (int c = 0; c <= r; c++) {
                double overflow = (dp[r][c] - 1.0) / 2.0;
                if (overflow > 0) {
                    dp[r + 1][c] += overflow;
                    dp[r + 1][c + 1] += overflow;
                }
            }
        }
        return Math.min(1.0, dp[query_row][query_glass]);
    }
}
```

## 复杂度分析
- 时间：\(O(\text{query\_row}^2)\)
- 空间：\(O(\text{query\_row}^2)\)
