## 最佳解法思路
- **状态压缩 DP（n ≤ 15）**  
把课程用 bitmask 表示：`mask` 中为 1 表示已学完。预处理每门课的先修集合 `pre[i]`。  
对每个 `mask`，求当前可选课程集合 `avail`（未学且 `pre[i]` 都在 `mask` 中）。  
每学期最多选 `k` 门：
  - 若 `avail` 数量 ≤ k，直接全选
  - 否则只枚举 `avail` 中恰好 `k` 门的子集（学得更少不会更优）

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        int[] pre = new int[n];
        for (int[] e : relations) {
            int u = e[0] - 1;
            int v = e[1] - 1;
            pre[v] |= 1 << u;
        }

        int size = 1 << n;
        int[] dp = new int[size];
        Arrays.fill(dp, 1_000_000);
        dp[0] = 0;

        for (int mask = 0; mask < size; mask++) {
            int cur = dp[mask];
            if (cur >= 1_000_000) continue;
            if (mask == size - 1) return cur;

            int avail = 0;
            for (int i = 0; i < n; i++) {
                if (((mask >> i) & 1) == 1) continue;
                if ((pre[i] & mask) == pre[i]) {
                    avail |= 1 << i;
                }
            }

            int cnt = Integer.bitCount(avail);
            if (cnt <= k) {
                int next = mask | avail;
                dp[next] = Math.min(dp[next], cur + 1);
            } else {
                for (int sub = avail; sub > 0; sub = (sub - 1) & avail) {
                    if (Integer.bitCount(sub) == k) {
                        int next = mask | sub;
                        dp[next] = Math.min(dp[next], cur + 1);
                    }
                }
            }
        }
        return dp[size - 1];
    }
}
```

## 复杂度分析
- 时间：约 \(O(2^n \cdot (n + C(n,k)))\)（取决于可选集合大小）
- 空间：\(O(2^n)\)
