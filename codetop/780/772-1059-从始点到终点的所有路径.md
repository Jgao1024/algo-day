## 最佳解法思路
- **DFS + 三色标记（防环 + “死路”判断）**  
要求：从 `source` 出发的所有路径都必须最终到达 `destination`，且过程中不能走进环。  
关键点：
  - `destination` 必须是“终点”（出度为 0），否则会继续走出终点导致失败
  - DFS 过程中遇到“出度为 0”的节点，必须是 `destination` 才算成功
  - 用三色数组：0 未访问，1 访问中（遇到说明有环），2 已确认安全

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public boolean leadsToDestination(int n, int[][] edges, int source, int destination) {
        List<Integer>[] g = new List[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (int[] e : edges) g[e[0]].add(e[1]);
        if (!g[destination].isEmpty()) return false;

        int[] state = new int[n];
        return dfs(g, source, destination, state);
    }

    private boolean dfs(List<Integer>[] g, int u, int dest, int[] state) {
        if (state[u] == 1) return false;
        if (state[u] == 2) return true;
        if (g[u].isEmpty()) return u == dest;

        state[u] = 1;
        for (int v : g[u]) {
            if (!dfs(g, v, dest, state)) return false;
        }
        state[u] = 2;
        return true;
    }
}
```
