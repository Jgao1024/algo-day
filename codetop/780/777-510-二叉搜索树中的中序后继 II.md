## 最佳解法思路
- **利用 parent 指针**  
分两种情况：
  - 有右子树：后继是“右子树的最左节点”
  - 无右子树：沿 parent 往上走，直到第一次从父节点的左边上来，该父节点就是后继

## Java 最佳实现

```java
class Solution {
    public Node inorderSuccessor(Node node) {
        if (node == null) return null;
        if (node.right != null) {
            Node cur = node.right;
            while (cur.left != null) cur = cur.left;
            return cur;
        }
        Node cur = node;
        while (cur.parent != null && cur == cur.parent.right) {
            cur = cur.parent;
        }
        return cur.parent;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)
- 空间：\(O(1)\)
