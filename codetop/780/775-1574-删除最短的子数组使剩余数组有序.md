## 最佳解法思路
- **前后有序段 + 双指针拼接**  
先找到最长非递减前缀 `[0..left]`，以及最长非递减后缀 `[right..n-1]`。  
如果整个数组已非递减，答案为 0。  
初始答案可以是删掉前缀后面或删掉后缀前面，然后用双指针尝试把前缀某个 `i` 和后缀某个 `j` 拼起来：  
若 `arr[i] <= arr[j]`，说明中间可删 `j-i-1`；否则移动 `j`。

## Java 最佳实现

```java
class Solution {
    public int findLengthOfShortestSubarray(int[] arr) {
        int n = arr.length;
        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) left++;
        if (left == n - 1) return 0;

        int right = n - 1;
        while (right - 1 >= 0 && arr[right - 1] <= arr[right]) right--;

        int ans = Math.min(n - left - 1, right);

        int i = 0;
        int j = right;
        while (i <= left && j < n) {
            if (arr[i] <= arr[j]) {
                ans = Math.min(ans, j - i - 1);
                i++;
            } else {
                j++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
