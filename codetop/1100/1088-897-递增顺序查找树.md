## 最佳解法思路
- 中序遍历 BST 得到递增序列，并把节点按顺序串成只有右孩子的链表。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private TreeNode cur;

    public TreeNode increasingBST(TreeNode root) {
        TreeNode dummy = new TreeNode(0);
        cur = dummy;
        dfs(root);
        return dummy.right;
    }

    private void dfs(TreeNode node) {
        if (node == null) return;
        dfs(node.left);
        node.left = null;
        cur.right = node;
        cur = node;
        dfs(node.right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
