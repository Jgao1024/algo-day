## 最佳解法思路
- 把所有数先变成“能达到的最大偶数”（奇数先 *2），然后用最大堆不断减小当前最大值：
  - 维护堆中最大值 `max`，同时维护当前最小值 `min`
  - 每次弹出最大值 `x`，更新答案 `min(ans, x-min)`
  - 若 `x` 为偶数，可变为 `x/2` 继续入堆并更新 `min`
  - 若 `x` 为奇数，无法再变小，结束

## Java 最佳实现

```java
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int minimumDeviation(int[] nums) {
        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
        int min = Integer.MAX_VALUE;
        for (int x : nums) {
            if ((x & 1) == 1) x *= 2;
            pq.offer(x);
            min = Math.min(min, x);
        }

        int ans = Integer.MAX_VALUE;
        while (!pq.isEmpty()) {
            int x = pq.poll();
            ans = Math.min(ans, x - min);
            if ((x & 1) == 1) break;
            x >>= 1;
            min = Math.min(min, x);
            pq.offer(x);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n \cdot \log V)\)（每个数最多除 2 若干次）
- 空间：\(O(n)\)
