## 最佳解法思路
- 贪心（类似区间调度）：
  - 按第二个元素升序排序
  - 依次选择当前对 `(a,b)`，只要 `a > lastEnd` 就能接到链上，并更新 `lastEnd = b`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int findLongestChain(int[][] pairs) {
        Arrays.sort(pairs, (x, y) -> x[1] - y[1]);
        int ans = 0;
        int lastEnd = Integer.MIN_VALUE;
        for (int[] p : pairs) {
            if (p[0] > lastEnd) {
                ans++;
                lastEnd = p[1];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不算排序）
