## 最佳解法思路
- 存每个用户的发帖链表（按时间递增），拉取 feed 时用最大堆做 K 路归并：
  - `postTweet`：把 (time, tweetId) 追加到用户列表
  - `follow/unfollow`：维护关注集合（自己默认关注自己）
  - `getNewsFeed`：把“自己+关注的人”的最后一条推文入堆，每次弹出最新的并把该用户上一条推文继续入堆，取 10 条

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.Set;

class Twitter {
    static class Tweet {
        int time;
        int id;

        Tweet(int time, int id) {
            this.time = time;
            this.id = id;
        }
    }

    static class Node {
        int userId;
        int idx; // 指向该用户 tweet 列表中的位置
        int time;
        int tweetId;

        Node(int userId, int idx, int time, int tweetId) {
            this.userId = userId;
            this.idx = idx;
            this.time = time;
            this.tweetId = tweetId;
        }
    }

    private int time = 0;
    private final Map<Integer, List<Tweet>> tweets = new HashMap<>();
    private final Map<Integer, Set<Integer>> follows = new HashMap<>();

    public Twitter() {
    }

    public void postTweet(int userId, int tweetId) {
        ensureSelfFollow(userId);
        tweets.computeIfAbsent(userId, k -> new ArrayList<>()).add(new Tweet(++time, tweetId));
    }

    public List<Integer> getNewsFeed(int userId) {
        ensureSelfFollow(userId);
        Set<Integer> fs = follows.get(userId);
        PriorityQueue<Node> pq = new PriorityQueue<>((a, b) -> b.time - a.time);

        for (int u : fs) {
            List<Tweet> list = tweets.get(u);
            if (list == null || list.isEmpty()) continue;
            int idx = list.size() - 1;
            Tweet t = list.get(idx);
            pq.offer(new Node(u, idx, t.time, t.id));
        }

        List<Integer> ans = new ArrayList<>(10);
        while (!pq.isEmpty() && ans.size() < 10) {
            Node cur = pq.poll();
            ans.add(cur.tweetId);
            int nextIdx = cur.idx - 1;
            if (nextIdx >= 0) {
                Tweet t = tweets.get(cur.userId).get(nextIdx);
                pq.offer(new Node(cur.userId, nextIdx, t.time, t.id));
            }
        }
        return ans;
    }

    public void follow(int followerId, int followeeId) {
        ensureSelfFollow(followerId);
        follows.get(followerId).add(followeeId);
        ensureSelfFollow(followeeId);
    }

    public void unfollow(int followerId, int followeeId) {
        ensureSelfFollow(followerId);
        if (followerId == followeeId) return;
        follows.get(followerId).remove(followeeId);
    }

    private void ensureSelfFollow(int userId) {
        follows.computeIfAbsent(userId, k -> new HashSet<>()).add(userId);
    }
}
```

## 复杂度分析
- 时间：`post/follow/unfollow` 近似 \(O(1)\)，`getNewsFeed` 为 \(O(F \log F)\)（F 为关注人数）取 10 次弹堆
- 空间：\(O(推文数 + 关注关系数)\)
