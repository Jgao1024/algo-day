## 最佳解法思路
- 扫描统计连续段最大长度：遇到字符变化就重置计数。

## Java 最佳实现

```java
class Solution {
    public int maxPower(String s) {
        int ans = 1;
        int cur = 1;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == s.charAt(i - 1)) cur++;
            else cur = 1;
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
