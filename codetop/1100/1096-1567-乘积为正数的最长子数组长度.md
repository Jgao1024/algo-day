## 最佳解法思路
- DP 记录以当前位置结尾的“乘积为正/负”的最长长度：
  - `pos`：以 `i` 结尾乘积为正的最长长度
  - `neg`：以 `i` 结尾乘积为负的最长长度
  - 遇到 `x>0`：`pos++`，`neg = neg>0 ? neg+1 : 0`
  - 遇到 `x<0`：`pos/neg` 互换后更新：`newPos = neg>0 ? neg+1 : 0`，`newNeg = pos+1`
  - 遇到 `0`：`pos=neg=0`

## Java 最佳实现

```java
class Solution {
    public int getMaxLen(int[] nums) {
        int pos = 0, neg = 0;
        int ans = 0;
        for (int x : nums) {
            if (x == 0) {
                pos = 0;
                neg = 0;
            } else if (x > 0) {
                pos = pos + 1;
                neg = (neg > 0) ? neg + 1 : 0;
            } else {
                int newPos = (neg > 0) ? neg + 1 : 0;
                int newNeg = pos + 1;
                pos = newPos;
                neg = newNeg;
            }
            ans = Math.max(ans, pos);
        }
        return ans;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
