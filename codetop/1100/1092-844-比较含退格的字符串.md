## 最佳解法思路
- 双指针从后往前跳过退格：
  - 分别用指针 `i/j` 从末尾开始，遇到 `#` 就增加跳过计数 `skip`
  - 找到下一个有效字符后比较
  - 任意不等返回 false，遍历结束返回 true

## Java 最佳实现

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1;
        int j = t.length() - 1;
        int skipS = 0, skipT = 0;

        while (i >= 0 || j >= 0) {
            while (i >= 0) {
                if (s.charAt(i) == '#') {
                    skipS++;
                    i--;
                } else if (skipS > 0) {
                    skipS--;
                    i--;
                } else {
                    break;
                }
            }
            while (j >= 0) {
                if (t.charAt(j) == '#') {
                    skipT++;
                    j--;
                } else if (skipT > 0) {
                    skipT--;
                    j--;
                } else {
                    break;
                }
            }

            char a = (i >= 0) ? s.charAt(i) : 0;
            char b = (j >= 0) ? t.charAt(j) : 0;
            if (a != b) return false;
            i--;
            j--;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n+m)\)
- 空间：\(O(1)\)
