## 最佳解法思路
- 贪心：
  - 先保证每行第一列为 1：若 `grid[i][0]==0`，等价于翻转该行（后续统计时用异或模拟即可）
  - 对每一列 `j` 统计在“行翻转后”这一列的 1 的数量 `ones`，若 `ones < m-ones` 则翻转该列
  - 该列对总分贡献是 `max(ones, m-ones) * 2^(n-1-j)`

## Java 最佳实现

```java
class Solution {
    public int matrixScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;
        for (int j = 0; j < n; j++) {
            int ones = 0;
            for (int i = 0; i < m; i++) {
                int v = grid[i][j];
                if (grid[i][0] == 0) v ^= 1; // 行翻转
                ones += v;
            }
            ones = Math.max(ones, m - ones);
            ans += ones * (1 << (n - 1 - j));
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)
