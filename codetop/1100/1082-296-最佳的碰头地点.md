## 最佳解法思路
- 曼哈顿距离下，最优点是行坐标的中位数 + 列坐标的中位数：
  - 收集所有 `1` 的行坐标列表 `rows`（天然有序）
  - 收集所有 `1` 的列坐标列表 `cols`（按列扫描也能有序）
  - 目标行 `rows[mid]`，目标列 `cols[mid]`
  - 总距离为两列表到各自中位数的距离和

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int minTotalDistance(int[][] grid) {
        List<Integer> rows = new ArrayList<>();
        List<Integer> cols = new ArrayList<>();
        int m = grid.length, n = grid[0].length;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) rows.add(i);
            }
        }
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                if (grid[i][j] == 1) cols.add(j);
            }
        }

        int r = rows.get(rows.size() / 2);
        int c = cols.get(cols.size() / 2);
        return dist(rows, r) + dist(cols, c);
    }

    private int dist(List<Integer> list, int mid) {
        int ans = 0;
        for (int x : list) ans += Math.abs(x - mid);
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(P)\)（P 为 1 的数量）
