## 最佳解法思路
- 只统计不相同位置的两种类型：
  - `xy`：`s1[i]='x', s2[i]='y'`
  - `yx`：`s1[i]='y', s2[i]='x'`
  - `xy` 两两配对需要 1 次交换，`yx` 两两配对也需要 1 次
  - 若两者都是奇数，则需要额外 2 次（一次无法同时修复）
  - 若奇偶不匹配则无解返回 -1

## Java 最佳实现

```java
class Solution {
    public int minimumSwap(String s1, String s2) {
        int xy = 0, yx = 0;
        for (int i = 0; i < s1.length(); i++) {
            char a = s1.charAt(i), b = s2.charAt(i);
            if (a == b) continue;
            if (a == 'x' && b == 'y') xy++;
            else yx++;
        }
        if (((xy + yx) & 1) == 1) return -1;
        return xy / 2 + yx / 2 + (xy % 2) * 2;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
