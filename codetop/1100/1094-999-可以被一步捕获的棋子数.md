## 最佳解法思路
- 先找到车 `R` 的位置，然后往四个方向走：
  - 遇到 `B`（象）挡住停止
  - 遇到 `p`（兵）计数 +1 并停止
  - 走出棋盘停止

## Java 最佳实现

```java
class Solution {
    public int numRookCaptures(char[][] board) {
        int r = -1, c = -1;
        for (int i = 0; i < 8; i++) {
            for (int j = 0; j < 8; j++) {
                if (board[i][j] == 'R') {
                    r = i;
                    c = j;
                    break;
                }
            }
            if (r != -1) break;
        }

        int ans = 0;
        ans += scan(board, r, c, -1, 0);
        ans += scan(board, r, c, 1, 0);
        ans += scan(board, r, c, 0, -1);
        ans += scan(board, r, c, 0, 1);
        return ans;
    }

    private int scan(char[][] b, int r, int c, int dr, int dc) {
        int i = r + dr, j = c + dc;
        while (i >= 0 && i < 8 && j >= 0 && j < 8) {
            if (b[i][j] == 'B') return 0;
            if (b[i][j] == 'p') return 1;
            i += dr;
            j += dc;
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（棋盘固定 8x8）
- 空间：\(O(1)\)
