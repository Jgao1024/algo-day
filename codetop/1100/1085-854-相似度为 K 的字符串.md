## 最佳解法思路
- BFS（最短交换次数）：
  - 每次找第一个不匹配的位置 `i`
  - 只尝试把某个 `j>i` 且 `s[j] == target[i]` 的字符换到 `i`，并且优先跳过已经匹配的位置（剪枝）
  - 对状态用 `visited` 去重，层数就是最少交换次数

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.HashSet;
import java.util.Queue;
import java.util.Set;

class Solution {
    public int kSimilarity(String s1, String s2) {
        if (s1.equals(s2)) return 0;
        Queue<String> q = new ArrayDeque<>();
        Set<String> vis = new HashSet<>();
        q.offer(s1);
        vis.add(s1);

        int step = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            while (size-- > 0) {
                String cur = q.poll();
                if (cur.equals(s2)) return step;

                int i = 0;
                while (i < cur.length() && cur.charAt(i) == s2.charAt(i)) i++;
                char[] a = cur.toCharArray();

                for (int j = i + 1; j < a.length; j++) {
                    if (a[j] == s2.charAt(j)) continue;
                    if (a[j] != s2.charAt(i)) continue;
                    swap(a, i, j);
                    String nxt = new String(a);
                    if (vis.add(nxt)) q.offer(nxt);
                    swap(a, i, j);
                }
            }
            step++;
        }
        return -1;
    }

    private void swap(char[] a, int i, int j) {
        char t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

- 空间：状态数量级别
