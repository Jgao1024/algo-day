## 最佳解法思路
- 前缀分治 + 归并计数：
  - 分治保证左右两半有序
  - 统计跨左右的翻转对：对每个左半 `i`，用指针 `j` 在右半找最小满足 `nums[i] <= 2*nums[j]` 的位置
    - 由于右半有序，`j` 单调递增，累计 `j-mid` 个为满足 `nums[i] > 2*nums[j]`
  - 最后归并排序

## Java 最佳实现

```java
class Solution {
    public int reversePairs(int[] nums) {
        if (nums.length == 0) return 0;
        int[] tmp = new int[nums.length];
        return (int) sortCount(nums, tmp, 0, nums.length);
    }

    private long sortCount(int[] a, int[] tmp, int l, int r) {
        if (r - l <= 1) return 0;
        int m = (l + r) >>> 1;
        long cnt = sortCount(a, tmp, l, m) + sortCount(a, tmp, m, r);

        int j = m;
        for (int i = l; i < m; i++) {
            while (j < r && (long) a[i] > 2L * (long) a[j]) j++;
            cnt += (j - m);
        }

        int p1 = l, p2 = m, t = l;
        while (p1 < m && p2 < r) {
            if (a[p1] <= a[p2]) tmp[t++] = a[p1++];
            else tmp[t++] = a[p2++];
        }
        while (p1 < m) tmp[t++] = a[p1++];
        while (p2 < r) tmp[t++] = a[p2++];
        for (int i = l; i < r; i++) a[i] = tmp[i];

        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
