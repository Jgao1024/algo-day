## 最佳解法思路
- 双指针爬坡：
  - 先从左向右走严格递增，停在峰顶 `i`
  - 峰顶不能是两端
  - 再从峰顶继续走严格递减，最后必须走到末尾

## Java 最佳实现

```java
class Solution {
    public boolean validMountainArray(int[] arr) {
        int n = arr.length;
        int i = 0;
        while (i + 1 < n && arr[i] < arr[i + 1]) i++;
        if (i == 0 || i == n - 1) return false;
        while (i + 1 < n && arr[i] > arr[i + 1]) i++;
        return i == n - 1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
