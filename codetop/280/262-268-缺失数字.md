## 最佳解法思路
- 用异或：把 `0..n` 和数组里所有数异或起来，成对抵消，剩下的就是缺失值。
- 也可以用求和公式，但异或不怕溢出。

## Java 最佳实现

```java
class Solution {
    public int missingNumber(int[] nums) {
        int n = nums.length;
        int x = 0;
        for (int i = 0; i <= n; i++) {
            x ^= i;
        }
        for (int v : nums) {
            x ^= v;
        }
        return x;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
