## 最佳解法思路
- 模拟栈：按 `pushed` 依次入栈；每次入栈后，尽可能把栈顶与 `popped` 当前指针相等的元素弹出。
- 最后如果 `popped` 全部匹配完就是合法序列。

## Java 最佳实现

```java
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        int n = pushed.length;
        int[] st = new int[n];
        int top = 0;
        int j = 0;
        for (int x : pushed) {
            st[top++] = x;
            while (top > 0 && j < n && st[top - 1] == popped[j]) {
                top--;
                j++;
            }
        }
        return j == n;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
