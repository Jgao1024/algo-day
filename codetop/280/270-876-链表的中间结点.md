## 最佳解法思路
- 快慢指针：`fast` 每次走两步，`slow` 每次走一步。
- `fast` 到尾时，`slow` 正好在中点（偶数长度返回第二个中点，符合题意）。

## Java 最佳实现

```java
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
