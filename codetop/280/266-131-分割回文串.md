## 最佳解法思路
- 先用 DP 预处理 `isPal[i][j]` 表示 `s[i..j]` 是否回文。
- 再做回溯：从位置 `start` 开始枚举 `end`，若 `isPal[start][end]` 为真就切一刀，继续递归。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i <= 2 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                }
            }
        }

        List<List<String>> ans = new ArrayList<>();
        List<String> path = new ArrayList<>();
        dfs(s, 0, isPal, path, ans);
        return ans;
    }

    private void dfs(String s, int start, boolean[][] isPal, List<String> path, List<List<String>> ans) {
        if (start == s.length()) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (!isPal[start][end]) {
                continue;
            }
            path.add(s.substring(start, end + 1));
            dfs(s, end + 1, isPal, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：预处理 \(O(n^2)\)，回溯为输出规模（最坏接近 \(O(n\cdot 2^n)\)）
- 空间：\(O(n^2)\)（DP）+\(O(n)\)（递归栈/路径）
