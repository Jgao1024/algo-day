## 最佳解法思路
- 把 0 当成 -1，把 1 当成 +1；问题变成“找最长子数组，使得和为 0”。
- 用前缀和 `sum`：如果同一个 `sum` 在下标 `i` 和 `j`（`i<j`）都出现过，说明 `(i, j]` 这段和为 0，长度 `j-i`。
- 用哈希表记录每个 `sum` 第一次出现的位置，取最大长度。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findMaxLength(int[] nums) {
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, -1);
        int sum = 0;
        int ans = 0;
        for (int i = 0; i < nums.length; i++) {
            sum += (nums[i] == 0) ? -1 : 1;
            Integer idx = first.get(sum);
            if (idx != null) {
                ans = Math.max(ans, i - idx);
            } else {
                first.put(sum, i);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
