## 最佳解法思路
- BST 性质：左子树都小于根，右子树都大于根。
- 如果 `p`、`q` 都小于当前节点，往左走；都大于当前节点，往右走；否则当前节点就是最近公共祖先。

## Java 最佳实现

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        int pv = p.val;
        int qv = q.val;

        TreeNode cur = root;
        while (cur != null) {
            int v = cur.val;
            if (pv < v && qv < v) {
                cur = cur.left;
            } else if (pv > v && qv > v) {
                cur = cur.right;
            } else {
                return cur;
            }
        }
        return null;
    }
}
```
