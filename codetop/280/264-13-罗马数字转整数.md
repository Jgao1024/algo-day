## 最佳解法思路
- 从左到右遍历，把每个字符映射成数值 `v`。
- 如果 `v < next` 说明是减法对（如 IV），就减；否则加。

## Java 最佳实现

```java
class Solution {
    public int romanToInt(String s) {
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            int v = val(s.charAt(i));
            int next = (i + 1 < s.length()) ? val(s.charAt(i + 1)) : 0;
            if (v < next) {
                ans -= v;
            } else {
                ans += v;
            }
        }
        return ans;
    }

    private int val(char c) {
        if (c == 'I') return 1;
        if (c == 'V') return 5;
        if (c == 'X') return 10;
        if (c == 'L') return 50;
        if (c == 'C') return 100;
        if (c == 'D') return 500;
        return 1000; // 'M'
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
