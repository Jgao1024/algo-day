## 最佳解法思路
- 固定长度滑动窗口：窗口长度为 `p.length()`。
- 用 `cnt[26]` 维护差分：先把 `p` 的字符计数加进去，再把窗口内字符减掉；当 `cnt` 全为 0 时就是一个异位词起点。
- 为了避免每次都扫 26 次，维护 `diff` 表示当前有多少个字母计数不为 0，`diff==0` 就命中。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        int n = s.length();
        int m = p.length();
        if (n < m) {
            return ans;
        }

        int[] cnt = new int[26];
        for (int i = 0; i < m; i++) {
            cnt[p.charAt(i) - 'a']++;
            cnt[s.charAt(i) - 'a']--;
        }

        int diff = 0;
        for (int v : cnt) {
            if (v != 0) diff++;
        }
        if (diff == 0) {
            ans.add(0);
        }

        for (int i = m; i < n; i++) {
            int in = s.charAt(i) - 'a';
            int out = s.charAt(i - m) - 'a';

            diff = apply(cnt, in, -1, diff);
            diff = apply(cnt, out, +1, diff);

            if (diff == 0) {
                ans.add(i - m + 1);
            }
        }

        return ans;
    }

    private int apply(int[] cnt, int idx, int delta, int diff) {
        int before = cnt[idx];
        int after = before + delta;
        if (before == 0 && after != 0) diff++;
        else if (before != 0 && after == 0) diff--;
        cnt[idx] = after;
        return diff;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（26 个字母）
