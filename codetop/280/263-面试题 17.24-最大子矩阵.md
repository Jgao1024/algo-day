## 最佳解法思路
- 把二维降成一维：固定上边界 `top`，从 `top` 往下扩展 `bottom`，把 `top..bottom` 之间每列的和压到数组 `sum[col]`。
- 对 `sum` 做一次最大子数组（Kadane），得到当前 `top..bottom` 下的最优左右边界与最大和。
- 过程中记录最大和对应的 `[top, left, bottom, right]`。

## Java 最佳实现

```java
class Solution {
    public int[] getMaxMatrix(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;

        int bestSum = Integer.MIN_VALUE;
        int[] ans = new int[4];

        int[] sum = new int[n];
        for (int top = 0; top < m; top++) {
            for (int j = 0; j < n; j++) {
                sum[j] = 0;
            }

            for (int bottom = top; bottom < m; bottom++) {
                for (int j = 0; j < n; j++) {
                    sum[j] += matrix[bottom][j];
                }

                int curSum = 0;
                int curLeft = 0;
                for (int right = 0; right < n; right++) {
                    if (curSum <= 0) {
                        curSum = sum[right];
                        curLeft = right;
                    } else {
                        curSum += sum[right];
                    }

                    if (curSum > bestSum) {
                        bestSum = curSum;
                        ans[0] = top;
                        ans[1] = curLeft;
                        ans[2] = bottom;
                        ans[3] = right;
                    }
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m^2 \cdot n)\)
- 空间：\(O(n)\)
