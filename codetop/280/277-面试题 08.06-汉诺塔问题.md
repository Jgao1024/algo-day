## 最佳解法思路
- 经典递归：把 `n` 个盘子从 A 移到 C（借助 B）。
- 先把 `n-1` 从 A 移到 B（借助 C），再把最大的从 A 移到 C，最后把 `n-1` 从 B 移到 C（借助 A）。

## Java 最佳实现

```java
import java.util.List;

class Solution {
    public void hanota(List<Integer> A, List<Integer> B, List<Integer> C) {
        move(A.size(), A, B, C);
    }

    private void move(int n, List<Integer> from, List<Integer> aux, List<Integer> to) {
        if (n == 0) {
            return;
        }
        move(n - 1, from, to, aux);
        to.add(from.remove(from.size() - 1));
        move(n - 1, aux, from, to);
    }
}
```

## 复杂度分析
- 时间：\(O(2^n)\)
- 空间：\(O(n)\)（递归栈）
