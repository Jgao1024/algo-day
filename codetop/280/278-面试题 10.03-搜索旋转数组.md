## 最佳解法思路
- 二分的变体（允许重复元素）：
  - 若 `nums[mid] == target` 直接返回。
  - 如果 `nums[l] == nums[mid] == nums[r]`，无法判断哪边有序，收缩边界 `l++，r--`。
  - 否则至少一边有序：判断 `target` 是否在有序区间内，决定往哪边二分。

## Java 最佳实现

```java
class Solution {
    public int search(int[] arr, int target) {
        int l = 0;
        int r = arr.length - 1;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (arr[mid] == target) {
                return mid;
            }

            if (arr[l] == arr[mid] && arr[mid] == arr[r]) {
                l++;
                r--;
                continue;
            }

            if (arr[l] <= arr[mid]) { // 左边有序
                if (arr[l] <= target && target < arr[mid]) {
                    r = mid - 1;
                } else {
                    l = mid + 1;
                }
            } else { // 右边有序
                if (arr[mid] < target && target <= arr[r]) {
                    l = mid + 1;
                } else {
                    r = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：平均 \(O(\log n)\)，最坏 \(O(n)\)
- 空间：\(O(1)\)
