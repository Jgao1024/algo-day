## 最佳解法思路
- 埃氏筛：用 `isComposite[i]` 标记是否合数。
- 从 2 到 `n-1` 遍历，遇到未标记的就是质数；并从 `i*i` 开始把 `i` 的倍数标记为合数。

## Java 最佳实现

```java
class Solution {
    public int countPrimes(int n) {
        if (n <= 2) {
            return 0;
        }
        boolean[] isComposite = new boolean[n];
        int cnt = 0;
        for (int i = 2; i < n; i++) {
            if (!isComposite[i]) {
                cnt++;
                long sq = 1L * i * i;
                if (sq < n) {
                    for (int j = (int) sq; j < n; j += i) {
                        isComposite[j] = true;
                    }
                }
            }
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：约 \(O(n \log\log n)\)
- 空间：\(O(n)\)
