## 最佳解法思路
- 前缀和 `pre[i]` 表示前 `i` 个数的和（`pre[0]=0`）。
- 需要找最短 `j-i` 使得 `pre[j]-pre[i] >= K`，等价于对每个 `j` 找尽量靠后的满足条件的 `i`。
- 用单调队列维护前缀和递增的下标：
  - 若 `pre[j]-pre[dequeFirst] >= K`，就更新答案并弹出队首（因为越靠后的 i 会更短）。
  - 为保持递增，若 `pre[j] <= pre[dequeLast]`，弹出队尾。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int shortestSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        int ans = n + 1;
        Deque<Integer> dq = new ArrayDeque<>();
        for (int j = 0; j <= n; j++) {
            while (!dq.isEmpty() && pre[j] - pre[dq.peekFirst()] >= k) {
                ans = Math.min(ans, j - dq.pollFirst());
            }
            while (!dq.isEmpty() && pre[j] <= pre[dq.peekLast()]) {
                dq.pollLast();
            }
            dq.addLast(j);
        }

        return ans == n + 1 ? -1 : ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（每个下标最多进出队列一次）
- 空间：\(O(n)\)
