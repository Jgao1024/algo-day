## 最佳解法思路
- 迭代：用 `prev` 指向已反转部分的头，用 `cur` 遍历原链表。
- 每次把 `cur.next` 指向 `prev`，再整体前进。

## Java 最佳实现

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
