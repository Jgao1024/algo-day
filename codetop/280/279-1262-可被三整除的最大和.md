## 最佳解法思路
- DP（按模 3 分类）：`dp[r]` 表示当前能得到的“和 % 3 == r”的最大和。
- 初始 `dp[0]=0`，其余为负无穷；每加入一个数 `x`，用上一轮 `prev` 去更新三种余数的转移。

## Java 最佳实现

```java
class Solution {
    public int maxSumDivThree(int[] nums) {
        int neg = -1000000000;
        int[] dp = new int[] {0, neg, neg};
        for (int x : nums) {
            int[] prev = new int[] {dp[0], dp[1], dp[2]};
            for (int r = 0; r < 3; r++) {
                if (prev[r] == neg) continue;
                int nr = (r + x) % 3;
                dp[nr] = Math.max(dp[nr], prev[r] + x);
            }
        }
        return dp[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
