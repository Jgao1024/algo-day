## 最佳解法思路
- 枚举候选（推荐）
- 最近回文一定来自这些候选：
  - `10^len + 1`（如 999 -> 1001）
  - `10^(len-1) - 1`（如 1000 -> 999）
  - 用前半部分 `prefix-1/prefix/prefix+1` 生成回文
- 从候选里选与原数差值最小的（相等取更小的），且不能等于原数。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String nearestPalindromic(String n) {
        long self = Long.parseLong(n);
        int len = n.length();
        long p10 = pow10(len);
        long p10Prev = pow10(len - 1);

        List<Long> cand = new ArrayList<>();
        cand.add(p10 + 1);
        cand.add(p10Prev - 1);

        long prefix = Long.parseLong(n.substring(0, (len + 1) / 2));
        cand.add(makePal(prefix - 1, len));
        cand.add(makePal(prefix, len));
        cand.add(makePal(prefix + 1, len));

        long best = -1;
        for (long x : cand) {
            if (x == self) continue;
            if (x < 0) continue;
            if (best == -1) {
                best = x;
                continue;
            }
            long d1 = Math.abs(x - self);
            long d2 = Math.abs(best - self);
            if (d1 < d2 || (d1 == d2 && x < best)) best = x;
        }
        return String.valueOf(best);
    }

    private long pow10(int n) {
        long x = 1;
        for (int i = 0; i < n; i++) x *= 10;
        return x;
    }

    private long makePal(long prefix, int len) {
        String s = String.valueOf(prefix);
        StringBuilder sb = new StringBuilder(s);
        int start = (len % 2 == 0) ? s.length() - 1 : s.length() - 2;
        for (int i = start; i >= 0; i--) sb.append(s.charAt(i));
        return Long.parseLong(sb.toString());
    }
}
```

## 复杂度分析
- 时间：\(O(len)\)
- 空间：\(O(len)\)
