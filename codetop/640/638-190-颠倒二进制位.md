## 最佳解法思路
- 逐位处理（推荐）
- 循环 32 次：把 `n` 的最低位拼到答案末尾，`n` 右移，答案左移。

## Java 最佳实现

```java
public class Solution {
    public int reverseBits(int n) {
        int ans = 0;
        for (int i = 0; i < 32; i++) {
            ans = (ans << 1) | (n & 1);
            n >>>= 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 空间：\(O(1)\)
