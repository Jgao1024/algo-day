## 最佳解法思路
- 余数计数（推荐）
- 对每个数取 `r = ((x % k) + k) % k`。
- 能配对满足 `(a+b)%k==0`：
  - `cnt[0]` 必须为偶数
  - 对 `r=1..k-1`：`cnt[r] == cnt[k-r]`
  - 若 `k` 为偶数，还要 `cnt[k/2]` 为偶数

## Java 最佳实现

```java
class Solution {
    public boolean canArrange(int[] arr, int k) {
        int[] cnt = new int[k];
        for (int x : arr) {
            int r = x % k;
            if (r < 0) r += k;
            cnt[r]++;
        }

        if ((cnt[0] & 1) == 1) return false;
        for (int r = 1; r <= k / 2; r++) {
            if (r == k - r) {
                if ((cnt[r] & 1) == 1) return false;
            } else {
                if (cnt[r] != cnt[k - r]) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n + k)\)
- 空间：\(O(k)\)
