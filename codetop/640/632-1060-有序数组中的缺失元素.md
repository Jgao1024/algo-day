## 最佳解法思路
- 二分（推荐）
- 定义 `missing(i) = nums[i] - nums[0] - i`，表示从 `nums[0]` 到 `nums[i]` 之间缺了多少个数。
- 若 `missing(n-1) < k`，答案在数组末尾之后：`nums[n-1] + (k - missing(n-1))`。
- 否则二分找最小的 `idx` 使 `missing(idx) >= k`，答案在 `idx-1` 与 `idx` 之间。

## Java 最佳实现

```java
class Solution {
    public int missingElement(int[] nums, int k) {
        int n = nums.length;
        int totalMissing = missing(nums, n - 1);
        if (totalMissing < k) {
            return nums[n - 1] + (k - totalMissing);
        }

        int l = 0, r = n - 1;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (missing(nums, m) >= k) r = m;
            else l = m + 1;
        }

        int prevMissing = missing(nums, l - 1);
        return nums[l - 1] + (k - prevMissing);
    }

    private int missing(int[] nums, int i) {
        return nums[i] - nums[0] - i;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
