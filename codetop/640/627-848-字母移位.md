## 最佳解法思路
- 后缀累加（推荐）
- 第 `i` 位会被 `shifts[i..]` 全部影响。倒序累加总偏移 `sum`，每次对 26 取模。

## Java 最佳实现

```java
class Solution {
    public String shiftingLetters(String s, int[] shifts) {
        char[] ch = s.toCharArray();
        long sum = 0;
        for (int i = shifts.length - 1; i >= 0; i--) {
            sum += shifts[i];
            int add = (int) (sum % 26);
            int v = ch[i] - 'a';
            v = (v + add) % 26;
            ch[i] = (char) ('a' + v);
        }
        return new String(ch);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（转 char 数组）
