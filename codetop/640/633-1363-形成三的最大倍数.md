## 最佳解法思路
- 贪心（推荐）
- 想让数字最大：尽量保留高位数字，所以优先删掉“最小的”数字来让总和能被 3 整除。
- 统计 0~9 计数，算总和 `sum%3`：
  - 余 1：删 1 个余 1 的最小数字，或删 2 个余 2 的最小数字
  - 余 2：删 1 个余 2 的最小数字，或删 2 个余 1 的最小数字
- 最后按 9→0 拼接；若全是 0 返回 `"0"`；若空返回 `""`。

## Java 最佳实现

```java
class Solution {
    public String largestMultipleOfThree(int[] digits) {
        int[] cnt = new int[10];
        int sum = 0;
        for (int d : digits) {
            cnt[d]++;
            sum += d;
        }

        int mod = sum % 3;
        if (mod == 1) {
            if (!removeOne(cnt, 1)) {
                if (!removeTwo(cnt, 2)) return "";
            }
        } else if (mod == 2) {
            if (!removeOne(cnt, 2)) {
                if (!removeTwo(cnt, 1)) return "";
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int d = 9; d >= 0; d--) {
            for (int i = 0; i < cnt[d]; i++) sb.append((char) ('0' + d));
        }
        if (sb.length() == 0) return "";
        if (sb.charAt(0) == '0') return "0";
        return sb.toString();
    }

    private boolean removeOne(int[] cnt, int mod) {
        for (int d = 0; d <= 9; d++) {
            if (d % 3 == mod && cnt[d] > 0) {
                cnt[d]--;
                return true;
            }
        }
        return false;
    }

    private boolean removeTwo(int[] cnt, int mod) {
        int[] removedDigits = new int[2];
        int removedCount = 0;
        for (int t = 0; t < 2; t++) {
            boolean ok = false;
            for (int d = 0; d <= 9; d++) {
                if (d % 3 == mod && cnt[d] > 0) {
                    cnt[d]--;
                    removedDigits[removedCount++] = d;
                    ok = true;
                    break;
                }
            }
            if (!ok) {
                for (int i = 0; i < removedCount; i++) {
                    cnt[removedDigits[i]]++;
                }
                return false;
            }
        }
        return true;
    }
}
```
