## 最佳解法思路
- 迭代反转（推荐）
- 遍历链表，对每个节点交换 `next` 和 `prev`，最终返回最后处理的节点作为新头。

## Java 最佳实现

```java
class Solution {
    public Node reverse(Node head) {
        Node cur = head;
        Node newHead = null;
        while (cur != null) {
            Node next = cur.next;
            cur.next = cur.prev;
            cur.prev = next;
            newHead = cur;
            cur = next;
        }
        return newHead;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
