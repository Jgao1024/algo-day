## 最佳解法思路
- 动态规划（推荐）
- `dp[s]` 表示当前掷到点数和为 `s` 的方案数。每增加一个骰子做一次转移。
- 状态转移：`ndp[s] += dp[s - face]`（`face` 从 1 到 `k`）。
- 取模 \(10^9+7\)。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int numRollsToTarget(int n, int k, int target) {
        int[] dp = new int[target + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            int[] ndp = new int[target + 1];
            for (int s = 1; s <= target; s++) {
                long ways = 0;
                for (int face = 1; face <= k && face <= s; face++) {
                    ways += dp[s - face];
                }
                ndp[s] = (int) (ways % MOD);
            }
            dp = ndp;
        }
        return dp[target];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot k \cdot target)\)
- 空间：\(O(target)\)
