## 最佳解法思路
- 前后缀乘积（推荐）
- `B[i] = (A[0..i-1] 的乘积) * (A[i+1..n-1] 的乘积)`，不使用除法。
- 先从左到右算前缀积放到 `B`，再从右到左用 `suffix` 乘进去。

## Java 最佳实现

```java
class Solution {
    public int[] constructArr(int[] a) {
        int n = a.length;
        if (n == 0) return new int[0];

        int[] b = new int[n];
        b[0] = 1;
        for (int i = 1; i < n; i++) {
            b[i] = b[i - 1] * a[i - 1];
        }

        int suffix = 1;
        for (int i = n - 2; i >= 0; i--) {
            suffix *= a[i + 1];
            b[i] *= suffix;
        }
        return b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出数组）
