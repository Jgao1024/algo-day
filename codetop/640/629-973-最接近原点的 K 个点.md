## 最佳解法思路
- 堆（推荐）
- 用大小为 `k` 的大根堆维护当前最接近的 k 个点（按距离平方）。
- 遍历所有点：入堆；若堆大小超过 k，就弹出最远的那个。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class Solution {
    public int[][] kClosest(int[][] points, int k) {
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> dist(b) - dist(a));
        for (int[] p : points) {
            pq.offer(p);
            if (pq.size() > k) pq.poll();
        }
        int[][] ans = new int[k][2];
        for (int i = 0; i < k; i++) {
            int[] p = pq.poll();
            ans[i][0] = p[0];
            ans[i][1] = p[1];
        }
        return ans;
    }

    private int dist(int[] p) {
        return p[0] * p[0] + p[1] * p[1];
    }
}
```

## 复杂度分析
- 时间：\(O(n \log k)\)
- 空间：\(O(k)\)
