# 146. LRU缓存机制

- 题号：146
- 难度：中等
- LeetCode：[LRU缓存机制](https://leetcode.cn/problems/lru-cache/)

## 题目描述
实现 LRU（最近最少使用）缓存。

支持：
- `LRUCache(int capacity)`：以正整数 `capacity` 初始化
- `int get(int key)`：存在返回值并把该 key 变为“最近使用”；不存在返回 `-1`
- `void put(int key, int value)`：写入/更新并变为“最近使用”；超过容量时淘汰“最久未使用”的 key

要求 `get/put` 平均时间复杂度 \(O(1)\)。

## 示例
输入：

```
["LRUCache","put","put","get","put","get","put","get","get","get"]
[[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]
```

输出：

```
[null,null,null,1,null,-1,null,-1,3,4]
```

解释：容量为 2，按 LRU 规则淘汰最久未使用的键。

## 最佳解法思路
- 思路1（推荐）：哈希表 + 双向链表  
哈希表 `key -> 节点` 做 \(O(1)\) 定位；双向链表维护“使用顺序”（头部最近，尾部最久）。`get/put` 都把节点移到头；超容量则删尾节点并从哈希表移除。

- 思路2：`LinkedHashMap(accessOrder=true)`  
Java 自带按访问顺序维护链表，重写 `removeEldestEntry` 自动淘汰。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class LRUCache {
    private static class Node {
        int key;
        int value;
        Node prev;
        Node next;

        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0);
    private final Node tail = new Node(0, 0);

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }

        Node n = new Node(key, value);
        map.put(key, n);
        addAfterHead(n);

        if (map.size() > capacity) {
            Node lru = removeTailPrev();
            map.remove(lru.key);
        }
    }

    private void moveToHead(Node node) {
        remove(node);
        addAfterHead(node);
    }

    private void addAfterHead(Node node) {
        Node a = head;
        Node b = head.next;
        a.next = node;
        node.prev = a;
        node.next = b;
        b.prev = node;
    }

    private void remove(Node node) {
        Node a = node.prev;
        Node b = node.next;
        a.next = b;
        b.prev = a;
    }

    private Node removeTailPrev() {
        Node node = tail.prev;
        remove(node);
        return node;
    }
}
```

## 复杂度分析
- 时间：`get/put` 平均 \(O(1)\)
- 空间：\(O(capacity)\)

## 总结（速记）
- 设计题的核心不是 API，而是把“定位”和“排序/淘汰”拆开：
  - 定位：HashMap \(O(1)\)
  - 顺序：双向链表 \(O(1)\) 删除/插入
- 关键点：
  - 用 `head/tail` 哨兵节点，所有插入/删除都变成 4 次指针修改
  - `get` 也算一次访问，要移动到头
  - 淘汰一定是“尾部前一个真实节点”
