# 补充题4. 手撕快速排序

- 题号：补充题4
- 难度：中等
- LeetCode：[手撕快速排序](https://leetcode.cn/problems/sort-an-array/)

## 题目描述
给定整数数组 `nums`，请你将该数组升序排序，并返回排序后的数组。

## 示例
- 示例1  
输入：`nums = [5,2,3,1]`  
输出：`[1,2,3,5]`

- 示例2  
输入：`nums = [5,1,1,2,0,0]`  
输出：`[0,0,1,1,2,5]`

## 最佳解法思路
- 思路1（推荐）：随机化快速排序  
选随机 pivot 做 partition，递归左右区间。平均 \(O(n\log n)\)，实现简单，面试常考。

- 思路2：归并排序  
稳定、最坏 \(O(n\log n)\)，但需要额外数组空间。

## Java 最佳实现

```java
import java.util.Random;

class Solution {
    private final Random rnd = new Random();

    public int[] sortArray(int[] nums) {
        quickSort(nums, 0, nums.length - 1);
        return nums;
    }

    private void quickSort(int[] a, int l, int r) {
        if (l >= r) return;
        int p = partition(a, l, r);
        quickSort(a, l, p - 1);
        quickSort(a, p + 1, r);
    }

    private int partition(int[] a, int l, int r) {
        int pivotIdx = l + rnd.nextInt(r - l + 1);
        swap(a, pivotIdx, r);
        int pivot = a[r];

        int i = l;
        for (int j = l; j < r; j++) {
            if (a[j] <= pivot) {
                swap(a, i, j);
                i++;
            }
        }
        swap(a, i, r);
        return i;
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

## 复杂度分析
- 快排：平均 \(O(n\log n)\)，最坏 \(O(n^2)\)（随机化后很少出现）
- 空间：平均 \(O(\log n)\)（递归栈）

## 总结（速记）
- 面试写快排：一定要“随机 pivot”或“三数取中”，不然几乎必被卡最坏情况。
- partition 常用写法：把 pivot 放到末尾，`i` 维护 “<= pivot 的边界”，遍历 `j` 交换。
