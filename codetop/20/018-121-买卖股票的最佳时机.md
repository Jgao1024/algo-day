# 121. 买卖股票的最佳时机

- 题号：121
- 难度：简单
- LeetCode：[买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

## 题目描述
给定一个数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。

你只能选择某一天买入，并在未来某一天卖出，最多完成一次交易。返回最大利润；如果无法获利，返回 0。

## 示例
- 示例1  
输入：`prices = [7,1,5,3,6,4]`  
输出：`5`  
解释：第 2 天买入（1），第 5 天卖出（6）

- 示例2  
输入：`prices = [7,6,4,3,1]`  
输出：`0`

## 最佳解法思路
- 思路1（推荐）：维护历史最低价  
遍历价格，维护 `minPrice`（到当前为止最低），当前利润为 `prices[i] - minPrice`，更新最大值。

- 思路2：DP（等价写法）  
`hold` 表示持有股票的最大收益（买入为负），`cash` 表示不持有最大收益。只交易一次时会退化成思路1。

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int ans = 0;
        for (int p : prices) {
            if (p < minPrice) minPrice = p;
            ans = Math.max(ans, p - minPrice);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 只交易一次：等价于找最大差值 `prices[j]-prices[i] (j>i)`，一趟维护前缀最小即可。
