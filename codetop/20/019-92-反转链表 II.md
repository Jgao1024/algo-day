# 92. 反转链表 II

- 题号：92
- 难度：中等
- LeetCode：[反转链表 II](https://leetcode.cn/problems/reverse-linked-list-ii/)

## 题目描述
给你单链表的头指针 `head` 和两个整数 `left`、`right`（1-indexed）。

请你反转从位置 `left` 到位置 `right` 的链表节点，并返回反转后的链表。

## 示例
- 示例1  
输入：`1->2->3->4->5, left = 2, right = 4`  
输出：`1->4->3->2->5`

- 示例2  
输入：`5, left = 1, right = 1`  
输出：`5`

## 最佳解法思路
- 思路1（推荐）：头插法反转区间  
用 `dummy` 方便处理 `left=1`。先走到 `pre`（指向 `left` 前一个节点），然后让 `cur=pre.next`。  
接下来重复 `right-left` 次：把 `cur.next` 节点 `move` 摘下来，插到 `pre` 后面（区间内头插），即可完成区间反转。

- 思路2：摘出区间再整段反转  
找到 `leftNode` 与 `rightNode`，断开区间，反转，再接回去。实现更长。

## Java 最佳实现

```java
class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        if (head == null || left == right) return head;

        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode pre = dummy;
        for (int i = 1; i < left; i++) {
            pre = pre.next;
        }

        ListNode cur = pre.next;
        for (int i = 0; i < right - left; i++) {
            ListNode move = cur.next;
            cur.next = move.next;
            move.next = pre.next;
            pre.next = move;
        }

        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 区间反转最好记“头插法”：固定 `pre`，不断把 `cur.next` 摘出来插到 `pre` 后。
