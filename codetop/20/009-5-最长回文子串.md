# 5. 最长回文子串

- 题号：5
- 难度：中等
- LeetCode：[最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

## 题目描述
给你一个字符串 `s`，找到 `s` 中最长的回文子串，返回该子串。

## 示例
- 示例1  
输入：`s = "babad"`  
输出：`"bab"`（或 `"aba"`）

- 示例2  
输入：`s = "cbbd"`  
输出：`"bb"`

## 最佳解法思路
- 思路1（推荐）：中心扩展  
回文的中心可能是一个字符（奇数长度）或两个字符之间（偶数长度）。枚举中心，向两侧扩展，更新最长区间。

- 思路2：动态规划（不推荐）  
`dp[l][r]` 表示 `s[l..r]` 是否回文，需要 \(O(n^2)\) 空间。

## Java 最佳实现

```java
class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n <= 1) return s;

        int bestL = 0, bestR = 0;
        for (int i = 0; i < n; i++) {
            int[] a = expand(s, i, i);
            if (a[1] - a[0] > bestR - bestL) {
                bestL = a[0];
                bestR = a[1];
            }

            int[] b = expand(s, i, i + 1);
            if (b[1] - b[0] > bestR - bestL) {
                bestL = b[0];
                bestR = b[1];
            }
        }

        return s.substring(bestL, bestR + 1);
    }

    private int[] expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return new int[]{l + 1, r - 1};
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)（每个中心最多扩到两端）
- 空间：\(O(1)\)

- 516 最长回文子序列：子序列 DP
- 5/647 对比：子串必须连续，中心扩展更合适

## 总结（速记）
- “最长回文子串”首选中心扩展：写法短、空间 \(O(1)\)。
- 若题目变成“统计回文个数”，中心扩展同一套路直接累加即可（647）。
