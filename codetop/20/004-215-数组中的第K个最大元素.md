# 215. 数组中的第K个最大元素

- 题号：215
- 难度：中等
- LeetCode：[数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

## 题目描述
给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

注意：不是第 `k` 个不同的元素。

## 示例
- 示例1  
输入：`nums = [3,2,1,5,6,4], k = 2`  
输出：`5`

- 示例2  
输入：`nums = [3,2,3,1,2,4,5,5,6], k = 4`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：快速选择（QuickSelect）  
一次 partition 把数组分成 “<= pivot” 和 “> pivot”（或反过来），pivot 的最终位置是确定的。根据 pivot 位置与目标下标比较，缩小到一边继续做，平均 \(O(n)\)。

- 思路2：小根堆大小为 k  
遍历数组，堆里只保留最大的 k 个，堆顶就是第 k 大。复杂度 \(O(n\log k)\)，实现稳定简单。

## Java 最佳实现

```java
import java.util.Random;

class Solution {
    private final Random rnd = new Random();

    public int findKthLargest(int[] nums, int k) {
        int target = nums.length - k; // 转成第 target 小（0-based）
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int p = partition(nums, l, r);
            if (p == target) return nums[p];
            if (p < target) l = p + 1;
            else r = p - 1;
        }
        return -1;
    }

    private int partition(int[] a, int l, int r) {
        int pivotIdx = l + rnd.nextInt(r - l + 1);
        swap(a, pivotIdx, r);
        int pivot = a[r];

        int i = l;
        for (int j = l; j < r; j++) {
            if (a[j] <= pivot) {
                swap(a, i, j);
                i++;
            }
        }
        swap(a, i, r);
        return i;
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

## 复杂度分析
- 快速选择：平均 \(O(n)\)，最坏 \(O(n^2)\)（随机化后很少出现）
- 空间：\(O(1)\)（原地）

## 总结（速记）
- TopK 两个常用模板：
  - 需要更快平均性能：QuickSelect（原地、平均线性）
  - 需要稳定、在线/流式：堆（\(O(n\log k)\)，或数据流用 \(O(\log k)\) 更新）
- QuickSelect 的关键是：partition 后 pivot 的位置是最终位置，答案一定在一侧。
