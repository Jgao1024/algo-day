# 103. 二叉树的锯齿形层次遍历

- 题号：103
- 难度：中等
- LeetCode：[二叉树的锯齿形层次遍历](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/)

## 题目描述
给你二叉树的根节点 `root`，返回其节点值的锯齿形层序遍历。

锯齿形：第一层从左到右，下一层从右到左，依次交替。

## 示例
- 示例  
输入：`[3,9,20,null,null,15,7]`  
输出：`[[3],[20,9],[15,7]]`

## 最佳解法思路
- 思路1（推荐）：BFS 分层 + 方向控制  
正常 BFS 分层拿到一层节点值。若当前层需要“从右到左”，可以：
1) 直接把本层结果反转；或  
2) 用 `Deque`，根据方向决定 `addLast/addFirst`。

- 思路2：双栈  
用两个栈交替保存下一层节点，按方向决定入栈顺序。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) return ans;

        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        boolean leftToRight = true;

        while (!q.isEmpty()) {
            int size = q.size();
            Deque<Integer> level = new ArrayDeque<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                if (leftToRight) level.addLast(node.val);
                else level.addFirst(node.val);

                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            ans.add(new ArrayList<>(level));
            leftToRight = !leftToRight;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 锯齿形本质就是“层序 + 每层方向翻转”，处理方向最省事的是 `Deque<Integer>`。
