# 33. 搜索旋转排序数组

- 题号：33
- 难度：中等
- LeetCode：[搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

## 题目描述
整数数组 `nums` 原本是升序排列，但在某个未知点发生了旋转（例如 `[0,1,2,4,5,6,7]` 变成 `[4,5,6,7,0,1,2]`）。

给你 `nums` 和目标值 `target`，如果存在返回下标，否则返回 `-1`。要求时间复杂度 \(O(\log n)\)。

## 示例
- 示例1  
输入：`nums = [4,5,6,7,0,1,2], target = 0`  
输出：`4`

- 示例2  
输入：`nums = [4,5,6,7,0,1,2], target = 3`  
输出：`-1`

- 示例3  
输入：`nums = [1], target = 0`  
输出：`-1`

## 最佳解法思路
- 思路1（推荐）：改造二分  
每次取 `mid`，必有一半是有序的：  
若 `nums[l] <= nums[mid]`，左半有序；否则右半有序。  
判断 `target` 是否落在有序半区范围内，决定收缩哪一边。

- 思路2：先找旋转点再二分（不如思路1）  
多一次二分，代码更长。

## Java 最佳实现

```java
class Solution {
    public int search(int[] nums, int target) {
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int mid = l + ((r - l) >> 1);
            if (nums[mid] == target) return mid;

            if (nums[l] <= nums[mid]) {
                if (nums[l] <= target && target < nums[mid]) {
                    r = mid - 1;
                } else {
                    l = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[r]) {
                    l = mid + 1;
                } else {
                    r = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 旋转数组二分只记一句：**先判断哪半有序，再判断 target 是否在这半**。
