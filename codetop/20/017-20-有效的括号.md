# 20. 有效的括号

- 题号：20
- 难度：简单
- LeetCode：[有效的括号](https://leetcode.cn/problems/valid-parentheses/)

## 题目描述
给定一个只包含 `'(' ')' '{' '}' '[' ']'` 的字符串 `s`，判断括号是否有效。

有效规则：
- 左括号必须用相同类型的右括号闭合
- 左括号必须以正确的顺序闭合

## 示例
- 示例1  
输入：`s = "()"`  
输出：`true`

- 示例2  
输入：`s = "()[]{}"`  
输出：`true`

- 示例3  
输入：`s = "(]"`  
输出：`false`

- 示例4  
输入：`s = "([)]"`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：栈  
遇到左括号入栈；遇到右括号就检查栈顶是否是对应的左括号，不匹配直接 false。最后栈为空才是有效。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> st = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == '[' || c == '{') {
                st.push(c);
            } else {
                if (st.isEmpty()) return false;
                char t = st.pop();
                if (c == ')' && t != '(') return false;
                if (c == ']' && t != '[') return false;
                if (c == '}' && t != '{') return false;
            }
        }
        return st.isEmpty();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（最坏全是左括号）
