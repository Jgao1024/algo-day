# 206. 反转链表

- 题号：206
- 难度：简单
- LeetCode：[反转链表](https://leetcode.cn/problems/reverse-linked-list/)

## 题目描述
给你单链表的头结点 `head`，请你反转链表，并返回反转后的头结点。

## 示例
- 示例1  
输入：`1 -> 2 -> 3 -> 4 -> 5`  
输出：`5 -> 4 -> 3 -> 2 -> 1`

- 示例2  
输入：`1 -> 2`  
输出：`2 -> 1`

- 示例3  
输入：空链表  
输出：空链表

## 最佳解法思路
- 思路1（推荐）：迭代，三指针  
用 `prev=null`，`cur=head`。每次保存 `next=cur.next`，把 `cur.next` 指向 `prev`，再整体推进：`prev=cur, cur=next`。最后 `prev` 就是新头。

- 思路2：递归  
递归到尾部返回新头；回溯时把 `head.next.next = head`，并把 `head.next = null` 断开原来的指向。

## Java 最佳实现

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（迭代）

## 总结（速记）
- 任何链表反转都离不开“先保存 next，再改指向”的顺序；不先保存就会丢链。
- 局部反转（92/25）本质是：先把要反转的段摘出来反转，再把前后接回去。
