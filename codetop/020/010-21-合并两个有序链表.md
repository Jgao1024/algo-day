# 21. 合并两个有序链表

- 题号：21
- 难度：简单
- LeetCode：[合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)

## 题目描述
将两个升序链表 `list1` 和 `list2` 合并为一个新的升序链表，并返回合并后的链表头结点。

## 示例
- 示例1  
输入：`1->2->4`，`1->3->4`  
输出：`1->1->2->3->4->4`

- 示例2  
输入：空链表，空链表  
输出：空链表

## 最佳解法思路
- 思路1（推荐）：迭代 + dummy  
用指针 `p1/p2` 逐个比较，把较小节点接到新链表尾部，最后把剩余部分整体接上。

- 思路2：递归  
每次选择较小的头结点作为结果头，递归合并剩余部分，写法更短。

## Java 最佳实现

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;

        ListNode p1 = list1, p2 = list2;
        while (p1 != null && p2 != null) {
            if (p1.val <= p2.val) {
                cur.next = p1;
                p1 = p1.next;
            } else {
                cur.next = p2;
                p2 = p2.next;
            }
            cur = cur.next;
        }

        cur.next = (p1 != null) ? p1 : p2;
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)（复用原节点）

## 总结（速记）
- 合并类题通用套路：`dummy + tail`，不断把“更小的头”接到尾部。
- 能整体接剩余就别一节点一节点接，代码更短。
