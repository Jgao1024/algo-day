# 3. 无重复字符的最长子串

- 题号：3
- 难度：中等
- LeetCode：[无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

## 题目描述
给定一个字符串 `s`，找出不含重复字符的最长子串的长度。

## 示例
- 示例1  
输入：`s = "abcabcbb"`  
输出：`3`  
解释：最长子串是 `"abc"`

- 示例2  
输入：`s = "bbbbb"`  
输出：`1`

- 示例3  
输入：`s = "pwwkew"`  
输出：`3`  
解释：最长子串是 `"wke"`

## 最佳解法思路
- 思路1（推荐）：滑动窗口 + 记录字符上次出现位置  
用 `left` 表示窗口左边界，遍历右边界 `i`。若当前字符 `c` 上次出现位置 `last[c] >= left`，说明窗口内重复，则 `left = last[c] + 1`。每步更新答案 `i - left + 1`。

- 思路2：双指针 + HashSet  
右指针扩张，遇到重复就不断移动左指针并从集合移除，直到不重复为止。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        Arrays.fill(last, -1);

        int left = 0;
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i);
            if (last[c] >= left) {
                left = last[c] + 1;
            }
            last[c] = i;
            ans = Math.max(ans, i - left + 1);
        }
        return ans;
    }
}
```

## 总结（速记）
- 这题属于“窗口内不允许重复”的约束；最佳写法是 `last[char]` 记录上次位置，重复就把 `left` 跳到 `last+1`，避免 while 循环反复挪。
- 窗口题常见三类：
  - 不含重复 / 至多 K 种：维护 `left` 和约束指标（last 或计数/种类数）
  - 固定长度：左右同步移动，维护计数差
  - 需要覆盖：先扩张到满足，再收缩到最小，再继续扩张
