# 53. 最大子数组和

- 题号：53
- 难度：中等
- LeetCode：[最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

## 题目描述
给你一个整数数组 `nums`，请你找出一个连续子数组（至少包含一个元素），使其和最大，并返回这个最大和。

## 示例
- 示例1  
输入：`nums = [-2,1,-3,4,-1,2,1,-5,4]`  
输出：`6`  
解释：`[4,-1,2,1]` 的和最大

- 示例2  
输入：`nums = [1]`  
输出：`1`

- 示例3  
输入：`nums = [5,4,-1,7,8]`  
输出：`23`

## 最佳解法思路
- 思路1（推荐）：Kadane 动态规划  
`dp` 表示“以当前位置结尾的最大子数组和”。转移：`dp = max(nums[i], dp + nums[i])`，答案是所有 `dp` 的最大值。

- 思路2：分治  
维护区间的 `sum / lmax / rmax / max` 四个量，可做到 \(O(n)\) 合并，整体 \(O(n\log n)\)。

## Java 最佳实现

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int dp = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            dp = Math.max(nums[i], dp + nums[i]);
            ans = Math.max(ans, dp);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- Kadane 的核心：要么把当前数接到之前的最优尾巴上，要么从当前数重新开始。
- 一看到“连续子数组最优”优先想：`dp(以 i 结尾)` 这个模型。
