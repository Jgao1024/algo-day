# 102. 二叉树的层序遍历

- 题号：102
- 难度：中等
- LeetCode：[二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

## 题目描述
给你二叉树的根节点 `root`，按层序遍历（从左到右）返回节点值。返回格式为 `List<List<Integer>>`，每一层一个列表。

## 示例
- 示例  
输入：`[3,9,20,null,null,15,7]`  
输出：`[[3],[9,20],[15,7]]`

## 最佳解法思路
- 思路1（推荐）：BFS 队列  
队列里放当前层节点，每次记录 `size`，循环 `size` 次弹出并把子节点入队，即可得到一层的结果。

- 思路2：DFS（按层收集）  
递归时带上 `depth`，如果 `res.size()==depth` 就新建一层，然后把值加进去。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) return ans;

        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int size = q.size();
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            ans.add(level);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（队列最宽一层）

- 层序遍历的“分层”关键：每轮先取 `size=q.size()`，这 `size` 个一定是同一层。
