# 50. Pow(x, n)

- 题号：50
- 难度：中等
- LeetCode：[Pow(x, n)](https://leetcode.cn/problems/powx-n/)

## 题目描述
实现 \(x^n\)（`n` 可能为负数）。

## 示例
- 示例1  
输入：`x = 2.00000, n = 10`  
输出：`1024.00000`

- 示例2  
输入：`x = 2.00000, n = -2`  
输出：`0.25000`

## 最佳解法思路
- 思路1（推荐）：快速幂（指数二进制拆分）  
把 `n` 转成 `long` 避免 `Integer.MIN_VALUE` 取反溢出。  
若 `n < 0`，先把 `x = 1/x`，再算 `x^{-n}`。  
遍历 `N` 的二进制位：若当前位为 1，就把答案乘上 `x`；每步 `x *= x`，`N >>= 1`。

## Java 最佳实现

```java
class Solution {
    public double myPow(double x, int n) {
        long N = n;
        if (N < 0) {
            x = 1.0 / x;
            N = -N;
        }

        double ans = 1.0;
        double base = x;
        while (N > 0) {
            if ((N & 1L) == 1L) ans *= base;
            base *= base;
            N >>= 1;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log |n|)\)
- 空间：\(O(1)\)

- 快速幂：`ans *= base`（遇到 1 位），`base *= base`（每右移一位）。
