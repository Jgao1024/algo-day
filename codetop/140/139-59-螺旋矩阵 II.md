# 59. 螺旋矩阵 II

- 题号：59
- 难度：中等
- LeetCode：[螺旋矩阵 II](https://leetcode.cn/problems/spiral-matrix-ii/)

## 题目描述
生成一个 `n x n` 矩阵，按顺时针螺旋填入 `1..n^2`。

## 示例
- 示例  
输入：`n = 3`  
输出：`[[1,2,3],[8,9,4],[7,6,5]]`

## 最佳解法思路
- 思路1（推荐）：四边界收缩模拟  
维护 `top/bottom/left/right` 四条边界：  
依次填充上边、右边、下边、左边，填完一圈就收缩边界，直到填满。

## Java 最佳实现

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] a = new int[n][n];
        int top = 0, bottom = n - 1, left = 0, right = n - 1;
        int cur = 1;
        while (top <= bottom && left <= right) {
            for (int c = left; c <= right; c++) a[top][c] = cur++;
            top++;

            for (int r = top; r <= bottom; r++) a[r][right] = cur++;
            right--;

            if (top <= bottom) {
                for (int c = right; c >= left; c--) a[bottom][c] = cur++;
                bottom--;
            }

            if (left <= right) {
                for (int r = bottom; r >= top; r--) a[r][left] = cur++;
                left++;
            }
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)（不计输出矩阵）

## 总结（速记）
- “四条边界 + 一圈一圈填”，每填完一条边就收缩对应边界。
