# 91. 解码方法

- 题号：91
- 难度：中等
- LeetCode：[解码方法](https://leetcode.cn/problems/decode-ways/)

## 题目描述
数字字符串 `s` 用 `1->A ... 26->Z` 解码，返回解码总数。`0` 不能单独解码。

## 示例
- 示例1  
输入：`s = "12"`  
输出：`2`（"AB", "L"）

- 示例2  
输入：`s = "06"`  
输出：`0`

## 最佳解法思路
- 思路1（推荐）：DP（滚动变量）  
设 `dp[i]` 表示前 `i` 个字符的解码数。  
转移：  
若 `s[i-1] != '0'`，`dp[i] += dp[i-1]`；  
若两位数 `s[i-2..i-1]` 在 `[10,26]`，`dp[i] += dp[i-2]`。  
只依赖前两项，用两个变量滚动即可。

## Java 最佳实现

```java
class Solution {
    public int numDecodings(String s) {
        if (s == null || s.length() == 0) return 0;
        int n = s.length();
        int dp0 = 1;
        int dp1 = s.charAt(0) == '0' ? 0 : 1;
        for (int i = 2; i <= n; i++) {
            int cur = 0;
            char c1 = s.charAt(i - 1);
            char c0 = s.charAt(i - 2);

            if (c1 != '0') cur += dp1;
            int two = (c0 - '0') * 10 + (c1 - '0');
            if (two >= 10 && two <= 26) cur += dp0;

            dp0 = dp1;
            dp1 = cur;
        }
        return dp1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 每个位置看 1 位、再看 2 位；`0` 只能和前一位组成 `10/20`。
