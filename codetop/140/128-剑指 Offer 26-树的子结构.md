# 剑指 Offer 26. 树的子结构

- 题号：剑指 Offer 26
- 难度：中等
- LeetCode：[树的子结构](https://leetcode.cn/problems/shu-de-zi-jie-gou-lcof/)

## 题目描述
判断树 B 是否为树 A 的子结构（B 不能是空树）。

## 示例
- 示例  
输入：`A = [3,4,5,1,2]`，`B = [4,1]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：遍历 A + 从每个节点尝试匹配 B  
在 A 的每个节点 `a` 上尝试把 B 从根开始匹配：  
`match(a,b)`：若 `b` 为空返回 true；若 `a` 为空或值不同返回 false；否则递归匹配左右子树。  
主过程：`isSubStructure(A,B) = match(A,B) || isSubStructure(A.left,B) || isSubStructure(A.right,B)`。

## Java 最佳实现

```java
class Solution {
    public boolean isSubStructure(TreeNode A, TreeNode B) {
        if (A == null || B == null) return false;
        return match(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B);
    }

    private boolean match(TreeNode a, TreeNode b) {
        if (b == null) return true;
        if (a == null) return false;
        if (a.val != b.val) return false;
        return match(a.left, b.left) && match(a.right, b.right);
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(|A|\cdot|B|)\)
- 空间：\(O(h)\)（递归栈）

## 总结（速记）
- 先“选起点”（遍历 A），再“校验结构”（match）。
