# 114. 二叉树展开为链表

- 题号：114
- 难度：中等
- LeetCode：[二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

## 题目描述
把二叉树原地展开成单链表：按前序遍历顺序连接，所有 `left` 置为 `null`，只用 `right` 指针串起来。

## 示例
- 示例  
输入：`root = [1,2,5,3,4,null,6]`  
输出：`[1,null,2,null,3,null,4,null,5,null,6]`

## 最佳解法思路
- 思路1（推荐）：原地迭代（类似 Morris 思想）  
遍历 `cur`：若 `cur.left` 不为空，找到左子树最右节点 `p`（前序里 `cur` 的前驱），把 `cur.right` 接到 `p.right`，再把 `cur.left` 挪到 `cur.right`，并置 `cur.left=null`。最后 `cur = cur.right`。

- 思路2：后序递归（返回尾结点）  
递归把左右子树先展开，再拼接。

## Java 最佳实现

```java
class Solution {
    public void flatten(TreeNode root) {
        TreeNode cur = root;
        while (cur != null) {
            if (cur.left != null) {
                TreeNode p = cur.left;
                while (p.right != null) p = p.right;
                p.right = cur.right;
                cur.right = cur.left;
                cur.left = null;
            }
            cur = cur.right;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 每到一个节点：把左子树“搬到右边”，右子树接到左子树最右端。
