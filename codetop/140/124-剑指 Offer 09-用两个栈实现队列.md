# 剑指 Offer 09. 用两个栈实现队列

- 题号：剑指 Offer 09
- 难度：简单
- LeetCode：[用两个栈实现队列](https://leetcode.cn/problems/yong-liang-ge-zhan-shi-xian-dui-lie-lcof/)

## 题目描述
用两个栈实现一个队列，支持 `appendTail(x)` 和 `deleteHead()`。

## 示例
- 示例  
操作：`appendTail(3) -> deleteHead() -> deleteHead()`  
输出：`3, -1`

## 最佳解法思路
- 思路1（推荐）：入栈/出栈双栈  
用 `in` 负责入队，用 `out` 负责出队。  
出队时若 `out` 为空，就把 `in` 全部倒到 `out`（顺序反转），然后从 `out` 弹出。  
每个元素最多被搬运一次，均摊时间 \(O(1)\)。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class CQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public CQueue() {
    }

    public void appendTail(int value) {
        in.push(value);
    }

    public int deleteHead() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) out.push(in.pop());
        }
        return out.isEmpty() ? -1 : out.pop();
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\)
- 空间：\(O(n)\)

- `out` 为空才倒一次；倒完就一直从 `out` 出队。
