# 958. 二叉树的完全性检验

- 题号：958
- 难度：中等
- LeetCode：[二叉树的完全性检验](https://leetcode.cn/problems/check-completeness-of-a-binary-tree/)

## 题目描述
判断一棵二叉树是否为完全二叉树。

## 示例
- 示例  
输入：`root = [1,2,3,4,5,6]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：层序遍历 + 空节点标记  
按层序遍历，把左右孩子（可以是 null）都入队。  
一旦遇到 `null`，后面再遇到非空节点就不是完全二叉树。

- 思路2：完全二叉树编号法  
层序给节点编号（根为 1，左 2i，右 2i+1），若最后一个节点编号等于节点总数则为完全二叉树。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isCompleteTree(TreeNode root) {
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        boolean seenNull = false;

        while (!q.isEmpty()) {
            TreeNode cur = q.poll();
            if (cur == null) {
                seenNull = true;
                continue;
            }
            if (seenNull) return false;
            q.offer(cur.left);
            q.offer(cur.right);
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（队列）

## 总结（速记）
- 层序遍历遇到 `null` 后，后面不能再出现非空节点。
