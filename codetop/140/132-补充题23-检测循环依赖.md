# 补充题23. 检测循环依赖

- 题号：补充题23
- 难度：中等
- 题面链接：[检测循环依赖](https://mp.weixin.qq.com/s/pCRscwKqQdYYN7M1Sia7xA)

## 题目描述
给定若干依赖关系（有向边），判断是否存在循环依赖。

## 示例
- 示例  
依赖：`0 <- 1 <- 2 <- 0`  
输出：存在循环

## 最佳解法思路
- 思路1（推荐）：拓扑排序（Kahn）判环  
统计每个节点入度，把入度为 0 的点入队，不断出队并削减其后继入度。  
若最终能处理的节点数 `cnt == n`，说明无环；否则有环（循环依赖导致入度无法清零）。

- 思路2：DFS 三色标记  
递归过程中遇到“正在访问”的节点（灰色）即可判环。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    // deps[i] = [a, b] 表示 a 依赖 b（边 b -> a）
    public boolean hasCycle(int n, int[][] deps) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        int[] indeg = new int[n];

        for (int[] e : deps) {
            int a = e[0], b = e[1];
            g.get(b).add(a);
            indeg[a]++;
        }

        Deque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (indeg[i] == 0) q.offer(i);
        }

        int cnt = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            cnt++;
            for (int v : g.get(u)) {
                if (--indeg[v] == 0) q.offer(v);
            }
        }
        return cnt != n;
    }
}
```

## 复杂度分析
- 时间：\(O(n+m)\)（m 为依赖条数）
- 空间：\(O(n+m)\)

## 总结（速记）
- 拓扑能排完（`cnt==n`）就无环；排不完就是循环依赖。
