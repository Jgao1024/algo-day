# 74. 搜索二维矩阵

- 题号：74
- 难度：中等
- LeetCode：[搜索二维矩阵](https://leetcode.cn/problems/search-a-2d-matrix/)

## 题目描述
矩阵满足：每行升序，且下一行的首元素大于上一行的末元素。判断 `target` 是否存在。

## 示例
- 示例  
输入：`matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]`, `target = 3`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：把矩阵当作一维有序数组二分  
下标 `mid` 映射到二维：`r = mid / n`，`c = mid % n`。  
直接在 `[0, m*n-1]` 上二分即可。

- 思路2：先二分找行，再二分找列  
先定位可能的行，再在该行里二分。

## Java 最佳实现

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int l = 0, r = m * n - 1;
        while (l <= r) {
            int mid = l + ((r - l) >>> 1);
            int x = matrix[mid / n][mid % n];
            if (x == target) return true;
            if (x < target) l = mid + 1;
            else r = mid - 1;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(\log(mn))\)
- 空间：\(O(1)\)
