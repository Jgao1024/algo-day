# 剑指 Offer 51. 数组中的逆序对

- 题号：剑指 Offer 51
- 难度：困难
- LeetCode：[数组中的逆序对](https://leetcode.cn/problems/shu-zu-zhong-de-ni-xu-dui-lcof/)

## 题目描述
在数组中统计逆序对数量：满足 \(i<j\) 且 `nums[i] > nums[j]` 的二元组个数。

## 示例
- 示例  
输入：`nums = [7,5,6,4]`  
输出：`5`

## 最佳解法思路
- 思路1（推荐）：归并排序计数  
分治统计左右逆序对；合并两段有序数组时，若 `left[i] > right[j]`，则 `left[i..mid]` 都与 `right[j]` 构成逆序对，一次性加 `mid - i + 1`。

- 思路2：树状数组（离散化）  
从右往左遍历，统计“比当前值小的已出现元素数量”。

## Java 最佳实现

```java
class Solution {
    public int reversePairs(int[] nums) {
        if (nums == null || nums.length == 0) return 0;
        int[] tmp = new int[nums.length];
        return sort(nums, 0, nums.length - 1, tmp);
    }

    private int sort(int[] a, int l, int r, int[] tmp) {
        if (l >= r) return 0;
        int mid = l + ((r - l) >>> 1);
        int cnt = sort(a, l, mid, tmp) + sort(a, mid + 1, r, tmp);

        int i = l, j = mid + 1, k = l;
        while (i <= mid && j <= r) {
            if (a[i] <= a[j]) {
                tmp[k++] = a[i++];
            } else {
                cnt += (mid - i + 1);
                tmp[k++] = a[j++];
            }
        }
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= r) tmp[k++] = a[j++];
        for (int p = l; p <= r; p++) a[p] = tmp[p];
        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
