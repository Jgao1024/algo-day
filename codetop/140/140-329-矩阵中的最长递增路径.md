# 329. 矩阵中的最长递增路径

- 题号：329
- 难度：困难
- LeetCode：[矩阵中的最长递增路径](https://leetcode.cn/problems/longest-increasing-path-in-a-matrix/)

## 题目描述
在矩阵中从任意格子出发，每步只能上下左右移动到更大的数，求最长递增路径长度。

## 示例
- 示例  
输入：`matrix = [[9,9,4],[6,6,8],[2,1,1]]`  
输出：`4`（`1 -> 2 -> 6 -> 9`）

## 最佳解法思路
- 思路1（推荐）：拓扑分层（DAG 最长路）  
把每个格子看作节点：若 `a[u] < a[v]`（相邻），则有边 `u -> v`。图是 DAG（严格递增不会成环）。  
计算每个节点的出度 `out[u]`（能走向更大值的邻居数），把 `out==0`（局部最大）入队。  
按层 BFS：每处理一层，相当于把路径长度 +1；处理节点时，去找比它小的邻居 `p`，把 `out[p]--`，减到 0 就入队。最后层数就是答案。

- 思路2：DFS + 记忆化  
`dp[r][c]` 表示从该点出发的最长路径，递归求 `1 + max(dp[next])`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestIncreasingPath(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] out = new int[m][n];
        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                for (int k = 0; k < 4; k++) {
                    int nr = r + dr[k], nc = c + dc[k];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    if (matrix[nr][nc] > matrix[r][c]) out[r][c]++;
                }
            }
        }

        Deque<Integer> q = new ArrayDeque<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (out[r][c] == 0) q.offer(r * n + c);
            }
        }

        int ans = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            ans++;
            for (int i = 0; i < size; i++) {
                int id = q.poll();
                int r = id / n, c = id % n;
                for (int k = 0; k < 4; k++) {
                    int nr = r + dr[k], nc = c + dc[k];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    if (matrix[nr][nc] < matrix[r][c]) {
                        if (--out[nr][nc] == 0) q.offer(nr * n + nc);
                    }
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)

## 总结（速记）
- 递增形成 DAG：从“出度为 0 的峰顶”开始一层层剥离，层数就是最长递增长度。
