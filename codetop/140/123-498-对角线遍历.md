# 498. 对角线遍历

- 题号：498
- 难度：中等
- LeetCode：[对角线遍历](https://leetcode.cn/problems/diagonal-traverse/)

## 题目描述
按对角线顺序遍历矩阵：同一条对角线满足 `row + col` 相等，并且方向交替（上右、下左）。

## 示例
- 示例  
输入：`mat = [[1,2,3],[4,5,6],[7,8,9]]`  
输出：`[1,2,4,7,5,3,6,8,9]`

## 最佳解法思路
- 思路1（推荐）：按对角线编号 \(d=row+col\) 模拟  
一共 `m+n-1` 条对角线。  
当 `d` 为偶数：从“下往上”走（row--, col++）；当 `d` 为奇数：从“上往下”走（row++, col--）。每条对角线的起点可由边界直接算出。

- 思路2：分桶再拼接  
按 `d=row+col` 把元素分到不同桶里，偶数桶反转后拼接。

## Java 最佳实现

```java
class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[] ans = new int[m * n];
        int idx = 0;

        for (int d = 0; d <= m + n - 2; d++) {
            if ((d & 1) == 0) {
                int r = Math.min(d, m - 1);
                int c = d - r;
                while (r >= 0 && c < n) {
                    ans[idx++] = mat[r--][c++];
                }
            } else {
                int c = Math.min(d, n - 1);
                int r = d - c;
                while (c >= 0 && r < m) {
                    ans[idx++] = mat[r++][c--];
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)（不计输出数组）

## 总结（速记）
- 记住 `d=row+col`：偶数对角线从下往上扫，奇数对角线从上往下扫。
