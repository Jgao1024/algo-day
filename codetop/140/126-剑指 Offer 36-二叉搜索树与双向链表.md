# 剑指 Offer 36. 二叉搜索树与双向链表

- 题号：剑指 Offer 36
- 难度：中等
- LeetCode：[二叉搜索树与双向链表](https://leetcode.cn/problems/er-cha-sou-suo-shu-yu-shuang-xiang-lian-biao-lcof/)

## 题目描述
把 BST 转换成一个**排序的循环双向链表**（原地修改指针），返回链表头结点。

## 示例
- 示例  
输入：`root = [4,2,5,1,3]`  
输出：`1 <-> 2 <-> 3 <-> 4 <-> 5`（循环）

## 最佳解法思路
- 思路1（推荐）：中序遍历原地串联  
BST 的中序遍历就是升序序列。  
用 `pre` 记录上一访问节点：`pre.right = cur`，`cur.left = pre`。  
遍历结束后，把 `head.left = tail`、`tail.right = head` 连接成循环。

## Java 最佳实现

```java
class Solution {
    private Node head;
    private Node pre;

    public Node treeToDoublyList(Node root) {
        if (root == null) return null;
        dfs(root);
        head.left = pre;
        pre.right = head;
        return head;
    }

    private void dfs(Node cur) {
        if (cur == null) return;
        dfs(cur.left);
        if (pre == null) {
            head = cur;
        } else {
            pre.right = cur;
            cur.left = pre;
        }
        pre = cur;
        dfs(cur.right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）
