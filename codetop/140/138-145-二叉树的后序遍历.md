# 145. 二叉树的后序遍历

- 题号：145
- 难度：中等
- LeetCode：[二叉树的后序遍历](https://leetcode.cn/problems/binary-tree-postorder-traversal/)

## 题目描述
返回二叉树的后序遍历结果（左、右、根）。

## 示例
- 示例  
输入：`root = [1,null,2,3]`  
输出：`[3,2,1]`

## 最佳解法思路
- 思路1（推荐）：迭代 + 前驱指针  
用栈模拟递归，`prev` 记录上一次访问的节点：  
每次看栈顶 `cur`：  
若 `cur` 是叶子，或 `prev` 是 `cur` 的孩子（说明孩子已处理完），就访问 `cur` 并出栈；  
否则先压右孩子再压左孩子（保证左先处理）。

- 思路2：反向前序  
前序是 根-左-右，把它改成 根-右-左，再把结果反转即可得到 左-右-根。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) return ans;

        Deque<TreeNode> st = new ArrayDeque<>();
        st.push(root);
        TreeNode prev = null;

        while (!st.isEmpty()) {
            TreeNode cur = st.peek();
            boolean leaf = (cur.left == null && cur.right == null);
            boolean childDone = (prev != null && (prev == cur.left || prev == cur.right));
            if (leaf || childDone) {
                ans.add(cur.val);
                st.pop();
                prev = cur;
            } else {
                if (cur.right != null) st.push(cur.right);
                if (cur.left != null) st.push(cur.left);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（栈）

## 总结（速记）
- 后序迭代的关键：用 `prev` 判断“孩子是否处理完”，处理完才访问根。
