# 7. 整数反转

- 题号：7
- 难度：简单
- LeetCode：[整数反转](https://leetcode.cn/problems/reverse-integer/)

## 题目描述
把 32 位有符号整数 `x` 的数字反转。若反转后溢出（超出 `[-2^31, 2^31-1]`）返回 0。

## 示例
- 示例1  
输入：`x = 123`  
输出：`321`

- 示例2  
输入：`x = -120`  
输出：`-21`

## 最佳解法思路
- 思路1（推荐）：逐位弹出 + 溢出判定  
每次取末位 `pop = x % 10`，更新 `x /= 10`。  
把 `pop` 拼到答案：`res = res * 10 + pop`。  
关键是更新前判断是否会溢出：  
`res > MAX/10` 或 `res == MAX/10 && pop > 7`；  
`res < MIN/10` 或 `res == MIN/10 && pop < -8`。

## Java 最佳实现

```java
class Solution {
    public int reverse(int x) {
        int res = 0;
        while (x != 0) {
            int pop = x % 10;
            x /= 10;

            if (res > Integer.MAX_VALUE / 10 || (res == Integer.MAX_VALUE / 10 && pop > 7)) return 0;
            if (res < Integer.MIN_VALUE / 10 || (res == Integer.MIN_VALUE / 10 && pop < -8)) return 0;

            res = res * 10 + pop;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(\log |x|)\)
- 空间：\(O(1)\)

## 总结（速记）
- 反转不难，难在溢出：先判 `res*10 + pop` 会不会越界。
