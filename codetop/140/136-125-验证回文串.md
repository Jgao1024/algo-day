# 125. 验证回文串

- 题号：125
- 难度：简单
- LeetCode：[验证回文串](https://leetcode.cn/problems/valid-palindrome/)

## 题目描述
只考虑字母和数字，忽略大小写，判断字符串是否为回文。

## 示例
- 示例1  
输入：`s = "A man, a plan, a canal: Panama"`  
输出：`true`

- 示例2  
输入：`s = "race a car"`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：双指针跳过无效字符  
左右指针向中间走：遇到非字母数字就跳过；有效字符统一转小写后比较，不等直接返回 false。

## Java 最佳实现

```java
class Solution {
    public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
            while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
            if (l < r) {
                char a = Character.toLowerCase(s.charAt(l));
                char b = Character.toLowerCase(s.charAt(r));
                if (a != b) return false;
                l++;
                r--;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
