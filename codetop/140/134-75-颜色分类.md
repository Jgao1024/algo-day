# 75. 颜色分类

- 题号：75
- 难度：中等
- LeetCode：[颜色分类](https://leetcode.cn/problems/sort-colors/)

## 题目描述
数组只包含 `0/1/2`，原地排序，使相同颜色相邻且按 `0,1,2` 顺序。

## 示例
- 示例  
输入：`nums = [2,0,2,1,1,0]`  
输出：`[0,0,1,1,2,2]`

## 最佳解法思路
- 思路1（推荐）：三指针（荷兰国旗）  
维护三个区间：  
`[0..low-1]` 都是 0，`[low..i-1]` 都是 1，`[high+1..end]` 都是 2。  
遍历指针 `i`：  
遇到 0 -> 和 `low` 交换，`low++，i++`；  
遇到 1 -> `i++`；  
遇到 2 -> 和 `high` 交换，`high--`（`i` 不动，因为换过来的还没看）。

## Java 最佳实现

```java
class Solution {
    public void sortColors(int[] nums) {
        int low = 0, i = 0, high = nums.length - 1;
        while (i <= high) {
            if (nums[i] == 0) {
                swap(nums, low++, i++);
            } else if (nums[i] == 1) {
                i++;
            } else {
                swap(nums, i, high--);
            }
        }
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 0 放左、2 放右、1 留中间；遇 2 换到右边后 `i` 先别动。
