## 最佳解法思路
- 用 `ArrayList` 存多组栈，每个栈容量为 `cap`。
- `push`：最后一组栈满了就新建一组再入栈；`cap==0` 时直接忽略。
- `pop`：等价于对最后一组做 `popAt`；弹出后若该栈为空则移除这一组。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;

class StackOfPlates {
    private final int cap;
    private final ArrayList<ArrayDeque<Integer>> stacks = new ArrayList<>();

    public StackOfPlates(int cap) {
        this.cap = cap;
    }

    public void push(int val) {
        if (cap <= 0) return;
        if (stacks.isEmpty() || stacks.get(stacks.size() - 1).size() == cap) {
            stacks.add(new ArrayDeque<>());
        }
        stacks.get(stacks.size() - 1).push(val);
    }

    public int pop() {
        return popAt(stacks.size() - 1);
    }

    public int popAt(int index) {
        if (cap <= 0) return -1;
        if (index < 0 || index >= stacks.size()) return -1;
        ArrayDeque<Integer> st = stacks.get(index);
        if (st.isEmpty()) return -1;
        int v = st.pop();
        if (st.isEmpty()) stacks.remove(index);
        return v;
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\)
- 空间：\(O(n)\)
