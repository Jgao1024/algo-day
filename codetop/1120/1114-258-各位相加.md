## 最佳解法思路
- 数字根：不断求各位和直到一位数，结果满足公式  
  - `num == 0` 时为 0  
  - 否则为 \(1 + (num - 1) \bmod 9\)

## Java 最佳实现

```java
class Solution {
    public int addDigits(int num) {
        if (num == 0) return 0;
        return 1 + (num - 1) % 9;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
