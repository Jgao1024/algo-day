## 最佳解法思路
- 设初始 \(x=1,y=0\)。无论执行 `A`（\(x=2x+y\)）还是 `B`（\(y=2y+x\)），都有 \(x+y\) 变为 \(2(x+y)\)。
- 初始 \(x+y=1\)，执行 \(n\) 次后结果为 \(2^n\)。

## Java 最佳实现

```java
class Solution {
    public int calculate(String s) {
        int ans = 1;
        for (int i = 0; i < s.length(); i++) {
            ans <<= 1;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
