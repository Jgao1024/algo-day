## 最佳解法思路
- 题目原本是 SQL，输出两行：  
  - 评分次数最多的用户（次数并列取名字典序最小）  
  - 2020-02 期间平均评分最高的电影（并列取电影名字典序最小）
- 用 Java 表达：  
  - 用映射 `userId->name`、`movieId->title`；  
  - 遍历评分表：统计用户评分次数；同时对 2020-02 的电影累计 `sum/count`；  
  - 最后按规则做最大值与字典序并列处理。

## Java 最佳实现

```java
import java.time.LocalDate;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class User {
        int userId;
        String name;
        User(int userId, String name) { this.userId = userId; this.name = name; }
    }

    static class Movie {
        int movieId;
        String title;
        Movie(int movieId, String title) { this.movieId = movieId; this.title = title; }
    }

    static class Rating {
        int movieId;
        int userId;
        int rating;
        LocalDate createdAt;
        Rating(int movieId, int userId, int rating, LocalDate createdAt) {
            this.movieId = movieId;
            this.userId = userId;
            this.rating = rating;
            this.createdAt = createdAt;
        }
    }

    public String[] movieRating(List<User> users, List<Movie> movies, List<Rating> ratings) {
        Map<Integer, String> userName = new HashMap<>();
        for (User u : users) userName.put(u.userId, u.name);
        Map<Integer, String> movieTitle = new HashMap<>();
        for (Movie m : movies) movieTitle.put(m.movieId, m.title);

        Map<Integer, Integer> userCnt = new HashMap<>();
        Map<Integer, long[]> movieSumCnt = new HashMap<>(); // movieId -> [sum, cnt]

        for (Rating r : ratings) {
            userCnt.put(r.userId, userCnt.getOrDefault(r.userId, 0) + 1);
            if (r.createdAt.getYear() == 2020 && r.createdAt.getMonthValue() == 2) {
                long[] sc = movieSumCnt.computeIfAbsent(r.movieId, k -> new long[2]);
                sc[0] += r.rating;
                sc[1] += 1;
            }
        }

        String bestUser = "";
        int bestUserCnt = -1;
        for (Map.Entry<Integer, Integer> e : userCnt.entrySet()) {
            String name = userName.get(e.getKey());
            int cnt = e.getValue();
            if (cnt > bestUserCnt || (cnt == bestUserCnt && name.compareTo(bestUser) < 0)) {
                bestUserCnt = cnt;
                bestUser = name;
            }
        }

        String bestMovie = "";
        long bestSum = -1;
        long bestCnt = 1;
        for (Map.Entry<Integer, long[]> e : movieSumCnt.entrySet()) {
            String title = movieTitle.get(e.getKey());
            long sum = e.getValue()[0];
            long cnt = e.getValue()[1];
            if (bestSum < 0) {
                bestSum = sum;
                bestCnt = cnt;
                bestMovie = title;
                continue;
            }
            long left = sum * bestCnt;
            long right = bestSum * cnt;
            if (left > right || (left == right && title.compareTo(bestMovie) < 0)) {
                bestSum = sum;
                bestCnt = cnt;
                bestMovie = title;
            }
        }

        return new String[]{bestUser, bestMovie};
    }
}
```

- 空间：\(O(U+M)\)
