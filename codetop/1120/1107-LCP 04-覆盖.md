## 最佳解法思路
- 棋盘黑白染色，把每个可用格子视为点，相邻可放一块多米诺骨牌视为边。
- 最大覆盖数 = 二分图最大匹配数：在黑格一侧做增广路匹配（匈牙利/DFS）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    private int n;
    private int m;
    private boolean[][] bad;
    private int[] match;      // 右侧点 -> 匹配到的左侧点
    private boolean[] vis;    // 右侧点访问标记
    private final int[] dx = {1, -1, 0, 0};
    private final int[] dy = {0, 0, 1, -1};

    public int domino(int n, int m, int[][] broken) {
        this.n = n;
        this.m = m;
        bad = new boolean[n][m];
        for (int[] b : broken) bad[b[0]][b[1]] = true;

        match = new int[n * m];
        Arrays.fill(match, -1);

        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (bad[i][j]) continue;
                if (((i + j) & 1) != 0) continue;
                vis = new boolean[n * m];
                if (dfs(i * m + j)) ans++;
            }
        }
        return ans;
    }

    private boolean dfs(int leftId) {
        int x = leftId / m;
        int y = leftId % m;
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k];
            int ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (bad[nx][ny]) continue;
            int rightId = nx * m + ny;
            if (vis[rightId]) continue;
            vis[rightId] = true;
            if (match[rightId] == -1 || dfs(match[rightId])) {
                match[rightId] = leftId;
                return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(VE)\)（DFS 增广路）
- 空间：\(O(V)\)
