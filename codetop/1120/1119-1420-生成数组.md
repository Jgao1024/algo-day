## 最佳解法思路
- DP（经典题）：`dp[len][max][cost]` 表示长度为 `len`、最大值为 `max`、搜索代价为 `cost` 的数组数量。
- 转移（在末尾新增一个数）：
  - 选 `1..max`：最大值不变，有 `max` 种选法：`dp[len][max][cost] += dp[len-1][max][cost] * max`
  - 选 `max` 且之前最大值 `< max`：代价 +1：  
    `dp[len][max][cost] += sum_{p<max} dp[len-1][p][cost-1]`
- 用前缀和把 `sum_{p<max}` 优化到 \(O(1)\)，整体 \(O(nmk)\)。

## Java 最佳实现

```java
class Solution {
    public int numOfArrays(int n, int m, int k) {
        int MOD = 1_000_000_007;
        long[][] dp = new long[m + 1][k + 1];
        for (int max = 1; max <= m; max++) dp[max][1] = 1;

        for (int len = 2; len <= n; len++) {
            long[][] ndp = new long[m + 1][k + 1];
            for (int cost = 1; cost <= k; cost++) {
                long sumLess = 0;
                for (int max = 1; max <= m; max++) {
                    long keep = (dp[max][cost] * max) % MOD;
                    long inc = (cost == 1) ? 0 : sumLess;
                    ndp[max][cost] = (keep + inc) % MOD;
                    if (cost > 1) sumLess = (sumLess + dp[max][cost - 1]) % MOD;
                }
            }
            dp = ndp;
        }

        long ans = 0;
        for (int max = 1; max <= m; max++) ans = (ans + dp[max][k]) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(nmk)\)
- 空间：\(O(mk)\)
