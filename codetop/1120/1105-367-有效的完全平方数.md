## 最佳解法思路
- 二分查找整数 \(x\)，判断是否存在 \(x^2=num\)。注意用 `long` 防止乘法溢出。

## Java 最佳实现

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        long lo = 1;
        long hi = num;
        while (lo <= hi) {
            long mid = (lo + hi) >>> 1;
            long sq = mid * mid;
            if (sq == num) return true;
            if (sq < num) lo = mid + 1;
            else hi = mid - 1;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(\log num)\)
- 空间：\(O(1)\)
