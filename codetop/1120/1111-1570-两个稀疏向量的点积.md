## 最佳解法思路
- 只存非 0 元素（下标 + 值），两向量做点积时用双指针按下标归并；相同下标相乘累加。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class SparseVector {
    private final List<int[]> list = new ArrayList<>();

    SparseVector(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) list.add(new int[]{i, nums[i]});
        }
    }

    public int dotProduct(SparseVector vec) {
        int i = 0, j = 0;
        int ans = 0;
        while (i < list.size() && j < vec.list.size()) {
            int[] a = list.get(i);
            int[] b = vec.list.get(j);
            if (a[0] == b[0]) {
                ans += a[1] * b[1];
                i++;
                j++;
            } else if (a[0] < b[0]) {
                i++;
            } else {
                j++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(p+q)\)（p/q 为非零元素个数）
- 空间：\(O(p+q)\)
