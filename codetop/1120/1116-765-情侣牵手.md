## 最佳解法思路
- 每对情侣编号为 `person/2`。每一排座位 `(2i, 2i+1)` 上的两个人所属情侣必然需要在同一“连通块”内通过交换变成相邻。
- 把同一排座位上的两个人的情侣编号做并查集 union；每个连通块大小为 `s` 时需要 `s-1` 次交换。
- 总答案 = `couples - components`。

## Java 最佳实现

```java
class Solution {
    public int minSwapsCouples(int[] row) {
        int couples = row.length / 2;
        DSU dsu = new DSU(couples);
        for (int i = 0; i < row.length; i += 2) {
            dsu.union(row[i] / 2, row[i + 1] / 2);
        }
        int components = 0;
        for (int i = 0; i < couples; i++) {
            if (dsu.find(i) == i) components++;
        }
        return couples - components;
    }

    private static class DSU {
        int[] p;
        int[] r;

        DSU(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) p[i] = i;
        }

        int find(int x) {
            if (p[x] != x) p[x] = find(p[x]);
            return p[x];
        }

        void union(int a, int b) {
            int pa = find(a);
            int pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else {
                p[pb] = pa;
                r[pa]++;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n \alpha(n))\)
- 空间：\(O(n)\)
