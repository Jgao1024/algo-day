## 最佳解法思路
- 固定长度为 \(k\) 的滑动窗口：先算前 \(k\) 个和，然后窗口右移时减去左端、加上右端，维护最大窗口和即可。

## Java 最佳实现

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        long sum = 0;
        for (int i = 0; i < k; i++) sum += nums[i];
        long best = sum;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i];
            sum -= nums[i - k];
            if (sum > best) best = sum;
        }
        return best * 1.0 / k;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
