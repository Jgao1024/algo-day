## 最佳解法思路
- 每次操作把一个左上角子矩阵全 +1，最终最大值只出现在所有操作子矩阵的交集。
- 交集尺寸为 `minRow = min(a)`、`minCol = min(b)`，答案是 `minRow * minCol`；无操作则为 `m*n`。

## Java 最佳实现

```java
class Solution {
    public int maxCount(int m, int n, int[][] ops) {
        int minRow = m;
        int minCol = n;
        for (int[] op : ops) {
            minRow = Math.min(minRow, op[0]);
            minCol = Math.min(minCol, op[1]);
        }
        return minRow * minCol;
    }
}
```

## 复杂度分析
- 时间：\(O(k)\)，k 为操作数
- 空间：\(O(1)\)
