## 最佳解法思路
- 预处理 `ring` 中每个字符出现的位置列表 `pos[c]`。
- DP：`dp[i]` 表示当前指针停在 `ring[i]`，已经拼出 `key` 前缀的最小步数。  
  - 从上一层所有位置 `p1` 转移到当前字符位置 `p2`：  
    `ndp[p2] = min(ndp[p2], dp[p1] + rotate(p1,p2) + 1)`，其中 `+1` 是按下按钮。
- 旋转代价 `rotate(a,b)=min(|a-b|, n-|a-b|)`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int findRotateSteps(String ring, String key) {
        int n = ring.length();
        @SuppressWarnings("unchecked")
        List<Integer>[] pos = new List[26];
        for (int i = 0; i < 26; i++) pos[i] = new ArrayList<>();
        for (int i = 0; i < n; i++) pos[ring.charAt(i) - 'a'].add(i);

        int INF = 1_000_000_000;
        int[] dp = new int[n];
        Arrays.fill(dp, INF);
        for (int p : pos[key.charAt(0) - 'a']) {
            dp[p] = dist(0, p, n) + 1;
        }

        for (int idx = 1; idx < key.length(); idx++) {
            int c = key.charAt(idx) - 'a';
            int pc = key.charAt(idx - 1) - 'a';
            int[] ndp = new int[n];
            Arrays.fill(ndp, INF);

            for (int p2 : pos[c]) {
                int best = INF;
                for (int p1 : pos[pc]) {
                    best = Math.min(best, dp[p1] + dist(p1, p2, n));
                }
                ndp[p2] = best + 1;
            }
            dp = ndp;
        }

        int last = key.charAt(key.length() - 1) - 'a';
        int ans = INF;
        for (int p : pos[last]) ans = Math.min(ans, dp[p]);
        return ans;
    }

    private int dist(int a, int b, int n) {
        int d = Math.abs(a - b);
        return Math.min(d, n - d);
    }
}
```

## 复杂度分析
- 时间：\(O(|key|\cdot n^2)\)（n 为 `ring` 长度，通常 \(\le 100\)）
- 空间：\(O(n)\)
