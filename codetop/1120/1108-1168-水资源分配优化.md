## 最佳解法思路
- 把“在每家打井”看成从虚拟点 0 连到房子 i 的边，代价为 `wells[i-1]`；管道 `pipes` 也是边。
- 在包含 0..n 的图上求最小生成树（Kruskal/Prim），总权重即最小供水成本。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minCostToSupplyWater(int n, int[] wells, int[][] pipes) {
        int m = pipes.length;
        int[][] edges = new int[m + n][3];
        int idx = 0;
        for (int i = 1; i <= n; i++) {
            edges[idx++] = new int[]{0, i, wells[i - 1]};
        }
        for (int[] p : pipes) {
            edges[idx++] = new int[]{p[0], p[1], p[2]};
        }

        Arrays.sort(edges, (a, b) -> a[2] - b[2]);
        DSU dsu = new DSU(n + 1);
        int ans = 0;
        for (int[] e : edges) {
            if (dsu.union(e[0], e[1])) ans += e[2];
        }
        return ans;
    }

    private static class DSU {
        int[] p;
        int[] r;

        DSU(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) p[i] = i;
        }

        int find(int x) {
            while (p[x] != x) {
                p[x] = p[p[x]];
                x = p[x];
            }
            return x;
        }

        boolean union(int a, int b) {
            int pa = find(a);
            int pb = find(b);
            if (pa == pb) return false;
            if (r[pa] < r[pb]) {
                p[pa] = pb;
            } else if (r[pa] > r[pb]) {
                p[pb] = pa;
            } else {
                p[pb] = pa;
                r[pa]++;
            }
            return true;
        }
    }
}
```

## 复杂度分析
- 时间：\(O((n+m)\log(n+m))\)
- 空间：\(O(n+m)\)
