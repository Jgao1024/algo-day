## 最佳解法思路
- 题目原本是 SQL：统计每个用户“第一次登录”的日期，并在 \([2019-06-30] 往前最多 90 天\)的范围内按天计数。
- 用 Java 表达：  
  - 先过滤 `activity=login`，对每个 `userId` 取最小 `loginDate`；  
  - 再筛选 `DATEDIFF(2019-06-30, loginDate) <= 90` 且不为负；  
  - 最后按日期聚合计数并按日期升序输出。

## Java 最佳实现

```java
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class Traffic {
        int userId;
        String activity;
        LocalDate activityDate;

        Traffic(int userId, String activity, LocalDate activityDate) {
            this.userId = userId;
            this.activity = activity;
            this.activityDate = activityDate;
        }
    }

    static class DayCount {
        LocalDate loginDate;
        int userCount;

        DayCount(LocalDate loginDate, int userCount) {
            this.loginDate = loginDate;
            this.userCount = userCount;
        }
    }

    public List<DayCount> newUsersDailyCount(List<Traffic> traffic) {
        LocalDate today = LocalDate.of(2019, 6, 30);

        Map<Integer, LocalDate> firstLogin = new HashMap<>();
        for (Traffic t : traffic) {
            if (!"login".equals(t.activity)) continue;
            LocalDate prev = firstLogin.get(t.userId);
            if (prev == null || t.activityDate.isBefore(prev)) {
                firstLogin.put(t.userId, t.activityDate);
            }
        }

        Map<LocalDate, Integer> cnt = new HashMap<>();
        for (LocalDate d : firstLogin.values()) {
            long diff = ChronoUnit.DAYS.between(d, today);
            if (diff < 0 || diff > 90) continue;
            cnt.put(d, cnt.getOrDefault(d, 0) + 1);
        }

        List<DayCount> res = new ArrayList<>();
        cnt.entrySet().stream()
                .sorted(Map.Entry.comparingByKey())
                .forEach(e -> res.add(new DayCount(e.getKey(), e.getValue())));
        return res;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(n)\)
