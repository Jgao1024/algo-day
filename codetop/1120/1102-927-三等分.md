## 最佳解法思路
- 统计数组中 `1` 的个数为 `ones`：  
  - `ones == 0`：三个部分都表示 0，直接返回任意合法切分（如 `[0, n-1]`）。  
  - `ones % 3 != 0`：无法三等分，返回 `[-1,-1]`。  
- 否则每段需要 `k = ones/3` 个 `1`。分别找到三段第一个 `1` 的位置 `i1,i2,i3`。  
- 由于三段二进制值相同，三段从各自第一个 `1` 开始的尾部模式必须完全一致；尾部长度为 `len = n - i3`。  
  - 先检查边界：`i1+len<=i2` 且 `i2+len<=i3`。  
  - 再逐位比较长度 `len` 的三段是否相同。  
- 成功则返回 `i = i1 + len - 1`，`j = i2 + len`。

## Java 最佳实现

```java
class Solution {
    public int[] threeEqualParts(int[] arr) {
        int n = arr.length;
        int ones = 0;
        for (int x : arr) ones += x;
        if (ones == 0) return new int[]{0, n - 1};
        if (ones % 3 != 0) return new int[]{-1, -1};

        int k = ones / 3;
        int i1 = -1, i2 = -1, i3 = -1;
        int cnt = 0;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 1) {
                cnt++;
                if (cnt == 1) i1 = i;
                else if (cnt == k + 1) i2 = i;
                else if (cnt == 2 * k + 1) i3 = i;
            }
        }

        int len = n - i3;
        if (i1 + len > i2 || i2 + len > i3) return new int[]{-1, -1};
        for (int t = 0; t < len; t++) {
            int a = arr[i1 + t];
            if (a != arr[i2 + t] || a != arr[i3 + t]) return new int[]{-1, -1};
        }
        return new int[]{i1 + len - 1, i2 + len};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
