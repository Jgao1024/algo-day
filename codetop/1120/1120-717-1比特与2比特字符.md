## 最佳解法思路
- 从左到右贪心解析：遇到 `0` 走一步（1 比特），遇到 `1` 走两步（2 比特）。
- 只需要解析到最后一个元素前：若最终落在 `n-1`，说明最后一个字符是 1 比特 `0`。

## Java 最佳实现

```java
class Solution {
    public boolean isOneBitCharacter(int[] bits) {
        int i = 0;
        int n = bits.length;
        while (i < n - 1) {
            i += bits[i] == 1 ? 2 : 1;
        }
        return i == n - 1;
    }
}
```

## 复杂度分析

- 空间：\(O(1)\)
