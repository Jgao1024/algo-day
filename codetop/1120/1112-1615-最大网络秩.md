## 最佳解法思路
- 先统计每个城市的度数 `deg[i]`，再用邻接矩阵 `connected[i][j]` 记录是否直接相连。
- 枚举所有 \(i<j\)：网络秩为 `deg[i] + deg[j] - (connected[i][j] ? 1 : 0)`，取最大。

## Java 最佳实现

```java
class Solution {
    public int maximalNetworkRank(int n, int[][] roads) {
        int[] deg = new int[n];
        boolean[][] conn = new boolean[n][n];
        for (int[] e : roads) {
            int a = e[0], b = e[1];
            deg[a]++;
            deg[b]++;
            conn[a][b] = true;
            conn[b][a] = true;
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int cur = deg[i] + deg[j] - (conn[i][j] ? 1 : 0);
                if (cur > ans) ans = cur;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 + m)\)
- 空间：\(O(n^2)\)
