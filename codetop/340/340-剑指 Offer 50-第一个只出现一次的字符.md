## 最佳解法思路
- 思路（推荐）：两次遍历  
第一次统计每个字符出现次数；第二次按原字符串顺序找第一个次数为 1 的字符；找不到返回空格。

## Java 最佳实现

```java
class Solution {
    public char firstUniqChar(String s) {
        int[] cnt = new int[256];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i)]++;
        }
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (cnt[c] == 1) return c;
        }
        return ' ';
    }
}
```

- 空间：\(O(1)\)
