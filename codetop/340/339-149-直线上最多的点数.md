## 最佳解法思路
- 思路（推荐）：枚举起点 + 统计斜率  
对每个点 i，统计它与其它点形成的斜率（用最简分数 dy/dx 表示，避免浮点误差）。  
重复点单独计数 dup。  
本轮答案为 `dup + 1 + maxSlopeCount`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxPoints(int[][] points) {
        int n = points.length;
        if (n <= 2) return n;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            Map<String, Integer> cnt = new HashMap<>();
            int dup = 0;
            int best = 0;
            for (int j = i + 1; j < n; j++) {
                int dx = points[j][0] - points[i][0];
                int dy = points[j][1] - points[i][1];
                if (dx == 0 && dy == 0) {
                    dup++;
                    continue;
                }

                if (dx == 0) {
                    String key = "1/0";
                    int v = cnt.getOrDefault(key, 0) + 1;
                    cnt.put(key, v);
                    best = Math.max(best, v);
                    continue;
                }
                if (dy == 0) {
                    String key = "0/1";
                    int v = cnt.getOrDefault(key, 0) + 1;
                    cnt.put(key, v);
                    best = Math.max(best, v);
                    continue;
                }

                int g = gcd(Math.abs(dx), Math.abs(dy));
                dx /= g;
                dy /= g;
                if (dx < 0) {
                    dx = -dx;
                    dy = -dy;
                }
                String key = dy + "/" + dx;
                int v = cnt.getOrDefault(key, 0) + 1;
                cnt.put(key, v);
                best = Math.max(best, v);
            }
            ans = Math.max(ans, dup + 1 + best);
        }
        return ans;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
}
```
