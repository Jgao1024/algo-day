## 最佳解法思路
- 思路（推荐）：回溯 + 去重  
把字符数组排序；用 `used[]` 标记是否已选。  
同一层遇到相同字符时：如果前一个相同字符没被用过，则跳过（避免重复排列）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public String[] permutation(String s) {
        char[] cs = s.toCharArray();
        Arrays.sort(cs);
        boolean[] used = new boolean[cs.length];
        List<String> ans = new ArrayList<>();
        dfs(cs, used, new StringBuilder(), ans);
        return ans.toArray(new String[0]);
    }

    private void dfs(char[] cs, boolean[] used, StringBuilder path, List<String> ans) {
        if (path.length() == cs.length) {
            ans.add(path.toString());
            return;
        }
        for (int i = 0; i < cs.length; i++) {
            if (used[i]) continue;
            if (i > 0 && cs[i] == cs[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            path.append(cs[i]);
            dfs(cs, used, path, ans);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot n!)\)（生成所有排列）
- 空间：\(O(n)\)（递归栈与路径，忽略输出）
