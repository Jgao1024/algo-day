## 最佳解法思路
- 思路（推荐）：按右端点排序的贪心  
将区间按 end 升序排序。  
第一支箭射在最小 end；遍历后续区间，若 start > 当前箭位置，则需要新箭并更新箭位置为该区间 end。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> {
            if (a[1] == b[1]) return Integer.compare(a[0], b[0]);
            return Integer.compare(a[1], b[1]);
        });

        int ans = 1;
        long pos = points[0][1];
        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > pos) {
                ans++;
                pos = points[i][1];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（排序栈空间不计）

- 区间贪心：按右端点排，能复用就复用，不能复用就开新箭。
