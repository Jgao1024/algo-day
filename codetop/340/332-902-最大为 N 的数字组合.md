## 最佳解法思路
- 思路（推荐）：按位数计数 + 同位数逐位枚举  
设 digits 长度为 m，N 的位数为 k。  
1) 先统计位数 < k 的所有数量：\(\sum_{len=1}^{k-1} m^{len}\)  
2) 再统计位数 = k：从高位到低位遍历，当前位置 cur：  
  - 统计 digits 中比 cur 小的个数 smaller，贡献 `smaller * m^(remain)`  
  - 若 cur 不在 digits 中，直接结束  
  - 若所有位都能匹配，最后再 +1（N 本身也可组成）

## Java 最佳实现

```java
class Solution {
    public int atMostNGivenDigitSet(String[] digits, int n) {
        char[] cs = String.valueOf(n).toCharArray();
        int k = cs.length;
        int m = digits.length;

        int ans = 0;
        for (int len = 1; len < k; len++) {
            ans += pow(m, len);
        }

        for (int i = 0; i < k; i++) {
            char cur = cs[i];
            int smaller = 0;
            boolean equal = false;
            for (String d : digits) {
                char dc = d.charAt(0);
                if (dc < cur) smaller++;
                else if (dc == cur) equal = true;
            }
            ans += smaller * pow(m, k - i - 1);
            if (!equal) return ans;
        }
        return ans + 1;
    }

    private int pow(int a, int b) {
        int r = 1;
        for (int i = 0; i < b; i++) r *= a;
        return r;
    }
}
```

## 复杂度分析
- 时间：\(O(k \cdot m)\)
- 空间：\(O(1)\)

- 先算短位数总量，再按位“数小于当前位的分支”，遇到不能匹配就停。
