## 最佳解法思路
- 思路（推荐）：一次遍历统计上升/下降长度  
维护 up、down：  
  - nums[i] > nums[i-1]：up++，down 置 0（若之前在下降则重置）  
  - nums[i] < nums[i-1]：down++（只有 up>0 时才可能形成山脉）  
  - 相等：up=down=0  
当 up>0 且 down>0 时，当前山脉长度为 up+down+1。

## Java 最佳实现

```java
class Solution {
    public int longestMountain(int[] arr) {
        int up = 0, down = 0;
        int ans = 0;
        for (int i = 1; i < arr.length; i++) {
            if ((down > 0 && arr[i] > arr[i - 1]) || arr[i] == arr[i - 1]) {
                up = 0;
                down = 0;
            }
            if (arr[i] > arr[i - 1]) up++;
            else if (arr[i] < arr[i - 1]) down++;
            if (up > 0 && down > 0) ans = Math.max(ans, up + down + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
