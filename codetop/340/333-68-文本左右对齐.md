## 最佳解法思路
- 思路（推荐）：贪心逐行拼装  
每行尽量多放单词；确定 [l..r] 后：
  - 若是最后一行或只有一个单词：左对齐，单词间一个空格，末尾补空格  
  - 否则：把总空格数均分到间隙，前面的间隙多一个

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> fullJustify(String[] words, int maxWidth) {
        List<String> ans = new ArrayList<>();
        int n = words.length;
        int i = 0;
        while (i < n) {
            int l = i;
            int len = 0;
            while (i < n) {
                int next = len + words[i].length() + (i == l ? 0 : 1);
                if (next > maxWidth) break;
                len = next;
                i++;
            }
            int r = i - 1;
            boolean lastLine = (i == n);
            ans.add(build(words, l, r, maxWidth, lastLine));
        }
        return ans;
    }

    private String build(String[] words, int l, int r, int maxWidth, boolean lastLine) {
        int wordLen = 0;
        for (int i = l; i <= r; i++) wordLen += words[i].length();
        int gaps = r - l;
        StringBuilder sb = new StringBuilder();

        if (gaps == 0 || lastLine) {
            for (int i = l; i <= r; i++) {
                if (i > l) sb.append(' ');
                sb.append(words[i]);
            }
            while (sb.length() < maxWidth) sb.append(' ');
            return sb.toString();
        }

        int spaces = maxWidth - wordLen;
        int base = spaces / gaps;
        int extra = spaces % gaps;
        for (int i = l; i <= r; i++) {
            sb.append(words[i]);
            if (i == r) break;
            int cnt = base + (i - l < extra ? 1 : 0);
            for (int t = 0; t < cnt; t++) sb.append(' ');
        }
        return sb.toString();
    }
}
```
