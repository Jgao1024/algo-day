## 最佳解法思路
- 思路（推荐）：一次扫描找左右边界  
从左到右维护当前最大值 max，若 nums[i] < max，则右边界 r=i。  
从右到左维护当前最小值 min，若 nums[i] > min，则左边界 l=i。  
答案为 `r-l+1`，若数组本身有序则返回 0。

## Java 最佳实现

```java
class Solution {
    public int findUnsortedSubarray(int[] nums) {
        int n = nums.length;
        int max = Integer.MIN_VALUE;
        int min = Integer.MAX_VALUE;
        int l = -1, r = -1;

        for (int i = 0; i < n; i++) {
            max = Math.max(max, nums[i]);
            if (nums[i] < max) r = i;
        }
        for (int i = n - 1; i >= 0; i--) {
            min = Math.min(min, nums[i]);
            if (nums[i] > min) l = i;
        }

        if (r == -1) return 0;
        return r - l + 1;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
