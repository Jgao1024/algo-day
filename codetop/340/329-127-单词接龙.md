## 最佳解法思路
- 思路（推荐）：BFS 最短路径  
把 wordList 放入 HashSet。  
从 beginWord 开始 BFS，每次枚举当前位置每一位改成 'a'..'z' 的所有邻居，若在集合中就入队，并从集合删除避免重复。  
第一次到达 endWord 的层数就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int ladderLength(String beginWord, String endWord, java.util.List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) return 0;
        dict.remove(beginWord);

        Deque<String> q = new ArrayDeque<>();
        q.addLast(beginWord);
        int step = 1;

        while (!q.isEmpty()) {
            int size = q.size();
            for (int t = 0; t < size; t++) {
                String cur = q.removeFirst();
                if (cur.equals(endWord)) return step;
                char[] cs = cur.toCharArray();
                for (int i = 0; i < cs.length; i++) {
                    char old = cs[i];
                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == old) continue;
                        cs[i] = c;
                        String next = new String(cs);
                        if (dict.contains(next)) {
                            dict.remove(next);
                            q.addLast(next);
                        }
                    }
                    cs[i] = old;
                }
            }
            step++;
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：约 \(O(N \cdot L \cdot 26)\)（N 为词表大小，L 为单词长度）
- 空间：\(O(N)\)
