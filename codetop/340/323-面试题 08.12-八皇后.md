## 最佳解法思路
- 思路（推荐）：回溯 + 三个集合剪枝  
逐行放皇后：每行只能放一个。  
用三个布尔数组记录是否被占用：  
  - 列 col[c]  
  - 主对角线 diag1[r-c+n-1]  
  - 副对角线 diag2[r+c]  
能放则继续下一行，放满 n 行收集棋盘。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> ans = new ArrayList<>();
        boolean[] col = new boolean[n];
        boolean[] diag1 = new boolean[2 * n - 1];
        boolean[] diag2 = new boolean[2 * n - 1];
        int[] pos = new int[n]; // pos[r] = c
        dfs(0, n, col, diag1, diag2, pos, ans);
        return ans;
    }

    private void dfs(int r, int n, boolean[] col, boolean[] diag1, boolean[] diag2, int[] pos, List<List<String>> ans) {
        if (r == n) {
            ans.add(build(n, pos));
            return;
        }
        for (int c = 0; c < n; c++) {
            int d1 = r - c + n - 1;
            int d2 = r + c;
            if (col[c] || diag1[d1] || diag2[d2]) continue;
            col[c] = diag1[d1] = diag2[d2] = true;
            pos[r] = c;
            dfs(r + 1, n, col, diag1, diag2, pos, ans);
            col[c] = diag1[d1] = diag2[d2] = false;
        }
    }

    private List<String> build(int n, int[] pos) {
        List<String> board = new ArrayList<>();
        for (int r = 0; r < n; r++) {
            char[] row = new char[n];
            for (int i = 0; i < n; i++) row[i] = '.';
            row[pos[r]] = 'Q';
            board.add(new String(row));
        }
        return board;
    }
}
```

## 复杂度分析
- 时间：回溯搜索（约 \(O(n!)\) 级别）
- 空间：\(O(n)\)（递归栈与标记数组，忽略输出）
