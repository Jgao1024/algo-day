## 最佳解法思路
- 思路（推荐）：26 进制转换（A=1..Z=26）  
从左到右累加：`ans = ans * 26 + (c - 'A' + 1)`。

## Java 最佳实现

```java
class Solution {
    public int titleToNumber(String columnTitle) {
        int ans = 0;
        for (int i = 0; i < columnTitle.length(); i++) {
            char c = columnTitle.charAt(i);
            ans = ans * 26 + (c - 'A' + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 把 A..Z 当 1..26 的“无 0 进制”，直接累加即可。
