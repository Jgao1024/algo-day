## 最佳解法思路
- 思路（推荐）：单调栈算贡献  
对每个元素 arr[i]，统计它作为“子数组最小值”能覆盖的子数组个数：  
  - left：向左延伸到上一个严格更小元素为止的距离  
  - right：向右延伸到下一个小于等于元素为止的距离  
贡献为 `arr[i] * left * right`，对 \(10^9+7\) 取模。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int sumSubarrayMins(int[] arr) {
        int n = arr.length;
        int mod = 1_000_000_007;
        int[] left = new int[n];
        int[] right = new int[n];

        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) stack.pop();
            int prev = stack.isEmpty() ? -1 : stack.peek();
            left[i] = i - prev;
            stack.push(i);
        }

        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) stack.pop();
            int next = stack.isEmpty() ? n : stack.peek();
            right[i] = next - i;
            stack.push(i);
        }

        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans = (ans + (long) arr[i] * left[i] * right[i]) % mod;
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 贡献法：每个点当最小值，乘上“往左/往右可扩的数量”，一边严格一边非严格处理重复。
