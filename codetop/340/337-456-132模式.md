## 最佳解法思路
- 思路（推荐）：从右往左 + 单调栈  
目标找 i<j<k 且 nums[i] < nums[k] < nums[j]。  
从右往左维护一个递减栈（候选 nums[j]），并用变量 third 记录当前可用的 nums[k] 最大值。  
遍历到 nums[i] 时，如果 nums[i] < third，则存在 132。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean find132pattern(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int third = Integer.MIN_VALUE;
        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] < third) return true;
            while (!stack.isEmpty() && nums[i] > stack.peek()) {
                third = stack.pop();
            }
            stack.push(nums[i]);
        }
        return false;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 从右往左：栈存“3”，third 存“2”；遇到比 third 小的就是“1”。
