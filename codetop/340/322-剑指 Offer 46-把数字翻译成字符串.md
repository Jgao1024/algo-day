## 最佳解法思路
- 思路（推荐）：DP（类似解码方式）  
把数字转成字符串 s。  
`dp[i]` 表示前 i 个字符的翻译数：  
  - 单独翻译 s[i-1]：`dp[i] += dp[i-1]`  
  - 若两位数在 [10,25]：`dp[i] += dp[i-2]`  
滚动变量即可。

## Java 最佳实现

```java
class Solution {
    public int translateNum(int num) {
        String s = String.valueOf(num);
        int n = s.length();
        int a = 1; // dp[i-2]
        int b = 1; // dp[i-1]
        for (int i = 2; i <= n; i++) {
            int two = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
            int c = b;
            if (two >= 10 && two <= 25) c += a;
            a = b;
            b = c;
        }
        return b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
