## 最佳解法思路
- 思路（推荐）：三组标记（行/列/九宫格）  
遍历每个格子，遇到数字 d：检查对应行、列、宫是否已出现过，若出现则非法；否则标记为已出现。

## Java 最佳实现

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        boolean[][] row = new boolean[9][9];
        boolean[][] col = new boolean[9][9];
        boolean[][] box = new boolean[9][9];

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char c = board[i][j];
                if (c == '.') continue;
                int d = c - '1';
                int b = (i / 3) * 3 + (j / 3);
                if (row[i][d] || col[j][d] || box[b][d]) return false;
                row[i][d] = col[j][d] = box[b][d] = true;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（固定 9x9）
- 空间：\(O(1)\)
