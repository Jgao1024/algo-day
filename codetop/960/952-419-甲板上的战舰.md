## 最佳解法思路
- 只统计“战舰的起点格子”：
  - 某个格子是 `X`
  - 且它的上方不是 `X`、左方不是 `X`
  - 满足则说明这里是一艘新战舰的左上端（起点），计数 +1

## Java 最佳实现

```java
class Solution {
    public int countBattleships(char[][] board) {
        int m = board.length, n = board[0].length;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] != 'X') continue;
                if (i > 0 && board[i - 1][j] == 'X') continue;
                if (j > 0 && board[i][j - 1] == 'X') continue;
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)
