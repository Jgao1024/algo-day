## 最佳解法思路
- 贪心：
  - 先把数组升序排序，尽量把负数翻成正数（每翻一次 `k--`）
  - 若 `k` 还剩且为奇数，则把绝对值最小的数再翻一次

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        Arrays.sort(nums);
        for (int i = 0; i < nums.length && k > 0 && nums[i] < 0; i++) {
            nums[i] = -nums[i];
            k--;
        }
        int sum = 0;
        int minAbs = Integer.MAX_VALUE;
        for (int x : nums) {
            sum += x;
            minAbs = Math.min(minAbs, Math.abs(x));
        }
        if ((k & 1) == 1) sum -= 2 * minAbs;
        return sum;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不算排序）
