## 最佳解法思路
- 一个数恰好有 4 个因数，只可能是：
  - \(p^3\)（p 为质数）：因数为 \(1,p,p^2,p^3\)
  - \(p \times q\)（p、q 为不同质数）：因数为 \(1,p,q,pq\)
- 对每个 `num`：
  - 找到最小因子 `i`
  - 设 `j = num / i`
    - 若 `j % i == 0` 且 `j / i == i`：是 \(i^3\)
    - 否则若 `i` 和 `j` 都是质数：是 \(i*j\)
  - 其它情况不是四因数

## Java 最佳实现

```java
class Solution {
    public int sumFourDivisors(int[] nums) {
        int ans = 0;
        for (int x : nums) {
            ans += sumIfFour(x);
        }
        return ans;
    }

    private int sumIfFour(int n) {
        int i = 2;
        while (i * (long) i <= n && n % i != 0) i++;
        if (i * (long) i > n) return 0; // prime
        int j = n / i;
        if (i == j) return 0; // square (3 divisors)

        // p^3
        if (j % i == 0 && j / i == i) {
            if (!isPrime(i)) return 0;
            long p = i;
            long sum = 1 + p + p * p + p * p * p;
            return (int) sum;
        }

        // p*q
        if (isPrime(i) && isPrime(j)) {
            return 1 + i + j + n;
        }
        return 0;
    }

    private boolean isPrime(int x) {
        if (x < 2) return false;
        if (x % 2 == 0) return x == 2;
        for (int i = 3; i * (long) i <= x; i += 2) {
            if (x % i == 0) return false;
        }
        return true;
    }
}
```
