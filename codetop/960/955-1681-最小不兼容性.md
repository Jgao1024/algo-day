## 最佳解法思路
- 状态压缩 DP：
  - 把数组分成 `k` 组，每组大小 `m = n/k`，同组内不能有重复数字，代价为 `max-min`
  - 预处理所有大小为 `m` 的子集 `sub`：
    - 若子集内有重复则无效
    - 否则 `cost[sub] = max - min`
  - `dp[mask]` 表示已选元素集合为 `mask` 时的最小代价
    - 枚举 `mask` 的一个有效子集 `sub`，转移 `dp[mask] = min(dp[mask ^ sub] + cost[sub])`
  - 若无法构成则返回 -1

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minimumIncompatibility(int[] nums, int k) {
        int n = nums.length;
        int m = n / k;
        Arrays.sort(nums);

        int[] freq = new int[n + 1];
        for (int x : nums) {
            if (++freq[x] > k) return -1;
        }

        int full = (1 << n) - 1;
        int[] cost = new int[1 << n];
        Arrays.fill(cost, -1);

        for (int mask = 0; mask <= full; mask++) {
            if (Integer.bitCount(mask) != m) continue;
            int min = Integer.MAX_VALUE;
            int max = Integer.MIN_VALUE;
            boolean ok = true;
            int last = Integer.MIN_VALUE;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0) continue;
                int v = nums[i];
                if (v == last) { // 同组重复（nums 已排序）
                    ok = false;
                    break;
                }
                last = v;
                min = Math.min(min, v);
                max = Math.max(max, v);
            }
            if (ok) cost[mask] = max - min;
        }

        int INF = 1_000_000_000;
        int[] dp = new int[1 << n];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int mask = 1; mask <= full; mask++) {
            if (Integer.bitCount(mask) % m != 0) continue;
            int first = Integer.numberOfTrailingZeros(mask);
            int anchor = 1 << first;

            for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
                if ((sub & anchor) == 0) continue;
                if (cost[sub] < 0) continue;
                dp[mask] = Math.min(dp[mask], dp[mask ^ sub] + cost[sub]);
            }
        }

        return dp[full] >= INF ? -1 : dp[full];
    }
}
```

## 复杂度分析
- 时间：\(O(3^n)\) 量级（n<=16 可过）
- 空间：\(O(2^n)\)
