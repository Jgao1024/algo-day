## 最佳解法思路
- 递归解析字符串（带全局指针）：
  - 先读整数（可能为负）作为当前节点
  - 若接下来是 `(`，解析左子树并吃掉对应 `)`
  - 若再次遇到 `(`，解析右子树并吃掉对应 `)`

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int idx = 0;

    public TreeNode str2tree(String s) {
        if (s == null || s.isEmpty()) return null;
        idx = 0;
        return parse(s);
    }

    private TreeNode parse(String s) {
        int sign = 1;
        if (s.charAt(idx) == '-') {
            sign = -1;
            idx++;
        }
        int num = 0;
        while (idx < s.length() && Character.isDigit(s.charAt(idx))) {
            num = num * 10 + (s.charAt(idx) - '0');
            idx++;
        }
        TreeNode root = new TreeNode(sign * num);

        if (idx < s.length() && s.charAt(idx) == '(') {
            idx++; // (
            root.left = parse(s);
            idx++; // )
        }
        if (idx < s.length() && s.charAt(idx) == '(') {
            idx++; // (
            root.right = parse(s);
            idx++; // )
        }
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（递归栈）
