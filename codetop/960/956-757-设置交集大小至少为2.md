## 最佳解法思路
- 贪心：
  - 按区间右端点 `end` 升序排序；若 end 相同，按 start 降序（更“紧”的先处理）
  - 维护已选择集合中最大的两个点 `a < b`
  - 对当前区间 `[l,r]`：
    - 若 `b < l`：一个都不在区间内，必须选 `r-1, r`
    - 否则若 `a < l`：只有 `b` 在区间内，再选一个 `r`
    - 否则：已经有两个点在区间内，无需操作

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int intersectionSizeTwo(int[][] intervals) {
        Arrays.sort(intervals, (x, y) -> {
            if (x[1] != y[1]) return x[1] - y[1];
            return y[0] - x[0];
        });

        int ans = 0;
        int a = -1, b = -1; // a < b，当前已选的两个最大点
        for (int[] it : intervals) {
            int l = it[0], r = it[1];
            if (b < l) {
                a = r - 1;
                b = r;
                ans += 2;
            } else if (a < l) {
                a = b;
                b = r;
                ans += 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不算排序）
