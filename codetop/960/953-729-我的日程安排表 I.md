## 最佳解法思路
- 用 `TreeMap` 按 start 存区间：
  - 新区间 `[start,end)` 只需要与相邻的前一个和后一个区间检查是否重叠
    - `prev`：`prevEnd > start` 则冲突
    - `next`：`nextStart < end` 则冲突

## Java 最佳实现

```java
import java.util.TreeMap;

class MyCalendar {
    private final TreeMap<Integer, Integer> map = new TreeMap<>();

    public MyCalendar() {
    }

    public boolean book(int start, int end) {
        Integer prev = map.floorKey(start);
        if (prev != null && map.get(prev) > start) return false;
        Integer next = map.ceilingKey(start);
        if (next != null && next < end) return false;
        map.put(start, end);
        return true;
    }
}
```

## 复杂度分析
- 时间：每次 \(O(\log n)\)
- 空间：\(O(n)\)
