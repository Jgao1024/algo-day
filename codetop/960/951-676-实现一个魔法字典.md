## 最佳解法思路
- 按长度分桶：
  - 只需要和相同长度的单词比较
  - `search` 时遍历同长度桶里的每个词，统计不同字符个数是否恰好为 1

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class MagicDictionary {
    private final Map<Integer, List<String>> map = new HashMap<>();

    public MagicDictionary() {
    }

    public void buildDict(String[] dictionary) {
        for (String w : dictionary) {
            map.computeIfAbsent(w.length(), k -> new ArrayList<>()).add(w);
        }
    }

    public boolean search(String searchWord) {
        List<String> list = map.get(searchWord.length());
        if (list == null) return false;
        for (String w : list) {
            if (diffOne(w, searchWord)) return true;
        }
        return false;
    }

    private boolean diffOne(String a, String b) {
        int diff = 0;
        for (int i = 0; i < a.length(); i++) {
            if (a.charAt(i) != b.charAt(i)) {
                diff++;
                if (diff > 1) return false;
            }
        }
        return diff == 1;
    }
}
```

## 复杂度分析
- 时间：`build` 与单词总长度相关；`search` 最坏 \(O(M\cdot L)\)（同长度桶大小为 M）
- 空间：\(O(\sum |word|)\)
