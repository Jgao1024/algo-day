## 最佳解法思路
- 贪心/DP：
  - 扫描字符串，维护已出现的 `1` 的数量 `ones`
  - `flip` 表示把前缀变成单调递增所需的最少翻转次数
    - 遇到 `1`：`ones++`
    - 遇到 `0`：要么把这个 `0` 翻成 `1`（`flip+1`），要么把之前所有 `1` 翻成 `0`（`ones`）
      - `flip = min(flip + 1, ones)`

## Java 最佳实现

```java
class Solution {
    public int minFlipsMonoIncr(String s) {
        int ones = 0;
        int flip = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '1') {
                ones++;
            } else {
                flip = Math.min(flip + 1, ones);
            }
        }
        return flip;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
