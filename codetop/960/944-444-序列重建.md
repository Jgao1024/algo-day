## 最佳解法思路
- 拓扑排序 + 唯一性判断：
  - 根据 `seqs` 建图并统计入度
  - 每次队列里若可选节点数 != 1，则无法唯一重建
  - 拓扑弹出顺序必须与 `org` 完全一致，且最终处理节点数等于 `org.length`

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Queue;
import java.util.Set;

class Solution {
    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {
        int n = org.length;
        int[] pos = new int[n + 1];
        for (int i = 0; i < n; i++) pos[org[i]] = i;

        List<Set<Integer>> g = new ArrayList<>(n + 1);
        for (int i = 0; i <= n; i++) g.add(new HashSet<>());
        int[] indeg = new int[n + 1];
        boolean[] seen = new boolean[n + 1];

        int seenCnt = 0;
        for (List<Integer> seq : seqs) {
            for (int x : seq) {
                if (x < 1 || x > n) return false;
                if (!seen[x]) {
                    seen[x] = true;
                    seenCnt++;
                }
            }
            for (int i = 1; i < seq.size(); i++) {
                int a = seq.get(i - 1), b = seq.get(i);
                if (g.get(a).add(b)) indeg[b]++;
            }
        }
        if (seenCnt != n) return false;

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            if (indeg[i] == 0) q.offer(i);
        }

        int idx = 0;
        while (!q.isEmpty()) {
            if (q.size() != 1) return false;
            int cur = q.poll();
            if (org[idx++] != cur) return false;
            for (int nxt : g.get(cur)) {
                if (--indeg[nxt] == 0) q.offer(nxt);
            }
        }
        return idx == n;
    }
}
```

- 时间：\(O(V+E)\)
- 空间：\(O(V+E)\)
