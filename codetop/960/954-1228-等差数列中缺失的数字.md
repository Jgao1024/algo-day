## 最佳解法思路
- 等差数列长度为 `n+1`，已给长度 `n`，公差应为：
  - `d = (arr[n-1] - arr[0]) / n`
  - 从左到右找第一个不满足 `arr[i] = arr[0] + i*d` 的位置，缺失值就是该期望值

## Java 最佳实现

```java
class Solution {
    public int missingNumber(int[] arr) {
        int n = arr.length;
        int d = (arr[n - 1] - arr[0]) / n;
        for (int i = 0; i < n; i++) {
            int expect = arr[0] + i * d;
            if (arr[i] != expect) return expect;
        }
        return arr[n - 1] + d;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
