## 最佳解法思路
- 原地编码下一状态：
  - 用低位保存当前状态（0/1），用第 2 位保存下一状态
  - 先遍历计算每格活邻居数，根据规则把下一状态写到第 2 位
  - 再遍历右移 1 位得到新棋盘

## Java 最佳实现

```java
class Solution {
    private static final int[] DX = {1, 1, 1, 0, 0, -1, -1, -1};
    private static final int[] DY = {1, 0, -1, 1, -1, 1, 0, -1};

    public void gameOfLife(int[][] board) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int live = 0;
                for (int k = 0; k < 8; k++) {
                    int x = i + DX[k], y = j + DY[k];
                    if (x < 0 || x >= m || y < 0 || y >= n) continue;
                    live += (board[x][y] & 1);
                }
                int cur = board[i][j] & 1;
                int next = 0;
                if (cur == 1) {
                    if (live == 2 || live == 3) next = 1;
                } else {
                    if (live == 3) next = 1;
                }
                board[i][j] |= (next << 1);
            }
        }
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                board[i][j] >>= 1;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)
