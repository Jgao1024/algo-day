## 最佳解法思路
- DP：`dp[j]` 表示处理到当前硬币时，正面朝上恰好为 `j` 的概率
  - 初始化 `dp[0] = 1`
  - 对每个概率 `p`：
    - 从大到小更新：`dp[j] = dp[j] * (1-p) + dp[j-1] * p`

## Java 最佳实现

```java
class Solution {
    public double probabilityOfHeads(double[] prob, int target) {
        double[] dp = new double[target + 1];
        dp[0] = 1.0;
        for (double p : prob) {
            for (int j = target; j >= 0; j--) {
                double stay = dp[j] * (1.0 - p);
                double take = (j > 0) ? dp[j - 1] * p : 0.0;
                dp[j] = stay + take;
            }
        }
        return dp[target];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot target)\)
- 空间：\(O(target)\)
