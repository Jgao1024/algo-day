## 最佳解法思路
- 后序 DFS 返回（深度，LCA）：
  - 递归得到左子树最深深度 `dl` 与候选 `nl`，右子树 `dr` 与 `nr`
  - 若 `dl == dr`，说明最深叶在两边都有，当前节点就是 LCA
  - 若不等，返回更深的一侧的结果，深度 +1

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    static class Info {
        int depth;
        TreeNode node;

        Info(int depth, TreeNode node) {
            this.depth = depth;
            this.node = node;
        }
    }

    public TreeNode lcaDeepestLeaves(TreeNode root) {
        return dfs(root).node;
    }

    private Info dfs(TreeNode node) {
        if (node == null) return new Info(0, null);
        Info L = dfs(node.left);
        Info R = dfs(node.right);
        if (L.depth == R.depth) return new Info(L.depth + 1, node);
        if (L.depth > R.depth) return new Info(L.depth + 1, L.node);
        return new Info(R.depth + 1, R.node);
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(h)\)
