## 最佳解法思路
- 并查集：
  - 遍历每条边 `(u,v)`，若 `u` 和 `v` 已在同一集合，说明这条边会成环，即为冗余边
  - 否则合并两点

## Java 最佳实现

```java
class Solution {
    static class UF {
        int[] p;
        int[] r;

        UF(int n) {
            p = new int[n + 1];
            r = new int[n + 1];
            for (int i = 1; i <= n; i++) p[i] = i;
        }

        int find(int x) {
            if (p[x] != x) p[x] = find(p[x]);
            return p[x];
        }

        boolean union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return false;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else {
                p[pb] = pa;
                r[pa]++;
            }
            return true;
        }
    }

    public int[] findRedundantConnection(int[][] edges) {
        int n = edges.length;
        UF uf = new UF(n);
        for (int[] e : edges) {
            if (!uf.union(e[0], e[1])) return e;
        }
        return new int[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n \alpha(n))\)
- 空间：\(O(n)\)
