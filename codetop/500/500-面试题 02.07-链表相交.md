## 最佳解法思路
- 双指针走同路程（推荐）  
两指针 `a`、`b` 分别从两链表头出发，走到尾后切换到另一条链表头。  
它们最终会在相交点相遇；若不相交，会同时走到 `null`。

## Java 最佳实现

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode a = headA;
        ListNode b = headB;
        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **让两指针都走 \(m+n\) 路程，必然在交点（或 null）对齐**。
