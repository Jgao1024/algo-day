## 最佳解法思路
- 公式生成（推荐）  
第 \(i\) 个格雷码：`i ^ (i >> 1)`，从 `i=0` 到 `2^n-1` 依次生成即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> grayCode(int n) {
        int m = 1 << n;
        List<Integer> ans = new ArrayList<>(m);
        for (int i = 0; i < m; i++) {
            ans.add(i ^ (i >> 1));
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(2^n)\)
- 空间：\(O(2^n)\)（结果）
