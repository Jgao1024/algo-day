## 最佳解法思路
- DP（推荐）  
`dp[i][c]` 表示刷到第 `i` 个房子且颜色为 `c` 的最小花费。  
转移：`dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2])`，其余同理。用 3 个变量滚动即可。

## Java 最佳实现

```java
class Solution {
    public int minCost(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;
        int a = costs[0][0];
        int b = costs[0][1];
        int c = costs[0][2];
        for (int i = 1; i < costs.length; i++) {
            int na = costs[i][0] + Math.min(b, c);
            int nb = costs[i][1] + Math.min(a, c);
            int nc = costs[i][2] + Math.min(a, b);
            a = na;
            b = nb;
            c = nc;
        }
        return Math.min(a, Math.min(b, c));
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **当前颜色不能和上一个相同：每次加上“上一步另外两色的最小值”**。
