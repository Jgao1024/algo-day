## 最佳解法思路
- DP（推荐）  
设 `dp[i][j]` 表示 `s[0..i)` 与 `p[0..j)` 是否匹配。  
- 若 `p[j-1] != '*'`：`dp[i][j] = dp[i-1][j-1] && match(s[i-1], p[j-1])`  
- 若 `p[j-1] == '*'`：  
  - `*` 表示 0 次：`dp[i][j] |= dp[i][j-2]`  
  - `*` 表示 1+ 次：若 `match(s[i-1], p[j-2])`，则 `dp[i][j] |= dp[i-1][j]`

## Java 最佳实现

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length();
        int n = p.length();

        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;
        for (int j = 2; j <= n; j++) {
            if (p.charAt(j - 1) == '*') dp[0][j] = dp[0][j - 2];
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char pj = p.charAt(j - 1);
                if (pj != '*') {
                    dp[i][j] = dp[i - 1][j - 1] && match(s.charAt(i - 1), pj);
                } else {
                    dp[i][j] = dp[i][j - 2];
                    char prev = p.charAt(j - 2);
                    if (match(s.charAt(i - 1), prev)) {
                        dp[i][j] |= dp[i - 1][j];
                    }
                }
            }
        }
        return dp[m][n];
    }

    private boolean match(char sc, char pc) {
        return pc == '.' || sc == pc;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
