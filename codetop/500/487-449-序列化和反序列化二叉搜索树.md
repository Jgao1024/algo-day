## 最佳解法思路
- BST 用前序 + 上下界还原（推荐）  
序列化：前序遍历输出节点值（不需要空节点）。  
反序列化：按前序数组，从左到右用 `min/max` 约束构建：当前值不在区间就返回空；否则创建节点并递归构建左右子树。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Codec {
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        pre(root, sb);
        if (sb.length() > 0) sb.setLength(sb.length() - 1);
        return sb.toString();
    }

    private void pre(TreeNode node, StringBuilder sb) {
        if (node == null) return;
        sb.append(node.val).append(',');
        pre(node.left, sb);
        pre(node.right, sb);
    }

    public TreeNode deserialize(String data) {
        if (data == null || data.length() == 0) return null;
        String[] arr = data.split(",");
        List<Integer> nums = new ArrayList<>(arr.length);
        for (String s : arr) nums.add(Integer.parseInt(s));
        int[] idx = new int[1];
        return build(nums, idx, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode build(List<Integer> nums, int[] idx, int low, int high) {
        if (idx[0] >= nums.size()) return null;
        int v = nums.get(idx[0]);
        if (v < low || v > high) return null;

        idx[0]++;
        TreeNode node = new TreeNode(v);
        node.left = build(nums, idx, low, v);
        node.right = build(nums, idx, v, high);
        return node;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（前序数组 + 递归栈）
