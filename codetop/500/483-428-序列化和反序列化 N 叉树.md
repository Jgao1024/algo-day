## 最佳解法思路
- 前序 + 子节点数量（推荐）  
序列化时对每个节点写入两部分：`val` 和 `children.size()`，然后依次递归写每个孩子。  
反序列化按相同顺序读取：先读 `val`、再读 `cnt`，递归构建 `cnt` 个孩子。

## Java 最佳实现

```java
import java.util.ArrayList;

class Codec {
    public String serialize(Node root) {
        if (root == null) return "#";
        StringBuilder sb = new StringBuilder();
        ser(root, sb);
        return sb.toString();
    }

    private void ser(Node node, StringBuilder sb) {
        sb.append(node.val).append(',').append(node.children.size()).append(',');
        for (Node child : node.children) {
            ser(child, sb);
        }
    }

    public Node deserialize(String data) {
        if (data == null || data.length() == 0 || "#".equals(data)) return null;
        String[] arr = data.split(",");
        int[] idx = new int[1];
        return de(arr, idx);
    }

    private Node de(String[] arr, int[] idx) {
        int val = Integer.parseInt(arr[idx[0]++]);
        int cnt = Integer.parseInt(arr[idx[0]++]);
        Node node = new Node(val, new ArrayList<>());
        for (int i = 0; i < cnt; i++) {
            node.children.add(de(arr, idx));
        }
        return node;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈，最坏 \(O(n)\)）
