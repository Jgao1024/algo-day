## 最佳解法思路
- 反复除 2/3/5（推荐）  
如果 `n<=0` 直接 false；不断把 `n` 除尽 2、3、5，最后看是否变成 1。

## Java 最佳实现

```java
class Solution {
    public boolean isUgly(int n) {
        if (n <= 0) return false;
        n = div(n, 2);
        n = div(n, 3);
        n = div(n, 5);
        return n == 1;
    }

    private int div(int n, int d) {
        while (n % d == 0) n /= d;
        return n;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
