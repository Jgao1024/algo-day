## 最佳解法思路
- DFS（推荐）  
如果 `node.left` 存在且是叶子（左右孩子都为空），把它的值累加；然后递归遍历左右子树。

## Java 最佳实现

```java
class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        return dfs(root);
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int sum = 0;
        if (node.left != null && node.left.left == null && node.left.right == null) {
            sum += node.left.val;
        }
        sum += dfs(node.left);
        sum += dfs(node.right);
        return sum;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）
