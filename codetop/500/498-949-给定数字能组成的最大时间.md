## 最佳解法思路
- 枚举全排列（推荐）  
只有 4 个数字，最多 \(4! = 24\) 种排列，枚举所有排列形成 `HH:MM`，筛选合法时间并取最大。

## Java 最佳实现

```java
class Solution {
    public String largestTimeFromDigits(int[] arr) {
        int best = -1;
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                if (j == i) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == i || k == j) continue;
                    int l = 6 - i - j - k;
                    int h = arr[i] * 10 + arr[j];
                    int m = arr[k] * 10 + arr[l];
                    if (h < 24 && m < 60) {
                        best = Math.max(best, h * 60 + m);
                    }
                }
            }
        }
        if (best < 0) return "";
        int hh = best / 60;
        int mm = best % 60;
        return String.format("%02d:%02d", hh, mm);
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（常数 24 次枚举）
- 空间：\(O(1)\)
