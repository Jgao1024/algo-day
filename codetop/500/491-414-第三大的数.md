## 最佳解法思路
- 一次遍历维护前三大（推荐）  
用 `a>b>c` 表示第一/第二/第三大，遍历时跳过重复值，依次更新。为处理 `Integer.MIN_VALUE`，用 `long` 做哨兵。

## Java 最佳实现

```java
class Solution {
    public int thirdMax(int[] nums) {
        long a = Long.MIN_VALUE;
        long b = Long.MIN_VALUE;
        long c = Long.MIN_VALUE;

        for (int x : nums) {
            if (x == a || x == b || x == c) continue;
            if (x > a) {
                c = b;
                b = a;
                a = x;
            } else if (x > b) {
                c = b;
                b = x;
            } else if (x > c) {
                c = x;
            }
        }
        return c == Long.MIN_VALUE ? (int) a : (int) c;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
