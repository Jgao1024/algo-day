## 最佳解法思路
- 贪心 + 小根堆（推荐）  
按开始时间排序，按天遍历：  
把所有 `start <= day` 的会议的 `end` 放入小根堆；把 `end < day` 的会议弹出；如果堆非空，就参加 `end` 最小的那个并弹出。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int maxEvents(int[][] events) {
        Arrays.sort(events, (a, b) -> a[0] - b[0]);
        PriorityQueue<Integer> pq = new PriorityQueue<>();

        int i = 0;
        int n = events.length;
        int day = 0;
        int ans = 0;

        while (i < n || !pq.isEmpty()) {
            if (pq.isEmpty()) {
                day = Math.max(day, events[i][0]);
            }
            while (i < n && events[i][0] <= day) {
                pq.add(events[i][1]);
                i++;
            }
            while (!pq.isEmpty() && pq.peek() < day) {
                pq.poll();
            }
            if (!pq.isEmpty()) {
                pq.poll();
                ans++;
                day++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
