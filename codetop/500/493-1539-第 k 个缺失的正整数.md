## 最佳解法思路
- 二分：用“缺失个数”定位（推荐）  
在下标 `i` 处，缺失的正整数个数：`missing(i) = arr[i] - (i + 1)`。  
二分找最小 `idx` 使 `missing(idx) >= k`，答案是 `k + idx`。

## Java 最佳实现

```java
class Solution {
    public int findKthPositive(int[] arr, int k) {
        int left = 0;
        int right = arr.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int missing = arr[mid] - (mid + 1);
            if (missing < k) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return k + left;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
