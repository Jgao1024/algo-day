## 最佳解法思路
- 频次取交集（推荐）  
对 26 个小写字母统计频次：  
先用第一组单词的频次初始化 `minCnt`，再对每个单词算 `cnt`，逐位 `minCnt[i] = min(minCnt[i], cnt[i])`。  
最后按 `minCnt` 把字符重复加入答案。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> commonChars(String[] words) {
        int[] minCnt = new int[26];
        for (int i = 0; i < 26; i++) minCnt[i] = Integer.MAX_VALUE;

        for (String w : words) {
            int[] cnt = new int[26];
            for (int i = 0; i < w.length(); i++) {
                cnt[w.charAt(i) - 'a']++;
            }
            for (int i = 0; i < 26; i++) {
                minCnt[i] = Math.min(minCnt[i], cnt[i]);
            }
        }

        List<String> ans = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            for (int k = 0; k < minCnt[i]; k++) {
                ans.add(String.valueOf((char) ('a' + i)));
            }
        }
        return ans;
    }
}
```

- 时间：\(O(\sum |word|)\)
- 空间：\(O(1)\)
