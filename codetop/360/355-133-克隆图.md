# 133. 克隆图

- 题号：133
- 难度：中等
- LeetCode：[克隆图](https://leetcode.cn/problems/clone-graph/)

## 题目描述
给定无向连通图的一个节点 `node`，返回该图的深拷贝。

## 示例
- 示例  
输入：`adjList = [[2,4],[1,3],[2,4],[1,3]]`  
输出：克隆后的图结构等价

## 最佳解法思路
- DFS/BFS + 哈希表映射（推荐）  
用 `map<旧节点, 新节点>` 保存已经克隆过的节点，避免重复创建和死循环。  
遍历邻居时：如果邻居没克隆就递归/入队克隆，然后把克隆后的邻居加入当前新节点的邻居表。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private final Map<Node, Node> map = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (map.containsKey(node)) return map.get(node);

        Node copy = new Node(node.val, new ArrayList<>());
        map.put(node, copy);
        for (Node nei : node.neighbors) {
            copy.neighbors.add(cloneGraph(nei));
        }
        return copy;
    }
}
```

## 复杂度分析
- 时间：\(O(V+E)\)
- 空间：\(O(V)\)
