# 164. 最大间距

- 题号：164
- 难度：困难
- LeetCode：[最大间距](https://leetcode.cn/problems/maximum-gap/)

## 题目描述
给定无序数组 `nums`，对其排序后，返回相邻元素之间的最大差值。要求 \(O(n)\) 时间与空间。

## 示例
- 示例  
输入：`nums = [3,6,9,1]`  
输出：`3`

## 最佳解法思路
- 桶排序/鸽笼原理（推荐）  
设最小值 `min`、最大值 `max`，把区间分成若干桶。  
最大间距一定不会出现在同一个桶内，而只可能出现在相邻非空桶之间：`gap = curBucketMin - prevBucketMax`。  
桶大小取 `bucketSize = max(1, (max-min)/(n-1))`。

## Java 最佳实现

```java
class Solution {
    public int maximumGap(int[] nums) {
        if (nums == null || nums.length < 2) return 0;
        int n = nums.length;
        int min = nums[0], max = nums[0];
        for (int x : nums) {
            if (x < min) min = x;
            if (x > max) max = x;
        }
        if (min == max) return 0;

        int bucketSize = Math.max(1, (max - min) / (n - 1));
        int bucketCount = (max - min) / bucketSize + 1;
        int[] bMin = new int[bucketCount];
        int[] bMax = new int[bucketCount];
        boolean[] used = new boolean[bucketCount];
        for (int i = 0; i < bucketCount; i++) {
            bMin[i] = Integer.MAX_VALUE;
            bMax[i] = Integer.MIN_VALUE;
        }

        for (int x : nums) {
            int idx = (x - min) / bucketSize;
            used[idx] = true;
            bMin[idx] = Math.min(bMin[idx], x);
            bMax[idx] = Math.max(bMax[idx], x);
        }

        int ans = 0;
        int prevMax = min;
        for (int i = 0; i < bucketCount; i++) {
            if (!used[i]) continue;
            ans = Math.max(ans, bMin[i] - prevMax);
            prevMax = bMax[i];
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
