# 223. 矩形面积

- 题号：223
- 难度：中等
- LeetCode：[矩形面积](https://leetcode.cn/problems/rectangle-area/)

## 题目描述
给定两个矩形的坐标 `(ax1, ay1, ax2, ay2)` 与 `(bx1, by1, bx2, by2)`（左下与右上），返回它们覆盖的总面积。

## 示例
- 示例  
输入：`ax1=-3, ay1=0, ax2=3, ay2=4, bx1=0, by1=-1, bx2=9, by2=2`  
输出：`45`

## 最佳解法思路
- 面积相加减重叠（推荐）  
总面积 = `areaA + areaB - overlap`。  
重叠宽 = `max(0, min(ax2,bx2) - max(ax1,bx1))`，重叠高同理。

## Java 最佳实现

```java
class Solution {
    public int computeArea(int ax1, int ay1, int ax2, int ay2,
                           int bx1, int by1, int bx2, int by2) {
        long areaA = (long) (ax2 - ax1) * (ay2 - ay1);
        long areaB = (long) (bx2 - bx1) * (by2 - by1);

        long overlapW = Math.max(0, Math.min(ax2, bx2) - Math.max(ax1, bx1));
        long overlapH = Math.max(0, Math.min(ay2, by2) - Math.max(ay1, by1));
        long overlap = overlapW * overlapH;

        return (int) (areaA + areaB - overlap);
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
