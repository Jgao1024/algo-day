# 772. 基本计算器 III

- 题号：772
- 难度：困难
- LeetCode：[基本计算器 III](https://leetcode.cn/problems/basic-calculator-iii/)

## 题目描述
给定字符串表达式 `s`，包含非负整数、`+ - * /`、括号与空格，返回计算结果（整数除法向 0 取整）。

## 示例
- 示例  
输入：`s = "2*(5+5*2)/3+(6/2+8)"`  
输出：`21`

## 最佳解法思路
- 递归下降解析（推荐）  
按优先级拆分：  
`expr` 处理 `+/-`；`term` 处理 `* /`；`factor` 处理数字或括号里的 `expr`。  
用一个全局指针 `i` 扫描字符串，遇到 `(` 就递归算到 `)`。

## Java 最佳实现

```java
class Solution {
    private String s;
    private int i;

    public int calculate(String s) {
        this.s = s;
        this.i = 0;
        return parseExpr();
    }

    private int parseExpr() {
        int val = parseTerm();
        while (true) {
            skipSpaces();
            if (i >= s.length() || s.charAt(i) == ')') break;
            char op = s.charAt(i);
            if (op != '+' && op != '-') break;
            i++;
            int right = parseTerm();
            val = (op == '+') ? val + right : val - right;
        }
        return val;
    }

    private int parseTerm() {
        int val = parseFactor();
        while (true) {
            skipSpaces();
            if (i >= s.length() || s.charAt(i) == ')' ) break;
            char op = s.charAt(i);
            if (op != '*' && op != '/') break;
            i++;
            int right = parseFactor();
            val = (op == '*') ? val * right : val / right;
        }
        return val;
    }

    private int parseFactor() {
        skipSpaces();
        char c = s.charAt(i);
        if (c == '(') {
            i++;
            int val = parseExpr();
            skipSpaces();
            i++;
            return val;
        }
        int num = 0;
        while (i < s.length()) {
            char ch = s.charAt(i);
            if (ch < '0' || ch > '9') break;
            num = num * 10 + (ch - '0');
            i++;
        }
        return num;
    }

    private void skipSpaces() {
        while (i < s.length() && s.charAt(i) == ' ') i++;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（递归栈）

## 总结（速记）
- **按优先级写三个函数：expr(+/-)、term(* /)、factor(数字/括号)**。
