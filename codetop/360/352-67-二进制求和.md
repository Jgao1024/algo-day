# 67. 二进制求和

- 题号：67
- 难度：简单
- LeetCode：[二进制求和](https://leetcode.cn/problems/add-binary/)

## 题目描述
给定两个二进制字符串 `a` 和 `b`，返回它们的和（也是二进制字符串）。

## 示例
- 示例  
输入：`a = "11", b = "1"`  
输出：`"100"`

## 最佳解法思路
- 模拟加法（推荐）  
从后往前逐位相加并维护 `carry`，把结果追加到 `StringBuilder`，最后反转。

## Java 最佳实现

```java
class Solution {
    public String addBinary(String a, String b) {
        int i = a.length() - 1, j = b.length() - 1;
        int carry = 0;
        StringBuilder sb = new StringBuilder();
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += a.charAt(i--) - '0';
            if (j >= 0) sum += b.charAt(j--) - '0';
            sb.append(sum & 1);
            carry = sum >> 1;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(\max(m,n))\)
- 空间：\(O(\max(m,n))\)
