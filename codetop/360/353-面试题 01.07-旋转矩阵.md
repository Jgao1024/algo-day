# 面试题 01.07. 旋转矩阵

- 题号：面试题 01.07
- 难度：中等
- LeetCode：[旋转矩阵](https://leetcode.cn/problems/rotate-matrix-lcci/)

## 题目描述
给定 `n x n` 矩阵，将矩阵顺时针旋转 90 度（原地修改）。

## 示例
- 示例  
输入：`matrix = [[1,2,3],[4,5,6],[7,8,9]]`  
输出：`[[7,4,1],[8,5,2],[9,6,3]]`

## 最佳解法思路
- 转置 + 每行反转（推荐）  
先沿主对角线转置，再把每一行左右反转，即得到顺时针 90° 旋转结果。

## Java 最佳实现

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int t = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = t;
            }
        }
        for (int i = 0; i < n; i++) {
            int l = 0, r = n - 1;
            while (l < r) {
                int t = matrix[i][l];
                matrix[i][l] = matrix[i][r];
                matrix[i][r] = t;
                l++;
                r--;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)

- **顺时针 90°：先转置，再每行反转**。
