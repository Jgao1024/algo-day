# 29. 两数相除

- 题号：29
- 难度：中等
- LeetCode：[两数相除](https://leetcode.cn/problems/divide-two-integers/)

## 题目描述
给定两个 32 位有符号整数 `dividend` 和 `divisor`，不使用乘法、除法和取模运算，返回 `dividend / divisor` 的结果（向 0 取整）。溢出时返回 `Integer.MAX_VALUE`。

## 示例
- 示例  
输入：`dividend = 10, divisor = 3`  
输出：`3`

## 最佳解法思路
- 位运算（推荐）  
用减法模拟除法：尝试用 `divisor << i` 去减 `dividend`（从大到小的 i），能减就把结果的第 i 位设为 1，并减去对应倍数。  
用 `long` 防止中间溢出，并处理 `MIN_VALUE / -1` 的特殊溢出。

## Java 最佳实现

```java
class Solution {
    public int divide(int dividend, int divisor) {
        if (dividend == Integer.MIN_VALUE && divisor == -1) return Integer.MAX_VALUE;

        long a = Math.abs((long) dividend);
        long b = Math.abs((long) divisor);
        long res = 0;

        for (int i = 31; i >= 0; i--) {
            if ((a >> i) >= b) {
                res += 1L << i;
                a -= b << i;
            }
        }

        if ((dividend ^ divisor) < 0) res = -res;
        return (int) res;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（固定 32 次循环）
- 空间：\(O(1)\)

## 总结（速记）
- **从高位到低位试探：能减就设置该位并扣掉 `divisor<<i`**。
