# 986. 区间列表的交集

- 题号：986
- 难度：中等
- LeetCode：[区间列表的交集](https://leetcode.cn/problems/interval-list-intersections/)

## 题目描述
给定两个不相交且已排序的区间列表 `firstList`、`secondList`，返回它们的交集区间列表。

## 示例
- 示例  
输入：`firstList = [[0,2],[5,10],[13,23],[24,25]]`，`secondList = [[1,5],[8,12],[15,24],[25,26]]`  
输出：`[[1,2],[5,5],[8,10],[15,23],[24,24],[25,25]]`

## 最佳解法思路
- 双指针（推荐）  
用 `i/j` 指向两个列表当前区间。  
交集区间为 `[max(starts), min(ends)]`，若 `start<=end` 则加入答案。  
然后移动“结束更早”的那个指针，继续比较。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] intervalIntersection(int[][] firstList, int[][] secondList) {
        int i = 0, j = 0;
        List<int[]> res = new ArrayList<>();
        while (i < firstList.length && j < secondList.length) {
            int a1 = firstList[i][0], a2 = firstList[i][1];
            int b1 = secondList[j][0], b2 = secondList[j][1];
            int s = Math.max(a1, b1);
            int e = Math.min(a2, b2);
            if (s <= e) res.add(new int[]{s, e});
            if (a2 < b2) i++;
            else j++;
        }
        int[][] ans = new int[res.size()][2];
        for (int k = 0; k < res.size(); k++) ans[k] = res.get(k);
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)（不含输出）

## 总结（速记）
- **交集取 max(start) 和 min(end)；移动 end 更小的那一边**。
