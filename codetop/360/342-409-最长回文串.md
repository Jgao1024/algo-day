# 409. 最长回文串

- 题号：409
- 难度：简单
- LeetCode：[最长回文串](https://leetcode.cn/problems/longest-palindrome/)

## 题目描述
给定字符串 `s`，用其中的字符重新排列，能组成的最长回文串长度是多少。

## 示例
- 示例  
输入：`s = "abccccdd"`  
输出：`7`

## 最佳解法思路
- 统计次数（推荐）  
所有字符出现次数的“偶数部分”都能放到回文两边；如果存在任意一个奇数次数，就可以把一个字符放在中间（+1）。

## Java 最佳实现

```java
class Solution {
    public int longestPalindrome(String s) {
        int[] cnt = new int[128];
        for (int i = 0; i < s.length(); i++) cnt[s.charAt(i)]++;
        int ans = 0;
        boolean hasOdd = false;
        for (int c : cnt) {
            ans += (c / 2) * 2;
            if ((c & 1) == 1) hasOdd = true;
        }
        return hasOdd ? ans + 1 : ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
