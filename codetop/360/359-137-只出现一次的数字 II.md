# 137. 只出现一次的数字 II

- 题号：137
- 难度：中等
- LeetCode：[只出现一次的数字 II](https://leetcode.cn/problems/single-number-ii/)

## 题目描述
给定整数数组，除一个元素只出现一次外，其余元素都出现三次。找出只出现一次的元素。

## 示例
- 示例  
输入：`nums = [2,2,3,2]`  
输出：`3`

## 最佳解法思路
- 位运算状态机（推荐）  
用 `ones` 表示“出现 1 次的位”，`twos` 表示“出现 2 次的位”。  
每来一个数 `x`：  
`ones = (ones ^ x) & ~twos`  
`twos = (twos ^ x) & ~ones`  
出现三次的位会被清零，最终 `ones` 就是答案。

## Java 最佳实现

```java
class Solution {
    public int singleNumber(int[] nums) {
        int ones = 0, twos = 0;
        for (int x : nums) {
            ones = (ones ^ x) & ~twos;
            twos = (twos ^ x) & ~ones;
        }
        return ones;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
