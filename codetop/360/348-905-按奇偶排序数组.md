# 905. 按奇偶排序数组

- 题号：905
- 难度：简单
- LeetCode：[按奇偶排序数组](https://leetcode.cn/problems/sort-array-by-parity/)

## 题目描述
给定整数数组 `nums`，将所有偶数放在前面，所有奇数放在后面，返回任意满足条件的数组。

## 示例
- 示例  
输入：`nums = [3,1,2,4]`  
输出：`[2,4,3,1]`（顺序不限）

## 最佳解法思路
- 双指针（推荐）  
用 `l/r` 从两端扫描：`l` 找到奇数、`r` 找到偶数则交换，直到相遇。

## Java 最佳实现

```java
class Solution {
    public int[] sortArrayByParity(int[] nums) {
        int l = 0, r = nums.length - 1;
        while (l < r) {
            while (l < r && (nums[l] & 1) == 0) l++;
            while (l < r && (nums[r] & 1) == 1) r--;
            if (l < r) {
                int t = nums[l];
                nums[l] = nums[r];
                nums[r] = t;
                l++;
                r--;
            }
        }
        return nums;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
