# 1206. 设计跳表

- 题号：1206
- 难度：困难
- LeetCode：[设计跳表](https://leetcode.cn/problems/design-skiplist/)

## 题目描述
实现跳表，支持：
- `search(target)`：是否存在
- `add(num)`：插入
- `erase(num)`：删除一个 num（存在则删并返回 true，否则 false）

## 示例
- 示例  
输入：`["Skiplist","add","add","add","search","add","search","erase","erase","search"]`  
`[[],[1],[2],[3],[0],[4],[1],[0],[1],[1]]`  
输出：`[null,null,null,null,false,null,true,false,true,false]`

## 最佳解法思路
- 经典跳表（推荐）  
每个节点有多层 forward 指针，层数随机生成（几何分布）。  
查找/插入/删除都从最高层往下走，记录每一层“最后一个小于目标的节点”（update 数组），即可在 \(O(\log n)\) 均摊完成。

## Java 最佳实现

```java
import java.util.Random;

class Skiplist {
    private static final int MAX_LEVEL = 16;
    private static final double P = 0.5;

    private final Node head = new Node(-1, MAX_LEVEL);
    private int level = 1;
    private final Random rnd = new Random();

    public Skiplist() {
    }

    public boolean search(int target) {
        Node cur = head;
        for (int i = level - 1; i >= 0; i--) {
            while (cur.next[i] != null && cur.next[i].val < target) cur = cur.next[i];
        }
        cur = cur.next[0];
        return cur != null && cur.val == target;
    }

    public void add(int num) {
        Node[] update = new Node[MAX_LEVEL];
        Node cur = head;
        for (int i = level - 1; i >= 0; i--) {
            while (cur.next[i] != null && cur.next[i].val < num) cur = cur.next[i];
            update[i] = cur;
        }

        int lv = randomLevel();
        if (lv > level) {
            for (int i = level; i < lv; i++) update[i] = head;
            level = lv;
        }

        Node node = new Node(num, lv);
        for (int i = 0; i < lv; i++) {
            node.next[i] = update[i].next[i];
            update[i].next[i] = node;
        }
    }

    public boolean erase(int num) {
        Node[] update = new Node[MAX_LEVEL];
        Node cur = head;
        for (int i = level - 1; i >= 0; i--) {
            while (cur.next[i] != null && cur.next[i].val < num) cur = cur.next[i];
            update[i] = cur;
        }
        cur = cur.next[0];
        if (cur == null || cur.val != num) return false;

        for (int i = 0; i < level; i++) {
            if (update[i].next[i] != cur) break;
            update[i].next[i] = cur.next[i];
        }
        while (level > 1 && head.next[level - 1] == null) level--;
        return true;
    }

    private int randomLevel() {
        int lv = 1;
        while (lv < MAX_LEVEL && rnd.nextDouble() < P) lv++;
        return lv;
    }

    private static class Node {
        int val;
        Node[] next;

        Node(int val, int level) {
            this.val = val;
            this.next = new Node[level];
        }
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- **从高层往下走，记录 update；随机层数决定 forward 指针数量**。
