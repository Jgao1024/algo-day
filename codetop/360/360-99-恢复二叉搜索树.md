# 99. 恢复二叉搜索树

- 题号：99
- 难度：困难
- LeetCode：[恢复二叉搜索树](https://leetcode.cn/problems/recover-binary-search-tree/)

## 题目描述
二叉搜索树中有两个节点被错误交换，导致 BST 性质被破坏。请在不改变树结构的情况下恢复 BST。

## 示例
- 示例  
输入：`root = [1,3,null,null,2]`  
输出：`[3,1,null,null,2]`

## 最佳解法思路
- 中序遍历找逆序对（推荐）  
BST 的中序遍历是递增序列。若有两个节点交换，中序序列会出现 1 次或 2 次“逆序”（`prev.val > cur.val`）。  
第一次逆序：`first = prev`；每次逆序都更新 `second = cur`。最后交换 `first/second` 的值即可。

## Java 最佳实现

```java
class Solution {
    private TreeNode first;
    private TreeNode second;
    private TreeNode prev;

    public void recoverTree(TreeNode root) {
        inorder(root);
        int t = first.val;
        first.val = second.val;
        second.val = t;
    }

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        if (prev != null && prev.val > node.val) {
            if (first == null) first = prev;
            second = node;
        }
        prev = node;
        inorder(node.right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）

## 总结（速记）
- **中序递增；遇到 `prev>cur` 记录 first/second，最后交换它们的值**。
