# 剑指 Offer 12. 矩阵中的路径

- 题号：剑指 Offer 12
- 难度：中等
- LeetCode：[矩阵中的路径](https://leetcode.cn/problems/ju-zhen-zhong-de-lu-jing-lcof/)

## 题目描述
给定字符矩阵 `board` 和字符串 `word`，判断 `word` 是否能通过矩阵中的相邻格（上下左右）依次连接得到，同一格不能重复使用。

## 示例
- 示例  
输入：`board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"`  
输出：`true`

## 最佳解法思路
- DFS 回溯（推荐）  
从每个格子作为起点匹配 `word[idx]`。匹配成功就临时标记该格已用（例如改为 `'#'`），向四方向继续搜索；返回时恢复。

## Java 最佳实现

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] b, String w, int i, int j, int idx) {
        if (idx == w.length()) return true;
        if (i < 0 || i >= b.length || j < 0 || j >= b[0].length) return false;
        if (b[i][j] != w.charAt(idx)) return false;

        char old = b[i][j];
        b[i][j] = '#';
        boolean ok = dfs(b, w, i + 1, j, idx + 1)
                || dfs(b, w, i - 1, j, idx + 1)
                || dfs(b, w, i, j + 1, idx + 1)
                || dfs(b, w, i, j - 1, idx + 1);
        b[i][j] = old;
        return ok;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(mn \cdot 4^{L})\)
- 空间：\(O(L)\)

## 总结（速记）
- **每格做起点 DFS；走过的格临时标记，回溯恢复**。
