# 698. 划分为k个相等的子集

- 题号：698
- 难度：中等
- LeetCode：[划分为k个相等的子集](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/)

## 题目描述
给定整数数组 `nums` 和整数 `k`，判断是否能把数组划分为 `k` 个非空子集，使每个子集元素和相等。

## 示例
- 示例  
输入：`nums = [4,3,2,3,5,2,1], k = 4`  
输出：`true`

## 最佳解法思路
- 回溯装桶（推荐）  
总和 `sum` 必须能被 `k` 整除，目标桶和 `target = sum/k`。  
把 `nums` 降序排序，从大到小尝试放入当前桶，桶满就切到下一个桶。  
用 `used[]` 标记元素是否已用，并在桶起点做剪枝（起点放不进去就直接失败）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    private int[] nums;
    private boolean[] used;
    private int target;
    private int k;

    public boolean canPartitionKSubsets(int[] nums, int k) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (k <= 0 || sum % k != 0) return false;
        this.target = sum / k;
        this.k = k;

        Arrays.sort(nums);
        for (int i = 0, j = nums.length - 1; i < j; i++, j--) {
            int t = nums[i];
            nums[i] = nums[j];
            nums[j] = t;
        }
        if (nums[0] > target) return false;

        this.nums = nums;
        this.used = new boolean[nums.length];
        return dfs(0, 0, 0);
    }

    private boolean dfs(int bucket, int start, int curSum) {
        if (bucket == k - 1) return true;
        if (curSum == target) return dfs(bucket + 1, 0, 0);

        int prev = -1;
        for (int i = start; i < nums.length; i++) {
            if (used[i]) continue;
            if (nums[i] == prev) continue;
            if (curSum + nums[i] > target) continue;

            used[i] = true;
            if (dfs(bucket, i + 1, curSum + nums[i])) return true;
            used[i] = false;
            prev = nums[i];

            if (curSum == 0) break;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：指数级（回溯）
- 空间：\(O(n)\)
