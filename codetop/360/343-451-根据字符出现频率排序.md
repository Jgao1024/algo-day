# 451. 根据字符出现频率排序

- 题号：451
- 难度：中等
- LeetCode：[根据字符出现频率排序](https://leetcode.cn/problems/sort-characters-by-frequency/)

## 题目描述
给定字符串 `s`，按字符出现频率从高到低排序后返回。相同频率的字符顺序不限。

## 示例
- 示例  
输入：`s = "tree"`  
输出：`"eert"`（或 `"eetr"`）

## 最佳解法思路
- 计数 + 桶排序（推荐）  
先统计每个字符出现次数；频率最大不会超过 `s.length()`，可以建桶 `buckets[freq]` 存放字符，最后从高频到低频拼接。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public String frequencySort(String s) {
        Map<Character, Integer> cnt = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            cnt.put(c, cnt.getOrDefault(c, 0) + 1);
        }

        List<Character>[] buckets = new List[s.length() + 1];
        for (Map.Entry<Character, Integer> e : cnt.entrySet()) {
            int f = e.getValue();
            if (buckets[f] == null) buckets[f] = new ArrayList<>();
            buckets[f].add(e.getKey());
        }

        StringBuilder sb = new StringBuilder();
        for (int f = buckets.length - 1; f >= 1; f--) {
            if (buckets[f] == null) continue;
            for (char c : buckets[f]) {
                for (int k = 0; k < f; k++) sb.append(c);
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
