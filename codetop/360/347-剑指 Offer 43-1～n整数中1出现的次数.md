# 剑指 Offer 43. 1～n整数中1出现的次数

- 题号：剑指 Offer 43
- 难度：困难
- LeetCode：[1～n整数中1出现的次数](https://leetcode.cn/problems/1nzheng-shu-zhong-1chu-xian-de-ci-shu-lcof/)

## 题目描述
给定整数 `n`，统计 1～n 的所有整数中数字 `1` 出现的次数。

## 示例
- 示例  
输入：`n = 12`  
输出：`5`

## 最佳解法思路
- 数位统计（推荐）  
按位（个位、十位、百位...）统计当前位为 1 的贡献。  
设 `digit=1,10,100...`，`high=n/(digit*10)`，`cur=(n/digit)%10`，`low=n%digit`：  
`cur==0`：`high*digit`  
`cur==1`：`high*digit + low + 1`  
`cur>=2`：`(high+1)*digit`

## Java 最佳实现

```java
class Solution {
    public int countDigitOne(int n) {
        long ans = 0;
        long digit = 1;
        while (n / digit != 0) {
            long high = n / (digit * 10);
            long cur = (n / digit) % 10;
            long low = n % digit;
            if (cur == 0) ans += high * digit;
            else if (cur == 1) ans += high * digit + low + 1;
            else ans += (high + 1) * digit;
            digit *= 10;
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log_{10} n)\)
- 空间：\(O(1)\)

- **按位拆 high/cur/low，cur 为 0/1/大于 1 分三种公式**。
