## 最佳解法思路
- 树状数组（Fenwick / BIT）  
维护前缀和结构，支持：
- 单点更新：\(O(\log n)\)
- 区间查询：`sumRange(l,r)=prefix(r)-prefix(l-1)`，\(O(\log n)\)

## Java 最佳实现

```java
class NumArray {
    private final int[] bit;
    private final int[] nums;
    private final int n;

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = new int[n];
        this.bit = new int[n + 1];
        for (int i = 0; i < n; i++) {
            update(i, nums[i]);
        }
    }

    public void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        int i = index + 1;
        while (i <= n) {
            bit[i] += delta;
            i += i & -i;
        }
    }

    public int sumRange(int left, int right) {
        return prefix(right) - prefix(left - 1);
    }

    private int prefix(int index) {
        int sum = 0;
        int i = index + 1;
        while (i > 0) {
            sum += bit[i];
            i -= i & -i;
        }
        return sum;
    }
}
```

## 复杂度分析
- 时间：构建 \(O(n\log n)\)，单次更新/查询 \(O(\log n)\)
- 空间：\(O(n)\)
