## 最佳解法思路
- 动态规划统计 4 个方向的连续 1 长度  
对每个格子 \((i,j)\) 若为 1：  
- 横向：当前行连续 1 计数 `hor`  
- 纵向：`ver[j]`  
- 主对角线：`diag[j] = prevDiag + 1`（来自 \((i-1,j-1)\)）  
- 副对角线：`anti[j] = anti[j+1] + 1`（来自 \((i-1,j+1)\)）  
边扫边更新全局最大值。

## Java 最佳实现

```java
class Solution {
    public int longestLine(int[][] mat) {
        if (mat == null || mat.length == 0 || mat[0].length == 0) return 0;
        int m = mat.length, n = mat[0].length;

        int[] ver = new int[n];
        int[] diag = new int[n];
        int[] anti = new int[n];

        int ans = 0;
        for (int i = 0; i < m; i++) {
            int hor = 0;
            int prevDiag = 0;
            for (int j = 0; j < n; j++) {
                int tempDiag = diag[j];
                int oldAntiRight = (j + 1 < n) ? anti[j + 1] : 0;

                if (mat[i][j] == 1) {
                    hor++;
                    ver[j]++;
                    diag[j] = prevDiag + 1;
                    anti[j] = oldAntiRight + 1;
                    ans = Math.max(ans, Math.max(hor, Math.max(ver[j], Math.max(diag[j], anti[j]))));
                } else {
                    hor = 0;
                    ver[j] = 0;
                    diag[j] = 0;
                    anti[j] = 0;
                }
                prevDiag = tempDiag;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
