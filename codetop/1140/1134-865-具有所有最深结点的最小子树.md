## 最佳解法思路
- 后序 DFS 返回（最深深度，答案节点）  
左右子树分别返回它们的最深深度：  
- 若深度相同，说明最深节点分布在两侧，当前根就是最小子树根  
- 否则答案在更深的那一侧  
一次遍历即可。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode subtreeWithAllDeepest(TreeNode root) {
        return dfs(root).node;
    }

    private Info dfs(TreeNode node) {
        if (node == null) return new Info(null, 0);
        Info L = dfs(node.left);
        Info R = dfs(node.right);
        if (L.depth == R.depth) {
            return new Info(node, L.depth + 1);
        }
        return (L.depth > R.depth) ? new Info(L.node, L.depth + 1) : new Info(R.node, R.depth + 1);
    }

    private static class Info {
        TreeNode node;
        int depth;
        Info(TreeNode node, int depth) {
            this.node = node;
            this.depth = depth;
        }
    }
}
```
