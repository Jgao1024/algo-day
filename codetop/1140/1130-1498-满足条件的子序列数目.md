## 最佳解法思路
- 排序 + 双指针  
先排序。固定最小值 `nums[l]`，尽量取最大的 `nums[r]` 使得 `nums[l] + nums[r] <= target`。  
当条件成立时，`l` 与 `r` 之间的任意元素都可选/不选，贡献为 \(2^{(r-l)}\) 个子序列；然后 `l++`。否则 `r--`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int numSubseq(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        int mod = 1_000_000_007;

        int[] pow2 = new int[n];
        pow2[0] = 1;
        for (int i = 1; i < n; i++) {
            pow2[i] = (int) ((pow2[i - 1] * 2L) % mod);
        }

        int l = 0, r = n - 1;
        long ans = 0;
        while (l <= r) {
            if (nums[l] + nums[r] <= target) {
                ans += pow2[r - l];
                ans %= mod;
                l++;
            } else {
                r--;
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
