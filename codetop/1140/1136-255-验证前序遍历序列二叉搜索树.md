## 最佳解法思路
- 单调栈 + 下界 `lower`  
遍历前序数组，栈维护“还没找到右子树的祖先”。当当前值 `x` 大于栈顶，说明开始回溯并进入某个祖先的右子树，持续出栈并更新 `lower`。任何时候若 `x < lower`，说明落在右子树却比祖先小，非法。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean verifyPreorder(int[] preorder) {
        Deque<Integer> stack = new ArrayDeque<>();
        int lower = Integer.MIN_VALUE;
        for (int x : preorder) {
            if (x < lower) return false;
            while (!stack.isEmpty() && x > stack.peek()) {
                lower = stack.pop();
            }
            stack.push(x);
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
