## 最佳解法思路
- 区间 DP + 前缀和 + 双指针找分界点  
设 `dp[i][j]` 表示区间 `[i..j]` 先手能获得的最大分数。一次切分为 `k`：左和 `L=sum(i,k)`，右和 `R=sum(k+1,j)`：  
- `L < R`：只能取左边，得分 `L + dp[i][k]`  
- `L > R`：只能取右边，得分 `R + dp[k+1][j]`  
- `L == R`：两边都可取，取最大  
对固定 `i`，随着 `j` 增大，满足 `L <= R` 的最大分割点 `k` 单调右移，可用双指针维护；并用两个“最优表”快速取最大值：  
- `bestL[i][t] = max_{k∈[i..t]} (dp[i][k] + sum(i,k))`  
- `bestR[t][j] = max_{k∈[t..j]} (dp[k][j] + sum(k,j))`

## Java 最佳实现

```java
class Solution {
    public int stoneGameV(int[] stoneValue) {
        int n = stoneValue.length;
        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stoneValue[i];

        int[][] dp = new int[n][n];
        int[][] bestL = new int[n][n];
        int[][] bestR = new int[n][n];

        for (int i = 0; i < n; i++) {
            bestL[i][i] = stoneValue[i];
            bestR[i][i] = stoneValue[i];
        }

        for (int i = n - 2; i >= 0; i--) {
            int k = i - 1;
            for (int j = i + 1; j < n; j++) {
                while (k + 1 < j && sum(pre, i, k + 1) <= sum(pre, k + 2, j)) {
                    k++;
                }

                int leftBest = (k >= i) ? bestL[i][k] : 0;

                int startRight = k + 1;
                if (sum(pre, i, k) < sum(pre, k + 1, j)) {
                    startRight = k + 2;
                }
                int rightBest = 0;
                if (startRight <= j) rightBest = bestR[startRight][j];

                dp[i][j] = Math.max(leftBest, rightBest);

                bestL[i][j] = Math.max(bestL[i][j - 1], dp[i][j] + sum(pre, i, j));
                bestR[i][j] = Math.max(bestR[i + 1][j], dp[i][j] + sum(pre, i, j));
            }
        }
        return dp[0][n - 1];
    }

    private int sum(int[] pre, int l, int r) {
        if (l > r) return 0;
        return pre[r + 1] - pre[l];
    }
}
```
