## 最佳解法思路
- DFS 返回两种长度：从当前节点向下的“递增链”和“递减链”  
对每个节点，分别从左右孩子拿到 `inc/dec`：  
- 若 `child.val == node.val + 1`，可以接到 `inc`  
- 若 `child.val == node.val - 1`，可以接到 `dec`  
用 `inc + dec - 1` 更新答案（把当前节点作为拐点）。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int ans = 0;

    public int longestConsecutive(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int[] dfs(TreeNode node) {
        if (node == null) return new int[] {0, 0};
        int inc = 1, dec = 1;

        if (node.left != null) {
            int[] L = dfs(node.left);
            if (node.left.val == node.val + 1) inc = Math.max(inc, L[0] + 1);
            if (node.left.val == node.val - 1) dec = Math.max(dec, L[1] + 1);
        }
        if (node.right != null) {
            int[] R = dfs(node.right);
            if (node.right.val == node.val + 1) inc = Math.max(inc, R[0] + 1);
            if (node.right.val == node.val - 1) dec = Math.max(dec, R[1] + 1);
        }

        ans = Math.max(ans, inc + dec - 1);
        return new int[] {inc, dec};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
