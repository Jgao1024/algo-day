## 最佳解法思路
- DP：用“左右高度差”做状态  
设 `dp[d]` 表示当前处理到某些钢筋后，左右高度差为 `d` 时，“较高一侧高度”的最大值。加入一根钢筋 `x` 有 3 种选择：不用、放到高的一侧（差变大）、放到低的一侧（差变小/可能翻转）。最终答案是 `dp[0]`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int tallestBillboard(int[] rods) {
        int sum = 0;
        for (int x : rods) sum += x;

        int[] dp = new int[sum + 1];
        Arrays.fill(dp, -1);
        dp[0] = 0;

        for (int x : rods) {
            int[] next = dp.clone();
            for (int d = 0; d <= sum; d++) {
                if (dp[d] < 0) continue;

                if (d + x <= sum) {
                    next[d + x] = Math.max(next[d + x], dp[d] + x);
                }

                int newD = Math.abs(d - x);
                int newTaller = dp[d] + Math.max(0, x - d);
                next[newD] = Math.max(next[newD], newTaller);
            }
            dp = next;
        }
        return dp[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot S)\)，S 为钢筋总和
- 空间：\(O(S)\)
