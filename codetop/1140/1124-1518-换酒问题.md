## 最佳解法思路
- 直接模拟  
每喝一瓶得到一个空瓶，`numExchange` 个空瓶可以换一瓶新酒。循环换酒直到空瓶不足以兑换。

## Java 最佳实现

```java
class Solution {
    public int numWaterBottles(int numBottles, int numExchange) {
        int ans = 0;
        int empty = 0;

        while (numBottles > 0) {
            ans += numBottles;
            empty += numBottles;

            numBottles = empty / numExchange;
            empty = empty % numExchange;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)（每轮空瓶数缩小）
- 空间：\(O(1)\)
