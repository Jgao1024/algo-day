## 最佳解法思路
- 扫描 + 复用“行段/列段”击杀数  
炸弹在一个空格 `0` 上能击杀同一行/列中被墙 `W` 阻挡前的所有敌人 `E`。  
遍历网格：  
- 当 `j==0` 或左侧是墙时，重新统计该行从 `j` 开始到下一个墙的敌人数 `rowHits`  
- 当 `i==0` 或上侧是墙时，重新统计该列从 `i` 开始到下一个墙的敌人数 `colHits[j]`  
若当前是 `0`，答案更新为 `rowHits + colHits[j]`。

## Java 最佳实现

```java
class Solution {
    public int maxKilledEnemies(char[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) return 0;
        int m = grid.length, n = grid[0].length;
        int[] colHits = new int[n];
        int ans = 0;

        for (int i = 0; i < m; i++) {
            int rowHits = 0;
            for (int j = 0; j < n; j++) {
                if (j == 0 || grid[i][j - 1] == 'W') {
                    rowHits = 0;
                    for (int y = j; y < n && grid[i][y] != 'W'; y++) {
                        if (grid[i][y] == 'E') rowHits++;
                    }
                }
                if (i == 0 || grid[i - 1][j] == 'W') {
                    colHits[j] = 0;
                    for (int x = i; x < m && grid[x][j] != 'W'; x++) {
                        if (grid[x][j] == 'E') colHits[j]++;
                    }
                }
                if (grid[i][j] == '0') {
                    ans = Math.max(ans, rowHits + colHits[j]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
