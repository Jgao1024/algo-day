## 最佳解法思路
- Trie（目录树）模拟文件系统  
每个节点保存：
- `children`：子目录/文件名到节点（用 `TreeMap` 保证 `ls` 字典序）
- `isFile` 与 `content`：是否文件以及文件内容  
按路径 `/` 分割逐层走即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

class FileSystem {
    private final Node root = new Node();

    public List<String> ls(String path) {
        if ("/".equals(path)) {
            return new ArrayList<>(root.children.keySet());
        }
        String[] parts = split(path);
        Node cur = root;
        for (String p : parts) cur = cur.children.get(p);

        if (cur.isFile) {
            List<String> res = new ArrayList<>();
            res.add(parts[parts.length - 1]);
            return res;
        }
        return new ArrayList<>(cur.children.keySet());
    }

    public void mkdir(String path) {
        Node cur = root;
        for (String p : split(path)) {
            cur = cur.children.computeIfAbsent(p, k -> new Node());
        }
    }

    public void addContentToFile(String filePath, String content) {
        Node cur = root;
        String[] parts = split(filePath);
        for (String p : parts) {
            cur = cur.children.computeIfAbsent(p, k -> new Node());
        }
        cur.isFile = true;
        cur.content.append(content);
    }

    public String readContentFromFile(String filePath) {
        Node cur = root;
        for (String p : split(filePath)) {
            cur = cur.children.get(p);
        }
        return cur.content.toString();
    }

    private String[] split(String path) {
        if ("/".equals(path)) return new String[0];
        return path.substring(1).split("/");
    }

    private static class Node {
        Map<String, Node> children = new TreeMap<>();
        boolean isFile = false;
        StringBuilder content = new StringBuilder();
    }
}
```

## 复杂度分析
- `mkdir/读写文件/ls`：与路径长度成正比，约 \(O(L)\)
- 空间：\(O(\text{总节点数} + \text{内容长度})\)
