## 最佳解法思路
- 栈模拟调用栈 + `prev` 记录上一次切片起点  
日志只有两类：`start`/`end`。遇到 `start`：先把当前栈顶函数从 `prev` 到 `time` 这段时间累加到答案，再把新函数入栈，更新 `prev=time`。  
遇到 `end`：把栈顶函数从 `prev` 到 `time`（包含 `time`）累加，出栈，更新 `prev=time+1`（下一段从下一时间点开始）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        int[] ans = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        int prev = 0;
        for (String log : logs) {
            String[] parts = log.split(":");
            int id = Integer.parseInt(parts[0]);
            String type = parts[1];
            int time = Integer.parseInt(parts[2]);

            if ("start".equals(type)) {
                if (!stack.isEmpty()) {
                    ans[stack.peek()] += time - prev;
                }
                stack.push(id);
                prev = time;
            } else {
                ans[stack.peek()] += time - prev + 1;
                stack.pop();
                prev = time + 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m)\)，m 为日志条数
- 空间：\(O(n)\)（栈深度最多 n）
