## 最佳解法思路
- 贪心双指针：从两端往中间拼“块”  
用 `i/j` 分别从左/右推进，维护两个字符串 `left/right`。每次各取一个字符追加到 `left`、前插到 `right`；当 `left == right` 时说明找到一对块，答案 `+2`，清空继续。最后若还有残余块，答案 `+1`。

## Java 最佳实现

```java
class Solution {
    public int longestDecomposition(String text) {
        int i = 0, j = text.length() - 1;
        StringBuilder left = new StringBuilder();
        StringBuilder right = new StringBuilder();
        int ans = 0;

        while (i <= j) {
            left.append(text.charAt(i++));
            right.insert(0, text.charAt(j--));
            if (left.toString().contentEquals(right)) {
                ans += 2;
                left.setLength(0);
                right.setLength(0);
            }
        }
        if (left.length() > 0) ans += 1;
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)（`insert(0, ...)` 有位移成本；数据范围不大时够用）
- 空间：\(O(n)\)
