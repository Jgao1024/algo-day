# 347. 前 K 个高频元素

- 题号：347
- 难度：中等
- LeetCode：[前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)

## 题目描述
给定数组 `nums` 和整数 `k`，返回出现频率前 `k` 高的元素（顺序不限）。

## 示例
- 示例  
输入：`nums = [1,1,1,2,2,3]`, `k = 2`  
输出：`[1,2]`

## 最佳解法思路
- 思路1（推荐）：小根堆维护 TopK  
先用 HashMap 统计频次。  
用大小为 `k` 的小根堆（按频次排序）维护当前 top k：  
堆未满直接入；堆满且当前频次大于堆顶就替换。最后堆里就是答案。

- 思路2：桶排序  
按频次把数放到桶里，从高频往低频扫到取满 k 个。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) cnt.put(x, cnt.getOrDefault(x, 0) + 1);

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]); // [num, freq]
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int num = e.getKey();
            int freq = e.getValue();
            if (pq.size() < k) {
                pq.offer(new int[]{num, freq});
            } else if (freq > pq.peek()[1]) {
                pq.poll();
                pq.offer(new int[]{num, freq});
            }
        }

        int[] ans = new int[pq.size()];
        int i = 0;
        while (!pq.isEmpty()) ans[i++] = pq.poll()[0];
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log k)\)
- 空间：\(O(n)\)
