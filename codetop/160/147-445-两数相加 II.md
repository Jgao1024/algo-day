# 445. 两数相加 II

- 题号：445
- 难度：中等
- LeetCode：[两数相加 II](https://leetcode.cn/problems/add-two-numbers-ii/)

## 题目描述
给你两个非空链表 `l1` 和 `l2`，分别表示两个非负整数。数字最高位在链表头部。

请你将它们相加，并以相同形式返回一个链表。不能修改输入链表（不能反转后再改回去那种修改）。

## 示例
- 示例  
输入：`l1 = 7->2->4->3, l2 = 5->6->4`  
输出：`7->8->0->7`

## 最佳解法思路
- 思路1（推荐）：栈 + 头插法构造结果  
把 `l1/l2` 的每一位压入两个栈，这样就能从低位开始相加。  
每次弹出相加加上 `carry`，把新节点头插到结果链表前面。

- 思路2：反转链表再相加（不推荐）  
会修改输入，不符合题意（除非你自己复制节点）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        Deque<Integer> s1 = new ArrayDeque<>();
        Deque<Integer> s2 = new ArrayDeque<>();
        while (l1 != null) {
            s1.push(l1.val);
            l1 = l1.next;
        }
        while (l2 != null) {
            s2.push(l2.val);
            l2 = l2.next;
        }

        int carry = 0;
        ListNode head = null;
        while (!s1.isEmpty() || !s2.isEmpty() || carry != 0) {
            int a = s1.isEmpty() ? 0 : s1.pop();
            int b = s2.isEmpty() ? 0 : s2.pop();
            int sum = a + b + carry;
            carry = sum / 10;
            ListNode node = new ListNode(sum % 10);
            node.next = head;
            head = node;
        }
        return head;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(m+n)\)（两个栈）

## 相关题目

- 415 字符串相加：字符串版竖式

## 总结（速记）
- 高位在前的相加：用栈把顺序翻转，再头插构造结果。
