# 295. 数据流的中位数

- 题号：295
- 难度：困难
- LeetCode：[数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/)

## 题目描述
数据流不断加入数字，随时返回当前数据的中位数。

## 示例
- 示例  
操作：`addNum(1), addNum(2), findMedian(), addNum(3), findMedian()`  
输出：`1.5, 2.0`

## 最佳解法思路
- 思路1（推荐）：双堆（大根堆 + 小根堆）  
维护：  
- `small`（大根堆）：存较小的一半  
- `large`（小根堆）：存较大的一半  
保证：`small.size() == large.size()` 或 `small.size() == large.size() + 1`，并且 `small` 的所有元素都 <= `large` 的所有元素。  
插入时先放入对应堆，再通过移动堆顶元素做平衡。

## Java 最佳实现

```java
import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    private final PriorityQueue<Integer> small = new PriorityQueue<>(Collections.reverseOrder());
    private final PriorityQueue<Integer> large = new PriorityQueue<>();

    public MedianFinder() {
    }

    public void addNum(int num) {
        if (small.isEmpty() || num <= small.peek()) small.offer(num);
        else large.offer(num);

        if (small.size() > large.size() + 1) large.offer(small.poll());
        else if (large.size() > small.size()) small.offer(large.poll());
    }

    public double findMedian() {
        if (small.size() == large.size()) {
            return (small.peek() + large.peek()) / 2.0;
        }
        return small.peek();
    }
}
```

## 复杂度分析
- 时间：`addNum` 为 \(O(\log n)\)，`findMedian` 为 \(O(1)\)
- 空间：\(O(n)\)

## 总结（速记）
- 左大根堆、右小根堆；保持左边数量不少于右边且最多多 1。
