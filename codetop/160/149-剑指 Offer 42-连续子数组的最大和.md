# 剑指 Offer 42. 连续子数组的最大和

- 题号：剑指 Offer 42
- 难度：简单
- LeetCode：[连续子数组的最大和](https://leetcode.cn/problems/lian-xu-zi-shu-zu-de-zui-da-he-lcof/)

## 题目描述
返回数组的连续子数组最大和。

## 示例
- 示例  
输入：`nums = [-2,1,-3,4,-1,2,1,-5,4]`  
输出：`6`（`[4,-1,2,1]`）

## 最佳解法思路
- 思路1（推荐）：Kadane（动态规划）  
`cur` 表示“以当前位置结尾的最大子数组和”：`cur = max(nums[i], cur + nums[i])`。  
每步更新全局最大值 `ans`。

## Java 最佳实现

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int cur = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            cur = Math.max(nums[i], cur + nums[i]);
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
