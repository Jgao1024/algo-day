# 补充题2. 圆环回原点问题

- 题号：补充题2
- 难度：中等
- 题面链接：[圆环回原点问题](https://mp.weixin.qq.com/s/NZPaFsFrTybO3K3s7p7EVg)

## 题目描述
在一个有 `n` 个点的圆环上，从 0 出发，每一步只能走到相邻点（+1 或 -1，模 n）。走 `m` 步后回到 0 的方案数。

## 示例
- 示例  
`n = 10, m = 2`  
输出：`2`（顺时针两步 / 逆时针两步）

## 最佳解法思路
- 思路1（推荐）：DP（按步数转移）  
`dp[i][j]` 表示走 i 步到达点 j 的方案数：  
`dp[i][j] = dp[i-1][(j-1+n)%n] + dp[i-1][(j+1)%n]`。  
用一维数组滚动即可。

## Java 最佳实现

```java
class Solution {
    public long ways(int n, int m) {
        long[] dp = new long[n];
        dp[0] = 1;
        for (int step = 1; step <= m; step++) {
            long[] ndp = new long[n];
            for (int j = 0; j < n; j++) {
                int left = (j - 1 + n) % n;
                int right = (j + 1) % n;
                ndp[j] = dp[left] + dp[right];
            }
            dp = ndp;
        }
        return dp[0];
    }
}
```

## 复杂度分析
- 时间：\(O(nm)\)
- 空间：\(O(n)\)

## 总结（速记）
- 走到 j 只能来自 j 的左右相邻点，按步数滚动 DP。
