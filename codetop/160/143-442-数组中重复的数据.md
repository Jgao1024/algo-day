# 442. 数组中重复的数据

- 题号：442
- 难度：中等
- LeetCode：[数组中重复的数据](https://leetcode.cn/problems/find-all-duplicates-in-an-array/)

## 题目描述
给定一个长度为 `n` 的整数数组 `nums`，其中 `nums[i]` 在 `[1, n]` 范围内。

有些元素出现两次，有些出现一次。请找出所有出现两次的元素。

要求时间 \(O(n)\)，额外空间 \(O(1)\)（不计返回结果）。

## 示例
- 示例  
输入：`nums = [4,3,2,7,8,2,3,1]`  
输出：`[2,3]`

## 最佳解法思路
- 思路1（推荐）：原地标记（利用符号）  
因为值在 `1..n`，把每个值 `x` 映射到下标 `x-1`。  
遍历 `nums`：取 `x=abs(nums[i])`，若 `nums[x-1]` 已经是负数，说明 `x` 之前出现过，这次就是重复；否则把 `nums[x-1]` 取反做标记。

- 思路2：原地交换（把值放到对应位置）  
类似“循环排序”，最终看哪些位置不对即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            int x = Math.abs(nums[i]);
            int idx = x - 1;
            if (nums[idx] < 0) {
                ans.add(x);
            } else {
                nums[idx] = -nums[idx];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出）
