# 剑指 Offer 04. 二维数组中的查找

- 题号：剑指 Offer 04
- 难度：简单
- LeetCode：[二维数组中的查找](https://leetcode.cn/problems/er-wei-shu-zu-zhong-de-cha-zhao-lcof/)

## 题目描述
在二维数组中查找目标值 `target`。矩阵每行从左到右递增，每列从上到下递增。

## 示例
- 示例  
输入：  
`matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]`  
`target = 5`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：从右上角走  
从右上角 `(0, n-1)` 出发：  
若当前值大于 `target`，向左；若小于 `target`，向下。  
每步都能排除一行或一列，最多走 `m+n` 步。

## Java 最佳实现

```java
class Solution {
    public boolean findNumberIn2DArray(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return false;
        int m = matrix.length, n = matrix[0].length;
        int r = 0, c = n - 1;
        while (r < m && c >= 0) {
            int x = matrix[r][c];
            if (x == target) return true;
            if (x > target) c--;
            else r++;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)
