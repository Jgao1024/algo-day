# 225. 用队列实现栈

- 题号：225
- 难度：简单
- LeetCode：[用队列实现栈](https://leetcode.cn/problems/implement-stack-using-queues/)

## 题目描述
使用队列实现一个栈，支持 `push/pop/top/empty`。

## 示例
- 示例  
操作：`push(1), push(2), top(), pop(), empty()`  
输出：`2, 2, false`

## 最佳解法思路
- 思路1（推荐）：单队列旋转  
`push(x)` 先入队，然后把前面的 `size-1` 个元素依次出队再入队，相当于把新元素转到队头，这样 `pop/top` 都从队头取即可。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MyStack {
    private final Deque<Integer> q = new ArrayDeque<>();

    public MyStack() {
    }

    public void push(int x) {
        q.offer(x);
        int k = q.size() - 1;
        while (k-- > 0) q.offer(q.poll());
    }

    public int pop() {
        return q.poll();
    }

    public int top() {
        return q.peek();
    }

    public boolean empty() {
        return q.isEmpty();
    }
}
```

## 复杂度分析
- 时间：`push` 为 \(O(n)\)，`pop/top/empty` 为 \(O(1)\)
- 空间：\(O(n)\)

- 想让 `pop` 快，就在 `push` 时把新元素“转到队头”。
