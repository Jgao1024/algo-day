# 208. 实现 Trie (前缀树)

- 题号：208
- 难度：中等
- LeetCode：[实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/)

## 题目描述
请你实现 Trie（前缀树），包含：
- `insert(word)`：插入单词
- `search(word)`：查找单词是否存在
- `startsWith(prefix)`：查找是否存在以 prefix 为前缀的单词

## 示例
- 示例  
```
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // true
trie.search("app");     // false
trie.startsWith("app"); // true
trie.insert("app");
trie.search("app");     // true
```

## 最佳解法思路
- 思路1（推荐）：定长 children 数组  
每个节点保存 `children[26]` 和 `isEnd`。插入/查询就是沿着字符一路走，必要时创建节点。

- 思路2：HashMap children  
字符集更大时更省空间，但常数更大，本题通常用数组。

## Java 最佳实现

```java
class Trie {
    private static class Node {
        Node[] next = new Node[26];
        boolean end;
    }

    private final Node root = new Node();

    public Trie() {
    }

    public void insert(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.next[idx] == null) cur.next[idx] = new Node();
            cur = cur.next[idx];
        }
        cur.end = true;
    }

    public boolean search(String word) {
        Node node = walk(word);
        return node != null && node.end;
    }

    public boolean startsWith(String prefix) {
        return walk(prefix) != null;
    }

    private Node walk(String s) {
        Node cur = root;
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (cur.next[idx] == null) return null;
            cur = cur.next[idx];
        }
        return cur;
    }
}
```

## 复杂度分析
- 单次操作时间：\(O(L)\)（L 为字符串长度）
- 空间：取决于插入的字符总数（节点数）
