# 678. 有效的括号字符串

- 题号：678
- 难度：中等
- LeetCode：[有效的括号字符串](https://leetcode.cn/problems/valid-parenthesis-string/)

## 题目描述
字符串只包含 `'('`、`')'`、`'*'`，其中 `'*'` 可以当 `'('`、`')'` 或空串。判断是否能变成有效括号串。

## 示例
- 示例1  
输入：`s = "()"`  
输出：`true`

- 示例2  
输入：`s = "(*)"`  
输出：`true`

- 示例3  
输入：`s = "(*))"`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：贪心维护可行区间 \([low, high]\)  
`low`：最少可能的未匹配 `'('` 数；`high`：最多可能的未匹配 `'('` 数。  
遍历字符：  
- `'('`：`low++，high++`  
- `')'`：`low--，high--`  
- `'*'`：`low--，high++`（把 `*` 当 `)` 会减少， 当 `(` 会增加）  
每步 `low` 不能小于 0（小于就置 0），`high` 若小于 0 说明右括号太多直接 false。最后 `low==0` 才可行。

## Java 最佳实现

```java
class Solution {
    public boolean checkValidString(String s) {
        int low = 0, high = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                low++;
                high++;
            } else if (ch == ')') {
                low--;
                high--;
            } else {
                low--;
                high++;
            }
            if (high < 0) return false;
            if (low < 0) low = 0;
        }
        return low == 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 用区间 `[low, high]` 表示“未匹配左括号可能数量”，一路更新，最后 `low==0` 即可。
