# 450. 删除二叉搜索树中的节点

- 题号：450
- 难度：中等
- LeetCode：[删除二叉搜索树中的节点](https://leetcode.cn/problems/delete-node-in-a-bst/)

## 题目描述
在 BST 中删除值为 `key` 的节点，返回删除后的根节点。

## 示例
- 示例  
输入：`root = [5,3,6,2,4,null,7]`, `key = 3`  
输出：`[5,4,6,2,null,null,7]`（一种合法结果）

## 最佳解法思路
- 思路1（推荐）：递归定位 + 分类处理  
先用 BST 性质递归定位 `key`：  
若在左边就删左子树，右边就删右子树。  
找到节点后分三种：  
- 只有右子树：返回右子树  
- 只有左子树：返回左子树  
- 两个孩子：用“后继”（右子树最小）替换当前值，再删除右子树中的后继节点（或用前驱也可以）。

## Java 最佳实现

```java
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        if (root == null) return null;
        if (key < root.val) {
            root.left = deleteNode(root.left, key);
            return root;
        }
        if (key > root.val) {
            root.right = deleteNode(root.right, key);
            return root;
        }

        if (root.left == null) return root.right;
        if (root.right == null) return root.left;

        TreeNode s = root.right;
        while (s.left != null) s = s.left;
        root.val = s.val;
        root.right = deleteNode(root.right, s.val);
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)（h 为树高）
- 空间：\(O(h)\)（递归栈）

- 两个孩子就找后继（右子树最小）来顶替，再去右子树把后继删掉。
