# 10. 正则表达式匹配

- 题号：10
- 难度：困难
- LeetCode：[正则表达式匹配](https://leetcode.cn/problems/regular-expression-matching/)

## 题目描述
给你一个字符串 `s` 和一个字符规律 `p`，实现支持 `'.'` 和 `'*'` 的正则匹配。

- `'.'` 匹配任意单个字符  
- `'*'` 匹配前一个元素的 0 次或多次

匹配要覆盖整个字符串（不是部分匹配）。

## 示例
- 示例1  
输入：`s = "aa", p = "a"`  
输出：`false`

- 示例2  
输入：`s = "aa", p = "a*"`  
输出：`true`

- 示例3  
输入：`s = "ab", p = ".*"`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：DP  
`dp[i][j]` 表示 `s` 前 `i` 个字符是否能被 `p` 前 `j` 个字符匹配。  
转移：
1) 若 `p[j-1]` 不是 `*`：当前字符匹配（相等或 `.`）则 `dp[i][j]=dp[i-1][j-1]`  
2) 若 `p[j-1]` 是 `*`：两种情况取或
   - 匹配 0 次：`dp[i][j] |= dp[i][j-2]`
   - 匹配 >=1 次：若 `p[j-2]` 能匹配 `s[i-1]`，则 `dp[i][j] |= dp[i-1][j]`

初始化：`dp[0][0]=true`；空串与形如 `a*b*c*` 的模式可匹配：`dp[0][j]=dp[0][j-2]`（当 `p[j-1]=='*'`）。

## Java 最佳实现

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length();
        int n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;

        for (int j = 2; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];
            }
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char pc = p.charAt(j - 1);
                if (pc != '*') {
                    if (match(s.charAt(i - 1), pc)) {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                } else {
                    dp[i][j] = dp[i][j - 2];
                    char prev = p.charAt(j - 2);
                    if (match(s.charAt(i - 1), prev)) {
                        dp[i][j] |= dp[i - 1][j];
                    }
                }
            }
        }
        return dp[m][n];
    }

    private boolean match(char sc, char pc) {
        return pc == '.' || pc == sc;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)

## 总结（速记）
- 遇到 `*` 就分两种：0 次（删掉 `x*`）或 >=1 次（消耗 s 一位，p 不动）。
