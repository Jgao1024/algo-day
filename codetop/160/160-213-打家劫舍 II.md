# 213. 打家劫舍 II

- 题号：213
- 难度：中等
- LeetCode：[打家劫舍 II](https://leetcode.cn/problems/house-robber-ii/)

## 题目描述
房子围成一圈，相邻不能同时偷，求能偷到的最大金额。

## 示例
- 示例1  
输入：`nums = [2,3,2]`  
输出：`3`

- 示例2  
输入：`nums = [1,2,3,1]`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：拆成两个线性打家劫舍  
因为首尾相邻，不能同时选 `0` 和 `n-1`：  
答案 = `max(rob(0..n-2), rob(1..n-1))`。  
线性 `rob(l..r)` 用滚动 DP：`dp[i]=max(dp[i-1], dp[i-2]+nums[i])`。

## Java 最佳实现

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        return Math.max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }

    private int robRange(int[] nums, int l, int r) {
        int pre2 = 0, pre1 = 0;
        for (int i = l; i <= r; i++) {
            int cur = Math.max(pre1, pre2 + nums[i]);
            pre2 = pre1;
            pre1 = cur;
        }
        return pre1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
