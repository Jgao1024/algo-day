# 135. 分发糖果

- 题号：135
- 难度：困难
- LeetCode：[分发糖果](https://leetcode.cn/problems/candy/)

## 题目描述
有 `n` 个孩子站成一排，每个孩子有一个评分 `ratings[i]`。

你要给每个孩子至少 1 颗糖，并且：
- 如果 `ratings[i] > ratings[i-1]`，则 `candies[i] > candies[i-1]`
- 如果 `ratings[i] > ratings[i+1]`，则 `candies[i] > candies[i+1]`

返回最少需要的糖果数。

## 示例
- 示例1  
输入：`ratings = [1,0,2]`  
输出：`5`（2,1,2）

- 示例2  
输入：`ratings = [1,2,2]`  
输出：`4`（1,2,1）

## 最佳解法思路
- 思路1（推荐）：两次扫描  
第一次从左到右，保证“比左边高就多 1”：  
`left[i] = left[i-1] + 1`（若 `ratings[i] > ratings[i-1]`），否则 1。  
第二次从右到左，保证“比右边高就多 1”，并把两侧约束取最大：  
最终 `candies[i] = max(left[i], rightNeed)`，累加即答案。

- 思路2：单次扫描（更难）  
把评分变化看成上坡/下坡段，统计坡长，处理峰顶补偿。面试不如双扫描稳。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        int[] left = new int[n];
        Arrays.fill(left, 1);

        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                left[i] = left[i - 1] + 1;
            }
        }

        int ans = 0;
        int rightNeed = 1;
        for (int i = n - 1; i >= 0; i--) {
            if (i < n - 1 && ratings[i] > ratings[i + 1]) {
                rightNeed++;
            } else {
                rightNeed = 1;
            }
            ans += Math.max(left[i], rightNeed);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
