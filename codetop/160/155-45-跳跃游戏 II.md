# 45. 跳跃游戏 II

- 题号：45
- 难度：中等
- LeetCode：[跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)

## 题目描述
给定数组 `nums`，`nums[i]` 表示从 i 最多能跳的步数，求到达最后一个下标的最少跳跃次数。

## 示例
- 示例  
输入：`nums = [2,3,1,1,4]`  
输出：`2`（0->1->4）

## 最佳解法思路
- 思路1（推荐）：贪心分层（BFS 思想）  
维护当前这一步能覆盖到的最远边界 `end`，以及下一步能到的最远位置 `farthest`。  
扫描 i：更新 `farthest = max(farthest, i + nums[i])`。  
当 i 走到 `end`，说明当前层走完，步数 `steps++`，并把 `end = farthest`。

## Java 最佳实现

```java
class Solution {
    public int jump(int[] nums) {
        int end = 0;
        int farthest = 0;
        int steps = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);
            if (i == end) {
                steps++;
                end = farthest;
            }
        }
        return steps;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 一次扫描，遇到边界就“跳一步”，边界更新成下一步最远可达。
