# 440. 字典序的第K小数字

- 题号：440
- 难度：困难
- LeetCode：[字典序的第K小数字](https://leetcode.cn/problems/k-th-smallest-in-lexicographical-order/)

## 题目描述
给定整数 `n` 和 `k`，返回区间 `[1, n]` 中按字典序排序后的第 `k` 小的数字。

## 示例
- 示例1  
输入：`n = 13, k = 2`  
输出：`10`

- 示例2  
输入：`n = 1, k = 1`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：前缀树计数 + 贪心走字典序树  
把 `1..n` 看成一棵“字典序前缀树”（根下有 1~9，每个节点 `p` 的孩子是 `p*10..p*10+9`）。  
从 `cur=1` 开始，令 `k--`（当前就在第 1 个）。循环：
1) 计算 `cur` 这个前缀下有多少个数字 `steps`（即在字典序树中从 `cur` 到 `cur+1` 之间的节点数）  
2) 若 `steps <= k`：说明第 k 个不在当前前缀子树里，走到兄弟 `cur++`，并 `k -= steps`  
3) 否则：说明在子树里，向下走 `cur *= 10`，并 `k--`（走到子节点本身）

计数方法：设 `first=cur, next=cur+1`，在每一层累加  
`min(n+1, next) - first`，然后 `first*=10, next*=10`。

## Java 最佳实现

```java
class Solution {
    public int findKthNumber(int n, int k) {
        long cur = 1;
        k--;
        while (k > 0) {
            long steps = countSteps(n, cur, cur + 1);
            if (steps <= k) {
                cur++;
                k -= steps;
            } else {
                cur *= 10;
                k--;
            }
        }
        return (int) cur;
    }

    private long countSteps(int n, long first, long next) {
        long steps = 0;
        long limit = (long) n + 1;
        while (first <= n) {
            steps += Math.min(limit, next) - first;
            first *= 10;
            next *= 10;
        }
        return steps;
    }
}
```

## 复杂度分析
- 时间：外层每次要么下探一层，要么跨过一整棵子树；每次计数是 \(O(\log_{10} n)\)，整体约 \(O(\log^2 n)\) 量级
- 空间：\(O(1)\)
