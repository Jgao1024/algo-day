## 最佳解法思路
- 思路（推荐）：贪心累加所有正收益  
只要今天比昨天贵，就把差价加到答案里，相当于把所有上升段拆成若干次交易。

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices) {
        int ans = 0;
        for (int i = 1; i < prices.length; i++) {
            int diff = prices[i] - prices[i - 1];
            if (diff > 0) ans += diff;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
