## 最佳解法思路
- 思路（推荐）：双栈同步维护最小值  
数据栈正常入栈出栈；最小栈每一步都保存“当前最小值”，这样 `getMin()` 就是栈顶。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MinStack {
    private final Deque<Integer> stack = new ArrayDeque<>();
    private final Deque<Integer> minStack = new ArrayDeque<>();

    public MinStack() {
    }

    public void push(int val) {
        stack.push(val);
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            minStack.push(Math.min(minStack.peek(), val));
        }
    }

    public void pop() {
        stack.pop();
        minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

## 复杂度分析
- 时间：push/pop/top/getMin 都是 \(O(1)\)
- 空间：\(O(n)\)
