## 最佳解法思路
- 思路（推荐）：拒绝采样（把 rand7 变成 1..49）  
两次 rand7 组成 7 进制数：  
`num = (rand7() - 1) * 7 + rand7()`，均匀落在 1..49。  
只接受 1..40，映射到 1..10：`1 + (num - 1) % 10`。

## Java 最佳实现

```java
class Solution extends SolBase {
    public int rand10() {
        while (true) {
            int num = (rand7() - 1) * 7 + rand7(); // 1..49
            if (num <= 40) return 1 + (num - 1) % 10;
        }
    }
}
```
