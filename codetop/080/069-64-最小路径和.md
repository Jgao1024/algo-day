## 最佳解法思路
- 思路（推荐）：DP（滚动数组）  
只能向右/向下：  
`dp[j]` 表示到当前行第 j 列的最小路径和。  
转移：`dp[j] = min(上方 dp[j], 左侧 dp[j-1]) + grid[i][j]`。

## Java 最佳实现

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) {
                    dp[j] = grid[i][j];
                } else if (i == 0) {
                    dp[j] = dp[j - 1] + grid[i][j];
                } else if (j == 0) {
                    dp[j] = dp[j] + grid[i][j];
                } else {
                    dp[j] = Math.min(dp[j], dp[j - 1]) + grid[i][j];
                }
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
