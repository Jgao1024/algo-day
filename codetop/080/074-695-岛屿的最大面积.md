## 最佳解法思路
- 思路（推荐）：DFS/BFS 搜索连通块  
遍历网格，遇到陆地就做一次 DFS，把连通的陆地都“淹掉”（置 0），统计本次面积并更新最大值。

## Java 最佳实现

```java
class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) ans = Math.max(ans, dfs(grid, i, j));
            }
        }
        return ans;
    }

    private int dfs(int[][] grid, int i, int j) {
        int m = grid.length, n = grid[0].length;
        if (i < 0 || i >= m || j < 0 || j >= n) return 0;
        if (grid[i][j] == 0) return 0;
        grid[i][j] = 0;
        return 1
                + dfs(grid, i + 1, j)
                + dfs(grid, i - 1, j)
                + dfs(grid, i, j + 1)
                + dfs(grid, i, j - 1);
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)（最坏递归栈）

## 总结（速记）
- 网格连通块：遇到 1 就 DFS 一次，并把访问过的点置 0 防重。
