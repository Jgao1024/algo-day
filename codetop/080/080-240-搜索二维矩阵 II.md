## 最佳解法思路
- 思路（推荐）：从右上角开始“排除行/列”  
矩阵每行递增、每列递增。  
从右上角出发：
  - 当前值 > target：左移（排除当前列）
  - 当前值 < target：下移（排除当前行）
直到越界或找到目标。

## Java 最佳实现

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        int i = 0, j = n - 1;
        while (i < m && j >= 0) {
            int v = matrix[i][j];
            if (v == target) return true;
            if (v > target) j--;
            else i++;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(m + n)\)
- 空间：\(O(1)\)
