## 最佳解法思路
- 动态维护 up/down（推荐）  
`up`：以当前位置结尾，最后一次比较是“上升”的最长湍流长度；  
`down`：以当前位置结尾，最后一次比较是“下降”的最长湍流长度。  
遍历时：  
- 若 `a[i] > a[i-1]`：`up = down + 1`，`down = 1`  
- 若 `a[i] < a[i-1]`：`down = up + 1`，`up = 1`  
- 否则都置为 1。

## Java 最佳实现

```java
class Solution {
    public int maxTurbulenceSize(int[] arr) {
        if (arr.length == 0) return 0;
        int up = 1;
        int down = 1;
        int ans = 1;
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > arr[i - 1]) {
                up = down + 1;
                down = 1;
            } else if (arr[i] < arr[i - 1]) {
                down = up + 1;
                up = 1;
            } else {
                up = 1;
                down = 1;
            }
            ans = Math.max(ans, Math.max(up, down));
        }
        return ans;
    }
}
```

- 空间：\(O(1)\)
