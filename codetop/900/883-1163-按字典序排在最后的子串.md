## 最佳解法思路
- 双指针找最大后缀（推荐）  
这是“最大字典序后缀”问题，用类似 Duval/最大表示法的双指针：  
维护两个起点 `i`、`j`（`i<j`），以及比较偏移 `k`。  
- 若 `s[i+k] == s[j+k]`，`k++`  
- 若 `s[i+k] < s[j+k]`，说明 `i` 起点更小，`i = i + k + 1`  
- 若 `s[i+k] > s[j+k]`，说明 `j` 起点更小，`j = j + k + 1`  
每次更新后令 `k=0`，并保证 `i!=j`。最终答案是从 `min(i,j)` 的较大字典序起点开始的子串。

## Java 最佳实现

```java
class Solution {
    public String lastSubstring(String s) {
        int n = s.length();
        int i = 0, j = 1, k = 0;
        while (j + k < n) {
            char a = s.charAt(i + k);
            char b = s.charAt(j + k);
            if (a == b) {
                k++;
            } else if (a < b) {
                i = j;
                j = i + 1;
                k = 0;
            } else {
                j = j + k + 1;
                k = 0;
            }
        }
        return s.substring(i);
    }
}
```

- 空间：\(O(1)\)
