## 最佳解法思路
- 先求高度再定位（推荐）  
高度为 `h`，输出矩阵大小为 `h x (2^h - 1)`，全部初始化为 `""`。  
递归填充：`dfs(node, row, l, r)`，把当前节点放在中点 `mid=(l+r)/2`，左子树区间 `[l, mid-1]`，右子树区间 `[mid+1, r]`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<String>> printTree(TreeNode root) {
        int h = height(root);
        int w = (1 << h) - 1;

        List<List<String>> ans = new ArrayList<>();
        for (int i = 0; i < h; i++) {
            List<String> row = new ArrayList<>();
            for (int j = 0; j < w; j++) row.add("");
            ans.add(row);
        }

        fill(ans, root, 0, 0, w - 1);
        return ans;
    }

    private void fill(List<List<String>> ans, TreeNode node, int row, int l, int r) {
        if (node == null || l > r) return;
        int mid = (l + r) / 2;
        ans.get(row).set(mid, String.valueOf(node.val));
        fill(ans, node.left, row + 1, l, mid - 1);
        fill(ans, node.right, row + 1, mid + 1, r);
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        return 1 + Math.max(height(node.left), height(node.right));
    }
}
```

## 复杂度分析
- 时间：\(O(h \cdot 2^h)\)（初始化矩阵占主导）
- 空间：\(O(h \cdot 2^h)\)
