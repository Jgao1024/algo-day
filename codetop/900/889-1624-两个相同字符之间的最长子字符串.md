## 最佳解法思路
- 记录首次出现位置（推荐）  
遍历字符串，`first[c]` 记录字符第一次出现的下标。  
再次遇到同字符时，更新答案：`i - first[c] - 1`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        int[] first = new int[26];
        Arrays.fill(first, -1);
        int ans = -1;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == -1) first[c] = i;
            else ans = Math.max(ans, i - first[c] - 1);
        }
        return ans;
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
