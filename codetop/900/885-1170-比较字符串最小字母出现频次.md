## 最佳解法思路
- 预处理 queries 的频次并二分（推荐）  
定义 `f(s)`：字符串中最小字母出现的次数。  
先把 `words` 的 `f` 全部算出来并排序。  
对每个 `q`，算 `fq`，在排序数组里找第一个 `> fq` 的位置 `idx`，答案是 `len-idx`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int[] numSmallerByFrequency(String[] queries, String[] words) {
        int[] wf = new int[words.length];
        for (int i = 0; i < words.length; i++) wf[i] = f(words[i]);
        Arrays.sort(wf);

        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int qf = f(queries[i]);
            int idx = upperBound(wf, qf);
            ans[i] = wf.length - idx;
        }
        return ans;
    }

    private int f(String s) {
        char min = 'z';
        int cnt = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c < min) {
                min = c;
                cnt = 1;
            } else if (c == min) {
                cnt++;
            }
        }
        return cnt;
    }

    // first index with a[idx] > target
    private int upperBound(int[] a, int target) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (a[m] <= target) l = m + 1;
            else r = m;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：预处理 \(O(W\log W)\)，查询 \(O(Q\log W)\)
- 空间：\(O(W)\)
