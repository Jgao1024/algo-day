## 最佳解法思路
- 回溯 + 位掩码（推荐）  
把每个字符串转成 26 位 bitmask；若字符串内部有重复字符则直接丢弃。  
回溯时维护已使用字符集合 `usedMask`：如果 `(usedMask & mask)==0`，就可以拼接，并更新答案为 `bitcount(usedMask|mask)`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int maxLength(List<String> arr) {
        List<Integer> masks = new ArrayList<>();
        for (String s : arr) {
            int mask = 0;
            boolean ok = true;
            for (int i = 0; i < s.length(); i++) {
                int bit = 1 << (s.charAt(i) - 'a');
                if ((mask & bit) != 0) {
                    ok = false;
                    break;
                }
                mask |= bit;
            }
            if (ok) masks.add(mask);
        }
        return dfs(masks, 0, 0);
    }

    private int dfs(List<Integer> masks, int idx, int used) {
        int ans = Integer.bitCount(used);
        for (int i = idx; i < masks.size(); i++) {
            int m = masks.get(i);
            if ((used & m) != 0) continue;
            ans = Math.max(ans, dfs(masks, i + 1, used | m));
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(2^n)\)
- 空间：\(O(n)\)（递归栈）

- **把字符串压成 bitmask，回溯用 `used&mask==0` 判断能否拼接**。
