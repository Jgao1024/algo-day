## 最佳解法思路
- 余数计数（推荐）  
两首歌能整除 60 ⇔ `t1%60 + t2%60 == 0 (mod 60)`。  
遍历时维护 `cnt[r]`：已出现的余数为 `r` 的数量；当前余数 `r` 的互补是 `(60-r)%60`。

## Java 最佳实现

```java
class Solution {
    public int numPairsDivisibleBy60(int[] time) {
        long ans = 0;
        int[] cnt = new int[60];
        for (int t : time) {
            int r = t % 60;
            int need = (60 - r) % 60;
            ans += cnt[need];
            cnt[r]++;
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
