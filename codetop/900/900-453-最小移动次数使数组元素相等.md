## 最佳解法思路
- 转化（推荐）  
每次操作把 `n-1` 个数都 +1，等价于“选择 1 个数 -1”。  
要让所有数相等，最终相等值就是最小值 `min`，答案为：  
`sum(nums) - min * n`。

## Java 最佳实现

```java
class Solution {
    public int minMoves(int[] nums) {
        long sum = 0;
        int min = Integer.MAX_VALUE;
        for (int x : nums) {
            sum += x;
            if (x < min) min = x;
        }
        return (int) (sum - (long) min * nums.length);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- **“n-1 个 +1” ⇔ “1 个 -1”，所以对齐到最小值即可**。
