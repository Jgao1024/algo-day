## 最佳解法思路
- 预处理两两 AND 计数（推荐）  
先统计所有二元组 `(a,b)` 的 `a & b` 结果频次 `cnt[mask]`。  
再枚举第三个数 `c`，需要 `(a&b) & c == 0`，即 `mask` 必须是 `~c` 的子集。  
若值域是 16 位（本题常见约束 `0<=A[i]<2^16`），可以对所有 `mask` 枚举并累加满足 `(mask & c)==0` 的 `cnt[mask]`。

## Java 最佳实现

```java
class Solution {
    public int countTriplets(int[] nums) {
        int max = 1 << 16;
        int[] cnt = new int[max];
        for (int a : nums) {
            for (int b : nums) {
                cnt[a & b]++;
            }
        }

        int ans = 0;
        for (int c : nums) {
            for (int mask = 0; mask < max; mask++) {
                if ((mask & c) == 0) ans += cnt[mask];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 + n\cdot 2^{16})\)
- 空间：\(O(2^{16})\)

- **先把 `a&b` 的结果计数，再用 `(mask & c)==0` 累加**。
