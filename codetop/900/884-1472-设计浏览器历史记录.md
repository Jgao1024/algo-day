## 最佳解法思路
- 数组 + 指针（推荐）  
用 `list` 保存历史记录，`cur` 指向当前页面下标，`end` 指向历史有效末尾。  
- `visit(url)`: `cur++` 写入，更新 `end=cur`（覆盖前进历史）  
- `back(steps)`: `cur=max(0, cur-steps)`  
- `forward(steps)`: `cur=min(end, cur+steps)`

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class BrowserHistory {
    private final List<String> list = new ArrayList<>();
    private int cur = 0;
    private int end = 0;

    public BrowserHistory(String homepage) {
        list.add(homepage);
    }

    public void visit(String url) {
        cur++;
        if (cur == list.size()) list.add(url);
        else list.set(cur, url);
        end = cur;
    }

    public String back(int steps) {
        cur = Math.max(0, cur - steps);
        return list.get(cur);
    }

    public String forward(int steps) {
        cur = Math.min(end, cur + steps);
        return list.get(cur);
    }
}
```

## 复杂度分析
- 时间：每次操作 \(O(1)\)
- 空间：\(O(n)\)
