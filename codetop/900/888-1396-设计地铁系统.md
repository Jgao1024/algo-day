## 最佳解法思路
- 两张 HashMap（推荐）  
`in[id] = (startStation, startTime)` 记录进站信息；出站时用它算耗时。  
`stat[start#end] = (totalTime, count)` 统计某条线路的总耗时与次数，均摊时间为 `totalTime / count`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class UndergroundSystem {
    private final Map<Integer, CheckIn> in = new HashMap<>();
    private final Map<String, Stat> stat = new HashMap<>();

    public UndergroundSystem() {
    }

    public void checkIn(int id, String stationName, int t) {
        in.put(id, new CheckIn(stationName, t));
    }

    public void checkOut(int id, String stationName, int t) {
        CheckIn ci = in.remove(id);
        String key = ci.station + "#" + stationName;
        Stat s = stat.get(key);
        if (s == null) {
            s = new Stat();
            stat.put(key, s);
        }
        s.total += (t - ci.time);
        s.cnt++;
    }

    public double getAverageTime(String startStation, String endStation) {
        Stat s = stat.get(startStation + "#" + endStation);
        return (double) s.total / s.cnt;
    }

    private static class CheckIn {
        String station;
        int time;
        CheckIn(String station, int time) {
            this.station = station;
            this.time = time;
        }
    }

    private static class Stat {
        long total = 0;
        int cnt = 0;
    }
}
```

- 时间：每次操作 \(O(1)\)
- 空间：\(O(n)\)
