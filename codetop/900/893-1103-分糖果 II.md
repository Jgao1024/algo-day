## 最佳解法思路
- 模拟发放（推荐）  
从 1 开始依次给：第 \(i\) 次给 `min(candies, i)`，下标是 `((i-1) % num_people)`，直到糖果用完。

## Java 最佳实现

```java
class Solution {
    public int[] distributeCandies(int candies, int num_people) {
        int[] ans = new int[num_people];
        int give = 1;
        int idx = 0;
        while (candies > 0) {
            int g = Math.min(candies, give);
            ans[idx] += g;
            candies -= g;
            give++;
            idx++;
            if (idx == num_people) idx = 0;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{candies})\)（发放次数数量级）
- 空间：\(O(n)\)
