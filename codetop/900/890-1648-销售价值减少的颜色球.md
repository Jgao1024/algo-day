## 最佳解法思路
- 贪心按“层”卖（推荐）  
总是先卖当前价值最高的球。把 `inventory` 降序排序，把相同高度的颜色当一组。  
假设当前最高高度为 `cur`，下一高度为 `next`，组内颜色数为 `k`：  
- 如果订单数 `orders >= (cur-next)*k`，就把从 `cur` 降到 `next+1` 的整层都卖掉（等差数列求和）。  
- 否则只卖 `full = orders / k` 层，再卖 `rem = orders % k` 个值为 `cur-full` 的球。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int maxProfit(int[] inventory, int orders) {
        Arrays.sort(inventory);
        int n = inventory.length;
        long MOD = 1_000_000_007L;
        long ans = 0;

        int i = n - 1;
        long cur = inventory[i];
        long k = 0;

        while (orders > 0) {
            while (i >= 0 && inventory[i] == cur) {
                k++;
                i--;
            }
            long next = (i >= 0) ? inventory[i] : 0;
            long delta = cur - next;
            long canSell = delta * k;

            if (orders >= canSell) {
                ans = (ans + k * sum(next + 1, cur)) % MOD;
                orders -= (int) canSell;
                cur = next;
            } else {
                long full = orders / k;
                long rem = orders % k;
                long low = cur - full + 1;
                ans = (ans + k * sum(low, cur)) % MOD;
                ans = (ans + rem * (cur - full)) % MOD;
                break;
            }
        }
        return (int) ans;
    }

    private long sum(long l, long r) {
        long cnt = r - l + 1;
        return (l + r) * cnt / 2;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（排序额外空间忽略）
