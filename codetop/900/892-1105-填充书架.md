## 最佳解法思路
- DP（推荐）  
`dp[i]` 表示摆放前 `i` 本书的最小总高度。  
枚举最后一层放哪些书：从 `i` 往前放，累加宽度不超过 `shelfWidth`，这一层高度取最大书高，转移：  
`dp[i] = min(dp[j-1] + maxHeight(j..i))`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minHeightShelves(int[][] books, int shelfWidth) {
        int n = books.length;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, 1 << 30);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            int w = 0;
            int h = 0;
            for (int j = i; j >= 1; j--) {
                w += books[j - 1][0];
                if (w > shelfWidth) break;
                h = Math.max(h, books[j - 1][1]);
                dp[i] = Math.min(dp[i], dp[j - 1] + h);
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)

- **最后一层从 i 往前试，宽度不超就更新 `dp[i]`**。
