## 最佳解法思路
- DP（推荐）  
设 `dp[i][c][t]`：涂到第 `i` 个房子（0-based），第 `i` 个颜色为 `c`，形成 `t` 个街区的最小花费。  
转移：从上一个颜色 `pc` 来：  
- 若 `pc==c`，街区数不变  
- 否则 `t+1`  
注意：若 `houses[i]!=0`，颜色固定且该房子花费为 0；否则花费为 `cost[i][c-1]`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minCost(int[] houses, int[][] cost, int m, int n, int target) {
        long INF = (long) 1e18;
        long[][] prev = new long[n + 1][target + 1];
        for (int c = 0; c <= n; c++) Arrays.fill(prev[c], INF);

        if (houses[0] != 0) {
            prev[houses[0]][1] = 0;
        } else {
            for (int c = 1; c <= n; c++) {
                prev[c][1] = cost[0][c - 1];
            }
        }

        for (int i = 1; i < m; i++) {
            long[][] cur = new long[n + 1][target + 1];
            for (int c = 0; c <= n; c++) Arrays.fill(cur[c], INF);

            for (int c = 1; c <= n; c++) {
                if (houses[i] != 0 && houses[i] != c) continue;
                long paint = (houses[i] == 0) ? cost[i][c - 1] : 0;

                for (int pc = 1; pc <= n; pc++) {
                    for (int t = 1; t <= target; t++) {
                        long val = prev[pc][t];
                        if (val >= INF) continue;
                        int nt = t + ((pc == c) ? 0 : 1);
                        if (nt > target) continue;
                        cur[c][nt] = Math.min(cur[c][nt], val + paint);
                    }
                }
            }

            prev = cur;
        }

        long ans = INF;
        for (int c = 1; c <= n; c++) {
            ans = Math.min(ans, prev[c][target]);
        }
        return ans >= INF ? -1 : (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m \cdot n^2 \cdot target)\)
- 空间：\(O(n \cdot target)\)
