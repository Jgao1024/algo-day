## 最佳解法思路
- 找规律（推荐）  
从 \(N\ge 5\) 开始，结果只与 `N%4` 有关：  
- `N%4==0`：`N+1`  
- `N%4==1`：`N+2`  
- `N%4==2`：`N+2`  
- `N%4==3`：`N-1`  
小值直接算：`1->1, 2->2, 3->6, 4->7`。

## Java 最佳实现

```java
class Solution {
    public int clumsy(int n) {
        if (n == 1) return 1;
        if (n == 2) return 2;
        if (n == 3) return 6;
        if (n == 4) return 7;
        int r = n % 4;
        if (r == 0) return n + 1;
        if (r == 1) return n + 2;
        if (r == 2) return n + 2;
        return n - 1;
    }
}
```
