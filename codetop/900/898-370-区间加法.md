## 最佳解法思路
- 差分数组（推荐）  
对每次更新 `[l, r, inc]`：  
`diff[l] += inc`，`diff[r+1] -= inc`（若 `r+1` 未越界）。  
最后对 `diff` 做前缀和得到最终数组。

## Java 最佳实现

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        int[] diff = new int[length + 1];
        for (int[] u : updates) {
            int l = u[0], r = u[1], inc = u[2];
            diff[l] += inc;
            if (r + 1 < length) diff[r + 1] -= inc;
        }

        int[] ans = new int[length];
        int cur = 0;
        for (int i = 0; i < length; i++) {
            cur += diff[i];
            ans[i] = cur;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(length + m)\)
- 空间：\(O(length)\)
