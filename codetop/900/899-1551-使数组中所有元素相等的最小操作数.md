## 最佳解法思路
- 数学公式（推荐）  
数组是 `[1,3,5,...,2n-1]`，每次操作让一个元素 `+1`、另一个 `-1`。  
最小操作次数等于把前一半“搬到”后一半所需的总差值，结果为：  
\[
\left\lfloor \frac{n^2}{4} \right\rfloor
\]

## Java 最佳实现

```java
class Solution {
    public int minOperations(int n) {
        long x = n;
        return (int) (x * x / 4);
    }
}
```
