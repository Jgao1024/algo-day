## 最佳解法思路
- 反向贪心：从 `target` 变回 `startValue`
  - 当 `target > startValue`：
    - `target` 为奇数：只能 `target++`（对应正向的 `-1`）
    - `target` 为偶数：`target /= 2`（对应正向的 `*2`）
  - 最后若 `target < startValue`，只能再做 `startValue - target` 次 `-1`

## Java 最佳实现

```java
class Solution {
    public int brokenCalc(int startValue, int target) {
        int ans = 0;
        while (target > startValue) {
            if ((target & 1) == 1) target++;
            else target >>= 1;
            ans++;
        }
        return ans + (startValue - target);
    }
}
```

## 复杂度分析
- 时间：\(O(\log target)\)
- 空间：\(O(1)\)
