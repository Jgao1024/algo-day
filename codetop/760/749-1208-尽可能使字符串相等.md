## 最佳解法思路
- 滑动窗口：
  - 把每个位置的修改代价 `cost[i] = abs(s[i]-t[i])`
  - 维护窗口 `[l..r]` 的总代价 `sum`，若 `sum > maxCost` 就不断右移 `l` 直到满足
  - 过程中更新最大窗口长度

## Java 最佳实现

```java
class Solution {
    public int equalSubstring(String s, String t, int maxCost) {
        int n = s.length();
        int l = 0;
        int sum = 0;
        int ans = 0;
        for (int r = 0; r < n; r++) {
            sum += Math.abs(s.charAt(r) - t.charAt(r));
            while (sum > maxCost) {
                sum -= Math.abs(s.charAt(l) - t.charAt(l));
                l++;
            }
            ans = Math.max(ans, r - l + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
