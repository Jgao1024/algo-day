## 最佳解法思路
- DP：
  - `dp[i]` 表示走到第 `i` 阶的方法数
  - 转移：`dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`，取模 \(10^9+7\)
  - 用滚动变量把空间降到 \(O(1)\)

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int waysToStep(int n) {
        if (n == 0) return 1;
        if (n == 1) return 1;
        if (n == 2) return 2;
        long a = 1; // dp[0]
        long b = 1; // dp[1]
        long c = 2; // dp[2]
        for (int i = 3; i <= n; i++) {
            long d = (a + b + c) % MOD;
            a = b;
            b = c;
            c = d;
        }
        return (int) c;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
