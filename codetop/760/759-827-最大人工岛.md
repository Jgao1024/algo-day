## 最佳解法思路
- 先给每个岛屿染色编号并计算面积，再尝试把一个 0 变成 1：
  - 第一次遍历：把每个连通块（岛屿）用 id（从 2 开始）标记，记录 `area[id]`
  - 第二次遍历：对每个 0，收集它四邻的不同岛屿 id，面积和 = 1 + sum(area[id])
  - 取最大；若原网格没有 0，则答案是 `n*n`

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private static final int[] DX = {1, -1, 0, 0};
    private static final int[] DY = {0, 0, 1, -1};

    public int largestIsland(int[][] grid) {
        int n = grid.length;
        int[] area = new int[n * n + 2];
        int id = 2;
        int best = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 1) continue;
                int a = paint(grid, i, j, id);
                area[id] = a;
                best = Math.max(best, a);
                id++;
            }
        }

        boolean hasZero = false;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 0) continue;
                hasZero = true;
                int sum = 1;
                int a = -1, b = -1, c = -1, d = -1;
                for (int k = 0; k < 4; k++) {
                    int x = i + DX[k], y = j + DY[k];
                    if (x < 0 || x >= n || y < 0 || y >= n) continue;
                    int nid = grid[x][y];
                    if (nid <= 1) continue;
                    if (nid == a || nid == b || nid == c || nid == d) continue;
                    if (a == -1) a = nid;
                    else if (b == -1) b = nid;
                    else if (c == -1) c = nid;
                    else d = nid;
                    sum += area[nid];
                }
                best = Math.max(best, sum);
            }
        }

        return hasZero ? best : n * n;
    }

    private int paint(int[][] grid, int si, int sj, int id) {
        int n = grid.length;
        Deque<int[]> st = new ArrayDeque<>();
        st.push(new int[]{si, sj});
        grid[si][sj] = id;
        int cnt = 0;
        while (!st.isEmpty()) {
            int[] cur = st.pop();
            cnt++;
            int i = cur[0], j = cur[1];
            for (int k = 0; k < 4; k++) {
                int x = i + DX[k], y = j + DY[k];
                if (x < 0 || x >= n || y < 0 || y >= n) continue;
                if (grid[x][y] != 1) continue;
                grid[x][y] = id;
                st.push(new int[]{x, y});
            }
        }
        return cnt;
    }
}
```

- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)（栈/队列最坏）
