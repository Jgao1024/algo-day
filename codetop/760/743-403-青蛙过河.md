## 最佳解法思路
- DP（位置 -> 可达步长集合）：
  - 用 `map[pos]` 存储能跳到该石头的所有步长 `k`
  - 初始 `map[0]` 有 `0`
  - 对每个石头位置 `p`，遍历它的每个 `k`，尝试 `k-1,k,k+1`（>0）跳到 `p+nk`，若存在该石头就把 `nk` 加入 `map[p+nk]`
  - 最后看终点石头的集合是否非空

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public boolean canCross(int[] stones) {
        Map<Integer, Set<Integer>> map = new HashMap<>();
        for (int s : stones) map.put(s, new HashSet<>());
        map.get(0).add(0);

        int target = stones[stones.length - 1];
        for (int p : stones) {
            Set<Integer> ks = map.get(p);
            for (int k : ks) {
                for (int nk = k - 1; nk <= k + 1; nk++) {
                    if (nk <= 0) continue;
                    int np = p + nk;
                    if (np == target) return true;
                    if (map.containsKey(np)) {
                        map.get(np).add(nk);
                    }
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：最坏约 \(O(n^2)\)
- 空间：最坏约 \(O(n^2)\)
