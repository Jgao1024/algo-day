## 最佳解法思路
- 并查集把同义词合并：
  - 把 `names` 里的名字、`synonyms` 里出现的名字都映射成 id
  - `union(a,b)` 时让字典序更小的名字做根，方便输出
  - 统计每个根的总次数（只累加 `names` 中出现的次数）
  - 输出形如 `"root(sum)"`

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    static class UF {
        int[] p;
        String[] name;

        UF(int n, String[] name) {
            this.p = new int[n];
            this.name = name;
            for (int i = 0; i < n; i++) p[i] = i;
        }

        int find(int x) {
            if (p[x] != x) p[x] = find(p[x]);
            return p[x];
        }

        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (name[pa].compareTo(name[pb]) <= 0) {
                p[pb] = pa;
            } else {
                p[pa] = pb;
            }
        }
    }

    public String[] trulyMostPopular(String[] names, String[] synonyms) {
        Map<String, Integer> id = new HashMap<>();

        for (String s : names) {
            String nm = parseName(s);
            if (!id.containsKey(nm)) id.put(nm, id.size());
        }
        for (String syn : synonyms) {
            String[] ab = parsePair(syn);
            if (!id.containsKey(ab[0])) id.put(ab[0], id.size());
            if (!id.containsKey(ab[1])) id.put(ab[1], id.size());
        }

        String[] idName = new String[id.size()];
        for (Map.Entry<String, Integer> e : id.entrySet()) {
            idName[e.getValue()] = e.getKey();
        }

        UF uf = new UF(id.size(), idName);
        for (String syn : synonyms) {
            String[] ab = parsePair(syn);
            uf.union(id.get(ab[0]), id.get(ab[1]));
        }

        long[] cnt = new long[id.size()];
        for (String s : names) {
            String nm = parseName(s);
            int c = parseCount(s);
            int root = uf.find(id.get(nm));
            cnt[root] += c;
        }

        List<String> ans = new ArrayList<>();
        for (int i = 0; i < cnt.length; i++) {
            if (cnt[i] == 0) continue;
            int root = uf.find(i);
            if (root != i) continue;
            ans.add(idName[i] + "(" + cnt[i] + ")");
        }
        return ans.toArray(new String[0]);
    }

    private String parseName(String s) {
        int idx = s.indexOf('(');
        return s.substring(0, idx);
    }

    private int parseCount(String s) {
        int l = s.indexOf('(');
        int r = s.indexOf(')');
        return Integer.parseInt(s.substring(l + 1, r));
    }

    private String[] parsePair(String s) {
        int comma = s.indexOf(',');
        String a = s.substring(1, comma);
        String b = s.substring(comma + 1, s.length() - 1);
        return new String[]{a, b};
    }
}
```

- 时间：并查集合并近似 \(O(N \alpha(N))\)
- 空间：\(O(N)\)
