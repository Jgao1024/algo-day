## 最佳解法思路
- 统计连续段长度：
  - `prev` 记录上一个连续段长度，`cur` 记录当前段长度
  - 每遇到字符变化，就把 `ans += min(prev, cur)`，并更新 `prev = cur, cur = 1`
  - 最后再加一次 `min(prev, cur)`

## Java 最佳实现

```java
class Solution {
    public int countBinarySubstrings(String s) {
        int prev = 0;
        int cur = 1;
        int ans = 0;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == s.charAt(i - 1)) {
                cur++;
            } else {
                ans += Math.min(prev, cur);
                prev = cur;
                cur = 1;
            }
        }
        ans += Math.min(prev, cur);
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
