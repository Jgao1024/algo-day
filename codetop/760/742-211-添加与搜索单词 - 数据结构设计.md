## 最佳解法思路
- Trie（前缀树）：
  - `addWord`：按字符插入
  - `search`：遇到 `.` 时枚举 26 个分支递归；否则走对应子节点

## Java 最佳实现

```java
class WordDictionary {
    static class Node {
        Node[] next = new Node[26];
        boolean end;
    }

    private final Node root = new Node();

    public WordDictionary() {
    }

    public void addWord(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.next[idx] == null) cur.next[idx] = new Node();
            cur = cur.next[idx];
        }
        cur.end = true;
    }

    public boolean search(String word) {
        return dfs(word, 0, root);
    }

    private boolean dfs(String w, int i, Node node) {
        if (node == null) return false;
        if (i == w.length()) return node.end;
        char c = w.charAt(i);
        if (c == '.') {
            for (int k = 0; k < 26; k++) {
                if (node.next[k] != null && dfs(w, i + 1, node.next[k])) return true;
            }
            return false;
        } else {
            return dfs(w, i + 1, node.next[c - 'a']);
        }
    }
}
```

## 复杂度分析
- 时间：`addWord` \(O(L)\)，`search` 最坏 \(O(26^d)\)（`d` 为 `.` 个数）
- 空间：\(O(\sum L)\)
