## 最佳解法思路
- 双向链表 + 哈希：
  - 链表节点表示一个计数 `cnt`，节点里维护该计数下的所有 key（HashSet）
  - `key -> node` 用 HashMap 定位当前 key 的节点
  - `inc/dec` 时把 key 在相邻计数节点之间移动，必要时插入/删除计数节点
  - `getMaxKey/getMinKey` 分别取尾/头的 key

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class AllOne {
    static class Node {
        int cnt;
        Node prev;
        Node next;
        Set<String> keys = new HashSet<>();

        Node(int cnt) {
            this.cnt = cnt;
        }
    }

    private final Node head;
    private final Node tail;
    private final Map<String, Node> map = new HashMap<>();

    public AllOne() {
        head = new Node(0);
        tail = new Node(0);
        head.next = tail;
        tail.prev = head;
    }

    public void inc(String key) {
        if (!map.containsKey(key)) {
            Node first = head.next;
            if (first != tail && first.cnt == 1) {
                first.keys.add(key);
                map.put(key, first);
            } else {
                Node node = new Node(1);
                node.keys.add(key);
                insertAfter(head, node);
                map.put(key, node);
            }
            return;
        }

        Node cur = map.get(key);
        Node nxt = cur.next;
        int newCnt = cur.cnt + 1;
        if (nxt != tail && nxt.cnt == newCnt) {
            nxt.keys.add(key);
            map.put(key, nxt);
        } else {
            Node node = new Node(newCnt);
            node.keys.add(key);
            insertAfter(cur, node);
            map.put(key, node);
        }

        cur.keys.remove(key);
        if (cur.keys.isEmpty()) remove(cur);
    }

    public void dec(String key) {
        Node cur = map.get(key);
        if (cur == null) return;

        if (cur.cnt == 1) {
            cur.keys.remove(key);
            map.remove(key);
            if (cur.keys.isEmpty()) remove(cur);
            return;
        }

        Node pre = cur.prev;
        int newCnt = cur.cnt - 1;
        if (pre != head && pre.cnt == newCnt) {
            pre.keys.add(key);
            map.put(key, pre);
        } else {
            Node node = new Node(newCnt);
            node.keys.add(key);
            insertAfter(pre, node);
            map.put(key, node);
        }

        cur.keys.remove(key);
        if (cur.keys.isEmpty()) remove(cur);
    }

    public String getMaxKey() {
        if (tail.prev == head) return "";
        return tail.prev.keys.iterator().next();
    }

    public String getMinKey() {
        if (head.next == tail) return "";
        return head.next.keys.iterator().next();
    }

    private void insertAfter(Node p, Node node) {
        Node n = p.next;
        p.next = node;
        node.prev = p;
        node.next = n;
        n.prev = node;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\)
- 空间：\(O(N)\)
