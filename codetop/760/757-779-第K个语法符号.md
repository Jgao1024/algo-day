## 最佳解法思路
- 规律：第 `k` 个符号等于 `(k-1)` 的二进制 1 的个数的奇偶性：
  - 1 的个数为偶数 -> 0
  - 1 的个数为奇数 -> 1

## Java 最佳实现

```java
class Solution {
    public int kthGrammar(int n, int k) {
        return Integer.bitCount(k - 1) & 1;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
