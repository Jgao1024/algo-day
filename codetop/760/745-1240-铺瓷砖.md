## 最佳解法思路
- DFS + 剪枝（用“每列已填高度”描述状态）：
  - 用数组 `h[]` 表示每一列当前已铺到的高度（0..m），目标是全部到 `m`
  - 每次选高度最小的列 `pos`，在 `(minHeight, pos)` 放一个尽量大的正方形（边长 `k`），要求：
    - `pos..pos+k-1` 这些列的高度都等于 `minHeight`
    - `minHeight + k <= m`
  - 放置后把这些列高度 `+k`，递归搜索最小块数
  - 用全局最优 `best` 剪枝：当前块数已 >= best 直接回退

## Java 最佳实现

```java
class Solution {
    private int m;
    private int n;
    private int best;

    public int tilingRectangle(int n, int m) {
        this.m = Math.max(m, n);
        this.n = Math.min(m, n);
        this.best = this.m * this.n;
        int[] h = new int[this.n];
        dfs(h, 0);
        return best;
    }

    private void dfs(int[] h, int used) {
        if (used >= best) return;

        int minH = Integer.MAX_VALUE;
        int pos = -1;
        for (int i = 0; i < n; i++) {
            if (h[i] < minH) {
                minH = h[i];
                pos = i;
            }
        }
        if (minH == m) {
            best = Math.min(best, used);
            return;
        }

        int maxK = 1;
        while (pos + maxK <= n && h[pos + maxK - 1] == minH && minH + maxK <= m) {
            maxK++;
        }
        maxK--;

        for (int k = maxK; k >= 1; k--) {
            boolean ok = true;
            for (int i = pos; i < pos + k; i++) {
                if (h[i] != minH) {
                    ok = false;
                    break;
                }
            }
            if (!ok) continue;

            for (int i = pos; i < pos + k; i++) h[i] += k;
            dfs(h, used + 1);
            for (int i = pos; i < pos + k; i++) h[i] -= k;
        }
    }
}
```

- 空间：\(O(n)\)
