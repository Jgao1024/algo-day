## 最佳解法思路
- 两次扫描原地处理：
  - 先统计“虚拟扩展后”的长度 `len`（遇到 0 多占一位）
  - 再从右往左写回到原数组：每次写 `arr[i]` 到 `--len` 位置，若是 0 再额外写一个 0

## Java 最佳实现

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        int n = arr.length;
        int len = 0;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 0) len += 2;
            else len += 1;
        }

        for (int i = n - 1; i >= 0; i--) {
            if (arr[i] == 0) {
                if (--len < n) arr[len] = 0;
                if (--len < n) arr[len] = 0;
            } else {
                if (--len < n) arr[len] = arr[i];
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
