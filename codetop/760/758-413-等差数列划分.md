## 最佳解法思路
- DP（统计以 `i` 结尾的等差子数组个数）：
  - 若 `nums[i]-nums[i-1] == nums[i-1]-nums[i-2]`，则 `cur = cur + 1`，答案加 `cur`
  - 否则 `cur = 0`

## Java 最佳实现

```java
class Solution {
    public int numberOfArithmeticSlices(int[] nums) {
        if (nums.length < 3) return 0;
        int cur = 0;
        int ans = 0;
        for (int i = 2; i < nums.length; i++) {
            if (nums[i] - nums[i - 1] == nums[i - 1] - nums[i - 2]) {
                cur++;
                ans += cur;
            } else {
                cur = 0;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
