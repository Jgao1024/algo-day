## 最佳解法思路
- 贪心 + 树状数组（Fenwick）：
  - 预先记录每个数字 0..9 在字符串中的出现位置队列
  - 从左到右构造答案：每一位尝试从小到大选数字 `d`
    - 取该数字最靠前的位置 `pos`
    - 当前它在“删掉前面已选字符”后的下标是 `pos - removedBefore(pos)`
    - 需要交换次数 `need = (pos - removedBefore(pos)) - i`
    - 若 `need <= k`，就选它：更新 `k -= need`，并在 Fenwick 标记 `pos` 已使用

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    static class BIT {
        int n;
        int[] bit;

        BIT(int n) {
            this.n = n;
            this.bit = new int[n + 1];
        }

        void add(int i, int delta) {
            for (int x = i; x <= n; x += x & -x) bit[x] += delta;
        }

        int sum(int i) {
            int s = 0;
            for (int x = i; x > 0; x -= x & -x) s += bit[x];
            return s;
        }
    }

    public String minInteger(String num, int k) {
        int n = num.length();
        Deque<Integer>[] pos = new Deque[10];
        for (int d = 0; d < 10; d++) pos[d] = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            pos[num.charAt(i) - '0'].addLast(i + 1); // 1-based
        }

        BIT bit = new BIT(n);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            for (int d = 0; d <= 9; d++) {
                if (pos[d].isEmpty()) continue;
                int p = pos[d].peekFirst();
                int removed = bit.sum(p);
                int curIndex = (p - 1) - removed;
                int need = curIndex - i;
                if (need <= k) {
                    k -= need;
                    sb.append((char) ('0' + d));
                    bit.add(p, 1);
                    pos[d].pollFirst();
                    break;
                }
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot 10 \cdot \log n)\)
- 空间：\(O(n)\)
