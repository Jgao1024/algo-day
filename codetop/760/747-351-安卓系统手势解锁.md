## 最佳解法思路
- 回溯 + 跳跃限制：
  - 预先构建 `skip[a][b]`：从 `a` 到 `b` 若必须经过某个中间点 `c`，则 `skip[a][b]=c`，否则为 0
  - DFS 枚举下一步 `nxt`：若 `skip[cur][nxt]==0` 或中间点已访问，则可走
  - 用对称性加速：1/3/7/9 相同，2/4/6/8 相同，5 单独

## Java 最佳实现

```java
class Solution {
    private int[][] skip = new int[10][10];
    private boolean[] vis = new boolean[10];

    public int numberOfPatterns(int m, int n) {
        buildSkip();
        int ans = 0;
        ans += dfs(1, 1, m, n) * 4;
        ans += dfs(2, 1, m, n) * 4;
        ans += dfs(5, 1, m, n);
        return ans;
    }

    private void buildSkip() {
        skip[1][3] = skip[3][1] = 2;
        skip[1][7] = skip[7][1] = 4;
        skip[3][9] = skip[9][3] = 6;
        skip[7][9] = skip[9][7] = 8;
        skip[1][9] = skip[9][1] = 5;
        skip[3][7] = skip[7][3] = 5;
        skip[4][6] = skip[6][4] = 5;
        skip[2][8] = skip[8][2] = 5;
        skip[7][3] = skip[3][7] = 5;
        skip[9][1] = skip[1][9] = 5;
    }

    private int dfs(int cur, int len, int m, int n) {
        vis[cur] = true;
        int ans = 0;
        if (len >= m) ans++;
        if (len < n) {
            for (int nxt = 1; nxt <= 9; nxt++) {
                if (vis[nxt]) continue;
                int mid = skip[cur][nxt];
                if (mid == 0 || vis[mid]) {
                    ans += dfs(nxt, len + 1, m, n);
                }
            }
        }
        vis[cur] = false;
        return ans;
    }
}
```

## 复杂度分析
- 时间：回溯枚举（常数规模 9）
- 空间：\(O(1)\)
