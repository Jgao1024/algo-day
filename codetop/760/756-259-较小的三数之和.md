## 最佳解法思路
- 排序 + 双指针：
  - 固定第一个数 `i`，对剩余区间用双指针 `l/r`
  - 若 `nums[i] + nums[l] + nums[r] < target`，则对当前 `l`，所有 `l+1..r` 都满足，计数加 `r-l`，然后 `l++`
  - 否则 `r--`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        int ans = 0;
        for (int i = 0; i < n - 2; i++) {
            int l = i + 1, r = n - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < target) {
                    ans += (r - l);
                    l++;
                } else {
                    r--;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)（不算排序）
