# 1401. 圆和矩形是否有重叠

- 题号：1401
- 难度：中等
- LeetCode：[圆和矩形是否有重叠](https://leetcode.cn/problems/circle-and-rectangle-overlapping/)

## 题目描述
给定圆心 `(xCenter,yCenter)`、半径 `radius`，以及轴对齐矩形的左下 `(x1,y1)`、右上 `(x2,y2)`，判断圆和矩形是否有重叠（相交或相切）。

## 示例
- `radius=1, xCenter=0, yCenter=0, x1=1, y1=-1, x2=3, y2=1` -> `true`

## 最佳解法思路
- 找到矩形中距离圆心最近的点 `(cx,cy)`：
  - `cx = clamp(xCenter, x1, x2)`
  - `cy = clamp(yCenter, y1, y2)`
- 计算圆心到该点距离平方 `dx^2+dy^2`，若 `<= r^2` 则重叠。

## Java 最佳实现

```java
class Solution {
    public boolean checkOverlap(int radius, int xCenter, int yCenter,
                                int x1, int y1, int x2, int y2) {
        int cx = clamp(xCenter, x1, x2);
        int cy = clamp(yCenter, y1, y2);
        long dx = (long) xCenter - cx;
        long dy = (long) yCenter - cy;
        return dx * dx + dy * dy <= (long) radius * radius;
    }

    private int clamp(int x, int lo, int hi) {
        if (x < lo) return lo;
        if (x > hi) return hi;
        return x;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
