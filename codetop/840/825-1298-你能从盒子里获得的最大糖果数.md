# 1298. 你能从盒子里获得的最大糖果数

- 题号：1298
- 难度：困难
- LeetCode：[你能从盒子里获得的最大糖果数](https://leetcode.cn/problems/maximum-candies-you-can-get-from-boxes/)

## 题目描述
有 n 个盒子。你一开始拥有一些盒子 `initialBoxes`，每个盒子可能是开着的（`status[i]=1`）或锁着的（`status[i]=0`）。

打开盒子 i 后可以得到：
- `candies[i]` 颗糖
- 一些钥匙 `keys[i]`（可以打开对应盒子）
- 一些盒子 `containedBoxes[i]`（加入到你拥有的盒子集合）

求你最多能获得多少糖果。

## 示例
见题面链接。

## 最佳解法思路
- BFS：维护“已拥有盒子”“已获得钥匙”“已打开”。
- 只要某个盒子已拥有且可打开（status=1 或已有钥匙），就入队打开。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int maxCandies(int[] status, int[] candies, int[][] keys, int[][] containedBoxes, int[] initialBoxes) {
        int n = status.length;
        boolean[] hasBox = new boolean[n];
        boolean[] hasKey = new boolean[n];
        boolean[] opened = new boolean[n];

        Queue<Integer> q = new ArrayDeque<>();
        for (int b : initialBoxes) {
            hasBox[b] = true;
            if (status[b] == 1) {
                q.offer(b);
            }
        }

        int ans = 0;
        while (!q.isEmpty()) {
            int b = q.poll();
            if (opened[b]) {
                continue;
            }
            if (status[b] == 0 && !hasKey[b]) {
                continue;
            }

            opened[b] = true;
            ans += candies[b];

            for (int k : keys[b]) {
                if (!hasKey[k]) {
                    hasKey[k] = true;
                }
                status[k] = 1;
                if (hasBox[k] && !opened[k]) {
                    q.offer(k);
                }
            }

            for (int nb : containedBoxes[b]) {
                if (!hasBox[nb]) {
                    hasBox[nb] = true;
                }
                if ((status[nb] == 1 || hasKey[nb]) && !opened[nb]) {
                    q.offer(nb);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n + \text{keys总数} + \text{contained总数})\)
- 空间：\(O(n)\)
