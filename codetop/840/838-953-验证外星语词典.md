# 953. 验证外星语词典

- 题号：953
- 难度：简单
- LeetCode：[验证外星语词典](https://leetcode.cn/problems/verifying-an-alien-dictionary/)

## 题目描述
给定单词列表 `words` 和外星字母表顺序 `order`，判断 `words` 是否按该顺序字典序非递减排列。

## 示例
- `words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"` -> `true`
- `words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"` -> `false`

## 最佳解法思路
- 建立 `rank[26]` 映射到外星字母顺序。
- 逐对比较相邻单词，按自定义字典序比较即可（遇到第一个不同字符决定大小；否则短的更小）。

## Java 最佳实现

```java
class Solution {
    public boolean isAlienSorted(String[] words, String order) {
        int[] rank = new int[26];
        for (int i = 0; i < order.length(); i++) {
            rank[order.charAt(i) - 'a'] = i;
        }

        for (int i = 0; i + 1 < words.length; i++) {
            if (compare(words[i], words[i + 1], rank) > 0) {
                return false;
            }
        }
        return true;
    }

    private int compare(String a, String b, int[] rank) {
        int n = Math.min(a.length(), b.length());
        for (int i = 0; i < n; i++) {
            int ra = rank[a.charAt(i) - 'a'];
            int rb = rank[b.charAt(i) - 'a'];
            if (ra != rb) {
                return ra - rb;
            }
        }
        return a.length() - b.length();
    }
}
```

## 复杂度分析
- 时间：\(O(\sum |word|)\)
- 空间：\(O(1)\)
