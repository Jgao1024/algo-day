# 920. 播放列表的数量

- 题号：920
- 难度：困难
- LeetCode：[播放列表的数量](https://leetcode.cn/problems/number-of-music-playlists/)

## 题目描述
有 `n` 首不同的歌，要构造长度为 `goal` 的播放列表，每首歌至少出现一次，并且同一首歌两次播放之间至少间隔 `k` 首歌。返回方案数（对 \(10^9+7\) 取模）。

## 示例
- `n = 3, goal = 3, k = 1` -> `6`

## 最佳解法思路
- DP：`dp[i][j]` 表示长度为 i 的列表，使用了 j 首不同歌曲的方案数。
  - 新加入一首新歌：`dp[i-1][j-1] * (n-(j-1))`
  - 加入一首旧歌：`dp[i-1][j] * max(j-k, 0)`

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int numMusicPlaylists(int n, int goal, int k) {
        long[][] dp = new long[goal + 1][n + 1];
        dp[0][0] = 1;

        for (int i = 1; i <= goal; i++) {
            for (int j = 1; j <= Math.min(i, n); j++) {
                long addNew = dp[i - 1][j - 1] * (n - (j - 1)) % MOD;
                long addOld = dp[i - 1][j] * Math.max(j - k, 0) % MOD;
                dp[i][j] = (addNew + addOld) % MOD;
            }
        }

        return (int) dp[goal][n];
    }
}
```

## 复杂度分析
- 时间：\(O(goal \cdot n)\)
- 空间：\(O(goal \cdot n)\)
