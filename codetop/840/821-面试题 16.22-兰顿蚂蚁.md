# 面试题 16.22. 兰顿蚂蚁

- 题号：面试题 16.22
- 难度：中等
- LeetCode：[兰顿蚂蚁](https://leetcode.cn/problems/langtons-ant-lcci/)

## 题目描述
在无限棋盘上，格子只有黑/白两种颜色。蚂蚁从 `(0,0)` 出发面朝右，初始格子为白色。

每一步：
- 若当前是白色：翻为黑色，右转 90°，前进一步
- 若当前是黑色：翻为白色，左转 90°，前进一步

给定 `K`，返回 K 步后的最小矩形棋盘打印结果：黑格用 `'X'`，白格用 `'_'`，蚂蚁位置用方向字符 `'L'/'R'/'U'/'D'`。

## 示例
`K = 0` -> `["R"]`

## 最佳解法思路
- 用 `HashSet` 记录黑格坐标，模拟 K 步。
- 最后根据黑格集合和蚂蚁位置计算边界，生成字符矩阵输出。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<String> printKMoves(int K) {
        Set<Long> black = new HashSet<>();
        int r = 0;
        int c = 0;
        int dir = 0; // 0:R 1:D 2:L 3:U

        for (int step = 0; step < K; step++) {
            long key = encode(r, c);
            if (black.contains(key)) {
                black.remove(key);
                dir = (dir + 3) & 3;
            } else {
                black.add(key);
                dir = (dir + 1) & 3;
            }
            if (dir == 0) c++;
            else if (dir == 1) r++;
            else if (dir == 2) c--;
            else r--;
        }

        int minR = r, maxR = r, minC = c, maxC = c;
        for (long key : black) {
            int br = (int) (key >> 32);
            int bc = (int) key;
            minR = Math.min(minR, br);
            maxR = Math.max(maxR, br);
            minC = Math.min(minC, bc);
            maxC = Math.max(maxC, bc);
        }

        int rows = maxR - minR + 1;
        int cols = maxC - minC + 1;
        char[][] board = new char[rows][cols];
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                board[i][j] = '_';
            }
        }

        for (long key : black) {
            int br = (int) (key >> 32);
            int bc = (int) key;
            board[br - minR][bc - minC] = 'X';
        }

        board[r - minR][c - minC] = dirChar(dir);

        List<String> ans = new ArrayList<>(rows);
        for (int i = 0; i < rows; i++) {
            ans.add(new String(board[i]));
        }
        return ans;
    }

    private long encode(int r, int c) {
        return (((long) r) << 32) | (c & 0xffffffffL);
    }

    private char dirChar(int dir) {
        if (dir == 0) return 'R';
        if (dir == 1) return 'D';
        if (dir == 2) return 'L';
        return 'U';
    }
}
```

## 复杂度分析
- 时间：\(O(K)\)
- 空间：\(O(B)\)（B 为黑格数量）
