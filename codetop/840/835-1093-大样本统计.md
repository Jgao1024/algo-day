# 1093. 大样本统计

- 题号：1093
- 难度：中等
- LeetCode：[大样本统计](https://leetcode.cn/problems/statistics-from-a-large-sample/)

## 题目描述
给定长度为 256 的数组 `count`，`count[i]` 表示值 i 出现的次数。返回统计信息：
`[minimum, maximum, mean, median, mode]`。

## 示例
`count[1]=1, count[2]=3` -> minimum=1, maximum=2, mean=1.75, median=2, mode=2

## 最佳解法思路
- 一次遍历求：最小、最大、总数、总和、众数。
- 中位数：根据总数的第 \((tot+1)/2\)、\((tot+2)/2\) 个元素位置（1-based）在累计计数中找到对应的值。

## Java 最佳实现

```java
class Solution {
    public double[] sampleStats(int[] count) {
        int min = -1;
        int max = -1;
        int mode = 0;
        long total = 0;
        long sum = 0;
        int modeCnt = 0;

        for (int i = 0; i < 256; i++) {
            int c = count[i];
            if (c == 0) {
                continue;
            }
            if (min == -1) {
                min = i;
            }
            max = i;
            total += c;
            sum += (long) i * c;
            if (c > modeCnt) {
                modeCnt = c;
                mode = i;
            }
        }

        double mean = (double) sum / total;

        long m1 = (total + 1) / 2;
        long m2 = (total + 2) / 2;
        int v1 = findK(count, m1);
        int v2 = findK(count, m2);
        double median = (v1 + v2) / 2.0;

        return new double[]{min, max, mean, median, mode};
    }

    private int findK(int[] count, long k) {
        long cur = 0;
        for (int i = 0; i < 256; i++) {
            cur += count[i];
            if (cur >= k) {
                return i;
            }
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(256)\)
- 空间：\(O(1)\)
