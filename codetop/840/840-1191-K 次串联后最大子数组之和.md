# 1191. K 次串联后最大子数组之和

- 题号：1191
- 难度：中等
- LeetCode：[K 次串联后最大子数组之和](https://leetcode.cn/problems/k-concatenation-maximum-sum/)

## 题目描述
给定整数数组 `arr` 和整数 `k`，把 `arr` 串联 `k` 次得到新数组，返回新数组的最大子数组和（可为空子数组，空和为 0）。答案对 \(10^9+7\) 取模。

## 示例
- `arr = [1,2], k = 3`，输出 `9`
- `arr = [1,-2,1], k = 5`，输出 `2`

## 最佳解法思路
- Kadane 求 1 次的最大子数组和 `best1`。
- 计算：
  - 总和 `sum`
  - 最大前缀和 `pref`
  - 最大后缀和 `suf`
- 若 `k == 1`，答案是 `best1`。
- 若 `k >= 2`：
  - `best2` 为把数组串联 2 次后的最大子数组和（Kadane 跑两遍）
  - 若 `sum > 0`，可能跨越中间多段：`pref + suf + (k-2)*sum`
  - 取 `max(best2, pref + suf + (k-2)*sum(若 sum>0))`。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int kConcatenationMaxSum(int[] arr, int k) {
        long best1 = kadane(arr, 1);
        if (k == 1) {
            return (int) (best1 % MOD);
        }

        long sum = 0;
        long cur = 0;
        long pref = 0;
        for (int x : arr) {
            sum += x;
            cur += x;
            pref = Math.max(pref, cur);
        }

        cur = 0;
        long suf = 0;
        for (int i = arr.length - 1; i >= 0; i--) {
            cur += arr[i];
            suf = Math.max(suf, cur);
        }

        long best2 = kadane(arr, 2);
        long ans = best2;
        if (sum > 0) {
            ans = Math.max(ans, pref + suf + (long) (k - 2) * sum);
        } else {
            ans = Math.max(ans, pref + suf);
        }

        ans %= MOD;
        if (ans < 0) ans += MOD;
        return (int) ans;
    }

    private long kadane(int[] arr, int times) {
        long best = 0;
        long cur = 0;
        for (int t = 0; t < times; t++) {
            for (int x : arr) {
                cur = Math.max(0, cur + x);
                best = Math.max(best, cur);
            }
        }
        return best;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
