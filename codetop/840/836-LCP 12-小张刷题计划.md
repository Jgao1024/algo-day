# LCP 12. 小张刷题计划

- 题号：LCP 12
- 难度：中等
- LeetCode：[小张刷题计划](https://leetcode.cn/problems/xiao-zhang-shua-ti-ji-hua/)

## 题目描述
给定按顺序排列的题目耗时数组 `time`，小张要在 `m` 天内刷完所有题目。每天必须刷一段连续的题目，并且每天可以请教一次，让当天耗时最长的那题耗时变为 0（等价于当天耗时 = 当天总耗时 - 当天最大耗时）。

求最小的“每天最大耗时”。

## 示例
`time = [1,2,3,3], m = 2` -> `3`

## 最佳解法思路
- 二分答案 S：是否能在 m 天内完成，且每天（使用一次请教后）的耗时都 <= S。
- `check(S)` 用贪心：顺序扫题目，尽量往当天塞；若超出 S：
  - 若当天还没用过请教，就把当天最大题目耗时减掉一次
  - 否则开新的一天，从当前题重新开始

## Java 最佳实现

```java
class Solution {
    public int minTime(int[] time, int m) {
        int sum = 0;
        for (int t : time) {
            sum += t;
        }

        int l = 0;
        int r = sum;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (check(time, mid, m)) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        return l;
    }

    private boolean check(int[] time, int S, int m) {
        int day = 1;
        int sum = 0;
        int max = 0;
        boolean help = true;

        for (int i = 0; i < time.length; i++) {
            sum += time[i];
            max = Math.max(max, time[i]);

            if (sum > S) {
                if (help) {
                    sum -= max;
                    help = false;
                } else {
                    day++;
                    if (day > m) {
                        return false;
                    }
                    i--;
                    sum = 0;
                    max = 0;
                    help = true;
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log(\sum time))\)
- 空间：\(O(1)\)
