# 1512. 好数对的数目

- 题号：1512
- 难度：简单
- LeetCode：[好数对的数目](https://leetcode.cn/problems/number-of-good-pairs/)

## 题目描述
给定数组 `nums`，统计满足 `i < j` 且 `nums[i] == nums[j]` 的好数对数量。

## 示例
- `nums = [1,2,3,1,1,3]`，输出 `4`
- `nums = [1,1,1,1]`，输出 `6`

## 最佳解法思路
- 边遍历边计数：当前值 `x` 之前出现了 `cnt[x]` 次，则以当前位置结尾新增 `cnt[x]` 个好数对；然后 `cnt[x]++`。

## Java 最佳实现

```java
class Solution {
    public int numIdenticalPairs(int[] nums) {
        int[] cnt = new int[101];
        int ans = 0;
        for (int x : nums) {
            ans += cnt[x];
            cnt[x]++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
