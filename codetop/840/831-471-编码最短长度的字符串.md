# 471. 编码最短长度的字符串

- 题号：471
- 难度：困难
- LeetCode：[编码最短长度的字符串](https://leetcode.cn/problems/encode-string-with-shortest-length/)

## 题目描述
给定字符串 `s`，可以使用编码规则 `k[encoded_string]` 表示 `encoded_string` 重复 k 次（k 为正整数）。
返回 s 的最短编码表示（如果编码不变短，则返回原串）。

## 示例
- `"aaaaa"` -> `"5[a]"`
- `"aabcaabcd"` -> `"2[aabc]d"`

## 最佳解法思路
- 区间 DP：
  - `dp[i][j]` 表示子串 `s[i..j]` 的最短编码
  - 两种更新方式：
    - 切分：`dp[i][k] + dp[k+1][j]`
    - 重复：若 `s[i..j]` 可由某个更短模式重复组成，则尝试 `t[dp[i..i+len-1]]`

## Java 最佳实现

```java
class Solution {
    public String encode(String s) {
        int n = s.length();
        String[][] dp = new String[n][n];

        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                String sub = s.substring(i, j + 1);
                dp[i][j] = sub;

                if (len < 5) {
                    continue;
                }

                for (int k = i; k < j; k++) {
                    String left = dp[i][k];
                    String right = dp[k + 1][j];
                    if (left.length() + right.length() < dp[i][j].length()) {
                        dp[i][j] = left + right;
                    }
                }

                int p = (sub + sub).indexOf(sub, 1);
                if (p < sub.length()) {
                    int repeatLen = p;
                    int times = sub.length() / repeatLen;
                    String pattern = dp[i][i + repeatLen - 1];
                    String cand = times + "[" + pattern + "]";
                    if (cand.length() < dp[i][j].length()) {
                        dp[i][j] = cand;
                    }
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

## 复杂度分析
- 时间：约 \(O(n^3)\)
- 空间：\(O(n^2)\)
