# 1561. 你可以获得的最大硬币数目

- 题号：1561
- 难度：中等
- LeetCode：[你可以获得的最大硬币数目](https://leetcode.cn/problems/maximum-number-of-coins-you-can-get/)

## 题目描述
有 `3n` 堆硬币，每轮三人各取一堆：Alice 取最多的，你取第二多的，Bob 取最少的。求你最终能得到的最大硬币数。

## 示例
- `piles = [2,4,1,2,7,8]`，输出 `9`

## 最佳解法思路
- 排序后用双指针：
  - 每轮丢掉一个最大（给 Alice），取次大（给你），丢掉一个最小（给 Bob）
  - 重复 n 轮即可最大化你的收益。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int maxCoins(int[] piles) {
        Arrays.sort(piles);
        int n = piles.length / 3;
        int l = 0;
        int r = piles.length - 1;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            r--;          // Alice
            ans += piles[r]; // me
            r--;
            l++;          // Bob
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（不计排序栈）
