# 87. 扰乱字符串

- 题号：87
- 难度：困难
- LeetCode：[扰乱字符串](https://leetcode.cn/problems/scramble-string/)

## 题目描述
给定两个等长字符串 `s1`、`s2`。`s1` 经过若干次递归划分并交换左右子串后，能否变成 `s2`。

## 示例
- `s1 = "great", s2 = "rgeat"` -> `true`
- `s1 = "abcde", s2 = "caebd"` -> `false`

## 最佳解法思路
- 递归 + 记忆化：
  - 状态 `f(i1, i2, len)` 表示 `s1` 从 i1 开始长度 len 的子串是否能扰乱成 `s2` 从 i2 开始长度 len 的子串
  - 先用字符计数剪枝（26 频次不同直接 false）
  - 枚举切分点 k，尝试“不交换/交换”两种组合

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private char[] a;
    private char[] b;
    private Map<Long, Boolean> memo;

    public boolean isScramble(String s1, String s2) {
        if (s1.length() != s2.length()) {
            return false;
        }
        if (s1.equals(s2)) {
            return true;
        }
        a = s1.toCharArray();
        b = s2.toCharArray();
        memo = new HashMap<>();
        return dfs(0, 0, a.length);
    }

    private boolean dfs(int i1, int i2, int len) {
        long key = pack(i1, i2, len);
        Boolean cached = memo.get(key);
        if (cached != null) {
            return cached;
        }

        if (equalsRange(i1, i2, len)) {
            memo.put(key, true);
            return true;
        }
        if (!sameCount(i1, i2, len)) {
            memo.put(key, false);
            return false;
        }

        for (int k = 1; k < len; k++) {
            if (dfs(i1, i2, k) && dfs(i1 + k, i2 + k, len - k)) {
                memo.put(key, true);
                return true;
            }
            if (dfs(i1, i2 + (len - k), k) && dfs(i1 + k, i2, len - k)) {
                memo.put(key, true);
                return true;
            }
        }

        memo.put(key, false);
        return false;
    }

    private boolean equalsRange(int i1, int i2, int len) {
        for (int i = 0; i < len; i++) {
            if (a[i1 + i] != b[i2 + i]) {
                return false;
            }
        }
        return true;
    }

    private boolean sameCount(int i1, int i2, int len) {
        int[] cnt = new int[26];
        for (int i = 0; i < len; i++) {
            cnt[a[i1 + i] - 'a']++;
            cnt[b[i2 + i] - 'a']--;
        }
        for (int x : cnt) {
            if (x != 0) {
                return false;
            }
        }
        return true;
    }

    private long pack(int i1, int i2, int len) {
        return ((long) i1 << 42) ^ ((long) i2 << 21) ^ (long) len;
    }
}
```

## 复杂度分析
- 时间：最坏较大（记忆化后大幅减少）
- 空间：\(O(n^3)\)（状态数级别）
