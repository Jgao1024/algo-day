# 面试题 16.02. 单词频率

- 题号：面试题 16.02
- 难度：中等
- LeetCode：[单词频率](https://leetcode.cn/problems/words-frequency-lcci/)

## 题目描述
设计类 `WordsFrequency`：
- 构造函数传入书本单词数组 `book`
- `get(word)` 返回 `word` 在 book 中出现的次数

## 示例
`book = ["i","have","an","apple","have","a","pen"]`
`get("have") = 2`

## 最佳解法思路
- 构造时用 HashMap 统计频次；查询时直接返回。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class WordsFrequency {
    private final Map<String, Integer> map = new HashMap<>();

    public WordsFrequency(String[] book) {
        for (String w : book) {
            map.put(w, map.getOrDefault(w, 0) + 1);
        }
    }

    public int get(String word) {
        return map.getOrDefault(word, 0);
    }
}
```

## 复杂度分析
- 构造：时间 \(O(n)\)，空间 \(O(n)\)
- 查询：时间 \(O(1)\)
