# 568. 最大休假天数

- 题号：568
- 难度：困难
- LeetCode：[最大休假天数](https://leetcode.cn/problems/maximum-vacation-days/)

## 题目描述
有 `n` 个城市、`k` 周。`flights[i][j]=1` 表示第 i 城市可飞到第 j 城市（也允许停留原地）。
`days[i][w]` 表示第 w 周在城市 i 休假的天数。

你从城市 0 出发，每周开始可以选择飞行一次（或不飞），然后在所在城市休假。求最多休假天数。

## 示例
`flights = [[0,1,1],[1,0,1],[1,1,0]]`
`days = [[1,3,1],[6,0,3],[3,3,3]]`
输出 `12`

## 最佳解法思路
- DP 按周推进：
  - `dp[i]`：当前周开始时在城市 i 的最大休假天数
  - 转移到下一周：`ndp[to] = max(ndp[to], dp[from] + days[to][week])`，其中 from==to 或 flights[from][to]==1

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int maxVacationDays(int[][] flights, int[][] days) {
        int n = flights.length;
        int k = days[0].length;

        int neg = -1000000000;
        int[] dp = new int[n];
        Arrays.fill(dp, neg);
        dp[0] = 0;

        for (int w = 0; w < k; w++) {
            int[] ndp = new int[n];
            Arrays.fill(ndp, neg);
            for (int from = 0; from < n; from++) {
                if (dp[from] == neg) {
                    continue;
                }
                for (int to = 0; to < n; to++) {
                    if (from == to || flights[from][to] == 1) {
                        ndp[to] = Math.max(ndp[to], dp[from] + days[to][w]);
                    }
                }
            }
            dp = ndp;
        }

        int ans = 0;
        for (int v : dp) {
            ans = Math.max(ans, v);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(k \cdot n^2)\)
- 空间：\(O(n)\)
