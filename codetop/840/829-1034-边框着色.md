# 1034. 边框着色

- 题号：1034
- 难度：中等
- LeetCode：[边框着色](https://leetcode.cn/problems/coloring-a-border/)

## 题目描述
给定网格 `grid` 和起点 `(row, col)`，将与起点连通（4 方向、颜色相同）的连通块的“边界”格子染成新颜色 `color`，返回染色后的网格。

## 示例
`grid = [[1,1],[1,2]], row=0, col=0, color=3`
输出 `[[3,3],[3,2]]`

## 最佳解法思路
- BFS/DFS 找到连通块。
- 对连通块中的格子，如果它在边界（贴边或相邻有不同颜色/不在连通块），就记录为边界格子。
- 最后统一把边界格子改色。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public int[][] colorBorder(int[][] grid, int row, int col, int color) {
        int m = grid.length;
        int n = grid[0].length;
        int base = grid[row][col];
        boolean[][] vis = new boolean[m][n];

        Queue<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{row, col});
        vis[row][col] = true;

        List<int[]> border = new ArrayList<>();
        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int r = cur[0];
            int c = cur[1];
            boolean isBorder = false;

            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k];
                int nc = c + dc[k];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                    isBorder = true;
                    continue;
                }
                if (grid[nr][nc] != base) {
                    isBorder = true;
                    continue;
                }
                if (!vis[nr][nc]) {
                    vis[nr][nc] = true;
                    q.offer(new int[]{nr, nc});
                }
            }

            if (isBorder) {
                border.add(new int[]{r, c});
            }
        }

        for (int[] p : border) {
            grid[p[0]][p[1]] = color;
        }
        return grid;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
