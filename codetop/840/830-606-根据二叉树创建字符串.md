# 606. 根据二叉树创建字符串

- 题号：606
- 难度：简单
- LeetCode：[根据二叉树创建字符串](https://leetcode.cn/problems/construct-string-from-binary-tree/)

## 题目描述
给定二叉树，用前序遍历生成字符串：
- 节点值直接输出
- 若有子树，用括号包裹
- 省略不影响一一映射的空括号，但当右子树存在且左子树为空时，需要保留左子树的空括号 `"()"`。

## 示例
输入：`[1,2,3,4]`  
输出：`"1(2(4))(3)"`

## 最佳解法思路
- 递归前序：
  - 叶子：只输出值
  - 只有左：`val(left)`
  - 有右：`val(left)(right)`，若左为空则用 `()` 占位。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public String tree2str(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        dfs(root, sb);
        return sb.toString();
    }

    private void dfs(TreeNode node, StringBuilder sb) {
        if (node == null) {
            return;
        }
        sb.append(node.val);
        if (node.left == null && node.right == null) {
            return;
        }
        sb.append('(');
        if (node.left != null) {
            dfs(node.left, sb);
        }
        sb.append(')');
        if (node.right != null) {
            sb.append('(');
            dfs(node.right, sb);
            sb.append(')');
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
