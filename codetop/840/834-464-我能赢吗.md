# 464. 我能赢吗

- 题号：464
- 难度：中等
- LeetCode：[我能赢吗](https://leetcode.cn/problems/can-i-win/)

## 题目描述
有整数池 `1..maxChoosableInteger`，两人轮流选择一个没选过的数并累加到总和。谁先让总和达到或超过 `desiredTotal` 谁赢。两人都最优，判断先手能否必胜。

## 示例
- `maxChoosableInteger = 10, desiredTotal = 11` -> `false`
- `maxChoosableInteger = 10, desiredTotal = 0` -> `true`

## 最佳解法思路
- 状态压缩 + 记忆化搜索：
  - `mask` 表示哪些数已被选
  - `dfs(mask, remain)` 返回当前玩家是否能赢
  - 尝试选择一个数 i：若 `i >= remain` 或者对手在新状态下必败，则当前必胜。

## Java 最佳实现

```java
class Solution {
    private Boolean[] memo;
    private int max;

    public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
        if (desiredTotal <= 0) {
            return true;
        }
        int sum = (maxChoosableInteger + 1) * maxChoosableInteger / 2;
        if (sum < desiredTotal) {
            return false;
        }
        max = maxChoosableInteger;
        memo = new Boolean[1 << max];
        return dfs(0, desiredTotal);
    }

    private boolean dfs(int mask, int remain) {
        Boolean cached = memo[mask];
        if (cached != null) {
            return cached;
        }
        for (int i = 1; i <= max; i++) {
            int bit = 1 << (i - 1);
            if ((mask & bit) != 0) {
                continue;
            }
            if (i >= remain) {
                memo[mask] = true;
                return true;
            }
            if (!dfs(mask | bit, remain - i)) {
                memo[mask] = true;
                return true;
            }
        }
        memo[mask] = false;
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(2^{max} \cdot max)\)
- 空间：\(O(2^{max})\)
