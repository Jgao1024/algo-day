# 1062. 最长重复子串

- 题号：1062
- 难度：中等
- LeetCode：[最长重复子串](https://leetcode.cn/problems/longest-repeating-substring/)

## 题目描述
给定字符串 `s`，返回最长重复子串的长度（同一个子串在 s 中至少出现两次，位置可重叠）。

## 示例
- `s = "abcd"` -> `0`
- `s = "abbaba"` -> `2`（"ab"）

## 最佳解法思路
- 转成“最长公共子串”：
  - 计算 s 与 s 自身的最长公共子串长度，但要求匹配的两个位置不同（避免同一个字符和自己匹配）。
- DP：`dp[i][j]` 表示以 `s[i-1]`、`s[j-1]` 结尾的最长公共后缀长度（i<j）。

## Java 最佳实现

```java
class Solution {
    public int longestRepeatingSubstring(String s) {
        int n = s.length();
        int[][] dp = new int[n + 1][n + 1];
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                if (s.charAt(i - 1) == s.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    ans = Math.max(ans, dp[i][j]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
