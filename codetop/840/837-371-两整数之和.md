# 371. 两整数之和

- 题号：371
- 难度：简单
- LeetCode：[两整数之和](https://leetcode.cn/problems/sum-of-two-integers/)

## 题目描述
不使用 `+` 和 `-` 运算符，计算两个整数 `a` 和 `b` 的和。

## 示例
- `a = 1, b = 2`，输出 `3`
- `a = 2, b = 3`，输出 `5`

## 最佳解法思路
- 位运算模拟加法：
  - `sum = a ^ b`（不考虑进位的和）
  - `carry = (a & b) << 1`（进位）
  - 反复把 `sum` 和 `carry` 相加，直到 `carry == 0`。

## Java 最佳实现

```java
class Solution {
    public int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a = a ^ b;
            b = carry;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)（最多 32 次迭代）
- 空间：\(O(1)\)
