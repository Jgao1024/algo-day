# 610. 判断三角形

- 题号：610
- 难度：简单
- LeetCode：[判断三角形](https://leetcode.cn/problems/triangle-judgement/)

## 题目描述
给定三条边长 \(a,b,c\)，判断能否组成三角形（任意两边之和大于第三边）。

## 示例
- 示例  
输入：`a=13, b=15, c=30`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：三角形判定  
只需判断：`a + b > c && a + c > b && b + c > a`。为避免溢出可转 long 再加。

## Java 最佳实现

```java
class Solution {
    public boolean isTriangle(int a, int b, int c) {
        long x = a, y = b, z = c;
        return x + y > z && x + z > y && y + z > x;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
