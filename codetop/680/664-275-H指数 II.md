# 275. H指数 II

- 题号：275
- 难度：中等
- LeetCode：[H指数 II](https://leetcode.cn/problems/h-index-ii/)

## 题目描述
给定按升序排序的引用次数数组 `citations`，求研究者的 H 指数。

## 示例
- 示例  
输入：`citations = [0,1,3,5,6]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：二分答案  
设数组长度为 n。若 H 为 h，则需要满足 `citations[n-h] >= h`。  
在 `h` 的范围 `[0..n]` 上二分找最大可行值。

## Java 最佳实现

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int l = 0, r = n;
        while (l < r) {
            int mid = (l + r + 1) >>> 1;
            if (citations[n - mid] >= mid) l = mid;
            else r = mid - 1;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)

## 相关题目
- 274 H指数：未排序版本

## 总结（速记）
- 排序版用二分：检查 `citations[n-h] >= h`。
