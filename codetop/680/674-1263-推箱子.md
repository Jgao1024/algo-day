# 1263. 推箱子

- 题号：1263
- 难度：困难
- LeetCode：[推箱子](https://leetcode.cn/problems/minimum-moves-to-move-a-box-to-their-target-location/)

## 题目描述
网格中：`#` 是墙，`.` 是空地，`S` 人起点，`B` 箱子，`T` 目标。  
人可以走到空地；推箱子需要站在箱子相反方向的相邻格，且箱子前方格必须为空。  
求把箱子推到目标的最少推箱次数。

## 示例
- 示例  
输入：见题面  
输出：最少推箱次数

## 最佳解法思路
- 思路1（推荐）：按“推箱次数”做 BFS（状态包含人和箱子位置）  
状态 `(boxPos, playerPos)`，边表示“一次推箱”。  
从当前箱子位置尝试四个方向推：  
需要玩家能在不穿过箱子的情况下走到“箱子背后”的那一格；若可达且箱子前方不是墙，则产生新状态，推箱次数 +1。  
由于每条边代价都是 1，用 BFS 找最少推箱次数即可。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class Solution {
    private static final int INF = 1 << 30;
    private static final int[] dr = {1, -1, 0, 0};
    private static final int[] dc = {0, 0, 1, -1};

    public int minPushBox(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int pr = -1, pc = -1, br = -1, bc = -1, tr = -1, tc = -1;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 'S') { pr = r; pc = c; }
                else if (grid[r][c] == 'B') { br = r; bc = c; }
                else if (grid[r][c] == 'T') { tr = r; tc = c; }
            }
        }

        int total = m * n;
        int[][] dist = new int[total][total];
        for (int i = 0; i < total; i++) Arrays.fill(dist[i], INF);

        int b0 = br * n + bc;
        int p0 = pr * n + pc;
        dist[b0][p0] = 0;
        Deque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{br, bc, pr, pc});

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            br = cur[0]; bc = cur[1]; pr = cur[2]; pc = cur[3];
            int bPos = br * n + bc;
            int pPos = pr * n + pc;
            int pushes = dist[bPos][pPos];
            if (br == tr && bc == tc) return pushes;

            for (int k = 0; k < 4; k++) {
                int needR = br - dr[k];
                int needC = bc - dc[k];
                int nbR = br + dr[k];
                int nbC = bc + dc[k];
                if (!in(m, n, needR, needC) || !in(m, n, nbR, nbC)) continue;
                if (grid[needR][needC] == '#') continue;
                if (grid[nbR][nbC] == '#') continue;

                if (!canReach(grid, pr, pc, needR, needC, br, bc)) continue;

                int nbPos = nbR * n + nbC;
                int npPos = br * n + bc;
                if (pushes + 1 < dist[nbPos][npPos]) {
                    dist[nbPos][npPos] = pushes + 1;
                    q.offer(new int[]{nbR, nbC, br, bc});
                }
            }
        }
        return -1;
    }

    private boolean canReach(char[][] grid, int sr, int sc, int tr, int tc, int br, int bc) {
        int m = grid.length, n = grid[0].length;
        boolean[][] vis = new boolean[m][n];
        Deque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{sr, sc});
        vis[sr][sc] = true;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int r = cur[0], c = cur[1];
            if (r == tr && c == tc) return true;
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (!in(m, n, nr, nc)) continue;
                if (vis[nr][nc]) continue;
                if (grid[nr][nc] == '#') continue;
                if (nr == br && nc == bc) continue;
                vis[nr][nc] = true;
                q.offer(new int[]{nr, nc});
            }
        }
        return false;
    }

    private boolean in(int m, int n, int r, int c) {
        return r >= 0 && r < m && c >= 0 && c < n;
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(\text{状态数} \times mn)\)（每次尝试推箱要做一次可达性 BFS）
- 空间：\(O((mn)^2)\)（dist）+ \(O(mn)\)（可达性 BFS）
