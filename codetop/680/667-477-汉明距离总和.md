# 477. 汉明距离总和

- 题号：477
- 难度：中等
- LeetCode：[汉明距离总和](https://leetcode.cn/problems/total-hamming-distance/)

## 题目描述
给定整数数组 `nums`，返回所有数对之间汉明距离的总和。

## 示例
- 示例  
输入：`nums = [4,14,2]`  
输出：`6`

## 最佳解法思路
- 思路1（推荐）：按位统计  
对每一位 bit，统计这一位上有 `ones` 个 1、`zeros` 个 0。  
该位对总汉明距离贡献为 `ones * zeros`（一正一反才产生距离 1）。  
累加 0..30 位即可。

## Java 最佳实现

```java
class Solution {
    public int totalHammingDistance(int[] nums) {
        int n = nums.length;
        long ans = 0;
        for (int b = 0; b < 31; b++) {
            int ones = 0;
            for (int x : nums) {
                ones += (x >>> b) & 1;
            }
            ans += (long) ones * (n - ones);
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(31n)\)
- 空间：\(O(1)\)
