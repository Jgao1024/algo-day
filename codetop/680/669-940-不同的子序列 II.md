# 940. 不同的子序列 II

- 题号：940
- 难度：困难
- LeetCode：[不同的子序列 II](https://leetcode.cn/problems/distinct-subsequences-ii/)

## 题目描述
给定字符串 `s`，返回不同的非空子序列数量（结果对 \(10^9+7\) 取模）。

## 示例
- 示例  
输入：`s = "abc"`  
输出：`7`

## 最佳解法思路
- 思路1（推荐）：DP + last 去重  
设 `dp` 表示“包括空子序列在内”的不同子序列数量。初始 `dp=1`（空串）。  
遍历字符 `c`：新子序列数本来是 `dp*2`（每个旧子序列要么不选 c，要么选 c）。  
但若 c 之前出现过，会重复计算，需减去上一次以 c 结尾时的旧 `dp` 值：  
`newDp = dp*2 - last[c]`，然后令 `last[c]=dp`，`dp=newDp`。  
最终答案为 `dp-1`（去掉空子序列）。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1000000007;

    public int distinctSubseqII(String s) {
        long dp = 1;
        long[] last = new long[26];
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            long ndp = (dp * 2 - last[c]) % MOD;
            if (ndp < 0) ndp += MOD;
            last[c] = dp;
            dp = ndp;
        }
        dp = (dp - 1) % MOD;
        if (dp < 0) dp += MOD;
        return (int) dp;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- `dp` 翻倍再减去重复：`new=2*dp-last[c]`，答案 `dp-1`。
