# 784. 字母大小写全排列

- 题号：784
- 难度：简单
- LeetCode：[字母大小写全排列](https://leetcode.cn/problems/letter-case-permutation/)

## 题目描述
给定字符串 `s`，把其中字母大小写自由切换（数字不变），返回所有可能结果。

## 示例
- 示例  
输入：`s = "a1b2"`  
输出：`["a1b2","a1B2","A1b2","A1B2"]`

## 最佳解法思路
- 思路1（推荐）：回溯  
遍历每个位置：  
若是字母，分支两种（小写/大写）；若是数字，只有一种。到末尾收集结果即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> letterCasePermutation(String s) {
        List<String> ans = new ArrayList<>();
        char[] a = s.toCharArray();
        dfs(0, a, ans);
        return ans;
    }

    private void dfs(int i, char[] a, List<String> ans) {
        if (i == a.length) {
            ans.add(new String(a));
            return;
        }
        char ch = a[i];
        if (Character.isLetter(ch)) {
            a[i] = Character.toLowerCase(ch);
            dfs(i + 1, a, ans);
            a[i] = Character.toUpperCase(ch);
            dfs(i + 1, a, ans);
            a[i] = ch;
        } else {
            dfs(i + 1, a, ans);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(2^k \cdot n)\)（k 为字母个数）
- 空间：\(O(n)\)（递归栈/构造字符串）
