# 298. 二叉树最长连续序列

- 题号：298
- 难度：中等
- LeetCode：[二叉树最长连续序列](https://leetcode.cn/problems/binary-tree-longest-consecutive-sequence/)

## 题目描述
返回二叉树中最长连续序列的长度（必须是父->子方向，且每步值 +1）。

## 示例
- 示例  
输入：`root = [1,null,3,2,4,null,null,null,5]`  
输出：`3`（3->4->5）

## 最佳解法思路
- 思路1（推荐）：DFS 返回“以当前节点为起点向下的最长连续长度”  
递归左右子树，若子节点值为 `cur.val+1`，则可接上：`len = max(len, childLen+1)`。  
用全局变量更新最大值。

## Java 最佳实现

```java
class Solution {
    private int ans = 0;

    public int longestConsecutive(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int best = 1;
        int l = dfs(node.left);
        int r = dfs(node.right);
        if (node.left != null && node.left.val == node.val + 1) best = Math.max(best, l + 1);
        if (node.right != null && node.right.val == node.val + 1) best = Math.max(best, r + 1);
        if (best > ans) ans = best;
        return best;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)

## 总结（速记）
- 连续序列只看子节点是否等于 `cur+1`；DFS 返回单链长度并更新全局答案。
