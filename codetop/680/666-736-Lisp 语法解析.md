# 736. Lisp 语法解析

- 题号：736
- 难度：困难
- LeetCode：[Lisp 语法解析](https://leetcode.cn/problems/parse-lisp-expression/)

## 题目描述
实现一个简单 Lisp 表达式求值器，支持：  
- `add e1 e2`  
- `mult e1 e2`  
- `let v1 e1 v2 e2 ... expr`（变量作用域仅在当前括号内）  
表达式可能嵌套，变量名为小写字母，整数可为负。

## 示例
- 示例  
输入：`"(add 1 2)"`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：递归求值 + 作用域栈  
遇到非括号表达式：如果是数字直接返回；否则在作用域栈中自顶向下查变量值。  
遇到括号表达式：先把括号内顶层按空格拆成 token（注意嵌套括号不能拆开），第一个 token 是操作符：  
- `add/mult`：递归求两个子表达式  
- `let`：新建一层作用域，依次处理变量赋值对，最后一个 token 为返回表达式

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int evaluate(String expression) {
        Deque<Map<String, Integer>> scopes = new ArrayDeque<>();
        scopes.push(new HashMap<>());
        return eval(expression, scopes);
    }

    private int eval(String expr, Deque<Map<String, Integer>> scopes) {
        if (expr.charAt(0) != '(') {
            if (isNumber(expr)) return Integer.parseInt(expr);
            return getVar(expr, scopes);
        }

        String inner = expr.substring(1, expr.length() - 1);
        List<String> parts = splitTop(inner);
        String op = parts.get(0);

        if ("add".equals(op)) {
            return eval(parts.get(1), scopes) + eval(parts.get(2), scopes);
        }
        if ("mult".equals(op)) {
            return eval(parts.get(1), scopes) * eval(parts.get(2), scopes);
        }

        scopes.push(new HashMap<>());
        int i = 1;
        while (i < parts.size() - 1) {
            String var = parts.get(i);
            int val = eval(parts.get(i + 1), scopes);
            scopes.peek().put(var, val);
            i += 2;
        }
        int res = eval(parts.get(parts.size() - 1), scopes);
        scopes.pop();
        return res;
    }

    private List<String> splitTop(String s) {
        List<String> res = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        int bal = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == ' ' && bal == 0) {
                res.add(cur.toString());
                cur.setLength(0);
                continue;
            }
            if (ch == '(') bal++;
            else if (ch == ')') bal--;
            cur.append(ch);
        }
        res.add(cur.toString());
        return res;
    }

    private boolean isNumber(String s) {
        char c0 = s.charAt(0);
        return (c0 == '-') || (c0 >= '0' && c0 <= '9');
    }

    private int getVar(String name, Deque<Map<String, Integer>> scopes) {
        for (Map<String, Integer> m : scopes) {
            Integer v = m.get(name);
            if (v != null) return v;
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(L)\)（L 为表达式长度，拆分/递归总量线性级别）
- 空间：\(O(L)\)（递归栈 + token 列表）
