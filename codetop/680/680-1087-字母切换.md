# 1087. 字母切换

- 题号：1087
- 难度：中等
- LeetCode：[字母切换](https://leetcode.cn/problems/brace-expansion/)

## 题目描述
给定表达式 `s`，其中 `{a,b,c}` 表示可选字符集合，求展开后的所有字符串并按字典序返回。

## 示例
- 示例  
输入：`s = "{a,b}c{d,e}f"`  
输出：`["acdf","acef","bcdf","bcef"]`

## 最佳解法思路
- 思路1（推荐）：解析分段 + 回溯笛卡尔积  
把字符串解析成若干段，每段是一个可选集合（普通字符就是单元素集合）。  
对每段从左到右选择，做笛卡尔积回溯即可。每段选项排序后，生成结果天然有序。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public String[] expand(String s) {
        List<List<String>> parts = new ArrayList<>();
        int i = 0;
        while (i < s.length()) {
            char ch = s.charAt(i);
            if (ch == '{') {
                int j = i + 1;
                List<String> opts = new ArrayList<>();
                StringBuilder cur = new StringBuilder();
                while (j < s.length() && s.charAt(j) != '}') {
                    char c = s.charAt(j);
                    if (c == ',') {
                        opts.add(cur.toString());
                        cur.setLength(0);
                    } else {
                        cur.append(c);
                    }
                    j++;
                }
                opts.add(cur.toString());
                Collections.sort(opts);
                parts.add(opts);
                i = j + 1;
            } else {
                List<String> one = new ArrayList<>();
                one.add(String.valueOf(ch));
                parts.add(one);
                i++;
            }
        }

        List<String> ans = new ArrayList<>();
        dfs(0, parts, new StringBuilder(), ans);
        return ans.toArray(new String[0]);
    }

    private void dfs(int idx, List<List<String>> parts, StringBuilder sb, List<String> ans) {
        if (idx == parts.size()) {
            ans.add(sb.toString());
            return;
        }
        int len = sb.length();
        for (String opt : parts.get(idx)) {
            sb.append(opt);
            dfs(idx + 1, parts, sb, ans);
            sb.setLength(len);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(\text{结果数量} \cdot L)\)
- 空间：\(O(L)\)（递归栈）

- 先把表达式拆成“每段选项列表”，再做笛卡尔积回溯即可。
