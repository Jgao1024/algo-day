# 853. 车队

- 题号：853
- 难度：中等
- LeetCode：[车队](https://leetcode.cn/problems/car-fleet/)

## 题目描述
目标点 `target`，每辆车位置 `position[i]`、速度 `speed[i]`。车不能超车，只能追上后变成同一车队。问最终有多少个车队到达目标。

## 示例
- 示例  
输入：`target=12, position=[10,8,0,5,3], speed=[2,4,1,1,3]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：按位置从近到远扫描（单调“到达时间”）  
按位置降序排序。计算每辆车到达目标的时间 `t = (target-pos)/speed`。  
从近到远扫描：若当前 `t` 大于已形成车队的最大时间 `maxT`，说明它追不上前车，形成新车队；否则会并入前车队。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int carFleet(int target, int[] position, int[] speed) {
        int n = position.length;
        int[][] cars = new int[n][2];
        for (int i = 0; i < n; i++) {
            cars[i][0] = position[i];
            cars[i][1] = speed[i];
        }
        Arrays.sort(cars, (a, b) -> b[0] - a[0]);

        int fleets = 0;
        double maxT = -1;
        for (int i = 0; i < n; i++) {
            double t = (target - cars[i][0]) * 1.0 / cars[i][1];
            if (t > maxT) {
                fleets++;
                maxT = t;
            }
        }
        return fleets;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
