# 1360. 日期之间隔几天

- 题号：1360
- 难度：简单
- LeetCode：[日期之间隔几天](https://leetcode.cn/problems/number-of-days-between-two-dates/)

## 题目描述
给定两个日期字符串 `date1`、`date2`（格式 `YYYY-MM-DD`），返回它们相差的天数。

## 示例
- 示例  
输入：`date1 = "2019-06-29", date2 = "2019-06-30"`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：把日期转换为“从固定起点到该日期的天数”  
实现 `toDays(date)`：累计年天数 + 月天数 + 日偏移，注意闰年规则。  
答案为 `abs(toDays(date1) - toDays(date2))`。

## Java 最佳实现

```java
class Solution {
    private static final int[] MDAYS = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

    public int daysBetweenDates(String date1, String date2) {
        return Math.abs(toDays(date1) - toDays(date2));
    }

    private int toDays(String date) {
        int y = Integer.parseInt(date.substring(0, 4));
        int m = Integer.parseInt(date.substring(5, 7));
        int d = Integer.parseInt(date.substring(8, 10));

        int days = 0;
        for (int year = 1971; year < y; year++) days += isLeap(year) ? 366 : 365;
        for (int month = 1; month < m; month++) days += daysInMonth(y, month);
        days += (d - 1);
        return days;
    }

    private int daysInMonth(int y, int m) {
        if (m == 2) return isLeap(y) ? 29 : 28;
        return MDAYS[m - 1];
    }

    private boolean isLeap(int y) {
        return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
    }
}
```

## 复杂度分析
- 时间：\(O(|y-1971|)\)（年份跨度很小）
- 空间：\(O(1)\)
