# 1367. 二叉树中的列表

- 题号：1367
- 难度：中等
- LeetCode：[二叉树中的列表](https://leetcode.cn/problems/linked-list-in-binary-tree/)

## 题目描述
给定链表头 `head` 和二叉树根 `root`，判断是否存在一条从某个节点向下（只能走 left/right）的路径，使得路径上的节点值依次与链表相同。

## 示例
- 示例  
输入：`head = [4,2,8]`, `root = [1,4,4,null,2,2,null,1,null,6,8,null,null,null,null,1,3]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：遍历树找起点 + 匹配  
对树的每个节点尝试作为起点：  
`match(node, head)` 判断从 node 向下能否匹配链表当前节点。  
主过程：`isSubPath(head, root) = match(root, head) || isSubPath(head, root.left) || isSubPath(head, root.right)`。

## Java 最佳实现

```java
class Solution {
    public boolean isSubPath(ListNode head, TreeNode root) {
        if (root == null) return false;
        return match(head, root) || isSubPath(head, root.left) || isSubPath(head, root.right);
    }

    private boolean match(ListNode head, TreeNode node) {
        if (head == null) return true;
        if (node == null) return false;
        if (head.val != node.val) return false;
        return match(head.next, node.left) || match(head.next, node.right);
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(nm)\)（n 为树节点数，m 为链表长度）
- 空间：\(O(h+m)\)（递归栈）

## 总结（速记）
- 树上找链表：先遍历找可能起点，再递归向下匹配。
