# 769. 最多能完成排序的块

- 题号：769
- 难度：中等
- LeetCode：[最多能完成排序的块](https://leetcode.cn/problems/max-chunks-to-make-sorted/)

## 题目描述
给定数组 `arr`（为 0..n-1 的一个排列），把它分成若干块分别排序后再拼接，要求结果整体有序。求最多能分成多少块。

## 示例
- 示例  
输入：`arr = [1,0,2,3,4]`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：前缀最大值  
从左到右维护前缀最大值 `mx`。当 `mx == i` 时，说明当前前缀里元素都落在 `[0..i]`，这一段排完一定能放回正确位置，可以切一刀。

## Java 最佳实现

```java
class Solution {
    public int maxChunksToSorted(int[] arr) {
        int mx = 0;
        int ans = 0;
        for (int i = 0; i < arr.length; i++) {
            mx = Math.max(mx, arr[i]);
            if (mx == i) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
