# 357. 计算各个位数不同的数字个数

- 题号：357
- 难度：中等
- LeetCode：[计算各个位数不同的数字个数](https://leetcode.cn/problems/count-numbers-with-unique-digits/)

## 题目描述
给定 `n`，统计 \(0 \le x < 10^n\) 中各位数字都不相同的数的个数。

## 示例
- 示例  
输入：`n = 2`  
输出：`91`

## 最佳解法思路
- 思路1（推荐）：组合计数  
`n=0` 时只有 0 -> 1。  
对位数 i（1..n）：  
- 最高位不能为 0：9 种  
- 后续每位从剩余数字里选：依次乘 `9,8,7...`  
把 i 位的数量累加即可（n 超过 10 也只需算到 10 位）。

## Java 最佳实现

```java
class Solution {
    public int countNumbersWithUniqueDigits(int n) {
        if (n == 0) return 1;
        n = Math.min(n, 10);
        int ans = 10;
        int cur = 9;
        int avail = 9;
        for (int i = 2; i <= n; i++) {
            cur *= avail;
            ans += cur;
            avail--;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- i 位独特数：`9 * 9 * 8 * ...`，累加到 n（最多 10 位）。
