# 面试题 02.04. 分割链表

- 题号：面试题 02.04
- 难度：中等
- LeetCode：[分割链表](https://leetcode.cn/problems/partition-list-lcci/)

## 题目描述
给定链表和值 `x`，将链表按 `x` 分割：所有 `< x` 的节点在前，`>= x` 的节点在后，并保持原相对顺序。

## 示例
- 示例  
输入：`head = [3,5,8,5,10,2,1]`, `x = 5`  
输出：`[3,2,1,5,8,5,10]`

## 最佳解法思路
- 思路1（推荐）：两条链表拼接  
分别用 `small` 收集 `<x` 的节点、`big` 收集 `>=x` 的节点，最后把 `small` 尾接到 `big` 头即可。

## Java 最佳实现

```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode sDummy = new ListNode(0);
        ListNode bDummy = new ListNode(0);
        ListNode s = sDummy, b = bDummy;
        while (head != null) {
            ListNode next = head.next;
            head.next = null;
            if (head.val < x) {
                s.next = head;
                s = s.next;
            } else {
                b.next = head;
                b = b.next;
            }
            head = next;
        }
        s.next = bDummy.next;
        return sDummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 稳定分割就用两条链：小于一条、其余一条，最后拼起来。
