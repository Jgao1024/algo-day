# 859. 亲密字符串

- 题号：859
- 难度：简单
- LeetCode：[亲密字符串](https://leetcode.cn/problems/buddy-strings/)

## 题目描述
给定两个字符串 `s`、`goal`，你最多交换 `s` 中的两个字符一次，判断能否得到 `goal`。

## 示例
- 示例1  
输入：`s = "ab", goal = "ba"`  
输出：`true`

- 示例2  
输入：`s = "ab", goal = "ab"`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：分类讨论  
若 `s.length != goal.length` 返回 false。  
若 `s == goal`：要能“交换一次后仍相等”，必须存在重复字符（交换两个相同字符）。  
若不相等：找出所有不同位置，必须恰好 2 个，并且交换后能相等。

## Java 最佳实现

```java
class Solution {
    public boolean buddyStrings(String s, String goal) {
        if (s.length() != goal.length()) return false;
        if (s.equals(goal)) {
            int[] cnt = new int[26];
            for (int i = 0; i < s.length(); i++) {
                int c = s.charAt(i) - 'a';
                if (++cnt[c] >= 2) return true;
            }
            return false;
        }

        int first = -1, second = -1;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != goal.charAt(i)) {
                if (first == -1) first = i;
                else if (second == -1) second = i;
                else return false;
            }
        }
        if (second == -1) return false;
        return s.charAt(first) == goal.charAt(second) && s.charAt(second) == goal.charAt(first);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 不相等：必须恰好两处不同且可交叉匹配；相等：必须有重复字符才能“交换不变”。
