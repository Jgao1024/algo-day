# 面试题 17.08. 马戏团人塔

- 题号：面试题 17.08
- 难度：中等
- LeetCode：[马戏团人塔](https://leetcode.cn/problems/circus-tower-lcci/)

## 题目描述
给定一组人，每个人有身高和体重。若 A 的身高和体重都严格小于 B，则 A 可以站在 B 上面。求能叠出的最高人塔高度（人数最大）。

## 示例
- 示例  
输入：`height=[65,70,56,75,60,68], weight=[100,150,90,190,95,110]`  
输出：`6`

## 最佳解法思路
- 思路1（推荐）：排序 + LIS  
先按身高升序排序，身高相同则按体重降序（防止相同身高被错误计入）。  
然后对体重做“严格递增”的 LIS，长度就是答案。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int bestSeqAtIndex(int[] height, int[] weight) {
        int n = height.length;
        int[][] a = new int[n][2];
        for (int i = 0; i < n; i++) {
            a[i][0] = height[i];
            a[i][1] = weight[i];
        }
        Arrays.sort(a, (x, y) -> x[0] != y[0] ? x[0] - y[0] : y[1] - x[1]);

        int[] tails = new int[n];
        int size = 0;
        for (int i = 0; i < n; i++) {
            int w = a[i][1];
            int l = 0, r = size;
            while (l < r) {
                int mid = (l + r) >>> 1;
                if (tails[mid] >= w) r = mid;
                else l = mid + 1;
            }
            tails[l] = w;
            if (l == size) size++;
        }
        return size;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 先按身高排（同高体重降序），再对体重做严格 LIS。
