# 423. 从英文中重建数字

- 题号：423
- 难度：中等
- LeetCode：[从英文中重建数字](https://leetcode.cn/problems/reconstruct-original-digits-from-english/)

## 题目描述
给定一个被打乱顺序的英文小写字母字符串 `s`，它由若干数字单词（zero~nine）组成，返回原数字按升序拼接的字符串。

## 示例
- 示例  
输入：`s = "owoztneoer"`  
输出：`"012"`

## 最佳解法思路
- 思路1（推荐）：用“唯一字母”确定数字个数  
某些字母只出现在某个数字单词中：  
`z->0, w->2, u->4, x->6, g->8`  
确定这些后，再用剩余字母推：  
`h->3(扣掉8)`, `f->5(扣掉4)`, `s->7(扣掉6)`, `o->1(扣掉0/2/4)`, `i->9(扣掉5/6/8)`。

## Java 最佳实现

```java
class Solution {
    public String originalDigits(String s) {
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) cnt[s.charAt(i) - 'a']++;

        int[] num = new int[10];
        num[0] = cnt['z' - 'a'];
        num[2] = cnt['w' - 'a'];
        num[4] = cnt['u' - 'a'];
        num[6] = cnt['x' - 'a'];
        num[8] = cnt['g' - 'a'];

        num[3] = cnt['h' - 'a'] - num[8];
        num[5] = cnt['f' - 'a'] - num[4];
        num[7] = cnt['s' - 'a'] - num[6];
        num[1] = cnt['o' - 'a'] - num[0] - num[2] - num[4];
        num[9] = cnt['i' - 'a'] - num[5] - num[6] - num[8];

        StringBuilder sb = new StringBuilder();
        for (int d = 0; d <= 9; d++) {
            for (int k = 0; k < num[d]; k++) sb.append(d);
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(|s|)\)
- 空间：\(O(1)\)
