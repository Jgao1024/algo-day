# 1135. 最低成本联通所有城市

- 题号：1135
- 难度：中等
- LeetCode：[最低成本联通所有城市](https://leetcode.cn/problems/connecting-cities-with-minimum-cost/)

## 题目描述
有 `n` 个城市与若干连接 `connections[i]=[a,b,cost]`，选择一些边使所有城市联通且总成本最小，返回最小成本；若无法联通返回 -1。

## 示例
- 示例  
输入：`n=3, connections=[[1,2,5],[1,3,6],[2,3,1]]`  
输出：`6`

## 最佳解法思路
- 思路1（推荐）：最小生成树（Kruskal）  
按边权从小到大排序，能连就连（并查集合并）。  
最终选边数为 `n-1` 且连通，则得到最小成本；否则返回 -1。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minimumCost(int n, int[][] connections) {
        Arrays.sort(connections, (a, b) -> a[2] - b[2]);
        UF uf = new UF(n + 1);
        int cost = 0;
        int edges = 0;
        for (int[] e : connections) {
            if (uf.union(e[0], e[1])) {
                cost += e[2];
                edges++;
                if (edges == n - 1) break;
            }
        }
        return edges == n - 1 ? cost : -1;
    }

    private static class UF {
        int[] p;
        int[] r;
        UF(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) p[i] = i;
        }
        int find(int x) {
            while (p[x] != x) {
                p[x] = p[p[x]];
                x = p[x];
            }
            return x;
        }
        boolean union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return false;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
            return true;
        }
    }
}
```

- 时间：\(O(m\log m)\)
- 空间：\(O(n)\)
