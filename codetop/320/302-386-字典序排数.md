# 386. 字典序排数

- 题号：386
- 难度：中等
- LeetCode：[字典序排数](https://leetcode.cn/problems/lexicographical-numbers/)

## 题目描述
给定整数 `n`，按字典序返回 `1..n` 的所有整数（不允许整体排序）。

## 示例
- 示例  
输入：`n = 13`  
输出：`[1,10,11,12,13,2,3,4,5,6,7,8,9]`

## 最佳解法思路
- 思路1（推荐）：迭代 DFS（十叉树先序）  
把数字看成前缀树：从 1 开始，能深入就乘 10；不能深入就回退到能 +1 的前缀。  
这样能以 \(O(n)\) 生成字典序结果。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> res = new ArrayList<>(n);
        int cur = 1;
        for (int i = 0; i < n; i++) {
            res.add(cur);
            if (cur * 10 <= n) {
                cur *= 10;
            } else {
                while (cur % 10 == 9 || cur + 1 > n) cur /= 10;
                cur++;
            }
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出）

- 规则：能下潜 `*10` 就下潜；否则不断回退到能 `+1` 的位置。
