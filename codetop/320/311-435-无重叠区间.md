# 435. 无重叠区间

- 题号：435
- 难度：中等
- LeetCode：[无重叠区间](https://leetcode.cn/problems/non-overlapping-intervals/)

## 题目描述
给定区间数组 `intervals`，返回为了让区间互不重叠需要移除的最少区间数。

## 示例
- 示例  
输入：`intervals = [[1,2],[2,3],[3,4],[1,3]]`  
输出：`1`

## 最佳解法思路
- 思路1（推荐）：贪心（按结束时间排序）  
按区间右端点从小到大排序，尽量保留结束更早的区间。  
维护当前已选区间的 `end`，若下一个区间 `start < end` 则重叠，需要删除；否则更新 `end`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
        int end = intervals[0][1];
        int remove = 0;
        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] < end) {
                remove++;
            } else {
                end = intervals[i][1];
            }
        }
        return remove;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不计排序）
