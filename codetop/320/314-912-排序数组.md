# 912. 排序数组

- 题号：912
- 难度：中等
- LeetCode：[排序数组](https://leetcode.cn/problems/sort-an-array/)

## 题目描述
给定整数数组 `nums`，将其按升序排序并返回（可实现任意 \(O(n\log n)\) 排序）。

## 示例
- 示例  
输入：`nums = [5,2,3,1]`  
输出：`[1,2,3,5]`

## 最佳解法思路
- 思路1（推荐）：归并排序  
分治把数组拆成两半排序后再合并，稳定、时间 \(O(n\log n)\)。  
用一个临时数组复用，减少反复分配。

## Java 最佳实现

```java
class Solution {
    public int[] sortArray(int[] nums) {
        int[] tmp = new int[nums.length];
        mergeSort(nums, 0, nums.length - 1, tmp);
        return nums;
    }

    private void mergeSort(int[] a, int l, int r, int[] tmp) {
        if (l >= r) return;
        int m = l + (r - l) / 2;
        mergeSort(a, l, m, tmp);
        mergeSort(a, m + 1, r, tmp);
        merge(a, l, m, r, tmp);
    }

    private void merge(int[] a, int l, int m, int r, int[] tmp) {
        int i = l, j = m + 1, k = l;
        while (i <= m && j <= r) {
            if (a[i] <= a[j]) tmp[k++] = a[i++];
            else tmp[k++] = a[j++];
        }
        while (i <= m) tmp[k++] = a[i++];
        while (j <= r) tmp[k++] = a[j++];
        for (int p = l; p <= r; p++) a[p] = tmp[p];
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
