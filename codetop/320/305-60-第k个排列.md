# 60. 第k个排列

- 题号：60
- 难度：困难
- LeetCode：[第k个排列](https://leetcode.cn/problems/permutation-sequence/)

## 题目描述
给定 `n` 和 `k`，返回由 `1..n` 组成的所有排列按字典序排序后的第 `k` 个排列（从 1 开始计数）。

## 示例
- 示例  
输入：`n = 3, k = 3`  
输出：`"213"`

## 最佳解法思路
- 思路1（推荐）：阶乘数系统（选第几块）  
总共有 `n!` 个排列。第 `1` 位每个数字会贡献 `(n-1)!` 个排列块。  
把 `k` 转成 0 基（`k--`），每次用 `k / fact` 选当前位的数字，再 `k %= fact` 继续。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String getPermutation(int n, int k) {
        int[] fact = new int[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i;

        List<Integer> nums = new ArrayList<>();
        for (int i = 1; i <= n; i++) nums.add(i);

        k--;
        StringBuilder sb = new StringBuilder();
        for (int i = n; i >= 1; i--) {
            int block = fact[i - 1];
            int idx = k / block;
            sb.append(nums.remove(idx));
            k %= block;
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)（`remove(idx)` 线性）
- 空间：\(O(n)\)

## 总结（速记）
- `k--` 变 0 基；每位用 `k / (i-1)!` 选数字，用 `k %=` 更新剩余。
