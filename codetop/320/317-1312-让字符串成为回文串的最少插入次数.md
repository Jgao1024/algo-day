# 1312. 让字符串成为回文串的最少插入次数

- 题号：1312
- 难度：困难
- LeetCode：[让字符串成为回文串的最少插入次数](https://leetcode.cn/problems/minimum-insertion-steps-to-make-a-string-palindrome/)

## 题目描述
给定字符串 `s`，每次可以在任意位置插入一个字符，使字符串变成回文串。  
返回最少插入次数。

## 示例
- 示例  
输入：`s = "mbadm"`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：区间 DP  
`dp[i][j]` 表示让 `s[i..j]` 变成回文的最少插入次数。  
若 `s[i]==s[j]`：`dp[i][j]=dp[i+1][j-1]`；否则 `dp[i][j]=min(dp[i+1][j], dp[i][j-1]) + 1`。  
按区间长度从小到大填表。

## Java 最佳实现

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i + 1][j], dp[i][j - 1]) + 1;
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)

## 总结（速记）
- 区间 DP：两端相等就缩一圈；不等就向内插一次（取两种缩法最小 +1）。
