# 306. 累加数

- 题号：306
- 难度：中等
- LeetCode：[累加数](https://leetcode.cn/problems/additive-number/)

## 题目描述
给定一个字符串 `num`，判断它是否为累加数：  
从左到右分成至少 3 个数，满足从第三个数开始，每个数都等于前两个数之和（不允许前导 0，除非该数就是 0）。

## 示例
- 示例  
输入：`num = "112358"`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：枚举前两个数 + 字符串加法校验  
枚举前两个数的切分位置（两层循环）。  
之后不断用字符串加法得到 `sum`，并判断剩余串是否以 `sum` 开头；匹配就继续推进窗口，直到结束。

## Java 最佳实现

```java
class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();
        for (int i = 1; i <= n - 2; i++) {
            if (num.charAt(0) == '0' && i > 1) break;
            for (int j = i + 1; j <= n - 1; j++) {
                if (num.charAt(i) == '0' && j - i > 1) break;
                String a = num.substring(0, i);
                String b = num.substring(i, j);
                int start = j;
                while (start < n) {
                    String sum = add(a, b);
                    if (!num.startsWith(sum, start)) break;
                    start += sum.length();
                    a = b;
                    b = sum;
                }
                if (start == n) return true;
            }
        }
        return false;
    }

    private String add(String x, String y) {
        int i = x.length() - 1;
        int j = y.length() - 1;
        int carry = 0;
        StringBuilder sb = new StringBuilder();
        while (i >= 0 || j >= 0 || carry != 0) {
            int a = i >= 0 ? x.charAt(i--) - '0' : 0;
            int b = j >= 0 ? y.charAt(j--) - '0' : 0;
            int s = a + b + carry;
            sb.append((char) ('0' + (s % 10)));
            carry = s / 10;
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)（枚举切分 + 字符串加法/匹配）
- 空间：\(O(n)\)

- 两层枚举前两段；后面反复“算和 + 前缀匹配”推进即可，注意前导 0。
