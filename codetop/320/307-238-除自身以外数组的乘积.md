# 238. 除自身以外数组的乘积

- 题号：238
- 难度：中等
- LeetCode：[除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)

## 题目描述
给定整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余元素的乘积。  
要求不使用除法，并且在 \(O(n)\) 时间内完成。

## 示例
- 示例  
输入：`nums = [1,2,3,4]`  
输出：`[24,12,8,6]`

## 最佳解法思路
- 思路1（推荐）：前缀积 + 后缀积（两趟）  
第一趟：`res[i]` 存 `i` 左侧所有数乘积（前缀）。  
第二趟：从右往左维护 `suffix`，把 `res[i] *= suffix`，并更新 `suffix *= nums[i]`。

## Java 最佳实现

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        res[0] = 1;
        for (int i = 1; i < n; i++) {
            res[i] = res[i - 1] * nums[i - 1];
        }
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= suffix;
            suffix *= nums[i];
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出数组）

## 总结（速记）
- `res[i]=左乘积`，再乘上 `右乘积`；右乘积用一个变量从右往左扫即可。
