# 523. 连续的子数组和

- 题号：523
- 难度：中等
- LeetCode：[连续的子数组和](https://leetcode.cn/problems/continuous-subarray-sum/)

## 题目描述
给定数组 `nums` 和整数 `k`，判断是否存在长度至少为 2 的连续子数组，使其元素和是 `k` 的倍数。

## 示例
- 示例  
输入：`nums = [23,2,4,6,7], k = 6`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：前缀和取模 + 记录最早位置  
设前缀和 `sum[i]`，若 `sum[i] % k == sum[j] % k`，则区间 `(j, i]` 的和可被 `k` 整除。  
用 map 记录每个余数第一次出现的下标，保证长度至少 2（`i - firstIdx >= 2`）。  
注意 `k` 可能为 0：此时只需判断是否存在连续两个 0。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        if (k == 0) {
            for (int i = 1; i < nums.length; i++) {
                if (nums[i] == 0 && nums[i - 1] == 0) return true;
            }
            return false;
        }

        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, -1);
        int mod = 0;
        for (int i = 0; i < nums.length; i++) {
            mod = (mod + nums[i]) % k;
            if (first.containsKey(mod)) {
                if (i - first.get(mod) >= 2) return true;
            } else {
                first.put(mod, i);
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(\min(n, |k|))\)

- 判断类：存“余数最早位置”；再遇到同余数且间隔 \(\ge 2\) 就成立。
