# 735. 行星碰撞

- 题号：735
- 难度：中等
- LeetCode：[行星碰撞](https://leetcode.cn/problems/asteroid-collision/)

## 题目描述
给定整数数组 `asteroids`，正数表示向右，负数表示向左。相向而行会碰撞：小的爆炸；相等都爆炸。  
返回所有碰撞结束后剩下的行星。

## 示例
- 示例  
输入：`asteroids = [5,10,-5]`  
输出：`[5,10]`

## 最佳解法思路
- 思路1（推荐）：栈模拟  
只有一种会碰撞：栈顶向右（`>0`）且新行星向左（`<0`）。  
循环比较大小并消除，直到不再碰撞为止。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> st = new ArrayDeque<>();
        for (int a : asteroids) {
            boolean alive = true;
            while (alive && a < 0 && !st.isEmpty() && st.peek() > 0) {
                int b = st.peek();
                if (b < -a) {
                    st.pop();
                } else if (b == -a) {
                    st.pop();
                    alive = false;
                } else {
                    alive = false;
                }
            }
            if (alive) st.push(a);
        }
        int[] res = new int[st.size()];
        for (int i = res.length - 1; i >= 0; i--) res[i] = st.pop();
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

- 只处理“右 + 左”相撞：`top>0 && cur<0`，循环消到稳定。
