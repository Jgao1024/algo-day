# 437. 路径总和 III

- 题号：437
- 难度：中等
- LeetCode：[路径总和 III](https://leetcode.cn/problems/path-sum-iii/)

## 题目描述
给定二叉树 `root` 和目标和 `targetSum`，统计路径和等于 `targetSum` 的路径数量。  
路径必须向下（父到子），但不要求从根开始，也不要求在叶子结束。

## 示例
- 示例  
输入：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：前缀和 + DFS + HashMap  
沿着根到当前节点维护前缀和 `sum`。  
若存在祖先前缀和 `sum - targetSum`，则从该祖先下一节点到当前节点的路径和为 `targetSum`。  
用 map 记录“某个前缀和出现次数”，递归进入子树前 +1，退出时 -1（回溯）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        Map<Long, Integer> cnt = new HashMap<>();
        cnt.put(0L, 1);
        return dfs(root, 0L, targetSum, cnt);
    }

    private int dfs(TreeNode node, long sum, int target, Map<Long, Integer> cnt) {
        if (node == null) return 0;
        sum += node.val;
        int ans = cnt.getOrDefault(sum - target, 0);

        cnt.put(sum, cnt.getOrDefault(sum, 0) + 1);
        ans += dfs(node.left, sum, target, cnt);
        ans += dfs(node.right, sum, target, cnt);
        cnt.put(sum, cnt.get(sum) - 1);
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
