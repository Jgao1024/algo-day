# 剑指 Offer 07. 重建二叉树

- 题号：剑指 Offer 07
- 难度：中等
- LeetCode：[重建二叉树](https://leetcode.cn/problems/zhong-jian-er-cha-shu-lcof/)

## 题目描述
给定二叉树的前序遍历 `preorder` 和中序遍历 `inorder`（无重复），重建该二叉树并返回根节点。

## 示例
- 示例  
输入：`preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]`  
输出：`[3,9,20,null,null,15,7]`

## 最佳解法思路
- 思路1（推荐）：递归分治 + 哈希表  
前序的第一个元素是根；在中序里找到根的位置即可确定左子树大小。  
用哈希表 `value -> inorderIndex`，递归构建左右子树。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[] preorder;
    private int[] inorder;
    private Map<Integer, Integer> idx = new HashMap<>();
    private int prePos = 0;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        this.inorder = inorder;
        for (int i = 0; i < inorder.length; i++) idx.put(inorder[i], i);
        return build(0, inorder.length - 1);
    }

    private TreeNode build(int inL, int inR) {
        if (inL > inR) return null;
        int rootVal = preorder[prePos++];
        TreeNode root = new TreeNode(rootVal);
        int k = idx.get(rootVal);
        root.left = build(inL, k - 1);
        root.right = build(k + 1, inR);
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（哈希表 + 递归栈）

## 总结（速记）
- 前序定根，中序切左右；哈希表定位根下标即可 \(O(n)\)。
