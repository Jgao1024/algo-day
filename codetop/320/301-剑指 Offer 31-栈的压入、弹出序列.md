# 剑指 Offer 31. 栈的压入、弹出序列

- 题号：剑指 Offer 31
- 难度：中等
- LeetCode：[栈的压入、弹出序列](https://leetcode.cn/problems/zhan-de-ya-ru-dan-chu-xu-lie-lcof/)

## 题目描述
给定两个整数数组 `pushed`、`popped`，分别表示栈的压入顺序和弹出顺序。  
判断 `popped` 是否可能是 `pushed` 的某种合法出栈序列。

## 示例
- 示例  
输入：`pushed = [1,2,3,4,5], popped = [4,5,3,2,1]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：模拟栈  
按 `pushed` 依次入栈；每次入栈后，尽量把栈顶等于当前 `popped[idx]` 的元素弹出。  
最终若能把 `popped` 全部匹配完，则为合法序列。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        Deque<Integer> st = new ArrayDeque<>();
        int j = 0;
        for (int x : pushed) {
            st.push(x);
            while (!st.isEmpty() && j < popped.length && st.peek() == popped[j]) {
                st.pop();
                j++;
            }
        }
        return j == popped.length;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
