# 补充题21. 字符串相减

- 题号：补充题21
- 难度：中等
- LeetCode：[字符串相减](https://leetcode.cn/problems/https://mp.weixin.qq.com/s/RtAoA1hdf0h1PaVxRj_fzA/)

## 题目描述
给定两个非负整数字符串 `a`、`b`（十进制），返回 `a - b` 的结果字符串。  
不使用大整数类，结果可为负数。

## 示例
- 示例  
输入：`a = "1000", b = "1"`  
输出：`"999"`

## 最佳解法思路
- 思路1（推荐）：模拟竖式减法  
先比较 `a` 和 `b` 的大小，确定结果符号；保证用较大数减较小数。  
从末位开始逐位相减，处理借位 `borrow`，最后去掉前导 0。

## Java 最佳实现

```java
class Solution {
    public String sub(String a, String b) {
        a = trim(a);
        b = trim(b);
        if (a.equals("0") && b.equals("0")) return "0";

        int cmp = cmp(a, b);
        if (cmp == 0) return "0";

        boolean neg = cmp < 0;
        String x = neg ? b : a;
        String y = neg ? a : b;

        int i = x.length() - 1;
        int j = y.length() - 1;
        int borrow = 0;
        StringBuilder sb = new StringBuilder();
        while (i >= 0) {
            int p = x.charAt(i--) - '0';
            int q = j >= 0 ? y.charAt(j--) - '0' : 0;
            int v = p - borrow - q;
            if (v < 0) {
                v += 10;
                borrow = 1;
            } else {
                borrow = 0;
            }
            sb.append((char) ('0' + v));
        }

        while (sb.length() > 1 && sb.charAt(sb.length() - 1) == '0') sb.deleteCharAt(sb.length() - 1);
        if (neg) sb.append('-');
        return sb.reverse().toString();
    }

    private String trim(String s) {
        int i = 0;
        while (i < s.length() - 1 && s.charAt(i) == '0') i++;
        return s.substring(i);
    }

    private int cmp(String a, String b) {
        if (a.length() != b.length()) return a.length() > b.length() ? 1 : -1;
        for (int i = 0; i < a.length(); i++) {
            char x = a.charAt(i), y = b.charAt(i);
            if (x != y) return x > y ? 1 : -1;
        }
        return 0;
    }
}
```
