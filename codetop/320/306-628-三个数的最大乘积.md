# 628. 三个数的最大乘积

- 题号：628
- 难度：简单
- LeetCode：[三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers/)

## 题目描述
给定整数数组 `nums`，返回任意三个数的最大乘积。

## 示例
- 示例  
输入：`nums = [1,2,3,4]`  
输出：`24`

## 最佳解法思路
- 思路1（推荐）：一次遍历维护最大/最小  
最大乘积只可能来自两种情况：  
1) 三个最大数 `max1*max2*max3`  
2) 两个最小数（可能是负数）与最大数 `min1*min2*max1`  
遍历时维护 3 个最大值和 2 个最小值即可。

## Java 最佳实现

```java
class Solution {
    public int maximumProduct(int[] nums) {
        int max1 = Integer.MIN_VALUE, max2 = Integer.MIN_VALUE, max3 = Integer.MIN_VALUE;
        int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;
        for (int x : nums) {
            if (x > max1) { max3 = max2; max2 = max1; max1 = x; }
            else if (x > max2) { max3 = max2; max2 = x; }
            else if (x > max3) { max3 = x; }

            if (x < min1) { min2 = min1; min1 = x; }
            else if (x < min2) { min2 = x; }
        }
        return Math.max(max1 * max2 * max3, min1 * min2 * max1);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
