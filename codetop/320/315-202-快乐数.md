# 202. 快乐数

- 题号：202
- 难度：简单
- LeetCode：[快乐数](https://leetcode.cn/problems/happy-number/)

## 题目描述
对一个正整数 `n` 反复执行：把它替换为其各位数字的平方和。  
如果最终能变成 1，则为快乐数；如果进入循环则不是。判断 `n` 是否为快乐数。

## 示例
- 示例  
输入：`n = 19`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：快慢指针判环（Floyd）  
把“平方和函数”看作链表 next。  
若会到 1 则快乐；否则会形成环，用快慢指针判断是否有环。

## Java 最佳实现

```java
class Solution {
    public boolean isHappy(int n) {
        int slow = n;
        int fast = next(n);
        while (fast != 1 && slow != fast) {
            slow = next(slow);
            fast = next(next(fast));
        }
        return fast == 1;
    }

    private int next(int x) {
        int sum = 0;
        while (x > 0) {
            int d = x % 10;
            sum += d * d;
            x /= 10;
        }
        return sum;
    }
}
```

## 复杂度分析
- 时间：\(O(\text{迭代次数} \cdot \log_{10} n)\)（迭代次数有上界）
- 空间：\(O(1)\)

## 总结（速记）
- 不是快乐数就会“进环”；用快慢指针判环即可。
