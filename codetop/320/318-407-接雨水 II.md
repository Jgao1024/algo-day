# 407. 接雨水 II

- 题号：407
- 难度：困难
- LeetCode：[接雨水 II](https://leetcode.cn/problems/trapping-rain-water-ii/)

## 题目描述
给定 `m x n` 高度图 `heightMap`，每个格子是一个柱子高度。  
求这个二维地形最多能接多少雨水。

## 示例
- 示例  
输入：  
`heightMap = [[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：最小堆 + BFS（从边界往里灌水）  
把所有边界格子入最小堆（高度小的先处理），并标记 visited。  
每次弹出最矮边界 `h`，看它的四邻：  
若邻居更低，则能接水 `h - neighbor`；邻居入堆的“有效高度”是 `max(h, neighbor)`，相当于更新新的边界高度。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class Solution {
    static class Cell {
        int r, c, h;
        Cell(int r, int c, int h) {
            this.r = r;
            this.c = c;
            this.h = h;
        }
    }

    public int trapRainWater(int[][] heightMap) {
        int m = heightMap.length;
        int n = heightMap[0].length;
        if (m <= 2 || n <= 2) return 0;

        boolean[][] vis = new boolean[m][n];
        PriorityQueue<Cell> pq = new PriorityQueue<>((a, b) -> a.h - b.h);
        for (int i = 0; i < m; i++) {
            pq.offer(new Cell(i, 0, heightMap[i][0]));
            pq.offer(new Cell(i, n - 1, heightMap[i][n - 1]));
            vis[i][0] = true;
            vis[i][n - 1] = true;
        }
        for (int j = 1; j < n - 1; j++) {
            pq.offer(new Cell(0, j, heightMap[0][j]));
            pq.offer(new Cell(m - 1, j, heightMap[m - 1][j]));
            vis[0][j] = true;
            vis[m - 1][j] = true;
        }

        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};
        int ans = 0;
        while (!pq.isEmpty()) {
            Cell cur = pq.poll();
            for (int k = 0; k < 4; k++) {
                int nr = cur.r + dr[k];
                int nc = cur.c + dc[k];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || vis[nr][nc]) continue;
                vis[nr][nc] = true;
                int nh = heightMap[nr][nc];
                if (nh < cur.h) ans += (cur.h - nh);
                pq.offer(new Cell(nr, nc, Math.max(nh, cur.h)));
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn\log(mn))\)
- 空间：\(O(mn)\)
