# 658. 找到 K 个最接近的元素

- 题号：658
- 难度：中等
- LeetCode：[找到 K 个最接近的元素](https://leetcode.cn/problems/find-k-closest-elements/)

## 题目描述
给定有序数组 `arr`、整数 `k`、目标 `x`，返回最接近 `x` 的 `k` 个元素（升序）。  
若距离相等，取较小的元素。

## 示例
- 示例  
输入：`arr = [1,2,3,4,5], k = 4, x = 3`  
输出：`[1,2,3,4]`

## 最佳解法思路
- 思路1（推荐）：二分答案窗口左边界  
答案一定是长度为 `k` 的连续子数组。  
在所有窗口 `[mid, mid+k-1]` 中二分左边界：  
若 `x - arr[mid] > arr[mid+k] - x`，说明窗口偏左，左边界应右移；否则左移/不动。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        int n = arr.length;
        int l = 0, r = n - k;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (x - arr[mid] > arr[mid + k] - x) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        List<Integer> res = new ArrayList<>(k);
        for (int i = l; i < l + k; i++) res.add(arr[i]);
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(\log(n-k) + k)\)
- 空间：\(O(1)\)（不计输出）
