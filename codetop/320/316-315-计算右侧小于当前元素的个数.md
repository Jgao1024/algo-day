# 315. 计算右侧小于当前元素的个数

- 题号：315
- 难度：困难
- LeetCode：[计算右侧小于当前元素的个数](https://leetcode.cn/problems/count-of-smaller-numbers-after-self/)

## 题目描述
给定整数数组 `nums`，返回数组 `counts`，其中 `counts[i]` 表示 `nums[i]` 右侧比它小的元素个数。

## 示例
- 示例  
输入：`nums = [5,2,6,1]`  
输出：`[2,1,1,0]`

## 最佳解法思路
- 思路1（推荐）：归并排序统计逆序对贡献  
用归并排序按值排序下标数组。  
在合并过程中，若右半部分元素先放入（更小），说明它会对左半部分尚未放入的元素产生“右侧更小”的贡献。  
具体做法：当选择左元素时，把已放入的右元素数量 `rightCount` 加到该左元素的答案上。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        int[] idx = new int[n];
        int[] tmp = new int[n];
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        mergeSort(nums, idx, 0, n - 1, tmp, ans);
        List<Integer> res = new ArrayList<>(n);
        for (int x : ans) res.add(x);
        return res;
    }

    private void mergeSort(int[] nums, int[] idx, int l, int r, int[] tmp, int[] ans) {
        if (l >= r) return;
        int m = l + (r - l) / 2;
        mergeSort(nums, idx, l, m, tmp, ans);
        mergeSort(nums, idx, m + 1, r, tmp, ans);
        merge(nums, idx, l, m, r, tmp, ans);
    }

    private void merge(int[] nums, int[] idx, int l, int m, int r, int[] tmp, int[] ans) {
        int i = l, j = m + 1, k = l;
        int rightCount = 0;
        while (i <= m && j <= r) {
            if (nums[idx[j]] < nums[idx[i]]) {
                tmp[k++] = idx[j++];
                rightCount++;
            } else {
                ans[idx[i]] += rightCount;
                tmp[k++] = idx[i++];
            }
        }
        while (i <= m) {
            ans[idx[i]] += rightCount;
            tmp[k++] = idx[i++];
        }
        while (j <= r) tmp[k++] = idx[j++];
        for (int p = l; p <= r; p++) idx[p] = tmp[p];
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
