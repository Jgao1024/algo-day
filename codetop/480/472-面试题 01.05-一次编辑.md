## 最佳解法思路
- **双指针一次跳过**  
长度差超过 1 直接 `false`。  
用双指针从左到右比较：
  - 相等就一起走
  - 不相等则消耗一次“编辑机会”，并根据长度关系决定：
    - 等长：两边都走（替换）
    - 长的多 1：只走长的（删除/插入）

## Java 最佳实现

```java
class Solution {
    public boolean oneEditAway(String first, String second) {
        int n = first.length();
        int m = second.length();
        if (Math.abs(n - m) > 1) return false;
        if (n < m) return oneEditAway(second, first);

        int i = 0;
        int j = 0;
        boolean used = false;
        while (i < n && j < m) {
            if (first.charAt(i) == second.charAt(j)) {
                i++;
                j++;
                continue;
            }
            if (used) return false;
            used = true;
            if (n == m) {
                i++;
                j++;
            } else {
                i++;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
