## 最佳解法思路
- **DFS 记录形状（相对坐标）**  
遍历网格，遇到新岛屿就 DFS，把每个陆地格子记录为相对起点 `(r-baseR, c-baseC)`，用固定遍历顺序把这些相对坐标拼成字符串，放入 `Set` 去重。`Set` 的大小就是不同形状岛屿的数量。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int numDistinctIslands(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        boolean[][] vis = new boolean[m][n];
        Set<String> set = new HashSet<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1 && !vis[i][j]) {
                    StringBuilder sb = new StringBuilder();
                    dfs(grid, vis, i, j, i, j, sb);
                    set.add(sb.toString());
                }
            }
        }
        return set.size();
    }

    private void dfs(int[][] g, boolean[][] vis, int r, int c, int br, int bc, StringBuilder sb) {
        int m = g.length;
        int n = g[0].length;
        if (r < 0 || r >= m || c < 0 || c >= n) return;
        if (g[r][c] == 0 || vis[r][c]) return;
        vis[r][c] = true;
        sb.append(r - br).append(',').append(c - bc).append(';');
        dfs(g, vis, r + 1, c, br, bc, sb);
        dfs(g, vis, r - 1, c, br, bc, sb);
        dfs(g, vis, r, c + 1, br, bc, sb);
        dfs(g, vis, r, c - 1, br, bc, sb);
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
