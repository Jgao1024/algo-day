## 最佳解法思路
- **拼接 + 子串判断**  
如果 `s` 和 `goal` 长度相等，那么 `goal` 是 `s` 的旋转，当且仅当 `goal` 是 `s+s` 的子串。

## Java 最佳实现

```java
class Solution {
    public boolean rotateString(String s, String goal) {
        if (s.length() != goal.length()) return false;
        return (s + s).contains(goal);
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)（`contains` 最坏）
- 空间：\(O(n)\)
