## 最佳解法思路
- **递归 + 位运算拆半（俄罗斯农民乘法）**  
用加法实现乘法：把较小的数 `smaller` 每次右移一位（除 2），较大的数 `bigger` 保持不变。  
递归计算 `half = multiply(smaller>>1, bigger)`：
  - 若 `smaller` 是偶数：结果是 `half + half`
  - 若 `smaller` 是奇数：结果是 `half + half + bigger`

## Java 最佳实现

```java
class Solution {
    public int multiply(int A, int B) {
        int bigger = Math.max(A, B);
        int smaller = Math.min(A, B);
        return mul(smaller, bigger);
    }

    private int mul(int smaller, int bigger) {
        if (smaller == 0) return 0;
        if (smaller == 1) return bigger;
        int half = mul(smaller >> 1, bigger);
        int ans = half + half;
        if ((smaller & 1) == 1) ans += bigger;
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log(\min(A,B)))\)
- 空间：\(O(\log(\min(A,B)))\)
