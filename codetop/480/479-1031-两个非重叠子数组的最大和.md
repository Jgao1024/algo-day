## 最佳解法思路
- **前缀和 + 滚动维护“左边最优”**  
分别考虑两种顺序：`firstLen` 在左、`secondLen` 在右；以及交换顺序，取最大值。  
扫描右边子数组起点 `start2`，同时维护 `start2` 左侧（不重叠）的长度为 `len1` 的最大子数组和 `best1`，则答案候选为 `best1 + sum(start2, len2)`。

## Java 最佳实现

```java
class Solution {
    public int maxSumTwoNoOverlap(int[] nums, int firstLen, int secondLen) {
        return Math.max(calc(nums, firstLen, secondLen), calc(nums, secondLen, firstLen));
    }

    private int calc(int[] nums, int len1, int len2) {
        int n = nums.length;
        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];

        int best1 = sum(pre, 0, len1);
        int ans = 0;
        for (int start2 = len1; start2 <= n - len2; start2++) {
            best1 = Math.max(best1, sum(pre, start2 - len1, len1));
            ans = Math.max(ans, best1 + sum(pre, start2, len2));
        }
        return ans;
    }

    private int sum(int[] pre, int start, int len) {
        return pre[start + len] - pre[start];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
