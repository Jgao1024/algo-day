## 最佳解法思路
- **双向映射**  
用两个数组分别记录 `s -> t`、`t -> s` 的映射关系。遍历每一位字符：
  - 若某方向已建立映射但与当前不一致，直接返回 `false`
  - 否则建立/保持映射

这样能保证一一对应（既不“多对一”，也不“一对多”）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) return false;

        int[] st = new int[256];
        int[] ts = new int[256];
        Arrays.fill(st, -1);
        Arrays.fill(ts, -1);

        for (int i = 0; i < s.length(); i++) {
            int a = s.charAt(i);
            int b = t.charAt(i);
            if ((st[a] != -1 && st[a] != b) || (ts[b] != -1 && ts[b] != a)) {
                return false;
            }
            st[a] = b;
            ts[b] = a;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
