## 最佳解法思路
- **位运算消 1（n & (n-1)）**  
每次执行 `n &= (n - 1)` 会把 `n` 的最低位 `1` 变成 `0`，循环次数等于 1 的个数。

## Java 最佳实现

```java
public class Solution {
    public int hammingWeight(int n) {
        int cnt = 0;
        while (n != 0) {
            n &= (n - 1);
            cnt++;
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(\text{1 的个数})\)
- 空间：\(O(1)\)
