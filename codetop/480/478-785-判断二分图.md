## 最佳解法思路
- **BFS/DFS 染色**  
用 `color[i]` 表示点的颜色（0 未染色，1/-1 两种颜色）。  
对每个连通分量做 BFS：给起点染色 1，遍历边 `(u,v)`，若 `v` 未染色就染成 `-color[u]`；若已染色且等于 `color[u]`，说明出现奇环，不是二分图。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n];
        Queue<Integer> q = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            if (color[i] != 0) continue;
            color[i] = 1;
            q.add(i);
            while (!q.isEmpty()) {
                int u = q.poll();
                for (int v : graph[u]) {
                    if (color[v] == 0) {
                        color[v] = -color[u];
                        q.add(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
}
```

- 时间：\(O(V+E)\)
- 空间：\(O(V)\)
