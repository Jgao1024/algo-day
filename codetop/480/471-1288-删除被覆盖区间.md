## 最佳解法思路
- **排序 + 扫描**  
先按 `start` 升序；若 `start` 相同按 `end` 降序。  
扫描区间，维护当前能覆盖到的最远 `maxEnd`：
  - 若当前 `end <= maxEnd`，说明被覆盖
  - 否则更新 `maxEnd = end`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0];
            return b[1] - a[1];
        });

        int covered = 0;
        int maxEnd = -1;
        for (int[] it : intervals) {
            if (it[1] <= maxEnd) {
                covered++;
            } else {
                maxEnd = it[1];
            }
        }
        return intervals.length - covered;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（排序额外空间视实现）
