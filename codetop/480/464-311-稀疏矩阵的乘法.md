## 最佳解法思路
- **只遍历非零元素**  
普通矩阵乘法是三重循环；稀疏矩阵里大量是 0，可以把 `mat2` 每一行的非零元素提前收集起来。  
遍历 `mat1[i][k] != 0` 时，只和 `mat2` 第 `k` 行的非零列相乘并累加到 `ans[i][j]`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int m = mat1.length;
        int k = mat1[0].length;
        int n = mat2[0].length;

        List<int[]>[] row = new List[k];
        for (int i = 0; i < k; i++) row[i] = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            for (int j = 0; j < n; j++) {
                if (mat2[i][j] != 0) {
                    row[i].add(new int[]{j, mat2[i][j]});
                }
            }
        }

        int[][] ans = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int x = 0; x < k; x++) {
                int a = mat1[i][x];
                if (a == 0) continue;
                for (int[] p : row[x]) {
                    ans[i][p[0]] += a * p[1];
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：约 \(O(\text{nnz}(mat1) \times \text{avgNnzRow}(mat2))\)
- 空间：\(O(\text{nnz}(mat2))\)
