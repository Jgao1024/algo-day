## 最佳解法思路
- **DFS + 记忆化（从终点回溯）**  
从 `(r,c)` 递归尝试从上/左走到起点；遇到障碍或越界返回失败。  
用 `bad[r][c]` 记录“从这里走不到起点”的格子，避免重复搜索；找到路径就把坐标加入答案（回溯顺序会得到从起点到终点的路径）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> pathWithObstacles(int[][] obstacleGrid) {
        List<List<Integer>> path = new ArrayList<>();
        if (obstacleGrid == null || obstacleGrid.length == 0 || obstacleGrid[0].length == 0) return path;
        int m = obstacleGrid.length;
        int n = obstacleGrid[0].length;
        boolean[][] bad = new boolean[m][n];
        if (dfs(obstacleGrid, m - 1, n - 1, bad, path)) return path;
        return new ArrayList<>();
    }

    private boolean dfs(int[][] g, int r, int c, boolean[][] bad, List<List<Integer>> path) {
        if (r < 0 || c < 0) return false;
        if (g[r][c] == 1) return false;
        if (bad[r][c]) return false;

        boolean ok = (r == 0 && c == 0)
                || dfs(g, r - 1, c, bad, path)
                || dfs(g, r, c - 1, bad, path);
        if (!ok) {
            bad[r][c] = true;
            return false;
        }
        List<Integer> p = new ArrayList<>(2);
        p.add(r);
        p.add(c);
        path.add(p);
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
