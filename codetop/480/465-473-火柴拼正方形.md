## 最佳解法思路
- **回溯 + 剪枝（把每根火柴放到 4 条边）**  
总和 `sum` 必须能被 4 整除，目标边长 `target = sum / 4`。把火柴按从大到小排序，优先放大火柴更容易剪枝。  
递归把第 `idx` 根火柴尝试放到 4 条边之一，只要不超过 `target`；如果某条边当前长度和上一条尝试过的一样，就跳过避免重复状态。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public boolean makesquare(int[] matchsticks) {
        int sum = 0;
        for (int x : matchsticks) sum += x;
        if (sum % 4 != 0) return false;
        int target = sum / 4;

        Arrays.sort(matchsticks);
        for (int i = 0, j = matchsticks.length - 1; i < j; i++, j--) {
            int t = matchsticks[i];
            matchsticks[i] = matchsticks[j];
            matchsticks[j] = t;
        }

        int[] side = new int[4];
        return dfs(matchsticks, 0, side, target);
    }

    private boolean dfs(int[] a, int idx, int[] side, int target) {
        if (idx == a.length) {
            return side[0] == target && side[1] == target && side[2] == target;
        }

        int x = a[idx];
        for (int i = 0; i < 4; i++) {
            if (side[i] + x > target) continue;
            if (i > 0 && side[i] == side[i - 1]) continue;
            side[i] += x;
            if (dfs(a, idx + 1, side, target)) return true;
            side[i] -= x;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：最坏指数级（回溯），排序 + 剪枝后通常很快
- 空间：\(O(n)\)（递归栈）
