## 最佳解法思路
- **快慢指针原地覆盖**  
用 `slow` 指向下一个可写位置，遍历 `nums[i]`，若不等于 `val` 就写到 `nums[slow++]`。返回 `slow` 即新长度。

## Java 最佳实现

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != val) {
                nums[slow++] = nums[i];
            }
        }
        return slow;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
