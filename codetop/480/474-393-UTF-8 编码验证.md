## 最佳解法思路
- **按首字节判断长度 + 校验续字节**  
首字节前导 1 的个数决定字符长度 `k`：
  - `0xxxxxxx`：1 字节
  - `110xxxxx`：2 字节
  - `1110xxxx`：3 字节
  - `11110xxx`：4 字节  
若 `k==1` 但首字节不是 0 开头（即 `10xxxxxx`），非法；接下来 `k-1` 个字节必须都满足 `10xxxxxx`。

## Java 最佳实现

```java
class Solution {
    public boolean validUtf8(int[] data) {
        int i = 0;
        while (i < data.length) {
            int b = data[i] & 0xFF;
            int k = countLeadingOnes(b);
            if (k == 0) {
                i++;
                continue;
            }
            if (k == 1 || k > 4) return false;
            if (i + k > data.length) return false;
            for (int j = 1; j < k; j++) {
                int nb = data[i + j] & 0xFF;
                if ((nb & 0xC0) != 0x80) return false;
            }
            i += k;
        }
        return true;
    }

    private int countLeadingOnes(int b) {
        int cnt = 0;
        for (int mask = 0x80; (b & mask) != 0; mask >>= 1) {
            cnt++;
        }
        return cnt;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
