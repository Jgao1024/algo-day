## 最佳解法思路
- **按对角线分组（i+j）+ 头插保证顺序**  
同一条对角线满足 `i + j` 相等；题目要求同一对角线按 `i` 从大到小输出。  
遍历 `nums` 时按 `sum=i+j` 分组，用 `Deque` 做 `addFirst`，最后按 `sum` 从小到大依次取出即可。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public int[] findDiagonalOrder(List<List<Integer>> nums) {
        List<Deque<Integer>> bucket = new ArrayList<>();
        int total = 0;

        for (int i = 0; i < nums.size(); i++) {
            List<Integer> row = nums.get(i);
            for (int j = 0; j < row.size(); j++) {
                int s = i + j;
                while (bucket.size() <= s) bucket.add(new ArrayDeque<>());
                bucket.get(s).addFirst(row.get(j));
                total++;
            }
        }

        int[] ans = new int[total];
        int idx = 0;
        for (int s = 0; s < bucket.size(); s++) {
            Deque<Integer> q = bucket.get(s);
            while (!q.isEmpty()) {
                ans[idx++] = q.removeFirst();
            }
        }
        return ans;
    }
}
```
