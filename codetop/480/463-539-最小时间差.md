## 最佳解法思路
- **桶（1440 分钟）+ 环形最小差**  
一天只有 1440 分钟，把每个时间点转成分钟数并放入布尔桶：
  - 若同一分钟出现两次，答案直接是 0
  - 扫描桶得到相邻两个时间点的差，并额外比较“首尾跨天差”

## Java 最佳实现

```java
import java.util.List;

class Solution {
    public int findMinDifference(List<String> timePoints) {
        boolean[] seen = new boolean[1440];
        for (String s : timePoints) {
            int m = toMinutes(s);
            if (seen[m]) return 0;
            seen[m] = true;
        }

        int first = -1;
        int prev = -1;
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < 1440; i++) {
            if (!seen[i]) continue;
            if (first == -1) first = i;
            if (prev != -1) ans = Math.min(ans, i - prev);
            prev = i;
        }
        ans = Math.min(ans, first + 1440 - prev);
        return ans;
    }

    private int toMinutes(String s) {
        int h = (s.charAt(0) - '0') * 10 + (s.charAt(1) - '0');
        int m = (s.charAt(3) - '0') * 10 + (s.charAt(4) - '0');
        return h * 60 + m;
    }
}
```

## 复杂度分析
- 时间：\(O(n + 1440)\)
- 空间：\(O(1440)\)
