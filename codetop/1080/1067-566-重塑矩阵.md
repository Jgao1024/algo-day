## 最佳解法思路
- 思路：一维映射  
若 `r*c != m*n` 直接返回原矩阵。否则把位置 `(i,j)` 映射到一维下标 `idx=i*n+j`，新矩阵位置是 `(idx/c, idx%c)`。

## Java 最佳实现

```java
class Solution {
    public int[][] matrixReshape(int[][] mat, int r, int c) {
        int m = mat.length;
        int n = mat[0].length;
        if (m * n != r * c) {
            return mat;
        }

        int[][] res = new int[r][c];
        for (int idx = 0; idx < m * n; idx++) {
            res[idx / c][idx % c] = mat[idx / n][idx % n];
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)（不计输出）
