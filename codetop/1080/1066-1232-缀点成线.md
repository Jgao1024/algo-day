## 最佳解法思路
- 思路：叉积判断共线  
用前两个点确定方向向量 `(dx, dy)`。对每个点 `(x,y)`，判断  
\((x-x0)\cdot dy == (y-y0)\cdot dx\)（避免浮点误差）。

## Java 最佳实现

```java
class Solution {
    public boolean checkStraightLine(int[][] coordinates) {
        int x0 = coordinates[0][0], y0 = coordinates[0][1];
        int x1 = coordinates[1][0], y1 = coordinates[1][1];
        int dx = x1 - x0;
        int dy = y1 - y0;

        for (int i = 2; i < coordinates.length; i++) {
            int x = coordinates[i][0];
            int y = coordinates[i][1];
            long left = (long) (x - x0) * dy;
            long right = (long) (y - y0) * dx;
            if (left != right) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
