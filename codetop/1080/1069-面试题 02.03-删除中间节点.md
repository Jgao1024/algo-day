## 最佳解法思路
- 思路：复制后继节点  
题目保证不是尾节点：把 `node.next` 的值复制到当前节点，再跳过 `node.next`。

## Java 最佳实现

```java
class Solution {
    public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
