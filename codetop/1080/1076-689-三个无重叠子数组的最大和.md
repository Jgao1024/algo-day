## 最佳解法思路
- 思路（推荐）：前缀和 + 左右最优预处理  
先计算每个长度为 `k` 的窗口和 `w[i]`（从 `i` 开始）。  
`left[i]`：在 `0..i` 中窗口和最大的起点（相等取更小下标）。  
`right[i]`：在 `i..end` 中窗口和最大的起点（相等取更小下标）。  
枚举中间窗口起点 `mid`，左窗口起点是 `left[mid-k]`，右窗口起点是 `right[mid+k]`，取总和最大的一组。

## Java 最佳实现

```java
class Solution {
    public int[] maxSumOfThreeSubarrays(int[] nums, int k) {
        int n = nums.length;
        int m = n - k + 1;
        int[] w = new int[m];

        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums[i];
            if (i >= k) {
                sum -= nums[i - k];
            }
            if (i >= k - 1) {
                w[i - k + 1] = sum;
            }
        }

        int[] left = new int[m];
        int best = 0;
        for (int i = 0; i < m; i++) {
            if (w[i] > w[best]) {
                best = i;
            }
            left[i] = best;
        }

        int[] right = new int[m];
        best = m - 1;
        for (int i = m - 1; i >= 0; i--) {
            if (w[i] >= w[best]) {
                best = i;
            }
            right[i] = best;
        }

        int[] ans = new int[3];
        int maxTotal = -1;
        for (int mid = k; mid <= m - k - 1; mid++) {
            int l = left[mid - k];
            int r = right[mid + k];
            int total = w[l] + w[mid] + w[r];
            if (total > maxTotal) {
                maxTotal = total;
                ans[0] = l;
                ans[1] = mid;
                ans[2] = r;
            }
        }

        return ans;
    }
}
```
