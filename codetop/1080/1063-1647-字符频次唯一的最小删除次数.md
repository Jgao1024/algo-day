## 最佳解法思路
- 思路：频次去重  
统计 26 个字符频次，对每个频次 `f`，若 `f` 已被占用就不断 `f--`（等价于删除），直到 `f==0` 或未占用。用集合记录已占用的频次。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minDeletions(String s) {
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
        }

        Set<Integer> used = new HashSet<>();
        int del = 0;
        for (int f : cnt) {
            while (f > 0 && used.contains(f)) {
                f--;
                del++;
            }
            if (f > 0) {
                used.add(f);
            }
        }
        return del;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
