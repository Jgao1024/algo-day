## 最佳解法思路
- 思路（推荐）：行转柱状图 + 单调栈  
把每一行当作底边，维护每列连续 1 的高度 `h[j]`。  
对每一行的 `h`，用单调栈计算“以当前列结尾”的全 1 子矩形个数并累加到答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int numSubmat(int[][] mat) {
        int m = mat.length;
        int n = mat[0].length;
        int[] h = new int[n];
        long ans = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                h[j] = mat[i][j] == 0 ? 0 : (h[j] + 1);
            }

            Deque<int[]> stack = new ArrayDeque<>();
            long rowSum = 0;
            for (int j = 0; j < n; j++) {
                int height = h[j];
                int cnt = 1;
                while (!stack.isEmpty() && stack.peek()[0] >= height) {
                    int[] pop = stack.pop();
                    rowSum -= (long) pop[0] * pop[1];
                    cnt += pop[1];
                }
                stack.push(new int[]{height, cnt});
                rowSum += (long) height * cnt;
                ans += rowSum;
            }
        }

        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
