## 最佳解法思路
- 思路：分治构造  
若 `A` 是漂亮数组，则 `2*A-1`（全奇数）和 `2*A`（全偶数）仍保持漂亮性质。  
从 `[1]` 开始迭代扩展：先生成奇数部分再生成偶数部分，并过滤 `<= n`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] beautifulArray(int n) {
        List<Integer> cur = new ArrayList<>();
        cur.add(1);

        while (cur.size() < n) {
            List<Integer> next = new ArrayList<>();
            for (int x : cur) {
                int v = x * 2 - 1;
                if (v <= n) {
                    next.add(v);
                }
            }
            for (int x : cur) {
                int v = x * 2;
                if (v <= n) {
                    next.add(v);
                }
            }
            cur = next;
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            ans[i] = cur.get(i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
