## 最佳解法思路
- 思路（推荐）：BFS 分层建最短路图 + DFS 回溯输出路径  
先 BFS 求每个单词到起点的最短距离 `dist`，并只保留满足 `dist[next]=dist[cur]+1` 的有向边（最短路图）。  
再从 `beginWord` 沿最短路图 DFS 回溯到 `endWord`，收集所有路径。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public List<List<String>> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) {
            return new ArrayList<>();
        }
        dict.add(beginWord);

        Map<String, Integer> dist = new HashMap<>();
        Map<String, List<String>> nexts = new HashMap<>();

        bfs(beginWord, dict, dist, nexts);
        if (!dist.containsKey(endWord)) {
            return new ArrayList<>();
        }

        List<List<String>> ans = new ArrayList<>();
        List<String> path = new ArrayList<>();
        path.add(beginWord);
        dfs(beginWord, endWord, nexts, path, ans);
        return ans;
    }

    private void bfs(String begin, Set<String> dict, Map<String, Integer> dist, Map<String, List<String>> nexts) {
        Deque<String> q = new ArrayDeque<>();
        q.add(begin);
        dist.put(begin, 0);

        while (!q.isEmpty()) {
            String cur = q.poll();
            int d = dist.get(cur);
            for (String nxt : neighbors(cur, dict)) {
                if (!dist.containsKey(nxt)) {
                    dist.put(nxt, d + 1);
                    q.add(nxt);
                }
                if (dist.get(nxt) == d + 1) {
                    nexts.computeIfAbsent(cur, k -> new ArrayList<>()).add(nxt);
                }
            }
        }
    }

    private List<String> neighbors(String word, Set<String> dict) {
        List<String> res = new ArrayList<>();
        char[] arr = word.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            char old = arr[i];
            for (char c = 'a'; c <= 'z'; c++) {
                if (c == old) {
                    continue;
                }
                arr[i] = c;
                String nxt = new String(arr);
                if (dict.contains(nxt)) {
                    res.add(nxt);
                }
            }
            arr[i] = old;
        }
        return res;
    }

    private void dfs(String cur, String end, Map<String, List<String>> nexts,
                     List<String> path, List<List<String>> ans) {
        if (cur.equals(end)) {
            ans.add(new ArrayList<>(path));
            return;
        }
        List<String> ns = nexts.get(cur);
        if (ns == null) {
            return;
        }
        for (String nxt : ns) {
            path.add(nxt);
            dfs(nxt, end, nexts, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：BFS 约 \(O(N \cdot L \cdot 26)\)，输出部分与答案规模相关
- 空间：\(O(N \cdot L)\)
