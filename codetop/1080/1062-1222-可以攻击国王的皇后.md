## 最佳解法思路
- 思路：八个方向扩散  
把皇后位置放入 `8x8` 布尔表。从国王位置沿 8 个方向走，遇到第一个皇后就加入答案并停止该方向。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> queensAttacktheKing(int[][] queens, int[] king) {
        boolean[][] q = new boolean[8][8];
        for (int[] p : queens) {
            q[p[0]][p[1]] = true;
        }

        int[] dx = {-1, -1, -1, 0, 0, 1, 1, 1};
        int[] dy = {-1, 0, 1, -1, 1, -1, 0, 1};
        List<List<Integer>> ans = new ArrayList<>();

        for (int d = 0; d < 8; d++) {
            int x = king[0] + dx[d];
            int y = king[1] + dy[d];
            while (x >= 0 && x < 8 && y >= 0 && y < 8) {
                if (q[x][y]) {
                    List<Integer> one = new ArrayList<>(2);
                    one.add(x);
                    one.add(y);
                    ans.add(one);
                    break;
                }
                x += dx[d];
                y += dy[d];
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(8 \cdot 8)\)
- 空间：\(O(1)\)
