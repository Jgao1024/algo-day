## 最佳解法思路
- 思路：下标归位（原地 \(O(n)\)）  
常见约束：数组长度为 `n`，元素为 `0..n-1` 的自然数（可能有重复）。  
遍历下标 `i`：若 `nums[i]` 应该放到的位置 `nums[i]` 上不是同一个值，就交换到正确位置；否则 `i++`。

## Java 最佳实现

```java
class Solution {
    public void sort(int[] nums) {
        int n = nums.length;
        int i = 0;
        while (i < n) {
            int v = nums[i];
            if (v >= 0 && v < n && nums[i] != i && nums[i] != nums[v]) {
                int tmp = nums[i];
                nums[i] = nums[v];
                nums[v] = tmp;
            } else {
                i++;
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（均摊）
- 空间：\(O(1)\)
