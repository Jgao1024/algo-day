## 最佳解法思路
- 思路（推荐）：扫描线 + 高度多重集  
把每个建筑 `[L,R,H]` 拆成两个事件：  
- 进入：`(L, -H)`  
- 退出：`(R, H)`  
按 `x` 升序排序，`x` 相同先处理进入（负高度优先）。  
用 `TreeMap<height,count>` 维护当前覆盖的高度集合，最大高度就是 `lastKey()`。当最大高度发生变化就记录关键点。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.TreeMap;

class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        int n = buildings.length;
        int[][] events = new int[n * 2][2];
        int idx = 0;
        for (int[] b : buildings) {
            events[idx++] = new int[]{b[0], -b[2]};
            events[idx++] = new int[]{b[1], b[2]};
        }

        Arrays.sort(events, (a, b) -> {
            if (a[0] != b[0]) {
                return a[0] - b[0];
            }
            return a[1] - b[1];
        });

        TreeMap<Integer, Integer> heights = new TreeMap<>();
        heights.put(0, 1);
        int prev = 0;
        List<List<Integer>> ans = new ArrayList<>();

        for (int[] e : events) {
            int x = e[0];
            int h = e[1];
            if (h < 0) {
                int hh = -h;
                heights.put(hh, heights.getOrDefault(hh, 0) + 1);
            } else {
                int cnt = heights.getOrDefault(h, 0);
                if (cnt <= 1) {
                    heights.remove(h);
                } else {
                    heights.put(h, cnt - 1);
                }
            }

            int cur = heights.lastKey();
            if (cur != prev) {
                ans.add(Arrays.asList(x, cur));
                prev = cur;
            }
        }

        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
