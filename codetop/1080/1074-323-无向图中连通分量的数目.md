## 最佳解法思路
- 思路：并查集  
初始化 `n` 个点各自为集合，遍历边做合并。最终集合数量就是连通分量数。

## Java 最佳实现

```java
class Solution {
    public int countComponents(int n, int[][] edges) {
        DSU dsu = new DSU(n);
        for (int[] e : edges) {
            dsu.union(e[0], e[1]);
        }
        return dsu.count;
    }

    private static class DSU {
        int[] p;
        int[] r;
        int count;

        DSU(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) {
                p[i] = i;
            }
            count = n;
        }

        int find(int x) {
            if (p[x] != x) {
                p[x] = find(p[x]);
            }
            return p[x];
        }

        void union(int a, int b) {
            int pa = find(a);
            int pb = find(b);
            if (pa == pb) {
                return;
            }
            if (r[pa] < r[pb]) {
                p[pa] = pb;
            } else if (r[pa] > r[pb]) {
                p[pb] = pa;
            } else {
                p[pb] = pa;
                r[pa]++;
            }
            count--;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(m \alpha(n))\)
- 空间：\(O(n)\)
