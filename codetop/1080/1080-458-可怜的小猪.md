## 最佳解法思路
- 思路：信息量（状态数）  
每只猪在总测试时间内有 `t = minutesToTest / minutesToDie + 1` 种状态（在哪一轮死/没死）。  
`p` 只猪能区分的桶数是 `t^p`，找最小 `p` 使 `t^p >= buckets`。

## Java 最佳实现

```java
class Solution {
    public int poorPigs(int buckets, int minutesToDie, int minutesToTest) {
        int t = minutesToTest / minutesToDie + 1;
        int pigs = 0;
        long cap = 1;
        while (cap < buckets) {
            cap *= t;
            pigs++;
        }
        return pigs;
    }
}
```

## 复杂度分析
- 时间：\(O(\log_t buckets)\)
- 空间：\(O(1)\)
