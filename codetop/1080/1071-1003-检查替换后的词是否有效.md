## 最佳解法思路
- 思路：栈  
遍历字符入栈；每次入栈后若栈顶三个字符是 `a b c`，就弹出这三个。最终栈空则有效。

## Java 最佳实现

```java
class Solution {
    public boolean isValid(String s) {
        char[] stack = new char[s.length()];
        int top = 0;
        for (int i = 0; i < s.length(); i++) {
            stack[top++] = s.charAt(i);
            if (top >= 3
                    && stack[top - 3] == 'a'
                    && stack[top - 2] == 'b'
                    && stack[top - 1] == 'c') {
                top -= 3;
            }
        }
        return top == 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
