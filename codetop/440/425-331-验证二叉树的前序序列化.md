## 最佳解法思路
- 槽位计数（推荐）
- 前序遍历序列化中：每个节点会“占用 1 个槽位”；非空节点会再“产生 2 个槽位”；`#` 只占用不产生。
- 初始 `slots = 1`，逐个 token：
  - 先 `slots--`，若 `slots < 0` 直接 false
  - 若 token 不是 `#`，再 `slots += 2`
- 结束后 `slots == 0` 才是合法。

## Java 最佳实现

```java
class Solution {
    public boolean isValidSerialization(String preorder) {
        String[] arr = preorder.split(",");
        int slots = 1;
        for (String s : arr) {
            slots--;
            if (slots < 0) return false;
            if (!(s.length() == 1 && s.charAt(0) == '#')) {
                slots += 2;
            }
        }
        return slots == 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计 split 产生的数组）
