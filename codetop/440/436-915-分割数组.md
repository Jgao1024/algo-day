## 最佳解法思路
- 前后缀（推荐）
- 目标找最小分割点 `i`，使得 `max(left[0..i]) <= min(right[i+1..n-1])`。
- 先预处理 `rightMin[i]`：从右往左的最小值。
- 再从左往右维护 `leftMax`，首次满足条件时返回 `i+1`。

## Java 最佳实现

```java
class Solution {
    public int partitionDisjoint(int[] nums) {
        int n = nums.length;
        int[] rightMin = new int[n];
        rightMin[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMin[i] = Math.min(nums[i], rightMin[i + 1]);
        }

        int leftMax = nums[0];
        for (int i = 0; i < n - 1; i++) {
            leftMax = Math.max(leftMax, nums[i]);
            if (leftMax <= rightMin[i + 1]) {
                return i + 1;
            }
        }
        return n;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
