## 最佳解法思路
- 题目给的是“要删除的节点本身”，且保证不是尾节点。
- 直接把后一个节点的值拷贝到当前节点，再跳过后一个节点即可。

## Java 最佳实现

```java
class Solution {
    public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }
}
```

## 复杂度分析
- 时间：\(O(1)\)
- 空间：\(O(1)\)
