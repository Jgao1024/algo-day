## 最佳解法思路
- 位编码 + 滑动窗口（推荐）
- DNA 只有 4 种字符，用 2 bit 编码：A=0，C=1，G=2，T=3。
- 长度固定 10 的窗口可用 20 bit 表示；每次右移/左移维护滚动值。统计出现次数，第二次出现时加入答案。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        List<String> ans = new ArrayList<>();
        if (s.length() < 10) return ans;

        int[] map = new int[128];
        map['A'] = 0;
        map['C'] = 1;
        map['G'] = 2;
        map['T'] = 3;

        int mask = (1 << 20) - 1;
        int x = 0;
        for (int i = 0; i < 10; i++) {
            x = (x << 2) | map[s.charAt(i)];
        }

        Map<Integer, Integer> cnt = new HashMap<>();
        cnt.put(x, 1);
        for (int i = 10; i < s.length(); i++) {
            x = ((x << 2) | map[s.charAt(i)]) & mask;
            int c = cnt.getOrDefault(x, 0) + 1;
            cnt.put(x, c);
            if (c == 2) {
                ans.add(s.substring(i - 9, i + 1));
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
