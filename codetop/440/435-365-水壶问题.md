## 最佳解法思路
- 数学（裴蜀定理）（推荐）
- 设水壶容量为 `x`、`y`，目标 `z`：
  - 若 `x + y < z`，不可能
  - 若 `z == 0`，可以
  - 否则当且仅当 `z` 是 `gcd(x, y)` 的倍数时可达

## Java 最佳实现

```java
class Solution {
    public boolean canMeasureWater(int x, int y, int z) {
        if (z == 0) return true;
        if (x + y < z) return false;
        int g = gcd(x, y);
        return z % g == 0;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(\log(\min(x,y)))\)
- 空间：\(O(1)\)
