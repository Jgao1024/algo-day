## 最佳解法思路
- 一次遍历（推荐）
- 维护历史最低价 `minPrice`，对每个价格计算 `price - minPrice` 更新最大利润。

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int ans = 0;
        for (int p : prices) {
            if (p < minPrice) minPrice = p;
            ans = Math.max(ans, p - minPrice);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
