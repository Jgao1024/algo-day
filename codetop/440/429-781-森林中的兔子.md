## 最佳解法思路
- 计数 + 分组（推荐）
- 每只兔子回答 `x` 表示“还有 x 只和我同色”，即同色一组大小为 `x+1`。
- 对同一个 `x` 的计数为 `cnt`，需要的组数为 `ceil(cnt/(x+1))`，贡献为 `组数 * (x+1)`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numRabbits(int[] answers) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int a : answers) cnt.put(a, cnt.getOrDefault(a, 0) + 1);

        int res = 0;
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int x = e.getKey();
            int c = e.getValue();
            int size = x + 1;
            int groups = (c + size - 1) / size;
            res += groups * size;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
