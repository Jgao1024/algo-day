## 最佳解法思路
- 前缀和 + HashMap（推荐）
- 令 `pre[i]` 为前 i 个元素和。子数组 `(j, i]` 的和为 `pre[i] - pre[j]`。
- 要使其等于 `k`，需要 `pre[j] = pre[i] - k`。用 HashMap 记录某个前缀和第一次出现的下标（最早，才能让长度最大）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxSubArrayLen(int[] nums, int k) {
        Map<Integer, Integer> firstIndex = new HashMap<>();
        firstIndex.put(0, -1);

        int pre = 0;
        int ans = 0;
        for (int i = 0; i < nums.length; i++) {
            pre += nums[i];
            if (!firstIndex.containsKey(pre)) {
                firstIndex.put(pre, i);
            }
            Integer j = firstIndex.get(pre - k);
            if (j != null) {
                ans = Math.max(ans, i - j);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
