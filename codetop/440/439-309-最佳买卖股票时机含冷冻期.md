## 最佳解法思路
- 动态规划（推荐）
- 三个状态：
  - `hold`：持股最大利润
  - `sold`：当天卖出（进入冷冻期）最大利润
  - `rest`：不持股且不在冷冻期最大利润
- 转移：
  - `newHold = max(hold, rest - price)`
  - `newSold = hold + price`
  - `newRest = max(rest, sold)`

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices.length == 0) return 0;
        int hold = -prices[0];
        int sold = 0;
        int rest = 0;
        for (int i = 1; i < prices.length; i++) {
            int p = prices[i];
            int newHold = Math.max(hold, rest - p);
            int newSold = hold + p;
            int newRest = Math.max(rest, sold);
            hold = newHold;
            sold = newSold;
            rest = newRest;
        }
        return Math.max(sold, rest);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
