## 最佳解法思路
- 动态规划（推荐）
- 定义：
  - `cash`：当前不持股的最大利润
  - `hold`：当前持股的最大利润
- 转移：
  - 买入：`hold = max(hold, cash - price)`
  - 卖出：`cash = max(cash, hold + price - fee)`

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        int cash = 0;
        int hold = -prices[0];
        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            int newCash = Math.max(cash, hold + price - fee);
            int newHold = Math.max(hold, cash - price);
            cash = newCash;
            hold = newHold;
        }
        return cash;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
