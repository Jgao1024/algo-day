## 最佳解法思路
- 后序序列化 + 计数（推荐）
- 对每个子树做唯一表示：`val,leftSerial,rightSerial`，放入 HashMap 计数。
- 某个序列化字符串第一次变成 2 时，把当前根加入答案（避免重复加入）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    private final Map<String, Integer> cnt = new HashMap<>();
    private final List<TreeNode> ans = new ArrayList<>();

    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {
        dfs(root);
        return ans;
    }

    private String dfs(TreeNode node) {
        if (node == null) return "#";
        String left = dfs(node.left);
        String right = dfs(node.right);
        String key = node.val + "," + left + "," + right;
        int c = cnt.getOrDefault(key, 0) + 1;
        cnt.put(key, c);
        if (c == 2) ans.add(node);
        return key;
    }
}
```

## 复杂度分析
- 时间：平均 \(O(n)\)（字符串拼接会有常数开销）
- 空间：\(O(n)\)
