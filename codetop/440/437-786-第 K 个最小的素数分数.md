## 最佳解法思路
- 小根堆（推荐）
- `arr` 递增且都是 1 和素数。所有分数形如 `arr[i]/arr[j] (i<j)`。
- 对每个分母 `j`，最小的分子先从 `i=0` 开始；把 `(i=0, j)` 入堆。
- 每次弹出最小 `(i,j)`，若 `i+1<j`，把 `(i+1, j)` 入堆。弹出第 k 次即答案。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class Solution {
    public int[] kthSmallestPrimeFraction(int[] arr, int k) {
        int n = arr.length;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> {
            long left = (long) arr[a[0]] * arr[b[1]];
            long right = (long) arr[b[0]] * arr[a[1]];
            return Long.compare(left, right);
        });

        for (int j = 1; j < n; j++) {
            pq.offer(new int[]{0, j});
        }

        while (k > 1) {
            int[] cur = pq.poll();
            int i = cur[0], j = cur[1];
            if (i + 1 < j) {
                pq.offer(new int[]{i + 1, j});
            }
            k--;
        }
        int[] res = pq.peek();
        return new int[]{arr[res[0]], arr[res[1]]};
    }
}
```

## 复杂度分析
- 时间：\(O((n + k)\log n)\)
- 空间：\(O(n)\)
