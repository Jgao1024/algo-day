## 最佳解法思路
- 排序起点 + 二分（推荐）  
把每个区间的 `start` 和原下标存起来并按 `start` 排序。  
对每个区间 `i` 的 `end`，二分找第一个 `start >= end` 的位置，返回其原下标；找不到则 -1。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        int[][] starts = new int[n][2];
        for (int i = 0; i < n; i++) {
            starts[i][0] = intervals[i][0];
            starts[i][1] = i;
        }
        Arrays.sort(starts, (a, b) -> a[0] - b[0]);

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            int end = intervals[i][1];
            int idx = lowerBound(starts, end);
            ans[i] = (idx == n) ? -1 : starts[idx][1];
        }
        return ans;
    }

    private int lowerBound(int[][] a, int target) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (a[m][0] < target) l = m + 1;
            else r = m;
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
