## 最佳解法思路
- 按行对统计公共 1 列（推荐）  
选择两行 `r1,r2`，统计哪些列这两行都是 1，若公共列数为 `c`，则能组成 `c*(c-1)/2` 个角矩形。  
遍历所有行对累加即可。

## Java 最佳实现

```java
class Solution {
    public int countCornerRectangles(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int ans = 0;
        for (int r1 = 0; r1 < m; r1++) {
            for (int r2 = r1 + 1; r2 < m; r2++) {
                int c = 0;
                for (int j = 0; j < n; j++) {
                    if (grid[r1][j] == 1 && grid[r2][j] == 1) c++;
                }
                ans += c * (c - 1) / 2;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m^2 \cdot n)\)
- 空间：\(O(1)\)
