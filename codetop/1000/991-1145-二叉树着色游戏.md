## 最佳解法思路
- 找到 x 的左右子树大小（推荐）  
第二个玩家想赢，只要能选择一个区域占据超过一半节点。  
对节点 `x`，可选区域有 3 个：  
- `x.left` 子树大小 `L`  
- `x.right` 子树大小 `R`  
- 剩余区域 `P = n - (L + R + 1)`（父方向那一块）  
若 `max(L, R, P) > n/2`，则第二个玩家必胜。

## Java 最佳实现

```java
class Solution {
    private int x;
    private int leftSize = 0;
    private int rightSize = 0;

    public boolean btreeGameWinningMove(TreeNode root, int n, int x) {
        this.x = x;
        count(root);
        int parent = n - (leftSize + rightSize + 1);
        int best = Math.max(parent, Math.max(leftSize, rightSize));
        return best > n / 2;
    }

    private int count(TreeNode node) {
        if (node == null) return 0;
        int l = count(node.left);
        int r = count(node.right);
        if (node.val == x) {
            leftSize = l;
            rightSize = r;
        }
        return l + r + 1;
    }
}
```
