## 最佳解法思路
- 构造（推荐）  
目标是相邻差值恰好有 `k` 种。  
先构造前 `k+1` 个数：`1, k+1, 2, k, 3, k-1, ...`（左右夹逼），这样差值会覆盖 `k,k-1,...,1`。  
剩下的 `k+2..n` 直接递增追加即可，不会产生新差值种类。

## Java 最佳实现

```java
class Solution {
    public int[] constructArray(int n, int k) {
        int[] ans = new int[n];
        int l = 1;
        int r = k + 1;
        int idx = 0;
        boolean takeLeft = true;
        while (l <= r) {
            ans[idx++] = takeLeft ? l++ : r--;
            takeLeft = !takeLeft;
        }
        for (int x = k + 2; x <= n; x++) {
            ans[idx++] = x;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出）

## 总结（速记）
- **前 k+1 用“左右夹逼”产生 k 种差值，后面顺着填**。
