## 最佳解法思路
- 直接构造（推荐）  
只处理前 `length` 个字符：遇到空格输出 `%20`，否则输出原字符。

## Java 最佳实现

```java
class Solution {
    public String replaceSpaces(String s, int length) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < length; i++) {
            char c = s.charAt(i);
            if (c == ' ') sb.append("%20");
            else sb.append(c);
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(length)\)
- 空间：\(O(length)\)
