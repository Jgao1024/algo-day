## 最佳解法思路
- 区间 DP（推荐）  
题目字符串只包含 `a/b/c/d`。设 `dp[i][j]` 为 `s[i..j]` 内不同非空回文子序列个数。  
转移：  
- 若 `s[i] != s[j]`：  
`dp[i][j] = dp[i+1][j] + dp[i][j-1] - dp[i+1][j-1]`  
- 若 `s[i] == s[j]`：设该字符为 `c`，在 `(i, j)` 内 `c` 的最左位置为 `l`、最右位置为 `r`：  
  - 若不存在（`l > r`）：`dp = 2*dp[i+1][j-1] + 2`  
  - 若只有一个（`l == r`）：`dp = 2*dp[i+1][j-1] + 1`  
  - 若有多个（`l < r`）：`dp = 2*dp[i+1][j-1] - dp[l+1][r-1]`  
用 `next/prev` 预处理快速得到 `l/r`，全程取模。

## Java 最佳实现

```java
class Solution {
    public int countPalindromicSubsequences(String s) {
        int n = s.length();
        long MOD = 1_000_000_007L;

        int[][] next = new int[n + 1][4];
        for (int c = 0; c < 4; c++) next[n][c] = n;
        for (int i = n - 1; i >= 0; i--) {
            for (int c = 0; c < 4; c++) next[i][c] = next[i + 1][c];
            next[i][s.charAt(i) - 'a'] = i;
        }

        int[][] prev = new int[n][4];
        int[] last = {-1, -1, -1, -1};
        for (int i = 0; i < n; i++) {
            last[s.charAt(i) - 'a'] = i;
            for (int c = 0; c < 4; c++) prev[i][c] = last[c];
        }

        long[][] dp = new long[n][n];
        for (int i = 0; i < n; i++) dp[i][i] = 1;

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                long val;
                if (s.charAt(i) != s.charAt(j)) {
                    val = dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1];
                } else {
                    long inside = (i + 1 <= j - 1) ? dp[i + 1][j - 1] : 0;
                    val = 2 * inside;
                    int c = s.charAt(i) - 'a';
                    int l = next[i + 1][c];
                    int r = prev[j - 1][c];
                    if (l > r) val += 2;
                    else if (l == r) val += 1;
                    else val -= dp[l + 1][r - 1];
                }
                val %= MOD;
                if (val < 0) val += MOD;
                dp[i][j] = val;
            }
        }

        return (int) dp[0][n - 1];
    }
}
```

- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
