## 最佳解法思路
- DP + 路径恢复（推荐）  
从位置 1 出发到 n，每次最多跳 `B`。`A[i]` 为花费，`-1` 表示不可达。  
设 `dp[i]` 为从 `i` 到 `n` 的最小总花费（含 `A[i]`），从后往前转移：  
`dp[i] = A[i] + min(dp[j])`，其中 `j` 在 `(i+1..i+B)` 且可达。  
为保证字典序最小：在最小花费相同的情况下，选择最小的 `j` 作为 `next[i]`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> cheapestJump(int[] coins, int maxJump) {
        int n = coins.length;
        long INF = (long) 1e18;
        long[] dp = new long[n];
        int[] next = new int[n];
        for (int i = 0; i < n; i++) {
            dp[i] = INF;
            next[i] = -1;
        }

        if (coins[n - 1] != -1) dp[n - 1] = coins[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            if (coins[i] == -1) continue;
            long best = INF;
            int bestJ = -1;
            for (int j = i + 1; j <= Math.min(n - 1, i + maxJump); j++) {
                if (dp[j] >= INF) continue;
                if (dp[j] < best) {
                    best = dp[j];
                    bestJ = j;
                }
            }
            if (bestJ != -1) {
                dp[i] = coins[i] + best;
                next[i] = bestJ;
            }
        }

        if (dp[0] >= INF) return new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        int cur = 0;
        while (cur != -1) {
            path.add(cur + 1);
            cur = next[cur];
        }
        return path;
    }
}
```

## 复杂度分析
- 时间：\(O(n\cdot B)\)
- 空间：\(O(n)\)
