## 最佳解法思路
- 状态压缩 + 找循环（推荐）  
8 个格子状态有限（最多 256），一定会循环。  
把 8 格压成一个整数 `state`，用 HashMap 记录第一次出现时剩余天数 `N`。  
当再次遇到相同 `state`，说明进入循环，循环长度 `cycle = prevN - N`，对 `N` 取模后继续模拟即可。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] prisonAfterNDays(int[] cells, int n) {
        int state = 0;
        for (int i = 0; i < 8; i++) {
            state = (state << 1) | (cells[i] & 1);
        }

        Map<Integer, Integer> seen = new HashMap<>();
        while (n > 0) {
            Integer prevN = seen.get(state);
            if (prevN != null) {
                int cycle = prevN - n;
                n %= cycle;
            }
            seen.put(state, n);
            if (n == 0) break;
            state = next(state);
            n--;
        }

        int[] ans = new int[8];
        for (int i = 7; i >= 0; i--) {
            ans[i] = state & 1;
            state >>= 1;
        }
        return ans;
    }

    private int next(int state) {
        int[] a = new int[8];
        for (int i = 7; i >= 0; i--) {
            a[i] = state & 1;
            state >>= 1;
        }
        int[] b = new int[8];
        b[0] = 0;
        b[7] = 0;
        for (int i = 1; i <= 6; i++) {
            b[i] = (a[i - 1] == a[i + 1]) ? 1 : 0;
        }
        int ns = 0;
        for (int i = 0; i < 8; i++) ns = (ns << 1) | b[i];
        return ns;
    }
}
```

## 复杂度分析
- 时间：\(O(循环长度)\)（最多 256 次）
- 空间：\(O(循环长度)\)
