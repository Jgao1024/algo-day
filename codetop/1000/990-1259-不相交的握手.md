## 最佳解法思路
- Catalan DP（推荐）  
`numPeople` 为偶数，设 `n=numPeople/2` 对握手。  
选定某个人与另一人握手，会把圆环分成两部分，子问题独立，满足 Catalan 递推：  
`dp[0]=1`  
`dp[i] = sum(dp[j] * dp[i-1-j])`。

## Java 最佳实现

```java
class Solution {
    public int numberOfWays(int numPeople) {
        int n = numPeople / 2;
        long MOD = 1_000_000_007L;
        long[] dp = new long[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            long sum = 0;
            for (int j = 0; j <= i - 1; j++) {
                sum = (sum + dp[j] * dp[i - 1 - j]) % MOD;
            }
            dp[i] = sum;
        }
        return (int) dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
