## 最佳解法思路
- 质因数分解（推荐）  
最优过程等价于把 `n` 分解成若干段“复制一次 + 粘贴若干次”，操作次数就是所有质因数之和。  
例如 `n=12=2*2*3`，答案 `2+2+3=7`。

## Java 最佳实现

```java
class Solution {
    public int minSteps(int n) {
        int ans = 0;
        int d = 2;
        while (d * d <= n) {
            while (n % d == 0) {
                ans += d;
                n /= d;
            }
            d++;
        }
        if (n > 1) ans += n;
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{n})\)
- 空间：\(O(1)\)
