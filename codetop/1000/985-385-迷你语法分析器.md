## 最佳解法思路
- 栈解析（推荐）  
若不是 `[` 开头，说明是单个整数，直接返回。  
否则从左到右扫描：  
- 遇到 `[`：新建一个空列表入栈  
- 遇到数字/负号：累积成整数  
- 遇到 `,` 或 `]`：如果刚解析出整数就加入栈顶列表；若是 `]` 则弹出一个列表，作为一个 `NestedInteger`（若栈空就是最终答案，否则加入上层）

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public NestedInteger deserialize(String s) {
        if (s.charAt(0) != '[') {
            return new NestedInteger(Integer.parseInt(s));
        }

        Deque<NestedInteger> st = new ArrayDeque<>();
        int num = 0;
        int sign = 1;
        boolean inNum = false;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '[') {
                st.push(new NestedInteger());
            } else if (c == '-') {
                sign = -1;
            } else if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
                inNum = true;
            } else if (c == ',' || c == ']') {
                if (inNum) {
                    st.peek().add(new NestedInteger(sign * num));
                    num = 0;
                    sign = 1;
                    inNum = false;
                }
                if (c == ']' && st.size() > 1) {
                    NestedInteger cur = st.pop();
                    st.peek().add(cur);
                }
            }
        }
        return st.pop();
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(n)\)
