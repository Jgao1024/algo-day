## 最佳解法思路
- 0-1 BFS（推荐）  
每个格子有一个“推荐方向”，沿推荐方向走代价 0，走其他方向代价 1。  
这是边权为 0/1 的最短路，用双端队列：  
- 走 0 边入队头  
- 走 1 边入队尾  
最终到达右下角的最小代价即答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    // 1:right 2:left 3:down 4:up
    public int minCost(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int INF = 1 << 30;
        int[][] dist = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) dist[i][j] = INF;
        }
        dist[0][0] = 0;

        int[] dr = {0, 0, 0, 1, -1};
        int[] dc = {0, 1, -1, 0, 0};

        Deque<int[]> dq = new ArrayDeque<>();
        dq.addFirst(new int[] {0, 0});
        while (!dq.isEmpty()) {
            int[] cur = dq.pollFirst();
            int r = cur[0], c = cur[1];
            int d = dist[r][c];
            if (r == m - 1 && c == n - 1) return d;
            for (int dir = 1; dir <= 4; dir++) {
                int nr = r + dr[dir];
                int nc = c + dc[dir];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int w = (grid[r][c] == dir) ? 0 : 1;
                int nd = d + w;
                if (nd < dist[nr][nc]) {
                    dist[nr][nc] = nd;
                    if (w == 0) dq.addFirst(new int[] {nr, nc});
                    else dq.addLast(new int[] {nr, nc});
                }
            }
        }
        return dist[m - 1][n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)
