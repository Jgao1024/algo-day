## 最佳解法思路
- 二分查找（推荐）  
`guess(mid)` 返回：  
- `0` 命中  
- `-1` 表示答案更小  
- `1` 表示答案更大  
直接二分 `1..n`。

## Java 最佳实现

```java
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        int left = 1;
        int right = n;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int g = guess(mid);
            if (g == 0) return mid;
            if (g < 0) right = mid - 1;
            else left = mid + 1;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
