## 最佳解法思路
- DP（推荐）  
`keep`：到当前位置且不交换当前对的最小交换次数；`swap`：交换当前对的最小交换次数。  
对每个 `i>0`：  
- 若 `A[i]>A[i-1] && B[i]>B[i-1]`：`keep` 可延续 `keep`，`swap` 可延续 `swap+1`  
- 若 `A[i]>B[i-1] && B[i]>A[i-1]`：`keep` 也可来自 `swap`，`swap` 可来自 `keep+1`  
取最小即可。

## Java 最佳实现

```java
class Solution {
    public int minSwap(int[] nums1, int[] nums2) {
        int keep = 0;
        int swap = 1;
        int INF = 1 << 30;
        for (int i = 1; i < nums1.length; i++) {
            int nk = INF;
            int ns = INF;
            if (nums1[i] > nums1[i - 1] && nums2[i] > nums2[i - 1]) {
                nk = Math.min(nk, keep);
                ns = Math.min(ns, swap + 1);
            }
            if (nums1[i] > nums2[i - 1] && nums2[i] > nums1[i - 1]) {
                nk = Math.min(nk, swap);
                ns = Math.min(ns, keep + 1);
            }
            keep = nk;
            swap = ns;
        }
        return Math.min(keep, swap);
    }
}
```

- 时间：\(O(n)\)
- 空间：\(O(1)\)
