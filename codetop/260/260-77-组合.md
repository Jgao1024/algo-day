## 最佳解法思路
- 思路1（推荐）：回溯（组合型 DFS）  
从 `start` 开始选择下一个数加入路径，递归到长度为 `k` 就收集答案。  
可用 `need = k - path.size()` 做剪枝：当前起点最多到 `n - need + 1`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> ans = new ArrayList<>();
        dfs(1, n, k, new ArrayList<>(), ans);
        return ans;
    }

    private void dfs(int start, int n, int k, List<Integer> path, List<List<Integer>> ans) {
        if (path.size() == k) {
            ans.add(new ArrayList<>(path));
            return;
        }
        int need = k - path.size();
        for (int i = start; i <= n - need + 1; i++) {
            path.add(i);
            dfs(i + 1, n, k, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(C(n,k)\cdot k)\)
- 空间：\(O(k)\)（递归栈 + 路径）
