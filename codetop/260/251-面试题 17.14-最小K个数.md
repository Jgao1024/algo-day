## 最佳解法思路
- 思路1（推荐）：快速选择（QuickSelect）  
用一次次 `partition` 把数组划分成“< pivot” 和 “>= pivot”。  
当分割点 `p == k-1` 时，前 `k` 个元素就是最小的 `k` 个（不要求有序）。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.Random;

class Solution {
    private final Random random = new Random();

    public int[] smallestK(int[] arr, int k) {
        if (k == 0) return new int[0];
        if (k >= arr.length) return arr;
        quickSelect(arr, 0, arr.length - 1, k - 1);
        return Arrays.copyOf(arr, k);
    }

    private void quickSelect(int[] a, int l, int r, int k) {
        while (l <= r) {
            int p = partition(a, l, r);
            if (p == k) return;
            if (p < k) l = p + 1;
            else r = p - 1;
        }
    }

    private int partition(int[] a, int l, int r) {
        int pivotIndex = l + random.nextInt(r - l + 1);
        int pivot = a[pivotIndex];
        swap(a, pivotIndex, r);
        int i = l;
        for (int j = l; j < r; j++) {
            if (a[j] < pivot) {
                swap(a, i++, j);
            }
        }
        swap(a, i, r);
        return i;
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

- 时间：平均 \(O(n)\)，最坏 \(O(n^2)\)
- 空间：\(O(1)\)
