## 最佳解法思路
- 思路1（推荐）：补父指针 + BFS 分层  
先 DFS 建 `parent` 映射，把二叉树变成“无向图”（子、父都能走）。  
再从 `target` 开始做 BFS，走 `k` 层后队列里的所有节点就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        build(root, null, parent);

        Deque<TreeNode> q = new ArrayDeque<>();
        Set<TreeNode> seen = new HashSet<>();
        q.offer(target);
        seen.add(target);

        int dist = 0;
        while (!q.isEmpty()) {
            if (dist == k) {
                List<Integer> ans = new ArrayList<>();
                for (TreeNode node : q) ans.add(node.val);
                return ans;
            }
            int size = q.size();
            for (int i = 0; i < size; i++) {
                TreeNode cur = q.poll();
                if (cur.left != null && seen.add(cur.left)) q.offer(cur.left);
                if (cur.right != null && seen.add(cur.right)) q.offer(cur.right);
                TreeNode p = parent.get(cur);
                if (p != null && seen.add(p)) q.offer(p);
            }
            dist++;
        }
        return new ArrayList<>();
    }

    private void build(TreeNode node, TreeNode p, Map<TreeNode, TreeNode> parent) {
        if (node == null) return;
        parent.put(node, p);
        build(node.left, node, parent);
        build(node.right, node, parent);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

- 先补 `parent`，再从 `target` BFS 走 `k` 层。
