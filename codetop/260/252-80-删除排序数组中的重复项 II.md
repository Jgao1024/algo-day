## 最佳解法思路
- 思路1（推荐）：双指针（保留至多 2 个）  
因为数组有序，只要保证新数组中任意元素最多出现两次即可：  
从下标 2 开始，若 `nums[i] != nums[slow-2]`，就保留该元素并 `slow++`。

## Java 最佳实现

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int n = nums.length;
        if (n <= 2) return n;
        int slow = 2;
        for (int i = 2; i < n; i++) {
            if (nums[i] != nums[slow - 2]) {
                nums[slow++] = nums[i];
            }
        }
        return slow;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
