## 最佳解法思路
- 思路1（推荐）：一次遍历计数  
维护当前连续递增长度 `cur`：  
- 若 `nums[i] > nums[i-1]`：`cur++`  
- 否则 `cur=1`  
过程中更新最大值。

## Java 最佳实现

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        if (nums.length == 0) return 0;
        int ans = 1;
        int cur = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                cur++;
            } else {
                cur = 1;
            }
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
