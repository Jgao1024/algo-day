## 最佳解法思路
- 思路1（推荐）：计数数组  
只包含小写字母时，用长度 26 的计数数组：对 `s` 加一，对 `t` 减一，最后全部为 0 即为异位词。

## Java 最佳实现

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
            cnt[t.charAt(i) - 'a']--;
        }
        for (int x : cnt) {
            if (x != 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
