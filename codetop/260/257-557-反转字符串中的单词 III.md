## 最佳解法思路
- 思路1（推荐）：原地反转每个单词  
把字符串转成 `char[]`，用指针找到每个单词 `[l, r]`，对该区间做一次反转即可（空格不动）。

## Java 最佳实现

```java
class Solution {
    public String reverseWords(String s) {
        char[] a = s.toCharArray();
        int n = a.length;
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && a[j] != ' ') j++;
            reverse(a, i, j - 1);
            i = j + 1;
        }
        return new String(a);
    }

    private void reverse(char[] a, int l, int r) {
        while (l < r) {
            char t = a[l];
            a[l] = a[r];
            a[r] = t;
            l++;
            r--;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（`toCharArray`）
