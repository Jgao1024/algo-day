## 最佳解法思路
- 思路1（推荐）：按 256 进制转换（位运算）  
IPv4 由 4 段组成，每段范围 `0..255`：  
- `ip -> long`：从左到右，`res = (res << 8) | part`  
- `long -> ip`：依次取出 4 个字节，`part = (x >> (8*i)) & 255`

## Java 最佳实现

```java
class Solution {
    public long ipToLong(String ip) {
        String[] parts = ip.split("\\.");
        long res = 0;
        for (int i = 0; i < 4; i++) {
            int x = Integer.parseInt(parts[i]);
            res = (res << 8) | (x & 255);
        }
        return res;
    }

    public String longToIp(long x) {
        StringBuilder sb = new StringBuilder();
        for (int i = 3; i >= 0; i--) {
            long part = (x >> (8 * i)) & 255L;
            sb.append(part);
            if (i != 0) sb.append('.');
        }
        return sb.toString();
    }
}
```
