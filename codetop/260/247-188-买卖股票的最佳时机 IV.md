## 最佳解法思路
- 思路1（推荐）：DP（最多 k 次交易）  
交易次数是关键维度：  
用 `buy[j]` 表示“完成了 j-1 次卖出后，当前持股的最大收益”，`sell[j]` 表示“完成了 j 次卖出后，不持股的最大收益”。  
遍历每天价格 `p`：  
- `buy[j] = max(buy[j], sell[j-1] - p)`  
- `sell[j] = max(sell[j], buy[j] + p)`  
当 `k >= n/2` 时等价于无限次交易，直接贪心累加所有上升段。

## Java 最佳实现

```java
class Solution {
    public int maxProfit(int k, int[] prices) {
        int n = prices.length;
        if (k == 0 || n == 0) return 0;

        if (k >= n / 2) {
            int ans = 0;
            for (int i = 1; i < n; i++) {
                if (prices[i] > prices[i - 1]) {
                    ans += prices[i] - prices[i - 1];
                }
            }
            return ans;
        }

        int[] buy = new int[k + 1];
        int[] sell = new int[k + 1];
        for (int j = 1; j <= k; j++) buy[j] = Integer.MIN_VALUE / 2;

        for (int price : prices) {
            for (int j = 1; j <= k; j++) {
                buy[j] = Math.max(buy[j], sell[j - 1] - price);
                sell[j] = Math.max(sell[j], buy[j] + price);
            }
        }
        return sell[k];
    }
}
```

## 复杂度分析
- 时间：\(O(nk)\)
- 空间：\(O(k)\)
