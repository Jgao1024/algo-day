## 最佳解法思路
- 思路1（推荐）：单调栈（从后往前扫）  
后序：`[左, 右, 根]`。从后往前就是 `根 -> 右 -> 左`。  
用栈维护一条递增链，并用 `root` 记录“当前允许的最大上界”（切到左子树时会更新）。  
遍历 `x`：  
- 若 `x > root` 说明出现在左子树却比祖先大，非法  
- 当 `x < stack.peek()` 时不断出栈，表示从右子树回到左子树，同时更新 `root`

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean verifyPostorder(int[] postorder) {
        int root = Integer.MAX_VALUE;
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = postorder.length - 1; i >= 0; i--) {
            int x = postorder[i];
            if (x > root) return false;
            while (!st.isEmpty() && x < st.peek()) {
                root = st.pop();
            }
            st.push(x);
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
