## 最佳解法思路
- 思路1（推荐）：双指针从两端填充  
平方后最大值只可能来自两端（绝对值最大）。  
用 `l`、`r` 指向两端，从结果数组末尾往前填：比较 `nums[l]^2` 和 `nums[r]^2`，取大的放入。

## Java 最佳实现

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        int l = 0, r = n - 1;
        int i = n - 1;
        while (l <= r) {
            int a = nums[l] * nums[l];
            int b = nums[r] * nums[r];
            if (a > b) {
                ans[i--] = a;
                l++;
            } else {
                ans[i--] = b;
                r--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
