## 最佳解法思路
- 思路1（推荐）：利用完全二叉树性质（左右高度判满）  
分别沿着 `left` 走到底得到左高 `lh`，沿着 `right` 走到底得到右高 `rh`。  
若 `lh == rh`，说明是满二叉树，节点数为 \(2^{lh}-1\)。否则递归左右子树累加。

## Java 最佳实现

```java
class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) return 0;
        int lh = leftHeight(root);
        int rh = rightHeight(root);
        if (lh == rh) {
            return (int) ((1L << lh) - 1);
        }
        return 1 + countNodes(root.left) + countNodes(root.right);
    }

    private int leftHeight(TreeNode node) {
        int h = 0;
        while (node != null) {
            h++;
            node = node.left;
        }
        return h;
    }

    private int rightHeight(TreeNode node) {
        int h = 0;
        while (node != null) {
            h++;
            node = node.right;
        }
        return h;
    }
}
```

## 复杂度分析
- 时间：\(O((\log n)^2)\)
- 空间：\(O(\log n)\)（递归栈）
