## 最佳解法思路
- 思路1（推荐）：双指针（两端夹逼）  
数组有序：`l` 从左、`r` 从右。  
- 若 `nums[l] + nums[r] < target`：`l++`  
- 若 `> target`：`r--`  
- 相等返回答案（注意题目要 1-based 下标）。

## Java 最佳实现

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int l = 0, r = numbers.length - 1;
        while (l < r) {
            int sum = numbers[l] + numbers[r];
            if (sum == target) return new int[]{l + 1, r + 1};
            if (sum < target) l++;
            else r--;
        }
        return new int[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
