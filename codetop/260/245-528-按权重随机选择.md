## 最佳解法思路
- 思路1（推荐）：前缀和 + 二分  
把权重数组转成前缀和 `pre`，总和为 `sum`。  
每次随机一个整数 `x`（范围 `[1, sum]`），用二分找到第一个 `pre[i] >= x`，返回 `i`。

## Java 最佳实现

```java
import java.util.Random;

class Solution {
    private final long[] pre;
    private final int sum;
    private final Random random = new Random();

    public Solution(int[] w) {
        pre = new long[w.length];
        long s = 0;
        for (int i = 0; i < w.length; i++) {
            s += w[i];
            pre[i] = s;
        }
        sum = (int) s;
    }

    public int pickIndex() {
        long x = random.nextInt(sum) + 1L;
        int l = 0, r = pre.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (pre[mid] >= x) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        return l;
    }
}
```

## 复杂度分析
- 构造：\(O(n)\)
- 单次选择：\(O(\log n)\)
- 空间：\(O(n)\)
