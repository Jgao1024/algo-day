## 最佳解法思路
- 思路1（推荐）：二分（和右端比较，处理重复）  
设区间 `[l, r]`。  
- 若 `nums[mid] > nums[r]`，最小值在右侧：`l = mid + 1`  
- 若 `nums[mid] < nums[r]`，最小值在左侧（含 mid）：`r = mid`  
- 若相等无法判断：`r--` 缩小范围  
最终 `l == r` 即最小值下标。

## Java 最佳实现

```java
class Solution {
    public int minArray(int[] numbers) {
        int l = 0, r = numbers.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (numbers[mid] > numbers[r]) {
                l = mid + 1;
            } else if (numbers[mid] < numbers[r]) {
                r = mid;
            } else {
                r--;
            }
        }
        return numbers[l];
    }
}
```

## 复杂度分析
- 时间：平均 \(O(\log n)\)，最坏 \(O(n)\)（大量重复）
- 空间：\(O(1)\)
