## 最佳解法思路
- 思路1（推荐）：从边界出发染色（BFS/DFS）  
所有“不会被围住”的 `O`，一定能从边界 `O` 走到。  
先把边界及其连通的 `O` 全部标记为 `#`（安全），最后：  
- 剩下的 `O` 全部翻成 `X`  
- `#` 再还原成 `O`

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public void solve(char[][] board) {
        int m = board.length;
        int n = board[0].length;
        Deque<int[]> q = new ArrayDeque<>();

        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O') mark(board, i, 0, q);
            if (board[i][n - 1] == 'O') mark(board, i, n - 1, q);
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') mark(board, 0, j, q);
            if (board[m - 1][j] == 'O') mark(board, m - 1, j, q);
        }

        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int k = 0; k < 4; k++) {
                int x = cur[0] + dx[k];
                int y = cur[1] + dy[k];
                if (x < 0 || x >= m || y < 0 || y >= n) continue;
                if (board[x][y] == 'O') mark(board, x, y, q);
            }
        }

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X';
                else if (board[i][j] == '#') board[i][j] = 'O';
            }
        }
    }

    private void mark(char[][] board, int i, int j, Deque<int[]> q) {
        board[i][j] = '#';
        q.offer(new int[]{i, j});
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(mn)\)（队列最坏情况）

## 总结（速记）
- 先保边界连通的 `O`，剩下的 `O` 才是被围住的。
