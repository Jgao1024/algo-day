# 41. 缺失的第一个正数

- 题号：41
- 难度：困难
- LeetCode：[缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/)

## 题目描述
给定未排序整数数组 `nums`，找出其中缺失的最小正整数，要求 \(O(n)\) 时间且常数额外空间。

## 示例
- 示例  
输入：`nums = [3,4,-1,1]`  
输出：`2`

## 最佳解法思路
- 原地哈希（推荐）  
理想状态：数字 `x` 应该放在下标 `x-1` 的位置（仅关心 `1..n`）。  
遍历数组，不断把当前数交换到它应该去的位置：当 `1<=nums[i]<=n` 且 `nums[nums[i]-1]!=nums[i]` 时交换。  
最后再扫一遍，第一个 `nums[i] != i+1` 的位置，对应缺失的就是 `i+1`；都满足则答案是 `n+1`。

## Java 最佳实现

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int j = nums[i] - 1;
                int t = nums[i];
                nums[i] = nums[j];
                nums[j] = t;
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- **把 `x` 放到 `x-1`；再找第一个不匹配的位置**。
