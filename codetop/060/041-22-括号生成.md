# 22. 括号生成

- 题号：22
- 难度：中等
- LeetCode：[括号生成](https://leetcode.cn/problems/generate-parentheses/)

## 题目描述
给定整数 \(n\)，返回所有由 \(n\) 对括号组成、且括号有效的字符串。

## 示例
- 示例  
输入：`n = 3`  
输出：`["((()))","(()())","(())()","()(())","()()()"]`

## 最佳解法思路
- 回溯（推荐）  
用 `left` 表示已放的 `(` 数量，`right` 表示已放的 `)` 数量。  
规则：`left < n` 才能放 `(`；`right < left` 才能放 `)`。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        char[] path = new char[2 * n];
        dfs(n, 0, 0, 0, path, res);
        return res;
    }

    private void dfs(int n, int idx, int left, int right, char[] path, List<String> res) {
        if (idx == 2 * n) {
            res.add(new String(path));
            return;
        }

        if (left < n) {
            path[idx] = '(';
            dfs(n, idx + 1, left + 1, right, path, res);
        }
        if (right < left) {
            path[idx] = ')';
            dfs(n, idx + 1, left, right + 1, path, res);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(C_n \cdot n)\)，\(C_n\) 为第 \(n\) 个卡特兰数（答案数量）
- 空间：\(O(n)\)（递归栈与路径，不含输出）

## 总结（速记）
- 生成有效括号就记两条：**左括号没用完就能放；右括号不能超过左括号**。
