# 76. 最小覆盖子串

- 题号：76
- 难度：困难
- LeetCode：[最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)

## 题目描述
给定字符串 `s` 和 `t`，返回 `s` 中包含 `t` 所有字符（包含重复）的最短子串；不存在则返回空串。

## 示例
- 示例  
输入：`s = "ADOBECODEBANC", t = "ABC"`  
输出：`"BANC"`

## 最佳解法思路
- 滑动窗口（推荐）  
用 `need[c]` 记录 `t` 里每个字符需要的次数，窗口右扩时减少 `need`；当某个字符还“缺”的次数从 1 变 0，说明满足了一个需求。  
用 `missing` 记录还缺多少个字符（按次数算）。当 `missing==0` 时开始收缩左边，直到窗口不再满足为止，更新最短答案。

## Java 最佳实现

```java
class Solution {
    public String minWindow(String s, String t) {
        if (t.length() == 0 || s.length() < t.length()) return "";

        int[] need = new int[128];
        for (int i = 0; i < t.length(); i++) need[t.charAt(i)]++;

        int missing = t.length();
        int l = 0;
        int bestL = 0, bestLen = Integer.MAX_VALUE;

        for (int r = 0; r < s.length(); r++) {
            char cr = s.charAt(r);
            if (need[cr] > 0) missing--;
            need[cr]--;

            while (missing == 0) {
                int len = r - l + 1;
                if (len < bestLen) {
                    bestLen = len;
                    bestL = l;
                }
                char cl = s.charAt(l++);
                need[cl]++;
                if (need[cl] > 0) missing++;
            }
        }
        return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（字符集固定）

## 总结（速记）
- **右扩到满足，左缩到刚好不满足；用 `missing` 判断是否满足**。
