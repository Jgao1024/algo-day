# 69. x 的平方根

- 题号：69
- 难度：简单
- LeetCode：[x 的平方根](https://leetcode.cn/problems/sqrtx/)

## 题目描述
给定非负整数 `x`，返回其平方根的整数部分（向下取整）。

## 示例
- 示例  
输入：`x = 8`  
输出：`2`

## 最佳解法思路
- 二分查找（推荐）  
在 `[0, x]` 里找最大的 `mid` 使得 `mid*mid <= x`，注意用 `long` 防溢出。

## Java 最佳实现

```java
class Solution {
    public int mySqrt(int x) {
        int l = 0, r = x, ans = 0;
        while (l <= r) {
            int mid = l + ((r - l) >> 1);
            long sq = (long) mid * mid;
            if (sq <= x) {
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log x)\)
- 空间：\(O(1)\)
