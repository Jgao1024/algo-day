# 239. 滑动窗口最大值

- 题号：239
- 难度：困难
- LeetCode：[滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)

## 题目描述
给定数组 `nums` 和窗口大小 `k`，窗口从左到右滑动，每次返回窗口内最大值。

## 示例
- 示例  
输入：`nums = [1,3,-1,-3,5,3,6,7], k = 3`  
输出：`[3,3,5,5,6,7]`

## 最佳解法思路
- 单调队列（推荐）  
队列里存下标，保持对应值单调递减；队头始终是当前窗口最大值下标。  
每次右端入队前，把队尾所有小于等于当前值的下标弹出；滑窗时把过期（`<= i-k`）的队头弹出。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k <= 0) return new int[0];
        int n = nums.length;
        int[] res = new int[n - k + 1];
        Deque<Integer> dq = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            int left = i - k + 1;
            while (!dq.isEmpty() && dq.peekFirst() < left) dq.pollFirst();
            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast();
            dq.addLast(i);
            if (left >= 0) res[left] = nums[dq.peekFirst()];
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(k)\)
