# 78. 子集

- 题号：78
- 难度：中等
- LeetCode：[子集](https://leetcode.cn/problems/subsets/)

## 题目描述
给定不含重复元素的整数数组 `nums`，返回所有可能的子集（幂集）。

## 示例
- 示例  
输入：`nums = [1,2,3]`  
输出：`[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]`

## 最佳解法思路
- 回溯（推荐）  
从位置 `idx` 开始，选择“要/不要”当前元素；每到一个节点就把当前路径加入答案。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int[] nums, int idx, List<Integer> path, List<List<Integer>> res) {
        res.add(new ArrayList<>(path));
        for (int i = idx; i < nums.length; i++) {
            path.add(nums[i]);
            dfs(nums, i + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n\cdot 2^n)\)
- 空间：\(O(n)\)（递归栈与路径，不含输出）

## 总结（速记）
- 子集：**先把当前路径加入答案，再从 idx 往后试着选每个数**。
