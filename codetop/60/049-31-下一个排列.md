# 31. 下一个排列

- 题号：31
- 难度：中等
- LeetCode：[下一个排列](https://leetcode.cn/problems/next-permutation/)

## 题目描述
给定整数数组 `nums`，将其重新排列成字典序更大的下一个排列；若不存在更大排列，则变为最小排列（升序）。

## 示例
- 示例  
输入：`nums = [1,2,3]`  
输出：`[1,3,2]`

## 最佳解法思路
- 贪心 + 反转后缀（推荐）  
从右往左找第一个 `nums[i] < nums[i+1]` 的位置 `i`（下降转折点）。  
再从右往左找第一个 `nums[j] > nums[i]` 的位置 `j`，交换 `i` 和 `j`。  
最后把区间 `[i+1, n-1]` 反转，使其变成最小升序。

## Java 最佳实现

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;

        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, n - 1);
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }

    private void reverse(int[] a, int l, int r) {
        while (l < r) swap(a, l++, r--);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
