# 704. 二分查找

- 题号：704
- 难度：简单
- LeetCode：[二分查找](https://leetcode.cn/problems/binary-search/)

## 题目描述
给定升序数组 `nums` 和目标值 `target`，返回目标值下标；不存在则返回 `-1`。

## 示例
- 示例  
输入：`nums = [-1,0,3,5,9,12], target = 9`  
输出：`4`

## 最佳解法思路
- 标准二分  
维护闭区间 `[l, r]`，每次取 `mid`，根据比较结果缩小一半区间。

## Java 最佳实现

```java
class Solution {
    public int search(int[] nums, int target) {
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int mid = l + ((r - l) >> 1);
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
