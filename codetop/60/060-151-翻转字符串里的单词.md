# 151. 翻转字符串里的单词

- 题号：151
- 难度：中等
- LeetCode：[翻转字符串里的单词](https://leetcode.cn/problems/reverse-words-in-a-string/)

## 题目描述
给定字符串 `s`，反转字符串中单词的顺序。  
单词之间可能有多个空格，输出要求：单词之间只保留一个空格，首尾无空格。

## 示例
- 示例  
输入：`s = "  the sky   is blue  "`  
输出：`"blue is sky the"`

## 最佳解法思路
- 从后往前扫描（推荐）  
跳过尾部空格；找到一个单词的左右边界后追加到结果；单词之间自己补一个空格即可。

## Java 最佳实现

```java
class Solution {
    public String reverseWords(String s) {
        int i = s.length() - 1;
        StringBuilder sb = new StringBuilder();
        while (i >= 0) {
            while (i >= 0 && s.charAt(i) == ' ') i--;
            if (i < 0) break;
            int j = i;
            while (j >= 0 && s.charAt(j) != ' ') j--;
            if (sb.length() > 0) sb.append(' ');
            sb.append(s, j + 1, i + 1);
            i = j - 1;
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
