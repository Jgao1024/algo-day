# 322. 零钱兑换

- 题号：322
- 难度：中等
- LeetCode：[零钱兑换](https://leetcode.cn/problems/coin-change/)

## 题目描述
给定硬币面额数组 `coins` 和总金额 `amount`，返回凑成 `amount` 所需的最少硬币数；无法凑成返回 `-1`。

## 示例
- 示例  
输入：`coins = [1,2,5], amount = 11`  
输出：`3`

## 最佳解法思路
- 完全背包（推荐）  
`dp[i]` 表示凑成金额 `i` 的最少硬币数。  
初始化 `dp[0]=0`，其他为大值；对每个金额 `i`，尝试使用每个硬币 `c`：`dp[i]=min(dp[i], dp[i-c]+1)`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        int INF = amount + 1;
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;
        for (int i = 1; i <= amount; i++) {
            for (int c : coins) {
                if (i >= c) dp[i] = Math.min(dp[i], dp[i - c] + 1);
            }
        }
        return dp[amount] == INF ? -1 : dp[amount];
    }
}
```

## 复杂度分析
- 时间：\(O(amount \cdot |\text{coins}|)\)
- 空间：\(O(amount)\)

## 总结（速记）
- `dp[i]` 最少硬币：**先把 dp 填成 INF，`dp[0]=0`，再用 `dp[i-c]+1` 去更新**。
