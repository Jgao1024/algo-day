# 8. 字符串转换整数 (atoi)

- 题号：8
- 难度：中等
- LeetCode：[字符串转换整数 (atoi)](https://leetcode.cn/problems/string-to-integer-atoi/)

## 题目描述
实现 `atoi`：把字符串转换成 32 位有符号整数。  
规则：忽略前导空格；可选正负号；后续连续数字构成结果；溢出时截断到 `[-2^31, 2^31-1]`。

## 示例
- 示例  
输入：`s = "   -42"`  
输出：`-42`

## 最佳解法思路
- 模拟扫描（推荐）  
跳过空格 -> 处理符号 -> 逐位累加数字；累加前做溢出判断。

## Java 最佳实现

```java
class Solution {
    public int myAtoi(String s) {
        int n = s.length();
        int i = 0;
        while (i < n && s.charAt(i) == ' ') i++;
        if (i == n) return 0;

        int sign = 1;
        char c = s.charAt(i);
        if (c == '+' || c == '-') {
            sign = (c == '-') ? -1 : 1;
            i++;
        }

        int res = 0;
        while (i < n) {
            char ch = s.charAt(i);
            if (ch < '0' || ch > '9') break;
            int d = ch - '0';

            if (sign == 1) {
                if (res > Integer.MAX_VALUE / 10 || (res == Integer.MAX_VALUE / 10 && d > 7)) {
                    return Integer.MAX_VALUE;
                }
            } else {
                if (res > Integer.MAX_VALUE / 10 || (res == Integer.MAX_VALUE / 10 && d > 8)) {
                    return Integer.MIN_VALUE;
                }
            }
            res = res * 10 + d;
            i++;
        }
        return sign == 1 ? res : -res;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- **先去空格再判符号；逐位累加前先判溢出**。
