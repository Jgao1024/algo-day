# 105. 从前序与中序遍历序列构造二叉树

- 题号：105
- 难度：中等
- LeetCode：[从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

## 题目描述
给定二叉树的前序遍历 `preorder` 和中序遍历 `inorder`（无重复值），构造并返回这棵二叉树。

## 示例
- 示例  
输入：`preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]`  
输出：`[3,9,20,null,null,15,7]`

## 最佳解法思路
- 递归分治（推荐）  
前序的第一个元素是根；在中序里找到根的位置，就能确定左子树大小，从而切分左右子树的区间。  
用哈希表保存中序值到下标的映射，避免每次线性查找。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[] pre;
    private int[] in;
    private Map<Integer, Integer> inPos;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.pre = preorder;
        this.in = inorder;
        inPos = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) inPos.put(inorder[i], i);
        return build(0, preorder.length - 1, 0, inorder.length - 1);
    }

    private TreeNode build(int preL, int preR, int inL, int inR) {
        if (preL > preR) return null;
        int rootVal = pre[preL];
        int k = inPos.get(rootVal);
        int leftSize = k - inL;
        TreeNode root = new TreeNode(rootVal);
        root.left = build(preL + 1, preL + leftSize, inL, k - 1);
        root.right = build(preL + leftSize + 1, preR, k + 1, inR);
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（哈希表 + 递归栈）

## 总结（速记）
- **前序定根，中序定左右；哈希表存中序下标**。
