# 2. 两数相加

- 题号：2
- 难度：中等
- LeetCode：[两数相加](https://leetcode.cn/problems/add-two-numbers/)

## 题目描述
给定两个非空链表表示的非负整数（低位在前），把它们相加并以同样形式返回结果链表。

## 示例
- 示例  
输入：`l1 = [2,4,3], l2 = [5,6,4]`  
输出：`[7,0,8]`

## 最佳解法思路
- 模拟加法（推荐）  
从头到尾逐位相加，带上 `carry`，新建结果链表。

## Java 最佳实现

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }
            if (l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }
            cur.next = new ListNode(sum % 10);
            cur = cur.next;
            carry = sum / 10;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(\max(m,n))\)
- 空间：\(O(\max(m,n))\)（结果链表）

## 总结（速记）
- **按位相加 + carry，循环条件带上 `carry!=0`**。
