# 32. 最长有效括号

- 题号：32
- 难度：困难
- LeetCode：[最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)

## 题目描述
给定只包含 `'('` 和 `')'` 的字符串 `s`，返回最长有效（格式正确且连续）的括号子串长度。

## 示例
- 示例  
输入：`s = ")()())"`  
输出：`4`

## 最佳解法思路
- 栈 + 哨兵下标（推荐）  
栈里存“还没被匹配的左括号下标”，并先压入 `-1` 作为哨兵。  
遇到 `(` 就入栈；遇到 `)` 就弹栈：  
若弹完栈空，说明这个 `)` 不能匹配，把它的下标当新的分隔点入栈；  
否则当前有效长度是 `i - stack.peek()`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    ans = Math.max(ans, i - stack.peek());
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
