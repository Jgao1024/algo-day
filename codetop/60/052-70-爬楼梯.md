# 70. 爬楼梯

- 题号：70
- 难度：简单
- LeetCode：[爬楼梯](https://leetcode.cn/problems/climbing-stairs/)

## 题目描述
每次可以爬 1 或 2 阶，爬到第 \(n\) 阶有多少种不同方法。

## 示例
- 示例  
输入：`n = 3`  
输出：`3`

## 最佳解法思路
- 动态规划（推荐）  
`dp[i] = dp[i-1] + dp[i-2]`，用两个变量滚动即可。

## Java 最佳实现

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        int a = 1, b = 2;
        for (int i = 3; i <= n; i++) {
            int c = a + b;
            a = b;
            b = c;
        }
        return b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
