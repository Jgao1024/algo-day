# 148. 排序链表

- 题号：148
- 难度：中等
- LeetCode：[排序链表](https://leetcode.cn/problems/sort-list/)

## 题目描述
给定链表头结点 `head`，将其按升序排序并返回排序后的链表。

## 示例
- 示例  
输入：`head = [4,2,1,3]`  
输出：`[1,2,3,4]`

## 最佳解法思路
- 归并排序（推荐）  
链表适合归并：用快慢指针找中点切分成两段，分别排序后再合并两个有序链表。

## Java 最佳实现

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;

        ListNode mid = getMid(head);
        ListNode right = mid.next;
        mid.next = null;

        ListNode leftSorted = sortList(head);
        ListNode rightSorted = sortList(right);
        return merge(leftSorted, rightSorted);
    }

    private ListNode getMid(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) {
                cur.next = a;
                a = a.next;
            } else {
                cur.next = b;
                b = b.next;
            }
            cur = cur.next;
        }
        cur.next = (a != null) ? a : b;
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(\log n)\)（递归栈）
