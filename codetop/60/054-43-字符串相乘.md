# 43. 字符串相乘

- 题号：43
- 难度：中等
- LeetCode：[字符串相乘](https://leetcode.cn/problems/multiply-strings/)

## 题目描述
给定两个非负整数的字符串 `num1`、`num2`，返回它们的乘积字符串（不能直接用大整数库）。

## 示例
- 示例  
输入：`num1 = "123", num2 = "456"`  
输出：`"56088"`

## 最佳解法思路
- 竖式乘法（推荐）  
用长度为 `m+n` 的数组 `res` 存每一位的累加结果。  
`num1[i] * num2[j]` 会影响 `res[i+j+1]`（低位），进位累加到 `res[i+j]`。

## Java 最佳实现

```java
class Solution {
    public String multiply(String num1, String num2) {
        if ("0".equals(num1) || "0".equals(num2)) return "0";
        int m = num1.length(), n = num2.length();
        int[] res = new int[m + n];

        for (int i = m - 1; i >= 0; i--) {
            int a = num1.charAt(i) - '0';
            for (int j = n - 1; j >= 0; j--) {
                int b = num2.charAt(j) - '0';
                int sum = res[i + j + 1] + a * b;
                res[i + j + 1] = sum % 10;
                res[i + j] += sum / 10;
            }
        }

        int idx = 0;
        while (idx < res.length && res[idx] == 0) idx++;
        StringBuilder sb = new StringBuilder();
        while (idx < res.length) sb.append(res[idx++]);
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(m+n)\)

## 总结（速记）
- **用 `m+n` 位数组做竖式：低位放 `i+j+1`，进位加到 `i+j`**。
