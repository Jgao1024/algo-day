# 232. 用栈实现队列

- 题号：232
- 难度：简单
- LeetCode：[用栈实现队列](https://leetcode.cn/problems/implement-queue-using-stacks/)

## 题目描述
仅使用栈的基本操作，实现一个队列，支持 `push(x)`、`pop()`、`peek()`、`empty()`。

## 示例
- 示例  
输入：`["MyQueue","push","push","peek","pop","empty"]`，`[[],[1],[2],[],[],[]]`  
输出：`[null,null,null,1,1,false]`

## 最佳解法思路
- 双栈（推荐）  
用 `in` 栈负责入队；用 `out` 栈负责出队。  
当需要 `pop/peek` 且 `out` 为空时，把 `in` 全部弹出并压入 `out`，即可得到队列顺序。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public MyQueue() {
    }

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void moveIfNeeded() {
        if (!out.isEmpty()) return;
        while (!in.isEmpty()) {
            out.push(in.pop());
        }
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\)
- 空间：\(O(n)\)

## 总结（速记）
- **入队进 `in`；出队看 `out`；`out` 空就把 `in` 倒过去**。
