## 最佳解法思路
- DP：
  - 把数组升序排序
  - `dp[x]` 表示以值 `x` 作为根的二叉树数量（至少为 1：单节点）
  - 枚举 `x` 的因子 `a`（来自数组），若 `x % a == 0` 且 `b = x/a` 也在数组里，则：
    - `dp[x] += dp[a] * dp[b]`（有序左右子树都算进去，枚举 `a` 时自然覆盖）
  - 总答案为所有 `dp[x]` 之和，取模

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private static final long MOD = 1000000007L;

    public int numFactoredBinaryTrees(int[] arr) {
        Arrays.sort(arr);
        int n = arr.length;
        Map<Integer, Integer> idx = new HashMap<>();
        for (int i = 0; i < n; i++) idx.put(arr[i], i);

        long[] dp = new long[n];
        Arrays.fill(dp, 1);

        for (int i = 0; i < n; i++) {
            long x = arr[i];
            for (int j = 0; j < i; j++) {
                if (x % arr[j] != 0) continue;
                long b = x / arr[j];
                Integer k = idx.get((int) b);
                if (k == null) continue;
                dp[i] = (dp[i] + dp[j] * dp[k]) % MOD;
            }
        }

        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
