## 最佳解法思路
- 按月份分类返回：
  - 2 月根据闰年规则返回 28/29
  - 其余月份直接查表

## Java 最佳实现

```java
class Solution {
    public int numberOfDays(int year, int month) {
        if (month == 2) {
            return isLeap(year) ? 29 : 28;
        }
        if (month == 1 || month == 3 || month == 5 || month == 7
                || month == 8 || month == 10 || month == 12) {
            return 31;
        }
        return 30;
    }

    private boolean isLeap(int year) {
        return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
    }
}
```
