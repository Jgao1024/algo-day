## 最佳解法思路
- 分离字母和数字后交替拼接：
  - 若两者数量差超过 1，则返回空串
  - 从数量更多的那类开始交替取字符

## Java 最佳实现

```java
class Solution {
    public String reformat(String s) {
        StringBuilder a = new StringBuilder();
        StringBuilder b = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') a.append(c);
            else b.append(c);
        }
        if (Math.abs(a.length() - b.length()) > 1) return "";

        StringBuilder sb = new StringBuilder();
        StringBuilder first = a.length() >= b.length() ? a : b;
        StringBuilder second = a.length() >= b.length() ? b : a;

        int i = 0;
        while (i < second.length()) {
            sb.append(first.charAt(i));
            sb.append(second.charAt(i));
            i++;
        }
        if (first.length() > second.length()) sb.append(first.charAt(first.length() - 1));
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
