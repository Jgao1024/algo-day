## 最佳解法思路
- 预处理每个下标是否能替换：
  - 对每个 `indexes[t]`，若 `s` 从该位置开始确实匹配 `sources[t]`，记录替换长度和替换目标串
  - 然后从左到右扫描 `s`：
    - 若当前位置可替换，追加 `targets` 并跳过对应长度
    - 否则追加当前字符

## Java 最佳实现

```java
class Solution {
    public String findReplaceString(String s, int[] indexes, String[] sources, String[] targets) {
        int n = s.length();
        int[] len = new int[n];
        String[] rep = new String[n];

        for (int i = 0; i < indexes.length; i++) {
            int idx = indexes[i];
            String src = sources[i];
            if (idx + src.length() <= n && s.startsWith(src, idx)) {
                len[idx] = src.length();
                rep[idx] = targets[i];
            }
        }

        StringBuilder sb = new StringBuilder();
        int i = 0;
        while (i < n) {
            if (len[i] > 0) {
                sb.append(rep[i]);
                i += len[i];
            } else {
                sb.append(s.charAt(i));
                i++;
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n + \sum |source|)\)
- 空间：\(O(n)\)
