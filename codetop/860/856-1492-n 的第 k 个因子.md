## 最佳解法思路
- 枚举因子到 \(\sqrt{n}\)：
  - 遇到小因子 `i` 就 `k--`，若 `k==0` 返回 `i`
  - 同时把对应的大因子 `n/i` 收集起来（注意平方根重复）
  - 遍历结束后，若还没找到，则从“大因子列表”的末尾取第 `k` 个（因为列表按降序收集）

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int kthFactor(int n, int k) {
        List<Integer> big = new ArrayList<>();
        for (int i = 1; i * (long) i <= n; i++) {
            if (n % i != 0) continue;
            k--;
            if (k == 0) return i;
            int other = n / i;
            if (other != i) big.add(other);
        }
        if (k > big.size()) return -1;
        return big.get(big.size() - k);
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{n})\)
- 空间：\(O(\sqrt{n})\)
