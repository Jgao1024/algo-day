## 最佳解法思路
- 最长山形子序列 = 左侧严格递增 LIS + 右侧严格递减 LIS：
  - 计算每个位置 `i` 的 `inc[i]`：以 `i` 结尾的严格递增 LIS 长度
  - 计算每个位置 `i` 的 `dec[i]`：以 `i` 开始向右严格递减的长度（等价于从右往左对 `nums` 做 LIS）
  - 只有 `inc[i] > 1 && dec[i] > 1` 才能作为山顶
  - 最大山形长度 `best = max(inc[i] + dec[i] - 1)`，答案 `n - best`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minimumMountainRemovals(int[] nums) {
        int n = nums.length;
        int[] inc = lisLenEnding(nums);
        int[] dec = lisLenEnding(reverse(nums));
        // dec 是反转数组的“以该位置结尾 LIS”，映射回原数组
        int[] dec2 = new int[n];
        for (int i = 0; i < n; i++) {
            dec2[i] = dec[n - 1 - i];
        }

        int best = 0;
        for (int i = 0; i < n; i++) {
            if (inc[i] > 1 && dec2[i] > 1) {
                best = Math.max(best, inc[i] + dec2[i] - 1);
            }
        }
        return n - best;
    }

    private int[] lisLenEnding(int[] a) {
        int n = a.length;
        int[] tails = new int[n];
        int size = 0;
        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            int x = a[i];
            int idx = Arrays.binarySearch(tails, 0, size, x);
            if (idx < 0) idx = -idx - 1;
            tails[idx] = x;
            if (idx == size) size++;
            res[i] = idx + 1;
        }
        return res;
    }

    private int[] reverse(int[] a) {
        int n = a.length;
        int[] b = new int[n];
        for (int i = 0; i < n; i++) b[i] = a[n - 1 - i];
        return b;
    }
}
```

- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
