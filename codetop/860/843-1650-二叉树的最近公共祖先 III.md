## 最佳解法思路
- 两指针走父链表（类似链表相交）：
  - 指针 `a` 从 `p` 向上走，走到 null 就切到 `q`
  - 指针 `b` 从 `q` 向上走，走到 null 就切到 `p`
  - 最终会在 LCA 相遇

## Java 最佳实现

```java
/**
 * Definition for a Node.
 * class Node {
 *     public int val;
 *     public Node left;
 *     public Node right;
 *     public Node parent;
 * }
 */
class Solution {
    public Node lowestCommonAncestor(Node p, Node q) {
        Node a = p;
        Node b = q;
        while (a != b) {
            a = (a == null) ? q : a.parent;
            b = (b == null) ? p : b.parent;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(h)\)
- 空间：\(O(1)\)
