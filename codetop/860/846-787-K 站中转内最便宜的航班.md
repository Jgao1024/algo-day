## 最佳解法思路
- 动态规划（Bellman-Ford 思想）：
  - 允许最多 `k` 次中转 = 最多 `k+1` 条边
  - `dp[v]` 表示使用不超过当前轮边数到达 `v` 的最小花费
  - 迭代 `k+1` 轮，每轮用上一轮的 `dp` 去松弛所有航班边

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
        final int INF = 1_000_000_000;
        int[] dp = new int[n];
        Arrays.fill(dp, INF);
        dp[src] = 0;

        for (int i = 0; i <= k; i++) {
            int[] next = Arrays.copyOf(dp, n);
            for (int[] f : flights) {
                int u = f[0], v = f[1], w = f[2];
                if (dp[u] == INF) continue;
                next[v] = Math.min(next[v], dp[u] + w);
            }
            dp = next;
        }

        return dp[dst] >= INF ? -1 : dp[dst];
    }
}
```

## 复杂度分析
- 时间：\(O((k+1)\cdot E)\)
- 空间：\(O(n)\)
