## 最佳解法思路
- 位运算表示每排座位占用情况（只关心 2..9）：
  - 初始每排可坐 2 组家庭（左 2-5、右 6-9）
  - 对有预定的行，构造 mask
  - 检查三种可放置区间：`[2..5]`、`[4..7]`、`[6..9]`
    - 若左右都空 -> 2
    - 否则若任一空（左/中/右）-> 1
    - 否则 -> 0

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        Map<Integer, Integer> rowMask = new HashMap<>();
        for (int[] r : reservedSeats) {
            int row = r[0];
            int seat = r[1];
            if (seat < 2 || seat > 9) continue;
            int bit = 1 << seat;
            rowMask.put(row, rowMask.getOrDefault(row, 0) | bit);
        }

        int ans = (n - rowMask.size()) * 2;
        int left = seatsMask(2, 5);
        int mid = seatsMask(4, 7);
        int right = seatsMask(6, 9);

        for (int mask : rowMask.values()) {
            boolean okLeft = (mask & left) == 0;
            boolean okRight = (mask & right) == 0;
            if (okLeft && okRight) {
                ans += 2;
            } else if (okLeft || okRight || (mask & mid) == 0) {
                ans += 1;
            }
        }
        return ans;
    }

    private int seatsMask(int l, int r) {
        int m = 0;
        for (int i = l; i <= r; i++) m |= (1 << i);
        return m;
    }
}
```

## 复杂度分析
- 时间：\(O(R)\)，R 为预定记录数
- 空间：\(O(\text{有预定的行数})\)
