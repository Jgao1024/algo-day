## 最佳解法思路
- 线程池 + 并发去重：
  - 只爬取与 `startUrl` 同域名的链接
  - `visited` 使用并发集合去重
  - 用 `active` 统计当前未完成任务数：
    - 新提交任务前 `active++`
    - 任务结束 `active--`，当减到 0 时表示全部完成

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * // This is the HtmlParser's API interface.
 * // You should not implement it, or speculate about its implementation
 * interface HtmlParser {
 *     public List<String> getUrls(String url);
 * }
 */
class Solution {
    public List<String> crawl(String startUrl, HtmlParser htmlParser) {
        String host = getHost(startUrl);
        Set<String> vis = ConcurrentHashMap.newKeySet();
        vis.add(startUrl);

        ExecutorService pool = Executors.newFixedThreadPool(8);
        AtomicInteger active = new AtomicInteger(1);
        CountDownLatch done = new CountDownLatch(1);
        AtomicBoolean finished = new AtomicBoolean(false);

        pool.execute(() -> work(startUrl, host, htmlParser, vis, pool, active, done, finished));
        try {
            done.await();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            pool.shutdown();
        }
        return new ArrayList<>(vis);
    }

    private void work(String url, String host, HtmlParser parser, Set<String> vis,
                      ExecutorService pool, AtomicInteger active, CountDownLatch done, AtomicBoolean finished) {
        try {
            for (String nxt : parser.getUrls(url)) {
                if (!host.equals(getHost(nxt))) continue;
                if (vis.add(nxt)) {
                    active.incrementAndGet();
                    pool.execute(() -> work(nxt, host, parser, vis, pool, active, done, finished));
                }
            }
        } finally {
            if (active.decrementAndGet() == 0) {
                if (finished.compareAndSet(false, true)) done.countDown();
            }
        }
    }

    private String getHost(String url) {
        int i = url.indexOf("://");
        int start = (i == -1) ? 0 : i + 3;
        int slash = url.indexOf('/', start);
        return (slash == -1) ? url.substring(start) : url.substring(start, slash);
    }
}
```

- 时间：与可访问页面数量及链接数有关
- 空间：\(O(V)\)
