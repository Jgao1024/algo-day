## 最佳解法思路
- 记忆化搜索：
  - 每天可以吃 1 个；或如果能被 2/3 整除，则先吃掉余数让其整除，再执行 `/2` 或 `/3`
  - 递推：
    - `f(n) = 1 + min(n%2 + f(n/2), n%3 + f(n/3))`
  - 用 HashMap 记忆化减少状态

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private final Map<Integer, Integer> memo = new HashMap<>();

    public int minDays(int n) {
        return dfs(n);
    }

    private int dfs(int n) {
        if (n <= 1) return n;
        Integer v = memo.get(n);
        if (v != null) return v;
        int ans = 1 + Math.min(n % 2 + dfs(n / 2), n % 3 + dfs(n / 3));
        memo.put(n, ans);
        return ans;
    }
}
```

## 复杂度分析
- 时间：状态数较少（约 \(O(\log n)\) 量级）
- 空间：\(O(\log n)\)
