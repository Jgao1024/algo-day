## 最佳解法思路
- 每次调用 `read4(tmp)` 最多读 4 个字符，累计写入 `buf`，直到读满 `n` 或文件结束（读到 0）。

## Java 最佳实现

```java
/**
 * The read4 API is defined in the parent class Reader4.
 * int read4(char[] buf4);
 */
public class Solution extends Reader4 {
    public int read(char[] buf, int n) {
        char[] tmp = new char[4];
        int total = 0;
        while (total < n) {
            int cnt = read4(tmp);
            if (cnt == 0) break;
            int len = Math.min(cnt, n - total);
            for (int i = 0; i < len; i++) {
                buf[total++] = tmp[i];
            }
        }
        return total;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
