## 最佳解法思路
- 只需检查最近几条边是否产生自交（O(1) 规则）：
  - 情况1：第 i 条边与第 i-3 条边相交
  - 情况2：第 i 条边与第 i-4 条边重合相交
  - 情况3：第 i 条边与第 i-5 条边相交

## Java 最佳实现

```java
class Solution {
    public boolean isSelfCrossing(int[] d) {
        for (int i = 3; i < d.length; i++) {
            // i 与 i-3 相交
            if (d[i] >= d[i - 2] && d[i - 1] <= d[i - 3]) return true;

            // i 与 i-4 重合相交
            if (i >= 4 && d[i - 1] == d[i - 3] && d[i] + d[i - 4] >= d[i - 2]) return true;

            // i 与 i-5 相交
            if (i >= 5
                    && d[i - 2] >= d[i - 4]
                    && d[i] + d[i - 4] >= d[i - 2]
                    && d[i - 1] >= d[i - 3] - d[i - 5]
                    && d[i - 1] <= d[i - 3]) return true;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
