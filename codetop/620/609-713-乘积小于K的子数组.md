## 最佳解法思路
- 因为数组元素为正数，可用滑动窗口维护当前乘积 `< k`。
- 右指针扩张并乘上新元素；若乘积 \(\ge k\)，左指针收缩并除掉移出元素。
- 以 `right` 结尾的合法子数组个数为 `right - left + 1`。

## Java 最佳实现

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        if (k <= 1) return 0;
        long prod = 1;
        int left = 0;
        int ans = 0;
        for (int right = 0; right < nums.length; right++) {
            prod *= nums[right];
            while (left <= right && prod >= k) {
                prod /= nums[left++];
            }
            ans += right - left + 1;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
