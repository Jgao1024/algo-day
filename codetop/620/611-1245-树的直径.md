## 最佳解法思路
- 两次 BFS/DFS：从任意点出发找到最远点 `u`，再从 `u` 出发找到最远距离 `d`，`d` 就是直径长度。
- 树无环，最远点一定在某条直径端点上。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public int treeDiameter(int[][] edges) {
        int n = edges.length + 1;
        List<Integer>[] g = new List[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (int[] e : edges) {
            g[e[0]].add(e[1]);
            g[e[1]].add(e[0]);
        }

        int u = bfsFarthest(0, g)[0];
        int[] res = bfsFarthest(u, g);
        return res[1];
    }

    private int[] bfsFarthest(int start, List<Integer>[] g) {
        int n = g.length;
        int[] dist = new int[n];
        for (int i = 0; i < n; i++) dist[i] = -1;
        Deque<Integer> q = new ArrayDeque<>();
        q.add(start);
        dist[start] = 0;

        int far = start;
        while (!q.isEmpty()) {
            int u = q.poll();
            if (dist[u] > dist[far]) far = u;
            for (int v : g[u]) {
                if (dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                q.add(v);
            }
        }
        return new int[]{far, dist[far]};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
