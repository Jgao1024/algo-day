## 最佳解法思路
- 欧拉路径：把机票看成有向边，需要从 `JFK` 出发走完所有边且字典序最小。
- 用 Hierholzer 算法：对每个出发点维护一个按字典序的最小堆；DFS 时不断取最小目的地走下去，走不动就把当前点加入答案头部。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.LinkedList;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    public List<String> findItinerary(List<List<String>> tickets) {
        Map<String, PriorityQueue<String>> g = new HashMap<>();
        for (List<String> t : tickets) {
            String from = t.get(0);
            String to = t.get(1);
            g.computeIfAbsent(from, k -> new PriorityQueue<>()).add(to);
        }

        LinkedList<String> path = new LinkedList<>();
        dfs("JFK", g, path);
        return path;
    }

    private void dfs(String u, Map<String, PriorityQueue<String>> g, LinkedList<String> path) {
        PriorityQueue<String> pq = g.get(u);
        while (pq != null && !pq.isEmpty()) {
            String v = pq.poll();
            dfs(v, g, path);
            pq = g.get(u);
        }
        path.addFirst(u);
    }
}
```

## 复杂度分析
- 时间：\(O(E \log E)\)
- 空间：\(O(E)\)
