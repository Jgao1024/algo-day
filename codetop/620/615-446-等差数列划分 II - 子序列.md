## 最佳解法思路
- DP + 哈希表：`dp[i][d]` 表示以 `i` 结尾、公差为 `d` 的等差子序列个数（长度 \(\ge 2\)）。
- 枚举 `j < i`：`d = nums[i] - nums[j]`，`cnt = dp[j][d]`，那么新增的长度 \(\ge 3\) 的数量是 `cnt`，并更新 `dp[i][d] += cnt + 1`（`+1` 表示新形成的长度为 2 的序列 `(j,i)`）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfArithmeticSlices(int[] nums) {
        int n = nums.length;
        @SuppressWarnings("unchecked")
        Map<Long, Long>[] dp = new Map[n];
        for (int i = 0; i < n; i++) dp[i] = new HashMap<>();

        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                long d = (long) nums[i] - (long) nums[j];
                long cnt = dp[j].getOrDefault(d, 0L);
                ans += cnt;
                dp[i].put(d, dp[i].getOrDefault(d, 0L) + cnt + 1);
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)（最坏不同差值很多）
