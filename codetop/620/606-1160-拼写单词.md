## 最佳解法思路
- 统计 `chars` 每个字母的次数；遍历每个单词，统计所需次数，若有任意字母超出可用次数则该词不可拼写。
- 可拼写的单词把长度累加到答案。

## Java 最佳实现

```java
class Solution {
    public int countCharacters(String[] words, String chars) {
        int[] base = new int[26];
        for (int i = 0; i < chars.length(); i++) {
            base[chars.charAt(i) - 'a']++;
        }

        int ans = 0;
        for (String w : words) {
            int[] need = new int[26];
            boolean ok = true;
            for (int i = 0; i < w.length(); i++) {
                int idx = w.charAt(i) - 'a';
                need[idx]++;
                if (need[idx] > base[idx]) {
                    ok = false;
                    break;
                }
            }
            if (ok) ans += w.length();
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\sum |word| + |chars|)\)
- 空间：\(O(1)\)
