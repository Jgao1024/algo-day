## 最佳解法思路
- 排序供暖器；对每个房子二分找最近的供暖器位置，取最近距离。
- 答案是所有房子“最近距离”的最大值。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int findRadius(int[] houses, int[] heaters) {
        Arrays.sort(heaters);
        int ans = 0;
        for (int h : houses) {
            int d = dist(h, heaters);
            ans = Math.max(ans, d);
        }
        return ans;
    }

    private int dist(int x, int[] a) {
        int l = 0, r = a.length - 1;
        while (l <= r) {
            int m = l + ((r - l) >>> 1);
            if (a[m] < x) l = m + 1;
            else r = m - 1;
        }
        int d1 = l < a.length ? Math.abs(a[l] - x) : Integer.MAX_VALUE;
        int d2 = r >= 0 ? Math.abs(a[r] - x) : Integer.MAX_VALUE;
        return Math.min(d1, d2);
    }
}
```

## 复杂度分析
- 时间：\(O(n\log m)\)（先排序 \(O(m\log m)\)）
- 空间：\(O(1)\)
