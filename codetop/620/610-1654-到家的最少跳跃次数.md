## 最佳解法思路
- BFS：状态为 `(pos, usedBack)`，`usedBack=1` 表示上一步是后跳（下一步不能再后跳）。
- 用 `forbidden` 集合做禁用点；并设置搜索上界 `limit`，避免无穷扩张（常用：`max(forbidden, x) + a + b` 再加一段安全距离）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumJumps(int[] forbidden, int a, int b, int x) {
        int max = x;
        Set<Integer> ban = new HashSet<>();
        for (int v : forbidden) {
            ban.add(v);
            max = Math.max(max, v);
        }
        int limit = max + a + b + a;

        boolean[][] vis = new boolean[limit + 1][2];
        Deque<int[]> q = new ArrayDeque<>();
        q.add(new int[]{0, 0});
        vis[0][0] = true;

        int step = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                int[] cur = q.poll();
                int pos = cur[0];
                int usedBack = cur[1];
                if (pos == x) return step;

                int f = pos + a;
                if (f <= limit && !ban.contains(f) && !vis[f][0]) {
                    vis[f][0] = true;
                    q.add(new int[]{f, 0});
                }

                int back = pos - b;
                if (usedBack == 0 && back >= 0 && !ban.contains(back) && !vis[back][1]) {
                    vis[back][1] = true;
                    q.add(new int[]{back, 1});
                }
            }
            step++;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(limit)\)
- 空间：\(O(limit)\)
