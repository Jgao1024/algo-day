## 最佳解法思路
- 预处理所有 `prefix + "#" + suffix` 的组合，记录最大的下标。
- 单词长度不大时（本题常见约束是 \(L \le 10\)），枚举每个单词所有前缀/后缀组合即可。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class WordFilter {
    private final Map<String, Integer> map = new HashMap<>();

    public WordFilter(String[] words) {
        for (int i = 0; i < words.length; i++) {
            String w = words[i];
            int n = w.length();
            for (int p = 0; p <= n; p++) {
                String pre = w.substring(0, p);
                for (int s = 0; s <= n; s++) {
                    String suf = w.substring(n - s);
                    map.put(pre + "#" + suf, i);
                }
            }
        }
    }

    public int f(String pref, String suff) {
        Integer v = map.get(pref + "#" + suff);
        return v == null ? -1 : v;
    }
}
```

## 复杂度分析
- 时间：预处理 \(O(N\cdot L^2)\)，查询 \(O(1)\)
- 空间：\(O(N\cdot L^2)\)
