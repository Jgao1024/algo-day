## 最佳解法思路
- 滑动窗口：窗口内最多允许替换 `k` 个字符，让窗口变成“全是同一个字符”。
- 维护窗口内出现次数最多的字符数 `maxCnt`，当 `windowLen - maxCnt > k` 时收缩左边界。

## Java 最佳实现

```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] cnt = new int[26];
        int left = 0;
        int maxCnt = 0;
        int ans = 0;

        for (int right = 0; right < s.length(); right++) {
            int idx = s.charAt(right) - 'A';
            cnt[idx]++;
            maxCnt = Math.max(maxCnt, cnt[idx]);

            while (right - left + 1 - maxCnt > k) {
                cnt[s.charAt(left) - 'A']--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
