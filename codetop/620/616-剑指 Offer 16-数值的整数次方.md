## 最佳解法思路
- 快速幂：把 `n` 转成 `long`，用二进制拆分指数，迭代做平方。
- 若 `n < 0`，先把底数取倒数，并把指数变成正数。

## Java 最佳实现

```java
class Solution {
    public double myPow(double x, int n) {
        long p = n;
        if (p < 0) {
            x = 1.0 / x;
            p = -p;
        }

        double ans = 1.0;
        double base = x;
        while (p > 0) {
            if ((p & 1) == 1) ans *= base;
            base *= base;
            p >>= 1;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\log |n|)\)
- 空间：\(O(1)\)
