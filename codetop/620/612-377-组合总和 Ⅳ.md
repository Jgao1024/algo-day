## 最佳解法思路
- DP：`dp[i]` 表示凑出和为 `i` 的方案数（顺序不同算不同方案）。
- 转移：`dp[i] += dp[i - num]`。

## Java 最佳实现

```java
class Solution {
    public int combinationSum4(int[] nums, int target) {
        long[] dp = new long[target + 1];
        dp[0] = 1;
        for (int i = 1; i <= target; i++) {
            long ways = 0;
            for (int num : nums) {
                if (i - num >= 0) {
                    ways += dp[i - num];
                }
            }
            dp[i] = ways;
        }
        return (int) dp[target];
    }
}
```

## 复杂度分析
- 时间：\(O(target \cdot n)\)
- 空间：\(O(target)\)
