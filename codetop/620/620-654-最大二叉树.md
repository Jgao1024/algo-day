## 最佳解法思路
- 单调栈：从左到右遍历，维护一个“从栈底到栈顶递减”的栈。
- 对当前值 `x`：不断弹出比 `x` 小的节点，它们会成为 `x` 的左子树；若栈不空，栈顶节点的右子树指向 `x`。

## Java 最佳实现

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        int n = nums.length;
        TreeNode[] st = new TreeNode[n];
        int top = -1;

        for (int v : nums) {
            TreeNode cur = new TreeNode(v);
            while (top >= 0 && st[top].val < v) {
                cur.left = st[top--];
            }
            if (top >= 0) {
                st[top].right = cur;
            }
            st[++top] = cur;
        }
        return st[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
