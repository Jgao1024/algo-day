## 最佳解法思路
- 思路：标记出现次数  
用布尔数组/计数数组遍历 `nums` 找到重复数 `dup`；再从 `1..n` 找缺失数 `miss`。

## Java 最佳实现

```java
class Solution {
    public int[] findErrorNums(int[] nums) {
        int n = nums.length;
        boolean[] seen = new boolean[n + 1];
        int dup = -1;
        for (int x : nums) {
            if (seen[x]) {
                dup = x;
            }
            seen[x] = true;
        }

        int miss = -1;
        for (int i = 1; i <= n; i++) {
            if (!seen[i]) {
                miss = i;
                break;
            }
        }
        return new int[]{dup, miss};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
