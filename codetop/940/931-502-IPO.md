## 最佳解法思路
- 思路（推荐）：排序 + 大根堆  
把项目按 `capital` 升序排序，用指针把所有 `capital <= 当前资金 w` 的项目加入大根堆（按 `profit`）。  
每轮从堆里取利润最大的项目做，更新 `w`，最多做 `k` 次；若堆为空则提前结束。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int findMaximizedCapital(int k, int w, int[] profits, int[] capital) {
        int n = profits.length;
        int[][] proj = new int[n][2];
        for (int i = 0; i < n; i++) {
            proj[i][0] = capital[i];
            proj[i][1] = profits[i];
        }
        Arrays.sort(proj, (a, b) -> a[0] - b[0]);

        PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> b - a);
        int i = 0;
        int cur = w;

        for (int t = 0; t < k; t++) {
            while (i < n && proj[i][0] <= cur) {
                pq.add(proj[i][1]);
                i++;
            }
            if (pq.isEmpty()) {
                break;
            }
            cur += pq.poll();
        }
        return cur;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n + k \log n)\)
- 空间：\(O(n)\)
