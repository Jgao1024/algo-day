## 最佳解法思路
- 思路：拼接后判断子串  
若 `s1` 与 `s2` 长度不同，必不可能。否则 `s2` 是 `s1+s1` 的子串即可。

## Java 最佳实现

```java
class Solution {
    public boolean isFlipedString(String s1, String s2) {
        if (s1.length() != s2.length()) {
            return false;
        }
        return (s1 + s1).contains(s2);
    }
}
```

## 复杂度分析
- 时间：取决于 `contains` 实现
- 空间：\(O(n)\)
