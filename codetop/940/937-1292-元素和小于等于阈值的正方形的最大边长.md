## 最佳解法思路
- 思路：二维前缀和 + 二分边长  
先算二维前缀和 `pre`，可 \(O(1)\) 求任意正方形和。  
对边长 `len` 二分：检查是否存在某个 `len*len` 正方形和 `<= threshold`，若存在尝试更大，否则更小。

## Java 最佳实现

```java
class Solution {
    public int maxSideLength(int[][] mat, int threshold) {
        int m = mat.length;
        int n = mat[0].length;

        int[][] pre = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                pre[i][j] = pre[i - 1][j] + pre[i][j - 1] - pre[i - 1][j - 1] + mat[i - 1][j - 1];
            }
        }

        int l = 0;
        int r = Math.min(m, n);
        while (l < r) {
            int mid = (l + r + 1) >>> 1;
            if (exists(pre, m, n, mid, threshold)) {
                l = mid;
            } else {
                r = mid - 1;
            }
        }
        return l;
    }

    private boolean exists(int[][] pre, int m, int n, int len, int threshold) {
        if (len == 0) {
            return true;
        }
        for (int i = len; i <= m; i++) {
            for (int j = len; j <= n; j++) {
                int sum = pre[i][j] - pre[i - len][j] - pre[i][j - len] + pre[i - len][j - len];
                if (sum <= threshold) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(mn \log(\min(m,n)))\)
- 空间：\(O(mn)\)
