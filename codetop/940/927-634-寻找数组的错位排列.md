## 最佳解法思路
- 思路：DP（错位排列数）  
设 `dp[n]` 表示 `1..n` 的错位排列数，则  
`dp[1]=0, dp[2]=1`，并且  
`dp[n] = (n-1) * (dp[n-1] + dp[n-2])`。  
结果对 \(10^9+7\) 取模。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int findDerangement(int n) {
        if (n == 1) {
            return 0;
        }
        if (n == 2) {
            return 1;
        }
        long a = 0;
        long b = 1;
        for (int i = 3; i <= n; i++) {
            long c = (i - 1L) * (a + b) % MOD;
            a = b;
            b = c;
        }
        return (int) b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
