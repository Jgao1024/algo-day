## 最佳解法思路
- 思路：Floyd（或对每个点跑 Dijkstra）  
`n<=100` 时 Floyd 很直接：初始化 `dist[i][j]`，跑三重循环求最短路。  
然后对每个城市数一数 `dist[i][j] <= threshold` 的邻居数，取邻居数最少的；若并列取编号最大的。

## Java 最佳实现

```java
class Solution {
    public int findTheCity(int n, int[][] edges, int distanceThreshold) {
        int INF = 1_000_000_000;
        int[][] dist = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                dist[i][j] = (i == j) ? 0 : INF;
            }
        }
        for (int[] e : edges) {
            int a = e[0], b = e[1], w = e[2];
            dist[a][b] = Math.min(dist[a][b], w);
            dist[b][a] = Math.min(dist[b][a], w);
        }

        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    int nd = dist[i][k] + dist[k][j];
                    if (nd < dist[i][j]) {
                        dist[i][j] = nd;
                    }
                }
            }
        }

        int bestCity = -1;
        int bestCnt = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int cnt = 0;
            for (int j = 0; j < n; j++) {
                if (i != j && dist[i][j] <= distanceThreshold) {
                    cnt++;
                }
            }
            if (cnt <= bestCnt) {
                bestCnt = cnt;
                bestCity = i;
            }
        }
        return bestCity;
    }
}
```

## 复杂度分析
- 时间：\(O(n^3)\)
- 空间：\(O(n^2)\)
