## 最佳解法思路
- 思路（推荐）：DP（最大分数 + 方案数）  
从右下到左上 DP。对每格维护：  
- `best[i][j]`：从该格到终点的最大得分  
- `ways[i][j]`：达到该最大得分的方案数  
转移来自三个方向（右、下、右下）。遇到障碍跳过。字符是数字就加分，`S/E` 当 0。最终输出 `[best[0][0], ways[0][0]]`，若不可达输出 `[0,0]`。

## Java 最佳实现

```java
import java.util.List;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int[] pathsWithMaxScore(List<String> board) {
        int n = board.size();
        int[][] best = new int[n][n];
        int[][] ways = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                best[i][j] = -1;
            }
        }

        best[n - 1][n - 1] = 0;
        ways[n - 1][n - 1] = 1;

        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                char c = board.get(i).charAt(j);
                if (c == 'X') {
                    continue;
                }
                if (i == n - 1 && j == n - 1) {
                    continue;
                }

                int maxPrev = -1;
                long cnt = 0;
                int[][] dirs = {{1, 0}, {0, 1}, {1, 1}};
                for (int[] d : dirs) {
                    int ni = i + d[0];
                    int nj = j + d[1];
                    if (ni >= n || nj >= n) {
                        continue;
                    }
                    int b = best[ni][nj];
                    if (b < 0) {
                        continue;
                    }
                    if (b > maxPrev) {
                        maxPrev = b;
                        cnt = ways[ni][nj];
                    } else if (b == maxPrev) {
                        cnt += ways[ni][nj];
                    }
                }

                if (maxPrev < 0) {
                    continue;
                }

                int add = 0;
                if (c >= '0' && c <= '9') {
                    add = c - '0';
                }
                best[i][j] = maxPrev + add;
                ways[i][j] = (int) (cnt % MOD);
            }
        }

        if (best[0][0] < 0) {
            return new int[]{0, 0};
        }
        return new int[]{best[0][0], ways[0][0]};
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n^2)\)
