## 最佳解法思路
- 思路：扫描相邻数字的间隙  
把 `lower` 作为“前一个数”，依次看 `nums[i]`，若 `nums[i] > prev + 1` 就产生缺失区间。  
注意用 `long` 处理边界溢出（`lower-1` / `upper+1`）。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> findMissingRanges(int[] nums, int lower, int upper) {
        List<String> ans = new ArrayList<>();
        long prev = (long) lower - 1;
        long up = upper;

        for (int i = 0; i <= nums.length; i++) {
            long cur = (i == nums.length) ? (up + 1) : nums[i];
            if (cur > prev + 1) {
                ans.add(format(prev + 1, cur - 1));
            }
            prev = cur;
        }

        return ans;
    }

    private String format(long a, long b) {
        if (a == b) {
            return String.valueOf(a);
        }
        return a + "->" + b;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)（不计输出）
