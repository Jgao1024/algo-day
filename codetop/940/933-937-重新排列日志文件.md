## 最佳解法思路
- 思路：自定义排序  
字母日志在前，数字日志在后且保持原顺序。  
字母日志按“内容”字典序排序，内容相同按“标识符”字典序排序。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public String[] reorderLogFiles(String[] logs) {
        Arrays.sort(logs, (a, b) -> {
            int ia = a.indexOf(' ');
            int ib = b.indexOf(' ');
            String ida = a.substring(0, ia);
            String idb = b.substring(0, ib);
            String ca = a.substring(ia + 1);
            String cb = b.substring(ib + 1);

            boolean da = Character.isDigit(ca.charAt(0));
            boolean db = Character.isDigit(cb.charAt(0));
            if (da && db) {
                return 0;
            }
            if (da) {
                return 1;
            }
            if (db) {
                return -1;
            }

            int cmp = ca.compareTo(cb);
            if (cmp != 0) {
                return cmp;
            }
            return ida.compareTo(idb);
        });
        return logs;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n \cdot L)\)
- 空间：\(O(1)\)（排序视实现）
