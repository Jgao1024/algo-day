## 最佳解法思路
- 思路（推荐）：完全背包（最大位数）+ 贪心回溯构造  
先用 DP 求“能组成的最大位数”：`dp[t]` 表示成本和为 `t` 时能得到的最大位数，转移 `dp[t] = max(dp[t-cost[d]] + 1)`。  
若 `dp[target] < 0` 则无解返回 `"0"`。  
构造答案时从 9 到 1 依次尝试：只要满足 `dp[t] == dp[t-cost[d]] + 1` 就选该数字并减少 `t`，这样保证数值最大（高位尽量大）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public String largestNumber(int[] cost, int target) {
        int[] dp = new int[target + 1];
        Arrays.fill(dp, Integer.MIN_VALUE / 4);
        dp[0] = 0;

        for (int t = 1; t <= target; t++) {
            for (int d = 1; d <= 9; d++) {
                int c = cost[d - 1];
                if (t >= c && dp[t - c] > Integer.MIN_VALUE / 8) {
                    dp[t] = Math.max(dp[t], dp[t - c] + 1);
                }
            }
        }

        if (dp[target] < 0) {
            return "0";
        }

        StringBuilder sb = new StringBuilder();
        int t = target;
        for (int d = 9; d >= 1; d--) {
            int c = cost[d - 1];
            while (t >= c && dp[t] == dp[t - c] + 1) {
                sb.append(d);
                t -= c;
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(9 \cdot target)\)
- 空间：\(O(target)\)
