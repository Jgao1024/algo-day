## 最佳解法思路
- 思路：按 turn 排序后做前缀和  
按 `turn` 升序累加 `weight`，找到最后一个使累计重量 `<= 1000` 的人即可。

## SQL 最佳实现

```sql
SELECT person_name
FROM (
    SELECT person_name,
           SUM(weight) OVER (ORDER BY turn) AS total_weight
    FROM Queue
) t
WHERE total_weight <= 1000
ORDER BY total_weight DESC
LIMIT 1;
```
