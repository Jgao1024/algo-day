## 最佳解法思路
- 思路（推荐）：差分延迟增量  
用数组存栈元素，再用 `inc[i]` 记录“对底部前 i 个元素的增量”。  
`increment(k, val)` 只做 `inc[min(k, size)-1] += val`。  
`pop` 时把 `inc[top]` 下传到 `inc[top-1]`，并返回 `stack[top] + inc[top]`。

## Java 最佳实现

```java
class CustomStack {
    private final int maxSize;
    private final int[] stack;
    private final int[] inc;
    private int size = 0;

    public CustomStack(int maxSize) {
        this.maxSize = maxSize;
        this.stack = new int[maxSize];
        this.inc = new int[maxSize];
    }

    public void push(int x) {
        if (size == maxSize) {
            return;
        }
        stack[size] = x;
        inc[size] = 0;
        size++;
    }

    public int pop() {
        if (size == 0) {
            return -1;
        }
        int i = size - 1;
        int add = inc[i];
        if (i > 0) {
            inc[i - 1] += add;
        }
        int res = stack[i] + add;
        size--;
        return res;
    }

    public void increment(int k, int val) {
        int i = Math.min(k, size) - 1;
        if (i >= 0) {
            inc[i] += val;
        }
    }
}
```

## 复杂度分析
- 时间：每个操作 \(O(1)\)
- 空间：\(O(\text{maxSize})\)
