## 最佳解法思路
- 思路：从后往前合并  
`A` 末尾有空位，从后往前用双指针，把较大的放到 `A[end]`，避免覆盖。

## Java 最佳实现

```java
class Solution {
    public void merge(int[] A, int m, int[] B, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;
        while (j >= 0) {
            if (i >= 0 && A[i] > B[j]) {
                A[k--] = A[i--];
            } else {
                A[k--] = B[j--];
            }
        }
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)
