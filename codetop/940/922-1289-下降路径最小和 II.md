## 最佳解法思路
- 思路（推荐）：DP + 维护上一行最小/次小  
转移：`dp[i][j] = grid[i][j] + min(dp[i-1][k]) (k!=j)`。  
直接枚举会 \(O(n^3)\)。优化：对上一行维护最小值 `min1` 及其列 `idx1`，还有次小值 `min2`。  
则当前列 `j` 用 `min1`（若 `j!=idx1`）否则用 `min2`。

## Java 最佳实现

```java
class Solution {
    public int minFallingPathSum(int[][] grid) {
        int n = grid.length;
        int[] dp = new int[n];
        for (int j = 0; j < n; j++) {
            dp[j] = grid[0][j];
        }

        for (int i = 1; i < n; i++) {
            int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE, idx1 = -1;
            for (int j = 0; j < n; j++) {
                int v = dp[j];
                if (v < min1) {
                    min2 = min1;
                    min1 = v;
                    idx1 = j;
                } else if (v < min2) {
                    min2 = v;
                }
            }

            int[] ndp = new int[n];
            for (int j = 0; j < n; j++) {
                int bestPrev = (j == idx1) ? min2 : min1;
                ndp[j] = bestPrev + grid[i][j];
            }
            dp = ndp;
        }

        int ans = dp[0];
        for (int v : dp) {
            ans = Math.min(ans, v);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
