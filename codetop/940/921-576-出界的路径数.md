## 最佳解法思路
- 思路（推荐）：DP（步数滚动）  
`dp[i][j]` 表示当前步数下在格子 `(i,j)` 的路径数。每一步从四个方向转移；若走出边界则累加到答案。用二维数组滚动 `maxMove` 次即可。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int findPaths(int m, int n, int maxMove, int startRow, int startColumn) {
        int[][] dp = new int[m][n];
        dp[startRow][startColumn] = 1;

        long ans = 0;
        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};

        for (int step = 1; step <= maxMove; step++) {
            int[][] ndp = new int[m][n];
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    int ways = dp[i][j];
                    if (ways == 0) {
                        continue;
                    }
                    for (int d = 0; d < 4; d++) {
                        int ni = i + dx[d];
                        int nj = j + dy[d];
                        if (ni < 0 || ni >= m || nj < 0 || nj >= n) {
                            ans += ways;
                        } else {
                            ndp[ni][nj] = (ndp[ni][nj] + ways) % MOD;
                        }
                    }
                }
            }
            ans %= MOD;
            dp = ndp;
        }

        return (int) (ans % MOD);
    }
}
```

## 复杂度分析
- 时间：\(O(\text{maxMove} \cdot m \cdot n)\)
- 空间：\(O(mn)\)
