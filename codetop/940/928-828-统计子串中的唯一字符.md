## 最佳解法思路
- 思路（推荐）：按字符贡献计数  
对每个字符的每次出现位置 `i`，它对答案的贡献是：  
以它为“唯一字符”的子串个数 = `(i - prev) * (next - i)`，其中 `prev/next` 是该字符上一次/下一次出现位置（不存在则用 -1 / n）。  
对所有字符的所有出现位置求和即可。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int uniqueLetterString(String s) {
        int n = s.length();
        List<Integer>[] pos = new ArrayList[26];
        for (int i = 0; i < 26; i++) {
            pos[i] = new ArrayList<>();
            pos[i].add(-1);
        }
        for (int i = 0; i < n; i++) {
            pos[s.charAt(i) - 'A'].add(i);
        }
        for (int i = 0; i < 26; i++) {
            pos[i].add(n);
        }

        long ans = 0;
        for (int c = 0; c < 26; c++) {
            List<Integer> p = pos[c];
            for (int i = 1; i + 1 < p.size(); i++) {
                long prev = p.get(i - 1);
                long cur = p.get(i);
                long next = p.get(i + 1);
                ans += (cur - prev) * (next - cur);
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
