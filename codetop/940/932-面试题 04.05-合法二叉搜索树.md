## 最佳解法思路
- 思路：中序遍历严格递增  
BST 中序遍历是递增序列，遍历时记录前一个值 `prev`，若出现 `cur <= prev` 则不是 BST。

## Java 最佳实现

```java
class Solution {
    private Long prev = null;

    public boolean isValidBST(TreeNode root) {
        prev = null;
        return inorder(root);
    }

    private boolean inorder(TreeNode node) {
        if (node == null) {
            return true;
        }
        if (!inorder(node.left)) {
            return false;
        }
        if (prev != null && node.val <= prev) {
            return false;
        }
        prev = (long) node.val;
        return inorder(node.right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
