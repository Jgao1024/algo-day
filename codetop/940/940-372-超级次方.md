## 最佳解法思路
- 思路（推荐）：快速幂 + 分解指数数组  
要求 \(a^b \bmod 1337\)，指数 `b` 以数组形式给出。利用：  
\((a^{10x+y}) \bmod m = ( (a^x \bmod m)^{10} \bmod m ) \cdot (a^y \bmod m) \bmod m\)。  
递归/迭代处理 `b` 的每一位，并用快速幂计算 `pow(a, k)`。

## Java 最佳实现

```java
class Solution {
    private static final int MOD = 1337;

    public int superPow(int a, int[] b) {
        int res = 1;
        int base = a % MOD;
        for (int digit : b) {
            res = pow(res, 10);
            res = (res * pow(base, digit)) % MOD;
        }
        return res;
    }

    private int pow(int x, int k) {
        int res = 1;
        int base = x % MOD;
        int exp = k;
        while (exp > 0) {
            if ((exp & 1) == 1) {
                res = (res * base) % MOD;
            }
            base = (base * base) % MOD;
            exp >>= 1;
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：\(O(|b| \cdot \log 10)\)（常数级）
- 空间：\(O(1)\)
