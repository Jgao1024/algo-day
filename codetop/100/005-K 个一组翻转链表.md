# 25. K个一组翻转链表

## 题目描述
给你一个链表，每 k 个节点一组进行翻转，请你返回翻转后的链表。k 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 k 的整数倍，那么请将最后剩余的节点保持原有顺序。

示例 1:
```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

示例 2:
```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

## 解题思路
1. 迭代法：
   - 使用虚拟头节点简化操作
   - 每次处理k个节点
   - 检查是否有足够的节点可以翻转
   - 翻转k个节点
   - 更新指针

2. 递归法：
   - 递归处理每k个节点
   - 检查是否有足够的节点可以翻转
   - 翻转当前k个节点
   - 递归处理剩余节点
   - 返回新的头节点

## Java实现
```java
// 迭代法
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) {
            return head;
        }
        
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        
        while (head != null) {
            // 检查是否有足够的节点可以翻转
            ListNode tail = head;
            for (int i = 0; i < k - 1; i++) {
                tail = tail.next;
                if (tail == null) {
                    return dummy.next;
                }
            }
            
            // 翻转k个节点
            ListNode next = tail.next;
            ListNode[] reversed = reverse(head, tail);
            head = reversed[0];
            tail = reversed[1];
            
            // 连接翻转后的链表
            prev.next = head;
            tail.next = next;
            
            // 更新指针
            prev = tail;
            head = next;
        }
        
        return dummy.next;
    }
    
    private ListNode[] reverse(ListNode head, ListNode tail) {
        ListNode prev = null;
        ListNode curr = head;
        
        while (prev != tail) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        
        return new ListNode[]{tail, head};
    }
}

// 递归法

        }

            if (curr == null) {
                return head;
            }
        }
        
        // 翻转当前k个节点
        ListNode next = curr.next;
        ListNode[] reversed = reverse(head, curr);
        head = reversed[0];
        curr = reversed[1];

        curr.next = reverseKGroup(next, k);

            curr = next;
        }

    }
}

class Solution:
    def reverseKGroup(self, head: ListNode, k: int) -> ListNode:
        if not head or k == 1:
            return head
            
        dummy = ListNode(0)
        dummy.next = head
        prev = dummy
        
        while head:
            # 检查是否有足够的节点可以翻转
            tail = head
            for i in range(k - 1):
                tail = tail.next
                if not tail:
                    return dummy.next
            
            # 翻转k个节点
            next = tail.next
            head, tail = self.reverse(head, tail)

            prev.next = head
            tail.next = next
            
            # 更新指针
            prev = tail
            head = next

        curr = head

            next = curr.next
            curr.next = prev
            prev = curr
            curr = next
            
        return tail, head

        if not head or k == 1:
            return head
            
        # 检查是否有足够的节点可以翻转
        curr = head
        for i in range(k - 1):
            curr = curr.next
            if not curr:
                return head
        
        # 翻转当前k个节点
        next = curr.next
        head, curr = self.reverse(head, curr)
        
        # 递归处理剩余节点
        curr.next = self.reverseKGroup(next, k)
        
        return head
    
    def reverse(self, head: ListNode, tail: ListNode) -> Tuple[ListNode, ListNode]:

        curr = head

            prev = curr
            curr = next

```

## 复杂度分析
- 时间复杂度：O(n)，其中n是链表长度
- 空间复杂度：
  - 迭代法：O(1)
  - 递归法：O(n/k)，递归调用栈的深度
