# 113. 路径总和 II

- 题号：113
- 难度：中等
- LeetCode：[路径总和 II](https://leetcode.cn/problems/path-sum-ii/)

## 题目描述
给定二叉树 `root` 和目标和 `targetSum`，返回所有从根到叶子路径上节点值之和等于 `targetSum` 的路径。

## 示例
- 示例  
输入：`root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22`  
输出：`[[5,4,11,2],[5,8,4,5]]`

## 最佳解法思路
- 思路1（推荐）：DFS + 回溯  
一路把节点加入 path，并把 `targetSum` 递减；到叶子且剩余为 0 时收集一份 path 的拷贝；返回时弹出回溯。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(root, targetSum, new ArrayList<>(), res);
        return res;
    }

    private void dfs(TreeNode node, int remain, List<Integer> path, List<List<Integer>> res) {
        if (node == null) return;
        path.add(node.val);
        remain -= node.val;

        if (node.left == null && node.right == null) {
            if (remain == 0) res.add(new ArrayList<>(path));
        } else {
            dfs(node.left, remain, path, res);
            dfs(node.right, remain, path, res);
        }

        path.remove(path.size() - 1);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)（每个节点进出一次；拷贝路径的开销与答案规模相关）
- 空间：\(O(h)\)（递归栈 + path）
