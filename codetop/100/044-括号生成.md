# 22. 括号生成

## 题目描述
数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

示例 1:
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

示例 2:
```
输入：n = 1
输出：["()"]
```

## 解题思路
1. 回溯法：
   - 使用递归生成所有可能的括号组合
   - 使用left和right记录左右括号的数量
   - 当left < n时可以添加左括号
   - 当right < left时可以添加右括号
   - 时间复杂度：O(4^n/√n)，空间复杂度：O(n)

2. 动态规划法：
   - dp[i]表示i对括号的所有有效组合
   - dp[i] = "(" + dp[j] + ")" + dp[i-j-1]，其中j从0到i-1
   - 时间复杂度：O(4^n/√n)，空间复杂度：O(4^n/√n)

## Java实现
```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(result, "", 0, 0, n);
        return result;
    }
    
    private void backtrack(List<String> result, String current, int left, int right, int n) {
        // 当前字符串长度等于2n时，添加到结果集
        if (current.length() == 2 * n) {
            result.add(current);
            return;
        }
        
        // 可以添加左括号
        if (left < n) {
            backtrack(result, current + "(", left + 1, right, n);
        }
        
        // 可以添加右括号
        if (right < left) {
            backtrack(result, current + ")", left, right + 1, n);
        }
    }
}
```

## Python实现
```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result = []
        
        def backtrack(current: str, left: int, right: int):
            # 当前字符串长度等于2n时，添加到结果集
            if len(current) == 2 * n:
                result.append(current)
                return
                
            # 可以添加左括号
            if left < n:
                backtrack(current + "(", left + 1, right)
                
            # 可以添加右括号
            if right < left:
                backtrack(current + ")", left, right + 1)
                
        backtrack("", 0, 0)
        return result
```

## 复杂度分析
- 时间复杂度：O(4^n/√n)，这是第n个卡特兰数
- 空间复杂度：O(n)，递归调用栈的深度
