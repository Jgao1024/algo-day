# 41. 缺失的第一个正数

## 题目描述
给你一个未排序的整数数组 nums ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

示例 1:
```
输入：nums = [1,2,0]
输出：3
```

示例 2:
```
输入：nums = [3,4,-1,1]
输出：2
```

## 解题思路
1. 原地哈希法：
   - 将数组视为哈希表，将数字放到对应的位置上
   - 遍历数组，将数字x放到索引x-1的位置上
   - 再次遍历数组，找到第一个不在正确位置上的数字
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 标记法：
   - 使用数组中的正负号作为标记
   - 将数字x对应的位置标记为负数
   - 找到第一个正数位置
   - 时间复杂度：O(n)，空间复杂度：O(1)

## Java实现
```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        
        // 将数字放到对应的位置上
        for (int i = 0; i < n; i++) {
            while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums, i, nums[i] - 1);
            }
        }
        
        // 找到第一个不在正确位置上的数字
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }
        
        return n + 1;
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

## Python实现
```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 将数字放到对应的位置上
        for i in range(n):
            while 0 < nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
                
        # 找到第一个不在正确位置上的数字
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
                
        return n + 1
```

## 复杂度分析
- 时间复杂度：O(n)，每个数字最多被交换一次
- 空间复杂度：O(1)，只使用了常数额外空间
