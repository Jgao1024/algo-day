# 121.买卖股票的最佳时机

## 题目描述
给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

## 解题思路
这是一个典型的动态规划问题，我们可以使用贪心的思想来解决。具体思路如下：

1. 遍历数组，记录当前遇到的最小价格
2. 对于每一天的价格，计算如果在这一天卖出能获得的利润（当前价格 - 最小价格）
3. 更新最大利润

## 代码实现

### Java实现
```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) {
            return 0;
        }
        
        int minPrice = prices[0];  // 记录最小价格
        int maxProfit = 0;         // 记录最大利润
        
        for (int i = 1; i < prices.length; i++) {
            // 更新最大利润
            maxProfit = Math.max(maxProfit, prices[i] - minPrice);
            // 更新最小价格
            minPrice = Math.min(minPrice, prices[i]);
        }
        
        return maxProfit;
    }
}
```

### Python实现
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
            
        min_price = prices[0]  # 记录最小价格
        max_profit = 0         # 记录最大利润
        
        for price in prices[1:]:
            # 更新最大利润
            max_profit = max(max_profit, price - min_price)
            # 更新最小价格
            min_price = min(min_price, price)
            
        return max_profit
```

## 复杂度分析
- 时间复杂度：O(n)，其中 n 是数组的长度。我们只需要遍历一次数组。
- 空间复杂度：O(1)，只使用了常数额外空间。

## 总结
这道题目是股票买卖系列中最基础的一道题，它有以下特点：
1. 只能买卖一次
2. 必须先买入后卖出
3. 不能在同一天买入和卖出

解题的关键在于：
1. 维护一个最小价格变量，记录遍历到当前位置时的最小价格
2. 对于每个位置，计算当前价格与最小价格的差值，更新最大利润

这个思路可以扩展到其他股票买卖问题，比如：
- 可以多次买卖
- 有交易费用
- 有冷却期
- 最多交易k次

掌握这个基础解法对于解决更复杂的股票买卖问题很有帮助。
