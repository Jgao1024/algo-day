# 227. 基本计算器 II

- 题号：227
- 难度：中等
- LeetCode：[基本计算器 II](https://leetcode.cn/problems/basic-calculator-ii/)

## 题目描述
给定字符串表达式 `s`（包含非负整数、`+ - * /` 和空格），按运算符优先级计算结果（整数除法向 0 取整）。

## 示例
- 示例  
输入：`s = "3+2*2"`  
输出：`7`

## 最佳解法思路
- 思路1（推荐）：栈  
从左到右读数字，遇到运算符（或结尾）就把上一个运算符 `sign` 应用到当前数字：  
`+` 入栈 `num`；`-` 入栈 `-num`；`* /` 与栈顶合并后再入栈。最后把栈求和。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        char sign = '+';

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
            }
            if ((c < '0' || c > '9') && c != ' ' || i == s.length() - 1) {
                if (sign == '+') stack.push(num);
                else if (sign == '-') stack.push(-num);
                else if (sign == '*') stack.push(stack.pop() * num);
                else if (sign == '/') stack.push(stack.pop() / num);
                sign = c;
                num = 0;
            }
        }

        int ans = 0;
        while (!stack.isEmpty()) ans += stack.pop();
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
