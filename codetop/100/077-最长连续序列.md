# 128. 最长连续序列

## 题目描述
给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1:
```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

示例 2:
```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

## 解题思路
1. 哈希表法：
   - 将所有数字存入哈希表
   - 对于每个数字，如果它是序列的起点（即num-1不在哈希表中），则开始向后查找连续序列
   - 记录最长序列的长度
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. 并查集法：
   - 使用并查集来维护连续序列
   - 对于每个数字，将其与相邻的数字合并
   - 记录每个集合的大小
   - 时间复杂度：O(n)，空间复杂度：O(n)

## Java实现
```java
class Solution {
    // 哈希表法
    public int longestConsecutive(int[] nums) {
        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) {
            numSet.add(num);
        }
        
        int longestStreak = 0;
        
        for (int num : numSet) {
            if (!numSet.contains(num - 1)) {
                int currentNum = num;
                int currentStreak = 1;
                
                while (numSet.contains(currentNum + 1)) {
                    currentNum += 1;
                    currentStreak += 1;
                }
                
                longestStreak = Math.max(longestStreak, currentStreak);
            }
        }
        
        return longestStreak;
    }
    
    // 并查集法
    private Map<Integer, Integer> parent = new HashMap<>();
    private Map<Integer, Integer> size = new HashMap<>();
    
    public int longestConsecutiveUnionFind(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        // 初始化并查集
        for (int num : nums) {
            parent.put(num, num);
            size.put(num, 1);
        }
        
        // 合并相邻的数字
        for (int num : nums) {
            if (parent.containsKey(num - 1)) {
                union(num, num - 1);
            }
            if (parent.containsKey(num + 1)) {
                union(num, num + 1);
            }
        }
        
        // 找出最大的集合
        int maxSize = 0;
        for (int s : size.values()) {
            maxSize = Math.max(maxSize, s);
        }
        
        return maxSize;
    }
    
    private int find(int x) {
        if (parent.get(x) != x) {
            parent.put(x, find(parent.get(x)));
        }
        return parent.get(x);
    }
    
    private void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX != rootY) {
            if (size.get(rootX) < size.get(rootY)) {
                parent.put(rootX, rootY);
                size.put(rootY, size.get(rootY) + size.get(rootX));
            } else {
                parent.put(rootY, rootX);
                size.put(rootX, size.get(rootX) + size.get(rootY));
            }
        }
    }
}
```

## Python实现
```python
class Solution:
    # 哈希表法
    def longestConsecutive(self, nums: List[int]) -> int:
        numSet = set(nums)
        longestStreak = 0
        
        for num in numSet:
            if num - 1 not in numSet:
                currentNum = num
                currentStreak = 1
                
                while currentNum + 1 in numSet:
                    currentNum += 1
                    currentStreak += 1
                
                longestStreak = max(longestStreak, currentStreak)
        
        return longestStreak
    
    # 并查集法
    def longestConsecutiveUnionFind(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        parent = {}
        size = {}
        
        # 初始化并查集
        for num in nums:
            parent[num] = num
            size[num] = 1
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> None:
            rootX = find(x)
            rootY = find(y)
            
            if rootX != rootY:
                if size[rootX] < size[rootY]:
                    parent[rootX] = rootY
                    size[rootY] += size[rootX]
                else:
                    parent[rootY] = rootX
                    size[rootX] += size[rootY]
        
        # 合并相邻的数字
        for num in nums:
            if num - 1 in parent:
                union(num, num - 1)
            if num + 1 in parent:
                union(num, num + 1)
        
        # 找出最大的集合
        return max(size.values())
```

- 时间复杂度：O(n)，其中n是数组长度
- 空间复杂度：O(n)
