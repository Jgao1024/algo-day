# 64. 最小路径和

## 题目描述
给定一个包含非负数的网格，找到一条从左上角到右下角的最短路径，使得路径上的数字总和最小。

注意：每次只能向下或者向右移动一步。

示例：
```
输入:
[
  [1,3,1],
  [1,5,1],
  [4,2,1]
]
输出: 7
解释: 因为路径 1→3→1→1→1 的总和最小。
```

## 解题思路
1. 动态规划法：
   - 定义dp[i][j]表示从左上角到位置(i,j)的最小路径和
   - 状态转移方程：dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
   - 边界条件：第一行和第一列需要特殊处理
   - 时间复杂度：O(mn)，空间复杂度：O(mn)

2. 空间优化法：
   - 由于每次只需要用到上一行和当前行的数据，可以只使用一维数组
   - 状态转移方程：dp[j] = min(dp[j], dp[j-1]) + grid[i][j]
   - 时间复杂度：O(mn)，空间复杂度：O(n)

## Java实现
```java
// 动态规划法
class Solution {
    public int minPathSum(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        
        int m = grid.length;
        int n = grid[0].length;
        int[][] dp = new int[m][n];
        
        // 初始化第一个位置
        dp[0][0] = grid[0][0];
        
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j-1] + grid[0][j];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i-1][0] + grid[i][0];
        }
        
        // 填充其他位置
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = Math.min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
            }
        }
        
        return dp[m-1][n-1];
    }
}

        }

    }
}
```

```python
    def minPathSum(self, grid: List[List[int]]) -> int:
        if not grid or not grid[0]:
            return 0
            
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        
        # 初始化第一个位置
        dp[0][0] = grid[0][0]
        
        # 初始化第一行
        for j in range(1, n):
            dp[0][j] = dp[0][j-1] + grid[0][j]
            
        # 初始化第一列
        for i in range(1, m):
            dp[i][0] = dp[i-1][0] + grid[i][0]

            for j in range(1, n):
                dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

## 复杂度分析
- 动态规划法：
  - 时间复杂度：O(mn)，需要遍历整个网格
  - 空间复杂度：O(mn)，需要存储整个dp数组

- 空间优化法：
  - 时间复杂度：O(mn)，需要遍历整个网格
  - 空间复杂度：O(n)，只需要存储一行数据
