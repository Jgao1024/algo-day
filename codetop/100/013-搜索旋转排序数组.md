# 33. 搜索旋转排序数组

## 题目描述
整数数组 nums 按升序排列，数组中的值互不相同。在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]。给你旋转后的数组 nums 和一个整数 target，如果 nums 中存在这个目标值 target，则返回它的下标，否则返回 -1。

示例 1:
```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

示例 2:
```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

示例 3:
```
输入：nums = [1], target = 0
输出：-1
```

## 解题思路
1. 二分查找法：
   - 将数组分为两部分，一部分是有序的，另一部分是旋转的
   - 如果target在有序部分，则在该部分继续二分查找
   - 如果target在旋转部分，则在该部分继续二分查找
   - 时间复杂度：O(log n)

2. 先找旋转点再二分：
   - 先找到旋转点（最小值的位置）
   - 根据target和旋转点的位置关系，确定在哪个部分进行二分查找
   - 时间复杂度：O(log n)

## Java实现
```java
// 二分查找法
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return -1;
        }
        
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            }
            
            // 判断左半部分是否有序
            if (nums[left] <= nums[mid]) {
                // 判断target是否在左半部分
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 判断target是否在右半部分
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        
        return -1;
    }
}

// 先找旋转点再二分
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return -1;
        }
        
        // 找到旋转点（最小值的位置）
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[right]) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        int pivot = left;
        left = 0;
        right = nums.length - 1;
        
        // 根据target和旋转点的位置关系，确定在哪个部分进行二分查找
        if (target >= nums[pivot] && target <= nums[right]) {
            left = pivot;
        } else {
            right = pivot - 1;
        }
        
        // 二分查找
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return -1;
    }
}
```

## 复杂度分析
- 二分查找法：
  - 时间复杂度：O(log n)，其中n是数组长度
  - 空间复杂度：O(1)

- 先找旋转点再二分：
  - 时间复杂度：O(log n)，其中n是数组长度
