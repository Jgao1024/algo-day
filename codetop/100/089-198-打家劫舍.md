# 198. 打家劫舍

- 题号：198
- 难度：中等
- LeetCode：[打家劫舍](https://leetcode.cn/problems/house-robber/)

## 题目描述
一排房子 `nums[i]` 表示第 `i` 家的钱，相邻房子不能同时偷，返回可偷到的最大金额。

## 示例
- 示例  
输入：`nums = [2,7,9,3,1]`  
输出：`12`

## 最佳解法思路
- 思路1（推荐）：DP（滚动变量）  
`dp[i]` 表示前 `i` 家的最大金额：  
`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。  
用两个变量滚动即可。

## Java 最佳实现

```java
class Solution {
    public int rob(int[] nums) {
        int prev2 = 0;
        int prev1 = 0;
        for (int x : nums) {
            int cur = Math.max(prev1, prev2 + x);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
