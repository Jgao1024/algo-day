# 226. 翻转二叉树

- 题号：226
- 难度：简单
- LeetCode：[翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

## 题目描述
给定二叉树 `root`，把整棵树左右子树全部交换，返回新根节点。

## 示例
- 示例  
输入：`root = [4,2,7,1,3,6,9]`  
输出：`[4,7,2,9,6,3,1]`

## 最佳解法思路
- 思路1（推荐）：递归  
对每个节点交换 `left/right`，再递归处理左右子树。

## Java 最佳实现

```java
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        TreeNode left = invertTree(root.left);
        TreeNode right = invertTree(root.right);
        root.left = right;
        root.right = left;
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)

## 总结（速记）
- 每个节点做一次 swap，然后递归即可。
