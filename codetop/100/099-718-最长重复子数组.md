# 718. 最长重复子数组

- 题号：718
- 难度：中等
- LeetCode：[最长重复子数组](https://leetcode.cn/problems/maximum-length-of-repeated-subarray/)

## 题目描述
给定两个整数数组 `nums1`、`nums2`，返回它们的最长公共子数组（连续）长度。

## 示例
- 示例  
输入：`nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：DP（公共后缀长度）  
`dp[i][j]` 表示 `nums1` 以 `i-1` 结尾、`nums2` 以 `j-1` 结尾的最长公共后缀长度：  
若相等：`dp[i][j] = dp[i-1][j-1] + 1`；否则为 0。  
用一维滚动数组，`j` 从后往前遍历。

## Java 最佳实现

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[] dp = new int[n + 1];
        int ans = 0;
        for (int i = 1; i <= m; i++) {
            for (int j = n; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                    ans = Math.max(ans, dp[j]);
                } else {
                    dp[j] = 0;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
