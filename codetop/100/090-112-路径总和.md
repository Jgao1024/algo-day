# 112. 路径总和

- 题号：112
- 难度：简单
- LeetCode：[路径总和](https://leetcode.cn/problems/path-sum/)

## 题目描述
给定二叉树 `root` 和目标和 `targetSum`，判断是否存在一条从根到叶子路径，使节点值之和等于 `targetSum`。

## 示例
- 示例  
输入：`root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：DFS  
递归向下把 `targetSum` 减去当前节点值；到叶子时判断剩余是否为 0。

## Java 最佳实现

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;
        targetSum -= root.val;
        if (root.left == null && root.right == null) return targetSum == 0;
        return hasPathSum(root.left, targetSum) || hasPathSum(root.right, targetSum);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)

- 根到叶：一路减到叶子判断是否为 0。
