# 4. 寻找两个正序数组的中位数

## 题目描述
给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的中位数。

示例 1:
```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

示例 2:
```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

## 解题思路
1. 二分查找法：
   - 将问题转化为寻找两个有序数组的第k小的数
   - 每次比较两个数组的第k/2个元素，较小的那个数组的前k/2个元素一定不是第k小的数
   - 递归处理剩余部分，直到k=1或某个数组为空
   - 时间复杂度：O(log(m+n))，空间复杂度：O(1)

2. 归并排序法：
   - 合并两个有序数组
   - 根据合并后数组的长度找到中位数
   - 时间复杂度：O(m+n)，空间复杂度：O(m+n)

## Java实现
```java
// 二分查找法
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length;
        int n = nums2.length;
        int left = (m + n + 1) / 2;
        int right = (m + n + 2) / 2;
        
        return (findKth(nums1, 0, nums2, 0, left) + 
                findKth(nums1, 0, nums2, 0, right)) / 2.0;
    }
    
    private int findKth(int[] nums1, int i, int[] nums2, int j, int k) {
        if (i >= nums1.length) {
            return nums2[j + k - 1];
        }
        if (j >= nums2.length) {
            return nums1[i + k - 1];
        }
        if (k == 1) {
            return Math.min(nums1[i], nums2[j]);
        }
        
        int midVal1 = (i + k/2 - 1 < nums1.length) ? nums1[i + k/2 - 1] : Integer.MAX_VALUE;
        int midVal2 = (j + k/2 - 1 < nums2.length) ? nums2[j + k/2 - 1] : Integer.MAX_VALUE;
        
        if (midVal1 < midVal2) {
            return findKth(nums1, i + k/2, nums2, j, k - k/2);
        } else {
            return findKth(nums1, i, nums2, j + k/2, k - k/2);
        }
    }
}

// 归并排序法
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length;
        int n = nums2.length;
        int[] merged = new int[m + n];
        
        int i = 0, j = 0, k = 0;
        while (i < m && j < n) {
            if (nums1[i] <= nums2[j]) {
                merged[k++] = nums1[i++];
            } else {
                merged[k++] = nums2[j++];
            }
        }
        
        while (i < m) {
            merged[k++] = nums1[i++];
        }
        while (j < n) {
            merged[k++] = nums2[j++];
        }
        
        if ((m + n) % 2 == 0) {
            return (merged[(m + n) / 2 - 1] + merged[(m + n) / 2]) / 2.0;
        } else {
            return merged[(m + n) / 2];
        }
    }
}
```

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        m, n = len(nums1), len(nums2)
        merged = []
        
        i = j = 0
        while i < m and j < n:
            if nums1[i] <= nums2[j]:
                merged.append(nums1[i])
                i += 1
            else:
                merged.append(nums2[j])
                j += 1
                
        merged.extend(nums1[i:])
        merged.extend(nums2[j:])
        
        if (m + n) % 2 == 0:
            return (merged[(m + n) // 2 - 1] + merged[(m + n) // 2]) / 2
        else:
            return merged[(m + n) // 2]

## 复杂度分析
- 二分查找法：
  - 时间复杂度：O(log(m+n))，每次排除k/2个元素
  - 空间复杂度：O(1)，只使用常数额外空间

- 归并排序法：
  - 时间复杂度：O(m+n)，需要遍历两个数组
  - 空间复杂度：O(m+n)，需要额外的数组空间
