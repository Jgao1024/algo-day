# 560. 和为K的子数组

- 题号：560
- 难度：中等
- LeetCode：[和为K的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

## 题目描述
给定数组 `nums` 和整数 `k`，返回和为 `k` 的连续子数组个数。

## 示例
- 示例  
输入：`nums = [1,1,1], k = 2`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：前缀和 + 哈希表计数  
设前缀和 `sum[i]`，区间 `[j+1..i]` 和为 `k` 等价于 `sum[i] - sum[j] = k`。  
遍历时用 map 记录“某个前缀和出现次数”，对当前 `sum`，累加 `map[sum - k]`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> cnt = new HashMap<>();
        cnt.put(0, 1);
        int sum = 0;
        int ans = 0;
        for (int x : nums) {
            sum += x;
            ans += cnt.getOrDefault(sum - k, 0);
            cnt.put(sum, cnt.getOrDefault(sum, 0) + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 连续子数组计数：前缀和 `sum`，答案加 `count[sum-k]`。
