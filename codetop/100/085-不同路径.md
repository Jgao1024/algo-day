# 62. 不同路径

## 题目描述
一个机器人位于一个 m x n 网格的左上角（起始点在下图中标记为"Start"）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为"Finish"）。

问总共有多少条不同的路径？

示例 1:
```
输入：m = 3, n = 7
输出：28
```

示例 2:
```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

## 解题思路
1. 动态规划法：
   - dp[i][j]表示到达(i,j)的路径数
   - dp[i][j] = dp[i-1][j] + dp[i][j-1]
   - 时间复杂度：O(mn)，空间复杂度：O(mn)

2. 组合数学法：
   - 从左上角到右下角需要m+n-2步
   - 其中需要向下m-1步，向右n-1步
   - 路径数等于组合数C(m+n-2, m-1)
   - 时间复杂度：O(min(m,n))，空间复杂度：O(1)

## Java实现
```java
// 动态规划法
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        
        // 初始化第一行和第一列
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1;
        }
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }
        
        // 填充dp数组
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
        
        return dp[m-1][n-1];
    }
}

// 组合数学法
class Solution {
    public int uniquePaths(int m, int n) {
        long ans = 1;
        for (int x = n, y = 1; y < m; x++, y++) {
            ans = ans * x / y;
        }
        return (int) ans;
    }
}
```

## Python实现
```python
# 动态规划法
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[1] * n for _ in range(m)]
        
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
                
        return dp[m-1][n-1]

# 组合数学法
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        from math import comb
        return comb(m + n - 2, m - 1)
```

## 复杂度分析
- 动态规划法：
  - 时间复杂度：O(mn)，需要填充整个dp数组
  - 空间复杂度：O(mn)，需要存储dp数组

- 组合数学法：
  - 时间复杂度：O(min(m,n))，计算组合数的时间复杂度
  - 空间复杂度：O(1)，只使用常数额外空间
