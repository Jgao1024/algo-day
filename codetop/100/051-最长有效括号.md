# 32. 最长有效括号

## 题目描述
给定一个只包含 '(' 和 ')' 的字符串，找出最长的有效（格式正确且连续）括号子串的长度。

示例 1:
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

示例 2:
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

示例 3:
```
输入：s = ""
输出：0
```

## 解题思路
1. 动态规划法：
   - dp[i]表示以i结尾的最长有效括号长度
   - 如果s[i]是')'，且s[i-1]是'('，则dp[i] = dp[i-2] + 2
   - 如果s[i]是')'，且s[i-1]是')'，且s[i-dp[i-1]-1]是'('，则dp[i] = dp[i-1] + dp[i-dp[i-1]-2] + 2

2. 栈方法：
   - 使用栈存储括号的下标
   - 遇到'('时，将下标入栈
   - 遇到')'时，弹出栈顶元素，计算当前有效长度
   - 栈为空时，将当前下标入栈作为新的起始位置

3. 双指针法：
   - 从左到右遍历，记录左右括号数量
   - 当左右括号数量相等时，更新最大长度
   - 当右括号数量大于左括号数量时，重置计数器
   - 从右到左再遍历一次，处理左括号数量大于右括号数量的情况

## Java实现
```java
// 动态规划法
class Solution {
    public int longestValidParentheses(String s) {
        if (s == null || s.length() < 2) {
            return 0;
        }
        
        int[] dp = new int[s.length()];
        int maxLen = 0;
        
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == ')') {
                if (s.charAt(i - 1) == '(') {
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (i - dp[i - 1] > 0 && s.charAt(i - dp[i - 1] - 1) == '(') {
                    dp[i] = dp[i - 1] + (i - dp[i - 1] >= 2 ? dp[i - dp[i - 1] - 2] : 0) + 2;
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }
        
        return maxLen;
    }
}

// 栈方法
class Solution {
    public int longestValidParentheses(String s) {
        if (s == null || s.length() < 2) {
            return 0;
        }
        
        Stack<Integer> stack = new Stack<>();
        stack.push(-1);
        int maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        
        return maxLen;
    }
}

// 双指针法
class Solution {
    public int longestValidParentheses(String s) {
        if (s == null || s.length() < 2) {
            return 0;
        }
        
        int left = 0, right = 0, maxLen = 0;
        
        // 从左到右遍历
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * right);
            } else if (right > left) {
                left = right = 0;
            }
        }
        
        left = right = 0;
        
        // 从右到左遍历
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);
            } else if (left > right) {
                left = right = 0;
            }
        }
        
        return maxLen;
    }
}
```

## Python实现
```python
# 动态规划法
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        if not s or len(s) < 2:
            return 0
            
        dp = [0] * len(s)
        max_len = 0
        
        for i in range(1, len(s)):
            if s[i] == ')':
                if s[i - 1] == '(':
                    dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
                elif i - dp[i - 1] > 0 and s[i - dp[i - 1] - 1] == '(':
                    dp[i] = dp[i - 1] + (dp[i - dp[i - 1] - 2] if i - dp[i - 1] >= 2 else 0) + 2
                max_len = max(max_len, dp[i])
                
        return max_len

# 栈方法
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        if not s or len(s) < 2:
            return 0
            
        stack = [-1]
        max_len = 0
        
        for i in range(len(s)):
            if s[i] == '(':
                stack.append(i)
            else:
                stack.pop()
                if not stack:
                    stack.append(i)
                else:
                    max_len = max(max_len, i - stack[-1])
                    
        return max_len

# 双指针法
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        if not s or len(s) < 2:
            return 0
            
        left = right = max_len = 0
        
        # 从左到右遍历
        for char in s:
            if char == '(':
                left += 1
            else:
                right += 1
                
            if left == right:
                max_len = max(max_len, 2 * right)
            elif right > left:
                left = right = 0
                
        left = right = 0
        
        # 从右到左遍历
        for char in reversed(s):
            if char == '(':
                left += 1
            else:
                right += 1
                
            if left == right:
                max_len = max(max_len, 2 * left)
            elif left > right:
                left = right = 0
                
        return max_len
```

## 复杂度分析
- 动态规划法：
  - 时间复杂度：O(n)，其中n是字符串长度
  - 空间复杂度：O(n)

- 栈方法：
  - 时间复杂度：O(n)，其中n是字符串长度
  - 空间复杂度：O(n)

- 双指针法：
  - 时间复杂度：O(n)，其中n是字符串长度
  - 空间复杂度：O(1)
