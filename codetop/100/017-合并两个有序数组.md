# 88. 合并两个有序数组

## 题目描述
给你两个按非递减顺序排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。

请你合并 nums2 到 nums1 中，使合并后的数组同样按非递减顺序排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 nums1 中。为了应对这种情况，nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0 ，应忽略。nums2 的长度为 n 。

示例 1:
```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6] 。
合并结果是 [1,2,2,3,5,6] 。
```

## 解题思路
1. 双指针法（从后向前）：
   - 使用三个指针：p1指向nums1的末尾，p2指向nums2的末尾，p指向合并后的末尾
   - 比较nums1[p1]和nums2[p2]，将较大的数放入nums1[p]
   - 移动相应的指针
   - 如果nums2还有剩余元素，直接复制到nums1

2. 双指针法（从前向后）：
   - 先复制nums1到临时数组
   - 使用双指针合并临时数组和nums2到nums1

## Java实现
```java
// 从后向前
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;
        int p2 = n - 1;
        int p = m + n - 1;
        
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] > nums2[p2]) {
                nums1[p] = nums1[p1];
                p1--;
            } else {
                nums1[p] = nums2[p2];
                p2--;
            }
            p--;
        }
        
        // 如果nums2还有剩余元素
        while (p2 >= 0) {
            nums1[p] = nums2[p2];
            p2--;
            p--;
        }
    }
}

// 从前向后
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int[] temp = new int[m];
        System.arraycopy(nums1, 0, temp, 0, m);
        
        int p1 = 0;
        int p2 = 0;
        int p = 0;
        
        while (p1 < m && p2 < n) {
            if (temp[p1] <= nums2[p2]) {
                nums1[p] = temp[p1];
                p1++;
            } else {
                nums1[p] = nums2[p2];
                p2++;
            }
            p++;
        }
        
        // 处理剩余元素
        while (p1 < m) {
            nums1[p] = temp[p1];
            p1++;
            p++;
        }
        while (p2 < n) {
            nums1[p] = nums2[p2];
            p2++;
            p++;
        }
    }
}
```

```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        temp = nums1[:m]
        
        p1 = p2 = p = 0
        
        while p1 < m and p2 < n:
            if temp[p1] <= nums2[p2]:
                nums1[p] = temp[p1]
                p1 += 1
            else:
                nums1[p] = nums2[p2]
                p2 += 1
            p += 1
            
        # 处理剩余元素
        while p1 < m:
            nums1[p] = temp[p1]
            p1 += 1
            p += 1
        while p2 < n:
            nums1[p] = nums2[p2]
            p2 += 1
            p += 1
```

## 复杂度分析
- 时间复杂度：
  - 从后向前：O(m + n)
  - 从前向后：O(m + n)
- 空间复杂度：
  - 从后向前：O(1)
  - 从前向后：O(m)
