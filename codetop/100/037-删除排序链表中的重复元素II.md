# 82. 删除排序链表中的重复元素 II

## 题目描述
给定一个已排序的链表的头 `head`， 删除原始链表中所有重复数字的节点，只保留原始链表中没有重复出现的数字。返回已排序的链表。

示例 1:
```
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

示例 2:
```
输入：head = [1,1,1,2,3]
输出：[2,3]
```

## 解题思路
1. 一次遍历法：
   - 使用虚拟头节点处理头节点可能被删除的情况
   - 使用双指针pre和cur遍历链表
   - 当发现重复节点时，记录重复值，删除所有具有该值的节点
   - 时间复杂度：O(n)，空间复杂度：O(1)

2. 递归法：
   - 递归处理链表
   - 如果当前节点与下一个节点值相同，则跳过所有相同值的节点
   - 时间复杂度：O(n)，空间复杂度：O(n)（递归调用栈）

## Java实现
```java
// 一次遍历法
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode pre = dummy;
        ListNode cur = head;
        
        while (cur != null && cur.next != null) {
            if (cur.val == cur.next.val) {
                // 记录重复值
                int val = cur.val;
                // 删除所有重复节点
                while (cur != null && cur.val == val) {
                    cur = cur.next;
                }
                pre.next = cur;
            } else {
                pre = cur;
                cur = cur.next;
            }
        }
        
        return dummy.next;
    }
}

// 递归法
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        
        if (head.val == head.next.val) {
            // 跳过所有重复节点
            while (head.next != null && head.val == head.next.val) {
                head = head.next;
            }
            return deleteDuplicates(head.next);
        } else {
            head.next = deleteDuplicates(head.next);
            return head;
        }
    }
}
```

## Python实现
```python
# 一次遍历法
class Solution:
    def deleteDuplicates(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
            
        dummy = ListNode(0)
        dummy.next = head
        pre = dummy
        cur = head
        
        while cur and cur.next:
            if cur.val == cur.next.val:
                # 记录重复值
                val = cur.val
                # 删除所有重复节点
                while cur and cur.val == val:
                    cur = cur.next
                pre.next = cur
            else:
                pre = cur
                cur = cur.next
                
        return dummy.next

# 递归法
class Solution:
    def deleteDuplicates(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
            
        if head.val == head.next.val:
            # 跳过所有重复节点
            while head.next and head.val == head.next.val:
                head = head.next
            return self.deleteDuplicates(head.next)
        else:
            head.next = self.deleteDuplicates(head.next)
            return head
```

## 复杂度分析
- 一次遍历法：
  - 时间复杂度：O(n)，其中n是链表的长度
  - 空间复杂度：O(1)，只使用常数额外空间

- 递归法：
  - 时间复杂度：O(n)，其中n是链表的长度
  - 空间复杂度：O(n)，递归调用栈的深度
