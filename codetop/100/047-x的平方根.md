# 69. x 的平方根

## 题目描述
给你一个非负整数 x ，计算并返回 x 的 算术平方根 。

由于返回类型是整数，结果只保留 整数部分 ，小数部分将被 舍去 。

注意：不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5 。

示例 1:
```
输入：x = 4
输出：2
```

示例 2:
```
输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。
```

## 解题思路
1. 二分查找法：
   - 在[0, x]范围内进行二分查找
   - 如果mid * mid <= x < (mid + 1) * (mid + 1)，则mid就是答案
   - 时间复杂度：O(logx)，空间复杂度：O(1)

2. 牛顿迭代法：
   - 使用公式：x = (x + a/x) / 2
   - 不断迭代直到收敛
   - 时间复杂度：O(logx)，空间复杂度：O(1)

## Java实现
```java
class Solution {
    public int mySqrt(int x) {
        if (x == 0) return 0;
        if (x == 1) return 1;
        
        int left = 1, right = x;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            // 使用除法避免溢出
            if (mid <= x / mid && (mid + 1) > x / (mid + 1)) {
                return mid;
            } else if (mid > x / mid) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
}
```

## Python实现
```python
class Solution:
    def mySqrt(self, x: int) -> int:
        if x == 0:
            return 0
        if x == 1:
            return 1
            
        left, right = 1, x
        while left <= right:
            mid = left + (right - left) // 2
            # 使用除法避免溢出
            if mid <= x // mid and (mid + 1) > x // (mid + 1):
                return mid
            elif mid > x // mid:
                right = mid - 1
            else:
                left = mid + 1
                
        return left
```

## 复杂度分析
- 时间复杂度：O(logx)，二分查找的时间复杂度
- 空间复杂度：O(1)，只使用了常数额外空间
