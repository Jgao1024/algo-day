# 补充题6. 手撕堆排序

- 题号：补充题6
- 难度：中等
- LeetCode：[手撕堆排序](https://leetcode.cn/problems/sort-an-array/)

## 题目描述
实现堆排序，对数组进行升序排序（可直接对应 `sort-an-array`）。

## 示例
- 示例  
输入：`nums = [5,2,3,1]`  
输出：`[1,2,3,5]`

## 最佳解法思路
- 思路1（推荐）：大根堆 + 原地排序  
1) 先把数组原地建成大根堆。  
2) 反复把堆顶（最大）与末尾交换，堆大小减 1，再下沉调整。

## Java 最佳实现

```java
class Solution {
    public int[] sortArray(int[] nums) {
        heapSort(nums);
        return nums;
    }

    private void heapSort(int[] a) {
        int n = a.length;
        for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n);
        for (int end = n - 1; end > 0; end--) {
            swap(a, 0, end);
            siftDown(a, 0, end);
        }
    }

    private void siftDown(int[] a, int i, int n) {
        while (true) {
            int left = i * 2 + 1;
            if (left >= n) return;
            int right = left + 1;
            int best = left;
            if (right < n && a[right] > a[left]) best = right;
            if (a[i] >= a[best]) return;
            swap(a, i, best);
            i = best;
        }
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)
