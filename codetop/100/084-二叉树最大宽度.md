# 662. 二叉树最大宽度

## 题目描述
给定一个二叉树，编写一个函数来获取这个树的最大宽度。树的宽度是所有层中的最大宽度。这个二叉树与满二叉树（full binary tree）结构相同，但一些节点为空。

每一层的宽度被定义为两个端点（该层最左和最右的非空节点，两端点间的null节点也计入长度）之间的长度。

示例 1：
```
输入: 
           1
         /   \
        3     2
       / \     \  
      5   3     9 
输出: 4
解释: 最大值出现在树的第 3 层，宽度为 4 (5,3,null,9)。
```

示例 2：
```
输入: 
          1
         /  
        3    
       / \       
      5   3     
输出: 2
解释: 最大值出现在树的第 3 层，宽度为 2 (5,3)。
```

## 解题思路
1. 层序遍历法：
   - 使用队列进行层序遍历
   - 给每个节点编号，左子节点编号为2*parent，右子节点编号为2*parent+1
   - 每层计算最左和最右节点的编号差
   - 时间复杂度：O(n)，空间复杂度：O(n)

2. DFS法：
   - 使用深度优先搜索，记录每层最左节点的位置
   - 遍历时更新每层的宽度
   - 时间复杂度：O(n)，空间复杂度：O(h)

## Java实现
```java
class Solution {
    // 层序遍历法
    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;
        
        Queue<TreeNode> queue = new LinkedList<>();
        Queue<Integer> position = new LinkedList<>();
        queue.offer(root);
        position.offer(1);
        
        int maxWidth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            int left = position.peek();
            int right = left;
            
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                int pos = position.poll();
                right = pos;
                
                if (node.left != null) {
                    queue.offer(node.left);
                    position.offer(2 * pos);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                    position.offer(2 * pos + 1);
                }
            }
            
            maxWidth = Math.max(maxWidth, right - left + 1);
        }
        
        return maxWidth;
    }
    
    // DFS法
    private int maxWidth = 0;
    private Map<Integer, Integer> leftMost = new HashMap<>();
    
    public int widthOfBinaryTreeDFS(TreeNode root) {
        dfs(root, 0, 1);
        return maxWidth;
    }
    
    private void dfs(TreeNode node, int depth, int position) {
        if (node == null) return;
        
        leftMost.putIfAbsent(depth, position);
        maxWidth = Math.max(maxWidth, position - leftMost.get(depth) + 1);
        
        dfs(node.left, depth + 1, 2 * position);
        dfs(node.right, depth + 1, 2 * position + 1);
    }
}
```

## Python实现
```python
class Solution:
    # 层序遍历法
    def widthOfBinaryTree(self, root: TreeNode) -> int:
        if not root:
            return 0
            
        queue = collections.deque([(root, 1)])
        max_width = 0
        
        while queue:
            size = len(queue)
            left = queue[0][1]
            right = left
            
            for _ in range(size):
                node, pos = queue.popleft()
                right = pos
                
                if node.left:
                    queue.append((node.left, 2 * pos))
                if node.right:
                    queue.append((node.right, 2 * pos + 1))
            
            max_width = max(max_width, right - left + 1)
        
        return max_width
    
    # DFS法
    def widthOfBinaryTreeDFS(self, root: TreeNode) -> int:
        self.max_width = 0
        self.left_most = {}
        
        def dfs(node: TreeNode, depth: int, position: int) -> None:
            if not node:
                return
                
            if depth not in self.left_most:
                self.left_most[depth] = position
            self.max_width = max(self.max_width, position - self.left_most[depth] + 1)
            
            dfs(node.left, depth + 1, 2 * position)
            dfs(node.right, depth + 1, 2 * position + 1)
        
        dfs(root, 0, 1)
        return self.max_width
```

## 复杂度分析
- 时间复杂度：O(n)，其中n是二叉树的节点数
- 空间复杂度：
  - 层序遍历法：O(n)，队列中最多存储n个节点
  - DFS法：O(h)，其中h是树的高度
