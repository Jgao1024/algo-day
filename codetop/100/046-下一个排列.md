# 31. 下一个排列

## 题目描述
实现获取下一个排列的函数，算法需要将给定数字序列重新排列成字典序中下一个更大的排列。如果不存在下一个更大的排列，则将数字重新排列成最小的排列（即升序排列）。必须原地修改，只允许使用额外常数空间。

示例 1:
```
输入：nums = [1,2,3]
输出：[1,3,2]
```

示例 2:
```
输入：nums = [3,2,1]
输出：[1,2,3]
```

示例 3:
```
输入：nums = [1,1,5]
输出：[1,5,1]
```

## 解题思路
1. 从后向前查找法：
   - 从后向前查找第一个相邻的升序对(i, i+1)
   - 从后向前查找第一个大于nums[i]的数nums[j]
   - 交换nums[i]和nums[j]
   - 将i+1到末尾的数反转

2. 优化查找法：
   - 从后向前查找第一个相邻的升序对(i, i+1)
   - 从后向前查找第一个大于nums[i]的数nums[j]
   - 交换nums[i]和nums[j]
   - 将i+1到末尾的数反转
   - 优化：使用二分查找找到第一个大于nums[i]的数

## Java实现
```java
// 从后向前查找法
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }
        
        // 从后向前查找第一个相邻的升序对
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        // 如果找到了升序对
        if (i >= 0) {
            // 从后向前查找第一个大于nums[i]的数
            int j = nums.length - 1;
            while (j > i && nums[j] <= nums[i]) {
                j--;
            }
            
            // 交换nums[i]和nums[j]
            swap(nums, i, j);
        }
        
        // 将i+1到末尾的数反转
        reverse(nums, i + 1);
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    private void reverse(int[] nums, int start) {
        int i = start;
        int j = nums.length - 1;
        
        while (i < j) {
            swap(nums, i, j);
            i++;
            j--;
        }
    }
}

// 优化查找法
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }
        
        // 从后向前查找第一个相邻的升序对
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        // 如果找到了升序对
        if (i >= 0) {
            // 使用二分查找找到第一个大于nums[i]的数
            int j = binarySearch(nums, i + 1, nums.length - 1, nums[i]);
            
            // 交换nums[i]和nums[j]
            swap(nums, i, j);
        }
        
        // 将i+1到末尾的数反转
        reverse(nums, i + 1);
    }
    
    private int binarySearch(int[] nums, int left, int right, int target) {
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return right;
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    private void reverse(int[] nums, int start) {
        int i = start;
        int j = nums.length - 1;
        
        while (i < j) {
            swap(nums, i, j);
            i++;
            j--;
        }
    }
}
```

class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        if not nums or len(nums) <= 1:
            return
            
        # 从后向前查找第一个相邻的升序对
        i = len(nums) - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
            
        # 如果找到了升序对
        if i >= 0:
            # 从后向前查找第一个大于nums[i]的数

            while j > i and nums[j] <= nums[i]:

## 复杂度分析
- 从后向前查找法：
  - 时间复杂度：O(n)，其中n是数组长度
  - 空间复杂度：O(1)

- 优化查找法：
  - 时间复杂度：O(n)，其中n是数组长度
  - 空间复杂度：O(1)
