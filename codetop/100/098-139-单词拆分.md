# 139. 单词拆分

- 题号：139
- 难度：中等
- LeetCode：[单词拆分](https://leetcode.cn/problems/word-break/)

## 题目描述
给定字符串 `s` 和单词字典 `wordDict`，判断 `s` 是否能拆分成若干个字典单词的拼接。

## 示例
- 示例  
输入：`s = "leetcode", wordDict = ["leet","code"]`  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：DP  
`dp[i]` 表示 `s[0..i)` 是否可拆分。  
枚举最后一个单词长度 `len`：若 `dp[i-len]` 且 `s[i-len..i)` 在字典中，则 `dp[i]=true`。  
用 `maxLen` 限制枚举长度，减少无效判断。

## Java 最佳实现

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> set = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String w : wordDict) maxLen = Math.max(maxLen, w.length());

        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 1; i <= s.length(); i++) {
            int start = Math.max(0, i - maxLen);
            for (int j = i - 1; j >= start; j--) {
                if (dp[j] && set.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot \text{maxLen})\)（`substring/contains` 视实现有常数开销）
- 空间：\(O(n + |dict|)\)
