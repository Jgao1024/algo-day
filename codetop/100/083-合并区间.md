# 56. 合并区间

## 题目描述
以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

示例 1：
```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

示例 2：
```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

## 解题思路
1. 排序法：
   - 首先按照区间的起始位置进行排序
   - 遍历排序后的区间数组，如果当前区间的起始位置小于等于前一个区间的结束位置，则合并这两个区间
   - 时间复杂度：O(nlogn)，空间复杂度：O(logn)

2. 扫描线法：
   - 将所有区间的起始点和结束点分别标记为1和-1
   - 按照位置排序，使用计数器记录当前重叠的区间数
   - 当计数器从0变为1时，记录起始位置；当计数器从1变为0时，记录结束位置
   - 时间复杂度：O(nlogn)，空间复杂度：O(n)

## Java实现
```java
class Solution {
    // 排序法
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) {
            return new int[0][2];
        }
        
        // 按照区间的起始位置排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        
        List<int[]> merged = new ArrayList<>();
        for (int[] interval : intervals) {
            // 如果列表为空，或者当前区间的起始位置大于前一个区间的结束位置
            if (merged.isEmpty() || merged.get(merged.size() - 1)[1] < interval[0]) {
                merged.add(interval);
            } else {
                // 更新前一个区间的结束位置
                merged.get(merged.size() - 1)[1] = Math.max(merged.get(merged.size() - 1)[1], interval[1]);
            }
        }
        
        return merged.toArray(new int[merged.size()][]);
    }
    
    // 扫描线法
    public int[][] mergeScanLine(int[][] intervals) {
        List<int[]> points = new ArrayList<>();
        for (int[] interval : intervals) {
            points.add(new int[]{interval[0], 1});
            points.add(new int[]{interval[1], -1});
        }
        
        // 按照位置排序，如果位置相同，结束点在前
        Collections.sort(points, (a, b) -> {
            if (a[0] != b[0]) {
                return a[0] - b[0];
            }
            return a[1] - b[1];
        });
        
        List<int[]> merged = new ArrayList<>();
        int count = 0;
        int start = 0;
        
        for (int[] point : points) {
            if (count == 0) {
                start = point[0];
            }
            count += point[1];
            if (count == 0) {
                merged.add(new int[]{start, point[0]});
            }
        }
        
        return merged.toArray(new int[merged.size()][]);
    }
}
```

## Python实现
```python
class Solution:
    # 排序法
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if not intervals:
            return []
        
        # 按照区间的起始位置排序
        intervals.sort(key=lambda x: x[0])
        
        merged = []
        for interval in intervals:
            # 如果列表为空，或者当前区间的起始位置大于前一个区间的结束位置
            if not merged or merged[-1][1] < interval[0]:
                merged.append(interval)
            else:
                # 更新前一个区间的结束位置
                merged[-1][1] = max(merged[-1][1], interval[1])
        
        return merged
    
    # 扫描线法
    def mergeScanLine(self, intervals: List[List[int]]) -> List[List[int]]:
        points = []
        for interval in intervals:
            points.append((interval[0], 1))
            points.append((interval[1], -1))
        
        # 按照位置排序，如果位置相同，结束点在前
        points.sort(key=lambda x: (x[0], x[1]))
        
        merged = []
        count = 0
        start = 0
        
        for point in points:
            if count == 0:
                start = point[0]
            count += point[1]
            if count == 0:
                merged.append([start, point[0]])
        
        return merged
```

## 复杂度分析
- 时间复杂度：O(nlogn)，其中n是区间的数量
- 空间复杂度：
  - 排序法：O(logn)，排序所需的栈空间
  - 扫描线法：O(n)，存储所有点
