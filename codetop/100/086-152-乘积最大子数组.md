# 152. 乘积最大子数组

- 题号：152
- 难度：中等
- LeetCode：[乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)

## 题目描述
给定整数数组 `nums`，返回连续子数组的最大乘积。

## 示例
- 示例  
输入：`nums = [2,3,-2,4]`  
输出：`6`

## 最佳解法思路
- 思路1（推荐）：DP（同时维护最大/最小）  
因为负数会把最大变最小、最小变最大，所以每步维护：  
`maxHere`：以当前位置结尾的最大乘积  
`minHere`：以当前位置结尾的最小乘积  
用它们更新答案。

## Java 最佳实现

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxHere = nums[0], minHere = nums[0], ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            int a = maxHere * x;
            int b = minHere * x;
            maxHere = Math.max(x, Math.max(a, b));
            minHere = Math.min(x, Math.min(a, b));
            ans = Math.max(ans, maxHere);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
