# 83. 删除排序链表中的重复元素

- 题号：83
- 难度：简单
- LeetCode：[删除排序链表中的重复元素](https://leetcode.cn/problems/remove-duplicates-from-sorted-list/)

## 题目描述
给定已排序链表 `head`，删除重复节点，使每个元素只出现一次。

## 示例
- 示例  
输入：`head = [1,1,2,3,3]`  
输出：`[1,2,3]`

## 最佳解法思路
- 思路1（推荐）：一次遍历  
利用有序性，若 `cur.val == cur.next.val`，跳过 `cur.next`；否则 `cur` 前进。

## Java 最佳实现

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode cur = head;
        while (cur != null && cur.next != null) {
            if (cur.val == cur.next.val) cur.next = cur.next.next;
            else cur = cur.next;
        }
        return head;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
