# 162. 寻找峰值

- 题号：162
- 难度：中等
- LeetCode：[寻找峰值](https://leetcode.cn/problems/find-peak-element/)

## 题目描述
给定数组 `nums`，找到任意一个峰值下标 `i`，满足 `nums[i]` 大于左右相邻元素（边界只需大于存在的邻居）。

## 示例
- 示例  
输入：`nums = [1,2,3,1]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：二分  
比较 `nums[mid]` 和 `nums[mid + 1]`：  
若 `nums[mid] < nums[mid+1]`，峰值在右侧；否则在左侧（含 mid）。

## Java 最佳实现

```java
class Solution {
    public int findPeakElement(int[] nums) {
        int l = 0, r = nums.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] < nums[mid + 1]) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：\(O(\log n)\)
- 空间：\(O(1)\)
