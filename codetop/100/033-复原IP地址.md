# 93. 复原IP地址

## 题目描述
有效 IP 地址正好由四个整数（每个整数位于 0 到 255 之间组成，且不能含有前导 0），整数之间用 '.' 分隔。

例如："0.1.2.201" 和 "192.168.1.1" 是有效 IP 地址，但是 "0.011.255.245"、"192.168.1.312" 和 "192.168@1.1" 是无效 IP 地址。

给定一个只包含数字的字符串 s，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在 s 中插入 '.' 来形成。你不能重新排序或删除 s 中的任何数字。你可以按任何顺序返回答案。

示例 1:
```
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

示例 2:
```
输入：s = "0000"
输出：["0.0.0.0"]
```

## 解题思路
1. 回溯法：
   - 将字符串分成四段，每段都是有效的IP地址段
   - 有效IP地址段的条件：
     - 长度在1到3之间
     - 数值在0到255之间
     - 不能有前导0（除非是0本身）
   - 时间复杂度：O(3^4)，空间复杂度：O(n)

2. 剪枝优化：
   - 提前判断剩余长度是否可能构成有效IP
   - 提前判断当前段是否可能构成有效IP
   - 使用StringBuilder优化字符串拼接

## Java实现
```java
class Solution {
    public List<String> restoreIpAddresses(String s) {
        List<String> result = new ArrayList<>();
        if (s.length() < 4 || s.length() > 12) {
            return result;
        }
        backtrack(s, 0, new ArrayList<>(), result);
        return result;
    }
    
    private void backtrack(String s, int start, List<String> path, List<String> result) {
        // 如果已经找到4段，且已经遍历完字符串
        if (path.size() == 4) {
            if (start == s.length()) {
                result.add(String.join(".", path));
            }
            return;
        }
        
        // 尝试取1-3个字符
        for (int i = 1; i <= 3; i++) {
            if (start + i > s.length()) {
                break;
            }
            
            String segment = s.substring(start, start + i);
            // 检查是否有效
            if (isValid(segment)) {
                path.add(segment);
                backtrack(s, start + i, path, result);
                path.remove(path.size() - 1);
            }
        }
    }
    
    private boolean isValid(String segment) {
        // 长度大于1时不能以0开头
        if (segment.length() > 1 && segment.charAt(0) == '0') {
            return false;
        }
        // 数值必须在0-255之间
        int value = Integer.parseInt(segment);
        return value >= 0 && value <= 255;
    }
}
```

## Python实现
```python
class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        def is_valid(segment):
            # 长度大于1时不能以0开头
            if len(segment) > 1 and segment[0] == '0':
                return False
            # 数值必须在0-255之间
            return 0 <= int(segment) <= 255
            
        def backtrack(start, path):
            # 如果已经找到4段，且已经遍历完字符串
            if len(path) == 4:
                if start == len(s):
                    result.append('.'.join(path))
                return
                
            # 尝试取1-3个字符
            for i in range(1, 4):
                if start + i > len(s):
                    break
                    
                segment = s[start:start + i]
                if is_valid(segment):
                    path.append(segment)
                    backtrack(start + i, path)
                    path.pop()
                    
        result = []
        if 4 <= len(s) <= 12:
            backtrack(0, [])
        return result
```

## 复杂度分析
- 时间复杂度：O(3^4)，其中3是每段IP地址的最大长度，4是IP地址的段数。
- 空间复杂度：O(n)，其中n是字符串的长度，主要是递归调用栈的开销。
