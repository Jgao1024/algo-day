# 543. 二叉树的直径

- 题号：543
- 难度：简单
- LeetCode：[二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)

## 题目描述
给定一棵二叉树 `root`，返回任意两个节点之间路径长度的最大值（按边数计算）。

## 示例
- 示例  
输入：`root = [1,2,3,4,5]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：后序 DFS 求深度  
对每个节点计算左右子树最大深度 `L/R`，用 `L + R` 更新全局直径；递归返回 `max(L, R) + 1`。

## Java 最佳实现

```java
class Solution {
    private int ans = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return ans;
    }

    private int depth(TreeNode node) {
        if (node == null) return 0;
        int left = depth(node.left);
        int right = depth(node.right);
        ans = Math.max(ans, left + right);
        return Math.max(left, right) + 1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）

## 总结（速记）
- 直径看 `L+R`；递归返回的是“向下单边深度”。
