# 662. 二叉树最大宽度

- 题号：662
- 难度：中等
- LeetCode：[二叉树最大宽度](https://leetcode.cn/problems/maximum-width-of-binary-tree/)

## 题目描述
给定二叉树 `root`，按题目“完全二叉树编号”的规则计算每层宽度，返回最大宽度。

## 示例
- 示例  
输入：`root = [1,3,2,5,3,null,9]`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：BFS + 下标编号  
层序遍历，给节点附一个下标 `idx`（根为 0，左 `2*idx`，右 `2*idx+1`）。  
每层宽度为 `lastIdx - firstIdx + 1`。为防溢出，每层把下标整体减去 `firstIdx` 做归一化。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    static class NodeIdx {
        TreeNode node;
        long idx;
        NodeIdx(TreeNode node, long idx) {
            this.node = node;
            this.idx = idx;
        }
    }

    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;
        Deque<NodeIdx> q = new ArrayDeque<>();
        q.addLast(new NodeIdx(root, 0));
        long ans = 0;

        while (!q.isEmpty()) {
            int size = q.size();
            long first = q.peekFirst().idx;
            long last = q.peekLast().idx;
            ans = Math.max(ans, last - first + 1);

            for (int i = 0; i < size; i++) {
                NodeIdx cur = q.pollFirst();
                long idx = cur.idx - first;
                if (cur.node.left != null) q.addLast(new NodeIdx(cur.node.left, idx * 2));
                if (cur.node.right != null) q.addLast(new NodeIdx(cur.node.right, idx * 2 + 1));
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（队列）

- 每层用“编号差”算宽度；下标记得做归一化防溢出。
