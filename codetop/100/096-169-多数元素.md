# 169. 多数元素

- 题号：169
- 难度：简单
- LeetCode：[多数元素](https://leetcode.cn/problems/majority-element/)

## 题目描述
给定数组 `nums`，找出出现次数大于 \(\lfloor n/2 \rfloor\) 的元素（保证存在）。

## 示例
- 示例  
输入：`nums = [2,2,1,1,1,2,2]`  
输出：`2`

## 最佳解法思路
- 思路1（推荐）：Boyer-Moore 投票  
维护 `candidate` 和 `count`：  
`count==0` 时更换候选；相等 `count++`，不等 `count--`。最后候选即多数元素。

## Java 最佳实现

```java
class Solution {
    public int majorityElement(int[] nums) {
        int cand = 0;
        int count = 0;
        for (int x : nums) {
            if (count == 0) {
                cand = x;
                count = 1;
            } else if (x == cand) {
                count++;
            } else {
                count--;
            }
        }
        return cand;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
