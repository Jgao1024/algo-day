# 24. 两两交换链表中的节点

- 题号：24
- 难度：中等
- LeetCode：[两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)

## 题目描述
给定链表 `head`，两两交换相邻节点并返回新链表（只能交换节点，不能改值）。

## 示例
- 示例  
输入：`head = [1,2,3,4]`  
输出：`[2,1,4,3]`

## 最佳解法思路
- 思路1（推荐）：迭代 + 哑节点  
用 `dummy` 统一处理头结点交换；每次把 `a=prev.next` 和 `b=a.next` 交换，然后 `prev` 跳到 `a` 继续。

## Java 最佳实现

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        while (prev.next != null && prev.next.next != null) {
            ListNode a = prev.next;
            ListNode b = a.next;
            a.next = b.next;
            b.next = a;
            prev.next = b;
            prev = a;
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 两两交换：`prev -> a -> b` 变 `prev -> b -> a`，`prev` 往后走到 `a`。
