# 162. 寻找峰值

## 题目描述
峰值元素是指其值严格大于左右相邻值的元素。

给你一个整数数组 nums，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回 任何一个峰值 所在位置即可。

你可以假设 nums[-1] = nums[n] = -∞ 。

你必须实现时间复杂度为 O(log n) 的算法来解决此问题。

示例 1：
```
输入：nums = [1,2,3,1]
输出：2
解释：3 是峰值元素，你的函数应该返回其索引 2。
```

示例 2：
```
输入：nums = [1,2,1,3,5,6,4]
输出：1 或 5 
解释：你的函数可以返回索引 1，其峰值元素为 2；
     或者返回索引 5， 其峰值元素为 6。
```

## 解题思路
1. 二分查找法：
   - 由于nums[-1] = nums[n] = -∞，所以数组一定存在峰值
   - 如果nums[mid] > nums[mid+1]，说明峰值在左半部分
   - 如果nums[mid] < nums[mid+1]，说明峰值在右半部分
   - 时间复杂度：O(log n)，空间复杂度：O(1)

2. 线性扫描法：
   - 遍历数组，找到第一个满足nums[i] > nums[i+1]的位置
   - 时间复杂度：O(n)，空间复杂度：O(1)

## Java实现
```java
class Solution {
    // 二分查找法
    public int findPeakElement(int[] nums) {
        int left = 0;
        int right = nums.length - 1;
        
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[mid + 1]) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        
        return left;
    }
    
    // 线性扫描法
    public int findPeakElementLinear(int[] nums) {
        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] > nums[i + 1]) {
                return i;
            }
        }
        return nums.length - 1;
    }
}
```

## Python实现
```python
class Solution:
    # 二分查找法
    def findPeakElement(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] > nums[mid + 1]:
                right = mid
            else:
                left = mid + 1
        
        return left
    
    # 线性扫描法
    def findPeakElementLinear(self, nums: List[int]) -> int:
        for i in range(len(nums) - 1):
            if nums[i] > nums[i + 1]:
                return i
        return len(nums) - 1
```

## 复杂度分析
- 时间复杂度：
  - 二分查找法：O(log n)
  - 线性扫描法：O(n)
- 空间复杂度：O(1)
