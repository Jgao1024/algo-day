# 62. 不同路径

- 题号：62
- 难度：中等
- LeetCode：[不同路径](https://leetcode.cn/problems/unique-paths/)

## 题目描述
给定 `m x n` 网格，机器人从左上到右下，每次只能向右或向下走一步，返回不同路径数。

## 示例
- 示例  
输入：`m = 3, n = 7`  
输出：`28`

## 最佳解法思路
- 思路1（推荐）：DP  
`dp[j]` 表示当前行到达第 `j` 列的路径数。  
转移：`dp[j] = dp[j] + dp[j - 1]`（上方 + 左方）。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j - 1];
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)

- 网格路径数：`dp[j] += dp[j-1]`（一维滚动）。
