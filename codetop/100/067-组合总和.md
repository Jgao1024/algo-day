# 39. 组合总和

## 题目描述
给定一个无重复元素的数组 candidates 和一个目标数 target ，找出 candidates 中所有可以使数字和为 target 的组合。

candidates 中的数字可以无限制重复被选取。

说明：
- 所有数字（包括 target）都是正整数。
- 解集不能包含重复的组合。

示例 1:
```
输入：candidates = [2,3,6,7], target = 7
输出：[[7],[2,2,3]]
```

示例 2:
```
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

## 解题思路
1. 回溯法：
   - 使用回溯算法，从数组的第一个数开始，尝试选择或不选择当前数
   - 如果选择当前数，则继续从当前位置开始选择（因为可以重复选择）
   - 如果不选择当前数，则从下一个位置开始选择
   - 当和等于target时，将当前组合加入结果集
   - 当和大于target时，剪枝返回
   - 时间复杂度：O(2^n)，空间复杂度：O(n)

2. 动态规划法：
   - 使用动态规划求解，dp[i]表示和为i的所有组合
   - 对于每个数，遍历所有可能的目标值
   - 时间复杂度：O(n*target)，空间复杂度：O(target)

## Java实现
```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> current = new ArrayList<>();
        backtrack(candidates, target, 0, current, result);
        return result;
    }
    
    private void backtrack(int[] candidates, int target, int start, 
                          List<Integer> current, List<List<Integer>> result) {
        if (target == 0) {
            result.add(new ArrayList<>(current));
            return;
        }
        
        if (target < 0) {
            return;
        }
        
        for (int i = start; i < candidates.length; i++) {
            current.add(candidates[i]);
            backtrack(candidates, target - candidates[i], i, current, result);
            current.remove(current.size() - 1);
        }
    }
}
```

## Python实现
```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        result = []
        current = []
        
        def backtrack(start: int, target: int):
            if target == 0:
                result.append(current[:])
                return
            
            if target < 0:
                return
            
            for i in range(start, len(candidates)):
                current.append(candidates[i])
                backtrack(i, target - candidates[i])
                current.pop()
        
        backtrack(0, target)
        return result
```

## 复杂度分析
- 时间复杂度：O(2^n)，其中n是数组长度
- 空间复杂度：O(n)，递归调用栈的深度
