# 300.最长上升子序列

## 题目描述
给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

## 解题思路
这道题可以使用动态规划或贪心+二分查找的方法来解决。我们这里介绍两种解法：

### 解法一：动态规划
1. 定义 dp[i] 表示以 nums[i] 结尾的最长上升子序列的长度
2. 对于每个位置 i，遍历其前面的所有位置 j
3. 如果 nums[i] > nums[j]，则 dp[i] = max(dp[i], dp[j] + 1)
4. 最终答案为 dp 数组中的最大值

### 解法二：贪心+二分查找
1. 维护一个数组 tails，其中 tails[i] 表示长度为 i+1 的上升子序列的最后一个元素的最小值
2. 遍历数组，对于每个元素：
   - 如果它大于 tails 数组的最后一个元素，则将其添加到 tails 数组末尾
   - 否则，在 tails 数组中找到第一个大于等于它的元素，将其替换为当前元素
3. 最终 tails 数组的长度就是最长上升子序列的长度

## 代码实现

### Java实现
```java
// 解法一：动态规划
class Solution {
    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        int[] dp = new int[nums.length];
        Arrays.fill(dp, 1);
        int maxLen = 1;
        
        for (int i = 1; i < nums.length; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }
        
        return maxLen;
    }
}

// 解法二：贪心+二分查找
class Solution {
    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        int[] tails = new int[nums.length];
        int size = 0;
        
        for (int num : nums) {
            int left = 0;
            int right = size;
            
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < num) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }
            
            tails[left] = num;
            if (left == size) {
                size++;
            }
        }
        
        return size;
    }
}
```

### Python实现
```python
# 解法一：动态规划
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
            
        dp = [1] * len(nums)
        max_len = 1
        
        for i in range(1, len(nums)):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)
            max_len = max(max_len, dp[i])
            
        return max_len

# 解法二：贪心+二分查找
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
            
        tails = []
        
        for num in nums:
            left, right = 0, len(tails)
            
            while left < right:
                mid = (left + right) // 2
                if tails[mid] < num:
                    left = mid + 1
                else:
                    right = mid
                    
            if left == len(tails):
                tails.append(num)
            else:
                tails[left] = num
                
        return len(tails)
```

## 复杂度分析
### 解法一：动态规划
- 时间复杂度：O(n²)，其中 n 是数组的长度。我们需要两层循环。
- 空间复杂度：O(n)，需要存储 dp 数组。

### 解法二：贪心+二分查找
- 时间复杂度：O(n log n)，其中 n 是数组的长度。对于每个元素，我们需要 O(log n) 的时间进行二分查找。
- 空间复杂度：O(n)，需要存储 tails 数组。
