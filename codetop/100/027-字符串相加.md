# 415.字符串相加

## 题目描述
给定两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和并同样以字符串形式返回。

你不能使用任何内建的用于处理大数的库（比如 BigInteger），也不能直接将输入的字符串转换为整数形式。

## 解题思路
这道题可以使用模拟竖式加法的方法来解决。主要思路如下：

1. 从两个字符串的末尾开始，逐位相加
2. 使用一个变量 carry 记录进位
3. 将每一位的结果添加到结果字符串中
4. 最后反转结果字符串

## 代码实现

### Java实现
```java
class Solution {
    public String addStrings(String num1, String num2) {
        StringBuilder result = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int carry = 0;
        
        while (i >= 0 || j >= 0 || carry > 0) {
            int digit1 = i >= 0 ? num1.charAt(i) - '0' : 0;
            int digit2 = j >= 0 ? num2.charAt(j) - '0' : 0;
            
            int sum = digit1 + digit2 + carry;
            carry = sum / 10;
            result.append(sum % 10);
            
            i--;
            j--;
        }
        
        return result.reverse().toString();
    }
}
```

### Python实现
```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        result = []
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        
        while i >= 0 or j >= 0 or carry > 0:
            digit1 = int(num1[i]) if i >= 0 else 0
            digit2 = int(num2[j]) if j >= 0 else 0
            
            sum_digits = digit1 + digit2 + carry
            carry = sum_digits // 10
            result.append(str(sum_digits % 10))
            
            i -= 1
            j -= 1
            
        return ''.join(result[::-1])
```

## 复杂度分析
- 时间复杂度：O(max(M, N))，其中 M 和 N 分别是 num1 和 num2 的长度。我们需要遍历两个字符串的每一位。
- 空间复杂度：O(max(M, N))，需要存储结果字符串。

## 总结
这道题是字符串操作中的经典问题，主要考察以下几点：
1. 字符串的遍历
2. 字符与数字的转换
3. 进位的处理

解题的关键在于：
1. 从右向左遍历字符串
2. 正确处理进位
3. 处理不同长度字符串的情况

这个解法可以扩展到其他类似的问题，比如：
- 二进制字符串相加
- 大数相乘
- 其他字符串运算问题

掌握这个解法对于理解字符串操作和数学运算很有帮助。
