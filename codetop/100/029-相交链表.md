# 160.相交链表

## 题目描述
给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

## 解题思路
这道题可以使用双指针的方法来解决。主要思路如下：

1. 使用两个指针 pA 和 pB 分别指向两个链表的头节点
2. 当 pA 到达链表末尾时，将其指向 headB
3. 当 pB 到达链表末尾时，将其指向 headA
4. 如果两个链表相交，pA 和 pB 最终会在相交点相遇
5. 如果两个链表不相交，pA 和 pB 最终都会指向 null

## 代码实现

### Java实现
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) {
            return null;
        }
        
        ListNode pA = headA;
        ListNode pB = headB;
        
        while (pA != pB) {
            pA = pA == null ? headB : pA.next;
            pB = pB == null ? headA : pB.next;
        }
        
        return pA;
    }
}
```

### Python实现
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        if not headA or not headB:
            return None
            
        pA, pB = headA, headB
        
        while pA != pB:
            pA = headB if pA is None else pA.next
            pB = headA if pB is None else pB.next
            
        return pA
```

## 复杂度分析
- 时间复杂度：O(M + N)，其中 M 和 N 分别是链表 A 和链表 B 的长度。最坏情况下，我们需要遍历两个链表各一次。
- 空间复杂度：O(1)，只使用了两个指针的额外空间。

这道题是链表操作中的经典问题，主要考察以下几点：
1. 双指针的使用
2. 链表的遍历
3. 相交节点的判断

解题的关键在于：
1. 理解两个指针的移动规律
2. 正确处理链表末尾的情况
3. 处理不相交的情况

这个解法可以扩展到其他类似的问题，比如：
- 判断链表是否有环
- 找到链表的倒数第k个节点
- 其他链表相交问题

掌握这个解法对于理解链表的操作和指针的使用很有帮助。
