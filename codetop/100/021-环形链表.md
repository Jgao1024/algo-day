# 141.环形链表

## 题目描述
给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：`pos` 不作为参数进行传递。仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 `true`。否则，返回 `false`。

## 解题思路
这道题可以使用快慢指针（Floyd's Cycle-Finding Algorithm）来解决。主要思路如下：

1. 使用两个指针，一个快指针（每次移动两步）和一个慢指针（每次移动一步）
2. 如果链表中存在环，快指针最终会追上慢指针
3. 如果链表中不存在环，快指针会先到达链表末尾

## 代码实现

### Java实现
```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        if (head == null || head.next == null) {
            return false;
        }
        
        ListNode slow = head;
        ListNode fast = head;
        
        while (fast != null && fast.next != null) {
            slow = slow.next;        // 慢指针移动一步
            fast = fast.next.next;   // 快指针移动两步
            
            if (slow == fast) {      // 如果快慢指针相遇，说明有环
                return true;
            }
        }
        
        return false;  // 快指针到达链表末尾，说明没有环
    }
}
```

### Python实现
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        if not head or not head.next:
            return False
            
        slow = head
        fast = head
        
        while fast and fast.next:
            slow = slow.next        # 慢指针移动一步
            fast = fast.next.next   # 快指针移动两步
            
            if slow == fast:        # 如果快慢指针相遇，说明有环
                return True
                
        return False  # 快指针到达链表末尾，说明没有环
```

## 复杂度分析
- 时间复杂度：O(n)，其中 n 是链表的长度。
  - 如果链表中没有环，快指针会先到达链表末尾，时间复杂度为 O(n)
  - 如果链表中有环，快指针会在环内追上慢指针，时间复杂度为 O(n)
- 空间复杂度：O(1)，只使用了两个指针的额外空间。

解题的关键在于：
1. 使用快慢指针来检测环
2. 正确处理快指针的移动（需要检查 fast.next 是否存在）
3. 处理空链表和单节点链表的特殊情况

这个解法可以扩展到其他类似的问题，比如：

- 计算环的长度
- 判断两个链表是否相交
