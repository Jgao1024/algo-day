# 283. 移动零

- 题号：283
- 难度：简单
- LeetCode：[移动零](https://leetcode.cn/problems/move-zeroes/)

## 题目描述
给定数组 `nums`，将所有 0 移到末尾，同时保持非 0 元素相对顺序（原地操作）。

## 示例
- 示例  
输入：`nums = [0,1,0,3,12]`  
输出：`[1,3,12,0,0]`

## 最佳解法思路
- 思路1（推荐）：双指针  
`slow` 指向下一个放置非 0 的位置；遍历数组把非 0 依次前移，最后把剩余位置填 0。

## Java 最佳实现

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int x : nums) {
            if (x != 0) nums[slow++] = x;
        }
        while (slow < nums.length) nums[slow++] = 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 覆盖写非 0，再补 0；不需要频繁 swap。
