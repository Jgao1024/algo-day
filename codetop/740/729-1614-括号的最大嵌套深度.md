# 1614. 括号的最大嵌套深度

- 题号：1614
- 难度：简单
- LeetCode：[括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/)

## 题目描述
给定一个有效括号字符串 `s`（可能包含其它字符），返回括号的最大嵌套深度。

## 示例
- `s = "(1+(2*3)+((8)/4))+1"`，输出 `3`

## 最佳解法思路
- 扫描字符串，遇到 `'('` 深度 +1，遇到 `')'` 深度 -1，记录最大值。

## Java 最佳实现

```java
class Solution {
    public int maxDepth(String s) {
        int cur = 0;
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                cur++;
                ans = Math.max(ans, cur);
            } else if (c == ')') {
                cur--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
