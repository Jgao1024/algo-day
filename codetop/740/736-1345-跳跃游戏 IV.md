# 1345. 跳跃游戏 IV

- 题号：1345
- 难度：困难
- LeetCode：[跳跃游戏 IV](https://leetcode.cn/problems/jump-game-iv/)

## 题目描述
给定整数数组 `arr`，你从下标 0 出发，每步可以跳到：
- `i + 1`
- `i - 1`
- 任意 `j`，满足 `arr[i] == arr[j]` 且 `i != j`

返回到达最后一个下标的最少步数。

## 示例
- `arr = [100,-23,-23,404,100,23,23,23,3,404]`，输出 `3`

## 最佳解法思路
- BFS：把每个下标当作节点。
- 预处理 `值 -> 下标列表`。
- 从 0 分层 BFS：
  - 可走 `i-1`、`i+1`
  - 还可走到所有“同值下标”
- 为避免同值边导致 \(O(n^2)\)，当某个值的列表被用过一次后就清空（或从 map 删除）。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Queue;

class Solution {
    public int minJumps(int[] arr) {
        int n = arr.length;
        if (n <= 1) {
            return 0;
        }

        Map<Integer, List<Integer>> map = new HashMap<>();
        for (int i = 0; i < n; i++) {
            map.computeIfAbsent(arr[i], x -> new ArrayList<>()).add(i);
        }

        boolean[] vis = new boolean[n];
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(0);
        vis[0] = true;

        int steps = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            for (int t = 0; t < size; t++) {
                int i = q.poll();
                if (i == n - 1) {
                    return steps;
                }

                int left = i - 1;
                int right = i + 1;
                if (left >= 0 && !vis[left]) {
                    vis[left] = true;
                    q.offer(left);
                }
                if (right < n && !vis[right]) {
                    vis[right] = true;
                    q.offer(right);
                }

                List<Integer> same = map.get(arr[i]);
                if (same != null) {
                    for (int j : same) {
                        if (!vis[j]) {
                            vis[j] = true;
                            q.offer(j);
                        }
                    }
                    map.remove(arr[i]);
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
