# 1483. 树节点的第 K 个祖先

- 题号：1483
- 难度：困难
- LeetCode：[树节点的第 K 个祖先](https://leetcode.cn/problems/kth-ancestor-of-a-tree-node/)

## 题目描述
给定一棵根为 0 的树，`parent[i]` 表示节点 i 的父节点（根的父节点为 -1）。实现数据结构 `TreeAncestor`：
- `TreeAncestor(int n, int[] parent)`
- `getKthAncestor(int node, int k)` 返回 node 的第 k 个祖先，不存在返回 -1。

## 示例
`parent = [-1,0,0,1,1,2]`  
`getKthAncestor(3,1)=1`，`getKthAncestor(5,2)=0`，`getKthAncestor(5,3)=-1`

## 最佳解法思路
- 二进制提升（倍增）：
  - `up[p][v]` 表示 v 的 \(2^p\) 级祖先
  - 查询时把 k 按二进制拆分，逐位跳跃即可

## Java 最佳实现

```java
class TreeAncestor {
    private final int[][] up;
    private final int LOG;

    public TreeAncestor(int n, int[] parent) {
        int log = 1;
        while ((1 << log) <= n) {
            log++;
        }
        this.LOG = log;
        up = new int[LOG][n];
        for (int v = 0; v < n; v++) {
            up[0][v] = parent[v];
        }
        for (int p = 1; p < LOG; p++) {
            for (int v = 0; v < n; v++) {
                int mid = up[p - 1][v];
                up[p][v] = mid == -1 ? -1 : up[p - 1][mid];
            }
        }
    }

    public int getKthAncestor(int node, int k) {
        int v = node;
        for (int p = 0; p < LOG && v != -1; p++) {
            if (((k >> p) & 1) == 1) {
                v = up[p][v];
            }
        }
        return v;
    }
}
```

## 复杂度分析
- 预处理：时间 \(O(n \log n)\)，空间 \(O(n \log n)\)
- 查询：时间 \(O(\log n)\)，空间 \(O(1)\)
