# 1099. 小于 K 的两数之和

- 题号：1099
- 难度：简单
- LeetCode：[小于 K 的两数之和](https://leetcode.cn/problems/two-sum-less-than-k/)

## 题目描述
给定整数数组 `nums` 和整数 `k`，找出 `nums[i] + nums[j] < k` 的最大和（`i != j`）。若不存在返回 -1。

## 示例
- `nums = [34,23,1,24,75,33,54,8], k = 60`，输出 `58`

## 最佳解法思路
- 排序 + 双指针：
  - 若 `nums[l] + nums[r] < k`，更新答案并 `l++`
  - 否则 `r--`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int twoSumLessThanK(int[] nums, int k) {
        Arrays.sort(nums);
        int l = 0;
        int r = nums.length - 1;
        int ans = -1;
        while (l < r) {
            int s = nums[l] + nums[r];
            if (s < k) {
                ans = Math.max(ans, s);
                l++;
            } else {
                r--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（不计排序栈）
