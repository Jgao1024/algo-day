# 1124. 表现良好的最长时间段

- 题号：1124
- 难度：中等
- LeetCode：[表现良好的最长时间段](https://leetcode.cn/problems/longest-well-performing-interval/)

## 题目描述
给定数组 `hours`，若某天工作时长 > 8 则为“劳累日”。当一个区间内劳累日天数严格大于非劳累日天数时，这个区间“表现良好”。返回最长表现良好区间长度。

## 示例
- `hours = [9,9,6,0,6,6,9]`，输出 `3`

## 最佳解法思路
- 前缀和：`>8` 记 +1，否则记 -1，得到前缀 `pre`。
- 若 `pre > 0`，则 `[0..i]` 就是表现良好。
- 否则若之前出现过 `pre-1` 的最早位置 `j`，则 `(j+1..i)` 的和 >0，更新答案 `i-j`。
- 用 HashMap 记录每个前缀值第一次出现的位置。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int longestWPI(int[] hours) {
        Map<Integer, Integer> first = new HashMap<>();
        int pre = 0;
        int ans = 0;
        for (int i = 0; i < hours.length; i++) {
            pre += (hours[i] > 8) ? 1 : -1;
            if (pre > 0) {
                ans = i + 1;
            } else {
                Integer j = first.get(pre - 1);
                if (j != null) {
                    ans = Math.max(ans, i - j);
                }
            }
            first.putIfAbsent(pre, i);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
