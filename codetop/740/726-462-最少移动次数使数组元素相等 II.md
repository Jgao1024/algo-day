# 462. 最少移动次数使数组元素相等 II

- 题号：462
- 难度：中等
- LeetCode：[最少移动次数使数组元素相等 II](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)

## 题目描述
每次可以把一个元素 +1 或 -1 一次。给定数组 `nums`，求让所有元素相等的最少移动次数。

## 示例
- `nums = [1,2,3]`，输出 `2`

## 最佳解法思路
- 把所有数变成同一个值时，最优是取中位数。
- 排序后取 `nums[n/2]` 作为目标，累加所有元素到目标的绝对差。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minMoves2(int[] nums) {
        Arrays.sort(nums);
        int mid = nums[nums.length / 2];
        long ans = 0;
        for (int x : nums) {
            ans += Math.abs((long) x - mid);
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（不计排序栈）
