# 969. 煎饼排序

- 题号：969
- 难度：中等
- LeetCode：[煎饼排序](https://leetcode.cn/problems/pancake-sorting/)

## 题目描述
给定一个数组 `arr`（1..n 的排列），你每次可以翻转前 k 个元素。返回任意一种把数组排成升序的翻转序列。

## 示例
输入：`[3,2,4,1]`  
输出：`[4,2,4,3]`（一种可行答案）

## 最佳解法思路
- 从后往前把最大值放到正确位置：
  - 找到当前未归位区间 `[0..i]` 的最大值位置 `idx`
  - 先翻转 `idx+1` 把它翻到最前
  - 再翻转 `i+1` 把它翻到位置 i

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> pancakeSort(int[] arr) {
        List<Integer> res = new ArrayList<>();
        for (int i = arr.length - 1; i > 0; i--) {
            int idx = maxIndex(arr, i);
            if (idx == i) {
                continue;
            }
            if (idx != 0) {
                flip(arr, idx + 1);
                res.add(idx + 1);
            }
            flip(arr, i + 1);
            res.add(i + 1);
        }
        return res;
    }

    private int maxIndex(int[] a, int r) {
        int idx = 0;
        for (int i = 1; i <= r; i++) {
            if (a[i] > a[idx]) {
                idx = i;
            }
        }
        return idx;
    }

    private void flip(int[] a, int k) {
        int l = 0;
        int r = k - 1;
        while (l < r) {
            int t = a[l];
            a[l] = a[r];
            a[r] = t;
            l++;
            r--;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)（不计返回序列）
