# 1172. 餐盘栈

- 题号：1172
- 难度：困难
- LeetCode：[餐盘栈](https://leetcode.cn/problems/dinner-plate-stacks/)

## 题目描述
实现 `DinnerPlates`：
- 初始化容量 `capacity`
- `push(val)`：把 val 放入最左侧未满的栈
- `pop()`：从最右侧非空的栈弹出
- `popAtStack(index)`：从指定栈弹出
若弹出失败返回 -1。

## 最佳解法思路
- 维护多个栈：
  - `pushPQ`：最小堆，存“未满栈”的下标（push 用）
  - `popPQ`：最大堆，存“非空栈”的下标（pop 用）
- 堆里会有过期下标，需要懒清理：取堆顶时检查该栈是否仍然满足条件，不满足就弹出继续。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

class DinnerPlates {
    private final int cap;
    private final List<List<Integer>> stacks = new ArrayList<>();
    private final PriorityQueue<Integer> pushPQ = new PriorityQueue<>();
    private final PriorityQueue<Integer> popPQ = new PriorityQueue<>((a, b) -> b - a);

    public DinnerPlates(int capacity) {
        this.cap = capacity;
    }

    public void push(int val) {
        cleanPush();
        int idx;
        if (pushPQ.isEmpty()) {
            idx = stacks.size();
            stacks.add(new ArrayList<>());
        } else {
            idx = pushPQ.peek();
        }

        List<Integer> st = stacks.get(idx);
        st.add(val);
        pushPQ.offer(idx);
        popPQ.offer(idx);
        cleanPush();
        cleanPop();
    }

    public int pop() {
        cleanPop();
        if (popPQ.isEmpty()) {
            return -1;
        }
        int idx = popPQ.peek();
        return popAtStack(idx);
    }

    public int popAtStack(int index) {
        if (index < 0 || index >= stacks.size()) {
            return -1;
        }
        List<Integer> st = stacks.get(index);
        if (st.isEmpty()) {
            return -1;
        }
        int val = st.remove(st.size() - 1);
        pushPQ.offer(index);
        popPQ.offer(index);
        cleanPush();
        cleanPop();
        return val;
    }

    private void cleanPush() {
        while (!pushPQ.isEmpty()) {
            int idx = pushPQ.peek();
            if (idx >= stacks.size()) {
                pushPQ.poll();
                continue;
            }
            if (stacks.get(idx).size() == cap) {
                pushPQ.poll();
            } else {
                break;
            }
        }
    }

    private void cleanPop() {
        while (!popPQ.isEmpty()) {
            int idx = popPQ.peek();
            if (idx >= stacks.size()) {
                popPQ.poll();
                continue;
            }
            if (stacks.get(idx).isEmpty()) {
                popPQ.poll();
            } else {
                break;
            }
        }
        // 去掉末尾空栈，避免 index 不断膨胀
        while (!stacks.isEmpty() && stacks.get(stacks.size() - 1).isEmpty()) {
            stacks.remove(stacks.size() - 1);
        }
        while (!popPQ.isEmpty() && popPQ.peek() >= stacks.size()) {
            popPQ.poll();
        }
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(\log n)\)
- 空间：\(O(n)\)
