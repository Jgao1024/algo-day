# 1268. 搜索推荐系统

- 题号：1268
- 难度：中等
- LeetCode：[搜索推荐系统](https://leetcode.cn/problems/search-suggestions-system/)

## 题目描述
给定商品列表 `products` 和搜索词 `searchWord`。对每个前缀，返回字典序最小的最多 3 个以该前缀开头的商品名。

## 示例
- `products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"`  
输出：`[["mobile","moneypot","monitor"],["mobile","moneypot","monitor"],["mouse","mousepad"],["mouse","mousepad"],["mouse","mousepad"]]`

## 最佳解法思路
- 先把 `products` 字典序排序。
- 对每个前缀 `p`，二分找到第一个 >= `p` 的位置 `idx`，从 `idx` 往后取最多 3 个且 `startsWith(p)` 的字符串。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        Arrays.sort(products);
        List<List<String>> ans = new ArrayList<>();

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < searchWord.length(); i++) {
            sb.append(searchWord.charAt(i));
            String pref = sb.toString();
            int idx = lowerBound(products, pref);

            List<String> list = new ArrayList<>(3);
            for (int j = idx; j < products.length && list.size() < 3; j++) {
                if (products[j].startsWith(pref)) {
                    list.add(products[j]);
                } else {
                    break;
                }
            }
            ans.add(list);
        }

        return ans;
    }

    private int lowerBound(String[] a, String key) {
        int l = 0;
        int r = a.length;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (a[m].compareTo(key) >= 0) {
                r = m;
            } else {
                l = m + 1;
            }
        }
        return l;
    }
}
```

## 复杂度分析
- 时间：排序 \(O(n \log n)\)，每个前缀二分 \(O(\log n)\) + 常数取 3 个
- 空间：\(O(1)\)（不计输出）
