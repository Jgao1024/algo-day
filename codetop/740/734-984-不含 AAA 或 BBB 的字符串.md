# 984. 不含 AAA 或 BBB 的字符串

- 题号：984
- 难度：中等
- LeetCode：[不含 AAA 或 BBB 的字符串](https://leetcode.cn/problems/string-without-aaa-or-bbb/)

## 题目描述
给定两个整数 `a` 和 `b`，构造一个只包含 'a' 和 'b' 的字符串，'a' 的数量为 a，'b' 的数量为 b，并且不包含子串 "aaa" 或 "bbb"。

## 示例
- `a = 1, b = 2`，输出 `"abb"`
- `a = 4, b = 1`，输出 `"aabaa"`

## 最佳解法思路
- 贪心：每次尽量放剩余更多的字符，但如果末尾已经有两个相同字符，就必须放另一个。

## Java 最佳实现

```java
class Solution {
    public String strWithout3a3b(int a, int b) {
        StringBuilder sb = new StringBuilder(a + b);
        while (a > 0 || b > 0) {
            int n = sb.length();
            char last1 = n >= 1 ? sb.charAt(n - 1) : '#';
            char last2 = n >= 2 ? sb.charAt(n - 2) : '#';

            if (last1 == 'a' && last2 == 'a') {
                sb.append('b');
                b--;
            } else if (last1 == 'b' && last2 == 'b') {
                sb.append('a');
                a--;
            } else {
                if (a >= b && a > 0) {
                    sb.append('a');
                    a--;
                } else {
                    sb.append('b');
                    b--;
                }
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(a+b)\)
- 空间：\(O(a+b)\)
