# 1375. 灯泡开关 III

- 题号：1375
- 难度：中等
- LeetCode：[灯泡开关 III](https://leetcode.cn/problems/bulb-switcher-iii/)

## 题目描述
有 n 个灯泡，初始都关。按数组 `light` 的顺序逐个打开灯泡（1..n）。当某一时刻从 1 到当前最大编号的灯泡都亮时，这一时刻“蓝灯”数量 +1。返回蓝灯时刻总数。

## 示例
- `light = [2,1,3,5,4]`，输出 `3`

## 最佳解法思路
- 扫描 `light`，维护当前已打开的最大编号 `max`。
- 当 `max == i+1`（i 为 0-based）时，说明 1..max 全部打开，计数 +1。

## Java 最佳实现

```java
class Solution {
    public int numTimesAllBlue(int[] light) {
        int max = 0;
        int ans = 0;
        for (int i = 0; i < light.length; i++) {
            max = Math.max(max, light[i]);
            if (max == i + 1) {
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
