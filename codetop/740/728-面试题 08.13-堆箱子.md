# 面试题 08.13. 堆箱子

- 题号：面试题 08.13
- 难度：困难
- LeetCode：[堆箱子](https://leetcode.cn/problems/pile-box-lcci/)

## 题目描述
给定若干箱子 `box[i] = [w, d, h]`，你可以把一个箱子放在另一个箱子上面，要求上面的箱子三维都严格小于下面的箱子。求能堆出的最大高度。

## 示例
`box = [[1,1,1],[2,3,4],[2,6,7],[3,4,5]]`

## 最佳解法思路
- 排序后做 DP：
  - 先按 `w`、`d`、`h` 升序排序
  - `dp[i]` 表示以第 i 个箱子作为最上面箱子时的最大高度
  - 转移：对所有 `j<i` 且 `box[j]` 三维都小于 `box[i]`，`dp[i] = max(dp[i], dp[j] + h[i])`

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int pileBox(int[][] box) {
        Arrays.sort(box, (a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0];
            if (a[1] != b[1]) return a[1] - b[1];
            return a[2] - b[2];
        });

        int n = box.length;
        int[] dp = new int[n];
        int ans = 0;
        for (int i = 0; i < n; i++) {
            dp[i] = box[i][2];
            for (int j = 0; j < i; j++) {
                if (box[j][0] < box[i][0] && box[j][1] < box[i][1] && box[j][2] < box[i][2]) {
                    dp[i] = Math.max(dp[i], dp[j] + box[i][2]);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
