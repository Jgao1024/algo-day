# 420. 强密码检验器

- 题号：420
- 难度：困难
- LeetCode：[强密码检验器](https://leetcode.cn/problems/strong-password-checker/)

## 题目描述
给定字符串 `password`，通过插入、删除、替换字符，使其成为强密码：
- 长度在 [6, 20]
- 至少包含：小写、大写、数字
- 不能出现 3 个连续相同字符
返回最少修改次数。

## 示例
- `"a"` -> `5`
- `"aA1"` -> `3`
- `"1337C0d3"` -> `0`

## 最佳解法思路
- 先统计缺失的字符种类数 `missing`（小写/大写/数字）。
- 统计所有连续段长度 `len`，每段需要的替换次数为 `len/3`，总替换 `replace`。
- 分三种长度区间处理：
  - `n < 6`：需要插入补长度，同时也能补类型/打断连续，答案 `max(missing, 6-n)`
  - `6 <= n <= 20`：答案 `max(missing, replace)`
  - `n > 20`：必须先删除 `del = n-20`。删除可以减少替换次数，优先从 `len%3==0`、`==1`、`==2` 的段里删，最大化减少 `replace`，最后答案 `del + max(missing, replaceAfter)`

## Java 最佳实现

```java
class Solution {
    public int strongPasswordChecker(String s) {
        int n = s.length();

        int missing = 0;
        if (!hasLower(s)) missing++;
        if (!hasUpper(s)) missing++;
        if (!hasDigit(s)) missing++;

        int replace = 0;
        int[] mod = new int[3];
        for (int i = 0; i < n; ) {
            int j = i + 1;
            while (j < n && s.charAt(j) == s.charAt(i)) {
                j++;
            }
            int len = j - i;
            if (len >= 3) {
                replace += len / 3;
                mod[len % 3]++;
            }
            i = j;
        }

        if (n < 6) {
            return Math.max(missing, 6 - n);
        }
        if (n <= 20) {
            return Math.max(missing, replace);
        }

        int del = n - 20;
        int left = del;

        // len%3==0：删 1 次就能少 1 次 replace
        int use = Math.min(mod[0], left);
        replace -= use;
        left -= use;

        // len%3==1：删 2 次少 1 次 replace
        use = Math.min(mod[1] * 2, left);
        replace -= use / 2;
        left -= use;

        // len%3==2：删 3 次少 1 次 replace（以及剩下的其它段同样按 3 删）
        if (left > 0) {
            replace -= left / 3;
        }

        return del + Math.max(missing, replace);
    }

    private boolean hasLower(String s) {
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= 'a' && c <= 'z') return true;
        }
        return false;
    }

    private boolean hasUpper(String s) {
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= 'A' && c <= 'Z') return true;
        }
        return false;
    }

    private boolean hasDigit(String s) {
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') return true;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
