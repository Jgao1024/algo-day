# 754. 到达终点数字

- 题号：754
- 难度：中等
- LeetCode：[到达终点数字](https://leetcode.cn/problems/reach-a-number/)

## 题目描述
从 0 出发，第 i 次移动必须走 i 步，可以向左或向右。给定 `target`，求到达 target 的最少移动次数。

## 示例
- `target = 2`，输出 `3`（+1 -2 +3）
- `target = 3`，输出 `2`（+1 +2）

## 最佳解法思路
- 只需要考虑 `target` 的绝对值。
- 令 `sum = 1+2+...+k`，当 `sum >= target` 且 `(sum-target)` 为偶数时，表示可以通过翻转若干步的方向来补差值，答案就是 k。

## Java 最佳实现

```java
class Solution {
    public int reachNumber(int target) {
        long t = Math.abs((long) target);
        long sum = 0;
        int k = 0;
        while (sum < t || ((sum - t) & 1) == 1) {
            k++;
            sum += k;
        }
        return k;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{|target|})\)
- 空间：\(O(1)\)
