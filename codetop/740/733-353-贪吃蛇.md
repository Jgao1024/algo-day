# 353. 贪吃蛇

- 题号：353
- 难度：中等
- LeetCode：[贪吃蛇](https://leetcode.cn/problems/design-snake-game/)

## 题目描述
实现一个贪吃蛇：
- 棋盘大小 `width x height`
- 食物按顺序出现，坐标为 `food[i] = [row, col]`
- `move(direction)` 让蛇移动一步，返回当前得分（吃到食物数），撞墙/咬到自己返回 -1

## 示例
见题面链接。

## 最佳解法思路
- 用队列保存蛇身（头到尾或尾到头都行），用 HashSet 保存占用格子，便于 O(1) 判重。
- 移动时：
  - 先算新头坐标
  - 若不吃食物，先把尾巴出队并从 set 移除（这样允许走到原尾巴位置）
  - 再判断是否撞墙/撞自己
  - 最后把新头加入队列和 set

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class SnakeGame {
    private final int width;
    private final int height;
    private final int[][] food;
    private int foodIdx = 0;

    private final Deque<Integer> body = new ArrayDeque<>();
    private final Set<Integer> occ = new HashSet<>();
    private int headR = 0;
    private int headC = 0;

    public SnakeGame(int width, int height, int[][] food) {
        this.width = width;
        this.height = height;
        this.food = food;
        int code = encode(0, 0);
        body.addLast(code);
        occ.add(code);
    }

    public int move(String direction) {
        int nr = headR;
        int nc = headC;
        char d = direction.charAt(0);
        if (d == 'U') nr--;
        else if (d == 'D') nr++;
        else if (d == 'L') nc--;
        else nc++;

        if (nr < 0 || nr >= height || nc < 0 || nc >= width) {
            return -1;
        }

        boolean eat = foodIdx < food.length && food[foodIdx][0] == nr && food[foodIdx][1] == nc;

        if (!eat) {
            int tail = body.removeFirst();
            occ.remove(tail);
        }

        int nh = encode(nr, nc);
        if (occ.contains(nh)) {
            return -1;
        }

        body.addLast(nh);
        occ.add(nh);
        headR = nr;
        headC = nc;

        if (eat) {
            foodIdx++;
        }
        return foodIdx;
    }

    private int encode(int r, int c) {
        return r * width + c;
    }
}
```

## 复杂度分析
- 时间：每次移动 \(O(1)\)
- 空间：\(O(L)\)（L 为蛇长度）
