# 265. 粉刷房子 II

- 题号：265
- 难度：困难
- LeetCode：[粉刷房子 II](https://leetcode.cn/problems/paint-house-ii/)

## 题目描述
有 n 栋房子，每栋房子可刷 k 种颜色，`costs[i][j]` 为第 i 栋刷成颜色 j 的费用。相邻房子颜色不能相同，求最小总费用。

## 示例
`costs = [[1,5,3],[2,9,4]]`，输出 `5`

## 最佳解法思路
- DP：`dp[j]` 表示刷到当前房子且当前颜色为 j 的最小费用。
- 为了把 \(O(nk^2)\) 优化到 \(O(nk)\)，每一行只需要知道上一行的最小值 `min1`、次小值 `min2` 及其颜色下标：
  - 若当前颜色 j 不是 `min1` 的颜色，用 `min1`；否则用 `min2`。

## Java 最佳实现

```java
class Solution {
    public int minCostII(int[][] costs) {
        if (costs == null || costs.length == 0) {
            return 0;
        }
        int n = costs.length;
        int k = costs[0].length;
        int[] dp = new int[k];
        for (int j = 0; j < k; j++) {
            dp[j] = costs[0][j];
        }

        for (int i = 1; i < n; i++) {
            int min1 = Integer.MAX_VALUE;
            int min2 = Integer.MAX_VALUE;
            int idx1 = -1;
            for (int j = 0; j < k; j++) {
                int v = dp[j];
                if (v < min1) {
                    min2 = min1;
                    min1 = v;
                    idx1 = j;
                } else if (v < min2) {
                    min2 = v;
                }
            }

            int[] ndp = new int[k];
            for (int j = 0; j < k; j++) {
                int bestPrev = (j == idx1) ? min2 : min1;
                ndp[j] = bestPrev + costs[i][j];
            }
            dp = ndp;
        }

        int ans = Integer.MAX_VALUE;
        for (int v : dp) {
            ans = Math.min(ans, v);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(nk)\)
- 空间：\(O(k)\)
