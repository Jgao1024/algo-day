# 960. 删列造序 III

- 题号：960
- 难度：困难
- LeetCode：[删列造序 III](https://leetcode.cn/problems/delete-columns-to-make-sorted-iii/)

## 题目描述
给定等长字符串数组 `strs`。你可以删除若干“列”（同一索引的字符一起删），使得删除后数组按字典序非递减。返回最少删除列数。

## 示例
- `strs = ["babca","bbazb"]`，输出 `3`

## 最佳解法思路
- 设字符串数量为 m，列数为 n。
- 把每一列看成一个“长度为 m 的向量”。如果对所有行 r 都满足 `col[i][r] <= col[j][r]`，则列 i 可以在列 j 前面保留。
- 于是问题变成：在列上找最长“可比较递增”的子序列长度 `L`，答案为 `n - L`。
- DP：`dp[j] = max(dp[i] + 1)`（i<j 且列 i 可接到列 j）。

## Java 最佳实现

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int m = strs.length;
        int n = strs[0].length();

        int[] dp = new int[n];
        int best = 1;
        for (int j = 0; j < n; j++) {
            dp[j] = 1;
            for (int i = 0; i < j; i++) {
                if (canFollow(strs, i, j)) {
                    dp[j] = Math.max(dp[j], dp[i] + 1);
                }
            }
            best = Math.max(best, dp[j]);
        }

        return n - best;
    }

    private boolean canFollow(String[] strs, int i, int j) {
        for (String s : strs) {
            if (s.charAt(i) > s.charAt(j)) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 \cdot m)\)
- 空间：\(O(n)\)
