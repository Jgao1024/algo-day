# 1090. 受标签影响的最大值

- 题号：1090
- 难度：中等
- LeetCode：[受标签影响的最大值](https://leetcode.cn/problems/largest-values-from-labels/)

## 题目描述
给定 `values[i]` 和 `labels[i]`，你最多选 `numWanted` 个元素，并且每个标签最多选 `useLimit` 个。返回可得到的最大总和。

## 示例
- `values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1`  
输出 `9`（选 5(1),3(2),1(3)）

## 最佳解法思路
- 把元素按 `value` 从大到小排序，贪心选取：
  - 总共选不超过 `numWanted`
  - 对每个标签计数，不超过 `useLimit`

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int largestValsFromLabels(int[] values, int[] labels, int numWanted, int useLimit) {
        int n = values.length;
        int[][] a = new int[n][2];
        for (int i = 0; i < n; i++) {
            a[i][0] = values[i];
            a[i][1] = labels[i];
        }
        Arrays.sort(a, (x, y) -> y[0] - x[0]);

        Map<Integer, Integer> used = new HashMap<>();
        int picked = 0;
        int sum = 0;
        for (int[] it : a) {
            if (picked == numWanted) {
                break;
            }
            int label = it[1];
            int cnt = used.getOrDefault(label, 0);
            if (cnt == useLimit) {
                continue;
            }
            used.put(label, cnt + 1);
            sum += it[0];
            picked++;
        }
        return sum;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
