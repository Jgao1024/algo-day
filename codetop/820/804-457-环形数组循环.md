## 最佳解法思路
- 快慢指针：从每个起点出发，要求环长度 > 1 且方向一致（全正或全负）。
- 一旦发现环返回 true；若失败，把本次路径上的点标记为 0，避免重复计算。

## Java 最佳实现

```java
class Solution {
    public boolean circularArrayLoop(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] == 0) continue;
            boolean forward = nums[i] > 0;
            int slow = i, fast = i;
            while (true) {
                slow = next(nums, slow);
                if (slow == -1) break;
                fast = next(nums, fast);
                if (fast == -1) break;
                fast = next(nums, fast);
                if (fast == -1) break;
                if (slow == fast) return true;
            }
            int cur = i;
            while (nums[cur] != 0 && (nums[cur] > 0) == forward) {
                int nxt = nextIndex(nums, cur);
                nums[cur] = 0;
                if (nxt == cur) break;
                cur = nxt;
            }
        }
        return false;
    }

    private int next(int[] nums, int i) {
        int n = nums.length;
        boolean forward = nums[i] > 0;
        int j = nextIndex(nums, i);
        if (j == i) return -1;
        if (nums[j] == 0) return -1;
        if ((nums[j] > 0) != forward) return -1;
        return j;
    }

    private int nextIndex(int[] nums, int i) {
        int n = nums.length;
        int j = (i + nums[i]) % n;
        if (j < 0) j += n;
        return j;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
