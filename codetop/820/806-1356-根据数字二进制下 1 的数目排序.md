## 最佳解法思路
- 自定义排序：先按 `bitCount` 升序，再按数值升序。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int[] sortByBits(int[] arr) {
        Integer[] a = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) a[i] = arr[i];
        Arrays.sort(a, (x, y) -> {
            int bx = Integer.bitCount(x);
            int by = Integer.bitCount(y);
            if (bx != by) return Integer.compare(bx, by);
            return Integer.compare(x, y);
        });
        for (int i = 0; i < arr.length; i++) arr[i] = a[i];
        return arr;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
