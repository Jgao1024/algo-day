## 最佳解法思路
- 二分答案：第 `n` 个丑数（能被 `a` 或 `b` 或 `c` 整除）在数轴上单调递增。
- 统计 `<= mid` 的数量：容斥  
  `cnt = mid/a + mid/b + mid/c - mid/lcm(a,b) - mid/lcm(a,c) - mid/lcm(b,c) + mid/lcm(a,b,c)`。

## Java 最佳实现

```java
class Solution {
    public int nthUglyNumber(int n, int a, int b, int c) {
        long lo = 1;
        long min = Math.min(a, Math.min(b, c));
        long hi = min * n;

        long ab = lcm(a, b);
        long ac = lcm(a, c);
        long bc = lcm(b, c);
        long abc = lcm(ab, c);

        while (lo < hi) {
            long mid = lo + ((hi - lo) >>> 1);
            long cnt = mid / a + mid / b + mid / c
                    - mid / ab - mid / ac - mid / bc
                    + mid / abc;
            if (cnt >= n) hi = mid;
            else lo = mid + 1;
        }
        return (int) lo;
    }

    private long lcm(long x, long y) {
        return x / gcd(x, y) * y;
    }

    private long gcd(long x, long y) {
        while (y != 0) {
            long t = x % y;
            x = y;
            y = t;
        }
        return x;
    }
}
```

## 复杂度分析
- 时间：\(O(\log (n\cdot \min(a,b,c)))\)
- 空间：\(O(1)\)
