## 最佳解法思路
- DP 两类状态：一行 3 列有两种形态：  
  - `aba`：两种颜色（第 1、3 列同色）  
  - `abc`：三种颜色都不同
- 转移：  
  `aba' = aba * 3 + abc * 2`  
  `abc' = aba * 2 + abc * 2`

## Java 最佳实现

```java
class Solution {
    public int numOfWays(int n) {
        long mod = 1_000_000_007L;
        long aba = 6;
        long abc = 6;
        for (int i = 2; i <= n; i++) {
            long nAba = (aba * 3 + abc * 2) % mod;
            long nAbc = (aba * 2 + abc * 2) % mod;
            aba = nAba;
            abc = nAbc;
        }
        return (int) ((aba + abc) % mod);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
