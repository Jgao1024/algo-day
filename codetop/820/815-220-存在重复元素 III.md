## 最佳解法思路
- 桶（HashMap）：把数按宽度 `w = t + 1` 分桶，相同桶内必然满足差值 \(\le t\)。
- 对每个数只需检查本桶和相邻桶；并维护窗口大小 `k`，把超出窗口的元素移除。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean containsNearbyAlmostDuplicate(int[] nums, int k, int t) {
        if (k <= 0 || t < 0) return false;
        long w = (long) t + 1;
        Map<Long, Long> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            long x = nums[i];
            long id = bucketId(x, w);
            if (map.containsKey(id)) return true;
            Long left = map.get(id - 1);
            if (left != null && x - left <= t) return true;
            Long right = map.get(id + 1);
            if (right != null && right - x <= t) return true;

            map.put(id, x);
            if (i >= k) {
                long old = nums[i - k];
                map.remove(bucketId(old, w));
            }
        }
        return false;
    }

    private long bucketId(long x, long w) {
        return Math.floorDiv(x, w);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(k)\)
