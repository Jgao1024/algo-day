## 最佳解法思路
- 从右往左扫：维护右侧最大值 `max`，当前位置先赋值为 `max`，再更新 `max = max(max, arr[i])`。

## Java 最佳实现

```java
class Solution {
    public int[] replaceElements(int[] arr) {
        int max = -1;
        for (int i = arr.length - 1; i >= 0; i--) {
            int cur = arr[i];
            arr[i] = max;
            if (cur > max) max = cur;
        }
        return arr;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
