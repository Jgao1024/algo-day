## 最佳解法思路
- 贪心：把 `target` 看作从全 0 通过“对子数组 +1”构造。
- `target[0]` 需要加这么多次；之后每当 `target[i] > target[i-1]`，多出来的差值必须额外操作。

## Java 最佳实现

```java
class Solution {
    public int minNumberOperations(int[] target) {
        int ans = target[0];
        for (int i = 1; i < target.length; i++) {
            if (target[i] > target[i - 1]) {
                ans += target[i] - target[i - 1];
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
