## 最佳解法思路
- 每个数组是升序，只需取每个数组的最小值和最大值。
- 扫描时维护“到目前为止的全局最小值/最大值”，用当前数组更新答案，再更新全局极值。

## Java 最佳实现

```java
import java.util.List;

class Solution {
    public int maxDistance(List<List<Integer>> arrays) {
        int min = arrays.get(0).get(0);
        List<Integer> first = arrays.get(0);
        int max = first.get(first.size() - 1);

        int ans = 0;
        for (int i = 1; i < arrays.size(); i++) {
            List<Integer> cur = arrays.get(i);
            int curMin = cur.get(0);
            int curMax = cur.get(cur.size() - 1);
            ans = Math.max(ans, Math.max(Math.abs(curMax - min), Math.abs(max - curMin)));
            min = Math.min(min, curMin);
            max = Math.max(max, curMax);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(m)\)（m 为数组个数）
- 空间：\(O(1)\)
