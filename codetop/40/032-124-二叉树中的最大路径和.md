# 124. 二叉树中的最大路径和

- 题号：124
- 难度：困难
- LeetCode：[二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

## 题目描述
二叉树中的“路径”指从任意节点出发到任意节点结束的一条序列，路径中每个节点最多出现一次，且必须沿父子连接。

路径至少包含一个节点，不要求经过根节点。返回路径和的最大值。

## 示例
- 示例1  
输入：`root = [1,2,3]`  
输出：`6`（2->1->3）

- 示例2  
输入：`root = [-10,9,20,null,null,15,7]`  
输出：`42`（15->20->7）

## 最佳解法思路
- 思路1（推荐）：后序 DFS  
对每个节点，计算“向上提供的最大贡献值”：
`gain = node.val + max(0, max(leftGain, rightGain))`。  
同时把“以该节点为拐点的路径和”更新全局答案：  
`node.val + max(0,leftGain) + max(0,rightGain)`。

## Java 最佳实现

```java
class Solution {
    private int ans = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int left = Math.max(0, dfs(node.left));
        int right = Math.max(0, dfs(node.right));

        ans = Math.max(ans, node.val + left + right);
        return node.val + Math.max(left, right);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈）
