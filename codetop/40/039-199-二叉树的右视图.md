# 199. 二叉树的右视图

- 题号：199
- 难度：中等
- LeetCode：[二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)

## 题目描述
给定二叉树的根节点 `root`，返回从右侧所能看到的节点值（从上到下）。

## 示例
- 示例  
输入：`[1,2,3,null,5,null,4]`  
输出：`[1,3,4]`

## 最佳解法思路
- 思路1（推荐）：层序遍历取每层最后一个  
BFS 分层，每层遍历 `size` 个节点，最后一个弹出的节点就是该层右视图。

- 思路2：DFS 先右后左  
先访问右子树，再访问左子树，第一次到达某层时记录该节点值。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) return ans;

        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int size = q.size();
            TreeNode last = null;
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                last = node;
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            ans.add(last.val);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
