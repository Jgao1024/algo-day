# 93. 复原IP地址

- 题号：93
- 难度：中等
- LeetCode：[复原IP地址](https://leetcode.cn/problems/restore-ip-addresses/)

## 题目描述
给你一个只包含数字的字符串 `s`，将其分割成所有可能的有效 IP 地址并返回。

有效 IP：由 4 段组成，每段是 `0~255`，且不能有前导零（除非该段就是 "0"）。

## 示例
- 示例1  
输入：`s = "25525511135"`  
输出：`["255.255.11.135","255.255.111.35"]`

- 示例2  
输入：`s = "0000"`  
输出：`["0.0.0.0"]`

## 最佳解法思路
- 思路1（推荐）：回溯  
从左到右尝试切 1~3 位作为一段，检查是否合法（<=255 且无前导零），累积 4 段后若刚好用完字符串则收集结果。  
剪枝：剩余字符长度必须在 `[剩余段数, 剩余段数*3]` 之间。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> restoreIpAddresses(String s) {
        List<String> ans = new ArrayList<>();
        dfs(s, 0, 0, new StringBuilder(), ans);
        return ans;
    }

    private void dfs(String s, int idx, int part, StringBuilder path, List<String> ans) {
        int n = s.length();
        int remainParts = 4 - part;
        int remainChars = n - idx;
        if (remainChars < remainParts || remainChars > remainParts * 3) return;

        if (part == 4) {
            if (idx == n) ans.add(path.toString());
            return;
        }

        int len0 = path.length();
        for (int len = 1; len <= 3 && idx + len <= n; len++) {
            if (len > 1 && s.charAt(idx) == '0') break;
            int val = parseInt(s, idx, idx + len);
            if (val > 255) continue;

            if (part > 0) path.append('.');
            path.append(s, idx, idx + len);
            dfs(s, idx + len, part + 1, path, ans);
            path.setLength(len0);
        }
    }

    private int parseInt(String s, int l, int r) {
        int v = 0;
        for (int i = l; i < r; i++) v = v * 10 + (s.charAt(i) - '0');
        return v;
    }
}
```

## 复杂度分析
- 时间：常数级分支（最多尝试 \(3^4\)），总体很小
- 空间：\(O(1)\)（递归深度最多 4，不计输出）
