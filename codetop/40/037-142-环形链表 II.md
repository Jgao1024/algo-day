# 142. 环形链表 II

- 题号：142
- 难度：中等
- LeetCode：[环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)

## 题目描述
给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，返回 `null`。

不允许修改链表。

## 示例
- 示例  
输入：`head = [3,2,0,-4], pos = 1`  
输出：下标 1 的节点（值 2）

## 最佳解法思路
- 思路1（推荐）：Floyd 判圈 + 定位入环点  
先用快慢指针相遇判断有环。  
相遇后，让一个指针从 `head` 出发，另一个从相遇点出发，每次都走 1 步，再次相遇的位置就是入环点。

- 思路2：HashSet  
遍历记录节点，第一次重复的节点就是入环点。

## Java 最佳实现

```java
class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                ListNode p1 = head;
                ListNode p2 = slow;
                while (p1 != p2) {
                    p1 = p1.next;
                    p2 = p2.next;
                }
                return p1;
            }
        }
        return null;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
