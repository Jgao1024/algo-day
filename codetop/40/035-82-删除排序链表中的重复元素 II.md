# 82. 删除排序链表中的重复元素 II

- 题号：82
- 难度：中等
- LeetCode：[删除排序链表中的重复元素 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/)

## 题目描述
给定一个已排序的链表 `head`，删除所有出现重复的节点，只保留原链表中没有重复出现的节点，返回新链表。

## 示例
- 示例1  
输入：`1->2->3->3->4->4->5`  
输出：`1->2->5`

- 示例2  
输入：`1->1->1->2->3`  
输出：`2->3`

## 最佳解法思路
- 思路1（推荐）：dummy + 指针跳过重复段  
用 `dummy` 指向头，`prev` 指向结果链表的尾。  
遍历 `cur`：如果 `cur` 与 `cur.next` 值相同，说明进入重复段，循环跳过所有同值节点，最后 `prev.next = curNext`；否则 `prev=cur` 正常前进。

## Java 最佳实现

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        ListNode cur = head;

        while (cur != null) {
            boolean dup = false;
            while (cur.next != null && cur.val == cur.next.val) {
                dup = true;
                cur = cur.next;
            }
            if (dup) {
                cur = cur.next;
                prev.next = cur;
            } else {
                prev = cur;
                cur = cur.next;
            }
        }
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
