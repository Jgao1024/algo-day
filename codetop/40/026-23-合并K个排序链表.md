# 23. 合并K个排序链表

- 题号：23
- 难度：困难
- LeetCode：[合并K个排序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)

## 题目描述
给你一个链表数组 `lists`，每个链表都按升序排列。

请将所有链表合并到一个升序链表中，返回合并后的链表头结点。

## 示例
- 示例  
输入：`lists = [[1,4,5],[1,3,4],[2,6]]`  
输出：`[1,1,2,3,4,4,5,6]`

## 最佳解法思路
- 思路1（推荐）：小根堆（PriorityQueue）  
把每个链表的头结点放入小根堆，重复执行：弹出最小节点接到答案尾部，并把该节点的 `next` 入堆。堆大小最多 k。

- 思路2：分治合并  
两两合并（类似归并排序），总复杂度 \(O(N\log k)\)，实现也不错。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
        for (ListNode node : lists) {
            if (node != null) pq.offer(node);
        }

        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (!pq.isEmpty()) {
            ListNode node = pq.poll();
            tail.next = node;
            tail = tail.next;
            if (node.next != null) pq.offer(node.next);
        }
        tail.next = null;
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(N\log k)\)（N 为总节点数）
- 空间：\(O(k)\)（堆）
