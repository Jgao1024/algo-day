# 141. 环形链表

- 题号：141
- 难度：简单
- LeetCode：[环形链表](https://leetcode.cn/problems/linked-list-cycle/)

## 题目描述
给你一个链表的头节点 `head`，判断链表中是否有环。

## 示例
- 示例  
输入：`head = [3,2,0,-4], pos = 1`（尾节点连接到下标 1）  
输出：`true`

## 最佳解法思路
- 思路1（推荐）：快慢指针（Floyd 判圈）  
慢指针每次走 1 步，快指针每次走 2 步。若有环，快慢指针一定会相遇；无环则快指针先到 null。

- 思路2：HashSet  
遍历节点，若节点已出现过则有环。空间 \(O(n)\)。

## Java 最佳实现

```java
class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
