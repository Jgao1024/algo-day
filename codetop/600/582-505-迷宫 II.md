## 最佳解法思路
- Dijkstra（推荐）  
球会沿着一个方向一直滚到撞墙才停，等价于图上的带权最短路：  
从一个停下的位置出发，向 4 个方向滚到下一个停点，权重为滚动步数。  
用 `dist[x][y]` 记录最短距离，优先队列按距离取最小扩展。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int shortestDistance(int[][] maze, int[] start, int[] destination) {
        int m = maze.length;
        int n = maze[0].length;
        int[][] dist = new int[m][n];
        for (int i = 0; i < m; i++) Arrays.fill(dist[i], Integer.MAX_VALUE);
        dist[start[0]][start[1]] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[2] - b[2]);
        pq.add(new int[] {start[0], start[1], 0});

        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int x = cur[0], y = cur[1], d = cur[2];
            if (d != dist[x][y]) continue;
            if (x == destination[0] && y == destination[1]) return d;

            for (int k = 0; k < 4; k++) {
                int nx = x;
                int ny = y;
                int step = 0;
                while (true) {
                    int tx = nx + dx[k];
                    int ty = ny + dy[k];
                    if (tx < 0 || tx >= m || ty < 0 || ty >= n || maze[tx][ty] == 1) break;
                    nx = tx;
                    ny = ty;
                    step++;
                }
                if (step == 0) continue;
                int nd = d + step;
                if (nd < dist[nx][ny]) {
                    dist[nx][ny] = nd;
                    pq.add(new int[] {nx, ny, nd});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(mn \log(mn))\)（每次扩展会滚动，整体可视为常数倍）
- 空间：\(O(mn)\)
