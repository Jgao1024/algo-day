## 最佳解法思路
- 双向映射（推荐）  
模式字符 `p[i]` 和单词 `w[i]` 必须一一对应：用 `Map<Character,String>` 和 `Map<String,Character>` 同时校验。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        String[] words = s.split(" ");
        if (words.length != pattern.length()) return false;

        Map<Character, String> p2w = new HashMap<>();
        Map<String, Character> w2p = new HashMap<>();

        for (int i = 0; i < pattern.length(); i++) {
            char p = pattern.charAt(i);
            String w = words[i];

            String mapped = p2w.get(p);
            if (mapped != null && !mapped.equals(w)) return false;

            Character mappedP = w2p.get(w);
            if (mappedP != null && mappedP != p) return false;

            p2w.put(p, w);
            w2p.put(w, p);
        }
        return true;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
