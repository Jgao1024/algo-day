## 最佳解法思路
- 回溯 + 同层去重（推荐）  
需要找所有“非递减”的子序列（长度 \(\ge 2\)），用回溯枚举选/不选。  
为了去重：在每一层（同一个 `start`）用一个 `used` 集合记录本层已经用过的数，避免同层重复选择相同值。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<List<Integer>> findSubsequences(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), ans);
        return ans;
    }

    private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {
        if (path.size() >= 2) ans.add(new ArrayList<>(path));

        Set<Integer> used = new HashSet<>();
        for (int i = start; i < nums.length; i++) {
            int x = nums[i];
            if (used.contains(x)) continue;
            if (!path.isEmpty() && x < path.get(path.size() - 1)) continue;
            used.add(x);
            path.add(x);
            dfs(nums, i + 1, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析
- 时间：最坏 \(O(2^n)\)
- 空间：\(O(n)\)（递归栈 + 路径）
