## 最佳解法思路
- 前缀和（推荐）  
先求总和 `sum`，遍历下标 `i`，维护左边和 `left`：  
若 `left == sum - left - nums[i]`，则 `i` 为中心索引；否则 `left += nums[i]`。

## Java 最佳实现

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int sum = 0;
        for (int x : nums) sum += x;

        int left = 0;
        for (int i = 0; i < nums.length; i++) {
            if (left == sum - left - nums[i]) return i;
            left += nums[i];
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
