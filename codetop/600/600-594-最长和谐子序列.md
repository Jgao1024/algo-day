## 最佳解法思路
- HashMap 计数（推荐）  
统计每个数出现次数 `cnt[x]`，答案是所有 `x` 中 `cnt[x] + cnt[x+1]` 的最大值（必须两种都存在）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findLHS(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) cnt.put(x, cnt.getOrDefault(x, 0) + 1);

        int ans = 0;
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int x = e.getKey();
            Integer next = cnt.get(x + 1);
            if (next != null) {
                ans = Math.max(ans, e.getValue() + next);
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
