## 最佳解法思路
- BFS + 状态（推荐）  
把“到达某个点且上一条边颜色为 red/blue”当成状态，做 BFS。  
从 0 出发时两种颜色都当作可起步：`dist[0][0]=dist[0][1]=0`。  
从状态 `(u, lastColor)` 只能走 `1-lastColor` 颜色的边到 `v`，首次到达就更新距离并入队。  
答案：`ans[i]=min(dist[i][0], dist[i][1])`，都不可达则 `-1`。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Deque;
import java.util.List;

class Solution {
    // 0: red, 1: blue
    public int[] shortestAlternatingPaths(int n, int[][] redEdges, int[][] blueEdges) {
        List<Integer>[] gRed = new ArrayList[n];
        List<Integer>[] gBlue = new ArrayList[n];
        for (int i = 0; i < n; i++) {
            gRed[i] = new ArrayList<>();
            gBlue[i] = new ArrayList<>();
        }
        for (int[] e : redEdges) gRed[e[0]].add(e[1]);
        for (int[] e : blueEdges) gBlue[e[0]].add(e[1]);

        int INF = 1 << 30;
        int[][] dist = new int[n][2];
        for (int i = 0; i < n; i++) Arrays.fill(dist[i], INF);
        dist[0][0] = 0;
        dist[0][1] = 0;

        Deque<int[]> q = new ArrayDeque<>();
        q.addLast(new int[] {0, 0});
        q.addLast(new int[] {0, 1});

        while (!q.isEmpty()) {
            int[] cur = q.pollFirst();
            int u = cur[0];
            int last = cur[1];
            int nextColor = 1 - last;
            List<Integer>[] g = (nextColor == 0) ? gRed : gBlue;
            for (int v : g[u]) {
                if (dist[v][nextColor] != INF) continue;
                dist[v][nextColor] = dist[u][last] + 1;
                q.addLast(new int[] {v, nextColor});
            }
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            int d = Math.min(dist[i][0], dist[i][1]);
            ans[i] = (d >= INF) ? -1 : d;
        }
        return ans;
    }
}
```

- 空间：\(O(n + m)\)
