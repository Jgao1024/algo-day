## 最佳解法思路
- 滑动窗口（推荐）  
维护窗口内 `a/b/c` 的计数。右指针每走一步，当窗口已包含三种字符时，就不断移动左指针缩小到“不满足”为止。  
对每个 `right`，满足条件的子串个数等于当前 `left`（左边界可选的起点数量）。

## Java 最佳实现

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int[] cnt = new int[3];
        int left = 0;
        int ans = 0;
        for (int right = 0; right < s.length(); right++) {
            cnt[s.charAt(right) - 'a']++;
            while (cnt[0] > 0 && cnt[1] > 0 && cnt[2] > 0) {
                cnt[s.charAt(left) - 'a']--;
                left++;
            }
            ans += left;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 对每个 `right`：窗口满足后尽量收缩，**答案加 `left`**。
