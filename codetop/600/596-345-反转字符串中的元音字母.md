## 最佳解法思路
- 双指针（推荐）  
左右指针向中间移动，分别找到元音字符后交换，直到相遇。

## Java 最佳实现

```java
class Solution {
    public String reverseVowels(String s) {
        char[] a = s.toCharArray();
        int l = 0;
        int r = a.length - 1;
        while (l < r) {
            while (l < r && !isVowel(a[l])) l++;
            while (l < r && !isVowel(a[r])) r--;
            char tmp = a[l];
            a[l] = a[r];
            a[r] = tmp;
            l++;
            r--;
        }
        return new String(a);
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u'
                || c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U';
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（char 数组）
