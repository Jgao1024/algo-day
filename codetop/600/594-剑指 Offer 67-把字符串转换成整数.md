## 最佳解法思路
- 模拟 atoi（推荐）  
步骤：跳过前导空格 -> 读符号 -> 连续读数字并累加。  
累加时处理溢出：用 `long` 计算，超出 `Integer` 范围直接截断到 `Integer.MAX_VALUE / MIN_VALUE`。

## Java 最佳实现

```java
class Solution {
    public int strToInt(String str) {
        if (str == null) return 0;
        int n = str.length();
        int i = 0;
        while (i < n && str.charAt(i) == ' ') i++;
        if (i >= n) return 0;

        int sign = 1;
        char c = str.charAt(i);
        if (c == '+' || c == '-') {
            sign = (c == '-') ? -1 : 1;
            i++;
        }

        long res = 0;
        while (i < n) {
            char ch = str.charAt(i);
            if (ch < '0' || ch > '9') break;
            res = res * 10 + (ch - '0');
            long val = res * sign;
            if (val > Integer.MAX_VALUE) return Integer.MAX_VALUE;
            if (val < Integer.MIN_VALUE) return Integer.MIN_VALUE;
            i++;
        }
        return (int) (res * sign);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
