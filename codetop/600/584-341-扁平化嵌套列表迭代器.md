## 最佳解法思路
- 栈展开（推荐）  
用栈保存当前还没展开的 `NestedInteger`。  
`hasNext()` 里把栈顶的列表不断展开（把子元素倒序入栈），直到栈顶是整数或栈空。  
`next()` 直接弹出整数返回。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Iterator;
import java.util.List;

public class NestedIterator implements Iterator<Integer> {
    private final Deque<NestedInteger> stack = new ArrayDeque<>();

    public NestedIterator(List<NestedInteger> nestedList) {
        pushList(nestedList);
    }

    private void pushList(List<NestedInteger> list) {
        for (int i = list.size() - 1; i >= 0; i--) {
            stack.push(list.get(i));
        }
    }

    @Override
    public Integer next() {
        hasNext();
        return stack.pop().getInteger();
    }

    @Override
    public boolean hasNext() {
        while (!stack.isEmpty() && !stack.peek().isInteger()) {
            List<NestedInteger> list = stack.pop().getList();
            pushList(list);
        }
        return !stack.isEmpty();
    }
}
```

## 复杂度分析
- 时间：均摊 \(O(1)\)（总展开次数与元素个数同阶）
- 空间：\(O(n)\)

## 总结（速记）
- **`hasNext()` 负责“展开到整数”，`next()` 只弹栈**。
