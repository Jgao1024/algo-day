## 最佳解法思路
- 先统计“本来就满意”的人数（老板不生气的时刻）。
- 再用长度为 `minutes` 的滑动窗口，计算在窗口内把生气改成不生气能额外增加的满意人数，取最大值。

## Java 最佳实现

```java
class Solution {
    public int maxSatisfied(int[] customers, int[] grumpy, int minutes) {
        int base = 0;
        for (int i = 0; i < customers.length; i++) {
            if (grumpy[i] == 0) base += customers[i];
        }

        int add = 0;
        for (int i = 0; i < customers.length && i < minutes; i++) {
            if (grumpy[i] == 1) add += customers[i];
        }
        int best = add;

        for (int i = minutes; i < customers.length; i++) {
            if (grumpy[i] == 1) add += customers[i];
            if (grumpy[i - minutes] == 1) add -= customers[i - minutes];
            if (add > best) best = add;
        }
        return base + best;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
