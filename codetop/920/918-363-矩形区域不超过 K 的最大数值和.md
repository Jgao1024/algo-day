## 最佳解法思路
- 枚举左右边界，把二维压成一维“行和数组”，问题变成：在一维数组中找“子数组和不超过 K 的最大值”。
- 一维用前缀和 + 有序集合（TreeSet）：对当前前缀 `cur`，找最小的 `pre >= cur - K`，即可更新答案 `cur - pre`。

## Java 最佳实现

```java
import java.util.TreeSet;

class Solution {
    public int maxSumSubmatrix(int[][] matrix, int k) {
        int m = matrix.length;
        int n = matrix[0].length;

        // 让列数更小，降低外层枚举
        if (m > n) {
            int[][] t = new int[n][m];
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    t[j][i] = matrix[i][j];
                }
            }
            matrix = t;
            int tmp = m;
            m = n;
            n = tmp;
        }

        int ans = Integer.MIN_VALUE;
        for (int left = 0; left < n; left++) {
            int[] sum = new int[m];
            for (int right = left; right < n; right++) {
                for (int i = 0; i < m; i++) {
                    sum[i] += matrix[i][right];
                }
                ans = Math.max(ans, bestNoMoreThanK(sum, k));
                if (ans == k) return k;
            }
        }
        return ans;
    }

    private int bestNoMoreThanK(int[] a, int k) {
        TreeSet<Integer> set = new TreeSet<>();
        set.add(0);
        int pre = 0;
        int ans = Integer.MIN_VALUE;
        for (int v : a) {
            pre += v;
            Integer ceil = set.ceiling(pre - k);
            if (ceil != null) {
                ans = Math.max(ans, pre - ceil);
            }
            set.add(pre);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2 \cdot m \log m)\)
- 空间：\(O(m)\)
