## 最佳解法思路
- 并查集：可交换的位置形成连通分量，每个分量内字符可以任意重排。
- 对每个分量，把下标排序、字符排序，然后按最小字符依次填回最小下标即可得到全局最小字典序。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        DSU dsu = new DSU(n);
        for (List<Integer> p : pairs) {
            dsu.union(p.get(0), p.get(1));
        }

        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int r = dsu.find(i);
            groups.computeIfAbsent(r, k -> new ArrayList<>()).add(i);
        }

        char[] res = new char[n];
        char[] arr = s.toCharArray();
        for (List<Integer> idxs : groups.values()) {
            int m = idxs.size();
            int[] is = new int[m];
            char[] cs = new char[m];
            for (int i = 0; i < m; i++) {
                is[i] = idxs.get(i);
                cs[i] = arr[is[i]];
            }
            Arrays.sort(is);
            Arrays.sort(cs);
            for (int i = 0; i < m; i++) {
                res[is[i]] = cs[i];
            }
        }
        return new String(res);
    }

    static class DSU {
        int[] p;
        int[] r;
        DSU(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) p[i] = i;
        }
        int find(int x) {
            while (p[x] != x) {
                p[x] = p[p[x]];
                x = p[x];
            }
            return x;
        }
        void union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return;
            if (r[ra] < r[rb]) p[ra] = rb;
            else if (r[ra] > r[rb]) p[rb] = ra;
            else {
                p[rb] = ra;
                r[ra]++;
            }
        }
    }
}
```

## 复杂度分析
- 时间：并查集 \(O(n+\text{pairs})\)，排序总计 \(O(n\log n)\)
- 空间：\(O(n)\)
