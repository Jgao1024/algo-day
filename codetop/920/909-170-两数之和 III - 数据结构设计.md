## 最佳解法思路
- `add` 统计每个数出现次数；`find` 遍历 key，检查 `value - x` 是否存在（注意 `x*2` 需要次数 \(\ge 2\)）。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class TwoSum {
    private final Map<Integer, Integer> cnt = new HashMap<>();

    public TwoSum() {
    }

    public void add(int number) {
        cnt.put(number, cnt.getOrDefault(number, 0) + 1);
    }

    public boolean find(int value) {
        for (int x : cnt.keySet()) {
            int y = value - x;
            if (y == x) {
                if (cnt.get(x) >= 2) return true;
            } else {
                if (cnt.containsKey(y)) return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：add \(O(1)\)，find \(O(U)\)（U 为不同数字个数）
- 空间：\(O(U)\)
