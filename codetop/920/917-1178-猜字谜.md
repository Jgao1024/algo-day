## 最佳解法思路
- 把每个单词变成 26 位 bitmask（出现过的字母置 1），只保留“不同字母数 \(\le 7\)”的单词并统计 mask 频次。
- 对每个 puzzle：必须包含首字母，且单词 mask 必须是 puzzle mask 的子集。  
  枚举 puzzle 的子集（只枚举除首字母外的子集），累加频次即可。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public java.util.List<Integer> findNumOfValidWords(String[] words, String[] puzzles) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (String w : words) {
            int mask = 0;
            for (int i = 0; i < w.length(); i++) {
                mask |= 1 << (w.charAt(i) - 'a');
            }
            if (Integer.bitCount(mask) <= 7) {
                cnt.put(mask, cnt.getOrDefault(mask, 0) + 1);
            }
        }

        java.util.List<Integer> res = new java.util.ArrayList<>(puzzles.length);
        for (String p : puzzles) {
            int mask = 0;
            for (int i = 0; i < p.length(); i++) {
                mask |= 1 << (p.charAt(i) - 'a');
            }
            int first = 1 << (p.charAt(0) - 'a');
            int rest = mask ^ first;

            int ans = 0;
            int sub = rest;
            while (true) {
                int cand = sub | first;
                ans += cnt.getOrDefault(cand, 0);
                if (sub == 0) break;
                sub = (sub - 1) & rest;
            }
            res.add(ans);
        }
        return res;
    }
}
```

## 复杂度分析
- 时间：预处理 \(O(\sum |word|)\)，每个 puzzle 枚举子集 \(O(2^6)\)
- 空间：\(O(\#mask)\)
