## 最佳解法思路
- 贪心：从左到右，如果当前位置在当前翻转影响下仍为 0，就必须在这里翻一次长度为 K 的区间。
- 用数组记录“某次翻转从 i 开始”的标记，滑动时维护当前翻转奇偶 `flip`。

## Java 最佳实现

```java
class Solution {
    public int minKBitFlips(int[] nums, int k) {
        int n = nums.length;
        int[] flipped = new int[n];
        int flip = 0;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (i >= k) flip ^= flipped[i - k];
            if ((nums[i] ^ flip) == 0) {
                if (i + k > n) return -1;
                ans++;
                flip ^= 1;
                flipped[i] = 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
