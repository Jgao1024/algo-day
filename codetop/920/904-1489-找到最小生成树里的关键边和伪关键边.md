## 最佳解法思路
- 先用 Kruskal 求出最小生成树总权重 `base`。
- 对每条边 `e`：  
  - **排除 e** 再跑 Kruskal，若无法生成 MST 或权重变大，则 `e` 是关键边。  
  - 否则 **强制选 e**（先 union 它并加权重）再跑 Kruskal，若最终权重仍为 `base`，则 `e` 是伪关键边。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> findCriticalAndPseudoCriticalEdges(int n, int[][] edges) {
        int m = edges.length;
        int[][] es = new int[m][4]; // u, v, w, idx
        for (int i = 0; i < m; i++) {
            es[i][0] = edges[i][0];
            es[i][1] = edges[i][1];
            es[i][2] = edges[i][2];
            es[i][3] = i;
        }
        Arrays.sort(es, (a, b) -> Integer.compare(a[2], b[2]));

        long base = kruskal(n, es, -1, -1);
        List<Integer> critical = new ArrayList<>();
        List<Integer> pseudo = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            long skip = kruskal(n, es, i, -1);
            if (skip > base) {
                critical.add(es[i][3]);
            } else {
                long pick = kruskal(n, es, -1, i);
                if (pick == base) pseudo.add(es[i][3]);
            }
        }

        List<List<Integer>> res = new ArrayList<>();
        res.add(critical);
        res.add(pseudo);
        return res;
    }

    private long kruskal(int n, int[][] es, int skipIdx, int pickIdx) {
        DSU dsu = new DSU(n);
        long w = 0;
        int used = 0;

        if (pickIdx != -1) {
            int[] e = es[pickIdx];
            if (dsu.union(e[0], e[1])) {
                w += e[2];
                used++;
            }
        }

        for (int i = 0; i < es.length; i++) {
            if (i == skipIdx || i == pickIdx) continue;
            int[] e = es[i];
            if (dsu.union(e[0], e[1])) {
                w += e[2];
                used++;
                if (used == n - 1) break;
            }
        }
        return used == n - 1 ? w : Long.MAX_VALUE / 4;
    }

    static class DSU {
        int[] p;
        int[] r;
        DSU(int n) {
            p = new int[n];
            r = new int[n];
            for (int i = 0; i < n; i++) p[i] = i;
        }
        int find(int x) {
            while (p[x] != x) {
                p[x] = p[p[x]];
                x = p[x];
            }
            return x;
        }
        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            if (r[ra] < r[rb]) p[ra] = rb;
            else if (r[ra] > r[rb]) p[rb] = ra;
            else {
                p[rb] = ra;
                r[ra]++;
            }
            return true;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(m^2 \log m)\)（m 为边数）
- 空间：\(O(m+n)\)
