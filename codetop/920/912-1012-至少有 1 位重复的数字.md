## 最佳解法思路
- 反向统计：先统计 \([1..N]\) 中“各位数字都不重复”的数量 `unique`，答案为 `N - unique`。
- `unique` 的统计用排列计数 + 按位枚举：  
  - 先加上位数小于 `len(N)` 的所有不重复数  
  - 再按位从高到低，枚举当前位比 `N` 小且未使用的数字，后面用排列数补齐。

## Java 最佳实现

```java
class Solution {
    public int numDupDigitsAtMostN(int N) {
        if (N <= 0) return 0;
        long uniqueUpTo = countUniqueUpTo(N);
        long unique1ToN = uniqueUpTo - 1; // 去掉 0
        return (int) (N - unique1ToN);
    }

    // 统计 [0..N] 中“各位不重复”的数量
    private long countUniqueUpTo(int N) {
        if (N == 0) return 1;
        int[] d = toDigits(N);
        int len = d.length;

        long ans = 0;
        for (int l = 1; l < len; l++) {
            ans += 9L * perm(9, l - 1);
        }

        boolean[] used = new boolean[10];
        for (int i = 0; i < len; i++) {
            int cur = d[i];
            for (int x = (i == 0 ? 1 : 0); x < cur; x++) {
                if (used[x]) continue;
                ans += perm(10 - (i + 1), len - i - 1);
            }
            if (used[cur]) break;
            used[cur] = true;
            if (i == len - 1) ans += 1;
        }

        return ans + 1; // 加上 0
    }

    private long perm(int m, int k) {
        long res = 1;
        for (int i = 0; i < k; i++) res *= (m - i);
        return res;
    }

    private int[] toDigits(int x) {
        String s = String.valueOf(x);
        int[] d = new int[s.length()];
        for (int i = 0; i < s.length(); i++) d[i] = s.charAt(i) - '0';
        return d;
    }
}
```

## 复杂度分析
- 时间：\(O(len \cdot 10)\)
- 空间：\(O(1)\)
