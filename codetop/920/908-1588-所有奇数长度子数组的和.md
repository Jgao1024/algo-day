## 最佳解法思路
- 贡献法：元素 `arr[i]` 出现在多少个奇数长度子数组里？  
  左边可选 `i+1` 种起点，右边可选 `n-i` 种终点，总子数组数为 `left*right`。其中奇数个数为 `(total+1)/2`。

## Java 最佳实现

```java
class Solution {
    public int sumOddLengthSubarrays(int[] arr) {
        int n = arr.length;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            long left = i + 1;
            long right = n - i;
            long total = left * right;
            long odd = (total + 1) / 2;
            ans += odd * arr[i];
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
