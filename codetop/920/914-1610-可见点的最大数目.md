## 最佳解法思路
- 把所有点相对于观察点的角度算出来并排序；再把角度数组复制一份并加上 \(2\pi\)，用滑动窗口找角度差 \(\le angle\) 的最大数量。
- 与观察点重合的点永远可见，单独计数加回。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int visiblePoints(java.util.List<java.util.List<Integer>> points, int angle, java.util.List<Integer> location) {
        int x0 = location.get(0);
        int y0 = location.get(1);
        int same = 0;

        double[] a = new double[points.size()];
        int m = 0;
        for (java.util.List<Integer> p : points) {
            int x = p.get(0), y = p.get(1);
            if (x == x0 && y == y0) {
                same++;
            } else {
                a[m++] = Math.atan2(y - y0, x - x0);
            }
        }
        if (m == 0) return same;

        Arrays.sort(a, 0, m);
        double[] b = new double[m * 2];
        for (int i = 0; i < m; i++) {
            b[i] = a[i];
            b[i + m] = a[i] + 2.0 * Math.PI;
        }

        double limit = angle * Math.PI / 180.0 + 1e-12;
        int ans = 0;
        int left = 0;
        for (int right = 0; right < 2 * m; right++) {
            while (b[right] - b[left] > limit) left++;
            ans = Math.max(ans, right - left + 1);
        }
        return ans + same;
    }
}
```

## 复杂度分析
- 时间：\(O(m\log m)\)
- 空间：\(O(m)\)
