## 最佳解法思路
- 最短路（Dijkstra）：到达某格子的代价是路径上最大高度的最小可能值。
- 走到邻格的代价为 `max(curCost, grid[nr][nc])`，用小根堆扩展即可。

## Java 最佳实现

```java
import java.util.PriorityQueue;

class Solution {
    public int swimInWater(int[][] grid) {
        int n = grid.length;
        boolean[][] vis = new boolean[n][n];
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        pq.add(new int[]{grid[0][0], 0, 0});

        int[] dr = {1, -1, 0, 0};
        int[] dc = {0, 0, 1, -1};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int cost = cur[0];
            int r = cur[1];
            int c = cur[2];
            if (vis[r][c]) continue;
            vis[r][c] = true;
            if (r == n - 1 && c == n - 1) return cost;

            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                if (vis[nr][nc]) continue;
                int ncost = Math.max(cost, grid[nr][nc]);
                pq.add(new int[]{ncost, nr, nc});
            }
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(n^2\log n)\)
- 空间：\(O(n^2)\)
