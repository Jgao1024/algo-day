## 最佳解法思路
- 逐列检查：对每一列 `j`，看所有相邻行 `strs[i-1][j] <= strs[i][j]` 是否成立；不成立就需要删这一列。

## Java 最佳实现

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int m = strs.length;
        int n = strs[0].length();
        int ans = 0;
        for (int j = 0; j < n; j++) {
            boolean ok = true;
            for (int i = 1; i < m; i++) {
                if (strs[i - 1].charAt(j) > strs[i].charAt(j)) {
                    ok = false;
                    break;
                }
            }
            if (!ok) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(1)\)
