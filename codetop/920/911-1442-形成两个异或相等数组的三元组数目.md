## 最佳解法思路
- 前缀异或：令 `pre[i] = arr[0..i-1]` 的异或。  
  若 `pre[i] == pre[k+1]`，则 `arr[i..k]` 的异或为 0，此时对任意 `j`（`i < j <= k`）都满足条件，贡献 `k - i`。
- 枚举 `k`，对所有 `i` 使 `pre[i]==pre[k+1]` 进行累加，可用哈希表维护出现次数与下标和。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countTriplets(int[] arr) {
        int n = arr.length;
        int pre = 0;
        Map<Integer, Integer> cnt = new HashMap<>();
        Map<Integer, Long> sumIdx = new HashMap<>();

        cnt.put(0, 1);
        sumIdx.put(0, 0L);

        long ans = 0;
        for (int k = 0; k < n; k++) {
            pre ^= arr[k]; // pre = pre[k+1]
            int c = cnt.getOrDefault(pre, 0);
            long s = sumIdx.getOrDefault(pre, 0L);
            // 对所有 i 满足 pre[i]==pre[k+1]，贡献 sum(k - i) = c*k - sum(i)
            ans += (long) c * k - s;

            cnt.put(pre, c + 1);
            sumIdx.put(pre, s + (k + 1L));
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
