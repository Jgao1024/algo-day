## 最佳解法思路
- 二分答案：平均值越大，是否存在长度 \(\ge k\) 的子数组平均值 \(\ge mid\) 具有单调性。
- 将数组变换为 `nums[i] - mid`，问题变成是否存在长度 \(\ge k\) 的子数组和 \(\ge 0\)。  
  用前缀和 + 维护前缀最小值即可 \(O(n)\) 检查。

## Java 最佳实现

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int lo = nums[0], hi = nums[0];
        for (int x : nums) {
            lo = Math.min(lo, x);
            hi = Math.max(hi, x);
        }

        double l = lo, r = hi;
        while (r - l > 1e-5) {
            double mid = (l + r) / 2.0;
            if (check(nums, k, mid)) {
                l = mid;
            } else {
                r = mid;
            }
        }
        return l;
    }

    private boolean check(int[] nums, int k, double mid) {
        int n = nums.length;
        double[] pre = new double[n + 1];
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i] - mid;
        }

        double minPre = 0.0;
        for (int i = k; i <= n; i++) {
            minPre = Math.min(minPre, pre[i - k]);
            if (pre[i] - minPre >= 0) return true;
        }
        return false;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log R)\)（R 为值域/精度）
- 空间：\(O(n)\)
