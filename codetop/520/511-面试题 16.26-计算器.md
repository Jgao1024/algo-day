# 面试题 16.26. 计算器

- 题号：面试题 16.26
- 难度：中等
- LeetCode：[计算器](https://leetcode.cn/problems/calculator-lcci/)

## 题目描述
给定一个包含非负整数、`+ - * /`、括号和空格的表达式字符串 `s`，返回计算结果（整数除法向 0 取整）。

## 示例
- 示例  
输入：`s = "2*(3+4)"`  
输出：`14`

## 最佳解法思路
- 思路1（推荐）：两个栈（数字栈 + 运算符栈）  
从左到右扫描：  
- 读到数字：解析完整数字入数字栈  
- 读到 `(`：入运算符栈  
- 读到 `)`：把栈顶运算符计算到遇到 `(`  
- 读到运算符：把运算符栈里优先级 \(\ge\) 当前的先算掉，再把当前运算符入栈  
最后把剩余运算符全部算完。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int calculate(String s) {
        Deque<Integer> nums = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        int n = s.length();
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (c == ' ') continue;
            if (c >= '0' && c <= '9') {
                int val = 0;
                while (i < n && s.charAt(i) >= '0' && s.charAt(i) <= '9') {
                    val = val * 10 + (s.charAt(i) - '0');
                    i++;
                }
                i--;
                nums.push(val);
            } else if (c == '(') {
                ops.push(c);
            } else if (c == ')') {
                while (!ops.isEmpty() && ops.peek() != '(') calc(nums, ops);
                ops.pop();
            } else {
                while (!ops.isEmpty() && ops.peek() != '(' && prec(ops.peek()) >= prec(c)) {
                    calc(nums, ops);
                }
                ops.push(c);
            }
        }
        while (!ops.isEmpty()) calc(nums, ops);
        return nums.pop();
    }

    private int prec(char op) {
        return (op == '*' || op == '/') ? 2 : 1;
    }

    private void calc(Deque<Integer> nums, Deque<Character> ops) {
        int b = nums.pop();
        int a = nums.pop();
        char op = ops.pop();
        if (op == '+') nums.push(a + b);
        else if (op == '-') nums.push(a - b);
        else if (op == '*') nums.push(a * b);
        else nums.push(a / b);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)

## 总结（速记）
- 两栈模板：遇到运算符先把“优先级不低于它”的算掉；遇到 `)` 就算到 `(`。
