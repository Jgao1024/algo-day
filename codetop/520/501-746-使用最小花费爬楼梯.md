# 746. 使用最小花费爬楼梯

- 题号：746
- 难度：简单
- LeetCode：[使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs/)

## 题目描述
给定数组 `cost`，`cost[i]` 表示踩到第 `i` 个台阶需要付出的花费。  
你可以从 `0` 或 `1` 开始，每次爬 1 或 2 个台阶，返回到达楼顶的最小花费（楼顶在 `n`）。

## 示例
- 示例  
输入：`cost = [10,15,20]`  
输出：`15`

## 最佳解法思路
- 思路1（推荐）：DP（滚动变量）  
设 `dp[i]` 表示到达第 `i` 级台阶的最小花费（`i` 可为 `n` 楼顶）。  
转移：`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`。  
用两个变量滚动即可。

## Java 最佳实现

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int prev2 = 0;
        int prev1 = 0;
        for (int i = 2; i <= n; i++) {
            int cur = Math.min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- `dp[i]` 到第 i 级：从 `i-1/i-2` 转移，注意花费在“踩上那级台阶”时产生。
