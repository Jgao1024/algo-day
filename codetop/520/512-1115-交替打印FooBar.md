# 1115. 交替打印FooBar

- 题号：1115
- 难度：中等
- LeetCode：[交替打印FooBar](https://leetcode.cn/problems/print-foobar-alternately/)

## 题目描述
有两个线程分别调用 `foo()` 和 `bar()`，要求交替打印 `"foo"` 和 `"bar"` 共 `n` 次，最终输出为 `"foobar"` 重复 `n` 次。

## 示例
- 示例  
输入：`n = 2`  
输出：`"foobarfoobar"`

## 最佳解法思路
- 思路1（推荐）：Semaphore  
用 `fooSem` 初始为 1，`barSem` 初始为 0。  
`foo` 线程：先拿 `fooSem` 再打印，打印后释放 `barSem`；  
`bar` 线程：先拿 `barSem` 再打印，打印后释放 `fooSem`。

## Java 最佳实现

```java
import java.util.concurrent.Semaphore;

class FooBar {
    private int n;
    private final Semaphore fooSem = new Semaphore(1);
    private final Semaphore barSem = new Semaphore(0);

    public FooBar(int n) {
        this.n = n;
    }

    public void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            fooSem.acquire();
            printFoo.run();
            barSem.release();
        }
    }

    public void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            barSem.acquire();
            printBar.run();
            fooSem.release();
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
