# 1423. 可获得的最大点数

- 题号：1423
- 难度：中等
- LeetCode：[可获得的最大点数](https://leetcode.cn/problems/maximum-points-you-can-obtain-from-cards/)

## 题目描述
给定数组 `cardPoints` 和整数 `k`，每次只能从数组两端拿一张牌，共拿 `k` 张，返回能获得的最大点数和。

## 示例
- 示例  
输入：`cardPoints = [1,2,3,4,5,6,1], k = 3`  
输出：`12`

## 最佳解法思路
- 思路1（推荐）：转化为“中间最小窗口”  
总共拿 `k` 张等价于：留下中间 `n-k` 张不拿。  
所以答案 = 总和 - 中间长度 `n-k` 的最小连续子数组和。  
用滑动窗口求最小和即可。

## Java 最佳实现

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length;
        int window = n - k;
        int total = 0;
        for (int x : cardPoints) total += x;
        if (window == 0) return total;

        int sum = 0;
        for (int i = 0; i < window; i++) sum += cardPoints[i];
        int min = sum;
        for (int i = window; i < n; i++) {
            sum += cardPoints[i] - cardPoints[i - window];
            min = Math.min(min, sum);
        }
        return total - min;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
