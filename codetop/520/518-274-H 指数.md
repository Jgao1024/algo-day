# 274. H 指数

- 题号：274
- 难度：中等
- LeetCode：[H 指数](https://leetcode.cn/problems/h-index/)

## 题目描述
给定数组 `citations`，`citations[i]` 表示第 `i` 篇论文被引用次数。  
返回研究者的 H 指数：最大值 \(h\)，使得至少有 \(h\) 篇论文引用次数 \(\ge h\)。

## 示例
- 示例  
输入：`citations = [3,0,6,1,5]`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：排序后扫描  
把引用次数降序排序，找到最大的 `i+1` 满足 `citations[i] >= i+1`。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int hIndex(int[] citations) {
        Arrays.sort(citations);
        int n = citations.length;
        int h = 0;
        for (int i = 0; i < n; i++) {
            int cand = n - i;
            if (citations[i] >= cand) {
                h = cand;
                break;
            }
        }
        return h;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(1)\)（不计排序栈）

## 总结（速记）
- 排序后看“有多少篇 \(\ge\) 某个值”：降序满足 `cit[i] >= i+1`；或升序找第一个 `cit[i] >= n-i`。
