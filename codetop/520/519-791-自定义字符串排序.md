# 791. 自定义字符串排序

- 题号：791
- 难度：中等
- LeetCode：[自定义字符串排序](https://leetcode.cn/problems/custom-sort-string/)

## 题目描述
给定字符串 `order` 和 `s`，将 `s` 里的字符按 `order` 中出现的顺序重新排列；  
`order` 中未出现的字符可以放在任意位置（通常放在最后）。

## 示例
- 示例  
输入：`order = "cba", s = "abcd"`  
输出：`"cbad"`

## 最佳解法思路
- 思路1（推荐）：计数  
统计 `s` 中每个字符出现次数。  
先按 `order` 把对应字符写出来，再把剩余字符按任意顺序写出来即可。

## Java 最佳实现

```java
class Solution {
    public String customSortString(String order, String s) {
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) cnt[s.charAt(i) - 'a']++;

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < order.length(); i++) {
            char c = order.charAt(i);
            int k = cnt[c - 'a'];
            for (int t = 0; t < k; t++) sb.append(c);
            cnt[c - 'a'] = 0;
        }
        for (int i = 0; i < 26; i++) {
            for (int t = 0; t < cnt[i]; t++) sb.append((char) ('a' + i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析
- 时间：\(O(|order| + |s|)\)
- 空间：\(O(1)\)
