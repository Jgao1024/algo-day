# 398. 随机数索引

- 题号：398
- 难度：中等
- LeetCode：[随机数索引](https://leetcode.cn/problems/random-pick-index/)

## 题目描述
给定整数数组 `nums`（可能有重复），实现 `pick(target)`：  
等概率返回 `nums[i] == target` 的任意下标 `i`。

## 示例
- 示例  
输入：`nums = [1,2,3,3,3]，pick(3)`  
输出：随机返回 `2/3/4` 之一，且等概率。

## 最佳解法思路
- 思路1（推荐）：蓄水池抽样（Reservoir Sampling）  
遍历数组，遇到一个 `target` 计数 `cnt++`，以 `1/cnt` 的概率把答案更新为当前下标。  
这样无需保存所有下标，且保证等概率。

## Java 最佳实现

```java
import java.util.Random;

class Solution {
    private final int[] nums;
    private final Random random = new Random();

    public Solution(int[] nums) {
        this.nums = nums;
    }

    public int pick(int target) {
        int ans = -1;
        int cnt = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                cnt++;
                if (random.nextInt(cnt) == 0) ans = i;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：每次 `pick` 为 \(O(n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 遇到第 `cnt` 个目标，用 `1/cnt` 概率替换答案，最终等概率。
