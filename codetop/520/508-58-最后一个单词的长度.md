# 58. 最后一个单词的长度

- 题号：58
- 难度：简单
- LeetCode：[最后一个单词的长度](https://leetcode.cn/problems/length-of-last-word/)

## 题目描述
给定字符串 `s`（可能有尾部空格），返回最后一个单词的长度。单词由非空格字符组成。

## 示例
- 示例  
输入：`s = "Hello World"`  
输出：`5`

## 最佳解法思路
- 思路1（推荐）：从后往前扫描  
先跳过尾部空格，然后计数直到遇到空格或到头为止。

## Java 最佳实现

```java
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') i--;
        int ans = 0;
        while (i >= 0 && s.charAt(i) != ' ') {
            ans++;
            i--;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
