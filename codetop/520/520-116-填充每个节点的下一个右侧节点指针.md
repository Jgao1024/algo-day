# 116. 填充每个节点的下一个右侧节点指针

- 题号：116
- 难度：中等
- LeetCode：[填充每个节点的下一个右侧节点指针](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node/)

## 题目描述
给定一棵**完美二叉树**（每个父节点有两个孩子，所有叶子在同一层），把每个节点的 `next` 指针指向同层右侧节点；若无则为 `null`。返回根节点。

## 示例
- 示例  
输入：`root = [1,2,3,4,5,6,7]`  
输出：按层 next 链接为 `1->null, 2->3->null, 4->5->6->7->null`

## 最佳解法思路
- 思路1（推荐）：O(1) 额外空间逐层连接  
利用完美二叉树性质：  
对每个节点 `cur`：  
`cur.left.next = cur.right`  
若 `cur.next != null`，则 `cur.right.next = cur.next.left`  
一层处理完后，移动到下一层最左节点。

## Java 最佳实现

```java
class Solution {
    public Node connect(Node root) {
        if (root == null) return null;
        Node leftMost = root;
        while (leftMost.left != null) {
            Node cur = leftMost;
            while (cur != null) {
                cur.left.next = cur.right;
                if (cur.next != null) cur.right.next = cur.next.left;
                cur = cur.next;
            }
            leftMost = leftMost.left;
        }
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
