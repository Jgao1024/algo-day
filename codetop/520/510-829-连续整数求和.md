# 829. 连续整数求和

- 题号：829
- 难度：困难
- LeetCode：[连续整数求和](https://leetcode.cn/problems/consecutive-numbers-sum/)

## 题目描述
给定正整数 `n`，返回将 `n` 表示为若干个连续正整数之和的方式数。

## 示例
- 示例  
输入：`n = 15`  
输出：`4`  
解释：`15 = 15 = 7+8 = 4+5+6 = 1+2+3+4+5`

## 最佳解法思路
- 思路1（推荐）：枚举长度 \(k\) 的数学推导  
设连续正整数从 `x` 开始，共 `k` 个：  
\[
n = x + (x+1) + \cdots + (x+k-1) = kx + \frac{k(k-1)}{2}
\]
所以：
\[
x = \frac{n - k(k-1)/2}{k}
\]
只要 `n - k(k-1)/2 > 0` 且能被 `k` 整除，就有一种方案。枚举 `k` 即可（直到 `k(k-1)/2 >= n`）。

## Java 最佳实现

```java
class Solution {
    public int consecutiveNumbersSum(int n) {
        long N = n;
        int ans = 0;
        for (long k = 1; k * (k - 1) / 2 < N; k++) {
            long rest = N - k * (k - 1) / 2;
            if (rest % k == 0) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(\sqrt{n})\)
- 空间：\(O(1)\)
