# 269. 火星词典

- 题号：269
- 难度：困难
- LeetCode：[火星词典](https://leetcode.cn/problems/alien-dictionary/)

## 题目描述
给定按火星字母顺序排序的单词列表 `words`，推导字母的顺序并返回。  
若不存在合法顺序则返回空串。

## 示例
- 示例  
输入：`["wrt","wrf","er","ett","rftt"]`  
输出：`"wertf"`

## 最佳解法思路
- 思路1（推荐）：建图 + 拓扑排序  
相邻单词 `a/b` 找到第一个不同字符 `a[i] != b[i]`，得到有向边 `a[i] -> b[i]`。  
特殊非法：若 `a` 以 `b` 为前缀且 `a` 更长（如 `"abc"` 在 `"ab"` 前），则无解。  
建好图后用 BFS 拓扑排序（Kahn），若结果长度不等于出现过的字符数量，说明有环，无解。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public String alienOrder(String[] words) {
        Map<Character, Set<Character>> g = new HashMap<>();
        Map<Character, Integer> indeg = new HashMap<>();
        for (String w : words) {
            for (int i = 0; i < w.length(); i++) {
                char c = w.charAt(i);
                g.putIfAbsent(c, new HashSet<>());
                indeg.putIfAbsent(c, 0);
            }
        }

        for (int i = 0; i < words.length - 1; i++) {
            String a = words[i];
            String b = words[i + 1];
            int len = Math.min(a.length(), b.length());
            int p = 0;
            while (p < len && a.charAt(p) == b.charAt(p)) p++;
            if (p == len) {
                if (a.length() > b.length()) return "";
                continue;
            }
            char from = a.charAt(p);
            char to = b.charAt(p);
            if (g.get(from).add(to)) {
                indeg.put(to, indeg.get(to) + 1);
            }
        }

        Deque<Character> q = new ArrayDeque<>();
        for (Map.Entry<Character, Integer> e : indeg.entrySet()) {
            if (e.getValue() == 0) q.addLast(e.getKey());
        }

        StringBuilder sb = new StringBuilder();
        while (!q.isEmpty()) {
            char cur = q.pollFirst();
            sb.append(cur);
            for (char nxt : g.get(cur)) {
                indeg.put(nxt, indeg.get(nxt) - 1);
                if (indeg.get(nxt) == 0) q.addLast(nxt);
            }
        }
        return sb.length() == indeg.size() ? sb.toString() : "";
    }
}
```

- 时间：\(O(\text{总字符数} + \text{边数})\)
- 空间：\(O(\text{字符数} + \text{边数})\)
