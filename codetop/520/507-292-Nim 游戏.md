# 292. Nim 游戏

- 题号：292
- 难度：简单
- LeetCode：[Nim 游戏](https://leetcode.cn/problems/nim-game/)

## 题目描述
桌上有 `n` 颗石子，你和对手轮流拿，每次可拿 `1~3` 颗，先拿完者获胜。  
双方都采取最优策略，判断先手是否必胜。

## 示例
- 示例  
输入：`n = 4`  
输出：`false`

## 最佳解法思路
- 思路1（推荐）：数学结论  
当且仅当 `n` 是 4 的倍数时，先手必败；否则先手必胜。  
原因：`n=4` 必败；若 `n%4!=0`，先手拿到让对手剩 4 的倍数即可；若对手拿 `1~3`，先手再补到 4 的倍数。

## Java 最佳实现

```java
class Solution {
    public boolean canWinNim(int n) {
        return n % 4 != 0;
    }
}
```
