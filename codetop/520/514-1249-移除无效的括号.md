# 1249. 移除无效的括号

- 题号：1249
- 难度：中等
- LeetCode：[移除无效的括号](https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/)

## 题目描述
给定字符串 `s`（包含小写字母和括号），移除最少数量的括号，使其成为有效括号字符串，返回任意一个结果。

## 示例
- 示例  
输入：`s = "lee(t(c)o)de)"`  
输出：`"lee(t(c)o)de"`

## 最佳解法思路
- 思路1（推荐）：两次扫描  
第一次从左到右，删除多余的 `)`：维护 `balance`，遇到 `)` 且 `balance==0` 就跳过；否则正常写入。  
第二次从右到左，删除多余的 `(`：同理维护 `balance`（这次把 `(` 当作需要匹配的多余项），最后反转回来。

## Java 最佳实现

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        StringBuilder sb = new StringBuilder();
        int balance = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                balance++;
                sb.append(c);
            } else if (c == ')') {
                if (balance == 0) continue;
                balance--;
                sb.append(c);
            } else {
                sb.append(c);
            }
        }

        StringBuilder res = new StringBuilder();
        for (int i = sb.length() - 1; i >= 0; i--) {
            char c = sb.charAt(i);
            if (c == '(') {
                if (balance > 0) {
                    balance--;
                    continue;
                }
            }
            res.append(c);
        }
        return res.reverse().toString();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
