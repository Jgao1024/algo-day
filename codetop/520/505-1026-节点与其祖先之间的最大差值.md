# 1026. 节点与其祖先之间的最大差值

- 题号：1026
- 难度：中等
- LeetCode：[节点与其祖先之间的最大差值](https://leetcode.cn/problems/maximum-difference-between-node-and-ancestor/)

## 题目描述
给定二叉树 `root`，返回任意节点与其祖先节点之间的最大差值（绝对值）。

## 示例
- 示例  
输入：`root = [8,3,10,1,6,null,14,null,null,4,7,13]`  
输出：`7`

## 最佳解法思路
- 思路1（推荐）：DFS 维护路径上的最小/最大值  
从根往下 DFS，沿途维护当前路径上的 `minVal/maxVal`。  
到达每个节点时，用 `max(|node-minVal|, |node-maxVal|)` 更新答案，然后继续向下传递新的最小/最大。

## Java 最佳实现

```java
class Solution {
    private int ans = 0;

    public int maxAncestorDiff(TreeNode root) {
        if (root == null) return 0;
        dfs(root, root.val, root.val);
        return ans;
    }

    private void dfs(TreeNode node, int minVal, int maxVal) {
        if (node == null) return;
        ans = Math.max(ans, Math.max(Math.abs(node.val - minVal), Math.abs(node.val - maxVal)));
        int mn = Math.min(minVal, node.val);
        int mx = Math.max(maxVal, node.val);
        dfs(node.left, mn, mx);
        dfs(node.right, mn, mx);
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
