# 1120. 子树的最大平均值

- 题号：1120
- 难度：中等
- LeetCode：[子树的最大平均值](https://leetcode.cn/problems/maximum-average-subtree/)

## 题目描述
给定二叉树 `root`，返回任意子树（包含某个节点及其所有后代）的最大平均值。

## 示例
- 示例  
输入：`root = [5,6,1]`  
输出：`6.0`

## 最佳解法思路
- 思路1（推荐）：后序 DFS 统计 (sum, count)  
对每个节点，后序返回其子树的 `sum` 和 `count`，平均值为 `sum / count`，用它更新全局最大值。  
最后返回最大平均值即可。

## Java 最佳实现

```java
class Solution {
    private double ans = Double.NEGATIVE_INFINITY;

    public double maximumAverageSubtree(TreeNode root) {
        dfs(root);
        return ans;
    }

    private long[] dfs(TreeNode node) {
        if (node == null) return new long[]{0, 0};
        long[] left = dfs(node.left);
        long[] right = dfs(node.right);
        long sum = left[0] + right[0] + node.val;
        long cnt = left[1] + right[1] + 1;
        ans = Math.max(ans, (double) sum / (double) cnt);
        return new long[]{sum, cnt};
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)
