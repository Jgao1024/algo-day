# 面试题 17.15. 最长单词

- 题号：面试题 17.15
- 难度：中等
- LeetCode：[最长单词](https://leetcode.cn/problems/longest-word-lcci/)

## 题目描述
给定字符串数组 `words`，找出其中最长的单词，使得它可以由数组中其它单词逐个拼接而成（至少两个）。  
若有多个答案，返回任意一个。

## 示例
- 示例  
输入：`["cat","banana","dog","nana","walk","walker","dogwalker"]`  
输出：`"dogwalker"`

## 最佳解法思路
- 思路1（推荐）：按长度排序 + DP 判断可拼接  
按单词长度从小到大排序，用集合保存已处理的较短单词。  
对当前单词 `w`，用 `wordBreak` 的 DP 判断是否能由集合中的词拼出来；能则更新答案。  
判断时不把 `w` 自己放进集合，避免用自身构成。

## Java 最佳实现

```java
import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public String longestWord(String[] words) {
        Arrays.sort(words, (a, b) -> a.length() - b.length());
        Set<String> dict = new HashSet<>();
        String ans = "";
        for (String w : words) {
            if (!dict.isEmpty() && canBuild(w, dict)) {
                if (w.length() > ans.length()) ans = w;
            }
            dict.add(w);
        }
        return ans;
    }

    private boolean canBuild(String s, Set<String> dict) {
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (!dp[j]) continue;
                if (dict.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：设最大长度为 \(L\)，总单词数为 \(m\)，最坏约 \(O(m \cdot L^2)\)
- 空间：\(O(L + |dict|)\)
