# 1227. 飞机座位分配概率

- 题号：1227
- 难度：中等
- LeetCode：[飞机座位分配概率](https://leetcode.cn/problems/airplane-seat-assignment-probability/)

## 题目描述
有 `n` 个乘客按顺序登机，每人都有自己的座位号。  
第一个乘客随机坐一个座位；之后每个乘客若自己座位空着就坐自己座位，否则随机坐剩余空座位。  
返回第 `n` 个乘客坐到自己座位的概率。

## 示例
- 示例  
输入：`n = 2`  
输出：`0.5`

## 最佳解法思路
- 思路1（推荐）：经典结论  
当 `n == 1` 时概率为 1。  
当 `n > 1` 时概率恒为 0.5。  
直观理解：整个过程的“关键随机座位”最终只可能落在“1 号座位”或“n 号座位”，两者对称，概率各一半。

## Java 最佳实现

```java
class Solution {
    public double nthPersonGetsNthSeat(int n) {
        return n == 1 ? 1.0 : 0.5;
    }
}
```
