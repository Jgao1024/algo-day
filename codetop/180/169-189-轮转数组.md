## 最佳解法思路
- 思路（推荐）：三次翻转（原地）  
把数组右转 k 位：  
1) 翻转全数组  
2) 翻转前 k 个  
3) 翻转后 n-k 个  
注意 k 需要对 n 取模。

## Java 最佳实现

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            int tmp = nums[l];
            nums[l] = nums[r];
            nums[r] = tmp;
            l++;
            r--;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
