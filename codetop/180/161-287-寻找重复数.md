## 最佳解法思路
- 思路（推荐）：Floyd 判圈（把数组看作链表）  
因为 nums[i] 在 1..n，令 next(x)=nums[x]，从 0 出发必然进入环，环入口就是重复数。  
先用快慢指针相遇；再让一个指针回到起点，同速前进，相遇点即入口。

## Java 最佳实现

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = 0, fast = 0;
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        int p = 0;
        while (p != slow) {
            p = nums[p];
            slow = nums[slow];
        }
        return p;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)

- 把 `i -> nums[i]` 当 next 指针：**重复数 = 环入口**。
