## 最佳解法思路
- 思路（推荐）：反转一半数字  
负数一定不是回文。  
不断把末位取出拼到 `rev`，直到 `rev >= x`；  
偶数位：x == rev；奇数位：x == rev/10。

## Java 最佳实现

```java
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        if (x != 0 && x % 10 == 0) return false;

        int rev = 0;
        while (x > rev) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return x == rev || x == rev / 10;
    }
}
```

## 复杂度分析
- 时间：\(O(\log x)\)
- 空间：\(O(1)\)
