## 最佳解法思路
- 思路（推荐）：双指针拆分再拼接  
维护 odd 指针走奇数位，even 指针走偶数位，同时保存偶链表头 evenHead。  
最后 odd.next = evenHead。

## Java 最佳实现

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null) return null;
        ListNode odd = head;
        ListNode even = head.next;
        ListNode evenHead = even;

        while (even != null && even.next != null) {
            odd.next = even.next;
            odd = odd.next;
            even.next = odd.next;
            even = even.next;
        }
        odd.next = evenHead;
        return head;
    }
}
```

- 空间：\(O(1)\)
