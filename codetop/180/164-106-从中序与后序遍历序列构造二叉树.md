## 最佳解法思路
- 思路（推荐）：递归分治 + HashMap 快速定位根  
后序遍历最后一个元素是根。  
在中序中找到根的位置后，左右子树规模确定，再递归构建。  
用全局指针从后往前扫 postorder：先建右子树再建左子树。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int idx;
    private int[] postorder;
    private Map<Integer, Integer> inPos;

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        this.idx = postorder.length - 1;
        this.postorder = postorder;
        this.inPos = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) inPos.put(inorder[i], i);
        return build(0, inorder.length - 1);
    }

    private TreeNode build(int inL, int inR) {
        if (inL > inR) return null;
        int rootVal = postorder[idx--];
        TreeNode root = new TreeNode(rootVal);
        int k = inPos.get(rootVal);
        root.right = build(k + 1, inR);
        root.left = build(inL, k - 1);
        return root;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)（哈希表 + 递归栈）

## 总结（速记）
- 后序末尾是根；用中序切分左右区间；**建树顺序：右后左**（配合后序从后往前）。
