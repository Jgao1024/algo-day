## 最佳解法思路
- 思路（推荐）：自底向上 DP（滚动数组）  
从最后一行开始，`dp[j]` 表示“到达当前位置下面那一层的最小和”。  
向上更新：`dp[j] = min(dp[j], dp[j+1]) + triangle[i][j]`。

## Java 最佳实现

```java
import java.util.List;

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        int[] dp = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            List<Integer> row = triangle.get(i);
            for (int j = 0; j < row.size(); j++) {
                dp[j] = Math.min(dp[j], dp[j + 1]) + row.get(j);
            }
        }
        return dp[0];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
