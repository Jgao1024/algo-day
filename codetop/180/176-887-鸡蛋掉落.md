## 最佳解法思路
- 思路（推荐）：换维 DP（按“操作次数”推能测的楼层数）  
定义 `dp[k]`：在当前操作次数 m 下，用 k 个鸡蛋最多能确定的楼层数。  
每增加一次操作：  
`dp[k] = dp[k] + dp[k-1] + 1`  
含义：扔一次后，碎了看下面 `dp[k-1]` 层，不碎看上面 `dp[k]` 层，再加当前这一层。  
从 k=K 递减更新，直到 `dp[K] >= N`，m 即最少次数。

## Java 最佳实现

```java
class Solution {
    public int superEggDrop(int K, int N) {
        long[] dp = new long[K + 1];
        int m = 0;
        while (dp[K] < N) {
            m++;
            for (int k = K; k >= 1; k--) {
                dp[k] = dp[k] + dp[k - 1] + 1;
            }
        }
        return m;
    }
}
```

## 复杂度分析
- 时间：\(O(K \cdot m)\)，m 为答案（一般远小于 N）
- 空间：\(O(K)\)
