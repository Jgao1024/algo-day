## 最佳解法思路
- 思路（推荐）：Fisher–Yates 洗牌（等概率）  
从后往前遍历 i：在 [0..i] 随机选 j，与 i 交换。  
reset 返回初始数组副本，shuffle 在工作副本上洗牌。

## Java 最佳实现

```java
import java.util.Random;

class Solution {
    private final int[] origin;
    private final Random random = new Random();

    public Solution(int[] nums) {
        origin = nums.clone();
    }

    public int[] reset() {
        return origin.clone();
    }

    public int[] shuffle() {
        int[] a = origin.clone();
        for (int i = a.length - 1; i > 0; i--) {
            int j = random.nextInt(i + 1);
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：shuffle \(O(n)\)，reset \(O(n)\)
- 空间：\(O(n)\)（返回副本）
