## 最佳解法思路
- 思路（推荐）：01 背包（能否凑出 sum/2）  
总和 sum 为奇数直接 false。目标 target=sum/2。  
用一维 dp：`dp[j]` 表示是否能凑出和 j。  
遍历每个数 x 时，j 从 target 递减到 x：`dp[j] |= dp[j-x]`。

## Java 最佳实现

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) sum += x;
        if ((sum & 1) == 1) return false;
        int target = sum / 2;

        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int x : nums) {
            for (int j = target; j >= x; j--) {
                dp[j] = dp[j] || dp[j - x];
            }
        }
        return dp[target];
    }
}
```

## 复杂度分析
- 时间：\(O(n \cdot target)\)
- 空间：\(O(target)\)
