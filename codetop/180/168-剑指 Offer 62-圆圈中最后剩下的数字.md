## 最佳解法思路
- 思路（推荐）：约瑟夫环递推  
设 f(n) 为 n 个人最后剩下的编号（0-based）。  
递推：`f(1)=0`，`f(n) = (f(n-1) + m) % n`。

## Java 最佳实现

```java
class Solution {
    public int lastRemaining(int n, int m) {
        int ans = 0;
        for (int i = 2; i <= n; i++) {
            ans = (ans + m) % i;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
