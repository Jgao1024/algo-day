## 最佳解法思路
- 思路（推荐）：中序遍历（BST 中序递增）  
用栈做迭代中序遍历，访问到第 k 个节点就是答案。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            if (--k == 0) return cur.val;
            cur = cur.right;
        }
        return -1;
    }
}
```

## 复杂度分析
- 时间：\(O(h + k)\)（最坏 \(O(n)\)）
- 空间：\(O(h)\)
