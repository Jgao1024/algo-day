## 最佳解法思路
- 思路（推荐）：DP（卡特兰数）  
设 `dp[i]` 表示 i 个节点能构成的 BST 数量。  
枚举根为 j（1..i），左子树节点 j-1，右子树 i-j：  
`dp[i] += dp[j-1] * dp[i-j]`。

## Java 最佳实现

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            int sum = 0;
            for (int root = 1; root <= i; root++) {
                sum += dp[root - 1] * dp[i - root];
            }
            dp[i] = sum;
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(n)\)
