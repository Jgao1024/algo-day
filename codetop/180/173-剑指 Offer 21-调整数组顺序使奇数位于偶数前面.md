## 最佳解法思路
- 思路（推荐）：双指针原地分区  
左指针找偶数，右指针找奇数，交换后继续推进，直到相遇。

## Java 最佳实现

```java
class Solution {
    public int[] exchange(int[] nums) {
        int l = 0, r = nums.length - 1;
        while (l < r) {
            while (l < r && (nums[l] & 1) == 1) l++;
            while (l < r && (nums[r] & 1) == 0) r--;
            if (l < r) {
                int tmp = nums[l];
                nums[l] = nums[r];
                nums[r] = tmp;
                l++;
                r--;
            }
        }
        return nums;
    }
}
```
