## 最佳解法思路
- 思路（推荐）：DP（前缀能否拼出）  
设 `dp[i][j]` 表示 s1 前 i 个字符与 s2 前 j 个字符能否交错组成 s3 前 i+j 个字符。  
转移：
  - 若 s1[i-1]==s3[i+j-1] 且 dp[i-1][j] 为真
  - 或 s2[j-1]==s3[i+j-1] 且 dp[i][j-1] 为真  
用一维滚动数组优化空间。

## Java 最佳实现

```java
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int n1 = s1.length(), n2 = s2.length();
        if (n1 + n2 != s3.length()) return false;

        boolean[] dp = new boolean[n2 + 1];
        dp[0] = true;
        for (int j = 1; j <= n2; j++) {
            dp[j] = dp[j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
        }

        for (int i = 1; i <= n1; i++) {
            dp[0] = dp[0] && s1.charAt(i - 1) == s3.charAt(i - 1);
            for (int j = 1; j <= n2; j++) {
                char c = s3.charAt(i + j - 1);
                dp[j] = (dp[j] && s1.charAt(i - 1) == c) || (dp[j - 1] && s2.charAt(j - 1) == c);
            }
        }
        return dp[n2];
    }
}
```

## 复杂度分析
- 时间：\(O(n_1 n_2)\)
- 空间：\(O(n_2)\)
