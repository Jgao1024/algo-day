# 160. 相交链表

- 题号：160
- 难度：简单
- LeetCode：[相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

## 题目描述
给你两个单链表的头节点 `headA` 和 `headB`，返回两个链表相交的起始节点；如果不相交返回 `null`。

链表结构不能被修改。

## 示例
- 示例  
输入：`listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]`（相交从值 8 的节点开始）  
输出：相交节点

## 最佳解法思路
- 思路1（推荐）：双指针换头  
两个指针 `pA/pB` 分别走 A、B；走到尾就切换到另一条链表头。  
这样两指针走过的总步数相同（A+B），若相交会在交点相遇；不相交会在 `null` 相遇。

- 思路2：先算长度差再对齐  
计算长度差，让长链表先走差值步，再一起走，首次相同即交点。

## Java 最佳实现

```java
class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode a = headA;
        ListNode b = headB;
        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;
    }
}
```

## 复杂度分析
- 时间：\(O(m+n)\)
- 空间：\(O(1)\)

## 总结（速记）
- 换头法的本质：让两指针都走完 A+B 的长度，从而对齐到同一“相对位置”。
