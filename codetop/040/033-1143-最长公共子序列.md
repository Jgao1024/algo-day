# 1143. 最长公共子序列

- 题号：1143
- 难度：中等
- LeetCode：[最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)

## 题目描述
给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长公共子序列（LCS）的长度。

## 示例
- 示例  
输入：`text1 = "abcde", text2 = "ace"`  
输出：`3`（"ace"）

## 最佳解法思路
- 思路1（推荐）：二维 DP（可滚动压缩）  
`dp[i][j]` 表示 `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的 LCS 长度。  
若 `c1==c2`：`dp[i][j]=dp[i-1][j-1]+1`  
否则：`dp[i][j]=max(dp[i-1][j], dp[i][j-1])`。

## Java 最佳实现

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        int[] dp = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            int prevDiag = 0;
            for (int j = 1; j <= n; j++) {
                int tmp = dp[j];
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[j] = prevDiag + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prevDiag = tmp;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)
