# 19. 删除链表的倒数第N个节点

- 题号：19
- 难度：中等
- LeetCode：[删除链表的倒数第N个节点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

## 题目描述
给你一个链表，删除链表的倒数第 `n` 个节点，并返回链表的头节点。

## 示例
- 示例  
输入：`1->2->3->4->5, n = 2`  
输出：`1->2->3->5`

## 最佳解法思路
- 思路1（推荐）：快慢指针 + dummy  
用 `dummy` 指向头，快指针先走 `n` 步，然后快慢一起走，直到快指针到尾。此时慢指针在待删除节点的前一个节点，执行删除即可。

## Java 最佳实现

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode fast = dummy;
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }

        ListNode slow = dummy;
        while (fast.next != null) {
            fast = fast.next;
            slow = slow.next;
        }

        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
