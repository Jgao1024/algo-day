# 56. 合并区间

- 题号：56
- 难度：中等
- LeetCode：[合并区间](https://leetcode.cn/problems/merge-intervals/)

## 题目描述
以数组 `intervals` 表示若干区间，其中 `intervals[i] = [start, end]`。

合并所有重叠的区间，并返回一个不重叠的区间数组，按起点升序。

## 示例
- 示例1  
输入：`intervals = [[1,3],[2,6],[8,10],[15,18]]`  
输出：`[[1,6],[8,10],[15,18]]`

- 示例2  
输入：`intervals = [[1,4],[4,5]]`  
输出：`[[1,5]]`

## 最佳解法思路
- 思路1（推荐）：排序 + 扫描  
先按区间起点排序。维护当前合并区间 `[curL, curR]`：  
若下一个区间 `start <= curR`，就合并：`curR = max(curR, end)`；否则把当前区间加入结果，开始新的区间。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        List<int[]> res = new ArrayList<>();

        int curL = intervals[0][0];
        int curR = intervals[0][1];
        for (int i = 1; i < intervals.length; i++) {
            int s = intervals[i][0];
            int e = intervals[i][1];
            if (s <= curR) {
                curR = Math.max(curR, e);
            } else {
                res.add(new int[]{curL, curR});
                curL = s;
                curR = e;
            }
        }
        res.add(new int[]{curL, curR});

        return res.toArray(new int[0][]);
    }
}
```

## 复杂度分析
- 时间：排序 \(O(n\log n)\) + 扫描 \(O(n)\)
- 空间：\(O(n)\)（输出）
