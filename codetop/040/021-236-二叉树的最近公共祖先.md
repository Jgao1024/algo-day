# 236. 二叉树的最近公共祖先

- 题号：236
- 难度：中等
- LeetCode：[二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

## 题目描述
给定一棵二叉树，找到两个节点 `p`、`q` 的最近公共祖先（LCA）。

最近公共祖先定义：对于节点 `p`、`q`，距离它们最近（最深）的那个公共祖先节点。

## 示例
- 示例  
输入：`root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1`  
输出：`3`

## 最佳解法思路
- 思路1（推荐）：后序 DFS  
递归返回“当前子树是否包含 p 或 q”。  
如果当前节点等于 `p/q`，或左右子树分别包含 `p/q`，则当前节点就是 LCA。

- 思路2：记录父指针 + 集合  
DFS 记录每个节点的 parent，然后从 `p` 往上把祖先放集合，再从 `q` 往上第一个命中集合的节点就是 LCA。

## Java 最佳实现

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) return null;
        if (root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) return root;
        return left != null ? left : right;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(h)\)（递归栈，h 为树高）

## 总结（速记）
- 二叉树 LCA 记住一句：**左右都找到就返回当前；只找到一边就向上返回那一边**。
