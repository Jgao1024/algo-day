# 72. 编辑距离

- 题号：72
- 难度：困难
- LeetCode：[编辑距离](https://leetcode.cn/problems/edit-distance/)

## 题目描述
给你两个字符串 `word1` 和 `word2`，返回将 `word1` 转换成 `word2` 所使用的最少操作数。

允许的操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

## 示例
- 示例1  
输入：`word1 = "horse", word2 = "ros"`  
输出：`3`

- 示例2  
输入：`word1 = "intention", word2 = "execution"`  
输出：`5`

## 最佳解法思路
- 思路1（推荐）：DP  
`dp[i][j]` 表示 `word1` 前 `i` 个字符变成 `word2` 前 `j` 个字符的最小编辑距离。  
转移：  
若 `c1==c2`：`dp[i][j]=dp[i-1][j-1]`  
否则取三种操作最小：  
替换：`dp[i-1][j-1] + 1`  
删除：`dp[i-1][j] + 1`  
插入：`dp[i][j-1] + 1`

空间可以用滚动数组压到 \(O(n)\)。

## Java 最佳实现

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[] dp = new int[n + 1];

        for (int j = 0; j <= n; j++) dp[j] = j;

        for (int i = 1; i <= m; i++) {
            int prevDiag = dp[0];
            dp[0] = i;
            for (int j = 1; j <= n; j++) {
                int tmp = dp[j];
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prevDiag;
                } else {
                    int replace = prevDiag + 1;
                    int delete = dp[j] + 1;
                    int insert = dp[j - 1] + 1;
                    dp[j] = Math.min(replace, Math.min(delete, insert));
                }
                prevDiag = tmp;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析
- 时间：\(O(mn)\)
- 空间：\(O(n)\)

## 总结（速记）
- 编辑距离模板就三种操作；滚动数组时要保存 `dp[j]`（上方）和 `prevDiag`（左上）。
