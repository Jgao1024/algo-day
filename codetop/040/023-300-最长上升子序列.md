# 300. 最长上升子序列

- 题号：300
- 难度：中等
- LeetCode：[最长上升子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

## 题目描述
给你一个整数数组 `nums`，返回最长严格递增子序列（LIS）的长度。

## 示例
- 示例1  
输入：`nums = [10,9,2,5,3,7,101,18]`  
输出：`4`  
解释：LIS 可以是 `[2,3,7,101]`

- 示例2  
输入：`nums = [0,1,0,3,2,3]`  
输出：`4`

## 最佳解法思路
- 思路1（推荐）：贪心 + 二分（扑克牌法）  
维护数组 `tails[len]`：长度为 `len+1` 的递增子序列，其末尾元素的最小可能值。  
遍历每个数 `x`，在 `tails` 中二分找第一个 `>= x` 的位置替换；若都小于 `x` 就扩展长度。`tails` 长度就是答案。

- 思路2：DP \(O(n^2)\)  
`dp[i]` 表示以 `i` 结尾的 LIS 长度，转移：`dp[i]=max(dp[j]+1)`（j<i 且 nums[j]<nums[i]）。

## Java 最佳实现

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int x : nums) {
            int l = 0, r = size;
            while (l < r) {
                int mid = (l + r) >>> 1;
                if (tails[mid] >= x) r = mid;
                else l = mid + 1;
            }
            tails[l] = x;
            if (l == size) size++;
        }
        return size;
    }
}
```

## 复杂度分析
- 时间：\(O(n\log n)\)
- 空间：\(O(n)\)
