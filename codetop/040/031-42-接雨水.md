# 42. 接雨水

- 题号：42
- 难度：困难
- LeetCode：[接雨水](https://leetcode.cn/problems/trapping-rain-water/)

## 题目描述
给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算下雨之后能接多少雨水。

## 示例
- 示例  
输入：`height = [0,1,0,2,1,0,1,3,2,1,2,1]`  
输出：`6`

## 最佳解法思路
- 思路1（推荐）：双指针  
维护 `left/right` 指针，以及 `leftMax/rightMax`。  
总是移动较低的一侧：  
若 `height[left] < height[right]`，则此处可接水为 `leftMax - height[left]`（若为正），并更新 `leftMax`；否则对右侧做同样处理。  
因为低的一侧决定当前能接多少水。

- 思路2：单调栈  
维护递减栈，遇到更高柱子时弹栈计算“凹槽水量”。

## Java 最佳实现

```java
class Solution {
    public int trap(int[] height) {
        int l = 0, r = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int ans = 0;

        while (l < r) {
            if (height[l] < height[r]) {
                if (height[l] >= leftMax) leftMax = height[l];
                else ans += leftMax - height[l];
                l++;
            } else {
                if (height[r] >= rightMax) rightMax = height[r];
                else ans += rightMax - height[r];
                r--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
