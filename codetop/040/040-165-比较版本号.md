# 165. 比较版本号

- 题号：165
- 难度：中等
- LeetCode：[比较版本号](https://leetcode.cn/problems/compare-version-numbers/)

## 题目描述
给定两个版本号字符串 `version1` 和 `version2`，比较它们的大小。

版本号由 `.` 分隔的修订号组成。比较时按从左到右逐段比较数值；缺失的段视为 0。  
返回：`1` 表示 `version1 > version2`，`-1` 表示 `<`，`0` 表示相等。

## 示例
- 示例1  
输入：`version1 = "1.01", version2 = "1.001"`  
输出：`0`

- 示例2  
输入：`version1 = "1.0", version2 = "1.0.0"`  
输出：`0`

- 示例3  
输入：`version1 = "0.1", version2 = "1.1"`  
输出：`-1`

## 最佳解法思路
- 思路1（推荐）：双指针逐段解析  
用指针从左到右读每段数字（跳过点），把段值解析成整数比较。两边某段更大就返回；都相等继续。遍历到两串结束为止。

## Java 最佳实现

```java
class Solution {
    public int compareVersion(String version1, String version2) {
        int i = 0, j = 0;
        int n1 = version1.length();
        int n2 = version2.length();

        while (i < n1 || j < n2) {
            int a = 0;
            while (i < n1 && version1.charAt(i) != '.') {
                a = a * 10 + (version1.charAt(i) - '0');
                i++;
            }
            if (i < n1 && version1.charAt(i) == '.') i++;

            int b = 0;
            while (j < n2 && version2.charAt(j) != '.') {
                b = b * 10 + (version2.charAt(j) - '0');
                j++;
            }
            if (j < n2 && version2.charAt(j) == '.') j++;

            if (a != b) return a > b ? 1 : -1;
        }
        return 0;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
