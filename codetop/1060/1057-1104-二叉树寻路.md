## 最佳解法思路
- **从 label 反推到根**  
第 `level` 层的正常编号范围是 `[start,end] = [2^level, 2^{level+1}-1]`。  
在之字形编号下，某个 `label` 在该层对应的“镜像”是 `start + end - label`。  
父节点的 label 可以用：`label = (start + end - label) / 2` 逐层向上推，直到 1。最后把路径反转。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public List<Integer> pathInZigZagTree(int label) {
        List<Integer> path = new ArrayList<>();
        int cur = label;
        while (cur >= 1) {
            path.add(cur);
            int start = Integer.highestOneBit(cur);
            int end = start * 2 - 1;
            cur = (start + end - cur) / 2;
        }
        Collections.reverse(path);
        return path;
    }
}
```

## 复杂度分析
- 时间：\(O(\log label)\)
- 空间：\(O(\log label)\)
