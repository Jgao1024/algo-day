## 最佳解法思路
- **字符到数字映射**  
先构建 `a-z` 对应的 T9 数字映射表。  
对每个单词，把每个字符转成数字串，与 `num` 完全相等就加入答案。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> getValidT9Words(String num, String[] words) {
        int[] map = build();
        List<String> ans = new ArrayList<>();
        for (String w : words) {
            if (w.length() != num.length()) continue;
            boolean ok = true;
            for (int i = 0; i < w.length(); i++) {
                int d = map[w.charAt(i) - 'a'];
                if (num.charAt(i) != (char) ('0' + d)) {
                    ok = false;
                    break;
                }
            }
            if (ok) ans.add(w);
        }
        return ans;
    }

    private int[] build() {
        int[] m = new int[26];
        fill(m, "abc", 2);
        fill(m, "def", 3);
        fill(m, "ghi", 4);
        fill(m, "jkl", 5);
        fill(m, "mno", 6);
        fill(m, "pqrs", 7);
        fill(m, "tuv", 8);
        fill(m, "wxyz", 9);
        return m;
    }

    private void fill(int[] m, String s, int d) {
        for (int i = 0; i < s.length(); i++) {
            m[s.charAt(i) - 'a'] = d;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(\text{总字符数})\)
- 空间：\(O(1)\)
