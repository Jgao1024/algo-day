## 最佳解法思路
- **自连接算距离，取最小**  
对表 `Point(x,y)` 自连接，限定不同点对并避免重复：`p1.x < p2.x OR (p1.x = p2.x AND p1.y < p2.y)`。  
计算欧氏距离并取最小，按题目要求四舍五入到 2 位小数。

## SQL 最佳实现

```sql
SELECT
  ROUND(MIN(SQRT(POW(p1.x - p2.x, 2) + POW(p1.y - p2.y, 2))), 2) AS shortest
FROM Point p1
JOIN Point p2
  ON (p1.x < p2.x) OR (p1.x = p2.x AND p1.y < p2.y);
```

## 复杂度分析
- 时间：\(O(n^2)\)
- 空间：\(O(1)\)
