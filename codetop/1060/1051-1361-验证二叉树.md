## 最佳解法思路
- **入度 + 从根 BFS 检查连通与成环**  
有效二叉树需要：
  - 每个节点入度 ≤ 1
  - 只有一个根（入度为 0 的节点恰好一个）
  - 从根出发能访问到所有节点（连通且无环）  
先统计入度并找根，再 BFS 遍历左右孩子，若出现重复访问则有环或多父节点。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public boolean validateBinaryTreeNodes(int n, int[] leftChild, int[] rightChild) {
        int[] indeg = new int[n];
        for (int i = 0; i < n; i++) {
            if (leftChild[i] != -1) {
                indeg[leftChild[i]]++;
                if (indeg[leftChild[i]] > 1) return false;
            }
            if (rightChild[i] != -1) {
                indeg[rightChild[i]]++;
                if (indeg[rightChild[i]] > 1) return false;
            }
        }

        int root = -1;
        for (int i = 0; i < n; i++) {
            if (indeg[i] == 0) {
                if (root != -1) return false;
                root = i;
            }
        }
        if (root == -1) return false;

        boolean[] vis = new boolean[n];
        Queue<Integer> q = new ArrayDeque<>();
        q.add(root);
        vis[root] = true;
        int cnt = 1;

        while (!q.isEmpty()) {
            int u = q.poll();
            int l = leftChild[u];
            int r = rightChild[u];
            if (l != -1) {
                if (vis[l]) return false;
                vis[l] = true;
                cnt++;
                q.add(l);
            }
            if (r != -1) {
                if (vis[r]) return false;
                vis[r] = true;
                cnt++;
                q.add(r);
            }
        }
        return cnt == n;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
