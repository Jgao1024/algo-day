## 最佳解法思路
- **Trie 前缀树 + 增量更新**  
每个节点维护该前缀下所有 key 的值之和 `sum`。  
插入时若 key 已存在，需要用 `delta = newVal - oldVal` 沿路径把 `sum` 加上 `delta`。  
查询前缀时走到对应节点直接返回 `sum`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class MapSum {
    private final TrieNode root = new TrieNode();
    private final Map<String, Integer> valMap = new HashMap<>();

    public MapSum() {
    }

    public void insert(String key, int val) {
        int old = valMap.getOrDefault(key, 0);
        int delta = val - old;
        valMap.put(key, val);

        TrieNode cur = root;
        cur.sum += delta;
        for (int i = 0; i < key.length(); i++) {
            int idx = key.charAt(i) - 'a';
            if (cur.next[idx] == null) cur.next[idx] = new TrieNode();
            cur = cur.next[idx];
            cur.sum += delta;
        }
    }

    public int sum(String prefix) {
        TrieNode cur = root;
        for (int i = 0; i < prefix.length(); i++) {
            int idx = prefix.charAt(i) - 'a';
            if (cur.next[idx] == null) return 0;
            cur = cur.next[idx];
        }
        return cur.sum;
    }

    static class TrieNode {
        TrieNode[] next = new TrieNode[26];
        int sum = 0;
    }
}
```

## 复杂度分析
- 时间：`insert/sum` 都是 \(O(L)\)
- 空间：\(O(\text{总字符数})\)
