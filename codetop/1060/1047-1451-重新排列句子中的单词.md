## 最佳解法思路
- **稳定排序按单词长度**  
把句子转小写并按空格分割；按长度升序稳定排序；最后拼回句子并把首字母大写。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public String arrangeWords(String text) {
        String[] words = text.toLowerCase().split(" ");
        Word[] arr = new Word[words.length];
        for (int i = 0; i < words.length; i++) {
            arr[i] = new Word(words[i], i);
        }
        Arrays.sort(arr, (a, b) -> {
            if (a.s.length() != b.s.length()) return a.s.length() - b.s.length();
            return a.idx - b.idx;
        });

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < arr.length; i++) {
            if (i > 0) sb.append(' ');
            sb.append(arr[i].s);
        }
        sb.setCharAt(0, (char) (sb.charAt(0) - 'a' + 'A'));
        return sb.toString();
    }

    static class Word {
        String s;
        int idx;

        Word(String s, int idx) {
            this.s = s;
            this.idx = idx;
        }
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(n)\)
