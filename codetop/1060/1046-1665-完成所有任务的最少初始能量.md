## 最佳解法思路
- **贪心排序（按 min-actual 降序）**  
每个任务 `(actual, minimum)`：做之前能量至少 `minimum`，做完消耗 `actual`。  
把任务按 `minimum-actual` 从大到小排序（越“亏”的越先做），然后顺序遍历维护当前能量 `energy`：  
若 `energy < minimum`，先把初始能量补到 `minimum`（累加到答案），再执行消耗。

## Java 最佳实现

```java
import java.util.Arrays;

class Solution {
    public int minimumEffort(int[][] tasks) {
        Arrays.sort(tasks, (a, b) -> (b[1] - b[0]) - (a[1] - a[0]));
        int energy = 0;
        int ans = 0;
        for (int[] t : tasks) {
            int actual = t[0];
            int minimum = t[1];
            if (energy < minimum) {
                ans += minimum - energy;
                energy = minimum;
            }
            energy -= actual;
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n \log n)\)
- 空间：\(O(1)\)（排序额外空间视实现）
