## 最佳解法思路
- **扫描连续 0 段**  
最大距离来源三种情况：
  - 开头连续 0：距离等于段长度
  - 结尾连续 0：距离等于段长度
  - 中间连续 0：坐在中间，距离是 `len/2`  
一次扫描即可。

## Java 最佳实现

```java
class Solution {
    public int maxDistToClosest(int[] seats) {
        int n = seats.length;
        int last = -1;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (seats[i] == 1) {
                if (last == -1) ans = Math.max(ans, i);
                else ans = Math.max(ans, (i - last) / 2);
                last = i;
            }
        }
        ans = Math.max(ans, n - 1 - last);
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
