## 最佳解法思路
- **前缀和 + 哈希表计数**  
数组元素只有 0/1，设前缀和 `pre`。区间和等于 `goal` 等价于 `pre[j]-pre[i]=goal`。  
遍历时用 `map` 统计每个前缀和出现次数，当前答案增加 `map[pre-goal]`。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        Map<Integer, Integer> cnt = new HashMap<>();
        cnt.put(0, 1);
        int pre = 0;
        int ans = 0;
        for (int x : nums) {
            pre += x;
            ans += cnt.getOrDefault(pre - goal, 0);
            cnt.put(pre, cnt.getOrDefault(pre, 0) + 1);
        }
        return ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
