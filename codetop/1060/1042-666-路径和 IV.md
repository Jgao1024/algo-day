## 最佳解法思路
- **哈希表建树 + DFS 累加路径**  
每个三位数 `d p v`：`d` 表示深度，`p` 表示该层位置（从 1 开始），`v` 表示节点值。  
用 `map` 存 `(d,p)->v`，从根 `(1,1)` DFS：子节点是 `(d+1,2p-1)` 和 `(d+1,2p)`。  
若当前节点没有子节点，就是叶子，累加当前路径和。

## Java 最佳实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int pathSum(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int x : nums) {
            int d = x / 100;
            int p = (x / 10) % 10;
            int v = x % 10;
            map.put(d * 10 + p, v);
        }
        return dfs(map, 1, 1, 0);
    }

    private int dfs(Map<Integer, Integer> map, int d, int p, int sum) {
        Integer v = map.get(d * 10 + p);
        if (v == null) return 0;
        int cur = sum + v;
        int ld = d + 1;
        int lp = p * 2 - 1;
        int rp = p * 2;
        boolean hasLeft = map.containsKey(ld * 10 + lp);
        boolean hasRight = map.containsKey(ld * 10 + rp);
        if (!hasLeft && !hasRight) return cur;
        return dfs(map, ld, lp, cur) + dfs(map, ld, rp, cur);
    }
}
```

- 空间：\(O(n)\)
