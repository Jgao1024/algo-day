## 最佳解法思路
- **差分数组统计每年存活人数**  
题目年份范围固定（1900~2000）。用差分：  
`diff[birth]++`，`diff[death+1]--`（死亡当年仍算存活）。  
做前缀和得到每年的存活人数，取最大值对应的最早年份。

## Java 最佳实现

```java
class Solution {
    public int maxAliveYear(int[] birth, int[] death) {
        int base = 1900;
        int[] diff = new int[102];
        for (int i = 0; i < birth.length; i++) {
            diff[birth[i] - base]++;
            diff[death[i] - base + 1]--;
        }

        int cur = 0;
        int best = 0;
        int year = base;
        for (int i = 0; i <= 100; i++) {
            cur += diff[i];
            if (cur > best) {
                best = cur;
                year = base + i;
            }
        }
        return year;
    }
}
```

## 复杂度分析
- 时间：\(O(n + 101)\)
- 空间：\(O(1)\)
