## 最佳解法思路
- **记录 1 的坐标 + 平移向量计数**  
把 `img1/img2` 中值为 1 的坐标分别收集到列表。  
如果把 `img1` 平移 `(dx,dy)`，重叠的 1 的数量等于“某个坐标差向量出现的次数”。  
遍历所有 `a in A`、`b in B`，统计 `(a.x-b.x, a.y-b.y)` 的频次，最大频次就是答案。

## Java 最佳实现

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int largestOverlap(int[][] img1, int[][] img2) {
        int n = img1.length;
        List<int[]> A = ones(img1);
        List<int[]> B = ones(img2);
        Map<Integer, Integer> cnt = new HashMap<>();
        int ans = 0;

        int offset = 2 * n + 1;
        for (int[] a : A) {
            for (int[] b : B) {
                int dx = a[0] - b[0];
                int dy = a[1] - b[1];
                int key = (dx + offset) * 1000 + (dy + offset);
                int v = cnt.getOrDefault(key, 0) + 1;
                cnt.put(key, v);
                if (v > ans) ans = v;
            }
        }
        return ans;
    }

    private List<int[]> ones(int[][] img) {
        int n = img.length;
        List<int[]> list = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (img[i][j] == 1) list.add(new int[]{i, j});
            }
        }
        return list;
    }
}
```

## 复杂度分析
- 时间：\(O(A \cdot B)\)，A/B 为 1 的个数
- 空间：\(O(A \cdot B)\)（最坏）
