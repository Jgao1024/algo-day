## 最佳解法思路
- **前缀和奇偶计数**  
前缀和只有奇/偶两种状态。遍历数组维护当前前缀奇偶 `parity`：  
  - 若当前为奇，则以当前位置结尾的奇数和子数组数量等于之前“偶前缀”的个数  
  - 若当前为偶，则等于之前“奇前缀”的个数  
答案对 \(10^9+7\) 取模。

## Java 最佳实现

```java
class Solution {
    public int numOfSubarrays(int[] arr) {
        int MOD = 1_000_000_007;
        long even = 1;
        long odd = 0;
        int parity = 0;
        long ans = 0;
        for (int x : arr) {
            parity ^= (x & 1);
            if (parity == 1) {
                ans += even;
                odd++;
            } else {
                ans += odd;
                even++;
            }
            ans %= MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(1)\)
