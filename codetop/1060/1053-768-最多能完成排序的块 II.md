## 最佳解法思路
- **单调栈合并区间**  
栈里存每个块的“最大值”。遍历 `arr`：
  - 若当前值 `x >= 栈顶最大值`，可以作为新块开头，入栈 `x`
  - 否则需要和前面块合并：记录当前块最大值 `mx=栈顶`，弹栈直到 `x >= 新栈顶`，最后把 `mx` 压回去  
最终栈的大小就是最大块数。

## Java 最佳实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maxChunksToSorted(int[] arr) {
        Deque<Integer> st = new ArrayDeque<>();
        for (int x : arr) {
            if (st.isEmpty() || x >= st.peek()) {
                st.push(x);
            } else {
                int mx = st.pop();
                while (!st.isEmpty() && x < st.peek()) {
                    st.pop();
                }
                st.push(mx);
            }
        }
        return st.size();
    }
}
```

## 复杂度分析
- 时间：\(O(n)\)
- 空间：\(O(n)\)
