## 最佳解法思路
- **其他字符串固定取较大方向 + 枚举切分点**  
先把每个字符串 `s` 和 `reverse(s)` 取字典序更大的作为默认方向 `best[i]`。  
然后枚举哪一个字符串作为“被切分的那一个” `i`，其余字符串的方向固定为 `best`，它们拼成 `other = best[i+1..] + best[0..i-1]`。  
对 `strs[i]` 的两个方向（原串/反转）分别枚举切分点 `k`，候选为：  
`part = s[k..] + other + s[0..k)`，取所有候选中字典序最大的。

## Java 最佳实现

```java
class Solution {
    public String splitLoopedString(String[] strs) {
        int n = strs.length;
        String[] best = new String[n];
        for (int i = 0; i < n; i++) {
            String s = strs[i];
            String r = new StringBuilder(s).reverse().toString();
            best[i] = s.compareTo(r) >= 0 ? s : r;
        }

        String ans = "";
        for (int i = 0; i < n; i++) {
            StringBuilder otherSb = new StringBuilder();
            for (int j = i + 1; j < n; j++) otherSb.append(best[j]);
            for (int j = 0; j < i; j++) otherSb.append(best[j]);
            String other = otherSb.toString();

            String s0 = best[i];
            String s1 = new StringBuilder(s0).reverse().toString();

            ans = maxAns(ans, tryAllCuts(s0, other));
            ans = maxAns(ans, tryAllCuts(s1, other));
        }
        return ans;
    }

    private String tryAllCuts(String s, String other) {
        String best = "";
        for (int k = 0; k < s.length(); k++) {
            String cand = s.substring(k) + other + s.substring(0, k);
            if (cand.compareTo(best) > 0) best = cand;
        }
        return best;
    }

    private String maxAns(String a, String b) {
        return a.compareTo(b) >= 0 ? a : b;
    }
}
```

- 空间：\(O(L)\)
